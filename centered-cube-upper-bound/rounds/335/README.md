# 第335轮：连续极值捕获几何与可行合并交换

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮构建可直接用于真实hard接收dx的极值几何，继续保留完整B_H总账。

主代理证明：固定完整hard场，若余项比值上确界c>0，所有极值序列的二次捕获特征强收敛到唯一h*，且每个匹配正L1来源满足 cW−F≥||Φg−h*||²。不需要来源紧性或L1极值达到。H=0还得到总质量极限。该定理没有给出c的根阶大小，不能循环回代。

辅助构造在真实可实现的不交捕获型及其并型之间合并来源，保持全部接收均值；不足的跨组共同来源质量会导致明确的比值改进。这给出极值重叠质量下界，保留曲率、原H门及全部前缀。并型可实现性、连续接收适用范围和重复计费重数仍需单独解决，不假定捕获型对并运算封闭。

本机Python完整重跑12个有限接收、真实立方体来源模型：23072项精确检查、7852项普通高精度诊断通过，分别统计。基线、既有极值候选、端点压力三阶段显示：须保留共同捕获支撑、不可比J来源对和倒数失配抵扣，粗D/2总积分会过付。本轮没有重新运行优化器。另9项有理检查将上轮有限证书转成极值特征距离界；不据有限数值推断一般维度指数。

独审先筛命题再核证明。一般根阶系数、饱和重尾、软层、极端尺度比、初始/删除时间项与总吸收仍未闭合。
