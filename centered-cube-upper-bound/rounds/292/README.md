# 第292轮：实际低pe的联合截断与共同软度交叠

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮针对任意来源距离上的原低pe、高归一质量交通，同时使用真实核与低密度门；不再把固定偏移类继续增加当成全域覆盖。

## 1. 可直接付款的软度—质量—尺度比联合门
原核为K_s(u)=Π[(1−s)h(u_i)+sφ(u_i)]，p=L^(−n)K_s((x−y)/L)，g=√(LR)。原完整e_g不变，m=e_g/[ell_n q c_j^(−n/2)g^n]。低pe直接给出

τ_row=(2K/(ell_n m))c_j^(n/2)(L/g)^n，p≤L^(−n)min(K_s,τ_row)。

不能把它改写成原p免费乘1/m。预先固定S、τ，定义U_S=sup_(s≤S)K_s，J_S(τ)=∫min(U_S,τ)。保留实际硬响应上限，先在原接收域使用该上限，再扩展积分域；整个实际尺度选择的费用为A_n=1+nlog(b/a)，从而任意来源距离的真实子交通满足

T_(low,s≤S,τ_row≤τ)≤(16/3)A_n J_S(τ)Wβ。

正水平集缩放和有限共同软度菜单给出可计算上界J_S(τ)≤τ^δ R_S(δ)，0<δ<1。R_S在详细证明中明确给出，包含完整软度菜单及一维分数矩；另给解析上界，正式费用不依赖普通浮点积分的正确舍入。

对预定有限软度分层I_h⊂[0,S_h]，保留实际门

m≥(2K/ell_n)c_j^(n/2)(L/g)^n (R_h/ε_h)^(1/δ_h)，

即可用(16Λ/3)A_n Σε_h Wβ支付这些原低pe子交通。原外层Λ仅一次；该槽没有新增score或时钟。所有软度分层来源费用明确相加。门下的原交通仍未付款，不宣称一般高m条件自动满足该联合门。

## 2. 为何阈值不能只看ns
对固定核的辅助乘积概率律，Z_i=−log f_s(U_i)，有精确恒等式

∫min(K_s,e^(−t))=E exp(−(t−ΣZ_i)_+)。

这只表示核，不是对原输入、来源或历史作独立假设。有限Chernoff上界来自一维分数矩，不使用未经核验的大偏差渐近。在0<s≤1/2时，令T=∫_(硬核外)φ，H_out=∫_(硬核外)φlog(1/φ)，A₂=∫_(硬核内)(1−φ)²，则

sTlog(1/s)+s(T+H_out)−s²A₂≤EZ_i≤sTlog(1/s)+s(T+H_out)。

所以存在真实的nslog(1/s)项。T=2/3−2E₄(1)约为0.494541684。该计算用于选择可验证的截断预算，不从有限维数据拟合阶数。

## 3. 共同软度的混合几何列
预先固定M≥1，另构造保留共同软度与原尺度资格的截断交叠列Γ_(j,M)，再针对其来源积分定义闭阈值锚点。付款分配始终同时保留原低pe及m>M门。为处理q(x)依赖，辅助允许来源集使用同一原树、同一原合格质量和固定q_-=3λ/4；它只正向扩大原接受集合。原e_g、低pe和m门均不改写。

在新列质量≤A₀ q_- c_j^(n/2)的原交通子分配上，闭阈值与实际列积分给出来源价≤A₀ Σ_j c_j^(n/2)Wβ<4A₀Wβ，外层Λ另计一次。须保留可行尺度区间、空根、端点和全部原门。此为新条件分配的付款，并非所有原高m行已经达到该阈值。

共同软度的正包络保留有限二项式菜单，列的总体积预算为多项式，避免把每坐标分别取max(h,φ)造成的指数体积误认成集中密度。仍需证明剩余实际交通在这些几何分配上的总费用，而不能把新列阈值直接当作全域结论。

## 4. 实际检验与复现
主代理在本机重跑checks.py、gate_checks.py，输出JSON与冻结记录的SHA256相同。三阶段一维计算：13组核剖面、52个截断比较，40/60位；最大精度差约5.16e−41。共同软度菜单、尺度包络和实际比值门：1484个精确系数案例、140个分带检查、72个尺度剖面、72个实际比值案例及72个精确费用分配。主代理另运行root_checks.py，完成504个Fraction尺度扩大和固定树阈值检查；clipped_mass_checks.py完成49个70位精度的三阶段不完全Gamma积分与有限多项式恒等式检验。

数值上n=512、s=1/512时ns=1而nEZ_i≈4.60517；n=10^6、s=1/n时约8.35265。n=512、s=1时，t=ns的有限网格上界为1，而t=2nEZ_i给出约1.09e−105的上界。上界为1不证明真实截断质量接近1；这些也不是区间证书、n维积分、FULL/history证书或一般证明。

解压research.zip后运行python checks.py、python gate_checks.py（需mpmath1.3.0）、python clipped_mass_checks.py（需mpmath）及python root_checks.py（标准库）。详细推导、独审和LaTeX文本保存在包内；不编译PDF。
