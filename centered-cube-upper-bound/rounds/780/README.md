# 第780轮　跨全部尺度的来源覆盖与双端共同容量

本轮估计第772轮同一份两跳峰。两次真价仍按各自的真实来源交集抽取，中父按原度作分母，所有者使用原勒贝格体积。设 \(S=\|f\|_1/\lambda,\ \ell=\log(n+2),\ L=\sqrt n\,\ell^3\)，\(V\) 为全部实际接收所有者的总体积。

**跨尺度支付集中来源。** 对小父 \(u\) 的半径 \(s_u\)、质量 \(m_u\) 及其真端点 \(y\)，若 \(\mu(Q(y,s_u/\kappa))\ge \tau m_u\)，则这一侧所有原峰满足

\[
 Q^0\{\mu(Q(y,s_u/\kappa))\ge\tau m_u\}
 \le C(n+2)S\left[\frac{\eta}{\tau}e^{4n/\kappa}
       +\frac{1}{\tau}\left(\frac{2+4h}{\kappa}\right)^n\right],
 \qquad \kappa\ge8,\quad\tau>0.
\]

这里 \(\eta=e^{-\lceil\sqrt n\,\ell^2\rceil/256}\) 是实际硬交门，\(h=1+1/(32n)\)。证明在全部尺度共选一个原空间不交方体族，合计向同一份 \(\mu\) 收费。取 \(\tau=\eta^{1/3},\ \kappa=8n/\log(1/\eta)\) 时，充分大的维数中两端并集只花 \(O(n\eta^{1/6}S)=o(S)\)。同时对一整段较小邻域保留指数权，所得连续分数费用为 \(O(nS)\)，回到平方根入口只花 \(O(\sqrt{n\ell}\,S)\)。

**跨中父合计两个远价。** 每条已知左臂可预选多至 \(\lfloor e^{L/2}\rfloor\) 个右价窗，每窗半宽至多 \(LR_O/(4n)\)，\(R_O\) 是其半径八度的下界。整张名单命中的真实峰在全部中父上合计只花 \(O(\eta e^{-L/4}V)\)。对其余峰，把每个小父每格能交付的实际质量截在该父的硬交上限。两个格心相差 \(d\) 时，所有可兼容中父的接收体积受乘积 \(\prod_i(1-|d_i|/(2t))_+\) 限制。每个中央体积档的位移共用一个容量帽。报告式（11）给出所有水平的准确物理体积，式（14）把这种容量与两个端点的空间容量合在同一条原峰上。

**完整账目。** 对所得真实剩余 \(R_{780}\)，证明了 \(0\le Q_{772}-|R_{780}|\le C(LV+nS)\)；在所选近极值入口 \(G\ge\sqrt n\) 上右侧为 \(CLV\)。继续缺少的是两端均为低局部来源质量、各自连接大量远窗时，端点与位移的共同亏损对一般输入的统一上界。一般 \(n^{1/2+o(1)}\) 弱型估计仍未证明。

**实际检验。** 本机 Python 对 \(1\) 至 \(64\) 维的七个首穿越边界来源核验了真实交质量，并在 \(2,4,8\) 维分别以两种求和次序核验两个中父共用同一片来源的原峰。在用户的二十四段宽窗口来源模型上，来源势可以指数小。另以准确有理原始及对偶证书核验144组共同容量模型，60组的剩余严格减少，一例从 \(9\) 降至 \(15/4\)。Arb 对36组位移体积和八个维数的门槛作区间复核。有限实例的资格、数据及其与一般证明的区别均在包内。[详细 LaTeX、两份 Python 源码及完整输出](research.zip)
