# 第595轮：不等权副本与有限输入严格增益

一般 n^(1/2+o(1)) 一致弱型上界仍未证明；本轮严格正增益尚不具有输入一致的幅度。

## 已证结果与界限

对每个非零有限正原子输入及每个阈值，构造两份不等质量、相应压缩的真实副本，总质量不变。将小副本置于完整原接收集最外侧，保留两侧全部纯接收，并由大侧实际见证与全部小侧来源形成一条与两个纯接收集均不交的新接收区域。因此完整接收比严格增加；全有限原子常数不能由有限输入达到。结合第589—591轮已审的固定来源数达值，还得 C_(n,2d)>C_(n,d)。没有据此断言增长率。

证明显式保留小步条件 α<min{M/(32W),(r/(16D0))^n}、真实横向面片面积和原坐标的平移。它们依赖输入，不能抹掉近极值误差 ζ/α。统一聚合全部接收量所需的正预算仍缺失，未得到维数阶改善。

互补分析核清两副本共同半径所对应的对数尺度同步，以及分裂因子 α(1−α)、Jacobian、平移概率归一费用。消去分裂衰减的宽尺度权重有明确代价，不能免费使用。
