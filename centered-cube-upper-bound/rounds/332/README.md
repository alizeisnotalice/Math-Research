# 第332轮：真实边界质量误差与容量余量结算

**一般根阶上界未闭合。** 本轮一般硬匹配场的来源分层保留真实行容量，并得到平方能量误差

\[E_{\rm all}-E_k\le2\sqrt{\lambda A_n\|f\|_1B_k}.\]

B_k是原来源在真实立方体边界层中的质量积分；未使用密度帽。B_k趋零但没有输入一致的网格分辨率，估计支付近似误差，不支付极限来源缺陷。算术平方E和几何Gram平方Q的极限分别保留。

共同来源精确切线属于容量类；其余量可由真实来源对称差、质量差和J后验方差表达。余量重排的点态覆盖收益必须与消耗的旧信用共同结算；尚无一般根阶付款。仅优化固定输入的平均覆盖会恢复已有平方账，未成为新的全局证明。

实际本机验证：numeric.py通过5188项精确有理/整数检查及3107项普通Decimal诊断；checks.py通过4322项精确代数检查。共9510项精确检查，Decimal另计。数值三阶段n1/2/3，来源全格积分，但接收为有限quadrature，不冒充真实dx。独审642项另记。本机MATLAB quadprog功能测试成功，可供后续共同势搜索，尚未求解本轮研究优化。

完整总账保留一般软核、重来源交通、极端尺度比、宽距离/低pe及全部时间初始/删除/未来删除项，总吸收未完成。
