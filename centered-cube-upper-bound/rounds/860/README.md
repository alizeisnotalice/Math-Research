# 第860轮　两端在不同位置支付时的共同容量

在第813轮原双臂积分上，每个完整中父历史可以分配一份位置耦合，分别送往两个实际小父的接触域。这两处可以互不相交。每个边际均受同一物理集合 \(E\) 的勒贝格测度控制。把所有父和尺度相加，费用至多为 \(C\mathcal H D\sum_O\int_E W_O^3\)。其中 \(W_O\) 按不交真实接收者赋权，两个原来源质量分母和完整度 \(d_v\) 均保留。[详细 LaTeX 证明与四项本机复算](research.zip)

**可直接支付的原质量。** 取中父与两小父的实际扩张交盒体积，分别除以各自合格的真实来源质量。两个比值相乘后乘 \(P d_v/(C\mathcal H)\)，在 1 截断。这样标记的原质量可以全数分送到三个真实接收位置，合计只用一份 \(P\mathfrak j\)。一端较大的体积比可以补偿另一端较小的比值。

**来源共同使用的位置。** 固定任意原割后，取遍满足同一输出密度上限的来源运输，可以选出一份对所有运输都适用的子流和一个空间价格。高价位置构成共同的小体积集合。若真实端点向公开选定的位置张成的坐标矩形伸出该集合，或有真实接收位置能在足够大的体积分数上看到高价，其原质量可计入根阶接收与线性来源预算。

**实际检验。** 在同一批920条归档四维记录上，按指定输出密度，公共计划与逐条重给容量的计划分别标记总原量的 27.9059% 和 63.6680%。原最坏割有848条正支路，公共计划在该割标记总原量的 26.6797%。有理对偶只使用输出价格，与原始有理可行值相差不到总原量的 \(10^{-12}\)。另一个有正体积的六记录压力例中，同点、最优独立、共同耦合的精确付款比例分别为 \(0,4/9,7/9\)。四维样本和压力例的历史条件分别列在证明包内。

**尚缺的全局估计。** 当两端同时集中在共同高价区，且所有中父可用的真实体积相对于两臂合格来源量都很小时，尚须控制该割中剩余的原质量。四维合同原有的 4.6039% 差额与公共计划的标记比例使用不同的容量。一般单窗次线性和全尺度 \(n^{1/2+o(1)}\) 弱型上界仍待证明。

证明包内的重放命令使用独立 Python，检查四个父包的 SHA-256 并逐项比对输出。归档保留 LaTeX 源文。
