# 第854轮　共用真实终端的跨尺度祖先与接收体积

本轮继续第853轮的单窗余根，保留每一根的原双臂、两枚真实来源和旧标记。在这份余根上额外构造了一条路径，使不同尺度的祖先都落在同一实际终端的比较方体中。由此可以按真实接收体积合并估计一部分祖先。一般上界仍待证明。[详细 LaTeX、五个复算程序和实际输出](research.zip)

## 能够合并支付的原量

固定当前保留的来源 \(s\)，把第 \(j\) 个体积档的接收中心写成 \(y=s+U_j\theta\)，其中 \(U_j=2^{j/n}\)。固定同一方向 \(\theta\) 后，每档真实行质量至多为 4。在连续累计秩上移动，再按所抵真实档抽另一枚来源，所得外方体逐次嵌套。根号维数量级的来源费支付一步终止。在同一根的两端分叉，还可要求两个子盒各含本端、各自排除另一端。原见证继续使用实际边长和分母。

取同一真实终端 \(t\) 上的接收密度 \(h_t\)，其在终端外盒上的积分至多为 1。反走两次，从中件新取得的真源 \(u\) 到祖先中心 \(x\) 是显式仿射映射。其雅可比和原秩选档概率给出实际中心密度。沿所有历史深度，只要末次转移的该密度在给定的接收费用内，就能合计到一次终端预算。若长史上有固定比例的两步转移接收密度适中，其原质量合计也至多为 \(C|\Delta_{\rm ray}|\)。证明在同一 \(h_t\) 上按不同真实体积档的严格先后次序积分，选出 \(k\) 段可得 \(1/k!\) 的节省。

另可沿每个来源与方向预定一个较小锚方体，统计它包含的真实伙伴质量。若一条长史有固定比例的中件在各自锚方体中取得至少 \(2^{-\lceil\sqrt n\rceil}\lambda 2^j\) 的来源，所有此类历史合计可按 \(O(\sqrt n\log(n+2)\|\eta\|)\) 支付。这项付款允许中件的仿射密度很高。原双臂上还给出按终端和完整方向选取尺度、以及按另一臂预测交体积的估计。

## 验证与剩余问题

本机 Python 3.12.14 运行有理算术及 192、384 位 Arb。256维的固定真实记录上，按所有早父逐次计数比按实际命中取并多收原流的 \(1431/3866624\)。正宽源样本显示外方体嵌套时，一份真见证仍可伸出前一份见证。12档、24个不等权接收胞的三组精确模型各检查62个有序子集，另在最高1024维复核交体积尾界。脚本、固定输入哈希、各组适用范围及逐项复算方法均在归档中。

余根仍可在长史的大多数两步块中具有高度集中的条件接收密度，同时在上述邻源门中只命中少数位置。其一般总量尚缺上界。本轮没有新增吸收系数。第813轮的完整双臂预算及第739轮全尺度账中的 \(9/32\) 阈值继续保留。
