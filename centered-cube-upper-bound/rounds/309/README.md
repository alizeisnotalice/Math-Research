# 第309轮：实际高 softness 的低次数捕获端付款

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未闭合。

本轮保留原真实接收测度、来源、FIRST、完整门、原前缀及未捕获端。通过实际乘积核的条件标签分布，证明 n s >= (28/5)(K+7) 时低次数捕获端至多为完整捕获端的1/128。合并原低捕获和中捕获的低次数部分，只支付一份 T/128；回代系数为4096/5和128/5。K沿用第308轮，门可能为空。另一共享势给该已付分支的来源价格 epsilon A_n W_nu，采用更小epsilon时须同步调整门，不能与内部吸收重复计收益。

未付部分明确为低捕获高次数、小实际softness低次数；条件性的硬核内部排除不支付边界来源质量。完整总账中的原入口、极端尺度比、宽距离、初始、真实删除跳跃、未来被删来源及全局误差总和仍待处理。当前远非只剩常数或对数优化。
