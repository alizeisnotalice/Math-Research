# 第808轮　共同旧价下的接收体积与原交价分散

在第807轮的完整四边余量上，固定同一枚原交价 \(z\)、两条实际小臂和其中一条完整对端臂。将总量至多 \(C\sqrt n\log^3(n+2)V+o_{\rm sp}(V)\) 的原路径份额计入已付部分后，另一条臂的真实接收点在同一份剩余条件分布中满足

\[
 \mathbb P(W\in B\mid z,\text{两条小臂、另一条对端臂及尺度档})
 \le e^{-r/512}\frac{|B|}{M}, \qquad r=\lceil\sqrt n\log^2(n+2)\rceil .
\]

这里 \(B\) 是任意勒贝格可测接收区域，\(M\) 是中父的体积档下端。证明先在另一条臂自己的价上使用实际父交的质量上界，再合计不交接收区。两种条件分布的低质量行循环清理，同一行只收费一次。两个接收点的联合密度至多 \(e^{-r/256}/M^2\)。[详细 LaTeX、数值笔记与复现程序](research.zip)

令 \(s_*=M^{1/n}/2\)。在每个保留的正条件行上，真实接收父中心的协方差至少有 \(\lceil n/16\rceil\) 个特征值达到 \(s_*^2/32\)。另令 \(J=\sqrt n\log^8(n+2)\)、\(d=\lfloor J/(128\log(n+2))\rfloor\)。即使利用同一行的全部公开信息选定至多 \(e^{J/8}\) 个 \(d\) 维仿射平面，该臂自己的原交价接近其中任意一个的条件概率仍小于 \(e^{-J/4}\)。距离门槛为 \(\tfrac12\Delta\sqrt d\,s_*\)，其中 \(\Delta=e^{-J/(2n)}-(1+1/(32n))2^{1/n}e^{-J/n}\)。这两条结论适用于充分大维数的非空尺度档。

在同一真实输入测度上，给定不同对端观测，可独立抽取各自的整条原路径。两根小父的交占第一根小父质量的期望至多 \(C\mathcal H(n+2)e^{-J-r/256}/L^2\)，分母使用第一根自己的质量。剩余困难是不同公开行可以占用同一大片接收区域；现在还无法对全部行合计给出根阶预算。一般 \(n^{1/2+o(1)}\) 弱型上界仍待证明。
