# 第314轮：硬最大化接触的来源几何预算

**一般根阶上界仍未闭合。** 本轮从完整输入的真实硬最大化性质推出外扩壳层的来源质量界，无需假设来源密度帽。结合一次共享的顶端尺度付款，在真实硬赢家合同下证明

\[
B_H\le[1+\log(1+\varepsilon/4)]W_\nu+\varepsilon X+B_{\rm far}.
\]

这里 B_far 精确保留低尺度层的较远接收点对。接触宽度为 a[(1+ε/4)^(1/n)−1]/2；所有维度和尺度费用保留。

旧 R302 抽象合同不能自动获得赢家性质。本轮原件核验补实了匹配硬子源 ν_V≤f 及原接收集全半径帽，但旧所选 R 的硬最大化身份仍未建立，应用时必须另留真实缺额 D_eff。Native 合同有赢家，但到旧双接收点目标的桥也不能省略。

独审通过。本机 fresh 复跑4431项真实正体积L1来源精确检查及2880项几何检查通过；独立复核另有有理几何与明确标记的高精度诊断。有限 receiver 求积不是原 FIRST 实现，也不证明远对根阶预算。
