一般 n^(1/2+o(1)) 一致弱型上界仍未证明；本轮没有取得全局预算的维数阶改善。

## 论证与未付费用

沿用完整阈值 halo E、真实来源及 R598—599 的外部余量 H。尝试通过共同删源支付完整费用，而不是逐父另发来源预算。

对全部来源子集 S 选局部删除 A_S，令共同删除 D=∪A_S，局部保留集合 L=∪C_{S\A_S}、共同保留集合 R=∪C_{S\D}。完整子集族保证 R⊂L⊂E：跨度释放已包含在原 halo 中，不能另算 R\L 的新增覆盖信用。单载体旁涉损失由实际旁涉删除质量 b_S 支付，但完整去重后的来源列权和仍未受控。

对完整 E 的同纤维空隙 g，真实两端载体边长 r,s，令 m=(r+s)/2、d=|r−s|/2。嵌套标签恰对应 g≤d，不能遗漏。非嵌套且共享质量 c>0 时，全子集竞争给出 c≥λ[r^n+s^n−(m+g)^n]。共同来源造成两种真实障碍：横向单侧接近边界，或至少一个接收载体纵向变薄。

在 ng/m≤1/4 的纵向分支，完整纵向宽≤(n−1)(g²−d²)/m；等边长时单载体体积折扣≤其来源质量/(16n)。这只是单载体估计，跨载体累计尚未支付，不能外推全族 1/n 收益。嵌套、无共同来源、较大距离以及短距离的共同来源列费用全部保留。

最终独审修复了“嵌套还可能出现在 g>d”的错误句，并明确有符号端点重排只对至少两个纤维分量成立。一般闭合状态没有改变。

## 实际验证

自含 pair.py 使用有理幂比较和 Arb512 端点排序，完整保留四来源的全部15个非空子集。维数2、4、8、16、64，共20例横向族与5例纵向族；25例全部通过。初步、并列进入及完整并集检查、扩大维数三阶段均限定这些冻结参数，不外推维数阶。

纵向族确实只有纵向厚度很薄，其他 n−1 个接收方向宽均为1；报告另外给出该机制对所有整数 n≥2 的解析构造及必要单源保护条件。最初实现错误地沿用了“完整轴向并集仅两分量”的断言，已修正为保留全部分量并核验目标空隙；最终纵向族有四分量，未改变输入或遗漏子集。

本机专用 Python 3.12.14、python-flint0.9.0；原运行0.00866秒、峰35.2MB。主代理完整复跑0.00933秒，所有非 execution 数学JSON字段相同；另用Arb检查五个嵌套实例，并作符号二次恒等式核验。没有运行新的空间体积积分、MATLAB或优化器，不认证高q或近极值预算。
