# 第564轮：真实质量适配的共同来源簇预算

一般中心立方体极大算子的 `n^(1/2+o(1))` 一致弱型上界仍未闭合。本轮扩大了一个完整原后验中可严格支付的事件，尚未改善完整最坏维数阶。

## 独审通过的新估计

对一次共同、可数、μ互斥的来源簇族，真实接收点 y 与旧来源 z 同属 H，且 μ(H) ≤ c M_C(v) 时，**完整原后验费用不超过 c L_cl(K) W**。不再要求整簇包含于外父立方体，因而允许 z 位于该盒之外。固定真实 y 后控制实际勒贝格中心，再按真实 M 分档，保留双来源、两个质量分母、所有旧窗及原 head/stop/core 权。

直接取 H 为原来源格 C_i，即支付完整事件 M_C(v) ≥ μ(C_i)/c；此前整簇包含条件不允许这一结论。该中心容量论证本身也适用于适当归一化的其他中心对称同形体，不能当作方体特有的多项式优势。

低增长新捕获的直接费用经独审加强为 δ G C_* S A_n W，使用准确 I_B 归一；取 δ=1/(S A_n)，与旧低场值付款合计为 (K+G C_*)W。共同质量簇付款与它们按原测度互斥组合，只使用一次 Q_g。

完整保原边际的共同簇耦合也已审查：大匹配块可支付，常数收费下总来源费严格不因耦合而改变。报告式 (13) 精确保留小块和供需失配，不能以匹配比例或耦合存在性认定全局进展。

## 全部补集与下一瓶颈

最终共同随机划分采用实际簇质量条件，覆盖率记 p_γ。唯一同账余项为

`V_rem = K ∫_{非低增长新捕获, L_i>1/D_clk, p_γ<η} dM/L_i`。

其费用在完整母式中带系数 `4 J²/(b0² d⁴)`，没有省略。另一个合法共同簇耦合的完整余项是带原旧来源权的供需失配，而非未匹配概率本身。二者是可选完整方案，不相加多份旧信用。

尚缺对一般输入的低覆盖/跨簇失配统一预算。小簇占比、接收质量不足、相位与历史费用必须联合控制；不能逐父重选一族簇后重复领取 W。原入口、宽距离、低 pe、极端尺度比、时间原子、删除跳跃、全尺度和终端账均保留。下一步主攻这一完整共同分配，保留方体全部坐标条件，不再扩展无净预算收益的辅助恒等式。
