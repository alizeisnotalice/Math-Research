# 第695轮　首次捕获并集与有限阶比较

第695轮证明，第694轮的实际空间并集在每个有限采样阶数上都给出两个完整估计中较小的一个。两个来源池同时覆盖同一点时，乘积概率律的重叠可用一个显式幂精确计算。

对来源父体积作截断，还得到完整并集的显式放大界。在温度为固定常数乘以根号维数时，这个界仍含指数费用。一般上界尚未证明。
