# 第843轮　不同真实接收者共用来源时的累计费用

在同一阈值和同一族严格见证上，本轮估计第842轮留下的双端大来源池。每次重抽都保留原接收者和已经抽到的对端来源。证明合计任意多次删除后的原记录质量。[详细 LaTeX、脚本与逐文件校验值](research.zip)

## 同一来源能支持哪些接收者

固定一条原记录的一端，重抽另外 $m-1$ 条记录。把这些记录的接收位置和对端全部固定，计算能同时替换这个端点的实际来源质量 $L$。若 $L$ 相对各见证的交体积偏小，而且这类重抽经常发生，就可给原记录付款。证明沿删除阶段对 $L$ 取差，使用了每条记录当时的真实活跃权。把字面交体积换为事前规定的位移或归一化仿射比较体积，也有相同的接收积分预算。

写 $T=C_0\sqrt n\log^2(n+2)$。扣除已付部分后，在每条存活记录的两个端点，各重抽一列真实记录。以至少 $15/16$ 的联合条件概率，每个 $m\ge2$ 的前 $m$ 条记录（含根）都满足 $L\ge c_{m,\varepsilon}T^{m-1}\lambda|\bigcap_i A_{x_i}|$。常数随 $m$ 改变。若两次接收中一个真实中心位于另一个见证内，这一事件在终端各端点的条件概率至多 $\min(1,64C_2/(\varepsilon T))$，其中 $C_2$ 是方体极大算子的无维数强 $(2,2)$ 常数。因此每个活端的接收中心必占据相应数量的不同坐标象限。

## 不同伙伴共用接收者的费用

在固定端点和体积档，把每个实际伙伴在此前各档的接收分布写成归一化的 $L^2(dx)$ 向量。按真实伙伴律独立抽两次，两个向量的内积平方在终端的期望至多 $(n+2)^{-8}$。若一个 $k$ 维子空间要捕获这些向量的 $\kappa$ 比例平均平方范数，必有 $k\ge\kappa^2(n+2)^8$。证明将同一来源档的伙伴分布按质量首次进入各二进区间时冻结，以一份迹估计支付所有后续删除。四步相关的检测另外用同一实际中间来源和两处原勒贝格接收位置。

两道估计在同一原双端流上同时取得。设 $\eta$ 为割的来源，$\tau$ 为原双端流，$R$ 为最终存活流，$\Lambda(a)$ 为在这个 $R$ 中确实可与 $a$ 配对的对端来源质量。若 $D\le |A_x|<2D$，仍待支付的事件为 $\mathcal B=\{\lambda D<\alpha\Lambda(a),\ \lambda D<\alpha\Lambda(z)\}$。完整总账给出

\[
(1-\varepsilon)|\tau|\le C_{p_0,\varepsilon}\sqrt n\log^2(n+2)\|\eta\|+R(\mathcal B).
\]

交体积很小的地方仍可承载高浓度的真实来源，与许多接收分布相关很低的伙伴并存。这个剩余原量跨来源、跨尺度的统一估计仍未证明。第813轮另一入口中的双臂、历史、完整度及接收补集继续保留。

## 本机精确核验

- 用 Python 3.12.14 的 Fraction 完整核验两记录和三记录的 49、343 个元组，另检验 7 个七记录元组。一个三记录元组的真实交含源质量恒为 $7/10$，但同时活跃量依次为 $7/10,7/40,7/80,0,0$。严格过门后首条记录的费用为 $7/80$。
- 在两处均有正宽的薄交接收区上，对比实际交与两点平移的比较交。后者的积分扩大为 17 倍，原共同来源质量仍为 $1/4$。两种判定均按各自的积分预算收费。
- 在同一三块正宽来源上比较两种共享配置，接收块宽度从 $2^{-7}$ 至 $2^{-28}$ 取四档。窄块宽趋零时，直接两步评分均趋零。有宽块共用中间来源时，四步评分平方的两向极限为 $49/387$ 和 $2/11$。换成无此共享的对照配置，两者均趋零。

解压后使用 Python 3.12.14 分别运行 `python -B geometry843.py` 和 `python -B star843.py`，对照同名文本。两脚本仅依赖标准库。这些结果用于核验有限几何及实现。一般估计见包内证明；固定 $p>1$ 的接收平均使用 Bourgain 的无维数强型。[Bourgain 原文](https://arxiv.org/abs/1212.2661)
