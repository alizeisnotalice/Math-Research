# 第866轮　共享来源的多步重新抽样与真实中父的出流

从第813轮每一条真实臂的中父、小父和来源出发，允许在同窗父交中换到另一枚真实来源，再重新抽取父。对任意正输入，证明了在多项式步数内触及勒贝格体积的概率可按原预算付款。原双臂可分别沿不同来源行走。对始终固定中父的情形，估计保留了中央完整度分母和两侧接收边际。[详细 LaTeX 推导、两项计算及原始输出](research.zip)

**完整原量。** 对每个真实中父 \(t\)，用其合格小父、实际来源和交盒体积计算高来源集合的最大出流缺额 \(d_t\)。记高来源占父质量的比例为 \(\alpha_t\)，矩阶为固定整数 \(m\)，置 \(x_t=\alpha_t^{1-1/m}d_t^{1/m}\)。整份原积分满足 \(\rho(1)\le C_m\mathcal H[\mathfrak j(A)+\sum_t r_tj_t\min(x_t,x_t^2/L)]\)。其中 \(r_tj_t\) 是割内该中父的真实接收权。对任意有限父族，\(d_t\) 可由真实成员胞上的最小割精确表示。

**实测。** 在同一批四维920条原记录、相同密度门1下，两端命中概率开方后的最大值按原质量计，一步为0.01069%，八步为88.73%。按848条难割记录自己的接收权重算，八步为87.60%。在流量阈值 \(1/8\) 的有限检验中，全窗抽样的缺额精确为零，固定中父并只用实际小父时，相对缺额却超过99.99999%。两种抽样的容量分别用有理数可行流与显式割核验。另一组真实区间实验检验了长期停留。四维数据的完整度低于渐近门槛。

**剩余缺口。** 对任意输入，尚须把上述中父总和控制在 \(C[\mathfrak j(A)+(n/\mathcal H)\mu(B)]\) 内，尤其是同一小父的来源被许多中父重复使用时。本轮新增吸收系数为零。一般单窗次线性及全尺度根阶上界仍待证明。
