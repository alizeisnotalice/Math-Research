# 第280轮：共同来源内部预算与物理末端时钟的根阶结算

一般中心立方体极大算子 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮得到两项原来源预算；剩余问题精确集中到中间物理时钟中的随机共同胞边界分配，而不是另造未付范数。

## 本轮假设与两项成果

保原任意正L1来源ρ≤β≤α与独立ν，不假设ν≤β；s,L,R为同一接收点的实际选择器，a≤L,R≤b≤2a。保真实dx、实际FIRST、hardcap、唯一j、完整两后验及原good/bad/high/history；仅在已知正支配后放宽门。原同一不交终端叶总账Wρ≤Wβ≤||f||₁，Wν≤||f||₁已回查R112/R273原文。

**物理末端时钟。** 令ξ=c_jt/b、δ_n=(1/2)n^(-3/4)。实际ξ≥1−δ_n的当前正交通满足

P_top≤5Λ√n Wν≤5Λ√n||f||₁，Λ=128/119。

此项不需R2小或低软度。关键是先逐行界住score再消后验，保唯一j并作物理换元；真实R≥max(a,bξ/γ)使接收尺度包络质量仅为1+n log[b/max(a,bξ/γ)]。输入FIRST先消软来源，硬来源只按原叶结算一次。不得把ξ窗口换成t/g窗口，亦不得把此价格复制到其它时段。

**共同来源胞内部。** 在近来源||y−z||₁≤d/2，d=a/(8√n)上使用边长d的随机平移网格，同胞概率P_d≥1/2。令I_C表示胞闭包完整落入两个实际窗口Q_L(x)、Q_R(x)，定义A_int=E_grid[1_samecell I_C]/P_d，A_bd=1−A_int。这是原接收/来源对的[0,1]权重，不重选来源或后验。

对胞质量A=ρ(C)、B=ν(C)，同时保留实际两帽，径向积分精确为

I(α,β)=min(α,β)[2+log(max(α,β)/min(α,β))]≤2√(αβ)，

零质量按0解释。它把内部母积分控制为(16/√3)√(WρWν)，避免先取单来源尺度上确界造成的n倍损失。对原R2(y,v)=Σmin(|y_i−v_i|²/b²,1)≤D的好槽，完整时钟行价≤min(n log2,4√(nD))。所以包含原外系数2Λ的内部交通满足

P_int≤(128Λ/√3)√(nD)√(WρWν)。

R279给固定K、ε下的D=C₀+C₁log(n+2)，故这是实际根阶乘对数来源预算。常数极大，未声称在有限维覆盖固定比例的交通。

## 合并与尚未解决

先按ξ分割原当前正交通为top/middle；只对middle使用A_int+A_bd=1。因此

P_current≤5Λ√n Wν+(128Λ/√3)√(nD)√(WρWν)+P_boundary,middle。

最后一项保原near、所有剩余门、真实dx、完整来源和后验，只加middle与A_bd。胞未完整落入硬窗口、输入core被切割、真实soft off-core尾都仍在其中，不能声称已付。随机平移本身不能消去边界费用：粗胞面并集可费nd/a≈√n，乘时钟根阶后会再次失去目标阶数。下一步需在此确切边界积分中保留两帽的共同几何。

本轮也证明完整显式时钟源价，但D=O(logn)代入只得O(n log²n)，不作为根阶成果；它定位了单来源尺度包络的失损。没有重复花费旧负信用。
