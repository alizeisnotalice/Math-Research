# 第717轮　按来源尺度支付全坐标移动后的原高损失质量

开题核对[第706轮指令](../../AGENTS.md)。在真实高损失关系内，按来源体积档分别分配接收测度。同一档的共同交点可以在全部坐标同时移动，欧氏位移至多为该档平均半径乘以 √(γ log n)，其中 γ=1/(48·65536)，且各轴位移至多为两倍平均半径。每档合计目的密度至多为 n^(1/8) 时，实际分配成功的原高损失质量至多为 ηV_T+Cη n^(25/64)√log(n) D。原始见证、来源权重和全部来源半径均予保留。

剩余边还满足一项在真实来源 owner 上计算的二次估计。它比较同一批接收测度移到见证前后的立方体平均，只对超过来源预算阈值的正差收费。对任意输入证明该项足够小，或者证明分配已支付足够质量，仍是缺口。

九组真实双中心历史中，缩减末期接收标签后，第712轮的原始共同交集即使放大 n² 倍也无法容纳这批接收体积；新区域用不超过 1 的密度即可分配整个末期接收块。这是对两种空间分配规则的检验。完整 V、D、接收块的原高积分范围以及本机 Arb 与 MacBook 复算结果见[证明和复现包](research.zip)。
