# 第51轮：质量自适应正则化、二进合并与必要密度预算

2026-10-10启动，2026-10-11完成归档。一般 sqrt(n)n^{o(1)} 上界及 geom 余项仍未闭合；保留的一般全尺度界为 O(n log n)。

## 本轮已证明

任意有限正原子来源可按质量自适应散布，并保持极大函数逆 n 次根的逐点加性稳定性。原始散布存在任意高重叠，密度与熵不能免费去掉原子数。使用最大超密度二进格合并后，质量全部保留，密度不超过 2^n H，且逆尺度误差不超过 2H^(-1/n)，两者均独立于原子数和最小质量。

取 H=λδ^(-n)、δ=c/n，以至多 e^(2c) 的降阈值费用保留原越阈集合；替代密度与新阈值的比不超过 (2n/c+4)^n。单原子证明：任何满足相同逐点逆尺度误差要求的有界密度替代，其高度对数至少为 n log n−O(n)。这是当前强接口的限制，不是弱型上界的下界。纯越阈覆盖不必服从这项限制。

## 剩余缺口

本轮去掉了 N 与最小质量费用，但没有把 n log n 的对数密度预算转为根号费用。需要更弱的来源加权覆盖，或对替代密度的真实越阈体积建立新的总预算；不能只对熵预算取平方根。全阈值近1比较也不成立：任意小的一维双原子分裂已有弱常数从1变为5/4的反例。
