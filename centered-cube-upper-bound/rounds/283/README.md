# 第283轮：无深度完整软核预算与第一包含层信息几何

一般中心立方体极大算子n^(1/2+o(1))一致弱型上界仍未闭合。本轮消除了第282轮完整软核估计中的nK细分深度费用，并建立了来源密度无关的第一包含层信息界；前者恢复时钟后仍有线性维数损失，后者尚不是实际交通价格。

## 完整原近对母量的已证预算

保原任意正L1来源、独立硬来源、实际s,L,R、真实dx、FIRST/硬帽、原后验和近对门。令κ₀=2+√n/8，M=min(n,⌊D⌋+1)，H*=(D+2)[log(en)+log(2D+3)+15]，

E*=H*+log(n+1)+log(2D+3)+60e，
B*=e²M(D+3)[3+2log2+2logM+2E*]。

每个原粗胞C的完整软响应有弱常数κ₀B*ρ(C)。证明对固定潜在矩形先作对角换元：变换支撑足够小时用已证胞内工具，否则使用全尺度强L1包络。短软半径以“基准+单坐标标记”概率律支付，逆半径矩及其熵均显式有界，不取不可控的最短边上确界。

两条实际帽给出完整近对母积分

T_near ≤ 2κ₀[(16/3)Wρ+(1+logB*)Wν]。

所有软尾、切胞及第一包含层增量都被包含；没有K、密度截断阈值或未付邻居数。当D=O(log(n+2))时B*=O(log⁴(n+2))。但原分数时钟仍带约√(nD)，因此这不是根阶闭合。报告保留物理时钟限定下的κ_ξ积分，没有把一般原余项替换成固定尺度问题。

另构造真实硬来源树分配Γ_P：其边缘≤[1+nlog(b/a)]ν|C。它对已正放宽为整个粗胞乘积响应的费用精确，不是包含全部near/history/score门的逐节点恒等式。候选两质量势I联合凹且齐次，但这不自动提供额外停止费用。完整证明与此范围限定见author.md、audit.md。

## 第一包含层的新信息几何工具

对原硬锚点z的近球内任意概率来源Y（可非乘积、可奇异），固定s,L，保留独立潜在矩形形状B和完整接收噪声。通道信息满足

I(Y;X,B) ≤ [d/(2L)](1+log(2n))。

网格独立于整个原通道。若J为首次细胞完整包含于接收矩形的层，则精确有

P(J>k |Y,B,grid)=1−∏ᵢ(1−d2^(−k)/(LBᵢ))₊。

因此J在给定B后与Y、grid条件独立；其均值≤log₂max(1,nd/L)+2，熵≤log(e[3+log₂max(1,nd/L)])。这把第一层的信息费用控制在O(loglog(n+2))，而不是全部细胞地址的nK熵。

主代理进一步加入原粗同胞权重1_same/P_d。该权重逐来源平均为1，保持原来源先验；联合KL至多log2。独审确认：在该精确加权正规化通道中，包含形状、网格和第一层的总信息仍≤log2+上述两项。没有暗中丢掉细胞间配对，也没有假设加权后网格仍独立于来源。

这是一般来源的辅助信息工具，不是原实际弱型结论。固定节点不得获新FIRST；源条件通道后验不能替换原辅助Π。实际s(x),L(x)的选择费用、信息到正响应的转换、回到ρν的来源对质量及其与时钟的关联仍未支付。有限参数列表只能得到带真实节点数及归一化的费用，不能免费令节点数为1。
