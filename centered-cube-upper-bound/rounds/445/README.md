# 第445轮：受容量限制的终端重配及原流拉回

可测的容量受限近邻部分匹配可以按其新终端边缘拉回原完整历史流。取密度容量乘子√n，匹配的原正部分费用≤2S eps0²√n W；原流恰分为这部分与积分Hall缺额。没有证明匹配总能覆盖固定比例，也没有证明剩余缺额的全局根阶预算。

连续Hall等式通过有限生成分割与联合有限容量上的弱*极限论证；单个粗LP不能认证连续缺额上界。匹配使用真实接收中心和完整来源质量，辅助近邻pair不冒充原历史。

指定Python实跑HiGHS、Fraction、SymPy与Arb；三LP另核精确原始/割证书，原far支拉回仍far。有限中心模型明确不满足原K²门；辅助192项切割与三耦合模型也非完整历史证书。三脚本隔离stdout及JSON复现一致。
