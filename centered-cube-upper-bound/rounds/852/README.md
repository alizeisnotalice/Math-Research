# 第852轮　跨档共用来源的累计付款与真实中父的共同伙伴

在同一个原根的两枚来源上各运行一条历史。每臂先通过一条真实旧记录换端，再由换得的同一个来源继续，直到原规则终杀。研究对象仍是任意正 \(L^1\) 输入、任意真实来源割和原接收者选择的共同方体尺度。[详细 LaTeX、四份本机程序及实际输出](research.zip)

## 哪些原量已经支付

一条同源历史的第一秩窗是 \([H,H+d]\)。经过至少 \(\lceil(H/d)^2\rceil\) 步后，把所有深度的占用一起加到同一来源的原行，密度上界为 \(3/H\)。在原根的两臂上保留两个中父、两个终端和原根共五个实际接收者。四次源交接对应的低共同质量部分，连同实际来源所在格胞中的低质量部分，合计可付 \(O(\sqrt n\,\|\eta\|)\)。

固定一条臂的中父位置 \(y\) 和其中一枚真实来源。把所有初始私端、当前中心和档号合并，计算另一端有多少真实来源质量可继续参与**同一个双臂事件**。在两位中父的四个端上反复删除伙伴质量不足的记录。每个固定的“来源、接收位置”只在首次删除时计费。按所有中父的真实接收体积积分，再对来源和档号求和，整个删除过程的费用为 \(O(\sqrt n\,\|\eta\|)\)。

若一个中父在极限里还有正流，它必须支持两枚左来源和两枚右来源的四种配对。四种配对都可延续为真实幸存双臂历史，它们的共同权重积分至少为该档伙伴门槛的四次方。这一结论在同一个实际接收点成立。

## 核验和剩余问题

指定的本机 Python 3.12.14 用有理算术复算。64维跨档例中，单次同时筛选只删除测试事件的 \(648/19783\)，交替筛选16轮后删完。另一个64维配置和256维扩展均保留正质量。64维存活样本在一个真实中父上恰好达到四种配对的下界。有限实例使用缩小的秩窗和单列的阈值。三个真盒程序依赖已固定散列的[第850轮几何样本](../850/research.zip)。

按整根的实际条件概率回代，新增费用为 \(O(\sqrt n\log^4(n+2)\|\eta\|)\)，沿用第851轮的两项单窗吸收。尚需估计许多真实中父同时具有大量共同伙伴并跨根复用时的幸存总量。第813轮完整双臂费用与第739轮全尺度回代仍待解决。
