# 第709轮　任意见证位移下的共享来源估计

本轮按项目 AGENTS.md 的公式（4）开题。证明对任意真实输入和单一合法见证，只要来源半径满足 s_i≥64√(n/log n) s_j，就能统一支付这一整段高损失积分。更一般地，只要求见证离实际接收点不超过 (h/64)s_i√(log n/n)。采用 η=n^(−1/4) 时费用至多 η V_T+C n^(27/64)√log(n+2) D。
