# 第371轮：集中来源的交叠付款与共同匹配证书

一般 $n^{1/2+o(1)}$ 一致弱型上界仍未闭合。

本轮将第370轮的均匀交叠极值定理用于不设密度上界的真实来源交通。令 $p_{uv}=|Q_u\cap Q_v|/R_v^n$，联合支付 $\min(f,q_v)+p_{uv}(f-q_v)_+$，精确保留 $(1-p_{uv})(f-q_v)_+$。单对预算为 $2p-p^2$，总账以联合 $2\Gamma_n$ 替换旧floor费用，不重复扣平方或来源费。

配套结果包括保持全部匹配与原目标的来源条件平均工具（可能无改善，不收费），以及带任意高度周期脉冲的真实n=10000见证：新增支付与保留余项同时严格为正，但没有统一覆盖比例。

本机MATLAB实际求解7个来源LP及2个价格LP，有理数复核全部零gap。一个有限非等权模型需要有符号接收价格达到最优；这只支持保留共同匹配抵消，不能替代真实连续场的证明。主代理共复跑3620项计数检查，详见numeric附件。
