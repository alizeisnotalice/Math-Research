# 第760轮　真实两价的联合分布和共同接收容量

沿用第759轮留下的完整三步流量。设 \(t\) 是两个中间父中的任一个，\(x,z\) 分别是进入和离开它时抽到的真实来源点，下一父为 \(k\)。给定 \(0<\eta<1/8\)，可取固定 \(\varepsilon_\eta>0\)。在 \(s_k/s_t\le\varepsilon_\eta\) 的部分，除去总量至多 \(C_\eta\log(n+2)S\) 的异常路径后，有
\[
 \left|\frac{\|x-z\|_1}{n s_t}-\frac{2}{3}\right|\le\eta .
\]
同时，在一个固定中父体积档内，共同含有这两个价格的父方体，其不交接收所有者总体积至多为该档参考方体体积的 \(\exp[-(1/2-2\eta)n]\) 倍。

**这笔异常费用直接作用于实际剩余。** 证明允许先固定整条路径的任一子测度，再用每步的真实父质量和额外的真实所有者探针构造独立均匀参考点。反过来把全部异常路径本身选作子测度，它的质量就能在同一不等式中吸收。逐步条件化的熵费用合计为 \(O(\log(n+2)S)\)。后验重新固定确切下父或完整尺度序列会改变参考分布，证明在条件化以前完成比较。

**恢复到真实来源还差什么。** 设 \(R\) 为中父的体积档上半径。归档式（6）保留入边的一枚原来源标签，并对真实小父测度
\[
 \sigma_R=\sum_{k:\,s_k\le\varepsilon_\eta R}|E_k|\frac{\mu|_{A_k}}{\mu(A_k)}
\]
积分。核是两个方体的重叠体积归一化所得的三角核。它对勒贝格测度的积分恰为一。对 \(\sigma_R\) 的积分还含不同小父对同一来源的重复使用。内层积分合乎归档门槛的关联已付款，超出门槛的实际总量和较大半径比的分支仍在原总账。按小父允许的最坏位移取核的逐点上包络，其积分恰为 \((1+\varepsilon_\eta)^n\)。一般 \(n^{1/2+o(1)}\) 弱型上界尚未闭合。

本机精确复核中，两步终端筛选下的正确相邻参考四分位联合表每格为 \(1/16\)。重用上一步实际探针的细坐标，会使一格变为 \(5/64\)。另在真实来源集中于小父内侧的有限构造中，三角核的真实平均与该小父内均匀平均之比大于 \((1+1/32)^n\)，按 \(n=16,64,256,1024\) 复核。这项计算检验了恢复公式中保留真实测度的必要性。
