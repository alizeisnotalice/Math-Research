# 第563轮：完整旧新预算与相位收益核验

一般中心立方体极大算子的 **n^(1/2+o(1)) 一致弱型上界仍未闭合**。本轮未取得完整母账的维数阶改善。

## 本轮改变的判断

对第562轮同一完整有限优化进行归因：最优场中 OLD 贡献约占总能量 **94.86%**，跨密度带 OLD–OLD 约占 **69.83%**。共同移回真实窗口、保留残余位移并合并相位后，OLD 相比 adaptive 仅下降约 **0.35%**，完整总能量反而增大。质量折扣后的实际均值投影也略增。因此，先前约16.2%的有限能量下降不能作为旧来源跨层平台已获几何付款的证据。

严格保留完整坐标的双来源容量，并接入完整旧、新费用共用的一份信用。低旧场值部分已经证明

\[
\mathcal C_{\rm low}\le K\tau D_{\rm clk}W,
\qquad \tau=D_{\rm clk}^{-1}\Rightarrow\mathcal C_{\rm low}\le KW.
\]

这笔线性来源费不消耗旧平方信用。对预先固定的共同互斥来源簇，双来源同簇且该簇实际包含于外父动作盒的正子费用，可按真实质量和相位求和支付。已独审通过其明确适用条件；**尚未构造覆盖全部实际来源对的共同分配**。

远来源核具有全坐标衰减，但当前合法外层积分仍付出指数维数费用。丢掉空间定位后产生的放松边际不能免费按 W 收费；近距离也不推出共同簇包含于外父盒。联合势 h²/M 的真实分割与质量增长可共用一次有限森林预算，但完整对象的嵌入、平坦段、重复合并及原权重变化费用仍未付。
