# 第769轮　每条原关联对所有空间位置的共同容量

第768轮留下的父对 \(A_t,A_u\) 半径相差至多两倍，交集中的真实来源质量小于 \(e^{-r/256}\min(m_t,m_u)\)，其中 \(r=\lceil\sqrt n\log^2(n+2)\rceil\)。本轮证明，对固定的原关联 \(e\)，一个空间位置能同时覆盖的邻居总权重受到统一控制。检验位置可随 \(e\) 的小父、原价格、方向和大父选择，各邻居共用同一选择。

**全行估计。** 保留两条原关联各自的来源块 \(C_e,C_{e'}\) 和质量分母，记未付父对的核为 \(k(e,e')=\mu(C_e\cap C_{e'})/(m_tm_u)\)，其余取零。以 \(D_u\) 表示对端父方体的几何扩张，正文式（3）、（4）给出
\[
 \int p(e)\sup_y\int q(e')k(e,e')\,\mathbf1_{D_u}(y)\,dI_2(e')\,dI_1(e)
 \le e^{-r/1024}\sqrt{I_1(p)I_2(q)} .
\]
这里两侧可以是不同的原子流，\(0\le p,q\le1\)。对完整好流 \(I_0\)，至多删去 \(e^{-r/1024}I_0(1)\) 的原量，便可使余下每一行在所有物理位置的上述权重均不超过 \(e^{-r/2048}\)。同一上界对后续子流保持。证明把各行选定的点合成一份测度，再在真实不交接收集上合计。式（2）保留父对的相交质量和两个分母。[Stein–Strömberg 原文定理 1](https://archive.ymsc.tsinghua.edu.cn/pacm_download/116/7398-11512_2006_Article_BF02384314.pdf)

**在真实来源上的含义。** 取 \(D_u=y_u+s_u(B_\infty+u_nB_1)\)，其中 \(u_n=r^2/(8192^2n)\)。以同一笔费用检验每个原价格和各父自身的真实来源分布。余下的两条关联要同时满足，两个原价格都在对端扩张体以外，而且每个父在对端扩张体外的真实来源比例都超过 \(1-e^{-r/2048}\)。

**完整费用。** 把这四个条件放入实际行积分，沿用第768轮的吸收额，得到
\[
  (1967/2048)T_0\le R_{769}+C\sqrt n\,\log^4(n+2)\,\|f\|_1/\lambda,
 \qquad R_{769}\le R_{768}^{\sigma}.
\]
仍须控制分散于许多不同位置的邻居总流量。每个位置的共同容量很小，多处合计仍可能很大。一般弱型上界尚未得到。

**有限核验。** 四个真实父区间有不同的来源质量和不交接收集。三档测试门槛分别保留 2、4、6 个有向交项。双端独立重抽时，内部、扩张壳和深外部的九种组合均有正质量。全空间检查包含 7 个闭端点和 8 个开胞，第一行的最大值只在闭端点取得。二维面积与三维体积另用多边形和截面独立核对。有限例使用明列参数，没有施加高维首穿越入口。复现命令为
