# 第338轮：高拥挤中心体积预算与外侧补集

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 在原 hard 合同中，本轮支付高过去交通的一个真实接收中心区域。

对与来源y无关的可测中心关系D，若每个大端点u对应的小中心集合体积≤L R_u^n，则原G_D≤L|E|/h≤L Xq/(q_-h)。证明先用高过去门保证原J>h，再以真实来源交叠I_uv≤m_v消去μv质量分母，最后用原ell包含端点的尾。没有来源密度帽。

取K=exp(√n)、h=(1+√n)/(εq_-)、α=(1+√n)^(1/n)，中心区域||v−u||∞≤αR_u/2可吸收εXq。与337合并：

`B_H(f,ν) ≤ G_out + 2εXq + (λ/q_-)[(2+3√n+2exp(-√n))/ε+1+√n]||f||1`。

G_out明确是高过去、远质量比、中心位于膨胀区域外且有共同来源的原交通。其一般根阶预算仍缺；原入口、软层、尺度、初始和删除时间费用全部留账。后验输运的对数列上界仅为辅助工具，不当作覆盖收益。
