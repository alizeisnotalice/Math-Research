# 第781轮　共用中央接收点与跨尺度来源预算

同一条两跳峰有两个实际交价 \(y,z\) 和一个中央父 \(v\)。在该父真正的接收集 \(E_v\) 上增加一个勒贝格探针 \(W\)，两个端点共用它。保留第770轮的割、原度分母 \(d(v)\)、真实来源 \(\mu=|f|\,dx/\lambda\) 和第780轮全部未付条件。以下 \(V\) 为不交接收所有者的总体积，\(S=\mu(\mathbb R^n)\)，\(\ell=\log(n+2)\)，\(L=\sqrt n\,\ell^3\)。

**相对面轴数。** 对全部中父合计，两价在至少 \(m\) 个坐标上相距中父直径的 \(1-1/n\) 倍时，原峰总量至多 \(C(n+1)V\,3^m/m!\)。因此 \(o(V)\) 费用所需的轴数从第779轮的 \((\log 2+o(1))n/\ell\) 降至 \((1+o(1))\ell/\log\ell\)。若支付 \(O(\sqrt n\,V)\)，轴数可再降至 \((1/2+o(1))\ell/\log\ell\)。这里使用独立坐标的是接收体积的参考方盒。

**同一尺度上的联合几何。** 对中央体积档 \(b\)，\(a_b(y,z)\) 是向真实来源 \(\mu\otimes\mu\) 投影后、合计所有中父的原峰密度上界。置 \(\mathcal T_b=\sum_{c\ge b}a_c\)。从原峰扣去质量 \(O(n^{-2}V)\) 的共同探针后，两端的经验分布同时受限。在其余真实峰的实际档上，报告式（8）给出

\[
 \mathcal T_b(y,z)\le\frac{C n^2}{L m_v}
       \exp\!\left[-\sum_{i=1}^n
       \left(t_i+\frac{t_i^2}{2}+\frac{t_i^3}{6}\right)\right],
 \qquad t_i=\frac{|z_i-y_i|}{2s_v}.
\]

这里 \(s_v,m_v\) 取实际峰的中央半径和质量。每档中所有坐标共用该档尺度，先按坐标取积再跨档求和。此前直接放宽帐篷积只保留 \(\exp[-\|z-y\|_1/(16s_v)]\)，新式还区分总位移相同、坐标分布不同的价格对。

**一次预算覆盖完整父。** 每个真实左价可冻结一份对全部绝对尺度共用的来源密度 \(h_y\)，要求 \(\int h_y\,d\mu\le1\)。由尾和望远镜求和，全部中父的分数 \(\min(1,(nh_y(z)/\mathcal T_b)^2)\) 每个方向只花 \(2nS\)。以 \(k=\lfloor\lceil\sqrt n\,\ell^2\rceil/(65536\ell)\rfloor\) 计，任取至多 \(\lfloor e^{L+k/64}\rfloor\) 个完整原父，只要其中有一个含右价且质量至多 \(e^{-L}m_v\)，相应远价峰已全付。按真实 \(\mu\) 并集计量还可使一整列嵌套父并共用该预算。名单、重叠、质量门和原行未覆比例见报告式（9）至（11）。

**总账。** 证明了 \(0\le Q_{772}-|R_{781}|\le C(LV+nS)\)。归回原入口后，仍须控制两向各自分散在大量父并、且上述来源支付分数未满的联合峰量 \(|R_{781}|\)。一般 \(n^{1/2+o(1)}\) 上界和统一收缩均待证明。

**实际验证。** 本机有理数计算核对了 2、4、8 维两个中父共用同一片真价的积分。在一、二、三个绝对八度中，逐档重用会在三档的21个价胞超出同一份预算，累计尾的逐胞上界均成立。256位 Arb 核对16个平衡秩轮廓的跨档级数、一组不满足共同秩约束的压力输入，以及频率和轴数阈值。脚本记录哪些有限输入实现了哪些原条件。[详细 LaTeX、四份本机脚本及完整证书](research.zip)
