# 第736轮　共同来源的接收中心链覆盖与剩余反链宽度

直接对第706轮（4）的同一个最小化见证逐来源积分。用有根森林覆盖实际接收小方体，按每条边新增的体积计费；接收中心沿坐标单调链排列时，只需支付首个方体及各轴的总跨度。每个来源可自选多条链，合并所有尺度后总计支付至多两份根阶来源预算，未动用接收体积吸收系数。

若某来源仍有超过根阶预算的真实剩余接收体积，则在每一种固定坐标方向次序下，其剩余网格中心必须含有超过报告阈值的反链。高宽度来源的总积分仍待估计。两机独立核验六个覆盖体积，另用三组含指数多个真实接收者的压缩历史核对原积分和来源价值。
