# 第516轮：源格隔离与低score来源付款

随机平移网格按原交叉score控制边界损失，保留中心的全部候选盒位于各自真实源格。各格场正交且Qg≥(1−β)²Q；不同覆盖按本格来源质量结算。固定局部场上的低score层α≤1/A_n已得CSW预算。

剩余高score层须同时控制实际软平方B_A和未覆盖交叉score；源加权覆盖Ω是充分选项，尚未获得统一多对数预算。同格跨半径来源重复、原入口及全尺度费用仍保留，一般n^(1/2+o(1))上界未证明。

本机隔离复跑29项Fraction精确检查及n=1,4,16,64的真实tensor积分实验，归档解压后再次复现。浮点实验整族已解析判定属于低score层，不能认证硬层；slice不是完整接收域，求解误差非严格区间证书。详细LaTeX、独审和代码随包，不编译PDF。
