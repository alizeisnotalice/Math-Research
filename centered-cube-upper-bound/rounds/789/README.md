# 第789轮　真实来源合并时的跨中父费用与双端平稳重抽

对第788轮已保留的同一批双端峰，本轮证明了一份可加的费用，并在留下的实际峰上构造了保持原测度的转移。记 \(\ell=\log(n+2)\)、\(V\) 为真实接收所有者总体积，则
\[
R_{788}=R_{\mathrm{paid}}+R_{789},\qquad |R_{\mathrm{paid}}|\le C\sqrt n\,\ell^2 V.
\]
尚缺的是 \(|R_{789}|\) 本身的根阶总界。[详细 LaTeX、五份复现脚本及精确输出](research.zip)

## 哪些峰已经付款

从一个真实端点出发，以局部窗口内的真实来源交构图，按父方体的体积逐层加入。对另一端第一次进入的分支，只收该层新增的标记质量。再按中父的真实全度分档，以确有同一合格中父承接两端的原交通量计费。其余原峰的两个方向都需要更大的真实中父。式（4）和（5）说明，按尺寸加权后，在同一度档、同一首入层内重抽，有超过一半的概率获得体积大于原来 \(1+\ell^2\) 倍的中父。

另从两个原价分别沿真实来源块行走。两端能在第三片小来源上有足够重合时，式（6）至（8）用同一个接收容量付款。两个实际小父放大 \(3/2\) 后仍有至少 \(e^{-n/100}\) 的相对勒贝格重合时，式（9）给出指数小的费用。两个判据均按实际双端峰求和。

## 保留原测度的转移和缺口

在同一已筛剩余上，从两端同步剥去条件质量低的节点。同一节点只在第一次删去时收费。极限核心的每个正活节点都保留足够的真实质量。对该节点中父体积的条件秩作循环平移，两个方向的转移各自保持整个 \(R_{789}\) 的原峰测度。给定该侧节点，以至少 \(1-(1+\ell)^{-2}\) 的概率，中父体积对数增加 \(c\ell^2-O(1)\)。

目前能以固定正概率保证的累计对数增长为 \(c\ell^4-O(\ell^2)\)，同一物理八度允许 \(n\log 2\)。式（11）尚不足以排空核心。对所有输入当前仍只有 \(|R_{789}|\le C(n+2)V\)。若将它提高到 \(C\sqrt n\,\ell^\gamma V\)，式（12）回代后的一般弱型常数为 \(O(\sqrt n\,\ell^{\max(10,\gamma+2)})\)。

## 已运行的核验

本机 Python 3.12.14 使用有理算术和 256 位 Arb。在 \(n=4,8,16\) 的三组真方体上，实际分支合并的逐峰与逐行核算一致。加入非乘积筛选，并采用有限输入的诊断阈值后，两侧分别经历 2、3、3 波剥除，保留 28、168、1085 条有权记录。循环秩转移逐条保持两侧边际。两个原小父物理分离时，另有可逆链实例在各走一步时没有共同来源，各走两步后有正的交量。\(n=8,16,32\) 的另三例区分了真实来源交与勒贝格交。

将第一组方体整体扩大16倍后，各来源胞边界对齐整数周期。用户二十四段宽窗口下界输入的平滑乘积在这些胞上的真质量恰等于体积，归一结果因而保持。非对齐的下界尺度与完整高维首穿越、极值割仍由一般论证负责。
