# 第47轮：全阈值精确分簇与共同来源几何审计

2026-10-10。一般 sqrt(n)n^{o(1)} 上界未闭合，保留的一般全尺度界仍为 O(n log n)。

## 已证明与限制

任意有限正原子来源在每个共同阈值下，按全部可行捕获集的超图分量，真实水平集精确分解为两两不交并。全部阈值分区由一棵最大生成树编码，无分离膨胀、最小质量或深度误差；计算仍依赖来源规模，树本身不提供维数预算。

n≥2时任意来源均可加入任意小正质量细桥，使两点可行图连通，而完整弱常数趋于原值。因此连通性单独不能缩小近极值难类。另保留真实空间时间扩张约束，并给正来源反例：全部真坐标投影相同仍可有不同短峰值，真实后验平均流也可有非零旋度。这些结论均不是主目标反例或新的维数增长下界。
