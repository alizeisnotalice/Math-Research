# 第429轮：全部初始与中途节点的统一父邻近预算

一般上界仍未闭合。本轮在R428余项上，支付两条原路径中任一初始或非终端active节点的父邻近事件：
\[
P429\le2Sr(1+\sqrt n)[2\log_+M+\Psi(M)]W
=O(\sqrt n\log^2(n+2))W,
\]
其中M=ε_0A_n/(1+√n)，Ψ为逐代闭质量秩积分的可求和预算，完整公式见归档。终端分支已在上一轮支付，不重复计价。

新增估计同时保留目标闭秩与访问代数，处理整块质量原子；不用最坏路径长度乘W。C429=C427，V429=V428+Ω429，新入口来源价64ΛFhatΩ429W，无新增X系数。

剩余原流现在两条路径的全部节点都对父中心远离，仍保完整来源、真实接收测度和原历史。该补集的共同父质量层联合预算、最终吸收及全尺度闭合尚未证明。

独审和本机检查通过：15个原子模型、19986项逐代密度检查；20个精确级数/总账配置；15个真实中心层饼模型。本机MATLAB实际计算27组参数费用，Python独立核对输出。有限数值不认证完整历史，浮点参数结果不充当证明。
