## 新的完整加权轮廓估计

在原完整 `dV=K·1_R dM/L_i` 中，令 `p_ell^U` 为同一平移网格的共同格包含真实y,z、且格子包含在实际双盒并集中的概率。全坐标公式保留两个盒项、负交项及真实单坐标跨接项，不换为外包盒。

证明尺度持久性 `p_(e^-t ell)^U≥1−e^t(1−p_ell^U)`。它使用单tuple内的锚定耦合；实际付款仍按全父共享的真正平移网格。

取 `Llog=ln(8b/a)`，一份共同log尺度律在`[a/8,b]`，`p*=max_[a/4,b] p_ell^U`，则

`∫Ψ(p*) dV≤Llog(1+γ)Lcl W`，因此 `∫p*² dV≤2Llog(1+γ)Lcl W`。

这里 `Ψ(s)=−ln(1−s)−s`（s≤1/2），`Ψ(s)=ln2−1+s`（s≥1/2），且`Ψ(s)≥s²/2`。所有父各自的好尺度共同付款：`V{p*≥η}≤Llog(1+γ)Lcl W/Ψ(η)`，没有按父或前沿复制来源预算。

R565累计冻结密度≤2/ε后，完整账为

`V_R≤[2Llog(1+γ)Lcl/(εΨ(η))]W + Vhat_frozen{p*<η} + Vhat_terminal(all)`。

**后两项仍未付。** 真实terminal没有改成原低p*事件。Llog、Lcl、ε、η及全部原参数均计价。该尺度论证也适用于其他固定包含目标，不能称作方体专属指数突破；方体全坐标信息保留在实际p*中。尚无完整维数阶改善。
