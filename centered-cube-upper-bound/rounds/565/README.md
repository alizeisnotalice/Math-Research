# 第565轮：累计冻结密度与共同来源预算

一般中心立方体极大算子的 `n^(1/2+o(1))` 一致弱型上界仍未闭合。本轮得到一个经独审的跨阶段累计密度估计，并用精确有限证书确定下一步研究取舍；尚无完整维数阶改善。

## 独审通过的累计估计

在原 marked product 上先截取完整剩余分支 `R=X_B(x) Z_B(z,σ)`，取 `p0=P_B(Z_B)`、`q0=Q_B(X_B)`、`δ0=p0q0`。两侧真实子边缘为 `ξ0=p0 Q_B|X_B`、`ν0=q0 P_B|Z_B`，其归一乘积准确恢复原 R；零质量分支单列。

对共同来源前沿逐阶段冻结匹配，使用**固定初始阈值** `max(a,b)≥εδ0`，全部已冻结耦合对原 `Q_B⊗P_B` 的累计密度不超过 `2·1_R/ε`，与阶段数无关。证明分别按接收侧或旧来源侧被完全移除的密度下降求和。初始条件化没有留下额外 `1/δ0`；不能把阈值擅自改成当前剩余质量 `εδ_s` 后沿用结论。

冻结块加真实终端准确保留原 R 的质量、原 `L_i` 及逆场费用；全阶段只用一次 `Q_g`。Astra 完整独审通过，Sol 另核费用及母式；可数极限保留终端，未假定终端消失。先耦合完整对象再删除混合事件的错误次序已排除。

## 完整缺口与吸收总账

目前只有 `V_R=V_frozen+V_terminal`，以及 `V_frozen≤(2/ε)V_R(U)`。U 是不同共同前沿的合资格事件并集，包含嵌套和重叠簇，不能套一次互斥簇付款，也不能逐层重新领取 W。

若将来证明 `V_R(U)≤a_U Q_g+L_U W` 和 `V_terminal≤a_T Q_g+L_T W`，须共同回代 `a=2a_U/ε+a_T`、`L=2L_U/ε+L_T`，且满足严格门槛 `a<d⁴/(4J²)`。目前这两个预算均未证，没有新完整常数可填入。

终端概率质量小不等于原逆场费用按同比例收缩。即便另证终端质量≤ε，直接粗估仍含 `K² S A_n D_clk ε W`；这部分维度费用没有消失。原入口、宽距离、低pe、极端尺度比、初始和删除时间原子、历史、全尺度及终端账全部保留。

报告另保留准确合并时的逆场协方差和质量资格退出费用，以及双捕获方盒并集的全坐标公式。后者的低覆盖补集未付，不计为完整根阶收益。不以更多局部接口代替当前联合估计。

## 实际计算、证书与研究取舍

- 使用指定本机Python环境，复用冻结 n=16、64来源、332父、1264动作。原连续旧场及非对称 head/stop/core 无法由有限资料恢复，因此运行前明确批准有限物理 χ-lift surrogate，不冒充原 Cstar。
- 初探核全旧窗、原来源及 marked receiver；压力检验 delta1 动作和全部补集；扩大到2080个来源区间、3个动作律、6组参数，共18张评分表。无新增输入、维数扫描或QP。
- N8 用 Fraction 独立认证全部18张序列化表的共同分区最优值、全部区间对偶约束及零 regret。同容量的非负 fractional interval packing 不能提高结果。这是**舍入表的严格证书**，不含理想评分组装误差的整体区间认证。
- 最佳给定参数 `c=2,ε=1/8` 下，adaptive/optimum 的加权高场未匹配费用分别为 `0.0551886740244 / 0.0439241068817`，约占4.7%–4.8%。主要残余来自旧来源与真实接收分布不匹配；低场补集和 `c/ε=16` 费用均保留。
- 逐父分区可大幅降低有限残余，但该实际完整分区实现复制了 **332W**；不能把它当作一份来源预算的付款。结果支持停止在同一静态区间族上换求解器或分数混合，不排除其他合法多尺度几何机制。
- `K_fin=1` 仅为单位，实际有限行值最大超过4，不能用作原行上界或套母式。
- 主代理从已提交R562/R563包提取输入后实际复现，N7全部结果、旧场和N8全部证书一致。N3/N7/N8约0.414/0.580/0.654秒，N7峰值约219MiB。
- 另实际运行24个有理协议例，逐步扩大至24阶段，75个冻结块的双边缘、原截断、旧场/逆场和终端账全部通过；SymPy母式残差为零。有限代数检查不代替联合容量证明。
- 复用6个Astra与10个GPT-6.1 Sol，开始时核实16个同时运行；完成任务即停止，不伪造满员。数值计算只运行一份，证书复用评分表。没有逐模型扣额数据，不猜测成本比例。
