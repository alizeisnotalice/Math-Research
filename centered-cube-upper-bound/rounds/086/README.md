# 第86轮：一般来源块 Hall 预算与分散余集

日期：2026-10-11。一般中心立方体弱(1,1)的 $n^{1/2+o(1)}$ 上界仍未证明；已保留的一般基准为 O(n log n)。

本轮证明一个任意正 L1 输入上的通用分支：将同一个来源按固定小网格分块，以各块实际捕获份额定义 eta_a。对 eta_a≥rho 的分支，每个可测 Hall 割都有费用

`1+(2/rho)[3+3 log(1/a)+4 log(4H_n/rho)]`，其中 `H_n=1+n log2`。

取 a=n^-p、rho=n^-1/2，费用为 O_p(sqrt(n)log n)，不依赖来源块总数。证明保留实际勒贝格接收测度，通过边缘秩、接收几何和一个共同来源异常集支付；不假设来源坐标独立。新的分散余集、全部已支付分支及条件性径向递推已在主账中明确定义，尚未得到该余集的一般预算。

另证明特定坏来源递推中持续接收行的立方体实际嵌套，修正第85轮对此范围过宽的警告；给出准确存活比例与几何、径向势函数账，但阈值放大误差仍未支付。近中心共同来源行对可按指数尾支付，空间分离的余项仍开放。两条硬前缀约束可达到平凡交叠上限；该局部反例不具备正接收体积及全部原门条件，不是弱型反例。更新后的64项技能和原文假设已核对，Hardy/Carleson工具的迁移限制明确保留。
