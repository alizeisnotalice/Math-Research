# 第752轮　同一批保留关联的真实共享质量与双向近面条件

从第749轮实际高密关联或其第750、751轮子集出发。记初始真实流量为 \(T_0\)，来源总质量为 \(M\)。本轮证明，对任意 \(0<\xi<1/2\)，可在同一原接收测度中保留至少
\[
 (1-2\xi)T_0-C_K\sqrt n\,M
\]
的流量，同时满足以下两项条件。

- **每条保留方体对都在最终筛选中有真实共享质量。** 若 \(r\) 是小半径与大半径之比，\(\ell=\log(n+2)\)，则该有向方体对最终保留的来源质量占小父方体实际来源质量的比例至少为 \(\exp[-nr/2-C(\sqrt{nr\ell}+\ell)]\)。证明先估计硬交体积的对数，随后用两向各自的原分母支付真实共享质量过小的全部标签对。原缩核参数 \(a=32n\) 即可，一般可行价格也允许 \(m_i>d_i\)。
- **同一价点、同一条保留关联的两端都有最终正权邻居。** 在来源端，至少 \(c_\xi T_0/(M\ell)\) 个不同坐标各有两名接收者从相反两侧贴近同一价点。在接收端，至少 \(c_\xi G T_0/(K V\ell)\) 个坐标各有两名来源满足相同的要求。各自所选方体同时把共同交限制在这些轴的 \(O(\ell/n)\) 相对宽度内；两组轴可以重合。

证明交替删除共享质量过小的方体对，以及总权不足或方向冲突太少的局部邻域。一个有向对或一个邻域只会被整组删除一次。将每个邻域在删除时使用的位移核保留下来，再按第751轮的共同预算整体计费。这样后一次筛除不会借用已经删掉的见证，也没有迭代次数费用。算法在有限步后停止。

**尚未支付的量**是上述最终保留关联的总流量。两端的见证群都依赖实际价点和尺度。共同交的勒贝格体积和每一对的真实共享质量下限，仍不足以给出这些共同交所承载的总来源质量上界。一般 \(n^{1/2+o(1)}\) 弱型上界尚未证明。

**实际核验。** 本机有理算术检查了1,638个尾概率分段和875个半径重标实例。另有实际方体算例区分 \(m_i\) 与父体积的归一化，并用一个五轮级联的有限图校验删除账目，精确扣除 \(11/2\)，保留质量为6。有限图检验记录收费和次序，连续几何及一般维数的结论由正文证明。256位 Arb 结果及版本记录随包保存，最终 JSON 已重跑逐字节核同。
