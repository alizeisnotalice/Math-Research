# 第774轮　共同小父的接收预算与同价三跳

对第773轮同一欠额割、同一来源和同一批峰，本轮同时使用它的两个小端。一个原峰经过“小父—中父—小父”，两跳各用一次真实交价。现在固定其中一个小父及其交价，按通过原筛的条件分布重抽其他中父。这个小父正好可作第768轮的第三个标签，因而所有新中父对未通过原硬边的费用可以合计支付。实际两跳没有被迫共用同一价。

**一笔绝对预算。** 设 \(V\) 为实际接收所有者总体积，\(\ell=\log(n+2)\)，\(L=\sqrt n\,\ell^3\)。若两次真交价的 \(\ell^1\) 距离不超过中父半径乘以 \(\max_{j\text{ 为小端}}\log^2(m_i/m_j)/(256n)\)，则这一整批原峰的质量至多 \(C\sqrt n\,e^{-L/4}V\)。证明用立方体加 \(\ell^1\) 球的精确体积包住真实接收点，没有给实际来源假设密度上限。

**共同使用的接收体积。** 对两个中父 \(i,i'\)，只计与两者都在原割内相连、能使用同一真实价的较小父 \(j\)。记 \(W_{ii'}=\sum_j|E_j|\)，并记 \(U_{ii'}\) 为按 \(|E_j|/m_j\) 加权的真实三重交质量之和，来源仍限于原集合 \(X_F\)。在报告式（5）的两峰测度上，所有满足 \(U_{ii'}\le L^2|A_i\cap A_{i'}|\) 的中父对合计至多 \(CLV\)。其余对必须共同使用超过 \(e^{r/256} L^2|A_i\cap A_{i'}|\) 的实际接收体积，其中 \(r=\lceil\sqrt n\,\ell^2\rceil\)。这一步先积分真实来源，再用立方体极大算子的强 \(L^2\) 界结算勒贝格交体积。

**回到完整原量。** 每个半径八度分为 \(J\) 个对数体积窗；给原峰两端各附 \(k\) 条真实峰。保留两端各自的全部中父都在原窗内、两两通过上述容量及硬边检验、两条私有交价避开对方扩张体，且拼出的新转折仍通过原路径筛的质量 \(R\)。对任意 \(0<\varepsilon\le1/2\) 得

\[
0\le Q_{773}-R\le\varepsilon Q_{773}
   +C_\varepsilon Jk(k+1)\sqrt n\,\ell^3 V .
\]

取 \(J=k=\lceil\ell\rceil\)，定义 \(Q_{774}=R\)。原入口满足 \(T_0\le C\sqrt n\,\ell^7 S+C\sqrt{\ell S Q_{774}}\)，其中 \(S=\|f\|_1/\lambda\)。**尚缺 \(Q_{774}\) 本身的一致预算**：许多中父可以在同一个真实交价上同时满足这些条件，而作为比较基准的中父交体积可能很小。不能仅凭中父数、有限次尺度下降或有限例中的团概率宣布一般弱型上界。

**实测与复现。** 在12个真实父区间、14条历史上，按路径及按真价换序逐项核对；一个三角的正质量柱与原三跳之比恰为 \(72/293\)，全部可用小端合计为 \(189/293\)。另核验49个有共同小端的有序对、27个低维精确体积及四组256位 Arb 参数区间。有限模型未施加原高维极值筛。[详细 LaTeX 论证与复现材料](research.zip) 内含三个脚本及一份基准证书，未编译 PDF。
