# 第535轮：联合请求的外部容量付款

一般根阶一致弱型上界仍未闭合；本轮完成联合请求中外部共同来源的统一预算，内部需求未付。

对任意合法联合请求集合 S 和接收来源集合 U，独审通过

`Δ_out(S,U) ≤ 2/(exp(√n/4)−1) ∫_U fD ≤ (8/√n) ∫_U fD`。

证明保留真实 Lebesgue 中心、根质量等式、全部请求复用及尺度，不假设来源密度上帽。U为全空间时内部需求仍是原完整核心，因此该结论不等于一般上界闭合。

实际本机验证：九份有限流结果均有精确割下界与有理可行流证书；前六份仅两个不同问题，且最坏约束全部位于外部。新增内部模型在 w=7/25 时唯一最坏约束全部来自未付内部需求。该模型的全部 w>0 最优值另由显式流解析证明，不靠样本外推。有限接收中心模型不认证连续定理。
