`|Gₜ|−|Xₜ|=(1−tⁿ)|R|+tⁿ|R\E|`。

Jacobian 差属于尚未支付的接收缺口，不能直接吸收。成功半质量保留只给前向包含，拉回系数 t⁻ⁿ>1；不同来源指派片之间的内部间隙仍需联合付款。继续增大高次参数不能解决这个方向问题，共同来源势 Φ 也未消失。
