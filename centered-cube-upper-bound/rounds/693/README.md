# 第693轮：首次捕获森林、完整交通费用与阈值优化界限

一般任意 L1、全尺度、固定勒贝格背景的纯 C_n≤K√n 上界仍未证明。

修正优先级 d_i r_i 下，所有坏目标进入实际首次捕获森林；内部父边体积严格增大，整棵树只有根边承受一次微小损失。完整根储备的阈值积分恰等于所选价值 D，但后代真实接收体积的空间估计仍未证明。

本轮记录了每个目标只分配一次的完整来源交通公式，保留约2^n的扩张费用；无半径上限的价格带容量界是点态结论，不能自动对多个目标重复付款。进一步严格证明：先用每个来源的整个放大方体、再作非负标量阈值混合的模板，最优费用仍为Theta(2^n)。这改变下一步决策：停止单独优化阈值，必须保留来源与不同首次捕获点之间的联合空间关系。这不是对实际构造或原定理的反例。
