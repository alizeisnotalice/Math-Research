# 第538轮：完整接收域的有限接触极值定理

一般根阶上界仍未闭合。本轮得到适用于任意维数、任意有限来源数及固定正质量向量的全局极值结构，不逐盒支付接收体积。

**已证明并独审：** 全部非空来源子集的接收盒并集，保留所有尺度及重叠。其真实勒贝格体积在每轴的端点排列区域内分别仿射；每个配置都可移到有限的接触顶点候选且体积不减，无需人工位置墙。顶点每轴具有候选端点生成树，锚定后坐标不超过 `(N−1)M^(1/n)`。接触可能隐藏，不能直接计作重叠收益。若对所有来源数、质量及接触候选建立同一预算，可无损传递至任意正 L1 输入；这个统一预算尚未证明。

实际本机验证及独立审查：

- SciPy 对二维等质量 N=4、4、6 作三次有界差分进化，均达到迭代上限、success=false，只报告候选。
- SymPy 与 Arb256 对六次坐标块移动核验活动秩、全部区域约束和完整并面积非下降；活动行未使用人工墙。独审用不同网格覆盖算法及 Arb384 重算通过。
- 两个 N=4 可行配置面积均为 `3/2+sqrt(2)/8−sqrt(3)/4`；N=6 可行面积为 `19/12−sqrt(6)/6−sqrt(15)/24+sqrt(2)/24+sqrt(5)/12`。不是这两个来源数的全局最优证书。
