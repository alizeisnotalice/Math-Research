# 第832轮　共享标签、真实接收体积与中父信息费用

使用研究者制作的 **euclidean-tensor-geometry** 技能。在同一个物理坐标系中，由实际来源确定一个坐标包围盒。将共享二元标签放在其全部角点，价格恰为该盒各轴宽度之和。所有能同时接收这些来源的方体也包含整盒；全尺度接收中心的积分由盒的各轴宽度给出显式上界。此步直接使用勒贝格体积。[原论文定理 1.1](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Euclidean-geometry-in-the-asymptotic-spectrum-of-tensors-November-24-2026/build/intro.tex)

在第813轮原双臂积分上，先固定真实右臂 \(G\)，令 \(B\) 为实际中父 \(t\) 同时包含的随机盒。当各轴总宽至少为中父边长的 \(H\) 倍时，该批原质量满足
\[
 M\le C\mathcal H\,Y\, e^{I(B;t\mid G)-H/h}(1+hn/H),\qquad h=1+1/(32n).
\]
参考分布在不同左端、中父和体积档间共用一次。报告同时给出逐轴体积的加强式、对任意正子流的一次扣除、低平均宽度的伙伴抽样估计，以及硬方体实际末根的来源割版本。即使另一个中父提供的盒在部分轴上伸出，按轴随机保留和截短，仍能估计其实际接收量。固定同一真实右端，另抽同一物理窗中的真左来源；如果当前方体需要截短的各轴长度比例之和至多 \(\beta/12\)，该事件的原质量至多
\[
 \frac{C\mathcal H nY}{\exp(\beta^2/(256n))-1},\qquad \beta\asymp \sqrt n\log(n+2).
\]
剩余困难是绝大多数独立真伙伴在各轴上的累计截短量都很大时，这些中父的不交接收体积能有多大。该部分尚缺统一预算。

两份第814轮四维原档各保留230条正记录。固定右臂后，从一枚实际左价获得的中父信息约为 \(0.05519,0.05567\) nats，从完整伙伴盒获得的为 \(0.77669,0.76175\) nats。两组各有8个跨中父体积档的正盒命中。每组76个正权比较中，31个整盒失配，其中26个经独立取舍坐标得到严格正效用。在保留概率为 \(1/4\) 时，这些失配组合分别贡献该软测试总量的26.08%和25.73%。有限张量实验还构造了合并矩阵、各父三元质量及相应秩均固定的正子流，其完整两臂跨档费用可趋零。独立的全尺度包络计算覆盖30个构型和两个边界，最大维数1024；另行检验部分轴或所有轴越界的正宽盒，最高维数65536。
