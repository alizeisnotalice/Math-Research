## 核验后的研究决策

实际正则最优权的线性部分 Q，不能从完整“线性项＋对数项”最优值的下降推断为下降。本轮在真实二维五方体、同一旧 KKT 来源及同一合法位移路径中，认证了 Q 严格上跳、真实接收并集 W 恒定、D=W−RQ 严格下跳。两边辅助线性 packing 最优值都等于 M；变化来自实际正则差额。这阻止了把每次新接触都当正信用的证明步骤。

四例远离困难窗口，只反驳无条件的跳跃符号主张，不否定 F，也不排除存在别的好动作。

## 完整正向记账及其限度

对一次完整位移，把全部原标签的线性容量沿嵌套外方体路径变化分成连续增长 C 与接触节省 J，再保留终点删零信用 Z 和实际正则差额 B，严格得到

    D = (W−V) − R C + R J + R Z + R B₁ − R B₀。

此式结算全路径的有符号净效应，没有额外事件数、最小权或尺度数费用；不声称不利跳跃的绝对值总和有界。初始负费目前只有 RB₀≤4V，仍需由同一次几何的接收增长、容量节省和终端信用联合支付。该恒等式及费用整理不算一般上界改善。

## 保真实来源的全尺度约束

对任意旧 active 来源包，真实接收增量在全部尺度上的累计体积有统一帽。由此得到一次使用每份来源质量的局部包熵界；合法稀疏化 KKT 来源后，推出低方差临界支的必要条件

    N ≥ exp(56H/9−1)/9。

当 H=32 时，该门槛已超过 10^84（有理 Taylor 证书核验）。它改变计算设计：少量显式方体扫描无法进入这个分支。这里的 log N 不能替换为 log n；大方差支也没有自动支付重叠损失。这不是一般上界证明。
