# 第768轮　不同来源共同使用的大父交集

从第766轮原有向流量出发，保留实际接收集、两种方向的权重和两个大父各自的来源质量。第767轮只要求中间尺度的两个大父有几何交。本轮在全部原流量上核算后，只有一类实际交集还会进入未付行。

设 \(r=\lceil\sqrt n\log^2(n+2)\rceil\)，\(\eta_*=\exp(-r/256)\)。**剩余父对**必须位于同一绝对半径档 \([2^b,2^{b+1})\)，对数体积差大于 \(\sqrt n\log^3(n+2)\)，且满足
\[
 \sqrt n\,|A_i\cap A_j|<\mu(A_i\cap A_j)<\eta_*\min\{\mu(A_i),\mu(A_j)\}.
\]
较小父的中心还必须越出式（5）之前给出的大父邻域。对每个父可另选一份概率见证，在实际计算未付行以前固定。同一份见证用于它的所有邻居。若任一端对另一父的命中率达到 \(\eta_*\)，该父对也在已估计的部分内。

**全尺度费用。** 在二次积分的同一个真实位置独立抽取第三个父标签，抽去第三标签后精确恢复原父对权重。这使来自不同小父、不同价格的父对都能使用真实共同来源的估计。极远父对沿用已有费用，其余跨档费用合计至多为档内平方和的 \(O(\log(n+2))\) 倍。每个绝对档按本档实际接收体积计费，所有档的体积恰好相加为 \(V\)。

**回到原流量。** 只将上述父对放入第767轮行积分，保留其后验权重及两个质量分母，得到式（6）的 \(H^\sigma_{t,s}\)。行积分至多为 \(\sqrt n\log^3(n+2)\) 的原流，沿用同一份 \(T_0/256\) 吸收额。以 \(R_{768}^\sigma\) 记其余实际流量，则对每一族预定见证 \(\sigma\) 都有
\[
 \frac{1967}{2048}T_0\le R_{768}^\sigma
       +C\sqrt n\log^4(n+2)\,\|f\|_1/\lambda,\qquad
 R_{768}^\sigma\le R_{767}.
\]
尚须对某一族共同见证证明余量比左侧少一个固定比例的 \(T_0\)，或直接估计 \(T_0\)。档内平方的吸收只用于推导上式。
