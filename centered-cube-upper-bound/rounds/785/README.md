# 第785轮　同一真实小端的远中父费用与逐步增长的方体路径

本轮在第784轮同一原峰、同一最大欠额割和同一份实际接收体积上继续估计。每一臂都保留供给来源的小父 \(u\) 和真实交点 \(y\)。

**不相通的中父可以从费用中去掉。** 对共同格 \(c\) 内的中父 \(v\)，将整格峰质量 \(q_c\) 换成 \(U_c(v)\)。后者只计体积相距很远、实体交很小、且与 \(v\) 确有同一合格小端和交点的中父，每一项按真实共享比例加权。用归一化的对称核在所有中父之间结算，费用只支付一次。另用中央与右小端实际接收集的联合体积，支付了每坐标有符号位移达到 \(0.9\) 倍桶顶放宽半径的一批峰。每个左端、每个中央体积档可预选至多 \(\min(2^n,\lfloor(800/561)^n e^{r/512}\rfloor)\) 个符号向量，\(r=\lceil\sqrt n\log^2(n+2)\rceil\)。

**剩余质量须支持一段真实的增长路径。** 先删除同一端点上来源重合过多、或自己的对端交点落入其它中父过多的记录。再按实际存活质量删除弱端点，每个端点只为最后余下的一段付费。在余量的每个真实端点，可以配出多个完整记录，各坐标保留原筛后的真实条件分布。将其按中父体积排序并沿两个端点交替前进，得到长度为 \(\Theta(\log(n+2))\) 的链。沿链每步中父体积增长超过 \(e^s\)，\(s=\sqrt n\log^4(n+2)\)，新交点避开此前所有中父。以成功链的中央记录定义 \(R_{785}\)。

令 \(\ell=\log(n+2)\)，\(V\) 为不交接收集的勒贝格总体积，\(S=\|f\|_1/\lambda\)。完整费用为

\[
 (1-\delta)Q_{772}\le 2k |R_{785}|+
 C_\delta\bigl(\sqrt n\,\ell^8 V+n\ell S\bigr),\qquad k=O(\ell).
\]

报告式（9）给出了从该峰沿真实路径可达的末父必须拥有多少局部共享峰质量。允许多一个对数时，式（11）还把不能接入增长链的全部原记录差额直接计入吸收项。**一般上界仍未证明。** 每条链产生的新来源仍可被许多不同链重复使用，目前缺少 \(|R_{785}|\le C\sqrt n\,\ell^aV\) 或同等的统一收缩。

**本机检验。** 在同一来源格放入16份互不相通的八维父族，\(q_c\) 精确放大16倍，原中父的 \(U_c(v)\) 保持原值。另在32、64、128维构造有正质量的真方体配对，连续1、2、4步严格增长且交点避开旧父的比率分别为 \(2/3,3/5,1/2\)。这些模型未达到一般高负载门槛。其余精确检查包括非乘积筛选后的逐记录删除、非均匀边际匹配、126项逐坐标联合体积和原宽窗口下界模型的21组参数。[详细 LaTeX、脚本及原始输出](research.zip)
