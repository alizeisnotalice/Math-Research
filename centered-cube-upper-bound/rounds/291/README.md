# 第291轮：跨胞配对与真实质量费用

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮把第290轮的同胞来源估计扩展到跨胞配对，避免为两个相距很远的来源胞支付其共同外包长方体的费用。

## 几何结论与适用域
沿用R290任意正L1来源、真实dx、a≤L,R≤b≤2a、q∈[3λ/4,λ]、实际软响应FIRST上限和硬最大响应≤4λ。对预先固定的网格及整数偏移k，配对ρ的胞C_i与ν的胞C_(i+k)。两侧限制来源分别支撑在其自己的长方体，不要求共同外包盒；i→i+k为双射，每侧来源恰好计费一次。

设κ_d=2+Σlog(1+d_i/a)，S=(16/3)Wρ+(1+log B_n)Wν。对同一个随机平移，准确配对权为

A_(d,k)(y,z)=Π_i(1−|(z_i−y_i)/d_i−k_i|)_+，

且∫A_(d,k)dT≤κ_d S。于是整个Σ|z_i−y_i−k_i d_i|/d_i≤η<1分支有κ_d S/(1−η)的来源费用。偏移可以在多个坐标同时很大。取d_i=a/n时κ_d≤3，剩余位移的l1范围≤a/(2n)时捕获至少1/2。该结论没有要求两侧来源均匀或乘积化。

预先固定的非负配对权矩阵若每行和、每列和≤1，也保留一次来源预算。多个偏移的总权重和选择费用不能丢弃。还可以将ν的整份网格平移任意固定实向量v，再逐胞配对；准确权为Π(1−|z_i−y_i−v_i|/d_i)_+，不要求v是网格整倍数。未知偏移的全域覆盖仍未解决。连续score交通还须保留原ns≤D、上槽R₂≤D及J_D费用，不能从原始交通估计直接宣称连续项已经支付。

## 全局交通的割证书
对所有胞对保留实际积分t_ij。作者从完整软度和尺度包络推导行、列容量及含真实区间交叠的边容量E_ij；对任意行集合I、列集合J，

Σt_ij≤Σ_(i∉I)R_i+Σ_(j∈J)C_j+Σ_(i∈I,j∉J)E_ij。

行、列来源分别至多计一次。包络保留Csoft_n=Σ_k max_s Bin(n,k)s^k(1−s)^(n−k)、A=1+nlog(b/a)，乘积核总质量为Csoft_n A²，不省略选择费用。该证书适用于完整实际交通，但目前只能保证一般线性阶的割；需要证明存在根阶总费用的割或改进实际边容量。它是可核算的全局接口，不是已完成的根阶估计。

## 质量费用的精确保留
定义H(x,y)=min(x,y)[2+log(max(x,y)/min(x,y))]，任一参数为零时H=0。实际F≤q至关重要：若F、G的弱型常数为A、B，G≤4λ，则∫FG/q≤H((16/3)A,B)。该标量工具与凹性已有R283依据；本轮贡献是保留其实际胞质量参数，量化配对中的费用节省，不将它称为新的极大算子定理。

对可数质量对x_i,y_i，有限总量X,Y及X₀=Σ_(y_i=0)x_i，令φ(t)=H(t,1)、Dφ(t,r)=φ(r)+φ′(r)(t−r)−φ(t)。当X,Y>0时，

H(X,Y)−ΣH(x_i,y_i)=Σ_(y_i>0)y_i Dφ(x_i/y_i,X/Y)+φ′(X/Y)X₀。

零总量单独处理，不使用未定义比值。随机胞宽度时用随机参数与可数标签的联合测度，保留真实期望容量。比例相同的质量可以没有任何此类节省，不能假设该缺额普遍支付中间硬层。

## 数值与复现
本机实际运行checks.py和geometry_checks.py，主代理独立重跑输出与作者冻结JSON逐字节相同。三阶段标量检验包括1344个通用上限案例、1344个实际F≤q案例、336个聚合检验、56个变κ缺额检验及零/奇异质量边界；40/60位精度对照。几何使用Fraction精确算术：72个包络案例、12204个坐标断点计算、105个边界案例，维度至1000、正负偏移至10^20；另有配对来源账及402个有限割检验。

复现：解压research.zip，运行python checks.py（需要mpmath1.3.0）及python geometry_checks.py（标准库）。另附kl_checks.py和JSON，主代理实际完成96个70位精度的三阶段KL、总量和Hellinger费用检验，指数范围扩至±100。

这些是有限标量、几何和费用检验，不是任意L1输入、完整历史或全域根阶预算的计算机证明。详细证明与独审保存在压缩包中；保留LaTeX文本，不编译PDF。
