# 第761轮　两次真实来源在全族父方体上的共同权重

设 \(x,z\) 是实际三步下降链经过同一中父时的入价和出价，\(S=\|f\|_1/\lambda\)。第760轮留下的实际终端及其每一子测度 \(\mathcal R\) 都满足
\[
 \int\sum_{i:\,x,z\in A_i}\frac{|E_i|}{G\,\mu(A_i)}\,d\mathcal R\le C_K S .
\]
这里对全族的所有父方体求和，保留真实所有者体积与真实来源分母，左边无需裁切。这一结论适用于两处中父和所有相邻半径比，上游取 \(L=\sqrt n\log^3(n+2)\)。若下一父与中父的半径比限于任意固定的 \(r_0<1\) 以下，则上游取 \(L=\sqrt n\) 也成立，常数可依赖 \(r_0\)。

证明用同一真实来源点结算极端半径比的两向权重。对移动平均取 \(p=1+1/\log(n+2)\)，可将半径比不超过 \(1/[16\sqrt{n\log(n+2)}]\) 的该项总和压到 \(O(S)\)。其余半径上，依据下一父的相对体积档，在抽出新来源以前预测真实接收点可到达的区域。两价靠近的费用由这个区域的真实接收体积支付，两价相远时用逐轴相交长度估计能同时容纳它们的所有父方体。

在中父两侧的六枚实际非锚标签中，任一所选父覆盖对侧价格，这些路径的总量至多为 \(C_KS\)。如果某中父的真实终端中至少 \(1/\sqrt n\) 的路径如此，经过这批中父的**全部**流量至多为 \(C_K\sqrt n\,S\)。证明单独展开已选标签的未归一权重，区分了终端条件律和重新抽样的后验。

按上述估计实际删去流量后，第760轮总账左端仍是 \(277T_0/3072+\mathcal D/3\)。尚须控制同一来源质量经不同父标签反复计入的总量。小半径比回代中的真实来源测度及较大半径比分支都保留在剩余中。一般弱型上界尚未闭合。

本机用有理算术核对了七个真实二维父方体的 144 个有序价格模式对，并复核 11 项盒几何测试和 5 组 256 位 Arb 标量区间。验证包括不等的真实质量分母和跨四个体积档的来源复用。有限输入及其适用范围见证明包。
