# 第824轮　同一真实右来源跨全部尺度的中父质量分配

沿11月23日指导第六节第三步，直接在第813轮原双臂积分上估计同一个右来源 \(q\) 经过许多中父时的累计质量。左来源 \(z\)、两处真实勒贝格接收者、中父质量档和完整历史都可以随记录改变。第一步的增长字典结果及第二步用到的方差与条件律见[第815轮](../815/README.md)。

**同一来源能被多少条记录重复使用。** 令 \(V\) 为原不交接收总体积，\(\mu=|f|\,dx/\lambda_0\)，\(A_t\) 为一条记录的中父，\(m_t=\mu(A_t)\)。写 \(J=\sqrt n\log^8(n+2)\)、\(b=\lfloor J/[1024\log(en/J)]\rfloor\)，取 \(\delta=e^{-b/32}\)。对第813轮任意正子流，扣除 \(o(V)\) 的原质量后，可以给每条保留记录 \(\omega\) 分配真实来源集 \(K_\omega\subset A_t\)，其质量至少为 \((1-2\delta)m_t\)。在剩余流自身的条件律 \(\Pr_*\) 下，有

\[
 \Pr_*\{\,r\in K_\omega\mid q\,\}\le 8\delta
 \qquad\text{对几乎每个真实右来源 }q\text{ 和 }\mu\text{-几乎每个 }r .
\]

即使给定的是完整右臂及其真实接收位置，上式仍成立。同一份分配也同时满足对应的左臂估计。两侧靠交替剔除生存率低于四分之一的顶点保住自己的原边际尺度。总删除量至多为初始删除量的两倍。证明先把中父的整份来源与右价近区的接收方体体积一起估计，再对所有总质量至多一档的来源表同时取最优。全部绝对体积档在占用率结论中已经合并。

**累计质量和可结算的原记录。** 固定几乎任一 \(q\)，从原剩余后验独立抽取 \(k\) 条完整记录。令 \(p=\min(1,8\delta)\)，则这些中父的真实并集满足

\[
 \mathbb E_*\!\left[\mu\!\left(\bigcup_{j=1}^k A_{t_j}\right)\middle|q\right]
 \ge \frac{1-(1-p)^k}{p}(1-2\delta)\mathbb E_*[m_t\mid q].
\]

取 \(k=\lfloor1/p\rfloor\)，实际只有一个中父包含的来源仍占期望总库存的固定正比例。在不同 \(q\) 的分组间，若某个来源区域的右小父接收权按原 \(1/D\) 价格累计至多 \(e^{b/64}\)，所有在该区域实际分到逆多项式比例中父质量的原记录合计花费 \(o(S)\)，其中 \(S=\mu(\mathbb R^n)\)。累计量的定义和完整回代见证明中的式 \((*)\)。另外，左右臂交替传递同一枚真实来源 \(r\) 时，连续通过 \(h\) 次的条件概率至多 \(p^h\)。

**本机计算。** 两份四维连续输入各有230条正权双臂记录。在实际价格档中，质量至多为 \(D\) 的最优来源表可捕获的条件质量均在 \([64/81,2048/2401]\)。取诊断门 \(64/81\) 后两份输入分别留下 \(4.78\%\) 和 \(4.00\%\) 的原质量。只固定真实 \(q\) 后，以有理穷举和来源胞积分分别计算抽取2、4条记录的并及独占质量，两者完全一致。四维输入的高维长跳门为空。另以连续正密度的方体构型验证共用右来源及大量中父私有来源可以并存，在五个小维数做精确交盒，并在三个指定的大维数用256位、384位 Arb 核验标量费用。

**仍待证明。** 当不同 \(q\) 所用来源表在同一实际区域上有很高的累计接收权，原记录可以沿两臂不断更换所用的来源点。对这部分总质量尚缺 \(C(\sqrt n\log^\alpha(n+2)V+n\log^\beta(n+2)S)\) 的预算。一般单窗 \(B_n=o(n)\) 及全尺度 \(C_n\le K\sqrt n\) 均待证明。
