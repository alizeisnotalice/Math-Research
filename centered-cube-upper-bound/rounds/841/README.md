# 第841轮　两端真实见证的累计来源交质量

在同一来源端点重抽见证，两个见证的尺度可以不同。本轮分别计算交集占每个见证真实来源质量的比例，并将两个端点的替代见证放进同一次抽样。即使根据已经删掉的记录反复重算条件分布，所有超过门槛的原行仍可合并支付。[完整 LaTeX、数值记录及复现代码](research.zip)

## 一般输入上已支付的原量

在同一物理窗 \([1,2]\) 和真实高度带上，固定来源割 \(\eta=\sigma|_A\) 以及任意严格见证 \(A_x\)。\(J(A)\) 是该见证下割平均的平方对实际接收位置的积分，记原双端流为 \(\tau\)，于是 \(J(A)=\lambda|\tau|\)。若从一条原行的两端各自重抽见证 \(A_y,A_t\)，实际计费的两个数是

\[
 \frac{\eta(A_y\cap A_t)}{\eta(A_y)},\qquad
 \frac{\eta(A_y\cap A_t)}{\eta(A_t)}.
\]

给定端点后，在余下的原记录中按其原质量抽取，覆盖本窗全部体积档。根见证与两端替代见证的交率也按两个方向分别计算。对低于 \(T\) 的端点边际和超过 \(\alpha\) 的任一期望交率累次删除，连同第840轮的短对及第839轮未达到伙伴条件的长对，原质量总费至多为

\[
 C\big[T+\alpha^{-1}\sqrt n\,\log^2(n+2)\big]\|\eta\|.
\]

异端估计在已见到的端点抽取一枚随机来源作参考点，再用乘积核估计下一见证的真实命中体积。条件分布在迭代中改变时，每经过一个二进边际档可以冻结一次参考分布。来源交率始终使用被覆盖见证自己的质量作分母。

## 同一根能够保留的来源

取 \(k=\lceil\log(n+2)\rceil\)。经过上述删除及存活份额筛选，得到 \(R_*\le\tau\)，满足

\[
 0\le J(A)-\lambda|R_*|
 \le C\lambda\sqrt n\,\log^4(n+2)\|\eta\|.
\]

对几乎每条剩余原行，从两个端点各抽 \(k\) 个实际见证。充分大维数下，以至少 \(1/2\) 的共同条件概率，这些见证连同根可同时满足以下条件。

- 任意两件的二进体积档指标相差超过 \(\lfloor\sqrt n\rfloor\)。
- 每件至少 \(31/32\) 的实际割质量落在其余所有见证之外。其中至少相当于该件实际割质量 \(1/32\) 的伙伴仍可沿同一终端原流继续选择。
- 任意两件的勒贝格交体积至多为较小体积的 \((7/8)^{n/6}\) 倍。真实来源与勒贝格体积各自估计。

筛去几乎没有可继续伙伴的端点片，共占本轮删除总量的至多 \(2/15\)，已在本轮吸收。第813轮历史路径原有的 \(9/32\) 预算新增支出为零。

## 本机核验和剩余缺口

- 本机独立 Python 3.12.14 以有理数计算正宽来源包与不交接收区。共同右端有2、4、16、64个见证的例子均保留原窗高度和两个不同体积档。64个见证的例子中，一小件与一大件的交源相对于小件与大件分别为 \(1/5120\) 和 \(1/327680\)。其中每个私端只参与一条记录。这些有限例验证交率和原条件律的计算。
- 另取四个正宽来源包，使同一条根记录的两个端点均有两件可独立重抽的真实见证。直接枚举两端重抽的四种组合，两个方向的期望交率分别为 \(1729351/3078486\) 和 \(1146821/2085426\)。本例核验双端重抽公式，门槛和高维结论由正文证明。
- 标量检验固定可用边际 \(r_0=1\)、门槛 \(1/32\)。4、16、128步删除的累计费用分别约为 \(0.091162,0.118214,0.136040\)，都在同一积分势差 \(0.139554\ldots\) 之内。解压后执行本机 Python 的 `python -B replay841.py`，完整输入、精确输出和归档哈希均在包内。

不同根构造的见证家族可反复使用同一批来源。尚未估计这些家族合在一起时的 \(|R_*|\)。若能在单窗给它统一的根阶乘固定对数上界，Naor–Tao 定理1.1将全尺度恢复的额外损失控制在一次对数。一般单窗次线性上界及全尺度根阶指数目前仍待证明。[Naor–Tao 原文](https://arxiv.org/abs/0912.1140)
