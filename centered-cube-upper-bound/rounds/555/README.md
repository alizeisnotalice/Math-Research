## 已核验的结论与范围

1. 对各向同性稳定生成元 A=−c(−Δ)^(α/2)，0<α<2、n>α，有界紧支撑非负f与κ>0的障碍分解得到u≥0且u∈L1、0≤σ≤κ、Au=σ−f、σ在u正集上等于κ、∫σ=∫f。因此正集测度≤||f||1/κ，常数恰1。罚函数、非循环L1界、域单调、极限和有限能量配对均已独审；不自动推广任意谱。
2. K,u∈L1且AK、Au为有限有符号测度时，对称稳定生成元的非紧支撑卷积交换通过独审，保留截断尾项与零频。软杀死占用核的完整身份AGq=qGq−δ0保留全部正测度，不由离原点公式代替。
3. 同一异常集合的全部尺度恢复桥保留真勒贝格测度，给条件性弱型常数2^-n∫K。核须同时满足K≥1_Q、K≥0、AK=β−aδ0且β≥0；**缺失的仍是根阶总质量**。
4. 显式正则性、紧性和对称假设下，联合变分及有限步式 C新/C旧=(1−m)/(1−d)通过独审；m保留真实余寿命Tq，d保留整个Q的原障碍余量。接触顶点的下降不能代替全Q付款。该稿的分离扰动区域假设不能自动用于后续Q内部杀死。
