# 第315轮：中间硬层的定向薄壳交通

**一般根阶上界仍未闭合。** 本轮用真实接收权与全半径硬帽支付较小捕获尺度和深内部来源；与第314轮顶层/接触估计按顺序组合，保留中间尺度、远接收点、捕获端内侧薄壳的联合费用。

根阶来源方案给出

\[
B_H\le [2+\log A_n+\log(1+\varepsilon/4)]W_\nu
+\tfrac{16}{3}C_{{\rm soft},n}W_\beta+\varepsilon X+D_{\rm eff}+C_{\eta,h},
\]

其中 Csoft≤1+π√n/2，eta^n=1/A_n。另有显式接收吸收方案，将deep与contact的epsilon费用合计为epsilon X。两方案替代使用；剩余真实薄壳交通尚未支付。

可以从一开始选择真实硬最大化半径并重建所有门，此时新构造D_eff=0；旧冻结选择器不能免费替换。完整原始入口及时间I/J/D、极端尺度比等缺口仍保留。
