## 已证明与剩余缺口

对任意固定有限位置集，完整弱型比值在闭权重单纯形上取得最大值，且存在取得阈值；证明的两端阈值控制不依赖最小正质量。删去零质量后，实际盒并的可达光滑分支存在同一组凸组合，同时平衡全部来源导数与阈值导数。

由此得到真实阈值接触面与原子来源之间的耦合，其来源边际恰好还原最优源。必须保留不同分支上的内部接触缝重数，不能只计算基点的外周长。任意有限原子输入可先优化权重而不降低弱比值，故该必要条件不把主目标限制到特殊输入族。它仍不控制未知的边界总通量；根号 n 的一般估计尚待证明。未将旧 log-max 泛函的平坦性思想当作新成果。
