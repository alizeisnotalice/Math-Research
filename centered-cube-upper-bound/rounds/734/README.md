# 第734轮　反复失配时必须修复多少坐标

开题核对[第706轮指令](../../AGENTS.md)。在每一真实接收行，先用较小来源的不交所有者控制接收点相对于其中心的位置，再以较大来源的真实所有者检验同一批坐标。除去可吸收的较小来源权重后，对任意 k 个坐标，修复至多 k²/(1024n) 个坐标的较大来源权重至多为 (CN/t) exp(−k²/(4096n))，其中 N 为相对半径档数。

这组坐标可以在看过第一个较大来源后选择。把它取为该来源漏掉的坐标，便能直接从真实四来源积分中扣去第二个来源修复过少的部分。当 k 至少为 256√(n log(n+2)) 时，新增费用由原接收质量的 O(n⁻¹⁰) 倍吸收。其余来源仍可能修复了规定的数量，却继续漏掉许多坐标；这一部分尚缺一般预算。

本机与 MacBook 的两种有理算法独立核对了12项非同分布伯努利尾概率。本机还检查了九个真实历史中的修复数和原高损失，含尾界有衰减及无衰减的对照。详见[完整证明与复现材料](research.zip)。
