# 第591轮：全尺度空间付款与联合接触几何

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮经独审通过，未宣称一般维数阶改善。

## 已证明与未付部分

- 所有尺度共用的空间异常集 G 具有一次费用至多 2e^(1/4)W/δ，δ=min(1/4,n^(-1/2))；G 已包含单原子异常集，避免重复付费。与 H2 合并后的完整入口为 c_G=2√n+2e^(1/4)/δ。
- 固定质量时，全部原子子集的完整接收并集在端点排序区域内逐轴仿射。固定来源数的极值可取含明确人工边界的坐标多面体顶点；没有推导联合凸性或自由质量变分。
- 完整共同切分保留出生盒、重叠及子输入接收集平移损失；极值比较的方向不足以证明所需正增益。接触中性协方差还可能退化，二阶开缝和光滑交叠仍未付款。
- 全尺度有限原子界若统一于来源数，可以不损失尺度因子地恢复一般 L1 输入；这一条件本轮没有证明。

## 实际验证

冻结 n=2、三来源质量 (1/2,1/3,1/6) 的10个位置参数点，始终包括全部7个原来源子集盒。9个小扰动点同端点顺序，混合项系数精确等于1；较大点跨顺序边界后原公式外推失效。没有极值认证、维数外推或新参数扫描。

端点划分法与独立包含排除法一致：后者计算10×127=1270个交盒项，10个最终体积的精确根式系数逐点一致。使用 Python 3.12.14、SymPy 1.14.0、python-flint 0.9.0/Arb512；主代理实际重跑两种实现。浮点近似只用于展示，符号判定没有浮点回退。
