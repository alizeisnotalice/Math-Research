# 第821轮　许多横向来源共同捕获同一实际右来源

延续11月23日指导第5节及第820轮的单窗真实接收分组。固定一般有限正来源 \(\mu\) 和阈值 \(\lambda\)，在单窗 \([1,2]\) 的真实成功集 \(F\) 上记 \(M=\lambda|F|\)、\(S=\|\mu\|\)。最高端点的费用至多为 \(S\)。本轮研究同一个接收者从不同实际来源出发时，所有后继方体的共同来源质量。

**已证明的必要结构。** 固定 \(\epsilon>0\)、每条射线的后继数 \(k\)、相邻对数体积差下限 \(a\ge\log2\) 和允许损失的早来源比例 \(\xi\in(0,1/4]\)。如果 \(M\ge\epsilon nS\)，则在占原接收质量固定正比例的记录上，有一枚共同的真实来源 \(q\)，以及至少 \(cH\) 个不同的真实来源 \(p_i\)。这里 \(C_0\le H\le h n\)，各常数只依赖已固定的参数。每个 \(p_i\) 经同一个早中心 \(x\) 发出一条射线，产生 \(k\) 个实际价档不同的晚接收者。它们同时满足

- 所有晚盒的共同交含早盒至少 \(1-\xi\) 比例的实际来源，还同时含有全部保留的 \(p_i\) 和 \(q\)。
- 每个 \(p_i\) 到 \(x\) 与此前各来源所张仿射平面的 \(\ell^1\) 距离大于 \(c'nt_x\)，其中 \(t_x\) 是早盒边长。
- 对每个保留的晚盒，若给定本臂 \(p_i\) 和该盒的实际体积档，按原接收测度独立重抽另一只盒，其再次捕获同一 \(q\) 的概率小于 \(e^{-c''n}\)。

取 \(H=\sqrt n\) 有至少 \(c\sqrt n\) 个这样的方向，且边长总比至多为 \(e^{1/\sqrt n}\)。取 \(H=hn\) 时，方向数至少为 \(ch n\)。费用中保留每一个实际接收边际。对所有来源臂作平均及对全部臂逐一求和，两种总量相差臂数因子。

**已支付的原质量。** 在早盒抽取同一个 \(q\)，在各个晚盒的实际体积档用冻结来源表检验它。若每表真实质量至多为本档阈值质量的固定多项式倍，且 \(H=\sqrt n\)，则对所有臂取平均、保留每臂全部 \(k\) 个晚盒后，可支付的原质量至多为
\[
 C n^{5/6}\log^{1/3}(n+2)S .
\]
证明将早盒限制在两真盒的交上。若早盒实际保留比例为 \(c_0\)，新条件律相对晚盒真实来源律的熵恰为 \(\log(v_{\rm 晚}/v_{\rm 早})-\log c_0\)。按原权 \(c_0\) 积分，跨尺度成本由对数体积比支付。另对能随接收者及先前已抽来源改变的低维仿射平面给出全尺度管内质量上界。

**实际核验和剩余问题。** 本机以有理算术核了共早中心的正 \(L^1\) 双射线和多方向例。1024维正密度例含512个所列方向，枢源中心到先前张成空间的距离精确为 \(2368/5\)。4096维例的体积比约为 \(3.80\times10^{27}\)，实际对数成本约为 \(63.50515\)。256位和384位 Arb 分别复核熵式与三个温度。尚缺对同一个 \(q\) 在这些多方向、逐档极难重新捕获的晚盒中重复出现的**总质量**估计。各臂只在给定早中心、进行共同筛选之前独立。一般单窗 \(B_n=o(n)\) 和全尺度 \(C_n\le K\sqrt n\) 仍待证明。
