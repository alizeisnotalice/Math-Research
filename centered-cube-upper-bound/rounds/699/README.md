# 第699轮　真实接触与跨层来源分配

第699轮给出跨层共享来源的全局支付估计。采用同一套嵌套空间分区时，每个接收者可自行选择层级；采用真实接触胞腔构成的可逆链时，每个接收者可自行选择任意传递长度。两种估计均保留真实接收体积，费用不随层数或步数增长。
