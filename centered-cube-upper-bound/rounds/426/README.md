# 第426轮：两源归一恢复预算与双终端排除父核

一般上界未闭合。本轮没有新增原费用付款，未付量继续记R425，原C425、V425及完整总账不变。

已证明并核验两项结构估计：

- 原递减对称两源核及同一阶段标记ν=κ_i b_i M_i满足
\[
\int\frac{d\nu}{\sqrt{c_i(y)c_i(z)}}\le\sqrt{A_0(A_0+L_0)},\quad c_i=\max(D_i,s),
\]
其中A_0=∫fD_0/c_0、L_0=∫f log(c_0/s)。保留归一恢复、初始与终端费用；带权原费用还需乘τ^{-1}。
- 同时捕获两来源、排除两终端中心的真实父质量尾，受明确的两盒交集减去两盒并集的体积积分支配；两排除盒的交叠计入容斥。该中心体积差尚未转成来源付款。

**未解决项：**去除原两源费用中的√(D_i(y)D_i(z))因子，以及完整来源—父—双终端积分的根阶预算。正文给出精确积分及充分但可能较松的上放版本；不要求更强上放一定成立，也不把它当原问题等价式。

本机验证：31个共同后验阶段核配置，全部恢复项为正，16个非零终端，全部通过C-S平方检查；36个真实一维父核配置，其中12个使用非均匀完整f，26个实际核为正。它们分别核代数和原生父几何，不认证高维完整历史。独审与隔离复跑见归档。
