# 第653轮：后继增长费用修正与真实分支总账

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮保持 Eulerian 联合覆盖路线。

本轮证明强来源入侵的实际已拥有接收体积满足

`V_B <= (2/3) R S + (15/64) E_next,C`，

其中 `C = B ∩ {u' > 8κ/3}`，条件为旧 `κ >= 7/2`、`0 < κ' <= 4`。先保留 `R'/R = κ'/κ` 再估计，消除了原粗界中的小 κ' 假奇性；未来费用只落在明确的高增长行。**这是已拥有体积的估计，不是丢失副本重数的估计。** 完整两步账、下一代重叠、低 κ' 后继及终端费用均保留。

报告给出实际联合价格对偶和完整未付量 `sum a'[u'χ−κz]/ε`，并修正旧质量层嵌套只能用于同奇偶或至少两级间隔。条件来源积分保留随全部锚点变化的真实丢失指示函数。通用范数嵌套没有被称为方体独有的维数收益。

真实一维 KKT／正宽来源模型在旧来源势接近下确界时仍有阻挡：单标签模型的完整 Euler 期望 D=0；分割为2、3个标签的完整两分支期望有精确有理包围。该模型 R=15/272<1，**不是全局 near-score 临界状态**，不据此推断一般上界。
