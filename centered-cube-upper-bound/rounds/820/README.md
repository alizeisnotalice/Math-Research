# 第820轮　同一来源上的多尺度分组与真实交质量

依11月23日指导第5节，直接处理任意有限正来源 \(\mu\) 的真实最右越阈方体。沿一个实际来源 \(p\) 的同一条射线，可以把不同体积档的接收者编入同一组。组内任意晚盒都含有每个早盒至少 \(1-\eta\) 的真实来源质量。所有组、所有位置的接收边际加起来仍由原测度 \(\lambda\,dx\,P_x(dp)\) 支配。

**单窗分解。** 固定每组长度 \(k+1\)、相邻对数体积差下限 \(a\ge\log2\) 和 \(0<\eta<1\)。要求组内最大对数体积差不超过 \(H\)。对原单窗中任意可测的来源和接收者子集，记其真实质量为 \(M_E\)。存在组测度 \(\Gamma\) 满足

\[
 0\le M_E-(k+1)|\Gamma|
 \le C_{k,a,\eta}\left(1+\frac{n}{\log(2+H)}\right)\|\mu\|,
 \qquad 2\le H\le n\log2.
\]

取 \(H=\sqrt n\)，未分组的全部原关联共费 \(O_{k,a,\eta}(n/\log(n+2))\|\mu\|\)。此时组内最大边长比至多为 \(e^{1/\sqrt n}\)。若只许体积比至多 \(n+2\)，对应费用为 \(O_{k,a,\eta}(n/\log\log(n+3))\|\mu\|\)。结合第816轮的真实源输运，取 \(H=\sqrt n\) 后，全尺度未分组费用为 \(O_{k,a,\eta}(n)\|\mu\|\)。总账均保留 \((k+1)|\Gamma|\)。

**几何机制。** 设 \(r=2\|x-p\|_\infty\)，\(t_x\) 为真末根边长。在同一射线上，量 \(n(t_x-r)\) 的下降控制晚盒遗漏的早盒质量。证明使用晚根在未来每个可用尺度的真实质量上限。按 \(\log(t_x^n/r^n)\) 分层后，一维径向入射有可求和的密度上界。把势下降超过允许值的有序对连成偏序，每次取出一组反链，组内所有早晚对同时满足质量要求。余下的链以实际势降和径向跨度结算。

**一对实际来源可在多档共同出现。** 从首盒另抽取真实 \(q\)，至少 \(1-k\eta\) 的组质量在所有盒内同时保留 \(p,q\)。若单窗费用达到 \(\epsilon n\|\mu\|\)，则可选仅依赖固定参数的 \(H,m,c>0\)，使正比例的同一批组在每个档都满足一项来源相关性条件。给定 \(p\) 和该价档，在本盒多读 \(m-1\) 枚实际来源后，受测 \(q\) 的条件似然至少提高 \(e^{cn}\) 倍。训练来源由各盒分别抽取。不同价档的参考概率不能相乘。

**实测与缺口。** 本机有理计算核验了一个二维非嵌套正密度例，一对真实来源保留份额为 \(3/4\)。在32、64、128、512维的正密度例中，各验证五个不同价格档和十对早晚来源份额。另穷举4374个有限偏序输入，并在真实接收胞上以256、384位 Arb 复核条件信息。尚须给全部成组质量定价。在同射线上生成的多个接收者保留了角度依赖，第817轮对独立选择的估计不能直接移用。一般单窗 \(B_n=o(n)\)、全尺度 \(C_n\le K\sqrt n\) 以及第813轮原双臂的完整估计仍待证明。
