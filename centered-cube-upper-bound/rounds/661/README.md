# 第661轮：因果接收筛选与不同共享子集的方体合并

2026-11-15。一般纯 C_n≤K√n 及旧一般 n^(1/2+o(1)) 目标仍未证明。本轮没有新增一般维数阶上界。

## 已证明的结果

- 从任意原有限族作真实因果接收筛选，只付固定覆盖因子1+exp(1/16)，并使每个接受owner上的过去来源负载≤1。该限制没有赋予原输入f密度帽。
- 对固定锚点来源，允许不同目标使用不同的共享子集。只要每个目标的共享负载≥τ/3、尺度满足同一窗口，τ=8√n、n≥256时，整组真实receiver并集≤exp(−√n/20)U_0。比R660“所有目标共享同一来源子族”的条件更宽。
- 关键几何是单位方体加ℓ1半径t的精确体积比 Σ binom(n,k)t^k/k! ≤ exp(2√(nt))，与真实来源层积分结合；全域标量证明不依赖有限数值外推。

## 完整费用与未解决问题

保持R660全族远账：V_sel=U+V_far+V_near，V_far≤2exp(33/32)U/τ，原P≥U/τ。

对任何符合条件的部分分组，正确余账仍含 exp(−√n/20)Σ_h U_h + V_frag。不同锚组可能重用来源，不能把Σ_h U_h改成U；某个目标与许多锚各自交负载不足，也不能强归任一组。全部近尺度损失的锚点选择、碎片化负载及总价仍未证明。

关闭了未截断全空间平方放缩：真实单尺度张量网格给精确指数反例，但其没有near损失，不反证原目标。不再用已知L2源场定理替代新增非切向上确界，也不把平方等价改写计为进展。
