# 第328轮：完整总账约束下的跨越容量与大原子付款

**一般 n^(1/2+o(1)) 一致弱型上界未闭合。** 本轮独立审计通过两个有明确适用范围的新估计。

- 一般软核整块跨越分解 E=L^-+C−S，原完整平方 S 保留；实际半径原子容量 K 给出 C≤K W_nu。无原子时 K=0，密集原子仍可能为线性维度费用。
- 硬核匹配场的跨越后大相对原子创新，获得 (16/3)sqrt(A_n)log_+(A_n/(q_-H))W_beta 的来源预算；新增正 X 损失为零。连续及小原子余项保持真实旧尺度对称差质量、旧势与有利修正，未获一般根阶预算。

完整总账保留一般软核密集原子及后续创新、质量可比重尾、极端尺度比/宽距离/低 pe、初始项、删除跳跃、未来删除来源、旧残差及全部外层费用。物理半径付款不替代时间原子预算；原负平方不重复扣除。尚无依据称只剩常数和对数优化。
