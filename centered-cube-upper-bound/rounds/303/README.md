# 第303轮：软坐标严格收缩与局部重列边界预算

一般n^(1/2+o(1))一致弱型上界仍未闭合。本轮直接推进R302剩余几何费用：一方面把完整软核的双尺度点幅度从根阶改善为维数无关，另一方面支付边界费用中含远接收器的部分，组合后只保留当前目标分支内的局部重列边界费。

## 新增严格估计

令rho=P(|W|≤3/2)=1−2∫_0^1 u exp(−3/(2u))du，其中W具有原真实密度w。对所有a≤L,R≤b≤2a和所有位移，每个软坐标的实际重叠满足φ_L*h_R≤rho/max(L,R)。将这个严格收缩保留到共同softness正展开，再积分两套尺度，得到

||P||∞≤(2a^(−n)−b^(−n))/(1−rho)。

rho≈0.88652101965929，(1−rho)^(−1)≈8.81220466554781。双尺度选择费用完整保留；P的L1质量仍是A_n²Csoft_n。该点值改进不是维数无关弱型定理。

原实际近对、轻局部列的交通可按2L0ν(Z_light)/(1−rho)支付，条件是β(Q_(2Db)(z))≤q_-a^nL0。由此可把L0扩大到根阶乘固定对数，而仍维持根阶来源价格。

另对任意原行接收器集合G_y，记f_y=∫_(G_y)U_y，则高累计行边界费用中至少一端落在G_y的部分满足

B_H^G≤4λ∫β(dy) f_y[2+log_+(I_y/H)]。

原累计CDF原子、终端尺度及原J分母全部保留，未出现(b/a)^n损失。使用真实完整软尾，取距离D1=1/2+log(1+16A_nCsoft_n n[2+log_+(A_nCsoft_n/(q_-H))]/(9ε))，该远接收器费用≤εWβ。

## 接入原交通的合并预算

令H=√(dA_n/(4λ))、C_rho=(1−rho)^−1；以D0=1+log(1+16A_nCsoft_n n/(9ε))划分近远来源，再按原局部β质量冻结ν_l、ν_h。保留原完整e_g、m、q、FIRST和历史，不随ν_h重算，可得

T_target≤2C_rho L0 Wν_l+4√(λdA_n)(Wβ+Wν_h)+3εWβ+2B_H^near(D1;ν_h)。

取L0=√A_n，已显示来源项为根阶，并保留λd和原aspect费用。最后一项只含重局部列和两个近接收器，但尚无一般根阶预算。它是正上界中的辅助几何费，不冒充原交通的精确余项划分。极小aspect补集及原外层时钟、来源桥仍待支付。

辅助重列笔记另核验了由R297自动推出的内侧捕获分支；未认定它相对既往近端工作具有独立新颖性。跨越接收立方体边界的整支推广需要额外的全半径硬帽，当前未验证其原始来源，因此仅记录为条件结论，不用于上式。

## 实际验证与复现

调用本机MATLAB R2026a Update4：三组尺度窗口的原软尾积分，宽/紧容差复核通过。Python另运行62项40/60位实际软卷积和共同系数和检查，包含两种尺度方向、端点附近、零/非零位移及n至1024；均通过，高精度求积不冒充区间证书。

15个真实正体积L1来源/接收壳模型，按n=4、8、16三阶段，1621项Fraction检查通过，主代理复跑。预计算1065个张量交叠二阶矩：每个一维交叠分段仿射，乘积二次式由精确分数积分。31个同心层的Q精确为零，位移模型出现正Q，显示这些模型中的边界贡献；不外推一般阶数。仅实现真实s=0核、FIRST和同半径硬帽，未认证完整low/m/e_g/history或所有半径极大硬帽。

接收器稳定性稿内嵌检查已由主代理提取复跑：384项有理pair/尺度检查、288项预算检查（对数用双精度1e−13容差）、72项尾参数检查（双精度1e−12容差）。辅助笔记另复跑540项有理内侧/自尺度检查和90项外边界检查，其中对数比较使用浮点。这些计算与严格证明分开记账。
