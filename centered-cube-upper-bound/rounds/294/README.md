# 第294轮：逆向变差消除饱和核心尺度费

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮建立新的全尺度几何包络工具，接回原完整质量与实际低pe交通；不是仅对有界密度来源作条件估计。

## 新的一般估计

设 H≥0 可积且沿每条射线非增，A(t)≥0 随尺度非减，a≤t≤b。允许硬边界、A的跳跃和0/∞值。记

    tau(t)=t^n A(t), D(u)=∫min(H,u), U(u)=∫H 1{H<u}。

证明

    ∫sup_t min(t^(-n)H(x/t),A(t))dx
       ≤D(tau(b))+n∫_a^b U(tau(t))dt/t。

旧包络对跨尺度的全部截断质量 D 收费；新式只对未饱和尾质量 U 收费，饱和核心仅付终端项。证明采用逆向有限尺度网格，不依赖光滑性，也不忽略实际选择器可能落在硬边界的情况。

进一步，由 tau(t)≤tau(b)(t/b)^n，若 0<delta<1 且 R_delta=∫H^(1-delta)<∞，有

    ∫sup_t min(t^(-n)H(x/t),A(t))dx
       ≤(1+1/delta) tau(b)^delta R_delta。

这里消去了旧系数 1+n log(b/a)。R_delta、终端tau及各比例带的费用必须保留，不能据此直接宣布根阶。

## 与原来源及几何的连接

把原轻块阈值的 q 冻结在 q_+=lambda，构造完整加权来源质量 e^+，保持原权重、距离限制和树路径。证明 e^+≤e_original 且差值≤lambda g^n J_j(g)，包括没有轻块时的fallback。原归一化质量的损失不超过 4sqrt(n)/(3ell)。原 e_g 和 low/high 资格不被替换。

利用合法单调映射 u_j(L)=min(bc_j,L/c_(j+1))，原低pe响应受非减高度 2Klambda/e^+(y,u_j(L)) 控制。先在真实接收点使用原硬cap，再应用新引理，得到无来源密度假设的完整 beta 加权尾质量预算。e^+=0按无限高度处理，不能误判为空交通。比例带求和明确保留。

在原高质量分支 m>M+d0、d0=4sqrt(n)/(3ell) 上，进一步以 e^+(g)/g^n 的源依赖根划分长尺度区间与宽度至多 log(gamma) 的终端带。跳跃根使用左极限；端点仍有原低pe截断，不能按空集省去。对软尺度 L≤硬尺度 R，跨全部原比例带获得真正的来源线性付款：

    T ≤ (16/3)(3+1/delta) R_delta
         (8K/(3ell M))^delta
         /[1-gamma^(-3n delta/2)] · W_beta。

其中 gamma=1+1/n、ell=1+log n；原外因子Lambda另乘一次。此为更尖锐证明式的简化上界，保留完整原e_g及所有原限制，不需要来源密度上限，也不固定来源距离。反方向 L>R 的比例带系数则增长，不能套用这个几何级数。全软度 R_delta 也未被证明足够小，因此这一真实分支付款尚非一般闭合。

另证明了实际共同软核的保质量来源平均与尺度迁移：平均边长d时，双核代价≤exp((2+4sigma)nd/a)，d≤a/n时≤e^6。物理上端边界可用原cap支付≤3W_nu+16Csoft_n W_beta。迁移后的软cap仍需明确的原未来尺度cap；小尺度平均本身未解决来源集中。

## 验证与证明状态

主引理先经独立命题审查，随后审核完整证明；冻结质量和来源迁移另行审查。检查脚本以本机Python Fraction及mpmath 1.3.0运行，主代理复跑输出hash一致。

三阶段共有63个径向分层模型（13/20/30）：708个精确有理单步检查，含65个正值 p=A 的严格指标边界；386个有理断点分段计算真实连续尺度上确界；维数至1000；189个delta=1/10、1/2、9/10的矩预算检查。40/60位最大差异约2.13e-39，全部通过。浮点积分不是区间证书，有限实验不替代全维解析证明。

实际节省例：n=1000的饱和硬轮廓，真实包络积分与新界均为0.5，旧界为347.07359，约694倍。该例仅展示已证明公式消除的费用，未作为一般极大算子证明。

额外复跑了800个树路径/fallback检查、2000个有理单步检查、1138个根与方向覆盖检查，以及1935个实际软核平移—放大检查，均通过。相关脚本一并归档。

复现：解压 research.zip，在安装mpmath 1.3.0的环境分别运行 `python3 checks.py`、`python3 tree_checks.py`、`python3 transport_checks.py`。包内保留完整证明、LaTeX文本、审计、必要代码/结果与SHA清单；不编译PDF。

## 剩余缺口

新估计不再重复收取饱和核心的线性尺度费用，但尚未证明所有原来源的终端质量、未饱和尾矩与比例带总价共同满足根阶预算。保质量平均同时满足合法响应比较与足够来源集中控制的桥梁也未完成。原连续高score及初始/跳跃/删除账目仍各自保留，不能由本轮原低pe付款代替。

本轮继续使用64项数学工具中的A02外放松预算原则，所有扩大、真实dx、原来源和Lambda一次均显式保留。实际额度扣减数据不可获得，不猜测模型成本。仅提交最终报告、一个精简研究包和项目总览更新。
