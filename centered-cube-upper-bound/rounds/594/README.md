## 目标与结果

将共同来源块着色与实际压缩、单一全局平移组合，直接计算全部混合来源的新接收并减去两侧完整纯接收的交叠。条件回代保留全部异常集入口费：不只需要 L_n/η，也必须支付 c_δ/η。

统一缓冲保护满足 P_t−t/2 ⊂ P_0，故该保护本身不能产生超越零平移的新体积；这不否定实际颜色极值释放和混合出生的增益。完整共同半径的双接收积分身份成立，但任意子输入的平坦平移平均可以为负。避开全部纯接收碰撞的共同平移律合法且收益非负，仍缺逃出差集的定量收益以及真实归一化体积预算。所有论证保留全并重叠，没有把原域来源帽套在移动后位置上。

同轮还核验了相同输入双副本：纯接收总价可精确等于原价，但标签数倍增必须改用全局有限原子近极值上价。匹配见证桥的平坦积分不强迫正增益；自适应正峰及未匹配混合出生仍未预算。它是已有重组机制的对称特例，不计作新一般估计。
