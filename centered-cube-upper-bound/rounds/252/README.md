# 第252轮：二阶胞内采样与粗胞来源的根阶付款

一般 n^(1/2+o(1)) 一致上界仍未闭合。本轮对任意胞内L1形状证明固定尺度采样界

    ||h_R*μ||_2² ≤ (1+32d²/R²)^n Σ_C μ(C)²/d^n。

进一步明确支付连续尺度网格的n费用：取粗胞边长d=a/(8√n)，将原μ按μ(C)≤λd^n/√n切出μlow，得到

    ∫E h_R(x)*μlow ≤ ελ|E| + [3e^(5/2)/(4ε)]√n ||μlow||_1。

来源按原限制分解，允许胞内强集中；高质量粗胞μhigh原样保留。其一般联合几何费用、原soft/双后验及全尺度来源回代仍未闭合。没有把固定尺度估计直接当作最大值定理。

[研究包](research.zip)含详细LaTeX文本、独审、证明、必要计算与复现材料，不编译PDF。接收胞共享尾法仅作为辅助：其有限例虽改善整域静态阈值，但简单逐胞高度上界更优，已完整列出。
