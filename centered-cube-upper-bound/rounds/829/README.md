# 第829轮　跨中父的真实来源份额与共同接收费用

固定第828轮剩余的原双臂。一个左父 \(u\) 可以在许多尺度、经许多中父 \(t\) 与不同右价相遇。本轮给这些记录共用一个来源预算，再在删除后的同一批记录上估计两个真供应点与三处接收位置。[完整 LaTeX 证明、复现脚本与输出](research.zip)

## 对同一来源只结算一次

对仍在使用的左父集合 \(\mathcal U\)，记 \(F(p)=\sum_{u\in\mathcal U}(j_u/m_u)\mathbf1_{G_u}(p)\)。用真实外部来源 \(G_u\setminus A_t\) 在 \(1/(\epsilon+F)\) 下的质量给 \(u\) 分配份额，其中 \(\epsilon=1/(n+2)\)。原左行一旦由接收费用和该份额支付，便同时删除它在所有中父的全部右臂，按剩余父更新 \(F\)。每一步的来源费用由同一势 \(\int\log(1+F/\epsilon)\,d\mu\) 的下降量支付。

允许任意次序、两端轮流进行。所有已删除记录的总费至多 \(C(\mathcal H V+nS_*)\)，其中 \(\mathcal H\lesssim1+\sqrt n/\log^2(n+2)\)，\(V\) 为接收总体积，\(S_*\) 为原归一化来源总质量。终端中，每条原记录两侧都必须满足实际行密度与外部来源负载的乘积限制。证明还给出两枚独立真供应同时满足终端几何限制的最低条件份额 \(1/32\)。

三处实际接收者的计算保留同一个中父位置。若两枚供应在至少 \(5n/6\) 个坐标上达到按三父真实体积档确定的分离门，这部分成本为 \(C(\mathcal H/L)\eta^2(n+2)^3\log(n+2)e^{-n/12}S_*\)。允许任意少数轴大幅越出中父的另一部分，也可按全体来源一次求和。

## 一般末根上的双端预算

在真正的中心方体末根上，可以先读接收者 \(x\) 和第一枚真来源 \(p\)，再预列 \(M\) 个参考点。一旦第二枚真来源 \(q\) 距其中之一的 \(\ell^1\) 距离至多 \(u t_x\)，该批原记录就有可回代的全尺度费用。对任意来源割 \(A\)，若 \(u=O(1)\)、\(M\) 至多随维数多项式增长，原归一化双端质量至多 \(C\sqrt{n\log(n+2)}\,\mu(A)\)。更一般地，\(u=o(n)\)、\(\log(M+1)=o(n)\) 时费用是 \(o(n)\mu(A)\)。列表可随首端和接收者改变。证明使用第二端的最早真实见证给每个小格的真实质量定价。

## 计算与缺口

- 两份第814轮原数据各有34条实际行。各自五个小父的120种删除次序均做了有理计算与对数势区间核验。原装数据的逐项最高费用约155.33，初始势约267.52；重建数据分别约155.24和267.37。
- 对准同一原始行权，核算真实外供应和双接收体积。三父远门在这两组四维行的独立重复中命中概率严格为零，第四轴的真实支撑就足以排除。这决定了下一步应研究中等分离的终端记录。
- 对原末根覆盖公式枚举7238个整数指标，并以正密度来源核验真实条件质量、阈值边界及参数范围。全部有限计算与解析结论在报告中分别标注。

剩余小父可以有很高的行密度，外部供应仍可能被许多剩余小父共同使用，而相互分离的轴数达不到远门。来源势已支付删除过程，尚缺给非空终端自身估计总量的方法。一般单窗 \(B_n=o(n)\) 与一般全尺度根阶弱界均未闭合。
