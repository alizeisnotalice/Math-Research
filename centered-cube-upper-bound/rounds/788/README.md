# 第788轮　跨中父的离散来源与整行峰量

第787轮的同一来源可以被许多不同中父反复使用。本轮直接把真实小端的价格合在一起计量，证明其中能由下述参考分布承接的部分，在全部中父和尺度合计后只需 \(C\sqrt n\,\log^3(n+2)V\)。两端各自的来源、质量分母、实际接收体积和原峰分母均保留。一般弱型上界仍未证明。[本轮详细 LaTeX、复现代码、实际输出与校验值](research.zip)

## 哪些真实峰已可支付

- 在每个绝对半径八度 \([R,2R)\)，按边长 \(R/(64n)\) 的细胞核对真实来源容量。一个共同参考预算供所有中父使用。细胞内可保留任意实际价点和小端历史。式（2）和（3）给出正测度分配与全体接收所有者的换序。
- 第一类参考允许各宽轴为独立的离散分布，只控制长度 \(R/\lceil\sqrt n\log^3(n+2)\rceil\) 的单轴窗质量，并允许至多 \(\sqrt n\log^2(n+2)\) 个例外坐标任意联合。按实际壳中源点的单侧质量秩积分，得到式（4）和（5）。第二类允许本轴分布依赖以前的真实坐标，要求每份条件律到预定均匀区间的搬移距离满足式（6）前的界。该类费用为 \(C\sqrt n\log^2(n+2)V\)。
- 若同一中父的一半真实下降臂可由共同参考承担，整行都已支付，包括两端都落在参考未选部分的峰。其余行中，至少一个实际价格被选中的部分也已支付。式（8）进一步限制了实际价格强度高的小胞在每份可用参考下的总质量。

## 总账和缺口

直接在 \(Q_{772}\) 上，本轮新增已付原量至多 \(C\sqrt n\log^3(n+2)V\)。式（9）另给一条对任意有限输入成立的上界。记 \(\mathfrak d\) 为仅用上述两类合格参考、总系数不超过真实首臂质量 \(Y\) 时，各胞未承接实际来源质量之和的下确界，则
\[
 |Q^0|\le C\sqrt n\log^3(n+2)Y+C(n+2)\mathfrak d .
\]
在第787轮的加强入口上，式（12）保留早先的吸收系数与全部尺度费用。尚缺对参考承接比例低、两端均未选中并通过旧筛的原峰总量的统一界。细胞内的位置耦合不能推出任意输入的 \(\mathfrak d\) 都足够小。

## 实际验证

本机 Python 3.12.14 使用有理算术和 256 位 Arb。三个真实方体输入的维数为 8、16、32，分别有 2、7、13 个中父，同一正质量来源胞可被多个中父使用。把每对坐标的半细胞符号关联后，来源在微胞内的支撑比例分别是 \(1/16,1/256,1/65536\)。共同参考总质量在三例中都精确等于 \(Y\)，原诊断峰全部计入。二维三个尺度共用一个尺度选择时，包络积分两次独立计数同为 \(523459091/401448960\)。三份有序相关参考另验了真实后验的三阶矩。下界笔记的单周期小窗在十个维数点与统一阈值作了区间对照。物理例使用诊断硬门，完整高维归约仍以报告的解析证明和剩余条件为准。
