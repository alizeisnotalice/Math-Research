# 第762轮　原始全尺度接收积分的分数覆盖估计

对每个原接收父 \(t\)，提前选一份质量至多 \(m\) 的正测度 \(\sigma_t\) 作为见证，实际来源父 \(A_i\) 得到的份额是 \(\min(1,\sigma_t(A_i))\)。一份选择用于该接收父的全部来源、价格及尺度。以 \(C_t(m)\) 表示在原始接收积分中如此能够覆盖的最大真实流量。设 \(V\) 为真实接收者总体积，\(S=\|f\|_1/\lambda\)，取 \(L=\sqrt n\log^3(n+2)\)。对任何原筛选及 \(0<\tau<1\) 已证
\[
 \sum_t C_t(m)\le \tau V+C_K(1+L+m/\tau)S,\qquad
 \sum_t C_t(m)\le C_K\big[(1+L)S+\sqrt{mSV}\big].
\]
两种大小次序共用同一个 \(\tau V\)。证明在真实价格处按接收父的体积排秩，联合筛除低来源装填和低接收秩的乘积。余下部分用抽取新来源以前已确定的最优见证估计。

在原反证所选的真实输入上已有 \(V\le Cn\log(n+2)S\)。因此每个接收父可带入至多 \(\log^5(n+2)\) 个依过去选取的价格点。当前按真实父质量重抽来源时，所抽的来源父包含任一个旧点，这部分总流量至多为 \(C_K LS\)。

有限线性规划的精确对偶同时给出原矩阵的一次实际删减，以及删减后每行在任何空间点上的共同权重上界。另有一项纯根阶结论：若按较大父统一选见证，所标记的是原关联中的较小父，则两向被标记流量之和至多为 \(C_K[1+\log(2+m)]S\)。特别可以在这一用法中取 \(m=\exp(\sqrt n)\)。

**尚缺的全局估计。** 设 \(T_*\) 为指南中同一份终端流量。在它上面计算 \(C_t\)，若能证明 \(\sum_t C_t(\sqrt n)\ge\theta T_*\)，其中 \(\theta>0\) 与维数无关，详细证明式（9）即给出严格吸收并恢复到任意 \(L^1\) 的全部尺度。当前已付的是能被同一行见证捕获的实际份额；其余来源可经不同父标签跨行重复使用，尚无该固定比例下界。

本机以有理数枚举了真实区间、五环方体和十一父二维例，核验闭盒边界、真实价格重抽、最优分数见证与有限对偶。五环的最优分数见证质量是 \(5/2\)，整数见证需要三点。另检查28组尺度秩阈值及8组来源与秩的乘积阈值。
