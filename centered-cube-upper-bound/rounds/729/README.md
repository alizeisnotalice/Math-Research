# 第729轮　同一接收点上的四来源联合估计

开题核对[第706轮攻坚指令](../../AGENTS.md)。将第728轮的联合对偶限制到二值价格，最多增加一份根阶费用。对每个二值测试，在真实接收点逐行计算同一对来源有多少种四边联合见证。联合见证不足的部分直接吸收，其余可转入四个两两分离的来源体积层。

沿四标签顺序使用共同的前缀分布，只优化一个混合参数，全部四元组共用原对偶的同一份来源预算。四个来源的共同交集在若干坐标上受到足够挤压时，证明给出可实际支付的接收体积。对任意来源集合，超过该容量的四元需求扣除真实所有者体积后，仍缺统一根阶估计。

两机独立计算核对了36组四边见证阈值及二值价格费用。本机另核验了六个真实贪心正损失算例，维数为256、1024、4096。这六例已有远来源费用可用。数值范围、复现命令及完整原积分回代见[研究包](research.zip)。
