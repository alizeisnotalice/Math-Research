# 第64轮：覆盖常数等价与障碍交叉项抵消

日期：2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**；保留全一般 O(n log n) 基准。

## 已证明的结果

- 区分共同总质量预算与候选来源自身质量预算的两个精确对偶。两者的全类最坏常数均恰好等于原好集上的有符号逼近常数；重赋权不再引入额外的全类损失，但尚未估计这个常数。
- 对任意有限正原子来源，导出有符号自由交叉核及精确方体环带抵消，给出 E_G=T_G+B_free−B_bad，且 0≤T_G≤(1−e⁻¹)HW。好集始终由原来源确定。
- 真实近重合原子使自由项与坏集项分别发散，但差保持 O(HW)。这否定分开取绝对值收费；不否定一般弱型目标。固定实例的线性覆盖/真实配对比也可任意大，不能把该比误当作完整二次对偶的反例。
- 按原子质量选径向体积的完整混合采样，评分上界改进为 2(1−e⁻¹)N，消除了最小质量因子；仍显式依赖原子数，不是一般能量上界。
- 精确双原子积分给出归一化能量 (5−6/e)/4，严格大于单原子值 1−e⁻¹。该反例只否定更强的统一常数猜想。

## 实际验证

36组初探、282组最终实验及10组校准，共1,221,632个接收点。主矩阵独立改变维数与请求原子数；重复位置先合并并记录实际数量。无空间截断或时间网格，使用全部真实到达及完整混合密度。

564个阈值边界高精度核验、30个极端点评分/有符号Gram交叉核验通过。主脚本在新临时目录独立复跑，JSON逐字节一致；三组嵌入式检查程序均通过，包括72项精确覆盖几何检查、120项精确多阶段检查，以及精确积分的数值校准。

新采样在所测 n=16、N=64 不均权来源中将样本标准误从约0.018–0.025降至约0.0035，但理想Hoeffding半径仍约0.607。标准误不是严格置信区间；Decimal不是向外舍入。没有拟合或宣称一般渐近阶数。
