# 第793轮　同一对真实端点的跨中父平方和与接收体积预算

本轮在第792轮完整剩余 \(P\) 上，把不同中父、不同体积档使用同一对来源价的贡献联合估计，并支付了原积分中的两类记录。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、数值检验笔记与复现材料](research.zip)

**同一对端点上可以先合并全部中父再平方。** 以 \(v\) 表示中央原历史，\(M_v=m_vd_v\) 为中父质量乘真实度。固定两个完整端点及原价 \(x,z\)，令 \(p\) 为原峰的两端密度，\(u\) 为给原峰乘 \(\sqrt{M_v/\Phi_d(x,z)}\) 后的两端密度。这里 \(\Phi_d\) 是以两价为中心、按该档半径计算的方体交叠比例。报告式（2）证明
\[
u^2\le C\sqrt{n\log(2+2C_0(n+2)/L)}\,p,\qquad L=\sqrt n\log^3(n+2).
\]
各档之间的交叉项全部保留，无需给中央接受率设下限。由此，对足以保留原价交叠的实际接收记录，可用 \(C\sqrt{n\log(n+2)}\,V\) 支付。式（6）的展宽逐坐标处理接收交叠，可覆盖一条轴已使原接收交体积为零的情形。

**同一中央接收点可以给跨档来源记一次账。** 固定左端及其真价 \(x\)。在体积档 \(2^d\le m_v<2^{d+1}\) 上，写 \(s_d=(1+1/(32n))(2^{d+1})^{1/n}/2\)，将真实中央接收点 \(T\) 记为 \(\theta=(T-x)/s_d\)。固定 \((x,\theta)\)，所有实际占用的方体 \(Q(x+s_d\theta,s_d)\) 随档嵌套。记 \(S_e\) 为第 \(e\) 个绝对档新纳入的来源区域，\(\Lambda_O\) 为这一八度原端点参考的价格边际，\(Z_e=\sum_{j\le e}\Lambda_O(S_j)/2^j\)。当前右价 \(z\) 首次进入第 \(e\) 档时，式（9）至（10）支付
\[
1+Z_e\le\sqrt n\,m_vd_v/2^e
\]
的全部原峰。这里每一层使用它的真实来源质量，两方向共用同一个中央接收点。另一个直接判据是，若同一预选概率能以至少 \(1/\log^2(n+2)\) 的概率把真价放入价格质量不超过 \(C(n+2)2^d\) 的集合，则这些记录总量至多 \(C'\sqrt n\,V\)。

**总账与缺口。** 令 \(\ell=\log(n+2)\)，扣去已付款的并集，准确分解为 \(P=P_{\rm paid}+R_{793}\)，其中 \(|P_{\rm paid}|\le C\sqrt n\,\ell^2V\)。保留原割及原吸收系数后，
\[
 (1-\delta_0)|Q_{772}|\le k|R_{793}|+C_{\delta_0}(\sqrt n\,\ell^9V+n\ell S),
 \qquad k=O(\ell),\quad S=\|f\|_1/\lambda .
\]
剩余记录在两个方向上都已经累积 \(1+Z_e>n\ell^3\) 的归一化来源质量，两个真价均离开各自较早的实际方体。仍缺不同起始臂和探针方向重复使用这些来源时的总量界或固定比例收缩。

**实际验证。** 在 \(4,8,16\) 维真实方体及非均匀来源上，本机用有理数和 256 位 Arb 复算了 \(141,974,5616\) 条带两价的记录。八维诊断例中，不同体积档贡献了未乘逆交比例的完整平方量的 \(34.55\%\)。另对三组分别 \(300,1764,9324\) 个真实代表点与臂的组合，独立重算了乘逆交比例后的平方。在同一正体积探针区域，逐价胞和嵌套首入两种算法得到相同的旧价、新价质量；不同来源层的实际选择会改变获付量。高维标量证书检验到 \(n=2^{128}\) 的档形。有限模型使用诊断筛和诊断参数。
