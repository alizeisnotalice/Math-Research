# 第855轮　同一真实来源对和双臂终端共享的接收体积

对任意固定单窗割，本轮构造了两条可以在全部坐标重新抽取实际接收者的辅助臂。每次换源仍保持外方体嵌套。两臂可以共同使用一批具有正勒贝格体积的根中心，因而能够按这批实际中心的并集结算一部分原质量。原第813轮与全尺度目标仍未闭合。[详细 LaTeX、六项复算程序和实际输出](research.zip)

## 两臂可以同时观察的接收区域

固定两枚实源、原见证体积档，并按每个坐标到方体两面的距离给两枚来源各记一个胞。给定这些信息后，两条辅助臂的全部成功后继和失败符号，都不会再泄露原根中心。若这两臂共同选出的区域占对应真实接收截面至多 \(\alpha\)，其中原质量合计至多 \(4\alpha I\)。这里 \(I\) 是单窗双源积分。取 \(\alpha=\lceil\sqrt n\rceil/(n+2)\)，费用至多 \(16\lceil\sqrt n\rceil\|\eta\|\)。在固定右端 \(q\) 后，对所有左源和尺度合计，命中质量相对于 \(\eta(dq)\) 的密度也至多为 \(16\lceil\sqrt n\rceil\)。这个界保留两枚来源、两条后续路径和原见证分母，不随胞数、所有者数或深度再乘费用。

在同一来源对和两条辅助臂下还可补抽第二个真实中心，两份接收边际各自恢复原测度。若给每个胞对分配预算，两条终端收紧盒的实际并、交体积可以直接检验。仍需证明不同来源、不同胞和中父之间的重复使用能由这些共同接收体积控制。

## 第854轮既有历史得到的估计

在原全角历史中，把同一终端的所有祖先合并，可以分别支付两种情形。第一种是祖先中心所在物理胞与末次抽到的实源联合集中。最后一次正反秩平移有同一交长，抵消了大尺度比产生的费用。第二种是保留两枚根源后的完整祖先密度，相对于真实可达中心体积很低。两种判据之间仍有未控制的密度区间。

在另一项保留真实目标记录的计算中，大档距使两份后继共同拥有的新增来源增大。先在同一真实记录上合并，再按同一来源跨方向、跨档计费，可以明确计算实际付掉的原质量。还缺其对余根的统一命中比例。第706/739轮的全尺度账仍需总接收系数严格小于 \(9/32\)。

## 本机核验

Python 3.12.14 使用有理算术、SymPy 和 192、384 位 Arb。256维正宽双臂样本中，偏置历史上的条件命中率约 \(0.513889\)，相对于真实样本基准的原质量仅约 \(1.048\times10^{-19}\)。尺度互易证书检查至158档差，共同来源的几何增益检查至16384维。有限几何和秩模型各自说明适用范围。归档清单含各成员的 SHA-256，未编译 PDF。
