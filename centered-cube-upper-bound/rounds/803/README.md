# 第803轮　不同小父重复使用真实价和接收观测的全尺度平方和

对第802轮的完整余流，一份有向观测 \(a=(z,q,w)\) 保留自己旧价、对端旧价和对端实际接收点。将同一小父的两份完整记录作比较。不同中父和不同小父都可以使用同一片来源，本轮直接估计它们在共同物理参考上的密度重合，并把同一观测对在不同体积档的费用合并。[详细 LaTeX、精确证书与复现程序](research.zip)

**跨所有小父的估计。** 令 \(D_u\le m_u<2D_u\) 是小父的二进体积档，\(J_u\) 是其真实两臂合计质量，\(f_u\) 是按所有中父求和后的观测密度。\(\eta\) 用真实输入和不交接收区定义。取 \(k=\lfloor r/(16384\log(n+2))\rfloor\)、\(\Xi=\sqrt{k\omega}\asymp n^{1/4}\log^{5/2}(n+2)\)。沿用第802轮的 \(L,H,J,b_0\)，置 \(B=CH e^{-J-b_0/8}/L\)。对充分大维数有

\[
 \sum_{u,v}\min(D_u,D_v)^3
 \frac{\big(\int f_u(a)f_v(a)\,d\eta(a)\big)^2}{J_uJ_v}
 \ \le\ C\,\frac{B^2}{L} e^{-\Xi/128}\sum_u J_u .
\]

各档的交叉项使用可求和权 \(2^{-3|d-e|/2}\)。真实平方和包括不同小父，无须额外乘体积档数。所用几何事实是，任意球心处半径 \(s_u\Xi/32\) 的 \(\ell^1\) 球只容纳极小的真实价概率。它由之前的欧氏小球界和所有 \(k\) 维坐标投影的覆盖数导出。

**实际付款。** 对一对观测，按真正可使用它的最小体积档计算一次费用。逐档总费用介于这份物理并集费用与它的两倍之间。由此得到原比较质量的共同平方预算。允许各行的来源和接收投影高度重叠。给定这份预算后，程序与证明都明确构造捕获最多真实质量的共同测试。删去对该测试命中率高的原记录，全部中父合计只花 \(o(V)\)。在剩余的每个正公开行上，真实输入质量至多 \(D e^{\Xi/1024}\) 的任意来源集合，命中同一小父另一枚真价的条件概率至多 \(e^{-\Xi/1024}\)。全轮及旧门重查仍在 \(C(LV+(n+2)\log^6(n+2)S)\) 内。

**本机核验。** Python 3.12.14 对含两档小父的二维真方体作了三阶段有理计算。扩大例有 10831 个真实观测行，忽略不同小父会漏算约 6.6353% 的平方和。逐档费用与物理并集费用的精确比为 \(13797047549389428402557/13439382112871833938557\)。有限诊断中，约 45.3367% 的完整支撑预算可捕获约 80.0610% 的真实配对量，最优性由有理原对偶等式认证。一维压力和扩大例还区分了共享真价后独立抽隐父与保持原根两臂相关性的两种抽样。384 位 Arb 核验了六个维数的系数区间。

**剩余问题。** 完整合法配对并集的加权测度仍可能很大。平方和已经估计了两份观测的共同复用；若许多行只在一枚真价相遇，再抽时分散到各自不同的接收区，现有估计还不能把总流量控制在根阶预算内。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。
