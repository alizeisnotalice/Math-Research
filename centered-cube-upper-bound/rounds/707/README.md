# 第707轮　高损失积分的整行费用与真实账目

按[第706轮后攻坚指令](../../AGENTS.md)核对本轮。对象为（4）的全部坏接收者，各点选择使完整来源和最小的同一合法见证。通用估计保留原半径段、原权重及勒贝格接收测度。

本轮证明，选取时剩余容量至少为 1/log n 的接收者，以及能在预先固定且有列测度控制的空间变换下遇到足够实际来源权重的接收点，其完整高损失贡献合计至多 C√n log(n+2)D，已用 V_T 吸收系数为零。其余接收点仍保留原始高损失和。对这部分的统一预算未证。

在真实首次捕获族上证明 R_high/V_T 可趋于 1/2，而同一历史的归一化正余量趋于零。此类高损失例不足以检验最困难的费用。另有带非恒定高损失区域的有理数精确实例。[LaTeX 证明、精确证书及两机数据](research.zip)。
