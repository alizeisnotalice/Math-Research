## 严格成果与失败路线

证明任意固定阈值、允许随机化的密度替代若具有次幂的质量、覆盖及吸收费用，就不能把密度与阈值之比普遍降至多项式量级。这由固定p的维数无关定理与任意实际正次数弱下界推出，不使用未定量的p趋1常数。

第51轮的正则化给出 D_n(p_n)≤C_n≤e^(5/2)D_n(p_n)，p_n=1+1/[2n log(2n+4)]。这是常数因子的等价接口，不是新的上界。全维数 D(1+ε)≤C ε^(-1/2)log^a(2/ε) 是更强的待证充分条件，不声称必要。

真实正宽方体来源证明：归一相邻尺度差分 (A_(1+h)−A_1)/h 的全维数弱p范数至少为 c/[εlog(1/ε)]。因此不能将该差分免费赋予平方根弱端点速率；它不是原极大算子的反例。另给一维强Lp增长1/ε与弱p有界的区别。

核对Bourgain固定p定理，并完整阅读2026年离散方体差分预印本；后者未提供本项目需要的端点定量费用。Euclidean balls的新上界没有用于立方体。内部平方根下界按接受稿依赖保留，未冒充本轮重新认证。详细论证、来源与限制在归档中。
