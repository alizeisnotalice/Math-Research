# 第557轮：完整接收的共同矩阵几何与时间积分

**一般 $n^{1/2+o(1)}$ 一致弱型上界仍未闭合。** 本轮沿第556轮的同一合法切换核，研究全部顶点方向、全部径向幅度及共同时间的联合接收。获得可核的矩阵表示、权重连接和时间积分下界，但没有证明这些量在整个立方体上的根阶预算。恒等式和坐标变换不计作一般上界改进。

## 原始合同与完整总账

令 $n\ge2$、$Q=[-1,1]^n$，$N=2^{n-1}$ 个无向顶点方向 $\varepsilon_d$ 取首坐标为1。保留第556轮生成元
\[
\psi(\xi)=\frac{\pi}{N}\sum_d|\xi\cdot\varepsilon_d|,
\quad J*f(x)=\frac1N\sum_d\int_{|r|>1/2}f(x-r\varepsilon_d)\frac{dr}{r^2},
\quad \|J\|=4.
\]
$F=R_1^A*J$，$P_k=(k+4)R_{k+4}^{A_s}\delta_0$，有限 $k\ge1$。归一核仍为 $(P_k+F*P_k)/5$。第555—556轮的障碍构造、生成元完整分布证书、卷积交换和同一异常集合下全尺度恢复继续使用，不重复认证，也不假定二维结果能外推。

唯一待支付的完整合同是：某个有限 $k(n)$ 满足
\[
\operatorname*{ess\,inf}_{x\in Q}\frac{P_k(x)+(F*P_k)(x)}5
\ge \frac{c\,2^{-n}}{\sqrt n\log^B(n+2)}.
\]
只有该式才能把已有合法核恢复成一般输入的目标弱型上界。本轮不声称已支付旧中间段硬层或其他未付积分；若新核合同未完成，旧缺口仍保留。$P_k$、全部方向权、真实接收测度和时间权始终在式内。

## 联合几何：已核内容及未付款处

取独立标准正态 $Z_d$，令 $c_t=\pi t/N$，
\[
\Sigma_t=\sum_d\frac{c_t^2}{Z_d^2}\varepsilon_d\varepsilon_d^T.
\]
精确混合为 $p_t(x)=\mathbb E\varphi_{\Sigma_t}(x)$。平均协方差不存在，不能以其替换真实随机矩阵。对每个方向，以 $U_d$ 为横向正交基，$B=\Sigma^{-1}$，令
\[
a_d=\varepsilon_d^TB\varepsilon_d,\quad
m_d=\varepsilon_d^TB(x-Y)/a_d,\quad C_d=U_d^T\Sigma U_d,
\quad Y\sim P_k.
\]
径向完成平方给
\[
\int_{|r|>1/2}\varphi_\Sigma(x-Y-r\varepsilon_d)\frac{dr}{r^2}
=\frac1{\sqrt n}\varphi_{C_d}(U_d^T(x-Y))\omega(a_d,m_d).
\]
其中 $\omega$ 是真实条件正态的阈值积分。自方向方差可再精确积分，得到 Normal$(0,\tau_d^2)$ 与 Cauchy$(c_t)$ 卷积密度 $q_{\tau_d,c_t}$，以及
\[
\Omega_c(\tau,m)=\int_{|r|>1/2}r^{-2}q_{\tau,c}(r-m)dr.
\]
横向密度、$m_d$ 与 $\tau_d$ 来自同一去自身矩阵，不能拆乘其期望。$n=2,\tau=0$ 已核验合法。

定义完整 $T=\sqrt n(F*P_k)=\int_0^\infty e^{-t}T_t\,dt$，则 $\int T=4\sqrt n$。显式 $1/\sqrt n$ 只是坐标 Jacobian，并非已付根阶收益。

共同矩阵权 $l_d=V_da_d$ 满足 $\sum l_d=n$、$\sum l_da_dm_d^2=(x-Y)^TB(x-Y)$。令 $H_d=\Omega_{c_t}(\tau_d,m_d)/q_{\tau_d,c_t}(0)$，条件化自身方差严格给
\[
\mathbb E[l_d\mid D_d]=\pi c_tq_{\tau_d,c_t}(0),\qquad
T_t(x)=\frac1{\pi^2t}\mathbb E\sum_d l_d\varphi_{C_d}(U_d^T(x-Y))H_d.
\]
独审核清了条件化、系数、退化情形与空间可积性。$1/t$ 由内层空间总量中的 $t$ 抵消，不能单独丢弃；阈值费用 $H_d$ 仍需联合控制。等对角与 Hamming 几何约束见详细 LaTeX，尚未提供所需补偿。

进一步令 $E=(x-Y)^TB(x-Y)$、$\mathcal G=\prod_d(H_d/\sqrt{a_d})^{l_d/n}$，同矩阵加权 AM–GM 给出已独审的实际比较
\[
\sum_d l_d\varphi_{C_d}H_d
\ge n\sqrt{2\pi n}\,\varphi_{\Sigma_t}(x-Y)e^{E/(2n)}\mathcal G.
\]
右侧受原正和支配，具有完整积分保障；但尚无其联合下界。几何平均可能丢失方向之间的互补，因此不把 $\mathcal G$ 的下界升级成必须证明的强目标。自适应删除方向还须同时支付保留权重与横向能量，本轮未发现能减少完整费用的选择方式。

## 共同时间下界

耦合 $\Sigma_t=t^2\Sigma_1$，保留同一 $Y$、全部方向和径向变量。对于
$D=(x-Y-r\varepsilon_d)^T\Sigma_1^{-1}(x-Y-r\varepsilon_d)>0$、$s=(n-1)/2$，
\[
\int_0^\infty e^{-t}t^{-n}e^{-D/(2t^2)}dt
=2^{(n-3)/2}\Gamma(s)D^{-s}
\mathbb E_{G\sim\Gamma(s,1)}e^{-\sqrt{D/(2G)}}
\ge \frac{2^{(n-3)/2}\Gamma(s)}{12}D^{-s}e^{-\sqrt{2D/(n-1)}}.
\]
证明用精确换元及 Paley–Zygmund；$n>2$ 另有逆 Gamma 均值的 Jensen 下界。该不等式保留了真实存活折扣。当 $D\le L(n-1)$ 时，相对不带存活折扣的积分，保留至少 $e^{-\sqrt{2L}}/12$；但足够接收是否落在此区域仍未证明。详细稿保留全部行列式、来源与射线宽度费用，不把某个单窗充分估计升级为新的必要目标。

## 实际数值与研究决策

计算使用用户指定独立 Python 环境。两套数值实验仅估计未与 $P_k$ 卷积的 $F/4$，未抽取 $Y\sim P_k$，未计算 $F*P_k$ 或完整归一核 $(P_k+F*P_k)/5$。因此它们只辅助筛选混合积分方法，不能认证完整合同。初步模型保留 $F$ 的完整高斯混合与原始径向积分；没有截去大方差或大时间，也没有协方差加岭、丢弃坏样本。模型精确不等于浮点积分严格：下溢、病态、求积返回消息和收紧容差复核均单列记录。

压力核查发现未与 $P_k$ 卷积的 $F$ 的自然密度在顶点射线上可真发散，故不能拿角点有限抽样均值当参照；这不是原目标反例。实际选用固定 seed 的一般内部点。范围为 $n=2,4$、每维两个点、每维四批各64样本。保留全部方向与正负径向积分，并与相同样本的最大方向贡献比较。有限样本全方向/最大方向均值比约为1.26—1.51，不能外推维数阶或全立方体最低值。

复核使用完全相同的随机输入，精确积分自身方向方差，以 Voigt 密度替代该部分随机抽样。$n=4$ 两点的有效样本量约由37.36、10.50变为34.29、10.87，稀有贡献没有实质缓解。因此停止扩大同类抽样，转回共同几何；没有以更多样本报告代替证明。

SymPy 核验标量 Cauchy 混合、Schur 恒等式和 Gamma 换元。Arb 在192位精度对16个实际二进制输入对应的精确有理参数验证 $\tau=0$ 闭式的严格区间 $0<\Omega<4$。这仅认证列出的16个参数；求积比较误差属于浮点复核，不能视为一般区间证明。没有运行 MATLAB 或新的高维扫描，也没有优化器认证。
