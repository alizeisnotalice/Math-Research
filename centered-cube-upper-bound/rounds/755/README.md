# 第755轮　四个父方体的共同来源费用与尺度分布差

第754轮的最终遮罩满足 \((1-2\xi)T_0\le T_*+C\sqrt n\,S\)。这里 \(T_0\) 是第752、753轮共同的真实入口，\(S=\|f\|_1/\lambda\)。本轮选择在第750轮后进入该程序。第751轮的两向预测核费用包含在第752轮的同次筛选中。完整证明第4节逐笔列出了第747至751轮的归属。

本轮直接估计同一小端、同一来源点汇总全部大端后的高负载正部。取 \(L=\sqrt n\log^A(n+2)\)。在一个实际来源点 \(z\) 按装填权抽取两枚来源，按真实接收体积除以原来源质量抽取两枚接收。四条交边各自具有原有向流量边际。两来源都小于两接收，或都大于两接收的概率，有如下精确值

\[
 \frac13+\int(A_z-B_z)^2\,d(A_z+B_z).
\]

\(A_z,B_z\) 是两侧的体积秩分布函数。体积并列时独立均匀拆分，只用于排序。将平方差按原来源测度 \(FW\,d\mu\) 积分，得到可抵扣的实际量 \(\mathcal D\)。两两体积距离 \(|\log(d_i/d_j)|\le L\) 的六种情形合计只花 \(O_K(LS)\)，包括同侧抽到同一标签。

对严格分离的有序四元组 \(Q\)，记 \(I_Q\) 为四父方体交区，\(M_Q\) 为在此交区按四条原终端高负载权同时计算的真实来源质量，另保留 \(F\ge\alpha\)。写 \(L_+=\max(L,\alpha G/K)\)。以下两整批流量均已支付，每批费用至多 \(C_{K,\alpha}LS\)。

- \(M_Q\le GLL_+|I_Q|\) 的全部四元组。证明用真实接收所有者不交与固定 \(p=4/3\) 的方体强型定理估计所有四体交的加权体积。[Bourgain 原文](https://arxiv.org/abs/1212.2661)
- 在其补集中，从四父共用的真实来源分布独立取两点。对另外三个父方体的尺度，分别计算同时容纳两点时所有者可用的体积比例 \(D_k\)。若 \(B_Q=(M_Q/m_{\min})\,\mathbb E\prod_{k\ne\min}D_k^{-1}\ge N^3/(GLL_+)\)，则该组的全部实际份额已付。\(N=2+\lceil n\log_2(1/\delta)\rceil\)，\(\delta=\sqrt{\log(n)/n}/64\)。因子 \(N^3\) 是三枚标签的真实规模费用，已进入门槛。

以 \(Z_{\rm rem}\) 表示两项都未支付的四重积分。它保留第754轮同一遮罩、四个原标签、两向质量分母及两段半径比。取 \(a=32n,\ K=16,\ \alpha=\xi=\zeta=1/4096\)，在反证所需的首穿越输入上回代得到

\[
 \frac{337}{4096}T_0+\frac14\mathcal D
 \le \frac14 Z_{\rm rem}+C LS .
\]

**未付的费用。** 足以闭合一般上界的下一条估计是 \(Z_{\rm rem}-\mathcal D\le T_0/4+C LS\)，代入后净余 \(81T_0/4096\)。目前仍缺这一步。共同来源可以比交区体积高度集中，同时两点位移过小或四体共享比例过低，使两价检验无法支付。上述不等式本身尚未给出一般弱型上界。

**本机复核。** 在四维五个半径档与十六维九个半径档的真实方体族上，小来源方向的全尺度正部分别占该遮罩流量的 \(8.33\%\) 和 \(6.96\%\)，每档重置阈值均得零。它们是完整终端筛选前的算例，测试帽与全族 \(G\) 分别记录。另用四组有理分布核对未拆分边际与随机拆并列后的真实秩概率，并在 \(4,16,64\) 维以有正体积的来源盒及有理区间核验四父两价矩。第753、754轮的价格及分母算例也已复核。全部严格参数与有限计算的误差范围见证明包。
