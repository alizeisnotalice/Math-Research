# 第730轮　按四来源共同交长估计整族接收量

开题核对[第706轮指令](../../AGENTS.md)。对第729轮真实四来源需求，将每个坐标上的共同交长除以最小来源的边长。若至少 ⌈2n/log n⌉ 个坐标的归一化交长集中在同一个长 1/n 的区间内，且区间上端不超过 1−4/n，这类四元组的总接收费用在充分大维数下至多为 Ce⁻ⁿ⁄⁵D。区间可随四元组选择，允许集中在正的中间值附近。

证明固定最小来源，将另外三个来源的权重按不交的真实所有者体积积分。由四区间的共同交长算出各坐标分布，再把坐标选择、尺度档和真实接收体积全部计价。对更一般的交长分布，报告给出按各档坐标数判定可付款部分的有限公式，保留满交长处的原子。仍缺少对其余四元需求扣除所有者容量后的统一根阶估计。

本机和 MacBook 独立核对九个三维平移体积，验证切片公式与平台贡献。本机另检查36个四来源窗口预算，并在三个维数构造六个真实贪心正损失算例。这六例均有远来源可支付。粗估的渐近常数不能直接用于断言这些有限维数已有指数节省。详见[证明和复现材料](research.zip)。
