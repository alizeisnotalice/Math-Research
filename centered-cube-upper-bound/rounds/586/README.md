## 已证结论与完整费用

将高质量见证异常集扩大为全部质量在 [2U/3,2U] 的实际见证载体之并 Top⁺。固定尺度 Fubini 给出 λ|Top⁺|≤3W；它包含旧 top，因此3W替代旧3W/2，不再重复相加。H₂ 的2√nW费用保留。

在 R⁺=R\Top⁺ 的每个保留点，最大见证 N 的质量 M 与边长 r 满足：对所有实数1<s≤2，真实外壳来源质量严格小于(s−1)M。证明使用原原子排除和最大见证资格，对相关、集中来源同样成立，没有来源密度帽，也不需要按连续尺度另删零测集。

偶数高次距离 cₚ=Σ|xⱼ−zⱼ|ᵖ 的真实载体积分保留各坐标宽度 tⱼ 和乘积 β。对每个实际父内来源，证明

`λ∫_{C_N} cₚ/(r_N/2)ᵖ ≤ M_N[1+(n−1)β_N]/(p+1)`。

完整近壳流另由真实接收环域的并集体积控制，不能直接由上面的来源质量界推出。一个共同、允许依赖输入的大偶数p可使完整近壳流和父内参考距离矩分别≤ηW；报告保留p对全部输入常数的依赖，不把它声称为维数统一参数。

以真实连续最优耦合及其共同来源势展开后，完整账仅为

`(1−η−η/(2n))J⁺ ≤ J_内部 + H Φₚ/(2n)`，其中 H=J⁺/W。

正左系数要求η<2n/(2n+1)，例如η=1/4。内部接收量和共同势缺陷仍未付：距离矩可以很小，而内部接收量仍等于全部J⁺；父尺度权重破坏了所需的来源势抵消。对固定原载体重新赋来源质量只给价格恒等式，不构成合法的目标迁移。完整外包体积及原半核心费用仍保留。

整簇近邻父的共同新增来源量也有近壳界，但尚无覆盖全族的根阶费用。因此不继续仅靠增大p或局部分组声称推进一般上界。
