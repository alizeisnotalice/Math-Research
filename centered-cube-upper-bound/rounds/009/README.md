# 第9轮：降阈值有限样本保值与质量分辨率（2026-10-07）

项目centered-cube-upper-bound；一般sqrt(n)n^{o(1)}上界未闭合，一般保留界仍为O(n log n)。

对任意有限正Borel源、固定有限尺度窗口及独立完整源分量抽样，本轮证明降低阈值后弱费用的乘性保值。若分量质量至多s，失败概率至多exp(−ε²λa^n/(2s))。固定原超阈见证后用单侧mgf，再按Lebesgue测度积分，不作尺度或观察点并集。iid N样本取s=W/N，得到显式N>=2ζ ε^{−2}log(1/δ)，ζ=W/(λa^n)。这是旧经验归约的有限N定量补充，不是新的维数上界。

一般Borel输入与重复样本均保留；合并同位置后最大物理原子质量可能大于W/N。固定一维的完整源压力又证明固定比例保值仍可要求N=Ω(ζ)，不能把该参数藏进仅依赖维数的常数。它与旧负经验噪声障碍一致；后续需要真正的空间局部化和终端预算。
