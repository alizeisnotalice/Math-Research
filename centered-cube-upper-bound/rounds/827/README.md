# 第827轮　全尺度共同捕获与原中父接收体积

沿11月23日指导第6节第三步，估计同一批真实来源能在多大体积上被共同接收。取原见证方体 $Q_x$、割内来源 $\nu$、真密度 $g_x=\nu(Q_x)/|Q_x|$、总量 $S_A=\|\nu\|$ 与阈值 $\lambda$。近期目标是一般单窗 $B_n=o(n)$，最终目标是一般全尺度 $C_n\le K\sqrt n$。

## 已证结果

1. 在整个割上，将每对来源的权除以两端累计接收量的较大值，得到一份在全部绝对尺度上共用、两边际均不超过原来源 $\nu$ 的配对测度。若一条记录的两枚真源在较小或相等尺度上共同回入原接收盒的归一份额至少为 $\theta>0$，这些记录的原割积分总和至多 $C_\theta\sqrt n\log(n+2)\lambda S_A$。任意尺度顺序也有同阶估计，须保留两个接收盒真实来源质量的比值折扣。大割因此必须有正比例原流，第二枚真源能逃出指数多个与第一枚真源相遇的较早见证盒。
2. 对每个原见证抽取 $k$ 枚真实来源。固定它们的各坐标跨度后，在每个接收格内取最后一个合格的**实际边长**，再用坐标交长的乘积估计体积。若至少 $\lfloor\sqrt n\rfloor$ 个轴的跨度距见证边长至多 $1/n$ 倍，且 $k-1\le\lfloor\sqrt n\rfloor\log\log(n+2)/(8\log(n+2))$，这部分元组的全尺度原割费为 $O(\lambda S_A)$。报告给出任意 $k$、门宽和截断阈值的费用。
3. 在第813轮原双臂上，保留原历史、完整度、两端真实质量分母及两个实际接收者，再从同一中父抽 $k-2$ 枚真源。若有 $m\ge32k$ 个坐标的相对宽度缺口至多 $m/[64(k-1)n]$，原正子流的费用至多 $C(\mathcal H/L)e^{-m}\min\{(n+2)^3\log(n+2) S_*,(n+2)^2Y\}$。这里的边长含中父实际所有者产生的因子 $1+1/(32n)$。固定两枚原价后，原有 $1/D$ 档费用与新增真源的接收折扣在同一积分中相乘。精确原式、量词与总账见包内 **REPORT.tex**。

## 实际核验与剩余问题

- 对两份第814轮样本，各用34条原记录、230个正双价单元复核固定配对。去除实际双臂接触限制时能达到归一亮度一的最优配对，加入两臂后在两份样本上有效质量都严格等于零。在同一批样本上构造另一份符合两种容量的固定配对，其实际可付份额约为 $1.633\times10^{-21}$、$9.108\times10^{-22}$。
- 四组正宽样本的87个接收胞次、5779个共同项经过两种有理枚举。另对2448项四维原记录积分，以及有理数与两种区间精度下的真实接收胞、实际尺度和端点乘积作独立检验。
- 本机12个进程完成张量扩大检验。11个维数、132组参数、4488条条件几何显示了中维趋势的反转。重建样、三枚来源、$1/n$ 缺口下，至少 $\lfloor\sqrt n\rfloor$ 个轴近乎撑满的概率在8192维大于 $0.99991$，在131072维至多 $2.027\times10^{-9}$。报告给出了有界一维边缘密度下的解析上界，并明确标注高维张量的来源律、同一边长和沿用的四维行权重。

同一右端在多位中父处与不同左端相遇、两枚来源共同回入少、多个实际探针又没有形成足够跨度的原接收体积仍未受控。双侧薄壳遗漏的短驻留集及随机平移厚化的补集仍在账内。一般 $B_n=o(n)$ 和一般硬方体的全尺度根阶上界尚未证明。
