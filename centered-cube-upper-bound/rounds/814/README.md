# 第814轮　同一右端来源的跨中父累计覆盖与双接收预算

给定一个真实右端来源 \(q\)，本轮把不同左源及不同中父的接触要求放入同一个分数覆盖。固定物理半径八度 \(O=[R,2R)\)，记 \(C_{tu}=G_t\cap G_u\cap\{\|Z-q\|_1>b_0R\}\)。公共测度须在每个 \(C_{tu}\) 上提供至少 \(\mu(C_{tu})/m_t\)。其最小总质量记为 \(K_{O,q}\)。原子流的右端边际满足

\[
 \frac{d\Gamma_\mathcal B^q}{d\mu}(q)
 \le C\frac{\mathcal H N}{L}(1+n/b_0)e^{-b_0/16}
       \sum_O F_O(q)K_{O,q},\qquad
 \sum_O\int F_O(q)\,d\mu(q)\le C V .
\]

由此，容量不超过 \(e^{b_0/32}\) 的父对表在全部尺度上共费 \(o(V)\)。另有一份带八度标记的真源分配，可同时控制两个勒贝格接收边际。其公开权取共同接收负载的倒数时，联合得分达到 \(\mathcal H/(NL)\) 的原记录总量至多 \(CNS\)。两式均作用于第813轮原双臂子流，保留完整度、臂历史及实际交源分母。

四维同一批跨档记录在倍率 512、梳齿半宽 \(1/2048\) 的诊断中，逐对独立、共享右端、再共享两处实际接收容量，三者可支付的原单臂质量比例约为 0.999922、0.999872、0.003780。半宽改为 \(1/1024\) 后依次为 0.999937、0.999902、0.032132。以上用真实来源胞质量定价，有理可行解及对偶约束另行复核。有限样本没有实现理论中的高维筛选条件。

尚缺对同时具有高覆盖容量、低联合评分和分散接收位置的原流给出统一预算。旧宽距、低占比、初始、跳跃、删除费用及短驻留接收者保留在总账中。一般弱型上界仍待证明。
