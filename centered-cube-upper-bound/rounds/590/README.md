# 第590轮：共同空间删源与相关半核心并集总账

日期：2026-10-24。一般中心轴平行方体极大算子的 `n^(1/2+o(1))` 一致弱型上界仍未证明。本轮保留完整来源和真实接收并集，核验了共同空间删源分支及同一来源二分的碰撞约束；没有得到剩余并集的根阶预算。

## 经过核验的结果

- 一个固定来源网格可对全部父、全部带内尺度同时剔除重来源单元，总代价至多 `eW/δ`，`δ=min(1/4,n^(-1/2))`。剩余父盒相交的每个**完整来源网格单元**质量均小于 `δM`。按原来源只收费一次，不使用密度帽，也不受重合标签拆分影响。
- 使用宽对象 `H_A⁺`：保留集合 A 后，其中包含的全部原合法半核心均可用，不强迫 `K=S∩A`。同一共同随机输入满足 `E λ|H_A⁺|≤4Bₙ E m_A`；公平来源费用是半份，但尚无与之匹配的完整接收增益。
- 同一二分 A、Aᶜ 的两侧若在完整带及 top 外碰撞，其实际捕获总质量必须小于较大父质量。以两倍超半质量记盈余，则 `s_A+s_Aᶜ<M−m`。严格多数进一步迫使父质量分离，但引入漏收；同一侧跨父重复和全部漏收尚未支付。
- 固定细网格、随机嵌套分组、选择一个共同层级的相关保留规则合法；粗层只同比抽取已有覆盖，细层可能难以同时删除分散的尾部来源。中间层的完整事件并集增益仍未证明。未把这一失败解释为所有相关保留机制都不可能。

空间删除 `G` 和原逐标签删除 `Zε` 是两种不同分支，不可互换其剩余集。共同空间删除只是已付分支，不能将其当作整个上界闭合。

`γₙ J₁ ≤ E λ|H_A⁺| + D₁,ₙW`，且 `E m_A≤κₙW`。

`Bₙ ≤ (2√n+5+e/δ+D₁,ₙ/γₙ)/(1−4κₙ/γₙ)`。
