# 第738轮　不重复的真实接收点配对与整体删除费用

直接从第706轮原高损失积分出发。短半径比的同源接收点组成互不重用的四元组，其余半径比组成互不重用的点对。每个来源只使用自己的真实接收点。配对后的加权到达测度等于出发测度，均由原勒贝格接收测度控制。

逐轮删除低接收权重点及低接收体积的来源类型，连同其所有伙伴一并结算。所有轮合计至多支付 \(V_T/16+O(\sqrt n)D\)。剩余每个接收点的来源权重至少为 \(1/64\)，每个非空来源类型的实际接收体积至少为 \(\sqrt n\,d_i\)，所有伙伴同时保留。这个剩余集合的总权重仍待控制。

本机与 MacBook 核对了成组及多轮删除费用；在三个维数、两个半径比上另构造了四个真实正体积接收核心，核算了原积分、接收体积和来源预算。[证明、脚本与输出](research.zip)
