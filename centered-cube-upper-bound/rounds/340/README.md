# 第340轮：随机格局部化与来源增长补集

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 继续主攻 B_H，以完整总账限制闭合判断。

使用同一个平移网格，L=nb/δ，M_L(u)=∫Q_(2L)(u)f。原外侧交通中 m_u≥ηM_L(u) 的端点满足

`G_good ≤ δXq(good)+[1+log(λ/(ηq_-))]W`。

不跨格端点由真实源格质量窗支付；跨格事件概率≤δ，原交通密度≤q_u。保持原J、来源和全部时钟门，直接对划分恒等式平均。取η=exp(-√n)、δ=ε，得

`B_H ≤ G_growthbad+3εXq+[C_(ε,n)+1+√n+log(4/3)]W`。

这替换339的重来源支付；新good包含旧全局heavy，不重复计费。G_growthbad保留原积分的全部门及 m_u<ηM_L(u)，尚未一般支付。入口及外乘后以ε=119/3072分配1/4 X；与同一账本旧CZ项合计65/256，不表示其他未付分支已吸收。软层、极端尺度、初始、删除与未来被删时间项独立保留。

本机实际验证：数值脚本19665项精确检查与81条普通浮点费用诊断；核心脚本457项有理检查（含真实连续接收跨格积分）；几何脚本250项精确检查。有限标签实验交通用K=1、α=1且无高过去门，不能认证原根阶剩余项。核心一维例仅检验构造与集合严格扩张，不计算G_out。独审意见及哈希见包内audit.md。
