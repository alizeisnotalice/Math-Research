# 第726轮　反复共同接收的来源能占多少权重

开题核对[第706轮指令](../../AGENTS.md)。固定一个真实来源，按原高损失积分在其各接收行上的质量抽取见证。若这些见证的逐坐标包围盒增长缓慢，可以进入的真实接收体积很小。若包围盒增长到给定阈值，同时覆盖所抽见证的来源所有者只能落在一个小交集里。两步使用同一个包围盒，允许位移分散在全部坐标。

设深度为 $u$，即来源与接收父方体的对数体积比扣除固定扩张后所在的二进档下端。在有足够真实接收质量的档内，凡共同接收比例至少为 $\exp[-u^2/(32768n)]$、体积至多为固定来源两倍的来源，其总贪心权重至多为 $\exp(-u/7)$。对较大的来源还可交换两端，以实际半径比计费。按原权重求和后，整列轻载、单档轻载和反复共同接收的部分均有统一费用。

未付部分要求两端均超预算，同一大来源要与许多个别共同接收比例很低的小来源分摊质量。现有估计尚不能控制这些稀少关联的一阶总和，一般根阶上界仍待证明。
