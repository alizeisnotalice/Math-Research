# 第810轮　两端真实接收记录的共同中父与联合截面预算

在第809轮余量的每条原记录上，保留中央历史 \(v\) 及全度 \(d_v\)。两条小臂 \(X=(i_u,z,U)\)、\(X'=(i_g,q,W)\) 各含自己的父历史、真实来源和实际勒贝格接收点。本轮给出两种可以在全部中父、全部物理八度上合计的付款。新增总费用为 \(O(LV)\)，其中 \(L=\sqrt n\log^3(n+2)\)，\(V\) 为不交接收所有者的总体积。[详细 LaTeX、数值检验笔记与复现程序](research.zip)

1. 给定中央历史和一端，分别计算另一端仍可通过联合条件的真实臂总权。将这两个截面与两端各自允许的中央历史总权相乘，四项乘积的平方根至多为 \(Ld_v/\mathcal H\) 时，对应原质量可同时支付。这里 \(\mathcal H=O(1+\sqrt n/\log^2(n+2))\)。即使两小父各自跨越全部体积档，也能保留它们在同一中央历史下的档间约束。
2. 交换积分次序，直接合计两个完整端点共用的中央历史。记 \(T_k(X,X')\) 为在同一中父体积档内对两臂同时合格的 \(dI(v)/m_t^2\) 积分。若 \(A_k(X), B_k(X')\) 是两个可达截面的真实端点质量，所有满足 \(T_k\sqrt{A_kB_k}\le Ld_v/((n+2)\mathcal H)\) 的原量可一次付清。用两端各自对中父档的实际预测概率，还可加强这个阈值。余量上的截面大小受到方体逐坐标交长的乘积约束。

**仍缺大截面的总量估计。** 多个不同端点可以反复使用同一批可达接收者。本轮尚未证明这些测试对每份一般输入覆盖固定比例。第772轮总账的原吸收系数仍为同一个 \(\delta_0<1\)，一般 \(n^{1/2+o(1)}\) 上界仍待证明。

## 本机计算

本机 Python 3.12.14 的有理算术和 384 位 Arb 复核三组连续多档方体模型及一组专门区分共父的模型。各项都使用真实的源质量、接收体积和完整度分母。

- 二、三、四维模型的跨档筛中，两侧各自最优的边际覆盖相乘，只提供一条真实跨档需求的一半。按联合截面计费，相比直接使用整条下降臂总质量，归一测试积分分别提高至原值的 2.2242、2.5441、2.4065 倍。
- 前三组中，真实共同中父权恰等于两端单点上界的较小者。增加三个同档中父分别处在左、中、右的模型后，共同核在 18.79845% 的跨档原质量上严格较小。固定同一诊断阈值 \(1/2\)，实际标记比例从 28.34% 提高到 47.14%。
- 独立坐标积分和 Möbius 反演得到相同的 9、24、98 个正源胞。实际五元律到保留四个相邻边际的比较律，前向相对熵在全臂时恰为零，跨档时恰为 \(\log 2\)。

这些模型使用诊断门，包含两端共用来源与跨尺度选择。高维原余量中的巨大体积比、长跳、硬交和原度下界是正文理论估计的假设。
