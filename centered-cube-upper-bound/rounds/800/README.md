# 第800轮　两枚真实交价的共同体积分配与邻域来源增长

本轮直接估计第799轮的整份剩余。对每个中父 \(t\)，把经同一真价 \(x\) 的全部实际小父记为一组 \(\omega\)。源类 \(X_{t,\omega}\) 的质量可以分配到同时属于这些小父和中父的体积区域 \(D_{t,\omega}\)。每个体积位置有容量 \(B_t\)，同一中父上各组竞争同一份容量。真实最小缺额为

\[
\delta_t(B_t)=\max_{\mathcal J}
 \left\{\sum_{\omega\in\mathcal J}\mu(X_{t,\omega})-
 B_t\left|\bigcup_{\omega\in\mathcal J}D_{t,\omega}\right|\right\}.
\]

**完整两臂估计。** 设 \(L=\sqrt n\log^3(n+2)\)、\(H=O(1+\sqrt n/\log^2(n+2))\)、\(m_t=\mu(A_t)=|A_t|\)、\(h_t=C_1(n+2)\delta_t(B_t)/m_t\)。\(j_t\) 是中父原历史质量，\(V\) 为真实接收总体积。对任意当前子流 \(\nu\)，在它自己的两条真腿上计算上述缺额，则

\[
 |\nu|\le C LV+CH\sum_t j_t\min\{h_t,h_t^2/L\}.
\]

原来余项中用的是中父内的整份高密度源质量。本轮换成了实际分配后留下的最小缺额。两条腿一条分配成功、一条未分配的交叉项也包括在内。令 \(a_t\) 为中父上所有实际小父的加权平均覆盖次数，权为 \(j_u/m_u\)。容量可取 \(B_t=(L/\sqrt H)\max(1,1/a_t)\)，全体中父的第一项合计仍为 \(CLV\)。存活中父必有 \(\delta_t(B_t)>Lm_t/(C_1(n+2)\sqrt H)\)。[完整推导与复现材料](research.zip)

**两枚真价的空间约束。** 在半径八度 \([R,2R)\) 上，取边长 \(R\log(n+2)/(16n)\) 的公共网格。两枚剩余真价都必须落在平均源密度超过任意预定多项式的胞内。对每个活胞 \(C\)，把实际相邻价胞的真参考质量合计，得到

\[
 \mu(Z\cap Y_O\cap Q(x_C,5R))>
 \frac{\exp(J/2+b_0/16-\ell/16)}{C_1(n+2)}
 \,\mu\big(C+[-JR/(2n),JR/(2n)]^n\big).
\]

这里 \(x_C\) 是胞中心，\(Z\cap Y_O\) 是第799轮同八度的高密度来源，\(\ell=\log(n+2)\)、\(J=\sqrt n\,\ell^8\)，\(b_0R\) 为两枚真价原有的最小一范数距离。证明按真实胞对先加完全部中父和体积档。两小父与中父的真实质量差给出 \(e^{-J}\) 折扣。两个胞及其最小轴盒周围的源质量共同进入分母。所有胞的删除费用用同一份小父参考质量合计。全尺度体积估计使用中心方体的强 \(L^p\) 定理。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

**数值与边界。** 本机 Python 3.12.14 用有理算术核对了最大流与全部子族割、原两臂积分及二维源盒的精确邻域费用。压力例的两个单类缺额均为零，合并后仍缺 \(1/5\)。允许按中父覆盖选容量后，这个缺额降至零。另一个更薄的真实交区在自选容量后仍缺 \(16385/65537\)。独立的两价模型中，保留整路径相关筛所得积分为 \(334811/776994816\)，误把筛后边际相乘会低估。二维扩大例的六胞余图与删费相加，精确恢复初始值 \(12196339/4195200\)。SymPy 检查了平方恒等式和分段导数，768 位 Arb 检查了八组维数的标量门。有限模型采用诊断阈值，未实现原高维近极值入口。

**总账与缺口。** 本轮从原流上实际扣除的部分合计至多 \(C(LV+(n+2)\ell^6S)\)，其中 \(S=\|f\|_1/\lambda_0\)。第772轮原峰的吸收系数保持。尚缺同时满足上述邻域增长的中父族上，\(\sum_t j_t\min(h_t,h_t^2/L)\) 乘回 \(H\) 后的全局上界。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。
