# 第728轮　许多稀少关联如何共用一份来源容量

开题复核[第706轮指令](../../AGENTS.md)。在第727轮剩余的一阶总和中，先把同一个有向来源对跨所有接收行的费用合并。每个较小来源可在自己的体积预算内选择一份共同测度，用它同时支付许多大来源。对两种预设的逐坐标分布，可以让每一对来源单独选择最有利的混合概率；各轴共用该概率时，所有选择的合计损失至多为两倍根号维数。证明给出精确的最坏因子，并处理了原交集任意薄的情形。

剩额可在两个真实所有者之间分配，每个标签的接收体积只用一次。报告给出了最优共同测度与这次分配的有限线性规划对偶。如果付款仍有缺口，必有一个来源子集，其内部关联总额超过这些标签的所有者容量。对任意一般输入给这个超额证明根阶预算，仍是未解决的问题。

本机与 MacBook 核验了平移交集和混合费用。九个真实贪心算例的原高损失均严格为正；其中三个例子里，单用两父方体原交集的体积乘根号维数仍不够，新的角点容量可以支付对应的共同接收量。这些接收行已有超远来源支付。
