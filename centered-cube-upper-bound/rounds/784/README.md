# 第784轮　用实际峰质量估计同一小端被不同中父重复使用的费用

第783轮把两条真实下降臂归到共同的体积子树与来源格 \(c=(O,B,P)\)。在格内，\(x_{cv}\) 是中父 \(v\) 从合格小端实际捕获的来源质量除以 \(m_v\)，\(d_v\) 是该中父原有的全部度。本轮使用该格真正承载的双臂峰质量

\[
 q_c=\int\frac{x_{cv}^2}{d_v}\,dI(v).
\]

**已支付的真实峰。** 先按照体积档和中心位置将物理中父分组。对每个共同格，已知一条臂的真实小端 \(u\) 和真实交价 \(y\) 后，可以预测至多 \(J=\lceil\log(n+2)\rceil\) 个中父组。只要任一端的名单命中，该峰的质量就能在全部格、全部中父上一起结算。这包括依据完整冻结输入选择的最优名单。证明保留同一小端的历史资格，利用不交的实际接收集控制各组容量。费用计入下式。另一项方体乘积估计支付了两次实际交价在各坐标上的跨度充分大的部分。

**剩余峰必须满足的条件。** 记 \(\ell=\log(n+2)\)、\(L=\sqrt n\,\ell^3\)、\(s=L\ell\)、\(\eta=\exp(-\lceil\sqrt n\,\ell^2\rceil/256)\)。每条剩余峰的两臂须同时满足 \(x_{cv}>L\) 和

\[
 q_c>\frac{\varepsilon^2\beta}{\eta}\exp\!\left(\frac{s+\gamma\max(H_y,H_z)}{2}\right)m_v x_{cv}^2 .
\]

这里 \(H_y,H_z\) 按原历史对两个真实交价处的来源重数计权。\(\varepsilon,\beta,\gamma\) 的对数依赖及总吸收份额见报告。旧门使用全格来源能量 \(Z_c\)，新门只使用实际双臂峰质量 \(q_c\)。筛后两价仍可相关。

**完整回代。** 记 \(V\) 为不交接收所有者的勒贝格总体积，\(S=\|f\|_1/\lambda\)。对固定 \(0<\delta<1/2\)，同一份原峰满足

\[
 (1-\delta)Q_{772}\le k|R_{784}|+
 C_\delta[\sqrt n\,\ell^8 V+n\ell S],\qquad k=O(\ell).
\]

仍缺 \(|R_{784}|\le C\sqrt n\,\ell^bV\) 或等价的统一收缩。特别是同一格可能有大量中父，其真实联合价律分散，而两端名单均未命中。一般上界仍未证明。

**本机复核。** 在六维精确例中，两中父的整个真实价分布相同，只看位置时最佳辨认率为 \(1/2\)，保留小端标签后为 \(1\)。另在 \(8,12,24\) 维从两个坐标方向安排中父，同一小端确有严格为正的远交叉项。两种求和给出同一有理数。复现包还给出十个窗与分组方案，以及原宽窗口下界模型的二十一个参数组合。有限模型使用诊断阈值。Python 3.12.14、python-flint 0.9.0，Arb 精度 256 位。[详细 LaTeX、精确输出与两份复现脚本](research.zip)
