# 第329轮：完整来源平方计算与共同来源变分接口

**一般 n^(1/2+o(1)) 上界仍未闭合。本轮没有新增一般根阶付款。**

本轮建立可复用的有限矩形场完整来源平方算法：保留全部接收交叉项，按实际来源盒积分。任意固定来源位置 y 均可处理，但全 beta 外积分、原场资格及任意场逼近不由算法自动保证。真实壳层测试已从点探针推进到完整 nu 二阶矩，维度至64。

冻结真实硬核接收场、保留同一个来源的局部均值约束后，原平方分解为正半定能量与两项非负余量，给出可实施的凹上界及弱对偶证书条件。独审通过其代数和适用范围；**达到根阶的对偶证书尚未构造**，不能把接口当作付款。

## 实际结果与决策

n=64 的中央来源行 BH约24.48775，初始化约0.79534，后续创新约23.69241；乘真实中央来源质量后仅约1.82638e−153。整个输入 W_beta=W_nu=4^64；全 beta 外积分未计算。这些有限结果不说明一般阶数或极值性，下一步必须联合真实来源质量和覆盖平方，而非仅估逐行费用。
