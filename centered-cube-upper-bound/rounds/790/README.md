# 第790轮　跨中父的来源覆盖与两步重用

从第789轮的同一原峰出发，固定一端的真实价点后，已能把所有中父对另一端小父的费用一起计算。多个小父在同一片来源上达到覆盖配额时，该片来源的预测成本只付一次。一般 \(n^{1/2+o(1)}\) 弱型上界仍待证明。[详细 LaTeX、精确证书与复现脚本](research.zip)

## 已经能在原峰上付款的部分

设 \(M_v=m_vd_v\)，其中 \(d_v\) 保留中父全部邻居。固定可见端 \(a\)、中父体积档 \(D\) 及隐藏小父体积档 \(G\)。对真实来源胞上预选的测试测度 \(\nu\)，报告式（4）证明

\[
 \int_{D,G} M_v\,\frac{\nu(A_g)}{m_g}\,dP_a
 \le C\eta\int \Omega_{a,D,G}(x)\,d\nu(x).
\]

这里 \(P_a\) 是原峰相对可见端基底的未归一条件测度。空间折扣 \(\Omega\) 是两个真实接收区域给出的一维允许比例之积。原来的两次交价仍以 \(\mu=|f|dx/\lambda\) 积分。各档的覆盖方案可以根据冻结输入优化，汇总两个方向、全部中父及两端体积档后，费用见式（5）。式（6）还直接支付一个无需优化的分支，即任一端附近按空间折扣计算的真实来源质量至多为 \(e^{r_0/512}M_v\)。

## 总账与剩余

恢复远价条件后，对两端分别固定原臂及全度档再重抽。第790轮式（10）证明，两跳后中父命中任一事前选定来源点的概率比任意固定的 \(n^{-p}\) 都小。反向转移给出另一份父质量分母。一条轨迹上，许多中父可以同时保有互不重合的真实来源。不同轨迹仍可能共用这些来源。

记 \(S=\|f\|_1/\lambda\)、\(\ell=\log(n+2)\)。所有实际删量合计满足

\[
 |R_{789}|-|R_{790}|\le C(\sqrt n\,\ell^5 V+nS).
\]

上游吸收系数沿用第789轮。尚缺 \(|R_{790}|\le C\sqrt n\,\ell^\gamma V\) 或同一实际余量的可求和收缩。全体可能位置未经原筛时，接收乘积核的总积分为 \((2(s+t))^n\)。将这份体积直接交还总账会产生指数费用。

## 已运行的验证

本机独立 Python 3.12.14 使用有理数和 256 位 Arb。在 \(n=4,8,16\) 的真实方体有限输入中，共有383个预测组。其中144组的最小共享测试成本严格低于真实来源并集质量，并集质量又严格低于逐父之和。各组配额均用可行覆盖和同值对偶核验。实际价格交通和逐轴乘积界还在81306个测试对上直接比较。

两步路径按中父及按实际来源胞计算的结果精确一致。四维例用起父及末父分母的重合均值分别为 \(0.801802\) 和 \(0.786215\)。两种分母在原积分中不能互换。有限组使用诊断门，渐近结论依赖报告中的证明。
