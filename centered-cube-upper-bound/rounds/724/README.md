# 第724轮　坐标排序误差与两个站点的共同来源

开题复核[第706轮指令](../../AGENTS.md)。对每个真实接收点对，将见证之间的有符号坐标差与实际接收坐标差分别排序，取对应位置的平均距离。即使原坐标逐一比较差异很大，这个距离仍可能很小。本轮用指数衰减的三角核控制了采用该误差后的完整跨组账目。

对尚未支付的共同来源，在两个见证所确定的方体交集中逐轴归一化其父方体中心。当排序误差为 E 时，归一化坐标的经验分布与均匀分布的距离至多为常数倍的 E^(1/3)+√(log(n+2)/n)。证明先按真实所有者的体积控制罕见配置占全部交叉费用的比例，再将这笔费用转回超预算来源。极薄的交集坐标单独处理。对于大误差，另用两端接收点的实际越界坐标计数支付一部分贡献。一般剩余交叉项能否合计控制在 O(nD)，仍待证明。

本机与 MacBook 核验了条件计数和核包络。另用本机 Arb 验证一族真实首次越阈历史，在 1024 维时逐坐标平均误差大于 0.17，排序误差小于 0.000008。这族接收点已由之前的超远来源估计支付。[详细证明与复现材料](research.zip)
