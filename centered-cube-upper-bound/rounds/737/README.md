# 第737轮　共同来源的四个接收点与较小来源的跨角权重

固定第706轮的同一个最小化见证。对接收半径与来源半径之比至多为 \(n^{-1/2}\) 的高损失边，将实际接收点按来源方体的周期分组。只支付 \(O(\sqrt n)D\)，即可保证每条剩余边都有两个坐标，在同一周期相位上实现四种真实接收组合。

在原行选定的另一较小来源若覆盖了四个见证中的两个，其中心在某个指定坐标上受到窄区间约束。全部这些较小来源的合计权重为 \(O(n^{-1/2})\)。报告将该估计回代到同一真实积分，保留较大半径比和至多覆盖一个角点见证的来源对。一般上界仍待证明。
