# 第799轮　同一真实交价上多条原记录的方体交与共同费用

第798轮留下了多个大父、小父反复使用同一批来源的问题。本轮将经过同一旧交价的所有原记录合在一起。证明了一个同时覆盖所有整数 \(k\ge2\) 的估计，并把两枚真实旧价都限制到平均来源密度超多项式的物理区域。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX 和复现材料](research.zip)

**同一价上的多个方体交。** 给定一个真实旧交价 \(x\)，从经过它的记录中按实际条件概率独立抽取 \(k\) 条。每次抽取都保留原来的大父、小父配对。对各自一侧的 \(k\) 个父，检验它们共同使用的真实来源质量与方体交的勒贝格体积之比，可以在整个空间或同一个来源盒中检验。另允许该侧的绝对体积档足够接近。记 \(p_k(x)\) 为两侧同时通过的概率。若 \(\ell=\log(n+2)\)，\(\mu=|f|\,dx/\lambda_0\)，\(\lambda(x)\,d\mu(x)\) 是两条臂合计的真实旧价边际，则

\[
\ell^2\sum_{k\ge2}\int\lambda(x)p_k(x)^{1/k}\,d\mu(x)
   \le C\big(\sqrt n\,V+nS\big).
\]

这里 \(V\) 为原接收总体积，\(S=\|f\|_1/\lambda_0\)。第 \(k\) 项在全空间容许的质量与体积之比为 \(W_{k,n}=c_k n^{(k-2)/4}\)，其中 \(c_k>0\) 只依 \(k\) 和原有绝对常数。各 \(c_k\) 已选到使总费用可求和。任给一个固定的多项式次数，都能用一个固定 \(k\) 达到。证明用中心立方体的强 \(L^{k/(k-1)}\) 界控制全部物理父，再对真实来源积分。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

**最终剩余必须同时满足的条件。** 逐次按原余流重算条件概率，只删掉实际碰到被删旧价的记录。最终在每个存活旧价上，所有 \(k\) 同时满足 \(p_k(x)\le\ell^{-2k}\)。所以在同一价上重新抽取记录时，高概率至少有一侧的多个父跨越较远的体积档，而且在全空间和本来源盒内都共同使用了相对交体积过多的真来源。

另令 \(W_n^*=\max_k W_{k,n}\)，则对任意固定 \(b>0\)，\(W_n^*/n^b\to\infty\)。两枚旧价现在都须落在集合 \(Z\) 中，其原函数密度、所在物理父成员胞的平均密度，以及所在整档父对重叠量的平均密度均超过 \(W_n^*\)。后两种平均都用源质量除以真实勒贝格体积。若 \(\zeta_t=\mu(G_t\cap Z)/m_t\) 是中父原来源在该集合内的份额，则

\[
 |R_{799}|\le CH\sum_t j_t\min\left\{C_2(n+2)\zeta_t,\
 \frac{[C_2(n+2)\zeta_t]^2}{L}\right\}
 \le CH(n+2)^2\ell\,\mu(Z).
\]

其中 \(L=\sqrt n\,\ell^3\)，\(H=O(1+\sqrt n/\ell^2)\)，\(j_t\) 为该物理父的原首臂质量。推导保留了两条原臂及原度分母。本轮实付 \(R_{798}-R_{799}\) 至多 \(C(LV+(n+2)\ell^6 S)\)。第772轮原峰的吸收系数和余项系数均保持。尚缺对高密度区域上多个父同时重复取价的总量控制。小勒贝格体积只能控制 \(|Z|\)，不能据此估计 \(\mu(Z)\)。

**本机验证。** 独立 Python 3.12.14 用有理数分别按原路径和联合父集合复算 \(k=2,4,6\)。初版把可付比值的不等号写反，已纠正为 \(\le\)，三阶段均已重跑。压力例同一真价胞上，双侧可付概率为 \(1537/3721\)，两侧边际相乘为 \(5710777/13845841\)。在独立的几何分层例中，一个平均密度为 \(16\) 的狭小父交所在整档平均只有 \(32/33\)，该档全部付清。扩大例中另一个平均为 \(56/3\) 的档确实留下正原量。另以 \(2,4,8\) 维实际方体检验同一个旧价用两个体积位置支付的费用，并用 SymPy 核对维数指数。有限计算使用诊断参数，一般估计见证明。
