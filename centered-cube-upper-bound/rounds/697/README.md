# 第697轮　共同方向分配与尺度分离费用

第697轮证明了每个来源只抽取一次方向时，所有真实接收区域合计的截断支付量可保留固定比例。对尺度充分分离的首次捕获来源，给出了逐来源根阶费用的显式分配。中间尺度上的共同方向分配仍未闭合。

双机对2160个一维输入核验五平移菜单的可行下界和严格对偶上界，270例追加加密计算。详见包内 REPORT.tex、NUMERIC.md、AUDIT.md 和 verify.py。一般维数的证明缺口见 REPORT.tex。
