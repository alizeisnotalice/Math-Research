# 第357轮：高面数交通的全组合几何预算

保留第356轮真实方向分散余流。按终端来源和接收点计算接近坐标面的数量，完整计入所有坐标组合后，实际接收容量由底部Bin(n,t)尾与径向壳层1+Bin(n−1,t)尾给出；这里是勒贝格体积计算，不假设实际路径独立。

以m=1+ceil(8log(n+2))为阈值，先支付高面交通占比>=1/4的整个来源，再支付其他来源上的高面tuple。联合只收费一次，新增来源费4N C_m W<=4sqrt(n)W，无新增接收吸收系数。

余流每个终端tuple只接近1到m−1个面；逐来源坐标占比界相应变为4/[3log(n+2)]，未无损沿用旧归一化。该余流仍未支付，原捕获平方回接也未完成。完整历史未付槽保留，一般上界未闭合。
