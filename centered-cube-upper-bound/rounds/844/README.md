# 第844轮　跨尺度接收记录能共同使用的真实来源份额

固定第843轮同一原流和严格见证。给定一条原记录，保留接收位置和对端，考察本来可以替换另一端的整份实际来源质量。新见证从同一被保留来源上重抽。[详细 LaTeX、程序与精确输出](research.zip)

## 多个接收者共用同一来源

令 $N=n+2$，$H=\sqrt n\log N$。合计支付 $O(H)\|\eta\|$ 的原记录后，固定其余任一典型原记录，在一端独立抽取 $\lceil\sqrt n\rceil$ 条真实记录。以至少 $1-2e^{-H}$ 的条件概率，能进入其中至少半数见证的可替换来源，只占首件原来源池的至多 $e^{-H}$。这里的分母是固定同一接收位置和原对端后的真实质量。两端均可这样结算。

抽取 $8n$ 条记录时，至少被半数见证包含的所有位置，以至少 $1-N^{-6}$ 的概率同时落在距离原来源 $32\log N$ 的 $\ell^1$ 球中。任一组方体的交集由其中至多 $2n$ 件确定。这使得证明可以先固定一个最远顶点，再对其余真实接收者计费。

## 可用来源变少后，原质量去了哪里

给定全部接收位置和对端后，按正确的条件分布换用另一枚来源。这个交换保持每条原记录的边际。其密度包含原来源总载荷的 $1-m$ 次幂。

将换入来源按步长 $1/n$ 量化，比较给定当前记录的预测与仅给定其接收位置和对端的预测。设 $M$ 为终端原质量，$S=\|\eta\|$，$\mathcal I$ 为按完整原质量加权的条件互信息。本轮证明

\[
 M\le C\sqrt n\log(n+2)S+C\sqrt{S\mathcal I}.
\]

在双端大来源池里，对数似然比至多 $h$ 的交换记录至多花费 $C(\sqrt n\log(n+2)+h)S$。证明使用约 $e^h$ 枚事前可抽的参考点，价格只依赖名单长度的对数。其余高信息原质量尚未得到统一预算。

对真实输入增加 $k$ 个均匀坐标给出一个尺度检验。若 $k$ 与 $n$ 同阶且最终有至少一半的真实终端质量落在内部，量化总信息至少为常数乘 $Mn\log n$。所以直接假设 $\mathcal I\lesssim n\log^A(n+2)S$，会要求这类终端的质量低到对数阶。增加坐标后筛选可能清空终端，因而该检验有明确前提。一般单窗次线性与全尺度根阶上界仍未证明。

## 本机精确检验

- 四个二维正面积接收核心上，逐个核验 $m=1,2,3$ 的 8、64、512 个正观测。换锚前后各槽及两端边际完全一致。$m=2$ 省掉 $1/r$ 后总变差为 $31556779674/257618939525$。
- 给定对端与原体积档后，三组条件互信息约为 0.0594662、0.2720862、0.4088154 nats。程序用有理级数及余项给出严格区间，另核验一位码、常数码和三档名单长度。
- 三组正宽配置的 26 个子族核验了决定交盒的端面、并列和补齐后的同一顶点。另在维数 1、4、16、128、1024 精确复算两个概率上界。
- 在均匀坐标的直积检验中，四维例的外层费用系数为 $319/1280<1/4$。取 4096、8192 个均匀坐标时，整数算术给出独立预测命中概率分别小于 $2^{-3061}$、$2^{-13499}$。这是对体积界的核验。
