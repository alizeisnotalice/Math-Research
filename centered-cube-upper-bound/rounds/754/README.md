# 第754轮　同一来源点上多个接收者的共同覆盖费用

固定一个小父方体和其中的实际来源点 \(z\)。在第753轮的原保留关联中，按真实权抽取两个都与 \(z\) 关联的大父标签 \(e,d\)。记 \(I_e\) 为小父与标签 \(e\) 的交区。从 \(I_d\) 均匀取点后仍落入 \(I_e\) 的概率精确等于

\[
 J_{ed}=\frac{|I_e\cap I_d|}{|I_d|}.
\]

用当时的实际共享比例 \(p_d\) 和体积比例 \(q_d=|I_d|/|A_s|\)，给候选 \(d\) 保留系数 \(\min(1,n^B q_d/p_d)\)。每个候选都接受同一点上**全部目标的真实权**检验。对固定 \(B,b\ge0\) 和 \(0<\eta<1/2\)，即使在 \(\lceil n^b\rceil\) 个实际候选中取覆盖份额最大者，命中的原接收量合计也至多 \(C_{B,b,\eta,K}n^\eta M\)。\(M\) 是来源总质量。因而凡期望能命中至少 \(n^{-1/2+\eta}\) 份额的来源点，**其全部原接收量**都能在 \(O_{B,b,\eta,K}(\sqrt n\,M)\) 内支付。

证明先用真实所有者不交及 Bourgain 的方体强型定理，估计全部来源合并后的输出。重复筛除时，每个价点只删一次，但一条边的条件分母仍可随别的价点退出而变小。正文式 (8) 对下降的实际质量积分，保留了这一项费用。来源允许分成任意有限个可测块，每一块的权重和共享比例均按其真实质量重算。另一项整组估计使用同一小父上的一个共同乘积密度，计算接收交区偏向同一方向时能支付的原流量。[Bourgain 原文](https://arxiv.org/pdf/1212.2661)

**未付量。** 两个新估计与第752、753轮共用一个有限筛除过程，新增接收吸收系数为零。对最终每个有正流量的实际来源点，有效覆盖得分达到 \(2n^{-1/2+\eta}\) 的邻居所占真实权至多 \((\log 2)/\lceil n^b\rceil\)。当真实来源比交区体积高度集中，或不同接收者只在很小的部分相交时，剩余来源点仍可承担较大总流量。一般 \(n^{1/2+o(1)}\) 弱型上界尚未证明。

**本机实际核验。** 在五维方体的81个正体积胞元上，用有理数在两种来源次序中分别核对了原积分与换序结果。两种交叠概率分别是 \(1\) 和 \(256/625\)，调换目标和候选会改变费用。另验三维至256维的共同倾斜，候选择优至128个，以及799项二进分层。48次分母减半的算例实际产生 \(25A\) 的累计费用。计算结果和256位 Arb 记录已重跑逐字节核同。
