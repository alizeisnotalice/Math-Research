# 第575轮：无共同标签的分位整族付款与森林桥边界

日期：2026-10-24。一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮证明整族几何付款并纠正全局连接策略，没有证明完整残余预算。

## 新的正向整族估计

沿第574轮，全部接收区域精确表示为实际来源子集的盒 C_S，已付高半质量核覆盖 H₂ 的费用≤2√n W。

固定真实残余参考 S₀，质量 m₀。每坐标取严格累计超过 m₀/(4n) 的两侧分位点，得到实际半质量核 K。任何质量≤m₀、从 S₀ 遗漏质量≤m₀/(4n) 的见证 S，其来源包围盒都包含 K 的包围盒；因此整个族的 C_S 可用一个载体覆盖，费用至多

    (1/√n + 1/n) m₀。

这些见证的实际共同来源标签可以为空。证明保留真实质量、原子并列、所有坐标和全部尺度；没有假设来源独立或使用边界密度帽。一般 M≥m₀ 时，费用为 bM+2(M−m₀)/n+4εm₀，必须保留 M≤2m_K。

## 改变下一步选择的严格边界

对每个 n≥2，取单位质量格点输入 {−a,0,a}^n，a=2−1/(n2^n)。全部非空接收盒可解析穷尽为单点盒及2^n个角块盒，角块盒在 H₂ 外且有唯一实际见证。

若强制用同阈值、原来源不复制森林的原节点盒覆盖，并按统一真实根质量收费，最小加权根费为4^n，相对 W=3^n 的重复是(4/3)^n。因此这一特定森林连接不能有统一亚幂重复费。

这不是一般上界的反例：同一残余可被中心单原子在阈值2^(−n)下的盒覆盖，计入真实阈值比后只费2^n≤W；精确残余体积更是2^(n−n²)/n^n。变阈值、实际接收体积加权和其他几何载体仍须保留。

## 完整缺口与总账

尚未构造同一全局选择，将所有真实残余覆盖为分位族、共享来源星或其他可付载体，并控制累计费用。仅来源质量距离的贪心分离不证明参考质量总和可控。

若分位组的共同权重确能满足 Σw_g m_g≤C n log^A(n+2)W，就足以给残余 C(√n+1)log^A(n+2)W；这个全局预算仍未证明。星组还必须按其最大见证质量付费，不能只付锚点质量。

全尺度残余预算 D_n W 将恢复一般常数2√n+D_n；仅完整单质量带预算则恢复16e+(4/3)N_n(2√n+D_n)，N_n=2+ceil(log₂(32n²))。这些条件账及旧Φ/Ψ吸收账均经逐式核对，仍保持未付，不能把新整族估计当作一般闭合。
