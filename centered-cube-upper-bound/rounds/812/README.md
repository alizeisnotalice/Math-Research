# 第812轮　两枚真价的共同供给方体与跨中父的联合命中估计

本轮证明了一个作用于第811轮原余量的全尺度估计。设 \(N=n+2\)、\(L=\sqrt n\log^3 N\)，\(V\) 是真实不交接收所有者的总体积。固定 \(0<\varepsilon<1/2\) 和 \(b\ge0\)。在每枚原交价上，用经过该价的校准方体把来源质量分配到真实勒贝格体积。允许两端读取同一对价格并选择联合分配，每侧可相对这一分布加权至 \(N^b\) 倍。**联合命中真实两端旧父的最优条件概率达到 \(N^{-1/2+\varepsilon}\) 的整批原记录，质量至多 \(C_{\varepsilon,b}LV\)。** 常数独立于维数、中父数、半径数和输入。[详细 LaTeX、数值笔记及复现证书](research.zip)

**为什么能跨中父求和。** 两端的真实价格参考边际均受 \(C(n+2)\log(n+2)\,\mu\) 控制。将经过同一片来源的质量摊回各自的校准方体后，一组空间可行装填同时限制所有中父的输出密度。结合输出总质量和立方体极大算子的固定高阶矩，可将多项式密度因子减到足以支付上述门槛。真实联合旧父权、原全度分母、两处交价及真实接收探针均保留。[Bourgain 的立方体强型定理](https://arxiv.org/abs/1212.2661)

**余下记录的几何。** 在同一份近极值来源上，辅助装填可以覆盖至少 \(1-N^{-7}\) 的来源总质量，并与正式首穿越族同时使用。付掉已列的门以后，两处价格各自至少有 \(1/2\) 的供给权处在半径区间 \(R/(4n)<s<32nR/\log(n+2)\)，其中 \([R,2R)\) 是该记录三只正式父方体所属的半径区间。每条余下记录至少有一端，至少有 \(1/4\) 的真实供给权来自与该端扩大的实际旧父薄交的方体。各交集占相应供给方体的勒贝格体积比例小于 \(2N^{-1/4+\varepsilon/2}\)。仍需控制众多中父反复使用这些薄交集时的原来源总量。一般 \(n^{1/2+o(1)}\) 上界和纯根阶均未证明。

**本机核验。** 独立 Python 3.12.14 对二维、三维、四维连续梳状来源作有理复算。四维跨档模型有 140 组由中父与两处交价所属胞确定的记录。在这份原量上，同一供应父的全局分配支付原质量的 \(8.38358\%\)。允许不同供应父共用同一行列容量后，实际可付比例为 \(19.63057\%\)。该方案在所有行上的分配权之和至多 \(0.82742\)，可直接计入原质量。另一项容量紧缺试验中，允许只保留部分旧父对，使最优原比例从 \(0.384243790838\) 增至 \(0.384267132212\)。四组软分配试验的有理原对偶间隙均为零。192 位和 384 位 Arb 另核验了 18 组高维标量。这些实验的参数与理论中使用的充分大维数条件分别记录。

**完整回代。** 本轮计入的总费用为 \(O_{\varepsilon,b}(LV+\mathcal H N^{-5}\log(N)S)\)，其中 \(S=\|f\|_1/\lambda_0\)，\(\mathcal H=O(1+\sqrt n/\log^2N)\)。原吸收系数仍是 \(\delta_0<1\)。若能对剩余原积分给出 \(O(\sqrt n\log^\alpha(N)V+n\log^\beta(N)S)\)，固定 \(\alpha,\beta\) 即足以得到一般带对数损失上界。
