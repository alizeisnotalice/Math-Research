# 第342轮：多源格完整分割与根阶局部增长覆盖

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮证明更大局部增长分支的真实接收量根阶预算。

令A为满足 `m_u≥exp(-√n) f(Q_((1+√n)b)(u))` 的原接收端点。新覆盖定理给出

`Xq(A) ≤ 2[1+3√n+log(8/3)]W`。

证明按实际来源y所在源格完整分割；每接收点可涉及多个格，但来源质量只记一次。小质量格费用由相交格数期望 `(1+R/L)^n` 支付，该数量只以对数进入大质量格的源窗口费用。取L=√n b/2得到根阶常数。这是实际Lebesgue接收量结论，不需要原高过去门。

因此该分支G_out≤Xq(A)全部按来源支付，局部化不再额外占用εXq；新槽为

`B_H ≤ G_bad^(342)+2εXq+{C_(ε,n)+2[1+3√n+log(8/3)]}W`。

原J、来源、时钟与全部交通门保留。已付集包含341已付集，新来源邻域从2nb缩至(1+√n)b；新bad仍未支付。入口外乘后的同槽接收费用由1/4降至1/6，和同一总账CZ合计131/768；剩余空间不是全局闭合证明。软层、尺度和历史时间项全部留账。辅助熵路线现有费用为O(n^(3/2))W，不计新增付款。

本机实际验证：8007项精确多格/来源检查，686项主构造检查；辅助242行上968项cut比较、242项完整熵恒等式、1452项gated恒等式和1452项far比较。均为有理或符号log2检查；有限step-source未实现全qband/原Gout，不冒充完整数值证明。独审通过，哈希与范围见audit.md。
