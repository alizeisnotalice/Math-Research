# 第688轮：精确跨组退款与净收益精度

一般任意 L1、全尺度、固定勒贝格背景的根阶上界仍未证明。本轮未获得新的无条件统一上界。

已核验的共同几何结构：对每个来源父，真实正体积相交的目标形成冲突图；目标之间零体积交为冲突。轴平行盒的严格 Helly 性给出，局部本质最大值等于目标总权减去最小加权顶点覆盖，因此退款可精确计算。

实际满来源池的体积熵进一步表明：针对原 q/tau 基准的比例删除，分数匹配的退款下界永远不足以认证正收益。这个限制不能推广到非比例删除或新基准。相同推导也给出真实全体接收量的预算 `V <= B exp(1-tau/c) U`；组数满足明确阈值时整个分支已付清，任意多组时仍须保留来源重用次数。

后续改用完整胞元约束下的选择性共同删除，不以常数近似的退款代替净收益，也不把一个新LP写法当成已支付预算。
