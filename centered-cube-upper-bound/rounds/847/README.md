# 第847轮　固定真实来源后的早期接收者与薄交盒

在第846轮仍未支付的原量 \(F\) 上，固定当前记录的一枚真实来源 \(w\)。只使用比当前见证严格早逾 \(\lceil\sqrt n\rceil\) 个二进体积档、也确实使用同一 \(w\) 的旧记录。记 \(S\) 为原来源割质量、\(D_k=2^k\) 为当前档上界，\(\ell=\log(n+2)\)。[完整证明、本机程序及输出](research.zip)

## 支付的原质量

除去至多 \(C\sqrt n\,\ell^{3/2}S\) 的原质量后，同一批当前记录满足以下三条。两端分别适用，共用同一冻结旧流和原见证。

1. 每枚当前来源在严格早期档的真实累计负荷至少为 \(\sqrt n\)。对整个当前见证，按各旧接收者实际交到当前见证的条件质量计算，有效旧接收质量之和至少为 \(e^{\ell^2}\lambda D_k\)。这些旧档互不相交，旧接收支撑的勒贝格体积至少为 \(e^{\ell^2}D_k/4\)。
2. 固定该枚真实来源，按其实际早期负荷再抽一次旧记录。除概率 \(e^{-9n/2048}\) 外，至少 \(\lfloor n/32\rfloor+1\) 个坐标上的两中心距离超过当前边长的 \(9/16\)。在每个这样的坐标上，两中心分居该来源两侧。新旧交盒的体积至多是旧方体体积的 \((7/16)^{\lfloor n/32\rfloor+1}\) 倍。
3. 在同一次早期重抽中，以至少 \(1-e^{-9n/2048}-\ell^{-1/2}\) 的概率，上项的薄交盒还保留很高的实际来源密度。正文给出的密度比 \(Q_R>\ell\) 同时计入两条记录各自的另一来源。特别有 \(\eta(A_x\cap A_y)>\lambda\ell\,|A_x\cap A_y|\)。两种端点角色可使用不同的旧记录。

前两项分别由原接收平方积分及固定 \(w\) 后的方体乘积核证明。第三项沿同一早期条件律使用 Bourgain 的无维数 \(L^2\) 强型。此次计费无需增加原账吸收系数。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

## 本机复算及剩余问题

- Python 3.12.14 的有理算术精确积分两组当前接收块和五个旧接收块，在2、4、32维检查完整的双接收分母。一个浓缩算例中，某个旧接收块仅占支撑体积的 \(1/513\)，却承载 \(128/129\) 的相应旧质量。
- 有理二项递推和192位 Arb 在2至4096维的六组参数上核验坐标门槛。4096维的实际正宽收者模型中，不超过128个坐标越门的条件概率约为 \(9.23\times10^{-28}\)。另检查了9216组原载荷首次越阈的组合。有限配置的计算范围和显示误差见正文。

当前缺口是**不同当前见证复用这些高密度薄交盒的总费用**。很大的旧接收体积可被多个当前见证同时使用；体积再薄也可以装入集中的实际来源。第813轮原积分的其他费用及全尺度终端继续保留。
