# 第861轮　按真实接收体积支付两个尺度端

设 \(R\) 为同一物理尺度窗的半径下端，\(w(Q_y)\) 为真实来源 \(y\) 所在停止块的最长边。在第813轮原双臂积分中，任一端满足下列条件的整批记录均可支付，包括另一端的全部原历史和实际接收位置。[详细 LaTeX 证明与三项本机复算](research.zip)

- 来源在高密度停止块以外，或 \(w(Q_y)\le c_b R\log(n+2)/n\)。
- \(w(Q_y)\ge \kappa nR/\log(n+2)\)。其中 \(\kappa>0\) 固定，相应提高固定的多项式停止高度。

在任一指定来源割 \(B\)、接收割 \(A\) 上，对 \(\mu|_B\) 作一次停止，这些分支在所有尺度合计至多为 \(C[\mathcal H\mathfrak j(A)+n\mu(B)]\)。若预先对全体输入固定停止族，小块部分在所有割上使用同一核，大块部分的全局原质量至多为 \(Cn\|\mu\|\)。与第859轮相比，可支付的小块上限提高了固定常数倍的 \(\log(n+2)\)，大块下限降低了同一对数因子。

**证明。** 用同一份来源核把每个停块 \(Q\) 中的质量均匀送入 \(3Q\)，再扣除被过多细盒覆盖的输出位置。每个块单独损失的均匀质量至多为 \(n^{-b}/4\)，总体输出密度受固定多项式控制。固定一枚真实来源后，给中父和小父各取一个实际的不交接收位置，在其勒贝格体积的乘积上估计过多坐标同时近面的代价。两端原来源的依赖关系、完整度和窗档费用均保留。

**实际验证。** 有理数逐块核验了 5、60、44 个停止块的截载，60 块例的输出峰从 \(19/6\) 降至 \(11/6\)。192 位和 384 位 Arb 核验显示，在 \(b=1/4\) 的保守坏尾估计中，\(c_b=2^{-18}\) 不足以支付全部档数，\(2^{-48}\) 给出严格指数余量。在同一批 920 条四维归档记录上，最细测试格的双端命中为总原量的 50.55%，输出峰约为 \(6.45\times10^{10}\)，超过指定密度帽 \(13140211\)。最粗格满足该帽，双端命中仅为 \(1.99\times10^{-9}\)。四维记录使用其归档门槛，渐近定理另由全维不等式证明。

**剩余原量。** 两枚真价同时处在 \(c_bR\log(n+2)/n<w(Q_y)<\kappa nR/\log(n+2)\)，并且第860轮共同位置容量也不足时，仍须控制跨中父、跨尺度共用同一右价的全部质量。本轮新增吸收系数为零。一般单窗次线性和全尺度 \(n^{1/2+o(1)}\) 弱型上界仍待证明。
