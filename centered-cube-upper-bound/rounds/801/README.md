# 第801轮　所有中父合计的欧氏球覆盖费用与真实旧价的分散维数

对第800轮的完整剩余路径，把两条腿的真实旧交价按物理小父 \(u\) 汇总为测度 \(\lambda_u\)。每条路径的两个接收点仍在原来不交的勒贝格所有者中。令 \(j_u\le C|E_u|\) 为原首臂质量，\(\rho_u=\mu|_{A_u}/m_u\) 为小父内的真实输入概率，\(s_u\) 为小父半径。设 \(r=\lceil\sqrt n\log^2(n+2)\rceil\)、\(\omega=r^2/(8192^2n)\)、\(H=O(1+\sqrt n/\log^2(n+2))\)。在 \(A_u\) 内任选 \(m\) 个球心，若 \(D\) 是其半径 \(d_u=s_u\sqrt\omega/8\) 的欧氏球并集与 \(A_u\) 的交，则

\[
 \lambda_u(D)\le CHj_u\big[m e^{-r/2048}+(n+2)e^{-\omega/8}\rho_u(D)\big].
\]

这条不等式已加完所有中父、体积档和停止代。第一个费用来自原小历史的逐点帽。对于球心落在中父扩张体外的旧价，只取一个命中球心，再利用不交接收区在参考方体内的实际体积。这样第二项对球数一致。若误将它也乘以球数，一般无法得到衰减。[完整证明及复现包](research.zip)

**对整批剩余记录的作用。** 令 \(M=\lceil e^{r/4096}\rceil\)，\(L=\sqrt n\log^3(n+2)\)、\(V=\sum |E_u|\)。每个小父各选 \(M\) 个球，所有至少一枚旧价命中的实际记录合计只花 \(o(V)\)。用该父的真实来源和冻结的真实价分布各作一次随机取点，再按损失比例删去低载父，整轮新增筛及旧门重查合计花费至多 \(C(LV+(n+2)\log^6(n+2)S)\)，其中 \(S=\|f\|_1/\lambda_0\)。比例删除系数 \(2/7\) 已由这份删除总账吸收。

**仍有正流的小父必须有多分散。** 设 \(J_u=\lambda_u(A_u)>Lj_u\)、\(\pi_u=\lambda_u/J_u\)。在两枚余价各自的位置 \(z\)，真实来源球概率小于 \(1/M\)，终态实际价球概率小于 \(8/M\)。要覆盖一半实际价质量，至少需要 \(c(L/H)e^{r/2048}\) 个半径 \(d_u\) 的球。即使每父自选至多 \(\lfloor e^{r/16384}\rfloor\) 个维数至多 \(k=\lfloor r/(16384\log(n+2))\rfloor\) 的仿射平面，这些平面各自的 \(d_u/4\) 邻域合计也只能容纳 \(o(1)\) 的实际价概率。实际价协方差的第 \(k\) 个特征值以后的总和至少为 \((1-o(1))s_u^2\omega/1024\)。

**数值核验。** 本机 Python 3.12.14 用有理算术复算了 64、128、256 维参考方体切片，用 384 位 Arb 核对了七组真实维数参数。与逐轴中位点独立的端点枚举给出，二维压力例的平均父间距为 \(120/121\)，下界为 \(50/121\)。一维两向分配例整条真实边仍余 \(3/16\)，先平均再截断会误报为零。保留筛后相关性，两腿同时未付为 \(9/2097152\)。这些是有限检验，详细 LaTeX 列出各自的输入与适用范围。

**尚待证明。** 两枚价均高度分散时，许多小父仍可通过同一批中父使用相关的高密度来源。本轮没有控制这批路径的总质量。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。
