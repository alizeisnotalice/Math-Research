# 第302轮：累计重叠的根阶主项与双尺度几何核

一般中心立方体极大算子 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮保留原实际接收测度、共同softness、FIRST、同半径硬帽以及全部原low/m/history资格，直接估计第301轮共同来源耦合费用。新结果包括一个根阶来源主项和一个真实可支付的局部质量分支；未将剩余几何费用认作已支付。

## 1. 累计行质量与真实立方体重叠

沿用R301的U_y、A_yz(r)、d和层测度ell_n，令J_y(r)=∫_{R≤r}U_y dx，M_y(r)=∫A_yz(r)dν。定义

Q_y(r)=(1/2)∫_{R(u),R(v)≤r}U_y(u)U_y(v) ν(Q_R(u)(u) Δ Q_R(v)(v)) du dv，

B_H=∫β(dy)ell_n(dr)1_{J_y(r)≥H}Q_y(r)/J_y(r)。

严格证明Q_y=J_y M_y−∫A_yz²dν，以及

O_d≤4λH Wβ+(d/H)A_n Wν+B_H，A_n=1+n log(b/a)。

小累计质量层只支付4λH每来源行，不额外乘尺度数；包括CDF原子跨阈值与终端层。大层用原FIRST共付一次来源费用。取H=√(dA_n/(4λ))并回代R301的T≤2O_d，得到

T_target≤4√(λdA_n)(Wβ+Wν)+2B_H。

保留λd=(4/3)κ0ψ∞/v0及原外乘数。质量不等的情形另给H*=√(dA_n Wν/(4λWβ))。这些阈值只优化已显示的主项，B_H必须在同一阈值重新计算。B_H目前只有A_nWν粗界；一般根阶边界费仍是缺口。

## 2. 双尺度包络保留根阶点值

使用完整共同softness的正系数包络Q_n，其质量Csoft_n≤1+(π/2)√n。对软/硬两套尺度包络，固定尺度卷积逐坐标按max(L,R)^{-1}控制；双尺度积分精确为

∫∫max(L,R)^{-n} μ(dL)μ(dR)=2a^{-n}−b^{-n}，μ=δ_b+n dL/L。

这避免把两次尺度费用直接乘成A_n²的点值损失，并保留来源距离的指数衰减。包络的L1质量仍是A_n² Csoft_n，不能把根阶点值偷换成任意来源积分的根阶价格。准确地，令b_D(z)=β(Q_(2Db)(z))，在b_D(z)≤q_-a^n L0的列上，近对|y−z|∞≤Db的原实际交通≤2Csoft_n L0 ν(Z_light)。L0为固定对数阶时该分支得到根阶价格；较重局部列及远对仍须支付。

## 3. 辅助尺度变化机制及明确范围

另证明真实三角形乘积卷积核的全尺度Lebesgue包络具有O(√(n log(n+2)))费用；对每个固定共同softness成立。尺度score的方差无限，使用精确截断矩，不能直接套有限方差平方根界。该辅助结果不允许将接收点依赖的卷积替换成固定参数卷积；选择器和任意β×ν积分两项费用均未省略。它不是一般闭合的替代。
