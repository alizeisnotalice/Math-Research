# 第40轮：捕获质量归一化与弱端点谱等价

日期：2026-10-10。主目标 sqrt(n)n^{o(1)} 一致上界尚未证明；一般全尺度上界仍保留 O(n log n)。

以真实选中方体的捕获质量归一化后，源空间 L²(μ) 的谱常数 K_n 满足 C_n≤2K_n、K_n≤8C_n；证明包括不损常数的原子化、真实赢家选择、阈值带求和及正部截断。该合同与原问题同阶，没有把额外的异质量强能量条件当作必要条件，也没有降低已知维数阶。

固定尺度归一化核的范数恰为1，源 Gram 是可逆 Markov 算子；接收点选择尺度后其源侧行和变为真实占用 I_y，守恒不再自动成立。本轮还证明均匀噪声的独立加性粗化仅支持整数尺度比，给出任意来源的 dyadic 逆鞅表示，并明确其移动接收点与原固定中心水平集的差别。细网格的常数取整损失不能直接与该 dyadic 表示拼接。
