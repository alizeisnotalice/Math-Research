# 第823轮　固定右来源的累计接收预算与两枚真实来源的距离

沿11月23日指导第六节第三步，直接估计第813轮的原双臂积分。固定右来源 \(q\)，左来源 \(z\) 可以随中父、左小父及真实接收位置改变。记 \([R,2R)\) 为本条记录所在的物理半径窗，\(V\) 为原来本质不交的接收集总体积，\(m_t,m_u,m_g\) 分别为中父、左小父和右小父的实际质量。

**真实源距随体积跳跃增长。** 写 \(J=\sqrt n\log^8(n+2)\)。在同一正子流中合并所有绝对尺度与中父，扣除 \(o(V)\) 的原质量后，每条余下记录满足

\[
 \frac{\|z-q\|_1}{R}>
 \left\lfloor\frac{J}{1024\log(en/J)}\right\rfloor
 \asymp\sqrt n\log^7(n+2).
\]

第813轮原有的距离门为 \(\asymp\sqrt n\log(n+2)\)。更精细地，若 \(p\le\log(m_t/\min(m_u,m_g))<2p\)，其中 \(p=2^jJ\)，上式可用该档的 \(p\) 代 \(J\)。至少 \(p^2/(2^{20}n)\) 个实际坐标上，两个小父的相向面各自离本父标记至多该轴源距的四分之一，两个闭区间间隙大于 \(pR/(128n)\)。所以在半径比至少为固定 \(1+\theta\) 的记录中，两价的一范数距离至少为 \(c_\theta nR\)，至少 \(c'_\theta n\) 个真实坐标有 \(c''_\theta R\) 的间隙。

**给同一个 \(q\) 结账。** 令 \(b=\lfloor J/[1024\log(en/J)]\rfloor\)。对每个 \((O,q)\) 选一张中父与左父的表，让一份对原来源绝对连续的测度同时覆盖所有真实接触集 \(G_t\cap G_u\cap\{\|z-q\|_1>bR\}\)，每份需求为该集合的真实质量除以 \(m_t\)。按这些集合重算的最小总量至多为 \(e^{b/32}\) 时，整张表所传递的原质量在全尺度只花 \(o(V)\)。分档使用实际 \(p\) 时，至多 \(O(\log n)\) 个档的费用已计入。证明联合使用中父和左小父的实际接收体积，一轴上的共同可用面积至多为两处外包边长之和的平方除以四。先前观察到的接收坐标可以决定下一轴及其测试区间。

**本机复核。** 两份四维浓度各有230条带两价的原权重记录。重放同批357个带右标事件的逐对分配、共享右价、再约束两处真实接收容量，原浓度各可付原单臂质量的约 \(99.9922\%,99.9872\%,0.3780\%\)，第二浓度为 \(99.9937\%,99.9902\%,3.2132\%\)。在第三种分配的有理可行解中，分别有6行和1行真实接收容量恰好饱和。另按真实来源胞内的连续质量复算坐标规则，更宽的区间把原浓度的零失误比例从 \(18.91\%\) 提到 \(24.87\%\)。检查了1722项有理截面、240项截断矩，以及四个指定维数的256位、384位区间。四维压力测试中的高维价格门为空。

**待证。** 同一右来源仍可能经许多不同中父，各自遇见实际距离很大、接收位置分散的左来源，而覆盖这些左来源需要很高的总容量。尚缺这部分累计原质量的 \(C(\sqrt n\log^\alpha(n+2)V+n\log^\beta(n+2)S)\) 预算。一般单窗 \(B_n=o(n)\) 及全尺度 \(C_n\le K\sqrt n\) 均待证明。
