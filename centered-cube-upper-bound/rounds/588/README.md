# 第588轮：完整接收集的坐标臂与有符号半核心预算

日期：2026-10-24。一般中心轴平行方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮构造、条件回代和有限精确计算通过各自范围的核验；没有一般根阶改善声明。

## 全局构造与未付量

对完整剩余 R′ 的真实互斥分片 E_N，逐坐标选择实际来源的半质量侧，将 E_N 仿射送入该半核心载体的外侧臂。保留全部原标签、每坐标宽度、真实接收体积和全部域外部分。推送的是 E_N，不能替换成全部父载体 C_N 后相加。同父各坐标臂互不交，跨父重叠保留。

低体积比给乘重体积增幅 gₙ=1+(log n)/4，但没有证明半核心并集 H 的无重数体积获得该增幅。未稀释整数占用数 q 满足

`λ∫q = λ|H| + C_overlap − C_unused`。

由于原 Jacobian 总量可能远超所需增幅，本轮将同父各臂统一稀释为 qθ，精确满足

`λ∫qθ = gₙ J′`，`C₊−C₋ = gₙ J′−λ|H|`。

C₋包括部分未填满的区域，不能只算零支撑区。**这一恒等式尚未给来源预算**。仍需证明全族净费用 `C₊−C₋≤DₙW`，且 `Dₙ/gₙ≤C√n logᵃ(n+2)`，常数统一于所有输入与尺度。

固定 H 和总推送量时，仅改变图像位置或压低正重叠，不会改变正负相抵后的净量。后续必须寻找完整 H 与实际来源的定量关系，不能把反复改写此恒等式计为进展。

## 完整费用回代

令 Bₙ 是不扣异常集合的完整单质量带弱比值上确界。闭见证方体贪心覆盖独立给 Bₙ≤3ⁿ，确保吸收前有限。半核心实际质量属于 [L/2,U]；阈值减半及两段质量带共同给 `λ|H|≤4BₙW`。

若上述未证净费用界成立，则

`Bₙ≤2√n+5+(4/gₙ)Bₙ+Dₙ/gₙ`。

先在完整单带内吸收，随后才支付继承的一般输入恢复因子 `Nₙ=2+ceil(log₂(32n²))`。gₙ≥8时条件吸收差值至少1/2；较小的有限维数范围可用3ⁿ并入统一常数。这不是已成立的根阶递推，因为 Dₙ 的统一估计缺失。

主路线的异常费用为 H₂ 的2√nW、Top⁺的3W和原基底的2W。独立核验的连续质量揭示方案可改付一个固定尺度出生集合W，从原R重新开始时总常数项为+4；它不是原R′，也没有得到完整面流预算。报告保留这一区别，不将局部面削减或出生守卫作为主要成果。
