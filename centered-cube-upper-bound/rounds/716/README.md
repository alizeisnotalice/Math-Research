# 第716轮　接收点和来源都持续拥挤时的联合预算

开题核对[第706轮指令](../../AGENTS.md)。在同一首次捕获历史上，给每个来源一次原装填预算及一小份实际 owner 体积预算。交替删去当前高损失权重小的接收点和实际接收体积小的来源，全部已删贡献合计至多为坏接收体积的 1/8 加根阶来源费用。深接收者允许按容量深度指数增加每个来源可使用的见证位置数，原来源的预算仍只发放一次。

若仍有未付质量，则在同一剩余关系内，存在长度至少 exp(常数·√n) 取整的交替路径。沿途接收行和来源均不重复，相邻来源的对数体积相差至少常数乘 √n，且每次均能避开当前来源尺度下此前见证的一批邻域。这里的尺度跳跃可以往返。一般输入下，此关系的剩余质量仍待估计。

九组真实双中心历史表明，直接在原接收点释放少数坐标，会漏掉几乎全部原高损失权重；这些算例有足够的来源预算。双机还对 1,536 个有限加权关系核验了删减账目。详见[详细证明和复现记录](research.zip)。
