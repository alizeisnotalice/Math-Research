# 第727轮　可替代的来源与整段运动的停留时间

开题复核[第706轮指令](../../AGENTS.md)。固定一个来源及其有足够真实接收质量的尺度档。第一次抽样要求原标签实际出现，后续抽样允许同一体积档内中心足够近的不同来源代替它。这样能在原账内支付单个标签出现很少、但附近总有来源接替的关联。

从第一次的真实见证出发，朝第二个独立真实接收点的方向移动。按来源所在档的边长缩放时，该测试适用于任意两个来源的尺度比。将整段中仍落在略扩张来源内的时间按原权重相加，容许少量坐标越界，所得条件期望至多为常数倍的 log(n+2)/n。由此，期望停留时长达到维数平方根倒数的关联，在完整账目里只耗费趋于零的接收质量系数。

六个真实贪心算例的原高损失积分均严格为正。其中同一批接收者可以每次使用不同的标签。这些算例的超远来源已足以支付费用。一般输入中，若很多来源很少替代彼此，且两端的停留时间都短，这些关联的一阶总费用仍缺根阶上界。
