# 第712轮　高损失来源的跨接收者联合分配

开题按[第706轮指令](../../AGENTS.md)核对原积分（4）。对同一接收体积档，把每个真实 owner 点送到一个辅助位置分布。若各目标位置收到的总测度至多为 Lebesgue 测度的 n^B 倍，其中 B 固定，则任意固定 δ∈(0,1/2) 下，可以支付平均捕获比例至少为 n^(−1/2+δ) 的高损失质量。源方体在测试时允许同心放大 1+4/n。证明保留原首次捕获见证、全部近半径和全族一次来源价值 D。

对每个合格见证，还可取其全部近来源膨胀方体的真实交集。以各接收者所有这类交集的并作为可分配区域，有限最大流给出未匹配的实际接收体积 Δ。完整高损失积分满足 R_high ≤ Δ + n^(−1/8)V_T + C_B,c D/n。任意输入的 Δ 或更灵活的联合捕获剩余仍待控制。

九组压缩表示的真实历史中，第711轮的每点未付权重均超过 0.49999999995。在同一历史上，本轮给出捕获全部高损失来源的显式分配。本机 Arb 与 MacBook Decimal 已交叉核验。
