## 全对象约束与剩余缺口

沿用完整E、W、v、q=λv/W、κ=W/v。对外点定义

T(x)=inf_r [λrⁿ−νQ(x,r)]/[κ|Q(x,r)\E|]，H(x)=(1−T(x))₊。

全部来源、尺度及完整E遮蔽均保留。对q≥max(2,C_n/2)，同一低阈值外壳L可用于每个0<θ<1，微填充总账给

(1−θ)λ|Aθ|≤(C_n−q)W(1+θ|L|/v)。

可测性、严格inf、固定输入以及Tonelli积分均经独审，得到

λ∫_{Eᶜ}H²≤(C_n−q)W(2+|L|/v)≤(C_n−q)W(2+2^(n+3))。

进一步用完整端点体积上界B=q(1+C_n−q)W/(q−1)，令S=(C_n−q)W(1+|L|/v)，得到线性预算：λ∫H≤Φ(S,B)，其中0<S<B时Φ=S[1+log(B/S)]，S≥B时Φ=B，S=0时为零。这来自严格尾界min{B,S/t}，没有直接积分发散的S/t。固定n后近极值极限使Φ/W趋零。

因此待证目标可放宽为完整H的线性下界 η_n λv−L_nW，且L_n/η_n为根阶多对数；比要求H平方下界更弱，但仍未证明。若只在q≥2证明，最终须保留低q分支max{2,L_n/η_n}；指数外壳因子与对数也不能在有限亏损时删除。

Astra检验中性端点：完整A₁也满足λ|A₁|≤q(1+C_n−q)W/(q−1)。内部见证位于测试盒外，其来源却可能在盒内；零总质量未给跨边界共同容量。独立贪心覆盖一次计来源仍付3^n，移用已选来源的外测试仅在既知窄窗口有信息。这些尝试未给新净估计，不作为进展重复计数。
