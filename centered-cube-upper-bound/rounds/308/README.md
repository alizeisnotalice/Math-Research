# 第308轮：原中捕获余项的高次数付款与共同容量证书

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮在第307轮原剩余积分上支付一个新的正子项：中捕获比例层的高次数软捕获端。原未捕获端、分母、所有资格和已付分支保持原定义。

## 新解析付款

保留共同softness的真实正展开 P_s,L=Σ b_nk(s)q_k,L。对原前缀尺度t，真实捕获且R<=t的接收点位于Q_t(z)。利用R303每软坐标收缩rho和一套软尺度包络，证明

A_k(y,z;t) <= c_nk rho^k [1+n log(t/a)]/q_-。

这里估计的是实际接收积分，不是以薄层体积推断来源质量。令A_n=1+n log(b/a)，选择统一K使

A_n Σ_(k>K)c_nk rho_bar^k <=epsilon eta_mid q_- H。

K不依赖来源总质量和局部密度，但完整依赖n、epsilon、eta_mid、q_-H；可能等于n。仅当逆参数有多项式控制时，解析几何尾才给O(log n)的充分截断。

在第307轮原余项G_res+B_near,res中，按二值捕获端定向，只将捕获端U拆成次数<=K和>K；未捕获端仍为完整U。原中捕获层eta_mid<=p_theta<7/8、J>=H上，高次数正子费逐层至多A_hi(J−A)/J<=epsilon A，积分后<=epsilon T。原低p补集完整保留，所有门均不重算，也未给无权单分量FIRST。

取epsilon=1/64，接入第307轮后得到

Lambda T <=(2048/3) Lambda lambda d W_beta
 +(64/3) Lambda integral_0^1 [R_low-p+R_mid,low-capture-degree]dtheta。

Lambda=128/119；d的逆尺度比费用不变。此前远失捕、quiet、rapid付款未重复使用。这是内部T吸收，对原全局X误差系数新增0。

## 剩余几何预算的可执行证书

另建立共同FIRST下的有符号行预算：实际行费用b_y若满足b_y<=C+∫U_yP，P>=0共享于全部来源行，则费用<=C W_beta+∫P。对完整方差费用，平方恒等式使h=A/J逐行同时最优，可消去拟合变量，转成有限线性规划；共同theta可先整合，不复制来源费用。

本机有限模型取得精确原始／对偶可行及零间隙证书。一个抽象两行模型的混合预算169/2000，严格小于列Jensen预算1771/20000、单独行预算1/8及单独接收预算37/400。另有正体积cube-cell模型显示联合预算有时改进、有时较差，完整保留对照，没有据此拟合维数阶。

该证书尚无一般根阶可行势的构造。完整方差的h消元不自动适用于新剩余pair费用：应用时必须按该余项重新定义实际行费用，不能偷换预算对象。

## 实际检查、复现与范围

所有报告区分解析证明与有限证据。调用本机Python，主代理独立进程复跑：

- 主尾探路分三阶段覆盖n=1至1024，2100项尾／阈值检查、456项方差Lipschitz检查通过。另以有限有理下和和指数Taylor余项证明rho<9/10。例epsilon=1/32、eta_mid=1/16、q_-H=1时，n=128的最小证书K=107，n=1024时K=115；小维或极小q_-H可无非平凡截断。
- 主pair程序检查1152个条件原子模型，444个合格层的正分裂与高次数付款界通过，其中372层高分量非零。它验证代数，不声称任意指定高份额都是可实现谱分量。
- 作者稿嵌入程序另检查16项尺度公式、60项精确尾阈值、126项方差扰动及1536项正pair分裂，全部复跑通过。
- 容量证书程序使用NumPy候选顶点枚举，再以Fraction重建并精确核验。零来源行按beta-a.e条件删除；最终3558项精确检查通过，58个LP取得零间隙证书，主代理复跑JSON逐字节一致；完整计数见研究包内验证记录。抽象transport模型与真实正体积cube-cell模型分开，后者仍未实现完整原low/e_g/m/history。

本机SciPy优化模块因已有本地二进制导入错误不可用，未修改环境；上述有限LP改用NumPy候选枚举和有理核验。复现容量程序需要NumPy，其余探路使用Python标准库。解压包后运行 `python3 r308_numeric.py`、`python3 r308_tail_probe.py`、`python3 r308_pair_probe.py`、`python3 joint_capacity_checks.py`、`python3 geometry_checks.py`。可再生的大JSON不重复归档；保留详细LaTeX文本，不编译PDF。
