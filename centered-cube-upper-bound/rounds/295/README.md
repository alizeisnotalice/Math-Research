# 第295轮：补偿冻结去除质量损失，双向尺度来源预算

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮继续推进原中间硬层：去除第294轮的附加质量阈值损失，支付具有既有小软度限制的一个完整高质量方向，并把反方向费用改成明确的对数平方来源积分。

## 1. 不再损失 sqrt(n)/ell 的质量阈值

保留原q∈[3lambda/4,lambda]、原完整e_g、原m、原FIRST和真实dx。取

    rho_q=(lambda/q)^(1/n), t=g/rho_q。

由于原树阈值H_j(t;lambda)≤H_j(g;q)，辅助冻结来源质量满足 e^+(t)≥e_original(g)。因此原 m>M 直接给出冻结尺度t上的高质量资格，不需再假设 m>M+4sqrt(n)/(3ell)。

辅助来源公式仅向下延伸一个(4/3)^(1/n)尺度因子，不在非法尺度使用核cap。根的端点跳跃仍放入终端带；其费用只增加log(4/3)。结合第294轮逆向变差，引出跨全部比例带的真实付款

    T_(low,m>M,L<=R)
       ≤(160/3) delta^(-2) R_delta
                       (2K/(ell M))^delta W_beta。

原Lambda另乘一次。证明保留原完整e_g，不重建后验或历史资格。

## 2. 共同软度矩与现有小软度部分的付款

令H_sigma=sup_{s≤sigma}∏f_s，R_delta=∫H_sigma^(1-delta)。对实际一维f_s，定义Z_sigma=∫f_sigma^(1-delta)。通过归一化幂密度及其参数变动，证明全参数界

    Z_sigma^n ≤ R_delta
       ≤Z_sigma^n [1+(sqrt(n)/2)L_(1-delta)(sigma)]。

L是显式的一维arcsin与log表达式，端点可积，共同s不被拆成独立坐标。旧n点菜单费降为sqrt(n)参数费；真正的Z_sigma^n仍保留。

进一步保留delta=0处的精确抵消。设Dhat=max(n sigma,1)，存在显式常数A_soft、C_L，使对于

    0<delta≤[2(1+A_soft)(1+Dhat)(1+log(1/hatsigma))]^(-1),
    hatsigma=max(sigma,1/n),

有R_delta≤sqrt(e)(1+C_L sqrt(Dhat))。常数可用解析上界，不依赖未认证的小数。

再把delta按log_+(2K/(ell M))减小，即可消去M≥2K/ell的额外限制，并保留该对数费用。于是当既有槽满足n sigma及log_+K为多对数时，取M=1可用多对数原来源价格支付其**全部原low、m>1、L≤R部分**。这是任意L1来源上的实际参数分支，不是固定函数模型；没有声称所有未解决槽都有小软度资格。

## 3. 反方向改用硬尺度，避免反向增长的比例带费

在原low、m>M、L>R分支，原高度界改写为

    p_y≤[2K/(ell M)]c_j^(3n/2) R^(-n)。

先使用原beta FIRST，再积分真实硬核。对任意预先冻结的0≤omega(y,z)≤1，令b_omega(z)=∫omega(y,z)beta(dy)，证明

    T_omega≤∫nu(dz) Psi_(n,A_win)(2K b_omega(z)/(ell M q_- a^n))，

其中A_win=(b/a)^n、q_-=3lambda/4，Psi是收敛的全部比例带级数，具有显式O(1+log_+²)上界。此式不含软度矩，不要求来源密度上限或位移限制。

若列质量满足

    b_omega(z)≤ell M q_- a^n exp(n^(1/4))/(2K)，

则对应原交通≤8sqrt(n)W_nu。没有证明omega=1自动满足这个容量，也没有通过重复切分beta来免费重复使用nu。

## 4. 实际验证与复现

主代理和独审先分别核验补偿冻结、共同参数矩、反向硬尺度公式，再审核完整证明。本机Python Fraction、Decimal及mpmath实际运行；主代理复跑全部最终脚本。

- 补偿冻结主检查：三阶段108个精确树/体积案例，包含fallback、节点阈值相等、原high-m继承和324次来源单调检查；270次方向覆盖，含90次端点等号；维数至10000，另验跳跃根与物理单点窗口。
- 同一脚本另有54个40/60位自适应矩预算标量检查，参数log10(r)跨±10000；它们不替代真实profile矩积分。
- 反向来源：每个40/60位精度运行120个标量案例，并有150个Fraction有限尺度积分。无穷带尾使用精确几何公式，没有把有限截断当整个级数。
- 实际软核：13个真实phi参数案例核验矩、归一化幂密度的参数变动及抵消，另有16个任意M的对数阈值检查。所有检查通过；普通高精度结果不是区间算术证书。

复现：解压research.zip，在安装mpmath 1.3.0的Python中依次运行 `python3 checks.py`、`python3 reverse_checks.py`、`python3 soft_moment_checks.py`。必要代码、结果、详细证明、LaTeX文本及审计均归档，不编译PDF。
