# 第828轮　同一右端的左父共同接收体积与多源跨度

在第813轮的原双臂上，先固定右来源 \(q\)、实际右接收者、原中父历史及中父的实际接收位置，再合计不同左父的质量。报告给出完整证明、每次条件化的次序、两条真实来源分母和整个回代。当前的一般单窗目标为 \(B_n=o(n)\)，全尺度目标为 \(C_n\le K\sqrt n\)。

## 一次估计许多左父的接收体积

设 \(H\) 表示上述固定信息，\(w(H)P_H\) 是原左臂相对于右侧基准测度的真实条件质量。对观察本次左臂前确定的紧集 \(K\)，有

\[
 w(H)P_H(A_u\cap K\ne\varnothing)
 \le \frac{C\mathcal H\eta}{d_v m_t}\,|K+Q_{h\sigma b_t}|.
\]

\(b_t,m_t,d_v\) 为真实中父边长、质量和完整度，\(\eta\) 是原薄交质量比例，\(\sigma=e^{-J/n}\)，\(h=1+1/(32n)\)。这给命中 \(K\) 的整个左父计费，左价可离 \(K\) 很远。固定右端后取至多 \(e^{J/12}\) 个预选仿射空间，其维数满足 \(r\log(8en/r)\le J/12\)。任何左父只要到其中之一的无穷范数距离不超过 \((1-\sigma)b_t/8\)，这些父的累计费用便至多 \(C(\mathcal H/L)\eta(n+2)e^{-J/2}Y\)，其中 \(Y\lesssim V\)。证明逐轴计算增厚的投影体积，允许低维空间同时在每个坐标上有很长的投影。

同一条件测度还给出一份逐点容量不超过一的真实左父分数装填。对同一个 \(H\)，小父供应点大量留在略扩中父的全部原记录也可支付。跨不同 \(H\) 的这些装填相加后，逐点容量仍待估计。

## 一个右端同时限制多条坐标

保留原 \(z,q\)，再从中父真实好来源抽任意枚伙伴。在至少 \(\lceil n/14\rceil\) 个坐标上，只要有伙伴与同一个 \(q\) 相距至少 \(63b_t/64\)，该子流的原费用至多 \(C\mathcal H(n+2)e^{-n/64}Y\)（\(n\ge512\)）。理由是同一个中父接收者在所有这些坐标上都必须靠近以 \(q\) 为中心的参考盒边缘。该二项体积上界对一般来源成立。

在一般方体末根的独立入口，若随机选择 \(k\) 条轴作保体积的居中矩形变形，真实平均密度有固定增益，则这一批接收者使用全尺度弱型常数的乘数至多 \(C(1+n/k)e^{-c n/k}\)。当 \(k=o(n)\) 时这项可以吸收。未出现密度增益的接收者保留在原问题中。

## 本轮计算

- 对两份原四维正来源，各34条实际双臂记录、230个正价单元，精确计算6528个单轴积分和37536个参数项。固定真实右价，加上左价和七枚中父来源，在每条行上都得到严格的平均命中概率下界 \(111/1000\)。
- 对同一行的独立坐标张量，精确下尾与区间算术检验覆盖32至 \(2^{30}\) 维的七个维数。由这68条行的有理下界和解析乘积估计，所有充分大的四倍数维数在该模型上都以至少 \(1-e^{-n/125}\) 的概率过门。一般高维历史的过门概率仍未知。
- 在原四维接触几何上，给定中父及右父后，允许中父内选两个点，最多可刺中过去两组数据约94.86%、95.70%的真实左父权重。将候选点限制在中父与右父的交内，份额降至39.91%、40.53%。另对居中矩形变形完成330项组合枚举、54组有理检验、68组区间检验。

剩余量 \(R_{828}\) 允许同一右来源在许多中父与不同左来源相遇。这些左父可以避开预选低维空间，供应点可以落于中父之外，而原右端又很少限制足够多的轴。各付款项已接回第772轮总账及第814轮原余量。一般上界尚未闭合。详情及实际完整输出见[本轮研究包](research.zip)。
