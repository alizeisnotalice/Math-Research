# 第848轮　多个早期见证共享真实来源时的累计接收质量

冻结第847轮最终未付的原记录 \(F\)，记实际来源割质量为 \(S\)，\(\ell=\log(n+2)\)。在同一二倍尺度窗内，本轮给每条原记录构造一段严格退档的历史，并估计哪些完整历史能够按根阶费用结算。[详细 LaTeX、三份程序及实际输出](research.zip)

## 固定真实来源，合并早期记录

把一枚来源在各档的实际负荷沿时间排成区间。当前记录抽取一个质量秩，所有早期见证都相对于这个秩，在相互分开的窗口内选取。每步移到第一条旧记录，并改由它的另一枚来源发起下一步。接收者、见证边长、两端来源和原密度分母均保留。所有当前记录合计，移到一条旧记录的质量至多为该旧记录自身的原质量。

对同一步抽到的 \(m\) 条记录，固定全部接收位置和每件的另一个真实端点。共同交盒中的候选来源只有在**它自己的全部时间档**都能按原规则进入时才计入。正文证明了这个实际密度可以在每一步同时超过门槛 \(L_n\)，而拒收这些步所产生的终端费用仍为 \(O(\sqrt n\,\ell^2 S)\)。选取随维数增加的阶数，\(L_n\) 可超过任意固定的 \(n^A\)。这一存在性使用每个固定 \(p>1\) 的无维数强型界，阶数增长速度尚无显式估计。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

在已接受的一步中，还可以保留全部接收者和实际对端，按真实条件律重抽共同来源。原、替换后的两条旧件都可保留为见证。对每个预先固定的换源规则，旧记录承接的总量和终端费用均与原规则相同。

## 一次终端费用能支付的原质量

令 \(c(e)\in[0,1]\) 为一条旧记录承接未来合法转移的总质量与自身质量之比。从实际终端反向计算，长度 \(j\) 的完整历史带有权重 \(\prod_{i<j}c(e_i)\)。由此，长度至多 \(\lceil\ell^2\rceil\) 的全部历史，以及任意深度中该权重至多 \((j+1)^{-2}\) 的全部历史，原质量合计至多为
\[
C\sqrt n\,\ell^4 S .
\]
这一估计无需增加旧账的吸收系数。扣除相应原件后，其余每件从任一端出发，都有超过 \(3/4\) 的概率产生更长的历史，且反向权重仍高于上述门槛。

## 本机复算及剩余问题

- 四维五档正宽实盒给出一条质量恰为 \(2^{-58}\) 的四步历史。从终端反算，逐状态恢复全部原质量。两条旧件共享同一当前秩时，伙伴筛选后的联合命中率为 \(10/243\)；分别重抽当前秩会得到 \(4/81\)。
- 128维、57个不同实际体积档的样本中，在同一组三个接收者和私有对端上，仅按物理交盒统计的来源质量是整档相容量的 **1,048,584 倍**。因此，分子中的共同来源必须逐一保留自己的时间历史。
- 指定的本机 Python 3.12.14 环境逐字节重现三份输出。有理算术还核对了十六维正宽样本中逐对交盒与三重交盒的差别，并在64至4096维的四组参数上检查多重交体积的显式费用。

**一般上界仍缺长历史的累计费用。** 当沿途大多数旧记录几乎可以全额承接未来记录时，反向权重衰减可能很慢。严格退档保证路径终止，但直接乘以最大深度会失去根阶。第813轮的其他原费用和全尺度条件仍保留。
