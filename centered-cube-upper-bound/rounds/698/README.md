# 第698轮　首次捕获的精确指数与共享来源

第698轮确定了首次捕获单个接收者所需来源预算的精确指数。在 t=√n、缩小倍数 32n²、捕获阈值 1/2 时，最小预算相对于接收者父方体体积为 exp((log 2+o(1))√n)。上、下估计分别由真实方体壳和历史剩余容量给出。

跨接收者按来源份额分层，所有层对每个来源的总计费至多一次。仍需对任意接收者子集控制共享费用。2160个一维输入的精确流与紧割通过双重核对，512个维数的逐壳计算通过独立复核。详见包内 REPORT.tex、NUMERIC.md 和 AUDIT.md。
