# 第43轮：后验壳层能量分解与相关来源谱障碍

日期：2026-10-10。一般中心方体 sqrt(n)n^{o(1)} 一致上界仍未证明，geom余项未闭合；保留 O(n log n) 一般全尺度上界。

本轮对任意正来源证明真实核心/壳层后验能量恒等式、有限标签熵链和固定终点的折扣方差预算。对乘积来源，边长比1+δ的后验平方能量增益至多δ/(1+δ)；但两个实际正乘积来源的混合就能使一般最坏增益达到min(nδ,1)阶，非负测试也成立。该阶数来自解析上下界，不是数值拟合。

具体有限来源在n≥2、δ=1/n、偶数参数N≥256n时，有符号单位测试增益至少245/2816>1/12，非负单位测试至少245/5632>1/24。这排除了把产品来源的小步谱估计免费推广到任意来源的路线，不是原弱型目标的反例。

把固定终点改为接收点依赖的真实选尺度后，预算重新包含来源占用量。常数测试使方差消去项全为零，仍不能支付占用。报告保留真实赢家及首次越阈的正壳层收费接口和初始尺度费用；共同来源、真实选择下的总几何预算仍未证明。
