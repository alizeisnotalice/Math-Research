## 已证结论及完整费用

给定有限正原子输入 ν、完整接收集 E、W=ν(ℝⁿ)、v=|E|、q=λv/W，任意有界开集 O⊂Eᶜ 都可由有限个不相交的缩放副本近填充。每步仍保留全部实际来源，质量精确为 (W/v)×已填体积，最大副本直径趋零。输入形状只影响有限副本数量，不增加最终质量费用。

微来源弱收敛到 (W/v)1_O dx，但不据此声称极限保留微接收。微接收信用在预极限有限输入上保留；同一列来源的每个固定立方体质量收敛恢复全部宏观严格见证。对 G={M(ν+(W/v)1_O dx)>λ}\(E∪O) 严格得到

λ|G| ≤ (C_n−q)W(1+|O|/v)。

原子在立方体面上的质量、O边界、全部尺度及标签数均保留。不存在固定来源数的免费上价，也不把严格阈值改成非严格平台。

进一步取完整低阈值外壳 L={Mν>2^(−n−2)λ}\E，在同一组周期细条中填入比例 θ=1/4，保留其余孔洞接收。对完整增广接收集合 Aθ（定义详见LaTeX），当 q≥1、q≥C_n/2 时，证明

(1−θ)λ|Aθ| ≤ (C_n−q)W(1+θ|L|/v) ≤ (C_n−q)W(1+θ2^(n+3))。

这个指数因子只乘近极值误差，仍完整记账；它不是根阶费用。真正缺失的是同一 Aθ 的统一几何下界。沿坐标退出的尝试仍须联合估计实际见证尺度、完整并外孔洞和间隙长度；不能逐父付款或删除遮蔽。
