# 第267轮：局部接收容量与同一来源份额三腿预算

一般 n^(1/2+o(1)) 一致弱型上界尚未闭合。

本轮从原 β 可测抽取同一份额 θ=min(1,τ/β(Q_{2(b+d)}(y)))，证明每个接收窗口的抽取质量≤τ。一般 Lp 响应估计同时支付移动两腿及 J 腿。τ=λa^n/√J0、固定原合法K和低soft s0=C log n/n时，来源价为 O(√n log³(n+2))，保真实dx、原后验、共同叶、唯一j与全部外常数。接收误差拆为 ε/2+ε/2。
