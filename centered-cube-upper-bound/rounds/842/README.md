# 第842轮　跨尺度来源覆盖与体积档的累计费用

沿一般输入的真实双来源割，固定边长窗 \([1,2]\)、阈值 \(\lambda\) 和原可测严格见证 \(A_y\)。用 \(\eta\) 表示这一割的来源测度，\(s_y=\eta(A_y)\)。本轮证明，即便要求许多尺度的见证在略微扩大后仍几乎彼此避开，也能合并支付违反这一要求的整批原记录。[详细 LaTeX 与复现](research.zip)

## 重复覆盖付出了多少

每次删除后，在同一真实端点重抽见证的概率律都会改变。将它在每个边际二进档首次出现时冻结，再把所有档抽出的参考点一次列齐，重复覆盖的收费只依赖参考点总数的对数。竞争见证可以扩大 \(1+B/(24n)\) 倍。被遮住的来源量始终除以自身原见证的 \(s_y\)。逐坐标相交计算的是允许真实接收中心出现的勒贝格体积。

对任意固定 \(p>0\)，在原双端流 \(\tau\) 上共付 \(C_p\sqrt n\log^2(n+2)\|\eta\|\) 后，几乎每条余留原记录的两个端点各有 \(\lfloor(n+2)^p\rfloor\) 件实际见证。它们连同根能同时各自保留至少 \(31/32\) 的原来源质量在其余全部扩大件外，其中可沿同一余流继续配对的来源至少为各自原质量的 \(1/32\)。如要求整个家族与根同一体积档，另有至多 \(2|R|/(n+2)\) 的原流例外。\(R\) 表示上述实际终端。若把容许费用改为任意固定的 \(\varepsilon n\|\eta\|\)，充分大维数下可取指数多个实际见证及与维数无关的正扩张比例。

## 哪些原记录能直接付款

固定实际来源 \(a\)，\(r(a)\) 为它在整个窗口的终端边际密度，\(D\le |A_y|<2D\) 为一个真实体积档。若事前给定的来源池质量为 \(L\)，档内一组见证各有至少 \(u\) 比例的原来源落在池中，这组见证在 \(a\) 的原条件质量 \(t\) 满足

\[
 \lambda D\,t^2\le 2\alpha\,r(a)L/u^2.
\]

这里 \(\alpha\) 是终端允许的定向平均覆盖率。证明同时使用同一来源上两次重抽的实际交质量和该档真实接收体积。对整组见证收费时，当前这一行的伙伴可以在池外。

令 \(\Lambda(a)\) 为同一终端中能与 \(a\) 实际配对的来源集合的 \(\eta\) 质量。凡原行有一端满足 \(\lambda D\ge\alpha\Lambda(a)\)，在所有真实体积档及两端合计，原量至多 \(C\sqrt n\,\|\eta\|\)。这一项在已构造的终端上支付一次。第840轮单对乘积核在部分参数范围也能支付这一档尾，正文给出两界的比较。

所有档还可同时实行如下分配。固定 \(a\)，把各见证的 \(s_y\,\mu_a(dy)\) 分给真实存活伙伴。所有见证共用下一来源 \(w\) 的密度至多为 \(4\alpha r(a)/\gamma^2\)，其中 \(\gamma=1/16\)。这份分配的需求带有 \(s_y\) 权重。

两端同时满足 \(\lambda D<\alpha\Lambda(a)\) 的原记录仍在账内。不同根可以多次使用同一批来源，各根的 \(31/32\) 私来源结论只对其自身构造的家族成立。这个交集的累计容量尚缺统一估计，一般单窗 \(o(n)\) 及全尺度 \(n^{1/2+o(1)}\) 上界仍待证明。

## 本机精确核验

- 在同一组一维正宽来源和真实接收记录上，新边际档沿用旧参考的负对数漏检率在 \([3.98995366885453,3.98995366885454]\) 内，改用该档自己的冻结参考后落在 \([9.03018129579680,9.03018129579681]\)。同一来源池的自分母覆盖率 \(U=(1,131/135)\)，反向为 \((1252/1485,151/165)\)。
- 二维例含两组互相垂直的正宽薄柱，提名接收区交面积为 \(1/64\)。在同一严格高度带取四块不交接收核心。在 \(33/32\) 倍扩张下，跨档两件的定向覆盖率为 \(1\) 和 \(11/16\)。这些计算核验有限几何和条件律。
- 用 Python 3.12.14 独立运行包内 replay842.py 与 strips842.py。归档保留精确输入、运行输出和逐文件 SHA-256。
