# 第3轮：时钟势恒等式与格点费用障碍（2026-10-07）

## 目标、假设与证明状态

目标为任意 L1 输入的中心立方体一致上界 sqrt(n) n^{o(1)}。本轮尚未闭合该目标或 geom/R_angle；保留一般 O(n log n) 上界。

完整证明保存在包内 Markdown 和 LaTeX TXT。在完整正来源、原连续窗口及 Lebesgue 接收端下，时钟势 Ψ 的归一化导数为 −Γ/质量；有限整组时钟给出合并下降量及带符号费用预算。齐次时钟必须区分阈值平台处的左右导数；无界停止仍需终端和可积性条件。单个受保护标签的归一化势在合并时可上升，只有条件平均下降。

完整整数格点模型证明固定共捕获图正费用为 Θ(n)。在不合并、不移动的合法原子时钟以及每个闭立方体至多一个存活原子的终端条件下，正 Γ 运行费用亦有线性下界。该结论只否定相应正费用策略，不是原极大算子弱型常数的线性下界。证明见 lattice_profile_clock_obstruction 和 adaptive_atomic_clock_count_audit；后者保留不等权版本。
