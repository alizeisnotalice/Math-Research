# 第696轮　首次捕获来源的根阶部分分配

第696轮用乘积三角密度构造了从真实接收点到首次捕获来源的部分质量分配。每个来源同时承担所有相关接收点，费用由其装填价值乘以根号维数控制。每个来源可以选择一个共同的平移方向，尺度分离时还可增大分配权重。

纯根阶定理仍待证明。剩余的是所有坏接收区域中尚未分配的实际质量。需要用同一组方向将其控制在 εV+C√nD，其中 ε<1。中心平均在一个真实高维族上遗漏几乎全部坏质量，共同方向修正能支付该族全部坏质量。

双机在54个一维网格上对中心平均和固定宽度的方向分配作有理数核验。方向实验支付了各例坏质量的99.64%至99.82%，该范围仅对应所测输入。另以有理级数和768位Arb核验积分常数，并复核5个维度的构造参数。两份 LaTeX 证明均已独审。
