# 第649轮：真实所有权加权中心矩与完整传播原型

一般 `n^(1/2+o(1))` 一致弱型上界仍未闭合。本轮保持同一全族覆盖和实际来源路线。

## 经独审的结果

- 正状态 `H=(1+kappa) eps sum v_j h_j` 有真实全族终端阈值，临界带内 `0<=H<=4M`。
- 真实归一化后 `H_next=eps sum p_j h'_j`，直接沿用实际所有权，消除原先单独的alpha/lambda换权和随机归一化分母。
- 统一选择最小化 `u_j B(u_j) r_j^2` 的合法来源分配，得到任意增长的旧来源传播原型，完整保留带符号的增长、填补和丢失拷贝。
- 单独Young/Cauchy吸收只在放松标量模型中就需要O(n)倍旧增长，不能用它声称根阶闭合；未将该标量必要性外推到真实方体几何。

## 剩余缺口

实际新来源条件均值与旧来源原型之间的差量，必须与同一次动作的丢失拷贝和增长相关联合支付。本轮已明确其完整对象，但没有得到可求和真实递推或一般上界。新分配分支不同时调用旧未加权最优性、二次交换强制性或旧reload拆分。
