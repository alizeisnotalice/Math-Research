# 第620轮：真实分源树全账与联合阈值核验

日期：2026-10-28。一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮没有新的统一维数上界。

已独审的结构：真实分源必须保持原始阈值；完整树中的接收体积只首次失付一次，来源质量只支付一次，深节点使用实际剩余 slack。高来源平均分支的收缩及与同一完整 barrier 来源连接的条件、吸收分母均已核。共同随机网格可控制实际边界损失，最大 antichain 可一次支付来源，但尚缺递推收缩和终端。

计算改变的决策：一次自由分源成功不自动延续为低损耗坐标树。12个既有混合尺度来源的24棵完整坐标树全部通过独立整数/有理复核；首次损失约34.8%–86.9%。12个浮点分源解中11个取得严格有限可行证书，1个仍有约3.26e-8阈值缺口，未认证。现有完整输入均不满足简化最优树DP的严格质量条件，因此未启动该重计算；另一个精确同barrier例子说明有限星面切点最优不能替代连续切点最优。

这些均不是一般根阶证明。剩余关键问题是全树存活比例或可求和切割费用的统一根阶预算，以及共同网格最大单元的粗尺度终端。原母账没有因此自动闭合。
