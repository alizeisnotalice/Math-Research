# 第797轮　两端外部来源与实际接收点的共同欠额

在第796轮留下的全部实际停止记录上，本轮同时使用真实接收体积与两端的真实外部来源。给定这两种资源的容量，最少还欠多少有一个精确公式。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、数值笔记和复现材料](research.zip)

**同一位置的接收容量只能用一次。** 一条记录的类型 \(e=(t,u)\) 给出实际终端父 \(t\) 和产生旧交价的小父 \(u\)；\(U\) 是该臂原已选中的接收点。每份记录可以在它的实际 \(U\) 上按勒贝格体积支付，也可以分配到两个父各自在对方见证体外的来源集 \(B_e\)。这些来源都在第770轮的原割所给的同一个 \(X_F\) 内。设 \(\ell=\log(n+2)\)，接收容量密度取 \(L=\sqrt n\,\ell^3\)，来源容量密度取 \(P_c=(n+2)\ell^6\)。任一类型子族 \(\mathcal F\) 在实际 \(U\) 上的密度和为 \(g_{\mathcal F}\)，它能动用的外部来源并为 \(H_{\mathcal F}\)。扣掉前置的大源盒费用后，最小未付量恰为

\[
\Delta=\max_{\mathcal F}\left\{\int (g_{\mathcal F}(U)-L)_+\,dU-P_c\mu(H_{\mathcal F})\right\}.
\]

空族给零。在任一最大欠额型族上，未付记录只出现在 \(g_{\mathcal F}>L\) 的真实接收位置。证明在每个接收点给原记录分配体积，在每个源点把容量分给能真正使用它的类型，再用有限维对偶同时结算全部体积档。无需假设同一小父内的接收密度为常数。

**同一来源被多批使用时能控制什么。** 在最大欠额子流的两端，分别从该父的实际外部来源选一个点。给定一端的来源点及体积档 \(D\le m_i<2D\)，把所有批次在每个真源点上的非负负载相加成 \(g\)。在共同保留下的记录上，隐父 \(A_i\) 捕获这些负载的条件期望至多

\[
\gamma_n\int g\,d\mu+\int_0^{\gamma_n\theta D}g^\downarrow(a)\,da .
\]

其中 \(g^\downarrow\) 按真实 \(\mu\) 递减排列，\(r=\lceil\sqrt n\,\ell^2\rceil\)、\(\theta=e^{-r/8}\)、\(\gamma_n=512e^{-\tau/8}\)，\(\tau=r\sqrt{\log(n)/n}/8192\)。高负载的来源按总重数进入最后一项。证明在远距离使用所有实际接收者所在的两个方体的交体积，在近距离使用真实来源的反集中。两个端点各用自己的条件分布，两条界作用于同一份剩余记录。

**回到原峰的费用。** 写 \(V\) 为不交接收所有者的总体积，\(S=\|f\|_1/\lambda\)。同一原根测度分解为 \(R_{796}=P_{\rm paid}+R_{797}\)，其中

\[
|P_{\rm paid}|\le |R_{796}|/128+C\big(\sqrt n\,\ell^3 V+(n+2)\ell^8 S\big).
\]

第772轮峰不等式中的余项系数只增加至上一轮的 \(128/127\) 倍。用原小父的旧交价换序，超过接收阈值的源点占该小父来源份额至多 \(\ell^5/(n+2)\) 的各列，可以一次按 \(C\sqrt n\,\ell^3V\) 控制。其余列中，多个大父可能在同一真实旧交价高重叠，并到达同一批超载接收位置。尚缺这个联合量相对共同外源容量的可积上界。新外部来源的条件估计不能直接移用到旧交价上。

**本机检验。** 三套独立 Python 3.12.14 脚本使用有理算术，分别检验精确欠额、实际小父的分配、两维来源上的共同选择。在一维模型中，每端扣除对端 \(1/64\) 相对膨胀区后，初探、压力、扩大三例的实际欠额为 \(53/524288,\ 3/131072,\ 3255/8388608\)。最大流与等值割一致，三例在旧交集内的来源付款均为零。首例若在小父内重新抽接收点会误报欠额为零。二维扩大例中，六个公开划分的最佳得分为 \(329/556\)，允许看到隐父后分别选择则为 \(109923/169024\)。这些数值针对归档中的低维输入及诊断阈值。可在解包目录对三个脚本分别执行 `python -B 脚本名.py --check 同名证书.json`；详细命令在包内。
