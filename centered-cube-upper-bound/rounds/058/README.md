## 严格结果与路线判断

令q=e^{-1}、c=1−q、u=n log L，真实相邻方体平均D_u=A_{exp(1/n)L}−A_L的单原子时间核为K_v(u)=e^{-u}(q 1{u≥log v−1}−1{u≥log v})，v=(2||x−y||∞)^n。本轮证明其Hilbert时间距离精确为：当v≤w≤ev，范数平方为v^{-2}−w^{-2}；当w≥ev，为c(v^{-2}+e w^{-2})。

对任意正有限来源μ及其原好集合G={Mμ≤H}，证明一般单尺度双测度估计

    ||A_L(gμ)||²_{L²(G dx)} ≤ H||g||²_{L²(μ)},
    ||D_L(gμ)||²_{L²(G dx)} ≤ 4c²H||g||²_{L²(μ)}。

这是维数无损的单尺度接口，但直接时间积分仍付窗口长度n log2。缺少共同尺度的符号消去预算，尚不能用第57轮尖锐L²常数直接闭合。
