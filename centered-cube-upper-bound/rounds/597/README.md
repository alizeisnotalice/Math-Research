# 第597轮：临界亏损与完整接收集遮蔽

一般 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮的共同分割、临界相关和来源进入面尝试均未取得新的全局预算。以下精确证书用于决定后续联合估计必须保留哪些几何信息，不计为维数阶改善。

## 目标与实际缺口

继续R596的完整外部接收集 Aθ，θ=1/4。所需下界仍是 λ|Aθ|≥η_n λ|E|−L_nW，其中 L_n/η_n 为根阶多对数，统一于全部输入与尺度。R596近极值上价及其指数误差系数保持完整；没有在有限亏损下删除该系数。

共同内部dyadic分割使来源只计一次，却没有递推收缩；搬移见证还留下中间尺度与完整遮蔽。固定负背景的实际critical集合上，孔洞收益仍须与同一集合的临界亏损联合估计，正的无阈值通量不能替代接收。来源进入面分配后，累计捕获质量并不归于最后进入来源；一次Tonelli粗界出现来源熵且只是上界，没有正部下界。报告保留这些确切失败点，不宣称它们否定原目标。

## 经核验的有限几何证据

两个二维九单位来源模型：{0,1,2}²与{(i,i):0≤i≤8}。完整511非空子集逐一核验后，两者全接收集面积均21−8√2，q均(21−8√2)/9。

在中心(2.75,1.49)与(7.75,7.44)、边长1.5处，均捕获质量2，但完整接收集交面积分别9/4−√2与519/200−√2，使真实接收余量一正一负。所有来源进入尺度逐一检验后，前者接收、后者任何尺度均不接收；各中心半边长10⁻⁵的整小盒也由严格区间界认证。来源质量与尺度的单独检验无法区分这两个真实几何状态。

固定接收点时，来源进入事件之间的余量严格下降，所以全部尺度检查化为有限实际进入事件；所有并列来源同时进入，r趋零的零极限保留。此结论消除尺度抽样误差，不消除空间几何问题。
