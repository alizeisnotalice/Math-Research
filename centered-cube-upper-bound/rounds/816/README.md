# 第816轮　同源三处真实接收与第三个方体的交体积削减

依11月23日的指导，优先估计一般正输入在共同尺度窗 \([1,2]\) 上的弱型常数 \(B_n\)，目标是 \(B_n=o(n)\)。最终目标仍为全尺度 \(C_n\le K\sqrt n\)。第815轮处理了按来源局域化后坐标字典较小的输入。本轮直接在任意有限正测度的实际超水平集上工作。

**已证的一般几何估计。** 单窗内取三个真实见证 \(Q_-,Q_x,Q_+\)。在总代价至多 \(C\sqrt n\,\|\mu\|\) 后，余下的三元记录有同一个实际来源 \(p\)，且对任意不同的 \(i,j\) 有

\[
 |Q_i\cap Q_j|\le 2^{-n/1024}\min(|Q_i|,|Q_j|),\qquad
 |Q_-\cap Q_x\cap Q_+|\le 2^{-n/1024}|Q_i\cap Q_j|.
\]

在全尺度，付同阶费用后可取两端边长比至多 \(R=\max(2,n^{1/4})\)，并把上述两式的指数取为 \(n/(512R)\)。每个第三盒用一组自身坐标削减前两盒的实际交。证明在给定原来源和三份体积档后，以方体乘积测度支配实际三点联合测度。完整原超水平集的显式不等式见报告式 (19) 和 (20)。

**实接收分配。** 在固定阈值 \(\lambda\) 上取每个成功中心 \(x\) 的最右越阈尺度 \(t_x\)，令 \(v_x=t_x^n\)，故 \(\mu(Q_{t_x}(x))=\lambda v_x\)。单窗中最大尺度已达到阈值的体积先付一次 \(\|\mu\|\)。给定任意原接收子集 \(F\)，对每个来源 \(p\) 把捕获它的真实接收点按见证体积排序。取 \(T=\sqrt n\)，用实际接收测度 \(1_{\{p\in Q_{t_x}(x)\}}dx/v_x\) 同时给中央点分配一个较小和一个较大的接收者。三处都包含同一个 \(p\)，相邻体积相差超过 \(e^{\sqrt n}\) 倍。

三个勒贝格边际分别至多为 \(\lambda1_F\,dx\)。除去总代价至多 \((8\sqrt n+8)\|\mu\|\) 的中心，中央边际至少为 \(\lambda\,dx/2\)。任意两处接收点的联合密度上界为其方体的实际共同来源质量除以 \(\sqrt n\,v_bv_c\)。三处的联合密度上界为其实际共同来源质量除以 \(n\,v_xv_-v_+\)。

记 \(L_p(F)=\int_F1_{\{p\in Q_{t_x}(x)\}}dx/v_x\)。本轮付掉的累计秩长至多为 \((4\sqrt n+4)\|\mu\|\)，进一步使用坐标几何之前，三处同源耦合的总质量恰为

\[
\int (L_p(F)-4\sqrt n-4)_+\,d\mu(p).
\]

**真实接收集合。** 另可预先为每份来源固定同一个输运去向，再同时产生三个接收者。对来源子集 \(A\)，取实际捕获它且尺度不超过当前末根的全部原接收者。若这份接收体积乘阈值至多为 \(K\mu(A)\)，所有拥有此类来源子集的中心合计可付，总成本 \(K\|\mu\|\)。在角点源族上，这个选择能付掉整个输运后剩余的接收区，而其中一批正体积中心的每个非空来源核在整空间膨胀后，体积质量比都至少为 \((7/4)^n\)。

**实际检验。** 对角点模型的六个维数 \(16,32,64,128,256,512\) 用 Arb 256 位、384 位精度交叉复核。对有理数排秩的六组测试逐项积分核对三边际、两端联合容量和删去的总质量。另对一个非负、分段常数的 \(L^1\) 密度例证明，所有 \(n\ge128\) 的同一单窗内都确有正质量的三处接收分配。另以 17,496 个三盒坐标检验和 27,216 个两盒坐标检验核对实际缩减方向。取 \(n=2^{18}\)，正密度例在三盒薄交筛后仍有正质量。解析例、真实几何与秩测试的范围分别列在报告中。

**尚缺的一步。** 各端的密度上界保留了来源被跨尺度重复使用的次数。还须对同时通过三种薄交条件的记录，估计其中的真实来源总质量，或证明相同质量上的收缩。所得共同标记局域化公式与 Naor–Tao 定理1.1给出的窗口量级一致。第813轮含原父历史的双臂积分也尚缺到这里的有界密度映射。一般单窗次线性和全尺度纯根阶均待证明。[Naor–Tao 原文](https://web.math.princeton.edu/~naor/homepage%20files/HLM.pdf)
