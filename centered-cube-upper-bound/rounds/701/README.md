# 第701轮　按实际半径积分的来源预算

对原首次捕获历史，按来源实际半径积分，结合乘积概率的熵估计，同时控制指定坐标遗漏模式的小尺度贡献。大尺度来源按真实互不相交的接收区域支付；每个来源可另选一个固定有向正交区域，允许所有坐标同时越界。详细定义、证明与完整余项见 research.zip 中的 REPORT.tex。一般输入上仍需控制未落入所选坐标族的小来源及未落入支付区域的大来源之和。

Mac mini 与 MacBook 合计完成 995 个维度的浮点扫描和五维 5,799,465 次精确整数检验；Mac mini 另作 995 个维度的 Arb 核验。范围、命令及实际输出见归档的 NUMERIC.md。
