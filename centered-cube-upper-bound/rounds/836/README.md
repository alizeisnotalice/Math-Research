# 第836轮　多枚真实来源共同约束的接收体积

在第813轮原双臂积分中，每条记录带有实际中父、两枚来源、两侧接收者及完整历史。本轮给中父内的左右两端分别附加 \(k,l\) 个独立真实来源。只要从一端自身观察能够预测这组来源，许多中父、物理窗和绝对尺度就能共用该端一份预算。采样个数任意，估计常数与 \(k,l\) 无关。[详细证明与数值检验笔记](research.zip)

设 \(m_t\) 是中父的真实质量，\(P_\pm\) 是分别能包含本端原来源和新增来源的接收中心的归一化体积，\(\alpha,\gamma\) 是左右端预分配到绝对尺度和样本的密度。已证明
\[
 \int_R \mathbb E_t\sqrt{\frac{m_t^{k+l}\alpha\gamma}{P_-P_+}}
      \le C\mathcal H\sqrt{Y_-Y_+}.
\]
这里 \(Y_\pm\lesssim V\) 是原两臂的接收参考质量，\(\mathcal H=O(1+\sqrt n/\log^2(n+2))\)。固定真实样本后，所有能接收这些样本的中父，其不交接收者必须落进同一个坐标交盒，这给出式中的体积因子。对任意正 \(L^1\) 输入的真实末根，同样的左端为 \(2\sqrt{\|\nu_L\|\|\nu_R\|}\) 所界，对全部绝对尺度共同成立。样本包围盒的实际来源质量还可用来识别尺度档。报告给出何种中父候选分布能支付相应原质量的定量条件。

另在同一价对和绝对档上，用实际门槛中父的质量重估两向来源争用。只要一侧争用中有固定的正比例落在该中父或报告中明确给出的低费用膨胀区域，就能从原账支付该价对的质量。旧的 \(9/32\) 吸收额度没有新增支出。仍需估计两端来源均难以预测、且主要争用候选位于高费用区域的记录。

## 本机验证

- 两份四维档案各230行。在阈值1下，相比均分尺度权重，依据真实本端历史分配权重的覆盖率下界分别从约40.03%、42.68%提高到49.39%、50.09%。阈值降至 \(1/2\) 后，合并成一个宽盒的预测覆盖更多。四维原档不满足高维历史门。
- 两批来源要在同一物理价对、同一档产生双向争用，所占原行质量比例上界分别为 \(5.834\times10^{-5}\)、\(4.882\times10^{-5}\)。报告另给出候补负载的真共父比例。
- 一个四维正密度输入有三个经全未来尺度检验的末根核心。两侧分别采样63和2047个真实点，同时识别所属体积档的比例至少为0.991146；这些核心上每对真实来源的无包含条件期望分数至少为167.4927。报告还记录质量不均衡的两个正宽盒及16至256维的交叉检验。
