# 第840轮　单窗原积分中短距离来源对的跨尺度分摊

在任意给定的真实见证下，按两端所在格子的实际来源质量分摊每一条短边，可以在同一份来源预算内合计所有见证尺度。第839轮留下的整批短距离来源对由此得到次线性上界。重新选取第839轮长对阈值后，短距离部分达到根阶乘一次对数。[完整 LaTeX、计算记录及复现代码](research.zip)

## 估计对象和结果

令 \(I=[1,2]\)，\(E=\{\lambda<M_I\sigma\le2\lambda\}\)，其中 \(\sigma=|f|\,dx\) 是任意有限来源。在 \(E\) 上固定任意共同的严格见证 \(l(x)\)，记 \(A_x=x+l(x)[-1/2,1/2]^n\)。对每个来源割 \(A\) 取 \(\eta=\sigma|_A\)。原积分为

\[
J(A)=\int_E \left[\frac{\eta(A_x)}{l(x)^n}\right]^2 dx .
\]

展开平方后的两枚来源记为 \(z,q\)。对 \(1\le B\le 2n\)，满足 \(\|z-q\|_1\le B\) 的贡献至多为

\[
 C\lambda\min\big\{n+1,\,1+\sqrt{nB\log(e+n/B)}\big\}\,\eta(\mathbb R^n).
\]

该分摊还在每端给出同系数乘实际来源测度的上界。每个格相固定后，格质量在所有中心与尺度共用。在真见证可向外扩张的部分用同一接收点的全窗高度控制格质量，在窗顶直接合计剩下的实际体积档。随机平移的逐坐标乘积恒等式同时适用于任意相关的来源。

在第839轮的原长短阈值 \(b\asymp\sqrt n\log(n+2)\) 下，全部短对贡献不超过 \(C\lambda n^{3/4}\log(n+2)\|\eta\|\)。重新从同一个 \(J(A)\) 取归一化阈值 \(b=1024\log(n+2)\)，全部短对与长对中可删除部分合计不超过 \(C\lambda\sqrt n\log(n+2)\|\eta\|\)。带参核验保留了第839轮严格见证分支的两个同时存活的真实伙伴库。较小阈值产生自己的长对余流。若某维数序列中原割负载至少为 \(c n\|\eta\|\)，则某个 \(\delta(c)>0\) 下距离至少为 \(\delta(c)n\) 倍该档归一边长的稳定长对，仍承担至少 \((c/2)n\|\eta\|\) 的归一原质量。

第829轮已经在真实末根上证明了预报点附近来源的同阶估计。其量级也可用较早见证的窗内高度帽推广到严格见证。本轮直接按格质量分摊，去掉这一字典估计的加性对数费用，并与第839轮的长对余流在同一原积分上合计。[第829轮记录](../829/README.md)

## 本机核验与尚缺的估计

- 正宽一维来源在指定真实接收子区、严格见证 \(l=5/4\) 时，单包割贡献为 \(9/100\)，整份割的贡献为 \(9/25\)。另一个例子在同一物理网格和两个不交接收区核对了同一右来源的跨体积档收费。窗顶部的独立例有 \(A_2=31/32\)，越出窗顶再扩张会纳入质量为 10 的外源。
- 16维正宽盒在固定格相下跨过全部16个坐标边界。随机格相的平均整数位移为 \(1/4\)，位移至多1的概率在 \([0.9746658492782,0.9746658492783]\)。整数位移格数经15组完整枚举核对，代价函数的有理区间计算最大维数为 \(2^{24}\)。取实际归档的位移门和 \(0<\theta\le1/4\)，在这一最高维数算得 \((n\theta+\log K_n)/n\) 的最小值介于 \(0.384384\) 与 \(0.400012\) 之间。该数值仅对应此有限参数优化。
- 解压后运行本机独立 Python 3.12.14 的命令 `python -B replay840.py`。输出、输入归档哈希和成员哈希均随包保存。
