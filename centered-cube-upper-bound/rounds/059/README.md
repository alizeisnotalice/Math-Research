## 一般来源的严格进展

令W=Σ_i p_i、c=1−e⁻¹、h=Σ_i(p_i/W)log(W/p_i)。对任意有限正原子来源μ、原好集合G={Mμ≤H}，令v_i=(2||x−y_i||∞)^n，F_x为真实累计捕获质量。全尺度能量可精确写成各到达批次的带符号差：

    Σ批次 P/v² [F(v−)+F(v)−e F(v/e−)−e⁻¹ F(ev)]。

审计发现不同立方体原子可在正测度接收区域同时到达，必须保留整批质量T_i=Σ_{j:v_j=v_i}p_j。误用单原子p_i的公式被真实二维两原子反例否定，显式好矩形上的遗漏积分为19/20736。

对来源中心伸缩S_i^±x=y_i+e^{±1/n}(x−y_i)作换元，得到保留T_i与移动cap的双向输运恒等式，并证明所有项绝对可积。单原子表明边长伸缩接近1仍有cHW的cap边界费用，不能由“小位移”忽略。

同时证明固定n、有限N、正权重和H时，完整cap能量随来源位置连续。故可先对每个坐标上原子位置互异的来源证明统一完整能量界，再无损传回全部有限来源；中间并列费用本身不连续，不能逐项免费传极限。一般位置下T_i=p_i几乎处处，可合法使用HW对角预算，但其余跨尺度费用仍待支付。此归约并未证明所需统一界。

还保留带来源熵的有效上界cHW(1+2h)，以及点能量检查界H²[1+2log(W/p_min)]。两者均有明确来源复杂度依赖，未被当成维数一致结果。
