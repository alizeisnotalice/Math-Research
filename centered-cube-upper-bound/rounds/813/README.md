# 第813轮　同一来源的双接收与中父位置、对端真价的联合几何

在第812轮剩余的原路径上，固定一条完整小臂及中父体积档。记 \(G\) 为中父中心的物理格标，\(P\) 为另一枚真实来源点的格标。**即使看见整条路径以后，两侧各改动 \(c\sqrt n\) 个坐标，任何质量超过本轮预算的余流仍须在 \(G,P\) 之间保留至少 \(c'\sqrt n\log(n+2)\) 的平均条件互信息。** 这里 \(c,c'>0\) 为绝对常数，\(n\) 充分大。估计同时合计所有中父、物理尺度、两端真实来源和原勒贝格接收者。[详细证明、数值笔记及复现证书](research.zip)

**实际可付的原质量。** 令 \(\Gamma\) 为任一正子流，\(Y\le C V\) 为原父历史质量，\(V\) 为不交接收总体积，\(N=n+2,\ L=\sqrt n\log^3N\)，\(\mathcal H=O(1+\sqrt n/\log^2N)\)。取原长跳参数 \(b_0\asymp\sqrt n\log N\)。如果两端各改动至多 \(\lfloor b_0/(1024\log N)\rfloor\) 个坐标之后，在该子流自己的真实条件律下，平均互信息至多 \(b_0/64\)（自然对数），则
\[
 |\Gamma|\le C\frac{\mathcal H N^2}{L}\exp(-b_0/32)\,Y .
\]
证明使用同一中父的不交接收体积。长跳使两枚真价共用的接收交盒具有指数折扣。另一方面，同一中心格对应的全部可能对端价格格，都落在某个真实服务中心的轻微扩张方体内，因而它们的真实来源总量有上界。原联合律必在这一相容关系上。改动坐标会损失多少信息，可由每个改后向量的可能原像数计清。

**分开两个接收位置。** 同一真价上的一份来源预算可分配到中父和小父各自的接收位置，每个位置在全空间各用一次勒贝格容量。来源分母取实际三父交质量。两处命中的原质量门、低载源行及来源格菜单，连同旧费用合计仍满足第772轮原账，吸收系数保持 \(\delta_0<1\)。需要的方体强型估计使用固定指数 \(p>1\)。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

**本机验证。** 六份结果使用 Python 3.12.14、有理算术、SciPy/HiGHS 和 192、384 位 Arb。二维至四维连续梳状例中，按实际价格、完整小臂和中父体积档计算，互信息分别约为 \(0.01889,0.04409,0.01632\) 比特。三例均可通过恰当固定擦除一轴把互信息降到精确的零。这些低维例未施加高维长跳和全部近极值条件。四维跨档例在同一接收预算下，同一点兼中两父的最优值为零，双位置可行方案在诊断门 \(D=512\) 支付了 \(2.35969\%\) 的原质量。两项运输检验分别保存了有理原对偶界和精确最优证书。

**剩余缺口。** 薄交来源可被许多中父反复使用，同时与对端真价保持上述强相关。对这种余流的一般质量上界仍缺。若能证明其总量至多 \(C(\sqrt n\log^\alpha(N)V+n\log^\beta(N)S)\)，其中 \(S=\|f\|_1/\lambda_0\)，就能由原账恢复一般带固定对数损失的根阶上界。纯根阶还需控制最终对数费用。
