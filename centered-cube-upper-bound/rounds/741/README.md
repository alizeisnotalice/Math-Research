# 第741轮　多个真实去向共用首次越阈来源预算

在第739轮删减全部完成后的同一份接收测度 \(\mu=H\,dx\) 上，证明了一项可以分配到原来源的根阶估计。出发点 \(x\) 使用它的真实首次越阈来源池 \(S_x\)。若同池来源在目标父方体的某片区域有累计权重至少 \(n^{-\sigma}\)，用该区域占目标父方体的体积分数衡量这次到达。按原配对求期望，把所有目标一起计入，再对步数取上确界，记为 \(G_{S_x}(x)\)。这里 \(0\le\sigma<1/2\)，计算各步期望时保留出发点自己的来源池。来源父方体在这项测试中扩张 \(1+2/n\)，费用仍按原体积 \(d_i\) 支付。

对任意固定 \(B>0\)、任一组出发点 \(W\)，令 \(b(x)=\min(1,n^{2B}G_{S_x}(x)^2)\)。本轮证明

\[
\int_W b(x) H(x)\,dx
  \le K_{B,\sigma,c}\sqrt n
       \sum_{i\in\bigcup_{x\in W}S_x}\theta_i d_i .
\]

因此可以把已付接收质量逐份分给各自首次越阈池中的来源。每个原来源跨目标、尺度和观察步数合计支付一次。证明用真实所有者上的空间积分、固定指数的方体强型估计、原配对的可逆性和有限最大流。对两端应用时总费用至多加倍。对共享同一见证位置的来源族，还给出可以使用更低覆盖阈值的估计。

**完整总账。** 冻结的原关联测度记为 \(d\Lambda\)，实际配对为 \(x\leftrightarrow y\)。令 \(l_i(x)\) 为未触发小位移、低接收度和共同来源筛选时尚未支付的比例 \(1-b(x)\)，任一筛选已付时取零。得到

\[
M\le(1/8+2n^{-1/4})V_T+C\sqrt nD+R_{741},
\qquad R_{741}=\int l_i(x)l_i(y)\,d\Lambda .
\]

在充分大的维数，本轮已用接收系数至多为 \(5/32\)。第706、739轮的原账目给 \(M\) 留出 \(9/32\)。因此尚须把 \(R_{741}\) 控制在 \(\eta V_T+K\sqrt n\log^A(n+2)D\)，其中固定 \(\eta<1/8\)。两端在所有步数上的联合覆盖都很稀薄时，该项的统一界仍未得到。

**真实历史检验。** 一个 \(n=64\) 的真实贪心历史只有一个高损失来源，同时供给半径 \(1/2\) 和 \(3/4\) 的接收者。有理数证书给出 \(M>0.96237V_T\)，两种半径各自均保留超过 \(0.46237V_T\)。本轮覆盖条件在该例可以支付全部保留质量。这个例子取极小的固定 \(c\)，结论限于该维数。另在 \(n=256,1024,4096\) 的三份双来源双尺度历史核对了 \(M=0\)，并以第710轮的薄交集构造核对覆盖条件的边界。
