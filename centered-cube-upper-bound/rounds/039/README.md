# 第39轮：共同来源重叠核与局部质量配对

日期：2026-10-10。一般中心立方体 sqrt(n)n^{o(1)} 弱型上界仍未证明；保留的一般全尺度上界为 O(n log n)。

本轮证明精确的共同来源方体重叠公式、正向 Bessel 合同，以及同时保留真实均值带和接收点时间长度的反向 Schur 界。分别核对正向合成、完整反向和接收点选择三个算子，避免将一个方向的谱界误用到另一个方向。

构造满足同一阈值、早期首次进入和真实短峰值条件的异质量来源，严格否定全局谱范数与全部倒体积权重相乘的 O(T) 预算：在有限倍尺度窗口中，该乘积指数增长，实际指定阈值的水平集费用仍为1。按来源块匹配能修复这个反例；任意来源所需的正分解、捕获下界、未归属接收点费用及总配对预算尚未证明。报告中的局部分块回代仅是条件引理。
