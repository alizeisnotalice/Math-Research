# 第743轮　不同方体共用见证时的来源总费用

固定第742轮未付的真实配对，沿用每个接收点原来的首次越阈池 \(L(x)\) 和共同见证。取固定 \(0<\zeta\le1/4\)、\(c\ge64e^{1/32}/\zeta\)，令 \(t=c\sqrt n\)。本轮证明了两批关联的联合估计，均未增加接收体积的吸收系数。

**方体内部的见证群。** 在每个配对来源 \(A_i\) 内部，可按实际输入放置任意有限族内部不交的小方体，中心作为见证位置，半径可各不相同。若原池中半径不超过某个小方体半径、且其原父方体内部含有该中心的次级来源权重之和达到 \(\zeta\)，该关联可以支付。固定次级来源 \(k\)，其中心 \(y_k\) 在每个相关的 \(A_i\) 内最多落入一个小方体。这些 \(A_i\) 又共同含有 \(y_k\)，故其原权重总和至多为一。结合第721轮固定见证估计，所有来源、所有群在同一端合计只花费 \(C_\zeta e^{-14\sqrt n}D\)。正文给出了允许共享原子测度和分数分配的形式。

**方体边界的全部顶点。** 若 \(L(x)\) 中半径 \(s_k\le s_i/2\) 且共同包含某一顶点的来源权重达到 \(\zeta\)，所有 \(A_i\) 的全部 \(2^n\) 个顶点可同时计算。同一个 \(k\) 在这些顶点上的加权出现次数为 \(O(1/t)\)。证明固定 \(k\)，按相对半径把真实所有者放回各符号对应的方体，再对所有半径和所有符号求和。单端合计费用为 \(C_\zeta t^{-1}e^{-14\sqrt n}D\)。

**为什么要选取实际位置。** 对每个真实接收点，把空间位置 \(z\) 和来源体积上限 \(v\) 按 \(dz\,dv/v^2\) 积分。即使允许来源各轴扩张 \(1+1/\sqrt n\)，共同权重达到 \(\delta\ge e^{-C\sqrt n}\) 的位置与尺度的测度仍至多为 \(\exp[-\tfrac12n\log n+O_{C,c}(n)]\)。这个逐行证明允许任意来源体积跨度。因此以 \(e^{-8\sqrt n}\) 为全额支付门槛的连续抽样方案对充分大维数的每一行都失效。上述两项证明直接选取离散位置。

**回代与未付范围。** 将任一端命中的关联从第742轮所用的同一配对测度扣除，余量为 \(R_{743}\)。两个端点合计给出

\[
0\le R_{742}-R_{743}\le 2C_\zeta(1+O(1/t))e^{-14\sqrt n}D,\qquad
M\le (1/8+2n^{-1/4})V_T+C\sqrt nD+R_{743}.
\]

当见证群靠得很近、各群调用的来源又不相同，仍缺少覆盖其全部接收质量的分配。边界处 \(s_k>s_i/2\) 的贡献若未被内部分配支付，也保留在 \(R_{743}\) 中。一般上界仍须证明 \(R_{743}\le\eta V_T+K\sqrt n\log^A(n+2)D\)，其中固定 \(\eta<1/8\)。

**真实历史检验。** 在第741轮的64维双尺度历史上，将第741、742轮可选参数都固定为 \(B=1/2\)。有理数界给出 \(R_{742}>0.68280V_T\)。同一来源的中心见证支付了这笔正余量，\(R_{743}=0\)。这份历史的 \(c\) 很小，实际有限费用由 \(V_T<118\sqrt{64}D\) 直接核验。另在固定 \(c=512\) 的真实贪心族中，核验了 \(n=6,24,96,384\) 与半径比 \(3/2,2,3\) 的12组顶点计数。在比率 \(3/2\) 时，单用顶点出现次数会产生 \((4/3)^n\) 级费用；这些历史的坏接收量为零。复现包还给出四组分配的有理数双向核算，以及最高4096维的256位 Arb 体积检验。
