## 已证明的推进

沿原已审 R224、R276—278 的核、FIRST、高层、来源和完整后验，令 κ=25/2^68，c=κ/432，R₂(y,v)=Σmin(|y_i−v_i|²/b²,1)，B_c=18exp(4c)/c。结合概率均值/方差产生的 Hellinger 距离损失、源软尾和 exact-min 共窗界，证明一维归一核心半核 D≤exp[−c(s+min(r²,1))]。目标软度可独立于源软度。

保实际 near 窗口后，固定参数半核质量≤exp[B_c−(c/2)(ns+R₂)]。对原两移动认证事件的并集，实际门 ns+R₂≥1+(2/c)(B_c+T) 的交通≤(64Λ/3)e^(5/2)√K n³(n+1)e^(−T)Wβ，其中 Λ=128/119。全软度、配对尺度菜单、原后验、原 dx 和全部 j 时钟费用已明列。

取 T=log_+[(64Λ/3)e^(5/2)√K n³(n+1)/ε]，本分支≤εWβ。结合第277轮已付的 J 认证子集，当前余域满足 ns+R₂<1+36e^(4c)/c²+(2/c)T。固定K、ε时为 C₀+C₁log(n+2)。常数极大，有限维付款门可能为空；不声称覆盖固定比例或新增 FULL 非空示例。

该限制消除仅用 Delta_L 时的饱和平台。R₂是截断平方位移：至多R₂个坐标的距离≥b，其余坐标平方距离之和≤b²R₂；大距离坐标的具体距离仍不受控。也不控制坏槽u。

余域内真实接收、共同来源、终端权重与完整好/坏槽之间的联合预算仍未付；没有一般根阶闭合。保留原三目标Q、全部历史和独立ν≤fdx，绝不推断ν≤β。
