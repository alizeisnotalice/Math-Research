# 第687轮：方体投影与跨历史联合退款

一般任意 L1、全尺度、勒贝格接收测度下的根阶上界仍未闭合，本轮没有新的统一上界。

本轮已证明并独审：共同锚点的逐坐标投影同时判定来源父与目标父的相交；真实历史锚点为严格内点，因此还有正体积相交与本质上确界的精确版本。对任何可行 packing，按目标场在每个旧父方体内的本质最大值删除旧系数，再加入目标系数，得到共同可行交换及准确费用。

决定后续方向的实际历史结论：在原 q/tau 基准上，任何只支持一个历史组的目标交换都没有正收益。单组内删除费用线性，真正的批量节省必须来自不同历史组，或先重新分配基准。有限三正方形证书给出了单次收益均为0、联合收益为1/2的实例，但不是原高阈值历史的闭合证明。

完整剩余量满足已核验的费用关系 `tau V <= sum mu_i m_i + L Delta`；其中 `Delta=tau P0-U`，`m_i` 是完整来源父上的本质最大值。右侧的统一几何预算仍未证明，不能把写出费用等同于支付费用。
