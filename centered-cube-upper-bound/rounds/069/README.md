# 第69轮：好集能量的完整弱型回代与单阈值归约

2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**，保留全一般 O(n log n) 基准。

- 闭合条件性返回链：若任意有限正原子的全局好集能量至多 K_n HW，则 C_n ≤ C[1+sqrt(n log(n+2)K_n)]。高全局极大值例外保留后在范数层面吸收；Naor–Tao 使用尺度比 max(n,2) 的实际窗口。
- 另证带上端扩展区间的局部返回链。二叉森林重分配显式处理无局部屏蔽的小块及粗根来源，完整有符号误差至多 2(1+e)HW，不依赖窗口长度、原子数和深度。
- 缺失的指示函数估计只需在单个阈值 delta_n=(4n²)^(-n) 成立。有限矩形并在 rho<1 时还有严格的原子能量反向传递；不声称一般 L1 好集能量随逼近收敛。
- 给出两个分离原子的解析能量公式，严格否定“单原子是能量最坏情形”的强归约；不否定较大的常数或次幂预算。
