# 第297轮：自身尺度付款与真实接收点的共同覆盖构造

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮从第296轮的条件覆盖接口进一步构造可付款的原交通部分：一条按来源块自身尺度直接积分，另一条实际构造受控体积的共同覆盖，并证明它支配哪些原交通。保留原完整e_g、m、q、所有来源/历史条件及真实接收测度。记ell=1+log n、gamma=1+1/n、G=gamma^(n/2)、q_-=3lambda/4。以下均为raw low费用，原外因子Lambda另乘一次，其他outer账目仍须单独核算。

## 1. 按来源块自己的尺度付款，消除人为体积损失

对每个软来源y固定合法尺度r(y)及来源对权重omega(y,z)，仅分配实际L,R≥r(y)的原low、m>M交通。记

    C_r(y)=∫omega(y,z)nu(dz)/(q_-r(y)^n)，kappa0=2K/(ell M)。

直接积分真实硬尺度包络得到

    T_(r,omega)≤kappa0∫C_r(y)Psi_G((b/r(y))^n)beta(dy)，
    Psi_G≤3−2/(3gamma^n)≤3−2/(3e)<2.754748。

大软尺度方向的常数还能取2。任意非恒定r(y)在同一个来源积分中处理，无逐窗口重复W_nu费用。合法accepted receiver自身尺度立方体供应C_r≤16/3，故不再出现(r/a)^n的归一化损失。

稿中给出可测来源分区、有限witness菜单的最小半径分配和确切剩余掩码。多个块在同一行的归一化质量必须实际相加；不声称任意多块免费。低于所选witness尺度的交通及未被覆盖的来源保留在补集中。

## 2. 实际构造预算内覆盖，并证明交通支配

固定整个原接收场。令U_y(x)是原接收权重p_y/q乘合法行资格，Z_y=∫U_y dx。零行单独处理，其余行定义

    pi_y(dx)=U_y(x)dx/Z_y，
    P(y,z)=∫(a/R(x))^n 1_(Q_R(x))(z)pi_y(dx)∈[0,1]。

对任意H≥0，以强度(e^H/4)(a/R)^n pi_y抽取真实accepted receiver立方体。总归一化体积的期望恰为e^H/4；只保留总体积≤e^H的配置，对其来源并集指示函数取平均，得到显式可测分配omega_H。

证明了两项同时成立的性质：

    ∫omega_H(y,z)nu(dz)≤(16/3)q_-a^n e^H，
    P(y,z)≥4log(4)e^(−H)  ⇒  omega_H(y,z)≥1/2。

第二项是真实的交通支配，不是把平均覆盖宣称为完整覆盖。结合第296轮行容量预算，捕获达到此阈值的原low、m>M交通可付

    2[1+(4/3)log_+((64/9)kappa_*e^H)](W_beta+W_nu)，
    kappa_*=2K gamma^(n/2)/(ell M)。

因此当H与log_+kappa_*均有根阶多对数上界时，可对该明确原交通部分得到相应线性预算。共同软度包络费用只用于证明Z_y有限，不进入规范化捕获阈值。

这份分配可以由固定整场计算，但在实际接收变量积分时是同一个来源对函数；证明重新核验了这种依赖的合法性。外部clock/seed的费用仍在原账目中，未声称跨clock自动只付一次。

## 3. 合并后的确切账目

先用第296轮远尾定理付epsilon W_beta，再分配自身尺度可付部分，然后用共同覆盖付高捕获部分。三个分配按原掩码顺序分开，得到

    原low、m>M交通
      ≤epsilon W_beta + 自身尺度归一行费用
        + 上述高捕获双来源预算 + R_weak。

R_weak明确保留：近距离、未被自身尺度分配支付、且规范化捕获低于阈值的原交通。已有乘积质量上界仍含W_beta W_nu/(q_-a^n)，不足以给一般根阶预算；没有因阈值指数小就把这笔费用删掉。

自身尺度分支可处理仅因(a/R)^n造成小捕获值的部分交通，避免把这种纯归一化损失都留给覆盖；尚未证明两条机制覆盖所有原交通。

## 4. 审查与本机计算

独审先独立推导命题及边界，再读取三份证明和合并账目。主代理实际复跑本机Python/Fraction/Decimal/mpmath代码。

- 三阶段尺度检查：72个来源模型，1296次保留尺度高度与1296次门槛排除、6480次pair高度、288个row-cap、288个独立空间包络及72次aggregate账。主要不等式先以Fraction精确核验，维数至10000。
- 另核验27个四次方体积的较尖锐包络；作者嵌入代码经提取复跑，28个积分比较和240个原带高度比较通过，维数至1000000。
- Poisson覆盖：21个案例、29678个预算内count配置，40/60位比较；检查丢弃概率、捕获下界、来源预算及高捕获交通支配。包括零行、无人捕获、重叠、阈值两侧和真正一维闭立方体边界。
- 两份主JSON均经重复运行一致，主代理复跑吻合。普通高精度求积不是区间证书，抽象有限矩阵不被称为完整高维软核实例。

复现：解压research.zip，在安装mpmath 1.3.0的Python中运行checks.py、scale_checks.py、poisson_checks.py。归档保留详细证明、LaTeX文本、审计与必要计算材料，不编译PDF。
