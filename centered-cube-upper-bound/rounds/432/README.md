# 第432轮：近整父尺度排斥与双来源局部质量—距离预算

一般一致 n^(1/2+o(1)) 上界仍未闭合。本轮在第431轮同一原流及已审 sourcewise 合同下得到两项几何预算：

- 采用 g(t)=t/(1+½log t)²，自适应邻域跨全部父质量尾的积分容量为2rs；实际 proper 节点至少一次命中支的价格为2Ω_cf W。
- 保留两来源的父中心交集，证明局部质量归一的距离指数矩；高指标支价格为 S s(1+ε_0)²Θ(M)²W。

两支顺序、不交付款，新增总价为 O(√n log²(n+2))W，无新增X_q。补集具有全部proper节点近整父尺度排斥及低联合距离—质量指标，但其一般预算仍未证明；未覆盖初始、全尺度和最终吸收等其他缺口。
