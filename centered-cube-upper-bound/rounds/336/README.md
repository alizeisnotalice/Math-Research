# 第336轮：真实近质量硬层付款与逆向补集

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮得到直接针对原hard积分、真实接收dx的一般分支预算。

证明sharp接收包络 C_K=(1+2logK)/q_-，据此整个质量可比分支可付 δXq+λ(1+2logK)W/(q_-δ)，包括饱和等质量情形。再证明小质量捕获端→大质量漏失端的费用为 δXq+λW/(Kq_-δ)。两者联合给出完整原槽估计：

`B_H ≤ B_rev + εXq + [2λ/(q_-ε)](1+2logK+1/K)W`。

B_rev明确是原正pair积分中 m_u>K m_v 的大质量捕获→小质量漏失部分。取K=exp(√n)，其余全部pair已有O_ε(√n)来源预算；没有删去逆向补集、原H入口、其他尺度或时间项。该直接证明不另加槽内λH完成费。接收包络使用真实du，不是假设任意来源有密度帽。

辅助四型来源交换给出质量最小面内的可行方向及完整高门费用；真实有限接收例上保均值、保总质量而Q下降超过1/50。有限交换仍不自动覆盖连续接收场。

主代理本机实际运行：接收包络358项精确+60项普通Decimal；pair恒等式576项普通Decimal；36次有限模型方向评估16522项精确；四型脚本292项精确。数值范围、三阶段检查与证明分开；本轮无新优化器。独审先筛命题再核证明。
