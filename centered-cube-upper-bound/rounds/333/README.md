# 第333轮：共同接收势支付有向边界费用

**一般 n^(1/2+o(1)) 上界未闭合。** 本轮证明了一个不增加正X或来源费用的实际付款分支：按接收质量由小到大定向，以 w(ρ)=min{1,(√ρ−1)²/2} 构造同一个接收势，其账单不超过原Dirichlet信用。它支付小质量端捕获、大质量端漏失的真实来源cut，并保留额外共同捕获收益。质量比≥(1+√2)²时该方向全付；≥9时至多用对应边信用的一半。

逆向、等质量/近质量剩余cut与fit仍未付；旧信用必须扣去已花部分。辅助负载条件给出另一完整B_H预算，但一般场尚未证明满足该条件，不能与上述同一信用重复结算。

本机MATLAB完整运行12LP、6QP、6LP；Python把候选修复为有理可行证书，4014项精确后检查通过。另1320项有向付款代数检查，总5334项精确检查。来源全格积分，接收数值仍为有限quadrature，不冒充真实dx。固定W的QP参考在n1变差、n2/3改善，说明后续需直接针对来源比值/小X预算目标；未声称最优或维度阶数。

原完整总账保留软核、质量可比重尾联合交通、极端尺度比、宽距离/低pe及全部时间初始/删除/未来删除项，总吸收仍待证明。
