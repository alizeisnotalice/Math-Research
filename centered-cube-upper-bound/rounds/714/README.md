# 第714轮　每次容量减半强制的价格跨度

开题重读[第706轮指令](../../AGENTS.md)。对坏接收者 j 的最初真实首半池，每个来源 i（包含触发项）都满足

\[
 \log(d_i/d_j)\ge (t/h^n-7\sqrt t)\log(1/(2r_j))-6 .
\]

证明直接按贪心价格积分，即使同一价格段中有任意大的来源、或来源自身剩余容量极小，界仍成立。后续每一次减半的真实时间段依序贡献价格跨度。对深度至少 K 次减半的行，原始首池最小来源体积相对 d_j 至少按 exp(常数·(K−1)√n)/2^K 增长；其余行合计至多 2^K(t+a^(−n))D。用最初菜单控制原积分时保留一个共同见证。

另外，每个接收者可从 K 个真实阶段中选择 m 个分配。跨阶段来源价值合计至多 4V/t；除以 m 后，来源支付可吸收到接收体积项。尚待控制的联合割要求同一批深接收者中的每一行都在至少 K−m+1 个阶段受阻。一般一致弱型上界仍未证明。

真实壳层历史给出了体积比对数同阶的解析上例。本机 Arb 与 MacBook Decimal 复核18组历史，另以360个整数网络验证选择阶段的割公式。
