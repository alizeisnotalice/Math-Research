# 第690轮：前向质量收缩与反向覆盖缺口

一般任意 L1、全尺度、固定勒贝格背景的 C_n≤K√n 上界仍未证明。本轮没有新的统一上界阶。

已证明真实不交 owners 经未来紧区域到未来来源的归一化质量流收缩，所有重复费用可求和。但旧紧胞元的覆盖缺口只能由仍覆盖它的较早来源补足；前向质量流不能自动实现反向的整父系数删除。回撤目标父也不保证释放仍被其他胞元约束的来源容量。这个动作与收费的联合选择仍是决定性缺口。

现有全来源筛除公式改用允许 O(U) 的预算，可把半径分界从 n 缩到约 n/log n。新分割从原 V 重新做一次，完整账为 Cadm{[2+(Kfar+Kup)/tau]U+Vdagger}，不再重复添加旧Kall。它不将分界缩到根号n，也没有支付整个Vdagger。共同dual质量块及同一h积分连接的条件与未付费用保留在S2，不视为闭合。
