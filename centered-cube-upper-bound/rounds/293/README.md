# 第293轮：共同软度交叠列的根阶弱分布与有限高度来源费用

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮给出新的全域几何估计，不把它等同于完整来源预算。

## 目标、定义和已证明结果

沿用第292轮实际低pe、完整 e_g、质量 m、共同软度及原比例带。设 gamma=1+1/n，c=c_j，c_+=c/gamma，V=min(H_sigma,tau)，D=∫V，h_tau=min(1,tau)。H_sigma 为原一维硬核与软核的张量混合对同一个软度参数取上确界。对非空物理窗口 t∈[a/c,bc]，令

    Gamma(t;y,z)=∫dx sup (LR)^(-n) V((x-y)/L) 1_{Q_R(z)}(x),

上确界取原 a≤L,R≤b、sqrt(LR)≥t、c_+≤min(L,R)/sqrt(LR)≤c。原实际唯一半开 j 不变；闭带只用于正支配。

存在显式次数 -n 的非负齐次核 Phi，使

    Gamma(t;y,z) ≤ Phi(z-y),
    ||Phi||_(1,infinity) = 4 gamma^n D
                        ≤ 4e[1+(pi/2)sqrt(n)].

结论覆盖任意来源位移、完整软度和带内任意实际尺度选择。关键步骤是在接收点积分之前，同时扩大软、硬尺度至固定长宽比，付 gamma^n，再对共同尺度作正积分。若 kappa 是扩大后固定尺度交叠且 ∫kappa=D，则

    Phi_r(delta)=2n∫_0^∞g^(-n)kappa(delta/g)dg/g,
    |{Phi_r>u}|=2D/u.

同次非负齐次核的弱常数可由球面积分精确相加。这里没有使用一般弱L1三角不等式。共同软度质量的全维证明来自二项概率总变差：Csoft_n≤1+(pi/2)sqrt(n)。

同时证明实际有限列的高度

    Gamma ≤ B_t=2c^n t^(-n)(D+h_tau),

可与原 a^(-n)[1+n log(b/a)] 取小。对于任意原来源限制密度 f，保留其重排 f* 后有

    ∫Gamma(t;y,z) f(z)dz ≤ ∫_0^∞ f*(u) min(B_t,4gamma^n D/u)du.

这是明确的来源集中费用。若另有真正已证的 f≤v、∫f=m，则费用≤K v Psi(B_t m/(Kv))，K=4gamma^nD，Psi(r)=r (r≤1)，Psi(r)=1+log r (r≥1)。原接收点的硬平均上限不推出 f≤4lambda。

## 与原交通连接及剩余缺口

来源证明保留 p、h、原 q≥q_-、原 FIRST 和真实 dx，给出冻结有限列的重排付款，并可与独立 A_n W_nu 付款取小。来源密度有额外限制时得到根阶乘显式对数的条件预算；一般来源没有自动满足这个条件。

Phi 在零点不可积，不能将它单独卷积代入原 E^-。必须保留有限高度。Lebesgue 弱分布也不能直接估计任意 beta 加权接收量；比例带 j 的总费用尚需原系数和共同选择器的联合控制。扩大尺度只用于正支配，未在扩大尺度上使用 FIRST 或硬cap。

原低pe、高m且未通过联合熵付款门、截断交叠列质量仍大的中间重尾、来源集中联动、连续高score及初始/跳跃/删除余项仍未整体支付。来源子片可拆分，但原完整 e_g、m 和历史标签不随子片重新计算。没有声称覆盖所有正L1输入，也没有将连续部分付款转移给时间原子。

## 本机实际验证

本轮检查分初步探索、边界压力测试、扩大范围三阶段。运行 checks.py，使用 Python Fraction 和 mpmath 1.3.0：

- 硬齐尺度齐次核的弱常数恒等式：n=1..64及128，65组精确有理恒等式；65组非负加权可加恒等式。
- 27组齐次径向检查，40/60位基础精度并加2n积分保护位。
- 288组精确比例带扩大检查，维数至10^6。
- 11个共同软度二项极值和，维数至10^4。
- 216组有限高度重排公式，40/60位精度。

作者重复运行一致；主代理独立复跑及SHA核对结果见 manifest 和审计。浮点检查不属于区间证书；有限检查不证明全维来源闭合。Fraction 恒等式为所列有限参数的精确计算；全维结论由解析证明给出。
