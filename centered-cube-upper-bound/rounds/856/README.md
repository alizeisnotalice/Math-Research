# 第856轮　同一右来源的共同伙伴质量与跨尺度接收矩阵

在第813轮原双臂积分上，固定真实右来源 \(q\)、半径八度 \(O\) 和中父体积档 \([D,2D)\)，把所有左来源、两端真实接收者及中父历史按原权合并。若这些历史频繁共用足够多的实际来源质量，**全部这类行合计只占 \(o(V)\)**。剩余原量必须分散在一个定量可估的巨大来源池中。一般一致弱型上界仍待证明。[完整 LaTeX、六项本机检验与复算器](research.zip)

## 共同来源的实际质量

记 \(p(w)\) 为按上述条件独立抽一条原历史后，\(w\) 落入其合格中父来源池 \(G_t\) 的概率。于是 \(\int p^r\,d\mu\) 正是 \(r\) 份真实历史共同拥有的伙伴质量的平均值。令 \(J=\sqrt n\log^8(n+2)\)、\(r=\lceil k n/J\rceil\)，其中 \(k\) 为足够大的绝对常数，\(n\) 充分大。在所有物理窗和体积档上同时有

\[
 \int\min\!\left(1,\frac{e^{J/2}}D\int p(w)^r\,d\mu(w)\right)d\Gamma
 \le C e^{-cJ^2/n}V .
\]

证明先在中父的不交接收集上估计 \(q,w\) 共同允许的体积。再利用右小父的真实质量 \(m_g<2De^{-J}\)，在小父的不交接收集上合并全部 \(q\) 的费用。对整个 \(A_t\) 内任意真实伙伴资格也有此界，证明保留原近极值入口。取 \(G_t\) 后，删去已付整行，每个承载一半平均伙伴质量的来源集都须有至少 \(cD\exp(c\log^{16}(n+2))\) 的真实质量。

## 接收体积和两端分配

在每个窗、体积档中，把拟接受的左右标签对按真实中父接收权求和，再除以 \(D\)，得矩阵 \(M\)。证明其 \(\ell^2\) 算子范数可以给该批原记录计费，各档合并只付完整度分层的对数。进一步用原流自己的两侧边际推出对整张表的二次估计。该方法亦直接适用于一般正输入、同一实见证的全尺度高度带割。

对一族每侧有 \(2^n\) 个来源字串的接收几何，允许事后任选 \(\lfloor n/256\rfloor\) 个失配坐标，接收矩阵范数仍有 \(C(0.97)^n\) 上界。零失配矩阵的最大行和与最大列和各按 \((37/32)^n\) 增长。能否给上述分散余量构造费用足够低、仍覆盖真实来源的共同标签，是当前缺口。

## 本机复算

Python 3.12.14 以有理算术重建第814轮的34个跨档根和920个正项，按15个真实右源与体积档的组合复核二重、四重的共同质量。原、加宽样本上均核验了两侧真实接收容量及分数对偶。另以 SymPy 隔离谱根，以 Arb 检查至4096维的容错接收矩阵，以及两个大维度参数的指数界。低维归档样本的最大实际体积比为 \(2401/625\)，用于校验费用公式，高维付款依赖正文证明。

解包后运行 `replay856.py`，传入项目的 `rounds` 目录和已有临时目录。复算器校验两份输入归档的 SHA-256，在干净目录中运行六项程序并逐字节对照实际输出。
