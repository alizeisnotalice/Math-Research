# 第779轮　跨中父的来源容量、相对面费用与原峰总账

沿用第772轮的真实两跳峰、同一个割 \(F\) 和实际不交接收者的勒贝格总体积 \(V\)。设 \(\ell=\log(n+2)\)，\(L=\sqrt n\,\ell^3\)。本轮将所有中父的求和化为一个有物理体积单位的来源分配问题，并直接支付了一类无需控制端点参照积分的远价峰。

**来源怎样共同使用接收空间。** 在每个半径八度 \(O=[R_O,2R_O)\)，将小端 \(u\) 自身的真实价 \(\mathbf1_{C_u}(y)\,dI(u)\,d\mu(y)/m_u\) 按位置合计为 \(\Lambda_O\)。以单轴尺度 \(R_O/\sqrt3\) 的乘积拉普拉斯核做二次能量最小化，选出一份可付的实际价 \(\nu_O\le\Lambda_O\)。令 \(\Lambda'_O=\Lambda_O-\nu_O\)。它集中在已付来源的高势集上，全部八度的这些集合体积之和至多 \(Y/\ell^6\)，其中 \(Y=I(1)\le C_*V\)。

令 \(s_O=R_O/\sqrt{128n\ell}\)。对有限来源 \(\sigma\) 记

\[
 {\cal D}_O(\sigma)=\sup_{K\ {\rm compact}}
 \big[\sigma(K)-L\,|K+[-s_O,s_O]^n|\big]_+ .
\]

这个量衡量在允许的距离内把来源送到密度上限为 \(L\) 的目的地时，最拥挤区域缺多少空间。按两个端点在同一份剩余中的实际权重分优先级，记第 \(t\) 层的原参考来源为 \(\sigma_{O,t}\)。证明给出

\[
 Q_{772}\le C L V+\tfrac12\sum_O\int_0^\infty{\cal D}_O(\sigma_{O,t})\,dt
 \le C L V+C(n+1)\sum_O{\cal D}_O(\Lambda'_O).
\]

同一份分配同时服务各优先级，费用包含两个方向及全部中央体积档。第二个上界只依赖原输入。两价相距很远时，高势集的体积本身无法控制共含两价的中父数量。**这些空间亏损的总和仍需统一估计，一般 \(n^{1/2+o(1)}\) 上界尚未证明。**

**无需来源密度假设的几何付款。** 若两次真价在至少 \(m_n=(\log 2+o(1))n/\log(n+2)\) 条坐标上相差至少 \(2s_v(1-1/n)\)，其中 \(s_v\) 是真实中父半径，则这类峰的全部原质量为 \(o(V)\)。证明对每条坐标计算可容纳另一真实接收者的长度，然后合计所有中父。剩余两价仍须满足第778轮的多坐标分离。

**实际核验。** 本机 Python 对 \(2,4,8,16,32\) 维的两个真实中父、六个正质量真价块独立按两种次序求和。同一张预选窗在实际尺度比下每次通过五块，改用整个桶的保守尺度比则通过三块。另以精确有理数核验729组有优先级的分配与最小割，以256位 Arb 核验谱界和八个维数的相对面阈值，并与原下界笔记的分层来源对照。有限几何模型使用指定的资格图。全维不等式的证明和数值适用范围分别载于报告。[详细 LaTeX、两份脚本和完整证书](research.zip)
