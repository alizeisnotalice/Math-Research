# 第826轮　方体平均的全尺度平滑估计与真实双来源分配

按11月23日指导第6节第三步，在同一输入、阈值、见证和勒贝格接收集合上，研究不同来源件的共同接收体积。近期目标是一般单窗弱型常数 $B_n=o(n)$，最终目标是一般全尺度 $C_n\le K\sqrt n$。

## 已证估计

令 $u_h$ 为长度 $h$ 的中心均匀密度，$K_{a,t}$ 为一维核 $u_1*u_a*u_a$ 的 $n$ 维张量再按边长 $t$ 缩放，$0<a\le1/4$。对任意有限正来源，两次小平移后的方体平均有单窗强包络 $1+\frac12\sqrt{3n/a}\log2$，全尺度弱型常数至多 $C(1+\sqrt{n/a}\log(n+2))$。证明用中心化的坐标尺度导数，再用每次只沿一个轴二分的格胞将每份真实来源限制在尺度比 $64n^2$ 的区间内。这个格胞结论也直接适用于原硬盒的同一成功见证。

在宽度 $a=1/8$ 下，按对数体积宽度 $\sqrt n$ 预选真实来源对，可以在不同段完全换配，并保留至多 $\sqrt n$ 个硬坐标。只要同一真实接收点从这些预选配对获得给定比例的阈值，其单窗费用为根阶，全尺度为根阶乘一个对数。一个割的预算只计该割自己的来源质量。设 $g(x)=A_{t_x}\mu_A(x)$，$U_A(x)$ 为该割预选配对的平滑密度。在原高度带上，取 $\delta=n^{-1/4}$、固定 $\theta>0$，有

$$
J(A)\le C_\theta n^{3/4}\lambda\mu(A)
       +\int_{E\cap\{g>\delta\lambda,\ U_A<\theta\delta\lambda\}}g^2\,dx .
$$

在第813轮原双臂上，保留真实联合接触分母、两处小父所有者和中父所有者。给定中父探针与物理半径窗，若分档候选中点边际的累计总变差为 $O(\sqrt n)$，则即使比较价彼此很近，联合得分条件均值至少 $n^{-1/2}$ 的原流量也已支付。详细证明、历史条件及总账见包内 **REPORT.tex**。

## 实际验证

- 两份第814轮原始输入各核对34条原中父记录、230个正双价单元。$a=1/8$ 时按真实质量加权的归一核值，一来源与两来源中点分别约为 $0.122484,0.464970$ 及 $0.122433,0.489848$。这些配对读取了当前记录，仅作几何诊断。
- 同一批357个事件、1041列另行重放三种分配。来源和实际接收者同时共享后，两组可支付原质量份额约为 $0.003780$、$0.032132$。包内记录有理原始与对偶界、饱和标签和全部参数。
- 对两组不同轴向的正体积来源，预配相反角使同一原见证上的中点密度恰为阈值一，单来源平滑值可以指数小。所选接收体积比为 $(16n)^{-n}$。有理枚举覆盖 $n=6,7,8,10$，标量表达式另在256及384位 Arb 下核至 $n=10^{160}$。
- 对二维正块的真实末根、短驻留接收胞、核的肩部积分、9198项坐标尺度比较和270项张量比较作确定性核验。全部有限结果均保留输入、脚本和输出。
