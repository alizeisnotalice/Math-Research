# 第731轮　小来源所有者平移后的整族根阶估计

开题核对[第706轮指令](../../AGENTS.md)。本轮回到真实接收点的有向来源对费用。固定较大方体与较小来源的半径档，以同一个有符号坐标置换，将小来源的实际所有者从共同见证平移到接收点附近。不交所有者给出卷积上界。取指数 p=1+1/log n 后，卷积在边界的衰减足以支付全部相对尺度。一次检验的整族费用至多为 M/n+C√nD，M 是真实剩余接收质量，D 是原贪心装填价值。

这支付所有小来源包含在大来源中的配对，也支付每个坐标容许 O(1/log n) 比例越界的近包含配对，因而处理了上轮的满交长原子。另一个估计允许例外坐标随来源对和接收行变化。固定 k 个例外只产生固定对数损失；k=o(log n/log log n) 时，来源支出仍为 n 的 1/2+o(1) 次方乘 D。报告给出整行费用、两次测试的付款次序与四来源余项的回代。

本机与 MacBook 核对一维卷积幂积分及合法尺度档求和。本机另核验12个真实贪心正损失算例，包括恒等变换漏掉整个小来源所有者、一次反射覆盖它的情形。这些算例原有远来源可支付。一般输入中，所有者在许多坐标上错开且无法用共同变换收回的需求，仍缺统一估计。[详细证明、核验结果及复现材料](research.zip)
