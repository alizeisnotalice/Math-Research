# 第713轮　拥挤见证交集的来源支付

开题核对了[第706轮指令](../../AGENTS.md)与第712轮的空间缺额。把接收者可以进入的空间区域和它能使用的真实来源放在同一个分配问题中，每个来源跨所有尺度只发放一次预算。完整高损失积分至多为联合最大流的未匹配体积 Γ，加上 n^(−1/8)V_T 和根阶来源费用。

若某个割仍有正缺额，则在同一个割上，对每行选取任一共同真实见证后，仍有超过该割接收体积 27/64 的积分质量来自未能通过来源包络支付的高损失边。每个来源可使用多个包络，按其实际并集体积结算。坐标投影公式给出这些包络的可检验费用。正缺额的连通分量还需要指数于 √n 的见证覆盖数，具体尺度及常数见证明。

真实历史中，第712轮空间缺额占比可趋于1，而本轮联合缺额严格为零。九组维度已用本机 Arb 和 MacBook Decimal 核对。任意正缺额割的统一预算仍待证明。
