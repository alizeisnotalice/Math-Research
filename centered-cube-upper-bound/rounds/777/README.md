# 第777轮　保持原峰分布的转移与共同来源预算

沿用第770轮同一个割和第772轮的实际两次交价。第776轮已控制多个中父在同一交价相遇时的不合格父对。本轮利用这条估计，在一条峰和另一条峰之间更换中父。每次经过的整条峰，包括它的小端、真价和原筛选历史，都有与出发时完全相同的边际分布。

**合计所有中父的来源费用。** 令 \(\widehat{\mathcal R}\) 为两侧都保留足够后继质量的原峰子测度，\(J\) 为相邻两峰按原质量计的联合测度。给每个中父 \(v\) 预定一个可重叠来源集，记该集上归一化的实际来源为 \(\zeta_{k(v)}\)。令 \(H\) 为 \(\zeta_{k(v)}(A_v)\ge 1/M\) 的中父集合。对任一固定方向证明了

\[
 \widehat{\mathcal R}(H)
 \le C_\varepsilon M e^{-r/2048}Y
      + J\{k(e)\ne k(v),\,v\in H\},\qquad
 r=\lceil\sqrt n\log^2(n+2)\rceil .
\]

这里 \(A_v\) 是真实父方体，\(Y\) 是原首臂的总质量，由实际接收勒贝格体积 \(V\) 的常数倍控制。同组部分共用一份预算。进入 \(H\) 的跨组原流量只计一次，系数为一。按实际交价分组时，新旧组的差异可直接在一条峰的两次真价上积分。论证也适用于事前给定的概率预测，单个指定位置的费用与此前走过多少次转移无关。

**回到原积分。** 在第773轮或第774轮入口，令 \(B_0=Q_{773}\) 或 \(Q_{774}\)，相应取 \(j=0,3\)。对 \(M\le e^{r/4096}\) 和固定 \(0<\varepsilon\le1/2\)，扣除已付份额后有

\[
 \begin{aligned}
 R_{\rm rem}
 &=\widehat{\mathcal R}(H^c)+J\{k(e)\ne k(v),\,v\in H\},\\
 0\le B_0-R_{\rm rem}
 &\le \varepsilon B_0+
 C_\varepsilon\sqrt n\log^{3+j}(n+2)\,V .
 \end{aligned}
\]

还证明了一个可在未筛原峰直接使用的来源增长界。若真价 \(x\) 附近半径 \(6s_e\) 的方体所含来源至多为中父质量的 \(e^{r/4096}\) 倍，则两侧这类峰合计至多 \(2e^{-r/4096}Y\)。第776轮的近价支付也可从反向原路径直接得到更强的界。

**剩余缺口。** 对一般输入，上式第一行的两个非负项之和仍需 \(C\sqrt n\log^\beta(n+2)V\) 的统一预算，或带固定节省的收缩。当前估计允许大量真价跨组，或者中父只能捕获所属来源集的很小份额。一般 \(n^{1/2+o(1)}\) 弱型上界和纯 \(K\sqrt n\) 上界均待证明。

**实际检验。** 本机 Python 3.12.14 以有理数计算了两个各含18个真实父区间的模型。第一个模型中，逐行独自归一化使列分布发生约 \(0.018\) 至 \(0.020\) 的总变差。修正耦合后，2、3、6步的256个原记录及其1024个细分记录均保持原质量。第二个模型有16个不同的中父和不交的真实接收者，在三个阈值下分别有9、16、16个中父通过来源占比检验。均逐项核验同组付款与跨组流入。有限模型采用指定的资格图，只用于验证构造、费用和选择预测方法。[详细 LaTeX 证明、两个可复现脚本及完整有理证书](research.zip)
