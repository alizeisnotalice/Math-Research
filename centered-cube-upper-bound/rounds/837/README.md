# 第837轮　跨细格的乘积核与真实来源负载

同一右来源可以在不同尺度与许多左来源配对。为估计它们的总质量，本轮把每个物理坐标分成粗细两层格，将真实落在同一粗格、不同细格的两臂也计入。细格及粗格的来源质量都按原端点历史计量，整批左伙伴共用一份右端预算。用到 OpenAI 第 022 篇预印本的逐坐标切片方法，并在立方体上重新证明了单轴常数与全尺度测度估计。[详细 LaTeX 证明、数值笔记和复现材料](research.zip) · [原论文第 2.3 节](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-weak-inhomogeneous-Duffin-Schaeffer-conjecture-September-25-2026/paper.pdf)

## 对原积分实际证明的估计

在一轴上给同细格权重 1、异细格权重 \(\rho\)。取指数 \(u=3/4\) 时，\(0\le\rho\le1/2\) 的最优单轴常数满足
\[
 c(\rho)^2=1+\frac{\rho^4}{1-2\rho^2}.
\]
以各坐标切片的真实质量迭代，得到任意相关来源的乘积常数 \(\prod_i c(\rho_i)\)。在第813轮双臂母式上，先用不交接收者得到所有真实来源共同允许的中心体积，再用上述乘积估计。两端实际质量和所有绝对体积档合计后，格分数的积分至多为 \(C\mathcal H\sqrt{Y_-Y_+}\)。在一般正 \(L^1\) 输入的真实末根上，常数是 \(2\sqrt{\|\nu_-\|\|\nu_+\|}\)。另得一个可对同一右来源的所有伙伴同时测试的 \(L^{4/3}\to L^4\) 估计。

原双臂的长跳满足 \(\sum_i|z_i-q_i|/a_D\ge b\)，其中 \(b\asymp\sqrt n\log(n+2)\)。在对该真实来源对加权的公共格相位中，能逐项计算有多少坐标跨过细格边界。取 \(\rho=(b/(4096n))^{1/3}\) 和 \(\Lambda=b^{4/3}/(128n^{1/3})\)。对报告定义的四格质量中位数分数 \(\mathcal L\)，证明了
\[
 \int\mathcal L\,dR\le C\mathcal H\sqrt{Y_-Y_+}\,e^{-\Lambda}.
\]
所以即使只要求分数达到 \(e^{-\Lambda}\)，这些原行也能从根阶接收费用支付。在仍然低分的每条原行上，以至少四分之一的条件概率，两个实际来源同时在许多坐标落进不同细格，所在粗格及两枚细格的实际来源质量又满足报告中的指数下界。该粗格内有至少 \(\tfrac12e^{\Lambda/2}m_t\) 的真实来源位于略微膨胀的原中父以外，结论对充分大维成立。

另一项可直接在原行上检查的条件是
\[
 \sum_{i=1}^n\bigl[3(1-|z_i-q_i|/a_D)\bigr]^{-1/2}\ge6n .
\]
满足它的记录跨全部物理窗和体积档合计花 \(O(\sqrt n\,V)\)。证明保留同一个真实所有者点，再对未显露的坐标求交长乘积。

**剩余缺口。** 不同左端或中父可以反复看到上面同一批外部来源。还需估计这种重复发生时，不交接收者的总质量，或者给出能对此统一收缩的递推。旧吸收系数维持原值，一般 \(n^{1/2+o(1)}\) 上界仍待证明。

## 本机证据

- 两份各230条原行的四维档案中，允许跨细格相对硬对角多覆盖70个正宽子块。固定右来源罩95时，涉及三个左来源罩和两个中父。这些新增子块同样通过 \(u=1\) 的粗格基准，且两份档案的高维历史门均为空。
- 一个正密度输入有两个实际末根，真实质量分别为48、96。两端共同预定跨尺度权重后，在自然阈值1上，\(u=3/4\) 覆盖全部四个不交接收子区中所测的双臂原质量 \(3/40000\)。用相同权重，\(u=1/2\) 的最优格间参数和 \(u=1\) 的粗格基准都覆盖零。这给出了中间指数严格改善的连续输入。
