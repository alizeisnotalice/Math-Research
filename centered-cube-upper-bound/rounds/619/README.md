## 已付款的完整family条件

全局共同来源合并严格给 κV≤PM，P=(1+1/a)^n。预先取ε=θ_n/(2P)，若构造所得κ≥θ_n，则 V≤2P Q/θ_n。a≥n、θ_n=(sqrt(n)log^A(n+2))^(-1)时，该完整family条件下得到根阶packing预算；没有额外selected-cover系数。

**剩余缺口：** 组件内部共同来源比例低、cliques相互交织时的联合几何付款。分离组件可分别结算再相加，不应靠增加其数量制造困难样本。方向通量总和≤1尚不能推出接收体积的根阶界；未证候选不列为结果。
