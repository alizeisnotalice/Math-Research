# 第776轮　不同中父共用真价时的两价集中估计

第772轮留下的一个困难是，许多中父可以反复使用同一处来源。本轮固定这处真实交价 \(y\)，在全部中父上取两份原峰，保留它们另一侧的真实交价 \(x,x'\)。两个原峰的小端可以不同。证明了

\[
 \sum_O\int\frac{d\mu(y)}{H_{O,y}^2}
 \iint {\bf1}_{\{\|x-x'\|_1\le u_n R_O\}}\,
       d\mathcal R_{O,y}(\pi)\,d\mathcal R_{O,y}(\pi')
 \le C L V .
\]

这里 \(O=[R_O,2R_O)\) 遍历原半径八度，\(u_n=\lceil\sqrt n\,\log^2(n+2)\rceil^2/(8192^2 n)\)，\(H_{O,y}\) 是给定 \(y,O\) 的原首臂权重之和，\(\mathcal R_{O,y}\) 是未归一的原峰条件测度，\(L=\sqrt n\log^3(n+2)\)，\(V\) 是不交接收者的实际勒贝格总体积。证明在两个中父形成原硬边时使用真实三跳，在其余情况下保留较小中父的原小端，分别核清费用。共同价只积一次来源测度。

**落到原积分上的结果。** 在保留第774轮两侧伙伴组的入口，对每个 \(y,O\) 可按全部中父的实际质量选出 \(\lceil\log^3(n+2)\rceil\) 个小直径区域，支付另一侧真价落入其中的原峰。另证了按源胞内实际质量收费及在同一真实交边连续取价的预算。前后使用同一份原峰，新增费用合计后，对任意固定 \(0<\varepsilon\le1/2\) 有

\[
 0\le Q_{774}-R^{\rm fin}_3
 \le \varepsilon Q_{774}
      +C_\varepsilon\sqrt n\,\log^6(n+2)V .
\]

所得 \(R^{\rm fin}_3\) 同时保留两侧旧筛。若改从第773轮的较大入口出发，每个方向取四个区域，则右端的线性费用为 \(C_\varepsilon\sqrt n\log^3(n+2)V\)。两个入口的条件核分别冻结。

**剩余缺口。** 两侧真价都分散在许多远隔区域、相应小父各自只容纳一部分来源时，仍缺这批原峰的总体积预算或固定比例收缩。一般 \(n^{1/2+o(1)}\) 弱型上界和纯 \(K\sqrt n\) 上界均待证明。

**实际验证。** 本机 Python 3.12.14 用有理数复算12个父区间、14份历史的真价与所有者，并在独立的四维连续来源上核对原峰分母和首次触发。四维输入的一条历史在原锚点价胞的峰质量为 \(M\)。从一次到五次补价，其实际付款由 \(M/4\) 增至 \(801M/1024\)，仍余 \(223M/1024\)。三份脚本各运行两次，输出逐字相同。有限模型的诊断参数与一般几何估计的适用范围均已列出。[详细 LaTeX 证明、完整证书及复现脚本](research.zip)
