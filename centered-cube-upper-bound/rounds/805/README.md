# 第805轮　先积真实交价的全族预算与共享两个源点的路径

对第804轮完整余量 \(R_{804}\)，本轮把外源积分的分母从最小可用小父体积换为实际中父体积。令 \(Z_t\) 为中父 \(t\) 出现在成功远锚中的真实外源集，\(m_t=\mu(A_t)=|A_t|\)，\(j_t\le C|E_t|\) 为原历史权。对全部中父同时有

\[
 |R_{804}|\le o(V)+CH(n+2)e^{-r/256}\sum_t j_t\,\frac{\mu(Z_t)}{m_t},
 \qquad r=\lceil\sqrt n\log^2(n+2)\rceil .
\]

这里 \(V\) 是实际接收总体积，\(H\le C(1+\sqrt n/\log^2(n+2))\)。证明先积两条真实历史块的交价，再用同档勒贝格接收集不交。因为正量中父质量至少是指定小父的 \(e^J\) 倍，其中 \(J=\sqrt n\log^8(n+2)\)，这一换序消除了旧分母带来的尺度比损失。所有满足 \(\mu(Z_t)\le e^{r/512}m_t\) 的中父，其成功锚合计只费 \(o(V)\)。[详细 LaTeX、计算笔记与离线复现材料](research.zip)

## 同一中央历史和同一条对端臂

固定原中央历史以及另一条臂的真实旧价、接收点和方向，从仍然成功的指定臂中重抽 \(p\) 份。先求和所有中父，所得联合密度相对于一份真实对端参考及 \(p\) 份真实外源与接收参考至多为

\[
 C^{p+1}\left(\frac{H e^{-r/256}e^{-J}}{L}\right)^p
 \frac{1}{\max(m_g,m_{u_1},\ldots,m_{u_p})^p}.
\]

该式用于未分档原行质量至少为 \(L\) 的行，按该行实际质量归一。跨档的几何级数对所有 \(p\ge1\) 可同时计费。在 \(1\le p\le\lfloor e^{r/1024}\rfloor\) 时，一个具体可付的几何事件是这些记录的真实源点和接收位置通过扩张体积为 \(e^J\) 倍的小盒组成强连通有向图。此检验可让观察后的数据自行决定有向连接，选树的费用也计入。

## 未付部分的共同端点

删去低载行、低载源列和频繁通过联合检验的行后，按实际中父档 \(M\) 与小父档 \(D\) 分组。从真实外源经中央历史及共同对端臂再到下一真实外源，所得路径可以在同一对精确首末源点上重抽。令 \(s=\log(M/D)\)，对按原权抽得的端点，平均意义下可同时取 \(\lfloor e^{s/16}\rfloor\) 条路径，每条至少有 \(\lfloor(k-1)/2\rfloor\) 个中间时刻满足双向分离。该时刻的源点位于其他路径所有指定小父按半径 \(e^{s/(16n)}\) 扩张后的方体外，对方的实际源点也位于本时刻的扩张小父外。失败概率上界为 \(e^{-ks/4}\)，其中 \(k=4+\lceil256(n/s)\log(32(1+n/s))\rceil\)。

按所有路径边取平均投影回同一份原流，得到精确分解。已付原质量至多为 \(C(LV+PS)+o(V)\)，可吸收部分至多为 \(97|R_{804}|/128+o(V)\)，其余原量记为 \(R_{805}\)。其中 \(V\) 为实际接收总体积，\(S=\|f\|_1/\lambda_0\)，\(L=\sqrt n\log^3(n+2)\)，\(P=(n+2)\log^6(n+2)\)。还须控制不同端点对和中央历史在这些路径中反复使用同一批来源的总权。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。

## 本机验证

本机独立 Python 3.12.14 的有理算术复核了 \(1,2,3\) 维实际方体模型。将合法外源质量错换为整小父质量，只回收到原量的 53.94%、40.22%、38.41%。另在 16、40、84 个真实标记行分别核对二次、三次重抽。压力例中，共享同一对端原臂时指定端接收半胞一致的概率为一，只保留中央历史时分别为 \(1/2,1/4\)。共同终点另用两种方法逐项核对了 27、13、625 个正源序列。4096 位 Arb 复核了五个非空维数的十五组标量参数。三套脚本、输入、结果、版本和 SHA-256 均在压缩包内。
