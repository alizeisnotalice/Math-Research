# 第720轮　集中接收组的来源价值与跨组费用

开题核对[第706轮指令](../../AGENTS.md)。固定同一次贪心历史，可直接把每组的需求取为原高损失积分在该组的值。组内各见证接近时，代表见证处的真实来源价值相对需求有指数余量。跨组共享的费用按来源实际分到各组的比例计算。条件熵估计给出一项能同时支付所有组的充分条件，允许单个来源关联许多低权重组。

对任意输入，把同站点的接收行合并后可无条件支付超远部分、组内项以及未超预算的来源。剩余量只涉及两个不同组同时使用的超预算来源，对其价值给出逐坐标交集上界。所有这些交叉项的总和能否控制在 O(nD)，仍未证明。[详细证明、脚本和计算记录](research.zip)

本机以有理算术在八个维数上核验了 3,120 个站点对，并另行检验偏斜来源分配与九个真实历史块。MacBook 两次连接超时，本轮独立数值复核在本机完成。
