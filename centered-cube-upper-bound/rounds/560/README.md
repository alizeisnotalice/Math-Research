## 已证明与独审

令 Λ=2+lnG，N_B=1+∫dg/κ_B(g)+G/κ_B(G)，H_B=m_B/N_B。真实自适应场Y保全部父对、来源、质量窗、相位及两个端点。得到

- 完整Gram因子化：‖Y‖²≤C_P Φ，Φ=∫t_B H_B/R_Bⁿ dB，C_P≤C_*+C。
- 非空bulk时的一次全质量层粗容量：Φ≤S(2A_n−lnG)W/Λ²；空bulk单列为0。
- 实际逆体积矩η_B≥Λ/(2G)。完整恢复量是 Cη=‖∫F_B/η_B dB‖²；I_B=N_Bη_B，不能恢复后再使用N_B折扣。
- Q_g≤J Cη/(1−3h)²+2E_rem/(1−3h)。自然旧平方信用仅≤Q_g，先在此层级吸收，最后恢复原Q。未反向误用Q_g≥(1−β)²Q。
- common律的η=p，故R559的p²能量折扣在精确恢复后相消。两种候选均按同样恢复规则比较。

几何独审、组合独审及动作合法性审查均通过；详细证明、条件和修复见包内REPORT.tex、AUDIT.md。上述粗容量仍含A_n；初始、删除跳跃、未来被删来源、宽距离、低强度、极端尺度比、原入口、全尺度和终端费用全部保留。
