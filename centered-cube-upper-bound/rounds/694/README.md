# 第694轮　首次捕获区域的联合扩张

第694轮对实际首次捕获区域作概率归一化，未扩张部分由 D/(1−β) 支付。对每个固定有限输入，高阶极限按不同来源池分别计入扩张体积。统一控制扩张后的重叠费用仍是缺口。 任意 L¹ 输入和全尺度的纯根阶弱型上界尚未证明。

双机有理算术覆盖 N=65 到 145 的81个真实一维网格，Mac mini 使用12个进程，MacBook 使用15个。全部81例的二阶总扩张费用超过一阶。逐池扩张体积之和与实际并集体积之比介于11.12与18.91之间。此范围仅对应这些输入。

research.zip 含详细 LaTeX、独立审查及可复现脚本。解压后用 Python 运行 verify.py，运行 dual.py 65 100 12 和 dual.py 101 145 15 可重算双机分片。NUMERIC.py 需要 python-flint，复算时会重写 RESULT.json，请在副本中运行。未编译 PDF。
