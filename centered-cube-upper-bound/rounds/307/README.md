# 第307轮：真实行质量增长付款与完整总账约束

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮以对称差费用为主攻点，在原合资格交通上证明新增捕获的快速增长分支可吸收，并给出近尺度安静增长分支的付款；没有把剩余问题描述成常数或对数优化。

## 新付款及其准确范围

保持原来源、真实接收dx、完整软核、FIRST、q、low-pe、高m、尺度比v>=v0及历史资格。共同资格阈值theta只积分一次。设J为真实接收行前缀质量，D=max(H,J)，N为更小半径的未捕获前缀，K保留原J>=H和p_theta<7/8门。

新增捕获在实际捕获接收器半径r处的精确费用为N(r/s)K(r)。对r<=t<=b证明

K(r) <= (r^(-n)-t^(-n))/D(r) + t^(-n)/D(t)。

因此，旧未捕获比例rho=N(r/s)/D(r)较小，或真实行质量在足够短的尺度窗口内增长到D(r)/delta，两类并集都可由同一eta T_theta付款，其中delta=eta/2。并集只计一份eta，不重复来源质量。第二类可支付rho较大的实际新增捕获；终端r=b无未来增长，不能套用此分支。

近尺度费用按捕获接收器定向，精确保留对方未捕获因子，等半径原子只计一次。它受实际近期质量比例与前向增长积分之和控制；这个和本身未必<=1。若整个近窗口的质量增长至多1+delta，费用<=2delta T_theta。增长补集继续保留原精确费用，不能用增长窗口数的对数界代替来源加权预算。
