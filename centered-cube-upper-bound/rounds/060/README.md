- 更强的标记多数源反例否定了**固定真实阈值带内、正反方向任选其一**的完整历史正漂移统一预算，且适用于每个固定维数。密度有界、质量与来源深度无关；平方能量仍可有界。这是收费方式的反例，不是原极大算子目标的反例。
