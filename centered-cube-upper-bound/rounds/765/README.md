# 第765轮　跨尺度三重交与真实接收者的共同平移

本轮估计攻坚指南式（4）的同一高负载积分。小父为 \(A_k\)，同一来源点 \(z\) 上按原权抽出两个大父 \(A_t,A_u\)，记 \(B=A_t\cap A_u\)。在首穿越近极值输入上，先用任意固定的 \(\varepsilon V\) 剔除低负载或来源过度拥挤的部分。两次抽样的真实方向、接收体积及来源分母保留在原流中。

**同一来源测度跨全部小父尺度。** 在 \(B\) 中保留真实来源拥挤度 \(W_d\le H_*G\) 的部分 \(B_*\)。令 \(D(k)\) 为小父体积二进档左端。满足
\[
 \frac{\mu(A_k\cap B_*)}{\mu(B_*)}\ \ge\ \frac{D(k)}{\sqrt n\,|B|}
\]
的流量，两方向与全部尺度合计至多 \(C_\varepsilon\sqrt n\,\|f\|_1/\lambda\)。逐档估计原本要乘以 \(O(n\log n)\) 的档数。本轮对固定大父对在各档使用同一份真实来源测度，全部小父重数可一次积分。详细证明见式（2）至（4）。

**剩余来源对真实接收体积的要求。** 在同一价点附上 \(\lceil\sqrt n\rceil\) 个实际接收者的方向观测。另用 \(O(\sqrt n\log(n+2)\|f\|_1/\lambda)\) 后，每个剩余的实际小父和来源点都属于一个至少有 \(\lfloor2^{\sqrt n/32}\rfloor\) 个成员的来源族。每个成员都能产生同一批观测，各小父的中心距离超过其较大半径，且一个成员的来源点和小父中心均落在其他小父之外。每一对来源在不同真实接收者上的同档平移重叠，按原遮罩、列权和档体积归一求和，均至少为 \(c\max(L,\gamma G)^2/N\)，其中 \(L=\sqrt n\log^3(n+2)\)，\(N=O(n\log(n+2))\)。证明使用实际条件分布的双抽，还保留了第一份原始关联。见式（5）至（7）。

**未结清的费用。** 取 \(\varepsilon=1/64\) 后，总账为
\[
 \frac{1983}{2048}\,T_0\le R_{765}+C L\,\|f\|_1/\lambda .
\]
不同来源对可以重复使用同一片接收体积。要推出一般上界，还需从整个 \(R_{765}\) 中支付一个固定的 \(T_0\) 份额。
