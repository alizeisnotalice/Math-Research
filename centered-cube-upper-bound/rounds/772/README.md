# 第772轮　同一来源上两小父的重合与下降流量

设一条真实路径经过小父 \(j\)、大父 \(i\)、小父 \(k\)。沿用第770轮冻结的同一份可付款来源 \(X_F\)，保留第771轮两跳的实际交点和所有原分母。令 \(Q^0\) 为中间父体积严格极大的原路径测度，\(m_i\) 为父的真实质量，\(Y_U\) 为割内端点的首臂总量，\(\eta_*=\exp(-\lceil\sqrt n\log^2(n+2)\rceil/256)\)。

**已证的新估计。** 两小父在同一份外部来源上的重合满足
\[
\int \frac{m_i\,\mu(X_F\cap A_j\cap A_k)}{m_jm_k}\,dQ^0
 \le C(n+2)\eta_*Y_U.
\]
所以当 \(\mu(X_F\cap A_j\cap A_k)\ge\sqrt{\eta_*}\,m_jm_k/m_i\) 时，这批峰的全部流量至多 \(C(n+2)\sqrt{\eta_*}Y_U\)。证明按中父展开同一来源密度的平方，再以不交的真实勒贝格接收集控制各体积桶。

**其余峰的费用。** 给定首跳实际交点后，第二端接收点的指定坐标模式有精确体积 \(m_i q_b^{|J|}\)。把它与原来源、可达小父和全部尺度的费用合并，得到原下降流量的整行上界 \(D(e)\)。\(D(e)\le L\) 的中心合计付 \(LY_U\)，其中 \(L=\sqrt n\log^3(n+2)\)。两方向均在同一条可逆路径上计算。

**一般问题的缺口。** 记 \(Q_{772}\) 为两小父在 \(X_F\) 中重合低、整行费用超过 \(L\)，且两端均未通过给定坐标检验的实际剩余峰量。原入口满足
\[
 T_0\le C\sqrt n\log^4(n+2)S+C\sqrt{S\log(n+2)\,Q_{772}} .
\]
其中 \(S=\|f\|_1/\lambda\)。尚缺对全部输入的 \(Q_{772}\le CLV\)。不同中父能够重复使用同一批外部来源，现有估计未给出它们加在一起的所需界。

**实际验证。** 22条有正权的真实区间峰上，逐路径求和与逐行平方积分独立得到同一有理值 \(234223/28467200\)。另核验了8个正行桶、284个测试点及16组坐标体积。有限例的来源集合与阈值详见证明包。Python 3.12.14 与 python-flint 0.9.0 的证书复跑逐字节一致。
