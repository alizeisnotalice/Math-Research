# 第751轮　共同去向的真实接收费用及多轴相反接触

对第750轮未付的同一积分，允许每个实际来源点安排一份总质量至多 \(L\) 的非负测度。某个目的地同时落入许多接收方体，就同时服务这些接收者。原接收权和原来源质量分母始终保留。

**两向都能合计付款。** 固定 \(B>0,\ 1\le L\le n^B\)。将父方体的半径乘以 \(q=(L\sqrt n\log^3(n+2))^{-1/n}\)。由发送者选择共同去向时，命中这些开内缩方体的真实总量至多为 \(O_B(\sqrt n M/\log(n+2))\)。由接收者反过来选择去向时，费用至多为 \(O_{K,B}(\sqrt n M)\)。\(M\) 是总来源质量，\(K\) 是原装填的逐标签帽常数。两向均无接收吸收费用。证明合并同一来源的所有共同去向，再使用经典的粗弱型界估计缩体项。[Stein 与 Strömberg，定理1](https://archive.ymsc.tsinghua.edu.cn/pacm_download/116/7398-11512_2006_Article_BF02384314.pdf)

**对第739轮所问的多去向情形**，在同一来源、同一价点和一档可比半径内，用实际接收权计算每个坐标要求向正、负方向内移的概率。若这些相反要求的条件熵之和不超过半个预算对数，一份共同的方向分布能覆盖该档至少一半的真实接收量。于是该档全部费用均可列入上述根号预算，方向之间允许相关。

写 \(T\) 为这次筛选前的完整未付流量，取 \(L=n^2\)。除去至多 \(\xi T+C_K\sqrt n M\) 后，每个保留的来源点和尺度档都能找到至多 \(2n\) 个同时在场的实际接收者。它们的方体在同一价点相交，并在至少 \(c_\xi T/(M\log(n+2))\) 个不同坐标上，同时把共同交限制到本档半径的 \(O(\log(n+2)/n)\) 倍。每个受限轴都有正权的两名接收者从相反两侧贴近这个价点。该结论可直接用于第750轮扣除之后的原量。**尚未受控的是这一批随来源点变化的共同交所承载的全部真实来源质量。**

**本机核验。** 两份有理方体配置分别枚举了168和68个原价格胞元。五环加孤立接收者的例子中，三个目的地的最优捕获率为 \(5/6\)，允许总质量同为3的分数分配后为 \(11/12\)，两者均有精确证书。五轴八接收者的实例还核对了条件方向损失和实际捕获率。256位 Arb 另查七个维数的标量公式，最高 \(2^{60}\) 仅代入公式。Python、SciPy、FLINT 版本和复现命令见包内 JSON。最终输出已独立复跑，逐字节一致。
