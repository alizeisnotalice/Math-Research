# 第288轮：小软度线性位移损失与当前近端正交通预算

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未认证闭合。本轮有实质新估计：将原小软度归一化核的平方位移损失提升为一阶位移损失，并接入实际连续参数菜单和来源积分。结合原完整软族近对估计，条件性支付当前两条 moving 核的近端正交通。全局回代缺口单独列明，不能把这一结论替代全定理。

## 新估计与实际积分
令 f_s=(1-s)h+sφ，b/2≤L≤A≤b，s,σ≤1/512，r=|y-v|/b，Ω=min(1,bC(r)/L)。归一化共同窗口亲和度满足

D_aff=Ω^(-1/2)∫_{Q_b(y)}√(p q₁) dx ≤ exp[-c(s+min(r,1))]，c=(25/2^68)/432。

关键是两个硬支撑的对称差长度≥2min(|y-v|,L)，其上平方根密度差的平方≥7/(8A)。小位移由此得到 D_aff≤exp(-47r/256)。归一化正确使用 Ω≥min(1,C(r))≥1-r；初稿的 Ω≥C(r) 已修正。大位移和软度损失使用R279已证界。完整解析证明、collar和全部常数见 linear_gap.md。

定义 D₁=Σmin(|y_i-v_i|/b,1)。实际 s≤1/1024,n≥1024时，原共同软度菜单σ_k≤s+1/n≤1/512，因此保持同一个c及B_c=18exp(4c)/c。原尾门

ns+D₁≥H_ε=1+(2/c)(B_c+T_ε)，
T_ε=log_+[(64Λ/3)e^(5/2)√K n³(n+1)/ε]

的两腿总价≤εW_β。保留原dx、完整Π、原high/FIRST/capture/history、实际唯一j；先固定原行后用菜单积分，未在换物理时钟后假设后验独立。所有菜单、collar、score、j和归一化费用已计入。第三条J核仍由R277单独支付，不混入小软度引理。

补集D₁≤H的score在原行估计，再换时钟。若H<n/2，

J_n(H)=H log(n/H)+(n-H)log[n/(n-H)]；

否则J_n(H)=nlog2；H=0时为零。统一有J_n(H)≤H[1+log_+(n/H)]。依R283，补集价格≤4Λκ₀J_n(H)S_D，其中κ₀=2+√n/8，S_D=(16/3)W_ρ+(1+logB_*)W_ν。R279留下ns+R₂≤D；当s>1/1024时n<1024D，原二次score价格≤16Λ(2+4√D)√(nD)S_D；n<1024时≤96Λ√(nD)S_D。因此这些物理例外也可支付。

对于固定合法Λ,K,ε，D,H=O(log(n+2))且B_*=O(log⁴(n+2))，上述当前moving近端预算为根阶乘固定对数幂。更一般参数必须保留T_ε中的依赖；不能先假定上游K(n)合法或增长受控。来源分别W_ρ,W_β,W_ν≤W，不假设ν≤β，也不假设三个预算不交。

附带保留两个经过审查的工具：D₁/R₂联合截断的精确score时钟积分，以及完整FIRST下的线性位移/最大坐标位移profile预算。后者是辅助结论，不作为全局分支已覆盖的凭据。
