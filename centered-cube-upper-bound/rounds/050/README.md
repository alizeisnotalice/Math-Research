## 已证明与被否定的接口

固定有限正分裂模式、固定阈值时，足够小扰动下部分簇捕获盒被完整簇盒严格包含，真实水平集精确等于完整簇盒并。扰动范围显式依赖最小细质量。完整簇盒也包含于对应重心移动源的接收盒，故中心分裂只有非正一阶变化。

对支撑于[-1,1]^n、各坐标本质端点均为±1的任意共同Borel profile，建立极端cap质量控制的双侧夹逼，证明固定来源、固定profile下同一一阶耗散；保留接触缝。连续三角密度否定精确完整簇支配；边缘越来越薄的密度族否定profile一致的o(ε)余项；细质量退化也破坏一致扰动范围。

阈值最优性给出的是耗散下界 λP≥2nλ^(1/n)F*，不能反读为F*上界。恢复原覆盖可通过降阈值或补质量，但分别留下最小质量依赖和N^(1/n)费用。没有取得来源一致的可求和总预算。
