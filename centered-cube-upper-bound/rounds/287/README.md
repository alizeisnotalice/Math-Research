## 一、实际几何覆盖的来源付款
沿第286轮共同来源随机首锚点分区C_k，使用μ=ρ/(4λ)+ν/q_-抽锚点，每个来源点分给首个距离≤2r的锚点。来源各自逐分区不交守恒。令

V=bⁿΨ_n(4r/b)，Ψ_n(u)=Σ_{k=0}^n binom(n,k)u^k/k!，
A(y,z)=E_partition Σ_k 1_Ck(y)1_Ck(z)1{ν(C_k)≥4λV}。

A在[0,1]，不依接收点、物理时钟与辅助槽。每个合格包的实际乘积响应≤4λ，硬响应支撑在体积V的Q_b+B₁(anchor,2r)中，所以其积分≤4λV≤ν(C_k)。不交求和后原A加权分支支付

P_A≤2Λ B_D Wν。

无K、κ或软菜单B因子；不恢复全部来源对，因此不需倒同簇概率。A可能为零，补集精确为原交通乘1−A。阈值V可达bⁿexp(O(n^(1/4)))，没有保证覆盖比例。

另给出完整硬最大帽排除内部立方体的壳层容量界：一般半径R0包，若mν>4λaⁿ，令t=min(b,(mν/(4λ))^(1/n))，则实际双包交通≤4λ[bⁿΨ_n(2R0/b)−(t−2R0)_+ⁿ]。小质量时只保留外体积项。严格端点与退化尺度带均在作者证明中核验。该辅助界不能自动支付全部中间质量区间。

## 二、无需全局来源熵假设的自适应捕获
M(z)=ρ(B₁(z,r))、N(y)=ν(B₁(y,r))，实际相对捕获cρ,cν沿第286轮定义；cρ可超过1，cν≤1。设

ℓρ(z)=2+logB+log_+(M(z)/(q_-aⁿ))，ℓν(y)=2+log_+(N(y)/(4λaⁿ))，J≥1，
τρ(z)=ℓρ(z)/J，τν(y)=ℓν(y)/J。

只要求cρ≥τρ的原分支，每物理时钟支付(3/2)J Wν；只要求cν≥τν的分支支付8BJ Wρ。另一侧捕获完全不需下界。硬方向保留B，不能改称logB。阈值由原来源和固定最小尺度决定，既不改来源测度，也不引入接收点依赖的阈值。若τν>1，硬分支为空，仍合法；软比值允许超过1。

证明同时利用自然点高度a_ξ^(-n)与一侧实际响应帽，用两帽弱乘积逐来源对积分，精确恢复近邻边缘。中间的对数邻域质量被吸收到显式自适应阈值，未假设其全局平均受控。详细全参数公式、传统适度对数质量分支和局部L1边界例均归档；该例不认证完整原历史。

2Λ B_D[(1+(3/2)J)Wν+8BJ Wρ]，B_D≤4√(nD)。
