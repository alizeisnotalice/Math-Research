# 第858轮　同一中央来源跨全部尺度的接触与分配

在第813轮的原双臂积分上，从中父 \(t\) 按 \(\mathbf1_{G_t}(w)\,d\mu(w)/D_j\) 附加一枚真实来源 \(w\)，其中 \(D_j\le m_t<2D_j\)。给定同一个 \(w\)，从全部物理窗、体积档和左右价格里独立抽两条完整历史。每份边际都保留原历史、完整度、两个来源分母及两处真实接收位置。[详细 LaTeX、五项本机检验及复算器](research.zip)

**跨尺度接触的估计。** 令 \(J=\sqrt n\log^8(n+2)\)。第一条历史取较大物理窗，第二条取较小物理窗。第一中父可按其真实条件律重抽两臂，每次可临时选左或右，也可在所选小父与中父的实际交盒内任取一点。把第二中父按 \(1+cJ/n\) 扩张，允许为这两位父共同略去 \(cJ/\log(n+2)\) 个坐标。若这样的接收仍可命中第一中父至少
\[
 \exp\!\left[-c'\frac{J^2}{n\log(n+2)}\right]
\]
的原双臂条件质量，那么这类父对在上述全部共同来源的测度下，总量至多 \(C e^{-c''J}V\)。这里 \(V\) 是原不交接收总体积。证明中固定第一中央历史，抽取约 \(n\log(n+2)/J\) 份双臂。能同时碰到每份接触集的任何方盒，其各轴边长之和通常至少为 \(cJR\)，其中 \(R\) 是第一物理窗的下端。将这一跨度放进第二中父真实所有者的逐轴交体积后，对所有来源只积分一次。

**在原质量上可以支付的部分。** 对每个 \(w\)，允许跨全部尺度选择最多 \(\exp(c\log^{16}(n+2))\) 个公共位置。若实际接触盒在指定容差与删轴范围内靠近其中一处，这些被标记的附源原量合计为 \(o(V)\)。另由实际臂的平方密度界，给出最坏来源割中一类连通分量的整批付款，所有这类分量共用一次 \(V\)。从附源量转为整条原记录时，须除以该记录的真实条件命中比例。

**仍缺的全局费用。** 许多中父可以共用 \(w\)，同时把左右接触分散到几乎互不接收的区域。对能调动很大实际小父容量的这类群体，尚须把最坏来源割的总差额控制在 \(O(\sqrt n\log^\alpha(n+2)V)\) 内。第813轮总账的原吸收系数保持有效，一般 \(n^{1/2+o(1)}\) 弱型上界仍未闭合。

**本机验证。** 在第814轮同一批920条四维原记录上，以逐右价独立全付的最小价格为预算，所有右价共用真源后，按真质量均分支付20.70%，最优重分配支付21.15%。两侧原接收者容量均未饱和。另在三个真实物理八度检验大小方向，在正宽交盒上精确枚举整盒换端与删轴，并用192位 Arb 在三个指定大维参数核验网格指数。四维原批没有实现高维大跳，维数渐近结论来自正文证明。
