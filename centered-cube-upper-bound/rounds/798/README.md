# 第798轮　两个实际接收点与三个物理父方体的共同来源割

第797轮留下的路径有一个大父方体 \(t\)、两个小父方体 \(u,g\)，以及两条原臂各自的旧交价和实际接收点。本轮证明，按两种真实容量支付后，只需检验同一组物理父方体内的记录。未付的一条路径，其三个父方体都必须把几乎全部真实来源留在同一个集合。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、计算笔记和复现材料](research.zip)

**物理父方体的检验。** 设 \(\mu=|f|\,dx/\lambda\)、\(S=\mu(\mathbb R^n)\)、\(\ell=\log(n+2)\)、\(L=\sqrt n\,\ell^3\)、\(P=(n+2)\ell^6\)。\(G_i\) 为父 \(i\) 在原割内可用的中间尺度来源集，\(\mu(G_i)\ge(1-C\ell^{-8}-e^{-r/2048})m_i\)，其中 \(r=\lceil\sqrt n\,\ell^2\rceil\)。每条记录可在两个旧交价及三父的实际外部来源中分配同一份 \(P\mu\)，也可在两个实际接收点分配同一份勒贝格容量 \(L\,dx\)。

扣掉已列预算的大源盒后得到原流 \(\Sigma\)。任取一组物理父方体 \(\mathcal I\) 和一个接收集合 \(W\)，令 \(\Sigma_{\mathcal I}(W)\) 为三个父都在 \(\mathcal I\)、两个原接收点都在 \(W\) 的实际质量。令

\[
D_{\rm phys}=\max_{\mathcal I,W}
  \left\{\Sigma_{\mathcal I}(W)
   -P\mu\!\left(\bigcup_{i\in\mathcal I}G_i\right)-L|W|\right\}.
\]

真实最小欠额 \(\Delta\) 满足 \(0\le\Delta-D_{\rm phys}=o(V)\)，其中 \(V\) 是原接收总体积，误差随维数一致。如果小父有正量可用来源留在割外，可以选一个点同时检验所有相邻大父，用原行估计支付。大父有来源留在割外时，所有相容小父的真实接收者一起落入一个体积可精确估计的扩大方体。两种费用都已对全部父和停止代求和。若两组父方体之间的 \(G_i\) 没有正质量交集，其来源费用、实际接收体积和三父记录分别可加。

**剩余记录还必须满足的条件。** 在同一物理子族上，继续删去流量不足的源点、接收点和实际出现的“旧交价、小父接收点”配对，每个位置按真实容量只付一次。剩下每个接收点 \(U\in E_u\)，在 \(Q(U,6s_u)\) 内都需要大量真实旧价，且这些旧价必须与另一端仍在使用的接收点实际配对。该联合参考质量至少为

\[
c\,e^J\frac{L^2}{H\alpha}\frac{v_u}{j_u}\,m_u,\qquad
J=\sqrt n\,\ell^8,\quad \alpha=e^{-r/2048},\quad H=O(1+\sqrt n/\ell^2).
\]

这里 \(j_u\le C v_u\) 是原历史质量，\(m_u\) 是小父的真实来源质量。反过来，每个仍有流量的旧价与接收点的配对，也需要足够多的实际接收体积。两条界使用同一份配对关系。若一个来源连通分量内相应正积分算子的 \(L^2\) 范数低于 \(c L^2/(H\alpha)\)，该八度在这个分量上的原量已全付。

**完整总账。** 本轮得到 \(R_{797}=P_{\rm paid}+R_{798}\)，且 \(|P_{\rm paid}|\le C(\sqrt n\,\ell^3 V+(n+2)\ell^8 S)\)。回到第772轮原峰时，上一轮的余项系数和吸收系数均保持。剩余缺口是同一来源连通分量内，多个小父可以重复使用同一批高权旧价与接收点，同时又被多个大父采用。上述双向下界还没有控制这种重复的总质量。

**本机复核。** 独立 Python 3.12.14 用有理算术核对三个连续低维输入的最大流、等值割和 \(32,512,4096\) 个候选割。三组最少欠额为 \(1/4194304,\ 1/524288,\ 541/50331648\)。压力例若把同一来源分别作为旧价和外部来源各发一次容量，欠额会被低估为 \(5/4194304\)。在另一个共享同一小父的例子中，实际出现的旧价与接收点的配对在共同参考下质量为 \(7/1024\)，把两个投影直接相乘会得到 \(11/1024\)。另用实际两臂原分母核对换序，并以 768 位 Arb 复核六组维数上的几何参数。前三组标量维数中，原硬体积差与同一八度不相容，已按空分支标注。低维计算验证所列积分和分配规则；高维估计的证明见 LaTeX。
