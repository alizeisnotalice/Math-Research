# 第194轮：稀疏位移与多硬面几何来源价

一般 n^(1/2+o(1)) 一致弱型上界尚未闭合。本轮两条具体几何分支通过独审并取得真实来源预算：硬核密度跳跃给多数坐标位移很小时的affinity间隙，保留全部自适应soft/scale成本后付根阶；短u-v位移坐标中足够多的current硬面交叉具有二项尾接收价格，连同原j/time费用给(32Λ/3)√n W_A。

先稀疏位移、再其补集上的多面分支可以不交结算，未证明两者覆盖全部剩余域。捕获率邻点比较仍保留nS、硬面和实际E/ν占用费用；小A同点匹配被旧RF更强界覆盖，不登记新付款。剩余是非稀疏y-v位移与不足多面的真实联合区域。

本机实际核验9个25/40位核例及9个精确有理二项尾例（n=2至512所列维度）。最终driver核验13个文件哈希，完整重跑两脚本，两份JSON逐字节一致。有限数值不认证FULL覆盖或一般维度阶数。
