# 第746轮　所有缩小方体内部互不相交时，原贪心仍可损失线性阶

对每个固定 \(c>0\)，在所有充分大维数都有同一类有限方体族，满足
\[
 D\le C_c V/n,\qquad P_0\ge (1-e^{-\Omega(n)})V .
\]
\(V\) 是全部缩小方体的真实并集体积，\(D\) 是原规则在完整输入上得到的贪心装填价值，\(P_0\) 是父方体的最优可行装填价值。**这次每个缩小方体的内部都与其余缩小方体的内部不交。** 因此每个标签的所有权在零测集意义下唯一，结论对全部合法所有权及任意并列处理都成立。第745轮反例曾允许通过重选所有权取得较大的贪心价值。

**证明。** 半径一的接收标签铺满 \(X=[-1,1]^m\times[-2,2]^{n-m}\)，其中 \(m=\lfloor n/16\rfloor\)。每个来源半径 \(s\) 各自使用边长 \(2s/(32n)\) 的网格。前 \(m\) 个坐标的外边界与 \(\pm s\) 精确对齐，只保留完全落入本档薄层和后部欧氏球内的闭格。各档薄层互斥，全部来源缩小方体又位于 \(X\) 外，其体积之和仅为 \(e^{-\Omega(n)}|X|\)。

对接收父方体内的测试点 \((0^m,x_{\rm 尾}/2)\)，每一档每轴几乎必有恰好 \(32n\) 个可能的来源中心覆盖这点。将连续均匀位移与这些中心逐轴配对，可证明每档平均原负载至少为 \(1-e^{-\Omega(n^{1/3})}\)，并严格保留内外边界。原贪心按半径递减处理 \(\lfloor n^{2/3}\rfloor\) 个来源档后，真实接收区的平均剩余容量仅为 \(O_c(1/t)\)，其中 \(t=c\sqrt n\)。代入每个来源和接收标签的实际权重即得 \(D=O_c(V/n)\)。

**与原攻坚积分的关系。** 完整输入的合法首次越阈见证、共同尺度和配对保持原定义。第706、739轮的账目给出 \(R_{\rm high}/V_T\to 1/2\) 及 \(\liminf M/V_T\ge13/32\)。固定满足第744轮条件的 \(c\) 后，仍有 \(\liminf R_{744}/V_T\ge17/64\) 及 \(\liminf\Delta/V_T\ge17/128\)。因此，在完整输入上先挑最有利的所有权，仍无法用这份 \(D\) 建立所要求的根阶预算。

**同一输入上的付款。** 给全部半径一的接收父方体赋权 \((32n)^{-n}\)，其他标签赋零，得到价值恰为 \(|X|\) 的可行装填。还可仅保留这批接收标签、重新运行贪心，所得 \(D_{\rm 子族}\ge e^{-1/t}|X|/(t+(32n)^{-n})\)，足以支付原来的完整 \(V\)。对任意有限方体族证明 \(V/P_0\le n^{1/2+o(1)}\) 仍是一般目标；一个可能入口是证明总能选出保留足够接收体积、且可由同一笔来源预算支付的子族。

**本机核验。** 用 Python 和 FLINT 对16、32、64维真实来源格分别计算两端半径档的平均原负载，以两种精度的整系数多项式卷积给出严格区间。64维的两个结果分别为 \([0.018459,0.020060]\) 与 \([0.011149,0.013054]\)，说明该维数离证明中的趋一阶段还很远。另用第二种算法核对九个坐标律，在12组256位 Arb 标量核验中，有5组同时认证 \(t^2D/|X|<2\)。超大维数只代入解析公式。
