# 第341轮：固定比例交通保留与局部来源预算

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮新增已独审的原交通付款，缩小上轮未付补集。

令L=nb、M(u)=∫Q_(2nb)(u)f、A={m_u≥ηM(u)}。同一个平移网格对每个实际捕获对(u,y)至少保留1/2交通。每shift按实际来源捕获比例p分层：p≥β以源格质量窗支付，p<β只支付其保留交通≤βXq(A)。从而

`G_out(A) ≤ 2βXq(A)+2[1+log(λ/(ηβq_-))]W`。

取η=exp(-√n)、β=ε/2，原槽变为

`B_H ≤ G_localbad+3εXq+{C_(ε,n)+2[1+√n+log(8/(3ε))]}W`。

原J、来源、真实接收测度和全部门保持。相比340，局部来源邻域从Q_(2nb/ε)降为Q_(2nb)，接收费用不增，来源费明确增加固定倍数与log(1/ε)。这替换旧支付，不重复收费。G_localbad及软层、极端尺度、初始/删除/未来被删来源等仍未付；完整总账见包内ledger.md。

本机实际检查：889项精确后验概率检查，832项主构造标量检查，另240个分块案例中的1440条等式、518项远质量比较、3项诊断断言。均用Fraction；普通浮点只作显示。后验试验无原高过去门，不当作完整交通证据。辅助分散/分块恒等式没有另记根阶付款。
