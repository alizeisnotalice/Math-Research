# 第623轮：全局坐标负载与联合保留费用

一般 `n^(1/2+o(1))` 一致弱型上界仍未闭合。本轮给出原始完整有限方体族上的合法权重机制，并准确保留其尚未支付的半径膨胀与共同来源修复费用。

- 已独审：允许梯度方向随位置变化的 top-k 坐标几何给出全局负载系数 `C(n,k)≤2n/(k−1)`；原行权重保持全来源同时可行。取k约为根号n只降低负载系数，不能据此宣称完整根阶上界。
- 已证明精确删除收益、同一来源负载修复的有限规划公式。真正未证的是保留真实接收量且能支付修复的统一联合估计；充分交换条件明确标为未证。
- 整行生成区域必须保留中心移动费用。全锥体积与实际负载系数简单相乘的粗模板仍有线性费用；此结论不限制最优删除、联合付款或原问题。
- 对指定周期点源模型，严格有理证书给出96维未裁剪平衡构造值小于0.013900；不能把它外推为一般输入结论，也不能不调整系数就用于其他构造。
- 有限数值诊断、独立新样本、精确有理算术与Arb区间检查分开记录；原输入、种子、版本、哈希和资源占用见复现包。
