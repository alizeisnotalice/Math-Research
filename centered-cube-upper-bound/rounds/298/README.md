# 第298轮：有序共同见证与可认证的分式覆盖

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮主攻全局极值几何中的跨尺度共同覆盖，不以特殊输入实验代替一般证明。

## 已证明的条件性付款

固定原始接收场及来源，保留完整 e_g、m、q、FIRST、low 与 m>M、硬帽、历史和来源掩码，接收积分始终是实际勒贝格 dx。所有以下费用是原场内的 raw 费用，仍需乘原外层 Lambda 并完成原全局账目。

1. 从同一行真实接收分布抽取 N 个实际见证，把每个硬来源分给包含它的最小半径见证。定义 C_y(t,z) 为半径不超过 t 且捕获 z 的接收概率，则精确平均掩码为 H_N=1−[1−C_y(min(L,R),z)]^N。逐个配置先应用第297轮自身尺度定理，再平均，得到 T_HN ≤ (16/3) ψ∞ κ0 N Wβ，其中 κ0=2K/(ell M)，ψ∞=3−2/(3γ^n)。没有按尺度窗口重复支付整份来源质量。C≥log(2)/N 分支费用至多两倍。取 N=ceil(sqrt(n)) 后仅该分支具有 κ0 sqrt(n) 费用；只有 κ0 及外层费用得到相应控制，才可称根阶预算。
2. 对已付远尾之外的近来源对，将接收行限制在距 y 不超过 (D+1/2)b 的区域，近交通的捕获分子完全不变，归一化分母下降。因此近捕获概率单调增加，无额外网格费用。
3. 对实际带硬帽的有限见证菜单和完整包含的目标单元，分式覆盖成本 τ 与最优共同归一化捕获 g 满足 τ=1/g。显式原始/对偶可行解同值即为最优性证书。可测行系数与完整单元覆盖是回代条件，不假设数值优化器自动提供一般可测选择。

## 剩余缺口及费用

精确残差为 T_(1−C)^N。L≥R 时获得包含原子情形的 CDF 秩不等式，但实际积分仍带 r^(−n)；现有粗界仍含 WβWν/(q_- a^n(N+1))，不是一般来源线性根阶费用。L<R 时 min(L,R) 与实际硬半径不匹配，不能沿用该秩增益。

尺度分布稿保留每个来源的跨层重复次数，并给出条件化 KL 费用；没有删除这些费用。一个短标量放松例仅定位缺失的几何前提，不是原立方体算子反例。全体弱捕获来源的低成本覆盖、集中费用以及原始初始/跳跃/删除和外层账目均未被本轮自动解决。

## 实际检验与复现

本机 MATLAB R2026a Update4 + Optimization Toolbox 实际运行两轮 linprog；15 个有限菜单（n=1,2,4,8,16）两轮结果一致。包含9个点目标案例、6个正体积单元案例；完全包含用整数坐标判定，部分相交不记作覆盖。Python Fraction 重建并精确验证全部原始/对偶可行性、零间隙及共同概率证书。主代理另外复跑有理验证。正体积三角案例均匀捕获153/700，优化32/75，τ=75/32；这只是该有限菜单的精确最优值，不推出一般维数阶。

有序见证主代理复跑：16160 配置、304 iid 恒等式、76 秩不等式、580 来源费用、528 阈值检查全部通过。三个阶段为同半径与并列、不同半径与边界、扩大到分离三维菜单。来源尺度复跑：45位 mpmath 下18个积分比较、100个 KL/Jensen 检查通过。有限模型不供应原始 FIRST/low/high 历史条件。

解压 research.zip 后，保留 r298_ 文件名，将复现文件放入 /tmp：在 MATLAB 中 run('/tmp/r298_cover_lp.m')；用 Python 3 运行 /tmp/r298_cover_verify.py、/tmp/r298_ordered_checks.py；/tmp/r298_variable_checks.py 需要 mpmath 1.3.0（本机已有 vendor）。MATLAB 和 ordered 脚本将 JSON 写到 /tmp；Fraction 脚本读取/输出相邻文件。manifest.json 绑定全部文件。证明与独审详见三个 md、audit.md 及 proof.tex.txt，不编译 PDF。
