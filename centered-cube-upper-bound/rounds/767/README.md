# 第767轮　不同小父和来源点的重复费用

第766轮已处理固定小父和来源点上的全部大父。本轮在同一份原积分中，把不同价点、不同小父、不同方向对同一位置的收费相乘，再对真实来源测度 \(\mu\) 积分。两条关联各自保留其大父真实质量分母。

**跨来源的估计。** 对每个保留的大父 \(A_t\) 和小父尺度档 \(s\)，取一块真实来源 \(C_{t,s}\subset A_t\)，其质量至少为 \(p_0\mu(A_t)\)，其中 \(p_0>0\) 固定。它在任意位置附近的截断距离球中都只占指数小的质量。因这些集合随小父尺度嵌套，剔除质量不足的全部档只需付一次 \(V/512\)。由此可用立方体交体积估计另一来源点上所有不更大的小父，见式（2）、（3）。

**全局二次费用。** 对任意保留子流 \(I\)，记原质量为 \(Y\)，令 \(\Phi_I(x)\) 为其各大父在 \(x\) 处按真实分母累加的密度。远尺度大父对对 \(\int\Phi_I^2\,d\mu\) 的贡献至多 \(C\sqrt n\,V\)。这是对全部价点合计的界。两大父对数体积差至多 \(L=\sqrt n\log^3(n+2)\) 的部分至多为 \(C(1+L)Y\)。对中间尺度，式（6）给出只用实际原根流量、父方体几何和质量分母的量 \(H_{t,s}\)。凡 \(H_{t,s}\le L\) 的原流量合计至多 \(T_0/256+C L\|f\|_1/\lambda\)。证明见式（4）至（7）。

**仍须证明的收缩。** 把本轮实际损失放回第766轮总账，得到
\[
 \frac{1967}{2048}\,T_0\le R_{767}+C L\|f\|_1/\lambda .
\]
余额上的每条关联满足 \(H_{t,s}>L\)。当很多不同小父、不同来源点同时到达同一批中间尺度大父时，还缺少对这部分总流量的固定比例上界。
