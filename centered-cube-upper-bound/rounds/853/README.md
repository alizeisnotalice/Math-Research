# 第853轮　固定真实来源后的四点共同接收体积

固定第852轮完整幸存事件、同一侧第一中父 \(y\) 和实际端点 \(s\)。本轮在保留另一枚原端点 \(u\) 的同时补抽两个真伙伴，使四个点在同一真实中父上构成四种配对。所有使用 \(s\) 的中父和尺度共同结算。[详细 LaTeX、四份本机程序与实际输出](research.zip)

## 可回代的估计

第 \(j\) 档的最大边长为 \(U_j=2^{j/n}\)，双侧最小正度为 \(\Gamma_j\)。四枚真实来源在第 \(i\) 轴的跨度记为 \(\Delta_i\)，其共同接收中心的归一化体积为 \(p_j=\prod_i(1-\Delta_i/U_j)_+\)。证明还允许把这个乘积换成更小的实际接收体积，并保留各档接收者的不交性。设 \(r(s)\) 是固定 \(s\) 的原行总量，\(N_j\) 是保留原端点、补全四角后的三伙伴密度，则

\[
  \sum_j\Gamma_j^3\int \frac{N_j^2}{p_j}\,d\eta^3\le 4r(s).
\]

在原边上补全的质量分母可很小。证明先对它的倒数作实际来源积分，再保留同一四点在所有坐标上的交宽。若所标三伙伴集的加权体积为 \(\mathcal C\)，相应原质量至多 \(2\sqrt{\mathcal M\mathcal C}\)，其中 \(\mathcal M\) 是冻结双臂事件的原质量。

还可直接在一枚原边上结算。对固定 \(s\)，给全体档和伙伴 \(u\) 的价格合计至多 \(\lceil\sqrt n\rceil\)。实际四角补全质量、原中父的边长及所有相容中父的真实接收体积共同决定可付的比例。左右源块在不同接收者上允许重新配对，固定价格、选配关系和来源预算的依赖顺序见证明。

## 计算与总账

本机 Python 3.12.14 运行有理算术、192 位 Arb 及 CVXPY/Clarabel。16维同批真实源包上，让配对随接收者变化，三标签和五标签配置的收入分别为固定配对的3倍和5倍。正宽包模型中，若有 \(2^{n/2}\) 种不同伙伴，随机两父的归一化重叠仅为 \(2^{-n/2}\)，四点跨度仍给出整个固定来源行的显式上界，在该族所有偶数 \(n\ge2\) 至多为 \(363/625000\)。程序枚举4、8维的实际父，在 \(2^{21},2^{22},2^{24}\) 维用相同几何公式做区间复核。另在38条真实来源行上用有理算术检查四角补全分母的倒数估计。各样本采用的具体门见归档。

若所选三伙伴集满足 \(\mathcal C\le K_n\|\eta\|\)，回代整根时可支付一次 \(\varepsilon_2 I\) 及 \(O_{\varepsilon_2}(K_n\|\eta\|)\)，其中 \(K_n=O(\sqrt n\log^4(n+2))\)。直接按原边价格支付的部分无需新增吸收。一般输入中，跨多档的幸存来源能否获得足额的统一价格、或其余三伙伴集的累计容量能否满足该界，仍待证明。第813轮双臂原费用及第739轮全尺度上界仍保留。
