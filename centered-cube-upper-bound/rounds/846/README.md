# 第846轮　同一右来源的早期伙伴与真实来源的坐标分布

取第845轮仍未支付的记录，并在原接收者、左来源和右来源上取其边际 \(F\)。这一步保留该余项的全部质量。记 \(S\) 为实际来源割的质量，\(\ell=\log(n+2)\)。[完整 LaTeX、两份精确计算及输出](research.zip)

## 同一来源在不同尺度的累计占用

固定真实右端，将每枚左伙伴在各早期体积档的真实接收质量除以该来源对的允许交体积，得到占用 \(q_i\in[0,1]\)。每枚伙伴在旧档中按 \(\max_{j<i}q_j^p\) 只计一次。可按右端的实际伙伴分布预先分胞，同一胞内允许许多旧伙伴和许多不同接收者。对 \(p=1,2\)，新的对数势在全窗沿尺度求和后至多为 \(CnS\)。因此，两端任一项达到 \(\sqrt n\) 的**原记录**合计至多为 \(C\sqrt n\,S\)。未达到门槛时，正文给出当前实际交体积和单胞载荷所要求的逐记录旧伙伴质量。二次占用保留两次真实接收位置和两个见证分母。

## 从原来源提取可支付的厚层

对每轴支撑长度有统一上界的概率乘积，证明了全窗极大函数的积分上界。在细格间距为 \(O(n^{-1/2})\)、单轴小区间质量符合正文上帽时，只需 \(O(\sqrt n\ell)\)。允许 \(O(\sqrt n\ell)\) 个粗轴任意相依。对实际来源，若在同一底胞位置的若干格位能提取占据比例至少 \(b\) 的层，则跨全部观测合计，这部分原质量至多为 \(C\sqrt n\ell\,S/b\)。高载荷余流如仍有上述细格边际，其真实条件律相对于这些边际的乘积分布，至少要有 \(\log\ell-O(1)\) 的相对熵。
