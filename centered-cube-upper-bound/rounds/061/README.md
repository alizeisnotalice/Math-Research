## 严格结果

- 对任意有限正原子来源及其原好集合，证明总密度受限的有符号替换问题存在松弛最优输出；精确质量与次质量问题的下确界相同。给出直接证明的对偶公式、非负间隙恒等式和阈值最优性条件。对偶测试给下界，不能自动支付所需上界。
- 给出保留来源位置的有限 Hall 分配：每粒质量移动不超过其到原好集合的距离，总密度不超过 3^n H。精确容量常数满足 2≤Γ_n≤3^n；O(n) 或适当对数损失的高度仍未证明。即使改善高度，整体有符号混合误差仍须另付预算。
- 证明真实 cap 内的接收点面采样障碍：密度平面边界处的小尺度误差能量为零，邻近点的极限为 n[1/n−1+exp(−1/n)]/4>0。因此接收网格对齐替换密度边界会低估能量。此结论用于修复数值方法，不是弱型反例。
- 保留实际来源的标签拆分反例：同一原子拆成 N 个标签后，总误差不变而对角迹缩小 N 倍。不能用对角迹替代完整混合二次型。
