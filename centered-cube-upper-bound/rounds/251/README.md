# 第251轮：阈值共同短窗与来源簇弱型费用

一般 n^(1/2+o(1)) 一致上界仍未闭合。本轮严格证明：任意正L1来源μ支撑于边长d的立方体，任意0<a≤b、u>0，

    u |{M_[a,b]μ>u}| ≤ [2+n log(1+d/a)] ||μ||_1。

关键是按阈值r=(||μ||_1/u)^(1/n)分区；外部接收点共用长度不超过d的尺度窗。d=a/√n时单簇价格≤2+√n，无须簇内平坦或乘积结构。多簇仍保留完整支持交叠熵，原软层和双后验回代尚未闭合。

[研究包](research.zip)含详细LaTeX文本、独审、两条证明、失败路线记录和必要复现材料，不编译PDF。仅新增本说明与ZIP，并更新项目总览。
