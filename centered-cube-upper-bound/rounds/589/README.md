# 第589轮：共同坐标切分、出生修正与联合删源预算

日期：2026-10-24。一般中心轴平行方体极大算子的 `n^(1/2+o(1))` 一致弱型上界仍未证明。本轮研究完整输入的共同变形，保留全部真实来源、接收并集和费用；没有把变分恒等式当作根阶估计。

## 本轮结果与决策

- 建立完整单带近极值输入的有限删源、增源、共同保留及坐标切分约束。保留实际亏损，不能把近极值直接视为驻点，也不能把中间子输入默认视为近极值。
- 一次性剔除 `Zε=∪ᵢ Q(zᵢ,(mᵢ/(ελ))^(1/n))`，费用至多 `W/ε`。取 `ε=min(1/4,n^(-1/2))`，使每个剩余父内的原标签质量均小于 `εM`。该费用只付一次，原 H₂、top、base 与完整半核心并集 H 均保留。
- 同一全局坐标顺序提供真实的半质量 prefix/suffix。严格多数可以产生质量增长，却同时丢掉中央分位间隙的臂长；不同尺度、反向顺序和同 pivot 的费用不能省略。
- 共同坐标切分的精确总账为 `λ(|Gcross|+|Gupper|−|Loss|)=λ|E_h|−λ|E_0|`。必须枚举全部原子子集，包括压缩后从负宽出生的盒；只膨胀原有正体积并集会遗漏真实接收面积。
- 保留同一份半质量删源预算下的全坐标乘积约束。一次共享 Bernoulli 删除确实只支付一次来源期望，但仅靠质量集中，恢复系数仍大于 1；完整共同半核心事件的并集增益没有得到下界。
- 固定原子数的全尺度极值可在归一化紧参数域达到，但尚无原子数一致的估计。普通嵌套交叠就能产生负的光滑二阶项，不能只用单父凸性并扣除接触原子来代表完整并集。

以上是完整机制的合法约束、必要修正与未闭合尝试，不是一般上界的维数改善。两个失败机制均针对确切推导步骤，不否定原目标。

## 完整剩余与费用

沿用第588轮：`gₙ=1+(log n)/4`，`J′=λ|R′|`，H 是全部原合法半核心的完整载体并集，不能用局部臂或裁剪图像替换。当前仍需证明

`gₙ λ|R′\Zε| − λ|H| ≤ D₀,ₙ W`，且 `D₀,ₙ/gₙ=O(√n logᴬ(n+2))`。

该估计若能在完整单带近极值序列上统一成立，才有条件递推

`Bₙ ≤ 2√n+5+1/ε +(4/gₙ)Bₙ +D₀,ₙ/gₙ`。

`4/gₙ` 包含半阈值及两段真实质量带；先取得统一吸收，再支付一般输入恢复因子 `Nₙ=2+ceil(log₂(32n²))`。所有前置、出生和来源费用都保留。共同切分的纯侧覆盖损失、跨父共同事件增益及嵌套交叠费用仍未统一支付。
