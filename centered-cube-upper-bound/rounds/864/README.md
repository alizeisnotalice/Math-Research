# 第864轮　按真实来源选择坐标位移与全窗共同付款

固定一个真实来源，它可以在各父和历史共用的一次发送中，自行选择怎样分配各坐标的移动幅度。对总幅度不超过 \(2^{-96}R\log(n+2)\)、每轴至多 \(R\) 的方案，两父共用振幅并分别取随机符号。若所有物理窗、所有真实来源送出的单位置边际合计至多为 \(n^a\,dx\)（\(a\) 固定），则任一端已准入的原记录都可以按 \(C_a[\mathcal H\mathfrak j(A)+n\mu(B)]\) 付款。两个端点都只准入一部分时，可付其准入比例的最大值。本轮没有新增吸收费用。[详细 LaTeX 证明、三项本机复现及实测输出](research.zip)

**方体几何。** 在固定源价和同一振幅下，按原体积档合并所有父。用不交接收者的真实勒贝格测度上界靠近许多方体面的父权，充分大维数下坏档尾至多为 \((n+2)^{-7}\)。其余父共有的符号命中率足以支付该端的原质量。整个估计保留真实中父、小父、原来源分母与另一臂的完整度。

**可达范围。** 对任意公共双位置方案，在固定真实右源密度层上，需要的物理输出主要落在这些右源的 \(O(R\log n)\) 的 \(\ell^1\) 邻域。在两片不同方向的正宽条纹上，选择对应坐标可以使两块合并的输出密度至多为1。另一组周期输入给出了这一机制的局限。即使允许任意方向和多项式输出密度，对数距离内可搬出的真实父来源份额也可能指数小。直接计算同一输入的方体平均可得单窗弱比至多为 \(1+o(1)\)。

**核验。** 同一批四维920条原记录中，总幅度 \(R/32\) 和同一输出上限下，沿第4轴的方案在两端同时命中1.5301%的实际原质量，按真价自适应的方案命中1.4817%。其余实验分别核验大维条纹的真实容量，以及多组相位集中时的可达体积。四维记录不满足高维完整度和质量差条件。三个实验的代码、参数及严格数值范围均在证明包中。

**剩余缺口。** 对任意正输入，两端在上述距离内都几乎无法搬运的原质量仍须整体控制。多组相位的例子表明，短距离可达性与该输入对极大函数的实际贡献可以差得很大。一般单窗次线性及全尺度 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。
