# 第82轮：共同来源运输与极低背景分支

日期：2026-10-11。**一般平方根上界仍未证明；全一般保留基准仍为 O(n log n)。**

本轮新增任意正 L1 输入上的一般支付：在真实物理窗口 `[1,2]` 的选定尺度，若硬平均越阈且平滑/硬平均比值低于正文明确给出的 `exp(-s_n)/2`，则接收弱费用为 `2(1+n log2)/sqrt(n+2)`。证明使用实际同源似然和参考立方体方向锥；不假设来源坐标独立。未支付的中间比值区域仍需一般几何估计。

共同来源运输有精确 Hall/最大流表述与紧致连续实现。真实 L1 多尺度输入族上，固定后验的旧来源负担随深度无界，而显式共同重分配的容量可统一取 `1/15`；这一特殊族用于检验一般支付机制，不替代一般证明。

另有真实 L1 构造说明：未支付的中间区域仍可有任意大的方向信息和坐标相关性；原保留门槛下首达来源也可几乎全为负方向。负方向及分支边界费用不能免费删除。所有构造均明确列出适用门槛、正体积持续性及不否定主弱型目标的范围。

## 交付与验证

`research.zip` 仅含7个成员：`proof.md`、`proof.tex.txt`、`entropy_probe.py`、`entropy_results.json`、`transport_probe.py`、`transport_results.json`、`inventory.json`。详细证明、数值范围、未决接口与独审报告集中在合并报告中。LaTeX 只作静态检查，未编译或生成 PDF。

解压后执行（仅标准库，实际运行 Python 3.12.14）：

```sh
python3 -B entropy_probe.py
python3 -B transport_probe.py
```

报告中的四个 Python 代码块依次为 transport、conditional、oriented、audit 核验脚本。主代理实际重放两个主程序，输出 JSON 逐字节一致；四个核验脚本均执行通过，并从最终归档再次执行可移植独审。完整回执、输出和哈希在清单中。

- 运输：17个实例、123599个完整 dx 单元、34个精确 Hall/最大流最优值、1402个来源子集条件。独审另重建全部几何单元、暴力计算全部割并检查2669条流量弧。有限网格超调与连续首次接触严格区分。
- 熵：120个有限共同联合律、333个真实 L1 有理首达点、四档积分复核；独审采用另一积分变量复算。对数和求积数值不作为区间证书。
- 解析接口：真实角向锥的一般支付、未付中间区域反例、全窗口负方向构造、严格越阈的邻域极限修复。不同来源的独立有理指数包络另证连续平滑门槛，未以网格扫描替代连续上界。

实际复核64项技能入口和437个直接引用，相对第81轮未变化；仅此可读性核验不认证全部工具。覆盖、软层与硬面使用 Astra medium，数值实现和独审使用 Sol high。
