## 新的极值几何估计

对任意Borel来源包μ=mπ，支撑于B₁(z,r)，实际自适应硬响应F=mL(x)^(-n)π(Q_L(x))若满足自身双帽cλ≤F≤λ，令ℓ=log(1/c)、v=2√(2nr/a)，则

- ∫F≤m(2+ℓ)(3+ℓ+v)；
- ∫F log(1/p)≤m(2+ℓ)(3+ℓ+v)²，p=π(Q_L(x))。

证明使用精确Minkowski体积 |Q_U+B₁(r)|=UⁿΣ binom(n,j)(2r/U)^j/j!。捕获概率每层由自身高度帽限制到O((1+ℓ)/n)的对数尺度窗；再结合真实l¹支撑体积作可求和估计，没有无限次重复支付同一来源质量。
