# 第794轮　真实隐藏臂的降尺度转移与终端来源预算

在第793轮的完整原余量上，本轮把所有微尺度块、所有中父和各代共用终端的部分费用合并到同一份来源质量。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、数值检验笔记及复现材料](research.zip)

**同一条原路径现在有两个真实的降尺度转移。** 每个中父只抽一条原历史，所有检验共用一个均匀阈值。对整张表取平均，精确恢复原两跳峰和共用的中央接收点。在固定一侧真价及规范化接收位置后，按实际质量和全度给出的权重排序，只给首次合格的完整对侧臂记账。在其余真实行上作一次保持长度的平移，产生更小的中父。任何由该方向合格记录构成的子流，经转移后仍受同表的原流支配。整八度两侧的体积档各至少下降 \(c\sqrt n\log(n+2)\)；两侧子方体的交体积除以各自体积的几何平均，至多为 \(\exp[-c\log^2(n+2)]\)。两方向使用同一个中央接收点。

**一笔覆盖所有停止代数的来源费用。** 将每个原八度内的中央物理体积档分成宽至多 \(\lceil\sqrt n\rceil\) 的连续段。保留原小端参考，支付初始低累计量后，在段内交替转移直到停止。令 \(A_t=Q(c_t,s_t)\) 为终端。每个最初的中央接收点都在 \(H_t=Q(c_t,\sigma_n s_t)\) 内，\(\sigma_n=O(n^{-1/2})\)。在真实接收者的并 \(\mathcal E\) 中，计算
\[
D_*(y)=\int_{\mathcal E}\max_{\{t:\,w\in H_t\}}\frac{\mathbf1_{A_t}(y)}{\mu(A_t)}\,dw,\qquad
p_t=\frac{1}{\mu(A_t)}\int_{A_t}\min(1,D_*(y)^{-1})\,d\mu(y).
\]
空最大值取零，取倒数时约定在零处的截断权为一。每条路径只停止一次。最初接收点的全局勒贝格密度至多 \(C(n+2)\)，所以所有来流按 \(p_t\) 加权合计至多 \(C(n+2)\mu(\mathbb R^n)\)。权重中的最大值允许不同中父共用同一接收区。报告式（10）按同一点所有终端中心的坐标跨度进一步估计此数。

**回代与缺口。** 记 \(\ell=\log(n+2)\)，\(S=\|f\|_1/\lambda\)，\(V\) 为真实接收总体积。已付子流满足
\[
 R_{793}=P_{\rm paid}+R_{794},\qquad
 |P_{\rm paid}|\le C\bigl(\sqrt n\,\ell^4 V+n\ell^8S\bigr).
\]
上游对 \(T_0\) 的原有项仍为 \(C\sqrt n\,\ell^{10}S\)。未付路径的终端有至少 \(1-\ell^{-4}\) 的真实来源质量落在 \(D_*>\ell^4\) 的区域，且两端各自预选的独立终端中心都很难命中该终端。尚缺这批路径的总量界或统一收缩。

**本机核验。** 在 \(4,8,16\) 维真方体上复算同一张表的历史筛和 36 组秩平移。两条路径分别走一步、两步到达同一段，精确地用掉两份单代预算。正反各 1225 组有理单轴数据核验了不同半径的交体积公式。对 5、17、33 个物理终端按来源和接收点两种顺序核算费用，结果完全相等。在最高 1024 维的诊断格上，集中到 24 个单侧坐标才使该样例的共同终端费用降至一以下。几何与标量样例的范围分别记录在报告末节和复现清单中。
