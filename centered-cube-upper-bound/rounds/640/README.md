# 第640轮：接收加权捕获的全族上限与真实费用

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮继续同一次完整方体位移、新族自身正则最优权和真实接收测度，没有缩小最终输入范围。

## 决定下一步的全族估计

固定同一旧 KKT 来源 μ、完整位移 Z 和一个共同新顺序，设真实新接收增量为 wj、来源总质量为 M。每个新方体 Cj 的体积 mj≤M。对每个来源点，包含该点的所有 Cj 的接收体都位于一个体积 PM 的方体中，因此

    Σj wj μ(Cj) ≤ PM²。

这是整个真实族、全部尺度的解析估计，不使用来源密度帽或有限数值外推。

本轮先从新 KKT 得到保留 mj、新总质量反馈和真实接收权的捕获下界，并用捕获降序实现合法共同排序。但上述全族估计进一步证明，在困难分支，这份 Jensen 捕获保证 Lcap 总满足

    Lcap ≤ (VZ−RM)+ + PM。

因此仅依赖这份保证，仍几乎必须让真实接收并集本身超过 RM，不能靠继续调整该捕获公式支付大规模接收亏损。这个结论只限制推导所得的保证，**不**上界实际 Dε、实际新权捕获项或来源未利用量，更不否定一般目标。

下一步继续同一个完整对象，保留实际新最优权 α 和完整来源账

    Dε = VZ−RM + R∫(1−Lα)dμ + RΣj αj μ(Cj\Aj)。

这两个真实信用的联合几何估计仍未解决，不能把它们换成当前粗下界后继续期待根阶付款。

## 其他核验与准确停点

- 全源行 mj=M 构成真实 box universal clique，其接收尾部总量≤PM。新正则 join 给明确的信用继承公式；真正删行后还要重算剩余接收增量。已核出全区间 ε-Lipschitz 和真实增量扰动的平方根费用，但其 R 倍代价尚未统一支付，不能免费按标签数归纳，也不能声称删除保持困难。
- 准备使用的“Qε 对全部合法 owner 质量向量凹”被严格否定。反例采用二维真实方体、全正 Lebesgue 分区和有理根区间；Jensen 缺口严格介于 −10^-12 与 −10^-13。它仅排除这条凹性推理，不否定所有顺序极点策略，也不是一般上界反例。
- 保留固定 N 终端、同一 ε、新真实增量、删零规则和全尺度一般输入的条件恢复。没有新增标签权限，没有未声明的密度帽、最小权下界或活动面假设。
