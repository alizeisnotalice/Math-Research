# 第446轮：统一软距离容量与实际未匹配量

本轮用单个幂衰减容量统一支配逐记录预算受控、半径不小于原阈值的距离层混合。通过真实双捕获饱和估计及原流一次拉回，可匹配部分获得根阶乘对数的来源价格。没有证明完整软容量缺额预算，一般上界仍未闭合。

有限中心块模型中，同一容量系数下匹配质量从0.32提升至至少0.557406062，缺额仍至少0.0625663816（均须乘实际θ²）。Arb整块界、有理最大流和cut证书严格夹住连续模型最优值。该模型不满足原质量门，只作为机制选择证据；辅助141项及3组精确检查仅核代数。
