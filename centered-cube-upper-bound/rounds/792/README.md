# 第792轮　两个真实交价的联合几何预算与跨中父配对

一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。本轮在第791轮整份剩余 \(P\) 上，合并了所有起始记录和中父。两个交价 \(x,z\) 取自原来源，接收量取自原来互不相交的实际所有者。所有旧筛、度分母及两条路径共享的中央历史均保留。[详细 LaTeX、数值检验笔记与复现材料](research.zip)

**两套接收体积如何合计。** 固定公开端和中父体积档 \(D\le m_v<2D\)，写 \(r_D=(2D)^{1/n}/2\)，\(s=(1+1/(32n))r_D\)。对另端可能位于的轴盒 \(B\)，中父的接收体积受以两个真价为中心的方体交体积控制，小父的接收体积受 \(B\) 按小父半径扩张后的体积控制。这给出报告式（3）的同一积分预算。其两向费用各为 \(C(n+2)Y/L\)，其中 \(Y\le C_*V\)，\(L=\sqrt n\log^3(n+2)\)。

由此能支付所有符号方向上的一整类峰。写 \(J=\sqrt n\log^8(n+2)\)。若除至多 \(\lfloor J/(32\log(n+2))\rfloor\) 条轴外，两个真价每轴的绝对距离都在 \(r_D(1\pm J/(8n))\) 之间，那么所有这些峰合计至多 \(Ce^{-J/2}(n+2)Y/L\)。包括全部 \(2^n\) 个符号组合。

**同一来源在不同中父间的重复使用。** 给定真实第一价和体积档后，从条件分布独立取两条完整原记录。以 \(\Lambda_O\) 表示该八度原小臂的价格参考，\(g_{x,d}\) 表示对端真价相对它的归一条件密度。报告式（7）支付了 \(DLg_{x,d}\ge e^{-b/128}\) 的整批峰，\(b=\lfloor\lceil\sqrt n\log^2(n+2)\rceil/(65536\log(n+2))\rfloor/16\)。另以一个公共价格分布抽样形成矩形，报告式（8）至（9）支付了其在真实中父内能从各坐标两侧括住对端价格的整组记录。各轴的价格允许相关。

**总账与缺口。** 令 \(R_{792}\) 为剔除这些已付部分的同一正测度，\(S=\|f\|_1/\lambda,\ \ell=\log(n+2)\)。有
\[
 (1-\delta_0)|Q_{772}|\le k|R_{792}|+
 C_{\delta_0}(\sqrt n\,\ell^9 V+n\ell S),\qquad k=O(\ell).
\]
剩余两端的条件价格均可非常分散。跨不同起始记录，没有得到一份覆盖足够多共同来源的分配，也没有证明一致收缩。原问题还需要 \(|R_{792}|\le C\sqrt n\,\ell^\gamma V\) 或足够的替代估计。

**实际验证。** 在 \(4,8,16\) 维的真实方体及非均匀来源上，用有理数重算了 \(141,974,5616\) 条两价记录的配对。八维真价配对中，两中父相隔至少两个体积档的比例约为 \(22.78\%\)，从中父另抽公共点时约为 \(13.64\%\)。四维同比缩放压力例区分了保留私标记和丢弃标记的原命中率。在 \(1836\) 个轴盒上核验了两套实际接收体积，另穷举三组符号盒和六组随机占位例。四个大维数的标量折扣由 256 位 Arb 严格包围；低维模型使用诊断筛，未实现完整近极值入口。
