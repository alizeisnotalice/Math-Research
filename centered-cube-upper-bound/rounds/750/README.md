# 第750轮　用已读坐标选择位移的全尺度接收估计

固定大方体 \(A_j\)。对所有比它小的方体使用同一套位移规则。规则可以依次查看真实所有者点已经揭示的坐标，再选择下一轴和该轴的位移中心。每轴另加宽度为 \(\epsilon\) 的独立三角噪声。记 \(q_{ij}\) 为这套规则从小中心移入 \(A_j\) 的概率，在小方体的真实所有者 \(E_i\) 上取平均。\(p_{ij}\) 为原交集的来源质量占小父方体来源质量的比例，也可以先限于第749轮未付的关联。

本轮证明，对全部小方体和连续半径一次求和，有
\[
 \sum_{s_i\le s_j}|E_i|q_{ij}
 \le h^n\left(1+\sqrt{\frac{8n}{3h\epsilon}}\right)|A_j|.
\]
原因是逐步生成的接收点有总质量一的条件密度，尺度导数的各步分数具有零条件均值。它们的二阶交叉项消去，积分到零半径时费用仍有限。每个大方体可依据全部已知输入单独选取一套规则。

**对完整积分的付款。** 对任何 \(b\ge0\)，原来每对的真实份额中，\(\min(p_{ij},bq_{ij})\) 在两个方向合计至多花费
\(b(1+K)h^n(1+\sqrt{8n/(3h\epsilon)})M\)，其中 \(K\) 是第749轮的实际装填帽，\(M\) 是原输入总质量。新增接收吸收系数为零。固定 \(b,\epsilon\) 时为根号阶，允许交集中的输入密度任意大。七层实例的真实密度为 \(2^n\)，共同负向位移能捕获每一层的全部共享份额。

**尚未支付的量**是两向 \((p_{ij}-bq_{ij})_+\) 乘各自原权重后的总和。正文的符号对称例说明，任意有限族上都能捕获固定比例的加强不成立。该例的接收体积与来源质量之比很小。下一步需要利用近极值时许多接收者共同使用来源的约束。一般 \(n^{1/2+o(1)}\) 上界仍未证明。

**实际核验。** 本机 Python 3.12.14 和 python-flint 0.9.0 使用有理数与256位 Arb，核对了84个边缘计算、一棵三轴自适应树上全部交叉项、4、16、64维各七个真实半径，以及一至三维的连续尺度包络。算例的 \(\sqrt n\) 是取装填权重时的测试归一化。主代理复跑得到逐字节一致的 JSON。解包后可运行独立数学环境的 Python 加参数 `-B verify.py --check verify.json`。
