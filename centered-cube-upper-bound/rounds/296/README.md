# 第296轮：全方向单对数来源包络与可支付远尾

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮针对中间硬层，保留原完整e_g、m、q、FIRST、来源与历史mask及真实Lebesgue接收测度，改进全局联合几何估计。不是固定尺度或特殊函数族结论。

## 1. 先合并比例带，不再多付一个对数

设kappa=2K/(ell M)，ell=1+log n，gamma=1+1/n，原low且m>M给出p_y≤kappa c_j^(n/2)(LR)^(-n/2)。在L>R方向，先逐点统一为p_y≤kappa R^(-n)，再使用原FIRST，最后积分硬尺度包络，得到

    T_(low,m>M,L>R;omega)
      ≤∫ F_(A,1)(kappa b_omega(z)/(q_-a^n)) nu(dz)。

这里omega是预先冻结的来源对分配，b_omega(z)=∫omega(y,z)beta(dy)，A=(b/a)^n，q_-=3lambda/4。原第295轮先逐带积分产生的Psi级数被单个F取代，其来源质量费用从对数平方降为单对数。该改进不重复使用来源预算。

## 2. 一个共同高度界覆盖全部软度和两种尺度方向

当L≤R，比例带下端点给c_j≤gamma sqrt(L/R)。因此两种方向统一满足

    p_y≤kappa gamma^(n/2) a^(-n/4) R^(-3n/4)。

于是对原全部low、m>M交通有

    T_omega≤∫ F_(A,3/4)(gamma^(n/2)kappa b_omega(z)/(q_-a^n))nu(dz)，
    F_(A,theta)(u)=min(1,u)+∫_1^A min(1,u/v^theta)dv/v。

F来自真实硬立方体径向积分。它具有显式分段公式，且F_(A,3/4)(u)≤7/3+(4/3)log_+u。此路线不再需要软度矩R_delta，也不需要小软度资格；仍有明确的来源集中费用。若其参数u≤exp(sqrt n)，则对应交通≤4sqrt(n)W_nu。这项容量条件尚未对全部原交通证明，不能把该条件结论称为一般闭合。

## 3. 远距离尾部已经直接支付

冻结omega_D(y,z)=1{|y-z|∞≤Db}，D>1。利用真实共同软度的正展开、原hardcap和全尺度尾部包络，证明

    T_(low,m>M)
      ≤∫F_(A,3/4)(gamma^(n/2)kappa beta(Q_(2Db)(z))/(q_-a^n))nu(dz)
        +(16/9)A_n n Csoft_n exp(1-D)W_beta，

其中A_n=1+n log(b/a)，Csoft_n≤1+(pi/2)sqrt(n)。选择D=1+log[(16/9)A_n n Csoft_n/epsilon]，0<epsilon≤1，即可用epsilon W_beta支付整个远尾。该尾部付款本身甚至不需要low/high资格。

因此剩余来源费用已从总质量W_beta局域化为距离O(b log(n/epsilon))内的实际质量。没有空间网格的指数重叠费，也没有对每个来源对复制一次来源预算。证明先对完整径向单调profile建立逐点尺度包络，再限制远尾区域；没有错误地假定截断尾部仍径向单调。

## 4. 行容量提供另一种双来源付款

设Q=q_-a^n、kappa_*=gamma^(n/2)kappa。若同一个冻结omega满足

    ∫omega(y,z)nu(dz)≤C Q  （beta几乎处处），

则凹性及真实行列总质量守恒给出

    T_omega≤W_nu F_(A,3/4)(kappa_* C W_beta/W_nu)。

进一步得到仅含log_+(kappa_*C)费用的(W_beta+W_nu)线性预算；精确最优标量常数和有限窗口公式见归档证明。这不要求逐列质量上限。

真实几何供应该行容量的充分条件是：每个y对应的分配来源可被一族合法accepted receiver立方体覆盖，且Σ(r/a)^n有统一上界；原hardcap给C=(16/3)Σ(r/a)^n。覆盖必须实际存在、可测，所有所用尺度都合法，不能免费假定全覆盖。若这笔覆盖费用仅为exp(O(sqrt n))且其余参数对数费用符合要求，就得到对应交通的根阶双来源预算；一般全覆盖仍是缺口。

## 5. 验证、复现和证据范围

独审先独立筛查命题、量词和潜在边界，再阅读作者证明。主代理审核后实际复跑本机Python脚本。有限receiver矩阵不被当作真实高维软核构造，普通高精度计算不被当作区间证书。

- 主检查：48个精确FIRST/height矩阵，1536次先并带min检验；每个theta各48个独立有限硬尺度包络；40次四次方体积的全方向精确高度比较。
- 三阶段Decimal40/60：144个标量案例，维数至10000、M跨10^(±10000)，含A=1及各分段端点；192次旧Psi闭式与直接求和交叉核对。两轮输出一致，主代理复跑一致。
- 行列预算：105个有限窗口最优系数/无穷窗口Lambert-W系数案例，100个精确有理行列账目及Jensen检查。
- 空间尾部：6个真实phi尾积分的两分辨率比较、42个共同软度系数与乘积尾案例、96个各向异性矩形profile的精确Fraction尺度尾包络。求积差仅为数值诊断，不是认证误差界。

在安装mpmath 1.3.0的Python中运行归档的checks.py、mixed_source_checks.py及spatial_checks.py；对应结果与证明一并保留。详细LaTeX文本归档，不编译PDF。实际扣额数据不可获得，不猜测模型成本。
