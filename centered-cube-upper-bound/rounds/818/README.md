# 第818轮　同一右来源下跨中父的小父并集与多坐标分离

接续第813、814、817轮的原双臂积分。同一记录保留中央历史 \(v\) 及其度 \(d_v\)、两个真实来源 \(z,q\)、小父 \(A_u,A_g\) 的实际质量分母和两处不交所有者上的勒贝格接收。设物理半径八度为 \([R,2R)\)，\(d=\log^{16}(n+2)/1024\)，\(V\) 为所有者总体积。

**两小父的真实空间分离。** 对原积分的任意正子流，跨所有中父和绝对尺度扣除 \(o(V)\) 原质量后，记
\[
 T=R^{-1}\max\{\operatorname{dist}_1(q,A_u),\operatorname{dist}_1(z,A_g)\}.
\]
每条留下的记录有 \(T>d\)，且至少 \(T/64\) 个坐标上的两个闭区间相距至少 \(TR/(4n)\)。因此两小父哪怕只共享一个边界点，这条记录也已经付费。估计先把真 \(q\) 逐坐标投影到完整 \(A_u\)，再用每个实际右所有者共同受到的体积限制。所有来源可以高度集中。

**很多左父对一个右父的联合占用。** 先保留 \(m_u\le m_g\) 和 \(\operatorname{dist}_1(q,A_u)>dR\)。固定同一右来源 \(q\)、八度和右父二进体积档，按原记录的权重，把所有中父提供的左父合成一份条件分布。独立抽取 \(k\) 个左父，以 \(Z_k\) 表示它们的并集占实际右父来源质量的期望比例。对这批原记录有
\[
 \int Z_k\,d\Gamma\le C\mathcal H\, k(1+n/d)e^{-d/8}Y,\qquad
 Y\le C_*V,\quad \mathcal H=O(1+\sqrt n/\log^2(n+2)).
\]
即使 \(k=\lfloor e^{d/16}\rfloor\)，期望捕获比例达到任一固定正阈值的整条原记录仍只占 \(o(V)\)。交换两臂即得另一大小排序。证明对所用的条件律同时处理全部中父，每档公用同一份真实来源。

**本机核验。** 在同一批四维几何数据的两种浓度下，分别重建2738个正质量基本盒、34条跨档父记录及230条两价正权记录。这34条中有14条的两个闭小父相交，其原质量比例分别为39.9077%和40.5313%。按同一右来源重抽左父，在两份样本的115条指定大小排序记录上，抽一次到抽32次，联合占用分别从15.14%升至25.10%、从16.10%升至24.42%。在固定右价胞的58条记录上，来源与接收者的混合覆盖费用分别达到等价纯覆盖费用的73.6951%和78.7248%。按有理概率和384位区间检查参考体积尾界及高维参数。四维数据没有满足高维质量跳跃条件的原峰。

**剩余缺口。** 极低条件频率的许多左父合在一起，仍可能反复经同一右来源、中父和分开的接收区域传递较大总质量。尚缺对这部分原积分的 \(C(\sqrt n\log^\alpha(n+2)V+n\log^\beta(n+2)S)\) 预算。一般单窗 \(B_n=o(n)\) 与全尺度 \(C_n\le K\sqrt n\) 仍待证明。
