# 第756轮　跨全部尺度的共同来源运输

第755轮的剩余量由同一来源点、两个来源标签和两个接收标签构成。四条边均保留第754轮的实际终端遮罩。本轮为这些四元组构造了一份**共用的运输**，从真实来源测度送到原来互不相交的接收所有者。来源点一旦得到分配，后续尺度都沿用它的运输落点。

把全部来源按实际父方体成员关系分成有限胞元，并按半径从小到大加入接收所有者。每层选取使「\(L\) 倍来源质量减去实际可达所有者体积」最大的胞元集，并取包含关系下最大者。证明给出三项结论。

- 这些集合逐层缩小。仍邻接本层所选集合的标签，跨全部层计算，完整所有者体积之和至多为 \(LS\)。
- 一个胞元首次离开时，可以将其全部真实来源送入此前未用过的所有者。运输落点属于实际 \(E_t\)，来源点属于对应的 \(A_t\)，且半径不超过离开层。所有层的目标测度合计至多 \(dy/L\)。
- 对其余实际四元组，同一个落点与来源点的距离至多为四个父方体最小半径的 \(h\) 倍。用这个落点同时检验四个来源—接收交区。返回任一原交区的概率达到 \(L^{-2}\)，或返回任一只需沿一根坐标轴放大三倍的交区的概率达到 \(n/(2L^2)\)，这一整批真实流量都可由 \(C_KLS\) 支付。第二个门槛计入了全部 \(n\) 个坐标。这里用到固定对角变换下的维数一致 \(L^2\) 估计。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

另外，对同一对固定父方体的实际共同来源可以先作一份分割。若某一块可触及的所有者体积在某个半径以内合计至多为该块来源质量的 \(L\) 倍，则这整个半径段可一次支付。详细证明式（4）逐项保留了计费端、第四端分别作为来源或接收时的四种不同分母。

**回代后的缺口。** \(T_0\) 是第752轮共同入口，\(S=\|f\|_1/\lambda\)，\(L=\sqrt n\log^A(n+2)\)；\(\mathcal D\) 是第755轮已抵扣的两侧尺度分布差。取 \(Z_{\rm next}\) 为上述支付后仍在同一四重积分内的实际流量。在反证所需的首穿越输入上，

\[
 \frac{336}{4096}T_0+\frac{\mathcal D}{4}\le \frac{Z_{\rm next}}4+C LS .
\]

未付样本上，以大于 \(1-n/(2L^2)\) 的概率，**同一个运输落点对四个混合交区都至少在两个坐标上出界**。这条结论约束落点位置。一般弱型上界还需要证明 \(Z_{\rm next}-\mathcal D\le T_0/4+C LS\)，届时净吸收余量为 \(80T_0/4096\)。本轮保留了任意来源、真实接收体积、第747至751轮的已花费用和两段半径比。

**有限核验。** 在 \(4,16,64\) 维的九组真实方体构造上检验了来源分块及跨档费用。等号组的密集块占交内真实来源的 \(8/9\)，两个尺度合并只花一份预算。五胞元、六层的一维实际区间图逐层枚举全部 32 个子集，并核对两次释放时的整数分配。在另一组正体积所有者上，四个锚用共同落点的原交命中率为 \(1/4\)，分别独立抽落点会给出 \(1019/2048\)。这些计算分别检查分块、容量和共同落点，适用范围见研究包。
