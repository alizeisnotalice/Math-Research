# 第107轮：共同空间叶与多尺度邻域容量

本轮先支付原软远尾，用独立随机格把原软点和整个硬赢家共同放入边长 256na 的叶。叶内有限邻格流按真实截片容量提取可运输来源；多尺度运行最大值将质量份额只收费一次，并保留所有尺度的 cut 与厚邻域证书。共同余源经 deep top-k、一次真实低尾行和轻尾窗口付款后，再按两种冻结来源的叶质量支付相对小尾和平方列分支。

最终总式完整保留新增 `(128/119)(ε+δ+kκ_n)X`、软来源费用与硬来源账。旧 P104、R105 来源费、X/768 及先剥离的远软费保持原位。当前硬尾得到两来源质量可比和自身归一化细格限制；原软来源不因此获得同样的 rank 界。一般 `n^(1/2+o(1))` 一致弱型上界仍为 **UNPROVED**。
