# 第331轮：接收容量联合势与来源付费截断

**一般 n^(1/2+o(1)) 一致弱型上界未闭合。** 独审通过一般硬匹配场的两项估计：

- 实际对称行次容量下构造Hilbert参考与共同负接收势，其费用精确抵消，并保留容量余量和Dirichlet信用。真正缺口是全来源位置的cut与拟合平方联合根阶估计，不能仅由接收端恒等式得出。
- 截断实际接收对分母，保持原H及全部接收对；欠覆盖用显式来源线性费支付。T=H时无需泛用补齐费。但接收对费用本身仍未一般支付。

本机Python重跑11934项精确有理检查通过，三阶段维度1/2、4/8、16，各两种来源分区。完整来源积分保留局部J后，n16平方收益较旧放松提高约27.46倍，但仍仅节省约0.00467%的X。此为指定几何的有限证据，不是精确B_all或一般根阶结论。独审617项与作者Decimal诊断另计。

完整总账保留宽距离、低pe、极端尺度比、初始、删除跳跃及未来被删来源。替代整个B_H槽时不重复叠加同槽旧付款；全部外层系数和总吸收仍待闭合。优先继续全局几何的共同容量与真实边界质量估计。
