# 第652轮：来源捕获与实际熵价格的联合所有权

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮沿用第651轮的 Eulerian 联合覆盖路线，没有改变最终目标。

本轮证明可同时选择真实接收所有权与其实际熵最优权重：高增长丢失行的旧来源方体被接收者的新方体包含；除固定基线面积外，自由分配选择合格候选中实际增长价格最小者。低增长损失由对应旧增长的 1/12 支付。选择器、非原子分割、删除标签及全部旧行均经独审。

另一条实际体积估计为：强来源入侵接收者的已拥有体积至多 RS/2+(69/236)E'/κ'。这是接收面积的部分结算，**不是丢失副本重数界**，且下一代 E'/κ' 仍未支付。新来源势能可在同一校准类中一次性按 4LM 控制，但完整 ED 或 Γ 的正增量尚未得到。

下一步固定这份联合选择，攻坚所有合法接收者均为高价格的区域及其分支重数。附录保留阻挡边使真实来源行质量增长超过 53/48 的结论；单链质量可和不等于分支容量已付。
