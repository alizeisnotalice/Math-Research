# 第723轮　按真实接收位移估计同档站点对

开题复核[第706轮指令](../../AGENTS.md)。顺序选档时允许避开先前的冲突组。由条件概率上界得到成对选档概率，在同一总账内抵消两组的分配分母。由此可用体积受控的区域支付第二个真实接收点；该区域可以同时依赖第一个接收点及其共同来源。

对上一轮剩余的同档站点对，本轮按两个真实位移之差和第二端自身位移中较小者计误差。当误差小时，未付站点对的有符号坐标差须接近三角分布。对仍未支付的每个共同来源，还证明了第一端见证相对该来源中心的有符号坐标须接近均匀分布。此处两个分布都是对有限坐标的经验分布要求，原输入始终是一般的真实历史。大误差部分和同时满足这些条件的部分仍未获得统一总量界。

本机和 MacBook 交叉核验了顺序选档、成对费用和标量阈值计算。本机另以有理算术检查 19,600 个一维超水平集体积不等式以及 128 个分布函数反卷积算例。[证明、脚本与记录](research.zip)
