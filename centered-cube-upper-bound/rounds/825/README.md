# 第825轮　同一实际来源上的双价与两处接收体积

沿11月23日指导第六节第三步，继续估计第813轮的原双臂积分。一条记录的左右真实来源为 \(z,q\)，两个实际接收者为 \(U,W\)，中父的质量 \(m_t\) 位于 \([D,2D)\)。在中父上按实际来源质量抽出 \(r\) 后，两侧仍共用原尺度、原历史和原完整度。第824轮处理了许多左来源经不同中父反复调用一个右来源的情况。本轮允许 \(z,q\) 同时更换。

**联合估计。** 固定来源 \(r\)、物理尺度窗和中父质量档。若一张价格表 \(A\) 的实际联合面积满足 \((\mu\otimes\mu)(A)\le K D^2\)，则在第823轮远价余项上，全部窗档命中这张表的原增广质量至多
\[
 C\,(\mathcal H/L)(n+2)^3\log(n+2)\,K e^{-b/8}\,\mu(\mathbb R^n).
\]
右价的允许集合可以随实际左价改变。若表指定两个真实接收位置，则以 \(\int_A dU\,dW\) 计面积，上式的 \((n+2)^3\) 降为 \(n+2\)。这里 \(L=\sqrt n\log^3(n+2)\)，\(b\) 为第823轮的来源分离阈值，完整定义见证明。另一个逐真实条件来源的估计可以由一对高占比小父支付所在整行。两个结果均使用小父的实际质量分母。

**同时更换两价。** 即使每一步重新抽中父来源、尺度及两价，往次真实小父对形成的联合表仍可按同一份来源预算测试。取 \(K=e^{b/32}\) 后，在删去指数小的真实质量并保留每条存活记录至少四分之一的中父来源质量后，一步命中此类表的条件概率至多为 \(C(\mathcal H/L)(n+2)^2 e^{-5b/64}\)。此外，两处接收者若在绝大多数坐标按预先确定的方向夹住该来源，三处实际接收体积的费用含 \(e^{-n/24}\)。若两个小父半径均不超过中父的 \(13/25\)，允许每轴任选夹住的次序，费用含 \(e^{-n/160}\)。

**数值核验。** 在第814轮两组四维连续来源各230条正权双价记录上，比较了真实双价条件律与独立化的两条边际，并在相同接收盒上精确积分。两组数据中，四轴均夹住实际来源的质量份额分别为 \(5.9960\%\) 和 \(6.3294\%\)。四维数据中的高维跳跃分支为空。另以有理数核验600个左右半径可不同的三接收截面，以256位和384位 Arb 核验两个指数常数。旧单臂支付模型的原质量、原对偶界与饱和接收约束均已复算。

**余项。** 两价可持续落在新的稀散来源对上，两个接收者也可避开此前记录提供的受控位置集合。尚缺对这批原质量的统一预算，或证明它在有限步内有固定比例进入已付事件。从原阈值见证到双臂流的密度、半径窗之间的复用也要结算。一般单窗 \(B_n=o(n)\) 与全尺度 \(C_n\le K\sqrt n\) 仍待证明。
