## 独审通过的新估计

对共享真实来源核心K的一整族接收盒，核心质量m、族最大质量M≤2m、核心乘积因子β，证明整族费用不超过

    βm + (β + 2/n)(M − m)。

允许β=0，保留所有坐标区间、实际来源质量与Lebesgue接收测度。进一步在给定的、来源不复制的二叉合并森林中，把轻边重复次数与高β子树覆盖一起结算，得到：

    若活跃质量带U/L≤2^(n+1)，全部活跃原节点的接收并集费用≤14√n W。

高β节点已经通过子树剪枝支付，不再要求森林中所有β都小。原标签始终保留，没有把覆盖盒冒充新的来源见证。

**关键范围：** 尚未证明任意相互交叠的来源簇能够以受控费用整理成这种森林，也未支付跨质量带的来源重复。因此这是有结构假设的整族定理，不能当作一般弱型闭合。
