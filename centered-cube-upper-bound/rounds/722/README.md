# 第722轮　接收组的来源体积选档与跨组费用

开题复核[第706轮指令](../../AGENTS.md)。对同一份真实历史，每个剩余接收组都有至少常数倍 √n 个可用的来源体积档，可从中任选一档分摊该组的完整需求。各档按全局同一套体积端点划分。来源只属于一个档，因此选择不同档的组之间的交叉费用严格为零。顺序选档还可以为每组避开常数倍 √n 个指定的先前冲突组。

在同一档内，共同来源权重至多为 4⁻ⁿ 的站点对可以整体吸收，无须限制站点数。具有固定共同权重的站点对，以及按坐标距离和接收尺度足够接近的站点对，也已计入总账。未付的是选在同一档、共同权重介于已付范围之间、在两个方向都不满足距离条件的超预算来源。所有剩余交叉项的合计界仍待证明。

本机和 MacBook 核验了 53 组精确分配算例及三组真实来源池的截断权重。另在本机检验了 64 组顺序选档和尺度条带的几何系数。[详细证明、脚本与实际输出](research.zip)
