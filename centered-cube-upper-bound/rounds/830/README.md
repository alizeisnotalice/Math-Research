# 第830轮　共享右来源时，哪些中父交叉接触可以支付

在第813轮的原双臂积分上，固定任一真实右来源 \(q\)，从当前剩余记录自身独立抽两条完整历史。它们可以来自不同物理窗和体积档，也可以使用不同左来源。记第一条的小父为 \(A_u\)，第二条的中父为 \(A_{t'}\)。本轮对实际父方体是否相交给出统一费用。两条记录各自保留原来源分母、完整度与两个勒贝格接收位置。[完整 LaTeX 证明与计算](research.zip)

**跨尺度接触。** 只要第二个中父的档边长不超过第一个的四倍，\(\{A_u\cap A_{t'}\ne\varnothing\}\) 在整个扩展原流上的质量至多 \(C N(1+\mathcal H)\exp[-\log^{16}N/2^{16}]Y+C(\mathcal H/L)\eta N e^{-J/2}Y\)，其中 \(N=n+2\)，\(Y\lesssim V\) 是原接收预算，\(J=\sqrt n\log^8 N\)。该式用于充分大维数。若两条记录的小父都接触对方的中父，则任意尺度比均适用，费用至多乘二。交点可随中父改变。把条件接触概率至少为 \(1/16\) 的原记录整条扣除，费用至多再乘16。

**完整左右臂固定后的共同容量。** 用原两价 \(z,q\) 和中父体积档 \([D,2D)\)，在同时能看到两端的位置 \(a\) 上积分 \(1/(D+\mu(Q_w(a)))\)，所得为 \(K_D(z,q)\)。从同一完整双臂的原条件律抽两位中父，令 \(J_*\) 为两者好来源集之交，\(B_-,B_+\) 为均被两位中父实际允许的左右小臂质量。所有满足 \(B_-B_+\le N^{-1}D\mu(J_*)K_D\) 的双中父扩展原量，可用 \(C(\mathcal H/L)\sqrt N\,Y\) 支付。完整报告给出任意多位中父、门槛和回代，并说明共同接收者落在两价共同中心盒内时如何直接付费。

**一般输入上的另一个可付部分。** 对真实末根，在看到第二枚来源前选实际接收池 \(Y_x\)，占用测度为 \(dy/t_y^n\)。若其总占用和所要求的绝对复用量的倒数都至多为维数的固定次幂，命中这份复用量的任意来源割有 \(O(\sqrt n\log(n+2))\) 费用。这里保留全部较早尺度和真实勒贝格体积。

**实算。** 在两份第814轮四维正密度样本上，各核算7598个同右源有向配对。实体方体双向相交的原权比例分别为96.30%和96.83%；两份样本的高维长跳门均为空。另对16个真实接收池和123对来源块检验绝对复用，维数最高512。独立的64维校准构造中，只移动方体外的源峰，就可使 \(K_D\) 从至少 \(0.673572893343\) 降到至多 \(5.8693\times10^{-8}\)，三父共同质量仍至少为 \(0.776899258555\)。这一构造未实现原历史的全部限制。

**一般上界仍待证明。** 现有估计允许同一 \(q\) 由许多互异左父反复使用，每个左父很少接触独立抽到的较小中父。同时，给定完整双臂后，两位中父所共用的左右小臂容量仍可能相对 \(K_D\) 很大。对两项同时成立的原量，尚缺一般预算或可收缩递推。
