# 第745轮　同一方体族的贪心价值与最优装填可相差线性阶

对第706轮指令中每个固定的 \(c>0\)，存在任意充分大维数的有限方体族和合法所有权，使原贪心规则在任何并列次序下均满足
\[
  D\le C_c\,V/n,\qquad P_0\ge V .
\]
这里 \(V\) 是全部缩小方体并集的勒贝格体积，\(D=\sum_i\theta_i(2s_i)^n\) 是指定贪心装填的价值，\(P_0\) 是同一族原父方体上的最优可行装填价值。故在“对任意给定的合法所有权”这一量词下，用 \(n^{1/2+o(1)}D\) 控制 \(V\) 的命题有反例。一般中心立方体极大算子的根阶上界仍待证明。

**构造。** 令 \(m=\lfloor n/16\rfloor,\ d=n-m\)，用半径为一的标签使缩小方体恰好铺满 \(X=[-1,1]^m\times[-2,2]^d\)。对 \(x\in X\) 取其接收父方体内的点 \(z(x)=(0^m,x_{\rm 尾}/2)\)。设置 \(\lfloor n^{2/3}\rfloor\) 档略大于一的来源半径。用前 \(m\) 维的最大绝对坐标给这些来源分配互不相交的薄层，用后 \(d\) 维的欧氏球限制所有来源的总体积。每档在 \(z(x)\) 的平均原负载趋于一，而全部来源所有者和额外铺格合计只占 \(e^{-\Omega(n)}|X|\)。有限微格、有边界的来源父方体和铺格剩余部分都有明确的所有权。

**为什么贪心会损失。** 相邻来源档的对数体积差为 \(\Omega(n^{1/3})\)，所有前档在任何点可能造成的对数剩余容量损失只有 \(O_c(n^{1/6})\)。所以贪心确实先按半径递减处理全部来源。按各档入选时的真实剩余容量求和，在主接收区留下的平均容量只有 \(O_c(1/t)\)，其中 \(t=c\sqrt n\)。收取贪心价值时还有一个 \(1/t\) 因子，得到 \(D=O_c(V/n)\)。取内点 \(z(x)\) 只用于估计接收标签在实际入选时的本质下确界。

**代回原接收积分。** 保持第706轮的合法首次越阈见证、共同尺度和第739轮的真实保留配对。此时 \(V_T/V\to1\)，并有
\[
 \frac{R_{\rm high}}{V_T}\to\frac12,\qquad
 \liminf\frac{M}{V_T}\ge\frac{13}{32}.
\]
因此第706轮所需的固定吸收系数 \(\eta_H<1/2\) 以及第739轮所需的 \(\alpha<9/32\) 均无法以原 \(D\) 统一支付。固定满足第744轮条件的 \(c\) 后，其已证账目进一步给出
\[
  \liminf R_{744}/V_T\ge 17/64,\qquad
  \liminf\Delta/V_T\ge 17/128>1/8 .
\]
这些是对原连续接收测度的渐近估计。

**同一输入上的可行装填。** 对全部半径一的铺格标签赋权 \(a^{-n}\)，其中 \(a=32n\)。每一轴上几乎处处至多有 \(a\) 个父区间覆盖，所得全维装填可行，价值恰为 \(V\)。在完全相同的父方体族上，将每个铺格的所有权全部交给自身并令其余标签所有权为零，还可证明新贪心价值至少为 \(e^{-1/t}V/(t+a^{-n})\)。对任意输入构造这样的所有权，或直接给 \(V/P_0\) 建立根阶上界，仍是一般问题。

**本机核验。** Python 有理数完整重建三份一维贪心历史，逐次选取实际优先级最大的标签。对固定坐标见证核对216个精确微格壳层，其中108个恰好落在来源边界。另核对99,648个铺格端点及中心、55,360个区间的装填覆盖数。256位 Arb 对12组标量参数逐项核算，10组满足证明所用的充分排序条件，5组同时认证 \(t^2D/|X|<3\)。最大维数 \(2^{192}\) 只用于解析公式的区间求值。一般反例由以上构造和估计证明。
