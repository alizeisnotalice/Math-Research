# 第304轮：完整总账与真实资格的累计捕获势

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮按“完整总账优先、B_H 主攻”推进。新增结果是保留全部原来源资格的共同见证估计、精确累计捕获势，以及共同软层高次数尾项的来源预算。没有证明 B_H 或其真实资格版本具有一般根阶上界。

## 完整总账与作用范围

从原归档核回 R_out、T_small、T_low、初始 I_rem、删除跳跃 J_rem、未来被删 D_rem、连续 P_suffix 和两项只可使用一次的负信用。总账保留 Lambda=128/119 和原已组装误差和：

19/768 + Lambda(epsilon_tree+delta_tail+k0*kappa_n+epsilon_LP)
+ epsilon_neartime+epsilon_FA+epsilon_IJ+epsilon_D+epsilon_G。

原始全事件入口至这一交通总账的精确连接、后续实际采用费用的完整清单仍未认证，因此不能宣称全局吸收系数已小于一。原已有命名来源费用全部保留；本轮抽核不是对数百轮旧引理的重新认证。

R303估计位于 low-pe、高m、尺度比受限的原始 raw 接收积分；进入此槽只乘一次 Lambda。没有依据把它移入高连续 suffix 槽。R303的3epsilon W_beta是来源费用，不贡献epsilon X。极小尺度比、宽距离连续项、初始项和时间删除费用继续单列。

## 本轮已证明的估计

在原 low-pe、高m、尺度比受限分支内，以一个共同的接收器—标记 Poisson 流，定义真实来源资格下的捕获 A*，保留原 I0、e_g、m、q、FIRST、真实勒贝格接收测度和原尺度。其截断容量满足

T/2 <= O_d* <= T，且积分 A* 的精确首矩就是原目标 T。

由此高累计行估计可使用 (d/H)T，而不必放大为 A_n W_nu。取 H=4d，得到

T <= 64 lambda d W_beta + 4 B*_(4d)。

这是同一有限T的内部自吸收；d仍带原尺度比费用，B*未付，也不产生全局epsilon X吸收。标记对称差分为立方体差和共同立方体内部的资格差；后一项必须保留。O*变小不保证B*变小，不能直接替换R302的旧B_H。

令 V(J,A)=积分(A-A²/J)dnu、V(0,0)=0。两个质量块满足精确恒等式

V(J+h,A+a)=V(J,A)+V(h,a)+Jh/(J+h)积分(A/J-a/h)²dnu。

因此累计V非减，W_H=1{J>=H}V是合法的正Stieltjes势，且

B*_H(y)=积分_[a,b] s^(-n)dW_H(s)。

初始端点、终端尺度、并列半径和跨阈值整块均保留。这提供实际质量与捕获平方的联合核算；新增平方差是费用，不能直接称为已获得的重叠节省。这里的尺度原子不支付原随机时间原子。

另对实际共同软参数展开，FIRST只给加权分量和，不给逐分量FIRST。利用R303严格软坐标收缩，逐原来源选择次数阈值j(z)，可将高次数尾付成epsilon W_nu且只付一次。j(z)可能等于n，低次数剩余部分没有得到一致小次数控制。完整证明提供rho_bar=19/20的有理证书。
