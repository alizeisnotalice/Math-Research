# 第795轮　真实终端来源与两端接收的全尺度估计

本轮在第794轮的完整停止流上，把同一来源经不同中父反复使用的双端费用，按全部中父和尺度合计。得到一条对实际两端条件分配的平方估计。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、数值检验笔记与复现材料](research.zip)

从每条实际路径的终端 \(A_t\) 按 \(\mu|_{A_t}/m_t\) 再抽取一个来源点 \(y\)。初根的两个接收点 \(U,W\) 保留在各自真实所有者上的勒贝格分布。固定 \(y\) 后，两个接收点的联合质量由初始两跳给出的正半定核支配。将核的迹对真实来源积分，原中父 \(i\) 的扩大方体只耗用 \(C\mu(A_i)\)。每个中父只出现一次，得到
\[
 \sum_{O,B}\int \operatorname{tr}G_{O,B,y}\,d\mu(y)
 \le C e^{-r/256} I(1),\qquad r=\lceil\sqrt n\log^2(n+2)\rceil .
\]
这里 \(O\) 是原物理半径八度，\(B\) 是该八度内的体积档分组。这个界覆盖全部停止代数。两个旧交价也可各自按任意精度分组，费用依赖每组实际匹配的行、列度数。

**这个界能支付哪些实际接收量。** 在固定体积尺度 \(D_B\) 的网格中，令 \(p_a\) 为格 \(a\) 内真实所有者的总体积。给定 \(y,O,B\)，用所有中父合计的真实停止分布计算 \(\Pr(b\mid a)\) 及 \(\Pr(a\mid b)\)。归一化双向得分为
\[
 \sqrt{\frac{D_B}{p_b}\Pr(b\mid a)\ \frac{D_B}{p_a}\Pr(a\mid b)} .
\]
该得分对实际中尺度来源和两端记录的积分至多 \(C e^{-r/256}\min\{I(1),(n+2)\log(n+2)S\}\)，其中 \(S=\|f\|_1/\lambda\)。另一个可付情形是来自同一终端的真源点接近两接收点间的某个插值位置。这能覆盖两个接收点都远离来源的记录。还可对同一终端取最多 \(c\log^2(n+2)\) 个独立来源，根据它们的坐标中位数作联合检验。

**剩余与总账。** 用同一组首停盒支付过大来源盒的接收质量后，每条其余路径至少 \(1-C\log^{-8}(n+2)\) 的终端来源已定位到每个源点仅 \(O(\log(n+2))\) 个半径八度。两项预算合并得到
\[
 R_{794}=P_{\rm paid}+R_{795},\qquad
 |P_{\rm paid}|\le C\big((n+2)\log^8(n+2)S+e^{-r/512}I(1)\big).
\]
一般情形尚无证据保证双向得分或联合几何检验在剩余路径上占固定比例。根阶仍需控制同时避开这些检验、又在多个中父间反复使用真实来源的总质量。

**本机核验。** 三组 \(1,2,4\) 维有理数据分别包含 \(2,4,8\) 个中央父。按真实路径和按接收格的两种算法核对原全度、Gram 迹、旧价分组及非对称停止。被中点检验捕获的子矩形中，两端都避开单端检验的质量份额分别为 \(58.85\%,77.78\%,77.91\%\)。三组二维首停计算核对多终端共用接收域。辅助固定半径计算用 256 位 Arb 检查频率和乘积例。这些比例仅针对归档中的有限输入。
