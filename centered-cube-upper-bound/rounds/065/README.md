# 第65轮：多数捕获尾部与守恒重分配误差预算

日期：2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**；保留全一般 O(n log n) 基准。

## 已证明的结果

- 对任意有限正原子来源，原好集上的严格多数捕获尾部费用不超过 (1−e⁻¹)²HW/θ（θ>1/2）。完全捕获尾部有更强的 (1−e⁻¹)²HW/2 界；单源入口也有一致预算。剩余区域明确为多源、尚未捕获多数总质量的接收点与尺度。
- 对任意有限正 Borel 来源，构造质量守恒的重分配；完整有符号误差在原好集上的平方积分不超过 (e+1)²HW，不依赖原子数、最小质量或分解深度。但目标密度上限为 [4(n²+1)]ⁿH，其能量仍未得到所需估计。这不是新的一般弱型上界。
- 一维正等权网格给出精确反例：幸存到达跳跃的平方预算随原子数趋于零，而真实完整捕获尾部能量保持正值。该反例否定跳跃平方单独控制整体能量，不否定目标弱型估计。

## 实际数值检验

4组初探、240候选；最终独立改变 n=1,2,4,8,16 与 N=4,16,64，搜索1500个真实正来源及阈值。最终搜索使用768,000次相关接收点评分；106组留出复核共1,261,568个接收点。阈值与位置交叉复核揭示明显选择偏差，未拟合渐近阶数。

8组多数捕获分段复用212,992个既有接收点，不额外计作独立证据。已测 n=16、N=64 来源的几乎全部能量位于多数捕获前，说明已付尾段不能替代早期余项。

主脚本在新临时目录独立复跑，JSON逐字节一致。212个高精度阈值检查、15个有符号Gram/事件检查、8个截断尾部检查，以及单原子与真实并列到达校验通过。两组嵌入式检查程序也通过，包括11,082项精确cap/跳跃检查和13,269项精确重分配比较。

有限数值不是一般证明；样本标准误不是严格置信区间，Decimal不是向外舍入区间认证。
