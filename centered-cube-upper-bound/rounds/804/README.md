# 第804轮　同一合法外源上的多个中父、四枚真价与实际接收体积

本轮从第803轮完整未付的两臂原记录出发。对所有尺度和中父合计，可以付清两类记录。其一是经实际可用来源转往另一条原记录时，显著遇到低负载来源或再次命中对方小方体。其二是缺少足够多合法四角的记录，四角须同时保留四枚真实旧价及其接收点。设 \(L=\sqrt n\log^3(n+2)\)、\(P=(n+2)\log^6(n+2)\)，这两项的原质量合计至多 \(C(LV+PS)\)，其中 \(V\) 是实际所有者的总勒贝格体积，\(S=\|f\|_1/\lambda_0\)。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、精确证书及离线复现材料](research.zip)

## 同一真实来源与不同中父

一条有向原记录 \(e\) 有小父 \(u\) 和中父 \(t\)。在该根合法的外源 \(G_u\setminus\mathcal D_t\) 上按真实 \(\mu\) 归一取点 \(y\)，再从能使用这个 \(y\) 的所有根里按实际权重抽另一根。所得联合测度的两个边际都等于原有向流。固定一个高负载 \(y\)，并把小父和中父分别限制在同一对体积档。在扣去 \(o(V)\) 的增广源质量后，条件质量足够大的这些组至少占一半。组中可同时抽出 \(\lfloor\exp(\omega/2^{22})\rfloor\) 条真实记录，其中 \(\omega\asymp\log^4(n+2)\)。以趋于一的概率，各指定小父均含同一个合法外源，彼此的指定旧价距对方小方体超过 \(2^{-17}\omega s_{u'}\)。每个中父的扩大集还同时避开其他组的四枚真价。这里使用的是同一份当前原流，组内抽样的结论按真实权重计。

## 四价跨度与三处接收位置

保留中央原历史和每条臂的真价、实际探针后，两条合法原路径交换端点可以失效。证明在同一中父处只计四条边都真正合法的配置。对每个坐标，以最大半径的小端作锚，测量另外三个实际接收点迫使四价产生的最小跨度。它的一维次水平体积精确为 \((2hs)^3(1+qt)^2(1+4qt)\)。由此可一次支付通过联合体积检验的四角，跨中父、体积档与三个接收位置求和后的四角质量至多 \(CH e^{-2J}Y/L^3\)。按实际最早删除的边计费，把这一界回到原路径需用四次矩，并计入仍可补成合法四角的条件权。

## 完整预算的剩余项

令 \(Z_t\) 为中父 \(t\) 实际作为远锚、且能参与上述多组配置的外源集合。\(D_{\min}(t,y)\) 是该中父与外源在成功配置中所用的最小小父体积档。先在同一对真价上加完小父，再积掉中父内的真实源，得到

\[
 |R_{804}|\le o(V)+C H e^{-\Xi/128}
 \sum_t j_t\int_{Z_t}\frac{d\mu(y)}{D_{\min}(t,y)},\qquad
 j_t\le C|E_t|,\quad \Xi\asymp n^{1/4}\log^{5/2}(n+2).
\]

这一式覆盖第804轮整份余流。对任意一个中父，若其归一外源积分至多为 \(e^{\Xi/256}\)，所有这类中父的成功锚总量只需 \(o(V)\)。仍须估计一个中父在许多不同外源点重复用于成功配置时的积分。给单个外源找到很多不同中父，只提供了相反求和方向的信息。第772轮原账的吸收系数 \(\delta_0<1\) 和 \(k_2=O(\log(n+2))\) 的回代详见研究包。

## 本机验证

本机独立 Python 3.12.14，使用 SymPy 1.14.0、有理算术和 256 位 Arb。三组真实区间模型核对了四角逐项枚举、矩阵换序和连续两批删除。压力例中，两个交叉角均为零，一条尾边在第一次删除后又触发第二次删除。扩大例保留原全度分母的墓点表示和按旧臂归一的表示，实际原边相同，四角权不同。同一阈值下，两批删除的边数分别为 11、1 和 3、3。公共外源另用 \(68,784,3280\) 条真实有向记录检验。初探将整小父的均匀源律代替合法外源，会将 \(10025/33554432\) 的质量送入禁止区域。四价与三处接收位置的独立计算在 \(4,9,18\) 维穷举 \(15,220,7315\) 种接收坐标计数，每组的归一质量精确为一。另在 \(8,48,160\) 维用有理单纯形体积和 Arb 核验同档距离下尾。有限例的原分母、简化筛选、参数、脚本和 SHA-256 均在包内，三份证书可独立重放。
