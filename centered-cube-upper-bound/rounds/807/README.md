# 第807轮　原五点的共父容量与真实来源预算

固定第806轮留下的完整四边配置。记 \(z\) 为四边的共同旧价，\(q_1,q_2\) 为两枚对端原交价，\(y_1,y_2\) 为原来的两个合法外源。本轮证明了一条同时包含这五个位置、所有父标签和两种方向的估计。四条边中任何一条缺少足够多的可用来源或接收历史，相应的真实配置份额都能计入原预算。[详细 LaTeX、数值笔记及复现脚本](research.zip)

在物理八度内，把体积档 \(F\) 中能同时容纳 \(v,w\) 的父按其真实接收权求和，定义

\[
 K_F(v,w)= F\sum_i \frac{j_i}{m_i\,\mu(G_i)}
                    \mathbf 1_{G_i}(v)\mathbf 1_{G_i}(w).
\]

这里 \(j_i\le C_*|E_i|\)，实际勒贝格接收区 \(E_i\) 两两不交。对边 \(v\to w\)，用 \(k=K_F(v,w)\) 和目的端的原参考测度 \(\sigma\) 定义

\[
 D=F^{-1}\sigma\{w':K_F(v,w')\ge k\}.
\]

目的地是 \(z\) 或 \(y\) 时用原来源测度。目的地是 \(q\) 时用真实对端接收历史诱导的交价测度，并保留原度下界 \(L\) 的分母。对八个有向选择同时付款后，每份保留的正配置均有

\[
 D>k^{-1/2},\qquad D\ge \frac{c(n+2)^{-12}}{k(2+|\log k|)^2}.
\]

原路径上的长距离已经使 \(k\) 超多项式小。因而这一要求给出了实际可用区域的质量下界，而且指定这些区域对出发点须有多大的共父权。证明分别以原价、外源或对端交价为根，逐边归一，直到只需一份来源总量或接收总量。辅助完成的付款按真实份额投回原路径。

另外，同一中父源点上，从另外三个父抽出的真实来源共同受四个方体接收区的交体积限制。对可达三源集合按共同价的方体交体积分权，其有效体积偏小的行合计只占来源总量的超多项式小量。

本轮合计得到 \(R_{806}=R_{\rm paid}+R_{807}\)，其中

\[
 |R_{\rm paid}|\le C\bigl(\sqrt n\log^3(n+2)V+(n+2)\log^6(n+2)S\bigr)
             +o_{\rm sp}(V+S).
\]

\(V\) 为实际接收总体积，\(S=\|f\|_1/\lambda_0\)。许多保留的原价和来源仍可能占用同一批接收历史。控制这种跨原价重用的总量，是完整一般上界的剩余问题。
