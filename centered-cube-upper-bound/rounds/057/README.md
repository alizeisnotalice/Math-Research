## 严格结果

对任意实或复 L² 输入，令 u=n log L、D_u f=(A_{exp(1/n)L}−A_L)f，则全尺度平方能量满足

    ∫ ||D_u f||²₂ du ≤ κ_n ||f||²₂,
    κ_n=n[(1+x_n)log(1+x_n)−x_n log x_n],
    x_n=sinh²(1/(2n)).

κ_n是最佳平方常数，且

    κ_n=(log n)/(2n)+(1+2log2)/(4n)+O(log(n+2)/n³).

证明适用于全部方向：方体投影为对称单峰密度，进而是中心均匀密度的概率混合；对同一个混合取尺度差后，用Jensen和dt/t尺度不变性归约至轴向精确积分。频率能量在轴向附近连续，补齐零测轴向到算子最佳常数的论证。无需假设输入具有张量结构。

这把第54轮的维数无关粗L²常数改善至尖锐log(n)/n，并把条件性正源替换所能负担的密度高度提高到nH。但任意来源的替换构造和原好集合上的误差预算尚未证明。第56轮微观能量缺陷及正门控反例仍限制下一步；本轮不是一般弱型目标的闭合。
