# 第732轮　反向输运较大来源的真实所有者

开题核对[第706轮指令](../../AGENTS.md)。对第731轮仍未支付的有向配对，固定小方体，把同一半径档内大方体的真实所有者压缩到小方体尺度。若其中心在真实接收点平移后，落在小方体的 65/64 倍放大内，允许至多 ⌊n/24⌋ 个坐标例外，则整个分支的费用至多为 M/n 加指数衰减的来源费用。例外坐标可随配对和接收行变化。

正向估计用软权重把可逐对选择的例外坐标范围扩大到 k=o(log n)，来源费用保持在目标指数内。研究包另给出分块直线相交的解析估计，逐项保留离散参数、极端尺度及吸收费用。其余四来源联合需求仍缺一般预算。

本机与 MacBook 的软权重结果经哈希和退出状态核验。本机另外核验九个真实贪心历史中的反向付款条件及二阶矩价格。所有这些算例已有远来源可支付。[详细证明及复现材料](research.zip)
