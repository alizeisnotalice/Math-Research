# 第834轮　不同中父反复使用同一来源时的接收体积

在第813轮原双臂积分上，每个中父保留自己的两份真实质量分母、完整度和原历史。两枚价和两个实际勒贝格接收者均在原测度中。本轮解决了一种跨尺度重用情形。若一枚实际来源被许多中父使用，但这些中父仍沿少数几个共同方向接近该来源，则可按所有者的真实联合体积一次付款。剩余量若仍超过预算，两个真实端点都必须面对大量方向不同的来源。[证明、数值笔记与复现材料](research.zip)

## 已证明的付款

对原中父的全边长 \(b_t\) 和两价 \(z,q\)，记逐坐标的负对数交长为
\[
 \phi_t=-\sum_{i=1}^n\log\!\left(1-\frac{|z_i-q_i|}{(1+2/n)b_t}\right).
\]
固定真右价后，两个真实右臂可跨任意尺度预先配对，再按各自条件律抽完整记录。第833轮的双向来源秩 \(r_{12},r_{21}\) 满足
\[
 \Pi_R\!\left\{\log\sqrt{r_{12}r_{21}}\le(1-o(1))\frac{\phi_1+\phi_2}{2}\right\}=o(V)
\]
一致地对所有这样的预选配对成立。这里的 \(1-o(1)\) 可以取 \((1-128\log(n+2)/b_0)/(1+1/\log(n+2))\)。估计使用两枚真实来源所允许的接收中心体积。张量几何的共享标签定理在每条边上精确读出 \(\phi_t\)。[固定版本的欧几里得价格定理](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/Euclidean-geometry-in-the-asymptotic-spectrum-of-tensors-November-24-2026/build/intro.tex)

在真正的物理方向上，令 \(K\) 为预先列出的紧凸集合，位置按当前档的实际边长归一化。中父接触这个方向集合时，所有相应的不交所有者共占的体积比例至多为常数乘 \(|[-1/2,1/2]^n+K|\)。该体积等于 \(K\) 的所有坐标投影体积之和，亦至多为 \(\exp(C\sqrt{nW(K)})\)，其中 \(W\) 为共享比特的归一化高斯宽度。这个预算可由多个共用方向集合分摊。只要总和不超过 \(e^{b_0/256}\)，两方向各自在菜单外的真实来源质量不超过其锚父质量的 \(e^{b_0/128}\) 倍，则这批同完整臂配对的原量至多为 \(CS_*+o(V)\)。菜单可随受争用的真实来源、物理八度和绝对体积档改变。斜跨所有坐标的一条线段 \([u,u+d]\) 只付 \(1+\|d\|_1\)。

另有一批原记录可直接按 \(O(\sqrt n\,V)\) 付款。在任一真实端点，将所有具有同一完整臂的适格中父的边长作一个斜率可控的上包络。当前中父近接触这个包络时，固定该端点的面积公式一次收下所有不交接收者。在独立的全尺度末根母式上，共同包络近接触且两价跨度至少 \(\sqrt n\log(n+2)\) 的记录有 \(O(\sqrt n)\) 倍实际来源的费用。

## 回代与剩余

把两种条件重抽的外部来源池放进同一份对数势，删除时总共花 \(O(nS_*)\)。若留下的原量超过显式的小预算，超过四分之三的**同条记录**在两个实际端点都出现高来源争用。每一端至少有一个体积档，其真实争用方向的共享比特价格达到 \(c\log^2(n+2)\)，仿射维数达到 \(c\sqrt n\)。按争用的实际权重抽方向时，它们还必须以高概率离开任何预先给出的低维仿射空间。两个端点的档可以不同。

记这些记录为 \(R_{834}\)。本轮回代为
\[
 |R_{833}|\le \tfrac43|R_{834}|+C(\sqrt n\,V+n S_*).
\]
尚需估计同时出现高争用和多方向重用的这批原质量。若实际高争用来源割每次缩小到原来源质量的 \(3/4\)，已证明的单臂递推有公比 \(6/7\) 的可求和费用。这个来源收缩在一般输入上仍待证明。原来的初始、删除跳跃、低占比、宽距离和方体环上正测度短驻留补集继续保留。一般 \(n^{1/2+o(1)}\) 上界与纯根阶上界均未证明。

## 实际计算

- 对两份第814轮原档各230条记录作连续来源积分。\(\phi_t\) 的原质量加权均值比线性一阶项高 \(57.10\%\) 和 \(57.35\%\)。两份四维档的高维充分门均为空。
- 在各992个正宽来源子胞上，核验了全流、只留三锚组和组内裁薄三种负载。每份原档都出现了三个被多个中父共同使用的子胞。删除指定原行后，势降与消失配对报价之比分别严格超过 \(1.0000000000678278\) 和 \(1.0000000000649124\)。
- 正宽来源的真末根在 \(2,16,256,4096\) 维复算，包含近接与超出包络门的正测度接收区域。另在最高 \(65536\) 维核验拉伸盒和一至三条共同斜向的正厚集合。三组 \(65536\) 维集合的真实体积成本的自然对数分别约为 \(11.40,20.29,28.73\)，逐轴外包则约为 \(26573,33478,36676\)。这些人工几何输入未取得第813轮历史资格。
