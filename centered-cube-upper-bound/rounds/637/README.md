## 本轮经过核验的结果

- 有限候选池用同一份真实旧 KKT 来源、另一份真实容量证书及完整接收并集建立联合模型，保留全部正体积坐标胞腔、旧矩、标签数和逐行需求。相同 incidence 可合并来源变量，真实接收体积必须全部累计。有限模型不等于无限动作优化。
- 全维整行付款限制通过独审：若每行完整需求由一个共同交包独自支付，则 V_new≤P‖τ‖₁；困难分支 R>P 下无法给正更新。因此不能因计算复杂度将完整分数容量简化为整行指派。
- 修正来源合包时共同标签的信用损失；保留所有逐行信用的分数构造合法，但没有证明其节省足够支付完整预算。
- 原始三个有限尺度池的140个非原尺度候选，均有精确单行不可达证书；结合解析论证，三个有限池的最优值恰为零。没有排除池外连续小尺度增长。
- 压缩宏中心后，三个完整混合尺度族获得同一实际 AC 旧来源、严格新见证、真实接收并集以及最优容量 Q_C=244/25。精确 D/V 分别为 1/5、71/375、239/1375。均为非困难控制，不是一般预算或 canonical Q* 的结论，也没有认证整个压缩候选池最优性。

决定性缺口仍是：在同一个完整近极值族和一个合法旧 KKT 来源下，通过跨 clique 的分数需求重组，获得足够真实容量节省，并与全部接收测度共同达到 V_new−R‖τ‖₁≥cV−C√n log^B(n+2)M。已有公式、有限正例和新增交集本身没有支付这一主步。
