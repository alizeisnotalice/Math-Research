# 第36轮：稀有价格障碍与半见证支付修复

2026-10-10。**一般 sqrt(n)n^{o(1)} 上界与 geom 余项仍未闭合，保留一般上界 O(n log n)。**

本轮证明：保持真实 k 命中需求，只选约一半、且能扩成原 k 见证的成员支付，可把价格分层损失从 k 降至小于2；调整后的完整价格预算与原窗口无权问题相差绝对常数。该等价关系含未知的原弱常数，不是新上界。

给出实际轴源和有限原子量化：m 为对数规模时，旧全员均分价格容量可达 Ω(n/log n)，但同一输入的实际总覆盖费用不超过4/3。半见证使稀有高价来源的费用从一阶降至 O(ε^(k−r+1))，避免这一额外障碍。例子不否定临界 m≈sqrt(n) 的旧接口，也不否定主目标。高占用分支有明确预算，剩余分支仍待证明。
