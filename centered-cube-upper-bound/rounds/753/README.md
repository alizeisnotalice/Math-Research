# 第753轮　真实共享来源的坐标距离与接收体积

取第752轮保留的一对父方体。按这对方体当前实际保留的来源质量，独立取两点。任何同时接纳这两点的大方体，其整个接收所有者都落在两个以样本点为中心的外方体之交内。以各轴上的实际距离计算交盒体积，再对互不相交的所有者求和，得到双向原积分上的估计

\[
 \sum_e T_e\,p_e\,e^{\Gamma_e}\le C(1+K)n\log(n+2)\,M .
\]

\(T_e\) 是该对的原接收流量，\(p_e\) 是相对于小父实际来源质量的共享比例，\(M\) 是来源总质量。\(\Gamma_e\) 是两枚真实来源点逐轴距离的三次多项式平均，在证明包式 (3) 定义。该式允许同一来源被任意多个接收者使用，也允许来源坐标间任意相关。

**实际支付的部分。** 令 \(r\) 为小、大半径之比，\(\Delta_e\) 为 \(\Gamma_e\) 与给定方体交允许的最大边际值之差。当 \(r\ge C_0(\log(n+2)/n)^{1/3}\) 且 \(\Delta_e\le nr^2/160\) 时，第752轮中这整批有向对的真实流量连同几何例外合计至多 \(O_K(M)\)。阈值来自硬交统计中的 \(nr^2\) 增益与 \(\sqrt{nr\log(n+2)}\) 误差的比较。更一般地，在两种来源次序中同时删除 \(p_e e^{\Gamma_e}\ge\sqrt n\log(n+2)\) 的整对，合计至多支出 \(O_K(\sqrt n M)\)，新增接收吸收系数为零。

**仍未解决。** 把新条件加入第752轮同一次筛除，仍能保留至少 \((1-2\xi)T_0-C_K\sqrt n M\) 的真实流量。其每一对都保留原共享质量下限和两端的正权见证，但满足 \(p_e e^{\Gamma_e}<\sqrt n\log(n+2)\)。较小半径比和较大半径比中坐标距离缺额较大的情形，均须留在同一未付积分中。一般弱型上界仍未证明。

**本机核验。** 一小六大的二维方体族覆盖两个父体积档，小父实际质量为 11，体积为 \(225/64\)。用有理算术分别核对两种来源次序及 \(k=1,2,3,5\) 个真实样本的换测度。另一个方体网格在二维显式枚举了252个大所有者，在16、64、256维按整数幂精确计数。多项式中的下界 \(1/40\) 有代数因式分解，并在含端点的17、257和4097点网格上复核。256位 Arb 检查含指数的有限实例；复跑所得 JSON 逐字节一致。算例中的 \(G=2\) 只用来核对给定质量帽。
