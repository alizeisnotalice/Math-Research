# 第290轮：长方体对数容量与宽距离交通的有价覆盖

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮主攻第289轮确认的宽来源距离缺口，建立了一个新的长方体来源弱型估计，并将其接入全软度实际来源积分。没有把窄距离引理继续冒充全域估计。

## 1. 新的长方体弱型几何
任意有限正来源μ支撑在轴平行长方体内，边长为d_i。对所有0<a≤b，中心硬立方体在[a,b]尺度上的极大算子满足

||M_[a,b]μ||_(1,∞)≤κ_d||μ||，κ_d=2+Σ_i log(1+d_i/a)。

无需均匀密度、乘积来源或FIRST。给定阈值u，令r=(||μ||/u)^(1/n)。若r≤[∏(a+d_i)]^(1/n)，直接用短尺度包络；否则唯一选A>a使∏(A+d_i)=r^n。内长方体的体积恰好花一份来源质量，其外的所有实际见证尺度被夹在[A,r]，剩余价格nlog(r/A)=Σlog(1+d_i/A)。由此严格得到对数宽度和，而非未经证明地把n倍最大宽度换成坐标和。空窗口和低阈值边界均处理。

这一步特别适合很长但横向很薄的来源几何。完整证明见rectangular_capacity.md。原强尺度包络也可给κ=min(1+nlog(b/a),κ_d)的安全改进，见wide_geometry.md；下文为统一记号使用κ_d。

## 2. 全软度与真实来源付款
恢复原a≤L,R≤b≤2a、真实dx、实际q∈[3λ/4,λ]、实际软响应FIRST上限和硬最大响应上限。对每个潜在矩形核做坐标缩放，使用宽度权重w_i=log(1+d_i/a)/κ_d的逆边长标记；这些权重总和小于1，条件化后宽度因子消去，标记熵仍至多log(n+1)。因此可复用R283已证的B_*(n,D)，没有另收宽度向量的熵费。D=n覆盖全部软度，记相应常数B_n，logB_n=O(log(n+2))。

对接收点选择之前冻结的共同矩形网格，准确同胞概率为

A_d(y,z)=∏_i(1-|y_i-z_i|/d_i)_+。

原A_d加权双来源交通满足

∫A_d dT≤κ_d[(16/3)W_ρ+(1+logB_n)W_ν]。

来源分别不交分配，同一个来源点没有复制到多个相交盒子。若原分支满足Σ|y_i-z_i|/d_i≤η<1，则A_d≥1−η，其完整费用仅再乘1/(1−η)。低pe分支的β FIRST已在R289核验，因此这项可直接接回原低pe宽距离积分，外层Λ仅一次。

## 3. 任意共同分区及明确的宽距离支
对于接收前固定的可测随机可数分区，每个胞C放进边长d_(C,i)的矩形，记κ_C=2+Σlog(1+d_(C,i)/a)。共同同胞权A的实际费用为

∫A dT≤(16/3)EΣ_C κ_Cρ(C)+(1+logB_n)EΣ_C κ_Cν(C)。

已明确可数共同索引、联合可测胞指示及可测宽度，保证Tonelli合法。容量可以无穷；未证明有限上界前不能称为根阶付款。对矩形胞，κ_C=2+log(|C+Q_a|/a^n)，是来源质量加权的扩张体积对数，而不是体积本身。

一个已可付款的真实宽距离类：预先固定第一坐标，允许|y₁−z₁|≤na，其余坐标差≤a/n³。取d₁=4na、d_i=4a/n²，则同胞概率至少1/2且κ_d≤2+log(1+4n)+4/n。故该正厚度、任意L1来源分支有O(log²(n+2))的全软度原始交通价，并非只容许原子或直线来源。

对原连续正交通，若另在原上槽保留R₂(y,v)≤D及实际ns≤D，先逐原行估计score再换物理时钟，完整费用为

[2Λ J_D κ_d/(1−η)] [(16/3)W_ρ+(1+log B_*(n,D))W_ν]，J_D≤4√(nD)。

因此上述宽方向类在D=O(log(n+2))时也有根阶多对数的原连续交通价。这里R₂是辅助上槽位移，不是原硬来源对距离；没有把R279仅在tiny-near证明的尾部付款套到wide域，wide域的大ns或大R₂补集仍在。

## 4. 可计算的最优宽度与未解覆盖
对接收前指定的正坐标包络v_i，要求Σv_i/d_i≤η。令t_i=v_i/a、x_i=v_i/d_i，最小化Σlog(1+t_i/x_i)是严格凸问题。唯一最优解满足Σx_i=η及

x_i=[sqrt(t_i²+4t_i/τ)−t_i]/2，τ>0。

数值实现使用有理化表达避免消减误差。此为固定包络的最优费用，不能对每个实际来源对分别选最优矩形后免费求和。未知方向的并集、随机分区的覆盖率和胞选择都须明确付费。

全局尚缺：构造对原宽距离交通有效、同时满足低来源容量和充分覆盖/有价遗漏的共同分区或混合几何估计。现有低pe、连续交通及初始/跳跃/删除槽的未付部分仍按原式保留。原矩形profile没有证明A普遍接近1，也没有把余项改名当作闭合。高连续项的score费用不能因原始交通已付而略去。
