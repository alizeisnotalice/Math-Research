# 第759轮　真实价格位移和下一方体半径的二次估计

第758轮留下同一份三步流量 \(R_3\)。固定一个中间父 \(t\)，记 \(x\) 为进入它时的真实来源点，\(z\) 为按 \(\mu|_{A_t}/m_t\) 重新抽取的来源点，\(k\) 为实际到达的较小接收父。以下两项付款都允许 \(x,z\) 高度集中或高度分散。

**在同一价格上累加所有尺度。** 令 \(R\) 为 \(s_k\) 的相对体积档上端，\(h=1+1/(32n)\)。只对超出剩余半径的坐标计算
\[
 J=n\sum_{\ell=1}^n
 \left(\frac{(|z_\ell-x_\ell|-s_t+hR)_+}{hR}\right)^2 .
\]
对 \(1\le b\le n/4\)，原三步流量中 \(J\le b\) 的部分至多为 \(C K(1+b)S\)，包括实际落点已经越出预测方体的路径。证明固定真实的 \(z\)，对各档内不交所有者的越界体积求和。每个坐标随半径下降而停止越界，累计费用取决于超出量的平方。取 \(b=\sqrt n\) 即为纯根阶付款。

**在重抽前为所有尺度共同选择价格区域。** 若能为各档选价集，使其按下一接收半径增厚后的并集体积不超过 \(L d_t\)，在这些价集上保留的流量便可支付。若它们覆盖该父实际出价行一半的带尾生存量，则经过该父的整批三步流量都可支付。取 \(L=\sqrt n\)，在所有实际尺度档中均可同时使用至少 \(\exp(c\sqrt n)\) 个半径不小于 \(c s_t/\sqrt n\) 的盒。下一半径至多为 \(r_0s_t\)、\(r_0<1\) 固定时，可在该档使用 \(\exp(c(r_0)n)\) 个半径 \(c(r_0)s_t\) 的盒。归档式（9）给出每档的确切配额，所有档共用一份预算。

设 \(R_{\rm far}\) 为这些付款及归档中平滑位移检验后留下的实际三步积分，完整回代给出
\[
 \frac{277}{3072}T_0+\frac{\mathcal D}{3}
 \le 2\cdot256^3 R_{\rm far}+C LS ,
 \qquad S=\|f\|_1/\lambda .
\]
**一般上界仍待证明。** 两个中间父的真实位移都超过二次门槛、出价无法由共同区域取得半数、且仍满足第758轮外逸和分散条件时，尚缺这批流量的统一上界。
