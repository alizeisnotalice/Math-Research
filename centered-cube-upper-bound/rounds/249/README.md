# 第249轮：局部接收重叠熵与保来源互补预算

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮证明支持相交图的局部熵弱型求和，将相距很远的来源团簇从彼此的熵费用中移除；再把块内平滑、可行部分运输和残余局部重叠费用合并到同一实际硬接收积分。所有来源、体积、容量与误差份额保留。部分运输只是估计内的正源分解，不改变原后验或自动赋予新 cut。

[研究包](research.zip)保存详细 LaTeX 文本、独立审核、实际 MATLAB 求解和有理证书、必要代码与复现说明。不编译 PDF；本轮仅新增本说明和 ZIP，并更新项目总览。

## 实际验证

- 三阶段126个有限支持函数族、1554个断点；50/80位运算的报告数字一致，属于有限数值证据。
- 八个真实有限网格 QP，619条边；八组精确有理可行流、弱对偶及 gap 证书，两个对称图另有精确零间隙证书。包含两个必须向邻块运输的浓集来源实例。
- 主代理独立实现检查网格覆盖、真实类型与体积、原基线、可行流、乘子、PSD 特征平方及 gap。MATLAB 状态本身不充当证明。

解压后运行 `python3 reproduce.py --verify-only` 验证保存的有理证书；运行 `python3 reproduce.py --output-dir /absolute/new/path` 另行复算局部熵 JSON。后者需 mpmath。重新调用本机 MATLAB 的命令见 numeric_notes.md；新的浮点候选不要求逐字节一致。

## 剩余缺口

局部重叠账的粗几何上界仍为 O(n log n)，不是根阶。尚需构造同一个实际可行部分流，使运输费用与残余局部重叠费的总和满足一般根阶预算，并完成对原重尾双后验交通的合法回代。集中软部分也未由硬支持估计支付。有限网格的显著成本下降不证明一般维数阶。
