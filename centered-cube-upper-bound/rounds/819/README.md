# 第819轮　真实末根双端割上的全尺度来源分配

沿11月23日指导第5节直接处理一般输入。给定有限正来源 \(\mu\)、同一阈值 \(\lambda>0\) 及实际成功接收点 \(x\)，取其最右越阈立方体 \(Q_x\)，体积 \(v_x\)。在真实接收测度 \(\lambda\,dx\) 上，从 \(P_x=\mu|_{Q_x}/(\lambda v_x)\) 独立抽取两个实际来源 \(p,q\)。全尺度均可用。有限窗的最高端点用该盒真实质量另行归一，单付一次。

**一份可同时用于所有来源割的容量。** 固定 \(p\) 及体积档 \(D\le v_x<2D\)，可任意预选 \(0\le w_{p,D}(q)\le1\)，只要求 \(\int w_{p,D}\,d\mu\le K\lambda D\)。各档可使用不同的来源。记被选双端边的实际质量为 \(\tau\)。写 \(N=n+2,\ a=4\log(N^2(1+K))\)。当 \(a/n\) 充分小时，对每个可测 \(A\) 有
\[
 \tau(A\times A)\le
 C\bigl[\sqrt{na\log(en/a)}+\log N\bigr]\,\mu(A).
\]
存在同一份分配，在真实接收记录上将每条选中边付给其一个实际端点，同时满足上述容量。若 \(K\) 是固定次数的多项式，系数为 \(O(\sqrt n\log n)\)。若 \(\log(1+K)=o(n)\)，系数为 \(o(n)\)。该结论包括无限多个绝对尺度。

**全尺度费用怎样合计。** 对每个双端割，暂时只标记 \(\mu|_A\)。删掉的接收区及坏标记由 \(O(\sqrt n\log n)\mu(A)\) 支付。坏标记的估计保留了第二个端点仍在 \(A\) 内的真实比例。每一个保留标记只使用 \(O(n\log n)\) 个体积档。最后对同一原流的全部割取得共同分配。详细证明也允许选择读取实际接收者，把所需的条件相对熵在真实来源上计费。

**对可能的线性下界构型的必要条件。** 若某个输入的原接收费用至少为 \(\epsilon n\|\mu\|\)，则存在 \(c_\epsilon>0\)。固定真实首来源和当前体积档，按原接收权独立重抽 \(\lfloor e^{c_\epsilon n}\rfloor\) 个立方体，至少一半原双价记录重新捕获第二来源的概率仍不超过 \(1/2\)。更直接地，把每单位原接收按实际质量归一，给定第一来源和体积档后，接收点与第二来源的条件互信息须至少为 \(c_\epsilon n\)。互信息和重抽概率都由输入本身决定。若允许读取接收者且要命中固定正比例，使用 \(\log(1+K)=o(n)\) 的来源表时，每单位原接收质量平均需要至少 \(c_{\epsilon,\theta}n\) 的相对熵。

**核验与缺口。** 在二维三原子例上，全部体积档合并后的最优端点容量精确为 \(21/20\)。将原子摊成小方块后，在明确内缩的正面积接收子集上为 \(16284/15625\)。另在 \(n=1,2,8,64,256,1024\) 的正 \(L^1\) 例中，\(k\) 次重抽的真实捕获比例恰为 \(1-2^{-k}/4\)。有理最大流、256位与384位区间结果均可重放。现有估计还缺对其余边的支付，或对任意输入覆盖固定正比例的低信息选择。因此一般单窗 \(B_n=o(n)\) 和全尺度 \(C_n\le K_0\sqrt n\) 仍待证明。
