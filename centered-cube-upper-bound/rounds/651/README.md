# 第651轮：旧最优来源几何与 Eulerian 联合覆盖

一般 `n^(1/2+o(1))` 弱型上界仍未证明。保持同一个完整 Gamma 目标，没有将来源容量替换成实际接收费用。

## 经独审的结果

- 近联合目标最大值迫使旧来源近其同几何势能下确界；保留实际 AC 源，不假定下确界达到。
- 证明每个旧饱和方体交集内的完整极小集是轴向矩形，有唯一最优半径向量、精确集合距离公式和逐行退化坐标接触。距离常数依赖实际权重，未当作统一常数。
- 源亏损控制实际锚点及自适应所有权的偏离费用，全部来源预算只使用一次。高增长、近平衡及新来源费用仍在。
- 核验 Eulerian 分配保留当前完整传播与费用账，使真实锚点体积权和来源接触体积权逐项匹配；完整期望账显式保留非负混合信用 `L J_mix`。旧最小分配优势不再领取。
- 接触方向分数覆盖可按同一实际来源测度汇总为 `sqrt(2n) M` 容量，并保留未覆盖质量的期望界。这不是物理接收费用已付，也未证明小混合亏损自动给出小例外。

## 剩余的唯一主攻接口

将接触通道容量用于同一次完整动作的物理损失及实际新来源行需求。物理价格 `u/epsilon`、低半径部分和新来源列不能省略；没有统一正 Gamma 或全局闭合。下一轮继续这一 Eulerian 联合机制，不换成新的局部归约。
