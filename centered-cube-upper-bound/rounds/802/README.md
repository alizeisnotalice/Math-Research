# 第802轮　已知中父、两枚真价和对端接收点后的共同来源质量

第801轮给出每个小父内部真价的分散界。本轮让不同中父、不同小父竞争同一份真实来源。每条存活记录依次公开中父 \(t\)、自己小父的体积档 \(D=2^d\)、两枚原交价 \(z,q\) 和对端真实接收点 \(w\)。保留自己的实际小父 \(u\)，从同一 \(u\) 的另一条完整有向记录抽取比较价 \(y\)。自己的小父标签及其接收点仍通过真实条件律积分。[完整 LaTeX、原始数据和复现程序](research.zip)

**能支付的整批原记录。** 令 \(\omega=\lceil\sqrt n\log^2(n+2)\rceil^2/(8192^2n)\)、\(W=e^{\omega/4096}\)、\(\tau=e^{-\omega/4096}\)。每个公开观测都可以单独选择使 \(y\) 命中概率最高的来源集合，集合的真实输入质量上限为 \(WD\)。将符合这一条件的最优命中强度按全部中父、两种方向和实际接收点积分。借助不交接收区的方体交体积，再用 \(\mu(A_t)=m_t\) 消去中父分母，所得收费即使再除以 \(\tau\) 仍为 \(o(V)\)，\(V\) 为真实接收总体积。由此可以整行删去最优命中率过高的原记录。

**对剩余的同时约束。** 在同一终态几乎每个正公开行上，任何输入质量至多 \(WD\) 的可测来源集，命中条件概率均至多 \(\tau\)。通过双向外部来源检验的比较价至少有 \(1-\delta_n\) 的条件质量，\(\delta_n\to0\)。这些价可用的来源并集因而必须具有至少 \(WD((1-\delta_n)/\tau-1)\) 的真实输入质量。进一步把两份记录各自的对端接收点都保留，只有由同一小父支持的配对才进入几何预算。全轮筛查和旧门重查的成本为 \(C(LV+(n+2)\log^6(n+2) S)\)，其中 \(L=\sqrt n\log^3(n+2)\)、\(S=\|f\|_1/\lambda_0\)。比例删除在同一总账中吸收 \(2/7\)。

**本机检验。** 独立 Python 3.12.14 对非均匀连续来源和不交实际接收区作了三阶段有理核验。压力例两份记录分别有正量，共同小父系数积为零，分别最大化会给 \(1/16\)。源并集成本上限取 \(5/2\) 时，1312 个真实公开行中，只看自己旧价与查看全部公开标记的最优捕获率分别为 \(7479/7792\) 和 \(23149/23376\)。扩大至 6174 行，仍有 1862 行无法完全捕获。另用 384 位 Arb 核验七个维数的系数包围。低维诊断的成本和距离阈值均在复现包中注明。

**剩余问题。** 许多公开行仍可反复使用同一批分散来源及相同的对端接收区。现有联合积分对单行给出必需的真实来源质量，总账尚缺这些重叠行的合计预算。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。
