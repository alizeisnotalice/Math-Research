# 第725轮　投影见证的接收体积与跨组费用

开题复核[第706轮指令](../../AGENTS.md)。若一族真实来源在固定的其余坐标上覆盖同一点，而允许至多 √n/log(n+2) 个坐标自由游动，本轮证明，凡从该族获得固定正权重的真实近尺度接收行，其总体积至多为该族装填价值的常数倍乘 exp(−7√n)。任意多个互不相交的此类来源族可以合计收费。

对第724轮未付的超预算来源，还估计了第二个见证的实际接收区域。该估计容许少数坐标有大位移，同时容许大量坐标各有小位移。若不同来源各自漏掉不同的坐标，则以实际所有者的体积推导另一条较严格的数量条件。两种条件的代价在原来的同一配对积分中支付。一般输入仍可能留下跨许多坐标分散、又没有足够投影覆盖的贡献，其合计 O(nD) 估计尚未证明。
