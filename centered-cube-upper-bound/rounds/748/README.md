# 第748轮　受真实接收体积约束的装填及两端的方体交集

对任意有限方体族，存在一份空间可行的装填，使每个标签得到的价值与它的实际接收体积相容。设 \(v_i=|E_i|\)、\(d_i=|A_i|\)、\(V=\sum_i v_i\)，\(G\) 为同一维数与缩核系数下 \(V/P_0\) 的上确界。对每个 \(K>0\)，同一组权重满足
\[
 d_i\lambda_i\le K v_i/G,\qquad
 \sum_i d_i\lambda_i\ge K(1-e^{-1/K})V/G .
\]
系数随 \(K\) 增大趋于一。因而当 \(V/P_0\) 接近最坏值 \(G\) 时，能以可控的逐标签上限获得接近最优的装填。构造使用全部子族的装填不等式及有限维极小极大；直接截断一份原最优装填可能损失几乎全部价值。

**对真实接收量的作用。** 从原函数的近极值超水平集取首次达到阈值的父方体，使每个父方体的实际来源质量等于其体积。沿任何假设 \(C_n/\sqrt n\to\infty\) 的子列，对每个 \(\epsilon>0\)，都可保留至少 \((1-\epsilon)V\) 的真实联合接收量，使以下几何性质同时发生。

- 第747轮的集中来源、极端尺度和窄体积窗已扣除。对剩下的配对，共同来源点 \(z\) 同时位于两个父方体的相对厚度 \(\log(n+2)/n\) 边界层内，而且两端全部近面坐标集合互不相交。共享同一近面坐标的中段接收量至多为 \(C(1+K)\log^3(n+2)\) 倍总来源质量。
- 设 \(r=\min(s_i,s_j)/\max(s_i,s_j)\)。当 \(r\ge 2^{20}\log(n+2)/n\) 时，除去至多 \(C(1+K)\) 倍总来源质量的接收量，两个父方体的交体积都满足
  \[
     |A_i\cap A_j|\le (3/8)^{nr/1024}\min(d_i,d_j).
  \]
  证明从实际不交所有者的体积估计逐轴交长。独立均匀坐标用于计算包住这些所有者的参考方体体积，实际来源测度可以集中。

两个例外费用都能进入根号阶总账。完整推导还逐项支付了装填缺载、二端内层和集中份额，写明了近极值、缩核与维数的取极限顺序。**一般上界仍未证明。** 余下困难是很多不同父方体对可以同时在很小的交集上取得很大的实际来源质量，还包括半径比低于上述显式阈值的那部分中段。逐对交体积小本身无法支付这些来源的总和。

**本机复现。** 四组方体的124个非空子族分别核验了有理原、对偶证书。在线段链上，\(K=1\) 时直接截断的价值为 \(32/9\)，重选为 \(6\)。另以512层真实同心区间核验标量系数，逐轴交长在567组有理输入上通过，九组二项尾值只核验参考乘积体积。解包后运行独立 Python 的 `-B verify.py --check verify.json` 可复现。
