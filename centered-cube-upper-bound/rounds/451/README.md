六个正Lebesgue中心、L1来源、同q与octave模型获得精确原/对偶证书。单尺度目标对全部可行来源质量固定；两尺度在二维、三维出现来源高阶相关性收益。结果只覆盖这些有限几何，不猜测维数阶数。

解析方面核清实际交叠的有符号matching差额及共同selector的适用范围，尚无其根阶来源预算。原完整R433和母账缺口保留。
