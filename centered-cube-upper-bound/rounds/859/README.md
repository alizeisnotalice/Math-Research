# 第859轮　来源与三个真实接收位置的共同分配

在第813轮原双臂积分上，每条记录保留原两价、原完整度以及小父的两个实际接收位置。再从中父自己的接收者均匀取一点。现在每条记录可以用三父之一所含的真来源付费，也可以用上述三个真实位置之一付费。全部窗档和所有角色共用一份来源容量及一份接收容量。[详细 LaTeX 证明、精确流与五份复算](research.zip)

**联合估计。** 给来源容量 \(K\mu\)，接收容量 \(P\mathfrak j\)，其中 \(\mathfrak j\) 是按原历史质量分布在不交接收集上的测度。每一只真实小臂把部分质量保留在原来源点，余量移入该来源所在的小格，再按全部小父共同产生的输出密度截载。由此得到两个明确的保留分数 \(a_r(X),a_s(X')\)，其中 \(r,s>1\) 共轭。对任意 \(0<e<1\)，原流中以下同一份质量可以在 \(e\) 倍的两类容量内同时全付：

\[
 \min\!\left(1,\frac{eP\,d_v\,a_r(X)a_s(X')}{C_{r,s}\mathcal H}\right)\,d\widehat\Gamma .
\]

证明覆盖任一来源集合与任一接收位置集合组成的割。割缩小时，在子流上重算的保留分数只增大。这使一个标记能通过所有割，也能恢复到精确的勒贝格接收位置。

**真实几何给出的付款。** 固定所有中父共用的一份来源运输，其总输出密度至多为 \(n^a\)，其中 \(a>0\) 固定。若任一端有至少 \(n^{-1/2+\varepsilon}\) 的运输概率进入该端真实小父与中父的轻微扩张交集（固定 \(0<\varepsilon<1/2\)），则这整批原记录可在 \(C\mathcal H\mathfrak j+C_{a,\varepsilon}n\mu\) 的容量内支付。另一个无需选运输的分支是某端的中父仅在 \(c\sqrt n\log^2(n+2)\) 个以内的坐标截掉小父的投影；在该端对小父角点择符号，便可按真实接收体积付清。不同端点的真实源价和历史一直保留。

**本机检验。** 在同一批920条四维跨档原记录上，以第858轮的真实来源单价和仅接收全付临界单价的一半计，单用来源可付43.85%，单用接收者可付52.39%，两者共同可付95.40%。有理数原流与最小割给出同一最优值。96维正宽方向例检验相关抽取，8至64维实源例保留回填后仍遗漏的中段，另在512个不交接收区间上检验割缩小后的标记。复现说明在证明包末节。

**剩余缺口。** 对两端共享运输的命中率都很低、可用方向分散且小格输出同时过载的原记录，尚须证明最坏割差额的根阶界，或给出统一收缩。四维样本的未付款比例为4.60%。目前的一般命题没有给出这一比例或其他固定的收缩率。一般单窗次线性及全尺度 \(n^{1/2+o(1)}\) 弱型上界仍待证明。
