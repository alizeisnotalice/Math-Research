# 第37轮：首次命中平方预算与早期短占用余项

日期：2026-10-10。状态：本轮已完成；一般中心立方体弱 (1,1) 的 sqrt(n)n^{o(1)} 上界仍未证明。

对任意有限正 Borel 来源，在同一 Poisson 配置和逐接收点自然滤过下，证明包含初始命中、批量出生及终端命中的首次命中停止平方恒等式。空间结算得到：首次命中时实际均值不超过 m/2 的分支费用至多 4(1+2T)W/m。

将它与长占用、末段首次命中和可吸收的大均值分支合并，得到严格接口

`C_[a,b] <= 32 [K_crit + 2m + 1 + 9T/m + 4/m]`，其中 `T=n log(b/a)`，`m>=1` 为整数。

取 m=max(1,ceil(sqrt(T))) 后已支付项为 O(1+sqrt(T))。K_crit 是早期命中、全路径半阈值占用短、命中均值处于 (m/2,32m) 的真实事件预算，目标估计尚未证明；全尺度回收也仍待支付。报告没有将该接口写成最终上界。

另证明全 m 有效的左向 Poisson 保留比较，审计实际两时刻协方差及 Bernstein 参数；用实际单原子来源否定统一长寿命假设，说明一次见证队列的占用方案不足以消除线性时间成本。该单原子总费用仍不超过来源质量，不是目标定理的反例。
