# 第700轮　共享来源的坐标遗漏与接收子集预算

第700轮用方体各坐标的端点约束和实际互不相交的来源区域，估计同一接收子集可获得的来源预算。来源可以漏掉不同坐标上的见证，费用按真实掩码和使用份额累计。

REPORT.tex 给出一般乘积估计、分组总账和熵损失估计。faces.tex 构造 2^n 个接收正交象限的真实首次捕获输入；对全部这些目标的每个子集得到根阶支付，所有目标共同拥有的来源权重却至多为 a^(-n)/t。一般输入上的分组与来源份额仍未控制。
