# 第809轮　跨中父的真实来源分数覆盖与两侧接收费用

在第808轮原四边余量上，固定物理中父和指定小父，把两者的真实旧价交集按位置分片。对任一组片，取能在每一片上放足其实际输入质量的最小检验测度，称为这组片的分数覆盖容量。同一份来源可以同时承担任意多个父对的需求。容量的原、对偶问题都能在正来源质量的成员胞上精确表示。[详细 LaTeX、数值笔记和复现代码](research.zip)

本轮证明了两项作用于同一原量的支付。若一个中父上超过一半的当前原质量，能由总容量不超过 \((L/\mathcal H)m_t\) 的各小档覆盖，则整个中父只付 \(CLj_t\)。若一个物理接收点上超过一半的当前原质量，能由各档归一容量总和不超过 \(L^2/(\mathcal H\eta)\) 的源片覆盖，则整个接收行只付 \(CLv(W)\,dW\)。其中 \(L=\sqrt n\log^3(n+2)\)，\(\eta=\exp[-\lceil\sqrt n\log^2(n+2)\rceil/256]\)，\(\mathcal H=O(1+\sqrt n/\log^2(n+2))\)。第一个预算来自原臂总质量，第二个预算保留原对端的真实交质量。交替清扫按中父优先的固定次序执行，每个中父和每个接收点仅在首次清退时收费，总计 \(O(LV)\)。

尚缺对同时避开两侧覆盖的全部质量给出上界。不同接收父上得到的分数装填仍可能使用同一片实际来源。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。

## 本机核验

用本机 Python 有理算术在一、二、三维的有限物理几何上重建原路径。压力例的全族最小覆盖容量为 \(1793/256\)，严格介于最大单片质量 \(9/2\) 和真源并集质量 \(1825/256\) 之间。三组清扫检验分别枚举了全部 16、1024、65536 个子族，每组比较 49 对诊断预算。扩大例在预算 \((1/8,1/4)\) 下，单次合并两侧名单仍留 7.18%，交替清扫到稳定后精确为零。另一个例子显示清扫次序会改变终态。

在 12 个单标签重配问题中，使用精确排序或 SciPy/HiGHS 生成候选，程序保存并独立检查有理原对偶证书，间隙均小于 \(8.3\times10^{-14}\)。SymPy 核对联合尺度与来源分母，384 位 Arb 核验九个条件信息差。有限模型采用诊断筛和固定体积档。
