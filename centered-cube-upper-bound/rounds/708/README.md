# 第708轮　真实容量减半阶段上的有序体积档

开题已按项目 AGENTS.md 核对（4）。原积分使用同一首捕见证、u=hs_j、原始半径区间、原权重和真实接收体积。后续容量胞元只用于估计整个接收点的费用。

对固定 K≥8 或 K≤O(log log n)，证明除去费用至多 ηV_T+C·2^K√nD 的点，凡留下的接收点，在每个合法的 2^(−K) 深度首次胞元中，至少 K−7 个容量减半阶段各有 c√n 个不同的二进来源体积档支持高损失。早期阶段的这些体积档严格高于晚期阶段，同一阶段的合格来源提供至少 (log 2)/2 的真实对数容量降幅。选择固定 K 时费用为纯根阶，选择 K=⌈log₂ log n⌉ 时损失一个对数。可取 η=1/16。
