# 第831轮　真实伙伴在不同尺度上的共同接收费用

本轮在第830轮原剩余上，固定包含真实来源、历史和勒贝格接收者的两条完整臂，允许重新抽到的中父来自不同绝对体积档。共同伙伴方向在各档只收一次。用真实不交接收者对最小中父以上的所有体积作径向积分后，低共同容量的费用为 \(C^k(\mathcal H/L)d^{1/k}Y\)。取两条历史、\(d=n+2\) 时，这部分可直接以根阶接收体积回代。另给出了每档真实配对强度的加权和。低强度而共同容量大的记录仍待估计。

对真实硬方体末根，固定来源割，同一来源条件下两条记录彼此命中对方方体的总量至多为该割来源质量的四倍。详细推导保留任意尺度、原归一分母和固定的来源割。这项估计尚未覆盖完整的第813轮积分。研究目标仍为一般正 \(L^1\) 输入的全尺度根阶弱界。

[完整 LaTeX、四个复算程序与校验摘要](research.zip)。解压后，用装有 SymPy 1.14.0 的 Python 运行以下命令。第814轮的压缩包作为原始输入，路径可自行指定。

```sh
python -B replay831.py --archive /absolute/path/to/rounds/814/research.zip --jobs 4 --output verification.txt
```

实跑采用 Python 3.12.14，四项退出码均为零。两份四维归档在固定右臂后的中央跨档概率为 0.0850854450、0.0718866407，固定完整双臂后的概率为 0.0652364705、0.0545876430。另复算了 16 和 64 维校准峰、12 个共享伙伴档以及六组实际来源割和密度阈值。模型、渐近原门及有限检验范围详列于报告。
