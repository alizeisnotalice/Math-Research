# 第299轮：无硬尺度门的共同软覆盖

一般中心立方体极大算子 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮正向改进第298轮的共同见证几何：允许实际接收尺度小于见证尺度，同时保留真实费用，不再把 L<R 边从覆盖构造中直接排除。

## 主结论

对每个实际带硬帽的见证 Q_r(u)，定义

χ_r(L,R)=min{1,(L/r)^(n/2) min[1,(R/r)^(3n/2)]}。

在原 low、m>M 等全部限定下，乘此软权重的原交通仍由第297轮自身尺度的同一径向包络控制，费用为 (16/3)κ0 Ψ_G((b/r)^n)，κ0=2K/(ell M)，Ψ_G≤ψ∞=3−2/(3γ^n)。不存在额外尺度窗口因子，也没有假设小尺度来源密度上限。

从同一行真实接收概率抽取 N 个见证，使用共同加权并集。定义 D_y(L,R,z)=∫χ_R(u)(L,R)1_QR(u)(u)(z)π_y(du)，则精确平均覆盖为 H_N=1−(1−D_y)^N，费用不超过 (16/3)ψ∞κ0 N Wβ。D_y≥第298轮的有序捕获 C_y(min(L,R),z)，且现在所有尺度对均可贡献正权重。因此在相同预算下，实际已覆盖分配单调增大。D≥log(2)/N 分支费用至多两倍；取N=ceil(sqrt(n))还须控制κ0与原外层费用，不能据此宣称全体交通闭合。

## 全局极值几何的准确目标

主稿给出来源位置与实际尺度下界单元的共同分式覆盖：系数为 χ_i(l_j,s_j) 乘完整单元包含关系；每见证成本为 Ψ_G((b/r_i)^n)，统一有界。可测原始可行覆盖系数的总成本τ直接支付原交通，费用 (16/3)κ0 τ Wβ。全部尺度损失保留在覆盖系数，不能删除。有限原始/对偶同值证书可认证τ；尚未证明任意原输入都存在τ≤sqrt(n)polylog(n)的此类覆盖。

辅助稿将带 r^(−n) 的秩余项写成精确累计捕获层积分，保留原子修正、真实来源容量及接收行质量。若累计捕获来源有实际硬帽见证覆盖、归一化体积成本≤C，且接收半径的对数体积跨度≤D，则对L≥R的秩余项有显式小因子 ε≤min{1,C/(N+1)[1+D+log_+((N+1)/C)]}。若用于两方向v≥v0分支，须将此式中C/(N+1)统一替换为C/[v0(N+1)]，包括对数中的倒数。FIRST将对应分支回代为4ελ|E|；只有同一有限接收集上的匹配入口已证且ε<1/4才允许吸收。这些覆盖与跨度条件尚未对全体输入证明。技能 math-e03-tree-bellman-cross-layer-budget 用于核对跨层预算和终端项；本轮没有已验证的单树流结构，因此没有引用其外部 Bellman 定理或常数作为闭合依据。

## 保留的缺口

精确余项是原交通乘 (1−D)^N。新构造消除了硬尺度门，但没有给D一个一致正下界。两方向均有 D≥min(1,(L/R)^(n/2))C_y(R,z)。因此在该尺度比因子≥v0的分支有秩估计，但完整保留1/v0及来源集中费用；极小尺度比和整体残差仍未得到足够的积分预算。全体来源的联合低成本覆盖、集中费用以及原外层/初始/跳跃/删除账目仍需支付。完整 e_g、m、q、FIRST、所有来源与历史掩码、真实勒贝格 dx 均保留。没有一般证明完成声明。
