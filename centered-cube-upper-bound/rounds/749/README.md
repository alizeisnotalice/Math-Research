# 第749轮　两种尺度次序的真实接收量及交集中的来源密度

设 \(M=\mu(\mathbb R^n)\)，\(A_i=Q(y_i,s_i)\)，\(m_i=\mu(A_i)\ge |A_i|\)，\(v_i\) 为真实所有者体积。第748轮选出的装填可以满足 \(\lambda_i m_i\le K v_i/G\)，其中 \(G\) 为同维数有限族的极值比。对首穿越输入，用的就是第748轮的原装填。对一般可行对偶，按 \(|A_i|/m_i\) 调整各权重后，总来源负载仍等于调整前的装填价值。

本轮对同一真实接收积分 \(\Pi\) 证明两项全族估计，均无需吸收接收体积。

- 令 \(r=\min(s_i,s_j)/\max(s_i,s_j)\)。所有 \(r\le \frac1{64}\sqrt{\log n/n}\) 的接收量合计至多 \(C(1+K+K^{1/3})\sqrt n\,M\)。当大方体是来源时，在接收者上积分移动方体平均；当大方体是接收者时，在小来源自己的所有者上作第二次平均，使用它的真实质量上限。两个方向的中间档分别只花费 \(O_K(n^{35/96}\log^{1/3}(n+2))M\)。
- 对任意 \(B\ge0\)，满足 \(\mu(A_i\cap A_j)\le B|A_i\cap A_j|\) 的全部接收量至多为 \(CKBM\)。证明在同一积分中保留两个真实权重，利用方体强 \(L^2\) 界控制它们的体积加权和。取 \(B=\sqrt n\) 即支付这部分全部共同来源。

**对全局目标的含义。** 若 \(C_n/\sqrt n\) 无界，对每个 \(\epsilon>0\) 均可在相应维数子列选取实际近极值输入，使至少 \((1-\epsilon)V\) 的真实接收量同时满足
\[
 \frac{|A_i\cap A_j|}{\min(|A_i|,|A_j|)}
    \le e^{-c\sqrt{n\log n}},\qquad
 \mu(A_i\cap A_j)>\sqrt n\,|A_i\cap A_j|.
\]
这些接触还保留了第748轮的双端来源分散和不同坐标近面条件。此前未受交体积估计覆盖的极小半径比，现已从两个方向一起结清。**仍待证明的是所有这些高密度交集的来源质量能否合计控制在根号预算内。** 现有的小体积结论无法单独给出这项控制。

**本机核验。** 六个方体的77个正体积价格胞元及15个缩核所有权胞元给出精确恒等式 \(\int WF=1671/262144\)。有向费用用三个次序算得 \(617/132\)，误换方向得到零。第二组检验允许 \(m_i>|A_i|\)。四个有理阶梯函数共核验43段移动窗包络，另用256位 Arb 校验七个维数的标量预算，最大维数 \(2^{60}\) 仅代入公式。解包后运行独立 Python 的 `-B verify.py --check verify.json` 可复现。
