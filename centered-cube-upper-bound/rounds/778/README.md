# 第778轮　按实际来源选方向的联合估计与双真价端点界

本轮直接作用于同一条原峰 \(u-v-g\)。两个小父分别为 \(u,g\)，中父半径为 \(s_v\)，两条交边各自的真实来源价为 \(y,z\)。所有估计都对中父求和。令 \(V\) 为不交接收者的实际勒贝格总体积，\(Y\le C_*V\) 为原首臂总质量，并设

\[
 \ell=\log(n+2),\quad L=\sqrt n\,\ell^3,\quad
 r=\lceil\sqrt n\,\ell^2\rceil,\quad k=\lfloor r/(65536\ell)\rfloor .
\]

**两个真实价的分离。** 将 \(|z_i-y_i|/s_v\) 从大到小排列为 \(a_1,\ldots,a_n\)。在第748轮选定的输入上，未筛原峰满足

\[
 Q^0\!\left\{\sum_{i>k}\min(1,a_i)\le k/16\right\}=o(V).
\]

更一般地，每个来源点可以依据全部原峰的真实权重，预选至多 \(\lfloor e^{r/65536}\rfloor\) 个方向，每个方向带至多 \(\lfloor r/65536\rfloor\) 个例外坐标。即使允许再按本条峰舍去最大的 \(k\) 个横向坐标，两价位移贴近所选方向的原峰也有同样的绝对费用。证明先在旧小父上把各方向的实际来源份额合成一份预测，再用完整的下降度分母恢复另一条边的真价。坐标独立性只用于计算覆盖真实所有者的参考方体体积。各绝对半径档共用一份来源预算。

**对全部剩余端点的改进。** 对以上余量，固定任意端点检验 \(0\le\Psi\le1\)。记 \(W(\Psi)\) 为第772轮原参照积分，保留两个小端自己的实际来源和接收探针，分母为 \(\max(m_u,m_g)\)。所有剩余中父的实际积分满足

\[
 \left(\int_{\|z-y\|_1>k s_v/16}\Psi\,dQ^0\right)^2
 \le C Y\,e^{-L-k/100}W(\Psi).
\]

因而 \(W(\Psi)\le e^{L+k/100}L^2V\) 的端点部分可以在 \(CLV\) 内支付。与第772轮相比，同一费用允许的参照预算扩大了 \(e^{k/100}\) 倍。这个增益来自计算两个真价能同时容纳的实际中父接收体积。

**完整总账。** 直接从 \(Q_{772}\) 出发，本轮实际扣除量至多 \(CLV\)。若继承第777轮保留的全部检验，对 \(B_0=Q_{773},Q_{774}\) 分别取 \(j=0,3\)，有 \(0\le B_0-R_{778}\le\varepsilon B_0+C_\varepsilon L\ell^jV\)。**仍未支付的是远价端点对中超出上述参照预算的原质量。** 对任意输入，尚缺其统一上界或固定比例收缩。一般 \(n^{1/2+o(1)}\) 弱型上界和纯 \(K\sqrt n\) 上界均待证明。

**实际检验。** 本机 Python 以有理数复算二维真实来源分配，以及 \(2,4,8,16,32\) 维同半径八度内的真实两价。二维方向分配例中，阈值 \(3/5\) 下按已知父分别选最佳单方向通过 \(127153/235606\) 的上行权重，合成预测通过全部四条测试上行。另以原下界笔记的分层来源检验多坐标分离，并用256位 Arb 核对五个维数的标量常数。有限图采用诊断资格，验证范围和未实现的高维条件已记入报告。[详细 LaTeX 证明、三份复现脚本及实际输出](research.zip)
