# 第849轮　同一终端的累计使用和整段来源质量

固定第848轮的原接收者、阈值、两个来源角色和第一旧槽，采用保留原连接来源的转移。记 \(S\) 为割的真实来源质量，\(D\) 为第848轮终端测度，\(b=\lceil\sqrt n\rceil\)。本轮沿同一二倍尺度窗的完整历史计费。[详细 LaTeX、四份本机程序及实际输出](research.zip)

## 共用一个终端的所有首件

设一条真实历史的终端方体边长为 \(l_0\)、中心为 \(y_0\)。给该终端预定一个对数放大率 \(u\ge0\)。把首件的私有来源落在 \(y_0+e^u l_0[-1/2,1/2]^n\) 的全部历史相加，其原质量至多为
\[
 E_n+\int \left(1+\frac{2nu}{b\log2}\right)\,dD,\qquad
 E_n\le C(n+2)^{3/2}2^{-b/4}S .
\]
特别，原终端方体的费用至多为 \(|D|+E_n\)，与有多少个长历史共用终端无关。取 \(u=b\log^2(n+2)/n\)，合计仍为 \(O(\sqrt n\log^4(n+2)S)\)。

证明用到早期真实接收者的高度帽。相差 \(r\) 步，旧方体体积至多为当前的 \(2^{-br}\) 倍。将旧盒扩大至当前体积的 \(2^{-br/2}\) 倍，边长仍在原窗内。可以在读取当前私端前生成一棵每个节点至多有 \(2^{b/4}\) 个子件的树，同时估计这些扩大盒中的真实来源质量。除已付的重访外，逆向经过同一终端的私端在哪些时刻还能进入其扩大盒，就有了逐条轨道的计数界。

## 连续多步的共同来源

在 \(k\) 步中固定全部接收位置和两枚外私端，把中间 \(k\) 枚来源一起积分。每条中间记录只贡献一份选择权、一个接收位置和一个原分母。对这段历史的真实联合来源质量，以及限制到各来源所在网格胞后的质量，均得到低于显式门槛时 \(2^{-k}|\tau|\) 的原质量上界。这里 \(\tau\) 是冻结前的单窗双端测度。一次合计所有位置及所有 \(k\ge\lceil2\log_2(n+2)\rceil\)，费用为 \(O(S)\)。几何比较使用中心方体极大算子的无维数强 \(L^2\) 不等式。[Bourgain 原文](https://arxiv.org/pdf/1212.2661)

## 本机复算及剩余缺口

- 四个正宽定向状态的正向与反向枚举完全一致。以一行原质量作单位，终端方体收得 \(5/2\)，其中一次终端为 \(2\)，重访误差为 \(1/2\)。该例用指定的有限转移核检验累计公式。
- 64维59档的正宽模型有一段满足所用整档秩窗的五步历史。保留同一中间接收者，联合通过率为 \(1/4\)。逐星重抽得到 \(1/16\)，把中间选择权重复计入得到 \(9/50\)。本例使用缩小的秩参数和专门的几何测试门。
- 第848轮的四维四步数值 \(2^{-58}\) 来自部分秩窗模型，适用于转置和伙伴筛选检验。该模型省略了 \(2H\) 低秩截止和整档相容筛选。本轮的复算程序明确区分了这些条件。

**一般上界仍待证明。** 长历史的首件私端可以散布在同一终端方体外，并在每个连续段维持高的相容来源质量。这批原件跨多个首件、多个终端的总量仍未支付。第813轮的其他原费用及全尺度条件继续保留。
