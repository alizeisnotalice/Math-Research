# 第25轮：高弱比来源的局部增益上限与全局Poisson修正

2026-10-08。**一般 sqrt(n)n^{o(1)} 上界未闭合，保留一般 O(n log n) 上界。**

对任意有限正Borel来源建立无需格直径限制的完整窗口L²噪声估计，并控制紧支撑输入的完整新旧对数势差与真正非负重选增益。沿用已接受的平方根下界族，证明指定a/n物理格、固定采样强度的增益上限按exp[−(1/4+o(1))nlog n]衰减：高弱比本身不足以保证该局部扰动有绝对正增益。该族未被证明为一般问题的近极值输入，也未否定增益/曲率比值策略。

调整为全局Poisson采样，质量标记h=αλa^n，证明同阈值完整对数势期望损失不超过6αW。采样数仍含输入参数ζ=W/(λa^n)，未取得几何占用或终态复杂度的一致预算。
