## 已证明与准确范围

对任意有限正来源，在体积时间u=n logL上取B(u)=∫_0^1 A_(exp((u+v)/n))μ dv。严格证明原极大函数与sup B只差绝对因子1/(1−e^(-1))；B局部绝对连续，B'=a(u+1)−a(u)。空间正变分在长度T窗口上至多(1−e^(-1))TW，未截断时单原子取等。这只是线性基线，不是根号上界。

真实一维有界正密度majority构造，质量恒为9/2、高度介于5/4与7/4，其尺度平滑后在固定带(1,2)内的正变分随来源深度K无界。证明用精确二项式条件增量和真实区间卷积的L1误差界；也给有限原子继承。它不同于第38轮未平滑网格微跳。

该例的上阈值2事件为空，所以不是原极大算子的反例。窗口长度T≈KlogK，反例只给沿该序列Ω√(T/logT)的费用，不否定单倍尺度或O(√T)的局部预算。K是来源深度，不是维数。

另证明合法窗口归约：越过2λ的接收体积由初始固定尺度费用W与λ乘截断正变分积分支付。回到原阈值须保留2/(1−e^(-1))因子及平滑的末端一单位时间延长。局部平方根预算仍是待证的更强充分候选，不能视为已知或必要条件。
