# 第289轮：全软度距离容量、低值域近对付款与真实宽距离缺口

一般中心立方体 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮新增可直接接入原积分的全软度距离容量估计；同时定位了此前近对路线之外真实保留的宽距离交通，不能把第288轮的局部付款当作只差常数核对的全局证明。

## 一、全软度任意半径的几何来源预算
保留真实dx、原实际选择器s∈[0,1]、a≤L,R≤b≤2a、q∈[3λ/4,λ]、两份接收前固定的正L1来源ρ、ν，以及实际响应帽∫p_yρ≤q、sup_(a≤t≤b)h_t*ν≤4λ。令T(r₀)为原q⁻¹p_yh_R双来源积分限制到||y-z||₁≤r₀，不含额外score或后验时钟权。

本轮证明对每个r₀>0，

T(r₀)≤4(1+nr₀/a)S_n，S_n=(16/3)||ρ||+(1+log B_n)||ν||，
B_n≤10000e²n³log(n+2)。

核心是把R283的任意D工具取D=n，恢复全部软度；在边长2r₀的共同随机移位网格中不交分配原来源。当变换后的来源支撑超过a时，改用已知强尺度包络，保证任意r₀下的证明合法；不把原紧支撑引理用到假设之外。完整证明和B_n准确公式见geometry.md。

对于非负递减右连续ψ、ψ(∞)=0、ψ(0)<∞、∫ψ<∞，进一步得到

T_ψ≤4S_n[ψ(0)+(n/a)∫₀∞ψ(r)dr]。

这是有明确来源价的距离权工具，不代表未付原交通自动具备这样的权。取r₀=a/(16√n)得到全软度√n log(n+2)预算；取r₀=17na只有n²log n粗价，明确不能据此宣称一般根阶。

## 二、确实新增的原低值域付款
原T_low保留pe_g<2Kq。R117 CL3已经给出β≤f且∫p_yβ≤P_(s,L)f=q，因此可合法将上述软来源设为β，无需从后来的ρ=β−σ∞倒推FIRST。独立硬来源保留原帽。

令r=a/(16√n)，原低值域的小来源距离支满足

T_low,near≤64√n log(n+2)(W_β+W_ν)。

回到旧总账只乘一次Λ=128/119；没有high分支的额外2，也没有辅助score/clock。本轮没有重领旧负信用。旧m≤M根法仍可按原价格使用；新的实际未付低支是

T_low,far,m>M=∫1_{pe_g<2Kq}1_{||y-z||₁>r}1_{m>M}dT，
m=e_g/[(1+log n)q c_j^(-n/2)g^n]。

保留原来源、Z_g、实际尺度、FIRST、heavy、小parent及history。该宽距离高归一质量支尚未支付。low_pe.md给出准确接口和已有价格，未以新名称当作证明。

## 三、全局范围审计改变下一步重点
R115原近端门是||x-y||₁≤16na，只能推出||y-z||₁≤17na。R256/R257的小距离门是新增正子分配，原文明确保留全部远来源对。R259随后在H中加入小距离指示，并非推出所有原交通都落在其中。

原R123总账还保留低pe、初始低测试、删除跳低测试和大删除耗散；第288轮只支付当前小来源距离的连续good-slot正交通。当前必须继续处理的原非负槽至少包括

ΛT_low,far +2Λ(I_rem+J_rem+D_rem)+P_cont,far，

随后仅按独立已证的不交付款扣除相应子项。未消费负项留在原共同测度上一次；不将它们重复贷给多个正项。global_bridge.md列出R_out前账、各原积分及来源，原X到R_out的完整入口也未在本轮认证。

本轮不声称第288轮局部引理失效；它的适用域仍有效。修正的是对尚待完成工作范围的认识：有真实宽距离几何缺口，不只是常数回代。

## 四、参数与全尺度连接
已定位原good/bad阈值推导允许任意固定K>0；后来的逆K价格和分支收缩要求各自保留，不能把数值K=64当成全部上游条件已满足。进一步核验：若K(n)≤K₀(n+2)^p且尾误差ε=ε₀(n+2)^(-p)，第288轮精确J核指数衰减可吸收多项式K，其当前near正交通仍有C(p,K₀,ε₀)√n log³(n+2)来源预算。该结论仍仅在原good/high/near资格内。

全尺度桥经核对Naor–Tao原论文Theorem1.1：完整的任意输入单倍频程硬立方体弱型界A_n，可推出全尺度C[1+A_n log(n+2)]。先覆盖[r,nr]的有限O(log n)个倍频程，再应用局部化定理，不对无限尺度逐层付整份W。缺的是完整倍频程定理本身，不能用near交通或选中子类替代。主代理核对了原论文公式(10)–(11)；详见scale_bridge.md及[原论文](https://arxiv.org/pdf/0912.1140)。
