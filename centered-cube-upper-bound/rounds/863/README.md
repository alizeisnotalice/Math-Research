# 第863轮　共同位移下的方体平均与原双臂的加权来源质量

同一右端来源可以经多个中父反复出现。本轮按每个真实小父的接收份额 \(j_i/m_i\) 计算这种使用的累计质量，并且在每个网格内让所有父共用同一位移。由方体核的逐坐标傅里叶乘积和不交的真实接收体积，得到以下两项对所有原割同时有效的估计。[详细 LaTeX 证明、四份本机程序与实测输出](research.zip)

**双端估计。** 在半径窗 \([R,2R)\) 内，把来源测度乘以 \(k(y)=\sum_i(j_i/m_i)\mathbf1_{G_i}(y)\)，每格以其实际累计质量计算保留分数。取边长 \(Rn^{-5/6}\) 和输出密度 \(n^{1/8}\)，按两个真实端点分数乘积保留的原量至多为 \(C(\mathcal H/L)n^{11/24}\mathfrak j(A)\)。这里 \(L=\sqrt n\log^3(n+2)\)，\(A\) 是任意接收位置割。两端均未超载的记录按全额计入。

**单端估计。** 每格 \(C\) 用实际积分 \(D_C=\int_C k^2/(k+\Lambda)\,d\mu\)，其中 \(\Lambda=n/[\mathcal H\log(n+2)]\)。令 \(K\) 为正文给出的共同位移系数。若任一端满足 \(K^2D_C\le |C|\)，该记录可全额支付，另一端的尺度、来源集中度和跨父复用均可任意。取两端分数标记的最大值时，原量在每个割上至多为 \(C[\mathcal H\mathfrak j(A)+n\mu(B)]\)。所有物理窗共享这笔来源预算。

**数值复核。** 在相同的920条四维跨档记录上，按8个实际窗内标签冻结来源量。在同一格宽 \(1/32\) 和同一压力门 \(1/32768\) 下，双端标记随零相位至半格相位从58.7550%降至1.6103%。单端平方费用在其独立的同价压力试验中，两端取最大值分别标记94.7181%和52.2380%。比例按原质量加权。证明包另含停止块的有理核验和最高320位的 Fourier 位移试验。单端根式用192与384位 Arb 交叉核验。该四维样本的中父质量差和完整度均未达到一般高维余项的条件。

**仍待解决。** 当两端所在格都严重超载且实际分数都很小，尚须整体控制这部分共享来源经许多中父和不交接收者所产生的原质量。本轮的新增吸收系数为零。一般单窗次线性和全尺度 \(n^{1/2+o(1)}\) 弱型上界仍待证明。
