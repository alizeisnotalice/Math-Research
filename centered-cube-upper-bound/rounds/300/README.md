# 第300轮：真实见证容量统一支付覆盖与秩余项

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮推进全局极值几何的真实质量计费，不再统一以见证数乘每个硬帽最大值代替全部来源费用。

## 新的统一预算

在原固定场内，从真实行接收概率抽取N个见证。对每个硬来源z，取捕获它的最小见证半径r_min，未捕获贡献0，定义

B_N(y)=E∫ r_min^(−n)1_被捕获(z)ν(dz)。

按最小半径分配来源后，第299轮的软权重给出合法的加权最大值覆盖。它不同于上一轮的乘积并集，不能直接沿用后者的残差公式。本轮证明了独立的正支配估计：在 v(L,R)=min{1,(L/R)^(n/2)}≥v0 的原交通上，

T_v0 ≤ κ0ψ∞/(q_-v0) ∫B_N dβ + (1/N)∫I_y B_N dβ。

这里κ0=2K/(ell M)，q_-=3λ/4，I_y是原接收行质量。覆盖与秩余项使用同一个真实容量；秩项不额外承担1/v0，也不重新收取每个尺度的Wν。完整e_g、m、q、FIRST、所有来源/历史掩码和真实勒贝格dx均保留，原外层费用仍须支付。

B_N随N递增且离散凹，B_N/N递减。重复见证的节省具有精确恒等式B_N=N B_1−R_N，R_N≥0是重复来源费用。加权秩满足J_N≤B_(N+1)/(N+1)≤B_N/N，非原子情形首个不等式为等式；原子情形保留准确非负修正。没有假设一般输入都具有足够重叠。

## 可测的自适应停止

令b_N=B_N/(4λ)。按每一行真实容量选择首个二次幂N使b_N/N≤ε（0<ε<1/4）。有限来源保证该搜索数学上终止，且其容量费用不超过同一采样律、同一容量停止准则的最优整数费用两倍。通过原FIRST，统一预算中的残差不超过4ελ|E|。取ε=1/8得到1/2系数，但吸收仍要求同一有限接收集上的匹配原始入口，以及对其余分支的明确账目。

更精确的J_N停止与容量停止、容量增量的比较见capacity证明稿；停止本身不能证明主项是根阶。A01技能用于核对归一化、正分母和零质量分支，没有引用未经核验的强对偶定理。

## 尚未支付的全局费用

核心剩余量是自适应停止后的实际∫b_N(y)β(dy)/v0，以及v<v0分支和原外层账目。有限停止不控制该量的维数阶；直接用B_N≤4λN会使接收项系数成为4，不能吸收。另一自动界B_N≤a^(−n)Wν也不足以给一般根阶。后续应利用原接收概率与FIRST的共同来源几何控制这些费用，而不是仅把它们改名或假设次线性。

## 实际检验与复现

本机Python三阶段精确分数检验两轮一致，主代理再次复跑：7742项全部通过。9个有限立方体模型使用正体积来源单元，逐对核对完整包含或严格不相交；维数包含1、4、8、16，样本数表覆盖1至64，停止搜索逐整数进行。包括576项容量增量≤精确秩、37项二次幂停止的两倍费用验证。8个容量阈值在搜索上限内未达到，明确记录为未达到，不解释成不可能。模型只核有限见证处同半径硬帽，未冒充完整原始接收场与历史。
