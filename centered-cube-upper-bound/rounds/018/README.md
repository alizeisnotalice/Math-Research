# 第18轮：真实捕获过程的质量时钟最大估计

日期：2026-10-07。**一般 sqrt(n)n^{o(1)} 上界未闭合。**

本轮证明：对任意真实输入、固定接收点和共同空间分割，若最大格质量为 q，则

- 质量帽下 E sup_{m_L<=H} |Z_L|² <= 4qH；
- 高质量后验 E sup_{m_L>=m0} |Z_L/m_L|² <= 16q/m0；
- 严格近赢家后验差 E D_eta² <= 64 exp(eta)q/(M a^n)。

证明保留同一格的多次部分捕获，借助辅助到达时间的条件平均与自足的有限鞅最大界。由此得到完整尺度线性增益和精确对数增益的细分趋零结论；只排除对所有足够细分割要求固定正原始增益，不排除适当物理分割或信号/曲率比较。尚缺一般高弱比近极值输入上的有效联合增益下界。
