# 第301轮：共同来源耦合费用与可实现的统一采样率

一般中心立方体极大算子 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮直接连接原FIRST约束和共同见证费用，保留真实接收占用与跨行差异，避免只把停止后的昂贵来源费用换名。

## 本轮已证结果

固定原外层场和v(L,R)=min{1,(L/R)^(n/2)}≥v0目标分支。原有与硬来源z无关、且仍支配同一目标掩码的行门α可直接保留在U_y=α1_Ep_y/q中。以tU_y du作为共同Poisson强度，原始I_y归一化因素不再进入最终费用。定义累计捕获强度A_yz(r)=∫_{R(u)≤r,z∈Q_R(u)(u)}U_y(u)du，真实最小见证容量为C_t。

1. 全部目标交通满足T≤(d+1/t)∫C_t dβ，d=κ0ψ∞/(q_-v0)。原子修正、实际dx、所有e_g/m/history/source限定以及外层费用均保留。该式来自正支配估计，不是把最大值覆盖的残差误认成乘积并集残差。
2. 用真实层积分测度dΩ=dβdν[b^(−n)δ_b(dr)+n r^(−n−1)dr]，令O_d=∫min(d,A_yz(r))dΩ，则O_d≤inf_t(d+1/t)∫C_t dβ≤在t=1/d的费用≤2O_d。因此一个共同可实现的采样率能达到逐耦合较低费用之和的两倍。O_d是这族上界费用的下界，不是原交通的下界；原交通确实满足T≤2O_d。
3. 行门若进一步限制、同时仍覆盖同一目标，C_t、O_d和行质量均单调下降。逐行还可取较低的4λI_y与2O_d(y)，没有额外来源复制。跨行FIRST/Jensen可保留真实占用A_z(r)，而非直接用整个接收立方体体积替代。
4. 低行质量集合I_y≤h的全部交通可按4λ∫低行I_y dβ支付；高行仅按真实质量B_hi(h)进入一个硬来源费用。参数优化保留阈值、维度、尺度及源质量。把所有真实信息粗化后只恢复已有的全局来源对数界，本轮不把这一粗界重复登记为新突破。

## 实质剩余问题

O_d以及跨行真实占用费用尚未获得任意输入下的根阶来源预算。低/高行分裂给出的可支付条件也未普遍建立。还需支付极小尺度比分支及原外层账目。共同采样率的常数因子优化不能代替缺失的几何估计；数值优化没有认证全局维数阶。A01技能用于核对正分母、零行和共同可实现参数，不调用未经验证的minimax或输运强对偶。

## 实际验证与复现

本机Python主脚本两轮一致，主代理再复跑：16152项检查通过。三阶段6个模型含22个正体积接收单元、74个β行（62个非零），使用真实s=0立方体核和由其精确诱导的π，不再任意指定行概率。完整包含关系、FIRST、同半径硬帽和跨行交通恒等式使用Fraction；Poisson费用使用40/60位mpmath复核。468项共同率费用≥精确O、36项t=1/d费用≤2O通过；最大相对精度复核差约3.73e−41。这些有限模型未实现完整原m/e_g历史及所有半径的极大硬帽，不当作一般证明。

几何稿另复跑36个Poisson原子秩、12个Jensen比较（双精度容差1e−13），12个45位标量积分（容差1e−35），16个双精度行门单调性。辅助稿复跑28个40位标量参数/端点检查；网格与局部优化不是区间认证的全局最优值。

为避免仅测试低行质量小单元，另构造n=16、32的真实同心接收壳模型，646项检查全部通过，主代理复跑成功。Fraction精确核对正体积中央来源、完整支持包含、FIRST、同半径硬帽、诱导π及I²>n。两例I约10.9942、20.9993；N=8时b_N/N约0.08790、0.05961，均≤1/8，其中容量≤4与停止条件有精确代数证书，显示数值由40/60位复核给出。该构造支持“大行质量伴随重叠节省”的后续方向，但只是明确来源模型，未证明任意大行质量都强迫重叠。
