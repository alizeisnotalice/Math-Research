# 第739轮　随机周期下指定接收标签的到达概率

对第706轮原高损失积分使用独立的坐标周期扰动，并保留真实来源、接收所有者和共同见证。对一个出发点和一个指定目标行，目标小方体唯一确定必须移动的轴和符号。实际接收截面由此给出到达概率上界。每个来源可预先指定例外坐标和需要避开的目标标签。

对短、长半径比分别按根阶预算结算后，剩余运动可逆。归一化前，短段跳到指定行的概率至多为 \(1/(1024n)\)，长段至多为 \(1/(8h\log n)\)。允许删除指定去向并维持整个配对，完整高损失账目动用 \(3V_T/32+O(\sqrt n)D\)。能持续提供大量不同去向的接收区域，其总权重仍待控制。
