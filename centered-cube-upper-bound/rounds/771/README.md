# 第771轮　割内真实来源的可逆路径与尺度转折

沿第770轮达到最大欠额的父对集合 \(F\)，将其全部实际交项写成一条可逆链。每一步的两个原历史及其共同价具有与原二次积分完全相同的边际，包括两种物理方向和两个真实质量分母。共同价从本步两块来源的真实交集抽取。链的各个状态按真实行总量加权。

**对割内交项的估计。** 在一段长度可以随维数增长的路径上，联合控制旧价、以前父的中心及以前抽出的共同价被后续无关联父再次命中的总量。令 \(Q_{\min}\) 为通过这些检验、路径中间父体积又比两侧都小的未归一质量，\(Q_{\max}\) 为中间父比两侧都大的质量。由可逆性和给定中间原历史后的条件独立，两种严格转折在检验前各占至少 \(1/4\)。联合检验所损失的原二次量至多 \(C e^{-3r/16384}Y_U\)。因此要给全部割内交项设上界，可以集中处理这两种转折中的任意一种。

**代回指南的原积分。** 用第770轮在同一份来源上已支付的全部割外项，连同第768轮的全尺度平方估计，得到
\[
 T_0\le C\sqrt n\,\ell^4 S+C\sqrt{S\ell\,\min(Q_{\min},Q_{\max})},
 \qquad \ell=\log(n+2),\quad S=\|f\|_1/\lambda .
\]
若其中一种转折能统一估计为 \(C\sqrt n\,\ell^3 V\)，上游的 \(V\le2T_0+C\sqrt n\,\ell^3 S\) 即给出所需弱型上界。目前仍缺这个估计。对另造的同档单向运输，本轮也证明了在出入边际均受同一测度控制时，终端至少损失 \(L/(n\log2+L)\) 的参考质量，其中 \(L=\sqrt n\,\ell^3\)。

**有理核验。** 三组真实价格区间模型穷举了 280 条正权二跳历史、1256 条三跳历史。直链例中，使用上一跳的真实共同价来检验下一父的扩张体，命中率为 \(2/3\)；若改用当前父的整个来源律则为 \(1025/4608\)。这一区别会改变实际回代。有限算例及其门槛见附包，所有有理数已经独立复算。
