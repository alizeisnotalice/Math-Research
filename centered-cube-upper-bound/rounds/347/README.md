# 第347轮：移位Hardy列容量与共同来源目标窗付款

**一般根阶一致上界仍未闭合。** 本轮从真实中心体积证明闭质量窗容量ρ_y[t,Kt]≤(1+logK)/q_-，保留全部质量原子。移位Hardy秩积分将相对高未来交通的共同来源入列界改进为λ[1+log(1/ε)]，但该列界单独不能吸收。

新增实际付款分支：若较大质量捕获中至少一半落在该来源的最高质量窗口Top_y，则条件路由保持整份原交通，以逐y列帽和真实Top容量联合得到

`G_rel,p≥1/2[g_ex] ≤ C_hit,n W_ex`，

其中 `C_hit,n=2(λ/q_-)(1+√n)[1+log(1/ε)]`。全部旧门、真实接收测度和原物理时钟保留，未使用来源密度帽。无新增X费用。

完整槽替换为

`B_H ≤ G_rem[g_ex] +(13/3)εXq +C_ε,n W +(C_top,n+C_hit,n)W_ex`。

剩余分支有超过(ε/2)J_b的真实上尾捕获落在最高质量窗之外；其多步列费用仍未闭合。外账接收系数保持13/36；历史CZ同账条件下841/2304。软层、质量可比重尾、极端尺度及历史初始/删除/未来被删来源独立留账，不把它们称为常数或对数优化。

主代理本机复跑：12,014项精确有理/有理对数包围检查；几何脚本1,767项Fraction断言，另2,304项Decimal诊断；核心脚本80组原子测度、960个Hardy情形和3,840个受限列等检查通过，但含80位Decimal比较，不统称精确证书。有限模型不认证一般几何实现；一维样例省略outside且为诊断参数。独立预审、全文后审与哈希绑定随包。
