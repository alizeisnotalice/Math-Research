## 已证明并独审通过

始终使用原有限正标签输入、原全尺度高核好区 H₂、全部实际见证和完整质量带 [L,U]。令 b=n^(-1/2)、T=log(U/L)，V 为全部不同见证质量的信用。截断 B_t=min(A_t,λ) 后，含终端原子的 Kcap 仍满足 Kcap≥λ(1+V)。因此 λ|R|≤Qcap=∫_R Kcap/(1+V)。真实来源分解保留总捕获质量分母，不能改为子集质量或密度帽。

依原贪心块分出 M_P>δm(t) 的近尺度分量。利用原 H₂ 的源中心空洞，其**整个质量带**费用至多 [log(1/(2δ))−1+2δ]W，端点另付一次 W。取 δ=b/2，得到

    Qcap ≤ (0.5 log n+b)W + Q_L(b/2)。

完整 Q_L 的饱和与次临界部分、全部尺度与两个接收权均保留，尚未付款。每个实际轻核心有坐标产品接收界，但不能将逐盒折扣当作全族折扣。

另对完整残余的最大实际见证作选择：质量≥2U/3的接收部分一次付3W/2；余部所选立方体捕获标签恰为所选S，真实质量分母等于m_S。其cells D_S分尽余部。对同一个 u∈(-1/2,1/2)^n 定义 A_S(u)={i∈S:z_i+r_Su∈D_S}，严格有

    λ|R_lo| = ∫ Σ_S m(A_S(u)) du。

若两个 A_S(u) 共享来源，原S、T必嵌套；所以任意原标签包含关系反链的实际接收费用≤W。同源嵌套链的重复仍未支付。此同锚嵌套也适用于一般凸体，不能冒称已取得方体特有的维数收益。
