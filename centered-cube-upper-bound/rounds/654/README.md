# 第654轮：合法产品源与自适应来源联合总账

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮保持实际 Eulerian 联合覆盖路线，不以局部费用代替完整预算。

对完整旧几何与真实全拥有类，证明可在不改变行质量、几何、旧拥有体积及实际熵优化器的条件下，选择饱和坐标格内的产品型正宽绝对连续来源，并以 `H(mu_theta) <= Phi + theta kappa M` 逼近完整 score 上确界。产品性仅在格标签条件下成立，不提供统一密度帽或条件碰撞后的独立性。

完整 high-only 来源总账保留真实物理损失和自适应优化器。双配置 bad-alpha 部分得到一次性费用 `R|Gamma_bad| <= 16 kappa M/a^n`；good-alpha 与真实损失／覆盖的联合控制仍未证明。加行比较明确：完整 D 中删除质量是有利项，未付的是保留行重优化的净反弹；辅助 B 值上界的费用不能直接移入 D。原输入恢复桥无最终 a^n 损失，但统一 surrogate 根阶预算仍缺。
