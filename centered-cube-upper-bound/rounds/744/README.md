# 第744轮　同一尺度上许多见证区域的联合来源费用

本轮估计第743轮留下的同一份真实配对。固定其第 \(k\) 个来源的接收端密度 \(\theta_k g_k(x)\)，记 \(H_3(x)=\sum_k\theta_k g_k(x)\)。后续删减仍使用这组密度。若 \(x\in E_j\) 且 \(g_k(x)>0\)，原共同见证 \(w(x)\) 位于 \(A_k\) 内部，且 \(2^{-1/n}s_j\le s_k<64\sqrt{n/\log n}\,s_j\)。

**可比半径的边界费用。** 固定 \(p>0\)。把这一半径范围内、属于同一真实来源池且共同覆盖某点 \(z\) 的原权重相加。若和至少为 \(n^{-p}\)，则 \(z\) 到 \(w(x)\) 的 \(\ell^1\) 距离至多为 \(O_{p,c}(s_j\sqrt{n\log n})\)。结合真实来源所有者的不交性，可以同时控制任意这类 \(z\) 靠近配对方体至少 \(m\) 个坐标面的关联，其中 \(m=O_{p,c}(n^{3/4}(\log n)^{1/4})\)，各轴容许宽度为 \(m s_i/(256n)\)。所有坐标选择、符号和尺度合计，每个端点至多占 \(\epsilon_nV_T\)，其中 \(\epsilon_n\to0\)。这一估计包括与配对来源等半径的次级来源。

**同一接收质量的两层分配。** 按真实接收父方体体积 \(\xi\le d_j<2\xi\) 分档，\(\xi\) 取二的整数次幂。将 \(w(x)\) 放入粗网格，每个粗格再细分。一个粗格里允许有不同的真实见证和完全不同的来源池。取固定 \(h_0=1/128,\ \zeta=h_0/16,\ c\ge128e^{1/32}/\zeta\)。每个来源 \(k\) 在每个实际体积档可以同时使用两份额度。

- 粗格额度为 \(P=\lfloor e^{8\sqrt n}\rfloor\)。用第721轮的矩形估计和真实来源分数权重，全体粗格单端费用至多为 \(C_{\zeta}J_ne^{-2\sqrt n}D\)。
- 细格额度为 \(Q_{k,\xi}=\sqrt n\,d_k/(6J_n\xi)\)，允许非整数。每个细格对应的真实接收量至多为 \(6\xi\)，每个来源最多涉及 \(J_n=3+\lceil n\log_2(64\sqrt{n/\log n})\rceil\) 个体积档。细格得分的单端积分至多为 \(\sqrt nD\)。

**剩余质量必须怎样分散。** 在剔除低密度端点和上述边界关联后，两端共同接收边际记为 \(\nu\)。对粗细两份额度联合优化，正文给出精确的分数割公式和 \(R_{744}\le2\Delta\)，其中 \(\Delta\) 是公式中的最大缺额。凡产生正缺额的同一割 \(0\le q(x)\le1\)，在每个来源的每个实际体积档分别取流量最大的 \(P\) 个粗格和 \(Q_{k,\xi}\) 个细格之后，仍有 **超过 \(7/8\)** 的总流量落在两份选取之外。这里总流量是 \(\sum_k\int q(x)\theta_k g_k(x)\,d\nu(x)\)，最后一个细格按余下额度取分数。此结论对割上的总流量成立。

**总账。** 对同一配对两端结算后，
\[
M\le (1/8+2n^{-1/4}+2h_0+2\epsilon_n)V_T+C\sqrt nD+R_{744}.
\]
接收系数趋于 \(9/64\)，原预算允许 \(9/32\)。尚无统一上界控制上述同一尺度的大量分散流量；若能证明 \(R_{744}\le\eta V_T+K\sqrt n\log^A(n+2)D\)，固定 \(\eta<1/8\) 仍可恢复全部尺度和任意 \(L^1\) 输入。

**核验。** 在64维真实双尺度历史中，前两轮取 \(B=1/2\)，第743轮取所有半径减半的内部格和全部顶点。此时 \(R_{743}>0.68280V_T\)，本轮边界估计的命中条件覆盖了这份正余量，\(R_{744}=0\)。这份输入的 \(c\) 很小，其费用 \(V_T<118\sqrt{64}D\) 单独按有理数核清。本机另以两种计数方法核对3至8维的坐标面并集，用有理数核对粗细额度的联合对偶，并以256位 Arb 核对到 \(n=2^{60}\) 的解析常数。超大维数的计算只涉及标量公式。
