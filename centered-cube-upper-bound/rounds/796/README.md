# 第796轮　不同接收点和尺度共用的来源分配

本轮在第795轮的整份剩余上，证明了跨终端的来源分配，并把一部分实际接收质量计入全局预算。一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。[详细 LaTeX、数值检验笔记与复现材料](research.zip)

**一个可跨尺度使用的来源分配。** 从每条原停止记录的终端父方体 \(A_t\) 附加一个新来源点 \(y\)。在两个实际旧交价中选择离 \(y\) 较远的 \(z\)，并保留产生 \(z\) 的小父接收点 \(U\)。固定物理体积档 \(D\le |A_t|<2D\)，可以由存活的不同实际接收点交错提出请求。对充分大维数，每档合计至多 \(\lfloor e^{r/4096}\rfloor\) 次，其中 \(r=\lceil\sqrt n\log^2(n+2)\rceil\)。每次都能选出一个对该接收点有正条件权的新终端，给它分配至少 \(|A_t|/768\) 的真实来源质量。来自所有指定接收点、所有体积档的这些来源片一起两两不交。接收点取在存活接收测度的满测度集上。

证明用到两个不同的分母。给定实际接收点，新增来源在任一已占集合上的概率，由该集合的真实来源质量除以 \(D\) 再乘一个指数小因子控制。再给定选中的终端，新增来源的条件密度至多是该终端真实归一来源密度的 \(384\) 倍。依体积档从小到大处理，每档可以容纳同样多的请求，因为此前所有档所占的质量只需计算一个二进几何和。

**能支付的原量。** 给实际接收点或新来源点各自列出最常使用的一批终端。命中相应清单的记录可以按全体中心、全部档合计支付。对其余终端，若两终端共用正质量的来源，或到达同一个真实小父所有者，就在同档连边。总权没有超过整组来源或接收预算的连通分量，也可整个支付。写 \(S=\|f\|_1/\lambda\)、\(V\) 为原接收体积、\(\ell=\log(n+2)\)，计入所有停止代和已有的吸收项后得到

\[
 R_{795}=P_{\rm paid}+R_{796},\qquad
 |P_{\rm paid}|\le \tfrac1{32}|R_{795}|+
 C\big(\sqrt n\,\ell^3V+n\ell^7 S\big).
\]

原峰总账中的余项系数由 \(k_0\) 变为 \(32k_0/31\)，其余费用仍在原对数幂以内。尚未支付的是同一体积档内总权很大、同时反复使用来源与接收体积的连通分量。把数量超过配额的接收请求拆成多批后，真实来源可能被不同批次重复使用。

**本机验证。** 使用独立 Python 3.12.14、有理算术与 256 位 Arb。三套证书分别核验共同源耦合、关联迭代删除和选中较远旧价后的实际接收分配。共享同一小父接收点的两个一维真实终端，对应的条件权为 \(10844/22757\) 和 \(11913/22757\)。先占用另一终端的整个区间，两种次序留下的条件新来源概率分别为 \(4/2711\) 和 \(2688/3971\)。这些分数针对归档中的连续一维输入。三套脚本的复现命令、模型范围及误差类型均列在包内。
