# 第281轮：单切割对数价格与潜在软矩形的根阶来源预算

一般 n^(1/2+o(1)) 一致弱型上界尚未闭合。本轮在第280轮原始中间时钟余项上得到两项经独审的新正分配预算，未宣称覆盖固定比例或全部余项。

## 假设与结论

保留任意正L1原来源ρ≤β≤α≤f dx、独立ν≤f dx，不能假设ν≤β。保真实接收dx、原FIRST/hardcap、唯一j、完整原后验及全部历史门。采用原near条件、d=a/(8√n)随机共同胞，同胞概率P_d≥1/2；R279已付门外后，当前ns+R2≤D，固定外参数下D=C₀+C₁log(n+2)，常数可能极大。

1. 单切割：两帽积分I(A,B)=min(A,B)[2+log(max/min)]满足I(A,κB)≤(1+logκ)A+B。用已证κ=2+n log(1+1/(8√n))胞内极大弱界，单切割正交通价格为16Λ√(nD)(2+logκ)[(16/3)Wρ+Wν]。逆向单切割必须保输入core条件；不能延伸到全部soft off-core。
2. 潜在软矩形：将真实φ写成区间核概率混合，其尺度律二阶矩13。以M=min(n,⌊D⌋+1)个固定软度节点和ζ=1+1/(D+1)的半径离散化获得固定正包络。每个矩形径向profile的弱常数为1；可数混合的熵费用完整保留。令H*=(D+2)[log(en)+log(2D+3)+15]，L=e²M[3+2log2+2logM+2H*]，则潜在矩形包含整个来源胞的分配价格为16Λ√(nD)[(16/3)L(1+logκ)Wρ+Wν]。这允许硬窗口切胞及部分真实软尾。只有实际分配总和有FIRST，不能给单个潜在分量FIRST。

同一原始不交终端叶账目Wρ,Wν≤||f||₁下，上述新价格均不超过C√n log^(9/2)(n+2)||f||₁。详细定义、全部常数和解析证明见proof_cut.tex.txt、proof_soft.tex.txt。

## 精确整合与缺口

先按第280轮划分原top/middle。middle上A0为旧完整胞内部，Ab=1−A0，Asc为本轮单切割，Alat为潜在矩形分配。精确非负恒等式为

1=A0+Asc+(Ab−Asc)Alat+(Ab−Asc)(1−Alat)。

因此不重复支付重叠部分。剩余P_rem是原middle完整正积分乘最后权重，仍保来源、真实dx、完整后验及所有未花费门。潜在矩形亦被来源胞切割的交通尚无一般根阶预算；这是下一轮目标，不是已经闭合的误差。完整回代见integration.md及其最终独审PASS。

另探索固定近来源的时钟熵恒等式；虽可推出初始度熵势上界，该势及其余时钟未能按原来源结算，故不列为新付款成果，不把路线改名当进展。
