# 第444轮：双终端距离加权匹配与实际二次捕获对偶

证明同一完整远终端流的距离加权费用≤S eps0² Φ(A_n²)X/s²，其中Φ(v)=v(v≤2)、2[1+log(v/2)](v≥2)。使用真实双来源匹配与总容量饱和，保全部原门；费用O(S eps0² log(n+2)/n)X。不能将带权结果当作未加权原余项付款。
