# 第757轮　按中间父方体的真实来源质量连续下降

第756轮留下的同一份四标签流量记为 \(Z\)。本轮证明，如果在任一反证输入上 \(Z\) 大到抵消前轮的吸收，那么必有可量化的流量连续三次通过原筛选，并且每一步都进入体积严格更小的接收父方体。

令 \(\pi_j=v_j=|E_j|\)。把两枚接收标签的位置交换后各取一半，记其实际双边际为 \(\pi_j C_{jt}\)，再令 \(D_{jt}=C_{jt}\mathbf1_{\{d_t<d_j\}}\)。从 \(j\) 转到 \(t\) 时按 \(\mu|_{A_j}/m_j\) 抽取来源点，保留该步的原两来源、两接收、两种尺度次序和全部筛选。下一步重新使用 \(\mu|_{A_t}/m_t\)。对任意固定父标签着色，先在未筛顺序块内估计两接收异色的概率，再用真实后继质量选择三种颜色。归档证明式（3）给出全部着色和终止费用。

对每个父 \(j\) 定义 \(T_j\) 为单位化后各坐标超出方体距离之和至多 \((\log L)^2/(4n)\) 的区域。它有体积至多 \(Ld_j\)。在三步链的每个到达父 \(t\) 上按真实 \(E_t\) 的均匀测度取一点。至少有一步落入前父 \(T_j\) 的流量至多 \(3KLS\)。设 \(Q_3^{\rm out}\) 是三次均在相应区域外的真实链质量，便有

\[
 \frac{277}{3072}T_0+\frac{\mathcal D}{3}
 \ \le\ 2\cdot256^3\,Q_3^{\rm out}+C L S .
\]

这里 \(S=\|f\|_1/\lambda\)，\(L=\sqrt n\log^A(n+2)\)，\(T_0\) 为第752轮共同入口，\(\mathcal D\) 为第755轮已入账的尺度分布差。\(A=0\) 也适用。**仍缺的是 \(Q_3^{\rm out}\) 的根阶来源上界。** 式中常数均与维数和父方体个数无关。若补上这个估计，前轮的全尺度有限覆盖即给一般结论。

有限入射模型用有理数核验。四接收链中唯一三步使用三个不同的来源点，\(Q_3=3267/174545516800\)。终点星的 \(Q_2=0\)，七接收链的 \(Q_6>0\)、\(Q_7=0\)。两种大小次序均穷举至四色。小模型检验了条件分母、重抽和着色的程序，不承担一般几何估计。
