# 第733轮　用互补的大来源支付整行需求

已核对[第706轮指令](../../AGENTS.md)。固定较小来源，两个较大来源按各自半径档压缩，在同一个真实接收点逐坐标选取能命中小方体放大区域的那一个。两者共同漏掉至多 ⌊n/64⌋ 个坐标时，这些配对组合的总费用至多为 M/n 加指数衰减的来源费用。证明直接对两个真实所有者在乘积空间积分，保留全部尺度档。两个端点均未命中时，该坐标计为漏掉。

还得到整行估计。若一批有足够权重的较大来源在每个坐标上都有至少 1/2+δ 的权重能命中，则这一行归在该小来源下的全部原配对需求都可支付。每个坐标可由不同来源命中。两个来源池之间的遗漏比例乘积也给出可直接计算的判据。许多来源反复漏掉同一批坐标的情形仍缺一般根阶预算。

本机与 MacBook 以不同的有理多项式积分方法核对五个矩。本机还核验九个真实贪心历史，包括单个来源各漏掉半数以上或半数坐标、两个来源合用覆盖全部坐标的情形。这些历史有远来源可支付。[完整证明与复现材料](research.zip)
