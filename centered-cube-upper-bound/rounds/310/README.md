# 第310轮：总外深度与极小softness来源付款

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。

本轮保留原真实接收测度、完整未捕获端、来源和全部门，证明低次数捕获端的总外深度尾可按 (16/3) A_n C_(n,K) exp(−D/2) W_beta 支付；另用实际二项权总质量支付极小softness且原高度合格的分支。两项严格按不重叠顺序结算，形成一个条件性的完整低高度分支付款。源费用、次数、尺度、原外乘数均保留，新增全局epsilon X为零。

**重要限制：** 沿用第309轮原K的12组参数联动中，对所检验的省带两高度版本，11组纯有理证书门为空；唯一未排除的一组，其原有来源主项已超根阶。不将该组合门当成一般上界改善证据，该判定不自动推广到较大的解析门tau*，也不把粗高度证书门为空推成实际加强高度门为空。下一步应支付浅深度较大高度和低捕获高次数核心，而不是继续优化该门常数。

辅助稿给真实来源沿单调立方体链的跨界/重叠预算；原全部交通到这些链的联合拥挤界仍未证明，不纳入主回代。原入口、极端尺度比、宽距离、初始、真正删除跳跃和未来被删来源继续独立未付。
