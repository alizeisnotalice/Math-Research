# 第192轮：来源对自适应祖先定位与持续捕获质量

一般n^(1/2+o(1))一致弱型上界尚未闭合。本轮独审通过两条实际接收预算：原共同随机网格上按固定来源对距离选层，可去掉大LCA失真交通，补集sidePu≤2A||y−u||1；原捕获余量若有足够质量且比完整target衰减更慢，则通过真实e_t分母支付整行ε费用。允许各bad来源选择不同中性测度，但沿t固定、不依运行target。

两机制按本轮总ε各分一半，并按不交顺序使用；没有重复接收预算或树层菜单。捕获侧使用原LCA/出生B上的可计算弱容量条件，排序失败、低K0和reserve费用全部保留。它们尚未证明覆盖一般中间硬层。辅助tiny-target score和真实Δ端点界通过，但未单独取得全局价格。

本机实际核验：9个Fraction网格例枚举272024个open相位单元及同数边界相位；15条重叠曲线共30次高精度求积，12个有理捕获容量例，12个真实C核score配置的双精度核验。最终归档driver核验15个文件哈希、完整重跑两脚本，两个JSON逐字节一致。有限模型和非区间数值不认证FULL或一般阶数。
