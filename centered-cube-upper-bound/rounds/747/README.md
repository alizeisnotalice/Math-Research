# 第747轮　所有尺度上集中来源的接收体积

对任意有限中心方体族，我们证明了一个跨尺度上界。设 \(A_j=Q(y_j,s_j)\)，\(d_j=(2s_j)^n\)，\(E_j\) 为原来的互不相交接收集，\(\mu\) 是该族的一份最优对偶测度，总质量为 \(P_0\)，且 \(\mu(A_j)\ge d_j\)。若来源点 \(z\in A_j\) 满足
\[
  \mu\big(Q(z,s_j/n)\big)\ge e^{-\sqrt n}\,d_j ,
\]
便计入它在该行实际占有的来源份额。所有这些份额对应的真实接收体积之和至多为 \(C\sqrt n\,P_0\)，没有接收体积吸收项。方体数、尺度数与最小绝对半径均可任意。

**为什么同一来源可以结算一次。** 按尺度递减选择互不相交的集中来源盒。一个价格点可以落在多个选中盒的二倍扩张中，把它统一分给其中最大的盒。每个选中盒用自身的来源质量控制它能负责的最大接收半径，用实际分给它的质量控制每行的来源份额。两笔质量在全空间合计至多 \(2P_0\)。在这两个约束下对体积尺度积分，阈值 \(e^{-L}\) 的费用为 \(C(1+L)P_0\)（\(0\le L\le n\)）。证明还允许把 \(Q(z,s_j/n)\) 换为一个全族共用、逐轴半宽之和不超过 \(s_j\) 的矩形。

**对原算子的结论。** 给定任意 \(f\in L^1\) 和阈值 \(\lambda>0\)，取 \(\mu=|f|\,dx/\lambda\)。若某个越阈方体中至少比例 \(\gamma>0\) 的来源质量满足上述集中条件，那么所有此类方体的中心所成集合的勒贝格外测度至多为 \(C\sqrt n\,\|f\|_1/(\gamma\lambda)\)。不同中心可各取不同的半径。

**全部费用和缺口。** 第746轮已证明，第706、739轮所用的原贪心值 \(D\) 可低至 \(O(V/n)\)。本轮经第693轮的原始最优装填值 \(P_0\) 回代。把集中部分与小来源、大来源、窄体积窗及对偶分母大的行在同一接收积分上依次扣除，得到
\[
     V\le \eta V+C_\eta\sqrt n\,P_0+\Pi(\mathcal U).
\]
\(\mathcal U\) 同时要求来源质量分散、来源半径与接收半径处在中间比例段、两方体体积对数差超过 \(\sqrt n\)，并且对偶分母小于 \(\sqrt n\log(n+2)d_j\)。证明包给出每个阈值以及乘回第739轮原密度 \(H\) 的公式。对 \(\Pi(\mathcal U)\) 的一般上界仍然缺失。

**本机核验。** 在两项非退化有理算例中，逐胞元核验装填与对偶价格同时最优，得到 \(P_0=16,4\)，对应的合格接收体积为 \(263/57344,179/704\)。在深度32的重合测试中，把各二倍盒分别计费会达到统一预算的8.45倍。另用16、64、256维的显式构造核验阈值选择，其中256维枚举65,536个分离的来源中心。三组在 \(e^{-\sqrt n}\) 阈值下都支付整行，在 \(n^{-1/2}\) 阈值下都支付零。Python 有理运算核验几何与分数，256位 Arb 核查七个维数的标量系数，最大维数 \(2^{60}\) 仅代入公式。解包后运行本机独立 Python 的 `-B verify.py --check verify.json` 可复核记录。
