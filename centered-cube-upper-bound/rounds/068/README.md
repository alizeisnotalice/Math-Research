# 第68轮：二叉矩形替换与共同来源缺失预算

2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**；保留全一般 O(n log n) 基准。

- 对任意正来源构造逐坐标二分的矩形重分配，长宽比不超过2，选中块密度跨度不超过2。原始好集上的完整有符号误差能量至多2(1+e)HW，不依赖原子数与深度。
- 一般有限原子的目标能量可常数损失归约为等高度嵌套并集测试，层析损失由1+n log2降至1+log2。绝对目标高度仍为指数级；所需次幂测试界及最终弱型回代仍未证明。
- 直接弱型路线建立共同来源包的完整费用公式：来源质量乘数、响应阈值损失与未覆盖带体积均显式保留。有限来源树的二次恒等式不能替代空间预算。
- 真实方体反例排除单一硬分割和少量坐标序树的某些逐点覆盖要求；它们不否定允许例外体积的总体估计。

93组、167424次全空间接收点采样完成，独立复跑JSON逐字节一致；三个补充精确守卫通过。数值显示部分共同树遗漏明显的剩余体积，并重复使用来源质量。有限检验不证明一般界；所有误差和范围见归档。
