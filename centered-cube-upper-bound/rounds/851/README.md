# 第851轮　实际来源跨档分配和同源重启

本轮在原双端积分 \(I=\lambda^{-1}\int_E[\eta(A_x)/|A_x|]^2\,dx\) 上工作。这里 \(\eta\) 是真实来源割，\(A_x\) 是接收中心 \(x\) 的原尺度见证。第850轮给出的局部质量门槛允许重新估计实际来源子割。本轮把子割的收费重新汇总到同一批原记录，并给出一种从实际终端继续使用同一来源的精确配对。[详细 LaTeX、六份本机程序及实际输出](research.zip)

## 跨档共同见证

一枚来源在各体积档中只参与确实包含它的见证竞争。给每个档一个共用的随机优先数，它在该来源已经遇到的档中最小时，才把来源分给本档第一位覆盖者。若某来源实际遇到 \(s\) 个档，总收费的期望次数恰为 \(H_s=\sum_{j=1}^s1/j\)。根的两端进入同一块的概率使用双方活跃档的**并集**和真实共同见证的强度。由此，多档合计的来源费用为 \(O(\sqrt n\log^5(n+2)\|\eta\|)\)。该估计给出明确的原质量权重，尚未覆盖所有原件。

另一种分配在同一随机格胞内按投影顺序切割真实质量。一个外部来源只有与原两端同时处于该胞、且其投影夹在两端之间时才竞争预算。三点同胞概率是各坐标真实跨度因子的乘积。这使一些局部总质量极大的记录也能收费。

## 切片平均与重启

对于任意 \(L^1\) 输入和原自适应尺度，选定 \(m\) 个坐标，在原方体上沿这 \(m\) 轴平均，同时保留该来源的其余坐标。用 \(\sqrt n\,\lambda/(m+1)\) 剪裁这个真实切片平均，再按原尺度对其余坐标平均。所得接收量的平方积分除以 \(\lambda\) 后为 \(O(\sqrt n\|\eta\|)\)，常数独立于所选坐标。它能以一份显式吸收系数作用于完整双端积分。证明用到其余坐标上的无维数强 \(L^2\) 界。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

设 \(\mu\) 为原带标签记录，\(P\) 为成功时严格降档、交接实际来源的核，\(\Delta=(1-P1)\mu\) 为终杀量。终杀件的保留来源边际，与缺入量 \(\mu-\mu P\) 在相反标签上的私有来源边际相等。因而可以从终杀件沿同一真实来源重启。逐档配对后，每个周期的平均件数恰为 \(|\mu|/|\Delta|\)，每道阈值的重启上穿量恰等于原成功转移的下穿量。

## 本机验证与决定证明的缺口

三档正宽样本中，使用全部真实早档的覆盖率为 \(83/108\)，最佳单档为 \(2/3\)。六档样本有一组根覆盖率达到 \(1\)，其累计计费为 \(569/462\)。因此多次支付同一份记录必须单列。64维的两种缩小秩窗及256维扩展上，逐来源、逐阈值核验了共780个通量等式，正向占用和终杀测度均逐状态复原。

增加均匀坐标可保留任意原输入在内区的 \(I/\|\eta\|\)，同时使仅靠局部低质量分块所捕获的比例指数下降。该断言没有假定这些输入能通过全部高载历史条件。它把剩余问题集中到**高切片质量、跨许多档、并反复使用相同来源的真实历史**。若能把重启上跳的平均档差控制到 \(O(\sqrt n\,\mathrm{polylog}(n))\)，便可用一次终端费用控制这些历史。现有逐阈值界合计仍过大，一般全尺度上界仍待证明。
