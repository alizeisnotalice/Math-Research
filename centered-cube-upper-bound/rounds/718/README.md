# 第718轮　全坐标折叠后的共同见证与一次来源预算

开题重读[第706轮指令](../../AGENTS.md)。按接收父方体体积分档，为每档所有实际接收点共用一份真实半阈站点排序。各坐标同时作分段平移后，若两个点落在同一位置，它们必定选中了同一个站点。因此，来自不同站点的接收点不会造成档内重叠。辅助站点可在原父方体外，证明直接支付真实坏接收体积。

重数至多 n² 的部分以及超远来源占足够质量的部分已计入根阶预算。其余需求按真实站点汇总。多份排序可以分摊原始接收测度，平均需求后，所有站点和尺度共同使用一次来源容量。由此得到对整个坏接收体积的上界，等于根阶来源费用加一个有限分配问题的缺额。一般输入上，多个高重站点共用来源时的缺额仍未控制。

本机和 MacBook 核验了九组全坐标折叠、810 项几何点对碰撞概率以及真实双中心历史中的高重数。真实算例中，同站点重数可远超 n²，需保留来源支付。[详细 LaTeX、双机脚本和数值记录](research.zip)
