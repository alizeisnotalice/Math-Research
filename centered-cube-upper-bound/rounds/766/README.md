# 第766轮　同点大父的交质量与共用来源容量

遵照攻坚指南式（4），本轮固定一个小父、方向与真实来源点 \(\theta=(k,z,\mathrm{dir})\)，保留全部可达大父及其原概率 \(\pi_\theta\)。按原概率独立抽出 \(t,u\)。取 \(S=\|f\|_1/\lambda\)、\(L=\sqrt n\log^3(n+2)\)、\(r=\lceil\sqrt n\log^2(n+2)\rceil\)。

**两个大父在何时可以整笔付款。** 在完整原测度上，只要以下任一条件成立，该部分流量在两方向和所有尺度上合计至多 \(C L S\)。
\[
 \frac{\mu(A_t\cap A_u)}{\mu(A_t)}\ge e^{-r s_k/(128s_u)}
 \qquad\text{或}\qquad
 \frac{\mu(A_t\cap A_u)}{\mu(A_u)}\ge e^{-r s_k/(128s_t)} .
\]
证明先用共同见证修补少数越界坐标，再按真实接收者的双盒交体积估计长位移。门槛中的两份质量均取自原输入。这个结论适用于一般 \(m_i\ge |A_i|\)，两个大父各自使用自己的分母。见详细证明式（1）至（6）。

**同时分配同一价点上的全部大父。** 付出 \(O(LS)\) 后，对根 \(\theta\) 的每个保留大父 \(t\)，可以从它实际包含的来源中分得至少
\[
 \eta_n^{-1}\,\pi_\theta(t)e^{r s_k/(128s_t)}\mu(A_t),
 \qquad \eta_n=e^{-\delta r/128},\qquad \delta=\sqrt{\log n/n}/64
\]
的质量。分配对全部 \(t\) 同时成立，对每个真实位置 \(x\) 的总份额至多为一。因此任一保留子族的份额之和受它们并集的真实来源质量控制。式（7）给出显式分配。这一步在充分大维数成立，有限个小维数并入原预算。

**剩余缺口。** 第765轮中已扣的接收费用及吸收系数可原样回代。取 \(\varepsilon=1/64\) 后，仍有 \((1983/2048)T_0\le R_{766}+C LS\)。同一位置 \(x\) 在不同小父和原价点的分配中还可能反复出现。式（9）保留了这些重复、各自的真实分母和尺度增益。一般上界所需的固定比例收缩仍未取得。
