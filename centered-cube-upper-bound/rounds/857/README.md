# 第857轮　固定完整左史后两条真实右臂的几何估计

固定第813轮的一条中央历史和一条完整左臂，保留左来源及其真实勒贝格接收位置。按原条件分布独立抽两条右臂，两份「原左臂与一条右臂」的边际各自精确恢复原流。以下估计同时涵盖全部物理窗和体积档。[完整 LaTeX、四项本机计算及复算器](research.zip)

**即使允许事后删去坐标，两枚右价通常仍相距很远。** 记 \(O=[R,2R)\)、\(J=\sqrt n\log^8(n+2)\)。读完中央历史、原左臂和第一条右臂后，可预测至多 \(\exp(c_1J)\) 个位置。读完第二条右臂后，还允许任删至多 \(\lfloor J/(32\log(n+2))\rfloor\) 个坐标。对一切这样的可测选择，第二右价与某个预测位置在其余坐标上的 \(\ell^1\) 距离小于或等于 \(RJ^2/(1024n)\) 的总质量至多为 \(C\mathcal H e^{-c_2J}Y\)。这里 \(Y\le C V\)，\(\mathcal H\) 是第813轮的原费用。证明以不交小父接收集的实际体积付款，对输入来源没有逐坐标独立假设。

**两条右臂的来源和接收者可以一起分配。** 删去至多 \(Ce^{-cJ^2/n}V\) 的重抽质量后，在每个中父体积档 \([D,2D)\)，完整右右端的联合测度至多为
\[
 e^{-cJ^2/n}D^{-1}\,\lambda_O\otimes\lambda_O .
\]
\(\lambda_O\) 保留原小父的实际质量分母、来源和接收者。同一个跨窗、跨档的运输方案可以据此截取原流，各端分别服从该来源及该真实接收者的全局容量。证明还给出固定同一右源时不同体积档实际中父共同来源的平方和估计。

**仍缺的全局费用。** 把所有右价通过同一真实来源 \(w\) 的费用合并，记 \(A_{Oj}(w)=D_j^{-1}\int\mathbf1_{G_t}(w)\,d\Gamma_{Oj}\)。每个 \(K\ge1\) 有
\[
 |\Gamma|\le C K(n+2)\log(n+2)S+
 2\sum_{O,j}\int(A_{Oj}-K)_+\,d\mu .
\]
取固定对数幂的 \(K\)，首项已在预算内。尚须把第二项控制在 \(O(\sqrt n\log^\alpha(n+2)V)\)，或证明整体命中比例和迭代终端。一般全尺度弱型上界仍未闭合。

**本机核验。** 由第814轮四维归档的64条完整左史重建14,896个正重抽项，两份边际逐件回到920条原记录。要求两右价胞不同的同一个公共匹配付原量的6.70%，允许按左史分别选择则为9.05%。此样本最大实际体积比为 \(2401/625\)。另以正宽中父几何复核至1024维，以224组精确有理切片核对盒加球体积，用192位 Arb 对九个指定大维参数的解析上包作区间检验。四份输出均可用包内复算器重放，输入为项目的 rounds 目录、本轮 ZIP 和一个已有的临时目录。
