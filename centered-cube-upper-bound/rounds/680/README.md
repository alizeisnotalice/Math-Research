## 独审结论

保持R679完整覆盖、真实owner、同一接收集合、全部原packing变量和far/upper总账。完整center-admission来源对可合法删除较早来源；首次组、halo和接收mask的变化由单调扩大保留。正确不等式为D_A,k≤(k−1)D_out,k−1。

归一化到r!D_r/T_*^r后系数是 **k(k−1)/T_***，当前hard参数下至少127/3，渐近约(8/3)√n。不能遗漏外面的k，也不能把此比较称为已付CU或统一收缩。互补项、终端费用和标记重数仍须支付。

未通过完整接纳的来源对使较小owner位于另一来源之外，也使横向交集边变窄；但该坐标可能已被其他来源压窄，不能重复领取收缩。真实Fi×Fj×Y积分不能免费把接收点换成owner。当前same-core来源半径比<n/2，故另设s_i≥n s_j的far支路为空。

## 实际验证与范围纠正

本机Python3.12.14/Fraction：旧输入100条记录、3335分块中有1045个all-outside cells，640 admitted-only、405无distinct碰撞；840次来源对全部通过完整接纳，mixed/nonadmitted-only为零。全部记录与R679费用精确一致。这仅说明旧样例未覆盖另一类来源对。

另一个三方体低τ构造经过全部正cell枚举，得到q=(w,w,0)、唯一loss、真实小盒不交、原admission均为零。来源对同向却在另一坐标失败；k=2至6的混合来源费用份额为1/2、3/4、7/8、15/16、31/32。

**该构造按实际分类是far=0、upper=2w，全部upper-paid。** 它不证明hard残余分支非空，也不反证一般目标；仅说明raw admission和共同见证本身不能强制完整pair gate。独审指出的这一范围限制已写入最终主稿。
