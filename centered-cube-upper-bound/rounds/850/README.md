# 第850轮　两次真实换端后的联合密度与未付根的来源质量

在第849轮的同一原积分中，记 \(\eta\) 为真实来源割，\(\lambda\) 为阈值，\(P\) 为保留实际来源、取得第一件合格旧记录、再翻换端点的原转移。每步至少降 \(b+1\) 个二进制体积档。令 \(b=\lceil\sqrt n\rceil\)、\(T=\lfloor n/(b+1)\rfloor\)、\(J=\lceil\log^2(n+2)\rceil\)，\(d\) 是原秩窗宽度，\(\Delta\) 是实际终杀测度。在单位边长窗 \([1,2]\)，每枚仍未付的原根必须满足

\[
\eta\big(B_\infty(x,2T+1)\big)>
\frac{\lambda d^2}{8\sqrt{2048}}\,2^{bJ}.
\]

这里 \(x\) 是该根的实际接收中心。球中可以有任意多互相分离的来源。对边长窗 \([L,2L]\)，球半径乘 \(L\)，质量门槛乘 \(L^n\)。[完整 LaTeX、四份本机程序和实际输出](research.zip)

## 两条真实长历史占用的接收者和来源

在根上固定角色，记 \(\mu\) 为原带标签记录测度。一次转移保留一枚真实来源，其条件律可以奇异。两次转移必须由同一个中间接收者连接终端私端和原根保留端。对这个真实接收位置积分一次，得到正反向共同密度

\[
\frac{dP^r(e,\cdot)}{d\mu}(t)
\le \frac{8\,2^{-b(r-1)}}{\lambda d^2\,2^{k(t)}},
\qquad 2\le r\le T.
\]

令 \(\theta(dt)=\Delta(dt)/(\lambda2^{k(t)})\)。从同一无标签根的两个相反角色分别启动条件独立的真实历史，联合筛选后仍留着原来的接收位置、来源和历史。对几乎处处的未付根，同时满足历轮条件且深度均大于 \(J\) 的终端对，必须占用超过 \(d^4 2^{2bJ}/2048\) 的 \(\theta\otimes\theta\) 容量。每个终端选定一枚来源，其第 \(j\) 档的 \(\theta\) 边际至多为 \(4\,2^{-j}\eta/\lambda\)。这就把联合终端容量换回上面的实际来源质量门槛。两臂各保留两枚来源时，逐轴交盒的帐篷因子也能保留在同一估计中。

## 多档合计

- 在终端方体外，可按实际来源质量预选任意可测集合。集合总质量不超过 \(\lambda v_t2^{b\log^2(n+2)}\) 时，所有根和所有深度共用 \(O(\log^2(n+2)|\Delta|)+O(n2^{-b}\|\eta\|)\) 的费用。
- 将来源和终端按各自真实比较边际交替分组，允许同一对来源与终端逐步择方向、逐层选择。对预定的嵌套分区，\(b\) 次操作后归一密度超过 \(2^{-b}\) 的原质量为 \(O(|\Delta|)\)。估计还包括从真实终端的一枚原子来源开始的分配。
- 方体的逐轴帐篷核支付了根、终端两源位移落在同一周期相位的全部外部副本。按接收体积分组则支付了两臂在除显式数目坐标外接近的联合历史。对净位移大的连续段，可以在同一真实联合来源分子中提高可付门槛；该比较用到方体的无维数强 \(L^{3/2}\) 估计。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

## 实际复算与缺口

64维59档与256维扩展模型使用正宽来源包和接收核心。两种秩窗下，选定二步密度的归一值分别为 \(4/147\)、\(7/48\)。来源分组在两组64维样本中各抬高54个有正原质量的格。逐一检查全部244格后，增加终端分组只抬高了零原质量格。样本采用缩小秩参数与专门的几何测试门。另以192位 Arb 在最高65536维检验了接收体积公式。

**一般上界仍未闭合。** 单窗中，已付部分合计仍为 \(O(\sqrt n\log^4(n+2)\|\eta\|)\)。剩下的是局部来源质量超过上述门槛、两臂接收者分散且各长段均保持高联合来源质量的原根。还缺对许多这样的根复用同一批高质量来源时的总量估计。第813轮完整双臂及第739轮全尺度账目的吸收条件仍需满足。
