# 第719轮　共同来源的坐标分离与整分量预算

按[第706轮指令](../../AGENTS.md)对同一有限历史的全部坏接收体积计费。每个来源按当前连通分量的真实体积至多退役一次。对剩余分量，从原来源覆盖两个站点的坐标交集推得可积分的核。若能在分量内选到一组由真实来源支撑、能量足够小的测试点，整个分量都能支付，费用与递推深度和尺度数无关。一般分量是否都有这样的测试点，或能以其他方式支付，仍待证明。

本机与 MacBook 交叉检查了三组精确退役账目、九个真实单站点块和角点核。高维检验至 \(2^{64}\) 的对象是一个标量组合和；完整角点行列枚举做到八维。证明、参数和计算记录见[研究包](research.zip)。
