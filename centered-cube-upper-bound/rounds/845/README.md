# 第845轮　同一真实右来源跨尺度接收的伙伴位移

固定原阈值、来源割 \(\eta\) 和每个接收者的原严格见证。记 \(S=\|\eta\|\)，把两份实际来源在同一方体内的平方积分除以 \(\lambda\) 得到原双臂质量 \(\tau\)。本轮直接估计这份质量。[完整 LaTeX、三份程序及实际输出](research.zip)

## 共享右端的累计质量

给定真实右来源 \(z\) 和见证的二进体积档，可以预列 \(J_0\) 个模一位移。对左来源 \(a\)，用**原边长** \(l_x\) 计算 \((a-z)/l_x\)，逐坐标模一。落在名单半径 \(\delta\) 内的原记录，在所有右来源、接收者和尺度档合计，费用至多为

\[
 C\bigl[1+\log(n+2)+\log J_0+n\delta\bigr]S .
\]

每个模一位移可以代表指数多个物理位移。更一般地，每项预测可取一个点集，只要其各点两两相距至少该档边长。证明用左端邻域的真实来源质量限制可用尺度，再在固定右端把交盒体积求和。两头共同使用一份来源预算。取 \(\delta=1/\sqrt n\) 和 \(J_0\le e^{\sqrt n}\)，得到根阶费用。取 \(\delta=1/n\) 和固定名单，只付对数阶。

从第843轮终端按同一真实右来源和体积档独立重抽伙伴。若它以至少 \(e^{-u}\) 的概率命中原位移的 \(\delta\) 邻域，则这批**原记录**至多花费 \(C[1+\log(n+2)+u+n\delta]S\)。两端可同时应用。第844轮的扩展保持首槽边际，故这笔费用适用于其高信息原量，新增吸收为零。

## 跨尺度来源载荷

令 \(r_\tau(a)\) 为一枚来源在原窗全部接收者上的单位质量载荷。在格距 \(1/m\)、每轴含至少 \(4n(m+1)\) 个节点的任意平移格块上，取 \(m\ge\sqrt n\)，格点处的 \(r_\tau\) 平均值有绝对常数上界。因此载荷至少 \(T\) 的点，在每一格块中的比例至多为 \(C/T\)。若原来源中确能提取这类格块的正混合分量 \(\nu\)，所有碰到 \(\nu\) 的双臂记录，包括与任意其余来源的交叉项，一次支付 \(C\|\nu\|\)。

## 本机核验

- 在第844轮原有的四个正宽接收核心上，固定同一实际右来源。较大体积档中，两次归一位移在半径 \(5/64\) 内的实际命中率从物理空间的 \(9/25\) 升为模一的 \(1\)。较小档两者同为 \(33/50\)。
- 另一组四个不交接收核心的定向原质量为 \(865219/25668341888\)。有理算术逐项核验16个共享右端的双接收边际，并在维数16、128、1024、4096核验指数多个方向的帐篷核总和。高维样本在全来源中所占份额很小。
- 正宽周期来源给出一个严格的尺度判别。原平方积分为 \(O(\lambda S)\)，若把见证所属尺度块放宽到整个窗口，全档平方差可达 \(\Omega(\sqrt n\,\lambda S)\)。本机另取64、256、1024维的4096、8192、8192个格相作浮点检验。全窗平均费用依次为1.742、3.482、6.831，见证所在约 \(\sqrt n\) 步的费用依次为0.364、0.377、0.373。一般维数的判别由证明给出。
