# 第365轮：共同来源矩与共同半径费用核验

本轮无新增根阶付款。核验真实来源posterior的三接收共同捕获矩，以及共同半径扩张的shell增量、归一化负信用、原clock损失三项精确账。明确普通Lebesgue L2与所需f加权矩的差别；现有可积共同半径证书仍花费X_q，未达到εX_q。

完整继承第364轮费用及所有未付槽。F_core、B_near及一般软层、尺度、时间原子和入口接口仍未闭合，不把恒等式、必要条件或候选证书计作新上界。

本机实际运行6487项Fraction来源矩/分位数检查及648项半径差恒等式检查。有限模型来源积分精确、接收仅quadrature，未实现原困难门，不外推维数阶。独审及复现材料、详细LaTeX源在research.zip；不编译PDF。只新增本轮README与ZIP并更新项目总览。
