# 第740轮　有真实距离约束的全维接收转移

对每个来源直接在第706轮的真实高损失接收集合上构造对称转移。每步至少在一个指定补集坐标上跨过来源边长，且相对于全部坐标的勒贝格测度，转移密度至多为 \(\sqrt n/d_i\)。未能纳入转移的总贡献由 \(O(\sqrt n)D\) 支付。证明使用有容量上限的对称分配，以及对未匹配点各坐标尾部的体积估计。

这使多个目标接收区域可以按实际并集体积合并计费。剩余运动从任意有效出发点跳到指定接收标签的条件概率至多为 \(2\sqrt n(32n)^{-n}/\delta\)，其中 \(\delta=1/64\)。一般输入容许任意多标签，剩余运动的总质量仍待估计。
