## 严格结果与缺口

对任意有限正原子共同来源μ=Σpiδyi、质量W和真实接收端G_H={Mμ≤H}，在体积时间u=nlogL上精确计算平滑差分D=B′的带符号Gram核。对角为c/v²，远体积尺度的交叉项为负，c=1−e^(−1)。证明全尺度cap能量≤2cHW(1+S)，S=Σ(pi/W)log(W/pi)。带内能量进一步≤λΣpi log_+(cWH/(λpi))。H=Kλ时只付logK，但来源熵S不受维数控制，不能用此结论通过任意原子化回代。

确定性Stieltjes分部积分给出带内能量的精确来源到达差公式。单个来源到达差可负，并有实际正双原子的一维解析实例。以源为中心的exp(1/n)膨胀，把两时刻差准确改写为同一时刻、不同接收中心之差；真实cap集合变化的门控边界必须保留。平移项和门控项的统一预算均未证明。

另证明固定一维有界密度的正Gram部分对小尺度截断呈对数发散，而实际平方能量有限。因此完全删除负交叉项的路线不能得到来源无关预算；这不否定目标弱型界或带符号cap能量猜想。
