# 第337轮：对称差联合付款与高质量过去补集

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮保持完整总账，推进原 B_H 的真实接收几何。

在详细报告的 hard-matched 合同内，先以 ν≤f 正支配，再精确保留实际交叠 I_uv，得到 B_H(f,f)=B_near+2B_fav+G_K。对前两项联合停止，低时钟只结算一次。新证明全局严格质量过去 Z_y(m_u/K-)≤h 的分支费用不超过 λ[h+(1+logK)/q_-]||f||1，保留整颗质量原子，不假设来源密度帽。

联合结论为：

`B_H(f,ν) ≤ G_(K,>h) + εXq + {λ(1+2logK+2/K)/(q_-ε) + λh + λ(1+logK)/q_-}||f||1`。

选 K=exp(√n)、h=√n/q_-，已付部分是 O_ε(√n) 来源费用。高过去补集 G_(K,>h) 仍未支付；原 H 入口、软层、极端尺度比及初始/删除/未来被删来源时间原子均留账。不能称只剩常数和对数优化。另给 q 波动的可付误差和未付纯半径差，属替代账，不重复计费。

主代理实际本机复跑：core 79 项、aux 2448 项、numeric 14902 项精确检查，另 30 项普通 Decimal 诊断。数值包括三阶段30次有限接收评估及3个真实dx积分；有限证据不充当一般证明。独立审查先筛查命题再读稿。全部吸收系数及剩余缺口见 ledger。
