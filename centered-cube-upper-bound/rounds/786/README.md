# 第786轮　共同真实源点上的跨中父分配与同体积档费用

沿用第772轮的同一最大欠额割和原始峰权。对一条从较小父进入较大父的真实边，先把所有相容较大父的接收体积按共同来源交加权求和。这个和低于门槛的较小父，其全部出边已合计支付。再按已知的真实交价点的位置和中父的物理体积档分组。写 \(D\) 为该档体积下端，\(L=\sqrt n\log^3(n+2)\)，\(r=\lceil\sqrt n\log^2(n+2)\rceil\)。支付完成后，任何仍有贡献的组，其剩余峰量均超过 \(L e^{r/512}D\)。低于门槛的组在所有八度和所有空间格上的来源费用只计一次。完整回代仍允许固定对数损失。

**同一实际源点上的分配。** 固定原峰的一笔真实价格及其半径八度，将不同小端历史和不同中父一起析取。在有足够条件质量的组中，令 \(d\) 为更早旧父体积档的下端，可以同时配对 \(\lceil (D/d)e^{r/512}\rceil\) 条真实成功路径。至少半数路径的根中父互异，末端旧父各自保留至少一半指定来源集的真实质量及一半自身接收所有者的体积。这些保留部分在该次见证中分别两两不交。来源集位于同一可付款来源、同一停止域及该旧父的实际来源块内。构造使用真实体积比 \(D/d\)，包括超过最低增长要求的情形。

**一般上界仍未证明。** 记上述峰的真实子测度为 \(R_{786}\)，\(S=\|f\|_1/\lambda\)，\(V\) 为全部不交接收者的勒贝格体积，\(\ell=\log(n+2)\)，\(k=O(\ell)\)。对任意固定 \(0<\delta<1/2\)，有

\[
(1-\delta)Q_{772}\le k|R_{786}|+
 C_\delta\big[\sqrt n\,\ell^9 V+n\ell S\big].
\]

剩余缺口是不同真实源点可能反复占用同一批旧来源和所有者。仍须对所有高密组的总量证明根阶预算，或证明同一原量的一致收缩。

**本机核验。** 有理算术在六至十二维物理方体上分别按完整记录和来源胞重算，得到相同积分。一个八维算例中，不同旧父的接收体积交为零，真实来源交却严格为正。另在32、64、128维构造18、100、648个物理中父，确认丢掉绝对接受量条件后，即使不同父的所有者完全分开，两条路径也可总是重用同一旧交价。九项分层原子输入的格平移费用另行精确核验。这些数值检验只覆盖所列参数和条件。
