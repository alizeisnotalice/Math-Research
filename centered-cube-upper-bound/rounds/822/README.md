# 第822轮　同一右来源的整组费用与多方向共同新增的真实质量

固定单窗 \([1,2]\)、真实来源 \(\mu\) 与同一阈值 \(\lambda\)。令 \(S=\|\mu\|\)，\(F\) 为去掉窗顶后的任一实际成功接收集，\(M=\lambda|F|\)，\(v_x=t_x^n\) 为最右见证的体积。从早盒的真实质量中抽取右来源 \(q\)。本轮沿11月23日指导第5节和第6节第三步，考察同一份 \(q\) 被不同来源、实际接收者及尺度共用的费用。

**已证明的整组预算。** 一组有 \(r\) 枚预选枢源，全部晚槽的枢与接收者边际合计至多为 \(rL\) 倍原边际，晚早体积比至多为 \(e^H\)。在晚体积档 \(D\) 上，给定一个端点后可预先选取实际来源质量至多 \(K\lambda D\) 的表。只要任一晚槽实际捕获 \(q\) 且命中相应表，就对整份记录收费一次。对 \(1\le A\le c n\)，其总量至多为

\[
CS\left[\log(n+2)+\sqrt{nA\log(en/A)}+\log(1+r)+rLK(n+2)e^{H-A/2}\right].
\]

该式支持两个来源端点交换。对同一个 \(q\)，还可按其真实条件律独立抽两组接收者，估计由较大早盒一侧的枢源命中对方任一盒的总量，两组的实际接收边际同时保留。若 \(r,L,K\) 至多为固定次多项式，固定 \(H\) 时整组费用为 \(O(\sqrt n\log n)S\)。\(H=\sqrt n\) 时为 \(O(n^{3/4}\sqrt{\log n})S\)。当 \(q\) 到所测枢的 \(\ell^1\) 距离大于 \(\sigma n t_x\) 且 \(H+\log(1+rLK)=o(n)\) 时，该类命中的费用指数小。

**对未付部分加强的几何必要条件。** 固定 \(\epsilon>0\) 和新增来源数 \(k\)。如果 \(M\ge\epsilon nS\)，则占 \(M\) 固定正比例的真实记录具有以下结构。存在至少 \(c_{\epsilon,k}n\) 枚沿不同方向发出后继的枢源。每一臂有 \(k\) 个实际晚接收者，总对数体积跨度 \(H_{\epsilon,k}\) 与维数无关。一枚共同的旧来源 \(q\) 一直被保留。另有同一批 \(k\) 枚真实新来源，其中第 \(j\) 枚在所有保留臂上同时从第 \(j\) 个晚盒开始出现，并在其后各盒中保留。枢源和共同标记可以依次与此前张成的仿射空间保持 \(\sigma_{\epsilon,k}nt_x\) 的 \(\ell^1\) 距离。就这些共同标记而言，至多 \(L_{\epsilon,k}\) 个坐标即可准确判断它们对全部实际盒的成员资格。该坐标集可以依赖早接收者和标记。证明直接使用早根未来帽及真实壳内来源质量。

**本机核验。** 二维正密度例中，每条晚臂新增 \(41/80\)，完全共享、半数共享及分离时的真实并集分别为 \(41/80,123/160,41/40\)。对同一批二维记录，三种容量分配均付清自然双来源需求；放大需求后的饱和行列另列为有限模型。1024维正密度例有2049个不交接收邻域，两档新增块分别被2048和1024个捕获。该例的所选接收质量 \(M/S<2^{-1024}\)。薄面坐标数以有理网格和256、384位 Arb 核验到4096维。

**尚缺的步骤。** 仍须支付真实接收者在许多方向上共同捕获这些来源，而给定 \(q\) 后独立重抽接收者几乎不能重获它们的总质量。坐标集依赖早中心和实际标记，对固定 \(q\) 的可负担来源表仍待构造。第813轮的原历史、完整度、两臂分母及两个勒贝格接收边际保留独立总账。一般单窗 \(B_n=o(n)\) 和全尺度 \(C_n\le K\sqrt n\) 均待证明。
