# 第763轮　真实价点分组与不同父方体的共同覆盖

本轮直接估计第753轮后指南式（4）的高负载原积分。固定大父，将两种方向按各自的原来源质量和真实接收体积计入。在真实价点分组后，保留第一枚原标签，从同一组独立抽第二枚小父标签。两枚各自的边际都等于原流量。

设 \(S=\|f\|_1/\lambda\)。每个大父可先用至多 \(\exp(C\sqrt n)\) 个组。在下列条件之一成立时，两枚标签对应的全部加权份额合计为 \(O_C(\sqrt n\,S)\)。

- 两小父的真实交质量至少是较小来源质量的 \(\exp(-C\sqrt n)\) 倍。
- 在半径较小的小父与大父的截盒上，两小父真正分离的坐标数至多 \(C\sqrt n/\log(n+2)\)，另有至多 \(C\sqrt n\) 个坐标相交而目标小父未包含整个截段。

第二种情形允许两小父在空间上彼此不交。证明用同一份随机坐标选择构造覆盖见证。真实来源可以在各坐标上任意相关。对更一般的价点信息，详细证明式（9）给出原流量、标签互信息与见证命中概率之间的定量不等式。

原三步下降链还可在末端按完整来源质量重抽一个价格。它重新落入至多 \(\log^5(n+2)\) 个指定旧位置之一的路径流量，在原反证所选的输入上合计为 \(O_K(\sqrt n\log^3(n+2)S)\)。各位置共用这一个新价。

**剩余缺口。** 同组标签仍可能只共享极小的来源质量，并在许多坐标上分离或互相裁切。完整总账式（12）保留了这部分原流量。尚缺它相对于原入口的一次统一收缩，一般 \(n^{1/2+o(1)}\) 上界仍待证明。
