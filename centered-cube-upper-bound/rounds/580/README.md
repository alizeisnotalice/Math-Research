## 完整对象与结论

保持任意有限正标签、原全尺度高核好区 H₂、全部实际见证、完整质量带 [L,U]。最大实际见证的填满 cells D_T 给出完整 J=λ|R_lo|=Σ_i m_i∫N_i(u)du。首次费至多W，全部未加权重复保留。

按真实新增来源改锚，质量加权重复 J_Δ 有准确全族流，目的列权 H≤1，因此仅得 J_Δ≤J。原费用恢复仍需 M/Δ；目的来源也可能已经有前驱。全新增来源均满足一个有向坐标面的距离收缩，但面可改变。忘掉条件盒得到的完整外条体积对质量增量比的一阶系数是2，不能当作单盒壳的1/(2n)。

独立几何证明给出八个实际单位源 {±1/2}²×{±9/10}：原全部高族只有单标签，在正体积 E=[−1/100,1/100]³ 上每个锚都有真实连续4→8收费。保持同一个当前x,T并按新增质量改锚，八状态组成封闭链，谱半径1、首次泄漏0。跨锚重算u，不是假定同一个数值u。体积和全部Jacobian准确保留。这个例子不反驳一般目标，要求后续整体支付循环或改变机制。

对于一般固定x,T，非首次闭类恰是至多2n条原T坐标尾之并，共同核心是真实旧方体的坐标交盒；闭类数至多2n。此结构已经独审，但不是根阶付款。重核心增量只付C_T之外于C_K的部分，核心内部的合法转移和跨(x,T)累计来源重复仍未支付。

互补路线保留完整接收者首次覆盖的两项实际重叠收益，得到有限有符号账；尚未证明它们抵消交叉全族来源增量的重复。没有把账的恒等重写计作上界改善。
