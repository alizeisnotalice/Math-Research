# 第583轮：完整共同覆盖的真实费用与全列证书

日期：2026-10-24。一般 n^(1/2+o(1)) 一致弱型上界仍未证明。本轮把逐个修剪改为全部实际半核心的共同覆盖，保留完整载体体积，得到了三组完整有限模型的费用改善；未获得一般维数上界改善。

## 研究结论与决定

固定原全尺度好区H₂及完整带内Rlo，允许全部有正体积接收的父S和全部实际半质量核心K。共同非负覆盖系数必须覆盖整个Rlo，真实费用Pv支付每个载体的完整体积，而非只付新增部分。积分直接给J≤Pv，不需整数舍入。

统一质量代理目标Pm≤Cn log^A(n+2)W不成立。对每个n≥2，真实输入{-a,0,a}^n上单位来源、a=2−1/(n2^n)，原H₂和所有允许列严格给出W=3^n、Pm=4^n/2，但Pv=J。全部列的几何分类和匹配原对偶证书已有独审，不是有限扫描。更精确的全族双目标公式说明：每个质量最优解的真实费用为J/δ，而把质量预算增加至2Pm即可实现J，δ=1/(n2^n)。因此下一步保留坐标宽度完整乘积，停止用统一质量费用替代真实体积。

真实体积对偶约束下，同一父的合法半核心扩张满足完整有符号差集预算。但它不能拆成逐坐标免费信用，也不能逐列相加得到全族容量。一般Pv≤C√n log^A(n+2)W仍未证明；这条局部限制不计为维数进展。
