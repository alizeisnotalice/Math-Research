# 第356轮：共同来源方向集中交通的根阶对数付款

真实单坐标薄边界接收容量为 B1=(1−sigma)+[n(1−sigma)+sigma]log(b/a)。在第355轮实际终端流中，对同一来源汇总全部路径，以max_i L_i>=L/log(n+2)分出方向集中来源，其全部交通一次支付不超过3sqrt(n)log²(n+2)W，不新增接收吸收系数。方向分散补集未付；没有假设任意来源的边界质量小。

原捕获平方的本质并集质量条件另给delta Xq证书，但与旧分支重叠，未加入本轮总账。质量亏损入口比较尚未成立，不算新增付款。

保留完整原入口及软层、尺度、初始/删除/未来删除时间原子等未付项。一般一致弱型上界仍未闭合。
