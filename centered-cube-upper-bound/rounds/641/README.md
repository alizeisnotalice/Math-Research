# 第641轮：跨来源块的全局重分配与局部价格边界

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。保持完整方体位移、同一旧 KKT 来源、新族自身正则最优权和真实接收测度。

## 本轮可核验结果

实际新 KKT 支持价格给出整组邻域的局部预算，保留实际新权、真实接收增量及同一新来源的局部质量分母。该估计合法，但不能替代完整来源缺额 S。

本轮构造了一族真实方体：旧交图为 C_(3k)，同一次零位移扩张产生横跨旧来源块的 k 元共同交集。局部 reach/join 信用对全部合法位移均为零，而实际新正则覆盖费用由 3km/2 降至 (k+1)m，真实缺额为 (k/2−1)m。证明覆盖整个旧 KKT 来源类；这不是靠更换来源密度获得的收益。

更重要的是，得到可正向使用的完整来源交换规则：从旧来源包移出质量后，只要同一次新交集组合逐行补足旧需求，就得到真实非负绝对连续容量证书。等量循环交换净省 (k−2)f；不等量情形保留全部共享行费用，净省为

    Σ min(ell_r,r_r) − max_r(ell_r+r_(r−1))。

不要求被移除包在新族中只有旧成员身份；额外新覆盖只是余量。多个交换必须共用同一位移，且不得超支任何旧来源包。新容量证书不冒充新的正则 KKT 来源。

## 一般目标还缺什么

上述显式族是非困难控制，R=2/a^n，不能据此宣布一般根阶上界改善。尚未证明任意困难族都能提取足量的全局来源交换，同时支付同一次位移下的接收体积亏损。

后续继续完整全局几何与容量路线，保留所有新交集之间的共同补偿和实际新正则收益；不再把主要精力放在扩大某个旧来源块的局部邻域。目标仍是完整 D≥cV−C√n log^B(n+2)M，或具有统一收缩、可求和费用与受控终端的递推。
