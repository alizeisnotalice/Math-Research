# 第806轮　同一真实来源处跨中父的三标签平方预算

固定同一真实外源 \(y\)、物理半径八度及中父档 \(M\)、指定小父档 \(D\)。按同一份第805轮余流抽原路径，在其真实旧价处补出四条都通过原筛的边。记 \(\bar p_y(t,t',u')\) 为其中两枚中父和另一枚小父的联合概率。令 \(b_i=j_i/m_i\)，其中原历史权 \(j_i\le C_*|E_i|\)，\(E_i\) 为不交的实际勒贝格接收区。本轮得到

\[
 \sum_{t,t',u'}\frac{\bar p_y(t,t',u')^2}{b_tb_{t'}b_{u'}}
 \le e^{-c\Xi},\qquad \Xi\asymp n^{1/4}\log^{5/2}(n+2).
\]

这个平方和先合并同一 \(y\) 的全部实际历史和中父，再取平方。反向固定另一条臂的实际交价 \(q\)，在同一份四边配置上得到两个小父和另一中父的对应界。该方向的指数可取 \(\max\{\Xi,s^2/(2^{18}n\log(n+2))\}\)，其中 \(s=\log(M/D)\)。两式对各自有正质量的组按真实观测边际几乎处处成立，全部组只用一次原质量。[详细 LaTeX、数值笔记、证书和复现脚本](research.zip)

## 实际付清的部分

所有满足 \(\bar p_y(I)\ge e^{-c\Xi/2}b_I\) 的三标签组合 \(I\) 可以一次付清，即使拥有同一来源的物理父数任意大。正反两个方向都可在同一真实完成上收费。关键是保留每条指定边自己的补全分母，并在两个比较价上先求和共同父的实际接收体积。未付配置还须有定量足够大的共同来源与接收区域，两小端必须能在同一条完整中央历史下共用这份区域。

把付款投回原路径，得到正测度分解 \(R_{805}=R_{\rm paid}+R_{806}\)，其中 \(|R_{\rm paid}|\le C\sqrt n\log^3(n+2)V+o(V)\)。这里 \(V\) 是实际接收总体积。所有低频组合的合计仍待估计。若固定同一三标签重抽两价，它们的真实联合权含逆频率 \(1/\bar p_y(I)\)，在低频部分可能很大。一般 \(n^{1/2+o(1)}\) 一致弱型上界尚未证明。

## 本机复核

本机 Python 3.12.14 以有理数恢复三组有限方体模型的 256、544、1952 条有向标记边。压力例即使固定同一旧价和三个物理父，仍恰有一半的对角配对不能真实换配。六个预定锚各取两个不交的真实价胞，对三标签先按父求和与先按两价求和，两个有理数结果逐项核对。省去每条原边自己的补全分母、改作一次整体归一，压力反向例把平方量抬高约 27.96%，扩大反向例又将它压低约 3.58%。

SymPy 核对了截断均值恒等式，256 位 Arb 核对有限后验的 Gram 计算，512 位 Arb 核对量化与参数比较。有限诊断使用归档中的真实方体和来源权；正文列出了继承的高维条件、三标签不等式的证明及仍未付的原质量。压缩包内列出实际环境、四条复算命令和文件哈希。
