# 第787轮　不同中父重用同一真实来源的联合装填

这一轮接续第786轮提交 `3932106d8ab6`。在同一真实旧付款位置上，不同中父、不同价点对同一来源的重用，可以按真实接收体积合计。一般中心立方体弱 \((1,1)\) 上界仍未闭合。[详细 LaTeX、精确证书、代码与复现清单](research.zip)

## 两条一般估计

- 固定一端已经看见的真实价、接收位置和允许的后续历史。对隐藏端父 \(i\)，将所有中父按原峰权的 \(d_vm_v\) 倍合计，得到相对于同一可见参考的需求密度 \(h_i\)。这组数同时满足真实来源上的装填约束和逐父的接收体积约束。可见参考在任一物理接收区域上至多为其勒贝格体积的 \(O(\log n)\) 倍。报告式（2）至（6）给出源点、中父和旧观测合并后的费用，保留原来的两个父质量分母。
- 对从同一物理旧位置条件抽取的两个真实原峰，来源重合的费用保留两中父质量的较大者。正权的两个原峰可以来自不同价点和不同格。在同一顶端中央历史重取完整真记录，又得到双向联合界，分母为两端中央质量的较大者，增益为 \(e^{-js}\)。用这个界可支付严格上升的**一条原路径**的接收位置落入顶所预报的一批方盒的实际质量。见报告式（5）、（7）至（9）。

## 回代与剩余

直接在 \(Q_{772}\) 上，低真度、装填容量低且实际需求最高的一族、条件来源重合高三部分已按同一次分割付款。在第786轮的加强入口上，还扣除了同一批原峰的上升失败与接收预测命中量。报告式（10）保留
\[
(1-\delta)Q_{772}\le k|R_{787}|+
 C_\delta\big(\sqrt n\,\log^9(n+2)V+n\log(n+2)S\big).
\]
尚缺对 \(R_{787}\) 的统一估计。许多不同旧点仍可能对应装填容量很大、彼此低重合的隐藏父族，真实接收位置也可能在各自的预测范围以外。

## 本机验证

独立 Python 3.12.14 使用有理数复算。三组真实方体输入维数为 8、16、32，同一可见观测下同时具有不同中父和不同隐藏价盒的配对占 43.01%、46.84%、33.97%。逐峰配对和按来源胞积分得到相同费用。逐个可见组完成 136 次子族装填检查。四组有限路径核验证共顶联合律的 Gram 等式，前两组另枚举 4 和 10,944 条完整路径。物理模型使用诊断硬门，有限核没有实现全维高负载条件。报告列出分母、原质量、下界模型的来源与长度对照及三个复现命令。
