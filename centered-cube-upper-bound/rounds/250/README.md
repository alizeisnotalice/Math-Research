# 第250轮：高度截断与无网格局部来源估计

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮利用每个来源块的实际响应高度 mi/a^n，截去不可能出现的层积分；局部费用中的 log(Mi/mi) 因而可改为按输出阈值截断的显式表达，消除小块标签带来的人工熵费。另证明直接连续、无需网格极限的局部来源质量截断，并保留所有层费用和实际接收测度。

[研究包](research.zip)包含详细 LaTeX 文本、独审、来源资格、真实正体积接收例、代码和复现材料。仅新增本说明与 ZIP，更新项目总览；不编译 PDF。

## 实际验证

6个真实 L1 来源族，加同一物理来源的2个细分表示；8模型共63个接收小立方体、10,233项精确有理几何检查。质量单调性将半径网格检查提升为整个连续 R∈[1,2] 的硬带证书，未声称原 FULL 资格。

同一来源分成4、16、64块时，实际接收域不变；u=1/2下旧规范化费用约为7.16、9.93、12.70，高度截断费用均约6.16。另完成40项高度费用、40项连续版本费用和80项闭式层积分求值；这些求值不是独立积分证明。主代理另运行126项精确阈值检查和60项径向积分检查。

解压后：`python3 reproduce.py --verify-only` 独立核验接收盒几何；`python3 reproduce.py --output-dir /absolute/new/path` 完整重算两份数值 JSON 并核对字节。需 Python 和 mpmath；本轮未新增 MATLAB/QP 计算。
