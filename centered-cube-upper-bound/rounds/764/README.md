# 第764轮　同一真实价点上两个大父的三重交与共同位置

本轮从指南式（4）的完整高负载量出发。在固定小父及真实来源点后，按原后验抽两个大父。两种来源方向保留各自的接收体积和质量分母，两个大父各自对小父的边际都等于原积分。

设小父为 \(A_k\)，两个大父为 \(A_t,A_u\)，记 \(B=A_t\cap A_u\)、\(x=s_k/s_t+s_k/s_u\)、\(S=\|f\|_1/\lambda\)。在整个同价抽样上，满足
\[
 x\le1,\qquad \mu(A_k\cap B)/\mu(B)\ge x^{n/2}
\]
的实际流量至多为 \(C_K\sqrt n\,S/\log^2(n+2)\)。当两个大父的半径都至少是小父的三倍时，门槛至多为 \((2/3)^{n/2}\)。另有一项按两大父真实交体积配额的估计，适用于全部半径比，见式（6）和（7）。

**同一来源点能否被定位。** 给每个辅助大父抽一个真实接收所有者，记录从共同价点到该所有者的完整归一化方向。可在 \(O_K(\sqrt n S)\) 的费用内同时使用 \(O(\sqrt n/\log(n+2))\) 个这样的方向。将已知父中心按观测反推价格后，若可能位置在小父半径除以 \(\sqrt n\) 的精度下只需 \(\exp(C\sqrt n)\) 个代表，全部相应流量可按纯根阶支付。即使几何候选更多，只要观测后真价在实际位置附近仍有 \(\exp(-C\sqrt n)\) 的条件质量，同一个预算也足够。两条证明分别见式（12）和（12a）。

**全局缺口。** 上述付款没有消耗新的入口吸收系数。一般上界尚缺对同一剩余流量的一次固定比例控制。当有指数多种相隔的位置都与实际大父方向兼容，真价的条件质量也分散时，现有估计还不足以从完整总账式（13）推出这项控制。
