# 第431轮：可预测质量门下的反事实邻近强度

一般一致 n^(1/2+o(1)) 上界仍未闭合。本轮在原R430全远余流上证明新的来源预算：

\[
\int\mathcal C\,d\Pi430\le\Omega_{\rm cf}W,
\qquad\Omega_{\rm cf}=2Sr(1+\sqrt n)[\Psi(M)+(1+\varepsilon_0)\Theta(M)].
\]

C是两条原路径所有proper跳的原核邻近概率之和，使用可预测质量门支持的较小父邻域。先保前态质量门，再正上放未来权，最后按原核补偿；反事实目标无需继承原未来历史。真实父中心积分与完整来源匹配给出上式。

因此实际正支C≥γ的价格为Ω_cf W/γ，固定γ时为O(√n log²(n+2))W，无新增X_q。全部旧费用保留，入口新增64ΛFhatΩ_cf W/γ。剩余C<γ仍保低避开风险、大父质量跨度及全部历史，其联合一般预算、总吸收和全尺度尚未闭合。

[研究归档](research.zip)含详细LaTeX源、独审、精确脚本和本机MATLAB输出。解压运行四个 `r431_*_check.py`，父脚本读取同包CSV；MATLAB运行 `r431_parameters.m` 输出到 `/tmp/`。三阶段检查保留原子、终端、相关未来权和真实连续中心诊断；有限模型不认证完整原历史。另附一页级正幂混合恢复费用说明，用于停止无效调参，不是一般几何不可能结论。
