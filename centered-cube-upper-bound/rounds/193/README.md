# 第193轮：共同有序输运与真实未来损失

一般 n^(1/2+o(1)) 一致弱型上界尚未闭合。本轮证明原捕获余量与目标的共同有序部分匹配判据：允许不同捕获点分别服务不同目标，且全部目标共享同一供给容量。紧空间极限、可测系数和原真实接收预算均有独立证明与审核。

进一步保留未匹配部分的真实未来损失，先支付低放大目标，只要求匹配快目标；保护已用target质量并扣除同核强制损失，给出加强的cut容量下界与精确单cut背包算法。原父块上的失败cut具有明确的供给不足或排序倒置位置约束，但这些配置的全局根阶价格仍未证明。

详细LaTeX文本、独审、三阶段数值与复现脚本归档于 [research.zip](research.zip)，不编译PDF。数值只验证有限代数模型与所列曲线，不认证FULL、连续一般输入或维度阶数。

仅新增本README和归档、更新项目索引。展开材料在仓库外备份并校验后移除；本轮使用1 Astra high、2 Sol high、1 Sol medium，无可获得逐模型实际扣额数据。

实际验证：15个匹配例（维度2–6，25/40位曲线）及3个保护容量Fraction例（2/3/4原子）通过。最终driver核验13个文件哈希，完整重跑两脚本，两份JSON逐字节一致。归档57,070字节、14成员，SHA256 `c16971ab359890e2cf834333150930ab877603c838f204b0a0fe75ad7f26747d`。

解压后 `python3 reproduce.py --verify-only`；完整重放在已有mpmath 1.3.0环境运行 `python3 reproduce.py --output-dir <新目录>`。本机依赖路径与有限测试范围见包内report.md。
