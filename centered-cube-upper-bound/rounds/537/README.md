# 第537轮：全扩大根约束与外侧联合几何

一般根阶上界仍未闭合，本轮没有新的核心阶数改善。原目标仍是完整外侧对数加权积分 `Elog_ext ≤ C n log^A(n+2) X`。

已核验：使用每个真实中心的全部扩大根约束，可合法给出联合来源覆盖费用 `2λΣ s_i^n β_i`，但其跨组重复成本未付；简单分格的体积比较损失为 `(2n+4)^n`，这不是原目标下界。报告保留准确的未完成覆盖权条件，没有把表示式视为预算改善。

实际本机计算与独审：

- 七个少中心模型×三约束版本，共21份有理原解/Arb对偶证书。三版本仅落在相同窄区间，不声称精确最优相等；最大认证间隙小于2.81e-8。
- 25、81、301个接收中心网格×三版本，共九份精确有理原—对偶证书；同一网格三版本最优值确实相同，分别为33/32、301/512、4021/8192乘log(2)。扩大帽的返回对偶权均为零。这不证明一般约束冗余。
- 同一四原子来源的真实全接收域面积为5/2−sqrt(2)。连续中心Sobol实际运行两种规模、各四次，共2621440点；较大规模外侧费用估计约0.262。样本波动不是严格误差界，原子来源也不是L1证明。

这些检查未提取出新的联合几何对偶机制。后续仍需控制不同请求共享真实连续接收中心的全局重复费用，不继续堆逐父局部工具。
