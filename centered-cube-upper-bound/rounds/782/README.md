# 第782轮　真实来源上的中父覆盖与跨尺度费用

在第772轮的原始两跳峰上固定一端的历史和真价 \(y\)。全部中父按原峰权给出一份概率分布 \(\pi\)。知道另一端的真价 \(z\) 属于来源盒 \(P\) 后，各中父的概率变为 \(\nu(P)\)。对任一分布，其在 \(x\) 的覆盖率就是所有含 \(x\) 的物理父所占的总权重。本轮估计两份分布同时覆盖的真实来源，保留原来的 \(d(v)\)、两次真实交价、共同中央探针和不交接收体积。

**跨中父的费用。** 令 \(\ell=\log(n+2)\)、\(L=\sqrt n\,\ell^3\)、\(r=\lceil\sqrt n\,\ell^2\rceil\)、\(\alpha=(n+1)e^{-r/256}\)。固定充分大 \(n\) 和 \(0<t<1/4\)。在来源树的每个节点，可以从真实 \(\mu|_P\) 中挑出质量占比为 \(\alpha\)、两份分布覆盖最密的部分。沿树只对第一次越阈的盒收费。扣去的峰量有统一预算后，余下每条峰在两个方向的每个祖先 \(P\) 上都满足

\[
 \frac{\mu\{x\in P:\Phi_\pi(x)\ge1/2,\ \Phi_{\nu(P)}(x)\ge1/2\}}{\mu(P)}
 \le 4\alpha t .
\]

证明将同一来源转移同时作用于全部物理父。大交父对用原双峰估计，小交父对直接用转移后的真实交质量。测度的列容量允许达到 \(1/\alpha\)，树深和父标签数均未乘进费用。

**每个位置可以独立选择分布。** 对来源密度逐轴二分，首停盒的平均密度在 \(H_0\) 与 \(2H_0\) 之间。支付一笔 \(O(\sqrt n\,V)\) 后，给定真价只剩 \(O(\ell)\) 个可用的绝对半径八度。在每个八度选择平移网格，合计所有相邻来源区域的真实质量至多 \(C\ell S\)。于是每个八度的每个格都可预选

\[
 N=\left\lfloor\frac{e^{r/256}}{(n+1)^2\ell t}\right\rfloor
\]

份中父分布，每份可含全部物理父。在已通过来源树检验的原峰上，若实际分布的覆盖率函数在本格的扩大来源区域上，与其中一份处处相差至多 \(1/8\)，这些锚点的原峰质量合计至多 \(CnS\)。这里 \(S=\|f\|_1/\lambda\)，\(V\) 为真实接收所有者总体积。格之间可以有任意多种不同的选择。

**全局回代。** 两向的检验在同一份原峰上冻结。对每个固定 \(\delta>0\)，本轮余量满足 \(Q_{772}-|R_{782}|\le\delta Q_{772}+C_\delta(LV/t+nS)\)。固定 \(t=1/16\) 时仍保留原入口的对数幂。一般输入在每个空间格内的中父覆盖分布可能高度分散，尚缺 \(|R_{782}|\le C\sqrt n\,\ell^\beta V\) 或统一收缩。一般上界仍未证明。

**实际复现。** 本机有理算术分别按物理父对和按来源首停盒复算相同峰权。一组三中父、六层的诊断例中，首次命中质量为全部原峰，逐层相加会报成七倍。二维真实来源例给出一个盒，两个父的体积占比都超过 \(3/4\)，而真实共同质量只有 \(81/64\)，小于半盒质量 \(3/2\)。另以256位 Arb 核对原宽窗口下界来源的七组维数参数。各模型的原图条件与简化均在报告中列明。[详细 LaTeX、三份本机脚本与数值证书](research.zip)
