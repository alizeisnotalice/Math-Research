# 第865轮　同一真实来源上多父交盒的联合付款

固定第813轮原积分的一条臂，保留其中父、小父和实际来源，再从同一来源上按真实接收权抽取其他父。以共同源质量和实际交盒体积之比衡量这条原臂可付的份额。对任意正输入、任意原割，两端可付份额取最大后，其原质量至多为 \(C[\mathcal H\mathfrak j(A)+n\mu(B)]\)。两侧的原来源分母、接收边际及历史保持在母式内。不同割允许各自确定辅助父的抽样律。[详细 LaTeX 证明、两项计算及原始输出](research.zip)

**付清的输入范围。** 若每个相位由足够多条独立的物理坐标轴形成，可将原交盒里的各相位一起平均。相位之间的源密度允许任意关联、任意峰值。由此付清了第864轮中短位移只能搬出指数小份额的多组振荡源，在适用窗内的整份原积分。若还保留 \(d_0\) 个自由轴，且辅助轴满足文中给出的物理截止条件，对这类输入的连续单窗弱型比得到 \(C(1+d_0)\)。

**实测范围。** 同一批四维920条原记录上，四父标记在密度门为1时约为原量的0.0107%，在门为 \(10^8\) 时为98.564%。在848条难割记录上按自身接收权重新计算，对应为0.0107%与98.408%。大门数值用于有限样本比较。另用320位 Arb 核验实际方体交上的相位平均，包括低维偏差和多组大维抑制。高维算例使用乘积公式。

**剩余缺口。** 对同一枚真实来源，如果少数父组合过载，其他组合仍可取得付款。剩余原量要求两端都存在大量共同来源密度过高的父组合，它们可以涉及不同来源。尚缺对这份原量的统一预算或固定收缩。本轮新增吸收系数为零。一般单窗次线性及全尺度根阶结论仍待证明。
