# 第833轮　两个真实来源在同一中父上的方向与相互来源秩

第832轮用欧几里得张量几何的共享标签公式，把伙伴盒的轴宽与真实接收体积联系起来。本轮在第813轮原双臂积分上，固定同一完整右臂，独立抽两条实际历史。按第二个中父接收第一条记录的左价所需的各轴截短量排列真实来源。记到达该左价时的累计来源质量除以第二中父的实际质量为 \(r_{12}\)，反方向为 \(r_{21}\)。同分的来源全部计入。可以将与这个右臂无关的外部来源从排列中去掉。

两方向合计得到
\[
 \Pi_R\{\sqrt{r_{12}r_{21}}\le K\}
 \le C\frac{\mathcal H(n+2)}{L} e^{-b_0/16} K[1+\log(eK)]Y,\qquad K\ge1 .
\]
两个中父的体积比在相乘时精确消去。固定同一真右价，还允许在保持两个真实右臂边际的条件下，预先挑选最有利的跨尺度配对。联合界对这种配对的最优值同样成立。取 \(K=e^{b_0/32}\)，用一次加权最小割，可把所有容易配对的右父对都覆盖。所删记录的原双臂质量为 \(o(V)\)，其余任意两只右父在同一真右价上命中此秩门的概率均小于 \(1/16\)（按删除前冻结的条件律）。该费用已经合计所有物理窗。在一般实际末根上，对任意来源割 \(\nu\)，同一双向秩门的费用至多 \(CK[1+\log(eK)]\|\nu\|\)。取 \(K=\sqrt n\) 时为 \(O(\sqrt n\log(n+2))\|\nu\|\)。文中给出截短量接近 \(n/4\) 而双向秩仍小于 2 的正密度真末根实例。

在同一个中父中心上，也可以比较两端仅用本臂信息作出的方向预测。每轴对共同位移的贡献及两端方向不一致的代价均由真实位置给出。在有限端点分区上，最大总净收益等于一个可用有理流与割认证的优化值。若此收益能解释某一正子流固定比例的原两价总位移，这整批记录有 \(C\mathcal H(n+2)e^{-c\log^2(n+2)}Y\) 的费用。报告还给出用同一个勒贝格中心接收所有伙伴时，累计截短量的双侧方差估计。

四项本机复算使用 Python 3.12.14。两份四维原档各保留230条真实正记录。按完整端点胞选最优方向，可解释总位移的36.93%和42.06%。取单向来源秩门倍率8，能另外接收的整盒外质量占全部原质量的比例分别位于 \([0.89978\%,1.01875\%]\) 和 \([0.81422\%,0.91803\%]\)。同一真右价上，固定使用同一右父的双向真价接触率为94.6811%和95.1570%，最优配对给95.0108%和95.4110%。四维算例的渐近高维筛选门为空。

剩余困难集中于同一右臂的多数伙伴配对的两个归一化来源秩的几何平均都很大，同时两个端点难以预测共同位移的情况。一般弱型上界仍待证明。[详细 LaTeX、可复现代码与检查摘要](research.zip)
