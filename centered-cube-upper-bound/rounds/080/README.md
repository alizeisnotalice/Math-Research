# 第80轮：单侧首达与低占用余项归约

日期：2026-10-11。核心目标 **未完成**；全一般保留基准仍为 O(n log n)。

本轮对任意非负 L1 输入用真实核正性吸收全部细软层尾项，只保留 O(log n) 个正向层输出越阈事件。平滑基线、连续高背景、锚点和连续通量例外，以及大恢复时间／大背景占用支路，合计严格支付 O(sqrt(n) log²(2+n))。仍欠短时低占用的原始有符号硬面首达弱体积，以及全尺度回代；已付支路的阶数不是整体上界。

另证真实硬首达处的径向来源年龄指数尾，给出按方向条件化加强式的真实 L1 正体积反例。共同物理来源的单侧 duty 证书及有限 LP 弱对偶合法，但临界正核与硬立方体双边可比；逐原子阈值 shutdown 在细分聚集来源上失败，一致廉价覆盖仍未建立。

## 材料与复现

`research.zip` 只有7个成员：`proof.md`、`proof.tex.txt`、`probe.py`、`results.json`、`firsthit_probe.py`、`firsthit_results.json`、`inventory.json`。报告包含完整假设、证明、反例、未决接口及三阶段数值笔记。LaTeX 仅静态检查，未编译、未生成 PDF。

解压后使用 Python 3 标准库（实际运行版本3.12.14）：

```sh
python3 -B probe.py
python3 -B firsthit_probe.py
```

`proof.md` 的四个 Python 代码块依次为软层、硬面、覆盖、最终独审守卫，提取至同目录运行。两个主程序由主代理独立重放，JSON 逐字节一致；四个守卫均实际执行通过。完整哈希、输出和重放记录见 `inventory.json`；归档解压后另行运行最终独审，核验可移植性。

- 实际 E2：7个正 L1 输入配置，592接收点，172个核心正向包含检查；5条正向 corridor 恒等式残差约1.02e-8。有限尺度及求积不称连续证书，未核验全部 E_short 剔除门。n16 的严重采样波动保留。
- 精确首达：有理分段箱重叠多项式、完整物理断点及 Sturm 排根；三阶段19个接收点，114个年龄尾区间核验，区分切触等号和严格上穿。独审另外直接核验376个分段多项式、2214个重叠值恒等式及158个更早区间排根记录。固定点证书不代表弱体积。
- 组件守卫：软层230项，硬面1122个精确有理年龄尾比较，覆盖643项。解析一般结论与数值诊断在报告中分开。

依赖保留的第78轮真实 E2 通量工具与第79轮统一量化／条件 Fatou 转移。本轮重新检查64项技能入口与437个直接本地引用；并按具体适用边界使用，无未验证的独立性、熵或方向捕获假设。
