# 第862轮　同一真实来源分别服务中父与小父

给每枚真实来源 \(y\) 一份所有父共用的次概率核，一次发送两个位置。若第一点进入本端中父、第二点进入本端小父，记其联合概率为 \(h_{ti}(y)\)。两个位置可以分离，各自汇总后的空间密度均可达到固定多项式 \(n^a\)。对 \(\gamma=n^{-b}\)、固定 \(0\le b<1/2\)，两端合计成功概率除以 \(\gamma\) 并在 1 截断后，所有窗中标记的原质量在每个原割上至多为 \(C[\mathcal H\mathfrak j(A)+n\mu(B)]\)。估计保留两臂真实来源分母、完整度和三个真实接收位置。[完整证明、原始程序及三项复算](research.zip)

**同一来源的容量。** 对固定真价，可把有正条件质量的中父和小父按各自共同交盒分组。证明给出同时服务这些标签的确切容量缺额，以及按原行密度加权后尚须控制的质量。若先忽略部分罕见标签，须用同一条件律计入实际省略量。

**改变路线的计算。** 在同一批920条四维归档记录上，每个真实来源只以概率 \(1/2\) 发一次位置对，所有记录的分数标记均达到 1，原最坏割的848条也全部达到。两个位置在此样本取于不交区域，各侧密度给 \(1/2048\) 已足够。对于这个要求完整标签共同命中的发送方案，\(3^{10}\) 个有理割与独立精确最大流给出每侧临界密度 \(0.00046579215\ldots\)。先前单位置公共方案即使给约 \(1.314\times 10^7\) 的密度也只标记了 27.91%。这些数值反映标记能力，四维原合同的实际差额另计。

**适用范围。** 在256维的正宽方体压力测试中，当源的两类标签完全交叉，全部标签可以同时保证的命中率明显下降。该测试只涉及一个端和原盒。一般问题仍需控制两端都处于中间尺度、同一来源被许多不同中父反复使用时的加权欠额。尚未证明一般单窗次线性或全尺度 \(n^{1/2+o(1)}\) 上界。
