# 第423轮：完整双路径的累计亲和预算与统一平方和

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮在原R421的同一次完整双保源路径上，令V为包括初始、终端在内的全部跨路径节点对来源亲和之和，支付χ=min(1,8V)这一正软份额：

\[
P423\le\Delta423X_q,\qquad
\Delta423=\frac{32S}{h^2q_-^2K(1-K^{-1/2})^2}.
\]

没有路径长度、占用层数或阶段数损失，无新增W费。完整入口新增64ΛFhatΔ423X_q，全部旧费保留。

剩余同一双路径具有V<1/8，其完整来源Gram矩阵统一满足5/24≤谱≤43/24（n≥9）。这不是任意两条不同样本路径或不同父之间的全族谱界。仍未得到R423的根阶来源预算。

另证明含终端、不含起点的总Green核闭秩界，保留实际非归一入量。下一步须将联合路径结构与跨父的共同来源重复入量结算，不能刷新来源或以点值代替免费L²测试。

本机实际检查：72个连续中心块/完整来源异截断亲和矩及24个软分/入口算术配置；60个Green模型、11424逐原子比较；78项分类核/中心包络/双链Gram检查。独审隔离复跑通过；最终归档解压复现由打包环节核验。有限模型不认证原完整历史。
