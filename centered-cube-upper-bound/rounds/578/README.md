# 第578轮：完整带见证信用与来源切面抽样边界

日期：2026-10-24。一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮保留一个同一完整残余上的无条件积分估计，并排除一项指定抽样机制；没有宣称一般根阶改进。

## 已证明及独审范围

对任意有限正标签原子、完整质量带 [L,U]，使用固定原全尺度高核覆盖 H₂。令 T=log(U/L)，K 为保留终端原子的共同尺度核；对每个真实接收点，把其全部见证的不同质量排序，定义 V=Σ(1−m_j/m_{j+1})。证明

    λ|R| + λ∫_R V ≤ ∫_(H₂ᶜ) K ≤ Σ_P M_P F(2M_P/L,T)。

P 是原贪心所选、来源不交且分尽输入的块。F(c,T) 在 c≤1、1<c<e^T、c≥e^T 三段分别为 1+T−c、T−log c、0，重合端点取共同值。这同时保留真实多质量见证信用、实际勒贝格接收测度以及原H₂的来源曝光扣减；没有假定来源密度帽或独立性。

但是，小来源块的 F 仍可接近 1+T，尚无一般几何估计保证信用与其他覆盖扣减能支付这份线性费用。V也不能直接等同修正切分势Ψ的下降。

另一严格结果针对“按来源质量抽原子，再在整个投影tie组前后各半切分”的指定抽样律。三维远隔复制族对任意非零投影方向都有 E D≥K²/1327104（K≥5），而每次势降有固定上界。故输入依赖选方向或方向混合均不能修复此律。同一输入存在 D=0 的真实间隙切；这不否定其他自适应共同切，更不否定一般上界目标。

## 实际计算与复现

- 一个三维八单位源模型：准确枚举70个实际见证和全部127个共同分组。原H₂外确有正体积孩子重叠；完整父并集仍使127个净D全为正。三个坐标面对分恰为势比最优。精确立方数域运算及Arb512认证。
- 四个一维六源完整带模型：各枚举63个实际子集和真实接收胞元。两例信用积分严格非零，两例残余为空；完整信用不等式全部由Fraction与Arb256认证。实际F项均在中间支，不声称数值覆盖另外两支。
- 三维复制族：K=2、4、8、16，各取四个固定投影，共16项完整有限抽样律。精确保留投影ties及前后概率，Arb256核费用。全方向结论来自书面证明，不来自16例外推。
- 三个原脚本独立逐一重放，除运行元数据外全部确定数学字段一致，原文件哈希未变。源码、证书、命令、版本、误差与独审在归档内。

使用本机独立Python环境、SymPy、Fraction及python-flint/Arb。本轮未运行MATLAB、优化器或PDF编译；不把未运行工具写为证据。

## 剩余全局缺口

仍须把同一完整残余上的小来源块累计曝光，与实际多质量信用、完整坐标产品和覆盖重复收益共同结算到 O(√n polylog n)W。固定来源平面抽样的失败已明确，不再靠改投影方向重试这一律。
