# 第742轮　同一未付积分中的共同见证与空间重叠

固定第741轮的参数、真实首次越阈来源池和原配对，记其未付积分为 \(R_{741}\)。本轮证明两项可顺序使用的估计，合计只增加 \(C\sqrt nD\) 的来源费用。

**同一来源反复遇到的见证。** 每个原来源和长短类型可以各自选取一组真实见证位置。若某接收点的首次越阈池与其中某个位置共有足够来源权重，就用共同见证的真实接收体积估计支付。对固定权重门槛 \(0<\zeta\le1/4\)，当 \(c\ge64e^{1/32}/\zeta\) 时，每个来源和类型可以同时选取 \(\lfloor e^{8\sqrt n}\rfloor\) 个位置。这里共同来源的体积上限为 \(e^{4\sqrt n}d_i\)，其中 \(d_i\) 是当前配对来源的体积。选择可以随来源改变，总费按各原来源的 \(\theta_i d_i\) 结算。在相应体积比例范围内还可使用更小的共有权重门槛，全部门槛的费用可求和。

**分散见证的合计费用。** 将上一步真正支付的份额从原配对两端扣除，记所得接收边际为 \(\nu\)。对每个 \(x\)，取其真实池的子集 \(J_x\)，在实际空间中选取概率密度 \(f_x\)，使其对这些来源覆盖权重的平均至少为 \(n^{-\sigma}\)，其中 \(0<\sigma<1/2\)。令

\[
e(x)=\int\!\int f_x(z)f_{x'}(z)\,dz\,d\nu(x'),
\qquad d(x)=\min\{1,n^B/e(x)\}.
\]

对任意一批接收点 \(W\)，证明了

\[
\int_W d(x)\,d\nu(x)
\le C_{B,\sigma,c}\sqrt n
\sum_{k\in\bigcup_{x\in W}J_x}\theta_k d_k .
\]

因此，只要见证分布与整批见证的归一化重叠不超过 \(n^B\)，它的真实接收质量就全部付清；更高重叠也可按比例支付。证明把同一物理位置的重叠合并积分，再用第741轮的空间矩估计和所有来源子集上的容量不等式。两端沿用原配对，接收体积吸收系数没有增加。

**总账和缺口。** 记这两项支付后留下的真实双端积分为 \(R_{742}\)。得到

\[
M\le(1/8+2n^{-1/4})V_T+C\sqrt nD+R_{742}.
\]

当许多小区域彼此分开、各自内部见证仍高度集中，而且同一批来源在这些区域中反复出现时，尚无统一估计。要闭合全尺度上界，还须证明 \(R_{742}\le\eta V_T+K\sqrt n\log^A(n+2)D\)，其中固定 \(\eta<1/8\)。

**真实余项检验。** 在第741轮的64维双尺度历史上，固定其原覆盖测试参数 \(B_{\rm old}=1/2,\ \sigma_{\rm old}=1/4\)。有理数核验给出 \(R_{741}>0.69969V_T\)。新测试使用原高损失来源上的均匀密度，其重叠量小于 \(942<64^2\)，故 \(R_{742}=0\)。该例的 \(c\) 很小。第741轮另取 \(B_{\rm old}=24\) 也可支付该例。复现材料列出原积分、来源费用及区间，并记录了在本机实际运行的重叠积分与误差校验。
