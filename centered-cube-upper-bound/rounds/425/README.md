# 第425轮：可和对数质量窗势与双K质量间隔

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮保留真实中心、完整来源和全部原历史，在同一Π423上顺序正分：

1. 对全部双路径节点r_v=log(m_A/(Km_v))，以Φ(r)=(1+r/3)^(-3)构造可和质量窗势，支付min(1,ΣΦ)的实际份额：
\[
P_A\le\Omega_AW,\qquad\Omega_A=\frac{S\lambda A_n}{hq_-^2}(5+12/\sqrt n)\le9S(\lambda/q_-)\varepsilon_0(1+\sqrt n).
\]
该权逐标签支配R424的指数质量权，正式替换其价格，不重复相加。
2. 在A余项上支付min(1,eΣexp(−r_v/√n))，价为
\[
P_B\le\Delta_BX_q,\qquad\Delta_B=\frac{2Se^2\varepsilon_0\sqrt n}{(1+\sqrt n)(e-1)}.
\]
最终正余支所有初始、后继和终端节点均有m_v<m_A/K²；原生成核仍严格按K下降，没有换核或刷新来源。
