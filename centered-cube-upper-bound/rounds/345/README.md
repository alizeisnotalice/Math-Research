# 第345轮：终端捕获尾付款与双侧共同来源交通

**一般一致根阶上界仍未闭合；本轮扩大已付分支，剩余域具备真实双侧捕获容量。** 对每个来源y，令U_y(t)为全部实际接收立方体中质量大于t且捕获y的μ权重。原大端满足U_y(Km_u)≤√n/q_-的交通，可按来源质量支付

`D_n=1+log(4/3)+(7/3)√n`。

证明使用实际源逐点质量分位，严格上尾与闭中窗完整保留原子；中窗用真实中心几何和原物理时钟，未假设来源密度帽。先截断来源后应用新定理，完整槽成为

`B_H ≤ G_bi[(f−T_clip)+] + 3εXq + C_ε,n W + D_n W_ex`。

W_ex是实际超截断来源质量；所有q、m、J和门始终按完整f定义。此式替换旧覆盖付款，不能再累加342费用。接收费用经过原入口和外乘仍为1/4；CZ同账条件下仍为65/256。新剩余同时要求质量低于m/K的捕获权>h、质量高于Km的终端捕获权>√n/q_-。高质量接收器可能在当前半径之后，跨尺度联合付款仍未证明。

辅助源分位网格以真实边界来源质量给δXq近似费用，显式保留Nⁿ格复杂度与内部未付交通；没有加入主预算。软层、质量可比重尾、极端尺度、历史初始/删除/未来被删来源及全部外积分仍独立留账。
