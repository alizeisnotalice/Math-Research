# 第791轮　真实接收位置上的共同来源费用与双端交价分散

一般 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。本轮在第790轮同一份峰测度上，把所有起始臂、所有中父对同一个实际接收位置的贡献合并。用 \(V\) 表示不交接收集的总体积，\(Y\le C_*V\) 表示原首臂质量，\(\ell=\log(n+2)\)。[详细 LaTeX、数值笔记与复现证书](research.zip)

**体积差可以扩大。** 取 \(J=\sqrt n\,\ell^8\)。两小父与中父之间只要有一端的对数体积差不超过 \(J\)，整批峰量至多为 \(C(1+J-\sqrt n\,\ell^3)Y\)。这笔费用乘回上游系数后仍在原有的 \(\sqrt n\,\ell^9 V\) 以内。以下两条估计共同作用于两个体积差都超过 \(J\) 的补集。

- 给定隐藏端的真实接收位置，把所有相容中父的接收体积相加，得到一个逐坐标相乘的明确核。其高次幂在整个物理空间有 \(e^{-J/4}\) 的体积折扣。任一端的加权活价池通过报告式（6）的门槛，两向全部原峰合计只需 \(O((n+2)V/(\sqrt n\,\ell^3))\)。来源在边界上可以集中。
- 在近极值输入中，剔除原极大值超过阈值 256 倍的接收中心，仍可达到旧入口要求的体积比。对每个可见完整臂和中父体积档，可选最能预报另端真实交价的 \(\lfloor e^{J/4}\rfloor\) 个边长 \(JR/(8n)\) 的方格，\(R\) 为该八度半径的下端。一格里所有合格小父共用一个真实中心的外半径质量界。两个方向的实际命中总量至多为 \(C(n+2)^2e^{-J/4}Y/(\sqrt n\,\ell^3)\)。

另有一份在全族物理小父上共享的矩阵预算。乘回中父体积的接收矩阵逐项受原下降流的 Gram 矩阵控制，归一后的迹至多为 \(C\eta Y\)。据此可按真实两端边际分配接收配额。来源耦合另有原分母下的预算，两种分数在同一份原峰上扣除。

**总账。** 记最终未付测度为 \(R_{791}\)。原来的 \(1-\delta\) 吸收系数保持有效，且
\[
 (1-\delta)|Q_{772}|
 \le k|R_{791}|+C_\delta\bigl(\sqrt n\,\ell^9 V+n\ell S\bigr),
 \qquad k=O(\ell),\quad S=\|f\|_1/\lambda .
\]
余下两端的加权价池都很高，两价都落在对端所选方格之外，真实来源还可能在不同起始峰中重复出现。尚缺这批原峰的 \(C\sqrt n\,\ell^\gamma V\) 总量界或可求和的收缩。

**已运行的验证。** 独立 Python 3.12.14 用有理数在 \(n=4,8,16\) 和三个来源振幅下逐条重算峰权及运输原对偶证书。九组都满足同价对角费用低于共用运输最优，而逐对重复使用容量给出的总和更高。另在 240 个真实接收探针核对新列界，用 256 位 Arb 检查三组几何矩和八组采用项目实际尺度的标量参数。四组具有真正首穿越的共享来源例检验了一胞只付一次。低维路径取诊断门，数值结果没有替代一般证明。
