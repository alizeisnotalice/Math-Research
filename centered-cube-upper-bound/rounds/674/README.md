## 尚未闭合的主要费用

高低划分依赖x，不是固定接收分支，也不是单独可行的packing向量。仍须对同一个L_low=L−L_H证明全空间O(τ)界。解析矩估计给∫L_H≤δ_n Vrem，其中δ_n≤5/96<1/16，因此∫L_low≥15Vrem/16。该低部分承载主要交通质量，不能声称一般C_n阶数已经改善。

低部分的保证共同来源率只有[m_a(x)−ν/5]_+；当m_a(x)≤ν/5时无正下界。完整低共载荷交叉来源几何未付。若未来L_low≤Aτ，才可把b_i=Σ_a(v_a/M_a)t_i,a除以Aτ+C_H形成packing，并得到V₀/P₀≤C_adm[(1+A)τ+K_far+K_up+C_H]。此为条件回代，未当作闭合。
