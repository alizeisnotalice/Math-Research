# 第422轮：保源首入质量带核与路径平方函数

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮没有新增根阶付款，原R421余项及完整母账不变。

对已有严格K降质量的真实保源路径，首入I=[M,2M]的核满足

\[
H_I(v,db)\le\frac{1_I(m_b)\rho_x(db)}{\max(h,\rho_x\{m<M\})}.
\]

保留初始Dirac项、质量原子及own-low停止。初始列回代仍留下上游因子1+J_>(2M)/max(h,r_-)。另证明单路径标准来源向量的平方和上界B_K=(1+K^(-1/2))/(1−K^(-1/2))；双路径上界2B_K。它不自动适用于未归一的实际流混合，不能直接推出W预算。

下一步瓶颈是实际双路径的上游来源入量与平方函数联合收费。初始小交叠不能传给全部后继节点；原来源不刷新。辅助能量恒等式只用于核对，未计作新付款。
