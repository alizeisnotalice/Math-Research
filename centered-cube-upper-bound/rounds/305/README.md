# 第305轮：共同资格阈值与根阶可支付的有限二值化

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮直接减少R304捕获预算中的人为标记方差，并给出保留全部原资格的有限二值化误差预算。真正的二值资格几何费仍未得到一般根阶估计，不把这一转换报告成核心问题已经解决。

## 同一目标的更小几何费用

保留原low-pe、高m、尺度比受限目标，以及原U、J、q、e_g、m、FIRST和全部来源/历史资格。设0<=I0<=alpha<=1，alpha>0时b=I0/alpha，alpha=0时b=0；d=kappa0*psi_inf/(q_-v0)，保留原逆尺度比费用。对一个所有接收器与来源共用的阈值theta取二值资格1{b>=theta}，逐theta应用原见证定理后再积分。theta>0时，新增资格的正支持仍在原I0>0内，故原点高度假设合法继承。

得到同一目标的估计

T <= 64 lambda d W_beta + 4 Bco_(4d)。

Bco使用真实差 |c_u b_u-c_w b_w|。它比R304独立标记费用少去精确非负项；来源系数没有增加。共同立方体内部的真实资格差 |b_u-b_w|仍保留。对给定边际资格，共同阈值同时达到所有接收器对的最小期望差；这只认证对差费用的最优耦合，不替代合法见证证明。

## 已付增量与稳定性

固定原U、J及H，对任意资格b、g证明

|Bco_H(b)-Bco_H(g)| <= T_(|b-g|)。

共同阈值截断容量也满足相同模量。这里右侧是资格差对应的原实际交通，未换成两份来源总质量的乘积。若|b-g|<=delta，原FIRST与硬尺度包络将其付成delta A_n W_nu，A_n=1+n log(b/a)。

取b_m=floor(mb)/m，则原目标满足

T <= 64 lambda d W_beta + 4 B^(m)_(4d) + A_n W_nu/m，

B^(m)=(1/m) sum_(k=1)^m B^(theta=k/m)。

m=ceil(sqrt(A_n))时，丢弃的真实交通费用不超过sqrt(A_n) W_nu。层权总和为一，不产生m份来源费。几何费离散误差本身也至多A_n W_nu/m；这是另一个误差界，若同时替换两处须合计其系数，不能把多个误差都算成一次。

资格已二值时，上述取整误差和人工方差均为零，剩余二值几何问题完全保留。尚无理由认为这一最难部分只差常数优化。

## 高捕获部分与完整补集

另一个配套预算在每个共同阈值层保留 p_theta=A_theta/J。p_theta>=1-eta 部分的费用至多eta T_theta，可对同一有限目标内部吸收。取H=8d、eta=1/8，得到

Lambda T <= 128 Lambda lambda d W_beta
+ 4 Lambda 积分_0^1 B_(8d,theta,p_theta<7/8)dtheta。

这里低捕获比例和中间捕获比例两部分都仍保留。它与前面的H=4d预算是不同备选，不能混用阈值和系数。按真实来源列重组还保留了负平方及行间方差节省，FIRST给出列占用不超过r^n；但把它直接积分仍回到A_n量级，本轮没有将此包装为新的中间层根阶付款。

## 原始总账约束

本轮采用来源费用版本的取整付款，没有新增全局epsilon X吸收。原始low-pe槽的Lambda只乘一次，d仍含逆尺度比费用。R304核回的宽距离、高连续suffix、初始、删除跳跃、未来被删来源、极小尺度比补集，以及原全事件入口连接和完整误差采用清单全部保留。

## 实际检验与复现

本机Python标准库精确Fraction计算，主代理复跑：

- 16,237项真实正体积模型检查通过：三个阶段、8个几何模型乘3种资格，共24组，n=1、4、8、16、32。包括共同阈值、捕获首矩、原J、取整误差和来源权总和。
- 1,320项有限代数检查通过，验证加权稳定性与共同阈值的对差最优性，包含零行、相同/相反资格和扩大接收器数量；这组不冒充实际L1模型。
- 几何稿内嵌264项精确检查通过，包括资格/尺度阈值端点与二值不变性。
- 高捕获和列预算稿的1,116项精确检查通过；这些是有限占用模型，不认证完整原函数场。

高维同心壳的菜单本轮明确缩为17层，未把R304的更大壳菜单算作本轮执行。真实模型实现s=0、FIRST和同半径硬帽，并未实现完整原low/m/e_g历史。数值证据不替代一般证明。
