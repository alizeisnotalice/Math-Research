# 第735轮　同一来源跨接收行的联合阈值估计

固定真实接收行和较大来源的半径带。若跨行比较能把其真实所有者限制在小体积内，停止前缀求和只收一次来源权重。允许每个来源私选比较行时，两个相反响应必须同时夹住一个预先固定的参照来源。单个固定坐标上的窄夹逼给完整旧总账新增至多 \(O(\log(n+2)/\sqrt n)V_T\) 的吸收费用。尚缺对逃过全部测试的四元组积分的一致估计。
