# 第710轮　较小来源的共同交集与整行费用

开题按项目 AGENTS.md 核对公式（4）。保留第709轮未付段及同一个真实首捕见证。在同一来源体积档内，可以另取任意来源子集的真实交集，按各坐标到交集的距离给同时捕获的质量加权。所有档合计后，若有效质量占该行高损失质量的比例达到 n^(−1/6)(log n)^(1/3)，整行都可按根阶支付。辅助点只用于原权重的费用估计。公式（1）保留未付差额与完整吸收系数。

证明的关键是一维带位移权重的区间平均在 L^(3/2) 上的算子范数至多为1，故逐坐标相乘没有指数常数。压缩真实历史中，n=2^56 时每个接收点的高损失质量严格超过0.42479；所有合法见证都不满足第709轮位移判据，新判据支付了整段。该历史的整体来源预算充足。任意输入上的剩余差额仍未闭合。
