# 第721轮　同一锚点的真实接收体积与跨组付款

开题核对[第706轮指令](../../AGENTS.md)。若若干真实来源的父方体都含有点 z，总价值为 D，考虑所有从这些来源取得固定份额 δ 的接收行。各行可以选不同的合法站点、半径和来源子集。取足够大的固定参数 c 后，这些行的真实接收体积之和至多为 C(δ) exp(−14√n)D。证明先用来源所有者的不交性限制站点到 z 的逐坐标距离之和，再直接计算整批接收点所在区域的体积。极小接收半径单独合并，一次计费。

代入第720轮总账，共同来源权重达到 δ 的站点对全部可以吸收，允许同一来源出现在任意多个站点。两端尺度满足本轮定量条件时，更小的共同权重也能吸收。剩余困难是两组仅共享很小的权重、这些来源却具有较大价值，而且两端都没有触发尺度估计。一般根阶上界尚未证明。

本机与 MacBook 完成了标量估计的交叉验证。主检验覆盖九个选定维数，4096 维完整扫描 2050 个尺度档。九个真实历史块保留原参数，仅用于核对距离和尺度条件。[详细证明与复现材料](research.zip)
