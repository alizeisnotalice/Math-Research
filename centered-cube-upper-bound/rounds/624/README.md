# 第624轮：完整动作菜单与近远尺度共同预算

一般 `n^(1/2+o(1))` 一致弱型上界仍未闭合。本轮没有改善一般维数上界的阶数。

- 已审核：原动作菜单可在同一全局包络上饱和，保持所有来源同时可行；允许的是一般可测接收分配，不冒称必由单一排列实现。真实最小半径见证连接到剩余最大菜单，费用 `P3=(1+3/a)^n` 完整保留。内部菜单跳跃得到常数预算；远处大尺度生成区域的共同来源复用仍未支付。
- 窄尺度种子和远尺度冲突删除可放进一套最终不交的原星体中，来源预算只付一次。全族回代仍有约 `n log n` 个近尺度类的选择损失，只恢复粗基线，不称为根阶改进。
- 84个真实二维方体的连续接收并集为 `V=573/4`，同一连续来源和四个不交原星体严格认证 `Q*=85`。`V/Q*=573/340` 是有限族合同比；自动转成弱型下界还需 `4/9` 因子，只给 `191/255`。
- 独审纠正了把全局半径菜单当成逐点可用菜单的错误。修正后三档精确积分区间嵌套；冻结最小包络的饱和信用严格低于最大半径优先，差至少3.0516。饱和与最小方案的区间仍重叠，不能宣称严格改善。该实例的新远尺度坏域为空，尚未测试真正剩余的来源复用项。
- 本轮使用本机Python、HiGHS、Fraction和192位Arb。最终精确积分使用4个进程、保守内存低于1.5GiB，短时间结束；没有为维持占用扩大无关扫描，也没有声称持续满载。
