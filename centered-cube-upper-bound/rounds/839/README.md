# 第839轮　反复删除后的真实替代伙伴与同一见证的源割

第838轮估计了同一真实端点的候选伙伴质量。当已经支付的记录被删去，先前看见的候选也可能随之消失。本轮把两端的候选库都按当前余流重算。可以做可数多次删除，所有删除的原质量只付一次。最后留下的伙伴属于同一份存活余流。[完整 LaTeX 证明、数值笔记及复现](research.zip)

## 指南第5节的真实接收积分

在任意非负 \(L^1\) 输入 \(\sigma=|f|\,dx\) 的高度带 \(E=\{\lambda<M_{[1,2]}\sigma\le2\lambda\}\) 上，固定任意可测的真实严格见证 \(l(x)\)。固定来源割 \(A\)，令 \(\eta=\sigma|_A\)。原积分为

\[
 J(A)=\int_E(A_{l(x)}\eta)^2\,dx .
\]

按实际见证立方体里的两枚来源分配该积分，两个端点必须使用同一边长。按体积取二进档 \(D\)，令 \(a_D=(1+1/(32n))(2D)^{1/n}\)。对 \(\sum_i|z_i-q_i|/a_D\ge b\) 的长对，取 \(b\asymp\sqrt n\log(n+2)\)、\(h=\lfloor b/16\rfloor\)、\(\kappa=\log(2)/64\)。从原积分中反复删除在任一端失去足够实际伙伴的记录，合计费用至多为

\[
 C\lambda(n+1)[n\log(n+2)]^2\,2^{-h}e^{2\kappa b}\,\eta(\mathbb R^n)
 =o\!\left(\lambda\eta(\mathbb R^n)\right).
\]

对留下的几乎每条记录，以至少 \(1-e^{-\kappa b}\) 的同一条件相位概率，左右两端同时有足够的替代伙伴。这些伙伴必须出自该割、该绝对体积档和最后留下的记录。固定任一端，在同一个真实来源上能找到至少 \(c e^{\kappa b}\) 个不同见证立方体。每个立方体都有一个真实来源落在其余所有这些立方体之外。两个端点可以各自得到一个这样的家族。几何相位的随机性与输入坐标的相关性无关。

在第813轮的原双臂流上，同样证明了两端同时保留真实伙伴。这里保留端的历史和勒贝格接收位置也固定，两个原质量分母都在。可选出的中父有彼此排他的来源，并且其不交接收体积合计至多为 \(CD\)。长对条件、相位分布和候选使用的 \(M'/P_D'\) 权在报告中逐项列出。

## 尚未支付的原量

每个源割的短距离来源对和最后存活的长距离来源对仍需估计。许多不同端点的见证家族可能反复使用同一接收体积。可数删除有可求和费用，存活部分的总质量尚无根阶界。所得一般单窗结论保留给定的 \(l(x)\)，与原第813轮流的结论分别证明。一般 \(B_n=o(n)\) 和全尺度根阶弱型界均未闭合。

## 本机核验

- 正宽双臂模型分别经历3、15、63次同步删除，删去11、47、191条记录，各自留下4条。最深例中共享端的累计带权费用约为 \(0.356819\)，直接用剩余库质量的倒数则为 \(2.618210\)。三个实际格相的独立测试核对了概率和库质量恰等于阈值时的取舍。
- 同一个一维正密度输入有两个宽 \(1/2048\) 的来源包。在长度 \(1/4\) 的接收区上，真实末根为 \(3/2\)，同包、异包的原质量各为 \(1/8\)。另取同区间上的严格见证 \(l(x)=5/4\)，单包割的 \(J(A)=9/100\)，整份输入的 \(J=9/25\)。这些是低维原积分的复算。
