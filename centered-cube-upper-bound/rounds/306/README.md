# 第306轮：跨尺度失捕付款与真实森林门的尺度窗口

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮直接推进R305保留的二值低/中捕获费用：支付跨尺度失捕这一正项，完整留下近尺度差、新增捕获及半径原子；并从原森林定义定位实际资格变化的尺度窗口，没有把窄窗口当作已付来源质量。

## 已证明的全目标正项付款

在原low-pe、高m、尺度比受限目标上，保留原U、J、q、完整e_g/m、来源和历史。逐共同资格阈值theta，将二值对称差按两个接收器的半径分为：

- 大半径至少为小半径s倍，捕获从有变无的失捕项L_far；
- 同样半径分离，捕获从无变有的新增捕获项G_far；
- 其余近尺度项，包括全部等半径原子。

原J>=H、p_theta<7/8门始终保留。通过非负积分交换及真实行前缀质量不超过J，证明

L_far(s) <= s^(-n) T_theta。

这里T_theta是原实际合资格交通，非扩大首矩；全部空间、软参数及资格配置均允许。共theta积分只计一次来源。取s^n=8，接入R305的H=8d预算后得到

Lambda T <= 256 Lambda lambda d W_beta
+ 8 Lambda 积分_0^1 [B_near(s)+G_far(s)]dtheta。

d=kappa0*psi_inf/(q_-v0)，逆尺度比费用仍保留。此次付款是有限T的内部吸收，不新增全局epsilon X。另可将同一失捕项按s^(-n)A_n W_nu支付；这与内部吸收是备选，不能重复花费。

## 真实森林门与完整窗口补集

直接核回R113：H_q(t)=q max(t^n,sqrt(n)(t²/b)^n)，原轻块采用h(P)<=H_q(t)。同一原top内有distinct-child LCA且h(P)>0时，原森林排除门等价h(P)>H_q(g)。没有把整个联合资格写成独立源对门。

正确的未裁剪临界尺度为

tau_q=min((h/q)^(1/n),sqrt(b)*(h/(q sqrt(n)))^(1/(2n)))。

材料提取中第二根一度写成b倍，主代理代回原式发现后已改为sqrt(b)，独审重新核回原ZIP。q(x)可变化，未假设原接收器之间的门单调。

在两个接收器共享同一比例带、同一尺度方向时，g/R属于同一[k_min,k_max]，其比为gamma=1+1/n。定义tau_-=tau_lambda/k_max、tau_+=tau_q-/k_min，则tau_+/tau_-<=gamma(4/3)^(1/n)。森林接受半径小于tau_+，排除半径不小于tau_-。

去掉已付的R_bad>=s R_good后，剩余森林资格差的两个半径均位于[tau_-/s,s tau_+]，其对数体积宽度至多2n log s+n log gamma+log(4/3)。取s^n=8时该宽度为绝对常数。**这只定位窗口，没有支付窗口内实际来源质量。** 窗口依赖原源对，不能在FIRST中冒充一个共同窗口。

跨比例带、不同尺度方向、不同top、无distinct-child LCA的回退情形继续留在补集中。真实立方体边界、森林同时接受时其他资格差也保留。失捕全局付款已经包含森林远失捕，不再为后者重复计一次吸收。
