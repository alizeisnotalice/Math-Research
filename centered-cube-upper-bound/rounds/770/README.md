# 第770轮　将分散父对的交项分配给同一份真实外部来源

对第769轮剩下的两条实际首臂 \(e,e'\)，设父为 \(A_i,A_j\)，保留共同价的真质量 \(\mu(C_e\cap C_{e'})\) 及分母 \(m_i m_j\)。将两个父顺序的原能量合计为 \(b_{\{i,j\}}\)。每一对可从 \(X_{\{i,j\}}=(A_i\setminus D_j)\cup(A_j\setminus D_i)\) 领取费用，每个实际来源点在所有父对和尺度上合计只付 \(LG\)，其中 \(L=\sqrt n\log^3(n+2)\)，\(G\) 是第748轮的全族最优装填比上确界。

**哪些交项得到支付。** 对最大的未付总量选择一组达到最大值的父对 \(F\)，令 \(U\) 为这些父对的端点，\(X_F=\bigcup_{a\in F}X_a\)。组外所有父对均能从 \(X_F^c\) 同时全额支付，包括只有一端在 \(U\) 的交叉项。具体地，若 \(B\) 为全部原硬交项，\(b[U]\) 为两端都在 \(U\) 的部分，则
\[
 B-b[U]+LG(1-\alpha)P_0(U)\le LG\,\mu(\mathbb R^n)\le\kappa LV .
\]
这里 \(P_0(U)\) 是原父方体的最优装填，\(\alpha=e^{-r/2048}\) 来自每个父在对端扩张体外的真实来源份额。证明将全族父对与真实来源胞接成一个有限流网络。对于父族 \(U_1\)，若每一非空子族 \(Q\) 的原首臂质量 \(j(Q)\) 均满足 \(j(Q)/P_0(Q)\le\sqrt{(1-\alpha)LG/2}\)，其内部全部硬交项都通过这一付款检验。

**回到原始高负载。** 在第766轮好首臂上同时筛去 \(U\) 外的父和第769轮原行指标 \(H_e\le L\) 的部分。两者的并集只占用原来的 \(T_0/256\) 吸收额。令 \(S=\|f\|_1/\lambda\)，有
\[
 (1967/2048)T_0\le R_{770}+C\sqrt n\,\log^4(n+2)S,\qquad R_{770}\le R_{769}.
\]
欠额为零的输入直接得到原积分的根阶带对数预算。欠额为正时，割内父对的共同价落在 \(X_F^c\) 的贡献至多 \(Cn\alpha\,j(U)\)。仍缺少 \(X_F\) 内跨不同父对重复使用同一来源时，对 \(R_{770}\) 的固定比例收缩。一般弱型上界仍待证明。

**有理核验。** 三组区间模型分别穷举了 4、16、128 个边子集，共核验 149 个非空父子族的装填证书。拥挤例中每条边单独足额，合计后欠额为 \(555/2097152\)。扩大例的一条跨割边从真实补集全付 \(41/65536\)。三个模型还核对了欠额为零的情形。算例使用有限筛选门槛，Python 3.12.14 的有理数复算与记录逐字节相同。
