# 第639轮：整层捕获与直接正则全局目标

一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮继续完整独立位移、同一真实来源和全族联合预算；没有用局部机制或有限正例替代困难族的统一估计。

## 本轮决定

经原接口独审确认，可以直接估计新方体族自身的正则最优权之线性部分 Qε,new，而不必额外证明等质量的实际容量来源。准确目标是同一次完整更新满足 Vnew−R Qε,new≥cV−C√n log^B(n+2)M。新真实增量、删零、同一个 ε、全部几何约束和不增加标签数都必须保留。

原固定 N 终端与 near-S_N 反证允许这个更宽的目标；不能将 Qε 当成线性容量上界，也没有允许任意新增标签的 S∞ 终端。将来若真正统一排除困难族，一般输入恢复给 Cn≤6PH，不额外再乘一个 P。本轮尚未取得所需统一净增益，故上述仍是条件恢复。

## 已证明的估计与未付费用

- 对同一旧 AC 来源逐行最大化实际新增捕获，可由同一个完整位移同时实现。若整个旧近最优层 Fγ 的捕获至少 κM，则共同来源加旧族分数修复给真实新容量质量 B≤[1−γκ/(γ+κ)]M。这个价格经过独审；困难族为何满足该层条件，以及同一次位移的接收亏损如何支付，仍未证明。
- 线性容量严格下降须排除整个旧最优面，旧 λ 单点超载不够。得到保留完整面外价格的定量界；不可将全域极小值无价限制到旧最优面。该要求属于线性容量支路，不是直接 Qε 目标的必要条件。
- 完整新总账保留旧方差、真实重叠、接收补量、线性容量节省、删零差额与新正则信用。新正则信用只有已知上界 εVnew，不能把它作为已经得到的下界。
- 全胞腔非负二次修复的精确耗散身份有效，但尚无能支付接收亏损的统一能量下界，因此仅简记为保留候选。

## 实际计算与证明范围

1. 对上轮一个真实旧族，精确有理几何说明所有 maximal cliques 均含同一标签，故其线性容量对全部允许位移恒为 M。这解释此前容量不变，停止在该输入上寻找线性下降。
2. 构造任意 n≥2 的真实 AC 五环模型，同一次合法位移形成新公共交，容量从5m/2降到2m，而接收体积不变、旧方差为零。完整来源、公共交、匹配 packing/cover 均给明确公式。它总是非困难族，不能推出一般上界。
3. 使用指定 Python 环境与 Fraction，精确验证 n=2,3,4,8,16,32,64,128,256,512,1024 共11例。初版方差表达式存在整数转浮点问题，已拒绝原数值证据、修复并重跑；修复后的代码加入类型断言。
4. 五个冻结动作比较新 Qε 与 Qlin。五环两个动作均由精确 KKT 证明 Qε=Qlin，没有额外正则信用。另三个有理替代几何通过完整顶点枚举证明正则信用严格正并给有理上下界，但不认证原始代数几何的同一结论；80位求根值与残差只作浮点证据，近临界接触尤其不能外推。

主代理在独立临时目录完整复现上述检查，通过11例精确参数记录、旧几何、2个精确新正则 KKT 和3个替代几何的精确字段核对，整体约0.728秒。11个独立进程的批次约0.060秒；五动作比较约0.245秒。机器实际15逻辑核、24 GiB；本轮任务很短，没有声称持续CPU满载。未运行 MATLAB、Arb 或编译PDF。
