# 第811轮　两枚实际交价的同步搬运与跨中父的稀疏接收区

本轮从第810轮余量的同一份真实联合记录出发。保留中父、两枚原交价、实际勒贝格接收点和原全度分母。对所有中父和物理尺度同时证明了下述付款，新增总费为 \(C(LV+(n+2)S)\)，其中 \(L=\sqrt n\log^3(n+2)\)，\(V\) 为不交接收所有者总体积，\(S=\|f\|_1/\lambda_0\)。[详细 LaTeX、数值检验和精确复现](research.zip)

**同步搬运。** 若一枚真价可在保留原实体父资格的条件下把比例 \(a\) 搬到勒贝格体积，另一枚可搬比例 \(b\)，两臂可共用一次随机门，以 \(\min(a,b)\) 保住两端。允许试探点偶尔离开实际小父时，按其真实命中率计费。将两枚落点的联合分布分别按边际估计，用一次接收重数的三次矩支付全部中父。该三次矩来自立方体维数一致的强 \(L^{3/2}\) 定理。每个物理八度可以按输入选择公共膨胀方向。[Bourgain 原文](https://arxiv.org/abs/1212.2661)

**余下真价必须频繁看到同一片稀疏区。** 记 \(\ell=\log(n+2)\)，\(\mathcal H=C_0(1+C\lceil\sqrt n\rceil/\ell^2)\)。每个八度 \([R,2R)\) 合并全部中父的来源，再作一次随机平移后的 Hall 分配。在细门 \(\theta=\mathcal H/L^2\) 下，所有八度的坏目的区 \(U'_O\) 的勒贝格体积合计至多 \(C\theta\ell S\)。每条未付记录至少有一枚真价，同时落在原来源的公共停区和该中父、该方向的停区，而且从此价出发，以至少 \(1/4\) 的概率平移到 \(U'_O\)。位移会在约 \(n/(512\ell)\) 条随机坐标上达到半宽 \(\ell R/n\)，其余坐标也保留半宽 \(R/(2n)\)。同一八度所有中父和方向共用这片 \(U'_O\)。较粗的门 \(\mathcal H/L\) 对两枚价均有相应约束。

**一般上界仍待证明。** 已进一步支付公共稀疏区在真实中父接收点附近占比足够大的整条停后历史。未付情形要求两臂在停源上的真实质量乘积仍大，稀疏区在中父接收者附近的占比却很小。原 \(Q_{772}\) 的吸收系数仍是 \(\delta_0<1\)。小勒贝格体积还不足以控制可集中的来源测度 \(\mu\)。

- 四维跨档模型允许搬往所有兼容成员胞。在同一可行流上，独立门的双端通过率约为 \(0.00032223\%\)，同步门约为 \(0.15338458\%\)。
- 保持膨胀体积相等，四维全域均匀可搬比例在等向、薄交方向优先、横向优先三种方案中分别为 \(0.00119686,\ 0.00235514,\ 0.00002490\)。门为 \(1/512\) 时，薄交方向优先使这份跨档母量的两端全部处在可供类型，实际通过还须乘门槛。
- 另作 18 组平移后公共来源池检验。四维门为 \(3/32768\) 时，较大的对称位移使可用双父资格下降到 \(0.466325\)，同时消除了坏右域，最终同步通过率由 \(4.81746\times10^{-6}\) 升至 \(4.26934\times10^{-5}\)。这项实验使用离散位移并单独记录原父资格。
