## 本轮改变了哪条路线

第61轮提出的“保持原子到好集距离以内，改善总密度高度到多项式量级”现已被严格否定。取 H=W=1，在 {±1/8}^n 的各顶点放质量 2^(-n)。每个原子到原好集的距离恰为 1/4；允许目的地的并集体积只有 (3/4)^n。因此任何保质量的局部分配都必须具有至少 (4/3)^n 的总密度高度。两次同距批量捕获均准确处理，此反例不依赖数值近似。

原局部容量常数现在满足 max{2,(4/3)^n}≤Γ_n≤3^n；第61轮有效的上界仍保留。还证明了所有子集容量的上确界可归约为所有完整来源的容量上确界，但分母必须保留局部小方体并集，不能换成整个超水平集。

对同一反例，将允许位移放大 α 倍后，最小总密度高度可精确计算：α≤1/2 时为 α^(-n)H，α≥1/2 时为 [4/(1+2α)]^n H；相应最小总 L² 范数平方也得到精确值。α=3/2 时存在高度 H 的显式分配。**这只修复了反例，不是一般来源的充分定理。**

任意高度不超过 βH 的目标及任意正耦合，都有至少 [1−β((1+2α)/4)^n]_+ 的质量比例必须移出 α 倍局部范围（α≥1/2）。所以固定 α<3/2、β 为多项式时，几乎全部质量都必须移出该范围，不能只给少量例外质量收费。位移或密度范数下界没有被误当作有符号误差或弱型常数下界。

## 真实体积与数值检验

对实际顶点来源，推导了全尺度精确捕获公式、径向边界公式和正概率递推。按事件半径分段后，体积积分的被积函数是至多 n−1 次多项式，故 Gauss 阶数至少 ceil(n/2) 在精确算术下无截断误差；实际浮点运算仍未做区间认证。

64维真实超水平集体积/W 的浮点结果约为 0.827884645，对应总质量/体积约为 1.20789775；这与局部并集的指数容量完全不同。未从有限维结果猜测一般阶数。
