## 经独审的完整覆盖限制

对每个实际接收点，原历史保证其共同core内包含该点的来源率≤1。只取全部来源均避开该点的组合，仍有 (T_*−1)^k V/k!≤D_out。实际参数k/T_*<1/40，故覆盖权重至少保留39/40。这不支付D_out，但合法加入了所有来源都避开接收点的几何约束。

将每个外部来源按其首个违反坐标和方向分类。共同交点保证同一坐标不可能出现反向，至多n类。生日碰撞估计并显式扣除重复同一来源后，可进一步限制为含两个不同来源同向的组合，仍保留超过97/100的完整覆盖权重。

该对来源确有一个坐标的expanded-center包含关系；**其余n−1个坐标没有因此成立**，原完整admission不能直接付费。删除来源后的几何单调性和真实owner双积分均保留，但新增pair的共同点、首次组与全部坐标费用仍待证明。下一步直接攻这份完整pair预算，不以概率碰撞本身当付款。
