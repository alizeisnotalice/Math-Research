# 第773轮　两次真实交价上的跨中父接收预算

沿用第772轮的同一最大欠额割、同一可付款来源和同一批真实峰。每个峰从小父经中父到另一小父，两跳各有一个实际交价。先扣除两个交价上可按来源负载直接支付的部分；再固定两价和两个端点，用真实勒贝格接收体积为所有相容中父分配一份合计预算。两方向共用这一估计，每个中父保留原路径上的真度分母。

**已证的部分估计。** 令 \(V\) 为实际接收所有者总体积，\(\ell=\log(n+2)\)，\(L=\sqrt n\,\ell^3\)。在每份原输入上，将第772轮剩余峰量分为已付和未付两项，有

\[
0\le Q_{772}-Q_{773}\le C L V,\qquad
T_0\le C\sqrt n\,\ell^4 S+C\sqrt{\ell S Q_{773}},\qquad S=\|f\|_1/\lambda.
\]

一个体积桶的接收预算不足时，另一桶可把未用完的份额付给它。论证先按两次交价汇总所有中父，再开一次平方根。原筛后两跳不一定条件独立；乘积结构只用于筛前的上界。

**尚未支付的质量。** \(Q_{773}\) 仍按原峰权积分：两个真实交价都在同一可付款来源中、各自负载都超过 \(L\)，而合计预算和该中父所在桶的预算同时不足。本轮没有证明这部分在所有输入上满足根阶界或固定比例收缩。因此一般 \(n^{1/2+o(1)}\) 一致弱型上界仍未证明。

**计算改变了哪一步。** 在一个两小父共同来源质量为零、两个中父各贡献正质量的二维模型中，有一批峰逐桶不能全付，但合并可以付清；另一个实例则须保留能单独支付的桶。另以本机 Python 对22条一维正权峰按路径、按交价独立积分，均得 \(4115/442368\)，并精确核验13,104组有限分配。这些模型没有实现原极值割及全部上游筛，不给出一般余项的相对大小。
