# 第339轮：外侧来源质量窗与真实双壳积分

**一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。** 本轮新增一个保持原J、原ell和真实来源的外侧交通预算。

令W=∫f。原外侧积分中大端m_u≥ηW的全部交通满足 `G_heavy ≤ [1+log(λ/(ηq_-))]W`。质量窗约束真实接收半径，原完整尾贡献精确为1。取η=exp(-√n)新增来源费为 `[1+√n+log(4/3)]W`。故338的完整hard槽式变为：

`B_H(f,ν) ≤ G_out_light + 2εXq + [C_(ε,n)+1+√n+log(4/3)]W`。

其中C为338既有根阶系数，light严格保留m_u<exp(-√n)W以及原高过去、远质量比、外侧中心和全部时钟门。该剩余项仍未付。组件局部化必须有真正源隔离，不假设有利划分存在。原入口、软层、尺度和历史时间预算全部留账。

本机已实际复跑：真实dx双壳中心分割11920项精确检查；选窗包络538项Fraction与640项普通Decimal检查；几何窗946项普通浮点断言及469项误差记录。双壳内外之和精确恢复338原量。新门ε=1下n36/64/100的外侧中央贡献均非零，ε=1/2下n100也非零；来源区域占比极小，结果只是全来源积分的正下界，不是全局极值。每数值行取H≤该行h；不提供H>h时相同数值。主回代的最终小ε未以该例验证。

多窗共享包络为辅助预算，全旧质量范围仍需O(n)费用；逆序packing不是新付款。独审通过。[研究包](research.zip)含详细LaTeX源（不编译PDF）、主稿、总账、独审与必要复现材料。解压后用Python3运行r339_numeric.py、r339_core_checks.py、r339_geometry_checks.py。承接[第338轮](../338/README.md)。仅新增两个仓库文件并更新索引。
