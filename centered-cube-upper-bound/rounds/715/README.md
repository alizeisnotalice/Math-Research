# 第715轮　真实来源的坐标释放与全局分配

开题核对[第706轮指令](../../AGENTS.md)。当其余坐标仍保留固定正量的真实近来源权重时，可以在选定坐标上各自由移动半个接收半径。每个体积分组允许多项式数量的坐标选择，每个选择同时释放至多 (1/2−δ)log₂ n 个坐标。对所有接收者、见证和尺度统一结算后，这一新通道所用的真实接收体积至多为 O(D/n)，其中 D 为原贪心装填价值。它可以直接加入第713轮的联合分配。完整积分仍有一个尚未支付的最大割缺额。

另外，沿实际终端胞元，任一命中来源的体积至少为接收方体体积的 exp(−O(1/√n)) 倍，包括全部微小更新。九组真实双中心历史经本机 Arb 256/384 位计算及 MacBook 独立 Decimal 选项复算，展示了首次捕获见证与终端见证可以分离。
