# 第63轮：正方体约束压缩与非局部有符号余项

日期：2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**；保留的全一般基准为 O(n log n)。

本轮承接第62轮局部支撑的指数容量反例，检验一般非局部替换与有符号对偶路线。

## 已证明的结果

- 对固定正原子支撑和原好集，全部中心方体正约束精确等价于有限捕获模式容量约束；给出有限 Farkas 对偶证明，保留总质量约束和全部中心、半径的几何下确界。计算复杂度可能随原子数指数增长，没有把有限抽样当作全约束认证。
- 对单原子及任意高度不超过 beta H（beta>=1）的正密度，有符号误差的 L² 范数平方至少为 Hp/(180 beta)。因此零缺陷替换不成立，但该下限不否定所需上界。
- 先取正部的收费法加入总质量截断后修复单原子的远场对数，却仍在真实分离多原子上付出 log N；优化单点覆盖可以消除该例的损失。一般优化覆盖预算仍未证明。
- 在 n>=2、位移放大3/2的真实顶点输入上，“从同一源点重抽直到进入原好集”的机制具有至少 W exp(c n) 的占用量及 H exp(c n)/4 的终端密度本质上确界，c=KL(log_2(3/2)||2/3)>0。该结论仅否定该重试机制，不否定移动过程、一般重分配或弱型目标。
- 给出移动链保留存活质量余项的准确有限时流恒等式，以及原好集实际接受概率的正递推和分段多项式积分。
