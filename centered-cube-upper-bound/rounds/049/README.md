# 第49轮：固定原子数取到性、共同位置应力与插入障碍

## 已证明的推进

固定最多N个原子时，最佳全尺度弱常数 C_{n,N} 在位置、权重、阈值上联合取到。方法是按真实共同阈值可行超图选归一费用最高的分量，再归一质量和位置；所有位置可放入 [−(N−1),N−1]^n。允许零权与碰撞的单阈值盒并体积连续，给出紧集最大者。紧区域依赖N，未证明全原子数族紧性。

删零、合并碰撞后，同一个可达分支混合同时平衡来源、阈值和自由位置变分。位置有向面积平衡进一步给出每个坐标轴恰占总通量的1/n。来源后验边际仍正确；未假设这些标记独立。一般常数可由这类真实联合最优源逼近，仍缺独立于N的总通量上界。

另严格否定把旧面混合当作新原子插入导数的接口：真实两等权原子中点插入时，旧混合势为1而导数为0；远处插入新分量时旧势为0而导数为1。固定N满支撑也不允许免费添加第N+1个原子。这些反例不否定主目标，只排除错误变分步骤。
