# 第559轮：真实质量相位筛选与完整探索平方

**一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未证明。** 本轮得到一项经过独审的完整场估计，仍有线性维数因子；不将其描述为全局根阶改善。

沿R520/R558冻结合同，原中心测度为Lebesgue，原盒边长为R_B，旧质量m_B=q_BR_B^n，q≤q_B≤λ，r_band=λ/q。保留全部bulk、真实源格、原权t_B≤S、实际质量窗和相位。完整探索律为

\[
\nu_G(dg)=p_G\,dg/g+p_G\delta_G,
\qquad p_G=(1+\log G)^{-1},\quad 1\le g\le G.
\]

固定真实接收坐标(y,σ,j)，所有有贡献父的旧质量必须在
\[
[\gamma^{\sigma-1-(j+1)h},\gamma^{\sigma-jh}]
\]
内。先保留该筛选，再对完整膨胀律积分，得到
\[
Z_{ij}\le p_GC_*(G),\qquad
\|Z\|^2\le p_G^2 C_*(G)S A_nW,
\]
其中C_*=S[1+log(Gγ^(1+h)r_band)]、A_n=1+nlog(b/a)、W=||f||₁。没有薄壳密度假设，没有遗漏端点原子、相位或跨父Gram交叉。

R520母账对任意覆盖全部bulk的合法概率族成立，因此可以直接选择该Z：
\[
\frac QW\le\frac1{(1-\beta)^2}
\left[\frac{G^2J_{\rm ph}C_*(G)SA_n}
{(1-3h)^2(1+\log G)^2}
+\frac{2CS(1+2G)}{1-3h}\right],
\qquad R_*\le2\sqrt{D_{\rm clk}WQ}.
\]
这一步不需要先执行优化迭代或假设全行动价格缺口小。若保留另一个既定近优场，其附带比较仍须(1−θ)^−2，不混用两个结论。

新估计比同G的旧探索场平方界多一个p_G，但不能靠放大G消掉A_n。令x=logG、c₀=1+log(γ^(1+h)r_band)，实际母账因子满足
\[
\frac d{dx}\frac{e^{2x}(c_0+x)}{(1+x)^2}
=\frac{e^{2x}[1+x+2x(c_0+x)]}{(1+x)^3}>0.
\]
本轮因此停止继续优化共同膨胀律。保留实际μ交集、窗重叠和相位后，REPORT.tex式(16)明确列出同一来源跨旧绝对质量层的正总和；中心层互斥和最多三层窗重叠仍不能支付该总和。
