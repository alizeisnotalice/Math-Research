# 第81轮：共同硬首达、来源几何与全尺度返回

日期：2026-10-11。核心目标 **未完成**；全一般保留上界仍为 O(n log n)。

本轮将软层先合并，再直接使用硬立方体平均与真实平滑基线之差。固定物理窗口的最简已付条件只有初始硬平均和连续平滑最大值，费用为 `[4+2(log2)sqrt(7n/3)]||f||1`。余下共同硬首达有长至多 log8/n 的近期硬面表示，但大近期余量自动成立，并不是稀有性证明。近期硬壳的完整强来源包络仍精确等于7/8+n log2。

已建立来源占用的雅可比／多重覆盖恒等式，并用真实 L1 输入排除过强的收缩覆盖、逐来源统一控制及单一整包 duty。共同来源分组有合法容量和有限 LP 证书，但其一致廉价性未证。

Naor–Tao 原文的端点局部化现已严格核验：一般 `[1,2]` 窗口弱界仅另付 O(log(n+2)) 即返回所有尺度，没有额外 n 项。**剩余核心是同一真实首达接收集合的一般弱体积，或等效的来源质量加权几何费用。**

## 交付与复现

`research.zip` 恰有7个成员：`proof.md`、`proof.tex.txt`、`endpoint_probe.py`、`endpoint_results.json`、`packet_probe.py`、`packet_results.json`、`inventory.json`。报告含完整论证、证明状态、反例、数值笔记、原文页码和精确剩余接口。LaTeX 源只做静态检查，未编译、未生成 PDF。

解压后执行（仅 Python 标准库；实际为3.12.14）：

```sh
python3 -B endpoint_probe.py
python3 -B packet_probe.py
```

`proof.md` 的六个 Python 代码块依次为 parent、soft、hardface、coverage、localization、audit 守卫，提取到同目录运行。两个主程序由主代理独立重放、JSON逐字节一致；六个守卫实际执行通过，另从最终归档提取独审验证可移植性。完整回执、输出和哈希见 `inventory.json`。

- E2端点：7组正 L1 输入、21个精确硬首达接收点、63个端点记录；独审检查411个完整多项式、2854个直接重叠值、169个前缀排根、126个年龄区间，以及21个硬近期／旧通量区间。平滑背景和连续门槛仍有明确数值范围限制，n16 粗硬面求积约5%的失败保留。
- 共同分组：有限有理噪声模型11个实例、2992个完整空间单元、44个有理 LP 上下界，12个完全相等，最大间隙约9.54e-10。核验原始有符号赢家、背景、来源容量、价格和弱对偶；这不认证连续 E2 或主剩余事件。
- 解析接口各有三阶段守卫。有限精确证书、浮点诊断与一般证明严格区分，不以有限结果猜测维数阶。
