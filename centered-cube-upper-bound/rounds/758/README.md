# 第758轮　全部下降路径的接收费用和中间父的来源覆盖

第757轮留下三步流量 \(Q_3^{\rm out}\)。本轮在同一份流量上证明了两项根阶付款。

**较晚的接收点返回任何较早的父方体。** 对每个较晚位置，从它的不交所有者中抽一个真实点，用这同一个点检验所有较早父方体的指定扩张。把命中量按所有位置对和全部链长相加，甚至给长度 \(k\) 加权 \((17/16)^k\)，总和仍至多 \(C K L S\)。证明使用整父真实质量的转移、第一步的点态帽，以及对一个固定中心对称凸体的维数一致强 \(L^2\) 定理。三个以上时间点共用的来源和接收均已进入同一和式。[Bourgain 原文](https://repo-archives.ihes.fr/FONDS_IHES/I_Prepublications/BOURGAIN/1984-1989/M_84_58/M_84_58.pdf)

**一个中间父的一侧来源可以覆盖。** 三步链有两个中间父，每个父都有实际入价和重新抽取的实际出价。只要其中一侧有一半生存质量满足下列任一种覆盖，经过该中间父的整批三步流量就能支付。盒的位置可依父、位置及方向分别确定。

| 每个覆盖集的最大 \(\ell^\infty\) 直径 | 可用的覆盖集个数 |
|---|---:|
| \(s_t/n\) | \(\lfloor\exp(\sqrt n)\rfloor\) |
| \(s_t\log(n+2)/(64n)\) | \(\lfloor\exp(n^{15/32})\rfloor\) |

费用是 \(C\sqrt n\,S\)。证明把轻片的实际来源相加，较重片则在原输入上共用第747轮的来源分配。盒数没有在接收费用上再乘一次。

令 \(R_3\) 为两种付款之后的真实三步流量。对余下的链，两个中间父各自的入价、出价均无法用表中的任何一组覆盖取得一半生存质量。每个较晚接收点还须同时逃出所有较早父的规定扩张。共同总账为

\[
\frac{277}{3072}T_0+\frac{\mathcal D}{3}\le 2\cdot256^3 R_3+C LS .
\]

**一般上界仍待证明。** 尚需控制四侧价格同时分散且所有晚接收点均外逸的 \(R_3\)。这里 \(S=\|f\|_1/\lambda\)，\(L=\sqrt n\log^A(n+2)\)，两项付款均允许 \(A=0\)。
