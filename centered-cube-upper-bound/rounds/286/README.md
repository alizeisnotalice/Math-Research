# 第286轮：实际双捕获的根阶付款与守恒随机几何分割

一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界尚未闭合。本轮新增一个已独审通过、接到原实际积分的根阶多对数已付分支。另一随机几何构造给来源守恒，但仍有额外n^(1/4)价格，不列入根阶账。

## 主命题与证明
对原近邻来源对定义 M(z)=ρ(B₁(z,r))、N(y)=ν(B₁(y,r))，r=a/(16√n)。原实际软核为p_y，硬核为h_z，F_z是ρ在B₁(z,r)的实际软响应，G_y是ν在B₁(y,r)的实际硬响应。正贡献边上令 cρ=F_z/(M p_y)、cν=G_y/(N h_z)。软比值可以超过1，硬比值是实际捕获比例。

在 cρ≥θρ、cν≥θν 上，原响应帽 F_z≤q、G_y≤4λ 给每对来源高度 p_y/q≤1/(θρM)、h_z≤4λ/(θνN)。用第285轮直接软点弱界B和硬点弱界1，以及两帽乘积与I(Bx,y)≤x+(1+logB)y，再对精确倒数邻域边缘积分，得到每个物理时钟的真实dx积分

T≤16Wρ/(3θν)+(1+logB)Wν/θρ。

没有新来源比较、覆盖重数或κ因子。令θρ=θν=1/log(n+2)，保留原完整两份后验、显式R₂≤D门和ns≤D，在原行估计score后再换物理时钟，唯一j保留至求和，原交通费用是

2Λ B_D log(n+2)[16Wρ/3+(1+logB)Wν]，B_D≤4√(nD)。

当D=O(log(n+2))、B=O(log⁴(n+2))时，这是根阶多对数价格。只对第285轮未付双高邻域质量部分应用，不重领此前已付分支。外层来源权重沿原终端账汇总；D等参数变化时须留在外层平均内。全部细节和显式常数见proof.tex.txt及作者/独审文件。

## 精确剩余问题
令I_dense为第285轮未付双高原交通，保留原ρ≤β≤α≤fdx、独立ν≤fdx、全部来源切分、实际high/FIRST/capture/history、真实dx与时钟。新未付部分精确为

I_dense·1{cρ<θ} + I_dense·1{cρ≥θ,cν<θ}。

没有证明它小，也没有证明新分支占有任何正比例。下一步需要对这两个低捕获分支证明平均来源预算，或给出有价转移。有限检验不能认证一般捕获覆盖。

## 独立几何工具与未达标价格
以μ=ρ/(4λ)+ν/q_-抽取独立同分布锚点，每个来源点分给第一个2r邻域包含它的锚点。几乎必然得到Borel不交来源分区；两种原来源各自总质量完全守恒。近邻对同簇概率精确等于其2r球交集μ质量/并集μ质量，交集至少J=M/(4λ)+N/q_-。

在并集质量U≤KJ的几何门上，实际双帽和半径2r的包估计给原总价

2Λ K(6+2n^(1/4)) B_D[16Wρ/3+(1+logB)Wν]。

此界独审通过，严格避免锚点来源重复收费；但是K未被一般控制，且κ仍带n^(1/4)。所以它只是n^(3/4)多对数工具，不从上述根阶未付账扣除。若要用它闭合，须改善实际双包乘积或总几何价格。未开展额外反例排除战役。

## 本机三阶段验证
主代理实际重跑本机Python Fraction与mpmath1.3.0脚本：

- 初探：16项精确边缘恒等式、17项双捕获门边核验、64个两帽标量实例；
- 不等权与多尺度压力：96项边缘、493项门边、256个标量实例；
- 扩大范围：192项边缘、2584项门边、1024个标量实例，质量及λ范围10^-15至10^15，B最高10^50。

有理边缘、响应帽与门高度无误差。标量分段积分以40/60位复核，最大归一化公式误差约4.47e-41，跨精度差约4.37e-41，无价格违反。另三阶段精确枚举2、24、720个加权首锚点排列，核验4、10、14个近邻对，同簇概率和来源守恒精确成立。模型为有限原子/代数模型，不是连续L1共同历史，不是区间证书，也不证明一般阶数。阶数与结论依靠解析证明及独审。
