# 第577轮：切分粒度障碍与基础来源预算修正

日期：2026-10-24。一般 n^(1/2+o(1)) 一致弱型上界仍未闭合。本轮纠正一个过强的完整残余切分合同；得到全维解析障碍与同族的解析修复，但没有得到新的一般几何预算。

## 决定研究方向的结果

在固定原始高核覆盖 H₂ 下，保留完整质量带所有实际见证，定义 v(I)=λ|R_I| 与有符号切分费用 D=v(I)−v(I⁻)−v(I⁺)。原合同试图要求每个正残余组件存在坐标切，使 D≤C n^(−1/2)ΔΦ。

对此，n个质量1/n的轴点 z_i=(5/4)(log n)/n·e_i、完整带[1,1]给出严格障碍：原贪心高核的最大块基数渐近为2n/5，原H₂之外仍有 Θ(n^(−5/4)) 接收体积；每个坐标切只能剥离一个原子，ΔΦ=Θ(1/n)。因此所需C至少增长为n^(1/4)，固定对数损失也不能修复。这只否定过细的逐切合同，不反驳一般弱型目标。

主代理将势修正为

    Ψ(m)=(m−a)₊ + b ∫[a,U] (m−t)₊ dt/t，a=L/2，b=1/√n。

它先保留一份基础来源质量预算，跨层部分再争取根阶节省。若能证明统一的非平凡共同切分 D≤CΔΨ，完整树总费将不超过 C[1+b log(2U/L)]W，足以经原完整单带恢复达到目标允许的对数损失。该切分存在性仍未证明。

修正势在上述轴点族上解析满足 D≤ΔΨ，常数1；所以旧障碍已被实际修复，不能继续作为新势的反例。对一般来源，仍缺真实接触质量、接收体积与重叠收益的联合比较。共同投影切面公式只准确定位这一缺口，不算一般上界改善。

## 实际验证

- 六源固定几何：三个完整带、各63组件，共390个真实坐标切；精确根式保存D，Arb192核势及最优比较。所有超上限祖先和零D切保留。此模型无负D，且两势的最佳切集合相同，不能认证重叠节省。
- 轴点标量：n=256、1024、2^16、2^32、2^64、2^128，Arb512核全部守卫和严格上下界。后两点的旧比值下界分别约70.18和459万；新势比值上界约1.53×10⁻⁵和2.33×10⁻¹⁰。没有枚举巨大来源集合，有限数值不替代全维解析证明。
