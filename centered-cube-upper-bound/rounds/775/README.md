# 第775轮　两次真实交价的共同接收预算与来源集中

**一般中心立方体极大算子的 \(n^{1/2+o(1)}\) 一致弱型上界仍待证明。** 本轮在第774轮同一份最大欠额割和原峰上，同时更换两个小端，再把能连接这两个新端的全部中父合计。两次实际交价各自留在原位置，中央真实度数 \(d(e)\) 只作一次分母。由真实接收者不交和方体极大算子的强 \(L^2\) 界，证明了所有中父可合用一笔 \(CLV\) 的预算。这里 \(L=\sqrt n\log^3(n+2)\)，\(V\) 是实际接收总体积。该预算可以支付部分逐个中父估计会漏掉的质量。

**几何估计。** 把每侧真交价按中央方体实际接收者的位置平移。对每个物理半径八度 \(O\)，按所有真实接收体积预先确定一个集合 \(\Omega_O\)。保留下来的平移价都在其中，对任意固定 \(p>1\) 有 \(\sum_O|\Omega_O|\le C_p L^{-p}V\)。对任意固定 \(b,M\ge0\)，平移后原来源在相应接收集反射上的平均密度至多为 \(L^b\) 的份额，合计至多 \(C_{b,M}L^{-M}V\)。同样的估计还支付了所有中父在落点上的合计密度相对于几何权重不超过 \(L^b\) 的份额。这里的来源积分始终用 \(\mu=|f|\,dx/\lambda\)。

**总账。** 设 \(\ell=\log(n+2)\)。对第774轮全部旧伙伴仍合格的峰，记本轮实际抽样并分数付款后剩余的质量为 \(R_P\)。对任何固定 \(0<\varepsilon\le1/2\) 有

\[
0\le Q_{774}-R_P\le\varepsilon Q_{774}
       +C_\varepsilon\sqrt n\,\ell^6 V,\qquad
T_0\le C_\varepsilon\sqrt n\,\ell^7S+
       C_\varepsilon\sqrt{\ell S R_P}.
\]

若直接作用于较大的第773轮原峰，无须预先形成第774轮的两侧伙伴组，相应的两项线性费用分别为 \(C_\varepsilon\sqrt n\,\ell^3 V\) 和 \(C_\varepsilon\sqrt n\,\ell^4S\)。**尚缺的是超过端点共同预算、两侧来源都高度集中时的原峰总量。** 同一旧伙伴组的私价平移后仍互斥，来自不同原峰的平移接收集合却可能重叠。报告式（17）列出保留真实体积分母的交项。

**复现。** 用本机独立 Python 和有理数核验。12个父区间、14份历史的有限模型中，按原峰和按两个新端求和在292个正质量三元组上逐项相等。严格秩的四种阈值、同端点跨中父合算、真实所有者平移前后积分均有独立复算。这些算例没有施加原高维极值筛。[详细 LaTeX 证明、证书与复现脚本](research.zip)
