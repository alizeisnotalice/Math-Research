## 结论与范围

保持任意有限正标签、原全尺度好区 H₂、完整带 [L,U] 和全部实际见证。固定共同坐标序，删除见证首标签形成核心 K；重单标签由原 H₂ 支付，其余孩子具有半质量核心。按核心质量递增，C_K 已由低质量初始项、原好区或较小核心组覆盖。把同一核心的全部孩子一次合并，壳费中的逐孩子质量和可换成最大新增质量 Δ_K，保留旧覆盖收益与外包盒未被实际孩子使用的收益。初始费≤2W，没有隐含的核心购买费。

另一算法只有真正支付并加入整个外包盒后，才复用相同坐标包围盒的既有覆盖。原实际孩子升质量处理，同盒增量区间不交；完整账为 J≤2W+[n^(-1/2)+(1+log2)/n]Σℓ_B−Σg_e。g_e 是真实旧覆盖收益，所有外包部分实际付款。单标签前置、零测剩余免费加入以及全部质量区间均已独审。

这两种算法仍缺少不同核心、不同包围盒之间的累计来源预算。对于包围盒闭合核心，同盒合并就是同核心合并，不能重复计算收益。核心内部的填满下降可能返回原见证；收费转移正负相抵，并无全局耗散。详细报告保留准确量词和未证步骤。
