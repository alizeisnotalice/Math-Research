# 第574轮：任意交叠来源簇的全尺度重核心覆盖

日期：2026-10-24。一般中心立方体极大算子的 n^(1/2+o(1)) 一致弱型上界仍未完成，本轮不宣称一般维数阶已经改善。

## 独审通过的全局付款

对有限正原子输入，把每个真实来源子集S对应的全部尺度接收区域写成盒C_S，其实际质量为m_S、阈值边长r_S=(m_S/λ)^(1/n)，坐标乘积比例为β_S=λ|C_S|/m_S。

按质量递减，从全部β≥b的来源子集中贪心选出来源不交的一族U。它们覆盖全部来源标签，形成一个划分。将每个U的来源包围盒向各侧扩张A^(1/n)r_U/2，得到共同覆盖H_A，严格有：

    λ|H_A| ≤ A W/b。

任何S，只要含有β_K≥b且m_K≥m_S/A的真实子核心K，其整个C_S便在H_A内。此结论允许来源簇任意交叠，跨全部质量层和尺度一次付费，不再假设给定森林，也不要求S包含于选中的U。

取A=2、b=1/√n，可支付含高β半质量核心的全部接收区域，费用≤2√n W。真正使用的方体结构是各坐标的乘积恒等式(1−q)(1+q)=1−q²；没有把来源质量当作薄层体积。

## 明确保留的完整缺口

H_2外每个实际见证S的所有半质量子核心都必须低β，且S至少遇到三个选中来源块，每个相交块的质量小于m_S/2。

这些必要约束尚不能支付剩余接收并集。共同核心增量已有小系数，但任意交叠标签之间反复使用同一来源的总费用没有得到统一控制；不能仅凭来源以前出现过就减去重组核心的接收体积。

两条条件总账分别保留：

- 若全部尺度剩余预算为D_n W，则一般L1可直接恢复常数2√n+D_n。
- 若只有完整单质量带剩余预算，则经R571实际局部化得到16e+(4/3)N_n(2√n+D_n)，N_n=2+ceil(log2(32n²))。不同局部来源的好区不能无证合为一份费用。

上述D_n均未证明。旧Φ/Ψ母账保留，不通过新记号默认删除历史或其他未付项。
