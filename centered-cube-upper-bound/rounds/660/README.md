## 数学结果与完整费用

从任意有限轴平行方体族及真实 Lebesgue owners 出发，使用实际已保留的前缀负载构造同一组共同 packing 权。它在所有有限族上可行，并逐行支配旧的原始负载阈值构造；旧断点不是新构造全部断点。

对完整饱和前缀按实际尺度分类，严格得到全族一次付款
V_far ≤ 2 exp(33/32) U/τ。
这里 U 是同一解的实际保留体积，P≥U/τ，完整账为 V=U+V_far+V_near。远尺度不再按行重复领取来源费用。

多个阻挡点共享同一批真实来源时，方体坐标乘积给出接收并集 ≤ exp(−B) U_I。在 n≥16、2 log n≤B≤n/2 及共享来源尺度比≤n 时，证明覆盖完整允许参数范围。该合并本身不含组内标签数费用。

**剩余缺口：**尚未构造覆盖全部近尺度损失且来源总价受控的全局分组。分开应用局部合并会重复使用同一来源；本轮没有将条件证书当作一般结论。阈值 τ=8√n 下 V_near≤A U 是下一项未证充分命题，并不预设该算法必然能完成原目标。
