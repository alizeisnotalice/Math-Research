# 第539轮：完整接收域的临界分隔面与联合质量损失

**一般根阶上界仍未闭合，本轮没有新的已付款上界。** 保持全局极值几何主线，不以更多局部工具或六原子最优常数替代原任务。

已证明并独审：完整接收并集的单侧变分必须同时计入外面变化、内部接缝裂开及零宽开口。固定质量位置极值满足 `U ≤ L`，其中 L 为集体比例撤质量的真实首阶损失；同侧共面标签取最慢收缩速度，有穿过盒则屏蔽，内部裂缝双侧都计费。

有损失的分隔面中心满足全部尺度质量帽 `μQ(y,s) ≤ s^n`，邻接临界尺度取等号；使用闭立方体，边界原子未遗漏。来源在临界立方体内的径向概率满足 `(s/r)^n` 上界。这给出真实联合约束，但来源重复收费仍未控制。L 的根阶界仅是可能更强的充分路线，未证必要或等价；逐源损失相加是下界，不能冒充上界。目前仅有指数粗帽。
