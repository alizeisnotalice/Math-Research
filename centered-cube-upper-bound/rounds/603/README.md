## 全族结论及其范围

固定原λ及α=θ/q，q≥max(2,C_n/2)，0<θ≤1/2，ζ=C_n−q。对任意共同删源ν′≤ν，原完整接收集E之外的全部新软信用满足

λ∫E外 f′ ≤ [C_n/(1−α)−q]W = q(ζ+θ)/(q−θ)W ≤ (4/3)(ζ+θ)W。

证明保留所有来源、尺度、见证切换和远处删源响应；它是完整阈值集合包含给出的解析上价。此结论也适用于相同假设下的其他伸缩族，没有产生方体特有的维数收益。

完整价格等于内部缺填R_in＋原软量I0−上述外部信用。若删除量≥σ_nW且θ≤σ_n，近极值极限中外部信用只有常数倍删除质量。若候选价格K_n确实成立，内部坏填充比例必须满足报告中的有限ζ界；仅取ζ→0后才可简化为(K_n+4/3)/(ηC_n)。这是成功动作的必要条件，不是付款已经证明。
