# 第66轮：有符号到达曲率与正收费反例

日期：2026-10-11。**一般 sqrt(n)n^{o(1)} 上界仍未证明**；保留全一般 O(n log n) 基准。

## 一般工具与精确反例

- 推导任意有限正原子来源的精确有符号到达曲率恒等式，保留真实并列到达与滞后端点。它消去随体积线性增长的密度贡献；恒等式本身尚不提供统一预算。
- 正到达包络满足 HW(1+来源熵) 上界；固定一维阈值的网格反例给出对数原子数下界，说明此正包络不能去掉熵费用。
- 更精细的曲率取正也无法统一支付：构造同一份有界正密度的分离尺度多数位模型，再严格转为有限正原子，固定 n=1、H=3、W=1 即可使收费无界。整个反例位于多源且扩大方体捕获不足半数总质量的区域。没有改变原好集，也没有用数值拟合代替证明。
- 第65轮重分配目标的全部块自能量已统一支付为至多 ceHW（c=1−e⁻¹），不依赖目标全局密度上限。尚缺带符号跨块总作用；实际目标子类上的对数反例否定先在接收点取正部再积分的收费，但不否定先保留空间抵消再估计的路线。

这些反例均不否定实际弱型目标。对应一维真实有符号能量有统一上界；不能把正代理费用发散解释为弱型反例。
