# 临界来源尾：严格相同 profile 类的事后降方差后处理

本后处理仅使用已完成的三轮保存分数，没有新抽样、没有重跑 oracle、没有修改原注册估计与置信区间。成员规则在读取分数后处理前登记；它是由完整来源几何指定的一个固定类，不按分数选择点或轮次。此项为 post-hoc 结构诊断，不是预登记主估计。

完整四格点输入中 C={y∈Z^n: |y_i|≤A−2}, A=16n。捕获 receiver 离来源至多1，全部候选 query 再延伸至多1，故都在原盒内。整数平移保留全部四层格点、原 q_k^-n 质量、全候选真实赢家、原阈值与捕获。proposal 的参考查询 halo 只有7/4，也同法则。故 C 上 S(y)=s0 且全部理想条件 score 同分布。边缘及非整数点原样保留。

Nc 为256个抽中来源中 C 的个数，N=16Nc。Nc>0 时 U=((ΣZ)^2−ΣZ²)/(N(N−1))；总估计 I2pool=(Nc/256)U+(1/256)Σ非C A_sB_s，Nc=0的类项为0。条件于所有来源，E U=s0²，故完整来源估计无偏。权重必须保留 Nc/256；不能以解析 pC 替换后在 Nc=0 删除该项。

理想 iid 法则下这是原 C 分组统计的 Rao–Blackwell 化。单 score 方差 v 时，原类均值方差=s0²v/(4Nc)+v²/(64Nc)，新方差=s0²v/(4Nc)+2v²/[16Nc(16Nc−1)]；非类和条件均值不变，故全估计方差不增。证明见上一级 critical_source_tail_mc_20261007_pooling_review.md，根已全文阅读。实际浮点采样法则仍未做区间认证。
