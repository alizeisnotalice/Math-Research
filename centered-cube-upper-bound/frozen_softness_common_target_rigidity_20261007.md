# 不同软度的共同正目标：有限四阶矩下的刚性

2026-10-07，根代理新推导。此为原 ψc 冻结族，区别于旧原文两 cube 半径反例；仅用于排除有附加矩条件的共同目标方案，不宣称排除所有参数转移。

固定 n≥2、ell>0、c≠d∈(0,1]，L_c=Σ_i ψc(−ell²∂ii)，ψc(v)=B(v)/(1+cB(v))，B(v)=v/log(1+v)−1。假设 u_c,u_d≥0 且 ∫(1+|x|⁴)u_j<∞；假设共同差 ν−μ=L_c u_c=L_d u_d 以可积密度/有限测度成立。结论：u_c=u_d=0，ν=μ。

直接幂级数给 ψc(v)=v/2−(1/12+c/4)v²+O(v³)。一维正跳核 G_c^(i)=I−cL_c^(i)，其中 L_c^(i)=ψc(−ell²∂ii)，其一坐标位移分布二阶矩为 c ell²，四阶矩为 (2c+6c²)ell⁴；可从其正 Gaussian 热钟表示的 Laplace 导数以单调收敛确认有限矩，不能单凭形式 Fourier 导数暗示矩存在。

于是（多项式上用真实跳积分定义 L）
L_c|x|²=−n ell²，
L_c Σxi⁴=−6ell²|x|²−n(2+6c)ell⁴，
L_c|x|⁴=−2(n+2)ell²|x|²−n(2+6c)ell⁴。
令 H=Σxi⁴−3|x|⁴/(n+2)，a_c=−(n−1)(2+6c)ell²/(n+2)，则 P_c=H+a_c|x|² 满足 L_c P_c=0。

在所列有限矩假设下，绝对 Fubini 合法，核对称使 ∫P_c(ν−μ)=∫(L_cP_c)u_c=0；同理 P_d。a_c≠a_d，相减得到 ∫|x|²(ν−μ)=0。再由二阶矩恒等式得到 −n ell²∫u_c=0；非负性迫使 u_c=0，另一势同理。
