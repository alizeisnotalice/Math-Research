# 临时小盒支配的固定输入输出覆盖：greedy 正结果与强分配障碍

2026-10-07。独立读取 `source_partition_dominance_extension_20261007.md`、root 的 `source_tube_budget_20261007.md`，并应用 L02/N04 的 SKILL、provenance、method、cube-interface。技能只用于真实输入／代理模型区分、边界检查和总质量记账；本稿不引用未读外部定理。只新增本稿、同名前缀精确算术脚本与收据，不改其它人的文件。

**主结论为正。** 固定弱阈值后，任意输入上“当前原 query 捕获的质量有超过 η 的份额落在某个临时小轴盒”这批输出，可由输入预选的有限 greedy witness cover 收费。无需证明这些输出仍被某份固定来源分配捕获 η 份额，也无需输入有 packet/network 结构。费用为 `e^(3nh/a) W/η` 的弱输出费、`4e^(3nh/a) W/η` 的原响应交通费；单位短壳能量费为 `4e^(1+3nh/a)/η`。`h=2a/n` 覆盖所有边长至多 `R(x)/n` 的临时盒（`R<=2a`）。更合主目标的选择是 `η_n=η0/sqrt n, η0=49/65536`：直接 paid traffic 为 `4e⁶ sqrt n W/η0`，已是所需平方根量级，near 吸收系数仍不超过 `49/16384`。不必为这一已付支另强求 Γ 能量为多对数。一般 far 余项仍待证。

后文同时证明：一个更强的“每个移动小盒自身都由固定小直径 packet 保留多对数份额”的无条件合同存在高维障碍。它不否定主结论，因为主结论使用输出覆盖，而非重建每个小盒的来源份额。

## 1. 原对象与应当证明的量词

固定有限正 Borel 输入 μ、`W=μ(R^n)>0`、`a>0`、`λ>0`、`η∈(0,1]`，原可测 `R(x)∈[a,b]`，完整

    m(x)=μ(Q(x,R(x))), u(x)=m(x)/R(x)^n,
    E={x:2λ<u(x)<=4λ}.

`Q` 使用全边长。保留同一 μ、λ、R、m 与 hardband；不按 witness 改变赢家。固定 `h>0`，定义严格临时盒事件

    E_exists={x∈E:存在 closed 轴盒 B, side(B)<=h,
                         μ(B∩Q(x,R(x)))>η m(x)}.          (A1)

预选分配合同 `Σμ_k<=μ` 是合法的质量预算，但若坚持由某个 μ_k **在原 Q 内** 捕获 η/P 份额，则还需额外证明，不能把“B 与已付 packet 相交”当作捕获结论。下述 root 提出的 greedy cover 完全避开这项更强要求。

这是 **固定阈值 λ/η 的输入预选**，不依赖正在积分的 x。它不是同一份 μ-only 分配同时用于全部阈值的声明；弱型证明在每个预先固定 λ 下分别选 cover 即可，最终费用常数对 λ 一致。

## 2. 无限候选族的有限 greedy cover：独立核验

令

    v=2ηλ a^n,
    F={所有 closed side=h 轴盒 B: μ(B)>v}.                (A2)

side<h 的 witness 可以先扩成 side=h；捕获不减，所以只需该候选族。若 F 为空，E_exists 也为空。

维护剩余候选族。若它非空，置 `s=sup_{B remaining} μ(B)`；有 `v<s<=W`。选仍在候选族内的 `B_j`，使

    M_j=μ(B_j)>s/2,

然后删除全部与 B_j **集合相交** 的剩余候选，继续。这里只需近最大，不要求 supremum attained；非空集合的有界正 supremum 保证可选。每一步是完整输入与固定参数的选择，不依赖 x，也不需要接收点的可测选择器。

**终止与边界。** 被选 B_j 仍属于 F，故每个 `M_j>v`；它们作为 closed 集合两两不交。闭面相接也算相交而被删除，所以含原子时仍有

    Σ_j μ|_{B_j}<=μ,  Σ_j M_j<=W.                         (A3)

若能选 N 项，则 `Nv<Σ_j M_j<=W`。因此至多有限步，且非空时 `N<W/v`；root 的较松 `2W/v` 也有效。若过程始终还有候选，可再选到超过这一上界，矛盾，所以最终候选族为空。该论证不要求初始候选可数；只产生有限个选择。它是一般 Borel 输入上的存在性算法，未宣称有有限计算成本的任意测度优化 oracle。

每个原候选 B 都在唯一首次删除阶段遇到某个 B_j；当时

    B∩B_j !=∅,   μ(B)<=s<2M_j.                            (A4)

不需要该 owner 映射可测，因为不对它积分。最终只使用固定有限输出盒。取 `μ_j=μ|_{B_j}` 是一份合法的有限来源分配，但未声称它在当前 query 中继续支配。

## 3. 从 witness 到输出盒：费用只用每份 M_j 一次

设 x∈E_exists，B 为扩大后的 witness，R 为原 R(x)。原 strict hardband 给

    μ(B)>=μ(B∩Q)>ηm(x)>2ηλR^n>=v.

所以 B 在 F 中，由 (A4) 指派给 B_j。捕获正质量保证 Q 与 B 有交点。等边长 h 盒 B 与 B_j 相交又给其中心距离至多 h。因此

    ||x−c_j||∞ <= R/2+h/2+h = R/2+3h/2.                 (A5)

质量比较给

    R^n < μ(B)/(2ηλ) <= M_j/(ηλ),
    ρ_j=(M_j/(ηλ))^(1/n)>R>=a.                           (A6)

由 (A5)–(A6)，x 落在固定 **open** 输出盒

    V_j=Q_open(c_j,(1+3h/a)ρ_j),  V=union_{j=1}^N V_j.   (A7)

严格性来自 `R<ρ_j`，所以 closed witness 的原子边界不会漏出 cover。V 为有限 Borel 集。定义真正付费和留账的输出为

    E_paid=E∩V, E_res=E\E_paid.                           (A8)

它包含 E_exists，可能额外支付一些输出，这只增强正支配。无须先给不计数 witness 投影证明可测，已可合法积分 E_paid。原分母 m、原赢家及未分配来源始终保留。

逐盒取 Lebesgue 体积、用 (A3) 仅收费每个 M_j 一次，得到

    λ|E_paid| <= (1+3h/a)^n ΣM_j/η
              <= e^(3nh/a) W/η,                         (A9)
    ∫_{E_paid}u <=4λ|E_paid|
                <=4e^(3nh/a) W/η.                       (A10)

这里不是将 μ(B_j) 当作其在原 Q 的捕获质量。费用来源是输出覆盖的体积，来源质量只是该固定输出盒的预算。即使 B_j 本身未被某一行的 Q 捕获，(A5)–(A7) 仍足以收费；这正是相较强来源重建合同的关键放宽。

对原单位短壳 profile，只以 E_paid 替换输出事件，仍使用完整 μ/W。既有 cone Jacobian 给

    0<=Γ_paid<=1,
    ∫Γ_paid² <=∫Γ_paid <=(e/W)∫_{E_paid}u
                        <=4e^(1+3nh/a)/η.               (A11)

原 profile 精确分为 paid 与 residual，L² 费用按三角不等式组合。没有据 (A11) 支付全部 Γ：residual 仍需其它工具。

## 4. 替代固定 packet 分支及可选宽度

对于任何既有固定来源分配 `Σμ_k<=μ`，若每包支撑位于 side<=h 的 B_k，且 `μ_k(Q)>ηm`，那么 `μ(B_k∩Q)>=μ_k(Q)>ηm`，所以该输出包含在 E_exists，进而包含在 E_paid。新分支因此覆盖所有这类固定 packet 支配输出，而且不要求输入事先有这种分配。对于特定固定网格／packet 分配，它还能额外支付原分配碎裂而未支配的输出。

在新 residual 上，严格得到

    μ(B∩Q(x,R(x)))<=ηm(x)
    对所有 side<=h 的 closed 轴盒 B.                    (A12)

这是完整输入的小盒捕获扩散条件，比只检查某份分配的每个 packet 更强。原 FIRST 等门只需与 paid/residual 输出相交保留；新 proof 不重新建立这些门，也不改它们。

可按目标选择宽度，保持同一 proof：

|固定 h|覆盖的临时盒（R<=2a 时）|弱费因子上界（除 W/η）|
|---|---|---|
|a/n|side<=a/n|e³|
|2a/n|side<=R/n|e⁶|
|C a/n|side<=C a/n|e^(3C)|
|2a loglog(n+2)/n|side<=R loglog(n+2)/n|[log(n+2)]⁶|

单位短壳能量另乘4e。若 η^(-1) 为固定常数或多对数，上述对应分支给常数或多对数能量费。无需把 `h=a/n` 当必要强度；`C≈sqrt(n)` 的指数费用仍不可接受。选盒数可能大，但未进入体积收费常数。

**主目标的较强阈值优化。** 不必用全部 Γ 的强式能量来支付这个分支。取

    h=2a/n, η0=49/65536, η_n=η0/sqrt n,

则直接交通 (A10) 给

    ∫_{E_paid}u <= (4e⁶/η0) sqrt n W.                    (A14-traffic)

同输出 near 接口的系数为 `4η_n=49/(16384 sqrt n)<=49/16384`；新 residual 的全部微盒份额上界降至 `η0/sqrt n`。paid Γ 强式界此时为 O(sqrt n)，而主目标的直接交通已经付清，不需要先将它改善为 polylog Γ。若允许 `L(n)>=1`，可进一步取 `η_n=η0/[sqrt n L(n)]`，直接 paid traffic 为 `O(sqrt n L(n) W)`，near 系数更小。这是参数回代的精确代数，不是拟合未知增长阶。

sqrt 阈值精确 guard 在 n=4,16,64 使用有理 `η0/2,η0/4,η0/8`。n=8,32,128 用分母 `2^20` 的平方根有理外包，保留 exact 平方比较；可选择保守有理阈值 `η0/sqrt_upper`，near 系数不增，paid 因子只增加一个明确的外包误差。这不把非平方 n 的浮点 sqrt 当证明。

## 5. exact exists 的可测性附注

虽然主证明只使用有限 V，仍可给初等 countable 表达。设 S(x) 为所有 side=h closed B 的当前捕获 supremum；令

    T_j(x)=sup_{c∈Q^n} μ(Q(x,R(x))∩Q(c,h+1/j)).

则

    S(x)=inf_{j>=1} T_j(x).                               (A13)

一方向：外膨胀和有理中心稠密保证每个原 closed h 盒包含在某个 rational-centred `(h+1/j)` 盒内，故 `T_j>=S`。反向：若右侧正，固定 x 取 near-maximizing c_j；其盒与固定 Q 正质量相交，故 c_j 有界。选收敛子列 c_j→c。任意 δ>0 下，最终这些盒包含于 Q(c,h+δ)，所以其质量 limsup 不超过 `μ(Q(x,R)∩Q(c,h+δ))`。令 δ↓0，有限测度的从上连续性给极限不超过原 closed h 盒质量，故 S 至少为右侧。右侧为0时反向显然。

固定有理中心、固定膨胀侧长时，移动 closed Q 与固定盒的相交质量是 (x,R) 的 upper semicontinuous 函数（逐点 indicator 的 limsup 与有限测度 reverse Fatou），因此复合原可测 R 后可测。countable sup/inf 保留可测性；严格 E_exists 等于 `{x∈E:S(x)>ηm(x)}`。**不能**把 same-side 的 rational-centred h 盒直接当稠密替身：两个原子可位于相距恰 h 的非有理端点，微移中心就丢失一个。这也是本稿使用外膨胀的原因。

## 6. 为什么强 packet 重建并非必要：两个具体障碍

**固定网格的真实 hardband 碎裂。** 取 `a=1,h=1/n`，μ 为支撑 `K=[−h/4,h/4]^n` 上总质量1的常值 L1 来源，固定 origin0 的 side=h 半开网格。K 横跨每一轴的网格边界，每个有质量格的份额为 `2^(−n)`。对 `||x||∞<1/2−h/4`，原连续窗口 `[1,2]` 的每个 cube 都捕获完整 μ，故唯一赢家 R=1、u=1。取 λ=1/3、η=1/4，则是真实 strict hardband；每格份额低于 η（n>=3），但 side=h/2 的 K 本身捕获全部原 m。输出开集体积 `(1−1/(2n))^n`，不是零测度边界构型。新 greedy branch 支付它；输入预选整个 K 也能修复该特定例子，所以它只反驳固定格自动代表所有小盒。

**重叠 witness 的来源复制。** 中央小立方体 `[-h/32,h/32]^n` 放质量1；每个 `σ∈{−1,1}^n` 的 `σ(3h/4)+[-h/32,h/32]^n` 放质量 `2^(−n)`，均取常值正 L1 密度。总 W=2。取 B_σ 的每坐标区间为 `[-h/8,7h/8]`（σ_j=+）或 `[-7h/8,h/8]`（σ_j=−）。每个 side=h B_σ 捕获中央质量和自己的 tip，总量 `1+2^(−n)`。若每个临时 witness 直接分配原 μ|B_σ，则

    Σ_σ μ(B_σ)=2^n+1,

中央质量被重复 `2^n` 次，违反来源合同。整个构型却位于 side<2h 的盒，合并成一份合法来源立即修复。新 greedy 也只收费 selected disjoint 的 M_j，而不是这些原 witness 的质量和。

如果一律把所有相交 witness 连通成一个 packet，1D 递进的 overlapping h intervals 可以成任意长链；diameter 没有 C h 上界。截断合并又留下边界问题。这类算法缺口不等于所有可能输入预选方案均不成立；主 proof 已以输出 cover 而非强合并解决当前存在性支。

## 7. 无条件全小盒份额合同的有限大盒反例

下面证明一个真正的 universal preallocation 障碍，但其量词严格强于 (A1)。固定 h>0、C>=1、n>=2，令 `T=2n+1`、`Ω=[0,Th]^n`、真实 `μ=1_Ω dy`，`W=(Th)^n`。任意输入预选可数分数分配 `μ_k=α_k μ` 满足 `α_k>=0,Σα_k<=1`，且每份支撑位于某个 side<=C h 轴盒。

考虑所有 **完全位于 Ω 内** 的移动 h 盒

    B_c=Q(c,h), c∈D=[h/2,(T−1/2)h]^n,
    |D|=((T−1)h)^n, μ(B_c)=h^n.                          (A14)

若试图保证每个 c 至少有一份保留 `γ μ(B_c)`，则必要地

    γ² <= [(2n+1)/(2n)]^n
           [1−2/(3(C+2)²)]^n
        < 2 exp[−2n/(3(C+2)²)].                          (A15)

**一维 exact Schur 预算。** 尺度归一化 h=1，令 I 为长度 C 的包围区间并平移为 `[-C/2,C/2]`；`D0=(C+2)/2`、`φ(s)=D0²−s²`。三角核 `k(s,t)=(1−|s−t|)_+` 的全空间卷积满足

    ∫ k(s,t)φ(t)dt=φ(s)−1/6.

对 s∈I，核只见 t∈[s−1,s+1]⊂[−D0,D0]，该范围 φ>=0。因此限制到 I 只减小积分，并给

    T_Iφ(s)<=φ(s)−1/6
             <=βφ(s), β=1−1/(6D0²)=1−2/[3(C+2)²].

用 `2uv<=u²φ(t)/φ(s)+v²φ(s)/φ(t)` 对称积分即得 `⟨g,T_I g⟩<=β||g||₂²`。张量积区间用乘积 φ 同样得到 β^n，无需引用未核文献。

把 α_k 延拓为 Ω 外0。对全部中心 c∈R^n，Fubini 与两个移动盒的相交体积给精确身份

    ∫ [μ_k(B_c)/h^n]² dc
     = ∬ α_k(y)α_k(z) P_h(y,z)dy dz,
    P_h(y,z)=h^(−n) Π_i(1−|y_i−z_i|/h)_+.

对每个包围盒使用上述张量预算并求和；`Σα_k²<=Σα_k<=1`，得到

    ∫_{R^n} Σ_k[μ_k(B_c)/h^n]² dc <=β^n W.              (A16)

若每个 c∈D 都有一份份额至少 γ，则左侧在 D 的积分至少 `γ²|D|`。于是 `γ²<=β^n W/|D|`，其中有限来源／内中心域体积比为精确的 `[(2n+1)/(2n)]^n<2`，得到 (A15)。没有把无限均匀“概率”偷换为有限来源，也没有忽略大盒边界。

令 `γ=1/P`，则

    1/P <sqrt(2) exp[−n/(3(C+2)²)].                      (A17)

如果 P 为 `[log(n+2)]^p`，必要膨胀近于 `C+2 >= sqrt(n/[3p loglog(n+2)+(3/2)log2])`。因此 C=O(loglog n) 不能实现这个 **全移动小盒自身份额保留** 的强合同；每个 n 的 exact 常数见算术收据。有限 n=8/32/128 的表仅检查公式，渐近障碍来自 (A15) 的自含证明，未凭三点拟合。

**它没有排除条件输出 cover。** 对 (A14) 的对应大 query `Q(c,a)`、`a=nh`，即使 c 靠 Ω 的边，每坐标与 Ω 的交叠长度仍至少 `(n+1)h/2`。所以

    μ(B_c)/μ(Q(c,a)) <=[2/(n+1)]^n.

内域未截断大 query 时该比例为 `n^(−n)`。这族一般不满足 η 固定／多对数倒数的原 query 小盒支配前提，而且新 greedy 不要求任何 μ_k 保留 B_c 份额。把 (A15) 当作对 (A9) 的反例是量词错误。

## 8. 与 root tube 合同及质量分层的关系

root tube 合同可支付任意 **已有固定** 来源分配及其实际 `D_k(ρ_k)`；若支撑包含于有限连通线段网络，费用证书为 `1+L_k/ρ_k`。它可避免长稀疏 packet 的包围盒指数，和新小盒 witness branch 互补。

(A15) 只约束支撑装入 C h 轴盒且试图保留全部移动 h 盒份额的分配，不限制任意低 tube-cost K_k。并且 n>=2 的均匀 Ω 来源在每个有限线段网络上质量为0；若其 μ_k 被要求精确集中在这种网络内，则 μ_k=0。这不是 root 已给低成本网络 packet 输入的反例，它不具备那种来源结构。原子／给定网络 packet 的合同仍合法；是否能为任意剩余输入找到足够支配、同时低成本的网络分配，仍未证明。不能从全维来源这条观察扩推到任意正体积厚管或任意 K_k。

质量删除的势能 `H_j=未选质量` 可给 `Σ(H_j−H_{j+1})<=W`，但单凭此并不保证每个原 Q 的份额被某个 packet 保留。若每个 mass layer 又使用全 μ，需预设权重 w_j 且 `Σw_j<=1`；layer-j 的支配只保留 `w_jη`，费用增加 `1/w_j`。层数可依赖 `log(W/(λa^n))`，没有自动的 n-only 多对数界。N04 的望远镜不能把未证覆盖损失当可和误差。当前 greedy 输出 cover 只需要 selected disjoint 的 (A3)，不需这条分层重建。

## 9. 同输出 actual near 来源对的吸收接口

这是同一接收点的 soft/hard 来源对，**不是**两个接收点共径向 t 的 double-cone pair。对 x∈E_res，固定完整硬捕获后验

    r_x(dz)=1_{Q(x,R(x))}(z) μ(dz)/m(x).

(A12) 对任意 soft 来源位置 y 给

    r_x(Q(y,h))<=η.

若原交通已有表示 `A_x(y,z) p_x(dy) r_x(dz)`，其中 p_x 为概率（或总质量<=1 的子概率），且 `0<=A_x<=1`，则

    N_x=∬1_{||y−z||∞<=h/2} A_x(y,z)p_x(dy)r_x(dz)
       <=∫p_x(dy)r_x(Q(y,h))<=η.                         (A18)

由原 hardband，near 来源对交通为

    ∫_{E_res}u(x)N_x dx <=4ηλ|E_res|.                    (A19)

任何已有 actual 标签／子交通若被该 product integral 正支配，也满足同一界；门控只减小被积式。这里没有假设条件化后凭空独立，也不能推广到任意相关 joint coupling：任意 joint 的硬边缘即使很 diffuse，也可与软边缘对角耦合，使 near 概率为1。

固定 `η=49/65536` 时，`4η=49/16384`，与要求的 ε 一致。取 `h=2a/n`，剩余 far 来源对满足 `||y−z||∞>a/n`。此为新的 paid／residual，再在 residual 作 near／far 的替代分解；若沿用既有 matching-light，需只对它删去后剩余且不重叠的交通使用，并重新登记吸收预算，不把同一 ε 花两次。near 已给可吸收系数，far 来源对及其原 actual 联合门费用仍未支付。
