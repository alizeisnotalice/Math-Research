# 中心立方体极大算子上界研究资料

本项目按 rounds/ 中的轮次独立归档。当前目标为纯 C_n ≤ K√n；此目标及原一般 n^(1/2+o(1)) 一致弱型上界均未闭合。最新研究见 [rounds/663/README.md](rounds/663/README.md)。R658完成全部656份摘要提炼及最小恢复链；R660给出实际残余共同权与全族远项，R661给出因果接收筛选与方体合并几何，R662证明真实共点来源随机交集的指数期望折扣并固定共同Poisson覆盖。R663吸收有限时钟的未完成损失，支付已标记父方体及重复来源的两项全族费用。剩余单次来源外部覆盖 E|S_8|≤AU 尚未证明；精确来源分解、前缀势和有限计算均不构成一般上界改善。后续继续保留实际 mutual admission、来源、接收测度与同一次选择，攻坚该完整联合几何预算。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 本机编译产物不纳入版本控制。Bernoulli 检验脚本使用相邻 C++ 源通过 clang++ 重新生成所需动态库。

## 复现与记录

运行某项检验前，请先阅读同主题的说明文件，确认依赖、参数和数据范围。数值实验仅验证所列有限参数范围，不替代一般性证明。每轮完成时使用主题明确的 Git 提交信息，并将结论、未解决条件和复现方式记录在对应笔记中。
