# 中心立方体极大算子上界研究资料

本项目按 rounds/ 中的轮次独立归档。一般 n^(1/2+o(1)) 一致弱型上界仍未闭合，最新已完成轮次见 [rounds/654/README.md](rounds/654/README.md)。R654证明全旧几何类中可合法选择产品格内来源并保留近极值score，支付双配置bad-alpha的部分来源相关费用；完整good-alpha、真实损失与净重优化反弹尚未联合控制。删除源质量在完整D中是有利项，辅助目标的比较费用不能取代实际预算。二维正宽有理证书与128个有限案例复现均按范围记录，特别明确后继kappa'>4的域外限制。两份终稿独审通过部分结果整合，不宣称一般上界改善，不编译PDF。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 本机编译产物不纳入版本控制。Bernoulli 检验脚本使用相邻 C++ 源通过 clang++ 重新生成所需动态库。

## 复现与记录

运行某项检验前，请先阅读同主题的说明文件，确认依赖、参数和数据范围。数值实验仅验证所列有限参数范围，不替代一般性证明。每轮完成时使用主题明确的 Git 提交信息，并将结论、未解决条件和复现方式记录在对应笔记中。
