# 中心立方体极大算子上界研究资料

每轮开题先核对[高损失来源联合估计攻坚指令](AGENTS.md)。第707轮给出原积分的整行费用和真实历史总账。详见[第707轮记录](rounds/707/README.md)。

第724轮用排序后的坐标差控制跨组费用，并估计实际共同来源中心在两站点交集内的分布。详见[第724轮记录](rounds/724/README.md)。

第723轮按两个真实接收位移和共同来源中心的位置，估计同档站点对的交叉费用。详见[第723轮记录](rounds/723/README.md)。

第722轮将全部剩余组分别分配到可选来源体积档，支付同档中极小重合与近距离的交叉费用。详见[第722轮记录](rounds/722/README.md)。

第721轮证明经过同一锚点的来源能支付整批接收体积，并将估计直接用于吸收跨组共享项。详见[第721轮记录](rounds/721/README.md)。

第720轮按实际来源价值支付集中接收组，留下超预算来源在不同组之间的交叉项。详见[第720轮记录](rounds/720/README.md)。

第719轮以两个站点共同来源的逐坐标交集估计整个连通分量的预算，并逐来源核算退役费用。详见[第719轮记录](rounds/719/README.md)。

第718轮证明全坐标折叠时不同站点不会碰撞，并核算混合排序后全族共享的来源费用。详见[第718轮记录](rounds/718/README.md)。

第717轮按来源尺度联合支付所有坐标上移动后的真实接收质量，并对未分配部分给出来源侧的平均密度差估计。详见[第717轮记录](rounds/717/README.md)。

第716轮将可支付的接收点和来源交替删去，并证明任何未付关系必须支持长程、尺度跳跃的真实路径。详见[第716轮记录](rounds/716/README.md)。

第715轮证明真实近来源允许同时释放对数多个坐标，并将相应接收体积费用回代原积分。详见[第715轮记录](rounds/715/README.md)。

第714轮证明深接收者每次容量减半都强迫真实贪心价格下降，并核算跨阶段选择的联合预算。详见[第714轮记录](rounds/714/README.md)。

第713轮将空间拥挤与真实来源预算放在同一割中，并给出正缺额割的几何必要条件。详见[第713轮记录](rounds/713/README.md)。

第712轮按跨接收者的实际测度重叠分配高损失来源，并给出完整积分的未匹配体积界。详见[第712轮记录](rounds/712/README.md)。

第711轮在完整半径范围支付相对越面总深度较小的高损失来源。详见[第711轮记录](rounds/711/README.md)。

第710轮用真实来源子集的共同交集估计较小来源的整行高损失费用。详见[第710轮记录](rounds/710/README.md)。

第709轮统一支付来源半径至少为接收半径 64√(n/log n) 倍的完整高损失段。详见[第709轮记录](rounds/709/README.md)。

第708轮从原高损失积分中提取容量减半阶段上严格有序的来源体积档，核清异常集与整族费用。详见[第708轮记录](rounds/708/README.md)。

第706轮证明按真实坐标面约束支付全尺度低损失来源的预算。详见[第706轮记录](rounds/706/README.md)。

第705轮证明坐标分组位移的根阶预算，并在真实首次捕获输入上与等距扩张逐项比较。详见[第705轮记录](rounds/705/README.md)。

第704轮按第 d+1 大位移结算多坐标接收贡献，并核验真实交集的整组费用。详见[第704轮记录](rounds/704/README.md)。

第703轮控制全部尺度的单轴越面费用，并保留可选命中见证下的多轴剩余积分。详见[第703轮记录](rounds/703/README.md)。

第702轮给出多方向接收预算与完整未付来源的符号分布约束。详见[第702轮记录](rounds/702/README.md)。

第701轮按实际来源半径积分，同时结算符合指定坐标模式的接收贡献；完整剩余估计仍待证明。详见[第701轮记录](rounds/701/README.md)。

第700轮用方体各坐标的端点约束和实际互不相交的来源区域，估计同一接收子集可获得的来源预算。来源可以漏掉不同坐标上的见证，费用按真实掩码和使用份额累计。 一般弱型上界仍未证明。详见 [第700轮记录](rounds/700/README.md)。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 本机编译产物不纳入版本控制。Bernoulli 检验脚本使用相邻 C++ 源通过 clang++ 重新生成所需动态库。
