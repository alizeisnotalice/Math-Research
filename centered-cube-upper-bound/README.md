# 中心立方体极大算子上界研究资料

本项目保存中心立方体极大算子上界研究报告及必要复现材料。新成果按 rounds/ 中的轮次独立归档；历史材料正在按依赖关系逐步精简。一般 sqrt(n)n^{o(1)} 上界尚未闭合，最新第80轮报告见 rounds/080/README.md。第80轮用真实核正性吸收细软层尾项，将一般输入的单窗口问题归约为 O(log n) 个正向层输出首达。平滑基线、连续高背景、锚点、连续通量例外及大恢复时间／大背景占用支路，合计已有 O(sqrt(n)log²(2+n)) 的显式预算；短时低占用原始有符号硬面首达弱体积及全尺度回代仍未证明。真实硬首达的来源径向年龄满足指数尾，但方向条件化版本有实际 L1 正体积反例。单侧来源 duty 证书合法，临界正核与硬立方体可比，逐原子阈值 shutdown 在聚集细分来源上失败，一致廉价共同覆盖仍未建立。全一般保留基准仍为 O(n log n)。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 本机编译产物不纳入版本控制。Bernoulli 检验脚本使用相邻 C++ 源通过 clang++ 重新生成所需动态库。

## 复现与记录

运行某项检验前，请先阅读同主题的说明文件，确认依赖、参数和数据范围。数值实验仅验证所列有限参数范围，不替代一般性证明。每轮完成时使用主题明确的 Git 提交信息，并将结论、未解决条件和复现方式记录在对应笔记中。
