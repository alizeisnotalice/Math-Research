# 中心立方体极大算子上界研究资料

本仓库保存中心立方体极大算子上界研究中的证明草稿、数值探路程序、输入数据与检验结果。资料按研究轮次和工具模块组织；文件名中的日期与主题用于追踪各轮工作。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 个别 `.dylib` 是 macOS 本机数值检验程序依赖；在其他平台上需要按相邻脚本说明重新构建。

## 复现与记录

运行某项检验前，请先阅读同主题的说明文件，确认依赖、参数和数据范围。数值实验仅验证所列有限参数范围，不替代一般性证明。每轮完成时使用主题明确的 Git 提交信息，并将结论、未解决条件和复现方式记录在对应笔记中。
