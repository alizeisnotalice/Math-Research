# 中心立方体极大算子上界研究资料

本项目保存中心立方体极大算子上界研究报告及必要复现材料。新成果按 rounds/ 中的轮次独立归档；历史材料正在按依赖关系逐步精简。一般 sqrt(n)n^{o(1)} 上界尚未闭合，最新第75轮报告见 rounds/075/README.md。第75轮严格否定未截断物理门软层覆盖在真实完整低背景分支上的一致下界，并证明半径 O(log n) 外全部软层远尾可一次强 L1 付费。来源分离给出优化覆盖精确可加性；核支配与混合门有支付接口，任意源近区网格覆盖费用仍为 O(n log n)。目标指数的有理最小割证书可扩大有限探路，但不证明连续覆盖。剩余困难是质量连通原源的统一覆盖，或截断软层核心的混合覆盖和全部异常集预算；全一般基准仍为 O(n log n)。

## 资料约定

- Markdown、文本和 LaTeX 源文件记录论证、假设及状态。
- Python 脚本用于数值探索、反例搜索和有限规模核验。
- JSON、NPZ、压缩文件等是对应计算的输入或输出数据，应结合相邻说明文件阅读。
- `__pycache__` 和 Python 字节码不纳入版本控制。
- 本机编译产物不纳入版本控制。Bernoulli 检验脚本使用相邻 C++ 源通过 clang++ 重新生成所需动态库。

## 复现与记录

运行某项检验前，请先阅读同主题的说明文件，确认依赖、参数和数据范围。数值实验仅验证所列有限参数范围，不替代一般性证明。每轮完成时使用主题明确的 Git 提交信息，并将结论、未解决条件和复现方式记录在对应笔记中。
