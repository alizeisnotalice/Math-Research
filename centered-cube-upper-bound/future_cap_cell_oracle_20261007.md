# 共同未来上限的连续参数正包络

2026-10-07。应用用户 B02 半无限约束 skill：先证明全索引分离误差，再使用有限计算。这里给出直接解析证明，不引用尚未核验的外部收敛定理。

固定完整正有限来源 μ，原 h=1_{[-1/2,1/2]}、φ=h*w，以及
P_{s,L}(x)=L^{-n}∏_i[(1−s)h(x_i/L)+sφ(x_i/L)]。
φ非负、偶递减；h采用闭边界规范。固定接收点x。不得重选来源或删掉混合分量。

## 1. 一个参数单元的全连续上界

令0≤p≤q≤1、0<l≤u，Δ=q−p，s*=q/(1+Δ)。有p≤s*≤q：
s*−p=Δ(1−p)/(1+Δ)，q−s*=qΔ/(1+Δ)。对s∈[p,q]，逐坐标正性给

    (1−s)h+sφ ≤ (1−p)h+qφ = (1+Δ)[(1−s*)h+s*φ].

对L∈[l,u]，偶递减性给h(v/L)≤h(v/u)、φ(v/L)≤φ(v/u)。因此逐核、逐来源积分均有

    P_{s,L}*μ(x) ≤ [(1+Δ)u/l]^n P_{s*,u}*μ(x).       (1)

此式对任意正有限 μ 和 n成立，不依赖来源的坐标独立性。有限原子的面到达跳跃完整保留：右端使用闭边长u，不能换成左极限或开放指标。

有限个单元覆盖 [s0,1]×[a,b]，令d=max P_{s*,u}*μ(x)，
U=max [(1+Δ)u/l]^n P_{s*,u}*μ(x)，则

    d ≤ sup_{s≥s0,a≤L≤b}P_{s,L}*μ(x) ≤ U.          (2)

节点位于对应单元内，左界是真实点值。若每个单元n[log(1+Δ)+log(u/l)]≤ε，
还有U≤e^ε d。选Δ≤ε/(2n)、log(u/l)≤ε/(2n)即可。
需要的点数至多(1+2n/ε)(1+2n log(b/a)/ε)，这是计算复杂度，不是可免费用于弱型范数的常数。

## 2. 合法分离与不能宣称的结论

若节点响应的认证下界>原q水平，则该future候选失败。若全部单元响应的认证上界乘因子均≤原q，才认证全连续future cap。
一般浮点点值、有限扫描或局部优化不能替代这两类认证。数值核的求积误差与浮点误差须分别控制，再代(1)。
若sup恰等于q，有限分割可以始终只给U>q；不能保证精确等号判定有限步终止。
对严格可行余量，若每层有限节点的认证包围误差一致趋零且全体单元尺寸趋零，则(2)保证最终可分离该余量。
这不要求预先假定hard响应对L连续；跳面由正上包络处理。

FIRST的其余定义、出生/森林/CP/GP/原winner等均未由本工具认证；它只处理冻结完整输入上的两个连续future参数。
把有限点并集费用直接相加会引入上面的n²网格规模，不能拿这个算法替代目标的来源一次空间预算。
