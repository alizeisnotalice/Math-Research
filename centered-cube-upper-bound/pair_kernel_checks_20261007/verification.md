## 1. 一维公式、边界与范围

独立从区间交计算

    p_Q(s) = |[-1,1] ∩ [s-Q,s+Q]|/2.

当 `Q>=1`，中央平台长度为 `2(Q−1)`，两条斜坡分别宽度2，由此得到稿中的分段表达。`b_Q(s)` 是两个固定面点 `+1,-1` 的闭区间命中概率；在 `|s|=Q−1` 处按双命中取1，在 `|s|=Q+1` 处按单命中取1/2。这些点不影响 Lebesgue 积分，但影响 cone 的离散面质量，程序另做闭边界点值核对。`Q<1` 时该分段式不适用，本轮未把它外推。

代码以有理断点 `−Q−1,−Q+1,0,Q−1,Q+1` 分段，每段记录 `p` 的一次多项式系数和 `b` 的常值，用精确反导积分，而非数值求积。结果为

    A = ∫p² = 2(Q−1)+2*(2/3) = 2Q−2/3,
    C = ∫b² = 2(Q−1)+2*(2/4) = 2Q−1,
    D = ∫bp = 2(Q−1)+2*(1/2)*1 = 2Q−1.

另独立积分 `I_epsilon=1_{|s−epsilon|<=Q}`：

    ∫I_epsilon p = 2Q−1,
    ∫I_epsilon I_epsilon = 2Q,
    ∫I_+ I_- = 2(Q−1).

`exact_results.json` 保存每段系数、逐段有理积分和全部分数。`Q=1+1/n<exp(1/n)` 只作通用代数核对，不能替代实际单位短壳上界；`Q=1+2/n` 可由 `exp(x)<=1+(e−1)x<1+2x`（`0<x<=1`）作为宽上包，但本轮并未因此认证原资格。

## 2. L、K 与全部交叉项

先固定面坐标 `j` 和符号 `epsilon`。自由坐标命中概率按定义独立相乘，固定面坐标贡献 `I_epsilon(delta_j)`；对 `2n` 个面／符号均匀平均正好是 (14) 的 `L_Q`。第二方向的条件是 `||delta+omega'||<=Q`，其概率为 `L_Q(−delta)`。cone 对称使 `L_Q(−delta)=L_Q(delta)`，两个方向独立，故 (15) 的 `K_Q=L_Q²` 成立。

程序用区间交的 `p` 算法显式枚举 `2n` 个面／符号；随后枚举全部 `(2n)^2` 面对，比较与 (14)、(15) 的值。每个 `(n,Q)` 使用六种预设位移：原点、近平台尾部、正负交替尾部、中央闭边界、单坐标外端闭边界和单坐标越出支撑。共54个点值测试，均精确相等。单坐标外端闭边界的 `L=1/(2n)`，正确保留 cone 固定面命中，未把它按自由坐标零概率删除。

独立体积算法对每个固定面／符号对逐项积分。同面项含 `∫I_epsilon I_eta` 乘 `A^(n−1)`；异面项含两份 `∫I_epsilon p` 乘 `A^(n−2)`。全部 `(2n)^2` 项相加再除以 `(2n)^2`，精确等于

    ∫K_Q = C A^(n−1)/n + (1−1/n) D² A^(n−2),
           = C A^(n−1)/n + (1−1/n) C² A^(n−2).

没有只保留同面或对角项。`Q=1` 时亦逐项核对 (18) 两式，包括 `delta=2Delta/r` 换元的 `(r/2)^n`，结果完全一致。

互捕条件 (12) 直接来自 `z'−x=r_t(delta−omega)/2` 和 `z−x'=−r_t(delta+omega')/2`。同面同号时，第 `j` 坐标的两个区间交包含在 `[−(Q−1),Q−1]` 中，给出 (13)；该宽度不构成任意来源对的概率预算。

## 3. 避开指数小概率的独立 cone 检查

每个 `(n,Q)` 固定 `delta_i=Q−1+1/(2n)`，于是

    p_Q(delta_i)=1−1/(4n), b_Q(delta_i)=1/2,
    L=(1/2)(1−1/(4n))^(n−1), K=L².

这些目标约为 `0.4` 和 `0.15`，不随 n 指数趋零。每个案例直接抽65536对独立 cone；面坐标与符号均匀，自由坐标均匀 `[-1,1]`，分别检查 `delta−omega` 与 `delta+omega'` 的 sup 范数，以及两个命中的联合事件。与精确分数目标比较，不从样本平方一个概率估计。

每个比例另给边际95% Hoeffding 区间，半宽 `sqrt(log(40)/(2*65536))`。本次27个比例目标均落在各自区间，最大绝对误差约 `0.003295`（精确值见结果文件）。这些区间不是27项同时置信保证。Monte Carlo 是浮点独立算法对照；数学认证来自前述有理身份，不依赖抽样通过。未试图用盲目 cone 抽样估计 (17) 的指数小 Lebesgue 体积。

## 4. 唯一赢家真实输入和非互捕下界

保留旧归一化 `c=1,a=1,b=2,M=n²b`，真实输入为

    f(y)=(1+||y||₂²/(nM²))1_[−M,M]^n(y), lambda=1/2.

用一维零阶、二阶矩精确积分计算完整质量 `W=(4/3)(2M)^n` 和内来源盒 `Z0=[−M+b,M−b]^n` 的质量；其比例严格等于

    q0=(1−1/n²)^n [3+(1−1/n²)²]/4
       >=(3/4)(1−1/n).

另读旧 n=4,16,64 的9条已保存记录，全部 q0 与 q0² 按旧分数复核相等；这只是读数据核公式，未重跑旧实验。

在整个接收盒 `[−M+b/2,M−b/2]^n`，响应为

    1+||x||₂²/(nM²)+R²/(12M²).

程序核对其全盒响应下界大于1、上界小于2，且 `b²−a²` 造成严格正响应增长。因此原连续窗口的 b 为唯一赢家，并属于同一个 strict-lower/closed-upper hardband。内来源盒对全部 cone 输出都保留该接收盒资格。`B=n log2>=n/2>=1`，最后单位 t 窗长度确为1。

若原源对 `||z'−z||∞>b`，任何方向的两个接收 cube 都无法互捕该源对，因为捕获来源与原来源的距离至多 `(r_t+b)/2<=b`。正性、`f<=2c` 与完整 W 给近源对上界

    Prob(||z'−z||∞<=b)<= (3/2)(b/M)^n.

从 `Z0×Z0` 的质量 q0² 中减去完整来源的近对上界，方向正确，得到 (23)：

    E_non>=q0²−(3/2)n^(−2n)>0.

全部值保留精确分数。n=128 的减项非零，但小于浮点下溢范围，JSON 的 float 近似0仅是显示下溢；数学比较和相减均用精确有理数完成，未把它置零。该守卫说明完整平方不能全部被近来源自由互捕核正支配；它没有超 polylog 增长，不解决一般剩余收费。
