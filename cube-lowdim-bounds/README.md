# 低维中心方体弱型常数

研究Lebesgue测度、中心、轴平行、所有坐标共用同一半径的方体极大算子。按有限轮次持续研究；不以精确最优常数作为阶段验收要求。

当前二维已证上界为B1=(100000/100009)B_Tomar<3.59091，见[第20轮](rounds/020.md)。公开准确基准B_Tomar约3.591224327506452345...已由两程序本机完整复现；本轮严格降低其核成本。旧3.8786及4841/1260仅保留为历史结果，不作最新公开突破标准。其余维度见[准确成果表](results/bounds_ledger.json)。

**第35—36轮证据更正与补验：** 原版 `hlcert` 的外区复积分回调未传递解析性标志，旧运行成功不能继续表述为两套均无缺口的严格认证。另一套闭式核验不调用该积分接口，B₁目前仍由该证据及既有解析桥支持；第36轮修正版已对固定B₁完整补验通过；公开原核没有另行补跑。旧轮次保留历史执行记录，缺口与修复范围以[更正说明](experiments/round035/dependency_correction.md)为准。

以下第1—3轮的公开基准是当时不完整的检索范围，现已被第20轮纠正。第1—3轮已完成，见[第一阶段总结](STAGE_01.md)。二维公开下界Phi约1.685509993355525；内部三、四维下界分别为R3约1.79393322779477与R4约1.90174261110095（既有构造，非本轮新结果）。公开基准二维上界准确值2787954611/718800000；第3轮参数证书给出27226955153507/7019746875000，准确减少4051576787/67277254050000000。三、四维使用一般上界8、16，未宣称已穷尽最新文献。

证明见 proofs/，每轮报告见 rounds/，标量与几何证书见 results/。解析上界依赖Lin的通用障碍定理；新参数未做Lean构建。内部原始附件与完整日志仅本地保存。
