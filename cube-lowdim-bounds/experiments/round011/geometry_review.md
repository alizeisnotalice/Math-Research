# 第 11 轮周期位置扰动：独立几何审查

状态：**解析与实际实现审查通过，未发现阻断缺陷。** 已审阅旧 round006/search_four_weights.py、新 round011/search_positions.py 及保存的 search_result.json；仅本文件由本审查者维护，未调用搜索主函数，未重跑各维80项搜索。

## 1. 构型及真实周期

本轮应明确表示
\[
x_0(n)=a_0n_0,\quad x_1(n)=a_1n_1,\quad
x_j(n)=a_jn_j+\Delta_j(n_0\bmod2,n_1\bmod2)\quad(j\ge2),
\]
其中 d=3 或4、全部 \(a_j>0\)，每个整数指标原子质量为1，位移不随其余整数指标改变。若程序用无量纲 shift，则 \(\Delta_j=a_j\,\mathrm{shift}_j\)，须在坐标中实际乘入。

真实轴向周期向量是 \(2a_0e_0,2a_1e_1,a_2e_2,\ldots\)。前两坐标的整数指标加2保持 parity，其余指标加1只沿对应周期平移。基本周期含四个余类，完整质量恒为4；即使存在更小实际周期，采用此周期仍有效，体积和质量应一致采用同一胞腔。不得沿用依赖反射对称性的 \(2^d\) 倍数。

此构型的指标到坐标映射是单射：前两个坐标确定 n0,n1，其余坐标在固定 parity 后由正间距确定相应整数。因此任意位移值都不会把不同指标的原子误合并。位移模周期可能重参数化同一物理构型，不应重复增加周期质量。

## 2. indexblock 的合法中心盒

对指标块 \(B=\prod_j\{s_j,\ldots,s_j+\ell_j-1\}\)，选入全部这些指标，质量为 \(M=\prod_j\ell_j\)。令 \(q=M^{1/d}/2\)，每一坐标必须实际计算
\[
L_j=\max_{n\in B}x_j(n)-q,\qquad
U_j=\min_{n\in B}x_j(n)+q.
\]
共同的 q 是同一方体半径。不得直接沿用旧规则格点的端点跨度公式；位移后的真实最小或最大值可能来自与指标端点不同的 parity。

若位移仅依赖前两 parity，可等价优化：先取块实际出现的 parity 集合 P，则 j≥2 的真实最小值为 \(a_js_j+\min_{p\in P}\Delta_j(p)\)，最大值为 \(a_j(s_j+\ell_j-1)+\max_{p\in P}\Delta_j(p)\)。前两方向仍用真实等距端点。该优化只在 P 恰为块实际出现的 parity 时成立，不能无条件取全四种。

若某坐标 \(U_j\le L_j\)，该盒无正体积，丢弃正确。开盒内可略缩方体而仍包含整个有限块，因此其平均值严格大于1；盒边界为零测集。遗漏不属于 indexblock 的其他正质量原子，只会低估方体实际质量，不会使该见证失效。固定有限长度范围只限制可用见证，不证明没有更大或非指标块见证。

## 3. wrap、重复及并集

每个 [Lj,Uj] 必须按真实轴向周期拆分：非正长度为空；长度≥周期覆盖整周期；其余按取模后可能跨端点拆成两段。坐标拆分的笛卡尔积是盒在周期胞腔的正确像。每个 wrapped 中心对应原见证的一次整数周期平移，物理构型在该平移下不变。

所有拆分盒须求真实并集。去掉完全重复或被包含盒保持并集；不能把盒体积简单求和，不能因多个 indexblock 或 wrap 分片覆盖同一中心而重复计分。最终得分为并集体积/4。

## 4. 数值与严格下界的界线

浮点根及端点会产生末位误差，搜索值只能作发现证据。出现超过基准的候选时，须将位置/间距有理化，用向下有理 d 次根界收紧共同半径，独立严格核对周期并集及完整质量。控制值在显示精度内一致不证明当前 indexblock 长度上限已穷尽真实超水平集。

## 5. 向有限质量 L1 函数传递的接口

周期原子测度本身不是全空间 L1 输入。有限见证种类、有限块长度和有界位移使所需原子与中心的相对距离有统一有限界。可在大量周期单元上截断，只计远离边界的完整见证中心；遗漏的边界单元相对总量趋零，而质量严格按每周期4结算。

再对有限原子作小尺度非负平滑。应先在开中心盒内保留正边距、取略小于质量根的方体或略高于1的平均值，再令平滑半径足够小；最后令舍去的边距趋零。这样才把有限周期见证的比值传递给一般 L1 下界。浮点并集核对、坐标轴零测或简单声称“原子可平滑”均不能替代该接口。

## 6. 新代码实际审查

search_positions.py 实现了以上条件：

- block_indices 生成完整的连续整数指标块，前两方向从四种起始 parity 出发，其余方向从0出发；全部其他起点均可由真实周期平移化到这些代表。质量精确按整数长度乘积 M 计算，side=M^(1/d)，无权重搜索。
- boxes_for 首先计算 indices*spacings，然后对每个真实原子加入 deltas[parity,:]*spacings[2:]。随后对全部点调用 min/max，再形成 low=maximum−side/2、high=minimum+side/2，未沿用旧跨度公式，也未只检查两个指标端点。
