# 独立β截断幂：本轮保守列及后续紧公式

状态：解析推导，待独立审读；本文件未伴随新求值或新LP。第一节的固定R凸性下界是本轮优先路线。后面紧公式不在本轮调用，不能把旧浮点缓存称严格区间。

## 1. 固定R凸性下界与可行基线

作者归一化为 `Aα f=2Σ(j=1,2)∫₀∞[f(x+te_j)+f(x−te_j)−2f(x)]t^(−1−α)dt`。取1<α≤β<2，p=β/α，r=|u|+|v|，Ψγ,R=(r^(−γ)−R^(−γ))_+。

定义y=Ψα,R≥0及Φ(y)=(y+R^(−α))^p−R^(−β)。有Φ(0)=0、Φ凸、Ψβ,R=Φ(Ψα,R)。逐跳凸性 `Φ(b)−Φ(a)≥Φ′(a)(b−a)` 对正/负跳分别相加；截断跳积分先离开0再取极限，在点值生成元存在处得

`AαΨβ,R(x) ≥ Φ′(Ψα,R(x)) AαΨα,R(x) = χβ(r) AαΨα,R(x)`，

其中χβ(r)=p min(r,R)^(α−β)。这是χ对**生成元值**的乘法，不是Aα(χΨα)；不能对样条部分也乘χ。令μβ=pR^(α−β)>0，则χβ≥μβ。Ψα内区生成元是完整r^(−α)的正Cα项加正截断补偿；外区Ψα(x)=0，跳积分非负。因此AαΨα≥0 a.e. away0，得第二界AαΨβ≥μβAαΨα。

凸函数切线还给Φ(y)≥Φ′(0)y=μβy，故Ψβ≥μβΨα。对已证K1=c1Ψα,R+S1，取cβ0=c1/μβ、s=1、T=0，便有Kβ,base≥K1及AαKβ,base≥AαK1。μβ不必≥1；补偿因子1/μβ是关键。比较a.e. off0，通过既有away0分布桥进入超解接口，未宣称生成元在原点局部可积或分布非负。

β=α时p=χ=μ=1全部退化成原式。β=6/5和5/4时分别μβ=(48/47)R^(−1/40)、(50/47)R^(−3/40)，可用整数40次根的Fraction包围；若需一个准确可行参数，可取cβ0上端再向上有理舍入，不必猜μ的浮点符号。此准确基线不意味着浮点矩阵具有严格slack。

严格认证中χ和AαΨα均须向外包围；已知后者非负时可将其下端替换max(0,Lα)，再乘χ的正下端。轴/截断交界可能+∞，不得直接浮点计算0×∞、inf−inf，必须以正分解或邻域解析界处理。分布桥及截断界面的导数跳跃处理见 `../round08/next_kernel_family.md`；新完整样条组合仍须全域核验。

## 2. 外区结构、质量与精确参数化

冻结R=R1=33/20，K=cΨβ,R+sS1+T，c,s≥0。中心三次B样条每坐标支撑半径2h，故canonical类(I,J)的轨道支持满足r≤h(I+J+4)。h=1/32、I+J≤48及H=1/8、I+J≤9均给r≤13/8<R1。粗类按已核四倍细化展开时索引增量每坐标±6，故最大i+j≤4(I+J)+12≤48，支撑保证不变。

r≥R1时T=0、Ψα,R1=0，所以S1=K1≥0，进而K≥0；c和s均非负。AK是非局部量，T在外区仍可有非零生成元，不能从T=0推AT=0，也不能从K外区非负推AK外区非负。

半质量直接积分为 `(1/2)∫R² Ψβ,R=βR^(2−β)/(2−β)`。完整成本为此量乘c，加s乘已证S1的有符号半质量，再加T各项的 `h² orbit_mult/2`（粗为H²）。S1半质量可负，不能取绝对值。先有理化(c,s,t_j)，再Fraction构造a=s*a1+Σt_j a_j，才精确保留外区sS1。逐项独立舍入a不能替代这个步骤。

## 3. 紧完整幂公式（后续路线，本轮不调用）

取u,v>0，r=u+v，fβ=r^(−β)。沿u方向设g(z)=(|z|+v)^(−β)。分布二阶导数为

`g″=β(β+1)(|z|+v)^(−β−2)dz −2βv^(−β−1)δ₀`。

两次分部积分，α∈(1,2)使端项消失，得到单坐标贡献

`Au fβ = 2/[α(α−1)] { β(β+1)(Jminus+Jmiddle+Jright) −2βv^(−β−1)u^(1−α) }`。

总生成元再加交换u,v的一项，不能丢kink delta或作者归一化的2。三段对应z<0、0<z<u、z>u：

* Jright=r^(−α−β) B(2−α,α+β)。
* Jmiddle=v^(−β−2)u^(2−α)/(2−α) ·₂F₁(β+2,1;3−α;−u/v)。
* Jminus=v^(−β−1)u^(1−α)/(α+β) ·₂F₁(α−1,1;α+β+1;1−v/u)。

推导分别令z=u+t并缩放、z=ut、z=−vt/(1−t)，化为Euler beta积分。端点可积指数2−α>0、α+β>0。为避免超几何负大参数，Pfaff变换给

`Jmiddle=v^(−β−1)u^(2−α)/[(2−α)r] ·₂F₁(1−α−β,1;3−α;u/r)`。

Jminus若u≤v，可改为 `v^(−α−β)/(α+β) ·₂F₁(α−1,α+β;α+β+1;1−u/v)`；若u≥v用原式。变换后参数位于[0,1)，但**不会消除**J两项与delta大项的近轴消去。不能以两个float闭式相近视为严格界，也不能未经额外验证将其批量装入LP。紧公式未来须固定高精度、条件数/损失位数诊断和独立原始跳积分核对；本轮不重复第28轮9个完整幂值。

## 4. 截断内区及正补偿

r<R时，

`AαΨβ,R=Aα fβ+4I(R−r)+2I(R+u−v)+2I(R+v−u)`，

其中 `I(d)=∫d∞[R^(−β)−(t+R−d)^(−β)] t^(−1−α)dt`。各d>0。直接表达

`I(d)=R^(−β)d^(−α)/α − d^(−α−β)/(α+β) ·₂F₁(β,α+β;α+β+1;1−R/d)`

有大数相减。分部积分给正表达

`I(d)=β/α∫₀∞(R+w)^(−β−1)(d+w)^(−α)dw ≥0`。

若d≤R，它等于 `β/[α(α+β)] d^(1−α)R^(−β−1) ·₂F₁(β+1,1;α+β+1;1−d/R)`；若d≥R，它等于 `β/[α(α+β)] R^(−β)d^(−α) ·₂F₁(α,1;α+β+1;1−R/d)`。d=R两式均为βR^(−α−β)/[α(α+β)]。d→0具有正的d^(1−α)奇异项，不应将0代入成0×∞。这些恒等式来自同一正积分，仍待下一阶段有限符号/数值交叉核验，非本轮新计算证据。

## 5. 截断外区的正有限积分

定义a_+=max(a,0)。r>R、u,v>0时L_v=(R−v)_+，单坐标为

`AuΨβ,R=2∫[−L_v,L_v] [(|z|+v)^(−β)−R^(−β)] |u−z|^(−1−α)dz`，

L_v=0表示空积分。若v<R，Fubini再给

`AuΨβ,R=(2β/α)∫v^R y^(−β−1)[(u+v−y)^(−α)−(u−v+y)^(−α)]dy`。

括号非负；下端两项相等处可用expm1/log1p形式稳定相减。加交换u,v的一项即总值。这是外区真实生成元，不是K外区结构证明的替代品。r=R及轴须用单侧极限/分布桥单独接合，不能把数值网格排除这些点当全域证明。
