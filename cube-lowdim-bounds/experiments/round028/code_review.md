## 两种生成元表达

SciPy 路线实际采用原始配对差分，不借用旧 `sing2`。每个方向截点 `c=min(a/2,r/8)`，故其前缀未跨越绝对值折点。偶二项式第 k 项为

`2 r^(-beta) (beta)_(2k)/(2k)! r^(-2k) c^(2k-alpha)/(2k-alpha)`。

代码递推、48项之和、首个遗漏项和积分幂一致。对本轮 `beta<=5/4`，相邻偶系数比至多2，积分项另乘小于1的分母比，因此尾比至多 `rho=2(c/r)^2<=1/32`；首遗漏项除以 `1-rho` 是正确的解析尾策略。**实现中的尾数值及全部四则运算仍为 float，不能称向外区间余项。** 其余两段分别为 `(c,a)` 与 `(a,infinity)`，折点两侧表达正确；每方向及总和的外乘2符合冻结归一化。quad 消息、警告、非有限值均使诊断停止，不静默接受。

mpmath 路线使用

`g''(s)=beta(beta+1)(abs(s)+b)^(-beta-2)-2 beta b^(-beta-1) delta_0`。

负原子乘距离权重后的项 `-2 beta b^(-beta-1) a^(1-alpha)` 与系数 `2/[alpha(alpha-1)]` 正确。负半轴 `s=-t/(1-t)`、中段 `a-s=a t^(1/(2-alpha))` 和右段 `s-a=(t/(1-t))^(1/(2-alpha))` 的 Jacobian 与幂消去均正确；两个紧化无穷端点极限确为零。固定60位和 `maxdegree=7` 不保证60位准确度，返回误差只作为数值估计；代码也据此标为非严格数值。

三组 beta、三组 r=1 形状正好9例，两实现正好18个完整生成元值。Gamma 控制与凸性下界沿用已审理论 note 的归一化；差异容差是诊断门槛而非不等式证书。mpmath 估计误差未满足预定阈值会直接停止，禁止重试。两表达交叉吻合仍不能代替 Arb 区间或全域证明。

## 预算、账本与终止

主循环固定一次 Fraction、10项符号、18个 A 值。每个 A 包括两个方向，回调上限10000、全轮180000；cap-th invocation 被记为 started 后、求被积函数前中断，因此实际求值更少而不会越限。`A_started=completed+failed+interrupted` 在正常保存终态处核对。方向和段先挂入行，保存 callback 起点和进度，首次失败或预算中断后不启动下一值。

内部180秒包含 imports 与准备；符号/工具内部阻塞由外层180秒进程组硬限兜底。包装器拒绝已有证据，唯一 `Popen(start_new_session=True)`，超时直接 SIGKILL 专属进程组并等待；正常退出后也清理残留同组进程，无 fallback、重启或调用共享 MATLAB。它保存实际 exit、耗时、源前后 hash 与日志 hash。硬杀时最后 checkpoint 可能仍标 started；必须结合 wrapper 终态报告，不能将 checkpoint 误称全部完成。

审读没有增加研究预算。后续报告应分别列准确 Fraction 证据、有限恒等式结果和非严格18值诊断的实际完成数；即使全部通过，也不产生新弱型上界。
