# 下一解析核族：算子阶数α与奇异指数β分离

状态：纯解析草案，未运行新数值/符号计算，待另一Sol独立审读；不宣称新界，也不改变本轮候选或核验代码。以下算子严格使用作者归一化

`Aα h(x)=Σj ∫R [h(x+te_j)+h(x−te_j)−2h(x)] |t|^(−1−α)dt`

`=2 Σj ∫0∞ [h(x+te_j)+h(x−te_j)−2h(x)] t^(−1−α)dt`。

正半轴积分前的2不能省略。令r=|u|+|v|，固定1<α≤β<2；算子始终是Aα，而非随β变化的Aβ。

## 1. 完整幂的逐跳凸性下界

取f=r^−α、p=β/α≥1。对a>0、b≥0，凸性给 `b^p−a^p≥p*a^(p−1)*(b−a)`。分别代入f(x±te_j)，相加并积分。在uv≠0处，两条坐标线都不经过原点，f与f^p在线上有界且在x附近C²；小跳二阶差为O(t²)，大跳尾可积，故两边积分绝对收敛，不能用两个分别发散的一阶增量替代配对差。

引用已审Tomar Lemma3.4（同归一化）的 `Aα f=Cα r^−2α`，其中

`Cα=−8 Γ(1−α)Γ(2α)cos²(πα/2)/Γ(1+α)>0`，

得到

`Aα r^−β >= (β/α) Cα r^(−α−β)>0`（uv≠0）。

β=α为等式；β>α时这是保守下界，不是完整角向公式。它没有宣称r^−β在整个平面可积，也没有把原点外分布正性延伸到包含原点的测试函数。β<α不在此结论内；论文指出其近轴负项可能占优。

## 2. 独立的二阶导数表示及边界项

固定u,v>0，令g(s)=(|s|+v)^−β。其一维分布二阶导数为

`g''=β(β+1)(|s|+v)^−β−2 ds −2β v^−β−1 δ0`。

于是坐标u的贡献应为

`Aα,1 g(u) = 2/[α(α−1)] * { β(β+1) ∫R (|s|+v)^−β−2 |s−u|^(1−α)ds −2β v^−β−1 u^(1−α) }`。

证明不忽略s=0的尖点项：二阶差分的三角核恒等式给 `Δt g(u)=∫(t−|s−u|)+ dg''(s)`；再用

`∫a∞ (t−a)t^−1−α dt = a^(1−α)/[α(α−1)]`。

乘正半轴归一化2并交换积分即得。交换对总变差也成立：s=u处的权|s−u|^(1−α)可积，因为α<2；s=0的原子离u>0，权有限；远尾为O(|s|^−α−β−1)。等价分部积分中的无穷远边界项 `g'|s−u|^(1−α)`、`g ∂s|s−u|^(1−α)` 均为O(|s|^−α−β)而消失。此式仍须独立核对归一化与数值实现，不可把仅适用于β=α的sing2闭式当成它。

## 3. 原点外分布桥（证明草案，供审读）

对H=r^−β或 `Ψβ,R=(r^−β−R^−β)+`，以及任意有限张量三次B样条S的线性组合，有以下候选引理：uv≠0、且截断项r≠R时AH绝对收敛；并存在原点外局部可积的a.e.代表，使

`∫ H Aαφ = ∫ (AαH)φ`，对所有 `φ∈C∞c(R²\{0})` 成立。

**局部绝对控制。** 固定紧集E远离原点，取η>0使其2η邻域仍远离原点。H在该邻域分片C²、局部Lipschitz，接口仅坐标轴与r=R的有限条线段，法向一阶导跳跃有限。若x到接口距离为δ，|t|<δ/2时二阶差≤Ct²，其余δ/2<|t|<η时≤C|t|。因此短跳绝对积分≤C(1+δ^(1−α))。δ为多个接口距离的最小值时，以各距离幂之和控制，仍局部可积，因为α<2。

长跳|t|≥η若坐标线接近原点，利用

`∫R (|s|+a)^−β ds = 2 a^(1−β)/(β−1)`（a>0），

以及权≤η^−1−α，得到分别为C|v|^(1−β)、C|u|^(1−β)的控制；−2H(x)项在E上有界。样条有限、C²且紧支撑，无额外奇异性。故可取

`G(x)=Σj∫R |ΔtH(x)| |t|^−1−α dt`

`<= C_E[1+|u|^(1−α)+|v|^(1−α)+dist(r,R)^(1−α)+|u|^(1−β)+|v|^(1−β)]`，

其中无截断时去掉r=R项。轴幂横向可积要求α<2与β<2；r=R在各象限为线段，同样可积，交点用这几个可积项的和控制。因此G∈L1loc(R²\{0})。轴上或r=R处的点积分可能为+∞，但不是以“测度零”代替本段可积证明。

**另一种短跳核对。** 在E的邻域，H的一阶梯度局部BV，二阶分布导数为局部有限测度（分片有界Hessian加有限接口跳跃）。对局部平滑化用三角核恒等式再取L1极限，可得 `∫E |ΔtH| <= C_E t²`。于是短跳联合绝对积分由 `∫0η t^(1−α)dt<∞` 控制。它与上述逐点距离估计一致，可独立审查接口项。

**交换及极限。** 对|t|>ε的Aε先由Fubini和x↦x±te_j换元，得 `∫H Aεφ=∫φ AεH`。截断H和S全局L1；完整r^−β虽然非全局L1，但任意有界E的平移满足 `∫E+y r^−β <= |E|+4/(2−β)`，故大跳联合积分也有限。右边以G支配通过ε↓0。左边的小跳差只支持在suppφ的固定η邻域，那里H有界，且|Δtφ|≤Cφt²，故误差O(ε^(2−α))；远处配对对ε<η不再变化。等价地，Aφ的远尾只在两条条带中出现，乘r^−β后为O(|x|^−1−α−β)，可积。由此闭合换序极限。

因此若有限组合K在这些规则点上AK≥0 a.e.，则对原点外非负φ有分布正性。**尚需独立审读的是本引理适用类/接口常数与论文比较定理假设的逐项对应；它不是当前任何新样条系数的全域正性证明。** 原点附近AK一般不可积（α+β>2），不能将结论写成整个平面上的非负函数分布，也不能省去“测试支持避开0”。

## 4. 截断公式与样条组合

令 `Iαβ(d)=R^−β d^−α/α − Jαβ(d)`，其中

## 5. 纯截断幂的成本障碍（解析证明）

若无样条，D上支配要求R>1且 `c>=1/(1−R^−β)`。即使暂不加生成元条件，半成本也至少

`Fβ(R)=β/(2−β) * R²/(R^β−1)`。

其对数导数为 `[(2−β)R^β−2]/[R(R^β−1)]`，唯一驻点为 `R^β=2/(2−β)`，两端R↓1及R→∞时成本均发散，故全局最小值

`min_R Fβ(R) = [2/(2−β)]^(2/β)`。

令z=β/2，则log最小值 `−log(1−z)/z=∫0¹(1−zt)^−1dt` 随z严格增加。β≥1时最小值≥4，等号仅β=1；本族β≥α>1，故实际上>4。该下界只用质量/支配，已足以说明**纯**截断幂无法改进3.59，更无法到3.4；需要样条/其他可控形状以交换生成元余量和质量。此解析证明计划另用有限SymPy恒等式核对，当前未运行。
