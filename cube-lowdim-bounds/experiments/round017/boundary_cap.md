# 支撑边界近轴角域的解析上包络

2026-10-24。本附件证明一个固定、有正面积的参数角域可直接覆盖，无需把它继续分成大量二维tiny盒。唯一候选仍为R=15/8、e2=69/100、e6=19/50、e7=11/10、e8=3/4，其他0。**严格结论仅为该角域的局部生成元正性，不是全域认证或新一般上界。** 未新增LP、网格、直接积分或自适应运行。

## 1. 覆盖域和目标

由对称性取u>=v>=0，r=u+v、q=(u-v)/r。固定角域

Bcap=[99/100,1]×[99/100,1]（r,q），参数面积1/10000。

置s=1-r、a=1-v、b=1-u、n=p-1。开象限内

Apsi_p=a^n h_p(u/a)+b^n h_p(v/b)。

在Bcap有v<=1/200、a>=199/200、s<=1/100，因此

0<=1-u/a=s/a<=epsilon:=2/199，tau:=1-epsilon=197/199，

0<=b=1-r(1+q)/2<=bmax:=299/20000。

目标是将首切片上界写成Hp加显式模连续余项，第二切片则用全内区有限上界乘小幅度b^n。全程只取Apsi_p上界，因为G=AH_R-sum e_p Apsi_p且e_p>=0。

## 2. p2的显式epsilon log epsilon余项

已审切片式给出

h2'(t)=4 log((1-t)/(1+t))+8/t，0<t<1。

令eta=1-t，积分到1并用log(2-z)<=log2、1/(1-z)>=1，得到

h2(1-eta)-H2
=4 integral_0^eta [log(2-z)-log z-2/(1-z)] dz
<=4 eta[log(2/eta)-1]。

右侧在0<=eta<=epsilon<=1/4递增，因为导数为4[log(2/eta)-2]，而log8>2。故

h2(t)<=H2+omega2，
omega2=4epsilon[log(2/epsilon)-1]=4epsilon(log199-1)。

这是包含(1-t)log(1-t)的余项，没有错误地假设h2在t=1有有界导数。

还可用一个较紧的全域上界h2(t)<=4。证明：F(t)=(1+t)log(1+t)+(1-t)log(1-t)满足F(0)=F'(0)=0、F''=2/(1-t²)>=2，所以F(t)>=t²。于是

h2/4=2-F(t)+2log t<=2-t²+2log t<=1，

末步使用log(t²)<=t²-1。端点t=1按连续值理解，t趋0时的负发散不会破坏上界。因此第二切片可取M2=4。

## 3. p6、p7、p8的单侧有界导数

对p>=3，令m=p-2>=1，使用第16轮J_m的正参数分支，有限公式求导可得

h_p'(t)=2p(p-1)[J_m(1+t)-J_m(1-t)]+4p/t。

本次已用本机SymPy对p6、p7、p8逐个验证该恒等式，精确残差为0，没有评价新增切片点。也可由分部积分关系J_n'(a)=nJ_(n-1)(a)-1/(1-a)直接证明。

对tau<=t<1、eta=1-t∈(0,epsilon]，

-J_m(1+t)=integral_0^1 z^m/(1+t-z) dz<=1/[tau(m+1)]，

J_m(eta)=sum(k=0,...,m-1) eta^k/(m-k)+eta^m log((1-eta)/eta)
<=sum epsilon^k/(m-k)+epsilon^m log(1/epsilon)。

最后一项的比较使用x^m log(1/x)在[0,epsilon]递增；epsilon<=1/4保证m log(1/epsilon)>1。再用4p/t>=4p，可得h_p'>=-L_p，其中

K_m=1/[tau(m+1)]+sum(k=0,...,m-1) epsilon^k/(m-k)+epsilon^m log(1/epsilon)，
L_p=max(0,2p(p-1)K_m-4p)。

故h_p(t)<=Hp+omega_p，omega_p=L_p epsilon。保留正项4p/t很关键；若把它丢掉，导数界会不必要地扩大约一个数量级。p>=3的导数在t=1有有限极限，积分延伸合法。

## 4. 第二切片的全t上界

对任意0<t<1，首个加权log(t/(1+t))为负，可舍去；令x=1-t，另一项满足

x^n log(t/x)<=x^n log(1/x)<=1/(ne)<1/(2n)。

多项式项满足(1+t)^k+(1-t)^k<=2^k+1。因此可取

M_p=2p[sum(k=0,...,n-1)(2^k+1)/(n-k)+1/(2n)]，p∈{6,7,8}。

精确值为M6=293、M7=9821/15、M8=30668/21。它们虽较粗，但乘以bmax^n后已很小。M2另取第2节的4。

由于a^n<=1且Hp+omega_p>0，首切片至多Hp+omega_p；第二切片至多bmax^n M_p。于是整个角域的统一上界为

Apsi_p<=U_p:=Hp+omega_p+bmax^(p-1)M_p。

该推导涵盖任意接近轴的正坐标点，不需要在hp的负发散处数值求值。在q=1、r<1上，垂直切片的cusp给负扩展值，上界仍安全；r=q=1时b=0，垂直支撑切片恒零，不能代入0/0。r=1、q<1的切片参数是1，采用已证Hp端点值。一般传递只需轴外a.e.及既有分布接口；本证明没有以错误的角点双侧连续性替代这些接口。

本次实际只运行一次常数核验和3条符号导数恒等式；无hp/bump点值、无LP、无网格、无直接积分、无自适应。所用对数核心hash为ed7a2460b2b71333072093843aa5818b822d11d07bbf7d6ba70b841d1c0485e2。

以下最小常数代码可在加载已审第8轮核心为c后复现上式，不运行任何搜索或盒划分：

```python
from fractions import Fraction as Q
R=Q(15,8)
e={2:Q(69,100),6:Q(19,50),7:Q(11,10),8:Q(3,4)}
eps=Q(2,199); tau=1-eps; bmax=Q(299,20000); r0=Q(99,100)
l2=c.log_point(2)
H={2:8-8*l2,6:Q(1334,5)-384*l2,
   7:Q(3108,5)-896*l2,8:Q(149104,105)-2048*l2}
omega={2:4*eps*(c.log_point(199).hi-1)}
M={2:Q(4)}
for p in (6,7,8):
    m=p-2; n=p-1
    K=1/(tau*(p-1))+sum((eps**k/Q(m-k) for k in range(m)),Q(0))
    K+=eps**m*c.log_point(1/eps).hi
    omega[p]=eps*max(Q(0),2*p*(p-1)*K-4*p)
    M[p]=2*p*(sum((Q(2**k+1,n-k) for k in range(n)),Q(0))+Q(1,2*n))
U={p:H[p].hi+omega[p]+bmax**(p-1)*M[p] for p in e}
F=sum((r0**j/((j+2)*R**(j+1)) for j in range(29)),Q(0))
T=2*(2*F+1/R)/(R-1)
margin=T-sum((e[p]*U[p] for p in e),Q(0))
assert margin>0
print(margin)
```

## 6. 与中心化比较的关系及限制

此cap直接处理的是r,q同时接近1的支撑角点；它不处理离边界的活跃盒，也不自动消除第17轮剩余9个负下界盒。第17轮旧/新包含界比较及第16轮未闭合证书的状态不会被本附件追溯改成成功。

主审另外保存的第一个活跃盒中心完整G严格下界>0.0841645227862181，仅说明该中心不是反例。其全盒新下界仍约-0.293978，提示在远离v、s、z-零集合的区域，可将更多或全部G_N纳入光滑Taylor以减少单侧余项的依赖损失；仍须完整的导数包含和全域覆盖，不能由中心正值推断整盒非负。本cap可作为后续边界机制的一部分，但不自行批准后续全域认证或改变严格一般上界。
