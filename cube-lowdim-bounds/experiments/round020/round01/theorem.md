 B0=(92947264679849/36283883716608)(33/20)^(33/40)
    −632486554619619/2251799813685248。

则本轮证明

 C2 ≤ B1 := (100000/100009) B0
    < 359091/100000 = 3.59091
    < 3.59123，且B1<B0。

B1约为3.590901146403276050426939597；近似值只用于展示，严格比较来自scaling_arithmetic.json的有理上下端。此结论严格低于公开准确证书成本，而非仅低于其向上取整展示值。

## 1. 外部比较定理与分布接口

使用[Tomar论文](https://www.mefyi.com/papers/weak-type-squares/weak-type-squares.pdf)第2.2节的Lin比较定理及Lemma3.1，锁定源码为[公开v4仓库](https://github.com/tejasvi/square-maximal-weak-type-v4)，commit bca281a706bbf6375b04d601ad19ba4ad0bf28b6。此处将其解析结果作为外部依赖，不声称重新证明全部障碍解存在性或Courrège步骤。

记D={|u|+|v|≤1}，生成元采用论文和核验器共同的全实线二阶差分归一化

 Af(x)=Σ(j=1,2) ∫R [f(x+te_j)+f(x−te_j)−2f(x)] |t|^(−1−α)dt。

该比较结果说：0<α<2，偶核K∈L1非负、在D上至少1，且对每个非负φ∈C∞c(R²\{0})有∫K Aφ≥0，则C2≤(1/2)∫K。与Fourier标准生成元之间仅差正因子，不能混用归一化计算成本。

对1<α<2的有限张量三次B样条加截断r^−α核，Lemma3.1把原点外的几乎处处AK非负转成上述分布正性。该接口处理轴及r=R附近的可积二阶差分控制；不能仅凭这些集合测度零而跳过隐藏分布项，也不要求AK在原点附近是有限测度。

公开第二完整核验报告中，C2全域接受叶的下界最小值被包围在[1.000099345±3.68e−10]。其有理下端为m=125012418079/125000000000；故D上K0≥m，且

这里使用的是扣去显示半径后的下端。新证书也已重新通过完整C2核验，不只依赖旧报告的裕量推断。

## 3. 半积分成本与严格公开比较

因为∫B=1，完整样条系数按D4重数展开后

 (1/2)∫K0 = c0 α R^(2−α)/(2−α) + (h²/2)Σaij = B0。

新核的半积分为B1=θB0。exact_cost.json以整数40次根和精确分数给L0≤B0<U0；scaling_arithmetic.json保存L1=θL0、U1=θU0，并精确验证

 U1 < L0，U1 < 359091/100000。

于是B1<U1<L0≤B0，且比较定理给C2≤B1<3.59091。两次新核验输出的Arb质量球都包含此准确成本区间；并未把float小数作为严格成本。

## 4. 全部输入、阈值和尺度

比较定理已经针对全部正实尺度s的Ks=s^−2K(·/s)，不是只针对检查网格或单一尺度。论文的传递链先处理光滑紧支撑非负输入，再经平滑到有界紧支撑可测输入，最后以fn=min(|f|,n)1{|x|≤n}单调逼近一般L1输入；非负核确保卷积、尺度上确界和严格超水平集的单调极限。共同零集及尺度连续性属于该外部定理的已引用证明，不能直接对不可数尺度的一族零集取并。

线性映射T(u,v)=(u+v,u−v)把D送到[−1,1]²，|det T|=2；水平集体积和L1范数同时乘2，故弱型比值不变，成本保留半积分。因此对每个f∈L1(R²)及每个t>0，有

 t |{x:Mf(x)>t}| ≤ B1 ||f||1。

对任意0<s<t，{Mf≥t}⊂{Mf>s}；先应用上式再令s↑t，亦得t|{Mf≥t}|≤B1||f||1。结论不只限于原子输入、有限补丁、有限尺度、平滑函数或数值测试点。
