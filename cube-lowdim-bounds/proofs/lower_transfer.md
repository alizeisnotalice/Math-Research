# 下界证书、完整原子入口与 L1 传递

## 1. 有限原子的精确覆盖公式

设 \(\mu=\sum_{i=1}^Nw_i\delta_{z_i}\)，\(w_i>0\)，阈值 \(\lambda>0\)。对非空子集 S 设
\[
r_S=\tfrac12(m_S/\lambda)^{1/d},\quad m_S=\sum_{i\in S}w_i,
\quad B_S=\prod_j[\max_{i\in S}z_{ij}-r_S,\min_{i\in S}z_{ij}+r_S].
\]
反向区间为空，则 \(\{M\mu\ge\lambda\}=\bigcup_S B_S\)。正向由盒子中心对应的见证方体包含 S 得出。反向：对于非原子点，平均值只可能在有限个“首次接触原子”的距离处达到最大值，之后直到下一接触前分母严格增加；原子点则单原子即可见证。取达到阈值的方体及其中全部原子 S，其半径不超过 rS，故中心属于 BS。

严格超水平集恰等于这些盒子内部的并：严格见证半径小于 rS；反向对盒子内部中心可略微缩小半径而仍包含 S。因此严格与非严格集合只差有限个盒子边界，测度相同。

把 S 扩为其坐标包围盒内的全部原子 T，极端坐标不变而质量不减，故 \(B_S\subseteq B_T\)。只枚举这类闭合子集不损失覆盖，候选最多由 2d 个坐标端点决定，即 O(N^(2d))。此公式保留任意权重、位置和原子数；任何固定 N 搜索仍不能替代对所有 N 的上界证明。

## 2. 原子与 L1 输入的双向传递

下界方向：有限见证族的最小边长 \(s_{\min}>0\)。把每个原子换成以它为中心、边长 \(\eta\)、同质量的小方体密度。原见证边长 s 增至 \(s+\eta\) 后包含全部平滑质量。在原覆盖上，平均至少
\(\lambda(1+\eta/s_{\min})^{-d}\)。使用略低于它的严格阈值，再令 \(\eta\downarrow0\) 及阈值损失趋零，即得相同弱型比值下界。

上界方向：若所有有限正原子、所有阈值均满足同一个 C，则先取非负紧支撑 f，把边长 h 网格的每格全部积分质量放到格中心。总质量不变。对任何中心 x 的严格见证 \(\int_{Q(x,r)}f>\lambda(2r)^d\)，网格原子在 \(Q(x,r+h)\) 中的质量至少为该积分，故 h 足够小时其平均仍大于 lambda。由点态 liminf 包含和 Fatou，连续 f 满足同一个界。随后用非负截断推广到一般 L1 输入。常数传递无损，也不要求网格点总数预先有统一上限。

## 3. 周期覆盖及边界结算

若周期格子每周期质量 m，基本胞腔内有可测覆盖 E，且 E 上只使用有限类型、有限平移距离的见证，则
\[
c_d\ge\lambda |E|/m.
\]
保留索引在 \([-N-b,N+b]^d\) 的周期质量，其中固定整数 b 足以容纳全部见证；只接收 \([-N,N]^d\) 个胞腔的 E 平移。总质量为 \((2N+2b+1)^d m\)，接收体积为 \((2N+1)^d|E|\)。胞腔使用半开约定，边界零测。先平滑并略降阈值，再令 N 趋无穷、平滑尺度及阈值损失趋零。这样周期非可积问题、共享质量和严格阈值均被处理。

附件均匀格子的 \(\ell_j\le4\) 见证索引在 [-1,2]，故 b=2 足够；附件写出的 \((2N+1)/(2N+5)\) 质量因子正确。各见证始终使用同一个标量半径，矩形格点间距不等不意味着平均集合变成了长方体。

## 4. 已有三、四维证书审计

`verify_bounds.py` 以 \(10^{12}\) 为坐标分母，整数求根向下取整确保见证质量不小于方体体积；逐项端点距离检查覆盖整个盒子。递归扫描与网格位掩码两种算法计算同一整数并集体积。本地复跑输出与输入证书完全一致；原始内部材料不随仓库发布。

`algebraic_bounds.py` 使用正实根 \(u^d=2,v^d=3\) 的有理隔离区间和有理多项式计算。非零符号必须经区间分离；无法分离就报错。形式系数相同必然代表相同实数；即使不额外证明基底线性无关，也不会造成错误符号断言，因为非形式零的符号均需区间证明。重跑得到
\[
1.79393322779477<R_3<1.79393322779478,
\quad1.90174261110095<R_4<1.90174261110096.
\]
结合第 3 节，\(c_3\ge R_3,c_4\ge R_4\)。这是附件已有结果的审计，不记作本阶段新下界。
