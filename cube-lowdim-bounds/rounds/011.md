## 1. 原子位置、周期和质量

原子由 n∈Z^d 索引，q=2(n0 mod2)+(n1 mod2)，parity 顺序为 `(0,0),(0,1),(1,0),(1,1)`。前两个坐标保持 `x_j=n_j*a_j`；后续坐标取

\[
x_j(n)=n_ja_j+a_j\delta_{q,j-2},\qquad j=2,\ldots,d-1.
\]

三维中 δ 为4×1矩阵，按前两个 parity 对第3坐标施加四种位移；四维中 δ 为4×2矩阵，并包括对第3、4坐标同时施加不同 parity 模式的耦合扰动。每列减去四个值的均值以消除共同平移。

间距与既有控制一致。若 `u=2^(1/d),v=3^(1/d)`，则

\[
a_0=1+u^{d-2}/2,\quad a_1=(2+u^{d-1}v)/4,
\quad a_j=(1+u)/2\ (j\ge2).
\]

平移 `2*a0`、`2*a1` 不改变前两个 parity；沿其它轴平移一个间距也保持同一 pattern。因此实际基本周期是 `(2*a0,2*a1,a2,...)`，其中恰有四个不同 parity 原子，每个质量1，完整质量为4。没有反射倍数或质量归一化误差。浮点舍入可能使去均值列和只在机器精度内为零，不影响位置定义和周期性。

## 2. 真实 block 几何和共半径盒

枚举范围与第6轮相同：每个坐标方向的 index block 长度为1、2、3、4，前两方向 start parity 各为0或1，共4个起点类；其余方向起点固定为0，因为这些方向的整数平移正是周期。

每个 block 的原子数及总质量均为 `m=prod(lengths)`。对应同一立方体边长为 `L=m^(1/d)`。代码先生成 block 内所有整数索引点，再逐个计算真实扰动坐标，取每轴

\[
p_j^{\min}=\min_{n\in B}x_j(n),\qquad
p_j^{\max}=\max_{n\in B}x_j(n).
\]

可同时覆盖这些原子的立方体中心盒是

\[
\prod_j[p_j^{\max}-L/2,\ p_j^{\min}+L/2].
\]

若任何方向上端不大于下端，该盒体积为零并丢弃。这里绝未继续使用旧的 `(start+length−1)*spacing` 极值公式；parity 位移对完整 block 的影响已进入真实 `points.min(axis=0)` 与 `points.max(axis=0)`。

每个有效盒按真实周期逐轴 wrap 到基本胞，长度达到整个周期时覆盖该轴全部；跨边界的盒拆成完整碎片。合并后计算真实 union 体积，再除以4。这是被枚举 block 所提供的见证中心集合，不声称已枚举所有可能的原子子集或所有立方体见证。

## 3. 预定80项日程与随机种子

三维共80项：

- 1个零扰动控制。
- 24个第3坐标单 parity 扰动：4个 parity × 6个幅度，幅度为 ±0.01、±0.04、±0.1 倍第3间距。
- 18个第3坐标 row、column、checkerboard 模式：3个模式 × 同样6个幅度。
- 剩余37个为四 parity 的 joint 随机位置扰动，种子 `2026102414=2026102411+3`。

四维共80项：

- 同样1个控制、24个单 parity 和18个第3坐标模式。
- 18个第3、4坐标耦合模式：第3坐标依次取 row、column、checkerboard，第4坐标取下一个不同模式，并用同样6个幅度。
- 剩余19个为4×2 joint 随机位移，种子 `2026102415=2026102411+4`。

随机位移先逐项从 `[−scale,scale]` 均匀抽取，scale依次循环0.01、0.04、0.1，再逐列去均值。去均值后的绝对幅度不必仍小于 scale；记录的 δ 才是最终实际参数。单 parity 的幅度指去共同平移前该 parity 相对其余点的位移差；去均值不改变这种相对位移。

这与更换第6轮权重随机种子有实质区别：权重始终全1，变化变量仅是 parity 相关位置。

## 4. 最佳非零构型

三维最佳为第80项、随机 scale=0.01 的 joint 位置扰动，位移以第3间距为单位按 parity 顺序为

```
[-0.0015498598689774176,
  0.0010172812084224470,
 -0.000009198823530885171,
  0.0005417774840858567]
```

其 union 盒数为69，分数 `1.7919450784365656`。相对参考基准差为 `−0.0019881493582047938`，相对本轮零控制差为 `−0.0019881493582043497`。

四维最佳为第4项、第3坐标对 parity `(0,0)` 作 −0.01 倍间距的相对位移，去均值后两个坐标的位移矩阵为

```
[[-0.0075, 0.0],
 [ 0.0025, 0.0],
 [ 0.0025, 0.0],
 [ 0.0025, 0.0]]
```

其 union 盒数为217，分数 `1.8941575821799068`，低于基准 `0.007585028921048842`。

## 5. 独立端点分胞体积核对

发现目标使用递归 union sweep；核对算法则收集全部盒端点，将基本胞划分成 elementary endpoint cells，以 boolean 数组标记各 cell 是否被至少一个盒覆盖，再按各轴 cell 宽度积分。为控制内存，只沿一个轴分 slab，所算对象仍是全部端点 cell。核对算法不调用递归 union 体积例程，但共享被核对的实际盒列表；因此这是体积算法的独立核对，不是对盒生成步骤的第二套实现。

实际核对结果：

|维数/构型|端点 cell shape|cell总数|分胞分数减递归分数|
|---|---|---:|---:|
|3/零控制|22×26×13|7436|+6.661338147750939e−16|
|3/最佳非零|22×26×27|15444|+6.661338147750939e−16|
|4/零控制|39×42×21×21|722358|−8.881784197001252e−16|
|4/最佳非零|39×42×29×21|997542|−2.220446049250313e−16|

四项均实际运行完成，没有触发资源跳过。预设上限为总20亿cell及每slab3200万boolean cell；实际最大slab只有23751个boolean cell。分胞算法对四维零控制给出约 `1.9017426111009548`，对最佳非零给出约 `1.8941575821799066`，与发现值在浮点求和误差范围一致。

这些都是实际本机 Python/NumPy 运行结果，是浮点体积核验，不是有理或区间认证。代码中的新候选触发阈值为比参考基准高 `1e−10`，用来避免机器舍入误触发；本轮所有158个非零构型甚至都严格低于参考浮点值，因此阈值选择不影响本轮有限失败结论。
