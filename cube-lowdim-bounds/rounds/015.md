# 第15轮联合质量位置实验报告

结论：在预定六维范围和有限预算内，**未找到超过 Lin 基线的数值候选**。这不证明该六参数族不可能改进，也不产生新的严格下界。

本轮确实联合改变 `h,V,w` 与卫星 `(x,y,m)`，并非只重复第9轮的三变量位置质量搜索。每周期 `(2h,V)` 的原子为 `(0,0;1)`、`(h,0;w)`、`(2hx,Vy;m)`，归一化分母一直是完整质量 `1+w+m`。通过参数化补丁构造器调用未修改的第9轮几何核心，枚举真实 `3×3` 周期补丁中的所有坐标端点闭矩形及其中全部原子，使用同一半径 `sqrt(M)/2`，真实 wrap 后计算矩形并集面积。没有把局部子集的质量当作完整周期质量。

实际使用本机 `math-research-tools` Python 环境执行 `python3 round015/search.py`。预先写定的边界为 `h/h0,V/V0∈[.85,1.15]`、`w/w0∈[.7,1.3]`、`x,y∈[0,1]`、`logm∈[log(1e-4),0]`。SciPy DE 使用固定种子 `2026102415`、六维 `popsize=10,maxiter=14,polish=False`、单进程 immediate 更新以及 `tol=atol=0`。旧最佳非零控制作为 `x0`。实际完成14代900次DE调用，加两个控制共902次目标调用；另外仅重建两次固定几何作独立并集核对，总几何构造904次。硬目标计数上限1000，未扩大边界、未追加优化或 polish。

排除初始旧控制后，DE实际最佳新参数行是第637次调用：`h/h0=.9866808832162908,V/V0=.9850365498220529,w/w0=.9574539817127441,x=.9247534849444445,y=.813091698990051,m=.00015199386433868787`，分值 `1.6846933999663398`，同样低于基线。该行仅作有限探索效果的补充记录，不代替总最佳行。

对零卫星基线和最终最佳非零行，使用第9轮独立端点单元标记法重新计算并集，未调用递归并集函数来取得独立面积。**两次核对共享同一套盒生成逻辑，只有并集算法独立，不能称为独立的原子枚举或见证生成审计。** 两行的并集面积绝对差均为 `8.881784197001252e−15`，分值绝对差均为 `1.7763568394002505e−15`。这核对了实际矩形并集的两种双精度实现，不能当作有理区间证明。有限补丁只提供可行见证，未枚举更大尺度的见证不能据此断言不存在更优参数。

DE返回 `success=False`、消息 `Maximum number of iterations has been exceeded.`，原因是到达预定14代上限；程序正常退出并保存结果，不将此返回值解读为全局收敛或不可行证明。初始 `x0` 旧控制本身是900次DE评价中的一次（总计第3次调用）；另有此前第2次控制调用，所以相同控制实际评价两次，两次均计入902总数，没有隐去重复调用。

## 独立几何审查、复现与后续

原结果字段independent_geometry_rebuilds=2是历史命名，只指同源盒重建后的独立并集算法核对；不能用它宣称独立验证整个几何流程。另一次审查从原子平移、闭矩形全集和整数周期裁剪重新实现5个固定配置，见[几何审计](../experiments/round015/geometry_audit.md)。该检查不调用生产patch/witness生成器，使用端点单元比较覆盖集合；仍是浮点几何审查，非有理下界证书。

主审在归档目录实际运行5配置移植核验通过，对称差面积全部为0，面积差最大1.7763568394002505e−15，详见geometry_verification.json。

从项目根运行python3 experiments/round015/verify_geometry.py，仅核验保存的固定配置，不运行DE。完整有限搜索由search.py复现，需NumPy/SciPy；已有result.json或同名临时轨迹时拒绝覆盖。复跑应在独立副本与空的临时目录中进行，不以删除既有证据为前提。

本轮无新的已证上下界。二维一般上界继续为411881/106500，三、四维与各维下界不变。第13—15轮总结见[第五阶段](../STAGE_05.md)。下一阶段先研究更丰富幂次基的上界形状选择；下界不继续用本构型仅换种子，而需改变周期或见证结构。
