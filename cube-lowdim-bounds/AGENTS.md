# 项目长期记忆与执行约定

## Git 提交方式（用户明确要求，2026-10-24）

每次创建本项目的 Git 提交，都必须实际执行 `git commit` 命令。不得以其他工具的提交接口或底层 Git API 代替。提交成功后核对命令退出状态及生成的提交哈希；仅暂存、写报告或准备提交信息不算完成提交。

本条与仓库根目录的逐轮提交、明确文件白名单、推送及远端包含核验规则同时执行。
