# R003 固定尾参数下的首轴事件法：证明与未运行候选

## 范围与状态

固定维数 8、尾间距 `a=(1+2^(1/8))/2`、长度族 `{1,2}×{1,2,3,4}^7`，只改变首轴间距 `s>0`。本文证明该有限盒族的完整 union 体积 `V(s)` 为连续分段仿射函数，并给出全正 `s` 的有限安全事件集和尾部饱和点。此结论只优化这一固定参数族；不是八维中心立方体极大算子弱型常数 `C_8` 的最优性证明，也没有扩大长度族。

实际运行仅有 `python3 -B certify_events.py`：标准库整数八次根、有理区间、240 轨道尾盒符号、事件去重与次序、16 个候选邻近排序。没有运行任何完整 union 或 finite L1 计算，没有提交或推送。`event_certificate.json` 给出可复核根下端和精确有理区间；展示小数不作证明依据。原 R001/R002 文件仅只读参考，脚本未导入或执行其 union 代码。

## 1. 盒的精确形式

记 `r_m=m^(1/8)/2`。对尾标签 `t=(t_2,…,t_8)`，令 `p=∏t_i`，首标签为 `j∈{1,2}`，半径为 `r_{jp}`。在一个正半胞内，尾盒为

`T_{j,t}=∏_{i=2}^8 [max(0,c_i a-r_{jp}), min(a/2,q_i a+r_{jp})]`，

其中奇数长度时 `q_i=-floor(t_i/2)`，偶数长度时 `q_i=1-t_i/2`，并且 `c_i=q_i+t_i-1`。退化或空尾盒可丢弃，因为它的八维体积恒为零。记剩余轨道集合为 `B_1,B_2`，并按完整尾坐标排列解释每个轨道，不能把一个轨道当一个物理盒。

首轴区间精确为

* `j=1`：`I_{1,p}(s)=[0,min(s/2,r_p)]`；
* `j=2`：若 `0<s<2r_{2p}`，`I_{2,2p}(s)=[max(0,s-r_{2p}),s/2]`；若 `s≥2r_{2p}`，丢弃其零体积或空盒。

第二式来自原上端 `min(s/2,r_{2p})`：非空性强制 `s<2r_{2p}`，故上端就是 `s/2`。这一步解释了为什么无需把所有下端、上端形式两两任意配对。

令 `U(s)` 为上述全部盒和尾排列的并，则 `V(s)=2^8 |U(s)|`，与 R001/R002 的完整对称 union 口径一致。

## 2. 完备安全事件集

令 `P_j={jp : T_{j,t} 有正七维体积}`。下列集合允许包含未造成真正转折的冗余事件：

`E = {r_q:q∈P_2} ∪ {2r_m:m∈P_1∪P_2} ∪ {r_p+r_q:p∈P_1,q∈P_2,p<q}`。

在不含事件的任一正开区间 `J` 中：

1. 每个 `j=2` 盒的存亡只在 `s=2r_q` 改变。
2. 它的下端分支 `0`/`s-r_q` 只在 `s=r_q` 改变。
3. 每个 `j=1` 上端分支 `s/2`/`r_p` 只在 `s=2r_p` 改变。
4. 分支固定后，活动首轴端点只可能为 `0,s/2,r_p,s-r_q`。两个常数端点或两个斜率为 1 的端点的次序固定。`s/2` 与其余形式相遇已列在第 1–3 项。仅剩 `r_p=s-r_q`，即 `s=r_p+r_q`。若 `p>q`，该相遇发生时 `j=2` 盒已消失，且 `j=1` 的真实上端尚未成为 `r_p`；故只需 `p<q`。`p=q` 已包含在 `2r_p`。

因此在 `J` 上，全部活动端点的排列固定。按首轴端点切分后，每条首轴薄片的尾截面是一个固定七维盒并。记其体积为 `W_k`，两端为仿射函数 `A_k(s),B_k(s)`，便有

`V(s)=256 Σ_k (B_k(s)-A_k(s)) W_k`，

故 `V` 在 `J` 上仿射。每个盒随 `s` 连续变化（以对称差体积衡量），有限并也连续；盒在消失事件处的首轴宽度趋零。因此 `V` 在各事件处连续，结论覆盖所有正 `s`。

这给出全覆盖证明，而非一次有限采样的经验观察。

## 3. 全正参数的尾部饱和与有限最大值

当 `s≥S*=2 max_{m∈P_1∪P_2}r_m` 时，全部 `j=2` 盒消失，全部 `j=1` 首轴区间已固定为 `[0,r_p]`。所以 `V(s)` 恒定。且 `V(s)→0` 当 `s↓0`。因此 `sup_{s>0}V(s)` 在有限安全事件 `E` 中取得；`S*` 本身属于 `E`。

本次整数证书得出：

* `|B_1|=17, |B_2|=27` 个尾轨道，分别代表 284 和 718 个原长度标签；两者之和 1002 是**正尾盒标签数**，不是任何指定 `s` 的正八维盒数。
* `P_1={1,2,4,8,16,32,64,128,432,486,648,729,972,1458,2187,12288,16384}`。
* `P_2={2,4,8,16,32,64,128,256,384,432,486,576,648,864,972,1296,1458,1944,2916,4374,10368,12288,13824,16384,18432,24576,32768}`。
* 安全事件原表达式 345 个，抽出整数八次幂后合并为 342 个不同实数，全部相邻有理区间严格分离。去重只使用可直接验证的根恒等式，没有假设某组根式线性无关。
* `S*=32768^(1/8)≈3.668016172818685`。

## 4. R002 赢家所在的完整线性段

令 `s96=(96^(1/8)+192^(1/8))/2`。整数区间认证其不是安全事件，且其相邻事件恰为

`L=r_64+r_256≈1.840896415253715`，

`R=r_32+r_486≈1.854532122294871`。

因而存在严格的 `0<λ<1` 使

`V(s96)=λ V(L)+(1-λ)V(R)`，其中 `λ=(R-s96)/(R-L)`。

故 `max(V(L),V(R))≥V(s96)`，若该段斜率非零，则为严格不等式。这是无需计算 union 的结构性保证，不能断言哪一端胜出或差额多大。实际 finite L1 证书有内缩、阈值和 collar 损失；若只得到体积相等，固定的有限化参数可能不会保持同一个有限数值下界，应按端点重新认证，或选择更小损失。

## 5. 可复用 tailsection 缓存的准确算法

### 5.1 推荐先实现的点值证书模式

1. 固定根精度 `D`，独立生成全部尾盒的有理内、外包，固定两份尾区间 ID 表。为 inner、outer 各建一个七维 `Union` 引擎；**跨首轴候选保留这两个缓存**。键必须完整包含七维尾区间 ID 多重集所组成的规范化状态；inner 与 outer 不共用数值缓存。
2. 对某个事件 `s` 计算向外有理区间 `[s_lo,s_hi]`；按 R001 的方向生成每个首轴内、外区间。对一般区间，首轴 `j=1` 的内上端 `min(s_lo/2,r_lo)`，外上端 `min(s_hi/2,r_hi)`；`j=2` 的内下端 `max(0,s_hi-r_lo)`、内上端 `min(s_lo/2,r_lo)`，外下端 `max(0,s_lo-r_hi)`、外上端 `min(s_hi/2,r_hi)`。内空盒删去，外空盒删去。
3. 各模式分别按首轴有理端点分片，取得规范尾状态 `Q`；查询固定缓存 `W_inner(Q)` / `W_outer(Q)`，累加“首片宽×尾 union 体积”，最后乘 256。这样直接得到真实事件体积的严格有理包围，根误差和事件处端点相等不造成拓扑误判。
4. 记录每候选根区间、输入散列、union 上下端、完整包含不等式和 finite L1 结果。缓存统计同时给出“批次累计状态数”和“本候选新状态数”；不能沿用独立候选总数的旧口径。预算耗尽意味着该候选未完成，不能填入零或粗略小数。

这种模式不需要先实现符号分段或精确斜率，即可让同一尾状态在不同首轴候选间复用。它可在真实事件位置计算完整内外并，不只是计算第一轴上界。

### 5.2 如需全事件参数族优化证书

可以只用第 5.1 节对全部 342 个事件求严格区间，再以第 2–3 节证明覆盖全正 `s`。如果最大候选区间与其他候选重叠，需提高精度或报告未分离的最大候选集合；不把排序中的微小差当成严格最优。

更进一步，可在每个事件胞取经认证的内部样点，记录活动端点的仿射表达式和每个薄片的尾状态，从缓存取得 `W_k`，写出该胞的仿射系数。根式比较必须用精确代数数算法，或用向外区间逐步升精并显式处理等式。当前有限事件证书已经以整数根分离全部不同事件，且去重只用了可核验恒等式；没有调用未经认证的浮点区间库。

此节是可复用算法设计，没有执行 342 个 union，也没有声称已经完成整个参数族优化。
