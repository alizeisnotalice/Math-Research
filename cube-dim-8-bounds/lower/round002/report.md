# 八维下界 R002

在登记的六个新候选中，m=96 是唯一严格超过 R001 完整 union 外端的候选：其完整内端及有限 L¹ 下界均严格超过该阈值。m=48、128、32、192、256 的完整外端均严格小于该阈值。比较由有理数运算给出，无小数舍入；各完整分数和 m=96 的 finite L¹ 证书在各自 candidate JSON 文件。该结论仅针对登记的六个候选，不主张整个参数族最优。m=16 沿用 R001 胞元预筛，m=64 沿用 R001 基线，均未重算。

本轮复制 R001 run.py 为 geometry_r001.py，字节散列一致；其八次根、32768 标签、240 对称轨道、完整内外并、包含和同半径有限 L¹ 构造见 R001 proof.md。每候选新建计算器和独立缓存，至多 2²⁰ 状态；各状态数分别为 m=96:179066、48:268905、128:158764、32:305911、192:131273、256:124520。代码和两项原始输入由 input_lock.json 锁定。各候选的 root、区间、包含及有限化遵循 R001 算法，故此处仅是新运行，不冒充旧计算或独立全标签审计。

六个首次进程均完成计算并写出 JSON 后，因 candidate.py 最后一行把 `flush=True` 误传给 json.dumps 而抛出 TypeError；每个 receipt 保留该异常。未单独记录各后台进程的 shell wait 退出码，因此不能声称逐一实测退出码；未捕获异常通常导致 Python 返回 1。冻结保留原脚本、输出和异常回执，没有重跑 union，也没有把计算的完整状态说成进程正常退出。verify_saved.py 读取保存结果，核对输入散列、注册、状态数、完整区间和有限 L¹ 分数的严格比较；其 PASS 是保存数据核验，不是重新执行 union。m=96 仍需独立全标签算法及数学审计。

本机执行保存核验：`python3 -B verify_saved.py`。相对目录依赖相邻 round001/results.json；无需硬编码 clone 绝对路径。manifest.json 列示本轮冻结文件散列。六项收齐后停止，未增加参数网格，没有 MATLAB、提交或推送。
