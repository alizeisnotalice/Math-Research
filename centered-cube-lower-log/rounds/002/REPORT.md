# 第2轮：固定混合重要抽样检验格点罕见尾

2026-10-28。目标仍为在已有 √n 下界上增加正对数。未取得新下界证明。

## 方案和实际运行

使用 NumPy 2.3.5，每维16384中心，n=128,512,2048，J=16。运行前在脚本中冻结混合分量、阈值和随机种子。U_i∈[0,1/2]，分量 j=0,1,2,3 中落在 [0,1/4] 的概率 p_j=1/2+j/√n；各半区内均匀。每个中心独立均匀选一个分量，再生成全部坐标。原均匀分布为 j=0 分量，保证全支撑。

令 K 为落在第一半区的坐标数。混合密度相对于目标均匀律的密度为

    q(U)= (1/4) Σ_j (2p_j)^K [2(1−p_j)]^(n−K).

用 log-sum-exp 计算，权重 w=1/q≤4。对预设 h=1,…,16，估计 e^h E_q[w 1{log响应>h}]。密度变换是精确恒等式；样本均值仍是数值证据。共同半径响应调用第1轮已直接计数核验的算法。

权重均值与标准误：128维 .99794±.01128；512维 1.00909±.01134；2048维 .98982±.01126。符合 E_q w=1 的控制，但这不是尾部精度保证。
