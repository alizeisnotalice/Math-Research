# 整数平移安全尺度窗口的尾部预算

日期：2026-10-28。先运行 translation_control.py，再推导下述命题。数值控制不是证明；下文给出独立解析证明。

## 命题及量词

设每个维数 n 对应非负、局部可积、1 周期且周期均值为 1 的函数 ρ_n。令

\[
Y_L(x)=L^{-1}\int_{x-L/2}^{x+L/2}\rho_n(y)dy=1+d_L(x),\qquad I=[10/9,11/9].
\]

设 S_n⊂I 是至多 m_n 个区间的并，且在 S_n 上一致满足

\[
\int_{\mathbb T}d_L=0,\quad |d_L|\le a_n,\quad
|n\int_{\mathbb T}d_L^2-v_n|\le C_0,
\quad a_nv_n\to0,\quad16\log n\le v_n=O(\log n).
\]

C_0 与 n、L 无关；m_n=O(v_n²)。令 h=v_n/2−2，X 在 T^n 上均匀分布。则对充分大的 n，

\[
e^h\Pr\left\{\sup_{k\in\mathbb N,\,L\in S_n}\prod_{i=1}^nY_{L+k}(X_i)>e^h\right\}
\le C(n+m_n)\left(e^{-511v_n/2560}+e^{-7v_n/22}\right)
=O(n^{-351/160}).
\]

这里 N={1,2,…}。常数只依赖假设中的固定常数。该结论是特定周期源、特定高阈值、特定尺度集合上的上界，不是 C_n 的上界。

## 证明

### 1. 周期平均的精确收缩

令 R 为 ρ_n−1 的周期原函数，即 R'=ρ_n−1，R(x+1)=R(x)。由局部可积性，R 可取绝对连续函数。于是

\[
Ld_L(x)=R(x+L/2)-R(x-L/2).
\]

任意整数 k≥0，由周期性可把第二端点平移 k，得到

\[
Y_{L+k}(x)=1+\frac L{L+k}d_L(x+k/2). \tag{1}
\]

平移保持圆周测度，所以式 (1) 的均值、方差及独立坐标乘积可直接用 d_L 计算。特别是方差乘以 (L/(L+k))²；不能把每个平移窗口视为原窗口的等强副本。

### 2. 连续尺度的有限网格

记 F(x)=∏ρ_n(x_i)。它非负，且以边长 t 的中心立方体取平均，恰得 ∏Y_t(x_i)。若 0<s≤t，则由积分区域包含关系，

\[
A_sF(x)\le(t/s)^n A_tF(x). \tag{2}
\]

对每个 k≥1，在 S_n 的每个区间闭包内取向上网格，步长不超过 (k+10/9)/n，并保留右端点。总点数至多

\[
N_k\le n|I|/(k+10/9)+2m_n\le C(n+m_n).
\]

区间平均对 L>0 连续，故所有假设延伸到闭包。每个 L 被一个 L'≥L 的网格点覆盖，且 n log((k+L')/(k+L))≤1。由式 (2)，连续尺度越过 e^h 必使某网格点越过 e^{h−1}。因此只需对网格点概率求和。此步骤不要求 ρ_n 连续。

### 3. 第一个平移窗口

令 a=L/(L+1)≤11/20，取固定幂 t=9/4。对于 |d|≤a_n，Taylor 展开有

\[
(1+ad)^t=1+tad+\tfrac12t(t-1)a^2d^2+O(a_n d^2),
\]

余项常数一致，因为 a_n→0。积分后用均值为零、log(1+u)≤u 得

\[
n\log E(1+ad)^t\le\frac{45}{32}a^2v_n+O(1).
\]

其中余项为 O(a_nv_n)+O(C_0)，一致有界。独立性和 Markov 不等式给

\[
e^h\Pr\{\prod_i(1+ad(X_i))>e^{h-1}\}
\le\exp((1-t)h+t+\tfrac{45}{32}a^2v_n+O(1))
\le C e^{-511v_n/2560},
\]

因为 5/8−(45/32)(11/20)²=511/2560。

### 4. 所有更远窗口的可求和预算

对 k≥2，置 a=L/(L+k)，取 t=1/a。这里 t 随 k 增大，不能套用前一步固定幂 Taylor 余项。改用精确不等式

\[
(1+ad)^{1/a}\le e^d.
\]

又由 Ed=0，Ee^d≤1+e^{a_n}Ed²/2，故

\[
n\log Ee^d\le v_n/2+O(1).
\]

因此每个网格点的加权概率不超过

\[
\exp\{h-(h-1)(1+k/L)+v_n/2+O(1)\}
\le C e^{v_n/2}\exp\{-(h-1)k/(11/9)\}.
\]

对 k≥2 求几何级数（n 充分大时 h−1>0），得到

\[
C e^{v_n/2}\frac{\exp\{-2(h-1)/(11/9)\}}{1-\exp\{-(h-1)/(11/9)\}}
\le C e^{-7v_n/22}.
\]

结合统一网格点数，得命题首式。m_n=O((log n)²)=O(n)，以及 v_n≥16log n，给

\[
n e^{-511v_n/2560}\le n^{1-511/160}=n^{-351/160}.
\]

第二指数衰减更快。可测性由连续 L 的可数稠密网格和可数整数 k 保证；无穷求和由上述几何预算控制，未调用任何待证弱型上界。证毕。

## 与现有平方根构造的衔接

paper/proof_work/01_source_kernel_detailed.tex 中，固定 p,w 后：
- v=Θ(log n)，v≥16log n；
- 安全尺度上 |q_L−v|=O_w(1)；
- a_n=77p/(15K)，a_nv→0；
- S_n={L∈I:dist(K(L−1) mod K,D)>2}，|D|=(B−1)(B−2)，v≤B<2v。

映射 L↦K(L−1) 在 I 内仅走过长度 K/9；每个圆周禁区至多产生常数个被删区间。因此 S_n 的连通分支数为 O(B²)=O(v²)。这给命题的全部接口。

结论：保持既有周期源与既有阈值，只加入 S_n+1、S_n+2、…，额外加权越阈体积趋于零，不能由此增加正的对数因子。原窗口本身、安全集以外的尺度、改变源、改变阈值及非整数尺度扩展均不在该排除结论内。
