## 本轮结论

未得到 C_n≥c√n(log n)^α（α>0）的新证明，也未得到足以支持这种增长的数值证据。沿用已有论文的平方根下界与常数，不把本轮采样值写成严格下界。

获得一项可完整证明的限制：对已有周期构造，在原阈值处加入全部整数平移安全尺度窗口，其额外加权越阈体积为 O(n^(-351/160))。证明见 translated_safe_windows.md。它说明不能靠这种窗口复制免费取得对数因子，不是所有下界构造的障碍定理。

## 实际运行的数值模型

使用本机 Python 3 / NumPy 2.3.5。周期矩形格点源的周期为 a_i，∏a_i=1；中心折叠为 a_i U_i，U_i 独立均匀于 [0,1/2]。取同一个立方体半径 r，计算各坐标计数乘积除以 (2r)^n。

每坐标第 j+1 个邻点进入的距离为

    a_i [ floor((j+1)/2) + (-1)^j U_i ],  j=0,…,J−1.

排序所有进入事件后更新计数，仅在每个坐标均至少含一个点后计分。各向同性用不相交事件层简化。非各向同性代码每坐标最多计 J 个点：远处可能遗漏更后邻点，因此给出保守截断响应，而非宣称完整无限格点极大函数已精确求出。始终保持共同半径；没有把坐标各自最优半径相乘。

周期原子模型用于探路。要成为 R^n 上的严格 L1 下界，还须有限截断、边界预算、平滑原子和阈值余量；本轮未对 Monte Carlo 体积出具确定性证书。

第一轮：n=8,32,128,512,2048；J=2,4,8,16,32,64；另测双块周期 exp(±σ)，σ=0,.02,.08,.2。训练半样本选阈值，验证半样本重算。独立直接 floor 计数与事件算法误差小于 9×10^(-16)，两种各向同性算法误差小于 2×10^(-15)。实际用时约14.17秒。

第一轮训练最优值易由极罕见尾样本主导，验证时出现零或一个命中；这种结果没有稳定解释。零命中时程序给出的零插件标准误也不能理解为真实概率等于零。

## 严格结果与剩余问题

已证：在 translated_safe_windows.md 明列的幅度、方差、窗口分支数条件下，整数平移窗口的尾部预算。现有论文固定 p,w 的周期源满足该接口。

仅数值观察：轻微双块周期形变带来有限维改善；扩大 J 后被冻结阈值的估计没有新增收益。

未解决：如何构造同一份 L1 来源质量，在足够多等强窗口上保持原平方根构造的单点尾概率，同时让联合越阈体积得到不被相关性或质量费用抵消的额外增长。整数平移由于方差收缩失败；非整数尺度族、非相同坐标源和更精细罕见尾重要抽样仍未排除。

本轮不提出未经数值探路的具体正对数指数，也不由搜索未成功推断 √n 是双边精确阶。原论文未被改写。
