# 第33轮：四相位混合固定尾层的独立数值确认

2026-10-29。本轮在一个合法的有限来源模型中，得到四相位混合相对单分量的**固定阈值尾差**正信号，并以单次预先登记的独立样本确认。保存数据的非参数e值反演下端为0.375697。严格浮点认证尚未完成；这一结果没有比较两来源各自的最优弱范数，也没有得到新的 \(C_n\) 或渐近对数下界。

## 1. 从探索到一次确认

首先冻结两个自然长度集合
\[
 L_j=10/9+j/(Kv),\qquad0\le j\le\lfloor Kv/9\rfloor,
\]
比较真实共同尺度共享混合与单分量。两组均用K255、B4真实GF迹标签、p=1/2、w=4，v=4/8，对应n3352400/6704800，样本数各256、相位数最多8/16。来源非负、质量1，保留全部指定低频；它们仍不满足原匹配平方根下界的全部参数条件。

自然集合分别有114/227点，末点均为3739/3060，未含11/9；二者也不是旧九点集合的超集。因此本轮不把“点数更多”称为对旧结果的单调提升。这些有限集合各自下界真实连续窗口最大值。

在较大自然集合中，允许各相位分别选择尺度的U增加明显，共同尺度V没有相同的最优弱尾改善证据。v8、R4、\(\lambda=e^2\) 的真实下界减真实上界之积分探索估计为 \(1.100\pm0.268\)，但原保守Hoeffding下端非正。不能仅凭该点或多个阈值中选出的最好点宣称改善。

## 2. 结果及其精确含义

令B为真实共享最大尾的条件下界，U₀为单分量最大尾的条件上界，W为正确提议权重，则
\[
 D=\lambda W(B-U_0),\quad |D|\le2\lambda,
 \qquad ED\le\lambda[P(M_4>\lambda)-P(M_0>\lambda)].
\]
这里比较下界与上界，而非两个松紧不同的下界。保存的1024个配对值经独立Python标准库重算：

|量|数值|
|---|---:|
|配对积分差均值|0.8823734426|
|描述性标准误|0.1509816834|
|共享尾下积分系数|5.64014|
|单分量尾上积分系数|4.75777|
|\(\log E_0\)|15.7622793202|
|拒绝阈值\(\log20\)|2.9957322736|
|单侧95% e反演下端|0.3756971860|
|Hoeffding下端|−0.24803522|

e值使用有界变量的独立乘法期望，不依赖正态标准误。它比这次Hoeffding界更有效，不表示可以事后选择最优下注；下注比例及分析规则已经在确认前固定。完整推导见 `PROOF.md`，独审见 `AUDIT.md`。

**尚未闭合的数值认证。** e值的理论覆盖要求每个D确为准确条件下界、条件上界及正确提议权重形成的有界量。程序使用普通双精度，尚未把三角函数、条件均值、方差帽及dot误差传播到最终D的区间。独立重算D数组的e值只验证统计复算，不能补这层误差。因此上述结论是以积分实现正确为前提的数值统计支持，不登记为确定性下界证明。

即使将来完成这一数值认证，结论也只针对固定有限尺度集合、固定λ的尾差。不能由它推出四相位来源的最佳弱范数更大，更不能推出 \(C_n\) 增加对数。两来源其他阈值处的尾形可能抵消这一局部优势；本轮的探索确实显示这种风险。

为把认证缺口写得具体，主线还计算了输入向下扰动的敏感性：若能认证全部1024个真实配对值均不小于保存值减0.1，并以已知真界截断下端，固定e反演下端仍约0.2731；误差预算约0.3658才使零假设检验到达临界。当前尚未证明任何该类误差预算。此表可由校验器重算，不能拿来代替误差认证。

## 4. 改变v的收益与首个抵消处

另一名代理实际比较了原规则 \(v\asymp\log n\) 与 \(v\asymp(\log n)^2\) 的14个标量规划点，并阅读原来源及概率证明。较大v仍有 \(K/v^r\to\infty\)、Taylor和有限面误差趋零，但有限域门槛、safe删除及有限n误差明显变差。本次规划点在n10^64才通过新规则所列的存在性预算；这不是最小n₀或完整有限维证书。

首个不产生新增下界的抵消已经明确：局部簇数约Kv，而单簇倾斜尾费用为 \(v^{-1/2}\)，所以
\[
 Kv\cdot v^{-1/2}=K\sqrt v=\frac{3p}{\sqrt{29}}\sqrt n.
\]
单纯增大v不会在这一阶和中留下对数。新规则的单来源仍受第30轮同类弱预算限制；第32轮强预算增加到 \(O(\sqrt n\log n)\)，只是为真正的混合机制留下空间，没有给出该增益。

原主阈值也应改为 \(h=v/2-2\)，不能固定旧阈值比较。有限面极限先固定的节点数、包长和间距仍须保留，不能把有限节点CLT直接用于随n增长的全部自然尺度。详细预算和首个抵消见 `AUDIT.md`，可复现标量表见 `parameter_probe.py`、`parameter_results.json`。

本轮只读“上界”的最新成果：第639轮推进了新族正则目标的合法估计，当前仍缺真实接收增益与新优化的统一净收益；没有可供本项目直接调用的一般平方根上界。没有因读取其他对话而向其发消息或改变其任务状态。

本轮前进的是一个真实共同尺度固定尾层的确认信号；主目标仍未完成。下一步应把这一信号转为源族中可扩展的尾层收益，同时支付最佳阈值变化、尺度同步及全部误差。可以优先检验分块共享潜变量等真实非乘积结构：它能改变同一尺度上的尾排序，但仍须按第32轮强预算筛选参数；不能再用U的增加替代V的增加。

当前第一处确定的认证缺口是确认D的严格输入误差；即便填补它，通向正对数下界的下一缺口仍是随n及混合规模增长的最佳弱尾收益，而非某个固定λ的分布重排。本轮没有缩小或替换一般 \(C_n\) 目标。

```bash
python3 verify_confirmation.py
```
