## 来源、真实质量和分位数规则

工作于单位周期 torus，Lebesgue 查询区域为 `[0,1)^n`。K 为偶数，χ(j)=1_{j<K/2}，源格索引向量均匀取自 `{0,…,K−1}^n`，S=Σχ(j_i)。第 b/R 分位点取满足

`R Σ_{s≤q_b} binom(n,s) ≥ b 2^n`

的最小整数 q_b，b=1,…,R−1；再取 q_R=n。第 b 段为前一切点加一到当前切点的闭整数区间。重复切点产生空段，保留其编号、固定表和 proposal 分量，实际 π_b=0。所有 π_b 用精确二项式整数和除以 2^n 定义；未将其替换为 1/R。

表参数 θ_b=(b+1/2)/R。在 plus 格取 u_b(j)=θ_b，在 minus 格取 1−θ_b，点为 a_b(j)=(j+u_b(j))/K。每个联合源格选择自己 S 所在段 b，在该格对应点放质量 K^{-n}，用全宽 δ=1/(64KR) 的各坐标 box 平滑。最近格边距离为 1/(2KR)，大于 δ/2，故 box 留在原格。每格恰放一份质量，来源为非负 L1 密度且总质量严格为 1；最大密度不超过 (64R)^n。

固定表来源在所有格使用同一 b；实际 prior 来源按 π 独立选择表。它们与 joint 来源分别计算。joint 的平均公式不额外乘 π。n3/R4 的 π=(1/2,0,3/8,1/8)，空段 b1 被保留。主实验 n15/R8 与 n31/R8 各有空段 b3，n63/R8 无空段。各精确段端点/π 在注册及结果 metadata 中完整保存。

## 真实共同 cube 平均与提议分布

对给定 x、L、表 b，记各坐标的 plus/minus 质量为

`w_{i,b,±}=(K L)^{-1} Σ_{j∈C_±} ∫_{−δ/2}^{δ/2} 1_{x_i−a_b(j)−t ∈ [−L/2,L/2] mod 1} dt/δ`，其中 C_+={χ=1}、C_-={χ=0}。

上述 mod 1 记号按所有整数平移的区间指标之和解释，L>1 保留覆盖重数。代码用周期区间与 box 的真实重叠长度求积分，没有以原子命中近似平滑。令 `P_b(z)=∏_i(w_{i,b,−}+z w_{i,b,+})`，则 joint 平均是对每表取其段内系数之和再对 b 求和；fixed_b 平均为 P_b(1)，prior 平均为 Σπ_b P_b(1)。每个 x 的最大值在同一 L 上计算完该模型平均以后，再对冻结 L grid 取 max。

计算先取 `t_i=w_++w_-`、固定表 log 乘积，再用归一化 plus/total、minus/total 的正 PB 概率 DP。直接累加目标段内系数，不用接近的 CDF 相减；logsumexp 合并表。含某个零 t_i 的表有精确零乘积，单独处理。L=1 的所有模型平均恒为 1，代码使用此精确恒等式。未采用正态近似。

令 F_{m,L} 为真实平均，模型数 T=R+2，J=62。查询提议为

`D(x)=1/2 + (2TJ)^{-1} Σ_{m,L} F_{m,L}(x)`。

实现为 50% uniform，否则均匀选模型和共同 L，实际抽该来源 T，再减独立 cube uniform 核并取模 1。joint 先抽源格再分类；prior 用独立 n 个公平 bit 的和分类来精确生成 π，然后独立抽源格。这样 π 的抽样无需浮点分类 CDF。RN 中包含所有模型、所有目标 L，W=1/D≤2。若 `M_m=max_L F_{m,L}`，则每个阈值的尾贡献 `λ W 1_{M_m>λ}` 不超过 `2TJ`，还不超过 2λ。各 case 的实际最大贡献和标签次数已保存。

## 小例与冻结成本

先运行 n3/K4/R2、R4 的全 64 源格直接求和，再校准时加 R8。直接枚举与 PB 的最大归一化绝对误差分别为 2.22e−16、2.22e−15、6.66e−16；控制长度含 δ、1/4、3/8、1、7/6。Fraction 在三种 R、三种有理长度完全相等。例如 x=(1/7,2/7,4/7)、L=3/8 时，R2 的 joint=32/27、prior=8/9；R4 的 joint=40/27、prior=28/27。L=1 均为 1。
