# 第38轮：分位数来源的条件方差估计与百万维尾探路

2026-10-29。本轮没有确认新的正对数增益，也没有改善已接受的平方根下界。已完成的工作是：证明一个不损失组合项数量的条件方差估计，把真实分位数来源接到带确定误差的 Poisson–binomial（PB）条件均值，并实际运行 n=6,704,800 的有限尺度尾试验。joint 与真实 prior 的尾包络尚未分离。

## 1. 已证：正多项式的条件矩

先在 n=3、5 的12个真实 box 小例上，以 Fraction 穷举2ⁿ个独立隐藏查询位置，并直接枚举Kⁿ个源格。真实立方体平均、正多项式/PB 表达和均值替换全部精确相等。观测相对方差约为9.65×10⁻⁵至9.50×10⁻⁴；随后证明如下命题。

给定有序 query bins，各坐标隐藏位置独立。设非负核 Zᵢ,ₐ 二阶矩有限，均值 μᵢ,ₐ>0，且 Var(Zᵢ,ₐ)≤tᵢ,ₐμᵢ,ₐ²。对任意有限正多项式
\[
 F=\sum_\alpha c_\alpha\prod_iZ_{i,\alpha_i},\qquad c_\alpha\ge0,
\]
坐标独立性给精确均值替换。对每个乘积先算二阶矩，再对中心化乘积使用 L² 三角不等式，得到
\[
 \operatorname{Var}(F)\le
 \left[\prod_i(1+\max_a t_{i,a})-1\right](EF)^2.
\]
零均值非负核几乎处处为零，可以删去。不同表、类别和尺度之间不要求独立。

若 F=Σ_bF_b，每个 F_b 只使用第b表的核，记 W_b=EF_b、r_b=∏ᵢ(1+maxₛtᵢ,b,s)−1，则更细的界是
\[
 \boxed{\operatorname{Var}(F)\le(\sum_bW_b\sqrt{r_b})^2.}
\]
没有额外的R²、2ⁿ或单项式数量因子；r_b本身仍受来源几何及参数影响。W_b∈[l_b,u_b]时，绝对方差上包为(Σ_bu_b√r_b)²。有理小例中平方根用10⁴⁰精度的整数平方根向外包围；n=3、R=4时分层相对帽约.00179–.00198，优于全局帽.00752，n=5时约.00351–.00397，优于.01256。证明和量词见 [conditional/PROOF](round038_conditional/PROOF.md)。

给定 histogram 后坐标不再独立。本轮所有目标对坐标置换对称，因此先在有序 bins 上证明，再用任意规范排列代表 histogram；没有直接假设 histogram 条件独立。

## 2. 已核对的文献接口：真实 PB 均值

真实 gated 来源的共同尺度平均是正多项式。替换类核为 bin 均值后，表b的段均值准确等于
\[
 W_b=A_b\Pr\{\sum_i\mathrm{Bern}(p_{i,b})\in I_b\}.
\]
Bernoulli 只是多项式系数的代数表达。不能将原输入当作乘积输入，也不能在 gated 项再乘 prior 权重。

采用已实际阅读原文的 Tyurin 独立非同分布 Berry–Esseen 定理，常数为 **0.5606**，不能向下取为0.56。设σ²=Σpᵢ(1−pᵢ)，β₃=Σpᵢ(1−pᵢ)[pᵢ²+(1−pᵢ)²]，CDF误差≤0.5606β₃/σ³。整数段在两个半格端点求差；每个有限端点支付一次误差，无穷端点准确处理。这里没有额外声称 continuity correction 改善定理。[原始预印本](https://arxiv.org/abs/0912.0726)，阅读范围及BibTeX在pb目录。

先运行57组独立或异质PB参数的精确DP算法，与正态CDF比较；456个段概率均在相应误差预算内。这是对公式的数值检查，不能以此证明文献常数。一个n=255、pᵢ=1/4的顶段概率约3.36×10⁻²³，而绝对BE预算约.05067，下包只能为零。与实际 prior 比较时，相对误差一般支付 max_b(k_bε_b/π_b)，约为R/√n；没有自动得到与R无关的罕见尾相对估计。完整证明见 [PB/PROOF](round038_pb_bound/PROOF.md)。

## 3. 具体有限输入与真实质量

主试验固定K=255、B=4、v=8、p=1/2、δ=1/(4Kv)、M=3。四表使用共同低频补偿D_M；前127个粗格的微相位加b，其余格减b。所有箱峰留在原格，各表有相同的逐格质量q_j，但q_j通常**不等于1/K**。实际plus类别质量为
\[
 \eta=127/255+\frac p{2K}\sum_{m=1}^M c_m\sin(2\pi m127/255)
      \simeq0.498047800888639.
\]
若误用1/2，输入计数均值偏约10.11个实际标准差。本轮用真实Bin(n,η)生成 prior 概率包。切点3338016、3339311、3340606在抽样前冻结；它们是固定整数，并非精确分位点。

gated 来源由源坐标plus计数所在整数段选表。由于各表具有共同类别质量，其周期L¹质量准确为1；实际 prior 使用这些段在Bin(n,η)下的概率，而不是1/R。背景正性由系数公式的确定界保证，下界>.476。具体构造、类核、归一化、截断到真正L¹输入的推导见 [DRIVER_PROOF](round038_highdim/DRIVER_PROOF.md)。

这些是合法有限输入；但B=4<v=8，且v<16log n，未满足接受的匹配平方根来源参数条件。改变相位后的表也没有自动继承旧来源的全部pair核性质。因此本次有限模型不能直接代入旧渐近证明。

## 4. 实际高维试验

n=6,704,800，query bins数48,960，共233个固定共同尺度，均位于[10/9,11/9]。缓存四类特征：log总核、PB均值参数、PB方差参数、log相对方差帽；计数矩阵乘法避免显式建立n维查询。128个独立 counts 样本使用冻结seed；样本数仅由矩阵成本预检选择。未因尾收益追加样本。

一维核的中点积分解析误差最多7.713×10⁻¹²，另列经验浮点guard=10⁻¹³。正态CDF参数误差、BE误差和分层方差分别传播；条件 Cantelli 给下包，Cantelli/Markov及尺度并集给上包。名义总核产生的proposal是均匀律与全表全尺度product tilt的等权混合，使用混合后的准确理想RN。两侧贡献均有预先确定的帽。8模型×21阈值×双方向共336项单侧KL区间，总名义失败概率.05。

主目标首个未闭合环节仍是：找到满足来源资格、随n增长的明确F_n及λ_n，并对原Lebesgue查询律证明，对某个固定a,c>0及所有充分大n，
\[
 \lambda_n|\{MF_n>\lambda_n\}|/\|F_n\|_1
       \ge c\sqrt n(\log n)^a.
\]
