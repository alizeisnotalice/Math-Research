# 条件均值与无项数损失的方差帽

本文件的一般结论自含，不用 Gaussian 或 Berry–Esseen。`RESULTS.json` 是先运行的真实 box 有理小例；`LAYERED_RESULTS.json` 是读取其核矩的分层帽后处理。高维 PB 近似不在本文已证范围。

## 1. 独立条件坐标与正 multilinear sum

固定一个 query-bin 向量 B=(B_1,…,B_n)。在基准 Lebesgue law 下，条件于 B，各 X_i 独立且在各自 bin 内均匀。两点隐藏位置的实验则用各坐标独立等概率两点 law；下面证明对两种 law 一样成立。

每坐标有一族非负核 Z_{i,a}=z_{i,a}(X_i)，二阶矩有限。写 μ_{i,a}=E(Z_{i,a}|B_i)，并假设对 μ>0 的核

`Var(Z_{i,a}|B_i) ≤ t_{i,a} μ_{i,a}²`。

μ=0 的非负核条件下几乎处处为零，含它的 monomial 可删去；保留空段不改变公式。考虑

`F=Σ_{α∈A} c_α ∏_{i=1}^n Z_{i,α_i}`，其中 c_α≥0。

有限和足够覆盖 gated cube 平均。对可数和，只要相应 L2 范数之和有限，可用截断和及单调收敛/范数极限迁移；本文实际接口都是有限正和。

独立性和 Tonelli 给出精确恒等式

`E(F|B)=Σ_α c_α ∏_i μ_{i,α_i}`。

因此将每个 class 核替换为其 bin 均值，再计算同一个段多项式，得到真实条件均值，而不是未经转移的 mean proxy。

## 2. 全局乘积帽

取 r_i=max_a t_{i,a}，T=∏_i(1+r_i)−1。对一个 monomial G_α=∏_i Z_{i,α_i}，独立性给

`E(G_α²|B) = ∏_i E(Z_{i,α_i}²|B_i) ≤ (1+T) [E(G_α|B)]²`，

从而 `||G_α−E G_α||_2 ≤ sqrt(T) E G_α`。在同一条件概率空间对中心化和使用 L2 三角不等式：

`||F−E F||_2 ≤ Σ_α c_α ||G_α−E G_α||_2 ≤ sqrt(T) E F`。

所以

`Var(F|B)/(E(F|B))² ≤ ∏_i(1+r_i)−1`。

不同 a 的核可以高度相关，不要求各表或各 class 独立。唯一用到的独立性是不同坐标条件独立。证明没有 monomial 数、R² 或 2^n 乘子；正系数使 Σ c_α E G_α 恰等于 E F。

## 3. 先表内、再跨表的分层帽

令 F=Σ_b F_b，每个 F_b 是固定表 b 内受允许 class-count 段限制的正 monomial 和。定义

`r_b=∏_i(1+max_{s∈{−,+}} t_{i,b,s})−1`，`W_b=E(F_b|B)`。

先对每个 F_b 应用第二节，再跨 b 用一次中心化 L2 三角不等式，得到

`Var(F|B) ≤ (Σ_b W_b sqrt(r_b))²`，

以及非零总均值时

`Var(F|B)/(Σ_b W_b)² ≤ [Σ_b W_b sqrt(r_b)/(Σ_b W_b)]²`。

空段严格给 W_b=0，其编号与 r_b 可以保留，但不贡献分子/分母。该帽不大于全局帽，因为每个 r_b≤T、W_b≥0。特别是，不必在每个坐标先把所有表的 transition 合并后取 max。分层帽中依然没有 R 的显式项数损失。

如果高维均值只能得到区间 `W_b∈[ℓ_b,u_b]`，ℓ_b≥0，则确定的绝对方差上界是

`Vhat=(Σ_b u_b sqrt(r_b))²`。

根号和若要作为证书，须向外舍入。小例用缩放10^40的有理平方根包围；`layered_postprocess.py` 用 integer isqrt 核验上下端点平方方向。其输出保存每个 W_b、r_b 和整个帽的有理包围。

## 4. Gated 来源的 class 核与 PB 均值

固定表 b 的一维非负单位质量密度为 ρ_b，源空间粗格类别 χ(y)∈{0,1}。令

`z_{b,s}(x,L)=L^{-1} ∫_{x−L/2}^{x+L/2} ρ_b(y) 1_{χ(y)=s} dy`，

积分按周期展开，L 可以大于1。源格决定分段 E_b⊂{0,…,n}，joint 源为

`f(y)=Σ_b [∏_i ρ_b(y_i)] 1_{Σ_iχ(y_i)∈E_b}`。

真实共同 cube 平均为

`A_L f(x)=Σ_b Σ_{s∈E_b} [u^s] ∏_i (z_{b,0}(x_i,L)+u z_{b,1}(x_i,L))`。

这是第一节的正 multilinear sum；不能再乘 π_b。替换 z 为 bin 条件均值 μ 后仍是精确条件均值。设 t_{i,b}=μ_{i,b,0}+μ_{i,b,1}，p_{i,b}=μ_{i,b,1}/t_{i,b}，则

`W_b=(∏_i t_{i,b}) Pr(Σ_i Bernoulli(p_{i,b})∈E_b)`。

这里 Bernoulli 只是正多项式系数的精确代数表示，不是对真实 query 或来源的 Gaussian 近似。所有 t>0 时可使用归一化正 PB DP；零 t 的整表乘积为零。

## 5. 条件 Cantelli 与共同 L

固定有限尺度集。若各 L 有真实条件均值 m_L 和方差上界 V_L，则对 m_L>λ，Cantelli 给

`P(A_L f>λ|B) ≥ (m_L−λ)²/[V_L+(m_L−λ)²]`。

若只知 m_L≥m_L^- 且 Var≤Vhat_L，则将分子中的 m_L 换成 m_L^-、分母中方差换成 Vhat_L，仍给下界，m_L^-≤λ 时取0。对各 L 下界取 max 是合法的：在 bin 信息上选择共同 L，再看隐藏位置。它给 `P(max_L A_L f>λ|B)` 的下界；并未假设各尺度独立。不能把各坐标或各表分别最大化后代入真实平均。

若有与均值无关的条件相对方差帽 T_L，还可直接用 gap=`(1−λ/m_L^-)₊`，下界为 `gap²/(T_L+gap²)`；这是精确相对方差 Cantelli 下界对 m 的单调性。对分层区间帽可使用绝对 Vhat，以免把未认证表权重当真。

这完成条件矩与 tail 转移的证明。它不证明有限实验出现收益，不给连续尺度最大值的上界，也不代替高维 PB 概率的带误差计算。
