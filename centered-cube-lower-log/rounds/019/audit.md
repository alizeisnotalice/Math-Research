# 重要抽样恒等式审查

## 恒等式与多项计数

在有限网格上令 P(x)=1/G，Z_j(x)=log(1+a X_j(x))，并假定所有对数实值且有限。必须使用同一网格的精确对数归一化

F(theta)=log sum_x P(x) exp(theta·Z(x)),

q_theta(x)=P(x) exp(theta·Z(x)-F(theta)).

对 q_theta 下 n 个独立样本，S=sum_i Z(x_i)，原律与抽样律的似然比为 exp(n F-theta·S)。因此对 E={S_j>=h，全部 j}，确有

P^n(E)=A E_q[W]，A=exp(n F-h sum_j theta_j)，

W=exp(-theta·(S-h 1)) 1_E。

此恒等式本身不要求 theta>=0；非负性保证 E 上 0<W<=1，也使 A 成为 Chernoff 上界。精确计算 F、保持 q 在原律支持上严格为正，是该结论的前提。二次近似 F 或把非线性最优参数的近似目标值代入 A，会改变估计值。

令 C~Multinomial(n,q_theta)，则 S=sum_x C_x Z(x)，其分布与逐个抽取 n 个状态完全相同。多项系数在两律的计数概率之比中消掉，故无需重新乘多项系数。这个压缩是分布恒等式，不是正态或 Poisson 近似。需要每个 Monte Carlo 复制重新独立抽取一整组计数，并保证总计数严格等于 n。

## 无偏性和标准误

冻结 theta 后，M 个独立复制 W_1,...,W_M 给出估计量 p_hat=A mean(W)。在理想精确算术下，该估计量对有限网格目标严格无偏。

Var(p_hat)=A^2 Var_q(W)/M。

M>=2 时，令 s_W^2=sum_m (W_m-mean(W))^2/(M-1)，通常报告 SE_hat=A sqrt(s_W^2/M)。SE_hat 的平方是估计方差的无偏估计；SE_hat 本身通常不是标准差的无偏估计。分母使用总复制数 M，不能只用命中的复制数。若 A 极小，应使用 log(A) 和稳定加和；指示函数为零时直接记 W=0，避免计算无用的大指数。

正态近似区间是渐近近似，不是有限样本认证。特别是少量或零次命中时，样本方差可能严重低估真实不确定性；零命中得到的 SE=0 不能作为概率为零的证据。因 theta>=0 时 W 位于 [0,1]，固定 M 可另用有界变量的集中界给出保守的有限样本区间；需要先定置信口径，不能将普通 SE 区间称为严格界。

## 参数冻结与零坐标

theta 可以由确定性优化产生，或由独立 pilot 样本选择。后一情形在给定 pilot 的条件下，上述恒等式、条件无偏性与条件 SE 公式仍成立；独立 final 样本必须在 theta 冻结后生成。若用同一批 final 样本挑选 theta，再直接套用这个固定抽样律估计量和 iid SE，通常没有这些保证。跨批次自适应抽样需要逐批使用实际提议律的似然比，并重新分析方差；不能直接冒用固定 theta 的 iid 公式。由观测结果决定何时停止，也不能自动保留固定 M 的区间保证。

theta_j=0 只表示似然权重不含该坐标，绝不删除事件条件 S_j>=h。该条件仍须逐复制检查并保留在指示函数中。二次模型中的 KKT 松弛也不意味着此条件在所有随机复制中自动成立。

## 数值与来源边界

上述无偏性针对指定有限网格、指定 n 与原始阈值 h。计算 q 时应稳定归一化，并确认没有浮点下溢产生零提议概率。若实际采样的 q 与理论指数倾斜的 q 存在实质差异，应按实际提议概率计算计数似然比 sum_x C_x(log P(x)-log q(x))；不能继续声称简化指数式在机器算术中完全精确。阈值附近的浮点误差也需要记录；任意放宽指示条件会改变目标概率。

有限网格 Monte Carlo 的 SE 只反映该离散模型的抽样误差，不包含网格到连续来源的离散化误差。连续模型还需要独立的积分/耦合误差与尾事件比较：单坐标误差可能随 n 累加，对数归一化误差在 nF 中放大。若能够构造连续变量与网格变量的耦合，并严格证明每坐标各 Z_j 的误差不超过 epsilon，可用总和误差 n epsilon 和阈值 h±n epsilon 的事件夹逼；现有方案本身没有提供这种证明。多项计数抽样精确并不填补这一缺口，也不能单凭 Monte Carlo 的正估计得到严格连续模型概率下界。

尤其需要区分中心化诊断网格与未中心化的来源网格。把经验均值减掉会改变分布；若先中心化 X 再取 log，改变还经过非线性变换，不能简单当作对 S 平移常数。中心化版本仅可诊断，不能认作原来源概率。主线所述 n 约为 2e8 至 9e8 时，极小的单坐标 Z 均值偏差也可积累为明显的总和漂移。单独比较协方差收敛不够，后续积分必须控制所用 theta 附近的完整 CGF F(theta) 及 n(F_grid-F_continuous)，同时核对梯度、阈值和事件条件。对有限网格估计较小的 Monte Carlo SE 不能消除此系统偏差。

若按 H 的平滑断点做分段 Gauss 积分，应把全部相关断点与端点纳入积分分段，并在实际倾斜参数附近比较 F、梯度和所需矩的求积收敛；单次高阶求积结果不能自动视为误差认证。该建议尚未被本次只读审查实测或验证。

## 本机独立枚举核验

本机 Python / NumPy 2.5.4 实际枚举了三状态、n=4 的全部 15 种计数。取均匀原律，Z 的三行为 (0.2,-0.4,0.1)、(-0.3,0.25,0.15)、(0.1,0.05,-0.2)，theta=(0.7,0,0.4)，h=-0.2。结果：

- F=0.01586520387903481；q=(0.39279104817220567,0.28238680681060163,0.32482214501719264)。
- A=1.3277168533949317；直接枚举 P(E)=0.14814814814814814；倾斜枚举 A E_q W=0.14814814814814814，float64 差为 0。
- Var_q(W)=0.0762046091889764。
- 若错误删除 theta_2=0 对应的第二条件，原律事件概率变成 0.5555555555555555，明确改变了目标。

这是独立实现的一致性检查；恒等式的依据是上面的似然比推导，而不是数值相等本身。
