# 第36轮：模分类来源的短尺度归约与合法低频投影

2026-10-29。本轮没有得到新的正对数或多项式下界。主要严格结果是把一种随类别数增长的非乘积机制缩减到短尺度，并给出允许类别失衡的宏观版本。低频投影虽能合法消除HB，剩余远位移误差没有闭合。

## 1. 主要严格结论

固定R整除K，每表每坐标在每个粗格有准确质量1/K。按源格余数和模R选择整格使用的表，得到单位质量非乘积来源F；其真实表先验为1/R，先验产品混合记为 \(\bar f\)。详见 [theory/PROOF.md](theory/PROOF.md)。

对K≥4，**全部**共同尺度L≥4/K同时有
\[
 |A_LF-A_L\bar f|\le\epsilon A_L\bar f,\qquad
 \epsilon=(R-1)e^{-n/K^2}.
\]
同一乘法夹逼保留到连续尺度最大值及周期弱系数，常数独立于尺度数量。若R≤K且 \(n/K^2-\log K\to+\infty\)，ε趋零。这一模分类机制相对自身先验混合的额外收益，必须到L<4/K中寻找；不能从旧宏观窗口的小残差推得正log因子。

证明先作实际字符乘积及有理窗口探路，再建立有限群展开。每个坐标窗口有至少两个完整粗格，连续根单位几何和产生严格损失；坐标乘积使非零字符指数衰减。L≥1还有更强的通用帽 \((R-1)2^{-n}\)，不需逐格假设，只需整类别平衡。

## 2. 跨格错误与条件弱化

独审发现：补偿线的独立均匀jitter经箱平滑后有若干峰跨格，类别质量不一定准确1/R。例如K63/v8有两个跨格箱，峰测度R3类别最大偏差约.007484。低于K/R的三角模态类别积分为零，只能保留原有类别质量，不能修复失衡。已明确这一适用条件，未把平衡定理套给这些样本。

随后用实际dyadic源做Fraction质量探路，并证明失衡版本。令每个产品边际的非零类别字符模都≤d<1，记
\[
 \zeta=(R-1)d^n,\qquad \epsilon=(R-1)((1+d)/2)^n.
\]
未归一化联合选择源总质量Z满足 \(|Z-1|\le\zeta\)。ζ<1时，**实际除以Z**后的来源，在全部L≥1上与均匀参考混合及真实表先验混合均有乘法因子
\[
 \frac{(1-\epsilon)_+}{1+\zeta}
 \quad\hbox{和}\quad
 \frac{1+\epsilon}{1-\zeta}.
\]
等测度类别、统一正背景κ给d≤1−κ。固定κ>0且logR=o(n)时，仍发生宏观退化。本轮没有把4/K结论迁给只知类别失衡帽的修正来源，也没有把36个具体正性证书升级成任意n参数族的统一证明。

## 4. 低频投影：真实来源合法，远位移仍未付账

从平滑primitive中移去包括零频的低频投影，记高频部分Q，将desired B置于移除的频带。真实密度同时加入投影的导数修正；质量保持1，HB对全部L,J严格为0。不能只在原Gram表里删掉cross。

令C为Q的自相关、α=6C(0)，谱尾为T。原目标下投影误差准确为
\[
 G_{\rm proj}-9L^2/29=(2C(0)-1/3)-2C(L)-T(L).
\]
两种真实归一化可消掉共同常数：H重标改变峰质量和背景；B重标保留峰质量，但目标及实际v均乘α，剩余误差为 \(-2C(L)-\alpha T(L)\)。相对误差上两方案等价，不能把目标缩小当新平坦收益。

九组实际对照并非统一改善。K63/v128的v倍Gram误差由7.734变为投影后16.238；K1023/v128则从2.517变为1.935。B重标并同步改目标后分别约3.854、2.250。完整结果和严格来源接口见 [compensation/PROOF.md](compensation/PROOF.md)。

36个具体来源的全x正性已另行支付：保存U视为精确dyadic，以有理π界、Taylor余项和70位有向Decimal重新包住系数，最小正密度下端>.0168。根代理隔离重放证书及12个有理平滑核对，结果一致；另一路代理复核全部系数与缩放。该证书不认证NumPy Gram曲线或高维尾概率。第一项尚未闭合的预算仍是所选来源剩余C(L)在整个窗口上的新小帽。

## 5. 下一处真正缺口

对本轮逐格平衡模分类族，连续尺度比较已完成至L≥4/K。水平集并集及已证比较给 \(W(MF)\le W(M_{<4/K}F)+(1+\epsilon)W(M\bar f)\)。短尺度水平集尚未获得新的下界。若先验本身只有平方根量级，而希望分类额外产生正log因子，则需要具体的参数及来源序列、固定a,c>0、N₀，使每个n≥N₀都有阈值λ_n满足
\[
 \lambda_n\left|\left\{x\in\mathbb T^n:
      \sup_{0<L<4/K_n}A_LF_n(x)>\lambda_n\right\}\right|
      \ge c\sqrt n\,(\log n)^a.
\]
目前没有这样的构造、证明或支持其阶数的数值证据。本式是仍未完成的目标；归约没有给出它。若收益来自先验混合本身，也必须单独证明，不能归于类别选择。

原总体目标仍是寻找正对数增益；以上仅排除本族在已覆盖尺度上的额外机制，不将失败试验理解成平方根一般上界。保留的另一候选方向是用合法补偿进一步控制远位移C(L)，其完整概率链也尚待证明。
