# 与分段数无关的 posterior/prior 包络

下述结论先经 `probe.py` 的确定Poisson–binomial (PB)计算探路，再给出自含证明。没有Gaussian、saddlepoint或极限近似。数值只是验证有限输入；一般结论由以下有限n证明给出。

## 1. 条件可用结论

设n≥1，独立Bernoulli变量之和为S，各参数

`3/10 ≤ p_i ≤ 7/10`，基准参数 `49/100 ≤ η ≤ 51/100`。

令B~Bin(n,η)，并记

`Δ=Σ_i(p_i−η)`，`d=Δ/√n`，`D=Σ_i(p_i−η)²`，`τ=D/n`。

若D=0，则S与B同分布，所有比例恰为1。若D>0，则每个k=0,…,n都有

`P(S=k) ≤ (20/3) exp[5Δ²/(7D)] P(B=k)`。       (1)

因此对任意整数集合I（不只连续段），

`P(S∈I) ≤ (20/3) exp[5d²/(7τ)] P(B∈I)`。    (2)

空集两边严格为零，分段多少不出现在常数中。尤其在明确的条件 `τ≥τ0>0` 下，得到 `(20/3)exp[5d²/(7τ0)]` 的统一系数。Δ=0、D>0时(1)仍成立，系数只是20/3；不需要除以Δ。

τ不是单纯的原variance defect。精确恒等式是

`D=nη(1−η)+(1−2η)Δ−Var(S)`。

η=.5时τ=1/4−Var(S)/n；η偏离.5时必须保留线性漂移项。(1)对τ很小的输入可能非常差，这是必要的适用性边界，不是R因子。

## 2. 精确倾斜与mgf比

写q_i=p_i−η。对z=e^t>0，令

`M(t)=∏_i(1−p_i+p_i e^t)`，`Mη(t)=(1−η+ηe^t)^n`，

`u=(e^t−1)/(1−η+ηe^t)`。

则精确地

`M(t)/Mη(t)=∏_i(1+u q_i)`。

u的闭极限范围为 `[−1/(1−η),1/η]`。因 |q_i|≤21/100，η和1−η均≥49/100，所以连同两个无限倾斜端点都有 `|u q_i|≤3/7`，且所有1+uq_i为正。

对|x|≤3/7，有

`log(1+x) ≤ x−(7/20)x²`。                   (3)

证明：x≥0时，`x−log(1+x)=∫_0^x s/(1+s)ds ≥ x²/[2(1+3/7)]`；x<0时写y=−x，差值为`∫_0^y s/(1−s)ds≥y²/2`，故同一系数可用。

于是当D>0时

`log(M/Mη) ≤ uΔ−(7/20)u²D ≤ 5Δ²/(7D)`。  (4)

最后一步仅配方；即使最优u不在实际范围内，向所有实数u放松仍给上界。D=0时所有q_i=0，mgf比严格为1，单独处理。

## 3. 局部质量比的常数帽

先取0<k<n，并选择有限t使基准倾斜后的成功率为r=k/n，即

`e^t=r(1−η)/[η(1−r)]`。

精确指数倾斜后，第i参数为 `p_i(t)=p_i e^t/(1−p_i+p_i e^t)`，而B倾斜后恰为Bin(n,r)。记P_t为PB倾斜律，V=nr(1−r)。系数提取给精确恒等式

`P(S=k)/P(B=k) = (M(t)/Mη(t)) · P_t(S=k)/P(Bin(n,r)=k)`。 (5)

下面证明右侧局部比≤20/3，不要求P_t的均值等于k。

令 `a_i=[p_i/(1−p_i)]/[η/(1−η)]`。参数范围保证

`49/119 ≤ a_i ≤ 119/49`。

且

`p_i(t)(1−p_i(t)) / [r(1−r)] = a_i/[1+(a_i−1)r]² ≥ min(a_i,1/a_i) ≥49/119>2/5`。

故倾斜PB的variance V_t≥(2/5)V。

对任意独立Bernoulli和T、variance v>0，由有限多项式的Fourier系数恒等式及

`|1−q+qe^{is}|²=1−4q(1−q)sin²(s/2)`，

有

`P(T=k) ≤ (2π)^{-1}∫_{−π}^{π} exp[−2v sin²(s/2)]ds ≤ sqrt(π/(8v))`。

最后用了 `sin(|s|/2)≥|s|/π`，再把Gaussian形状的确定积分放宽至整条实轴；这只是Fourier积分上界，不是把T当Gaussian。再结合质量≤1以及V_t≥(2/5)V、π<16/5，得到

`P_t(S=k) ≤ min(1,1/√V)`。                 (6)

另一方面，Bin(n,r)的均值k为整数且k是其mode（由相邻质量比直接核对）。Chebyshev给 `P(|B_r−k|<2√V)≥3/4`，这一区间最多有4√V+1个整数。因此

`P(B_r=k) ≥ 3/[4(4√V+1)]`。               (7)

用(6)/(7)：V≤1时比≤`(4/3)(4√V+1)≤20/3`；V≥1时比≤`(4/3)(4+1/√V)≤20/3`。结合(4)、(5)即证明内部k的(1)。n=1没有内部k，无遗漏。

端点k=0与k=n不使用零variance的局部质量除式。直接写

`P(S=0)/P(B=0)=∏(1−p_i)/(1−η)`，

`P(S=n)/P(B=n)=∏p_i/η`。

它们分别是mgf比在u=−1/(1−η)、u=1/η处的极限。第二节的正性与(4)在端点仍成立，因此端点甚至无需20/3这个局部因子。(1)对全部k完成。逐k求和给(2)。

## 4. 对gated/prior输入的精确迁移

固定真实query x、一个共同L，表b的真实产品cube均值为A_b≥0，其正class核比给参数p_{i,b}。同一实际source class law为η，分段I_b的实际prior权重为 `π_b=P(Bin(n,η)∈I_b)`。记D_b、d_b、τ_b与上文同义，并定义

`H_b=1` 若D_b=0，否则 `H_b=(20/3)exp[5d_b²/(7τ_b)]`。

若各表参数在规定范围，则点态有

`Σ_b A_b P_{p_b}(S∈I_b) ≤ Σ_b H_b π_b A_b ≤ (max_b H_b) Σ_b π_b A_b`。 (8)

这是真正的共同L、gated平均对实际prior平均的包络，显式常数不含R。空段π_b=0且posterior概率同为0，保留不影响结论。不同表的p可以任意相关；证明没有假设尺度、表、或来源选择独立。不得在先验权重中误用1/R。

如果只把本结论用于bin条件均值的PB参数，则(8)只比较条件均值，不自动成为每个隐藏query的点态比较；必须保留原来的条件方差/Cantelli转移。nominal参数和区间计算也须支付已有误差。

若所有表同时满足τ_b≥τ0且|d_b|≤d0，才可从(8)读出固定系数 `(20/3)e^{5d0²/(7τ0)}`。max_b不带显式R，不等于这些条件对所有表成立的概率与R无关。没有对漂移事件、τ小事件、极端tail或H_b的可积性给出控制，故不能把(8)直接积分为R统一weak/L1界。exp(Cd²)本身可能不可积。

## 5. 已证反例与适用边界

仅以有界d获得全部k的常数比是不可能的。取η=.5、n≥25、所有p_i=.5+1/√n，则d=1、D=1；在k=n处

`P(S=n)/P(B=n)=(1+2/√n)^n ≥ exp(2√n−2)→∞`。

这里用了0≤x≤1时 `log(1+x)≥x−x²/2`。所以任何只依d的固定 `C1 exp(C2 d²)` 都不能支配全部pmf/整数段。τ=1/n趋零，正是(1)保留的退化。

对一个具体更弱候选 `P_p(I)≤2e^{2d²}Pη(I)+2/√n`，本轮有精确有限反例：n256、p_i=9/16、η=1/2、d=1、I=[147,256]。Python整数与Fraction核验

`P_p(I)−16Pη(I)−1/8 = .08777219692644… >0`。

完整正有理残差保存在RESULTS.json。由于e<11/4，2e²<16，它也反驳所述较小系数候选。e<11/4可由级数前四项和8/3及余项<5/96直接得出。这个反例只反驳这里具体常数的加性形式；本文不以有限筛选宣称已排除所有可能常数组合的加性式。

概率内点假设也不可删除：n128、64个p=0与64个p=1时，S确定为64，η=.5、d=0、τ=.25，但pmf比约14.21>20/3。它在数值中作为明确越界对照，不是假装满足本定理。全部p∈[.3,.7]时的局部variance比较正是排除这种集中失效的步骤。
