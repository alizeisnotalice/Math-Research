# 第39轮：posterior/prior 的条件点态包络

本轮先完成确定NumPy探路，再给出一个有限n、自含、与分段数R无关的包络。一般的“只看均值漂移d就有常数比例”不成立；一个具体的exp(Cd²)+n^{-1/2}加性候选也有精确有理反例。可证明式必须保留异质性/variance-defect量，并另外控制其退化。

## 结果

设S为独立Bernoulli(p_i)之和，p_i∈[.3,.7]，η∈[.49,.51]。定义

`Δ=Σp_i−nη`，`d=Δ/√n`，`D=Σ(p_i−η)²`，`τ=D/n`。

`PROOF.md` 自含证明，对全部k及全部整数集合I：D=0时PB与Bin(n,η)严格相同；D>0时

`P_p(S∈I) ≤ (20/3) exp[5d²/(7τ)] P_η(S∈I)`。

这里 `D=nη(1−η)+(1−2η)Δ−Var(S)`，η偏离.5时保留线性项。若τ≥τ0>0，可把指数分母换成τ0。Δ=0、D>0时系数20/3；n1和k0/n端点单独覆盖，没有零variance除式。

证明用精确指数倾斜与Fourier局部质量上界。将PB与基准Bin一起倾斜至基准均值k，倾斜后variance至少为基准的2/5；Fourier积分上界与Bin mode的Chebyshev下界给局部质量比≤20/3。剩余mgf比写成∏(1+u(p_i−η))，用统一二次压低和配方得到指数5Δ²/(7D)。不调用Gaussian、BE、saddlepoint或渐近式。

对第38轮每个真实query和共同L，若所有表PB参数满足范围条件，令π_b为实际Bin(n,η)段概率，则

`gated = Σ_b A_b PB_b(I_b) ≤ Σ_b H_b π_b A_b ≤ (max_b H_b) prior`。

显式常数无R，空段保留为0。若只在bin条件均值层用该式，结论也只在条件均值层，不能省略隐藏位置的Cantelli转移。更没有由此得到R一致的积分/weak界：必须支付|d|大、τ小及多表同时满足条件的费用，exp(Cd²)可能不可积。

范围假设也必要：n128、64个p=0与64个p=1的pmf比约14.21，超过d0下的20/3；交替.001/.999也超过该帽。它们明确标记为越界对照，未当成定理范围内失败。
