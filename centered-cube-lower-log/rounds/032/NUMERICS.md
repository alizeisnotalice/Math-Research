# 数值来源与实现：初次2.5.4记录及归档复跑说明

2026-10-29。本轮实际运行了 n 达 \(2.16\times10^8\) 的合法正来源实验，使用精确多项分布压缩 bin 指标，不生成 n 个坐标、不模拟 Gaussian 过程。**这些来源没有获得原匹配平方根下界；九个尺度也不能检验其前的渐近对数。** 有信息的结果是：原有限域标签可保留；解析条件平均与严格方差帽可把压缩计算接回真实 cube 尾概率；同步上方量明显优于共同尺度量；最高 v 的尾层及质量诊断波动不足以支持增长趋势。

原参数可行性与完整量词见主报告、parameter_gate结果及独审；本附件保留本次合法替代族的具体推导。程序与结果只写本目录，无 Git 修改、无新代理。

**版本口径。** 本附件保留子代理Python3.15.0/NumPy2.5.4的初次统计表，与 `initial_large_dimension_results.json` 对应；不是主线新环境的结果表。主线随后用Python3.12.14/NumPy2.3.5完整复跑全部固定配置和预定诊断，输出为 `large_dimension_results.json`，主要新值列于 `REPORT.md`。NumPy版本改变了多项分布采样的随机序列，未宣称逐位复现。两版都没有追加seed追求通过，初次v16异常保留。



## 1. 原来源哪些资格在可计算区间失败

读入依据是第30/31轮报告，以及 `../028/source_interface_baseline.tex`。固定 p=1/2，原规则选择最大的 \(K=2^d-1\)，使 \(v=9p^2n/(29K^2)\ge16\log n\)，再取 \(B=2^{\lceil\log_2v\rceil}\)、\(M=\lceil\sqrt v\rceil\)。完整有限域存在性要求 \(q=K+1>H(B)\)，原文以更方便的 \(q>3B^4\) 保证。

实际整数/浮点参数代入：n=\(10^{12}\) 时 K=8191、v≈1156.4、B=2048，而 \(q=8192\ll H(B)\approx3.95\times10^{13}\)。n=\(10^{30}\) 时仍失败。n=\(10^{36}\) 的示例通过该存在性预算，但 K≈\(4.5\times10^{15}\)，本身不能枚举。这个示例也不是全部渐近门槛的有限维认证。

因此没有在“任意标签”上假装恢复完整来源，也没有声称一个可算 K 的实验已匹配原下界。

## 2. 本轮采用的真实有限域、增长 v 合法来源

使用 B=4 的真实迹标签：
\[
 y_j=\operatorname{Tr}(g^j)+2\operatorname{Tr}(6g^j),\qquad
 a_j=(j+(y_j+1/2)/4)/K.
\]
GF(2^8)、GF(2^10) 分别用多项式 0x11d、0x409，g=2。程序实际验证 g 遍历全部非零元素、迹值为0/1、非零状态直方图、三非零元素乘法 Sidon、六个有序比率互异及无邻接/短 lag。两个域的基都是 (1,6)：

|K|缺陷 lag 集合 D|q>H(4)=129|
|---:|---|---|
|255|26,57,83,172,198,229|是|
|1023|67,78,145,878,945,956|是|

q=256 未过更强的方便门槛 \(3B^4=768\)，但过 H(4)，且基的实际功能资格已逐项验证；q=1024 也过更强门槛。

每个来源仍完整使用
\[
 \rho=1-p+p\mu_{K,\delta}+(p/K)D_M,\quad
 p=1/2,\quad w=4,\quad \delta=(4Kv)^{-1},\quad M=\lceil\sqrt v\rceil.
\]
三个点为：

|v|K|n=\(116vK^2/9\)|M|Rmax|Q|N|
|---:|---:|---:|---:|---:|---:|---:|
|4|255|3,352,400|2|8|24,480|256|
|8|1023|107,908,768|3|16|196,416|192|
|16|1023|215,817,536|4|32|392,832|128|

全部正峰留在本格，质量严格为1，背景下界由 \(1/2-(10/(3K))H_M>0\) 保证。没有删低频、另归一化或用随机标签替代迹标签。

明确失败的**原匹配**接口是 \(v\ge16\log n\)、最大周期选择，以及 v=8,16 时 B≥v。故这里是有 n 依赖的合法原型来源族，未获原 \(\sqrt n\) 下界。只用三个有限点，不拟合渐近。

## 3. 精确压缩对象、查询网格与成本

共同尺度 \(L_k=(80+k)/72\)，k=0,…,8；相位 r/Rmax。R=1,4,8,16,32 中可用者从该相位网格嵌套抽取。真实来源仍为
\[
 F_{\rm sh,R}=\frac1R\sum_r\prod_i\rho(x_i-r/R),\qquad
 F_{\rm ind,R}=\prod_i\left[\frac1R\sum_r\rho(x_i-r/R)\right].
\]
均为单位质量。各混合分量、各坐标共用同一个 L。

取均匀空间 bin 数
\[
 Q=\operatorname{lcm}(8Kv,144,R_{\max}).
\]
原子中心、平滑盒端点、九尺度半长平移与全部相位的断点均落在 bin 端点。主核 \(H_{L,\delta}\) 在每个开 bin 内线性，低频是有限三角多项式。因此
\[
 m_{q,L,r}=E[Y_L(X-r/R)\mid X\text{ 在 bin }q]
\]
由主核的中点值及每个 cosine 的精确 sinc 平均求出。代码对主核先做整数有理运算：位置采用 \(2Q\) 单位，最后才除法，不用未认证查询网格冒充 Lebesgue 结果。

真实 n 个均匀坐标的 bin 计数
\[
 (N_q)_q\sim\operatorname{Multinomial}(n;1/Q,\ldots,1/Q)
\]
由 NumPy multinomial 精确抽取。给定 counts 后，各坐标在其 bin 内仍独立均匀（或按对称交换后的等价条件律）。于是固定相位乘积的条件平均是
\[
 A_{L,r}=\prod_qm_{q,L,r}^{N_q}.
\]
**A 是真实 cube average 的条件均值，不是真实点上的乘积。** 表只按 L 流式构建，最大 counts 与单尺度相位表约数百 MB；复杂度从 \(O(NnRL)\) 降成 \(O(NQRL)\)。本机三个点主体耗时约0.40、2.40、5.34秒，独立诊断另5.81秒；具体时间不作性能承诺。

## 4. 条件方差帽与真实共同尺度尾下证据

令 \(\varepsilon=p/K\)。因来源正且1周期单位质量，L>1 时 \(Y_L\ge1/L\)。在每个 bin 中，
\[
 |\partial_xY_L|\le\frac{\varepsilon}{L}
       (|\partial_xH_{L,\delta}|+D_B),\qquad
 D_B=\frac{880}{63}H_M,
\]
其中使用 \(\pi<22/7\)、\(c_m<20/(9m^2)\)。主核斜率绝对值恰为 0 或 \(1/\delta\)，记过渡指标 \(T_{q,L,r}\in\{0,1\}\)。由方差≤range²/4，
\[
 \frac{E[Y_L^2\mid q]}{m_{q,L,r}^2}
 \le1+t_{T_{q,L,r}},\quad
 t_b=\left[\frac{\varepsilon(D_B+b/\delta)}{2Q}\right]^2.
\]
独立坐标相乘后，固定相位乘积的条件相对方差至多
\[
 r_{L,r}=
 \exp\{n\log(1+t_0)+N_{\rm trans,L,r}
             [\log(1+t_1)-\log(1+t_0)]\}-1,
\]
其中 \(N_{\rm trans}=\sum_qN_qT_q\)。无 Gaussian 近似，也不要求相位间独立。

对选定 L 的共享平均，Cauchy 给
\[
 \operatorname{Var}(F_{\rm sh,L}\mid N)
 \le\left[\frac1R\sum_rA_{L,r}\sqrt{r_{L,r}}\right]^2.
\]
选 \(L=L(N)\) 为使条件共享平均最大的九尺度之一，仍合法：条件于 N 后选择已确定。

若该条件平均为 m、条件相对方差帽为 r，Cantelli 给
\[
 P\{V_{\rm true}>\lambda\mid N\}\ge
 B_\lambda(N):=
 \frac{(1-\lambda/m)_+^2}{r+(1-\lambda/m)_+^2}.              \tag{C}
\]
因此 \(E B_\lambda\) 是真实共同尺度 maximal 尾概率的下界。计算 \(E B_\lambda\) 的 MC 估计仍有统计误差，**不是已经认证的总体数值下界**。

也记录
\[
 \bar V=\max_L R^{-1}\sum_rA_{L,r},\qquad
 \bar U=R^{-1}\sum_r\max_L A_{L,r}.
\]
barU≥barV 是条件均值层面的同步上方诊断，不能把 \(\bar U/\bar V\) 当真实 U/V 的样本比值。对 U 的真实尾下证据，是先按每个相位的条件均值选 \(L_r(N)\)，再对相位选择和应用同样的条件方差/Cantelli；真实 U 在它之上。independent 的条件平均则必须先在 bin 内平均相位 m，再跨坐标相乘，程序另行计算。

## 5. Counts 层精确提议、归一化审计与罕见贡献界

提议为整样本层 50% 原始均匀多项分布，50% 从全部九尺度及 Rmax 相位的倾斜多项分布混合。固定 (L,r) 的倾斜 bin 概率是
\[
 p_q^{L,r}=\frac{m_{q,L,r}}{\sum_am_{a,L,r}}.
\]
其相对原始 counts 律的 RN 为
\[
 \prod_q(m_{q,L,r}/\bar m_{L,r})^{N_q},\qquad
 \bar m=Q^{-1}\sum_qm_q.
\]
归一化因子即使数值接近1也保留在 RN 中。最终提议 D 是半个常数1加半个全部 RN 的平均，权重 W=1/D≤2。

当计算 R 个嵌套相位的 V 或 U 下证据时，正贡献要求相应条件平均超过 λ，且
\[
 \lambda W B_\lambda\le
 \min(2\lambda,\ 18R_{\max}/R).                              \tag{IS}
\]
特别是全 Rmax 模型的贡献≤18，不随 λ 的罕见程度增长。 这是准确归一化时的理想帽；归档程序对raw均值的数值Z另乘exp(max(0,n max log Z))，并用新帽重新反演保存的置信下界。该因子不补偿其余未认证舍入。这有助于下一轮设计，但 N=128 的大阈值仍会有很低的有效样本数。

程序在 discovery 半样本选阈值，只在 holdout 半样本评价该固定阈值。尾贡献 ESS 基于 \(WB_\lambda\)，另保存固定阈值全表。对 (IS) 的有界贡献，附一个单侧 Bernoulli-KL Chernoff 下置信值：若 \(0\le Z\le b\)，由 \(e^{tZ/b}\le1-Z/b+(Z/b)e^t\) 得到二项 KL 上尾界；反演给 \(EZ\) 下置信界。51个 holdout 目标每项分配 α=.05/51。统计推导不依赖正态标准误；但全部数值尚未做区间浮点认证，不能单凭 JSON 的置信值宣称严格数值定理。

### 最高 v 的异常必须保留

初始质量检查：

|v|样本平均 W|样本标准误|
|---:|---:|---:|
|4|0.99536|0.01620|
|8|1.00697|0.03250|
|16 初始 seed|0.76421|0.06380|

v16 初始 seed 实际只抽到46/128个 uniform 分支，82个 tilt 分支；精确双侧 Binomial(128,.5) p≈0.001862。仅由 W≤2 得到的点态95% Hoeffding半径为0.24008，初始质量区间仍覆盖1。不能用“3.7个样本标准误”直接判定代码错误，但该点也不能支持精确趋势。独立诊断仅同样固定规模128点、uniform69个；两个 seed 都保存，未继续加样本追求通过。

发现并修正了一个较小的浮点接口不一致：最初 sampling 按连续一维向量归一化，RN 则按二维数组列 mean 求和。v16 的最大 \(n\Delta\log\bar m\) 为 \(1.3754\times10^{-5}\)，远不足解释0.236质量差。稳定脚本已统一求和次序；独立诊断的每个一维查询均值归一化残差为浮点0，probabilities总和残差≤\(1.12\times10^{-16}\)。初始三个 JSON 保留原值，原始 v16 异常未被替换。在同一份已抽取counts上，这项归一化修正只对RN权重及固定阈值积分带来约 \(10^{-5}\) 相对量级的影响；这不适用于更换NumPy版本后的随机序列，也不保证重新选择的holdout阈值不变。

## 7. 误差与范围账本

- 多项计数是准确分布压缩，不是用均值/正态替代真实 bin 随机性。
- 条件均值和方差帽有解析依据；把条件均值作为真实点值则是错误，本轮通过 (C) 处理。
- 双精度三角函数、dot 与归一化未使用 interval arithmetic。局部核对不等于所有 bins 的浮点证书；要输出严格数值下界，应另把每个条件均值/方差帽的误差传播至 n 次乘积。
- 九尺度真实 maximal 的弱系数确定≤9。因此不能把这些表拟合为 \(\sqrt n\log n\)，也不能由九尺度的阴性结果排除完整窗口。
- barU/barV 分位数来自 importance proposal 的样本分布，未作为 Haar 分位数加权反演；它们只描述本次被提议命中的中心。条件尾下证据的 MC 积分才使用目标权重。
- 周期来源转成 \(\mathbb R^n\) 的 L1 输入仍可用第31轮整数胞截断：质量精确为1，内部中心保留比例 \((1-1/T)^n\ge1-n/T\)。本轮不额外近似或丢弃空间质量。

## 8. 能改变下一步选择的结论

最重要的进展是可计算接口，而不是正增益：有真实有限域标签的 n≈\(10^8\) 来源可通过精确 counts、解析条件均值和 Cantelli 访问；不必直接生成 n 个坐标。此接口仍受 Q 的原子/尺度断点数控制，不能直接跨到 K≈\(10^{15}\) 的完整匹配源。

数值建议下一轮优先处理**同步**和**查询规模**，而不是在本三点族加大 N 追趋势：

1. 在有限共同尺度上，即使 barU 的混合收益出现，barV 未同步；必须针对真实 V 设计尾层，不应先把平均 phase maximal 当目标。
2. 若继续数值，应先扩大共同尺度数量至自然网格，且报告确定的 query 数帽。一个有利算术结构是 \(L_j=10/9+j/(Kv)\)：在 K、v 的本次整除条件下，Q仍可取 \(24Kv\)，不必随 query 数再乘一遍分母；然而 matmul 总成本仍线性增加至 \(O(NQRL_{\rm count})\)，需要先选一个有界小点验证，不能直接跑完整匹配族。
3. 主线现已告知：任意一格一原子、允许非 iid product 的正混合 strong L1 帽及 counts 贡献引理已通过独审。本轮不重证；下一次应先按该广义帽筛选 v 与 R 的目标范围，再决定是否值得增加查询，不能把它仅理解为 translation 模型结论。

一个合适的后续目标不应是“代理 weak scan 随 R 上升”，而应是：在合法来源和明确的 query 集上，找到固定阈值 λ，使**共同尺度** Cantelli 条件积分下证据随 R 有可靠提升，并在可量化的方差/MC/浮点误差后仍成立。只有随后恢复完整匹配资格、自然尺度数与真正的渐近量词，才谈 \(\sqrt n\) 前的正对数。
