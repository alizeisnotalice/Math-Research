## 1. 实际数值探路与校验

`python3 probe.py` 使用本机 Python 3.15.0 / NumPy 2.5.4，约 3.5 秒运行 6336 个确定性积分。K=4,8,16,32；q=1,2,3；ell 为 [.01,.99] 的41点等距网格加1/6、1/3、2/3，共44点；每项6个相位。源有两种：均匀源；每格质量1/K、基底密度.15、宽度.22/K、峰密度额外.85/.22的严格正 box 源。第 i 格 box 左端为 `(i+.78*(((7*i mod K)/K+shift) mod 1))/K`，shift=0,1/32,1/16,1/8,1/4,1/2。class 始终是原格 [i/K,(i+1)/K)，不是 box 编号重排。

周期区间积分由分段线性原函数精确表示；在全部源边界±ell/2处分段，再用16阶 Gauss–Legendre 对最终有理函数积分。独立核验包括：

- n=1、均匀源、K=2、q=1、ell=1/2 的精确非平凡 Gram 特征值为1/27；实算差3.89e-16。

- query 质量残差≤4.45e-16，class prior残差≤7.78e-16，平凡特征向量残差≤1.67e-15；最小非平凡特征值约−7.13e-17，为浮点量级。
- n=2、K=4，直接构造对称张量子空间并投影 H⊗H，trace 与 h_2(λ) 公式在所测例中浮点一致。

最大 class 非平凡 trace 为 .12245970921549565，出现在 K32、q1、ell1/3、box相位0；全源 χ²=.12488537260472486，Jensen帽=.125。该例 histogram trace 在 n=1、2、10、100 的数值及其无限乘积上限见 JSON。全部扫描满足 class trace≤全源χ²≤Jensen帽，最大正向浮点超帽4.17e-17。

## 2. 严格定义与一维 χ² 上界

令 T=R/Z，rho≥0、∫_T rho=1；正性不是本结论所必需，因为 q≥1 保证 query 密度正。设 L=q+ell，其中整数q≥1，0≤ell≤1。真实长度L的中心窗周期计数核，在对query作确定性平移q/2后，可写为

k_L(x,y)=(q+h(x-y))/L，h=1_{[-ell/2,ell/2] mod1}。

q为奇数时该平移是半周期；所有以下积分和Gram不受该平移影响。忽略零测边界后这正是周期源的中心窗平均核，不是额外假设。

生成 Y∼rho(y)dy，再令 X|Y=y 的密度为 k_L(x,y)。记

r(x)=∫rho(y)h(x-y)dy，a(x)=(q+r(x))/L，Q(dx)=a(x)dx。

有0≤r≤1，∫r=ell。相对于乘积边缘的全源 χ² 满足精确恒等式

χ²(P_{X,Y} || Q⊗P_Y)
=∫_T ∫_T rho(y)(k_L(x,y)-a(x))²/a(x) dy dx
=∫_T r(x)(1-r(x)) / [L(q+r(x))] dx。

令 f(t)=t(1-t)/(q+t)，则 f''(t)=−2q(q+1)/(q+t)^3≤0。Jensen 给出

χ²(P_{X,Y} || Q⊗P_Y) ≤ ell(1-ell)/(q+ell)^2 ≤ 1/[4q(q+1)]。

最后一步直接求导：b'(ell)=[q−(2q+1)ell]/(q+ell)^3，极大点ell=q/(2q+1)。均匀rho使r恒为ell，第一不等式取等。这里是 χ² mutual information，而不是通常概率论中允许值接近1的单个最大相关系数定义；不能混淆。

把源划成任意有限classes，质量η_c>0、总和1，允许用子密度rho_c、∑rho_c=rho表述。令

z_c(x)=[qη_c+∫rho_c(y)h(x-y)dy]/L，p_c(x)=z_c(x)/a(x)，u_c=√η_c，
H_cd=E_Q[p_c(X)p_d(X)]/√(η_cη_d)，A=H−uu^T。

则H u=u，A≥0，Au=0，而且

τ:=tr A=tr H−1=χ²(P_{X,C} || Q⊗P_C)
≤χ²(P_{X,Y} || Q⊗P_Y)≤β_q:=1/[4q(q+1)]。

class不等式可直接由每个x上的条件期望收缩证明：令 V=h(x−Y)，则∑η_c(E[V|C=c]−r)²≤E(V−r)²=r(1−r)，再除以L(q+r)并积分。此证明也明确了方向：class压缩减小χ²，绝不能把class谱trace当成全源χ²的下界以外的逆向证据。

n=1核对的精确计算：均匀K2、ell1/2时，r_1(X)在[0,1/2]上均匀，a=1，p_1=(1/2+r_1)/(3/2)在[1/3,2/3]上均匀。所以τ=4Var(p_1)=1/27；全源χ²=1/9。两个量确实不同。

## 3. 严格的对称 n-histogram trace 公式

固定同一个channel，取n个独立的(C_i,X_i)。令N为K类计数，prior为真实Mult(n,η)，π_m=n!∏η_c^{m_c}/∏m_c!；令g_m(X^n)=P(N=m|X^n)。定义后验Gram

G^{(n)}_{m,r}=E_{Q^n}[g_m g_r]/√(π_mπ_r)。

设H的谱为1,λ_2,...,λ_K，其中λ_j≥0、∑_{j≥2}λ_j=τ≤β_q。则严格有

tr G^{(n)}=h_n(1,λ_2,...,λ_K)
=∑_{d=0}^n h_d(λ_2,...,λ_K)
≤∏_{j=2}^K(1−λ_j)^{-1}≤1/(1−τ)≤1/(1−β_q)。

证明：单坐标条件期望算子的源端Gram是H；独立乘积给H^{⊗n}。normalized histogram indicators恰是源端对称张量空间的标准正交基，所以G^{(n)}是H^{⊗n}在该子空间的压缩。对称张量特征向量按多重指标α、|α|=n编号，特征值为∏λ_j^{α_j}（λ_1=1）；这给出h_n精确式。非负项求和给无限乘积；也可用h_d(λ_2,...,λ_K)≤τ^d直接求几何级数。没有Gaussian、CLT或n→∞近似。

因此任意n、K、允许的rho与class划分，都有

χ²(P_{X^n,N} || Q^n⊗P_N)=tr G^{(n)}−1≤β_q/(1−β_q)。

q=1时trace≤8/7，histogram χ²≤1/7。n增大本身不会在这个固定channel的二阶后验trace里产生log K或log n。这里既没有取消其他score权重，也没有比较不同table的query密度；不能由此推出多table selector的HL上界或下界。

## 4. 微平移table的共同 PSD 支配：数值有希望，尚无连续族证明

所有table保持η_c=1/K，所以源端有共同u及共同class坐标。对固定K、q、ell的6个table，以B为u^⊥的固定正交基，记A_b=B^T(H_b−uu^T)B。程序取这些A_b的均值M，作很小的谱下截断得到M_reg，计算

γ=max_b λ_max(M_reg^{-1/2} A_b M_reg^{-1/2})·(1+1e−8)，D=γM_reg+1e−10 I。

这直接检验共同Löwner支配，无需不同channel共基。程序还对固定K、q的全部44个ell及6个table共264项重做同一构造。有限扫描的所有剩余D−A_b最小特征值≥约1e−10；最大非零交换子Frobenius范数约.00137554，所以实测box族确有不能共用特征基的例子。

|共同覆盖范围|uniform：K4 / K8 / K16 / K32，q1的trD|positive box：K4 / K8 / K16 / K32，q1的trD|
|---|---|---|
|全部44个ell及6个table|.113488 / .183193 / .240510 / .277328|.160287 / .226452 / .396513 / .391499|

固定ell构造的全扫描最大trD=.4192829744；把全部ell一起构造的最大trD=.3965134026。两者使用不同参考均值，非最优支配矩阵，所以这两个数的次序不矛盾。q2、q3更小，全部记录在JSON。K32/q1/box的isotropic支配trace约1.469，低trace非各向同性D则约.3915，说明保存矩阵几何有实质价值。

条件性严格推论：若对任意一族channel已经严格认证共同η以及0≤A_b≤D、Du=0、trD<1，则H_b≤uu^T+D；张量Löwner单调性及对称子空间压缩给

tr G_b^{(n)}≤h_n(1,eig(D|u^⊥))≤∏(1−d_j)^{-1}≤1/(1−trD)。

该推论不要求A_b彼此交换。但本轮数值D只覆盖有限扫描，并且未向外认证，不能声称覆盖任意微相位、连续ell或真实GF来源。还需注意，各table的Q_b可能不同；共同源端PSD支配并不自动给出共同query measure下多table maximum的尾比较。

仅有逐table trA_b≤β并不能推出维数无关的共同trD：抽象PSD族βe_be_b^T逐个trace=β，任何共同D都满足trD≥(K−1)β。该抽象例不声称由本中心窗源实现；它说明“先证明共同D”是独立任务，不能偷换为逐channel trace帽。
