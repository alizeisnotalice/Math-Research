# 中心方体 Tauberian 常数的高阶渐近

研究Lebesgue测度下的中心轴平行方体极大算子，使用严格水平集。线性输入为任意有限正测度可测集；共享方体的多线性模型以公共交集归一化，单个输入可有无限测度。

## 当前严格结论

固定整数n≥2，令a=2ⁿt=vⁿ、v=2t^(1/n)，
\[
 L_n(t)=\left[1-\frac{a}{(1+v)^n}\right]^{-1},\qquad
 K_n=\binom n2\frac{n^2}{27}.
\]
已由一般输入匹配上下界及独审证明
\[
 C_n(1-t)=L_n(t)+K_nav^6-\left(n+\frac{26}{9}\right)K_nav^7+o_n(av^7).
\]
上界涵盖全部可测输入及全部半径；下界由每个充分小参数的实际有限构造实现。固定维数的little-o不预设维数一致性；第38轮已严格匹配到av⁷，二维式是同一公式的特例。

普通参数的全部系数统一为
\[
 C_n(1-t)=1+\sum_{j=0}^7 b_{n,j}t^{1+j/n}+o_n(t^{1+7/n}),
\]
\[
 b_{n,j}=2^{n+j}\left[
 \sum_{k=1}^{1+\lfloor j/n\rfloor}
 (-1)^{j-(k-1)n}\binom{n+j-1}{j-(k-1)n}
 +\mathbf1_{\{j=6\}}K_n-\mathbf1_{\{j=7\}}(n+26/9)K_n\right],\quad0\le j\le7.
\]
三维b_(3,5)=0；第七系数b_(n,7)在全部n≥2非零，三维为正，其余维数为负。二维b_(2,7)=−16015360/243；全维非零性包含n≥8的解析符号证明，并非有限表外推。

多线性超临界区精确约化为
\[
 C_n^{(m)}(\lambda)=C_n(1-m(1-\lambda^{1/m})).
\]
m≥2时在阈值(1−1/m)^m及以下发散。令ε=1−λ、σ_m=m[1−(1−ε)^(1/m)]，
\[
 A_m(\epsilon)=1+\frac{m-1}{2m}\epsilon
 +\frac{(m-1)(2m-1)}{6m^2}\epsilon^2
 +\frac{(m-1)(2m-1)(3m-1)}{24m^3}\epsilon^3.
\]
关于全部m≥1一致有
\[
 C_n^{(m)}(1-\epsilon)=1+\sum_{j=0}^7b_{n,j}
 [\epsilon A_m(\epsilon)]^{1+j/n}+o_n(\epsilon^{1+7/n}),
\]
并在s=σ_m(ε)、a_s=2ⁿs、v_s=2s^(1/n)下有统一极限
\[
 \lim_{\epsilon\downarrow0}\sup_{m\ge1}
 \left|\frac{C_n^{(m)}(1-\epsilon)-L_n(s)-K_na_sv_s^6}
 {a_sv_s^7}+\left(n+\frac{26}{9}\right)K_n\right|=0.
\]
精确约化和同一个标量余项的模量给出全部m一致性；四阶σ截断误差O(ε⁵)严格小于最高目标ε^(9/2)。三维ε^(8/3)系数仍为160(1−1/m)。没有用L_n(ε)替代自然基线。

二维已进一步完成真实匹配结算：
\[
 C_2(1-t)=L_2(t)+\frac4{27}av^6-\frac{176}{243}av^7+o(av^7),
 \qquad a=4t,\quad v=2\sqrt t.
\]
完整七层总装和独审见第30轮；两份第28轮正式审查已供给其唯一局部接口，
第26轮给真实有限下界。它现在是第38轮一般维数真实七阶公式的二维特例。第40轮已将一般维统一证明编入51页正式PDF，旧二维独立证明与六阶构造模块已合并消重。
二维在自然参数s=σ_m(ε)、a_s=4s、v_s=2√s下传递到全部m≥1，余项一致为o(ε^(9/2))；正式证明见更新论文最后一节。

## 复现

```sh
cd paper
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

需要XeLaTeX、BibTeX、Songti SC、Times New Roman以及标准mathrsfs宏包。主要符号工具为本机Mathematica/Wolfram15 ARM，精确有限证书使用Python Fraction；只把实际运行结果作为证据。

各包README和`rounds/`保留具体输入、实际输出、范围与复现命令。历史必要构造证书保留在对应包，不为CPU占用重复旧批次；更细构造的一侧展开与真实常数的匹配渐近分开记录。
