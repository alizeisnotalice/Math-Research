# 中心方体 Tauberian 常数的高阶渐近

研究Lebesgue测度下的中心轴平行方体极大算子，使用严格水平集。线性输入为任意有限正测度可测集；共享方体的多线性模型以公共交集归一化，单个输入可有无限测度。

## 当前严格结论

固定整数n≥2，令a=2ⁿt=vⁿ、v=2t^(1/n)，
\[
 L_n(t)=\left[1-\frac{a}{(1+v)^n}\right]^{-1},\qquad
 K_n=\binom n2\frac{n^2}{27}.
\]
已由一般输入匹配上下界及独审证明
\[
 C_n(1-t)=L_n(t)+K_nav^6+o_n(av^6).
\]
上界涵盖全部可测输入及全部半径；下界由每个充分小参数的实际有限构造实现。固定维数的little-o不预设维数一致性，尚未识别更细的真实下一项。

普通参数的系数为
\[
 C_n(1-t)=1+\sum_{j=0}^6 b_{n,j}t^{1+j/n}+o_n(t^{1+6/n}),
\]
\[
 b_{n,j}=2^{n+j}\left[
 \sum_{k=1}^{1+\lfloor j/n\rfloor}
 (-1)^{j-(k-1)n}\binom{n+j-1}{j-(k-1)n}
 +\mathbf1_{\{j=6\}}K_n\right].
\]
三维b_(3,5)=0，不能称所列七个幂次均非零。新增目标系数b_(n,6)在全部n≥2非零；例如二维为443392/27，三维为−13312。

多线性超临界区精确约化为
\[
 C_n^{(m)}(\lambda)=C_n(1-m(1-\lambda^{1/m})).
\]
m≥2时在阈值(1−1/m)^m及以下发散。令ε=1−λ、σ_m=m[1−(1−ε)^(1/m)]，
\[
 A_m(\epsilon)=1+\frac{m-1}{2m}\epsilon
 +\frac{(m-1)(2m-1)}{6m^2}\epsilon^2
 +\frac{(m-1)(2m-1)(3m-1)}{24m^3}\epsilon^3.
\]
关于全部m≥1一致有
\[
 C_n^{(m)}(1-\epsilon)=1+\sum_{j=0}^6b_{n,j}
 [\epsilon A_m(\epsilon)]^{1+j/n}+o_n(\epsilon^{1+6/n}),
\]
以及自然基线的统一极限
\[
 \lim_{\epsilon\downarrow0}\sup_{m\ge1}
 \left|\frac{C_n^{(m)}(1-\epsilon)-L_n(\sigma_m(\epsilon))}
 {2^{n+6}\epsilon^{1+6/n}}-K_n\right|=0.
\]
二维ε⁴精度需要四阶σ；三维ε^(8/3)系数仍为160(1−1/m)。没有用L_n(ε)替代自然基线。

二维已进一步完成真实匹配结算：
\[
 C_2(1-t)=L_2(t)+\frac4{27}av^6-\frac{176}{243}av^7+o(av^7),
 \qquad a=4t,\quad v=2\sqrt t.
\]
完整七层总装和独审见第30轮；两份第28轮正式审查已供给其唯一局部接口，
第26轮给真实有限下界。此下一阶结论仅限二维；一般维数仍停在上面的匹配六阶。
更新论文节正在独立编排、复核；当前PDF仍为第23轮38页版本。
