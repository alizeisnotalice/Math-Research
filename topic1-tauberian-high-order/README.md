# 中心方体 Tauberian 常数的高阶渐近

研究Lebesgue测度下的中心轴平行方体极大算子，使用严格水平集。线性输入为任意有限正测度可测集；共享方体的多线性模型以公共交集归一化，单个输入可有无限测度。

## 当前严格结论

固定整数n≥2，令a=2ⁿt=vⁿ、v=2t^(1/n)，
\[
 L_n(t)=\left[1-\frac{a}{(1+v)^n}\right]^{-1},\qquad
 K_n=\binom n2\frac{n^2}{27}.
\]
第57轮已由全部输入匹配上下界及两份独立完整终审证明
\[
 C_n(1-t)=L_n(t)+K_nav^6-\left(n+\frac{26}{9}\right)K_nav^7
                   +\widehat J_nav^8+o_n(av^8),
\]
\[
 \widehat J_n=\frac{(n-1)n^3(2609+1971n+81n^2)}{26244}
                    +\frac{16}{27}\mathbf1_{\{n=2\}}.
\]
八阶归一化余量的极限存在；二维为17638/6561。上界涵盖定义中的全部正有限测度可测输入及全部正半径，下界由每个充分小实参数的真实有限构造实现。固定维数，不主张维数一致性。

ordinary全部系数统一为
\[
 C_n(1-t)=1+\sum_{j=0}^8b_{n,j}t^{1+j/n}+o_n(t^{1+8/n}),
\]
\[
 \begin{aligned}
 b_{n,j}=2^{n+j}\Big[&\sum_{q=1}^{1+\lfloor j/n\rfloor}
 (-1)^{j-(q-1)n}\binom{n+j-1}{j-(q-1)n}\\
 &+\mathbf1_{j=6}K_n-\mathbf1_{j=7}(n+26/9)K_n
 +\mathbf1_{j=8}\widehat J_n\Big],\quad0\le j\le8.
 \end{aligned}
\]
低维幂次碰撞包含在通式内；二维b₂,₈=1737988096/6561。最初研究的归一化极限为−n2^(n+1)，三维b₃,₅=0。

多线性超临界区精确约化为
\[
 C_n^{(m)}(\lambda)=C_n(1-m(1-\lambda^{1/m})).
\]
m≥2时在阈值(1−1/m)^m及以下发散。令ε=1−λ、σ_m=m[1−(1−ε)^(1/m)]、
\[
 A_{5,m}(\epsilon)=1+a_m\epsilon+b_m\epsilon^2+c_m\epsilon^3+d_m\epsilon^4,
\]
其中a_m=(m−1)/(2m)，b_m=(m−1)(2m−1)/(6m²)，c_m=(m−1)(2m−1)(3m−1)/(24m³)，d_m=(m−1)(2m−1)(3m−1)(4m−1)/(120m⁴)。统一余项满足|σ_m−εA5,m|≤(32/3)ε⁶（ε≤1/2）。关于全部m≥1一致有
\[
 C_n^{(m)}(1-\epsilon)=1+\sum_{j=0}^8b_{n,j}
 [\epsilon A_{5,m}(\epsilon)]^{1+j/n}+o_n(\epsilon^{1+8/n}).
\]
若P7,n=Ln+Knav⁶−(n+26/9)Knav⁷，s=σ_m(ε)、a_s=2ⁿs、v_s=2s^(1/n)，还成立
\[
 \lim_{\epsilon\downarrow0}\sup_{m\ge1}
 \left|\frac{C_n^{(m)}(1-\epsilon)-P_{7,n}(s)}{a_sv_s^8}-\widehat J_n\right|=0.
\]
一致性来自同一个标量余项在ε≤s≤2ε的模量，未交换逐m极限与确界。二维目标为ε⁵，故旧四次σ截断的O(ε⁵)不能沿用，现已改为五次σ。

第41轮有限构造给出的旧Jn与第54轮二维微孔改善现已由第57轮全部输入上界匹配。旧Jn在二维的8/27来自真实分母；新增inside物理小源费用另给8/27，两笔来源不同。完整源、两审及实际计算见`rounds/057.md`。第58轮已将精确结论及必要完整证明编入67页正式PDF，并完成独立数学审、可逆排版审、实际编译与全页视觉验收。
