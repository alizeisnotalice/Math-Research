# 中心方体 Tauberian 常数的高阶渐近

研究Lebesgue测度下的中心轴平行方体极大算子，使用严格水平集。线性输入为任意有限正测度可测集；共享方体的多线性模型以公共交集归一化，单个输入可有无限测度。

## 当前严格结论

固定整数n≥2，令a=2ⁿt=vⁿ、v=2t^(1/n)，
\[
 L_n(t)=\left[1-\frac{a}{(1+v)^n}\right]^{-1},\qquad
 K_n=\binom n2\frac{n^2}{27}.
\]
已由一般输入匹配上下界及独审证明
\[
 C_n(1-t)=L_n(t)+K_nav^6-\left(n+\frac{26}{9}\right)K_nav^7+\Theta_n(av^8).
\]
第46轮已严格证明显示七阶式之后的余量具有正的双侧Theta_n(av⁸)量级；上界涵盖全部可测输入及全部半径，下界由每个充分小参数的实际有限构造实现。固定维数，不预设维数一致性。尚未证明八阶归一化余量有极限，也未识别精确八阶系数。

普通参数的全部系数统一为
\[
 C_n(1-t)=1+\sum_{j=0}^7 b_{n,j}t^{1+j/n}+O_n(t^{1+8/n}),
\]
\[
 b_{n,j}=2^{n+j}\left[
 \sum_{k=1}^{1+\lfloor j/n\rfloor}
 (-1)^{j-(k-1)n}\binom{n+j-1}{j-(k-1)n}
 +\mathbf1_{\{j=6\}}K_n-\mathbf1_{\{j=7\}}(n+26/9)K_n\right],\quad0\le j\le7.
\]
三维b_(3,5)=0；第七系数b_(n,7)在全部n≥2非零，三维为正，其余维数为负。二维b_(2,7)=−16015360/243；全维非零性包含n≥8的解析符号证明，并非有限表外推。

多线性超临界区精确约化为
\[
 C_n^{(m)}(\lambda)=C_n(1-m(1-\lambda^{1/m})).
\]
m≥2时在阈值(1−1/m)^m及以下发散。令ε=1−λ、σ_m=m[1−(1−ε)^(1/m)]，
\[
 A_m(\epsilon)=1+\frac{m-1}{2m}\epsilon
 +\frac{(m-1)(2m-1)}{6m^2}\epsilon^2
 +\frac{(m-1)(2m-1)(3m-1)}{24m^3}\epsilon^3.
\]
关于全部m≥1一致有
\[
 C_n^{(m)}(1-\epsilon)=1+\sum_{j=0}^7b_{n,j}
 [\epsilon A_m(\epsilon)]^{1+j/n}+O_n(\epsilon^{1+8/n}),
\]
并在s=σ_m(ε)、a_s=2ⁿs、v_s=2s^(1/n)及精确自然基线P7下有
\[
 C_n^{(m)}(1-\epsilon)=P_{7,n}(s)+\Theta_n(a_sv_s^8),\qquad
 \liminf_{\epsilon\downarrow0}\inf_{m\ge1}
 \frac{C_n^{(m)}(1-\epsilon)-P_{7,n}(s)}{a_sv_s^8}\ge J_n>0.
\]
正双侧常数及起效阈值均不依m；来自同一个标量余项在ε≤s≤2ε上的控制，不交换逐m极限与确界。四次σ截断误差O(ε⁵)在二维恰与目标同阶，只能并入ordinary big-O，不能推出八阶精确系数。三维ε^(8/3)系数仍为160(1−1/m)。

二维现在统一写为C₂=L₂+(4/27)av⁶−(176/243)av⁷+正Θ(av⁸)，a=4t、v=2√t；同属全部n≥2及全部m一致传递，不再单列较弱的七阶o项证明。

第41轮另得到严格的实际八阶下界。存在每个小t的真实有限输入，其全部半径严格halo比值为
\[
 L_n(t)+K_nav^6-(n+26/9)K_nav^7+J_nav^8+O_n(av^9),
 \quad
 J_n=\frac{(n-1)n^3(2609+1971n+81n^2)}{26244}
      +\frac8{27}\mathbf1_{\{n=2\}}.
\]
因此C_n相应八阶归一化余量的下极限至少J_n，二维J₂=15694/6561。此具体族系数已过两份独立完整审核，第46轮已得全输入同量级上界，第48轮已将两者及全部重数传递统一编入53页正式PDF。尚无精确系数匹配，不能认作真实八阶最优系数。

第54轮真实两尺度微孔将二维八阶下极限进一步提高到17638/6561，较J₂增加8/27；宏/微所有点的严格见证、同一总孔质量及有限化均经两份独审。精确约化也把二维自然参数的全部m一致下极限提高到该值。它仍是一侧下界，极限及最优系数未定；当前53页PDF保留第41轮有效但较弱的下界，新构造详见`rounds/054.md`与对应证明。
