# 第3轮：部分 halo 的尺度界与周期微扰排除

整理核验日期：2026-11-04。固定 n≥2，H=2^n，u=t^(1/n)。本轮底稿和第一批有理核验形成于2026-10-29，本次完成最终转写审查、Mathematica独立符号核验与交付。

## 数学结果

1. 对任意有限正测度输入 E，若外部点集 F 的每个点都由同一半径见证，则 z=|F|/|E| 满足
   \[
   \frac z{1+H^2t/(1-Ht)}+
   \frac{n}{2(n+1)}(1-Ht)^{1+1/n}z^{1+1/n}\le Ht.
   \]
   因而 z≤Ht−[n2^n/(n+1)]t^(1+1/n)+O_n(t^(1+2/n)+t²)。不要求周期或全孔填满。
2. 见证半径可跨任意多个尺度；若在 F 上存在 Lipschitz 常数 L=o(u) 的合法半径选择，则 z≤Ht−[n/(2(n+1))]tu+o(tu)。完整有限参数不等式、Gram 距离亏损和自适应 dyadic 计费见正文。
3. 单位周期立方孔附近，每胞任意 O(tu) 体积的可测增删微扰，即使允许全部半径、跨孔和部分捕获，也不能提高原构造的二阶系数 −n2^(n+1)。上界与基线构造在该局部族内匹配。
4. 任意小 t、任意 n≥2 下，直接以平均半径替代固定三角核自能的公式仍失败。给出连续指标集、全部参数解析公式及精确系数证书；该例首项效率低，不能据它判断真实二阶系数。

这些结论未确定一般 C_n 的高阶极限：本轮一般问题仍保持原上下包络。尺度类上界不得外推为无条件上界。

## 实际计算与复现

本轮以 Mathematica/Wolfram Language 为主要符号工具，Python 精确分数用于独立有限核对。

Wolfram 15.0.0 ARM 实际运行：

```sh
wolframscript -file verification/wolfram/gram.wl
wolframscript -file verification/wolfram/energy.wl
wolframscript -file verification/wolfram/endpoint.wl
```

- Gram 交叠的4项实参数全域蕴含均为 True，相应违反集 Reduce 返回 False；假设直接写入脚本。
- 对全部 0<ε<1，八区间分段积分精确得 E_1=19ε²/32、E_(1/4)=ε²/4−ε³/48。另以 Integrate 交叉核对两个代表区间对；不是声称对全部区间对重新独立积分。
- n=2,…,8 的根方程系数与一般证明相符，包括 L=γt^(1/n) 的修正。形式代入本身不证明根的存在、唯一性和渐近余项，这些由正文论证给出。
- 初始三个主进程并发时 Gram 进程异常退出139；随后单独重跑成功、无消息。失败运行没有计作计算结果。保存的是成功脚本和关键输出。

Python 标准库精确核验已实际通过：

- Gram：10000组有理点对、160组边界参数。
- 反例：2304个仿射正部表达式逐项核对根不在(0,1)，得到全ε区间的有理多项式系数证书。
- 周期微扰：2160个小半径、5759个中间半径、2880个大半径质量样例。
