## 2. 无界度完整图的粗加权增长通过

对 `U⊃I`，新加入的 `j∈N(U)\U` 必为外部规则指标。把它分给任一邻接 `i∈U` 后，单向半径界给 `r_j≤3r_i`，中心距至多为 `4r_i`，故 `B_j⊂Q(x_i,11r_i/2)`。

同根所分配的半盒内部不交，所以其总权不超过 `11^nr_i^n`。求和加回旧权得到 `S(N(U))≤(1+11^n)S(U)`。该步骤对任意 `U⊃I` 使用同一组局部条件，不要求完整图有界度，也不要求异常–异常边尺度可比，因而可以合法迭代。

取 `ell(v)=floor(log(1/v)/(2log C_circle))`，则

\[
S(Z_v)\le C_\circ^{\ell(v)+2}S(I)=O_{n,B}(v^{9/2}S).
\]

`Z_v` 包含 `I` 及原边界。对 `G_v` 中的根，任何固定图层及其下一层最终全是规则、外部深处指标。

这里确实区分了两个尺度：粗加权指数界可用于随 `v` 增长的 `ell(v)`；后面的几何紧性始终只对固定图层作抽取，没有把 R14 的固定层多项式界延伸到对数层。

## 3. 固定图球紧性和闭覆盖通过

归一化任意良好根为中心零、半径一。固定图层 `k` 后，路径上全规则，半径在 `[Λ^{-k},Λ^k]`，中心位于固定有界区域。半盒不交和半径下界给节点数的一致有限上界。因此可先稳定有限 rooted 组合类型，再抽取中心、半径；对整数 `k` 对角抽取可以保持各有限球嵌套。

每个固定极限顶点的半径严格为正，极限保留 `dist_centers≥max(r_i,r_j)`，故极限半盒内部不交。

对固定顶点 `i`，任何原半盒碰 `A_i^0` 都在下一层完整图球内，因为其 `Q` 邻接有严格余量；其半径在 `(r_i/2,3r_i/2)`，数量一致有界。故不能有某些给 `A_i^0` 提供质量的盒在取极限时逃出清单。`e_i^0→0` 再与有限闭盒的坐标收敛结合，给全部内点覆盖；取闭包得到 (12)，包括原来仅旁切的边界盒。

这一步没有仅证明“覆盖几乎处处”，而是得到有限闭盒对闭 `A_i^0` 的完全覆盖。

## 4. 相同半径、组件扩窗与全部尺度清单通过

把有限覆盖盒截到连通的 `A_i^0` 后，相交图连通。任意相交极限半盒满足

\[
\max(r_j,r_p)\le\|x_j-x_p\|_\infty
\le(r_j+r_p)/2,
\]

因此两半径相等。覆盖中包含 `B_i`，遂使全部覆盖盒与 `i` 同半径；即使某覆盖盒只在边界接触，也由这一闭覆盖相交图被连接。

根单位半盒由此生成单位组件。每个组件半盒的四分之一增厚都由下一固定图层的单位半盒覆盖。Minkowski 增厚与并集交换，归纳得

\[
Q(0,1/2+m/4)\subset U_m.
\]

该论证不需要面面对齐或唯一面邻居，允许 T 接缝。

### 漏网微盒与大盒的排除是充分的

固定 `R≥1` 后取 `m=ceil(8R+8)`。组件覆盖 `Q(0,2R+1)`，且有固定正裕量。若额外原半盒碰 `Q(0,R)`，其中心距 `c`、半径 `r` 满足 `c>max(1,r)`、`c≤R+r/2`，从而 `r<2R`、`c<2R`。

允许该额外半径趋零，仍可取其中心极限 `x_*`。组件覆盖保证某个固定单位半盒中心 `y` 满足 `||x_*-y||≤1/2`。但它与漏网指标始终不同，原强分离取极限要求 `||x_*-y||≥1`，矛盾。这里矛盾发生在中心层面，所以不仅排除正体积额外盒，也排除任意微盒、图距离逃向无穷的盒以及窗口外中心伸入的大盒。

作为依赖来源，最初的 `r<2R,c<2R` 使用预极限严格分离；最后比较使用弱极限下界。固定扩窗裕量使边界等号不造成遗漏。

## 6. 异常关联角交量的 Hölder 估计通过

同一第五层中，非边界 pair 的 owner 依 R14 取 `R_i≥R_j` 的源端。即便 owner 不在坏集 `Z` 内，实际相交的有界次数和半径可比也给

\[
W_q=\sum_{e\leftrightarrow Z}r_{i(e)}^n\le C_nS(Z).
\]

按坏端点收取有限个 pair 即可，不需要 owner 本身属于坏集。owner 盈余总量仍由全体 `Σε_i r_i^n=O(v^5S)` 控制；选定真正面邻居的 `Γ` 重复次数也有限，属于原 `F` 预算。

R14 的粗角界 (15) 因而给线性交损 `O(v^7S+v^8S)`。对 `ζ_q=q/(2q-1)∈(0,1)`，加权 Hölder 得

\[
v^{q+\zeta_q}\sum_e\varepsilon_{i(e)}^{\zeta_q}r_{i(e)}^n
\le C v^{q+6\zeta_q}\mu^{1-\zeta_q}S.
\]

`q+6ζ_q≥6`、`1-ζ_q≥1/3`，且 `0≤μ≤1`，所以该式至多 `Cv^6μ^{1/3}S`。空 owner 集合对应零和，无需在 Hölder 端点人为定义商。边界 pair 独立使用单源界，给 `O(v^7S+v^9S)`，不把深处面容量错用于边界。

取 `S(Z_v)/S=O(v^{9/2})` 后得到 (3) 的 `O(v^7S)`。若 `q≥3`，最小额外幂为 `3/5`，所以全部高余维交损为 `O(v^{33/5}S)`，连同边界仍为 `o(v^6S)`。

Markov 坏胞推论使用的两种均值尺度也准确：`ε/v^5` 和 `(g-μ)/(av^5r^n)` 的坏权为 `O(S/T)`；物理宽误差的坏权为 `O(vS/δ²)`。这些只给关联角交量的可积性，不把 scaled 变量升级为逐胞一致有界。
