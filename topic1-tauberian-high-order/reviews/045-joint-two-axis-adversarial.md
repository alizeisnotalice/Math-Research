## 1. 全域非正常强制性确实独立于 T,m

记 D 为两个截断共同根移的三次成本之平均，G=b/27−bxy+D。沿共同平移方向，正部多项式为凸函数，故 D≥xy(x+y)≥2(xy)^(3/2)。同时

    G ≥ b/27 − max xy(b−x−y) = b(1−b²)/27.

若 G/(b+D) 沿正常窗外趋零，b=0 时比值为 1。D/b→∞ 时 bxy/D≤C(b/D)^(1/3)b^(2/3)→0，仍不可能趋零。若 D/b 有界而 b→0，xy→0，且 G/(b+D) 至少趋近一个固定正下界。余下 b 有正下界、D 有上界，G→0 迫使 b→1、xy 有正下界；于是 x+y≤D/(xy) 有界，截断约束又使根移有界。极限取等唯一为 (b,x,y,ζ)=(1,1/3,1/3,0)，与固定正常窗外矛盾。退化 b=D=0 直接满足所需不等式。

这证明 c_ν 可先于 T,m 固定。它同时控制 b 和完整 D，不能只控制 bD。R45 正确保留了这两种份额。

实际成本与该标量的转换也有足够强度。除正常根差外，相交根只知 1+O(v)，产生的是 Cv 倍完整成本，可以由严格非正常亏损的一部分吸收，不必冒充 O(v^8) 绝对误差。原宽和核心的固定上下界使 B_bad 与 v^6 Σ D R_e^n 有双侧比较，其常数与 T,m 无关；核心剩余一半所需的小 v 阈值可以依赖 T。宽度平均误差为 O_T(v^(17/2)S)，核心相对裁剪 O_T(v²) 给 O_T(v^8S)。截断横权 (bhat−1)_+ 的总权 O(v^(7/2)S)，在固定 T 上亦晚于八阶。

因此可把 G 的固定份额分别给出角权折扣 2γ_ν A_6 W_bad 与完整成本 c′_ν B_bad。先选这两个小常数，再选择 T，是合法顺序。不存在先用全部 G 取得折扣、后又把同一 G 全额留给长角的重复支出。

根差截断不会使所用目标帽失真：若真实根差超出最大交长，大根源使用较小的截断帽，仍是原见证保证捕获的子帽；反向两正部宽度都为零。固定有界窗下这些帽宽为 O_T(v^3R)，小于真实原宽 c vR。它们的体积减去帽内完整原缺量正是该帽内实际 F_j 的质量，故每个 A_ij≥0。

## 2. 一个共同正部与完整 J 的一次分配

同源、同轴对、同符号和同排序内，正常与有界非正常目标的实际 F_j 质量先相加。不同目标源相互排他，并与自身完整 G_i 排他；原轴向面邻居还与这些二临界目标不同。同一个原指定见证因此同时支持该总和及浅轴帽容量约束。

所有高度使用同一个 E_i(T) 和同一个源核心。若 A_N、A_bad 表示该位置的非负实际名义高度，则

    (A_N−E)_+ ≤ (A_N+A_bad−E)_+,
    0 ≤ (A_N+A_bad−E)_+ − (A_N−E)_+ ≤ A_bad.

A_bad 不超过完整目标原横截面的名义高度。两个排序按大小关系分区；不同轴对通过共同核心剪裁分离；不同符号在源宽 c vR 内也分离。因此积分后得到真实集合嵌套 Y_N⊂Y_all，且

    raw_N = raw_all + (v/a)|Y_all\Y_N|
          ≤ raw_all + (1+v)^(-(n−1)) B_bad
          ≤ raw_all + B_bad.

这个系数确为一，不含 T 相关常数。相同核心和相同 E 对此是必要的，R45 已明确保留。不是在正常层和非正常层分别取正部后相加，也没有假设同角两种层物理不交。

对唯一的 Y_all 应用强 CDF，完整 ΣJ_i 仅出现一次。鲜导数乘法损失至多 O_T(v^6 Σ ε_iR_i^n)=O_T(v^11S)；原高度侵蚀积分为 O_T(v² ΣE_iR_i^n)=O_T(v^8S)。故联合名义成本减两类退款，再加 raw_all 和端移固定正比例，是实际 CDF 的单次合法分配。

## 3. 联合退款不会倒用定性轮廓

正常退款沿 R42 定量缺集比较重放，以实际 raw_N 作为全部未解释缺集。换用共同较大核心和 E_i(T) 只增加允许的绝对 O_T(v^8S)；正常帽核仍由固定正常窗的 Cv²/a 控制。因此乘 raw_all、B_bad 和端移的 Cv 系数无需依赖后选 T。正常偏差项由完整 G_N 的二次控制及 Young 不等式付到 Cv^8S。

非正常有界退款的核为 C_Tv²/a。把目标缺集分成真实 Y_N 和其余，后者由 raw_N 支付，成本为 C_Tv raw_N。每胞 Y_N 体积≤Ca v^5R_j^n，正常集合每角唯一且角数固定。每条有界非正常边的完整 B_bad 成本至少 c_m v^6R_e^n，因为 p,q≥m，D≥xy(x+y)，且实际源核心和目标原宽有固定正下界。故落在 Y_N 的退款≤C_(T,m)v B_bad。有限邻接度控制所有目标次数。代入上节的 raw_N 比较即是 (19)。常数依赖 T,m 只出现在最终乘 v 的项中，允许最后吸收。

本次未找到先假定缺集已是标准两臂、再用该假定证明退款的循环。

## 4. 零短边与外边界

有界小角不申请任何 J。未饱和软权分支用 C_soft≥16T/k；已饱和分支用 min(p,q)<m≤k/(16T)。两支均得 pq≤(k/16)ω，故实际 gross 交量本身具有固定领先折扣，短边可任意趋零。

边界处所需的反向缺量界不能从 R45 (1) 的 |D_i|≤C ε_i aR_i^n 倒推。本次已查实其正确来源：global.tex 第 175 行给 μ_i≥(1−Av)ar_i^n，而 R_i≤r_i；第 254 行定义 ε_i=|W_i|/μ_i−1。因 F_i⊂x_i+W_i^0、W_i⊂W_i^0，直接有

    ε_i μ_i = |W_i|−μ_i ≤ |D_i|,
    ε_i aR_i^n ≤ (1−Av)^(-1)|D_i|.

seventh.tex 第 713 行也已显式使用前式。这是实际源输入的推论，不是新增假设。R45 宜明确这一来源以免读者误认倒推；在其保留原实际源族的声明下不构成数学缺口。

将邻边界缺集分为 Y_N 与余量后，Y_N 部分用邻边界根权 O(v^5S) 给至少 O(v^12S)，原单源的纯项为 O(v^9S)，其余为 Cv(raw_all+B_bad)。因此 (23) 的 O(v^9S) 上包足够，不需边界定性正常轮廓。非 G_v 端点同样保留全部源与退款，其 gross 未被按坏根权丢弃。

## 5. 长帽估计对 Q→0 一致，两管无循环

每个真实正常层在其两个轴的坐标支撑长度都为 O_N(v^3R_j)，不论 E_i(T) 的侵蚀或有效端点平移如何。一个长帽的两轴长度为固定正比例 P r_i、Q r_i，其余轴取原完整宽度。

若某正常层的轴对含长轴，沿长轴的交比例≤C v^3/P；若不含长轴，该层至多一个轴是短帽轴，故另一个轴在帽中取全宽≥cvR，比例≤Cv²。逐个正常角求和仍只有维数常数。这个论证完全不除以 Q，因此 (24) 对极细短边一致。二维第二种情形为空。

于是先固定大 T 可使正常层最多占所保证目标帽的四分之一。真正目标余量例外只检查 D_j\Y_j,N，其全部交量以 Cv raw_N 支付；正常两臂没有被当作第二笔可用缺量。面对／端移例外由 PQ/H=max(P,v²)≤Cv 给 Cv(自由面+端移)，前者明确留到同一次真实自由面条恢复支付。

其余长角的源矩形采用长轴深度 c_2P、短轴深度 c_3H，H=min(Q,PQ/v²)。同一原见证保证目标真实帽质量≥c a r_i^nPQ/v²，而浅短轴面容量最多为 C a r_i^n(c_3+c_exception)H；选择固定小系数即矛盾。故整矩形是有效缺集的真实子集。

其成本逐边满足

    (v/a)|rectangle_e| ≥ c r_i^n PH/v
       = c r_i^n PQ min(1/v,P/v³) ≥ c T I_e.

截宽比例、源核心剩余比例、源点容量和度上界都只依赖原几何与正常小窗。最后取 v 小可同时令 1/v≥T。因此 c 与 T、Q、m 无关。取 T>4K_N/c_2 后，矩形只有短轴可能靠近一面，确实避开正常小管和 Y_N。其全部重数由相交度一次控制，所以长角费用≤(C_L/T)raw_N≤(C_L/T)(raw_all+B_bad)。

长角矩形无需避开覆盖 Y_all 的最后大管。矩形与有界非正常层重合的份额已经由 B_bad 预留成本支付；同一份 J 没有重新全额出现。参数顺序可以先取固定 c_ν、K_N、原矩形常数，再取 T 使 C_L/T 小于两份预留系数，随后选 m、C_soft、共同核心和 K_all，最后 v 小。R44 后续另取依赖 K_all 的高支撑长窗阈值，不反向修改本处 T。

## 6. 同一正常集合、槽缺口及二维桥

R45 的 N 以 x,y 接近 1/3、实际归一化横权及未截根差定义。取 ν 小于 R42 紧窗常数的固定比例后，满足该 packet 所需的合并偏差界；其实际交长和非临界中心差也满足 R43 几何。无需换第二个 v 无关中心定义正常集合。正常边软权为一。

全二轴 soft 分配与正常分配使用同一 clean 规则。不同微阈值的跨锚单射已在 R36 的实际面积论证中解决。对正常占用先按槽取并，根权传输和漏片给

    W_N+W_O ≤ C_actual+O(v³S),
    W_N = C_actual−D_N+O(v³S).

于是价格和为

    (A_6+Γv^7)W_N +(1−γ)A_6W_O
    ≤(A_6+Γv^7)C_actual −(γ A_6+Γv^7)D_N +O(v^9S).

这同时留下 c_Dv^6D_N 和 c_RZ_all。缺槽系数来自领先角权折扣；完整非正常成本另有份额用于退款和长角。两者的来源已在强制性步骤区分，无重复支出。

二维确需桥接，不能仅以 R42 的 n≥3 声明越界引用。本次逐项检查空横积版本：正常层／共同帽／同见证容量／根差凸性／两臂退款均仍有相同公式；共享其他轴对的退款项消失；源核心无横向变量；长帽第二分支为空。实际槽使用 R027 已证的真实二维四胞分配：全部好边有唯一四胞，原稳健面对次序使每角至多使用一次，根权差沿至多两条面对路径收费 O(v^6S)，坏端点角权 O(v^(9/2)S)。加软权≤1 后总容量界保持，正常权为一时占用恒等式也保持。这些误差均小于所需 O(v^3S)。因此 R45 的局部结论覆盖固定 n=2。

## 7. 与 R43/R44 的联合供货及尚未审的总装

R45 留下的是最后实际大管的 Z_all；它满足 Z_all≤raw_all。R44 对任意固定管宽 K 成立，故可取该同一个 K_all。R43 的坏根由同一个 N 的真实槽占用定义，故其 D_N 与 R45 完全相同。先固定 η<min(c_R,c_D)/4，再令 v 小，R43/R44 的高支撑交量由 ηZ_all+ηv^6D_N+Cv^8S 支付，仍留固定正余额。好根高支撑 gross O(v^8S) 只用粗先验，未另减 J。

自由面成本只有 Cv F。新 (32′) 对任意预先固定 χ>0 成立，因为 c_R,c_D 可先保持，最后令 Cv≤χ。总装若还需要 C′vF，应与本处一起由同一次 c_0F 恢复收入支付，不能复制收入。R45 已明确此点。
