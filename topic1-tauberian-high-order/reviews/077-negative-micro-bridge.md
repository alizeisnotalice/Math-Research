## 3. 完整负算子与旧安全条件

原指定 \(r=\rho+s\)、\(\rho=1-2w\) 给 \(r+w=1-\|x\|_\infty\)。负矩阵的所有可见整数目标通过
\[
\|Tk\|_\infty\ge[1-(n-1)e]\|k\|_\infty
\]
先缩减到小整数，再逐符号分类为 \(k=\pm1_A,|A|\ge2\)。混合正负需要同时 \(\sum k_i>1\) 和 \(<-1\)，支撑一仅为零体积接触。该清单不随 \(w\) 改变；不是用旧正号 balanced-even 清单代替负号。

非临界目标坐标满足 \(2w+ne<\rho\)，所以对全部源点精确进入原见证整宽。坏点先由总名义量得到 \(s\le C_ne^2/f\)，然后才在浅带使用最近面符号筛选。完整输出保留所有奇支撑、全部最浅轴图及真实顶端 clip。

固定目标物理点的可见源底面计数，给支撑 \(j\) 的核 \(C_n\delta(e/w)^{j-2}\)，pair 外最浅轴再多 \(e/w\)。有限全清单合计是 \(C_n\delta=O(u)\)，对任意可测删除集同时成立。微孔数量、形状或在帽内是否均匀都不进入这个常数。

从空集开始，反单调性给 \(U_1\subset U_4\subset U_0\) 和 \(\mathcal B(K)\subset K\)。特别
\[
|U_0\setminus U_4|\le|U_0\setminus U_1|
\le L_u|U_0|=O(u)|U_0|.
\]
名义二轴每个无序轴对两个相反角共 \(2V_0\)，其余项更晚，故源 (6) 的负号领先体积直接成立。这不是逐点借用正号坏集。

只有旧 \(K(w)\) 假设 \(D_\Lambda>|K(w)|\)。新 \(K^\mu\) 本身不需要先满足纯宏观安全；稍后证明的是新的组合预算 \(D_{\Lambda^\mu}+|H|-|V|>0\)。正文没有暗加这个更强假设。

## 4. 跨孔宽稳定：内禀度量、域差与 Jacobian

这是本轮关键新增接口。源 §3 的
\(x_l=\sigma_l(w-d_l)\)、\(d\in[0,w]^n\)
在各最近面符号图 Jacobian 的绝对值为一。除原坐标中分面零测集外，每点唯一表示；在同一有限符号直和中域外补零后，两个指标的 \(L^1\) 距离确实支配**体积差**。

它不支配同阶的原物理坐标对称差。活动角整体平移 \(\Delta w\) 时，相关面积约 \(e w^{n-2}\)，可产生 \(e w^{n-2}|\Delta w|=O(a u^7|\Delta\Lambda|)\) 的物理对称差。源明确否认了把它压到 \(a u^{10}|\Delta\Lambda|\) 的错误陈述；后文也没有运输旧 host。

对共同内禀源坐标，\(s=\min d_l\)、\(y_l=d_l-s\) 不随 \(w\) 变。临界实际穿透
\(((j-1)e-y_l)_+\)
中的两端孔宽变化与 \(\rho=1-2w\) 精确抵消；目标临界前缀离中分面保持固定比例裕量。非临界目标积分覆盖全部原宽，其 \(\mp je\) 位移仍精确退出。

因此源 (8) 的输入项确可由同一个可见底面核作用于 \(I_wV-I_{w'}V'\)，得到 \(C_n\delta_{\max}\)；这里没有假设两个物理测试集边界相近或规则。

参数项分别核如下：

* 目标自由积分端改变的差条由完整名义 cap 上包，占比 \(C|\Delta w|/w_{\min}\)。\(b^{-1}\) 的变化同样相对可控；即使输入删除集不规则，删量也不超过完整帽，归一化误差仍可用该上包。
* 在共同浅带，\(F_w(s)/s\) 正且 \(|\partial_w\log(F_w(s)/s)|\le C/w\)。\(s=0\) 用连续延拓；\(F'_w\ge f\) 使逆容量的参数误差不超过名义高度乘相同相对变化。
* 源新旧域的差轴靠近 \(d_l=w\)，而坏点的最浅深度仅 \(O(h)\)。该轴既非最浅轴，也不可能属于任何活动支撑，因为临界 \(d_l\le(n-1)e+Ch\ll w\)。其余目标帽对这个源自由坐标严格独立，Fubini 因而按自由长度比例 \(|\Delta w|/w\) 收费。真实 clip 的变化用同一自由轴条处理。

最后一条尤其不能换成整个源盒底面积乘 \(|\Delta w|\)。本稿按完整名义**坏层**体积 \(O(a u^5)\) 收费，恰得到 (8) 的第二项。所有支持 \(j\) 和所有最浅轴只增加维数常数。

从共同空集固定迭代四次，\(C_n\delta_{\max}<1/2\) 保持此内禀界。代入 \(\Delta w=u^6\Delta\Lambda\)、\(w_{\min}\asymp u\)，得
\[
\bigl||K(w')|-|K(w)|\bigr|
\le C_n a u^{10}|\Delta\Lambda|.
\]
这是实际新旧体积比较；所需几何和误差均已在新层重新供应，没有隐藏旧孔定位假设。

## 5. 新 host、完整一步保护与短严格见证

所有微孔在新 \(K^\mu=U_4(w^\mu)\) 内重做。有限 cap 交量对端点连续，对任意可测输入仍成立；各实际坏层是连续高度图的下层并保留有限分片边界。故 \(K^\mu\) 闭、边界为零测高度图及分片面，\(|\operatorname{int}K^\mu|=|K^\mu|\)。没有使用其包含整 \(\partial C_w\) 的 canonical 代表的字面周长小量。

微格用不交基本胞计量。以立方体的 \(\ell^\infty\) 距离理解文中 \(3\ell/2\) 的内部条件，距补集足够远的点被有效胞覆盖；换任意等价范数只改固定常数。因此 \(L_\ell\to|K|\)，首个满足规定精度的 dyadic 间距有限存在。每个固定 \(u\) 选出的孔数有限，估计不要求关于 \(u\) 的网格复杂度界。

精确微孔质量是
\(a'(1+v')^{-n}L_\ell\)，所以 \(|H|=a|K|[1+O(u)]\)。host 可以重叠而基本胞不重叠，未按重叠 host 重复计量。

短半径满足 \(r_\mu\ge\ell-2\omega\ge2\omega\)，包含自身全孔；任何其他格孔至少一个坐标距为 \(r_\mu\) 以上，只有可能的零体积接触。见证全在自己的 host 内，缺陷率至多 \(t'=t(1-u)<t\)，包括微孔边界点均严格。

固定新参数后，
\[
V=K\cup\mathcal B_w(K\setminus H)
\]
包含整个 \(K\) 及全部 host。反单调性给 \(\mathcal B_w(V\setminus H)\subset V\)。又 \(\mathcal B_w(K)\subset K\)，故新增物理体积不超过 \(L_u|H|\)。这是**同一个新参数下**的物理输入 \(L^1\) 界；与上一节跨参数的内禀界清楚区分。

未来宏孔避开整个 \(V\)，所以短见证 host 无宏孔污染。不同宏胞的外包孔有固定间隔，短见证留在自身 host，更不可能碰其他宏胞孔。全部奇支撑都在保护用的完整负算子里，不是分别保护若干指定角。

## 6. 设计预算与选参次序

预先扩大 \(\Lambda\) 区间，统一几何、体积稳定和 host 密度常数；随后选安全 \(C\)，最终令 \(Cu\le\min(1,L_*/2)\)。因此
\(|\Delta\Lambda|\le a(L^*+1)\)
的常数与待选 \(C\) 无关，新参数留在同一预选盒中，且 \(\Lambda^\mu<\Lambda\)。没有常数反依赖安全参数的循环。

各项实际量级是：

| 项目 | 量级／用途 |
|---|---|
| 新微孔量 \(|H|\) | \(na^2L_0u^5g^{n-2}+O(a^2u^6)\) |
| \(\Delta D\) 的主损失 | \(-na^2L_0u^5g^{n-2}\)，与 \(H\) 抵消 |
| 安全项在 \(D\) 中的收入 | \(+nCa^2u^6g^{n-2}\) |
| 保护费与密度误差 | \(O(a^2u^6)\) |
| 新旧 \(K\) 体积差 | \(O(a^2u^{10})\) |
| 新实际质量主增量 | \(2na^2g^{n-1}L_0u^6\) |
| 安全项对实际质量的损失 | \(O_C(a^2u^7)\)，晚一阶 |

源 (13) 使用精确可删体积的导数，误差乘 \(|\Delta\Lambda|=O(a)\) 后确为 \(O(a^2u^{10})\)。源 (14) 同样只比较体积，不比较或搬动集合。合并新 \(H\)、保护费和新 \(K\) 后，(15) 保留原旧正余量，再增加一个固定正的 \(a^2u^6\) 份额。故即使旧余量没有统一下界，本步仍安全。

新 \(K^\mu\) 不必单独给足纯宏孔空间。真正由 (15) 得到
\(|C_{w^\mu}\setminus V|>M^\mu-|H|>0\)。同样的 cap 连续性使 \(V\) 闭；开补集中可先取内部紧集，再连续分位取精确质量。宏孔 \(A\) 与 \(H\) 不交，总实际孔质量恰为 \(M^\mu\)。

长见证捕获完整本胞 \(A\cup H\)，所以自身质量根仍是 \(M^\mu=a(\rho^\mu)^n\)，不是 \(|A|\)，更不是旧 \(M\)。外国实际孔被 \(C\setminus(V\setminus H)\) 上包，源 (16) 因而给全部宏孔点的严格原阈值。长短见证在最终同一个输入中同时成立。

## 7. 相对质量收益、一般维数有限化和三维兼容

改变 \(\Lambda\) 时 \(e,T_-,d_-\) 固定。直接对 \(M=a\rho^n\) 求差，源 (17) 的主项和 \(O_{n,C}(a^2u^7)\) 余项正确。精确分母导数 \(d/(d-m)^2=1+O(a+u^6)\) 不改变主阶。归一化
\[
\frac{2na^2g^{n-1}L_0u^6}{av^{n+6}}
\longrightarrow\frac{nL_0(0)}{32}
=\frac{\binom n2\kappa_0^3}{256n}
\]
正确；最优八阶尺度 \(\kappa_0=8n/3\) 时为 \(2K_n\)。保护并非免费，而由实际质量中晚一阶的安全项支付。

一般维数统一取 \(N=\lceil u^{-(n+12)}\rceil\)。周期积分给精确输入质量；所有长短半径都小于一，只有固定格层边界宏胞可能丢失见证。费用按每个宏胞的**总**孔质量 \(O(a)\) 求和，为 \(O(a/N)=O_n(a^2u^{12})\)，没有微孔个数因子。它严格晚于 \(av^{n+6}\)；仅用 \(N=u^{-12}\) 的大维数问题已经避免。

凸外盒外任一中心、任意正半径的中心方体在分离半空间内占比至多一半，故无外部 halo。输入密度点几乎处处进入 halo，内层全部宏微孔点有各自严格见证。因此 (19) 是完整极大算子的双侧实际比值公式，适用于每个充分小实 \(u\)。

三维组合先选 R072 的明确正余量参数，正 \(U_4\subset U_2\)；同层正负比较保证旧负 \(U_4\) 安全。再从这个确切旧负族执行本微孔步骤，构造新 \(M^\mu\) 的一个实际输入。

源 (20) 的精确相减把第一项固定在旧 \(M\)，第二项固定在负 \(d_-\)。两项没有偷换质量或参考族。三维 \(d_+-d_-=4e^3\)、\(\kappa\to8\) 给第一项 4，实际保护后的质量增量给第二项 2，共同有限误差更晚，故确为 \((6+o(1))av^9\)。

一般 \(n\ge4\) 正确地只单独声明相对旧负纯宏的微孔收益；若同时对正族比较，保留精确 triangle 分式。冻结稿没有将较早阶未知余项误当作更晚微孔阶的小量。
