# R7 真实尾桥反例的独立审查

审查对象：`r007-global/real_tail_counterexample.md`。主文件中 (w_b=v2^{-b}) 的版本与可能的固定 (\theta) 加强版分别判定。

**结论：主版本 proof-valid。** 对任意满足误差 (o(av^2)) 的紧内逼近，以及任意有限严格 Besicovitch 见证覆盖，固定阈值尾 (S_b/S=o(v)) 确实失败。所有合法半径、保护层、任意代表取点及全 (J) 一致性均已核查，没有发现实质缺口。

**固定 (\varepsilon>0) 的加强版也可严格闭合，见第 9 节。** 它需要把稀释权改成固定 (\theta v2^{-b})，其中 (\theta>0) 依赖 (\varepsilon,n)，并单列陈述。它不提供相对下包络或真实最优值的 (o(av^2)) 极大化序列反例。

## 1. 有限周期组件及全部实际半径

令 (N=\lceil v^{-4}\rceil)、(J=\lfloor\log_2(1/v)\rfloor)。因为 (Jv\to0)，所有 (b\le J) 都有

\[
 g_b=\frac{v}{2(1+v)}(1-bv-v^3)>0,
 \qquad \frac{h_b}{a}=\frac{(1-bv-v^3)^n}{(1+v)^n}\longrightarrow1
\]

一致成立，且最终 (g_b<1/4)、(2g_b<R_b=2g_b/v)。外盒的各边长度恰为整数 (N+2)，其边界位于半整数处；因此它包含 ((N+2)^n) 个完整周期单元和同样多的完整孔，没有半截孔。于是

\[
 |E_b^0|=(N+2)^n(1-h_b)
\]

是精确值。保护层按同一晶格挖孔十分必要：它使有限输入包含于全空间周期输入，因而周期孔的缺陷下界可用于所有大半径实际见证。

对本孔内中心，若 (r\le2g_b)，每个坐标与本孔的相交长至少为 (r)，故缺陷比例至少 (2^{-n}>t)。若 (r>2g_b)，其方体包含整本孔，严格见证条件强迫

\[
 h_b<ar^n,qquad r>R_b.
\]

还必须排除 (r\ge1)。一维中写 (r=k+s)，(k\ge1,0\le s<1)。周期交长精确为 (4kg_b+\ell(s))：整长度 (2k) 贡献 (2k) 个周期，余下的两段由周期性合并为以同中心、半径 (s) 的交长。当 (s\le2g_b)，(ell(s)\ge s)，所以

\[
 \frac{4kg_b+s}{2k+2s}\ge2g_b.
\]

当 (s\ge2g_b)，本孔完整包含，(ell(s)\ge2g_b)，所以

\[
 \frac{4kg_b+2g_b}{2k+2s}\ge\frac{(2k+1)g_b}{k+1}\ge3g_b/2.
\]

晶格孔集合是各坐标一维孔集合的笛卡尔积，因此立方体中的周期缺陷比例至少 ((3g_b/2)^n)。它与 (t=(v/2)^n) 的比趋于 ((3/2)^n>1)，对所有 (b\le J) 一致。因此全部实际组件见证满足

\[
 R_b<r<1,qquad\text{且包含整个本孔。}
 \tag{R1}
\]

内部孔每一点所用的指定半径 (1-2g_b) 则确实严格可行：邻孔至多边界接触，方体在外盒内，并且

\[
 1-2g_b-R_b=bv+v^3>0.
\]

特别地，(b=0) 的严格性由 (v^3) 项提供，不能在保留闭孔全体点时无声删去。

## 2. 全局归一化、远隔和盒外水平集

权重 (w_b=v2^{-b})、(w_0=1-\sum_{b=1}^Jw_b) 正且和为一。按

\[
 \lambda_b^n=\frac{w_b}{(N+2)^n(1-h_b)}
\]

缩放后，各组件测度精确为 (w_b)，因此 (|E_v|=1)。有限个组件可以移到两两外盒距离大于 10 的位置；每个 (v) 的输入分别有界。构造不声称所有 (v) 共用一个固定紧支集。

任意全局严格见证都有

\[
 (1-t)(2r)^n<|E_v\cap Q(x,r)|\le1,
 \qquad r<[2^n(1-t)]^{-1/n}<1
\]

对充分小 (v) 成立。它不可能碰到两个远隔外盒。若中心在唯一所碰外盒之外，则至少一个坐标上与该盒相交的长度不超过 (r)，整个平均值至多 (1/2<1-t)。所以外部水平集只能在盒内孔中。

对盒内中心，其全局见证与单组件输入上的见证完全相同。缩放回组件单位后可用 (R1)，无论物理半径与 (lambda_b) 相比有多大。这里不能仅凭全局 (r<1) 推出组件单位 (r<1)；真正提供后者的是第 1 节的周期缺陷下界。原稿没有混淆这两步。

## 3. 有限截断精度及主近饱和下界

内部闭孔全部属于真实外部水平集，因此

\[
 |F_v|\ge M_{\rm int}
 =\left(\frac{N}{N+2}\right)^n
 \sum_{b=0}^Jw_b\frac{h_b}{1-h_b}.
\]

Bernoulli 不等式及 (sum_bw_bb\le2v) 给

\[
 M_{\rm int}\ge a-nav-C_nav^2.
\]

所有保护层孔的总质量不超过

\[
 \left[1-\left(\frac N{N+2}\right)^n\right]
 \sum_bw_b\frac{h_b}{1-h_b}=O_n(a/N)=o(av^2),
\]

其中使用 (h_b\le a)、(sum_bw_b=1)，常数与 (J) 无关。所以全部内部闭孔的有限并本身就是合格紧 (K_v)，并非只存在抽象测度内逼近。

还可得有用的精确方向：令

\[
 h_*:=a(1+v)^{-n},\qquad f_*:=\frac{h_*}{1-h_*}=L_n(t)-1.
\]

因为 (F_v) 全部在组件孔内，且 (h_b\le h_*)，

\[
 |F_v|\le\sum_bw_b\frac{h_b}{1-h_b}\le f_*.
\]

因此该构造相对 (L_n-1) 的差也确实非负且为 (O_n(av^2))，但不因此成为 (o(av^2))。

## 4. 中心半孔强迫本孔代表，且每孔最多一个

任意实际见证包含自身完整孔，且组件半径小于 1。故其捕获别孔的总孔质量小于 (a-h_b)。由 (h_b/a\to1) 对所有 (b\le J) 一致，最终

\[
 a-h_b<h_b/4^n
 \tag{R2}
\]

对全 (J) 同时成立。

若该见证碰到别孔的中心半孔 (k+[-g_b/2,g_b/2]^n)，则每个坐标与别孔相交的长度至少 (g_b/2)，相交孔质量至少 ((g_b/2)^n=h_b/4^n)，与 (R2) 矛盾。这个论证适用于来自保护层的代表，也不要求目标中央点在方体内部；闭边界接触已足够产生所用正体积。

一孔内任意两中心的距离至多 (2g_b)，而任意合法半径大于 (R_b>2g_b)，故严格 Besicovitch 条件排除两个代表同属一孔。

任何 (K_v) 的中心半孔点都必须被某个选方体覆盖；别孔代表已被排除，故本孔必须有自己的唯一代表。该代表的方体又由 (R1) 覆盖整个本孔。跨组件的代表不能进入，因为物理见证半径小于 1、外盒远隔。

## 5. 任意 (o(av^2)) 内逼近只会损失 (o(v)) 比例的固定型别孔

固定正整数 (b)。设该组件内部孔中有 (q_bN^n) 个没有代表。每个这样的中心半孔都完全在 (F_v\setminus K_v)，且半孔物理体积为 (lambda_b^nh_b/2^n)。另一方面

\[
 N^n\lambda_b^nh_b\sim w_ba=v2^{-b}a.
\]

因此

\[
 q_b\le\frac{2^n|F_v\setminus K_v|}{N^n\lambda_b^nh_b}=o(v).
 \tag{R3}
\]

这里 (b) 固定，(2^b) 只是常数；不能把这一结论误说成对全部 (b\le J) 的一致 (o(v))。当前证明只需要在给定 (D) 后固定一个 (b)，所以量词正确。

删除与缺代表格的 Chebyshev 格距至多 1 的格，至多再删除 (3^nq_bN^n) 个格；删除最外一层的比例 (O_n(1/N)=o(v))。剩余 ((1-o(v))N^n) 个格的全部相邻孔都有代表。

本代表中心在本孔内且半径小于 1，故它只能碰到 Chebyshev 格距至多 1 的孔。每个别孔的所有 (K_v) 点已被其自己的代表方体覆盖，因此不可能贡献给本代表的私有部分。选格又远离内部孔边缘，保护层不额外进入。故这些代表均满足组件单位下

\[
 |P_i|\le h_b.
 \tag{R4}
\]

其他方体覆盖本孔中的点只会进一步减小私有部分，对上界没有不利影响。

## 6. 容量分支与空面柱的常数

固定 (D>0)，再固定整数 (b>(4^n+4)(D+1))。最终 (b\le J)。若代表的容量亏损不超过 (Dv)，由 (R4)，

\[
 r_i\le R_b(1-Dv)^{-1/n}
 \le R_b(1+2Dv)\le1-(b-2D)v.
 \tag{R5}
\]

这些不等式在固定 (b,D) 的小 (v) 下成立。

令 (L=(b/2-D-1)v>0)，在半盒右面作法向长度 (L/2)、切向边长 (r_i/4) 的开柱。由于 (r_i\to1)，它最终在 (A_i\setminus B_i) 中。

别孔若有非零切向格位移，则其中心到柱切向坐标的距离至少

\[
 1-2g_b-r_i/8>1/2,
\]

而所有别半盒的组件半径小于 (1/2)，故不能进入。仅有法向格位移时，负向别孔显然远离；正向别孔的半盒到本半盒的法向间隙至少

\[
 1-2g_b-(r_i+1)/2
 \ge(b/2-D)v-2g_b
 \ge(b/2-D-1)v=L.
\]

这里用了 (R5) 及 (2g_b<v)。所以长为 (L/2) 的整个开柱不属于任何半盒。其他组件离得更远，也不能进入。于是

\[
 e_i\ge\frac{L}{2\,4^{n-1}r_i}
 >\frac{b-2D-2}{4^n}v>Dv.
\]

最后一步只需 (b>(4^n+2)D+2)，原稿选择更强，余量充分。若容量亏损最初已经大于 (Dv)，当然也有 (d_i>Dv)。因此上述保留孔的代表全部异常，不依赖代表在本孔中的选点，也不依赖全部实际允许半径中的选择。

## 7. 全族半盒上界及固定尾下界

每个保留孔的选半盒物理体积大于 (lambda_b^nR_b^n)。因此

\[
 \sum_{d_i>Dv}r_i^n
 \ge(1-o(1))N^n\lambda_b^nR_b^n
 =(1-o(1))v2^{-b}.
 \tag{R6}
\]

为了除以任意选族的 (S)，不应只数某个组件。全局统一上界来自每个严格见证：

\[
 |B_i\cap E_v|\ge|B_i|-|Q_i\setminus E_v|>(1-a)r_i^n.
\]

所有物理半盒两两不交，所以

\[
 (1-a)S\le|E_v|=1.
 \tag{R7}
\]

该界独立于 (J)、型别、代表数量及所有见证半径选择。合并 (R6)、(R7)，确得

\[
 \liminf_{v\downarrow0}\frac{\sum_{d_i>Dv}r_i^n}{vS}\ge2^{-b}>0.
\]

这是对任意 (K_v) 和任意有限严格 BIP 覆盖的结论，不是对某个便利贪心输出的结论。

## 8. 量词和不能推出的结论

当前构造的顺序是先给整个 (E_v) 序列，再给任意内逼近序列和任意见证族；对每个固定 (D)，最后固定一个足够大的整数 (b)。由于 (J\to\infty)，同一个输入序列同时应对所有固定 (D)，无需为每个 (D) 重建输入。

起效阈值可依赖固定 (n,D)，低限常数可依赖 (n,D)。不需要对增长的 (D=D(v)) 或型别 (b=b(v)) 一致。固定 (J) 截断中的大 (b) 不参与面柱低限，只参与统一的周期半径排除及质量预算，这两项已经对全 (J) 统一核查。

结论只能否证“有界第三尺度亏损自动给固定尾小 (o(v))”这一必要性主张。它不能否证相对真正最优值误差 (o(av^2)) 的极大化序列可能有更强尾性质，也不能否证第三系数存在。

## 9. 固定 (\varepsilon) 近 (L_n) 的加强版：单独成立

这一节是对固定参数强化的独立推导，与主文件 (\theta=1) 的陈述分开。
固定 (\theta>0)，改用

\[
 w_b=\theta v2^{-b}\quad(1\le b\le J),\qquad
 w_0=1-\sum_{b=1}^Jw_b.
\]

对充分小 (v)，权重仍正。全部几何及实际见证分析不变。令

\[
 f_b=\frac{h_b}{1-h_b},\qquad f_*=L_n(t)-1.
\]

因 (s=bv+v^3\in[0,1])，有

\[
 0\le f_*-f_b
 =\frac{h_*-h_b}{(1-h_*)(1-h_b)}
 \le C_n a\,[bv+v^3].
\]

又 (sum_bw_bb\le2\theta v)，故

\[
 \begin{aligned}
 0\le f_*-|F_v|
 &\le f_*-M_{\rm int}\\
 &\le C_n\theta av^2+C_nav^3+O_n(a/N).
 \end{aligned}
\]

所以对任意固定 (\varepsilon>0)，先选固定 (\theta>0) 足够小，再令 (v\downarrow0)，可保证

\[
 |F_v|\ge L_n(t)-1-\varepsilon av^2.
\]

固定 (b) 的组件孔质量变为 (sim\theta v2^{-b}a)，任意 (o(av^2)) 的内逼近仍使缺代表比例为 (o(v))，因为 (\theta) 固定。于是第 7 节的尾低限变为

\[
 \liminf\frac{\sum_{d_i>Dv}r_i^n}{vS}\ge\theta2^{-b}>0.
\]

**这一固定 (\varepsilon) 强化有效。** 不能再令 (\theta=\theta(v)\to0) 后保留正尾低限；若这样做，上述低限随之趋零。因此本构造没有得到相对 (L_n) 的 (o(av^2)) 最优精度反例。更不能从固定 (\varepsilon) 的一族反例直接换序极限，宣称真正极大化序列的尾桥失败。

## 10. 实际本机精确核验

本轮实际调用 `/usr/local/bin/wolframscript`，版本输出 `15.0.0 for Mac OS X ARM (64-bit) (May 15, 2026)`。下列精确违反集均返回 `False`：

```wl
Reduce[k>=1 && 0<g<1/4 && 0<=s<=2g &&
       (4k g+s)/(2k+2s)<2g, {k,g,s}, Reals]
Reduce[k>=1 && 0<g<1/4 && 2g<=s<1 &&
       (4k g+2g)/(2k+2s)<3g/2, {k,g,s}, Reals]

rr=(1-b v-v^3)/(1+v);
Reduce[v>0 && b>=0 && dd>0 && b v+v^3<1 && dd v<1/2 &&
       rr (1+2dd v)>1-(b-2dd)v, {v,b,dd}, Reals]

gg=v(1-b v-v^3)/(2(1+v));
Reduce[v>0 && b>=0 && dd>0 && b v+v^3<1 &&
       r>0 && r<=1-(b-2dd)v &&
       1-2gg-(r+1)/2<(b/2-dd-1)v, {v,b,dd,r}, Reals]

Reduce[hh>=16 && dd>0 && b>(hh+4)(dd+1) &&
       (b-2dd-2)/hh<=dd, {hh,dd,b}, Reals]
```

还实际输出

```wl
Limit[v Log[1/v],v->0,Direction->"FromAbove"]
(* 0 *)
Factor[1-2gg-rr]
(* v (b+v^2) *)
```

这些检查支持明确的代数子步骤，任意覆盖与一般维数的几何证明仍由前文承担，没有把有限数值搜索当作证明。

**最终判定：真实反例主版本通过；固定 (\varepsilon) 的固定 (\theta) 强化也通过；不支持 (o(av^2)) 最优序列版本。**
