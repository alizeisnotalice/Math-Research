## 对象与当前范围

固定整数 n≥2，Lebesgue 中心轴平行方体，严格水平集，输入为任意正有限测度可测集，取全部正半径。多线性模型共用中心和半径，分母为公共交集；单个输入允许无限测度。常数可依固定维数，未证维数一致性。

令 a=vⁿ=2ⁿt，v=2t^(1/n)，A_v=(1+v)ⁿ，L_n=A_v/(A_v-a)，K_n=binom(n,2)n²/27。当前正文的完整标量结论为
\[
C_n(1-t)=L_n+K_nav^6-(n+26/9)K_nav^7+
\widehat J_nav^8+o_n(av^8),
\]
\[
\widehat J_n=\frac{(n-1)n^3(2609+1971n+81n^2)}{26244}
+\frac{16}{27}\mathbf1_{\{n=2\}}.
\]
本轮从当前实际源重新展开基础、六阶、七/八阶和真实下界，并核合它们在同一原半径、同一 I、同一次有限八层构造上的依赖，未发现必须修改该主定理的数学缺口。二维值17638/6561、三维9251/486。两笔二维8/27分别来自实际分母与inside小源费用；不是同一预算使用两次。

这也证明最初的归一化极限为−n2^(n+1)，且基线外前五阶无修正。普通t系数仍含L_n的低维碰撞；三维t^(8/3)系数为零不表示更高几何修正消失。
