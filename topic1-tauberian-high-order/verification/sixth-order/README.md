# R14 最小符号核验包

本包只核对代数、低维幂次碰撞、物理尺度和标量账本。真实全部输入的六阶上界由正文解析证明及独立审核承担，不从15个维数外推。

环境为本机 Mathematica/WolframScript 15.0.0 ARM。实际最终运行启动15个不同子内核，原始维数n=2,...,16分别由KernelID 1,...,15处理；PID及完整输出见result.txt，全部FAILURES=0。物理参数组成的4个任务复用同一内核池。

复现：`wolframscript -file verify.wl > result.txt 2>&1`。脚本没有计算时间限制，断言失败会非零退出。

- 归一化变量v中的L_n−1=v^n/[(1+v)^n−v^n]，六个系数与一般有限和逐项一致。n=3的j=5恰为0。
- 物理参数必须取v=2σ^(1/n)。设q=1/m、x=ε^(1/n)、P=1+(1−q)x^n/2+(1−q)(2−q)x^(2n)/6，脚本使用σ=x^nP及正根2xP^(1/n)，未使用PowerExpand。n=2,...,5的所有可见系数按符号q输出，q=1还原2^(n+j)c_nj。四个已发表ε²系数66−2q、−572−4q、9224−8q、−127984−16q全部作为验收断言。三维ε^(8/3)系数为160(1−q)。
- σ的三阶Taylor式、q→0延拓、四阶导及其系数界、正根归一化系数非负和替换余项阶均实际符号核验。0≤q≤1、0≤ε≤1/2时导数上界96，余项≤4ε⁴；其在所有重数的一致意义另由正文证明。
- 新E+M内部恒等式及目标重复量系数化简均通过；1D体积比率与对数导数界通过。它们不证明新增几何接口。

探索初次参数组成遗漏了因子2，所得数组仅属于不同的归一化模型，不能作为项目物理L_n(σ)的结果。主代理指出后已重算，并以四个旧系数及q=1双重回归检查；最终包由主代理清洁整合后实际运行，只保留正确物理组成。无必要的旧模型数组、逐维重复缓存与阶段性日志留在仓库外，没有把它们冒作额外证据。
