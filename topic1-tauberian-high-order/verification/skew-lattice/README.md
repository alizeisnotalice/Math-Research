# R10：给定斜晶格公式的有限参数证书

本包验证给定的根方程、面积表达式和有限参数不等式。它不证明实际集合的几何见证、坏区包含或真实极大算子的下一阶系数。

运行环境：Python 3.15.0（标准库，无额外依赖）；Wolfram Mathematica 15.0.0 for macOS ARM。以下命令从本目录运行；Python生成器必须显式指定输出目录，不会默认写入脚本目录。

```sh
python3 compute.py generate --output-dir results
python3 compute.py verify --input results/certificates.json
wolframscript -file verify.wl "$PWD/results/certificates.json" "$PWD/results/wolfram-crosscheck.txt"
```

生成器共配置15个worker。实际最终运行用了15个不同worker，耗时约0.21秒；这些是执行记录，其他机器的进程数与时间可不同。输入共204组：n=2,3,4分别取κ=n,2n,4n,16n/3,7n及u=1/8,...,1/1024，得到120组；n=5,...,16取κ=16n/3及u=1/16,...,1/1024，新增84组，互不重复。所有守卫通过；G的有理区间182组严格正、22组严格负、0组符号未决。负值完整保留。

每个成功组以200次有理二分夹住唯一正根。`root` 中的十六进制整数 p 和 p+1 对应端点 `(δ−e)p/2^200`、`(δ−e)(p+1)/2^200`。正系数的多项式和积分在正半轴上递增，使用根两端的精确分数算出面积、坏区量和G的有理上下界，再向外舍入为35位有效数字。唯一正根由多项式正系数及端点预算守卫保证。

`verify` 不重新搜索根：它读取存档括界，精确重建根方程、面积上下界、坏区量及G上下界，检查所有守卫、端点顺序、符号、汇总及十进制端点确实向外包围精确分数。最终目录实跑204组全部PASS，记录见 `results/python-verify.txt`。

Wolfram脚本验证一般n的隐函数首项、面积原函数与优化代数；然后独立读取全部204组，以150位工作精度求根、120位工作精度数值积分面积并比较G区间与符号。最终运行15个子内核，204/204区间内、204/204符号一致，最大区间中点差约4.89×10⁻³⁵；输出 `results/wolfram-crosscheck.txt`，运行日志 `results/wolfram.log` 无消息。此过程是高精度数值交叉检查，不是区间证书。

公式的全局几何假设和这些固定参数以外的情形须另行证明。脚本无自动时间限制；不要把有限计算结果当成真实常数结论。

## 明确有限输入与实际见证

`witnesses.py` 从同一根括界重建n=2,…,16、κ=16n/3、u=1/1024的15个输入，固定N=ceil(u^(-9))，保存有限集E_N的完整公式参数；利用有限内孔计数精确证明每个输入的halo比值下界严格大于L_n。另对每个输入保存孔中心和一个靠近短角的实际点及见证半径，以有理区间交长直接求和复算平均值和严格裕量，30个裕量均正。遗漏晶格指标的排除依赖正文几何，不由25项直接求和自行替代。输出中有限比值差用十六进制整数分子／分母保存，均为精确数。

```sh
python3 witnesses.py --input results/certificates.json --output results/witnesses.json
```

204组守卫还由主代理逐项确认满足正文所列的充分小参数条件。22个负G仅表示保守构造下界在那些参数下未超过L_n，不表示真实C_n低于L_n。主代理从归档路径重新运行证书重建和全部204组Wolfram交叉核验，均通过；Wolfram结果文件现为该次实际运行输出。
