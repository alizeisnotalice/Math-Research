# 固定几何重采样

从第5轮 15 个幅度扫描中，按 `(估计捕获增益−基线增益)/u^4` 最大选中 job 02；所用的 u=0.08、孔中心和矩形半轴及选择口径保存在 `rescramble/selected.json`。这是一项基于先前估计的选择，后续15次scramble均固定该几何。

每个孔使用 65,536 个 scrambled Sobol 点，共15次独立扰动。结果归一化值的均值为 −0.9589731，最小值 −0.9606593，最大值 −0.9552399，样本标准差 0.0018656；15次均为负。逐次计数、增益与耗时保存在 合并的 `rescramble/results.json`。这些数只描述经验散布，不是严格误差界或置信区间。

对该输入原先采样中的16个点，用独立逐盒交体积和各半径区间数值最小化复算；16点的浮点见证均满足严格阈值，最小 t−缺陷率约 3.4573×10⁻⁵。输入点、半径和余量见 `rescramble/witnesses.json`；独立脚本为 `verify_witnesses.py`。

半径仅搜索 [10⁻⁸,1.5]，更大半径未排除；浮点误差和QMC积分误差均未认证。采样点的见证检查不证明捕获集体积，因此这不构成严格新下界或三阶系数证明。脚本使用相对路径，依赖 Python、NumPy 和 SciPy；设 `SOBOL_POWER` 可修改每孔采样数的二进制指数。

复算代码复用前一轮 `../exploration005/lattice_batch.py` 的半径搜索函数，独立见证脚本不导入该函数。Python 3.15、NumPy 2.5.4、SciPy 1.18.1。
