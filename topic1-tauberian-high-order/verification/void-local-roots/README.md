# Face collision scalar check

Use Mathematica/WolframScript 15 ARM: wolframscript -file face_collision.wl. The retained actual log gives endpoint identity residual 0 and violation set False.

Given two diagonal invasions at least ell>0 in an already determined four-cell fibre, at least one corresponding face invasion is at least ell. Only this finite scalar implication is checked here. The probability construction of robust face paths, physical local-root transport, actual void estimate, and Fubini capacity are proved analytically and independently reviewed; no model enumeration or configuration scan supports a broader claim.

Probe use in the associated proof is restricted to one specified probe per root or a uniformly bounded number N0. The constant includes N0 unless N0 depends only on dimension. These results do not establish measurable helper allocation or a high-dimensional Slot theorem.
