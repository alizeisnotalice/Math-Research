# 第40轮横向体积因子的实际符号核

独立Sol在正文审查中发现并修复n维角臂核积分遗漏的目标横向体积因子。此短核验证完整前因子乘横向体积及两臂矩后，恰为(1+v)^(n−1)·5p_*⁴/(3n²)·v⁷·R_j^(n+1)/R_i；取p_*=n/3后两端系数为(10/9)n²/27。整数n≥2、v/R_i/R_j/p_*>0的假设明确写在脚本。

transverse_check.log为本机Wolfram15 ARM真实输出，PID94692，两个残差均为InputForm[0]，不是未解析的积分或方程。它只核此有限代数，不证明实际源轮廓、横宽余项或任意输入价格；这些由修复正文和独立数学审查承担。

复现：wolframscript -file transverse_check.wl。脚本无私有路径，不产生大文件。渲染图、构建缓存和重复小核不入仓库。
