Frozen v2 proof: `../../proofs/078-end-face-reserve.md` (SHA256 `792c6a7edd5ff3f4dc49db99bcdae91e4a500895194eec95936641d3637a0b1f`). Review: `../../reviews/078-end-face-reserve.md` (SHA256 `9a58e3c5b11817d9222d72701ddf6ed9200be18daceefc4199f337f20a31c189`).

`end_face_ledger.wl/log` records the actual Wolfram 15.0.0 ARM run (exit 0): exact telescope, reverse-ratio and CDF endpoint-normalization residuals are zero; the printed assertions pass. `independent_checks.py/json` is a portable rewrite of the reviewer check (original script SHA256 `bcf1ee759357155acc7afedd2cd80604b125a19153eb063b0143558deadad9a4`). The rewrite preserves its exact Fraction separation, telescope, reserve, endpoint and exponent assertions; it obtains the v1/v2 bytes by importing this package's read-only `verify_inverse.py`, which reconstructs from the staged diff and metadata in memory. It does not read the absent old/new source files or execute the source-writing `notation_patch.py`. Reproduce it in this directory with `python3 independent_checks.py`; the actual run is captured in `independent_checks.json`. This is a scalar/algebra check, not a replacement for the source's geometric argument.

The v2 source adds three literal clarifications to v1: identify actual normal weight W_N separately from full slot capacity, parenthesize the excluded-face union, and state that the fixed robust-face list includes tau*=1/128. `notation.diff`, `freeze.v2.json`, and the original `freeze.json` preserve the three edits and old/new byte hashes. `verify_inverse.py` reverses the unified diff in memory, checks final/source/diff/metadata hashes and exact old byte count, and never writes to either source. Reproduce it from this directory with `python3 verify_inverse.py > verify_inverse.json`.

The proved interface is a same-family finite-layer supply statement for fixed n>=2 and a fixed finite robust-face list. It retains actual end-shift, ordinary-face and robust-face reserves while using a single terminal union. It does not determine the absolute C_n ninth-order coefficient, upgrade all high-support contributions to o(v^9), or prove an all-order upper bound. The old core R_* estimate remains O(v^8); the good q=3 intrinsic v^9 term is retained.

The manifest is `manifest.json` in this directory. Its paths are relative to the project root (`../../` from this package).
