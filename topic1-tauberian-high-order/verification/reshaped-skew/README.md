# R13 单坐标对斜晶格与选子集：有限参数计算

本目录只检查给定公式的算术；它不证明周期几何、坏区包含、严格见证或对选中集合的可测质量分割。上界B、精确质量M和真实构造需另行证明。

`certify.py` 实跑15个(n,κ)分支：n∈{2,3,4}，κ/n∈{1,2,8/3,3,7/2}；取 Λ=(11/10)κ³/(8n²)、u=1/8,...,1/1024，共120组。所有地方均重新使用外半宽 w=u/(1+2u)+Λu⁶、ρ=1−2w、K=a/(2w)^(n−2)，没有假设 w=uρ。15进程池最终实际使用的不同worker的PID及运行记录见 `certify.log`。

Fraction精确计算中，一组 n=4、κ=14、u=1/8 未通过 e<w/4 守卫；其余119组根夹逼和算术守卫通过。D−B 的区间有90组严格正、29组严格负；D−B负的组不满足该充分预算，不把其形式G称为有效构造。90个预算可行组中，G为87正、3负；3个负例均为κ=7n/2、u=1/32。这是有限条件下的结果，不排除别的坏区估计或参数。

每个守卫合格组经320次Fraction二分；根端点记为 `(w−e)*int(hex,16)/2^320`。对A及B按单调性传播有理上下界，`D_minus_B`和G以30位有效数字向外舍入。归档只保留合并输入及结果 `cases.json`；如重新生成，脚本会临时创建 `fraction/`。

`check.wl` 实际启动15个Mathematica 15.0.0子内核，以150位求根及120位数值积分对119个守卫合格组逐项比对：根括界、D−B区间和G区间均119/119通过；见 `check.log`、`wolfram-results.txt`。数值计算不替代Fraction证书。

同脚本对一般整数n≥2核验 D/(a u⁵)→nΛ、A/u⁷→κ³/(4n)、B/(a u⁵)→κ³/(8n)、G→(κ²−2nΛ)/64。令Λ↓κ³/(8n²)后，最优κ=8n/3给 n²/27；此处有限参数 Λ=1.1Λ0，κ=8n/3 的预测值是4n²/135，而不是 n²/27。此极限计算依赖给定模型和根渐近。

所有计算均实际运行，无时间限制；本目录不改其他项目或冻结稿。

## 15个具体有限输入与中心见证

`center_finite.py` 使用15个独立同步启动的本机进程，分别处理n=2,...,16；κ=8n/3、Λ=1.1κ³/(8n²)，所有15组均以首选 u=2^(-16)、N=ceil(u^(-7))=2^112 通过，无需重试。不同worker的PID、所有守卫、根括界、精确分数均保存在 `center_finite.json`，实际运行日志为 `center_finite.log`。

记录中 G 是外孔去除非严格见证坏点的可测好集，A=G∩{x₁<c}，c选使|A|=M；有限输入记作 E_N=T([-N,N]^n)∖⋃_{z∈Zⁿ}(Tz+A)。这15组均有 M>m_out/2。由于 G 包含于关于原点对称的外孔，|G∩{x₁≤0}|≤m_out/2<M，不需要G自身对称；切片体积连续和|G|≥M的解析论证给出 c>0。中心处s=w且邻孔贡献的归一化上界是2e²，严格预算守卫 F(w−e)>2e² 和F递增给 F(w)>2e²，故中心属于G并属于A。切片存在性、坏区包含和邻孔上界仍依赖解析证明。

每组均精确验证中心半径 r=ρ+w 下，缺陷率至多 [M+2e²(2w)^(n−2)]/(2r)^n，且 t减去此上界严格为正；这是原集合平均的严格下界，绝非实际平均等式。也精确保存并验证有限截断比值 `1+((2N−5)/(2N))^n M/(d−M)` 减去Ln为正的完整分数。差值的几何意义仍依赖周期截断与实际见证的解析证明。

`center_finite.wl` 仅对这15个新输入独立启动15个Mathematica子内核，150位根/120位数值积分核对预算和G，另以精确有理运算核N、半体积、中心严格裕量和有限差，全部逐项为True；完整结果 `center_finite_wolfram.txt` 与日志 `center_finite_wolfram.log`。数值交叉核验不替代解析证明。

## 复现与非重搜复核

在本目录中运行 `python3 certify.py` 可一次生成15个分支并自动合并更新 `cases.json`；运行 `python3 center_finite.py` 生成15个中心/有限截断结果；运行 `python3 verify.py` 则只读取已保存的两个JSON，不重搜根，逐组用存档的有理上下端重建F、A、B、D−B和G，核对十进制向外包围、预算与admissible标志及中心精确分数。135条实测为105预算正、29预算负、1守卫失败，15项中心精确检查通过。`verify.py` 复用生成器公式，不是独立算法，输出见 `verify.log`。

Wolfram交叉核验可用 `wolframscript -file check.wl` 和 `wolframscript -file center_finite.wl`；现存日志为原路径实际执行结果。计算无时限。
