# R22：条件性的下一项代数传递

**条件范围。** 本目录假设对每个固定n≥2，已有 C_n(1−t)=L_n(t)+K_n a v⁶+o(a v⁶)，K_n=binom(n,2)n²/27，a=v^n、v=2t^(1/n)。该几何上界现已由第21轮的完整独审组合证明，本目录仍只核验以它为前提的代数。计算只核对条件下的代数传递；统一little-o仍需使用原假设及阈值代换的量词。

## 普通t的系数

`conditional_transfer.wl` 由Mathematica 15.0.0实际启动15个不同子内核、KernelID 1–15，对n=2,...,16计算 Ln(v) 的j=6项，并核对

  c_n6 = b_n6 + 2^(n+6)K_n,

其中 b_n6=2^(n+6) Σ_{k=1}^{1+floor(6/n)} (−1)^[6−(k−1)n] binom(n+5,6−(k−1)n)。15项全部一致。n=2,...,6时的 c_n6 依次为

  443392/27, −13312, 1138688/9, 11571200/27, 1978368。

这五项均不为零；各维全部结果、实际PID及KernelID见 `conditional_transfer.log` 。该批次的系数是物理t尺度：v=2t^(1/n)。

## 物理参数阈值

取q=1/m∈[0,1]、x=ε^(1/n)，以四阶σ多项式的正根计算 v=2σ^(1/n)，直接展开 Ln(σ)+K_n(2σ^(1/n))^(n+6)，未使用PowerExpand。条件下 ε^(1+6/n) 的系数为：

- n=2： (972950−88227q+2070q²−9q³)/54；
- n=3： 4(−10414+429q+q²)/3；
- n=4： 32(35719−135q)/9；
- n=5： 64(180719+81q)/27；
- n=6： 32(61825−q)。

q=1全部回到上面的普通t系数；n=3先前 ε^(8/3) 系数仍为160(1−q)。这里q=0按m→∞连续延拓。各式均是以sharp K_n为前提的代数式；该前提的真实几何证明见第21轮，本包自身不承担它。

## 阈值余项

`sigma_uniform.wl`、`sigma_uniform.log` 实跑验证 σ_m=m[1−(1−ε)^(1/m)] 的四阶系数为

  (m−1)(2m−1)(3m−1)/(24m³)。

令q=1/m，0≤q≤1时第五导数的系数 (1−q)(2−q)(3−q)(4−q) 在[0,24]；对0≤ε≤1/2，乘以 (1−ε)^(q−5) 至多2⁵，故第五导数绝对值≤768。四阶Taylor余项因此统一至多 (32/5)ε⁵；q=0同样以−log(1−ε)的连续延拓处理。正根的截断多项式在q∈[0,1]、x≥0时为正，避免跨分支幂变换。

复现：`wolframscript -file conditional_transfer.wl`、`wolframscript -file sigma_uniform.wl`。实际计算日志和结果在本目录；未设自动时间限制。几何来源与sharp假设均需独立证明。
