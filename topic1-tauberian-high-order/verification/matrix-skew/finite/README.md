# R15 全对称构造：15个有限输入的算术与中心见证检查

本目录核验给定全对称模型的有限算术条件；几何坏集覆盖、实际见证及可测切片的存在性仍依赖独立的R15/R11解析论证。计算本身不证明一般维结论。

n=2,...,16各取 κ=8n/3、u=2^(-20)、Λ=(11/10)binom(n,2)κ³/(8n²)，故 N=ceil(u^(-7))=2^140。生成器先小试n=2，再由15个独立同步启动的Python进程各处理一个维数；最终15个不同PID，15组全部通过，无需降低u。输入和 Fraction 精确输出保存在 `results/certificates.json`；`python.log`记录实际PID、时间与状态。

每个输入按 T=(1−e)I+eJ、d=det T、w、ρ、M、F重新计算；两个根 h*、hH各用400次有理二分。正系数单调性给出A及坏区上界B的精确有理括界；G中存档的A、B和D−B十进制端点均以35位有效数字向外舍入。守卫包括w<1/4、(n−1)e<1/12、e<w/2、F(w−e)>2·3^n e²、hH<w−e和D≥B。15组均通过。`verify.py` 读取存档的双根括界、不重新搜索，重建所有Fraction算式并核验守卫、端点向外包围与精确分数；它复用生成公式，不是独立算法，实跑15/15通过。

设外孔内可测好集为G，A=G∩{x₁<c}，其中c按|A|=M选取。15组均精确满足M>m_out/2；因G包含于关于原点对称的外孔，|G∩{x₁≤0}|≤m_out/2<M，不要求G自身对称。结合另行证明的|G|≥M和切片连续性，可取c>0。中心点x=0的见证半径 r=ρ+w；程序以独立Laurent动态规划和偶q组合和计算外包邻孔上界并精确比较。对实际集合，中心缺陷率**至多**为

  [M+Σ_{q偶, q≥2} binom(n,q)binom(q,q/2)e^q(2w)^(n−q)]/(2r)^n。

15组的 t 减去该上界均严格正；因此在解析包含条件成立时，实际平均有严格下界 >1−t，不能把上界写成实际缺陷率等式。另精确检查 ‖T⁻¹‖∞r<N，保证中心见证方体位于有限截断中。

有限输入定义为 E_N=T([-N,N]^n)∖⋃_{z∈Zⁿ}(Tz+A)。15组均用精确分数确认 `1+((2N−5)/(2N))^n M/(d−M)−L_n(t)>0`，完整分数和中心坐标、半径、裕量均在JSON内；把该算术式解释为真实halo下界仍依赖周期截断和几何证明。

`verify.wl` 实际启动15个不同Mathematica 15.0.0子内核，对这15组独立用210位工作精度求双根、170位数值积分，双根括界、A/B区间及D−B区间均15/15吻合；同时用精确数核行列式、逆矩阵范数、中心裕量和有限差，各15/15通过。高精度结果仅为交叉检查。详见 `wolfram.log` 和 `results/wolfram-crosscheck.txt`，无Mathematica消息。

复现（从本目录）：`python3 compute.py --pilot`；`python3 compute.py --output-dir results`；`python3 verify.py`；`wolframscript -file verify.wl`。无自动时间限制。旧R11/R13批次未重跑。
