# R15 二维代数根输入与实际中心平均

本目录只核验给定的坏角、slab及邻孔面积公式的算术后果；这些几何等式由独立审查确定，不能由数值计算证明。

`input.json` 是 R15 有限证书中 n=2 的原记录快照：u=2^(-20)、κ=16/3、Λ=704/135，并保留原先400步h*有理括界。`explicit.py` 只读取该括界，不重新搜索h*；它按此括界传播A的精确有理上下界，再针对 D−2A 的上下界分别对 z 做400步有理二分。`explicit.json` 记录新z的十六进制有理括界、向外舍入的A、z、c、C、邻孔量、中心平均和严格裕量，以及18项检查。运行 `python3 explicit.py --input input.json --output explicit.json` 可复现。

结果包括：F′(0)>e，0<z<h*<e<w，c=w−z>0，H(z)位于正确括界；C递增且正。在所给几何公式下，实际邻孔量为 2e²−2A−C(z)，中心平均为 1−[M+2e²−2A−C(z)]/(2r)²。其严格余量 t−缺陷率约为 1.73472099443812486449×10⁻¹⁸。相对于此前把两个邻孔均用完整e²外包的平均下界，精确平均高约 6.80265529502650847×10⁻⁴²。有限截断N及中心见证方体位置沿用原证书并重新以Fraction核对。上述几何等式现已通过独立非作者Sol窄审，见项目reviews/015-explicit-2d.md。程序本身只核验算术。

`explicit.wl` 用Mathematica 15.0.0独立核验H′、C′及slab积分恒等式；以高精度计算h*、z，用两个嵌套积分计算坏角并另对slab扣除积分，和Fraction的A、z、c、C、邻孔量、平均值与裕量括界全部吻合。积分使用210位工作精度，z求根230位；详见 `explicit-wolfram.log`。数值积分是交叉检查而非有理区间证明。复现：`wolframscript -file explicit.wl`。

初次Wolfram运行误对受保护符号D赋值，出现Set::wrsym及后续求根错误，未得有效结论；失败日志保留在仓库外，没有计作有效证据。修改变量名后运行通过且无消息。计算未设置自动时限。

`geometry.md` 为已签名的原冻结窄审稿，其SHA保持04534c035b0022140501c7d6362eb95e5071190b95e1b6c492764d5a21d66e31；末尾“待审”是冻结时状态，随后独审已完成。原input快照还含e<w/2和双角守卫，不能只看新增表中的较弱e<w；这些原守卫均已精确核验。
