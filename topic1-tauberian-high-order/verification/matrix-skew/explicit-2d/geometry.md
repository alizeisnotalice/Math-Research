# 二维显式分位切片与中心平均：几何等式窄审稿

仅用R15-finite中n=2的同一有理参数。记外孔C_w=[−w,w]^2、ρ=1−2w、实际孔质量M=aρ²、e>0，T=[[1,e],[e,1]]，D=(2w)²−M。F(s)=a[(ρ+s)²−ρ²]，J(s)=∫₀ˢF，h>0由F(h)=e²定义。程序须严格核验原双角/分离守卫及以下额外条件：F′(0)>e、0<h<e<w/2。

潜在好集G仍以R13/R15的原实际安全半径r(x)=ρ+w−||x||∞定义。只有两个相反短角进入；双角同时进入的点由原守卫为好点。坏点至多一个正短角，且最小面深度s≤h。对正短角令α=h_(1,+)、β=h_(2,−)。相反面不可能取得最小值，故s=min(α,β)。在α≤β分支，失败条件精确为

  0≤α≤h，α≤β≤α+e−F(α)/e。

F′(0)>e且F递增/凸，故F(α)/e≥α，右端≤e；另一排序同理。因此该整个坏角都在e×e角方块内，精确面积

  A=2∫₀ʰ[e−F(s)/e]ds=2eh−2J(h)/e。

两个相反坏角互不交，总坏量精确为2A（边界零测）。这比一般维联合上界更强，限二维。

对0<z<h固定α∈[0,z]，当0≤β≤α时，函数 e(e+β−α)−F(β) 的导数e−F′(β)<0，在β=α处仍≥0，所以这一段全为坏点；β≥α段的坏点上界为e+α−F(α)/e。由此右侧slab x1∈(w−z,w)内坏截长恰为e+α−F(α)/e，且只有右侧那一个短角遇此slab。该slab的good质量是

  H(z)=(2w−e)z−z²/2+J(z)/e。

H′(z)=2w−e−z+F(z)/e>0。若0<D−2A<H(h)，则唯一z∈(0,h)满足H(z)=D−2A。令c=w−z，实际孔A_actual=G∩{x1<c}。因为|G|=(2w)²−2A，移去的good slab恰为D−2A，故|A_actual|=M。该输入现在由两个代数根及隔离区间完整指定，不再需要未计算的体积分位阈值。c>0及0∈G保证中心属于实际孔。

中心x=0的半径r=ρ+w=1−w。在每个相反短邻孔中，外包交区精确为一个e×e角方块，其G部分质量为e²−A。右cut不影响左侧方块；在右侧方块移去的good面积恰为

  C(z)=J(z)/e−z²/2，C′(z)=F(z)/e−z≥0。

所以两个实际邻孔的质量和精确等于2e²−2A−C(z)。自身完整实际质量为M，其余晶格孔不进入中心见证。因此实际中心平均精确为

  1−[M+2e²−2A−C(z)]/(2r)²。

最终有限输入E_N=E_period∩T[−N,N]^2，N=u^(−7)。若存档精确验证 ||T^(−1)||∞r<N，则整个中心见证位于截断中，上式是实际有限输入的平均等式。所有等号只涉及可测面积，临界曲线及切片边界为零测；严格裕量由Fraction区间和独立Wolfram积分核验。
