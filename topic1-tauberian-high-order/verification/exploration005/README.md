# 周期矩形孔数值探路

2026-11-04；Python 3.15、NumPy 2.5.4、SciPy 1.18.1。全部数值任务已正常结束。输入文件的随机种子、周期胞内孔中心及半轴、逐孔捕获计数和运行时长保存在合并后的 `results.json`（`source` 字段保留原输出名） 中。

- 批次一：15 个二维配置；其中 8 个 2×2 孔组、7 个 3×3 孔组，u ∈ {0.08, 0.10, 0.12}。独立偏移为 O(u²)，矩形半轴相对扰动为 O(u²)；每孔 16,384 个 scramble Sobol 点。
- 批次二：15 个 2×2 孔组，u ∈ {0.04, 0.06, 0.08}，扰动幅度从 1/64 到 1 的五档，每孔同样 16,384 点。
- 对每点，取半径 10⁻⁸ ≤ r ≤ 1.5，按矩形边界生成分段端点；每段孔交体积是至多二次多项式，其归一化缺陷率只需在端点及段内驻点比较。全部计算使用浮点算术。半径 r>1.5 未检验。

批次一的 15 个捕获增益估计与基线 L₂(t)−1 之差均为负，范围约 [−9.52×10⁻³, −1.03×10⁻³]；批次二也均为负，范围约 [−9.12×10⁻⁴, −5.55×10⁻⁶]。这是这 30 个具体参数和有限半径搜索的采样结果，不排除其他参数、孔形或半径给出更大捕获。

`validate_baseline.py` 对 u=0.004、0.006、0.007 的均匀方孔解析点态公式作 81 点浮点比对，最大绝对误差 1.36×10⁻²⁰；只验证这些基线点，不能推出其他参数的误差上界。浮点误差没有认证，Sobol 采样积分误差没有估计或上界，结果不是严格新下界或三阶系数证明。

`lattice_batch.py`、`amplitude_batch.py` 和 `validate_baseline.py` 使用脚本目录作为相对基准；安装 numpy、scipy 后可直接运行。`SOBOL_POWER` 控制每孔采样数的二进制指数，默认 14。脚本会在本目录创建 `batch/` 和 `amplitude-batch/`；运行结果为新的采样和计时，不能替代本轮原始日志。

初次运行曾发生 JSON 序列化错误；另一次的周期副本预筛遗漏第二孔附近邻孔。两次均已作废，不计入以上30组；当前结果由修正脚本重跑。

逐核心采样程序 `cpu_probe.py` 只适用于macOS，读取系统CPU累计时间，两秒差分；结果包含其他系统任务，不宣称CPU绑定。
