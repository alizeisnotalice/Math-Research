# Correlated finite-grid probe

The MILP uses actual grid-edge rectangles, not coordinate-maximal compositions. Input amplitudes are rational grid values and every selected-rectangle mass, strict margin, and receiving union is independently recomputed. Only `exitflag=1` is treated as an `intlinprog` optimum; `exitflag=2` time-limit incumbents remain candidates. This is a finite 4x4 family comparison and has no implication for Q, C_n, or a dimension asymptotic.

Retained rectangles: 1422. Best correlated ratio: 1.51047244909. Best axis-block constant baseline: 1.46670924469.
