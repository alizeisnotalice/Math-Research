# 第480轮　积分近饱和迫使实际门槛质量服从指数轮廓

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对任意有限目录，中央积分缺额控制窗口内部的最大高度差，继而控制每个门槛带承载的实际接收体积。这个约束同时追踪阶梯宽度和高度。
- 下一步须利用同一切片源的平均约束，检验这种指数门槛分布能否与区间覆盖等号共存。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第479轮，$v=s(q-p)$，在 $0\le v\le1$ 上设 $f(v)=A(p+v/s)/A(p)$，$g_*(v)=|F_{p+v/s}|/[CA(p)]$。注意 $g_*$ 为右连续非增函数。设 $\epsilon=\int_0^1(f-g_*)$，$M=\sup|f'|=1+O_I(k^{-1/2})$。若一点高度差为 $d=f(v)-g_*(v)$，则对 $v\le w\le1$ 有 $f(w)-g_*(w)\ge(d-M(w-v))_+$。于是固定 $0<\delta<1$，当 $\epsilon<M\delta^2/2$ 时，
\[
 \sup_{0\le v\le1-\delta}(f(v)-g_*(v))\le\sqrt{2M\epsilon}.
\]
若 $d>M\delta$，仅积分后续长度 $\delta$ 即矛盾；否则积分完整三角形。此处需要保留右侧窗口余量，右端点本身没有同样的控制。

令 $u(x,y)$ 为第473轮门槛最大值，即 $F_q=\{u>q\}$。则对任意 $0\le v<w\le1-\delta$，门槛带的实际接收体积除以 $CA(p)$ 等于 $g_*(v)-g_*(w)$，与 $f(v)-f(w)$ 相差至多 $\sqrt{2M\epsilon}$，因为两端缺额同属 $[0,\sqrt{2M\epsilon}]$。而 $-f'(v)=e^{-v}(1+O_I(k^{-1/2}))$ 一致成立。若本步相对整个包络分子的节省只有 $O(1/k)$，非负缺额和第479轮的分子尺度强制 $\epsilon=O(1/k)$。因此在任意宽度 $w-v\gg k^{-1/2}$ 的内部带上，
\[
 \frac{|\{p+v/s<u\le p+w/s\}|}{CA(p)(e^{-v}-e^{-w})}=1+o_I(1).
\]
端点取值按严格水平集约定。对应物理门槛带宽远大于 $1/k$。即便门槛值足够密，只要某个这样的带有固定比例的接收质量偏差，沿该序列的归一化积分缺额就不能保持 $O(1/k)$。此为光滑包络条件下的必要分布形状，尚未证明共同源无法实现它。

本机 Python 对单位斜率线性包络和一次向下跳跃后保持常值的阶梯核验了三角面积 $d^2/2$，说明平方根尺度来自单调性本身。
