# 第413轮　两色证书的精确超图割与高阶修正

- A 已覆盖全部等权深度轮廓。对有限目录的两色平均证书，最大化目标精确化为按标签单元体积加权的超图最大割。
- 重数至多三的部分可无损化为普通图；重数四已需高阶费用，且一个有理盒目录即可实现该障碍。
- 一般目录仍需控制割收益和线性行费用之差。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定任一待染行集 $V$，其并为 $U_V$，不必全为饱和行。令每个非空活跃标签集 $T$ 的空间体积为 $c_T$。对任一二分 $A,V\setminus A$，
\[
 L(A)+L(V\setminus A)=L(V)+\sum_T c_T 1_{0<|T\cap A|<|T|}.
\]
这是两个色类的并体积之和减去同一线性费用。故最优平均证书恰为 $(L(V)+\mathrm{MaxCut})/2$，这里割的超边是空间单元，且不同重数只结算一次。独立均匀染色使每边割开概率 $1-2^{1-|T|}$；对有限单元逐行固定条件期望可确定性实现不低于此期望的割值。

对 $d=|T|\ge2$，将该单元给每对行赋普通图权 $c_T/\lfloor d^2/4\rfloor$。若有 $j$ 个该单元内的行取第一色，图割贡献为 $c_T j(d-j)/\lfloor d^2/4\rfloor$，不超过精确贡献，且在非平凡分割时其比例至少 $(d-1)/\lfloor d^2/4\rfloor$。对 $d=2,3$ 恒等，故若重数至多三，普通加权图的任一最优割精确实现两色最优平均。任意重数时，把普通图最大割记为 $G$，则真实最优割落在 $[G,G+\sum_{d\ge4}\sum_{|T|=d}c_T(1-(d-1)/\lfloor d^2/4\rfloor)]$。这一加性项用实际体积，不含源内外未结算的对数精度保证。

对四个标签共同覆盖的一个单元，若用固定边权的四顶点普通割表示所有二分的单位收益，平均全部标签置换后必得到相等边权 $w$，但单顶点割需 $3w=1$，二对二割需 $4w=1$。在单位核心四面外伸的第387轮二维四盒例，所有正体积单元除核心外均为单标签，故整个割函数恰为这种四元收益。此排除只涉及原四个顶点上固定边权的精确表示。下一步应把高重数修正按中央目录的实际行选择截断，并检验截断所失接收体积。
