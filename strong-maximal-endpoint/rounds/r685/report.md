# 第685轮　沿两个方向分配见证的精确最小割

2026-11-13。每行 e=D×Q 可交给 D 组或 Q 组；设 k=dim D，h=dim Q。按第660轮，前者把同 D 的已分配行并内的源质量乘 H_h(p)，后者把同 Q 的已分配行并内的源质量乘 H_k(p)。各组相加给 |X| 的上界，严格门槛保持。以下最小割直接优化分配后的并内质量，组的未分配行不收费。实际计算可把 H 换为任何已证明的相应上界。

把原行并切成有限端点原子 A，质量 m_A=|E∩A|。为每行建节点 e，割的源侧表示选 D，汇侧表示选 Q。每个命中该原子的 D 组建辅助节点 v_{A,D}，由它向汇连容量 H_h(p)m_A 的边；每个含 A 且同 D 的 e 向它连无限容量边。对 Q 组反向建节点 u_{A,Q}，源向它连容量 H_k(p)m_A 的边，它向每个对应 e 连无限容量边。无限容量可取大于所有有限容量之和的数。给定行分配时，最省的辅助节点摆放恰在该原子被相应组的至少一条已分配行命中时付一次费。因此最小割值就是两方向单组估计总和的最小值。积分原子可以按相同命中模式合并。本结论只对该估计族最优，不宣称是真实接收体积。

**真正需要混合方向的目录。** 在 k=h=1 时取两个相隔离的星形分量，各有 N 条边。第一分量同 D 配 N 个互异近重合的单位 Q，第二分量交换两轴；沿两轴平移令分量的端点及矩形互离。以整个目录并为源，每行平均为一。对第一分量选 D 中心，对第二分量选 Q 中心，总费用恰为 H_1(p)|E|，也是最优，因为每个源点至少被一个组收费。若统一选 D 或统一选 Q，则其中一个分量被收 N 个单位质量；取各分量单位区间平移跨度趋零时，两种统一费用与混合费用之比均趋于 (N+1)/2。共同投影不再产生第684轮的单向容量障碍。

一般上界仍需在合适的选轴或删选后对最小割值给出统一估计，系数差仍为 (μ−1)/8。下一步：用对偶流刻画混合费用也很高时的必要重叠；检验近重合但没有共享端点的行能否先合并再应用该割。
