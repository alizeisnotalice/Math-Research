# 第395轮　连续标签排序的无损同门槛取整

- A 已覆盖全部等权深度轮廓。若存在一个盒排序使每点的活跃标签连续，则任意门槛的最优分数证书精确等于最优子集证书。
- 对一般排序，给出由中间空档的总权控制的可计算加性误差，不需降低门槛。
- 尚需结合接收几何控制适当排序的误差。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取第392轮同门槛最优权 $0\le z_i\le1$，按任意指定顺序将长度 $z_i$ 的半开区间首尾相接。用同一个 $T\sim U[0,1)$，若第 $i$ 个区间模一的投影含 $T$ 就选该行。每行边际正好为 $z_i$。固定 $x$，其活跃行集 $I(x)$ 的区间投影并长即真实覆盖概率 $P_x$，记 $S(x)=\sum_{i\in I(x)}z_i$。总有 $P_x\le\min(S,1)$。若活跃行连续，等号成立，不论全体行权和有多大。

一般地，忽略零权，将活跃首末行之间非活跃行的总权记为 $g(x)$（没有活跃行时取零）。首末间整段的投影长为 $\min(1,S+g)$，删去空档至多损失 $g$。因而同门槛最优子集证书 $L_*(p)$ 满足
\[
 0\le M(p)-L_*(p)\le\int_U [\min(S,1)-P_x]dx
 \le\int_U\min\{g(x),S(x),1\}\,dx.
\]
其中第一道上界来自取整证书期望与分数对偶目标的精确差值。最好的实现可在累计权的模一端点之间逐段枚举，无随机近似。当存在连续活跃排序时，对所有原始容量、门槛均无损。特别在一个轴上按左端点排序、右端点亦同序且其他轴相同的盒族满足条件。更一般，若每轴的左、右端点沿目录顺序分别单调且同向（各轴的方向可不同），每轴包含固定坐标的行连续，取交后仍连续。

这也允许在不同空间区域中积分误差，而无须强求每个标签连续。加性误差应与源体积而不是接收体积比较；仅知异常区域占接收并集的小比例，在中央尺度仍可能过大。下一步应寻找以源质量归一化的空档付费，或用多个排序分担不同的交叉标签。
