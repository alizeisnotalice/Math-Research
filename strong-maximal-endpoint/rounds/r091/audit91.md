# 第 91 轮独立审计

## 1. 有限与连续层的同侧边比例门槛

核对通过式 (1) 及其带双侧门槛的版本，按实际有限正体积轴平行矩形、严格平均、有限正体积基集理解。上界直接来自基层指标。下界可固定任一 $E$，无需紧支撑。每个网格立方体上，$E$ 的限制测度无原子；正质量时可将第一坐标的连续条件分布函数作为均匀变量，零质量格任意赋值。对所有占用份额或高度阈值，每个完整小格的质量恰好匹配期望；任一固定矩形中剩余边界格所占体积决定统一误差。这是同时针对所有比例或所有 CDF 截点的确定性误差。跳跃高度律可取有相应平台的分位函数；全局高度分布连同每个原子质量均精确，故 $J=|E|\int\Phi_N\,dK$ 对每个网格精确。

对任一严格成功的 $x$，已有一个密度高于 $\beta$ 的矩形。若需上门槛，关于矩形中心连续放大可保留该点，密度因边界零测而连续，且最终趋零，因为 $|E|<\infty$。故可选单个矩形使基层密度严格落入开带，并保留正的下门槛余量。有限层最低份额 $p_k>0$ 使所有下阈值都有余量；完整高度律版本则由条件 CDF 一致收敛和固定法则的有界平均收敛充当余量。严格 CDF 距离在占用质量有正下界的矩形邻域内连续，这是因为每个阈值质量误差均由同一矩形对称差体积约束。稍向外扩的有理矩形保留所有严格条件，保障可测性。Fatou 后再对 $E$ 取上确界，不要求上确界实际取得。所有有限 $k$ 及所有正容差均为逐参数结论，即使它们依赖 $N$ 也不会给出统一的必要网格尺度。对各层非负重价的除数 $\sum_i w_i p_i$ 来自全局精确的体积等式；对递增高度链的实际模数取 $w_0=\Phi(h_0)$、$w_i=\Phi(h_i)-\Phi(h_{i-1})$ 即可。

## 2. 全部成功矩形的条纹构造与边界

矩形并的交叠限于零测边界；每个盒子的每条轴长都是 $\varepsilon$ 的整数倍。第一坐标单独积分即可在每盒内得到完整全局相位律，与盒子的起点和相位无关。固定闭盒并之外的 $x$ 后 $b_x>0$；任何含 $x$ 又接触 $E$ 的矩形的最长边至少 $b_x$。沿该最长方向积分，对每个盒子的任意横截面，至多两片端部周期残片造成 $2\varepsilon$ 的误差；横截面体积至多为原矩形的横截面。其和证明 (3)，对每个成功矩形和所有相位阈值同时有效。这里可测 $0\le w\le1$ 即可，未要求 $w$ 或 $g$ 连续。针对每个相位阈值分别应用同一确定性上界，即可取 Kolmogorov 上确界。(4) 由 $w=g/A_*$ 得出。

对固定 $N,x$，若 $\beta<M_S1_E(x)\le\beta+\eta$，选一严格余量矩形带入 (4) 即可保住一次成功。之后同一个 $\varepsilon$ 的 (3)–(4) 同时约束经过这个 $x$ 的*所有*成功矩形。为达到 r090 的误差，可先令 $2A_*K_0\varepsilon/b_x$ 小于 $L^2/N$ 并小于该点原严格余量的一半。这样支持亏量为 $\tau+O(L^2/N)$，平均不超过 $1+O(L^2/N)$，占用条件 CDF 的误差为 $O(\tau+L^2/N)=O(LN^{-1/4})$。这里 $\varepsilon$ 可以随维、盒并和接收点变化；只在距离及严格余量均有统一正下界的区域上声称用一个足够细的网格同时保障成功。闭盒边界点未被断言。此处实际源已经净化；由补上缺失亏量 $O(\tau)$ 的零原子可得 r090 原尺寸整矩形 CDF，但并不能把任意原灰阶的低部质量亏损等同于其零集体积。

对截断正态 $V$，两端原子均为 $\tau$，最大 Kolmogorov 距离不超过 $\tau$，均值由奇对称得到。顶端原子独立给出的价格比下界满足对数 $d+O(L)$，因为二阶差为 $O(N\tau^2)=O(L)$。这个代价下，条纹壳自身的实际得分甚至满足
\[
 \frac{|\text{shell}|}{J(f_\varepsilon)}\le\frac{H_N(\beta)}{\int\Phi_N\,dK}
 \le C_N\frac{\Phi_N(1/\beta)}{\int\Phi_N\,dK}
 \le Q_N\exp\{-d+O(L)\}.
\]
最后一步只用既有 $\log(C_N/Q_N)=O(L)$ 界。这个比较作用于给定指标壳；它没有给整个未门控条纹 halo 增加限制，更没有给 $C_N/Q_N$ 下界障碍。

## 3. 可复现的有理数核验

以下 Python 标准库脚本已在本机运行。它与作者的测试独立，在单位方块取每周期低相位占 $1/3$（高度 $1$），其余高度 $5/4$，因此 $a=7/6$，$\beta=6/7$。矩形有一个接收点 $(12/11,1/2)$ 位于 $b_x=1/11$ 的壳上。二重原函数是两个正部平方之差，四角交替求和给精确面积。在 $m=6,12,24,48$ 时，低层实际密度相对比例目标的绝对误差依次为 $11/48960,11/257040,0,0$，实际均值为 $41393/39168,217327/205632,539/510,539/510$，均严格成功。全局低层份额恰为 $1/3$。

```python
from fractions import Fraction as F
p = F(1, 3)
def low_volume(rect, eps):
    lo, hi, bo, to = rect
    def primitive(t):
        def q(z):
            return max(F(0), z)**2 / 2
        return sum(q(t-k*eps)-q(t-(k+p)*eps)
                   for k in range(int((hi+to)/eps)+1))
    return primitive(hi+to)-primitive(hi+bo)-primitive(lo+to)+primitive(lo+bo)
def area(r):
    return (r[1]-r[0])*(r[3]-r[2])
R = (F(1,8), F(12,11), F(1,7), F(5,7))
intersection = (R[0], F(1), R[2], R[3])
unit = (F(0), F(1), F(0), F(1))
base = area(intersection)/area(R)
assert base == F(77,85)
for m in [6,12,24,48]:
    eps = F(1,m)
    low = low_volume(intersection,eps)/area(R)
    err, mean = abs(low-p*base), (5*base-low)/4
    assert low_volume(unit,eps)==p and err<=2*eps/F(1,11) and mean>1
    print(m, err, mean)
```

## 4. 定稿新增的近基准物理源价格与共享负载 (5)–(10)

**结论。** 在 r011、r021、r090 与既有 $Q_N\le C_N\le Q_N\exp(O(L))$ 估计下，定稿 (5)–(10) 均通过。固定效率参数 $K>0$，允许每维换用不同输入。对紧区间层体积的双界需固定 $A<\infty$，移动上层 (10) 仅使用全实轴上的 r090 CDF 界和 (9)。

* 对 $D$ 的指示函数，在一个合格的物理下降重排秩 $a$ 上，r011 的归一化原终端恰为 $1_{S_N>\log(a/|D|)}$，最后一个连续条件增量使端点无原子。若 $a<|D|$ 该指标恒为一，r021 对同一负阈值仍适用。对非紧 $D$ 可先截有界盒，物理严格 halo 与体积取递增极限。CDF 下界接真实的严格成功策略，然后正态逆分位单调性给 (6)。任一样本位置均未被逐点假设有最优反馈效率。
* $P=K+2$ 使 (1) 的例外集相对物理 halo 损失至多 $N^{-2}$。对留下的每个严格成功证据，整矩形高度的 CDF 偏差给 $m_R1_{E_y}\ge\bar\Phi(y/\sigma)-C_Ph$；正文减去多一个 $h$ 将非严格下界改成严格 halo。$|y|\le A$ 时对一段紧内区间取正态逆，误差 $O_{K,A}(h)$。因此将 (6) 用于物理层集合，得 $\log H_N(p)\le\mu N+y\sqrt N+O_{K,A}(N^{1/4}L)$。与同一个 $|G|/J$ 的下界相除给 (5) 下方向。上方向仅用 $\int\Phi(F)\ge\Phi(\lambda_y)|E_y|$ 和一致 Taylor 余项；$\lambda_y>1$ 对固定 $A$ 最终成立。全部常数可统一，未把个别层可行者拼成多个不同源。
* 经过任一严格成功 $x$，可向外移动各面为有理坐标，使 $x$ 落入内部并保留严格平均。枚举后首次满足条件的选择可测，或者取任何矩形端点可测的其他成功选择。Tonelli 给 $\int w=|G|<\infty$，以及 $\int_{E_y}w=\int_Gm_{R(x)}1_{E_y}\,dx$。所有层共享原矩形。紧区间的上下尾均离开 0 和 1，故 (7) 的对应对数商为 $O_A(1)$，两层体积双界之差证明 (8)，若层距缩小则须保留原文误差。
* 灰阶基准 $e=\min(F,1)$ 非零可积且 $S_0\le J$；对 $b=1-d/N-O_K(L^2/N)$，保留矩形的 $m_Re>b$ 来自 r090 的 $m_R(1-F)_+$，不是用原始灰阶零集去代替。$0\le e\le1$ 和 $\Phi(t)/t$ 单调给逐点 $\Phi(e/b)\le e\Phi(1/b)$。$1/b=1+d/N+O_K(L^2/N)$，故 $\log\Phi(1/b)=d+O_K(L^2)$，和 $G$ 的体积下界共同给 (9) 的第一部分。第二部分只需对整个可用帽内的 $\lambda_y$ 做统一 Taylor，充分保留了原模数价格。即便 $\{F>0\}$ 有无限体积，$S_0$ 的定义仍可用。
* 对 $t_N=\sqrt{L/2-4\log L}$，$\phi(t_N)=N^{-1/4}L^2/\sqrt{2\pi}$，Mills 给 $\bar\Phi(t_N)\sim N^{-1/4}L^{3/2}/\sqrt\pi$。因此超出已有 CDF 的绝对误差 $C_K L N^{-1/4}$。所选高层在帽内对充分大 $N$ 成立，且 $|E_{y_N}|>0$。层核质量至少为 $|G|\bar\Phi(t_N)/2$；分母的基准总核质量 $\int we\le |G|$，正性来自 $\int we\ge b|G|>0$。将层体积 (9) 代入，$\log\bar\Phi(t_N)=O(L)$ 被 $O_K(L^2)$ 吸收，得 (10)。$t_N/z\to1/\sqrt2$ 的极限是必要负载之下界，未证明真实最大算子的对数系数变化。

## 5. 独立的一层检验：更靠近帽顶的必要负载

这项推导使用额外的单个变换后物理 halo；它没有被用作定稿 (5)–(10) 的证明依赖。令 $u_N=\sigma\sqrt{L-8\log L}$，$w_N=\sigma/\sqrt L$，$a_N=w_N/(2\sqrt N)$。在标准化高度变量中取坡道 $0\le\psi\le1$，在 $u_N$ 以下为零，在 $u_N+w_N$ 以上为一，中间线性。r090 的核对量 $\nu_s$ 质量为 $1-p_s$。由其 (5)–(6)，在 $s=q_0-DL$、$D$ 固定时，
\[
 b_N:=\int\psi\,d\nu_s\ge \bar\Phi((u_N+w_N)/\sigma)-O_D(L/\sqrt N)
 \ge c N^{-1/2}L^{7/2}.
\]
最后一步用 Mills：$e^{-(u_N/\sigma)^2/2}=N^{-1/2}L^4$，宽度位移只乘常数，分母阈值是 $O(\sqrt L)$。对净化源取 $T(0)=0$、$T(v)=v-a_N\psi(Y(v))$ 于占用高度。它保序且非负（扰动 Lipschitz 常数至多 $1/2$）。由 r090 (5)，$\mathbb ET(W_s(G'))\le1+C_D L^2/N-a_N b_N$，加上 r021 的 $6N^{-4}$ 仍由加大常数支付。只要成功矩形内的 $m_R[1_{F>1}\psi(Y(F))]<b_N/2$，实际 $m_RT(F)>1-a_N b_N/2$，因为 $a_N b_N\gtrsim L^3/N\gg L^2/N$，可用 r090 (4) 在此门槛将所有这种接收点纳入体积 $\le e^sJ$ 的单一可测 halo。对原灰阶源取同一净化序列及该 halo 的 liminf；该坡道只在严格超单位的固定源部位非零，任一原严格成功矩形最终仍成功，因此保持完全相同的费用。原 r090 的好集与此额外好集取交，$D=K+6$ 足以维持 $|G'|\ge(1-O(N^{-2}))Q_N N^{-K}J$。在 $G'$ 的每个成功矩形上
\[
 m_R1_{E_{u_N}}\ge m_R[1_{F>1}\psi(Y(F))]\ge c N^{-1/2}L^{7/2}.
\]
对这个进一步删过微小体积的 $G'$ 选择任意可测成功矩形并形成 $w'$。用定稿 (9) 的原模数价格与 $\int w'e\le |G'|$ 得
\[
 \log\frac{|E_{u_N}|^{-1}\int_{E_{u_N}}w'}{S_0^{-1}\int w'e}
 \ge u_N\sqrt N-O_K(L^2),\qquad
 \liminf \frac1d\log\frac{|E_{u_N}|^{-1}\int_{E_{u_N}}w'}{S_0^{-1}\int w'e}\ge1.
\]
$u_N$ 的高度在临界帽内，因为 $d/\sqrt N=\sigma z\le\sigma\sqrt L$。此外对原先 $G$ 的任意同一选择，其层核质量至少为限制到 $G'$ 的质量，分母仍 $\le |G|$，而 $|G'|/|G|=1-O(N^{-2})$，故这种*积分*负载下界也传回原 $G$。逐矩形的移动尾层断言仅在 $G'$ 上成立。这里只获得一个近极值输入必须实现的物理复用量下界；没有给这项复用量普适的上界。

**最终主式版本复核。** 作者已将本审计 §5 的单尾强化写入 `core91.md` 主式 (10)。现行 (10) 的系数是 $1$；上文 §4 的 $1/\sqrt 2$ 仅对应保留的较低层对照。正文预留 $P=K+2$、r090 异常指数 $P+1$ 及单项测试 $D_*=P+5$，合并后体积费用不超过 $Q_N N^{-P}J$。已逐项复核子概率质量、额外 halo、灰阶 liminf 与对原 $G$ 任意选择转移积分下界，现行版本通过。
