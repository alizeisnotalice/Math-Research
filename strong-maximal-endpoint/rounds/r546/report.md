# 第546轮　固定双条带近一水平集的首项系数

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对第545轮源，逐轴复合的源外近一水平集面积为 $2e\log(1/e)+O(e)$。两个空角各贡献一半，外边界只贡献低阶项。
- 下一步需判断允许平面源随维数变化时能否突破这个固定源的面积阶。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。记 $C=M_yM_x1_E$。在空角 $(x,1+v)$，$0<x,v<1$，水平极大值在下、上条带分别为一和 $1/(1+x)$。从接收纵坐标向下的前缀先经过上条带，再经过更高的下条带，最优端点为零；向上无收益。因此精确有 $1-C=xv/[(1+x)(1+v)]$。另一空角由中心反射得到相同面积。令 $X=x/(1+x),Y=v/(1+v)$，则单角面积为
\[
 \int_{(0,1/2)^2}1_{XY<e}(1-X)^{-2}(1-Y)^{-2}\,dX\,dY.
\]
当 $e<1/4$ 时去掉雅可比的积分为 $e+e\log(1/(4e))$。雅可比与一之差至多常数乘 $X+Y$，且 $\int X1_{XY<e}\le\int_0^{1/2}X(e/X)dX=e/2$，故单角首项为 $e\log(1/e)$。

在包围盒 $[-1,1]\times[0,2]$ 外，若 $C>1-e$，横向距离此盒不得超过 $e/(1-e)$，因为两条水平极大平均均至多 $1/(1+\operatorname{dist}(x,[-1,1]))$。同理纵方向以长二的满区间支配，距离至多 $2e/(1-e)$。外侧薄框面积为 $O(e)$。盒内除源外恰为上述两个角，遂得所述全平面公式。

此外在每个角取第545轮的 $a=e\log^2(1/e)$、$x,v\ge a,xv\le e$ 子区（另一角反射），面积合计 $2e\log(1/e)(1-o(1))$。充分小时 $x,v\le e/a<1/4$，真平均至多 $1-a/3$，复合平均严格超过 $1-e$。故即使要求这一移动真门槛，仍保留全部首项。对 $e=k^{-1/2}$ 的此固定源，近一源外区域无论如何选取，都不能再改善 $-\tfrac12\log k+\log\log k$ 的面积阶。本轮没有对其他平面源作最优性断言。

本机 Python 以单角严格轮廓 $v<e(1+x)/(x-e(1+x))$ 作分段解析积分，并检查归一化首项。
