# 第152轮　重叠见证的行排序冲突

2026-11-12。平衡块和中央严格门槛。两件成功见证均满足第151轮的双向偏差条件时，行秩在共同区域上的逆序概率可由形状误差、相对重叠体积及共同区域的行密度反集中量控制。仅凭固定正重叠比例仍可有固定正比例的逆序。一般系数差仍为 (μ−1)/8。

**共同排序的定量条件。** 取 R_i=X_i×Y_i，重叠 R₀=X₀×Y₀ 有正体积，θ_i=|R₀|/|R_i|。设双向偏差为 η_i，第151轮提供真实行秩排序及按该顺序嵌套的近似集合 T_i，满足 |(E△T_i)∩R_i|/|R_i|≤e_i=2√η_i+η_i。用 R₀ 上归一化测度，写 d(x) 为 E 在共同列 Y₀ 上的行密度，d_i(x) 为 T_i 的相应密度。则 ∫|d_i−d|≤e_i/θ_i；限制到 Y₀ 仍保持各自的行包含次序。两行 x,x' 从 X₀ 独立均匀抽取。若两套排序相反，且 d(x)>d(x')，则至少有一个 i 把密度较大的行排到后面，因而 d_i(x)≤d_i(x')。所以
E[1_{逆序}|d(x)−d(x')|] ≤ 2(e₁/θ₁+e₂/θ₂)。
d(x)<d(x') 时同理，平局的权重为零。因此对任何 t>0，逆序概率≤P(|d(x)−d(x')|≤t)+2(e₁/θ₁+e₂/θ₂)/t。这给出了可直接在原见证重叠上测量的附加条件。例如共同密度律有界密度 K 时第一项至多 2Kt，优化得到 4√(K(e₁/θ₁+e₂/θ₂))。列排序有相同结论。

**固定重叠不能单独支付排序。** 在二维（两块各一维）取 X=[0,1]，Y₁=[0,1]、Y₂=[3/4,7/4]，公共列长 h=1/4。在各列区间分别作保测的分段平移，把公共列以相同顺序送到 [0,h]，各自其余列送到 [h,1]；记所得列坐标 v_i。第一件见证的行坐标 u₁=x，第二件在 0≤x≤1/2 内取 u₂=1/2−x，在其余位置仍为 x。设 0<δ<1/16，在 R_i 内定义源为 u_i+v_i<1+δ。在公共列上，前半行全部命中，其余行映射相同，所以两种定义相容，确实给同一个可测源。其他坐标若需升维，可乘独立单位盒并保持分块等维。

每件矩形的严格 1/2 命中余量为 δ−δ²/2，真实接收并面积为 7/4（两件所列见证之并）。源面积为 2(1/2+δ−δ²/2)−[h−(h−δ)²/2]。两方向密度重排同为单位方形中 u+v<1+δ 的下集（边界原子不影响面积），相对等块中央目标 u+v<1 的偏差均为 δ−δ²/2。对 x∈[1/8,3/8]，两个全见证行密度分别为 1+δ−x 与 1+δ−(1/2−x)，均严格单调且方向相反。故任取该区间两个不同行必逆序，整体独立抽样的逆序概率至少 1/16，与 δ 无关。相同两行在共同列上却都是满行，d(x)−d(x')=0。这解释了为什么有权冲突能趋零，而未加权逆序不必趋零。此例未宣称全空间 halo 近极值。
