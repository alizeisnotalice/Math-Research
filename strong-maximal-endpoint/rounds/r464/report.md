# 第464轮　中央规模下外部叶支持仍可分成任意多组

- A 覆盖全部等权深度轮廓，中央误差有界。
- 以两个附加坐标复制一般见证目录，保持其体积比至绝对常数，并产生任意多个等权、外部叶支持互不相交的组。
- 下一步应估计组内几何；单靠中央规模不能保证少量根覆盖固定比例的外部接收。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。给定 $k$ 维有限严格成功目录 $B_j$、有限正体积源 $G$，记 $U=\bigcup B_j$。按第366轮以参数 $t$ 先在该目录取贪心根 $Q$。在附加平面取第463轮的 $N$ 个根 $P_i$ 与窄叶 $R_i$，令 $D=\bigcup_i(P_i\cup R_i)$。取共同源 $E=D\times G$，实际目录仅含 $P_i\times Q$ 与 $R_i\times B_j$。所有行在同一门槛严格成功，因为平面因子完全包含于 $D$。

**实际归并。** 产品根之间若平面标签不同则两方向伸长均超过 $t$；同标签时，相交的不同 $Q$ 已两两分离。每个 $B_j$ 有相交的基底根 $Q$ 满足 $|Q|\ge|B_j|$、$d(B_j,Q)\le t$（根可取自身）。于是 $P_i\times Q$ 严格大于对应产品叶的体积，且相交；平面叶各轴均短于平面根。按体积递减归纳，所有产品根均保留、所有产品叶均被同平面标签的根归并。与哪个合格的同标签根匹配不影响结论。叶在自身根内的源平均至多 $h/(h+1/4)$，可任意小。

**结算。** 每个平面标签都有 $(R_i\setminus P_i)\times U$ 的专属接收区，体积 $|U|/16$，且该标签全部叶位于 $R_i\times U$。源体积至多 $(17N/16)|G|$，故专属接收区总量除以源体积至少为 $|U|/(17|G|)$。根接收区之并位于 $(\bigcup P_i)\times U$，全接收体积至多 $(17N/16)|U|$，故专属区至少占全接收的 $1/17$。任取 $s$ 个产品根，其所属外部叶只覆盖至多 $s/N$ 的专属接收区，亦只触及至多 $s$ 个平面标签的叶源。此处不主张每个平面标签只含一个产品根。
