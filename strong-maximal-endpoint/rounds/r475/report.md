# 第475轮　双截断递推的曲率抵消与中央点余量

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对中央高斯包络，第474轮试用截断的单步对数余量一致为 $O_I(1/k)$；在 $p=1/2$ 上首个非零余量严格为负。
- 下一步需控制离开中央点的二次分位数项并结算跨维传播和初始化。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。写 $z=\Phi^{-1}(1-p)$，$h=\sigma\sqrt k$，$s=h/\phi(z)$。以第474轮试值 $a=p-\mu/s$ 作用于 $e^{B_k}$。在 $v=s(q-p)$ 坐标下，提出主倍率后的积分权重为概率密度
\[
 (1_{v\ge-\mu}+1_{v\ge0})e^{-v}/(1+e^\mu).
\]
等价于 $V=X-\mu D$，$X$ 为均值一的指数变量，独立的 $D$ 为成功概率 $1/\mu$ 的伯努利变量（因 $1+e^{-\mu}=\mu$）。故 $EV=0$，$EV^2=\mu$，$EV^3=3\mu-\mu^2$。分位数求导给
\[
 B_k(p+v/s)-B_k(p)=-v+zv^2/(2h)-(1+2z^2)v^3/(6h^2)+O_I(v^4/h^3).
\]
因此积分取对数并减去 $B_{k+1}(p)$ 后得到
\[
 h^{-2}\left[-(1+2z^2)EV^3/6+z^2\operatorname{Var}(V^2)/8\right]+O_I(h^{-3}).
\]
确实一阶项为 $z\mu/(2h)$，正等于基线维数增量扣除 $\mu$ 后的一阶项，因为 $\sigma^2=\mu$。余项可先限 $v\le h^{1/8}$，以指数权积分 Taylor 多项式及其多项式余项；更远处至稍大紧区间右端由统一负斜率给指数尾，右端外用单调性。对于仅在稍大紧区间成立的包络，可在其右端以常数延拓作上界，所得展开相同。作用于真实 halo 时，公式是代入包络后的上界，并须加上原有对数误差。

特别地在中央点余量为 $-(3-\mu)/(6k)+O(k^{-3/2})$。这说明直接丢掉全部 $1/k$ 项会忽略有利符号，但仅在一个门槛上的负余量不能用于整个积分递推的归纳。此处尚未优化截断的次阶移动。

本机 Python 以显式指数矩及二项展开核对前三矩。
