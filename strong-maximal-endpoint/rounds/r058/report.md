# 第58轮：校正系数的衰减界与高阶共享反例的 Orlicz 价格

日期：2026-11-07。状态：严格局部系数定理、固定反例族成本定理及512/1024维本机计算完成独立审查。一般C_N对数级区间与认证下界未变。统一Phi_N(t)=t(1+log^+t)^(N-1)。

## 1. 从裸导数相减改为完整响应表示

冻结单接收、等双块、目标1、cap2的正则共同驻点源H0。沿用第57轮G(d,v,a)及径向校正K，令k_-=k1−k2、s_+=s1+s2、s_t,-=partial_t1 s1−partial_t2 s2。一次分部积分给
\[
G_{avv}=-B(k_-,s_{t,-}+s_+k_-),\qquad
\boxed{K=-B(k_-,s_{t,-}+(s_+-\beta)k_-)},
\]
其中beta=B(k1+k2,s_+)/B(1,k1+k2)。B始终包含下端跳跃coarea和soft两部分。这避免用两个较大数的差分相减来理解K，也说明仅控制score的Fisher矩不足以控制该系数。

## 2. 严格局部系数界

在全正象限、N=2b、|c−mu|<=C0 sqrt(logN/N)、上述精确驻点与正则性条件下，令L=logN，本轮证明
\[
\boxed{|K|=O_{C_0}(L^3/N^2),\qquad
\left|\frac{K^2}{8G_{aa}G_d}\right|=O_{C_0}(L^6/N^3).}
\]
所需新增步骤是将概率尾估计正确转移到响应测度，而非忽略下端层。具体包括：

- 紧倾斜C1桥给中偏差带上的|k_i−1|、|s_it|=O(sqrt(L/N))；
- 条件Gamma逆矩与移位Gamma密度峰值给1、k、k²、|s_t|、k|s_t|这份有限权重清单的coarea尾控制；
- Ward和第57轮pi0界给r=λ/P至少cN/L，故B00=O(L/N)，beta=O(L)；
- 中央响应被积函数为O(L²/N)，积分即得K界；Gaa<=−p_mu/4、Gd>=1/N给四阶系数界。

另有径向二阶系数d2=O(L/N)。[proof58.md](proof58.md)给出完整有限权重尾论证、混合位置导数及适用范围。

这是系数定理。把v取到sqrtN时，形式四阶项虽只有O(L6/N)，Taylor/隐函数余项尚无统一控制，不能由此宣布整个冻结输入机制受阻，更不能推出一般C_N的对数项。

## 4. 固定阶反例达到目标损失尺度的成本

第57轮给出了有界M纤维反例：R_J=delta/M²>0而k<M时Delta_k=0。本轮将它嵌入N维，并按实际Phi_N核算，而不是保留Phi2分母。其精确归一化成本为
\[
\mathcal B_N=\frac{J_N}{M^2}
=1-\frac\delta{M^2}+\frac{M-1}{M^2}
 \{\Phi_N(1+\delta)-(1+\delta)\}.
\]
0<delta<=1/2时，严格有
\[
\boxed{R_J\le\frac9{4(N-1)M^2}\log(1+2M\mathcal B_N).}
\]
若R_J至少kappa(logN)²/N，则对充分大N，
\[
\boxed{\log\mathcal B_N\ge
\frac{2\kappa}{9}M^2(\log N)^2-\log(4M).}
\]
所以该特定反例族若达到这一反馈点值比较尺度，其归一化成本超过任意固定多项式预算。例：M2、delta=4(logN)²/N，N1024时log归一化成本约161.147。

[budget58.md](budget58.md)包括实际N维输入、精确格点成本及完整证明。本结论仅约束这一固定外区间反例族，不说明所有高秩输入都昂贵，也未证明任何危险输入必须满足多项式归一化预算或有限Helly秩；全局外区间逃逸仍须另外处理。
