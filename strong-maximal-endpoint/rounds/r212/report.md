# 第212轮　实际源边际平方根项的锐性与密度极限律

2026-11-12。对每个固定 \(0<p<1\)，存在实际有限双曲十字源、有限严格成功盒族及不交接收归属，\(\log(|U|/|E|)=B_n(p)+O_p(1)\)，使
\[
 \frac{\log(|E|f_X(X))}{\sigma\sqrt n}\Rightarrow (G-u\mid G>u),\qquad
 \frac{D(P_X\Vert\mathrm{Unif}(E))}{\sigma\sqrt n}\longrightarrow\varphi(u)/p-u.
\]
其中 \(G\) 标准正态、\(u=\bar\Phi^{-1}(p),\sigma=\sqrt\mu\)。因而[第211轮](../r211/report.md)的一般上界在平方根阶的整个系数上可达。未确定对数阶余项。

**物理见证与源深度。** 取 \(L(y)=\sum_i-\log|y_i|\)，\(E=\{y\in[-1,1]^n:L(y)>T\}\)，\(T=n^4\)。沿用[第182轮](../r182/report.md)的共同最优侧比 \(r=e^{-\mu}=\mu-1\)。在接收点 \(y\) 处按各轴符号反射区间 \([-r|y_i|,|y_i|]\)。盒内均匀样本的深度为 \(L(y)+S_n\)，其中 \(S_n\) 为独立同分布增量之和。每轴增量等于独立单位指数加上 \(\mu\) 乘一个成功率 \(r/(1+r)\) 的 Bernoulli 位（按所选正负半轴条件化）。所以均值及方差均为 \(\mu\)。令 \(a_n\) 为严格上尾概率等于 \(p\) 的分位；[第111轮](../r111/central-cross111.md)给 \(a_n=\mu n+\sigma\sqrt n\,u+O_p(1)\)。动作严格成功的内部接收区为 \(D=\{L(y)>T-a_n\}\cap[-1,1]^n\)，每件动作盒自身也在 \(D\) 内（坐标绝对值只会缩小）。

均匀立方体深度的尾为 \(e^{-t}P_{n-1}(t)\)，\(P_{n-1}(t)=\sum_{j=0}^{n-1}t^j/j!\)。当 \(t>0\)，有 \(0\le(\log P_{n-1})'(t)\le(n-1)/t\)。因此 \(\log(|D|/|E|)=a_n+o(1)\)；在均匀 \(Y\in D\) 下，\(L(Y)-(T-a_n)=O_P(1)\)，其尾至多 \(e^{-v(1-(n-1)/(T-a_n))}\)。这些界对所选有限深度直接成立。

在该接收点的动作盒内均匀抽源样本，就是将 \(S_n\) 条件于 \(S_n>T-L(Y)\)。给定 \(Y\)，深源子集 \(F_z=\{x\in[-1,1]^n:L(x)>T+\sigma\sqrt n z\}\) 的入选概率，对 \(z\ge0\) 为
\[
 \Pr(S_n>T-L(Y)+\sigma\sqrt n z)/\Pr(S_n>T-L(Y)).
\]
分母至少为 \(p\)。由中心极限定理及连续极限分布，取平均得 \(P_X(F_z)\to\bar\Phi(u+z)/p\)。而 \(\log(|F_z|/|E|)=-\sigma\sqrt n z+o(1)\)，由同一多项式导数界可见。

**落实到有限族。** 对固定 \(n,T\) 在每个正交象限以二进制网格向上舍入接收点各轴绝对值到顶点 \(v\)。顶点在 \(D\) 的单元用该顶点的动作盒负责，单元被盒包含（忽略零测边界），盒本身包含于 \(D\)。取这些有限盒的完整并，未被上述单元负责的余点按固定次序归属给含它的盒。网格趋细时好单元在 \(D\) 内的体积分数趋 1，因为几乎处处的严格内点最终有合格顶点。顶点深度趋于样本深度，上述概率比式由 \(S_n\) 的连续密度及支配收敛趋回连续归属的平均。依次选足够细网格，使体积相对误差及对前 \(n\) 个枚举的非负有理 \(z\) 的概率误差均小于 \(1/n\)。由单调性与极限尾连续性，上述深源结论在真实有限族上对所有固定 \(z\ge0\) 成立。所需网格可能极细；这里使用解析存在性，不以有限模拟替代此极限。

**从深源层到真正的似然比。** 令 \(Z_n=\log(|E|f_X(X))/(\sigma\sqrt n)\)。对任意 \(z>0,\epsilon>0\)，在 \(F_{z+\epsilon}\) 上且 \(Z_n\le z\) 的实际概率至多为 \(e^{\sigma\sqrt n z}|F_{z+\epsilon}|/|E|=o(1)\)。由深源层概率、再令 \(\epsilon\downarrow0\) 得 \(\liminf\Pr(Z_n>z)\ge\bar\Phi(u+z)/p\)。反向用第211轮的中尾估计，在 \(t=\sigma\sqrt n z\) 处其门槛为 \(2n^{-4}+\bar\Phi(u+(t-A\log n)/(\sigma\sqrt{n+t_0}))\)，得相同上极限。令 \(z\downarrow0\) 也排除了留在非正半轴的极限质量。于是得到所述分布收敛。对正尾应用 Fatou，未缩放对数似然负部的实际期望至多 \(1/e\)（在源均匀概率下积分 \((-v\log v)_+\)）。故 KL 系数的下极限至少为截断正态的平均超额；第211轮给匹配的上极限。

一般端点系数差仍为 \((\mu-1)/8\)。任何将实际源边际偏差一概压为 \(o(\sqrt n)\) 的步骤都会漏掉这一近中央源。下一步应在第210轮的熵恒等式中把该项与同一批见证的反向 KL 联合估计，而不能分别强行削去其平方根项。
