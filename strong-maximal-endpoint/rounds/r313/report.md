# 第313轮　任意中央近极值源含有抗条件乘积逼近的子集

2026-11-12。固定中央紧区间 $I$ 与 $K\ge0$。设 $p\in I$，$E\subset\mathbb R^n$ 有限正测度，实际对数超额 $r=\log(|\{M_S1_E>p\}|/|E|)-B_n(p)\ge-K\log n$。取 $1\le k\le n$ 且 $k^2/(n\log n)\to\infty$。存在可测 $R\subset E$、门槛 $q\le p$，满足
\[
 |R|/|E|\ge n^{-C_{I,K}},\quad
 \sqrt n(p-q)=o(1),\quad
 \log\frac{|\{M_S1_R>q\}|}{|R|}-B_n(q)
 \ge r+\log(|E|/|R|)-o(1).
\]
此外存在绝对 $a,c>0$，令 $\theta=\exp(-ak^2/(2n))$。对任意 $P$，只要在某组 $k$ 条轴上具有第312轮的条件乘积截面且 $|P|\le e^{ck/2}|R|$，就有 $|P\cap R|<\theta |R|$。这里量词同时涉及全部轴组和全部可测截面因子，无须预先指定有限菜单。

**按实际覆盖率剥离。** $a,c$ 取[第312轮](../r312/report.md)的低门槛常数，$\delta=e^{-ak^2/n}=\theta^2$。从 $R_0=E$ 出发。若当前剩余源 $R_i$ 有满足体积预算且覆盖比例至少 $\theta$ 的候选 $P_i$，取任意一个并令 $R_{i+1}=R_i\setminus P_i$；若没有，即停止。记 $q_i=p-i\delta$、$V_i=|\{M_S1_{R_i}>q_i\}|$。对下面考虑的步数 $q_i$ 都在稍大的固定中央紧区间。次可加性与第312轮的结构项界给
\[
 V_{i+1}\ge V_i-|\{M_S1_{P_i}>\delta\}|
 \ge V_i-e^{B_n(p)}e^{-ck/2}|R_i|.
\]
此处低门槛估计从始至终用原来的 $p$ 结算，避免逐步累乘常数。每次覆盖使 $|R_i|\le(1-\theta)^i|E|$，故所有步的接收体积总损失至多 $|E|e^{B_n(p)} e^{-ck/2}/\theta=o(V_0)$。为保证最后的小量，可先缩小 $a$：减小 $a$ 提高结构部分的测试门槛，低门槛上界仍成立；取 $a<c/2$，用 $k^2/n\le k$ 及 $r\ge-K\log n$。对任一已到达的步数均有 $V_i\ge(1-o(1))V_0$。

**为何一定停止。** 选固定 $M>C_J+K+3$，其中 $C_J$ 为稍大中央区间上一般指标粗界的对数系数（见[第110轮](../r110/central110.md)）。拟作 $N=\lceil M\log n/\theta\rceil$ 步。总门槛移动至多 $N\delta=O(\theta\log n)$；由 $k^2/(n\log n)\to\infty$ 可知 $\sqrt n N\delta=o(1)$。故 $B_n(q_i)-B_n(p)=o(1)$。如果剥离能做满 $N$ 步，则 $|R_N|\le n^{-M}|E|$，一般粗界给 $V_N\le n^{C_J-M}e^{B_n(p)+o(1)}|E|$，与上段保留的体积矛盾。于是存在停止步 $j<N$。同一粗界对 $R_j$ 给 $|R_j|/|E|\ge (1-o(1))e^r n^{-C_J}$。取 $R=R_j,q=q_j$，并用保留下来的实际接收体积即得全部断言。

**对闭合问题的归约。** 若一般中央准则存在正对数系数反例，同维数上也存在上述所有条件乘积候选均只能捕获极小比例的反例，原正系数保留。取 $k=n$ 时尤其排除了体积至多 $e^{cn/2}|R|$、捕获比例至少 $e^{-an/2}$ 的任意可测笛卡尔积。该陈述针对抽出的子集，门槛移动可以随源改变；未证明每个原源都满足排斥性质。一般端点系数差仍为 $(\mu-1)/8$。下一步应检验这种排斥性质能否约束真实成功矩形中的源质量分配，并用已知中央基线族衡量其强度。
