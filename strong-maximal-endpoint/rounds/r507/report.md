# 第507轮　中央规模下典型接收点的逐见证源块分散

- A 覆盖全部等权深度轮廓，中央误差有界。
- 把矩形表示的全局块数障碍加强为逐见证的命中分散：除指数小的接收份额，经过同一点的所有成功矩形都必须从指数多个源块取得命中。
- 下一步须利用这些小块处于同一真实见证内的相对位置，或比较不同见证的源块分布。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。设 $E=\bigcup_j Q_j$ 为有限矩形并，$D=\sum_j|Q_j|/|E|$。规定任一可测不交归属 $E_j\subset Q_j$ 覆盖 $E$。在一个严格 $p$ 成功的见证 $T$ 内，令 $w_j(T)=|T\cap E_j|/|T\cap E|$，为真实命中的标签分布。若 $w_j(T)>e^{-nx}$，则整个见证都在 $Q_j$ 的门槛 $p e^{-nx}$ 的 halo 中。故所有此类见证之并 $U_{bad}$ 满足
\[
 |U_{bad}|\le D |E|\exp\{nR(x+n^{-1}\log(1/p))\}.
\]
这里可直接用全部 $Q_j$ 的单盒 halo 之并作为可测例外集，从而界对一切成功见证同时成立。第506轮的 $R$ 给出准确的单盒指数。假设 $V/|E|\ge e^{\mu n-o(n)}$，$\log D=o(n)$ 且 $p$ 在固定中央区间。任取固定 $0<x<R^{-1}(\mu)$，则例外接收份额至多 $\exp[-(\mu-R(x))n+o(n)]$。

例外集外，经过该点的每个成功见证对任意 $k$ 个标签的总命中比例都至多 $ke^{-nx}$。尤其若 $y<x$，即使按每个见证自身的命中量选取最大的 $\lfloor e^{ny}\rfloor$ 块，也只能支付指数小的比例。两次独立按真实命中抽源点落入同块的概率 $\sum_j w_j^2\le e^{-nx}$，且 $-\sum_j w_j\log w_j\ge nx$。这些结论是逐见证的，不需指定负责区域或失败混合。它仍允许很多邻接小块拼成简单区域；因而无法单靠此标签熵得出端点改进。若相互重叠的源块有任意归属，例外集的单盒定义甚至与归属无关。

本机 Python 有理数核验：对非均匀权重 $(1,2,3,4)/10$，检查碰撞概率与前两大标签质量上界。
