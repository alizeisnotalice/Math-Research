# 第163轮　列侧公共交叠的单次计费

2026-11-12。平衡分块、任意固定中央紧区间 I。设各行因子 F_i 两两不交，列因子 G_i 可交。若存在列集 C，使 G_i∖C 两两不交，且公共外包 P=(∪F_i)×C 满足 |P|≤n^K|E|（K 固定），则 E=∪F_i×G_i 的真实严格中央上界有固定 √n 阶余量，常数不依赖分量总数。C 内的各分支可有不同的列子集，无需整个公共区域已被源填满。一般系数差仍为 (μ−1)/8。

**精确冲突公式。** 在一件成功矩形内，记行占比 a_i，列占比 b_i，列交叠占比 b_ij。第157轮的四点冲突概率恰为 Σ_{i,j} a_i a_j(b_i−b_ij)(b_j−b_ij)。条件于两行标签后，每个交叉失败要求各自的列命中一个单侧差集，两列抽样独立；不属于任何标签的行不产生冲突。特别地，在一个列集 C 以外，若不同标签的剩余列互斥，记 r_i 为该见证在 F_i×(G_i∖C) 中的密度，l=Σr_i，那么 K_conf≥l²−Σr_i²。不必用外包取代源来计算这个概率，两列都不在 C 时交叉点也都不在 C。

**支付缺失公共行列。** 忽略 C 外除最大命中标签 j 以外的部分，损失至多 √K_conf，由上式及 l≥l−max r_i 得。保留的全部真实源点可用 P 和 Q_j=F_j×(C∪G_j) 包含。它们在行侧逆向于列侧嵌套，且这两个乘积之并在原矩形中密度大于 p−δ，只要 √K_conf<δ；没有对外包假设形状稳定。用第150、151轮先在原源上排除偏差≥η 的见证，留下 K_conf≤4(2√η+η)，可取固定 η 充分小。沿用第161轮两象限截线论证，对 p−δ 的联合命中找到一个低角点，在第91轮固定紧门槛网格上以 B_n(p)−c√n 的秩估计相应真实 halo 乘积。参数先按 I 和块比例定截线缺口，再定 δ、η，与源价格无关。

所有选到 P 的见证共用同一笔网格价格。对 Q_j，按行互斥性有 Σ|Q_j|=|P|+Σ|F_j||G_j∖C|≤|P|+|E|。于是总价至多 |E|+2|P|，相对源分母至多 1+2n^K，吸收其对数后仍保有平方根余量。如果 C 为空就直接用互斥簇结果；只有一个非空分量时用乘积定理。退化的零体积因子先删除。对于给定有限列集族，最小的强制公共区（按零测等价）恰为列重数至少二的点集：其中每一点若不剔除便同时属于一对剩余列。可数情形同理。故条件可直接按实际重叠计算。

**与不分支外包的区别。** 将行分成 M 个长度为 1 的岛。前 M−1 个标签的私有列长 1，末标签私有列长 M，全部互不交；另设 C 长 1，并给每个标签分配 C 中 [0,1/2] 或 [1/2,1]（两种各至少两次），不增加私有列间交叠。真实源量 d=(M−1)+M+M/2，公共外包价格 M，接收预算与 M 无关；整个单乘积外包相对价格为 M(2M)/d，可任意大。该例在允许门槛上直接由新定理覆盖，不以标签数计费。进一步取两个分支、两列各长 1 且交长 1/2，在包含所有行列的整矩形（两等宽行）上有 a₁=a₂=1/2、b₁=b₂=2/3、b₁₂=1/3，真实密度 2/3，p=1/2 时严格余量 1/6。冲突为 1/18，若完全忽略共享列则错误地给出 2/9。取两行各宽 1，真实源面积 2，整见证接收面积 3。
