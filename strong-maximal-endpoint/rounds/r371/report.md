# 第371轮　一次真实命中下同时抽取指数多个双向远见证

- A 已覆盖全部等权可测深度轮廓，误差有界。
- 近中央目录在实际命中点条件下可同时抽取指数多个见证，所有盒含同一个源点且以指数高概率两两双向远。无需先删盒。
- 尚需估计这些随机共同交集在实际命中分布下的几何约束。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第364、370轮记号。对原盒均匀抽样并条件于命中 $E$，命中点密度为 $1_E Z/T$，其中 $Z(y)=\sum w_i1_{R_i}(y)$，$T=\int_E Z>p|U|$。固定命中点后独立按 $w_i1_{R_i}/Z$ 抽两个标签。设 $F(y)$ 为有序双标签的未归一化近边权和（含对角线），近指 $\min(d(i,j),d(j,i))\le n/400$。第370轮的定向估计给出
\[
 \int_E F\le(1+2D)|U|,\qquad D=\exp[n(\log3+1/400+2/20)].
\]
点态还有 $F\le Z^2$。因此直接用 Cauchy–Schwarz，
\[
 \Pr(\text{近})=T^{-1}\int_{E\cap\{Z>0\}}F/Z
 \le T^{-1}\int_E\sqrt F
 \le p^{-1}\sqrt{(1+2D)e^{-H}}.
\]
分母是实际命中质量，此步无需假设源上处处具有高重数。若 $H\ge B_n(p)-O_I(1)$，右端至多 $\exp(-0.0386761n+O_I(\sqrt n))$（系数向下舍入）。

特别地，给定同一命中点，独立抽 $k=\lfloor e^{0.01n}\rfloor$ 个后验标签。对所有标签对求并界，至少 $1-\exp(-0.0186761n+O_I(\sqrt n))$ 的联合概率下，它们互异、两两双向远，并且全部见证含该点。再对条件失败概率用 Markov，除去命中概率指数小的一批源点，逐点条件失败概率亦指数小（指数减半）。此处源点按命中律加权；并未得到均匀源点的同等结论。下一步可检验从这样的盒族再独立抽第二个命中点时，能否同时维持高阶交叠，以及所得衰减如何对冲接收体积。
