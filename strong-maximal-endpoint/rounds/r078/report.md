# 第78轮：同角点分数覆盖无损合并与跨角点的完整定价

日期：2026-11-08。状态：证明同角点的真实分数源覆盖可无损合并，含可数列和全接收集合；认证一个跨角点有限族的严格分数优势，并解析证明新增自然角点使差距消失。一般锐上界仍未闭合。

## 1. 同角点的分数合并已闭合

统一Φ_N(t)=t(1+log⁺t)^(N−1)，J(G)=∫Φ_N(G)，0≤G≤F≤2。固定一个物理角点a。设可数个真实源列G_k≤F，权重w_k≥0，且对每个目标接收点x，

\[
 W(x)=\sum_{k:H_aG_k(x)>1}w_k\ge1.
\]

无需网格、源的分片常值性或有限接收集，定义

\[
 \boxed{
 h=\min\!\left\{\Phi_N(F),\sum_kw_k\Phi_N(G_k)\right\},
 \qquad G=\Phi_N^{-1}(h).
 }
\]

则0≤G≤F，整个目标集合仍满足H_aG>1，且

\[
 \boxed{J(G)\le\sum_kw_kJ(G_k).}
\]

证明：固定x，若W(x)<∞，将其成功列作归一平均A_x。A_x≤F，Jensen及W(x)≥1给Φ_N(A_x)≤h，所以G≥A_x；所有列在同一个矩形[a,x]上严格成功，其平均也严格成功。W(x)=∞时取有限子列、总权重≥1，论证相同。非负级数、Tonelli及单调收敛处理可数情形。

Φ_N在[0,1]上线性、在t>1上二阶导数为

\[
 \Phi_N''(t)=\frac{(N-1)(N-1+\log t)(1+\log t)^{N-3}}t>0,
\]

且一处右导数N≥左导数1，因此上述凸性与逆函数合法。

固定角点的列成本c_a(S)因此满足**分数次可加性**；同一角点的完整合法分数覆盖最优值等于单个共同源的最优值。这比r077的整数max合并更强。它不声称次模性，也不允许把不同角点的不同矩形直接当作同一个约束。[全列框架及一般接收集合证明](columns78.md)，[独立推导和边界审查](structure78.md)。

## 2. 合法全列覆盖及证书

有限角点列表和有限接收小格下，c_a(S)是一个真实源在角点a、阈值σ>1成功覆盖全部S的最小Orlicz成本。r077的网格归约使其成为精确有限凸规划。对每个非空可行S建立一列：

\[
 V_{\mathrm{frac}}=\min\sum_{a,S}w_{aS}c_a(S),\qquad
 \sum_{a,S\ni P}w_{aS}\ge1,\quad w_{aS}\ge0.
\]

列源保持真实成功，权重只线性收费；于是|E|≤K_N∑wJ(G)，K_N是固定角点的cap2 Hardy常数。同角点全部方向无需额外2^N因子。

全列对偶要求y_P≥0且∑_{P∈S}y_P≤c_a(S)对**每一个**可行(a,S)成立。只检查部分定价列不提供全列下界。本轮所有有限族都穷举可行子集，用有理内层成本下界认证每一条对偶约束；覆盖权重和实际源给有理上界。整数最优用全部列的bitmask动态规划作上下包围。

若只有k个角点，同角点合并还给整数分配≤k倍合法分数分配：每个小格至少有一个角点累计权重≥1/k，在该角点将权重乘k后合并。这个k可能随维数增长，不是一般锐上界。

## 3. 真正的跨角点分数优势：解析三角实例

取

\[
 Q=[-9/10,-1/10]^2,\quad F=(25/16)1_Q,\quad |Q|=16/25,
 \quad \int F=1,\quad \sigma=1+10^{-8}.
\]

三个接收小格为中心p1=(0,2/1000)、p2=(1/1000,21/20000)、p3=(2/1000,0)，半径10⁻⁷的开放方格。三个角点a_j=(-h_j1,-h_j2)，其中

\[
 h_1=(21/20,(1-2077/10^6)/(21/20)),\quad
 h_2=(1,1-2025/10^6),\quad
 h_3=((1-2075/10^6)/(21/20),21/20).
\]

所有矩形都包含Q。精确有理体积检验表明，角点j恰可覆盖另外两个小格；在第j个小格上，甚至F自身的平均也低于1。任意可行非空S的列价可解析计算：

\[
 M_{j,S}=\sigma\max_{i\in S}
 (h_{j1}+p_{i1}+10^{-7})(h_{j2}+p_{i2}+10^{-7}),
 \qquad
 c_j(S)=M_{j,S}\!\left[1+\log\frac{M_{j,S}}{16/25}\right].
\]

因为所有矩形见到同一源质量，Jensen的常值源恰达到这个价格。三个角点共9个可行列，无遗漏。

半权选择三个双格列，覆盖全部小格。由三对价格构造的对偶λ_i=(c_ij+c_ik−c_jk)/2逐条认证可行，因此分数最优精确等于这三个双格价格和的一半。整数最优由完整动态规划包围。认证得到

\[
 \boxed{
 1.3331609908
 <\frac{V_{\mathrm{int}}}{V_{\mathrm{frac}}}
 <1.3331609909.
 }
\]

这里是实际严格成功列、实际Orlicz成本和整个开放小格，并非r077的裸阈值缩放。它只针对**给定三个角点**，不是一般C_N的改进。

再加入自然角点a0=(-9/10,-9/10)，完整列表增至16列。其最坏体积在P2；该角点覆盖全部三格的价格c0恰等于只覆盖P2的价格。其他任何覆盖P2的列，其必需质量都≥这列。把对偶价格c0全部放在P2，与a0的全覆盖列形成同价原始/对偶证书，故

\[
 V_{\mathrm{int}}=V_{\mathrm{frac}}=c_0
\]

**精确成立**。这说明角点列表不完整会制造一个随后消失的分数组合优势。[三角实例完整证明](triangle78.md)。

## 4. 合并公式不能直接跨角点使用

这个限制也有同方向的实际源反例。令N≥2，

\[
 \varepsilon=\frac1{8N},\ t=1+\varepsilon,\
 \delta=\varepsilon/4,\ h=\varepsilon^2/(64N).
\]

两个不交源盒是

\[
 A=[-1,-\delta]\times[-\delta,0]\times[-1,0]^{N-2},\quad
 B=[-\delta,0]\times[-1,-\delta]\times[-1,0]^{N-2}.
\]

取G1=t1_A、G2=t1_B、F=G1+G2及各自负角点a1、a2。两列在E=(0,h)^N都使用相同的正向矩形，实际平均至少

\[
 \frac{t(1-\delta)}{(1+h)^{N-1}(1+h/\delta)}
 \ge1+\varepsilon/3.
\]

半权Orlicz合并却在A∪B上仅有高度

\[
 q=\Phi_N(t)/2\le e^{1/8}/2<1.
\]

由于q在Φ的线性段，逆函数后仍为q，整个强极大halo为空；同时成本仍等于半权列成本和。故第1节的同角点条件不能去掉，即使方向相同。

本例只否定这个合并公式的跨角点移植；它不证明整数/分数最优有差距，不是高效临界族或一般上界的反例。
