# 第198轮　重新划分共点族不能普遍消除条件标签熵

2026-11-12。对每个 \(n\ge2\)，构造每轴仅有一种边长的严格成功盒族、同一个有限指标源和明确的接收分配，使**每一种**将原盒归入共点族的标签 \(C\) 都满足
\[
 H(C\mid X)\ge \tfrac4{15}[2H_2(1/4)-\log2]n\approx0.115073n.
\]
这里 \(X\) 服从[第197轮](../r197/report.md)实际接收面积加权的源抽样律，\(H_2\) 用自然对数。此系数超过该轮可支付的 \(\mu-\log(24/7)\)。不同轴联合编码或任意增加标签数均不改变下界。

**严格平均、分母与接收概率。** 每轴取三个单位区间 \(I_0=[0,1],I_1=[3/5,8/5],I_2=[6/5,11/5]\)，原盒族取所有乘积。其并 \(U=[0,11/5]^n\)。源取 \(E=\{x\in U:\{5\sum_i x_i\}<1/2\}\)，花括号表示小数部分。任一坐标沿上述单位区间或沿整个并区间积分时均跨整数个周期，故 \(|E|=|U|/2\)，每盒平均恰为 \(1/2>p=1/3\)。将每轴按位置依次三等分，各归给对应编号的区间；三段长均为 \(11/15\) 且各自被负责区间包含。因此由均匀接收点确定的负责盒标签向量 \(R\) 为独立均匀三元位。给定 \(R\)，从 \(E\cap R\) 均匀取 \(X\)，其密度是 \(2\mathbf1_E\prod_i\mathbf1_{I_{R_i}}\)。给定 \(X\) 后，原标签各位条件独立，各自在覆盖 \(X_i\) 的区间中等概率。并且给定整个 \(R\)，\(X_i\) 在自身区间上均匀，因为至少有一条其他轴可以积掉周期因子。这两个性质同时保留下来，尽管给定盒的源采样具有跨轴约束。

**任何共点归类都须泄露至少这么多标签信息。** 因 \(I_0\cap I_2=\varnothing\)，任何共点族在每轴上不能既含标签 0 又含标签 2。由 \(C\) 定义二元变量 \(Z_i\)：若该族第 \(i\) 轴含标签 2 则取 1，否则取 0。这样 \(R_i=0\) 必给 0，\(R_i=2\) 必给 1，而 \(R_i=1\) 时允许任意偏置 \(t_i=\Pr(Z_i=1\mid R_i=1)\)。由上段的单轴均匀性，给定 \(R_i\) 时 \(Z_i\) 与 \(X_i\) 独立。条件独立的后验与熵次可加性给
\[
 H(C\mid X)=I(R;C\mid X)\ge
 \sum_i[H(R_i\mid X_i)-H(R_i\mid Z_i,X_i)] .
\]
在左侧二重覆盖段 \(I_0\cap I_1\) 及右侧二重覆盖段 \(I_1\cap I_2\)，\(X_i\) 各以概率 \(4/15\) 落入，区间编号各有两个等可能值。在单覆盖段编号已知。因此第 \(i\) 个互信息等于
\[
 \tfrac4{15}[H_2(t_i/2)+H_2((1+t_i)/2)-H_2(t_i)] .
\]
它关于 \(t_i\) 对称且凸：固定输入律时互信息对信道凸，由相对熵的对数和不等式得到；此处信道对 \(t_i\) 为仿射，给定 \(X_i\) 后按其分布平均仍凸。所以最小值在 \(1/2\) 取得，得证。这个下界允许中间区间的归类依赖于全部其他轴。本机 Python 以有理数核对三段归属，并计算熵系数。

**适用边界。** 指定接收并的体积比为 2，其对数为常数。该例排除仅根据矩形归类与一个给定接收分配、普遍保证标签熵低于第197轮余量的路线；没有排除改变接收分配、加入近中央假设，或保留族内价格的实际松弛量。事实上第194轮在单边长时已给出 \(2^n/p\) 的覆盖界，无需支付标签熵。一般系数差仍为 \((\mu-1)/8\)。下一步转向实际熵收支的联合估计：将源在成功矩形中的均匀律偏差按轴分摊，检验标签不确定性高的坐标是否从真实接收扩张中获益。
