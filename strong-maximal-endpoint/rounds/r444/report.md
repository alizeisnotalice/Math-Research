# 第444轮　拼合后的中央超额传递与根数下界

- A 已覆盖全部等权深度轮廓。若叶组承担次多项式损失内的接收份额，且加权拼合费用低于中央门槛精度，则严格成功的父盒仍承载同阶正对数超额。
- 对这样的分组，所需不同父盒数具有指数下界，且可对成功父盒直接应用第371轮的双向尺度分离。
- 尚缺一般目录中符合该费用条件、同时具有额外可用几何结构的分组。一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第443轮，令 $e_j=(pg_j+(1-p)r_j^E)/|P_j|$，$\bar e=\sum a_j e_j/A$。逐组恒等式给 $|E\cap P_j|/|P_j|>p-e_j$。故固定 $0<\delta<p$，选 $e_j\le\delta$ 的组，原负责体积至少为 $A(1-\bar e/\delta)$，父盒均在 $p-\delta$ 严格成功。若 $\bar e>0$ 取 $\delta=2\bar e<p$，保留至少一半；若费用为零直接保留全部而不降门槛。父盒可重复，合并重复标签时只合并负责区域而不重复计接收体积。

若 $A=\theta|U|$，$\log(1/\theta)=o(\log n)$，$\bar e=o(\log n/\sqrt n)$，则在稍扩中央区间内 $B_n(p-\delta)-B_n(p)=O_I(\sqrt n\delta)=o(\log n)$。因此成功父盒并相对 $B_n(p-\delta)$ 的超额至少为原超额减 $o_I(\log n)$。每个成功父盒体积严格小于 $|E|/(p-\delta)$，所以不同成功父盒的个数至少为 $(p-\delta)A(1-\bar e/\delta)/|E|$（零费用单独按原门槛）。这是对可压缩程度的必要限制。对有固定正对数超额的序列，可在保留的父盒并上重新分配不交接收单元并调用第371轮；所得分离约束针对合并后的真实父盒。它不能单独排除超额，因为逐盒单独成组总满足零费用。

可取 $\delta$ 优化实际保证 $\log(1-\bar e/\delta)-[B_n(p-\delta)-B_n(p)]$，但改进系数仍取决于父盒间的几何，而非单独选择门槛。
