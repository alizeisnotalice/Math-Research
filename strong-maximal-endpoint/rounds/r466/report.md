# 第466轮　以实际投影并的纤维体积无损传递门槛

- A 覆盖全部等权深度轮廓，中央误差有界。
- 公共投影可放宽为不同位置、不同形状的投影。门槛保持不变，代价由活跃投影并的平均体积以及最小投影体积决定。
- 下一步需构造覆盖足够接收份额且加权纤维体积费用可控的分组，并结算递归降维的累计代价。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。有限严格成功见证按组写为 $A_{gj}\times B_{gj}$，基底维数 $k\ge1$。记 $U_g=\bigcup_j B_{gj}$，$T_g=\bigcup_j(A_{gj}\times B_{gj})$，$a_g=\min_j|A_{gj}|>0$。在 $y\in U_g$ 处写 $D_g(y)=\bigcup_{j:y\in B_{gj}}A_{gj}$。定义
\[
 f_g(y)=\min(1,|E_y\cap D_g(y)|/a_g),\quad
 c_g=|T_g|/(a_g|U_g|).
\]
$E_y$ 是真实源纤维。对每个 $y\in B_{gj}$，$f_g(y)$ 至少为 $|E_y\cap A_{gj}|/|A_{gj}|$，因为截断前分子较大、分母较小，右侧至多一。故其在每个 $B_{gj}$ 上的平均严格大于 $p$。按第465轮在基底原子上保积分切块，得到同平均指标源，体积至多 $|E\cap T_g|/a_g$。于是
\[
 |T_g|\le c_g H_k(p)|E\cap T_g|,\qquad
 \frac{|\bigcup_g T_g|}{|E|}\le H_k(p)\frac{\sum_g c_g|E\cap T_g|}{|E|}.
\]
其中 $c_g$ 是实际活跃投影并体积在 $U_g$ 上的平均值除以 $a_g$；少量很大的纤维不必按其上确界计费。若 $T_g$ 覆盖原接收的 $\eta$ 份额，对数损失为上述加权费用的对数再加 $\log(1/\eta)$。此步没有中央门槛位移。仅把每个见证单列虽得 $c_g=1$，却可能付出很大的源重数。

例如一组二维见证的两个基底区间为 $[0,1],[1-h,2-h]$，横向投影为任意两个不交单位区间，$0<h<1$。则 $c_g=2/(2-h)$，与横向位置间距无关，$h\downarrow0$ 时费用趋于一。相反只用整组横向包围盒的体积会随间距无界增长。本机 Python 有理数检验 $h=1/10$ 得 $20/19$。一般中央目录中仍未控制加权费用，故此结论只给出分组降维的充分条件。
