# 第150轮　任意指标源的大偏差见证估计

2026-11-12。令 n=m+k，m/n,k/n≥ρ>0，I 为固定中央紧区间。本轮取消嵌套表示及局部分量数条件，给出对任意有限正体积指标源 E 的必要近极值见证形状。若一个接收点有严格成功矩形，使其条件切片密度重排后的区域与中央高斯半平面的概率对称差至少 η，则所有这样的接收点的外体积除以 |E| 至多
exp(B_n(p)−c√n η+C_I log n)， p∈I， log n/√n≤η≤1。
常数与盒数、源、证据矩形无关；分块比例的限制可保留在常数中。任一块顺序有此偏差的点亦满足同阶估计。一般端点系数差仍为 (μ−1)/8；估计涵盖任意源的一部分接收点，未涵盖所有接收点。

**用实际切片定义形状。** 对真实见证 X×Y，在 X 上取条件密度 b(x)=|Y∩E^x|/|Y|，以 X 内均匀概率定义 A(v)=P_X(b>v)。在独立标准正态 Z,W 平面取集合 K={(Z,W): Φ̄(Z)<A(Φ̄(W))}。其概率由层积分精确等于 |E∩(X×Y)|/|X×Y|。定义 s²=(m+t₀)/(n+2t₀)，t²=1−s²，t₀ 为第140轮共同时间膨胀；取半平面 P={sZ+tW>U(p)}。偏差指 P(K△P)，此处概率针对辅助高斯变量。该定义不要求 E 是乘积并，也不涉及人为插入的标签。

**从缺口取得低角点。** K 是上象限的并：在均匀概率坐标中为下矩形 [0,A(v)]×[0,v] 的并，等式按零测边界理解（单调函数仅可数个跳点）。若概率对称差≥η，且 K 概率严格大于 p，则 K 在半平面外的质量大于等于 η/2。将每个角点的两个边际下调至网格下门槛 a,b，步长 n^(−3)，使正门槛严格低于原值，再按第140轮接口减 2n^(−4)。极小角点可按零处理。整片概率损失≤8n^(−3)，因为一次向左下平移即可控制所有矩形的舍入，参见第148轮。半平面边缘宽 cη 的条带概率最多 cη/√(2π)。取绝对常数 c 充分小，舍入后仍有角点的修正分位满足
s U(a−2n^(−4))+t U(b−2n^(−4))<U(p)−cη。
该角点来自某个 v，且 b<v、a<A(v)。

**按实际源结算，消除外包标签。** 对接收点 (x₀,y₀) 及这一对实际门槛，定义 F_b(y₀)={x:M_k1_{E^x}(y₀)>b}。原见证 Y 含 y₀；在 X 内，b(x)>v 的那些 x 全在 F_b(y₀) 中。因此 x₀ 属于 F_b(y₀) 的严格 a-halo。单个网格对所覆盖的全部接收体积至多为
H_m(a)∫|F_b(y₀)|dy₀ ≤ H_m(a)H_k(b)|E|。
两次 Fubini 均保留原源分母；正门槛保证相关截面几乎处处有限，可取有理盒定义横向极大函数。放松为逐 x 选择横向盒发生在已由同一物理 Y 找到低角点之后。用第140轮的全域移动门槛界并求和至多 O(n^6) 对，即得所述上界。无需对全部见证或源分量求和。交换两块再并集仅付 log 2。

**剩余部分。** 对 η√n/log n→∞，上述接收点低于中央目标任意固定对数阶。在任何企图超过中央目标的源中，剩余接收点的每个成功见证在两种块顺序下都必须接近同一半平面（交换坐标后比较）。没有仅凭这种必要性推出剩余接收体积小。与前轮的标签分位不同，在一个乘积里重复加入被包含的子乘积可以任意细分其标签密度，却绝不会改变本文的条件切片分布。反过来，半平面形状本身在局部可以物理实现：单位方盒内以两块各一个均匀坐标作高斯分位变换，选 sZ+tW>U(p') 的点，p'>p，整盒是真实严格见证，源分母 p'，接收盒体积 1，两方向的重排形状与门槛 p 的半平面相差恰为 p'−p。这个局部例子没有达到高维近极值体积比。因此下一步应考察许多接收见证能否在同一有限源上同时具有这种双向切片分布，并检验条件切片的排序是否能强制近嵌套结构。[移动门槛接口](../r140/report.md) · [概率舍入](../r148/report.md) · [前轮嵌套情形](../r149/report.md)
