# 第44轮：反馈模型锐对数项与一般常数的新系数上界

日期：2026-11-07（本轮跨午夜完成）。状态：严格证明完成并经独立审查；真实强极大常数的锐对数系数仍未确定。计算主要使用本机Wolfram 15.0 ARM，独立有理证书使用Python Fraction；未启动MATLAB。

## 1. 本轮主要结论

统一Phi_N(t)=t(1+log⁺t)^(N−1)、mu=log B=1+exp(−mu)、barPhi_G(z_N)=sqrt(mu/N)z_N、d_N=sqrt(mu N)z_N。令

c_Q=(9−mu)/24≈.321730644051622，
g=(mu−1)/8≈.0348080678451342，c_R=(3+mu)/12≈.356538711896756。

本轮闭合反馈上界模型本身的锐对数项：

**log R_N=Nmu−d_N+c_R log N+o(log N)。**

因此真实强矩形极大常数满足

c_Q≤liminf (log C_N−Nmu+d_N)/log N
   ≤limsup (log C_N−Nmu+d_N)/log N≤c_R。

相对于原先只有O(log N)的一般上界，本轮确定了上界系数；剩余宽度为g。没有证明真实C_N的系数极限存在，也没有证明C_N=R_N。R_N/Q_N=N^(g+o(1))现为模型的精确分离，说明仅靠这个反馈重排上界模型不能降到独立比例系数c_Q。

## 2. 端点结算的关键账本

完整证明在[proof.md](proof.md)。取s=Nmu−d_N+C log N、匹配ell(a)=s/N，直接展开参考分布，得到

M=Nmu−g log N+o(log N)，d(V)=d_N−2g log N+o(log N)。

保留这两个不同补偿后，一项绝对Edgeworth展开及**实际有限终端**恒等式给

v_N^a(s)=1−(C−c_Q)f_N(s)log N+o(f_N log N)，f_N(s)∼log N/N。

有限终端的shortfall/N保留到证实为O(1/N)后才吸收，不能以Q_N的最终渐近式直接代替此参考结算。精确Poisson式在s=Nell处二次项为0，剩下调和项J_N/f_N=g log N+o(log N)。有界密度源、floor和固定初始化平移只付O(f_N)。

利用第43轮已闭合的全空间势，先固定alpha>1使(alpha−1)g<epsilon/2，再在C=c_Q+g+epsilon处得到

mathcalU_(N,N)(s)≤1−c_epsilon(log N)²/N。

第32轮对所有轮廓/策略的真实预算归约误差仅O(log N/N)，故严格亏损足以排除全部该预算输入。配合第29轮反馈模型下界完成R_N等号。无需最优轮廓存在或非临界根全局唯一。

## 4. 下界线：现有跨分量见证的张量障碍

详细证明在[tensor.md](tensor.md)。对第43轮20个已认证二维见证，实际Phi_(2k)分母给任意异构积接收比值

L_(2k)=∏[V_i/(|E_i|A_i)]/(1+∑log A_i)^(2k−1)
       ≤4^k/(1+k log2)^(2k−1)。

用log2>69/100的有理Taylor证书，该上界从k=3起严格小于1且继续递减；k=2的15个无序振幅对另有精确有理证书，最大上界49000000/260409987<1。因此该字典的**所有20^k种异构积接收构造在k≥2时均小于1**，且log L_(2k)/(2k)≤−log k+O(1)。

这是明确的实际分母障碍，范围仅限这些积接收集合，不排除完整halo、非积相关接收或薄双曲基底。Wolfram另作k=1…128的70位字典DP（数值目标比较），其k=2最佳约.16761934，k=128约5.158e−481；全k证明不依赖该DP。独立Python Fraction重新核对20个输入比值、15个有理对、Taylor余尾及全k递推常数，全部通过。

本轮未提高真实C_N下界。已有n=64非对称几何评分71.282178064572，64 log B−log L≈10.539552672137，仍低于标量评分71.714992087949。新的上界结算不改变这些候选的验收状态。
