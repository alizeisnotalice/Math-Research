# 第217轮　平方根熵饱和向精确较低门槛的传递

2026-11-12。沿用[第216轮](../r216/report.md)的假设和记号。固定任意 \(0<q<p\)，记 \(z=\bar\Phi^{-1}(q)\)。存在 \(z_n<z,\ z_n\to z\)，使原源层 \(E'=F_{z_n}\) 配合原族中的一批矩形，构成门槛**恰为 \(q\)** 的严格成功族。可以选择其实际接收归属，使新并 \(U'\) 与新源样本 \(X'\) 同时满足
\[
 |U'|/|U|\to1,\quad V':=\log(|U'|/|E'|)=B_n(q)+o(\sqrt n),
 \qquad
 V'+D(P_{X'}\Vert\mathrm{Unif}(E'))=\mu n+\sigma\sqrt n\,\varphi(z)/q+o(\sqrt n).
\]
因此传递后仍满足第216轮的联合熵假设，可沿任何预定的有限递减门槛链迭代。所调的是源层，不是成功门槛。

**严格见证与归属。** 在含 \(z\) 于内部、下端大于 \(u=\bar\Phi^{-1}(p)\) 的紧区间上，第216轮的盒内比例曲线在接收概率下统一趋于 \(\bar\Phi\)。取正数 \(\epsilon_n\downarrow0\) 足够慢，使曲线误差以趋于一的概率小于 \((\bar\Phi(z-\epsilon_n)-q)/2\)，并令 \(z_n=z-\epsilon_n\)。选出所有在 \(E'\) 上平均严格超过 \(q\) 的原盒。这些盒原来负责的区域 \(G_n\) 占 \(U\) 的比例趋于一。它们的完整并满足 \(G_n\subset U'\subset U\)；在 \(G_n\) 沿用原归属，其他点按固定次序归属。由夹在固定的 \(F_{z\pm\epsilon}\) 间并令 \(\epsilon\downarrow0\)，第216轮的体积估计给出 \(V'\) 的展开。同理，旧律下 \(P_X(E')\to q/p\)。

**重新抽样的权重。** 在旧联合抽样中条件于 \(X\in E'\)，接收点 \(Y\) 的密度相对原均匀接收律为
\[
 \frac{|R(Y)\cap E'|/|R(Y)\cap E|}{P_X(E')}.
\]
分子在接收概率下趋于 \(q/p\)（第216轮紧区间结论）且有界，故此密度在 \(L^1\) 中趋于 1。给定 \(Y\in G_n\)，新抽样及条件化旧抽样在同一盒的同一源片上均匀。由此新联合律与条件化旧联合律总变差趋零：在 \(G_n\) 比较接收边际即可，补集在两种律下质量都为 \(o(1)\)。特别，写 \(g_n=f_X1_{E'}/P_X(E')\)，则 \(\|f_{X'}-g_n\|_1=o(1)\)。

**似然比与熵。** 总变差收敛本身不给熵收敛。先注意在新律下 \(\log(f_{X'}/g_n)=o_P(1)\)：任一固定对数比偏离零的事件，其新概率至多为两密度总变差的常数倍，包含 \(g_n=0<f_{X'}\) 的集合。第216轮给出旧标准化对数密度的上尾在每个 \(v>u\) 趋于 \(\bar\Phi(v)/p\)。因此在 \(X\in E'\) 条件下，该量趋于 \((N\mid N>z)\)，\(N\) 标准正态；移动截点不影响连续极限。由总变差、\(P_X(E')\to q/p\) 和 \(|U'|/|U|\to1\)，新律下的
\[
 Z'_n=(\log(|U'| f_{X'}(X'))-\mu n)/(\sigma\sqrt n)
 \Rightarrow (N\mid N>z).
\]
复用第216轮不依赖源分母的中尾与极远尾估计（以固定 \(q\) 替代 \(p\)），得新正尾一致可积。另一方面，\(Z'_n=(V'-\mu n)/(\sigma\sqrt n)+\log(|E'|f_{X'}(X'))/(\sigma\sqrt n)\)；首项趋于 \(z\)，第二项负部期望至多 \(1/(e\sigma\sqrt n)\)。故新负尾亦一致可积，期望趋于 \(\varphi(z)/q\)，即得联合熵展开。每次均用有限真实子族和实际分母，有限迭代不要求不同轮的未知收敛速率一致。

一般系数差仍为 \((\mu-1)/8\)。传递保留平方根精度，源层位置的定性调整可能带来超过 \(\log n\) 的对数体积误差。下一步需定量联系联合熵缺口、层位置修正和保留接收体积，检验能否在门槛传递时保留对数精度。
