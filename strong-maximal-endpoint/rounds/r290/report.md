# 第290轮　轻度硬化失败集在双曲乘积例中的精确对数系数

2026-11-12。沿用[第289轮](../r289/report.md)的真实源、常数和阈值。记全空间失败集为
\[
 D_n=\{M_S f_n>p,\ M_S1_{E_n^*}\le p-c_p/\sqrt n\}.
\]
对固定 $0<p<1$，有
\[
 B_n(p)-\tfrac12\log n-O_p(1)
 \le \log(|D_n|/\!\int f_n)
 \le B_n(p)-\tfrac12\log n+\log\log n+O_p(1).
\]
因此这一族的半对数损失确实出现在实际失败集体积中。下界直接引用第289轮。以下给出上界，同时保留立方体之外的接收点。

**主块的门槛移动。** 写 $f_n=1_E\otimes g$，$d=n-2$，$F=M_S1_E$，平面变量为 $z$，$s(z)=1-M_Sg(z)$。若 $s\ge1-p$ 则无成功。另取 $q_0=(1+p)/2$，对 $s<1-p$ 用门槛 $q=\min(q_0,p/(1-s))$。[第111轮全空间估计](../r111/central-cross111.md)和[第182轮中央分位](../r182/report.md)给
\[
 |\{F>q\}|/|E|\le C_p\exp(B_n(p)-a_p\sqrt n\,s).
\]
事实上 $q-p\ge\min(p,q_0-p)s$，$-B'_d(q)=\sqrt{\mu d}/\varphi(U(q))\ge\sqrt{2\pi\mu d}$，且 $B_d(p)-B_n(p)=O_p(1)$。所有门槛在同一紧区间，常数一致。由乘积公式，对每个 $z$ 这就控制了成功接收点的整个主块截面。

**扣掉硬源内部。** 记平面硬集合为 $K$、软支撑为 $S=([0,1]\times[0,1])\cup([1,2]\times[0,8])$。在 $K$ 的几乎每一点，平面硬极大值为一，故软成功时硬值也大于 $p$。$S\setminus K$ 面积为 $7.6\epsilon$，$\epsilon=A_p/\sqrt n$。这一部分至多花费 $O_p(|E|e^{B_n(p)}/\sqrt n)$。

**支撑外的角区。** $M_Sg(z)>p$ 需要一件成功矩形，每条边长分别小于 $2/p,8/p$，因为支撑投影宽分别为 2 和 8。因此所有这样的 $z$ 都在一个固定有界盒中。取 $a,b$ 为两坐标分别到网格线 $\{0,1,2\}$、$\{0,1,8\}$ 的距离，各截到至多 1。支撑外除零测网格线外，包含 $z$ 的开网格单元与 $S$ 不交。穿过 $z$ 的任意区间在对应单元内的长度至少为区间长与该坐标距离的较小值。因此在任何平均大于 $p$ 的矩形中，至少 $p^2 ab/16$ 的比例落在空单元。取上确界得到 $s(z)\ge p^2 ab/16$。

在有界盒每个坐标上，截断距离的推前测度在 $(0,1)$ 有有界密度（分段斜率为正负一），在 1 可有有限原子。两坐标分别积分，$L\asymp_p\sqrt n$ 时
\[
 \int_0^1\int_0^1 e^{-Lab}\,da\,db
 =L^{-1}\int_0^L(1-e^{-v})\,dv/v
 \le (1+\log L)/L\quad(L\ge1).
\]
含单个原子的项为 $O(1/L)$，双原子为 $O(e^{-L})$。代入主块截面上界，再除以 $\int f_n=(9-7.6\epsilon)|E|$ 即得结论。推导同样适用于固定有界矩形网格的单元并支撑、硬集合包含于支撑且遗漏面积为 $O(n^{-1/2})$、平面软质量有统一正下界的乘积族（仅上界）。常数依赖固定几何和 $p$。

一般上下界系数差仍为 $(\mu-1)/8$。证明所需输入是主块在变动阈值处的全空间上界，以及平面硬化后保留的满密度区域。一般源尚缺第一项与平面位置耦合时的估计。下轮两项动作是检验能否对随主块位置改变的网格截面维持同一质量预算，以及估计凹角贡献在扣除硬成功点后是否仍有对数因子。
