# 第365轮　消去任意整体缩放后的形状覆盖

- A 覆盖全部可测等权深度轮廓，中央误差有界。
- 对一般有限目录的任一逐轴边长全序链，全部大小的成功盒之并体积至多 $3^n|E|/p$。允许接近一条链的总对数边长误差，并按真实局部源质量合并多条链。
- 未证部分是形状链的源质量重复费用，尤其是跨链见证的命中重叠。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。将盒按组 $g$ 分配。对组内每盒 $R$，存在包含它的同心矩形 $P_R$，其体积至多 $e^{t_g}|R|$，且全部 $P_R$ 的边长向量按逐坐标次序构成链。位置无需相同，链长不限。令 $E_g=E\cap\bigcup_{R\in g}R$。将 $P_R$ 按边长从大到小处理，保留与此前所选盒内部不交者。每个被舍弃的盒与某个已选盒相交且逐轴不长于后者，故包含于后者的三倍同心放大。接收并集至多为所选 $P_R$ 总体积的 $3^n$ 倍。对应的原盒内部不交，严格成功给出
\[
 |U|\le (3^n/p)\sum_g e^{t_g}|E_g|.
\]
右端也可将 $|E_g|$ 换成该组所选原盒实际命中体积之和。特别同形任意缩放只是链的一例，纵横比可沿链改变。采用固定对数形状 $s$ 的最佳单侧同形外包时，令 $d_i=\log\ell_i(R)-s_i$，则所需体积费恰为 $t_R=n\max_i d_i-\sum_i d_i$，对任意整体缩放不变。

进一步可逐点截去低重复源。令 $M(y)=\sum_g e^{t_g}1_{E_g}(y)$，$G=\{y\in E:M(y)\le e^{\beta n}\}$。只对从 $G$ 命中密度至少 $\delta$ 的盒作上述选择，便有其接收并体积至多 $3^n e^{\beta n}|E|/\delta$。取 $\delta=n^{-1/2}$ 及 $\beta<\mu-\log3$ 即比中央基线指数小。余盒对原源的剩余部分 $E\setminus G$ 仍严格超过 $p-\delta$。这一步使用单一全局组分配，不能逐源点各选一组再直接套用不交选择。下一步要控制划分成形状链时在源上的最小加权重复量；对全部可能划分取最优是合法的，但仍需几何界。
