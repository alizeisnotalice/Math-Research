# 第595轮　全部独立区间附加目录的锐核冗余率

- A 已覆盖全部等权深度轮廓，中央误差有界。
- 第594轮的附加块即使允许任意轴间非同分布、任意长度的一维区间菜单，在完整重组且附加源等于并时，固定份额的最小核冗余率至多 $d_*=2\log2-1-\log(2\log2)$。两平移区间已达到此值。
- 尚需估计跨轴标签不能独立重组的附加块。一般系数差仍为 $(\mu-1)/8$。

2026-11-13。每轴取有限有界区间菜单，并为 $U_i$，令附加源 $U=\prod_{i=1}^m U_i$，假定正体积。全部积行都可用。与第326轮一致，先逐轴去掉冗余区间，留下保并极小覆盖，几乎处处重数为一或二。该轮估计的是一般源的真实接收增益；本轮估计固定接收份额所需的确定子目录的最大核积分，两者分母与目标不同。记双覆盖区所占比例为 $h_i$，$H=\sum h_i$。均匀接收点的积行重数为 $2^J$，其中 $J$ 是独立均值 $h_i$ 的伯努利变量之和。各行体积之和为 $|U|\prod(1+h_i)$。

**选取子目录。** 固定 $0<\beta<1$，取常数 $A,B>0$ 使 $(1-1/(4A^2))(1-e^{-B})>\beta$。以 $t=\min(1,B2^{-H+A\sqrt m})$ 独立保留每行。若未饱和，$J\ge H-A\sqrt m$ 的接收点保留概率至少 $1-e^{-B}$，而 Chebyshev 保证此类点的比例至少 $1-1/(4A^2)$；若饱和则保并。故期望覆盖比例超过 $\beta$ 一个固定余量，达到 $\beta$ 的概率有正下界。行体积和的期望为 $t|U|\prod(1+h_i)$。Markov 保证某确定子目录同时保留所需份额且行体积和不超过此期望的常数倍。对单位源密度，真实最大核积分小于等于行体积和（分别对每行的归一化二点核积分）。因此最小核积分除以 $|U|$ 的对数至多
\[
 \sum_i[\log(1+h_i)-h_i\log2]+O_\beta(\sqrt m+1)\le d_* m+O_\beta(\sqrt m+1).
\]
凹函数在 $h_*=1/\log2-1$ 处取最大值。第593轮两位置例中 $h=(1-d)/(1+d)$、$f=1-h$；其精确率 $f\log2-\log(1+d)=\log(1+h)-h\log2$。取 $d=2\log2-1$ 即达，若限有理端点则用有理数逼近。这同时证明该常数作为一般上界不可降低。

**附加到真实基底。** 取基底任意子目录与上述好子目录的完整乘积，则覆盖份额相乘，最大归一化二点核逐块因子化，其双积分除以源质量的比也相乘。即使允许选择相关子族，最小费用也不比此构造更高。因此这类独立区间附加块所能强制的额外费用率至多 $d_*<\mu$，无法靠增加附加坐标填补第594轮的线性维数成本。基底本身的核费用及更一般的耦合块仍待估计。
