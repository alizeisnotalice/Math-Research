# 第736轮　整个最不利权面的精确容量认证

2026-11-14。一般 $C_n$ 的 $\log n$ 项精确系数仍未确定。本轮补齐第732轮固定权认证中的外层选择，取得完整有限目录结论；没有将有限维数值结果外推为中央渐近定理。

固定一个共同最优源 $f$，写 $a_i(f)$ 为行平均、$d_j(\pi)$ 为混合空间密度。整个负责最不利权集合恰为下列有界线性多面体在 $\pi$ 上的投影：
$$\pi\in\Pi,\quad \pi\cdot a(f)=q,\quad 0\le\eta\le\max_i|R_i|^{-1},$$
$$d_j\le\eta\ (f_j=0),\qquad d_j\ge\eta\ (f_j=1),\qquad d_j=\eta\ (0<f_j<1).$$
证明包括阈值正性、退化源及零权情形。$\exp\Lambda(\pi)$ 是连续凸函数，因此遍历扩展多面体顶点的投影足以计算整个LF面的最大容量；不要求 $\Lambda$ 本身凸，也不把投影自动视为极点。[完整证明](LF_face.md)。

本机 Python 12进程对第732轮27个有理目录精确枚举，得到35个不同权。仅case2、15、23、26非单点，分别有2、2、4、4个权；全部9个中央门槛case为单点。Mathematica 15实际12子核独立重建几何，以精确线性规划核验仿射包及全部凸包面，27/27通过。另一个仅用Python标准库的独立算法以全部交叉点对及活跃秩筛选重新构造整个多面体，避免只相信枚举器或求解器成功标志。

每个权均有精确Hall条件、共同源及NP价格等式和有理对数容量证书。35份内层证书与27份外层最大端点全部通过独立64项有理对数回放；所有外层区间宽度小于 $5.612\times10^{-8}$。两个很小标签分量造成初始梯度上界偏宽，改用保持分量比例的正乘法迭代，分别17、18次后获得足够窄的证书。最终严格性依据有理上下界，并非浮点收敛状态。
