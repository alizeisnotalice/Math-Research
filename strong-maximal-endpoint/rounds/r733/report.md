# 第733轮　中央标签熵约束、相关积容量与高秩候选排除

2026-11-14。一般 $C_n$ 的 $\log n$ 精确系数仍未知。本轮对一般目录保留两个严格引理，并排除一个容易被单点编码误导的真实源。

负责权的单行Hall约束给 $w(z)\le N(z)\le k$。若π是既定门槛的负责最不利权、NP源质量为s，则
$$k\ge q e^V,\qquad H(I\mid Z, Z\in E)\ge V+\log q.$$
因而真正近中央问题需要指数级行数及约μn的命中区标签歧义。任意负责权也有相同形式，但必须使用它自己的NP价格，不能混用全局LF的s。

对两个任意实际目录及固定负责参考权，即使标签倾斜ν任意相关，精确有
$$F_{AB}(\nu)=F_A(\nu_A)+E_{Z_A}F_B(\nu_{B\mid Z_A})-I(I_A;I_B\mid Z_A).$$
由此容量严格张量化：$\Lambda(\pi_A\otimes\pi_B)=\Lambda(\pi_A)+\Lambda(\pi_B)$。相关候选的容量亏损是三个非负项之和，所以近最优相关性必须被空间输出解释。这并不证明同一半门槛的LF权或最小源质量也张量化。[证明、准确量词与中央缺口](central_capacity.md)。

高秩统计量 $-n\min(PZ)$ 确实能编码径向和，但未周期化的轮廓 $h(v)=-n\min v-b$ 把真实源直接变成小立方体。其**完整强矩形**半门槛halo满足
$$G_n\le2\exp(2\sqrt{2n\log2}),\quad\log G_n=o(n),$$
所以不是近μn源。周期化和截断会改变这一代数归约，仍需分别计算实际源预算及相位/角向分布，不能自动套Haar。

本机Mathematica对两个真实区间目录与一个相关有理标签律，精确核验上述链式残差为0；原始输出随附。该候选的互信息损失约0.087208，积容量亏损约0.116277，均非零。

Python另外以12进程、40/70位及20保护位，计算12个维数1至65536的完整cube halo，共24组；用独立SciPy正Laguerre积分复算，最大对数差约3.55e−15。Mathematica实际12核，以相同目标精度独立计算n=1至128的16组正积分，保存小数与Python之差在70位档不超过2.84e−69。精度加倍、截断位置和尾界显示均已记录；未把高精度小数当区间证书。[正公式与计算说明](cube_computation.md)。
