# 第463轮　叶支持约束下全局根数压缩的反例

- A 覆盖全部等权深度轮廓，中央误差有界。
- 根盒与其见证叶必须同时参与时，即使根有正体积共同核、两两双向分离、根叶均严格成功，也可能需要任意多个根才能覆盖全部可用外部源。
- 下一步应保留中央规模的接收体积条件，以排除由各根独占外部源的配置。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定二维、$N\ge2$、分离门槛 $t\ge0$、成功门槛 $0<p<1$ 以及内部命中上限 $d>0$。取整数 $B>\max(4,e^t)$，$X_i=B^i$，$Y_i=B^{-i}$。根 $P_i=[0,X_i]\times[0,Y_i]$ 面积均为一，所有根的交面积为 $B^{1-N}>0$。不同根在两个方向的正对数伸长均为 $|i-j|\log B>t$。

取 $0<h<\min(1/8,d/8)$，令叶
\[
 R_i=[(1-h)X_i,(1+1/4)X_i]\times[Y_i/2,3Y_i/4].
\]
叶只与自身根相交：较早的根横向太短，较晚的根纵向太矮。叶也两两不交，体积小于一，正向伸长为零，所以第366轮贪心确实先保留这些根再按指定方式归叶。令共同源为全部根与全部叶的并，则每个平均为一，严格超过 $p$。叶在自身根内的源平均为 $h/(h+1/4)<d$。各 $S_i=(E\cap R_i)\setminus P_i$ 两两不交且面积都为 $1/16$，全部只对应自己的候选根。因此选择任意 $k$ 个根及其所有叶，只能覆盖外部可用源的 $k/N$。在各叶外部取均匀源律并给各行相等权重，结论对这一流量同样成立。即使所有根共享一个正体积内核，第462轮的全局 $2n$ 覆盖在加入叶支持后也没有维数常数替代。

若先让根负责自身并、再按叶分配余下接收区，则每叶承担面积 $1/16$。总接收并恰为 $E$，故 $V/m=1$。这个构造检验的是排斥、支持和严格成功的联合几何；它没有中央体积增益。若固定一个叶覆盖标签模式，在该模式上仅对有叶覆盖的根应用第462轮，仍可局部选至多 $2n$ 个根；本例的 $N$ 个互不相交外部区域分别需要不同的选择。后续估计必须控制模式承担的接收体积，不能直接合并局部根数上界。

本机 Python 用有理数对 $B=5,N=8,h=1/100$ 的全部根叶配对核对内部相交关系与面积。
