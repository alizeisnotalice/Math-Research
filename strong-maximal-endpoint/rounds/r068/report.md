# 第68轮：精确径向包络、缩放协变预算与混合导数障碍

日期：2026-11-08。状态：固定动作条件窗口的预算输运定理与固定维数混合导数反例已证明、独立审查并本机复核。一般 C_N 的锐上界仍开放。

## 1. 固定动作的径向最大化只付对数窗口代价

固定 b≥2、c>0，保留 Z_i=Exp(1)+cJ_i 的全部联合符号标签。令 S=ΣZ_i、H_b={Σy_i=0}，在重心坐标 Y=Z−S/b 上记条件卷积为 K_c^s。定义

\[
 H_{b,c}(s)=\frac1{(b-1)!}\sum_{k=0}^b{b\choose k}(s-ck)_+^{b-1}.
\]

条件密度在支撑 D_(s,J)={y_i≥cJ_i−s/b} 上为常数；支撑随 s 嵌套扩大，高度按 H(s)^(-1) 递减。因此任何固定正窗口 I=[a,d] 的核包络质量精确为

\[
 \boxed{Z_I=\int\sup_{s\in I}k_{c,s}=1+\log\frac{H_{b,c}(d)}{H_{b,c}(a)}.}
\]

这是相应正最大卷积的锐 L¹ 常数，不是实际 halo 的锐常数。结点 s=ck 不增加额外项，b=2 也成立。分布导数的总变差为2∂s log H；只对新进入的壳层收费，才得到上述精确系数。

当 c 与 s/b 均在固定正紧区间时，统一有

\[
 \partial_s\log H_{b,c}(s)=\gamma+O(b^{-1}),\qquad
 s/b=1/\gamma+c/(1+e^{\gamma c}).
\]

特别地，c=μ、临界窗口 q_b+O(log b) 上，长度 ℓ=O(log b) 的包络为

\[
 Z_I=1+\ell\{1+O(\sqrt{\log b/b})\}.
\]

固定正比例的 log b 窗口在对数账本中只增加 log log b+O(1)。若 a↓0，则即使 d<c 也有 Z=1+(b−1)log(d/a)，不能推广成整个正半轴上的强 L¹ 常数。完整证明见 [radial_envelope68.md](radial_envelope68.md)。

## 2. 保留源层后，预算可以承受任意接收深度选择

设 G(w,X,σ)≥0 为源成本（可取 Φ_N(F)），J(G)=∫e^(−w)∥G_w∥₁dw。对固定 c 和固定 I 定义

\[
 A_u(X,\sigma)=\int_I e^{-(u+s)}
        K_c^sG_{u+s}(X,\sigma)\,ds.
\]

先换元 w=u+s，再对每个固定源层 w 使用核包络，得到

\[
 \boxed{\int\sup_{u\in\mathbb R}A_u(X,\sigma)\,dX\,d\lambda(\sigma)
 \le Z_I J(G).}
\]

因此也允许任意可测的 u=u(X,σ)。这里没有把 F(u(X)+s,·) 错当成同一个固定卷积输入，而是先固定真正的源层 w，再交换正积分。源预算有限时 A_u 连续，sup_u 可由有理数 u 取得同一上确界，可测性合法。

在全局对数重心坐标 v_i=−log|x_i|、V=Σv_i、X=v−(V/b)1 中，物理测度为

\[
 dx=\frac{2^b}{\sqrt b}e^{-V}dV\,dH(X)\,d\lambda(\sigma),
\]

其中 λ 是符号群上的均匀概率。此坐标没有 V^(b−1) 因子。物理伸缩使 G^D(w,X)=G(w−bD,X)，且精确满足

\[
 A_u^D=e^{-bD}A_{u-bD},\qquad J(G^D)=e^{-bD}J(G).
\]

这给出了与第67轮缩放反例相容的候选预算密度。产品块和产品条件窗口的常数精确相乘；不因此推断增长块数的一般动作定理。输运证明见 [envelope_proof68.md](envelope_proof68.md)，测度及独立审查见 [transport_review68.md](transport_review68.md)。

## 3. 同时平滑两个参数的直接路线被严格排除

固定 b≥4、c>0、s>c 且 s≠kc。取零和频率 ξ=q(b−1,−1,…,−1)。移除高频坐标的 c 边界面产生精确相位 e^(iq(bc−s))，不随 q 衰减。归一化通量恒等式给

\[
 \boxed{\partial_s\partial_c\Phi_{b,c}(s;\xi)
 =iq\,\frac{A_{b,c}(s)}b e^{iq(bc-s)}+O(1),\qquad
 A_{b,c}(s)=bp_c\frac{f_{b-1,c}(s-c)}{f_{b,c}(s)}>0.}
\]

故混合导数在频率上无界，即使 b 固定，也没有有界的 L² 混合导数乘子。余项控制使用条件单坐标边际及其径向导数的 BV 分部积分；不能直接对 O(1/q) 余项求导，也不能把低面非零和频率代入第67轮的零和定理。

这与分别成立的 ∥∂c K∥₂→₂=O(1)、∥∂s K∥₂→₂=O(1/b) 相容。它排除经统一混合导数取得无损联合最大化的路线，不证明所有联合最大估计都失败，更不是 C_N 的反例。见 [mixed_obstruction68.md](mixed_obstruction68.md)。

## 4. 本机验证与计算效率

- Mathematica 15，12工作内核：48项包络测试，b=16…4096，窗口长度为log b、2log b、4log b；60/120位精度，结点分段积分。24组精度加倍保留30位一致；每例另检查μ方程、正态尾分位数方程和倾斜均值方程残差，容差为10^(−floor(WP/2))。原有限和及积分耗时174.68秒；缓存精确二项系数后同组正式计算约23秒、含启动监测25.83秒，保留结果一致。总CPU峰值1155.4%，RSS峰值约2.32GiB。
- 长度2log b时，包络质量在b=16、256、4096分别约7.43639170936、12.9242595822、18.0661998409。
- 35项混合导数测试，b=4、8、16、32、64，q=2⁴…2²⁰，c=5/4、s=15/8；60/120位精度，10组加倍保留30位一致。采用完整有限Beta分部积分式并保留终点项，无后验截断。另10项径向中心差分，步长2^(−80)，相对主项误差均小于1.3×10^(−37)。
- b=4、q=2²⁰ 时，混合导数模约162360.238213，主项相对误差约1.06×10^(−6)。一般无界性由解析证明给出，有限扫描只作核对。

第一版数值率函数缺少 NumericQ 保护，触发积分器符号预求值警告；该批已终止，未采用结果。检查器也按实际保存精度修正了比较字段。正式两批均通过数值、行数及精度检查，并已关闭全部自有内核。所有计算确定性，无随机种子；未实施定向舍入，不登记新的认证下界。详见 [validation68.json](validation68.json)。

## 5. 尚缺的真实上界桥及下一轮

本轮输运仅控制固定 c、固定 s 窗口内的源成本。真实接收平均为 ∫f_(b,c)(s)K_c^sF_(u+s)ds，含有不同径向权重；接收点依赖 c 时，还须证明它与同一参考成本密度兼容。不能由上述正预算界直接推出变动作成功在固定动作下仍近成功，也不能直接调用 Q_N。

一般账本仍为 Q_N≤C_N≤R_N，log Q_N=q0+(9−μ)log N/24+o(log N)，log R_N=q0+(3+μ)log N/12+o(log N)，系数间隙仍是(μ−1)/8。最佳有限维认证仍为log C64>71.79。

下一轮优先两项动作：

1. 用本轮缩放协变成本密度建立效率条件下的临界窗口捕获，保留真实 f_(b,c)(s) 权重，检验能否同时提供动作无关的局部基准。
2. 从精确通量中分离不平滑的高频边界面，研究其正面预算分配或停止规则；避免再假设已被否定的有界混合导数。

原始附件继续作为待核验研究材料；本轮是内部推导与独立审查，不作新的公开优先权主张。依赖第28轮固定动作全输入定理、第64轮条件动作包络、第67轮条件单参数响应与缩放障碍；原始文献索引沿用项目 sources.md。
