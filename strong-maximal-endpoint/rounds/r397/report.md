# 第397轮　双行取整化为最小交体积匹配

- A 覆盖全部等权深度轮廓。对任意非对称目录，给定入选边际且每次恰选两行时，最优取整可由矩形交体积的匹配规划精确求解。
- 四个互异有理区间上，均匀选两行与最优选两行的证书差可趋于单行体积的三分之一。
- 未解决的是中央目录中总边际远大于二时，多行交叠对匹配收益的遮蔽。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。给定 $q_i\in[0,1]$，$\sum q_i=2$，令 $A=\sum q_i|R_i|$。在恰选两行的耦合中，记选到无序对的概率为 $x_{ij}$。其和自动为一，边际等式为 $\sum_{j\ne i}x_{ij}=q_i$（对称记号）。可行性也可由第395轮共享阈值构造得到。子集证书期望恰为 $pA-\sum_{i<j}x_{ij}|R_i\cap R_j|$。故最小碰撞费用等于最大 $\sum_i q_i u_i$，约束为 $u_i+u_j\le |R_i\cap R_j|$，其中势 $u_i$ 可为负；这是有限 LP 的精确对偶。若有可行方案完全避开正体积交，则达到任何保持相同边际的耦合的上界 $pA$，即使允许选行数变化。

取 $0<d<1$ 有理，四个单位区间左端点依次为 $0,d,3,3+d$，$q_i=1/2$。从前两行中选一行、后两行中选一行即无碰撞；均匀六对则以概率 $1/3$ 选中同组重叠对。其证书分别为 $2p$ 与 $2p-(1-d)/3$。在 $p=1/2$ 时，若 $d\le1/2$，每组在公共部分取质量 $1/2$ 即满足两行的非严格需求。两组共一，匹配所得证书也为一，故分数权和取整均达到最优。严格成功由任意小的补充质量逼近。此例接收规模有界，仅说明固定行数不能替代对盒交几何的优化。下一步应估计在多组匹配同时运行时哪些收益能穿过其他组的覆盖。
