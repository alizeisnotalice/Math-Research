# 截断真实负载后恢复宏观覆盖的原始价格

日期为2026-11-11。对一组有限有理矩形和同一个实际二元源，覆盖体积超过 $1-1/N$。这组矩形的线性规划价格为 $(1+o(1))5\log N\exp(-s_p^{\rm iid})$。未截断的单阶矩证书在这类构造上有超多项式损失。删去一个真实深层后，二阶矩已足以认证上述价格的至少 $4/e^2-o(1)$，约为54.1%。

用 $O(\sqrt{\log N}\log\log N)$ 个真实径向层的一、二阶矩，连同包间交叉项与删权记录，可恢复 $1-o(1)$ 的相对精度。逐行筛选同时控制了截断质量的偏差与宏观覆盖损失。普遍结论仍需证明每个宏观覆盖族有满足这种截断余量和交叉矩要求的混合。[完整证明](core109.md) · [独立审查](audit109.md)
