# 第470轮　双区间直积的全坐标切片费用

- A 覆盖全部等权深度轮廓，中央误差有界。
- 同一目录的所有坐标在奇数维均有严格切片损失，在偶数维均无损。
- 下一步须区分中央增长与一般目录的累计切片费用。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取 $[0,2],[1,3]$ 的所有 $n$ 重直积，门槛取一半。记 $C_n^*$ 为最小源体积（严格成功取下确界）。按各轴反射及坐标置换平均单位网格原子密度。各行平均相同；具有 $j$ 个公共段坐标的层体积为 $v_j=\binom nj2^{n-j}$，每行内体积为 $\binom nj$。单位源收益随 $j$ 严格递增，故最优解依次填充高层。取 $b_j=1$ 对 $2j>n$，$b_j=0$ 对 $2j<n$，中央层取半。二项对称性保证每行恰好半满，$C_n^*=\sum_j b_jv_j$。有限原子内可切块实现，微增密度可恢复严格平均。

任意坐标的每个非空切片都包含全部低一维目录，故 $S_n=3C_{n-1}^*$，约定形式零维费用为一半。按末坐标是两个外段或一个公共段求差，每个低维层的系数为 $3b_j^{(n-1)}-2b_j^{(n)}-b_{j+1}^{(n)}$。在 $n=2k$ 时只有 $j=k-1,k$ 的系数非零，分别为负二分之一和一，层体积比为二，故差为零。在 $n=2k+1$ 时只有中央层系数二分之一，故 $S_n-C_n^*=2^{k-1}\binom{2k}k$。本机 Python 以有理数核对了前64维。

同门槛递归的累计费用倍率为 $3^n/(2C_n^*)$。Stirling 公式和上尾相邻层体积比至多一半给出 $C_n^*=\Theta((2\sqrt2)^n/\sqrt n)$。故累计损失的对数为 $n\log(3/(2\sqrt2))+\tfrac12\log n+O(1)$。此目录本身的体积增益远低于中央基线，例子只排除了对任意目录一律要求累计次多项式损失的做法。
