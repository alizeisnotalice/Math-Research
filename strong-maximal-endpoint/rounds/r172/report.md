# 第172轮　调整选盒次序不能保证保留较厚的新增区域

2026-11-12。在中央门槛 \(p=1/2\) 构造同一有限指标源的真实见证族。任取子族、任意排序，即使允许每个盒的新增区域形状任意，只计新增占比至少 \(1/n\) 的那些盒，也只能保留原接收并集的指数小比例。这排除了以统一几何排序补足[第171轮](../r171/report.md)薄新增区域的方案。一般系数差仍为 \((\mu-1)/8\)。

**排序无关的估计。** 设全部盒的并为 \(U\)，在其任意有序子族中定义 \(A_j=R_j\setminus\bigcup_{i<j}R_i\)。对任意可测测试区 \(G\subset U\) 及 \(0<t\le1\)，
\[
\frac1{|U|}\sum_{|A_j|\ge t|R_j|}|A_j|
\le \frac{|U\setminus G|}{|U|}+t^{-1}\sup_R\frac{|G\cap R|}{|R|}.
\]
第一项用新增区域互不相交。第二项用被计盒的体积总和至多 \(|U|/t\)。该估计也同时约束仅保留原并集一部分的选盒策略。

**实际源与接收体积。** 取偶数 \(n\)，每轴在 \([0,2]\) 与 \([1,3]\) 间二选一，所有 \(2^n\) 个积盒体积均为 \(2^n\)，并为 \(U=[0,3]^n\)。忽略零测边界，记 \(L(x)\) 为落在中段 \([1,2]\) 以外的轴数。均匀取于任何一盒时 \(L\sim\mathrm{Bin}(n,1/2)\)，均匀取于并集时 \(L\sim\mathrm{Bin}(n,2/3)\)。同一源 \(E=\{x\in U:L(x)\le n/2\}\) 在每个盒的平均为 \(1/2+2^{-n-1}\binom n{n/2}>1/2\)，所以整个并都是严格接收点。实际指标分母为 \(|E|=\sum_{i=0}^{n/2}\binom ni2^i\)。末项最大且前项与后项之比至多 \(1/2\)，由 Stirling 得
\[
\log(|U|/|E|)=n\log(3/\sqrt8)+\tfrac12\log n+O(1).
\]
这是该盒族的实际体积比，对源在其他矩形下的全部接收体积只给下界。

**比阈值厚的新增区域。** 取 \(G=\{L\ge7n/12\}\)。由两个二项分布的 Hoeffding 界，前式右端至多 \((1+t^{-1})e^{-n/72}\)。故连 \(t=e^{-o(n)}\) 也只能收回指数小比例。该结论对所有子族和次序同时成立，且允许查看实际源后再选盒。在 \(t=1/n\) 下直接算两条精确二项尾（下附入口），当 \(n=1200\) 时得到比例上界 \(5.122\times10^{-6}\)（向上取整），对应 \(\log(|U|/|E|)\) 约 73.75262。局部几何障碍是解析结论，十进制仅用于展示。

**对全局路线的限制。** 此族的指数率 \(\log(3/\sqrt8)\) 低于中央目标主率 \(\mu\)。故不能据此排除在接近目标主率的源上作选择，也不能断言这些接收点躲过第170轮的例外集。下一步应把源的体积比纳入筛选：先估计令见证均匀分布与接收均匀分布显著分离所需的共同源质量，再检验这种质量估计能否排除达到主率的薄新增覆盖。[整数计算](check.py)
