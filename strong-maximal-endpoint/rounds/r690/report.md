# 第690轮　斜率与平台宽度联动的常数级增益

2026-11-13。固定 c=μ，L=log n，σ=√μ。对固定 a≥0 取斜率 β/n，其中 β=1+a√(L/n)，平台宽 w=(1+a²)L/2+2log L。沿用第19轮平台前为零、平台高一的物理轮廓。相对于第19轮同 c 的平台，对数评分增量趋于 σa−a²/2。该固定参数族的最优 a=σ，增量为 μ/2。

分母。尾积分 I(β)=∫₀∞ exp(−x+βx/n)(1+βx/n)^(n−1) dx。令 y=1+βx/n、r=n/β−1，则 I≤(n/β)exp(r)Γ(n)/r^n（延伸积分到零）。Stirling 展开得 log I≤L/2+a²L/2+O_a(1)，因为 r/n=1−a√(L/n)+O_a(L/n)，n(r/n−1−log(r/n))=a²L/2+o(1)。故 K=1+exp(−w)(I−1)=1+O_a(L^(−2))。

分子。写 q_s 为第19轮同 c 的纯斜坡软根，S 为该轮独立和。测试 q=q_s+t，固定 t。相对单位斜率、平台宽零的平均 A(q)，新平均的差为
$$ [(β−1)\mathbb E(S−q)_+−βw]/n+o(L/n). $$
细节：在 S≥q 上，两个指数的非负指数分别为 u/n 和 β(u−w)_+/n，u=S−q。差的一阶项用精确差商积分；将差商中的指数换为一的误差至多常数乘 E[((β−1)u+w)u exp(2u/n)1_{u≥0}]/n²=o(L/n)。这里 E[u_+² exp(2u_+/n)]=O(nL)，由 Cauchy–Schwarz、中心四阶矩 O(n²)、q=nμ−(σ+o(1))√(nL) 及显式独立增量 mgf 得出。用 w 代替截断的 min(u,w) 仅损失 o(L)，因 P(S<q+w)=o(1)（Chebyshev）。同理由 E|S−nμ|=O(√n) 得 E(S−q)_+=(σ+o(1))√(nL)。

第19轮根附近密度 f~L/n 给 A(q_s+t)=1−tL/n+o(L/n)。故新平均减一为 [−t+aσ−(1+a²)/2+o(1)]L/n。取极限零点两侧固定测试值，以单调性夹住根。扣除已控制的分母，对比旧平台 q_s−1/2+o(1)，即得增量。严格见证仍从根下逼近。结合第18、19轮固定 c 展开，这给该新族在 a=σ 时的常数项 b₀−1/2+μ/2（中心为 nμ−d_n+[(3−μ)/6]z_n²，b₀=(5μ−6)/6）。这是选定物理族的乘法改进；一般端点对数系数未定。下一步把同一扰动与偏移的最优矩形比例结合，并检验非线性软段是否能进一步提高常数。
