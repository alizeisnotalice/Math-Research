# 第100轮 允许前缀自由变化的对数凸截面锐上界

日期为2026-11-11。写 $L=\log N$。固定 $k$ 个前缀坐标，允许后 $N-k$ 维截面的大小、形状、中心和各轴尺度随前缀任意可测变化。如果几乎所有非空截面都是经平移和可逆对角伸缩的无条件对数凸下集，且 $k\log L=o(L^2)$，则
\[
\log\sup_E |\{M_S1_E>p_N\}|/|E|=q_{0,N}+c_Q L+o(L).
\]
低门槛用真实截面的锐指标价，高门槛用一般高斯秩上界。前块强型价格中的 $\mu k$ 与后块维数下降精确抵消。完整 $N$ 维等权双曲十字给匹配下界。[证明和任意源的截面必要条件](strip100.md) · [独立审查](strip-audit.md)

对一般源，若完整对数价高出基准 $\gamma L$，任何这种前缀坐标选择下都必须有一部分源体积落在高价截面中。去掉截面假设还需要控制这部分体积或它的跨层复用。下一步研究真实覆盖混合中的深核心亏损，并用连续门槛积分检验可容许的前缀维数。

一般端点的已证对数系数介于 $c_Q=(9-\mu)/24$ 与 $c_R=(3+\mu)/12$ 之间。以 $B_0=e^\mu$ 计，现有下界距离为 $N\log B_0-\log Q_N=d_N-c_Q\log N+o(\log N)$。
