# 第85轮：真实单方向费用与源分配的精确熵障碍

日期：2026-11-11。状态：本轮严格结果与独立核验完成，研究继续；一般锐上界未闭合。

固定一个相对方向 $\sigma\in\{\pm1\}^N$，允许每个接收点自由选择全部边长的真实矩形极大算子 $M^\sigma$，其cap-$A$最优端点常数恰等于已知单物理角点常数 $K=K^{\rm H}_{N,A}$。这给出可实际支付的方向残差；但对达到已知下界量级的真实径向主体，保留原成功矩形所需的逐方向源费用有精确熵障碍，预算率比目标高 $\log\mu$。[完整证明](core85.md)，[独立审查](audit85.md)。

## 1. 可以直接结算的物理残差

单方向真实算子只满足 $M^\sigma\le P_N^{\sigma_N}\cdots P_1^{\sigma_1}$，未声称与坐标极大的复合取等。单侧rising-sun给重排 $\le H^N F^*$，接回第28轮 $r=0$ 的精确Gamma标量常数；同象限近极值给反向。这与双侧非中心坐标算子的反馈模型不同。

令 $m_F(x)=\#\{\sigma:M^\sigma F(x)>1\}$，则
\[
|\{m_F\ge q\}|\le\frac{2^N K}{q}J_N(F),\qquad
\left|\bigcup_{\sigma\in U}\{M^\sigma F>1\}\right|\le |U|KJ_N(F).
\]
因此高方向重合区、少数固定方向的成功区可直接按真实物理体积支付。任意可测方向源片也有
\[
\left|\bigcup_\sigma\{M^\sigma G_\sigma>1\}\right|
\le K\sum_\sigma J_N(G_\sigma),\quad 0\le G_\sigma\le F.
\]
这些是有适用范围的上界，并未控制剩余全部halo。

## 2. 真实主体的方向分散和精确源费用

第69轮校准参考 $r_N=e^{-c_N}$，$c_N=\mu-\sqrt{\mu\log N/N}/2$，给cap2单调径向源及有限深截断 $L(N)$。其真实接收壳 $E_N$ 满足
\[
|E_N|/J_N(F_N)=Q_N\exp(o(\log N)),
\]
每点的原矩形 $R_x=\prod_i[-r_Nx_i,x_i]$ 平均严格超过 $1+N^{-2}$。先固定 $N$ 再选有限 $L(N)$ 同时逼近费用和壳体积；没有交换两个极限，也没有把未知 $L(N)$ 冒充已计算的有限输入。

该壳每点成功方向只可能在向内方向的 $o(\log N)$ 个坐标上改变符号，故 $m_F\le\exp(o((\log N)^2))$。但方向随象限遍及全部 $2^N$ 个标签。因此仅有 $Q_N/K=\exp((\mu-1)N+o(N))$ 个固定方向无法捕获其正比例，高方向重合残差也遗漏该主体。

更强地，对任意固定 $0<\theta\le1$，记 $b_N(\theta)$ 为任意真实源片 $G_\sigma\le F_N$ 保留至少 $\theta|E_N|$ 个**原矩形**严格成功的最小实际模块倍数。则
\[
\boxed{\lim_{N\to\infty}\frac{\log b_N(\theta)}N
 =h_2\!\left(\frac{\mu-1}{\mu}\right)
 =\mu-1+\log\mu=0.5241243246575\ldots.}
\]
在目标预算率 $\mu-1=0.2784645427611\ldots$ 下，保留成功的比例指数小；精确指数隙为 $\log\mu=0.2456597818964\ldots$。

下界把实际物理接收点 $X$ 和矩形样本 $Y_i=X_iU_i$ 的符号模式、Jacobian与源模块一并结算。典型负号模式的概率率正是二元熵。匹配上界在每个源点保留Hamming半径 $Np_N+2\sqrt{N\log N}$ 内的方向；实际模块倍数恰为该球基数，Hoeffding给丢失平均 $\le2N^{-8}<N^{-2}$，保留全部原矩形。允许源片任意小振幅和任意空间重叠，未用更强的线性振幅收费替代实际Orlicz费用。
