# 第138轮　两块任意指标集的真实中央上界

2026-11-12。对固定 A<∞、c>0、D>0，n=m+k，m≥k≥c(log n)²，任取有限正体积的可测指标因子 F⊂ℝᵐ、G⊂ℝᵏ，在充分大 n 时一致有
log(|{M1_{F×G}>p}|/(|F||G|)) ≤ μn+σ√n u−D log n， p=1−Φ(u)，|u|≤A。
这里没有对两因子施加对数凸或单调假设。几何条件是整个源为一个笛卡尔积，不能将该结论用于任意盒并的跨分量见证。一般端点上下系数差仍为 (μ−1)/8。

记 U(z)=Φ⁻¹(1−z)，U(1)=−∞。第91轮式 (6) 的全局高斯包络在任意固定内部紧区间给 log H_j(z)≤μj+σ√j U(z)+O(log j)，常数可依赖紧区间（第110轮中央证明中说明了秩平移、方差扰动和绝对误差）。以下只在固定紧区间调用。对真实乘积源，强极大函数恰为 b_F b_G，两因子可各自用严格矩形逼近。故可用有限个门槛矩形覆盖标量事件 b_F b_G>p，用两维数各自的指标常数为其联合体积定价。下面用子列法证明一致性：若命题失败，在反例序列上抽取 k/n 有极限。

**极限为零。** 取常数 q₀∈(max p,1)，分为 b_G>q₀ 与 b_G≤q₀ 两支。第一支联合价格至多 H_m(p)H_k(q₀)，第二支至多 H_m(p/q₀)H_k(p)。记中央主项为 B=μn+σ√n u。第一支的对数减 B 至多
σ U(q₀)√k + O_A(k/√m)+C_A log m+C_{q₀}log k。
因 k=o(m)，第一误差为 o(√k)，最后一项也为 o(√k)。先选 q₀ 足够靠近 1，使负项用 √k≥√c log n 支付 (C_A+D+3)log n，并留出吸收 o(√k) 的余量。第二支满足 U(p/q₀)≤u−d，其中 d>0 由 p 的紧区间和固定 q₀ 给出。因此第二支对数减 B 至多 −σd√m + O_A(√k+k/√m)+O_{A,q₀}(log n)。该负项最终超过任意固定对数费用。两支求和的 log 2 可吸收。常数选择按此顺序进行，未用趋近 1 门槛的一致粗估计。

**极限为正。** 令 α=√(m/n)、β=√(k/n)，此子列上两者远离零且 α²+β²=1。若 b_F b_G≥p，写 v=U(b_F)、w=U(b_G)，则 v,w≤u。对有限 v,w，取独立标准正态 X,Y。事件 X>v、Y>w 的概率为 b_F b_G，严格小于 αX+βY>αv+βw 的概率，因为半平面在该象限之外还含有正测度开集。因此 αv+βw<u。对本子列所用权重及 p 的紧参数域，有一致严格余量 d'>0：先将低于 −M 的 v,w 截到 −M，取固定 M 足够大使任何含被截项的加权和≤−A−1；其余情况在有限闭矩形中用连续性及上述严格不等式。这个证明也包括某个原始分位为 −∞ 的情形。

将截断后的两个分位各向上取整到固定网格并再加一格，以保证实际函数值严格大于对应门槛。网格步长足够小，使加权总误差小于 d'/2。只保留与成功事件相交的格子；门槛个数有固定上界，全部位于内部紧区间。每格联合对数价格≤B−σd'√n/2+O(log n)，有限求和仍优于 B−D log n。两种子列均无反例，得证。

**适用边界与交接。** 这使第110轮的中央充分条件在上述真实乘积类内具有任意固定对数余量。第110轮要推出一般 Orlicz 端点还要求控制所有指标源；第92轮归约中的指标源没有已证的两块独立分解。第119—136轮的换盒证书也不能代替这一步。若继续，最直接的问题是：能否对每个无此分解的源，用实际见证的联合体积分层，得到类似半平面与联合成功事件之间的定量差，并控制分层重叠。暂停时保留这一缺口。
