# 第707轮　独立标量机制的绝对 1/log n 项与高维小尾更正

2026-11-14。状态：严格细阶渐近，原生 Astra 独立审查通过；本机 Mathematica、Python 多核计算及定向区间证书实际完成。保持用户目标“二阶精确常数”，未推进一般上界闭合。

## 本轮结果

沿用第706轮 μ、精确隐式 z_n、d_n、c_Q=(9−μ)/24、B_Q=(13μ−15)/12。完整独立比例标量机制满足
$$ \boxed{\log Q_n=\mu n-d_n+c_Qz_n^2+B_Q+
 \frac{-4\log z_n+A_Q}{z_n^2}+o(z_n^{-2}),\qquad
 A_Q=\frac{\mu+3}{8}-\log(2\pi\mu).} $$
数值上 A_Q=−1.5487287804606667900887993…。这里 z_n 是 barΦ_G(z_n)=√(μ/n)z_n 的精确根。

在前面 c_Qz_n² 保持不变时，新增项也可写成 [−2log log n+A_Q]/log n。若把 c_Qz_n² 本身也展开，则 log log n/log n 的总系数改为 −(μ+3)/6，详见[完整证明](proof.md)式(18)。两种记法不能混合。

一般 C_n 获得相应实际输入下界，未得到同精度等价式。若 E_n 表示框内显式部分，则 liminf z_n²[log C_n−E_n]≥0。严格成功、固定维数有界截断及深层物理见证转换沿用第18、22、705轮，近极值误差可取 o(z_n^(−2))，例如 z_n^(−4)。

## 系数来自哪里

相对于 μn−d_n+c_Qz_n²：

|来源|常数项|1/z_n²项|
|---|---:|---|
|纯软根与独立比例优化|b₀−(μ−1)/4|(7+5μ)/8|
|最佳临界斜坡相对软根|(μ−1)/2|−4log z_n−log(2π√μ)−μ|
|任意非减标量轮廓相对斜坡|0|D₀=(μ−1−log μ)/2|

三项合并为 B_Q 与 −4log z_n+A_Q。软根必须使用全轴二阶 Edgeworth 的 O(n^(−3/2)) 余项，不能沿用单阶展开的 O(1/n) 余项。斜坡根的导数必须保留 A(q_s)=1，预算必须保留 log K∼1/N，这些都会改变新系数。

本轮也得到更有效的重求和表达式：令当前方差为 V，a=K₃/(6V)、R=barΦ_G(z_V)/φ(z_V)、H=(1+R/z_V)^(−1)，则
$$ q_s=M-\sqrt Vz_V+
 H\left[a(z_V^2-1)+\frac Vn\left(1+\frac{(1-z_V^2)R}{2z_V}\right)\right]+o(1/\log n). $$
它把慢收敛的 Mills 修正保留下来，适合有限维计算。所有误差对定位类 D≤K log n 一致，允许无界及无穷单坐标比例；随后可分别优化全部比例向量。

## 数值异常、认证反例与更正

本机 SciPy 1.18.1 的 gammainc 在所测大形状参数、标准化自变量略小于−4.5的点出现明显偏差，不能仅靠混合根残差或二项截尾稳定性排除这种误差。尚未把偏差归因于具体实现代码。

例如 n=16777216，精确二进制输入 x=4498651739637745/268435456。正项级数加定向区间算术认证给

0.000003371471354642103386455 < P(Gamma(n,1)≤x) < 0.000003371471354642103386457，

而本机库返回约0.0000030699662038556284。该点的概率相对误差约8.9%。向右平移2后误差急剧减小，具体结果与另外三个形状参数的测试见[12个概率证书](gamma_certificates.json)。

证书使用
P(n,x)=exp[n log x−x−log Γ(n+1)]×Σ_{j≥0} x^j/(n+1)_j。
所有项为正，在 x<n+j+2 时，j之后的尾用下一项除以1−x/(n+j+2)界住；本批证书满足更强的0<x<n。Stirling对数余项在0与1/(1260n⁵)之间。区间精度60位，输出十进制端点用精确二进制有理数向外舍入，12个概率区间的最大宽度小于1.001e−27。Stirling余项的符号和首遗漏项上界见[NIST DLMF §5.11(ii)](https://dlmf.nist.gov/5.11#ii)。

Mathematica在4个中心异常点以80/120位计算，结果均落在这些区间内。为修正后续混合实验，另由正Laplace积分构造稳定小尾计算，用32/64点Gauss–Laguerre求积，与12个概率证书逐点比较的最大绝对偏差约1.28e−20；完整混合根重算见[corrected.json](corrected.json)。这些点的认证不能扩张为整个混合评分的区间认证。

[第706轮高维数值更正](corrected_r706.json)使用原来相同的比例搜索范围、容差及输入参数重新优化。旧的受影响高维浮点表项保留为历史记录，不再承担精度证据；第706轮解析证明及绝对常数结论不依赖这些表项，未发生改变。本轮常数推导亦独立于浮点求和。
