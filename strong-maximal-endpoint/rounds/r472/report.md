# 第472轮　异门槛切片的水平集与一维接收恢复

- A 覆盖全部等权深度轮廓，中央误差有界。
- 任意目录的向量门槛可经一个共同水平集恢复全部接收点，代价为一维 halo 在显式门槛处的费用。
- 下一步须联合多个水平以削减第一个单水平估计产生的半对数损失。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。令 $R_j=I_j\times B_j$，$T=\bigcup R_j$，$C$ 为同一目录在门槛 $p$ 下的最小原源体积。使用第471轮最优解 $u_{Dj}$，在 $D$ 上置 $u_j(x)=u_{Dj}$。固定 $0<q<p$，定义 $F_q$ 的切片为所有 $u_j(x)>q$ 的活跃基底盒之并。则
\[
 |F_q|\le H_{n-1}(q) C,\qquad
 |T|\le H_1(\alpha-) |F_q|,\qquad \alpha=(p-q)/(1-q).
\]
第一式逐段用同一基底最优密度，切块保持全部平均，再按段长求和。第二式固定 $y\in B_j$：在 $I_j$ 上 $u_j$ 的平均至少为 $p$，故 $u_j>q$ 的长度比例至少为 $\alpha$。这些点均在 $F_q^y$，所以整个 $I_j$ 属于该纤维在任何门槛 $\alpha'<\alpha$ 的一维 halo。沿 $y$ 积分后令 $\alpha'\uparrow\alpha$。特别地由区间并的二重覆盖界有
\[
 H_n(p)\le\inf_{0<q<p}\frac{2(1-q)}{p-q}H_{n-1}(q).
\]
这里取有限严格目录再穷尽即可，无需估计切片上不同见证的总数。

在中央紧区间取 $q=p-n^{-1/2}$，中央基线位移为 $O_I(1)$，而显式恢复因子的对数为 $\tfrac12\log n+O_I(1)$。因此这次降维尚未达到所需的次对数精度。就仅用行平均与 $[0,1]$ 取值推断好段比例而言，$\alpha$ 已最优：一行上以比例 $\alpha$ 取一，其余取 $q$ 即达等号；严格情形可从上逼近。取有理数 $p=1/2,q=2/5$ 时，$\alpha=1/6$，本机 Python 精确核算。此锐性仅针对单行好段比例，不证明实际 halo 递推一定损失半对数。
