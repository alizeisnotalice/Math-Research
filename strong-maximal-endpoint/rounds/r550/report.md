# 第550轮　预定坐标组上的逐轴放松可以处处取等

- A 的全部等权深度轮廓已有中央有界误差（第325轮）。
- 给定总共涉及次对数个坐标的放松方案，可以在所有这些方案上同时取等，且保留基底在中央基线以上的对数增益至次对数误差。
- 待证仍是对每个有限有理盒并和每个中央门槛的真实矩形 halo 体积上界，误差须与盒数、方向和网格无关。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。设预定坐标组的并集大小为 $d$，重排后为最后 $d$ 轴。取任意正有限体积的 $k$ 维有理盒并 $G$，置 $E=G\times[0,1]^d$，$n=k+d$。对每个接收点 $(x,z)$，矩形平均等于基底盒平均乘上各区间的一维平均。各因子非负且区间可以独立选取，因此取上确界给出
\[
 M_S1_E(x,z)=M_S1_G(x)\prod_{j=1}^d M_1 1_{[0,1]}(z_j).
\]
其中基底上的 $M_S$ 使用同一个真实矩形。任选上述 $d$ 轴的子集，将其轴依任意顺序逐轴取极大，其余轴合用一个真实矩形。每次单轴运算只替换对应的一维因子，剩余矩形平均仍可分离，故所得函数与上式处处相同。结论包含源外接收点，也包含全部严格门槛。

记 $H_G(p)=|\{M_S1_G>p\}|$，$r=\log(H_G(p)/|G|)-B_k(p)$。在单位立方体内部新增因子都等于一，$|E|=|G|$，故
\[
 \log(H_E(p)/|E|)-B_n(p)\ge r-\mu d-
 \sqrt\mu\,\Phi^{-1}(1-p)\frac d{\sqrt{k+d}+\sqrt k}.
\]
这是直接的同门槛比较，对 $p\in I$ 一致。若 $d=o(\log k)$，基底的对数增益最多损失 $o_I(\log k)$。特别地，对任意预定方案菜单，只要坐标并集满足该条件，中央基线精度无法迫使菜单中哪怕一个方案出现正差集。若假设存在有正对数阶超额的基底序列，此构造同样保留其超额系数。此处没有断言这种超额序列存在。

下一步对源依赖的选轴须证明：若真实体积超过目标，则某个选择产生足以支付超额的乘性改进。另一条直接路线是指南 C 的原空间合成核，固定接收并集及共同源，估计最高源体积份额。上述乘积测试要求这类估计在附加区间因子后仍成立。

离散算例：在三点轴上取二维对角线指标作为基底，附加两个三点轴上的区间指标，穷举含点的离散区间，以 Python 有理算术逐点比较全矩形平均上确界和两个单轴放松后的基底极大。
