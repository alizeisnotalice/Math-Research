# 第376轮　首点之后的预测信息具有不可避免的平方根损失

- A 已覆盖全部等权可测深度轮廓，误差有界。
- 对任意固定 $0<p<1$，真实有限有理成功目录可有 $H=\Theta_p(\sqrt n)$，而任意多次同盒命中提供的标签信息均为零。第375轮对全体 $H=O(n)$ 的误差阶最优。
- 仍须利用接近中央基线的额外假设排除或支付此损失。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取 $E=[0,1]^n$，$0<L<\log(1/p)$，考虑包含 $E$、体积严格小于 $e^L$ 的全部轴平行盒。其开内部并在零测边界外恰由 $\sum_i\log(1+\mathrm{dist}(x_i,[0,1]))<L$ 给出，这是包住 $E$ 与 $x$ 的最小盒条件。可只用有理端点，因严格体积余量允许向外有理逼近。按在单位区间外的坐标数 $k$ 积分，区域体积 $V$ 满足
\[
 \sum_{k=0}^n {n\choose k}(2L)^k/k!\le V\le e^L\sum_{k=0}^n {n\choose k}(2L)^k/k!.
\]
此处用对数距离作变量后雅可比在一与 $e^L$ 之间。上界至多 $e^{L+2\sqrt{2Ln}}$。下界只取 $k=\lfloor\sqrt{2Ln}\rfloor$：因 $k=O_L(\sqrt n)$，下降阶乘 $(n)_k\ge n^k e^{-O_L(1)}$，Stirling 得该项对数至少 $2\sqrt{2Ln}-O_L(\log n)$。穷尽可数有理盒目录后可取有限子并体积超过 $V/2$。每盒原平均严格大于 $e^{-L}>p$。故有限目录具有
\[
 H=2\sqrt{2Ln}+O_L(\log n).
\]
给定任意见证标签，命中点均匀于同一 $E$；同标签独立多次命中的联合律总是 $P_E^k$，与标签独立。因此第375轮增量互信息恒为零，对所有接收分区、所有观测次数同时成立。

这也给出了第361轮几何外包在固定 $L$ 下的首项常数；不是一般中央目标的反例，因为这里 $H/n\to0$。下一步应测试这种公共子盒几何与中央基线在不交坐标上的组合，并结算为保持同一门槛而付出的原密度费用。
