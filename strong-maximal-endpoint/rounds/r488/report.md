# 第488轮　按双覆盖接收体积扰动见证需求

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对双覆盖带按实际标签计量两个见证的接收份额。最优对偶加权和的上确界等于最小源体积的一侧导数，并有不依赖见证数的上界。
- 下一步须从切片高门槛条件给出同一扰动的源体积增长下界。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定第481轮的可测双覆盖带 $B$，仅保留有两条所选行的点。把每点同时记给这两行，得行计量 $d_i$，总和 $2|B|$ 且 $d_i\le |R_i|$。令 $C(e)$ 为各行需求从 $p|R_i|$ 加到 $p|R_i|+e d_i$ 后的最小源体积。若 $0\le e\le1-p$ 则全一源可行。原问题零点的最优对偶面记 $\mathcal T$。有限原子线性规划给
\[
 C'(0+)=\max_{t\in\mathcal T}\sum_i d_i t_i
 =\max_{t\in\mathcal T}\int_B(t_{i(x)}+t_{j(x)})dx .
\]
具体证明：将对偶罚项用各原子的非负附加变量线性化，得到与 $e$ 无关的有限多面体。它由非负变量组成而无直线，且目标在零附近有界（小负扰动也可行）。最优值为有限个顶点仿射函数之最大值，所以右导数取零点最优顶点的最大斜率；零点的最优射线不可能有正斜率，否则小正参数无界。左导数同理取最小斜率。

对原问题每个最优乘子均有 $t_i\le1$：若某一项大于一，则在整个 $R_i$ 权重和大于一，第487轮的互补性使该盒全满，而正乘子又强制行平均恰为 $p<1$，矛盾。故在 $B\cap\{w>1\}$ 上该点的两个权重之和也至多二。结合 $|\{w>1\}|\le C(0)$，得
\[
 0\le C'(0+)\le |B|+\min(|B|,C(0)).
\]
若中央带的 $|B|/C(0)$ 指数大，则任何最优对偶的按双标签计数的平均行权至多 $1/2+C(0)/(2|B|)$。本式还适用于无需任选对偶的最大斜率，未给出左侧正下界；有限参数上线性段何时结束依赖目录。

**检验。** 在基底相同、长度均为二、公共段长度一的两行模型中，取 $B$ 为公共段、基底单位体积、$p=1/2$。有 $d_1=d_2=1$，$C(e)=\max(1+e,1+2e)$ 对零附近成立。右导数二、左导数一，右导数达到上述上界。高维中央比值条件在该例不成立。本机 Python 以有理数核对了两侧差商。
