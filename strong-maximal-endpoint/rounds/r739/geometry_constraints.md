# 近中央 LF 信息谱：拼接不变量与非高斯机制的排除

本稿只研究真实有限轴平行矩形目录，保留实际负责权与 LF 条件。目标是检验：稳定 q、稳定 rho 和 `log G>=mu n-D log n` 是否足以保证存在某个 LF 权，使其信息密度满足 `Sigma=O(sqrt n)` 与 `epsilon=o(log n/sqrt n)`。本轮没有构造出满足全部近中央条件的反例，也没有证明该蕴含。以下给出不相交并的精确公式、共同核心机制的几何排除式及乘积构造的限制；这些结果说明若干看似自由的谱混合实际上不可行。

记单目录的完整并为 X、体积为 Omega，Q 为其均匀律，P_pi 为负责行混合，`L=log(dP_pi/dQ)`。本文的“存在某个 LF 权”与“每个 LF 权都满足正态逼近”严格区分：找到一个坏 LF 权只否定后一个更强命题，不能否定前一个。

## 1. 两个普适的谱不变量

负责分割 `X=union U_i`、`U_i subset R_i` 给 `pi_i=|U_i|/Omega`。所有 pi_i 正的行覆盖 X 几乎处处，因为其余 U_i 为零测集。因此负责混合相对于 Q 的密度 w 严格为正几乎处处，且

\[
E_P e^{-L}=1.
\tag{1}
\]

特别地，负责混合的 Sigma=0 必有 L=0、P=Q。若这种权还是 LF，则 s=q Omega，且 m_*>=s，故 `G<=1/q`，不可能近中央。不能把一个非零常数信息谱作为近中央负责例子。

还存在不依赖行数和行体积的粗二阶矩界

\[
E_P L^2\le C(n+1)^2.
\tag{2}
\]

证明只需项目 r725 已引用的强矩形 L2 范数 `||M_S||_2=(1+sqrt(2))^n`。对任意非负 g，负责分割给

\[
E_Pg=\Omega^{-1}\sum_i\int_{U_i}\fint_{R_i}g
\le\Omega^{-1}\int_XM_S(g1_X)
\le(1+\sqrt2)^n\|g\|_{L^2(Q)}.
\]

由对偶性 `||w||_{L2(Q)}<=(1+sqrt(2))^n`。令 `A=2 log(1+sqrt(2))`，得到

\[
P(L>An+t)\le e^{-t},\qquad P(L<-t)\le e^{-t},\quad t\ge0.
\]

积分尾界即有 `E L_+^2<=(An)^2+2An+2`、`E L_-^2<=2`，证明 (2)。这只是 O(n^2) 原始二阶矩界，绝不能冒写成所需 O(n) 方差。

## 2. 不相交并：负责质量不是自由参数

设有限多个目录的完整并 X_j 两两不交，且所有行都位于其所属分量。写

\[
\Omega_j=|X_j|,\quad w_j=\Omega_j/\sum_l\Omega_l,
\quad Q_j=\operatorname{Unif}(X_j).
\]

全局负责权必且只可能形如

\[
\pi_{j,i}=w_j\pi_i^j,\qquad \pi^j\in\Pi_j.
\tag{3}
\]

必要性可由实际分割直接看出，也可把 Hall 约束分别用于整个第 j 分量的标签及其补集，得到该分量标签总质量恰为 w_j。反向由各分量负责分割的并实现。

所以 P 与 Q 在分量上的质量完全相同：

\[
P=\bigoplus_jw_jP_j,\quad Q=\bigoplus_jw_jQ_j,
\qquad L|_{X_j}=\log(dP_j/dQ_j)=L_j.
\tag{4}
\]

**实际谱确实是权重 w_j 的分量谱混合，但没有任何额外平移。** 若把非负责标签总质量记为 v_j，才会出现 `L_j+log(v_j/w_j)`；负责条件强制 v_j=w_j，恰好消去该项。通过平移、各向异性缩放调整分量体积只改变混合概率 w_j，不改变各分量的归一化谱。特别是不同尺寸的同一目录副本具有同一个 L_j，混合后谱毫无改变。

其均值和方差精确为

\[
M=\sum_jw_jM_j,\qquad
\Sigma^2=\sum_jw_j\Sigma_j^2+
\sum_jw_j(M_j-M)^2.
\tag{5}
\]

要靠分量均值差制造大方差，必须先找到真正不同的几何谱；纯体积差不能提供这个均值差。

## 3. 不相交并的 LF 价格是命中率分配问题

把局部 LF 价格归一化为

\[
\beta_j(t)=\max_{\pi^j\in\Pi_j}
\min_{0\le f\le1,\,P_{\pi^j}f\ge t}Q_jf,
\quad 0\le t\le1.
\]

由已经建立的有限共同源对偶，beta_j 同时是保证所有负责权命中 t 的最小 Q_j 预算；它是连续、递增、凸的分段线性函数，端点为 0 和 1。全局精确公式是

\[
\boxed{\displaystyle
\beta(q)=\frac{s}{|X|}
=\min_{\substack{0\le t_j\le1\\\sum_jw_jt_j=q}}
\sum_jw_j\beta_j(t_j).}
\tag{6}
\]

证明：将全局共同源 f 限制到各分量，令 `t_j=min_{pi^j}P_{pi^j}f_j`。全局最小负责命中率恰为 `sum w_j t_j`，而各分量至少花费 beta_j(t_j)。反向将达到各局部共同源价格的 f_j 拼接即可。最优时可以把总命中率取为恰好 q。

若全局 pi 为 LF，取一个共同最优源 f，则每个分量的 pi^j 都在其实际分配到的 t_j 上为局部 LF，f_j 为该局部共同最优源；同时所有非退化分量的 NP 检验必须共享一个**相对于 Q_j 的密度阈值**。这是因为全局似然比在 X_j 上正好等于局部似然比。不能把各分量任意选取的 q-LF 权直接拼接，便宣称它是全局 q-LF。

反过来，如果局部共同最优源和局部 LF 权在 t_j 上达到价格，`sum w_jt_j=q`，且这些选定检验拥有共同的 NP 阈值，那么拼接源既是全局共同可行源又是拼接权的 NP 最优检验，故拼接权确为全局 LF。

对内点分配，(6) 的最优性条件为存在一个共同边际价格

\[
\lambda\in\bigcap_j\partial\beta_j(t_j).
\tag{7}
\]

端点使用带 `[0,1]` 约束的次梯度。要拼接预先指定的局部 LF 权，仍应检查它们自身的 NP 阈值；共同 beta 次梯度仅说明存在最优价格分配。

记真实全行源的归一化价格为 `a_j(q)=m_j(q)/Omega_j`。不相交并满足

\[
\frac{m_*(q)}{|X|}=\sum_jw_ja_j(q),\qquad
\rho=\frac{\beta(q)}{\sum_jw_ja_j(q)}.
\tag{8}
\]

即使每个分量都在 q 处满足 rho_j=1，全局 rho 也未必为 1：全局检验可以通过 t_j 不等于 q 获得更便宜的预算。此时全局 rho=1 当且仅当恒定分配 t_j=q 在 (6) 中最优，等价于各 beta_j 在 q 的次梯度有公共交点。各分量行传递并不足以自动提供这个交点。

## 4. 近中央得分对分量的指数筛选

记 `g_j=log G_j(q)`，由真实源价格直接得

\[
e^{-\log G(q)}=\sum_jw_je^{-g_j}.
\]

所以近中央条件等价于

\[
\boxed{\displaystyle
\sum_jw_j\exp(\mu n-g_j)\le n^D.}
\tag{9}
\]

特别地，亏损至少 T 的所有分量总质量满足

\[
\sum_{j:\,\mu n-g_j\ge T}w_j\le n^De^{-T}.
\tag{10}
\]

固定正概率或多项式小概率的分量必须自身具有 `mu n-O(log n)` 得分。低指数率的共核星、单盒、已知低增益乘积等若被加入近中央目录，只能获得指数小的负责概率；不能让它们以固定概率生成非高斯混合。

也不能用指数小概率乘一个任意巨大的局部谱方差来补救：由 (2)，坏分量对全局 `E L^2` 的总贡献至多 `C(n+1)^2 n^D e^{-T}`。T 为固定正数乘 n 时，该贡献指数小；均值贡献同样可控。这个排除不依赖分量行数，也没有假设单块体积相近。

因此不相交并如果要成为真正反例，其具有多项式以上概率的分量就已经必须是近中央几何例子。该操作本身没有把一个低增益谱反例升级为近中央谱反例。

## 5. 共同核心大原子的几何排除式

设全部行盒都包含一个正体积矩形 C，令

\[
A=\max_i|R_i|/|C|\ge1.
\]

把 C 仿射归一化为单位立方体。若点 x 属于某个行盒，包含 C 和 x 的最小轴平行盒的体积不超过 A，所以

\[
X\subseteq\{x:\prod_{r=1}^n[1+\operatorname{dist}(x_r,[0,1])]\le A\}.
\]

令 k 个坐标位于核心外，并变换 `t_r=log(1+dist(x_r,[0,1]))`。每个外坐标有两个方向，Jacobian 为 e^{t_r}。因此

\[
\frac{|X|}{|C|}
\le A\sum_{k=0}^n\binom nk\frac{(2\log A)^k}{k!}
\le A\sum_{k\ge0}\frac{(2n\log A)^k}{(k!)^2}
\le A\exp(2\sqrt{2n\log A}).
\tag{11}
\]

最后一步由 `binom(2k,k)<=4^k` 比较指数级数即可得到。任何真实源都至少有体积 `q max_i|R_i|`，故对任意 q 有

\[
\boxed{\log G\le-\log q+2\sqrt{2n\log A}.}
\tag{12}
\]

若 qA<=1，该下界源质量可以在 C 内实现，因此还精确有 `m_*=q max_i|R_i|`。特别在 q=1/2、A<=2 时，所有混合在核心上有一个质量至少 1/2 的信息谱原子，正态 Kolmogorov 距离至少 1/4；但 (12) 将其得分限制为 O(sqrt n)，严格排除近中央。

更一般地，A 为 n 的多项式时，得分只有 `O(sqrt(n log n))=o(n)`。对于任意选定核心 C，`P(C)=|C| sum_i pi_i/|R_i|` 是核心对同一个信息谱原子的贡献，整个等密度层还可能更大；可变体积时不能把该贡献误写成 1/A。

若给定负责权的所有正权行具有相同体积 v，可把 C 取成这些正权行的完整交集。它们仍覆盖 X 几乎处处，而最大密度层恰为 C；若 C 有正体积，该层质量恰为 `p=|C|/v=1/A`。把 (11)—(12) 用于这个正权子目录，并用完整目录仍有 `m_*>=qv`，得到同一个得分上界。因此，任何靠这种最大密度共同核心层保留 `c log n/sqrt n` 以上质量的等体积构造，都有 A 为多项式，必被 (12) 排除。这个结论并不排除其它成员层形成的大原子。

此外，保 Lebesgue 测度且在行标签上传递的群作用强制所有行体积相同。“可变体积行传递”若仍声称使用这种对称性，定义已经不相容。允许带 Jacobian 的缩放群则不能继续直接沿用均匀负责权与 rho=1 的证明。

## 6. 乘积与填充不能跳过 LF 检验

全 Cartesian 积目录允许把负责分割取积，因此乘积负责权确实可行，且其信息密度为独立块信息密度之和。但两个因子分别在同一个 q 上 LF，并不自动使乘积权在 q 上 LF；两个 q 命中事件的积只有 q^2 命中率。全目录的真实最优源也不必是块源的积。

在各块行传递、取均匀权的特殊情形，积群仍行传递，才能直接认证乘积均匀权为 LF 和 rho=1。此时若独立块熵为 M_j，已有负责熵界给

\[
\sum_jM_j\le\mu n-\tfrac12\sum_j\log d_j+C_0h.
\]

如果另已证明该积谱的逆检验误差 `V-sum M_j<=E_n`，近中央必满足

\[
\tfrac12\sum_j\log d_j-C_0h\le D\log n+E_n.
\tag{13}
\]

当 E_n=O(log n) 且各块趋大，这排除了大量温和块。若未证明 E_n 的对数级控制，则不能仅凭 (13) 排除全部乘积，也不能利用它偷证所需 CLT。

把每个行盒都乘以同一个额外矩形 J 是另一种精确不变量：负责权多面体不变，所有预算按 |J| 缩放，G、rho 和归一化信息谱完全不变。故增加 r 个这种惰性坐标会在近中央基准中多损失 mu r；它不能以远大于 log n 的 r 免费制造新谱。平移、统一各向异性缩放也不改变谱。

## 7. 真正还缺哪一类几何例子

一个可能的条件性障碍是：找到两个真实近中央分量，它们在适当命中率上有兼容的 LF 阈值，而归一化谱在 sqrt n 尺度上具有不同的极限形状或不同的方差常数。固定正权混合后，(4) 保留这些分量谱，可能不再趋于一个标准正态。但目前没有给出这种几何分量，也没有证明它们的阈值兼容；因此这不是反例。

即使构造出一个这样的坏全局 LF 权，也只否定“所有 LF 权都正常”。要否定本轮闭合路线实际需要的“存在某个好 LF 权”，还须排除整个 LF 面中的其它选择，例如证明相关最优分配和局部 LF 权唯一，或对全 LF 面统一建立谱障碍。

任意离散信息谱若有原子质量 a，其与任一连续正态 CDF 的 Kolmogorov 距离至少 a/2。因此真正可检查的反例门槛之一，是在全部可选 LF 权上保留一个 `Omega(log n/sqrt n)` 的原子；但第 5 节说明最直接的共同核心实现无法同时保持近中央得分。任意概率空间里的两点谱或自由平移混合没有自动对应的真实矩形实现。

当前结论是：负责+LF+近中央条件尚未被证明推出目标谱条件；本轮也没有否定它。不相交并、同形缩放、惰性填充以及大共同核心这些自然操作均留下了明确约束，不能直接生成所需的近中央反例。
