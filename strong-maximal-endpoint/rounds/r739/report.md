# 第739轮　负责混合的密度层数亏损与联合谱排除

2026-11-14。一般 $C_n$ 的精确 $\log n$ 系数仍未确定。本轮得到一个真实负责混合的定量熵改进，并用两组几何必要条件分别排除两个抽象候选。

若混合密度 $w=dP/dQ$ 只有 $k$ 个不同正值，则存在绝对常数c,C>0使
$$D(P\Vert Q)\le\mu n-\tfrac12\log n-c\frac{\sqrt n}{k}+C.$$
等价地，熵缺额预算 $A=\mu n-\frac12\log n+C_0+1-D(P\Vert Q)$ 满足 $k\ge c\sqrt n/(A+1)$。因此常数级熵缺额要求至少平方根维数级的不同密度值。这计数的是**混合密度**，不是输入源的层数、矩形行数或成员原子数。[完整逐秩预算与附录B证明](rank_budget.md)。

关键在于：每个秩阶梯在对数坐标内都是截断单位指数律，故到阶梯起点集合的半指数矩至多2。KL变分和负责混合的耦合预算将其传给比较律，而最优独立比较律的密度峰高只有 $O(n^{-1/2})$，迫使足够多的起点。这项证明没有使用有限维扫描。

对任意实际负责混合，令 $w=dP/dQ$、$L=\log w$。负责分割与强算子范数给
$$\log E_Pe^{tL}\le nK(t),\quad K(t)=(1+t)\log c_{(1+t)/t},$$
其中 $c_q>1$ 解 $(q-1)c_q^q-qc_q^{q-1}-1=0$。解析展开为
$$K(t)=\mu t+\frac\mu2t^2-\frac{\mu(\mu+3)}{24}t^3+O(t^4).$$
不能把有线性熵亏损的单侧矩界逐次求导当作方差界。[完整证明](lp_spectrum.md)。

抽象秩密度 $k_n$ 是三个Gamma密度的正混合，保留均值 $\mu n-1$，具有自然信息方差、锐到常数的熵界、趋零反向KL，却有正的 $c_0\log n$ 中位数偏移，$c_0=0.1940873520810026\ldots$。还能逼近为有界正有限阶梯秩密度。这说明弱标量信息不足，不是矩形反例。[保留的逐秩KL预算及构造](rank_budget.md)。

进一步检查真实矩族：实际信息密度是 $L=T+\log k_n(T)$，不是T。Gamma主体的领先矩率为 $F_1(t)=\mu(1+t)\log(1+t)$，与K之差首项为 $\mu(\mu-1)t^3/24>0$；正混合保留违反。在固定 $t=1/10$，独立有理认证给
$$0.00001411891677682855533678003335204521785516464876468147205
\le F_1(1/10)-K(1/10)\le
0.00001411891677682855533678003335204521785516464876468147206.$$
该具体候选在所有充分大维数有线性阶矩违反，无法成为真实负责盒混合。同时保留此指定矩的阶梯逼近也被排除；不据此排除其它截断或谱。

这项排除没有使全矩族成为充分条件。另构造有限正三阶梯抽象谱，满足归一化、锐熵尺度、自然方差及三阶矩，并满足全部t>0的相同矩上界，却可有额外正log n检验位移，甚至平方根位移。全参数比较由解析的cosh界完成；48组数值参数的充分条件另通过精确有理检查。它仍不是盒/Hall/LF反例：本轮附录B已经用上述密度层数定理严格排除了它满足完整逐秩比较的可能。[三阶梯构造及限制](lp_spectrum.md)。

另有两条真实几何筛选：[证明](geometry_constraints.md)。不相交并的负责概率由分量体积强制决定，谱没有额外log权重平移；全局LF价格须分配命中率并匹配检验阈值。近中央得分迫使低率分量概率指数小，普适 $E_PL^2=O(n^2)$ 又排除巨大局部方差补救。全部盒共含核心C、最大体积比为A时
$$\log G\le-\log q+2\sqrt{2n\log A}.$$
多项式A只有次指数得分。这排除了最大密度大原子的直接共同核心实现，没有证明一般谱正常。
