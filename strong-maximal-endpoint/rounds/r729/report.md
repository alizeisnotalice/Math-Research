# 第729轮　非切向单调轮廓与全部角点跨原点盒

2026-11-14。一般 $C_n$ 的 $\log n$ 系数仍未知。本轮不仅控制预设动作场，还控制这类源的全部角点跨原点成功矩形，包括任意深度、相位和完整接收点依赖的侧比选择。

分解 $\xi=a+\lambda\boldsymbol1$，$\sum a_i=0$。对 $h\in C^1$，若
$$1-\lambda h'(\phi)>0\qquad(\text{所有相位}),$$
则隐式轮廓 $\widetilde h(\psi)=h(\psi+\lambda\widetilde h(\psi))$ 严格存在，且与 $h$ 值域相同、具有完全相同的源预算：
$$\langle e^{-\widetilde h}\rangle=\langle e^{-h}\rangle.$$
当半振幅 $A\le B\log n$ 时，全部指定角点跨原点盒的中位数成功集满足
$$\limsup_{T\to\infty}\frac{|\Omega_T^{\rm cross}|}{|E_T|}
\le \exp\{\mu n+o_B(\log n)\}.$$
若切向部分 $a=0$，无需相位均匀化，另有 $e^{\mu n+C}$ 界。[完整证明](noncentered_reduction.md)。

核心覆盖方向是逐点上包：对每个相位优化所有实侧比，利用严格平均裕量把实动作捕获为有理动作，再构造Borel近选择。第728轮对全部动作场统一的界因此控制优化包络，而原先任意深度依赖的动作都落在该包络内。没有预设中位数关于动作连续。立方体外的成功接收点必有每个坐标绝对值小于3，其体积只占源的 $O_{n,A}(T^{-1})$，对固定 $n,A$ 统一可忽略。

对余弦 $h=A\cos$，上述单调条件等价于 $|\lambda|A<1$；例如 $A=O(\log n)$、$\lambda=O(n^{-1/2})$ 时最终成立。切向频率部分可以任意大或很小。若单调条件失效，可能出现多支径向阈值，本轮不覆盖。

隐式变换、源成本、可测上确界、全部深度动作覆盖、纯径向分支及外部体积估计均经独立Astra终审通过。本机Mathematica实际核验区间占比导数、余弦换元抵消项和Gamma尾比，输出分别为0、0、exp(q)。脚本及原输出随附；内核已结束，未启动MATLAB。

这仍是指定角点跨原点盒族的深层上界。一般矩形与一般输入的覆盖尚未解决，一般系数区间仍保持 $[(9-\mu)/24,(3+\mu)/12]$。
