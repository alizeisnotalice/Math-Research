# 第522轮　任意固定阶切片检验可漏掉共同区间损失

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对任意 $N\ge3$，构造真实平面指标源，使任意 $N-1$ 类切片均有共同最优横区间，但全部 $N$ 类的局部选择损失恰为 $1/(4N^2)$。
- 下一步须直接控制全体切片共同区间，或给出随维数增长的多切片近似误差。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定 $x=0$ 与外区间 $J=[0,N]$，把 $J$ 等分成长度一的 $N$ 条带。类型 $i$ 的横向指标函数支撑于 $[0,4N]$。写 $d_{ij}=1_{i=j}$，$d_{i0}=0$。在第 $j$ 个长度四的单元中，仅把最右端长度 $2+d_{i,j-1}-d_{ij}$ 的子区间填满。各长度在一至三之间，所得平面源为有限矩形并。

在端点 $4j$，第 $i$ 类累计源长为 $2j-d_{ij}$。在一个单元内部，累计源长除以当前位置先递减（或为零）再递增，因此右侧前缀平均的最大值只需检查各正端点。更直接地，源长减去一半前缀长度先降再升，端点均非正。延至负半轴只增加分母，越过最右端也不能改善。因此每条切片最优值为 $1/2$；任何至多 $N-1$ 类切片漏掉某个标签 $j$，区间 $[0,4j]$ 即同时达到它们的最优值。相应任意低于 $N$ 阶的耦合下界均为零。

各类型等权合成的横密度在每个长度四单元内单调不减，其累计积分是凸函数。故任一端点之间的前缀平均不超过两端平均的较大值（首段由凸性及起点积分为零单独处理）。在正端点 $4j$，合成前缀平均为 $1/2-1/(4jN)$，最大在 $j=N$。由此 $L_J=1/(4N^2)$。若采用 $N$ 个边际均匀的耦合，让每次恰取每类一次（随机置换并在各条带内均匀抽点），每组的最小总损失均为 $NL_J$，故 $N$ 阶检验达到等号。此结论针对给定外区间，未证明全部近最优外区间有相同损失；也未将这一二维例提升到中央接收规模。

本机 Python 按所有整数端点穷举 $3\le N\le24$ 的真实指标源，核验单类上确界、去一类后的共同最优区间及总体损失。
