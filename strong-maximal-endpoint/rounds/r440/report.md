# 第440轮　任意预定交换宽度下的线性局部间隙

- A 已覆盖全部等权深度轮廓。对任意整数预算 $b\ge1$，均有真实有限矩形目录，使所有最多加入 $b$ 行的交换都严格降低证书，而全局最优值是当前值的 $\Theta(n)$ 倍。
- 该目录只实现低接收体积比。一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第439轮的 $m=2n$ 条独占臂、单位核心及 $l=1+1/m^2$。每个大盒为核心加一条臂；把每臂均匀切成 $K=b(m^2+1)+1$ 个有理矩形，目录的小盒改为所有这些片。以全并为源，门槛 $p=1/2$，各盒严格成功。所用证书为 $L(J)=|\bigcup_{i\in J}R_i|-\frac12\sum_{i\in J}|R_i|$。

初态选全部大盒，值 $1+1/(2m)$。若删 $d$ 个大盒、增添 $s$ 个小盒，其中 $u$ 个位于已删臂上，则相对初态的精确差值为
\[
 -d(l-1)/2-1_{d=m}+(2u-s)l/(2K).
\]
确实，独占臂移除的体积为 $dl$，新增并体积为 $ul/K$；最后一个大盒移除时另失核心。故只要 $s\le b$ 且 $d\ge1$，差值至多 $-(l-1)/2+bl/(2K)<0$。若只加不删也严格变差。这甚至允许一次删除全部大盒。反过来删一盒并在该臂加 $b+1$ 片即可严格改善，因为 $K(l-1)/l=b+1/(m^2+1)$。所以首次改善所需新增数精确为 $b+1$。

保留 $j\ge1$ 个大盒时，最优补充恰为其余臂的全部小片，值为 $1+ml/2-j/2$；不保留大盒则最优 $ml/2$。全局值 $(1+ml)/2$ 与第439轮相同，故全局与局部倍率渐近于 $n$。该反例对维数给定的任意交换预算 $b=b(n)$ 均成立，但目录数随 $b$ 增加，不排除按目录大小自适应的算法。对相应臂的小片作一次整体交换即可去除此障碍。下一步应把联合更新单位改为可用一个父矩形精确拼出的整批见证，检验合并会否改变严格成功条件及原费用。
