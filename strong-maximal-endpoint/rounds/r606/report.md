# 第606轮　正权行全部饱和时的大斜率可由公共核心产生

- A 的全部等权深度轮廓中央误差有界。
- 用真实有理矩形给出门槛质量函数的精确折点。即使每条正权行都饱和、对偶唯一且斜率比远大于平方根维数，目录增益仍可只有多项式规模。
- 待证的是同时利用中央接收规模与门槛窗内的累计增长，排除这种单折点超载作为唯一机制。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取单位立方体 $C$，第 $i$ 行 $R_i$ 仅沿正向把第 $i$ 轴伸长为二。目录并 $X$ 由单位核心和 $n$ 个体积一、两两不交的私有外片组成，$|X|=n+1$。容量域为整个 $X$。若源在核心取质量 $u\in[0,1]$，在各外片取 $z_i\in[0,1]$，需求正是 $u+z_i\ge2t$。对 $n\ge2$、$0<t<1$，最优质量为
\[
 m_X(t)=\begin{cases}2t,&t\le1/2,\\1+n(2t-1),&t\ge1/2.\end{cases}
\]
固定 $u$ 时最省的外片质量是 $(2t-u)_+$；当 $u<2t$ 增加核心质量每单位替代 $n$ 单位外片，故最优 $u=\min(1,2t)$。该非严格最优值由严格成功源逼近，见第604轮。

在 $1/2<t<1$，每个外片取 $2t-1\in(0,1)$，每行恰饱和。由部分填充外片的互补条件，每个最优对偶都须满足 $\lambda_i=1$；此权在第604轮目标中确实达到 $2nt-(n-1)=m_X(t)$。故对偶唯一，权重和函数在核心等于 $n$，在每个私有外片等于一。全部超载积分 $n-1$ 由同一个核心承担。

取 $t_n=1/2+1/(2n)$，则 $m_X=2$，$m'_X/m_X=n$，而 $|X|/m_X=(n+1)/2$。还可取 $t_n=1/2+c/\sqrt n$，此时斜率比为 $2n/(1+2c\sqrt n)\sim\sqrt n/c$，增益亦仅为 $O_c(\sqrt n)$。因此第605轮必要条件中的移动门槛、大峰值与正权行饱和三者均可在低增益目录同时出现。对该目录，门槛增长完全来自外片被迫各自新增质量；它不会给出指数大小的接收并。下一步应把门槛斜率与实际可覆盖且不重复的外片总体积同时结算。
