# 第166轮　高重数列可按不同的行剖面合并计费

2026-11-12。平衡分块、固定中央紧区间 I。令 C 为任意列集，在 C 外保留原源 E_low；在 C 内可用扩大后的源覆盖原源，使其中各列截面仅取 h 个不同的行集合（忽略零测）。设扩大后 E' 的体积至多 n^K |E|，K 固定。若 E_low 在稍大紧区间有固定 a√n 的对数余量，则 h 固定时 E 也有固定平方根余量；若 h log n=o(√n)，则 E 有任意预定 D log n 的余量。高重数列可以承载全部或任意正比例的源质量，不要求第165轮的组合矩。一般端点系数差仍为 (μ−1)/8。

**机制。** 在任一真实见证 X×Y 中，按实际列密度 c(y)=|E'^y∩X|/|X| 排序，记降序分位为 c*(v)。落在 C 的每个列剖面只对应一个密度高度；若 |Y∩C|/|Y|≥δ，这至多 h 个高度的原子在分位轴上合计至少占 δ 长度。C 外即使也产生相同的高度，原子长度只会增加。第150轮列方向目标曲线为 f(v)=Φ̄((U(p)−tU(v))/s)，其中 s,t 为其膨胀旋转权重。对固定 δ∈(0,1/2)，在 [δ/4,1−δ/4] 内有 −f'(v)≥b_{I,ρ,δ}>0，来自正态密度商及 s,t 的一致正下界。上述平段截入该区间后长度和至少 δ/2。任一长 l 的平段对 ∫|c*−f| 至少贡献 b l²/4：将前后两半配对，函数值差至少 b l/2。各段不交，故列方向概率对称差至少 bδ²/(16h)。这是发生在同一严格成功矩形内的原子检测，不依赖实际标签重数或列域的整体测度。

**真实接收体积。** 可略去零测异常列。E 的任一成功见证对 E' 也成功。选固定 δ>0 使 p−δ 留在好部的紧区间且 B_n(p−δ)−B_n(p)≤a√n/2。在 |Y∩C|/|Y|<δ 的见证上，高列密度总贡献小于 δ，故同一原矩形在 E_low 上严格超过 p−δ。其余见证用刚证的列偏差及第150轮，真实接收并体积至多
|E'| exp(B_n(p)−c_{I,ρ,δ}√n/h+O_I,ρ(log n))。
在 h log n=o(√n) 时可用该筛选且吸收 n^K。与好部求和即得。若好部为空则第一支无成功点，可任选足够小的固定 δ。对 h 固定的结论还允许 log(|E'|/|E|) 是足够小系数的 √n 阶量。

**按涉及的行付费。** 可将高列分为互不相交的 C_j，在各 C_j 内仅以所涉及的行并 P_j 填充，所用价格为 Σ|P_j||C_j|，不用覆盖未参与的行。h 只数不同的 P_j，允许源的原始列重数任意大。例取 n 个互不交的公共列岛，每岛长 1/n；另取 n 个互不交的行岛，每岛宽 1。将第 j 列岛连接第 j 行岛内的任意有限有理子格并，面积占行岛的 1/2；也可把每个行岛进一步划分出很多不同的行标签并在该列岛内取不同子集，只须源占这块面积至少一半。令 n 改为 h 个岛并把列宽相应改为 1/h，则局部行外包总价 1，全局行并乘公共列的价格 h。该算例说明计费差异；定理的适用范围取 h 固定或 h log n=o(√n)，不是把 h=n 代入增长结论。高列源占比可以为 1。另加一个在其余列上的任意合格好部也不破坏结论。
