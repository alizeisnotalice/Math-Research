# 有限反馈前缀的严格增益与离散误差

日期为2026-11-11。目标是比较一条固定侧比向量与允许前缀反馈的秩模型。设独立后缀和为 $S_n$，每个动作增量为单位指数加 Bernoulli 位移 $cB_c$，其中 $P(B_c=1)=1/(1+e^c)$。在至少两个自由前缀坐标上，对任一固定向量的有限正末动作 $c$，取 $0<c'<c$。记前 $k-1$ 项之和为 $s$。若 $0<q-s<c'$，将末动作改成 $c'$，其余状态保留 $c$。在此事件上，带正位移的分支必高于 $q$。新动作使总和在 $q$ 的 CDF 严格减少
\[
 (P(B_{c'}=1)-P(B_c=1))\int_{\max(0,q-c')}^q F_{Y+S_n}(q-s)\,dP_{S_{k-1}}(s)>0.
\]
这里 $Y$ 为最后一个单位指数，积分严格为正，因为这些和在任意正开区间具有正密度。在对应分位处，连续性给严格的反馈模型分位增益。证明没有估计该增益的量级，真实矩形的侧边在抽样之前选定。

12个进程完成60个离散 Bellman 案，覆盖 $N=32,64,128,256,512$，后缀比例为四分之一、二分之一、四分之三或一，网格间距为1/16、1/32、1/64。同一网格的固定动作作为递推对照，另外计算 Gamma–二项真分位。15个零前缀案的模型策略增益为零。其余同网格增益约0.000503至0.020729，高维时插值偏差足以影响相对真分位的符号。最细网格中 $N=512,n=128$ 的反馈相对固定真分位增量约0.01445。运行 `python code/feedback108.py --outdir /tmp/bellman108` 重算。[数值核验](results108.json)
