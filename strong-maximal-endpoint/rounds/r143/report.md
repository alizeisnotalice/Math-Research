# 第143轮　异常长纤维的中央门槛费用

2026-11-12。对分块维数比例 m/n,k/n≥ρ>0、固定中央紧区间 I 及有限正体积源，沿第142轮的时间轴使用宽 w 的格。若各格可由固定 r 个乘积覆盖、外包体积至多 n^K 倍格源体积，且存在固定 b 使长度超过 bw 的纤维所含源质量占比衰减快于任意负幂，则不需任何最大纤维长度上界，仍有 log(|halo_p(E)|/|E|)≤B_n(p)−D log n，对任意先固定的 D>0 一致成立。假设中的尾衰减应对所讨论的源序列一致；对指定的 D，仅需一次充分大的多项式衰减。一般系数差仍为 (μ−1)/8。

**有限维二项不等式。** 写 ℓ(y)=∫1_E(t,y)dt，E_b 为 ℓ(y)>bw 处的全部源点，τ=|E_b|/|E|。取整数 s>b/p，ε=b/s，q=(p−ε)/(1−ε)。第一侧长度不超过 sw 的严格见证由至多 s+2 个连续格的窗口覆盖。若用 K_{n,R}(p) 表示两个给定维块、至多 R 个乘积的并的最优归一化价格，则
|halo_p(E)|/|E| ≤ (s+2)n^K K_{n,(s+2)r}(p)+τ H_n(q)。
第一项即第142轮按源质量求和，无需限制任何纤维。对较长见证 I_t×B，令 θ=|B∩{ℓ>bw}|/|B|，z 为 E_b 的实际密度。短纤维总贡献至多 ε(1−θ)，且 θ≥z。因此 p<z+ε(1−z)，同一矩形在 E_b 上严格超过 q。这比仅给出 p−ε 保留了更多中央门槛，且只使用一次 |E_b|。

**按维数取参。** 记 L=log n，s=floor(λ√k/L)，其中 λ>0 固定但可小。第140轮截线证明直接对 R=(s+2)r 给出 −c_I√k/R+O_I(log n+log R) 的秩改变量；这里 R≤√n，原网格舍入 O(R n^(−3))=o(st/R)（此处 st 指第140轮旋转权重之积，在平衡分块上有正下界）。因而即使 R L/√k 趋于小的正常数，也保有这个带显式费用的估计；此处用的是证明的不等式，而非将其 o 条件作形式替换。先按 D,K,r,I,ρ 选 λ 小，使第一项低于 exp(B_n−(D+1)L)。第二项中 q 留在稍大的固定紧区间，B_n(q)−B_n(p)≤C_I√n b/s≤C_{I,ρ} bL/λ，另需第91轮的 C L 粗界。所以 τ≤n^(−D−2−C−C' b/λ) 即足够，常数可按上述紧区间加大。两项相加吸收 log 2。τ=0 时直接删去第二项。结果允许异常纤维的绝对长度任意大。

**门槛移动的局部适用边界。** 在一个时间区间内，对横向比例 θ 的列完全填满，其余列只填开头 ε 比例。真实平均恰为 θ+(1−θ)ε。按真正长短纤维区分时，可令切分长度为 ε 倍见证长度，短列等于该长度，长列严格超过它。将 θ 从上方趋于 (p−ε)/(1−ε) 即给严格见证，长源密度恰为 θ。要强制见证长度严格超过 sw，可将短列占比从下方趋于 b/s。这个单见证模型表明，只知道纤维上限时不能统一提高转移门槛；没有据此断言全空间体积界取等。例取见证 [0,1]²、ε=1/10、θ=9/20、p=1/2，源为两个有理盒并，面积 101/200，完整见证的接收面积 1，严格余量 1/200。尾源在该见证的密度 9/20，转移门槛为 4/9。[本机精确复算](check.wls)
