# 第73轮：一般输入到有界输入的指数精度归约

日期：2026-11-08。状态：一般振幅归约已闭合；逐点参考转移存在严格反例，更强的局部效率反例机制仍待证明。一般C_N锐上界尚未闭合。

## 1. 一般输入可归约为固定上限2

定义真正的物理输入受限常数

\[
 T_{N,A}=\sup_{0\le f\le A}
 \frac{|\{M_Sf>1\}|}{\int\Phi_N(f)},\qquad A>1.
\]

本轮证明，对充分大的N，

\[
\boxed{1\le\frac{C_N}{T_{N,2}}
 \le(1-2e^{-N/100})^{-N}=1+O(Ne^{-N/100}).}
\]

这个结果适用于任意空间输入、全部矩形和完整标签，不是单一径向测试族或固定动作结论。它只归约了振幅；未知的T_{N,2}仍包含真实几何难题。固定上限A>1也有C_N/T_{N,A}=1+O_A(Ne^(−κ_A N))，κ_A>0可明确选取。

证明把f切成低部分f1_{f≤3/2}、中部分3/2<f≤e^√N和极端部分f>e^√N。取s=e^(−N/100)，分别给三个部分阈值1−2s、s、s。低部分除以1−2s后仍小于2，模数成本至多乘(1−2s)^(−N)。中段取固定p=4，强型参数b4满足

\[
 4(1-e^{-b_4/4})=1+e^{-b_4}.
\]

其有效指数率为

\[
 r_0=b_4+0.04-\log(1+\log(3/2))
 =1.16939190644\ldots<\mu=1.27846454276\ldots.
\]

另一个端点和迭代截断核大段均为−N log N/2+O(N)，更小。严格粗界不依赖这些浮点数：b4<3/2、log(1+log(3/2))>1/3，故r0<181/150<5/4<μ，四项有理Taylor区间已认证这些比较。

三个源部分互不相交，模数积分可直接相加。因此总体常数由三项系数的最大值控制，而不是另对重叠输入使用模数次可加性。已证明的有界测试族给T_{N,2}≥exp(μN−o(N))，故高振幅系数最终小于T_{N,2}，得到上式。无需知道T_{N,2}的精确上界。[完整证明与显式系数](amplitude73.md)，[独立审查](review73.md)。

也核对了近阈值截幅版本：若s=N^(−M)，M>1，取p=√(μ/(2M))√(N/log N)，在f=e^{A√(log N/N)}切分，则高段系数≤exp[Nμ−(A−√(2μM))√(N log N)+O(log N)]。选A>√μ+√(2μM)可使其低阶，修复成本1+O(N^(1−M))。指数阈值版本进一步把固定上限的归约误差压低到指数尺度。

## 2. 与第72轮的接口

一般振幅与无界余集现在可以先在**全局halo层面**分开支付，再把保留部分交给有界输入问题。第72轮宽窗口筛选也已闭合固定参考、有界输入的局部成本资格条件。因此，不应再把“全j弱型定理”或“无界振幅余集”列为此前提。

剩下的是：怎样把真实变动作、变锚点的成功接收集合，转成可以共用源成本支付的参考或动作索引分配。一般截幅定理不提供某一接收点处参考平均≥1−o(log N/N)，也不证明不同锚点能同时使用同一预算。

## 3. 无条件逐点参考转移不成立

本轮给出紧支有界源的显式例子。记a(c)=2/(1+e^(−c))，完整单坐标增量分布在b>c时满足

\[
 q_c(b)=P_c(Z\le b)=1-a(c)e^{-b}.
\]

在一个接收点，取b>2、λ>0、c_−=c0−δ，δ≈√(log N/N)，并令B_N=log(a(c_−)N/λ)。在全部源标签上，让F在增量盒[0,b]×[0,B_N]^(N−1)内取同一高度(1+δ²)/P_{c_−}(盒)。选择b与λ可使高度小于任何预先指定的固定上限>1。于是实际动作平均严格大于1，而确定性参考c0下的平均为

\[
 1-\kappa\delta+O(\delta^2+\delta/N),\qquad\kappa>0.
\]

物理源是紧的signed product annuli，即每坐标区间[−1,−e^(−b_i)]∪[e^(−b_i),1]的乘积；不能误写成单一正正交象限盒，否则上述完整标签CDF不适用。严格成功还给出邻近的正体积接收集合。小尺度叠加到一个近极值主包上，可使总输入仍任意接近主包效率，因此全局效率也不能推出“每一个成功点都满足精细参考比较”。该例不满足局部近标量最优成本条件，不能排除真正以局部效率为条件的定理。

## 4. 更强参考障碍的条件数值探路

考虑条件计数后验w_k(c,s)=binom(N,k)(s−ck)_+^(N−1)。在实际动作下删除概率≤1/[N(log N)²]的高计数尾，然后观察同一事件在参考动作下的概率。Python对N=64至1048576、均值/临界位置、固定偏移D=3/2及消失偏移D=(log N)^(−1/4)，共32例。

在N=1048576、临界s、固定D=3/2时，实际删除概率约4.894×10^(−9)，参考概率约9.080×10^(−4)，后者约为(log N)/N的68.68倍。消失偏移例此维参考概率约6.83×10^(−7)，仍小于(log N)/N，不能把其预期渐近增长说成已在有限维观察到。条件后验之外的完整径向均值与共同物理成本尚未结算。

因此这些数据不是新的物理反例或下界证书。把候选变成局部近效率反例，还须证明条件后验的一致中偏差、动作变化下的似然比展开，以及基准KKT轮廓的参考均值误差。具体缺口列于 [reference73.md](reference73.md)。若成立，将提示保留实际动作并直接作源分配，而不是逐点强行转到一个参考。

## 5. 本机验证

Python3.12.14 / SciPy1.18.1使用12进程；Mathematica15使用12内核，全部批处理结束前CloseKernels[]。本轮未启动MATLAB。任务规模较小，未为CPU占用添加重复或空转计算，也没有声称未监测的峰值。

- 多项式阈值：48项Python、96项Mathematica60/120位计算。144项跨软件字段比较最大相对差4.45×10^(−15)。
- 指数阈值：16项Python、32项Mathematica60/120位计算；16项有效高振幅系数比较最大相对差1.90×10^(−16)。四项常数不等式均用16阶有理Taylor和有理余项上界，在两软件独立认证。
- 条件后验：32项Python；N=64,256的8例经Mathematica全有限和60/120位复算，共16次。16项跨软件尾概率字段比较最大相对差8.59×10^(−14)。Python实际众数截断的解析遗漏界≤(N+1)e^(−220)；浮点总误差未作定向认证。

精度配对在存储的40位有效数内一致，不把输出截位后相等称为无限精度相等。指数阈值在N=32,64时不满足1−2s>0，程序明确标为修复域外；首次原型曾对此错误应用对数并产生复数警告，已改为域检查并重跑通过，未将该错误当成数学反例。Python极小修复量下溢时保存null及其对数上界；Mathematica以稳定ArcTanh公式计算正修复量。

正式Python三批约0.30、0.30、0.54秒；Mathematica核内约0.18、0.12、0.05秒，不含启动与工具开销。见 [validation73.json](validation73.json)。解析归约不依赖数值拟合；有限维起效点未认证。
