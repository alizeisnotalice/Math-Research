# 第407轮　碰撞预算的精确截断对偶

- A 已覆盖全部等权深度轮廓。第406轮的最优费用等于一个只含点势和源外两盒交体积的截断和。
- 当一个固定子族取得极大费用时，可从单次常值势测试给出下界；一般上界需同时控制嵌套子族随截断高度的变化。
- 未得一般中央目录的一致费用上界。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定最优源与正对偶权 $z_i$，设 $a_{ij}=|(R_i\cap R_j)\setminus E_*|/M$。每条边有质量 $z_i z_j$，可分别交给任一端点或留在残差；留在残差的单位费用为 $a_{ij}$。以 $u_i\ge0$ 松弛点容量条件，最小化关于非负峰值 $t$ 的拉格朗日式给出 $\sum z_i u_i\le1$。固定点势后各边全部选择三个单位费用中最小者。有限线性规划可行有界，强对偶给出
\[
 P=\max_{u\ge0,\ \sum_i z_i u_i\le1}
 \sum_{i<j} z_i z_j\min(a_{ij},u_i,u_j).
\]
零权行可删。该式避免了二阶段选择禁止图。

令 $A_s=\{i:u_i>s\}$。由逐层积分，对偶目标为 $\int_0^\infty\sum_{i<j\in A_s,\,a_{ij}>s}z_i z_j\,ds$，约束为 $\int_0^\infty z(A_s)ds\le1$。于是单族下界为 $\sum_{i<j\in A}z_i z_j\min(a_{ij},1/z(A))$，对任意非空 $A$ 成立。反向的问题是能否由这些测试控制嵌套势，而不付出依赖行数的损失。

另有严格的几何充分条件。源外 $S\le1$，故对每行 $i$，$\sum_{j\ne i} z_j a_{ij}\le (1-z_i)|(R_i\setminus E_*)|/M$。若所有正权行的外部体积均至多 $BM$，则取 $s>0$ 时其阈值图的每行邻权至多 $B/s$。对每个 $A_s$，边质量同时至多 $z(A_s)^2/2$ 与 $B z(A_s)/(2s)$。此估计在 $s$ 很小时退化，不能直接积分出统一常数。下一步应比较单族测试与多层势之间的实际差距，并利用行体积对小高度区再分层。
