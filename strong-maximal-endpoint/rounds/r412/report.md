# 第412轮　弱冲突染色的精确体积费用

- A 已覆盖全部等权深度轮廓。对最优对偶的正权行，不要求真染色即可获得同门槛证书，颜色冲突只按源外重复覆盖的实际体积扣费。
- 当冲突图由任意多条小边构成团时，新估计可比真染色改善任意倍。
- 尚缺近中央目录上颜色数与源外扣费的统一权衡。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。正权行均饱和。以任意 $k$ 色标记这些行，$d(x)$ 表示覆盖次数，$h(x)$ 表示出现的不同颜色数。将每个色类作为一个候选子集，平均其证书得
\[
 L_*\ge k^{-1}\left[\int_{E_*}h(x)dx-\int_{U\setminus E_*}(d(x)-h(x))dx\right].
\]
这是平均证书的等式再取最大。在线性行费用中，每一正权行恰好支付其源外体积，故每个点每增加一种颜色就多保留一次覆盖。更具体地，$d-h$ 是逐点使活跃行颜色不重复所需删掉的最少行数，并非同色行对数。若 $h\ge1$ 于源上且第二项至多 $\eta M$，则 $L_*\ge(1-\eta)M/k$。

构造同维有理例检验这种计费。单位核心的 $m=2n$ 个面各伸出一条长二的独占臂，每盒体积三，门槛 $p=1/2$。最优源取满核心及每臂体积 $1/2$，由第387轮 $M=1+m/2$。对每盒的源内外同时有正质量的独占单元，互补松弛迫使每行权一。此时源外无交。为了看出真染色的不稳定性，改取同一目录的门槛 $p=(1-\epsilon)/3$，$0<\epsilon<1$，并取核心内体积 $1-\epsilon$ 的最优源；每行需求皆为 $1-\epsilon$，单行即给出匹配下界。可选正权最优解 $z_i=1/m$（核心负载一，独占部分负载小于一）。源外冲突图为完全图，分数染色数 $m$，而任一色类单行都已覆盖全部源。对所有行只用一种颜色，上式给 $M-(m-1)\epsilon$，取 $\epsilon=m^{-2}$ 即相对损失 $O(1/m)$。这一比较针对该最优权上的图染色数；第411轮按源单元而非按行的覆盖也能识别单行证书。此例接收规模为多项式，不能代替中央目录估计。

下一步可直接最大化色类并体积之和（线性行费用已固定），并检验源外重叠体积很大但颜色也很多时，源内颜色增益能否补偿。
