# 第477轮　修正包络的高斯均值障碍

- A 覆盖全部等权深度轮廓，中央误差有界。
- 静态分位数修正能完全消去上轮余量中的二次项；在零高斯边界通量类内，最小的一致首阶余量恰为现存系数差。
- 下一步须从真实目录与标量包络之间提取额外余量，或证明非零边界通量可由实际尾界支付。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。以 $F_k(p)=B_k(p)+f(z)$ 为对数包络，$f$ 固定且局部四次连续可微，计算固定中央紧区间上的一步作用，右端外沿用稍大紧区间端值延拓上界。令 $h=\sqrt{\mu k}$，现在用真实斜率 $s=(h+f')/\phi(z)$ 定义 $v=s(q-p)$。相对于线性项 $-v$，指数的二次系数为
\[
 F_k''(p)/(2s^2)=z/(2h)+(f''-zf')/(2h^2)+O_I(h^{-3}).
\]
三次系数至 $h^{-2}$ 仍为 $-(1+2z^2)/(6h^2)$，由链式求导得出，四阶及积分余项同第475轮。故按第476轮取 $s(p-a)=\mu-\mu(\mu-1)z/(2h)$ 后，仅多出 $(f''-zf')M_2/(2h^2)$，其中 $M_2=\mu$。扣除 $F_{k+1}(p)$ 的余量为
\[
 [R(z)+(f''-zf')/2]/k+O_I(k^{-3/2}),\qquad
 R(z)=-(3-\mu)/6+c z^2,\quad c=(9-\mu)/24 .
\]
次阶截断位移的最优性仍由上轮的正二次费用保证。这是试用包络的展开，不是假设实际 halo 处处取等号。

取 $f(z)=cz^2$，余量系数恒为 $r=c-(3-\mu)/6=(\mu-1)/8$。反向若 $f'(z)\phi(z)\to0$ 在正负无穷均成立，且修正项高斯可积，则分部积分给 $\int(f''-zf')\phi=0$。因此所有这类修正的余量系数上确界至少为 $r$，二次修正恰达到。这个极小性质针对局部展开系数在全实轴的上确界，不需要把渐近展开的误差视作全轴一致；也没有证明真实指标源需要该对数损失。

在有界窗口上可形式上将系数消至零：在二次修正上再加偶函数 $g$，$g(0)=0$，$g'(z)=-2r e^{z^2/2}\int_0^z e^{-t^2/2}dt$。此时 $(g''-zg')/2=-r$，但 $g'$ 在两端具有非零高斯通量，$g$ 向两侧迅速下降。固定窗口内的这一局部等式不提供递推所需的尾部支配。下一轮应检验真实严格见证平均或区间单覆盖部分能否支付每步 $r/k$，而非再次调节零通量静态修正。

本机 Python 以分数系数逐项核验恒等式 $c-(3-\mu)/6=(\mu-1)/8$。
