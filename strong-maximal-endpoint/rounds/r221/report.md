# 第221轮　同盒第二个源点必须传递线性量的见证信息

2026-11-12。固定中央门槛 \(p\)，假定有限成功盒并满足 \(\log(|U|/|E|)\ge B_n(p)-B\log n\)。任意不交接收归属，按实际接收体积抽负责盒 \(R\)，再在 \(E\cap R\) 内条件独立均匀抽取 \(X_0,X_1\)。则
\[
 I(R;X_1\mid X_0)\ge (0.000030-o(1))n .
\]
不需要第219轮的联合熵近等号假设。这里是对负责盒身份的条件互信息；与第220轮的标量密度分数独立极限可同时成立。常数仅用于给出正的线性费用。

**固定数目的源样本能定位投影形状。** 只看前 \(m=n-1\) 个轴，给定原盒抽 \(k=2001\) 个源点，记这批点在投影中的最小坐标包围盒为 \(B\)。先以整个原盒的均匀样本作参照。每个轴的样本范围除以该边长独立服从 \(\mathrm{Beta}(k-1,2)\)（由最大最小次序统计量的联合密度积分）。其负对数均值为 \(1/(k-1)+1/k<0.001\)，且有有限方差。由大数定律，各轴对数边长缺损之和以趋于一的概率低于 \(0.0011m\)。从整盒换成这 \(k\) 个源样本至多把失败概率放大 \(p^{-k}\)，它虽大但与维数无关。因此结论对所有成功盒一致。第186轮的去整体尺度距离是中心化对数边长差的半个一范数；因原始边长缺损逐项非负，该距离至多为缺损之和。故 \(B\) 与真实投影的形状距离以高概率至多 \(0.0011m\)。

**与单点后验比较。** 记全部样本为 \(D=(X_0,\ldots,X_{k-1})\)。在给定 \(D\) 后，再从真实后验独立抽另一个负责盒 \(R'\)。两盒对 \(D\) 的边际联合律相同，各自与同一包围盒满足上段估计。故两投影以概率 \(1-o(1)\) 距离至多 \(0.0022m<m/400\)。反之，给定 \(X_0\) 只按单点后验独立选两盒时，由[第192轮](../r192/report.md)取单个预设投影、\(\beta=0.06\)，除了 \(O(1/n)\) 的第一盒质量，第二盒落在其 \(m/400\) 邻域的条件概率至多 \(1/N\)，\(N=\lfloor e^{0.06m}\rfloor\)。

比较真实联合律 \((X_0,R,R')\) 与同边际的条件独立律，即可避开 \(O(1/n)\) 稀有大邻域的干扰：测试事件取“两盒邻近且第一盒的单点后验邻域概率至多 \(1/N\)”。真实律下概率趋 1，条件独立律下至多 \(1/N\)。由二元 KL 数据处理，\(I(R;R'|X_0)\ge(1-o(1))\log N-\log 2\)。这里两种律的每个单盒边际确实相同，因为用全样本后验重抽保留原联合边际。

**回到一步重抽。** 给定 \(X_0\)，后验抽盒通过其余 \(k-1\) 个源样本产生，故
\[
 I(R;R'|X_0)\le I(R;X_1,\ldots,X_{k-1}|X_0)
 \le (k-1)I(R;X_1|X_0).
\]
后一步用给定 \(R\) 后的独立性：链式展开每项，附加以往样本只降低该项的首个条件熵，给定盒后的条件熵均为 \(\mathbb E\log|E\cap R|\)。代入 \(k-1=2000\) 得首式。本机 Python 核对了范围均值与显式常数。精确地，该一步费用亦等于 \(I(R;X_1)-I(X_0;X_1)\)，但尚不能把它直接作为第210轮反向 KL 的同额下界。

一般系数差仍为 \((\mu-1)/8\)。本轮证明额外的真实源样本能辨别见证；尚缺与体积恒等式的同一项对应。下一步应分解此费用中由边长与由位置分别产生的部分，并检查其中多少可由已计入的反向 KL 支付。
