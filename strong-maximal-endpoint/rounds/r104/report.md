# 布尔乘积目录全覆盖斜率的维数渐近

日期为2026-11-11。每个坐标等分为两格，源允许在各格内取任意可测二值子集。记 $T_D$ 为第101轮中全覆盖价格对门槛亏损的斜率。本轮得到
\[
T_D=(1+O(e^{-cD}))\max_s {D\choose s}2^{-s}\sim\frac{3}{2\sqrt{\pi D}}(3/2)^D .
\]
下界来自同一余维的主子立方体族，上界在每个接收顶点用随机排列计数，再对盒的不同余维作加权。计数方法来自 Ellis 对 Meshulam 估计的证明。[推导与原始来源](boolean104.md)

Python 用有理数计算了284个维数的上下包络，最大维数为2048。运行 `python code/check104.py /tmp/bounds104.json` 可重算。全覆盖下确界 $1-(1-p)T_D$ 的已证线性区间为 $0<1-p\le2^{-D}$。[有限结果](bounds104.json)

后续检验放宽目录尺度对斜率的影响，并继续从真实截面几何推进连续问题。
