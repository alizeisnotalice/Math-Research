# 第644轮　跨中央宽度折点后所有低侧最优权同时失效的量级

- A 的全部等权深度轮廓中央误差有界。
- 一个不等体积外片目录使低侧整个门槛区间的全部最优乘子都落在同一条射线上。在距离 $2/\sqrt n$ 的高门槛，其任意非负混合能认证的质量仅为真实最优值的 $O(n^{-1/2})$。
- 一般系数差仍为 $(\mu-1)/8$。该例排除不加几何条件的统一转移，本身的接收增益仅为多项式。

2026-11-13。取 $n=k^2,k\ge4$，单位核心 $C$。第 $i$ 个矩形仅沿第 $i$ 轴向正侧伸长，体积 $V_1=2+1/k$、$V_i=2$（$i>1$）。各独占外片互不相交。对任意 $0<t<1$，最小源质量为
\[
 m(t)=u+\sum_i(tV_i-u)_+,\qquad u=\min(1,tV_1).
\]
给定核心质量 $v$，外片最少分别需要 $(tV_i-v)_+$；在 $v\le tV_1$ 时增加核心质量至少替代等量外片质量，故可取上述 $u$。选定 $u$ 后，外片容量足够：若 $u=1$ 则 $tV_i-1<V_i-1$，否则所需外片质量为零。

当 $0<t<1/V_1$ 时，取核心中体积 $tV_1$ 的子集。除第一行外所有行严格松弛，故其在每个最优对偶中的权皆为零。核心有正体积填充及未填充部分，第一行权必须恰为一。于是整个低侧最优锥只支持第一行，甚至允许任意多个低侧门槛、最优面选择和重新缩放，高门槛 $p$ 的最强证书也只有 $pV_1$（单行最小质量）。

取 $q=1/2-1/k$，$p=1/2+1/k$，则 $q<1/V_1<1/2<p$。在 $p$ 处各外片均须填入正质量，
\[
 m(p)=pV_1+(n-1)(2p-1),\qquad
 \frac{m(p)}{pV_1}=1+\frac{2(k^2-1)}{k pV_1}=\Theta(\sqrt n).
\]
所以对数证书损失为 $\tfrac12\log n+O(1)$，而 $B_n(q)-B_n(p)=O(1)$。这是对第643轮“两区间可择优消除损失”现象的严格区分。在全部 $t<1/V_1$ 上补充证书都无济于事；在折点之后取新权则不受此限制。整个接收并体积为 $1+n+1/k$，所以目标门槛的最优增益仅为 $\Theta(\sqrt n)$。下一步应检查在近中央基线约束下，新增活跃行能否在短窗内贡献同样大的质量比例。
