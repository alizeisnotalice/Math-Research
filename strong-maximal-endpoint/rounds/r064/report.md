# 第64轮：角向实际预算的精确结算与半对数包络障碍

日期：2026-11-08。状态：两份证明、独立审查及本机计算完成。本轮推进真实矩形的预算接口；一般强极大常数的系数区间未改变。

记 L=log N、μ=1+e^(−μ)、p_c=(1+e^c)^−1，统一 Φ_N(t)=t(1+log⁺t)^(N−1)。以下 D 表示几何深度，避免与 log N 混淆。

## 1. 共同动作下，角向 Jacobian 完全抵消

在本轮固定全局锚点的矩形族中，大小为 b 的块内，接收角 ξ 服从均匀单纯形概率测度 σ；固定径向位置 V>0、增量 z≥0、Σz_i=s 时，源角为 Θ=(Vξ+z)/(V+s)。其精确推前密度是

\[
\left(\frac{V+s}{V}\right)^{b-1}
1_{\{\eta_i\ge z_i/(V+s)\}}.
\]

对原始输入 F(w,η) 作条件平均 h_(u,ξ,c)(s)，Jensen 后乘实际接收权重 e^(−Σu)∏V_j^(b_j−1)，并积分 e^(−Σs)ds，恰得到源的实际上锥模数：

\[
 e^{-\sum u_j}\prod_j V_j^{b_j-1}
 \int e^{-\sum s_j}\int\Phi_N(h_{u,\xi,c}(s))d\sigma(\xi)ds
 \le \mathcal O_D^+(F;u).
\]

没有冻结误差，也没有把 e^(−s) 径向模数换成增量概率。恢复物理 Lebesgue 测度时，两侧共同因子为 2^N e^(−D)/∏Γ(b_j)。完整条件与推导见 angular_budget64.md。

这给出固定径向接收点上的平均预算，不给每个角纤维相同的预算，也不使条件终端自动与动作无关。

## 2. 动作随角位置变化时的全径向上界

令 g_c^s 为 b 个 Z_c=Exp(1)+c Bern(p_c) 在和为 s 条件下的密度。对窗口 0<a<d，定义

\[
 Z_{b,s}([a,d])=\int_{\sum z_i=s}\sup_{c\in[a,d]}g_c^s(z)dz_{-b}.
\]

参数变化时，密度在移动超平面之间向上增长，穿越 z_i=c 则向下跳。其正向连续变差给

\[
 Z_{b,s}\le1+b\log\frac{1+e^{-a}}{1+e^{-d}}
 -\log\frac{f_{b,d}(s)}{f_{b,a}(s)}.
\]

又有精确边界通量恒等式及其全 s 控制：

\[
 bp_c-\partial_c\log f_{b,c}(s)
 =bp_c\frac{f_{b-1,c}(s-c)}{f_{b,c}(s)}\le b/c.
\]

因此，对所有 s>0，

\[
\boxed{Z_{b,s}([a,d])\le1+b\log(d/a).}
\]

这里用的是 e^t f_(b−1,c)(t) 非减，而不是密度 f 本身非减。对每个大小 b_j≥2 的块采用一个共同参数、各块参数可为径向位置、正负号及接收角的任意可测函数时，上一节的平均预算至多增加

\[
\prod_j[1+b_j\log(d_j/a_j)]
\]

这一因子。对任意非偶输入，必须保留原始正负号与潜在 Bernoulli 标签。其联合条件包络恰等于上面的密度比表达式，而不是仅有一个上界；固定标签后的符号映射是正负号集合上的置换，因此实际源模数仍被完整结算。非负无界输入可由截断和单调收敛处理。单坐标块的联合标签有3/2例外，不能直接用本节因子。

该结论保留完整物理权重，覆盖所有径向和；它不覆盖尚未证明可归约成这种块结构的全部真实矩形。

## 3. 临界窗口的增长阶是锐的

令 s=bμ−d_b+O(log b)，d_b 用既有正态根定义，并取固定 K>0 的完整窗口 c∈[μ−K√(log b/b),μ+K√(log b/b)]。本轮证明

\[
\boxed{Z_{b,s}\asymp\sqrt{b\log b},\qquad
\log Z_{b,s}=\tfrac12\log b+\tfrac12\log\log b+O(1).}
\]

下界不来自抽样。两个增量律的几何平均仍是 Exp 加三个离散位移的混合；其均值在 (μ,μ) 一阶驻定。完整倾斜局部极限定理因而控制条件 Hellinger 亲和度为 C exp(−κb|c−d|)。间隔 D_0/b 的动作网格有 Θ(√(b log b)) 个点；对其密度使用 Cauchy–Schwarz 即得匹配下界。

在切向条件卷积模型内，Z 恰是角向极大卷积的 L1 范数。高度不超过1的缩小脉冲能逼近这个因子，此时 Φ_N 恰为线性。但其平均响应随脉冲质量趋于零，所以这是不加效率条件的预算归约障碍，不是高效率真实输入、C_N 下界或有限深度认证构造。详见 envelope64.md。

## 4. 全局径向积分仍然重复收费

若把第一节不等式直接在全部径向接收点 u 上积分，源点 w 会被每个 u≤w 的上锥再次收费。精确额外乘数为

\[
M_U(w)=|\{u\in U:-D\alpha<u\le w\}|.
\]

不限制 U 时它等于 ∏(Dα_j+w_j)。例如源支持在 0<w_j<1 时，收费比在 ∏Dα_j 与 ∏(Dα_j+1) 之间，随深度增长。这个例子只否定免费全局积分；低振幅源甚至可以没有接收 halo。

因此本方法还需要带效率条件的源预算分配或接收锥 packing。第28轮已证明全输入的固定全局比例反射锚定子族恰受 Q_N 控制；本轮并未改写该结论。新增接口处理角位置相关的共同块参数，但仍没有把全部竞争矩形的重叠结算为一般上界。
