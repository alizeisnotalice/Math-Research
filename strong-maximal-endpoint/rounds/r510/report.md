# 第510轮　包围对偶与可分配源质量之间的指数差距

- A 覆盖全部等权深度轮廓，中央误差有界。
- 构造精确张量例，证明第509轮的最优分数包围费用可以指数倍大于真实并体积。给出对偶标签质量能分配到候选盒内的充要条件。
- 下一步应直接对成功见证的命中部分应用分配条件，并核算相应接收体积，而非仅靠候选菜单整体的包围费用。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。对标签权 $y_i$，在每个候选 $P_i$ 内选不交可测源块、体积分别为 $y_i$ 的充要条件是对每个子族 $J$ 有 $\sum_{i\in J} y_i\le |\bigcup_{i\in J}P_i|$。必要性由不交性，充分性由按所有盒端点切原子后从标签到原子的容量流与最小割定理，原子内按流量切块即可。若只允许从给定源 $E$ 分配，右侧改为交 $E$ 后的并体积。第509轮的包围对偶只要求每子族总权至多其包围盒体积，此条件可能显著宽松。

二维取 $P_0=[0,2]\times[0,1]$、$P_1=[0,1]\times[0,2]$。在 $2d$ 维取所有 $2^d$ 个乘积候选 $P_\omega$。真实并是二维并的 $d$ 重积，体积为 $3^d$。逐盒付费为 $4^d$，也是最优分数费用：给每个标签 $y_\omega=2^d$。任取非空子族 $J$，设在 $m$ 个二维因子上两种标签都出现，则 $|J|\le2^m$。其轴平行包围盒体积为 $4^m2^{d-m}$，足以支付 $|J|2^d$。由第509轮对偶得等号。因此包围费用与并体积之比为 $(4/3)^d$。即使源正是候选并，表示无任何外溢，也不能用次指数因子普遍把最优包围对偶转为不交源质量。

此例还能精算上述均匀对偶的最大统一缩放因子。全体子族给出上限 $(3/4)^d$；在二维将公共单位方块各分一半给两盒，加上各自独占的单位方块，得两个面积 $3/2$ 的不交块。将此分配取张量积，逐个标签恰得 $(3/2)^d$，实现缩放上限。该例未指定中央近最优接收目录，所排除的是从包围费用直接恢复真实源质量的一般步骤。
