# 第364轮　按真实接收体积抽取的两个见证的尺度分离

- A 已覆盖全部等权可测深度轮廓，误差有界。
- 在达到中央基线的目录上，给定同一个实际命中点，两次独立后验抽样所得见证的对数边长向量，以指数高概率相隔线性的总距离。该结论对任何接收分区成立。
- 一般中央上界仍需约束不同尺度见证对同一源的命中。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取均匀接收点，按任意可测分区选盒，再在原盒均匀抽样，最后条件于命中 $E$。写 $a_j$ 为接收分区体积，$w_j=a_j/|R_j|$，$Z(y)=\sum_{j:y\in R_j}w_j$，$T=\int_E Z>p|U|$。命中点密度为 $1_E Z/T$，后验盒律为 $w_j1_{R_j}(y)/Z(y)$。写 $s_j$ 为对数边长向量。

给定模板中心 $s$，考察 $\|s_j-s\|_1\le t$ 且含 $y$ 的盒。相应接收分区互不相交。对每个分区内的 $x$，以 $d_i=|x_i-y_i|e^{-s_i}$ 归一化，必有 $\sum_i\log^+ d_i\le t$，且 $1/|R_j|\le e^{t-\sum s_i}$。由第361轮外部坐标积分（按 $d_i>1$ 的坐标数分层，正象限内每个外部坐标无额外方向数），整个归一化区域体积至多
\[
 2^ne^t\sum_{k=0}^n{n\choose k}t^k/k!\le 2^n e^{t+2\sqrt{nt}}.
\]
故这些盒的 $w_j$ 总和至多 $C_n(t)=2^n\exp(2t+2\sqrt{nt})$，中心可随源点与第一盒改变。抽取命中点 $Y$ 后，独立按其后验抽两盒 $J,J'$。对每个第一盒，第二盒落在上述球内的条件概率至多 $C_n(t)/Z(Y)$。对真实命中密度积分正好抵消 $Z$：
\[
 \Pr(\|s_J-s_{J'}\|_1\le t)\le C_n(t)|E|/T\le p^{-1} C_n(t)e^{-H},\quad H=\log(|U|/|E|).
\]
因此只要 $H\ge B_n(p)-O_I(1)$，取 $t=n/25$ 时，指数衰减率至少为 $\mu-\log2-0.48>0$（允许 $O_I(\sqrt n)$ 的对数误差）。零接收权目录项对概率完全无贡献。结论以实际命中点为平均，不断言每一点都满足同一界。下一步应区分尺度差由整体缩放还是由不同坐标反向伸缩产生，并控制两种情形的共同命中质量。
