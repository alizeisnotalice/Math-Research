# 第71轮：临界列极限、远尾范围与连续小格下界

日期：2026-11-08。状态：固定维数紧支源的弱尾恒等式、临界单列一阶展开、后验截断界及连续小格下界公式已证明；本机交叉核验通过。全输入弱型界和一般强极大算子锐上界仍未闭合。

## 1. 上界路线的新辨别结果

沿用第70轮局部成本算子 \(\mathcal J_c\)、完整标签及物理测度。固定 N≥2、有限 c>0，若源在对数坐标盒 [−R,R]^N 内，物理源质量为 m，则

\[
\boxed{\lim_{t\downarrow0}t\,\nu\{\mathcal J_cG>t\}=m.}
\]

这是固定维数、固定紧支源的低阈值渐近式；收敛常数依赖 N,c,R，不是全输入弱型常数等于1的证明。证明保留完整标签，利用远尾 H(T+w)∼2^N T^(N−1)/Γ(N) 和内外接收锥。场的相对 O(1/T) 误差只移动截止点 O(1/q)；若仅控制为 O(1)，便不足以推出精确极限。

单列在列自身阈值对应的体积评分为

\[
 D_N(s)=\int_0^s e^{-r}\frac{H_{N,c}(s-r)}{H_{N,c}(s)}dr.
\]

固定 N 时 s→∞ 有 D_N(s)→1；但在 c=μ+O(√(log N/N))、s=q0+O(log N) 时，D_N(s)→1/2。更精确地，在宏观紧参数范围内，设 γ 解

\[
 s/N=1/\gamma+c/(1+e^{\gamma c}),
\]

则 D_N(s)=1/(1+γ)+O(1/N)。尤其 c=μ、s=q0 时

\[
\boxed{D_N(q0)=\tfrac12-\frac{z_N}{4\sqrt{\mu N}}+O(\log N/N).}
\]

这里 μ=1+e^(−μ)，正态上尾满足 barΦ(z_N)=√(μ/N)z_N，q0=Nμ−√(μN)z_N。推导只使用已有 B=∂s log H=γ+O(1/N)，没有对误差项求导。固定维数远尾与大维临界窗口不能交换；列阈值也不能直接代入第69轮实际筛选阈值 J_ref N^ε。[完整证明与截断引理](tail71.md)。

## 2. 把网格探索升级为可认证的几何接口

对数源小格 k 和接收小格 j 的边长为 Δ，有限动作满足 c=dΔ。若每坐标 k_i≥j_i+1，则源对整个接收小格可达；可全格保留的标记标签只满足 k_i−j_i≥d+1。偶输入的统一下界矩阵为

\[
 L_{jk}=2^{\#\{i:k_i-j_i\ge d+1\}}q_{|k-j|},\qquad
 q_M=\Delta^N\int_0^N\frac{e^{-\Delta(M+x)}f_{\rm IH,N}(x)}{H_{N,c}(\Delta(M+x))}dx.
\]

不满足逐坐标可达条件时置零；单侧极限没有标记因子。第70轮允许坐标差0、标记差d的配点规则不能作为全接收格证书，其历史数值仍只作探索。上述新公式是严格几何下界，但只有再给定向系数区间、源成本上界、接收体积下界和严格平均余量，才能产出连续弱型下界证书。任意标签源不能以标签平均高度替换共同点值下界。[证明及认证规则](cell_certificate71.md)。

## 3. 本机计算与证据等级

Python 3.12.14 / SciPy 1.18.1 使用12进程，Mathematica 15 使用12内核。未启动MATLAB；Wolfram脚本在结束前 CloseKernels[]，批处理正常退出。

- 列积分：N=2,4,8,16,32,64,128,256,1024,4096,16384,65536,262144,1048576；临界、均值、μN²、μN³四种位置。共56基础例和16容差收紧复算。后验按实际众数截断，遗漏质量严格≤(N+1)e^(−220)；72例众数符号用有理数对数区间认证，作用于所记录的二进制有理 s,c。它不认证完整浮点积分或精确超越参数。
- Mathematica对N≤256的32例使用全部后验项、50/100位独立积分，并核验56组众数符号。32组列精度配对最大差约5.61×10^(−39)，跨软件列积分最大绝对差3.34×10^(−16)。48组小格核精度配对最大差约4.01×10^(−40)，跨软件最大相对差9.05×10^(−16)。积分截尾r=80时余项≤e^(−80)。N=2均值恰逢节点时只登记B的左值。
- 新连续下界矩阵：24组N=2,3有限小格MILP，每例8秒、2000节点、目标gap 1%。11例达到设定gap，13例限时；最大剩余gap约3.9185。24例通过浮点原始约束核验，最小阈值余量约−2.69×10^(−12)，因此不能冒充严格正余量证书。最大探索比值0.618254，不提供上界或突破证书。矩阵删去≤10^(−14)正系数，单位质量下每行该项误差≤10^(−14)，另外仍有求积误差。
- 三原子源诊断：N=2、有限c的同标签和混合标签、单侧核；R=4,12，每组两种固定种子7100—7111。将源径向重心归零，在Q∈[0.05,32]搜索；12例共74928次目标计算，10例优化器报告收敛，145次因浮点根区间等问题被判无效并罚回，未将其当作可行值。最大浮点评分0.985619，没有找到>1候选；不排除搜索盒外、更高维或更多源反例，浮点根与halo积分没有定向认证。

三原子正式搜索用时约3.64秒（含监控启动），实测峰值CPU 1137.2%（12核满载约1200%），RSS 936992 KiB，采样间隔0.2秒。小格搜索用时约17.00秒；Mathematica核内计算约2.77秒。CPU占用来自有效研究任务，没有增加空转负载。

示例：N=64临界D≈0.4708315762；N=1048576临界D≈0.4994069699，而该维μN³位置D≈0.9999999999993。远尾差小于双精度时不据其声称更精细渐近系数。全部检查见 [validation71.json](validation71.json)。没有登记新认证C_N下界。

## 4. 账本、缺口与下一轮两项动作

一般账本仍为Q_N≤C_N≤R_N，log Q_N=q0+(9−μ)log N/24+o(log N)，log R_N=q0+(3+μ)log N/12+o(log N)。系数间隙(μ−1)/8和已认证log C64>71.79均未改变。Φ_N(t)=t(1+log⁺t)^(N−1)保持不变。

本轮排除了把固定维数远尾直接当作临界窗口控制的推论。接续重点是：

1. 证明实际有限c、完整标签、任意叠加源的弱型界 W_N≤N^γ，γ≤(9−μ)/12；或找出跨尺度、多源叠加增长机制。单列极限、逐列弱范数及有限搜索都不足以回答它。
2. 若全输入弱型仍过强，研究临界接收主体的效率限定筛选，结算共同源成本、变动作均值精度1−o(log N/N)、移动锚点及无界振幅余集。这些缺口未由本轮小格公式解决。
