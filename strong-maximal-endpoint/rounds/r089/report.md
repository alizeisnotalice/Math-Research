# 第89轮：一般输入临界截高的锐固定系数

日期：2026-11-11。状态：一般物理输入的截高相变证明及独立核验完成；研究继续，一般锐上界未闭合。

设 $L=\log N$、$\rho=\sqrt{L/N}$、$\mu=1+e^{-\mu}$、$\sigma=\sqrt\mu$，$C_N(A)$ 为原始 $\Phi_N$ 分母下、真实输入 $0\le F\le A$ 的端点常数。不限高的常数记作 $C_N$。本轮将第73轮 cap2 归约推进到趋于一的临界窗口，并核定固定系数门槛。

## 1. 严格改进

对所有固定 $P>0$，
\[
 K\ge\sigma(1+\sqrt{2P+1})\quad\Longrightarrow\quad
 1\le\frac{C_N}{C_N(1+K\rho)}\le1+O_P(N^{-P}).
\]
在恰好 $K=2\sigma$ 时也有
\[
 \boxed{\quad C_N/C_N(1+2\sigma\rho)=1+O((\log N)^{-1/4}).\quad}
\]
而对每个固定 $0<K<2\sigma$，$\log[C_N/C_N(1+K\rho)]/\log N\to\infty$。因此 $2\sqrt\mu$ 是保留对数精度的锐**固定系数**；本轮没有给出随维数收缩的系数过渡窗。系数的有理定向区间见 [validation89.json](validation89.json)，位于 $(2.26,2.27)$。

证明用真正截顶 $f=F\wedge a$、超额源 $g=F-f$，以 $\Delta J=J(F)-J(f)$ 计费。虽然二者支撑重合，原费用仍精确等于 $J(f)+\Delta J$。新的估计
\[
 \|g\|_p^p\le\frac{(2(1+\log2)p/N)^p}{\Phi_N(a)}\Delta J
\]
给出先前丢弃整块高源所没有的 $p/N$ 改善。与真实强 $L^p$ 界和 cap2 归约结合，低源/超额源的最大费用闭合截幅上界。

若 $\delta_N\to0$ 且 $\delta_N/\rho\to\infty$，则对每个固定 $c<1/(2\mu)$，截到 $1+\delta_N$ 只损失 $1+O_c(Ne^{-cN\delta_N^2})$。对充分小的固定 $\delta$ 也有此结论；未声称所有固定振幅上的最优指数率。

## 2. 三个尺度及软层比较

定义 $\bar\Phi(z)=\sigma z/\sqrt N$、$q_0=\mu N-\sigma\sqrt N z$，其中 $\bar\Phi$ 是标准正态右尾。

|截高的超额|真实最优常数的结论|与一般常数的比较|
|---|---|---|
|$N^{-1}$|$\log C_N(1+N^{-1})=\mu N-\sigma\sqrt N\,\bar\Phi^{-1}(N^{-1})+O(L)$|首个负项变为 $-\sqrt{2\mu NL}(1+o(1))$|
|$(NL)^{-1/2}$|同上，分位数尾改为 $(NL)^{-1/2}$|对数损失 $\sim\sigma\sqrt{N/L}\log L$|
|$K\rho$，$0<K<\sigma$ 固定|相应分位数式的误差为 $o(\sqrt{N/L})$|对数损失 $\sim\sigma\log(\sigma/K)\sqrt{N/L}$|
|$\sigma\le K<2\sigma$ 固定|$\log C_N(1+K\rho)=q_0-(1+o(1))D_K$|$D_K\gg L$|
|$K=2\sigma$|保留一般常数到乘法 $1+o(1)$|仍须研究真实分层输入|

这里 $f_0=\phi(z)/(\sigma\sqrt N)$、$w=(K/\sigma)\sqrt L-z$，
\[
 D_K=\frac{\sigma[\phi(w)-w\bar\Phi(w)]}{\sqrt N f_0}.
\]
在 $K=\sigma$，$D_K\sim\sigma\sqrt N/(\sqrt{2\pi}L)$；在 $\sigma<K<2\sigma$，$D_K=N^{[1-(K/\sigma-1)^2]/2+o(1)}$。上界使用第11轮物理归约与第21轮**全可预测策略** CDF 界；下界使用延迟到达帽高的真实软斜坡/两层输入及其实际模块费用。没有用固定比例模型替代一般上界。[完整证明](core89.md)，[独立审查](audit89.md)。

## 3. 本机核验

Python12进程与Wolfram15的12内核，以80/160位目标精度独立计算112个标量参数案例：35个斜坡根、28个小帽分位数、49个超额源费用；另核对12项符号恒等式。维数参数为 $N=2^k$，$k=16,32,64,128,256,512,1024$。这些是大整数维数参数，计算未生成指数大小的空间网格。

最大软件相对差小于 $4.85\times10^{-65}$；早期有限参数不被强行要求已经进入渐近符号区。全部结果按公式重放，精度加倍、尾概率残差、根残差、极小阈值的省略误差、代码与历史依赖哈希均验收。[认证契约](certification89.md)，[验收摘要](validation89.json)。

按约1GiB可用内存余量监控；最终Python批次RSS峰值约372MiB，Wolfram约1832MiB，报告的可用内存最低约7864MiB。监控是系统估计，不是OS硬预留。本轮未启动MATLAB，全部自有Wolfram并行核已关闭。
