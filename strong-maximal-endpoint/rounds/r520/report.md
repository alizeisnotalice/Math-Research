# 第520轮　两轴复合中的内区间选择损失

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对真正的二维算子给出两种区间选择损失的精确分解。一个双条带指标源在正面积接收集上严格区分复合与矩形 halo。
- 下一步需判断中央近饱和目录能否在足够多切片上强制这种区间不相容。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。对有界非负可测 $g$，固定接收点 $(x,y)$。记 $a_I(t)$ 为 $g(\cdot,t)$ 在含 $x$ 区间 $I$ 上的平均，$m(t)=\sup_I a_I(t)$，$C=M_y M_x g(x,y)$。用含点的有理端点区间逼近可保证可测。若 $A_J$ 表示含 $y$ 区间上的平均，则
\[
 C-M_S g(x,y)=\inf_{J\ni y}\left[(C-A_Jm)+\inf_{I\ni x} A_J(m-a_I)\right].
\]
恒等式由对同一矩形的两个区间分别取下确界得到。首项是外区间离其最优值的差，第二项是各切片必须共用一个内区间的费用。特别地，只在一个指定外区间上证得正差通常不足以给算子差作下界。对乘积输入 $g(x,t)=u(x)v(t)$ 两算子相等，故没有对所有输入严格一致的比值改进。

**真实 halo 的正面积差。** 取源为 $[1,2]\times[0,1]$ 与 $[-2,-1]\times[1,2]$ 的并，接收区域取 $|x|\le1/10,3\le y\le31/10$。两条带各可独立沿横轴选区间，其平均均至少 $10/21$，再取外区间 $[0,y]$，得 $C\ge200/651$。对任一真正矩形，若其纵区间只命中上条带，则源比例至多 $(10/19)/(y-1)\le5/19$（命中长度与总长之比在取满上条带时最大）。若命中下条带，总纵长至少 $y-1$，且横向两个源区间合计所占比例至多 $10/19$：只命中一侧时端点计算即得；两侧都命中时，中间有长度二的空隙，两侧命中总长至多二，故比例至多一半。用各带纵命中长度至多一即得同一上界。因此在门槛 $2/7$ 处，复合 halo 至少在这块面积 $1/50$ 的区域内多计接收。这个例子并不估计高维中央切片上此类不相容的频率。
