# 第 2 轮：多层轮廓凸归约与有限维改进

日期：2026-11-06（Asia/Shanghai）。状态：完成严格固定维数归约与有限维数值机制验证；尚未声明高维次项突破。

## 1. 严格的固定轮廓下界

固定 n 和 r 向量，T=ΣZ_(r_i)。令 h 为有限有界、非减阶梯，在某个有限点以下为0。
取 f_L(x)=h(S(x)−L)1_[-1,1]^n。
Gamma 对数坐标给
\[
 \int\Phi_n(f_L)=\frac{2^ne^{-L}}{(n-1)!}\int_{-L}^{\infty}e^{-u}(L+u)^{n-1}\Phi_n(h(u))du.
\]
由于左边支撑有下界、右边有界，除以 \(2^ne^{-L}L^{n-1}/(n-1)!\) 后支配收敛成立。
若 \(E h(T-q)>1\)，由非减性，E_(L-q) 的每个非零坐标点均有所选矩形见证，因此
\[
 C_n\ge\frac{e^q}{\int e^{-u}\Phi_n(h(u))du}.
\]
这是实际可积函数的下界：先固定 n、h、q，再令 L→∞。没有使用原附件的全空间 halo 上界。

令 g(t)=h(t−q)，可把 q 完全吸收入分点。此时
\[
 J(g)=\int_0^\infty e^{-t}\Phi_n(g(t))dt,\qquad E g(T)>1,
 \qquad C_n\ge J(g)^{-1}.
\]
所以评分为 −log J，不能再额外加 q。把 g 设为 t<0 时为0不会损失见证。

## 2. 固定分点的全局凸振幅问题

分点 0≤t1<…<tm<∞，在最后一层后取常数高度，令 t_(m+1)=∞。
写 p_j=P(t_j≤T<t_(j+1))、w_j=e^-t_j−e^-t_(j+1)。优化
\[
 \min_{0\le c_1\le\cdots\le c_m}\sum_j w_j\Phi_n(c_j),\qquad
 \sum_j p_jc_j\ge1+\eta.
\]
Phi 在 [0,1] 线性，右导数于1从1跳到n。在 c>1 时
\(\Phi_n'(c)=(1+\log c)^{n-2}(n+\log c)\)。
以拉格朗日乘子 lambda 写 d_j=lambda p_j/w_j，逐层最优高度满足：
- d_j<1 时 c_j=0；d_j=1 时可取 [0,1]；
- 1<d_j≤n 时 c_j=1；d_j>n 时解 Phi'(c_j)=d_j。

条件于 Bernoulli 选择集合 A，令 a_A=Σ_(i∈A)(−log r_i)。密度的似然比为
\[
 e^t f_T(t)=\sum_A P(A)e^{a_A}\frac{(t-a_A)_+^{n-1}}{(n-1)!},
\]
它单调非减。p_j/w_j 为此函数在相邻区间内按 e^-t 的加权平均，亦单调非减。
所以逐点 KKT 高度已满足单调性，不需要额外块合并。
代码对 log lambda 作二分，对超过1的高度用 v=log c 反解导数；有限单元导致的0到1跳跃允许一个分数高度以满足期望。
固定分点的凸性证明给出算法的全局最优性条件；浮点输出仅验证这些条件的数值残差。

## 4. 运行验证与限制

MATLAB R2026a 实际求解，最大 KKT 相对残差 4.28e-14。
Wolfram 15 以80位独立重算全部概率、期望和模数：每个候选的期望均为 1+约1e-9，对数评分差最大1.53e-14。
sm_staircase 的 Code Analyzer 无报告；网格概率和权重为正、似然比顺序、期望约束、高度单调性均由运行断言检查。

这些检查仍不是定向认证；高精度不自动成为严格误差界。
理论归约保证：任何被严格验证期望>1、并对J给出上界的有限阶梯，都可转成 C_n 的严格下界。
固定维截断极限不提供维数一致收敛率，不能据表作跨维证明。
