# 第525轮　中央目录不提供全局统一的见证尺度窗口

- A 覆盖全部等权深度轮廓，中央误差有界。
- 在维数、门槛及接收源比全部固定时，可以把接收体积等分到任意多组相隔任意远的横向尺度。给定目录的截断不能只按一个全局长度比结算。
- 下一步须在每个接收点或每个局部组件估计有效尺度，而非约束全目录的尺度跨度。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取 $n\ge2$，有界源 $E$ 及有限严格见证目录，接收并 $U$。令指定第一轴的最小与最大见证长度为 $a,b$。给定窗口倍率 $H\ge1$ 和整数 $N$，取 $T>Hb/a$。做 $N$ 个副本，第 $j$ 个先在第一轴乘 $T^j$、第二轴乘 $T^{-j}$，再平移，使各副本的源与全部见证所处的有界包围盒互不相交。每次变换保持体积与轴平行性。取各源之并及变换后目录，各原见证的严格平均保持，源与接收体积均乘 $N$。设原比值已达中央基线减 $o(\log n)$，新目录在同一维数保持同一精度；可用有限有界近最优目录作为基底。

任取事后选择的窗口 $[l,Hl]$，它至多与一个尺度带 $[T^j a,T^j b]$ 相交，因为相邻带最近端点的比大于 $H$。故仅保留窗口内长度的原目录行，所得接收体积至多 $|U|$，只占新接收并的 $1/N$。同时各组件独立还原坐标后具有完全相同的局部尺度数据。这个障碍只针对从给定目录中删行；没有排除对同一源重新选见证，也没有说明任何单个点同时需要多个组件的尺度。

**局部计费。** 对不交接收组件 $U_j$，若在第524轮所考察的固定外区间问题中，各点均已独立建立长度窗口，比例至多 $H_j$，则固定样本阶数 $r$ 的受限损失逼近误差在归一化接收积分中至多为
\[
 4e+\sum_j \frac{|U_j|}{|\cup U_j|}
 \sqrt{\frac{\log[(1+\lfloor\log_2 H_j\rfloor)(2+2/e)^2]}{2r}} .
\]
这是对逐点期望误差的积分（数据取可测），不要求跨点同时成功的高概率事件。若从无限制问题改用这些窗口，还需另外支付截断误差。上述复制表明全局跨度可能完全来自彼此无关的接收点；局部尺度费用则对复制精确不变。尚未得到一般目录的局部截断误差界。

本机 Python 用有理数核对十二个行长带的分离及每个副本的二维行列式。
