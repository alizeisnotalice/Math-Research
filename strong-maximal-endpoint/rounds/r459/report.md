# 第459轮　单根外部双门槛模型包含低一维的一般目录

- A 覆盖全部等权深度轮廓，中央误差有界。
- 仅利用第458轮单根源的稀薄比例及两个严格门槛，所需的局部估计已包含低一维的一般指标源 halo，即使所有叶对根的正向伸长为零。
- 下一步应追踪单根提取后仍保留的全局源体积预算，尤其是为使根本身成功付出的源质量。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。给定任意有界有限正体积源 $G\subset\mathbb R^{n-1}$ 和有限严格 $p$ 成功矩形 $B_i$，记 $U_0=\bigcup_i B_i$。任取 $0<u<p$、内部平均上限 $d>0$ 及稀薄度 $\rho>0$。下面构造单根 $P$、共同源 $E$、外部子源 $F$，使所有叶在 $E,F$ 上分别严格超过 $p,u$，内部源平均小于 $d$，且 $|F|/|P|<\rho$。

取盒 $Q$ 包含 $G$ 及所有 $B_i$，设 $P=Q\times[-H,0]$，$F=G\times(0,1)$，$E=P\cup F$，叶 $R_i=B_i\times[-h,1]$。选 $h>0$ 足够小使 $h/(1+h)<d$ 且 $p/(1+h)>u$，再取 $H>1+h$ 足够大满足稀薄度。记 $z_i=|G\cap B_i|/|B_i|>p$，则
\[
 P_{R_i}(E)=(z_i+h)/(1+h)>p,\qquad
 P_{R_i}(F)=z_i/(1+h)>u.
\]
根平均为一，叶与根内部相交，各轴边长都不超过根，故第366轮贪心在任意 $t\ge0$ 均先保留根并将全部叶归给它。即使先让根负责自身全部体积，叶仍可分得 $U_0\times(0,1)$ 的不交接收区，负责体积除以 $|F|$ 恰为 $|U_0|/|G|$。因此局部双门槛体积比的上确界至少为 $H_{n-1}(p)$（有界源、有限严格目录的穷尽见指南 C.3）。还可对每个有限目录把 $u$ 取到 $p$，只需使用有限个 $z_i-p$ 的正最小值选 $h$。

**全局预算。** 这里 $|E|=H|Q|+|G|$，接收并为 $P\cup(U_0\times(0,1))$，故全局体积比至多 $1+1/H$。这说明构造本身远离中央反例，同时明确了局部化中丢掉的量：相同的局部双门槛、任意小的根外源占比和任意大的低一维 halo 比，都可与接近一的全局体积比共存。下一步可用各根成功条件 $p|P|<|E\cap P|$ 联合控制根内源重复与外部接收，而不能从稀薄度直接推出比低一维一般问题更强的单根上界。

本机 Python 有理数检验取 $z_i=3/5,p=1/2,h=1/100$，两个实际平均为 $61/101$ 与 $60/101$。
