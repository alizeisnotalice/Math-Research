# 第420轮　细门槛分带的对数费用

- A 覆盖全部等权深度轮廓。一般有限目录按原盒命中率分带，无须逐盒扩大。宽度 $1/(\sqrt n\log^4 n)$ 的中央各带可用 $O_I(\log\log n)$ 对数费用同时结算。
- 若超额落在中央带，严格余量可在原维数压低到第416轮所需精度。仍须处理高门槛尾部及限制接收分区后源边际的变化。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。设 $p\in I\Subset(0,1)$，固定 $b\in(\sup I,1)$，$h=1/(\sqrt n\log^4 n)$。不交负责区域按其原盒密度分组：$q_j=p+jh$，取 $q_j< b$，第 $j$ 组对应 $(q_j,\min(q_j+h,b)]$，另列 $d_i>b$ 的尾组。写 $v_j$ 为各组负责体积，$v_b$ 为尾组体积，$m=|E|$。每个中央组对 $q_j$ 严格成功且余量至多 $h$。令 $D$ 是所有非空组 $\log(v_j/m)-B_n(q_j)$ 和尾组 $\log(v_b/m)-B_n(b)$ 的最大值。则
\[
 \log(|U|/m)-B_n(p)\le D+\log\left[1+(1-e^{-c\sqrt n h})^{-1}\right],
\]
其中 $c=\sqrt{2\pi\mu}$，因为 $-B_n'(q)=\sqrt{\mu n}/\varphi(\Phi^{-1}(1-q))\ge c\sqrt n$。将各组体积按其自己的门槛基准求和，得到上式的几何级数。因此超额至多损失 $4\log\log n+O(1)$。尾组若占优，则仍有原门槛上移至固定 $b$ 的超额结论，但其行余量没有变小。

更具体地，若中央组占优且还具有第349轮同量级的稳定输运，则第416轮的严格余量费用至多 $2B\log(kn)h=O(1/\log n)$（$k$ 至多多项式）。这一输运前提不能从分带自动推出：条件化在负责体积占比 $\theta$ 的组，会把原耦合的源边际上界从 $K$ 放大至 $K/\theta$。反之，若单独掌握门槛 $b$ 的尾组体积上界 $m\exp(B_n(b)+O(\log n))$，则因 $b-\sup I>0$，尾组在原门槛处指数小于基线（对数差为负的 $\sqrt n$ 量级）。此时中央组必承载超额。下一步需核对已有中央粗界能否在固定 $b$ 提供这项尾估计，再处理分组内输运，避免先后两次归约互相破坏。
