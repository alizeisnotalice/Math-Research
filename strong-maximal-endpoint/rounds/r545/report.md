# 第545轮　同一反向双条带的双曲接收面积

- A 覆盖全部等权深度轮廓，中央误差有界。
- 用一个与维数无关的平面源同时计入全部可用尺度，中央门槛移动保持一步，归一化差集下界比第544轮增大对数因子。
- 下一步须估计一般平面源能否超过双曲面积阶，并区分存在性差额与一般输入必付缺额。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。令源 $E=[0,1]^2\cup([-1,0]\times[1,2])$，体积二。对 $0<x,v<1/4$ 的点 $(x,1+v)$，横复合再纵平均用 $[0,1+v]$ 得 $c\ge1-xv/[(1+x)(1+v)]$。真正矩形的横区间可分两侧前缀。右前缀只命中底带，平均至多 $1/(1+v)$。左前缀长度若至多 $2x$，顶部平均至多一半；若纵区间命中底带，顶部占比至少 $v/(1+v)$（裁到源的纵支撑后，加入更多顶部只提高该比例）。否则平均至多一半。左前缀长于 $2x$ 时底带横平均至多一半、顶部至多 $1/(1+x)$。以上给出
\[
 c\ge1-xv,\qquad s\le1-\tfrac13\min(x,v).
\]

取 $e=k^{-1/2}$，$a=e(\log k)^2$。限制 $x,v\ge a$ 且 $xv\le e$；充分大时 $e/a<1/4$。区域面积精确为 $e\log(e/a^2)-e+a^2\sim\tfrac12 e\log k$。在整个区域上同时有 $c\ge1-e$ 与 $s\le1-a/3$。固定中央物理门槛 $P$，同一基底只需在 $q=P/(1-e)$ 处达标。真矩形尾门槛 $P/(1-a/3)$ 比 $q$ 至少高 $c_I a$，第541轮同源界使收回比例至多 $k^{A+D}\exp(-c'_I(\log k)^2)$，前提为 $R_q=H_G(q)/(|G|e^{B_k(q)})\ge k^{-D}$。按第536轮归一化，认证差集对数体积比至少
\[
 B_{k+2}(P)+\log R_q-\tfrac12\log k+\log\log k-O_I(1).
\]
这些面积来自同一源和同一基底，按真实并集积分，未把相交的多份证书重复相加。所得改进为 $\log\log k$，尚未消除半对数主损失。对这个构造，横纵距离的乘积控制复合亏损，较小距离控制真平均亏损；一般输入是否允许更大的接收区域仍未知。
