# 第 111 轮独立审查

**可冻结。** 对任意固定紧区间 $J\Subset(0,1)$，存在 $n_0(J)$，使对全部 $n\ge n_0(J)$ 和 $p\in J$，等权双曲十字 $E_T$ 的**全空间严格 halo** 对原体积的比，在每个 $T\ge0$ 时至多为 $e^{s_p}$；对厚度取上确界恰为 $e^{s_p}$。$s_p=\mu n+\sigma\sqrt n\,\Phi^{-1}(1-p)+O_J(1)$。下界是 $T\to\infty$ 的极限。上述结论给 r110 (C) 在这一真实指标类上的有界秩余项。

1. 在正正交域可用 r093 的逐坐标单调性将实际成功矩形化为 $[-r_ix_i,x_i]$ 的乘积；符号对称覆盖其余正交域。对 $x_i>1$，本轴无论选择何种合法长度，落入 $[-1,1]$ 的最大比例为 $2/(1+x_i)\le x_i^{-1/2}$。令 $h=\sum_{x_i>1}\log x_i$，联合落入源立方体的概率 $w\le e^{-h/2}$。严格成功要求 $w>p$，故 $h<2\log(1/p)$，且条件命中概率严格大于 $p/w\ge p e^{h/2}$。该条件是原乘积空间的各轴事件之积，因此保留各轴均匀性及独立性。外轴的条件区间恰为 $[-\min(r_i x_i,1),1]$（左端未超出 -1 时原样保留）；内轴无变化。基本半径变为 $\min(x_i,1)$，全部条件对数增量仍属于确定侧比类。
2. 固定动作时 $S=G_n+J$，其中 $G_n$ 是单位尺度 Gamma，$J$ 为与之独立的非负移位和。故 $S$ 的密度上界为 $\|f_{G_n}\|_\infty\le K/\sqrt n$，且在正半轴连续严格为正。对每个固定动作积分，从阈值 $p$ 到 $p'=pe^{h/2}<1$ 的秩下降至少 $(p'-p)\sqrt n/K\ge p h\sqrt n/(2K)=ah$。先作此逐动作比较再取上确界，不要求选出共同优化动作。于是严格成功必须满足内轴深度 $>T-s_p+ah$。Chebyshev 给 $s_p=\mu n+O_J(\sqrt n)$，下方向可用最大均值 iid 动作；$a\asymp_J\sqrt n$、$C=2\log(1/p)=O_J(1)$。
3. 若 $0\le T<s_p$，包含关系给整箱的全空间 halo 上界。r095 的箱估计或直接按外轴距离作单纯形积分给 $|\mathcal H_p([-1,1]^n)|/2^n\le\exp(O_J(\sqrt n))$。原十字体积分数至少 $e^{-s_p}s_p^{n-1}/(n-1)!$。由 Stirling，价格对数至多 $(\mu-1-\log\mu)n+O_J(\sqrt n+\log n)$，一致小于 $s_p$。这包含 $T=0$，无须套用仅在非负自变量上的 Gamma 多项式公式至负参数。
4. 若 $T\ge s=s_p$，全是外轴时内深度为零，严格成功不可能。对恰有 $1\le j<n$ 个外轴，内轴以 $n-j$ 维 Gamma 原始生存概率计算，外轴用 $x_i=e^{h_i}$，薄层体积为 $e^hh^{j-1}dh/(j-1)!$。提出 $e^{-(T-s)}$ 后得到原稿的非负积分，衰减项为 $e^{-(a-1)h}$。先利用 $0<h<C$、$aC\le s/2$ 将多项式估为 $P_{n-j-1}(T-s/2)$，然后仅对已无多项式依赖的正核将积分放宽至无穷给 $(a-1)^{-j}$。又 $\binom{n}{j}/(a-1)^j\le (s/2)^j/j!$ 对所有 $j$ 同时成立，因为 $n/(a-1)\le s/2$。内轴项可作 $j=0$ 项处理。逐幂二项式恒等式给 $\sum_{j=0}^{n-1}v^j P_{n-1-j}(x)/j!=P_{n-1}(x+v)$，其中 $x=T-s/2,v=s/2$。乘回 $2^n e^{-(T-s)}$ 恰为 $e^s|E_T|$。$T=s$ 及每个中间外脸均在此论证内。
5. 固定 $n,p$。对立方体内部非坐标轴点，深度 $>T-s_p$ 时，按分位上确界的定义可找到一个固定动作给严格成功；深度等于边界的点是零测集。因此内部接收体积下界为 $2^nG_n(T-s_p)$。除以 $2^nG_n(T)$，当 $T\to\infty$，由 Gamma 多项式比得 $e^{s_p}$。这里可用严格成功的动作逼近分位，不需要分位等号通过严格测试，也不声称有限厚度取到上确界。
6. r022 (10) 的独立阵列一项 Edgeworth 展开在紧区间可统一反演：标准化三阶修正为 $O(n^{-1/2})$、余项 $O(1/n)$，$u=\Phi^{-1}(1-p)$ 在有界区间且稍扩区间的正态密度下界为正；于是在原秩上有 $s_p(S)=m+\sqrt V\,u+O_J(1)$。若 $D=\mu n-m$，r022 (2) 给 $|\sqrt V-\sigma\sqrt n|\le C\sqrt D$。上确界相对基准的误差至多 $\sup_{D\ge0}(-D+C_J\sqrt D)+O_J(1)$；最大均值 iid 动作满足 $m=V=\mu n$，提供反向界。受限类没有向全部二元源的上界传递。

本机 Python `Fraction` 对 $n=2,5,12,32$、$x=13/3,v=5/7$ 的截断多项式平移恒等式作精确有理复验，四项均相等；一般 $n$ 的结论来自第 4 条的逐幂计算。

## 增补终审：任意权重

**新增整节通过，可与等权部分同时冻结。** 对 r093 全体归一权重 $0\le w_i\le1,\max w_i=1$、全部 $T\ge0$ 及 $p\in J$，相应类的全空间物理价格上确界介于 $e^{s_p}$ 与 $e^{s_p}(1+O_J(e^{-c_J\sqrt n}))$。精确等式此前只对等权子族证明。

1. $D=\sum_i(1-w_i)\le n/4$ 时，多于或等于半数的权重至少 $1/2$，删掉一项后仍有线性数量的正则指数分量。其特征函数乘积给总密度上界 $K/\sqrt n$ 及 r093 的删除和局部高斯逼近，绝对误差 $O(1/n)$。在 $p\in J$ 的固定动作分位 $q$ 上，Chebyshev 保证 $(q-E S)/\sqrt n$ 落在固定紧区间。在 $1\le Z_i\le2$、$0\le w_i\le1$ 上，删除和在 $q-w_iZ_i$ 处的高斯密度至少 $c_J/\sqrt n$，真实密度亦然。真分位导数 $E[Z_i f_{-i}(q-w_i Z_i)]/f(q)$ 因而至少为 $c_J$。向等权依次增加权重始终保留条件 $D\le n/4$，积分后得到 $s_{p,w}\le s_p-c_JD$。零权用连续性。升高条件阈值的降秩同样可用总密度上界，$a=p\sqrt n/(2K)$。
2. 取固定小 $b<\min(c_J/2,\mu/8)$。立方体所占比例只依赖几何而与 $w$ 无关，所以 $h=\sum\log^+x_i<C_J$；层 $I=\{i:\log^+x_i>b\}$ 至多含 $\lfloor C_J/b\rfloor$ 个坐标。仅有一个空层，非空层数为 $O_J(n^{\lfloor C_J/b\rfloor})$。由条件分布回到原坐标时，权重外侧深度至多损失 $\sum_{x_i>1}w_i\log x_i\le h$，因此真实必要条件仍有 $(a-1)h$ 的正降秩。非空层有 $h>b$，可保守换为 $(a-1)b$。
3. 每个层放宽为坐标盒 $x_i\le e^{b_i}$，$b_i=b$ 或 $C_J$。若 $\sum_i w_i(-\log x_i)>T-s'$，正正交域积分不超过 $e^{\sum b_i}G_w(T-s'+\sum w_i b_i)$。因为至少一项权重为 1，对任意 $r\ge0$、实数 $t$ 有 $G_w(t-r)\le e^rG_w(t)$，负移位另用单调性。于是除源体积后的上界是文中两个指数的较大者。第一项 $\sum b_i\le bn+O_J(1)$ 始终远低于 $s_p$。第二项在空层至多 $s_p-(c_J-b)D$，非空层至多 $s_p-(a-1)b+O_J(1)$，因为 $\sum (1-w_i)b_i\le bD+O_J(1)$。$n^{O_J(1)}e^{-(a-1)b}=O_J(e^{-c'_J\sqrt n})$，故层数可吸收。对 $D>n/4$ 不用密度降秩，采用 $s'=s_{p,w}+C_J$；Chebyshev 给 $s_{p,w}\le3\mu n/4+O_J(\sqrt n)$。加 $bD+O_J(1)\le bn+O_J(1)$ 后仍距 $s_p$ 有固定线性间隔，足以支付全部层数。
4. 任意权类的下界仍由等权十字的厚度极限给出。以上不等式控制每个单独截断的加权对数半空间和真实全空间接收体积，未覆盖任意对数凸交集或任意一般源。
