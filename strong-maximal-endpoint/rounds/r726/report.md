# 第726轮　有限振幅真实中位数搜索与大样本稳定性

2026-11-14。此轮是探索性计算交付，未得到严格改进或一般障碍；一般端点的 $\log n$ 系数仍未知。严格的增长支撑障碍另见第727轮，不由本轮抽样负值推断。

对 $n=16,128,1024,8192$，比较稀疏 $(1,-1,0,\ldots)$ 与弥散 $n/2$ 个 $1/\sqrt n$、$n/2$ 个 $-1/\sqrt n$ 两种频率，轮廓 $h(\theta)=\epsilon\cos\theta$，$\epsilon=1,4,16$。每组64个相位节点、多起点局部优化几何代理函数，再对选定控制直接抽样真实变量 $S-\epsilon\cos(\theta+W)$ 的中位数。分别搜索侧比 $[0,8]^2$ 与 $[-8,8]^2$，各24组；不声称选定代理控制最优化了真实中位数评分。

**纠错记录。** 初批曾将应最大化的代理函数写成最小化；该批全部数值结论作废，仅在私有work保存错误JSON。最终脚本使用 `minimize(-proxy)`，另加每角结果不得劣于可行基线 $(\mu,\mu)$ 的断言，全部通过。负侧扩展还显式保留原可行控制，防止局部求解下降。此前复杂指数误用实指数的问题也已修正，正式结果均来自两项修正后的完整运行。

实际使用6维分组Gamma–二项逆变换，避免生成 $n$ 维样本矩阵；每参数两档独立扰动Sobol样本为 $2^{15}$ 和 $2^{17}$。64个中位数用周期插值控制场解释，评分用64节点积分，并记录偶节点32积分的差。两批均12进程、每进程BLAS单线程，耗时约2.54与2.96秒，保守峰值约1.80GB；所有样本有限。基线用有限Gamma–二项CDF求根，残差保留在JSON。主批7个、负侧19个被选局部解退出状态非成功，已逐项登记，不能当作全局最优证书。

两批没有正的相对基线抽样评分，但原两档最大差约0.179，足以说明不能把负样本值当成严格障碍。对较接近零的弥散 $\epsilon=1$ 情形，又在 $n=1024,8192$ 使用 $2^{19},2^{20}$ 两档、每档3个独立新seed，共12任务。因内存估计切为8进程，实测并发进程树峰值约2.55GB、约7.26秒结束。代表结果如下，均为相对固定 $c=\mu$ 基线中位数的抽样对数评分。

因此目前没有值得认证的正候选，仍不排除其它控制或轮廓。大样本检查不是置信区间或定向区间认证。随机种子、软件版本、角节点差、优化状态、内存口径和分位数值均有记录。

本机Mathematica另外实际使用12核，对两批共48组保存控制独立重算几何代理函数。按文件实际10位有效数字的舍入口径全部匹配；最大差约 $5\times10^{-6}$ 出现在万量级代理值。重算采用60位算术，但这不恢复输入已经舍去的数字。最初固定 $10^{-6}$ 比较容差未计入保存舍入，已依据真实保存精度更正；初始诊断保留私有work。它核对复杂相位和目标公式，不核验QMC中位数。

复现顺序：`nonlinear_search.py`、`negative_search.py`、`stability.py`，以及 `proxy_crosscheck.wl`。对应JSON为最终结果。所有本轮计算进程与Wolfram子核均已退出；本轮未启动MATLAB。
