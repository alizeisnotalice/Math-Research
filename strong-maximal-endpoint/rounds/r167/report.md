# 第167轮　见证内列密度的部分量化误差

2026-11-12。任意有限正体积指标源、平衡分块、固定中央门槛紧区间 I。在某个严格成功见证 X×Y 内，若至少 δ 比例的列的实际密度可用 h 个数值近似，且按整个 Y 归一化的绝对误差积分不超过 bδ²/(32h)，则该类接收点的对数价格至多 B_n(p)−c√n/h+O(log n)，其中 δ>0 固定，b,c 仅依赖 δ,I 与分块比例，h log n=o(√n)。这些数值和被近似的列均可随见证改变；不需取可数个候选剖面再求和。一般端点系数差仍为 (μ−1)/8。

**形状误差的价差。** 写 v(y) 为按实际列密度 c(y) 降序并打散平局的均匀秩，f(v)=Φ̄((U(p)−tU(v))/s) 为第166轮目标曲线。对任意列子集 D⊂Y、|D|/|Y|≥δ 及至多 h 个密度中心 Z⊂[0,1]，记
Q=∫_D dist(c(y),Z)dy/|Y|。
第150轮列方向对称差 η_col 满足
η_col + Q ≥ bδ²/(16h)，
其中 b 是 −f' 在 [δ/4,1−δ/4] 的统一正下界。理由：D 在该中央秩带内仍至少占 γ=δ/2 的质量。对任何 u>0，带内 dist(f(v),Z)≤u 的秩总长至多 2hu/b；即使 D 同一个密度层内只取一部分，均匀秩仍给出同样的质量上界。按 u 层积分，∫_D dist(f(v(y)),Z)dy/|Y| 至少为 ∫₀^{bγ/(2h)}(γ−2hu/b)du=bγ²/(4h)。再用距离函数的 1-Lipschitz 性及 η_col=∫|c(y)−f(v(y))|dy/|Y| 即得。代入第150轮即可，无需外包整个源。反之剩余见证在每个 δ 质量的列子集上都必须有相应的量化误差下界。这在数值中心随见证任意挑选时仍成立。

**按实际见证控制近似。** 对欲单独处理的列区 C，可以选 h 份参考行函数 g_j∈[0,1] 并给列标上 j(y)。对每个实际行盒 X 用中心 z_j=∫_X g_j/|X|。上式中的 Q 至多为
(1/|Y|)∫_{Y∩C} |∫_X(1_{E^y}−g_{j(y)})/|X||dy。
这允许行盒内部的正负误差抵消。比如沿行块第一轴 t 的每个截面，若有向原函数 ∫₀^t(1_{E^y}−g_{j(y)}) 的振幅（上确界减下确界）至多 l，则任一该轴宽 W 的行盒都给 Q≤l/W，直接由两端点作差及其余坐标积分。因此 W≥32hl/(bδ²) 的见证均可在 C 占比≥δ 时使用本轮定理。对 C 占比<δ 的见证仍可用 C 外的原源在门槛 p−δ 计费；短行盒则需要单独的局部源预算，不能由原函数振幅推出。按宽 w 的周期排布占空比 1/2 的条纹，可因列而任意改变相位，在完整周期段内相对常值 1/2 的振幅至多 w/4，却有逐点绝对差 1/2；用包含完整周期的有界支撑并将参考函数同时截断也成立。故以上假设确实允许非微小的逐点形状差。

**量级检验。** 在两块等维的中央门槛，目标分位 f(v)=1−v。取秩区间长度 δ，用 h 个等宽小段中点作中心，准确量化误差为 δ²/(4h)。在单位方形以源 x+y<1+ε（0<ε<1/8）取严格成功见证，实际密度 1/2+ε−ε²/2，接收盒体积 1；列排序分位为 min(1,1+ε−v)。在未饱和的一段长 δ 的秩区间（δ≤1−ε）同样能恰取 δ²/(4h)，列方向偏差却随 ε↓0 趋零。故只假定无常数限制的 O(δ²/h) 近似不足以强制正偏差。例子仅针对局部判别，并未否定一般中央目标。
