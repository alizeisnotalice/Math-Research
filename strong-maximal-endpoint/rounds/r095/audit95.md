# 第95轮独立审查

**结论。** 对每个固定临界门槛系数 $B$，式 (1) 的两个分数均为有限原源、相同严格门槛的**完整物理 halo**。单次坐标 Steiner 压缩可损失任意预定幂 $N^a$；极限取色数 $m=\lfloor c(L/N)h_N\rfloor$ 时，原分数为 $Q_NN^{o(1)}$，压缩分数为 $\Theta(N/L)$。全坐标压缩版对于每个预定次序可将编码方向放在第一位，最终分数为 $\exp(o(N))$ 的上界。没有证明同一标号源对每种首次压缩方向都产生此损失，一般 $H_N$ 和 $C_N$ 的对数系数仍未确定。

## 1. 封闭的真实体积结算

1. **后缀包。** 取 $n=N-1$、$\delta=L/N$。$p+2\delta$ 最终严格在 $(0,1)$，与后缀维数的临界门槛仅差可由两个固定 $B'$ 括住的 $O(L_n/n)$；$q_{0,n}=q_{0,N}-\mu+o(1)$。r093 的单个有界等权产品子水平集通过选择足够深的有限 $T$ 获得半个极限分数。其真实完整 halo $H$ 在每个坐标都界于有限区间，因为任何成功盒的侧长都被该源坐标宽度除以 $p+2\delta$ 所界，且必须与源相交。严格余量允许有理盒见证和可测首次编号选取。因此 $T_0<\infty$ 足以同时控制所有选定见证，且 $\log(|H|/|D|)=q_0+c_QL+o_B(L)$。

2. **随机铺包与删色。** 先将这两个有界集合放入边长 $S$ 的一个坐标图；副本可绕边界，但在周期提升中保留原短见证。每色放 $M=\lceil S^n/|H|\rceil$ 个独立 Haar 平移；$|H|/S^n\le1/4$ 确保 $1/h\le u=M|D|/S^n\le5/(4h)$。固定 $y$ 和色 $j$，某个该色副本的 $H$ 抵达 $y$ 的概率至少 $1-e^{-1}$。给定该色所有平移，再按固定规则选择其一个副本及短见证。其他色仍独立，每个空间点受到其他色覆盖的概率至多 $\lambda=mu$。因此该见证上因其他色被删除的**体积分数**期望至多 $\lambda$；Markov 给其超 $\delta$ 的概率至多 $\lambda/\delta$。原见证严格 $>p+2\delta$，现在仍严格 $>p+\delta$。不同色的成功接收集允许重叠，因为现在只加它们的体积。

   另行核对实际源费用。所有副本重数的积分确定为 $\lambda S^n$。同一点若重数 $l=0,1$ 不亏，$l\ge2$ 时丢掉的重数至多 $l\le l(l-1)$；故积分期望亏损至多 $\lambda^2S^n$，无需忽略同色内的交叠。存活体积低于 $3\lambda S^n/4$ 的概率至多 $4\lambda$。另一方面，若 $c$ 足够小则成功体积之和期望至少 $.6mS^n$ 且上界 $mS^n$，超过 $.3mS^n$ 的概率至少 $3/7$。由于 $\lambda=O(c\delta)\to0$，两件事对同一实现可同时达成。这一步无需在指数多的颜色间逐色并集。

3. **周期守护与裁剪。** 取 $P$ 是 $S$ 的整数倍，$nT_0/P\le\eta/2$，$\eta=1-p$。对角相位在任一短见证上的位移至多 $nT_0/P$，所以占长 $2\eta$ 的删除弧及两端扩张总长至多 $3\eta$。以整 $P$ 周期胞计算相位平均，删除源的期望至多 $2\eta\lambda P^n$，删除的认证接收体积之和的期望至多 $3\eta m P^n$。分别把失败界取为 $\lambda P^n/4$ 和 $.1mP^n$，两坏相位的总概率至多 $38\eta<1$。这一步发生在前一步已经固定的好铺包上。取 $R$ 为 $P$ 的任意足够大的整数倍，源体积精确介于 $\lambda R^n/2$ 与 $\lambda R^n$。舍弃边距不足 $T_0$ 的接收点所占比例至多 $2nT_0/R$，取 $R\ge40nT_0$ 即可使其低于 $.05$；裁剪后没有使用无限质量源的 halo 充数。

   长边控制作用于**每个**实际成功矩形，包括盒外接收点。若任意后缀边长大于 $T_1=4P/\eta$，沿该坐标每一条贯穿线的守护删除比例至少 $2\eta-2P/T_1=3\eta/2>\eta$。整盒密度因而不可能严格超过 $p$。裁剪源的每个成功接收点的后缀在 $[-T_1,R+T_1]^n$ 内，取 $R\ge4nT_1$ 使 $(1+2T_1/R)^n\le e^{1/2}<2$。两项对 $R$ 的要求可同时满足，没有遗漏随维数增长的边界因子。

4. **前坐标编码。** 生存的 $A'_j$ 两两不交，故每个非空前坐标纤维长度严格等于一，单次压后精确成为 $I_0\times\bigcup A'_j$，费用守恒。任意原成功盒的前边长 $<1/p<2$，因每条前坐标截面至多长度一。间距至少二的两编码带不可能同时贡献；同一门槛的单带水平外扩各侧又都短于一。原 halo 的接收体积下界为 $.15mR^n$（各带的水平内部互不相交），上界为 $2m(2/p-1)R^n$。压后下界为 $.15R^n$（认证后缀的并至少是和除以 $m$），上界为 $2(2/p-1)R^n$。除以同一费用，再用 $\lambda\asymp m/h$，即得 (1) 两边及各应用。单次损失来自不同色在压后共用接收体积，不能把原分数误解为比各分量自身最优弱常数又增加了 $m$ 倍。

5. **全坐标压缩。** 饱和色数下盒内源密度为 $\Theta(\delta)$；任意后续坐标压缩只将当轴纤维移为长度不超过原盒该边的居中间隔，从而仍被同边长的一个矩形容纳。对矩形本身，$\prod_i(1+d_i/\ell_i)<1/p$ 蕴含 $\sum d_i/\ell_i<1/p-1$，按外侧坐标个数分解、积 simplex，得正文中的指数上界。$N(1/p-1)=O(\sqrt{NL})$，于是最终分数 $\le C\delta^{-1}\exp(O(N^{1/4}L^{1/4}))=\exp(o(N))$。此处不需要守护在后续操作下仍保留。

## 2. 平移箱纤维

- 对任意可数个不同带，成功见证不能取两个色源的质量，且各单带的严格 halo 水平方向不交。单带乘积因式分解；在 $b_j(y)>p$ 的截面其严格水平 halo 长为 $2b_j/p-1$，故式 (2) 为真实全式。
- 对任意可测中心 $b(y)$，式 (3) 的前向每边 $<1/p$ 来自单纤维长度一；能为当前矩形贡献测度的后缀行必落在所定义的 $D_x$ 中。原后缀侧边不变且其 $D_x$ 密度 $>p$。Fubini 对每个已占用行计 $(1+2/p)^k$ 的可兼容接收位置。对 $N/2\le n=N-k<N$，r091 的 $2n^{-4}$ 可忽，基准正态密度 $\asymp L/\sqrt N$，门槛产生原秩 $O_B(1)$ 位移。均值损失 $-\mu k$、前向积分收益 $k\log3+O(k\rho)$、尾距变化 $O(k\rho)$，得 (4)。其中 $\mu-\log3>0$，所述 $k\gg L$、$k\le N/2$ 的排除有效。
- (5) 仅需一次全局坐标膨胀和源原体积守恒，允许中心和宽度共同随行变化。原稿的匹配下界语句已收窄：允许 $k=1$ 的联合类包含等权 cross，给定 $k=o(L)$ 也可取 $k$ 维纯箱乘 $N-k$ 维 cross，在前箱内部取所有真实成功后缀点；$q_{0,N-k}-q_{0,N}=O(k)=o(L)$。对一般预先给定的更大 $k$，等权 cross 的 $k$ 维纤维不再是箱，不能由 r093 自动得到匹配下界。统一上界 (5) 不受此限制。

**独立本机常数检查。** 选择 $c=1/1024$，以 $1-e^{-1}>5/8$ 作有理下界；在 $\eta\le1/128$、$\delta\le1/1024$ 的尺度诊断中，最低预期成功比例为 $20455/32768$，打包两事件同时成功概率下界为 $485691/1048576$，两守护事件同时成功概率下界为 $45/64$。长边最坏删量是 $3\eta/2$。本机 Python 实际执行的复现算式如下；无随机抽样，未计算有限维生效起点。
```python
from fractions import Fraction as F
c, eta, delta = F(1,1024), F(1,128), F(1,1024)
lam = F(5,4)*c*delta
good = F(5,8)*(1-F(5,4)*c)
print(good, (good-F(3,10))/F(7,10)-4*lam, 1-38*eta, 2*eta-eta/2)
```

**定稿式 (6)。** 对周期真指标的有限侧长 $K$ 接收集先作整周期盒裁剪，内部接收点保留全部见证、原源体积恰为周期密度乘盒体积；先令盒端趋远再令 $K\to\infty$，得 $d_N(p,\theta)\ge \theta/H_N(p)$。反向从一个有界真实源及其整个有界真 halo 出发，整体等比缩小至固定环面一图中；以 $f$ 表示 halo 面积分率，$h$ 表示其物理得分。$M=\lceil\log(1-\theta)/\log(1-f)\rceil$ 个独立环面平移使任一点至少以 $\theta$ 的概率保留某副本原本的严格见证，而任一实现的源体积分率均不超过 $Mf/h$。这两点无需同一实现上的第二次选优。取满足所需覆盖份额的一个实现，再令 $f\downarrow0$、$h\uparrow H_N(p)$ 即得另一方向。有界真实源可由单调截断得到。$\theta=1-1/N$ 时负对数周期密度与 $\log H_N$ 差至多 $O(\log\log N)$，该等价本身未给出更优的真实 $H_N$ 上界。至此已审 core95 (1)–(6) 及全坐标推论。
