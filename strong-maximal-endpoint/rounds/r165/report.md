# 第165轮　高重数列的分位收费与多项式尾质量

2026-11-12。平衡分块、固定中央紧区间 I。E=∪ F_i×G_i，行因子两两不交，列重数 N(y) 可以无界。固定整数 d≥1。若下列两项条件成立，则任意预定 D 的中央上界 B_n(p)−D log n 成立：
* 关于归一化源测度，Σ_{j=0}^{d−1} binom(N(y)−1,j) 的期望至多 n^K，K 固定；
* N>d 的列中所占源质量比例 τ_n 小于任意负幂（对指定 D 只需充分大的固定负幂）。

N 在源测度下至少为 1，组合数按有限子集计数。常数、维数起点可依赖 I、块比例、d、K、D 和尾部预算。此处不要求 τ_n≤exp(−λ√n)，也不限制列重数的本质上界。一般系数差仍为 (μ−1)/8。[完整证明](proof.md)

本轮保留了异常列在原矩形中的排序。若在最高秩列中找到合适的低重数列，沿用第164轮的有限标签阶梯，所有候选按上面的源矩计费。若任何低重数列都不能捕获足够命中，则在一段固定高秩带上，几乎所有列均有高重数。由双向分位偏差和加权形状误差，可在真实见证上选一对联合门槛，其秩成本至多为 B_n(p)+O(log n)，分母只支付异常列所含的源质量。这使低质量异常列在平衡块下只需支付多项式费用。

剩余缺口是高重数列承载显著的源质量，或其有限阶组合矩过大时的统一估计。下一步应检验：当高低秩列都由高重数标签主导时，能否以列内不同真实行剖面的数量替代原标签数。[有界重数基线](../r164/report.md) · [赋权稳定性](../r151/report.md)
