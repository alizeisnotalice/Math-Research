# 第370轮　原见证直接覆盖与双向远尺度交叠

- A 已覆盖全部等权可测深度轮廓，误差有界。
- 扣除所有单向近邻后，第369轮的直接覆盖和最小加权度仍同时成立。每条计费边在两个方向上的总对数伸长都超过 $n/400$。
- 未证部分是双向远邻在同一源上的集体命中约束。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第369轮的实际接收单元 $C_i$、体积 $a_i$、权 $w_i=a_i/|R_i|$、源交体积 $e_{ij}$。写 $d(j,i)=\sum_k(s_{j,k}-s_{i,k})_+$。近边指 $\min(d(j,i),d(i,j))\le t$。对每条无向近边将费记在较大体积的端点 $i$（平手按序），于是 $d(j,i)\le t$。只需计正交体积的边。固定 $i$ 后，第366轮归并区域估计给出这些 $R_j$ 的并体积至多 $D|R_i|$，其中 $D=3^n\exp(t+2\sqrt{nt})$。由于接收单元不交，且 $e_{ij}\le|R_j|$，
\[
 \sum_{j\text{ 记入 }i} w_iw_je_{ij}\le w_i\sum_j a_j\le Da_i .
\]
这个估计可在任何子目录内重用原权，无需重新分区。

只以双向远边计算度，反复删去剩余加权边和小于 $ha_i$ 的盒。对已删集 $L$ 记 $A=\sum_{i\in L}a_i$。其无向远边总权至多 $hA$，无向非对角近边总权至多 $DA$，对角线至多 $A$。第369轮同一源上的二阶矩下界遂给出
\[
 p^2 A^2/|E|\le (1+2D+2h)A.
\]
取 $t=n/400$，$\eta=n^{-2}$，$H=\log(|U|/|E|)\ge B_n(p)-O_I(1)$。因 $\log3+1/400+2/20<\mu$，充分大维数可取 $h=\eta p^2e^H/4$ 并使 $A\le\eta |U|$。剩余原盒直接覆盖其保留的接收单元。且对每个剩余 $i$，
\[
 \sum_{j\text{ 剩余},\ \min(d(i,j),d(j,i))>n/400}
 w_j e_{ij}/|R_i|\ge p^2e^H/(4n^2).
\]
对单条计费边又有 $e_{ij}\le e^{-n/400}\min(|R_i|,|R_j|)$。故同一批真实见证同时满足直接覆盖和双向远邻约束，无需对代表盒的膨胀区域重新指定见证。尚不能要求剩余盒两两远；下一步应控制每盒的这些远邻能在多少源点同时命中，并追踪条件命中分布。
