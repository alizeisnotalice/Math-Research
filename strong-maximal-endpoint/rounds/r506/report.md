# 第506轮　矩形源块数障碍的精确单盒指数

- A 覆盖全部等权深度轮廓，中央误差有界。
- 用单矩形 halo 的精确大维指数提高第505轮的两个源块数下界。
- 下一步须处理多个源块在同一见证内的联合命中，突破逐块取并的估计。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。对第453轮的 $Q_n(e^{-nx})$，归一化到单位半边长后，单轴坐标代价为 $h(v)=\log^+((1+v)/2)$，$v\ge0$；正半轴体积相对原盒归一化。其拉普拉斯积分为 $Z(u)=\int_0^\infty e^{-(1+u)h(v)}dv=1+2/u$。于是 $Q_n(e^{-nx})\le e^{nR(x)}$，其中
\[
 R(x)=\inf_{u>0}\{(1+u)x+\log(1+2/u)\},\qquad u_x=\sqrt{1+2/x}-1.
\]
这个指数精确：取 $0<x'<x$，按上述密度以 $u_{x'}$ 归一化独立抽各轴，代价均值为 $2/[u_{x'}(u_{x'}+2)]=x'$。在样本均值与 $x'$ 相差至多 $\epsilon<x-x'$ 的事件还原体积，由大数律得下指数至少 $(1+u_{x'})(x'-\epsilon)+\log Z(u_{x'})$。让 $\epsilon\downarrow0,x'\uparrow x$ 即得匹配下界。单盒接收包络的每个内部点确由逐轴连接远端点的乘积区间见证，故不是更大虚拟区域的指数。

对第505轮的矩形并，保留 $a=\log(M/p)$，有 $\log(V/|E|)\le\log D+nR(a/n)$。$R$ 严格递增且在零点连续延拓为零。中央规模下，若 $\log D=o(n)$，则 $\liminf\log M/n\ge R^{-1}(\mu)$；一般用 $D\le M$ 则取 $R(x)+x=\mu$ 的根。两者分别为 **0.19782760** 与 **0.15408974**（近似值）。这是改进的必要条件，不声称可用相应块数构造极值源。两处数值由本机 Python 二分求得，解析定义为准。
