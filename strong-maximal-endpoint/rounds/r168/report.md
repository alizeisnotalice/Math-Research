# 第168轮　任意盒源的单参考剖面嵌入

2026-11-12。固定 n=m+k、p₀>0 及任意有理盒并 A，0<|A|<∞。给定 ζ>0、l>0，可以构造有限盒源 E，使所有 p∈[p₀,1) 同时满足
(1−ζ)V_A(p)/|A| ≤ V_E(p)/|E| ≤ V_A(p)/|A| + ζ H_n(p₀)。
在整份源上，沿指定行坐标的列剖面相对于两份参考行函数（列盒内同一份、盒外零函数）的原函数振幅至多 l。同时构造中所有成功矩形均只能命中一个时间单元，时间宽度小于 l。因而第167轮的长见证近似条件即使在所有列上成立，也不足以给短见证提供优于一般 H_n(p) 的价格。这里的 l 可相对于归一化后的宏观时间支撑任意小。一般系数差仍为 (μ−1)/8。

**备置与平移。** 记时间坐标 t、其余行坐标 x、列坐标 y。先作有理平移与对角缩放。在时间相位 [0,1] 中把支撑放进 [1/3,1/3+w]，有理 w<p₀/10。对每个列坐标，把支撑缩进横向单位周期内很小的区间。凡单源的严格成功矩形，其在任一轴的长度至多为源投影宽除以 p₀；故所有成功见证的各列坐标投影都在事先固定的扩盒中。可使扩盒各侧宽度小于 ζ/(4k)（必要时先把 ζ 减小）。上述变换保持全部归一化 halo 体积比，以下以 A 指变换后源。

取足够大的公共整数 q，使列坐标所有有理盒面均在 1/q 网格上。对 y 取 q^k 个离散环面平移，每个平移一次，在一个时间单元中放入其周期切割后的源。对几乎每个固定 y∈[0,1]^k、每个固定时间相位 t 和其余行坐标 x，所有平移副本在该点的指标之和恰为 q^k g(t,x)，其中 g 为原切片在整个列单位盒内的平均。这是因为各列网格单元的值被遍历一次；无需假设横向连续性。g 在列盒外以另一参考剖面 0 替代。把依次排放的 q^k 个时间单元称为一个周期。其在任意列和固定 x 上的累计有符号误差恰为零，原因是对每个单元先在同一相位上求和再积分。周期可以重复任意整数次。最后压缩时间，使总支撑放在 [0,1]，每个完整周期长为 1/N；取 N≥2/l。各参考剖面用相同相位重复、在时间支撑区间以外设为零。误差函数绝对值≤1，其原函数的任意两值之差绝对值至多 2/N≤l，独立于列与 x。

**在全空间结算。** 若某时间区间碰及 j≥2 个活动段，其时间占用率至多 jw/[(j−1)(1−w)]<p₀；因此严格成功只来自一份单元。成功区间长至多 w/p₀ 乘单元宽，还小于 l，且位于该单元内部。不同单元的接收域不交，真实源质量也精确按单元相加。对单个平移，若原先的扩盒在所有列方向平移后均未遇到周期切口，整份源只是普通平移，所有 p≥p₀ 的真实 halo 价格精确保持。坏平移比例按各轴求并至多 k(ζ/(4k)+2/q)，可将 q 取为原分母的足够大倍数以使之小于 ζ。每个坏单元仍有完全相同的源体积，其接收价格至多 H_n(p₀)。两侧求和即得首式；不把环面切碎的坏单元当作全空间刚性平移。

**直接面向一般源的后果。** 固定 n,p，取逼近 H_n(p) 的有限有理盒源，先固定其严格精度再作上述构造，让 ζ↓0。两参考剖面且原函数振幅任意小的类，在不限制短见证复杂度时，仍具有全部一般指标常数的上确界。只看长程抵消的改进必然在这一类上遇到与原问题相同的短见证子问题。该结论没有否定在每个短格另有独立结构假设时的局部化定理。下一步转向限制见证内、尺度不变的剖面复杂度，并检验它是否能同时识别环面平移微结构与真正的低复杂度输入。[前轮量化估计](../r167/report.md) · [严格盒逼近](../r116/slices.md) · [网格置换校准](check.py)
