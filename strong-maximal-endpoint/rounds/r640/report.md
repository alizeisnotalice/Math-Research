# 第640轮　中央增益保持下的全最优面对偶密度上界

- A 的全部等权深度轮廓中央误差有界。
- 任一中央近最优有限目录向下移动一个 $n^{-1/2}$ 的门槛后，其相对中央基线的增益至多损失常数，而每个最优对偶在均匀接收体积下的平均密度都指数小。无需可微门槛。
- 一般系数差仍为 $(\mu-1)/8$。未控制按平均值归一化的密度分布，也未得到中央增益的绝对上界。

2026-11-13。容量域为目录并 $X$，沿用第604轮的闭包最小质量 $m(t)$ 及第639轮的 $G(t)=|X|/m(t)$。取 $0<q=p-h<p<1$。对 $q$ 处任一最优乘子，令 $s_q=\sum_R\lambda_R1_R$，$T_q=\int_X s_q$。该对偶在任意门槛都是合法仿射下支撑，所以
\[
 m(q)+hT_q\le m(p),\qquad
 \frac{1}{|X|}\int_X s_q\le\frac{G(p)^{-1}-G(q)^{-1}}{h}\le\frac{1}{hG(p)}.
\]
此处必须取较低门槛处的对偶，且适用于整个最优面，即使 $q$ 正好是折点。逐行需求随门槛单调，故 $G(q)\ge G(p)$。非严格最优对应的严格增益上确界由第604轮混合恢复。

**中央精度。** 对 $p\in I\Subset(0,1)$ 取 $h=n^{-1/2}$，充分大维时 $B_n(q)-B_n(p)=O_I(1)$。因此若 $\log G(p)\ge B_n(p)+r$，则同一目录 $\log G(q)\ge B_n(q)+r-O_I(1)$，且
\[
 \frac{|\{x\in X:s_q(x)\ge t\}|}{|X|}
 \le \min\{1,\sqrt n\,e^{-B_n(p)-r}/t\}
\]
对任意 $t>0$ 一致。特别若 $r\ge-D\log n$，则任取固定 $0<\eta<\mu$，在 $t=e^{-(\mu-\eta)n}$ 处右端仍为 $e^{-\eta n+O_{I,D}(\sqrt n+\log n)}$。这把第639轮的低密度障碍落实到中央近最优目录本身，只需常数对数误差的门槛转移；对原门槛 $p$ 的上方次梯度没有作出断言。

**归一化后的缺口。** 在门槛 $q$ 处 $T_q>0$。令 $g_q=|X|s_q/T_q$，则接收均值为一。若 $E_q$ 是任一最优指标源，由正权行饱和有 $\int_{E_q}g_q=q|X|$，但 $|E_q|/|X|=1/G(q)$。所以归一化密度已有固定质量集中在指数小的源上；要利用源外剩余的 $1-q$ 份质量，还须控制它落在多大接收体积内。仅由均值或固定密度层的支持不能读出所求上界。
