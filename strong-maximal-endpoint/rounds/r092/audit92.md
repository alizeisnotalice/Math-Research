# 第 92 轮独立审查

**审查结论。** 临界截高下的真实单指标上界归约成立。其门槛为 $1-d/N-B_P(\log N)/N$，其中 $P$ 先固定；它不提供真实指标 halo 随阈值的连续性估计。实际指标、固定独立增量的命中分位以及全可预测策略的命中分位是三个不同的对象。已对照 r011、r021 (15)、r022、r028 第4节、r029 (17),(19),(20) 及第90、91轮物理源测试。以下为固定参数、充分大整数维数的结论。

1. **去掉高度一的跳跃。** $T(v)=(v-1)_+$ 在 r090 包络的整个断开定义域连续非减、$T(0)=0$、值域有界。$T(W_s(t))\le (t-s)_+/N+C\rho^2 1_{t\ge s}$，截帽后右边继续递增。r021 高斯比较变量满足 $E(G'-s)_+=d+O_P(L)$（左超越量有界），故变换后的期望为 $\tau+O_P(L/N)$ 的上界。该处无占用跳跃项 $-P(G'<s)$，没有把旧 $O_P(L^2/N)$ 误差强行缩小。r090 (4) 先对紧截断的原源重排并使用其原模数，再由变换保序给物理严格异常 halo，费用为 $e^{q_0-(P+5)L}J(F)\le Q_N N^{-P}J(F)$。同一 $U=\{M_S(F-1)_+>\tau+B_PL/N\}$ 在空间净化前后完全相同，故灰阶源在这一处甚至无须取异常集极限。对 $x\notin U$ 的任意真实成功 $R$，$m_R\min(F,1)=m_RF-m_R(F-1)_+>\beta_N$，严格号方向正确。

2. **物理收费与量词。** 记 $S_0=\int\min(F,1)$，有 $0<S_0\le J<\infty$，原支持可以有无穷体积。对任意 $0\le u\le1$ 的真实严格 halo，以网格内同质量零一替换及边界格误差、Fatou 得 $|\{M_Su>p\}|\le H_N(p)\int u$。这一步不引入 $\Phi(1/p)$ 因子。对所有临界帽源先取上确界，再应用第89轮一般帽归约，得到 core92 (2)。在原 $F$ 上未证明 $m_R 1_{F>0}$ 具有相同精细的双侧估计。对每个固定 $P$，$B_P$ 一经选定便与源、矩形和 $N$ 无关，未给出有限维生效阈值。

3. **临界指标的未标准化秩。** r091 (6) 的输入是实际强极大指标上界，r021 的比较误差在尾概率变量中为 $2N^{-4}$。$\bar\Phi(z)=\tau$ 及 Mills 公式给 $\phi(z)/(\sigma\sqrt N)\sim L/N$。$\tau$ 变至 $\tau+B_PL/N+2N^{-4}$，在固定倍数 $1/\sqrt N$ 的标准化邻域里密度比一致为 $1+o(1)$，故原始秩只移动 $O_P(1)$；增加 $t_0=O(L)$ 所致标准差项亦为 $o(1)$。于是 $\log H_N(\beta_N)\le q_0+C_HL+O_P(1)$。对真实 $Q_NN^{-K}$ 效率源令 $P=K+3$ 并减除实际异常量，$J/S_0\le N^{K+C_H-c_Q+o(1)}$。对任意帽内 $y\ge0$ 有 $\Phi_N(1+\tau+y/\sqrt N)|E_y|\le J$，且该价格对数为 $d+y\sqrt N+O(L)$，推出正文全层体积上界。

4. **移动高层负载的双侧指数。** 保持第91轮自己的 $G$、$G_{\rm tail}$ 和任意成功矩形选择，无须将本轮 $U$ 再交进去。令 $t=\sqrt{L-8\log L}$、$y=\sigma t$。r091 一次额外测试给 $m_R1_{E_y}\ge cN^{-1/2}L^{7/2}$ 在 $G_{\rm tail}$ 上对所有见证成立；通过正性，$\int_{E_y}w\ge c(1-O(N^{-2}))N^{-1/2}L^{7/2}|G|$。因此正文高层/基底平均负载比的对数至少为 $d+y\sqrt N-O_K(L)$。

   反方向也闭合。取 $p=cN^{-1/2}L^{7/2}/2$，则实际 $G_{\rm tail}\subset\{M_S1_{E_y}>p\}$。由 Mills，$\bar\Phi(t)\asymp N^{-1/2}L^{7/2}$，其概率乘固定正因子只使正态分位改变 $O(1/\sqrt L)$（在 $t\pm C/\sqrt L$ 直接比较正态尾）。$2N^{-4}=o(p)$。代 r091 (6) 得 $\log H_N(p)\le\mu N+y\sqrt N+O_K(\sqrt{N/L}+L)$。由 $|G_{\rm tail}|\ge Q_NN^{-K}J/2$，$\log(J/|E_y|)\le d+y\sqrt N+O_K(\sqrt{N/L})$。现在 $S_0\le J$、$\int_{E_y}w\le |G|$、$\int ew\ge(1-o(1))|G|$（r091 在原 $G$ 的基底亏损界），给所有原选择相同的反侧上界。由于 $y\sqrt N/d\to1$，该负载对数除以 $d$ 沿每列此种源及各列任意选择都趋于 $2$。这是指定移动层的负载率；没有随之得到一般 $C_N$ 的对数系数。

5. **固定动作及全可预测动作的区别。** r022 的统一一阶 Edgeworth CDF 绝对误差 $O(1/N)$ 在共同分位附近除以 $\phi(z)/\sqrt V\asymp L/N$ 仅为 $O(1/L)$ 的秩误差；所求阈值变化 $BL/N$ 为 $O_B(1)$ 秩误差。Taylor 核对量级，$O(L)$ 位移的高斯二阶项和 Edgeworth 项变化除以密度均为 $O(L^{5/2}/\sqrt N)$，从而正文的统一式 (7) 成立。有竞争力的固定向量因 $D\le CL+Cz\sqrt D$ 而有 $D=O(L)$。在此窗口展开 $V$ 的平方根，并逐坐标优化，偏置项增加 $g=(\mu-1)/8$，标准第三累积量项给 $(3-\mu)/6$，两者之和为 $c_Q=(9-\mu)/24$。r028 实现的轮廓取 $h(t)=1_{t>s}$ 就是货真价实的指标源；在任意低于命中分位的 $s$ 有严格命中，经深层盒极限给真实指标下界，不能据此给真实指标上界。

   对 r029 的另一种短核验是，在其偏置独立基准 $a_N$ 上直接以 $t=s_p(S_{a_N})$ 为起点，连续正密度给 $F_a(t)=1-p$。$t=q_0+c_Q L+o(L)$ 与 r029 (20) 的平台根在同一 $O(L)$ 窗口，故密度一致等价于 $L/N$。在 $s=t+(1-6\epsilon)gL$ 用 r029 (17),(19)，独立 CDF 增量为 $(1-6\epsilon)gf_N(t)L(1+o(1))$，可预测策略的 CDF 收益至少 $(1-4\epsilon)gf_N(t)L(1+o(1))$，故该策略严格可行，任意固定 $B$ 都可使用。令 $\epsilon\downarrow0$ 得 $c_R=c_Q+g$ 的可预测命中下界。r044 的软端点上界不自动给独立的纯命中分位上界 $c_R$。真实指标 $H_N$ 与全可预测最大命中之间仍只有一侧物理比较。

**轻量本机复现。** 以下 Python 标准库脚本按真实运行记录给出对照数。$L=16,32,64,128$ 时，$f(q_0)/(L/N)$ 依次为 $0.63354579,0.76412431,0.85738093,0.91694783$；在保持标准差不变的对照模型中，把尾概率增大 $3L/N$ 的未标准化秩移动为 $4.72514893,3.92605902,3.49902813,3.27172375$。以变动区间的三点 Simpson 公式积分避免两小概率相减。解析界承担所有渐近结论。

```python
from math import erfc, exp, pi, sqrt

mu = 1.0
for _ in range(48):
    mu = 1 + exp(-mu)
sigma = sqrt(mu)
for L in (16, 32, 64, 128):
    n = exp(L)
    lo, hi = 0.0, sqrt(L)
    for _ in range(80):
        z = (lo + hi) / 2
        if erfc(z / sqrt(2)) / 2 > sigma * z / sqrt(n):
            lo = z
        else:
            hi = z
    z = (lo + hi) / 2
    ratio = sqrt(n) * exp(-z*z/2) / (sigma * L * sqrt(2*pi))
    def scaled_probability_change(k):
        def f(u):
            return exp(z*u/(sigma*sqrt(n)) - u*u/(2*mu*n))
        return ratio*k*(f(0) + 4*f(k/2) + f(k))/6
    lo, hi = 0.0, 8.0
    for _ in range(75):
        k = (lo + hi) / 2
        if scaled_probability_change(k) < 3:
            lo = k
        else:
            hi = k
    print(L, format(ratio, '.8f'), format((lo + hi)/2, '.8f'))
print(mu, (3-mu)/6, (mu-1)/8, (9-mu)/24, (9-mu)/24+(mu-1)/8)
```
