# 第687轮　截面宽度与逆体积的二维分层割

2026-11-13。沿用第686轮两侧固定分簇。在 D 簇 g 内，以全簇行预计算 w_g(u)=|∪_{e∈g:u∈Q_e}D_e|，令 c_e 为 w_g 在 Q_e 上的本质上确界，b_e=1/|D_e|。给定方向分配，在源原子 A 上将所有命中且分给 g 的行对应的参数矩形 [0,c_e]×[0,b_e] 取并，其面积记作 P_A。该组接收并体积至多 H_h(p)Σ_A m_A P_A。

证明：所分配行的实际宽度不超过 w_g。实际宽度大于 t 的每个附加点，除零测边界外，属于某个已分配且 c_e>t 的 Q_e。应用第682轮层估计再对 t 积分，所得正是参数矩形并的面积。故该结论对每个分配同时成立。P_A≤|∪_{e∈g}D_e| max b_e（最大值限于分配并命中 A 的行），所以改进不会增加第686轮任一分配的费用。Q 侧交换两轴即可。

**精确求割。** 用参数矩形的全部端点将参数平面切为小格；每个正面积格的费用是 H_h(p)m_A 乘其面积，只要至少一条被分给该方向的命中行覆盖该格才支付。按第685轮对每个这样的“或”约束用一个辅助节点即可。有限可行割与方向分配的最优值相同。不能仅用 max(c_e b_e) 替代并面积，因为不同宽度与体积可形成互不包含的参数矩形。

**严格改善。** 两侧各固定一个簇，取 N 个互不相交的单位 D_i，分别配互不相交的单位 Q_i，两轴均为一维。源为全部积行的并。对任一方向旧费用每行均为 NH_1(p)，任何混合分配的总费用为 N²H_1(p)。新参数矩形均为单位方形，两方向每行只付 H_1(p)，最小总费用恰为 NH_1(p)。这个比较固定了簇，不排除旧方法通过重新分簇取得同样的费用。

一般系数差仍为 (μ−1)/8。下一步：对同一分配把宽度按已分配行重新计算，检验是否仍能精确求割；用几何分离条件约束对偶流所经过的参数格总容量。
