# 第476轮　优化截断后的二阶余量与变号门槛

- A 覆盖全部等权深度轮廓，中央误差有界。
- 在第474轮积分递推中优化次阶截断位移，中央高斯包络的一步对数余量为显式的分位数二次式除以维数。在中位点附近的固定开区间内余量为负。
- 下一步须构造跨越变号点的修正包络，并控制递推边界的传播。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第475轮 $z,h,s$。置 $b=s(p-a)=\mu+v/h$，其中 $v$ 在紧集内。主项 $L(b)=\log((e^b+1)/b)$ 满足 $L'(\mu)=0$，$L''(\mu)=1/\mu$。若 $M_j(b)$ 为第475轮指数权重改用下限 $-b$ 后的归一化矩，移动积分端点给
\[
 M_j'(b)=\frac{e^b}{1+e^b}[(-b)^j-M_j(b)] .
\]
从而 $M_2'(\mu)=\mu-1$。一阶项 $zM_2(b)/(2h)$ 和主项共同给二阶系数增加 $v^2/(2\mu)+vz(\mu-1)/2$。第475轮的积分余项对这里的有界位移一致（积分下限在固定紧集，正尾相同）。选
\[
 v=-\mu(\mu-1)z/2
\]
使该二次费用最小。用 $M_4(\mu)=12\mu-4\mu^2+\mu^3$（指数变量减伯努利位移的四次展开），结合上轮 $M_2,M_3$ 与 $h^2=\mu k$，递推作用于中央包络后，扣除 $B_{k+1}(p)$ 的对数余量为
\[
 \frac1k\left[-\frac{3-\mu}{6}+\frac{9-\mu}{24}z^2\right]+O_I(k^{-3/2}).
\]
这里计算的是代入包络和所选截断的费用，真实 halo 只有相应上界。此系数在 $|z|<2\sqrt{(3-\mu)/(9-\mu)}$ 为负，在两端临界点为零。故在闭区间 $|z|\le 2\sqrt{(3-\mu)/(9-\mu)}$ 上，单步正误差至多为 $O(k^{-3/2})$，前提是稍大中央区间已有输入包络；不能只在该闭区间内启动归纳。阈外正的二次项表明只优化这一阶位移无法获得所有固定中央门槛的一致可求和费用。

本机 Python 分别由原始矩公式和化简后的二次式核对若干分位数的系数，变号分位数绝对值约为 0.944。
