# 第146轮　小质量长纤维对自适应分割的障碍

2026-11-12。对固定 n≥2、严格门槛 p∈(0,1)，可取任意接近 H_n(p) 的有限盒源，使第145轮的全纤维条件在每个坐标选向、每个非平凡坐标分块上都迫使局部外包费用超过预定预算。扰动源的质量可以任意小。另一方面，给出可支付这种扰动的充分阈值。一般系数差仍为 (μ−1)/8。

**构造与物理价格。** 取有限有理盒源 A，真实体积比至少 (1−α)H_n(p)，其中含正体积子盒 C，|C|=θ|A|。沿所有坐标对角平移 L 份 A，使各轴投影均分离，间隙大于 4/p 倍最大单份投影宽。记并集为 E₀。任何成功矩形不能遇到两份：若沿一轴遇到 j≥2 个投影段，该轴占用率至多 jw/[(j−1)间隙]<p。各单份接收域亦分开，因此完整严格 halo 比精确保持，|E₀|=L|A|。统一平移和坐标缩放，使所有副本落在 [0,H]^n；缩放不改变各体积比。

每轴加一根轴向投影恰为 [0,H] 的实心细长盒，其余坐标放在远处。可取横截面充分小且有理，使总新源量≤τ|E₀|，并与原源分离。新源记作 E。由单调性与 H_n(p) 的定义，
(1−α)H_n(p)/(1+τ)≤V_E(p)/|E|≤H_n(p)，
0≤V_E(p)−V_{E₀}(p)≤(α+τ)H_n(p)|E₀|。
故即使某些跨针见证成功，其完整接收体积也已包含于结算。α 可先任意小，τ 可在选定 L 后任意小。

**所有选向的格成本。** 任取时间轴及 b≥1。任何满足第145轮第一条件的分割，在 [0,H] 内部有正长交叠的每一格都须宽至少 H/b：长盒的正测度纤维沿该格存在，长度至少 H。故与 [0,H] 相交的格数至多 B=⌊b⌋+2（两端的格可越界），不需用相邻格缓变条件。时间分割界面至多切开 B−1 个不同副本子盒，因为这些子盒时间投影两两分离。记第 j 格完整包含 N_j 个副本子盒（此处只要求时间投影包含），ΣN_j≥L−B。在任何坐标分块上，这些等尺寸子盒的两组投影都各自两两分离。按第141轮抽取代表点的对角价格，每格的 r 乘积外包体积至少 |C|N_j²/r。这也适用于 N_j<r。用 Cauchy–Schwarz，所有格的外包体积之和除以 |E| 至少为
θ (L−B)²/[r B L(1+τ)]，其中 L>B。
给定 n,b,r 和预算 T，先选 L 足够大即可超过 T；用相同原理，若许多格被列为复杂格，需另算其所含核心源质量。此障碍同时作用于同一源的所有选向。它针对的是按最长实际纤维强制决定格宽的方案。

**允许忽略污染的充分费用。** 对任意分解 E=E_good∪P（可交叠），任取 δ∈(0,p)，按同一见证的 P 密度是否大于 δ 分开，有
V_E(p)≤V_good(p−δ)+|P| H_n(δ)。
若 E_good 在稍大的中央紧区间已具任意固定 D 的对数余量，取 δ=log n/√n，第一个门槛移动的秩损失为 O_I(log n)。由第91轮式 (6) 在移动尾部的版本，以及高斯上尾 Chernoff 界，U(δ−2n^(−4))≤√log n（充分大 n）。故任何固定 a>σ，如果 |P|/|E|≤exp(−a√(n log n))，则第二项也一致低于 exp(B_n(p)−D log n)|E|。两项求和先增加一个对数余量即可。这允许删去极小异常质量之后再决定格宽；尚无对任意源找到此种好部的定理。上面的坏格下界并未否定剪除异常集后的方案。
