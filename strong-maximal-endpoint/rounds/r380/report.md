# 第380轮　实际命中份额的熵与跨格接收体积

- A 已覆盖全部等权深度轮廓。任意有限不交矩形源的低命中熵见证分支得到与源格数无关的全空间界。
- 在达到中央规模的目录中，除指数小的接收体积外，每个可选见证的命中分布都须有线性维数的熵。
- 未证部分是对许多源矩形分散命中时的合计费用。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。给定任意有限不交轴平行矩形分解 $E=\bigsqcup_j Q_j$，略去边界。对每个严格成功矩形 $R$，令 $u_j=|R\cap Q_j|/|R\cap E|$，$S_R=-\sum u_j\log u_j$。由于 $\max u_j\ge e^{-S_R}$，当 $S_R\le s$ 时，同一见证对某单一 $Q_j$ 的平均严格超过 $pe^{-s}$。因此该分支的接收并集 $V_s$ 包含于诸单盒严格 halo 的并。按第376轮（或第377轮区间因子分解），令 $L=s+\log(1/p)$，有
\[
 |V_s|/|E|\le e^L\sum_{k=0}^n {n\choose k}(2L)^k/k!
 \le \exp(L+2\sqrt{2nL}).
\]
不同源盒可有完全不同的边长和尺度，因各单盒仿射归一化后的费用相同，求和时恰以原体积分摊。实际还可将 $S_R$ 直接换为 $-\log\max u_j$，得到更大的可剥离分支。若每盒仅碰到 $K$ 个正体积源块，可取 $s=\log K$；于是 $\log K=o(n)$ 时整个分支为次指数，而用整格邻域计数可能给出指数界。

具体取 $s=n/8$。线性指数为 $1/8+2\sqrt{2/8}=1.125<\mu$，固定中央区间仅另有 $O_I(1)$。所以在该分支以外的接收点，其每个成功见证对任一原块的命中份额都小于 $e^{-n/8}$（这里剥离的是上述最大份额分支）。此结论针对给定分解；任意细分会人为降低最大份额。可在若干预定分解中剥离各自的低复杂度点，若分解个数为 $e^{o(n)}$ 仍保留严格线性余量。下一步需构造能反映实际几何的较粗不交分解，或证明所有低费用分解都无法聚集命中份额。
