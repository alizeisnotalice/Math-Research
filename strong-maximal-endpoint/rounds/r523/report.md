# 第523轮　无尺度限制时切片抽样没有一致逼近率

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对每个检验阶数 $m$，可使所有 $m$ 切片检验同时为零，而真实共同区间损失恒为 $1/8$。
- 下一步须引入与中央目录相关的有效区间数或尺度约束，才能由有限切片估计共同选择损失。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取 $2m$ 个等长纵条带作为类型，以全部 $m$ 元类型子集 $S_j$ 枚举横端点 $X_j=4^j$，$j=1,\ldots,\binom{2m}m$。在类型 $i$ 的端点 $X_j$ 指定累计源长 $A_{ij}=X_j/2$ 若 $i\in S_j$，否则 $A_{ij}=X_j/4$。取 $X_0=A_{i0}=0$。在每个横单元 $(X_{j-1},X_j]$ 的最右端填入长度 $A_{ij}-A_{i,j-1}$。这确为指标源：除首段外，该差在 $X_{j-1}/2$ 与 $7X_{j-1}/4$ 之间，小于单元长 $3X_{j-1}$，首段亦可行。

固定 $x=0$、外区间为全部条带。每个类型在单元内的累计源长为凸函数，端点值均不超过 $X_j/2$，所以其前缀平均至多 $1/2$，且在包含该类型的子集端点达到。任取 $m$ 条切片，即使有重复，均可选一个包含全部所取类型的 $S_j$；同一横区间 $[0,X_j]$ 对全部切片都最优。因此任意具有正确边际的 $m$ 切片耦合都检出零损失。

所有类型的合成累计源长在每个正端点恰为 $3X_j/8$，单元内同样凸，故整体平均最优值为 $3/8$。延伸至负轴或越过末端只会稀释前缀平均。真实损失恰为 $1/2-3/8=1/8$，与 $m$ 无关。可统一缩放横坐标到单位区间；所需最大与最小正端点之比仍为 $4^{\binom{2m}m-1}$。这证明仅让测试阶数随维数增加不能提供对全部有限目录一致趋零的误差。结论只针对指定外区间的局部损失，不是一般端点反例。

本机 Python 以整数与有理数对 $m=1,\ldots,5$ 穷举全部指定子集端点，核对填充容量及合成最优值。
