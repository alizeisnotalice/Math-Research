# 第489轮　双标签有限扰动的增长界与门槛检验

- A 覆盖全部等权深度轮廓，中央误差有界。
- 双标签扰动的预算可沿整个可行参数区间积分；高标签密度行的接收并给出同一有限扰动的 halo 下界。
- 下一步须估计中央带中标签份额占见证体积的分布，并比较下界与初始最小源量。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第488轮，$b=|B|>0$，$C_0=C(0)$，$0\le e<1-p$。各行需求仍严格小于行体积，第487轮互补性与第488轮方向导数在每一点均适用。于是 $C'_+(e)\le b+\min(b,C(e))$。分段线性性允许积分，得
\[
 C(e)\le\min\{C_0+2be,\ (C_0+b)\exp(e)-b\}.
\]
这无需知道对偶何时换顶点。小 $e$ 且 $C_0/b$ 很小时，第二式给增量至多 $be[1+O(C_0/b+e)]$。

对 $0<t\le1$ 定义 $U_t$ 为所有 $d_i\ge t|R_i|$ 行的矩形并。任取 $0<q<p+et$，有
\[
 |U_t|/H_n(q)\le C(e).
\]
因为一个最优分数源可逐原子切成指标源，每条入选行的平均均严格大于 $q$。取 $\tau\in(0,p+et)$、$q=p+et-\tau$ 即把严格门槛移动明示出来。两式合并给出可检验的几何约束 $|U_t|\le H_n(q)[(C_0+b)e^e-b]$，同时可取线性上界。有限差商的下界是 $(|U_t|/H_n(q)-C_0)/e$；凸性只保证它不超过末端左导数的相应上界，不能据此直接下推初始右导数。

**两种尺度。** 写 $A=b/C_0$。若 $A$ 指数大，在扰动 $e=\lambda/A$（固定 $\lambda>0$）上，增长预算仍为 $(1+\lambda+O_\lambda(1/A))C_0$，但每行门槛移动至多 $\lambda/A$。若目标是移动 $\asymp n^{-1/2}$ 的中央门槛，即使 $t=1$，所需 $e$ 也至少为该量级；此时上述预算允许远大于 $C_0$ 的增量。这是当前预算与门槛检验联用的尺度缺口，不证明实际增量很大。对含公共单位段的两个长度二区间，$p=1/2$ 时 $C(e)=1+2e$，确实达到线性上界；本机 Python 对有理参数核对。
