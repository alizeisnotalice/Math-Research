# 第725轮　精确非线性几何相位不等式

2026-11-14。一般 $C_n$ 的 $\log n$ 系数仍未确定。本轮得到每一维都精确成立、对相位振幅和频率不设小参数限制的几何相位不等式：
$$\left\langle\exp\left\{\sum_iM(c_i(\theta))+E\log F(\theta+\xi\cdot Z_{c(\theta)})\right\}\right\rangle
\le e^{\mu n}\langle F\rangle.$$
其中 $F$ 为正连续周期函数，动作场可为任意逐点有限实值Borel场，且可按极限定义允许正无穷。常数函数及全部动作等于μ时取等。[证明与适用范围](geometric_phase.md)。

证明先从Grafakos–Montgomery-Smith已发表的锐强矩形 $L^p$ 范数推出几何极大函数的 $L^1$ 界，再构造实际正函数、真实跨原点矩形，依次取截断尺度和内部边距极限。锐强型结果见[作者原始PDF](https://stephenmontgomerysmith.github.io/preprints/uncentered.pdf)，主定理在打印第1页，强矩形推论在打印第4页。相位推导属于本项目论证，不归属于原论文。已更正来源索引中此前错写的推论页码。

正函数在原点附近保持正值；矩形内对数平均没有零区域导致的负无穷问题。相位分布以全变差趋于Haar，允许Borel动作场。非有界场经有界截断和支配收敛延拓。截断损失恒等式由本机Mathematica实际符号积分核验，原脚本和输出随附；计算进程已退出，未启动MATLAB。主证明及延拓均经独立Astra审查。

**尚缺接口：** 几何平均控制不能直接替代真实指标源的中位数。要据此确定一般端点系数，仍需中位数与该均值的一致误差控制或其它一般几何论证。一般上下界区间保持 $[(9-\mu)/24,(3+\mu)/12]$。
