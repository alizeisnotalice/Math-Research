# 第689轮　平台宽度的局部精确修正

2026-11-13。沿第19轮的真实平台见证，固定比例 c=μ 或取该轮有界临界窗口内的比例。令 L=log n，w₀=L/2+log L，w=w₀+b，q(w) 为严格平均的边界根，S(w)=q(w)−log K_n(w) 为对数评分。对任意固定紧区间上的 b，一致有
$$ L[S(w₀+b)-S(w₀)]\longrightarrow -b+κ(1-e^{-b}),\qquad κ=\sqrt{π/2}. $$
这直接比较同一 n 的物理见证，无需将软根本身展开到 o(1/L)。

证明。第19轮式(3)对 w 求偏导得 −A_c(q+w)/n，故 q'(w)=−A_c(q+w)/(A_c(q+w)+nf(q))∈[−1,0]。由第19轮式(4)，w₀ 处的根距软根有界；Lipschitz 性把这一性质传给紧区间内的 b。第19轮式(6)—(7)遂给 nf(q)/L→1 与 A_c(q+w)→1，一致成立。因此 Lq'(w)→−1。又 K_n(w)=1+(I_n−1)exp(−w)，I_n/√n→κ，故 −L(log K_n)'→κexp(−b)。两式相加并从零积分即证。各评分均可从根下方取严格成功输入逼近。

极限函数严格凹，在 b*=log κ 唯一最大。于是对包含 b* 的任意固定紧区间，最优宽度为 w₀+log κ+o(1)，相对原宽度的对数评分提升 (κ−1−log κ)/L+o(1/L)。这里的最优性仅指有界偏移内；乘上 L 后的提升为正，仍不改变已有 (9−μ)/24 的测试族对数系数。下一步需研究软段斜率的扰动，并区分宽度局部修正和能改变 log n 系数的形状方向。
