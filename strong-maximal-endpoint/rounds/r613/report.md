# 第613轮　投影纤维等大的耦合外片目录全门槛公式

- A 已覆盖全部等权深度轮廓，中央误差有界。
- 不要求块间独立。若每个坐标投影的非空标签纤维等大，全部门槛的最小源质量由投影基数的一次排序精确给出。只假设纤维重数有界时仍有双边估计。
- 一般目录缺少统一的行内重数信息；一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取第612轮的 $b$ 个外片块，只保留标签族 $F\subseteq[k]^b$ 的积行，$F$ 非空。对每个块子集 $J$ 记 $N_J=|\pi_J F|$。恰在 $J$ 中进入私有外片的单位胞元由投影标签编号，故并体积 $|X|=\sum_J N_J$；每条行在每个 $J$ 恰含一个单位胞元，行体积为 $2^b$。以下 $m(t)$ 是容量域 $X$ 内实现全部非严格行需求的最小质量，也是严格问题对 $0<t<1$ 的下确界。

**统一纤维时的精确解。** 假设每个 $J$ 的所有投影标签各有 $|F|/N_J$ 个原像。阿贝尔群上子群的陪集满足此条件，因为投影同态的各非空纤维都是同一核的陪集。任意可行源在第 $J$ 层的质量为 $s_J$，则对全部行取均值，得 $\sum_J s_J/N_J\ge t2^b$，且 $0\le s_J\le N_J$。反向，在第 $J$ 层每个胞元取同一比例 $s_J/N_J$，就能让每条行恰好收到平均值。于是将 $2^b$ 个数 $N_J$ 递增排序为 $N_{(i)}$，设 $z=2^b t$、$a=\lfloor z\rfloor$，则
\[
 m(t)=\sum_{i=1}^a N_{(i)}+(z-a)N_{(a+1)}.
\]
当 $z$ 为整数时只取前项。等价的对偶是各行共同赋权 $N_{(\lceil z\rceil)}/|F|$。该权令已填层的叠加密度至少一、未填层至多一，在可部分填充的临界层等于一。独立菜单只对应 $N_J=k^{|J|}$ 的特殊情况。

**任意耦合的可算界。** 记 $M_J$ 为第 $J$ 层最大纤维大小，令 $L_J=|F|/M_J$。对任意源，行平均需求迫使 $\sum_J s_J/L_J\ge z$，而每层在平均命中上的贡献也至多一。准确地，若其平均贡献为 $u_J$，则 $0\le u_J\le1$、$s_J\ge L_J u_J$。故在排序公式中分别代入 $L_J$ 和 $N_J$ 得到下界与上界；后者由各层均匀填充直接可行。特别若各层最大纤维不超过其非空纤维均值的 $D$ 倍，则两个估计相差至多 $D$ 倍。

**全局尺度限制。** 对任意 $F$，单行已迫使 $m(t)\ge t2^b$，而 $|X|\le(k+1)^b$。故每维增益率至多 $k^{-1}\log[(k+1)/2]+O_I(1/(bk))<\mu$（固定 $k\ge2$ 且 $b$ 充分大）。这一简单估计已经排除该几何族达到中央基线；排序公式的新增信息是同一目录的准确门槛曲线和对偶。下一步应在一般真实目录里按子族投影的纤维差异估计平均需求松弛与逐行需求之间的损失。
