# 第731轮　一般目录的几何容量与全标签费用

2026-11-14。一般 $C_n$ 的 $\log n$ 精确系数仍未知。本轮回到任意有限真实矩形目录，给出一般可计算接口，而非继续扩张指定相位族。

对负责权 $\pi$、完整并上的均匀概率 $Q$，定义
$$\Lambda(\pi)=\log\sup_{Qf=1}\sum_i\pi_i\exp\left(\fint_{R_i}\log f\right).$$
严格有
$$\Lambda(\pi)=\max_{\nu\ll\pi}\{D(P_\nu\Vert Q)-D(\nu\Vert\pi)\}\le\mu n.$$
最大化目标对标签权 $\nu$ 凹，即使 $\nu$ 本身不负责也成立；不负责的重加权通过精确标签KL费用计入。对任一正权候选，目标值 $F_\pi(\nu)$ 和梯度 $g_i$ 给
$$F_\pi(\nu)\le\Lambda(\pi)\le\max_i g_i.$$
这为一般实际目录提供有限双侧证书入口。[完整变分、凹性与责任方向证明](general_interface.md)。

在负责最不利面上记 $\Lambda_{\rm LF}=\max_\pi\Lambda(\pi)$，$V=\log(|X|/s)$、$\rho=s/m$。一般指标得分满足
$$\log G\le\mu n+[V-\Lambda_{\rm LF}]+\log\rho.$$
因此若能在第718轮稳定近中央目录上证明 $V-\Lambda_{\rm LF}+\log\rho=o(\log n)$ 的上侧比较，就能接续第709轮归约。该比较尚未证明；固定 $\pi$ 的内层证书也不自动认证整个LF面的外层最大化。

本轮另严格计算共核积星：对全部负责最不利权和全部标签重加权，仍有
$$V-\Lambda_{\rm LF}=(\log2+o(1))\log n.$$
证明用所有联合标签投影的真实Hall容量及KL数据处理，覆盖整个重加权空间。因此不能无条件宣称检验价与几何容量只差 $o(\log n)$。这个例子真实得分 $\log G=o(n)$，没有否定稳定近中央比较，也没有决定一般系数。
