# 第517轮　按接收面积筛选可消除二维二进插入的附加损失

- A 覆盖全部等权深度轮廓，中央误差有界。
- 第516轮整个目录上的任意小缩放，在允许舍弃固定接收份额后消失。所有平面二进菜单都可保留至少四分之一并面积，同时为任一可行包围对偶分配一半权重。
- 下一步须处理附加坐标与基底源相互依赖时的真实命中分配，以及固定接收损失反复出现时的累计费用。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。给定有限平面矩形菜单，只要求横投影来自同一二进网格，纵区间可任意。按横宽递减扫描，若一个矩形至少有比例 $1-\lambda$ 的面积尚未被此前选中矩形覆盖，则选入，其中 $0<\lambda<1$。各入选盒的新面积互不相交。记原并为 $G$，入选并为 $G'$。对每个被拒盒 $I\times J$，与它相交的较早入选盒其横投影都包含 $I$（忽略零测边界）。所以对几乎每个 $x\in I$，在 $J$ 上此前入选并的垂直切片密度均超过 $\lambda$：该密度在 $I$ 内恒定，等于二维重叠比例。故 $G$ 包含于 $G'$ 的单轴门槛 $\lambda$ 的 halo（模零）。第467轮的区间二重覆盖界沿纵轴给 $|G|\le2|G'|/\lambda$。同时每个入选盒的任意包围对偶需求不超过该盒面积，新面积块便能不交支付需求的 $1-\lambda$ 倍。该分配完全位于原附加源 $G$。

对第516轮的乘积目录，可保留全部基底标签，只筛选附加标签。于是接收体积至少保留 $\lambda/2$，原源及原门槛照用；把基底最优对偶与入选附加菜单最优对偶取积，由第512轮张量律它仍是最优，且至少可分配基底最佳缩放的 $1-\lambda$ 倍。取 $\lambda=1/2$ 即分别得到 $1/4$ 与 $1/2$。因此第516轮反例只排除了强制保留全部附加标签的策略，无法排除先保留固定接收份额的策略。本步仅在二维附加因子筛一次，所付对数接收代价至多 $\log4$，未推广到一般高维真实源。

本机 Python 用整数网格检查多组平面菜单的筛选面积与每个入选盒的私有新增面积。
