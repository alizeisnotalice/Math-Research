# 第580轮　公共交盒几何余量可支付指数级局部复用

- A 已覆盖全部等权深度轮廓，中央误差有界。
- 对混合分组，可分别按每组真实的几何上界计入复用费用。具有足够大公共交盒的组允许指数多次共享同一部分源，而不必放宽其他组的预算。
- 待证的是对中央近最优目录构造这样的混合覆盖，并统一控制没有公共交盒余量的组。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。设组 $c$ 的矩形并为 $X_c$，最大行体积为 $V_c$，正体积交盒为 $K_c$。采用第571轮的 $F$，置 $G_c=\exp[nF(n^{-1}\log(V_c/|K_c|))]$，则 $|X_c|\le V_cG_c$。若组内各行对分配的指标子源 $E_c$ 在门槛 $q$ 严格成功，最大行给 $q V_c<|E_c|$。因此这一几何界对任何可行分配均给出局部系数 $L_c=G_c/q$。对于其他组，只要有对同一门槛、对分配后源一致的局部定理，也可使用其局部系数 $L_c$。

**按组系数的精确分配费用。** 固定 $q<p$，在每行 $R$ 上要求分配后平均至少 $b=(p+q)/2$，于是严格超过 $q$。令 $w_c=L_c e^{-B_n(p)}$。所有满足行需求的子源（允许重叠）中，
\[
 T=\min\sum_c w_c|E_c|
 =\sup_{\lambda_R\ge0}\left[b\sum_R\lambda_R-
 \int_E\sum_c\left(\sum_{R\in c}\lambda_R1_R(y)/|R|-w_c\right)_+dy\right].
\]
按行命中原子设分配变量在 $[0,1]$ 内，对各行约束加乘子后逐原子取最小即得有限 LP 对偶。全部分配原源可行。任一最优分配给 $|X|\le e^{B_n(p)}T$。与第579轮相比，这里把组内节省直接写入源点价格，无需先估计无权总复用质量。$T$ 是该分配证明的最优费用，未断言等于实际接收体积。

**显式混合判据。** 先不分割，取 $E_c=E\cap X_c$。若第一类组的 $n^{-1}\log G_c\le\mu-2\eta$，其中 $\eta>0$ 固定，则对固定中央门槛和 $q=p-n^{-1/2}$，充分大维时均有 $w_c\le e^{-\eta n}$。只要源上这类组的平均重数至多 $e^{\eta n}$，其总贡献至多 $|E|e^{B_n(p)}$。第二类组若已有 $L_c\le e^{B_n(p)+o_I(\log n)}$（余项统一）且平均重数 $n^{o(1)}$，其贡献为 $|E|e^{B_n(p)+o_I(\log n)}$。两项相加后仍是目标精度。这允许第一类的巨大复用与第二类并存，无权总复用量并不必为次多项式。若第二类只能调用已有粗界，则其组并所占源质量之和还须有相应的多项式节省。下一步需从见证几何给出覆盖判据，而非预设两类的预算。
