# 第648轮　分割树的全局重叠比与阈值剪枝

- A 的全部等权深度轮廓中央误差有界。
- 给定一棵候选分割树，无须逐路径估计最小源质量即可精确检验：能否在允许的几何终止节点处剪枝，并保住指定的全局接收增益因子。
- 一般系数差仍为 $(\mu-1)/8$。尚无适用于任意目录的候选树及终止节点几何界。

2026-11-13。固定严格成功源，沿用第647轮的质量 $m_v$、接收体积 $x_v$。对任一剪枝前沿 $F$（每条根到原叶的路径恰遇一个选定节点），对其上方真正切开的内节点 $v$ 写 $a_v,b_v$ 为接收与源的相对重复份额。逐层望远镜给
\[
 \sum_F m_v=m_0+\sum_{v\ {
m cut}}m_v b_v,\qquad
 \sum_F x_v=x_0+\sum_{v\ {
m cut}}x_v a_v .
\]
若全部前沿增益至多 $U$，则根增益至多 $U\rho_F$，其中
\[
 \rho_F=\frac{\sum_F m_v/m_0}{\sum_F x_v/x_0}.
\]
这恰是叶并重数在归一化源测度和归一化接收测度下的期望之比。只要两端重数同阶，叶子可任意小而不增加对数损失。比值可以小于一。

**可检验的净费用条件。** 对给定 $L>0$，记 $g_0=x_0/m_0$，置 $c_v=m_v b_v-Lx_v a_v/g_0$。则 $\rho_F\le L$ 等价于 $\sum_{v\ {
m cut}}c_v\le (L-1)m_0$。设某些节点有独立证明的局部上界 $U$，只允许它们作终点。在树底向上算 $D_v$：可停止时费用候选为零，可切分时费用候选为 $c_v+D_{v_1}+D_{v_2}$，取所有合法候选的最小值；无候选时置正无穷。归纳即知根值为所有合规剪枝的最小净费用。用 $D_0\le(L-1)m_0$ 可认证根上界 $LU$。根增益虽出现在计算中，但对具体目录它是实际测度比，不能仅凭递推对所有目录断言中央目标。

**两种尺度的检验。** 把单位区间分成任意多个不交子区间，全部源密度相同（可在各段内等比例取指标）。所有切分的 $c_v=0$，前沿比值为一，即使最小叶质量趋零。反之，第606轮公共核心及 $n$ 个独占外片目录在 $p<1/2$ 用核心作严格源，终点若限单行，则 $\sum_Fm_v=n$、$\sum_F x_v=2n$、$m_0=1,x_0=n+1$，因而 $\rho_F=(n+1)/2$。各叶增益二，此处全局合并界恰取等，证明即使可自由选二叉切分顺序，也不能保证在单行终止时只损失 $o(\log n)$。本例根增益仍仅线性。下一步须选取能整体处理公共核心的终止族，再验证其余切口的净费用。
