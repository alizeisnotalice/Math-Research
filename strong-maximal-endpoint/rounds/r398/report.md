# 第398轮　其他组的覆盖可以改变唯一最优配对

- A 已覆盖全部等权深度轮廓。独立组内每次恰选两个盒时，固定其他组后的最优更新仍是线性匹配，但需按未覆盖概率计价。
- 五个整数端点矩形已足以使裸交体积与真实费用选出不同的唯一最优方案。
- 中央目录仍需统一控制各组同时更新后的总覆盖收益。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定其余各组的联合抽样，并令待更新组与它们独立。设 $h(x)$ 为其余所有组都未覆盖 $x$ 的概率。在当前组指定边际且每次恰选一对时，期望证书的可变部分恰为 $-\sum_{i<j}x_{ij}\int_{R_i\cap R_j}h$：因为两盒并的指示等于两行指示之和减交指示，单行期望与线性行费用固定。此公式不要求其他组内部独立。故第397轮的对偶只需替换边费用。组间独立时整体目标对每一组分别线性，有限匹配多面体的顶点组合中至少有一组全局最优解（从最优解逐组移至同价值顶点）；这不保证逐组改进一定达到全局最优。

取四行边际各为一半，另一个组确定选择第五盒。矩形按左、右、下、上端点顺序为 [(1, 4, 4, 6), (4, 6, 2, 3), (2, 6, 2, 5), (4, 5, 2, 6), (3, 6, 3, 6)]。可取源为五盒并，所有行严格成功于任意 $p<1$。四行半边际的任意恰选两行方案都为三个完美匹配的混合：各顶点的度等式相减给出对边概率相等，每种匹配内两对等概率。按 $12|34,13|24,14|23$ 排列，裸交费用的两倍为 [3, 3, 2]，扣除第五盒后两倍费用为 [1, 2, 2]。两列的唯一最小项不同。该证书仅针对指定边际；这里没有断言边际本身最优或目录达到中央规模。下一步需估计遮蔽在实际最优分数权上的大小，尤其是一些组的全部交区已被高概率覆盖时的剩余收益。
