# 第503轮　共同矩形核与有界外部重数的精确体积界

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对含同一矩形源的见证族，外部重数至多 $d$ 时，非平凡行数至多 $2nd$；外片独占时中央门槛下接收体积比的上确界精确为 $1+2n(1/p-1)$。
- 下一步须从共同矩形核转向可变核，或把逐点重数上界改为未填命中律下的重数尾界。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。设 $Q$ 为正体积轴平行矩形，有限目录每个 $R_i$ 均包含 $Q$，源为 $1_Q$。忽略与 $Q$ 相等的行。若 $Q$ 外几乎处处最多有 $d$ 个见证覆盖，则每个有向面至多被 $d$ 行向外延伸。事实上取所有越过同一面的行的最小正伸长，该面外厚度等于此最小值、其余坐标限制在 $Q$ 内的开柱体有正体积，且被这些行全部覆盖。每个非平凡行至少延伸一个面，故行数至多 $2nd$，独占情形的行数上界可由每面各放一行达到。成功条件给 $|R_i|<|Q|/p$，从而
\[
 |\cup R_i|/|Q|\le 1+2nd(1/p-1).
\]
当 $d=1$，使每一行只延伸一个不同有向面，取 $|R_i|=(1/p-\varepsilon)|Q|$（$0<\varepsilon<1/p-1$），所有外片两两不交且行严格成功，令 $\varepsilon\downarrow0$ 即得所述上确界。允许包含多个面的行亦不能超过它。$d>1$ 不主张该体积上界锐利。

因此在这类共同核目录中，若 $p$ 位于固定中央区间，而接收源比至少为 $V/|Q|$，外部最大重数必至少为 $(V/|Q|-1)/(2n(1/p-1))$。特别是严格独占外片机制不能在保持此结构时扩展到中央指数增益。该论证依赖所有见证包含整块 $Q$；另一方面，检出最大重数的柱体可以任意薄，故它并不提供第501轮所需的容量积分下界。

本机 Python 以有理数对各正负面构造核算严格门槛与并体积。
