# 有限矩形目录的全覆盖最小源密度

日期为2026-11-11。

## 范围

本轮对14个有限均匀环面网格，完整枚举每个私有格子集对应的12个 mask chunk。结果给出有限矩形目录中的精确常数 $\eta^*$，以及由私有格推出的源密度下界。本轮没有证明连续矩形目录、任意长方体、所有维数或一般强极大算子的上界。

归档内容包括搜索程序及其C++枚举核心、14份最小机器证据、精确检查程序和本报告。原始大日志未复制。程序使用 `--shapes` 可以重跑列出的形状；验证器检查每个chunk的范围、最大值见证、最优私有格的矩形体积和并集。

## 有限目录定理

固定网格中有 $n$ 个等体积格，归一化整个环面的体积为1。记 $\mathcal R$ 为由这些格组成的有限周期矩形目录。对任意非空私有格集合 $P$，定义

\[
 T(P)=\sum_{i\in P}\max\{ n|R|: R\in\mathcal R,\ R\cap P=\{i\}\},
 \qquad
 \eta^*=\max_{\varnothing\ne P\subseteq[n]}\frac{T(P)}{n}.
\]

这里 $T(P)$ 的单位是格数；$|R|$ 是归一化环面体积，每格体积为 $1/n$。每个格至少有其单格矩形，因此 $T(P)$ 定义良好。

设 $f$ 是环面上的任意指标函数，且一组目录矩形的 $f$ 平均值均至少为 $p$，并覆盖接收格的并集 $C$，其中 $|C|\ge\theta$。从中取一个覆盖相同接收格的包含极小子族。子族中每个矩形都有一个私有接收格；不同矩形的私有格不同。把这些格组成 $P$。每个子族矩形 $R_i$ 满足 $R_i\cap P=\{i\}$，所以

\[
 \sum_i |R_i|\le \frac{T(P)}{n}\le\eta^*.
\]

每个盒子上的缺损 $\int_{R_i}(1-f)$ 至多为 $(1-p)|R_i|$。对并集的缺损求和时重复计数只会增加右侧，因此

\[
 \int f\ge\int_C f
 \ge |C|-(1-p)\sum_i|R_i|
 \ge \theta-(1-p)\eta^*.
\]

所以当 $\theta>(1-p)\eta^*$ 时，目录内所有这样的覆盖都要求正的源密度。这是有限网格目录结论。若盒子平均值严格大于 $p$，相应单盒缺损不等式也严格；报告保留较安全的非严格下界。

## 全覆盖线性段的精确价格

对一般正体积格，以 $v_{\min}$ 表示最小格体积，并以 $T$ 表示私有盒最大**归一化体积和**。在 $0<\eta=1-p\le v_{\min}$、要求覆盖全格时，下确界恰为 $1-\eta T$。覆盖要求严格大于 $1-v_{\min}$ 时同样成立。

取达到 $T$ 的私有格集合，并对每个私有格选一个最大盒。若有漏格，将该格及其单格盒加入，原先的每个最大盒仍然可用；归一化体积和严格增大，矛盾。因此这些盒覆盖全网格。先充满整个环面，再在第 $i$ 个私有格里挖去体积 $(\eta-\epsilon)|R_i|$ 的可测子集。该格体积足够，且其他选中盒都看不到这次删减。每个盒的平均恰为 $p+\epsilon$，全覆盖的源体积随 $\epsilon\downarrow0$ 趋于 $1-\eta T$。前述极小子覆盖不等式给反方向。这里格间决定矩形，格内允许任意可测二值源。

例如五维二格目录在 $31/32\le p<1$ 时的全覆盖下确界是 $1-(1-p)45/16$。表中的 $\eta^*$ 为斜率 $T$，与亏损参数 $\eta$ 区分。

全14案中最大的 $\eta^*$ 为 $13/4$，由 4×8 网格达到。因此，对这14个目录统一有

\[
 |E|\ge \theta-\frac{13}{4}(1-p).

五维二格网格有 $T(P^*)=90$、$n=32$，故 $\eta^*=45/16$。在该单一目录全覆盖时，正下界条件是 $p>29/45$；取 $p=4/5$ 得 $|E|\in[7/16,1]$。

## chunk 和盒证书复核

每案使用12个半开整数区间 $[\lfloor 2^n j/12\rfloor,\lfloor2^n(j+1)/12\rfloor)$。验证器确认所有区间依次相接且并为完整 mask 范围 $[0,2^n)$，报告的每个chunk最大值都由该chunk内的 mask 达到，并逐个重算 $T(P)$ 与所报最大值相等。全局最大 mask 的最大盒逐个满足 $R\cap P^*=\{i\}$，各私有格恰好出现一次；这些盒的格数之和等于 $T(P^*)$，其并集在每案均为整个环面。



这项复核检查了已运行穷举记录的分块覆盖和最大值见证，没有再次执行所有 $2^n$ 个 mask。要从原始搜索复算，可运行：

```sh
python code/search101.py rounds/r101/data --shapes \
  2x2 2x3 3x3 2x2x2 3x4 4x4 2x3x3 2x2x2x2 \
  2x3x4 2x2x2x3 3x3x3 2x2x2x2x2 4x8 2x4x4
python code/verify101.py
```

原搜索已分两批完成：首批11案约6.17秒，扩展3个32格形状约402.10秒。Guard记录均为 `exit_code=0`、`stop_reason=null`、1 GiB可用内存余量、6.5 GiB RSS预算；观测峰值分别约41.69 MiB与41.88 MiB。可用内存是系统采样估计，不是操作系统硬预留。

## 结论边界和后续

有限枚举精确给出所列目录的 $\eta^*$。它不控制连续矩形、非网格端点、其他维数或一般强极大算子的上界。仍需处理这些目录之外的私有格代价，并证明从有限网格目录到连续盒族所需的统一逼近与误差预算。

下一步可沿两条线推进：

1. 扩展或结构化证明 $T(P)$ 的统一估计，避免对每个 $2^n$ 私有格子集逐一穷举。
2. 建立连续端点盒子与有限网格目录之间的传递，明确边界覆盖损失及其对源密度线性段的影响。

验收状态与全部输入/源码/文档 SHA-256 见 [`validation101.json`](validation101.json)。

一般端点的对数系数差仍为 $(\mu-1)/8$，已知下界距离为 $d_N-c_Q\log N+o(\log N)$。
