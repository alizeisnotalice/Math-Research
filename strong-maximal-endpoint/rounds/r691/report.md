# 第691轮　软段斜率的有限维扫描

本机 Python 12 进程，SciPy 1.18.1，24 个维数、34 个斜率参数，共 816 个评分差。计算固定 c=μ 的第690轮新平台相对第19轮旧平台的对数评分差。每维另解一个基准根。使用二项条件化的 Gamma 分布与指数倾斜，Brent 绝对根容差 1e−11，截去二项两侧各约 1e−14 概率后归一化；无随机抽样。截断概率不等同评分误差。最大浮点根残差 1.039e-12。全部输出有限。

在 a=√μ 时，n=8192 的差为 −0.00779377，n=10000 为 +0.00722424；这是两个样点的符号变化。n=1048576 时差为 0.23766941，同维网格最佳在 a=0.8125，差为 0.30494064，而渐近峰值 μ/2 约 0.63923227。有限维最优偏移明显，不能据此精确拟合一般端点的对数系数。

独立 Wolfram 全二项求和、不截尾，分别用 40 和 80 位精度，在 n=16,64 对 a=√μ 核对。两档前22位相符，分别为 −0.2151142935488241230034 和 −0.3739976634154550636517；Python 与两者相差均低于 7e−14。大维结果使用双精度，没有区间认证。

复现文件为 sweep.py、verify.wl、scores.csv。下一步：由有限维一阶条件优化斜率与宽度；对更大维度采用倾斜积分复核慢收敛。
