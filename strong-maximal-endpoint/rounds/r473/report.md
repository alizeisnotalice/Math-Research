# 第473轮　多水平积分消去单步半对数损失

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对一般指标源建立截断积分递推；代入低一维的中央包络时，第472轮的单步半对数费用降为有界量。
- 下一步须降低逐轴累计的常数，或一次消去多轴。此递推没有证明中央包络本身。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第472轮的 $F_q,C,T$。设 $0<a<p$，令 $g(x,y)=\max_{j:(x,y)\in R_j}u_j(x)$（空最大值取零），故 $F_q=\{g>q\}$。固定 $y\in B_j$，由于行平均约束，$(g-a)_+$ 在 $I_j$ 上积分至少为 $(p-a)|I_j|$。从这些区间中抽取覆盖同一并的极小子族，几乎处处重数至多二。逐行积分再沿 $y$ 积分，得
\[
 (p-a)|T|\le2\int(g-a)_+
 =2\int_a^1 |F_q|\,dq\le 2 C\int_a^1 H_{n-1}(q)\,dq .
\]
故 $H_n(p)\le\inf_{0<a<p}2\int_a^1 H_{n-1}(q)dq/(p-a)$。本步使用的是同一组嵌套水平集。第472轮以 $(1-a)H_{n-1}(a)$ 替代了整个积分。

**中央尺度。** 令 $k=n-1$，$B_k(q)=\mu k+\sigma\sqrt k\,\Phi^{-1}(1-q)$。假设在稍大的固定中央紧区间 $J$ 上有 $H_k(q)\le\exp(B_k(q)+r_k)$。对其内部紧区间中的 $p$，置 $s=-B'_k(p)$，$a=p-1/s$，于是 $s\asymp\sqrt k$。用此包络代入积分，得到
\[
 H_{k+1}(p)\le (2e+o(1))\exp(B_k(p)+r_k).
\]
具体地，变量 $v=s(q-p)$ 从 $-1$ 开始；固定有界 $v$ 时基线差一致趋于 $-v$。在 $J$ 内右侧由 $\exp(-c v)$ 控制正尾，因为负斜率与 $s$ 的比在紧区间有正下界。超过 $J$ 的部分由 halo 单调性及右端点的指数衰减控制。因此归一化包络积分为 $(e+o(1))/s$。更一般取 $a=p-b/s$ 时相应常数为 $2e^b/b$，最小值在 $b=1$。这是代入包络的费用，并未取得实际 halo 的等号。

与 $B_{k+1}(p)-B_k(p)=\mu+O_J(k^{-1/2})$ 比较，保留下来的单步对数余量为 $\log(2e)-\mu+o(1)>0$。这足以将已知低维误差传递一步而不添半对数，却不足以逐维归纳到第110轮的 $o(\log n)$ 目标。用本机 Python 核算了局部指数模型的积分。
