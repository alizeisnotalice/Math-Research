# 第491轮　按接收份额截断对手混合并计入已有余量

- A 覆盖全部等权深度轮廓，中央误差有界。
- 可将只阻碍极小接收份额的行从最坏混合中排除。所得精确极小极大值给出单个新增源对固定份额见证的门槛保证。
- 下一步须在中央几何中估计受接收份额支配的混合核，或构造仍满足支配条件的低增益混合。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。将接收并分成不交负责区，令 $w_i$ 为各行负责体积占比，略去零权行。记原行平均 $p+z_i$，$z_i\ge0$。沿用第490轮容量测度与重排记号，取 $0<\alpha\le1$，限制概率权 $\pi_i\le w_i/\alpha$。定义
\[
 V_\alpha(B)=\min_{\pi}\left[\sum_i\pi_i z_i+\int_0^{\min(B,\nu(U))}K_\pi^*(s)ds\right].
\]
这是可行补入中“最差 $\alpha$ 份额”的最大平均超额：固定补入时按各行最终超额升序取总权 $\alpha$，最后一行可在负责区内分割，以 $1/\alpha$ 归一化。此取法正是受限概率混合的最小线性目标。按第490轮交换极大极小后即得公式，且存在同一个补入实现此值。因最差部分的均值不超过其最大值，最终超额严格小于 $V_\alpha(B)$ 的行权之和至多 $\alpha$。所以只要 $V_\alpha(B)\ge\delta$，至少 $(1-\alpha)|U|$ 的接收体积可在同一体积至多 $C+B$ 的指标源上达到平均 $p+\delta$（代入严格 halo 时取略低门槛）。这是充分条件，并非保留给定份额的必要条件。

**得到可检验的相反情形。** 若预期的保留份额结论失败，则有一个满足上述支配的混合，使原超额与最高容量质量之和小于 $\delta$。因二者非负，该混合给 $z_i\ge L\delta$ 的行至多 $1/L$ 权重，故 $z_i<L\delta$ 的行至少承担 $\alpha(1-1/L)$ 的原接收份额，同时混合核在任何容量至多 $B$ 的区域上质量小于 $\delta$。这将门槛几乎紧与容量分散施加于同一个混合，避免单条饱和但无接收份额的见证破坏判据。

**有限例。** 两个不交单位区间，原平均分别为 $p,p+1/4$，负责份额各半，取 $p=1/2,B=1/8,\alpha=3/4$。全部预算给第一行后，最差四分之三份额平均超额为 $1/6$；混合 $(2/3,1/3)$ 的原超额为 $1/12$，最高容量质量为 $1/12$，给同值上界。本机 Python 用有理数核对。
