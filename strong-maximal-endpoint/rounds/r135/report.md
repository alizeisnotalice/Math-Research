# 第135轮　按总维数优化斜板构造

2026-11-12。中央严格门槛 p=1/2。令 n=m+k，J 先在 n−1 个横向坐标取真正的强极大，再取时间极大，V 为完整真实强 halo 体积。存在实际源使
log((J−V)/|E|) ≥ μn−√(2μ log n)−(1/2)log log n−O(1)。
同一源满足 log(V/|E|)≥μn−O(√log n)。对 k 与 √log n 同阶的斜板或任意 k 维因子乘等权截断双曲十字，最优差值的对数在 O(log log n) 内具有相同第二项。一般端点系数差仍为 (μ−1)/8。这里是迭代放松的损失，不给一般真实 halo 的上界。

**下界的统一性。** 写 L=log n，取 k 为 √(L/(2μ)) 的最近整数，m=n−k。第130轮中央带构造中的 K 固定一次即可，F 的带体积除以 |F| 至少 c_K exp(μm)，且有效不足 η 在 [c₁/√m,c₂/√m]，其中正数 c₁,c₂ 均与 k 无关。原因是选取该带只调用 m 维横向十字的中央价格，没有使用斜板的几何参数。对所取 k，
log(100k²)+(log c₂−(log m)/2)/k→−∞，
故全带均满足第134轮的 h≤1/(100k²)。体积为 1 的斜板也与 η 无关；对每个带内点可以分别选接收区域，乘积积分直接计价。其显式下界给
(J−V)/|E| ≥ c exp(μm) m^(−1/(2k))/k，
c 与 n 无关。真实 V 可直接在带上用斜板内部全部接收点结算。闭式优化来自恒等式
μk+L/(2k)−√(2μL)=μ(k−√(L/(2μ)))²/k。
整数化增加 O(1/k)，用 log m 代替 L 的差为 O(1/n)，而 log k=(log L)/2+O(1)。这给首段结论。按真实总体积归一化时，此文没有使用尚未证明的一般中央锐上界。

**同一增长区间内的反向核验。** 任取固定 0<a<b，a√L≤k≤b√L。对所有 k 维源和所有 m 维等权十字深度，证明
(J−V)/|E| ≤ C exp(μm) k m^(−1/(2k))。
在乘积积分中写 u=M1_F，η=1−p/u。令 u₀=p+(log m)²/√m。当 p<u≤u₀ 时 h≤[2(log m)²/√m]^(1/k)≤2m^(−1/(2k))（充分大的 n，依赖 a,b），并满足第134轮小窗口。逐坐标截断的上界因而为 C k m^(−1/(2k))；该带总体积用 A_F(p)≤C|F|exp(μm)。当 u>u₀，取 h≤(1/2)^(1/k)，通用体积因子至多 (Ck)^k，因为 1−exp(−log(2)/k)≥c/k。第111轮的紧区间上界在 u₀ 给 A_F(u₀)≤C|F|exp(μm−c(log m)²)。由于 k log(Ck)=O(√L log L)，外带可吸收。再用上面的优化恒等式即可。若区间包含最优比例 1/√(2μ) 的内点，最大差值对数在 μn−√(2μL) 的上下各 O(log L) 内。未对该增长区间之外的全部 k 给出匹配上界。

这个构造在对数阶上已达到 μn−o(log n)，但损失占 exp(μn) 的比例仍未证明有正下界。下一轮将检验从绝对体积差转换到真实秩误差是否还需额外的局部斜率控制，并核对在完整中央门槛区间能否统一构造。[统一斜板窗口](../r134/report.md) · [中央带](../r130/report.md) · [Wolfram 核验](check.wls)
