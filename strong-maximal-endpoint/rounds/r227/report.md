# 第227轮　用源点解码边长改进随机共点族的熵费用

2026-11-12。沿用[第226轮](../r226/report.md)的有限严格成功族与随机共点两尺度标签 \(C\)。令 \(d_R=\mathbb E\log(|R|/|E\cap R|)\)、\(d=\log(1/p)\)。则
\[
 V+D_X\le n\alpha+I(R;C|X)+O(\sqrt{nd_R})+d_R,\qquad
 \alpha=\log[2(1+(4/5)5^{-1/4})]\approx1.121673.
\]
常数绝对，长度比与标签数任意。可取最优随机标签。固定中央门槛下，近中央覆盖故必有 \(\Gamma\ge(\mu-\alpha)n-O_{I,B}(\sqrt n+\log n)\)，新线性系数为 \(0.15679203\ldots\)，高于第225–226轮的 \(0.04632086\ldots\)。第226轮例子的精确最优费用 \(0.115073n\) 已在新余量之内。此改进直接利用共点条件，并不声称所有族的最优费用均低于新余量。

**逐轴先条件于共点标签。** 给定 \(C=c\) 取其支持族的公共点 \(o_c\)。再使用 \(T_i=(X_{<i},Y_{>i})\) 展开条件微分熵差。更细条件 \(V_i=(Y,X_{<i})\) 加标签时，单轴源律相对负责区间均匀律的 KL 按真实条件平均后总和仍为 \(d_R\)：标签只由负责盒随机生成，与源样本给定盒后独立。以下 \(d_t\) 指给定 \((T_i,c)\) 的这一平均费用。

若两种长度的比 \(r\le5\)，第201轮的位移参考密度与第203轮的小比值推导原样给条件熵增至多 \(\log B(r)+d_t+(5\log5/4)\sqrt{d_t/2}\le\alpha+d_t+O(\sqrt{d_t})\)。单长度主项可取 \(\log2\)。

**远尺度用实际源坐标识别标签。** 写短长为 \(s\)、长边为 \(rs\)，\(r>5\)，长标签的条件概率为 \(w\)。所有负责区间经过同一轴点 \(o_{c,i}\)，因此若 \(|X_i-o_{c,i}|>s\)，负责盒必取长边。在整区间均匀参考律下，长边被误认为候选短边（源点落在内带）的概率至多 \(2/r\)。转回实际律，长边与内带同时出现的条件概率至多 \(2w/r+\sqrt{d_t/2}\)，由细条件 Pinsker 后平均得到。

将长度标签记为 \(S_i\)。在外带用长边概率 1 解码，在内带给短边概率 \(v=131/200\)。条件熵至多为该预测的交叉熵，故
\[
 H(S_i|X_i,T_i=t,C=c)
 \le (1-w)\log(1/v)+(2w/r+\sqrt{d_t/2})\log(1/(1-v)).
\]
另给定长度 \(l\)，接收点总落在 \([o_{c,i}-l,o_{c,i}+l]\) 内，故其熵至多 \(\log(2l)\)；实际源条件熵至少为 \(\mathbb E[\log l]-d_t\)（两式按标签概率合并）。由第204轮标签恒等式，此轴的上界是 \(\log2+d_t\) 加上述源侧标签熵，再**减去** \(H(S_i|Y_i,T_i=t,C=c)\)。因此也可直接使用随 \(r,w\) 变化的费用，并保留接收侧未识别标签的额外节省。对全族取统一值时，远尺度主项至多
\[
 \log2+\max\{\log(200/131),(2/5)\log(200/69)\}<\alpha.
\]
两项的严格比较只涉及正代数数，指数化后可取整数次幂比较；本机 Wolfram 计算表达式为 1.11883152534 对 1.12167250881。频率搜索未用于证明。

**跨族接口。** 各轴按真实概率累加，根号项总计 \(O(\sqrt{nd_R})\)。解除 \(C\) 条件只加 \(I(Y;C)-I(X;C)=I(R;C|X)\)。因此无需先对每个族用统一多项式门槛价再张量化。局部两尺度情形也可用第226轮的源点归类上界 \(\Gamma\le I(R;X_1|X_0)\)，即加强同盒第二样本的必要信息量。

一般系数差仍为 \((\mu-1)/8\)。上述估计可排除 \(\Gamma/n\) 严格低于新余量的覆盖。对高费用族仍需把可预测长度的程度与跨族费用本身配对，或进一步利用达到近中央体积的实际归属。
