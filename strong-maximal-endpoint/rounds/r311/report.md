# 第311轮　条件乘积与稀疏坐标约束的中央负余量

2026-11-12。设有限正测度源 $F\subset\mathbb R^n$ 在零测集以外是有限个可测坐标约束的交集。用坐标为顶点，同一约束中共同出现的坐标两两连边，记所得简单图平均度为 $D$。若 $D=o(\sqrt n)$，则对固定中央紧区间 $I$ 一致有
\[
 \log\frac{|\{M_S1_F>p\}|}{|F|}\le B_n(p)-c\,\frac{n}{1+D},\qquad p\in I,
\]
对充分大 $n$ 成立，$c>0$ 可取绝对常数。此结论针对存在这种因子表示的源；一项多坐标约束的全部不同坐标对均计入图，重复边只计一次。

**固定共享坐标后结算实际截面。** 写 $n=d+k+h$。假设固定 $h$ 个坐标 $z$ 后，几乎每个正质量截面均为任意 $d$ 维源与 $k$ 个一维集合的乘积。各因子可依赖全部 $z$。设 $d\asymp n$。则有
\[
 \log\frac{|\{M_S1_F>p\}|}{|F|}
 \le B_n(p)-\mu k+C_I\log n+O_I(1+(k+h)/\sqrt n). \tag{1}
\]
事实上，[第309轮](../r309/report.md)无条件估计在每个截面上给 $B_d(q)+C_J\log d+O_J(k/\sqrt d)$ 的对数价格，适用同一稍大的中央紧区间 $J$。以 $m=d+k$ 为主维数，$B_d(q)-B_m(q)=-\mu k+O_J(k/\sqrt d)$。故相对 $B_m(q)$ 的截面价格因子至多
$P=\exp(-\mu k+C_J\log n+O_J(k/\sqrt n))$。对全部 $z$ 按实际截面质量积分，总预算为 $P|F|$。在[第302轮](../r302/report.md)的弱矩证明中，比较 $(M_m1_{F_z}-b)_+$ 的每个非空水平集时均有同一因子 $P$（高门槛以 $J$ 内门槛代替时亦然），故该因子原样传到最终界，即使 $P<1$ 也成立。恢复 $h$ 轴的额外对数误差为 $O_I(1+h/\sqrt m)$；这就给出 (1)，无须限制 $h$ 固定或小于 $k$。$h=0$ 直接用第309轮。

同理，若辅助部分为[第310轮](../r310/report.md)的小维块乘积，总维数仍为 $k$，最大块维数为 $o(\log n)$，(1) 右侧多 $o(k)$；块内相互作用任意。只需这些估计对截面一致，截面因子的形状、尺度与位置无需相同。

**从约束图选轴。** 至少半数顶点的度数至多 $2D$。在这些顶点诱导的子图上贪心选独立集，每选一点连同邻居至多排除 $1+2D$ 点，可选出
$k=\lfloor n/[8(1+2D)]\rfloor$ 个坐标。固定它们在全图中的邻居，固定坐标数 $h\le2Dk$。于是 $d=n-k-h\ge7n/8$。没有约束含两个所选坐标，含有一个所选坐标的约束在固定邻居后只涉及该坐标。其余约束共同定义剩下 $d$ 个坐标的任意主源。这是实际切片上的乘积恒等式；空截面可忽略，有限正截面质量保证各非空因子有有限正测度（几乎处处）。代入 (1)，$k\asymp n/(1+D)$，$h/\sqrt n\le 2Dk/\sqrt n=o(k)$，$\log n=o(k)$，故净节省至少 $\mu k/2$。同样的常数预算给出只依赖 $I$ 的 $\epsilon_I>0$：若 $D\le\epsilon_I\sqrt n$，充分大 $n$ 时该节省仍成立。

因此，若某列源在固定中央区间达到 $B_n(p)-O(\log n)$，则充分大维数的每个上述精确约束表示都需要 $\Omega_I(n^{3/2})$ 条不同坐标对。此结论不约束单个稠密约束的函数复杂度，对任意可测源仍可用一个全坐标约束表示。一般端点上下系数差仍为 $(\mu-1)/8$。下一步检验允许少量违反约束的输入，并比较图中存在稠密小核心时选择共享坐标的实际费用。
