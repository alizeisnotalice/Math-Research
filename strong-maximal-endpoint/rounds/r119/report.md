# 第119轮　保持完整 halo 体积的尺度复制
2026-11-12。一般有限有理盒源，任意固定严格门槛 0<p<1，维数 n≥2。一般系数差仍为 (μ−1)/8。剩余问题是对每个中央门槛控制允许接收点独立选择前缀时新增的体积。

写 V(E) 为完整强 halo 体积，S(E) 为逐 x 取横向切片指标 halo 再积分的体积。J_k(E) 为每个 x 可选 k 个含 x 的前缀，用其平均后的横向强 halo 的并，先对前缀取体积上确界再积分。横向盒始终允许自由重选。有限盒源的分段常切片给 S≤J_k≤V，严格平均允许有理端点取上确界。

对任意有限有理盒源 E、任意整数 k≥1、任意 ε>0，存在有限有理盒源 F 使 V(F)/|F| 和 S(F)/|F| 分别精确等于原比值，且
J_k(F)/|F| ≤ S(E)/|E|+ε。
先作坐标仿射变换，将 E 的第一坐标支撑放进 [1/3,1/3+w]，有理 w<p/10，其余坐标放进单位盒。各比值不变。作 m 个组，每组在第二坐标平移分开，支撑带之间留大于 10/p 的空隙。组 j 的第一坐标分成 q_j 个等周期铺满 [0,1]，每周期内放一个缩小 q_j 倍的模板。各组体积恰为 |E|。遇到至少两个横向组的矩形密度至多 2/(10/p)<p。在同组内碰到 l≥2 个时间支撑段，其第一坐标占用率至多 lw/[(l−1)(1−w)]<p。因此成功见证只遇一个副本，其第一坐标长度小于 w/(p q_j)，整个见证落在其周期内部；同理各横向成功区域在不同组间不交。故完整 halo 精确分拆为各副本的完整 halo，切片 halo 同样可加。

令 D 为模板第一坐标各分割点数（包括周期边界）。在每组去除距这些点的周期副本不足 δ/q_j 的 x，总去除长度至多 2Dδ。每组的全部横向成功接收点都落在一个体积 B=(1+2/p)^(n−1) 的扩盒内。好 x 上长度小于 δ/q_j 的前缀只读到原切片，超过 w/(p q_j) 的前缀没有成功见证。取整数 q_j 逐次增长使这些中间长度区间两两分离。每个 x 的 k 个前缀至多在 k 个组中产生好 x 上的新增体积。因此 J_k(F)≤m S(E)+2mDδB+kB。先取 δ 小，再取 m 大即得，所有分割和缩放均可有理化。

中央门槛处，取有限盒近极值源使 V(E)/|E| 逼近 H_n，且 S(E)/|E|≤H_{n−1}。由既有 log H_n(1/2)/n→μ，对任意固定 η>0 有无穷多维满足 H_n/H_{n−1}≥exp(μ−η)，否则逐维求和与指数率矛盾。在这些维数中即使预先指定任意有限 k=k(n)，仍有近极值源使 J_k/V≤exp(−μ+η)+o(1)。这解决了第118轮标记体积能否代表完整 halo 损失的问题。量词允许源依赖 k。

独立低维校准：单位方块、p=1/2，两个一维极大函数相乘。源内第一坐标给横向长 3；向任一侧外移距离 0<d<1 时横向长 4/(1+d)−1。故 V=1+8log2，S=3。尺度复制可使 J_k/V 逼近 3/(1+8log2)。复核命令为 wolframscript -file check.wls，在本目录运行。
