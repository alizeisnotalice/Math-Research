# 第534轮　不预选外区间的二维选择损失证书

- A 覆盖全部等权深度轮廓，中央误差有界。
- 有限矩形源的两轴复合与真正矩形平均可在同一张端点表上精确比较，得到同时处理所有外区间的门槛证书。
- 下一步须估计中央切片上该证书成立的接收体积，而非继续增加端点数。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定接收点 $(x,y)$，源为有界有限矩形并；亦适用于有限矩形网格上的非负有界阶梯函数。插入接收点的两条坐标线，形成 $H$ 个横向间格与 $V$ 个纵向间格，并在网格外补零。令 $I_i,J_j$ 分别为从接收点到同轴任一网格线的非零单侧区间，两个方向都枚举。记 $a_i(t)$ 为横平均，$m(t)=\max_i a_i(t)$。若接收点在网格外，同样插入它并保留中间零段。忽略分界线上的源值。

对固定 $t$，前缀积分在相邻网格线间仿射，除以长度后单调或恒定，零长度端由紧邻单元的常值实现；越过支撑边界不改善平均。任意跨接收点的区间平均又是两侧平均的凸组合。因此 $m$ 等于真实横极大值，且在每个纵向间格恒定。相同论证适用于 $m$ 以及每个 $a_i$ 的纵平均。固定任意纵区间时其平均后的横向密度也是同网格阶梯函数，故真正的二维值也在所列矩形上达到。对零源约定两值为零。于是
\[
 C=\max_j A_{J_j}m,\quad S=\max_{i,j}A_{J_j}a_i,\quad
 C-S=\min_j\big[C-A_{J_j}m+\min_i A_{J_j}(m-a_i)\big].
\]
给定 $h,v,\tau>0$，若每个 $C-A_{J_j}m<\tau$ 的候选和每个 $i$ 都满足 $|\{t\in J_j:m(t)-a_i(t)\ge h\}|\ge v|J_j|$，则 $C-S\ge\min(\tau,hv)$。反之若 $C-S<\delta$，必有一对实际端点，使外损失小于 $\delta$，且对所有 $h>0$ 该横端点的坏切片比例至多 $\delta/h$。这是一个同时选择外区间与横端点的检验；不要求连续参数中的每个近最优外区间逐一通过。计算全部横向前缀平均及其最大值，再为每个横端点沿纵轴累计，即可在已给网格值时用 $O(HV)$ 运算得到 $C,S$ 和一对实现 $S$ 的端点。构造源的网格分解费用不含在此复杂度中。

本机 Python 对所有 $3\times3$ 二值源及四个内网格交点，用有理数把端点算法与跨点双侧矩形的穷举比较。有限端点刻画尚未给出对网格大小一致的中央缺额。
