# 第738轮　连续软计数源的完整端点压缩与网格率障碍

2026-11-14。一般 $C_n$ 的 $\log n$ 精确系数仍未确定。本轮给出可复现的真实连续源计算公式，并以严格机制障碍结束一个指定网格测试路线。

源为 $f(y)=w_{N(y)}1_{[-R,R]^n}$，$N(y)=\#\{i:|y_i|\le1\}$，$w_j$非负非减。实际Orlicz成本是
$$J_n(f)=(2R)^nE\Phi_n(w_B),\quad B\sim\operatorname{Bin}(n,1/R).$$
逐轴分段线性分式最大化证明：核心坐标可取全内侧区间；$1<x_i\le R$只需 $[-1,x_i]$；$x_i>R$只需 $[-1,x_i]$ 或 $[-R,x_i]$。固定外侧选择数r，计数分布只依赖r，支持比例乘积由把长负端点分配给最大r个坐标取得。因此完整强矩形最大值只需排序后的r=0,…,o候选；未枚举 $2^o$ 个端点。[完整公式、实际预算及有限积分](count_profile.md)。

这确实是完整矩形公式，但后面的数值体积仅计算**指定网格见证内近似**，不宣称完整halo积分已算出。720组本机Python12进程精确Fraction穷举，将全部端点选择与排序候选对比，全部相等；包含非示性单调软振幅。另以120个配置探索n=8至256、R=4/8/16/64/256；此探索保留为数值证据，不承担严格不等式。

对R=4、轴格[0,1]、[1,2]、[2,4]，采用上角实际矩形严格半命中来收集整个格子。计数(a,b,c)的平均恰为
$$P\{a+\operatorname{Bin}(b,2/3)+\operatorname{Bin}(c,2/5)\ge k\},$$
同计数类型的正象限格子总体积为多项式系数乘 $2^c$。本机12进程对12个维数8至768作精确整数分类、体积及全部k比较；计算改为尾和递推并逐维保存检查点，完成版约24秒。768维最优网格k=589，log(见证体积/真实源体积)约318.6029231341；分类和体积是整数精确值，最后对数是浮点诊断。

进一步证明该网格机制的最优指数率恰为
$$\kappa_{\rm grid}=\log\frac{t_*^{15}+t_*^{10}+2t_*^6}{t_*^{15}+3},$$
其中 $t_*>1$ 是 $-5t^{19}-18t^{15}+45t^9+30t^4+36=0$ 的唯一正根。证明用Hoeffding夹逼、均匀类型熵与Bernoulli变分恒等式，覆盖小阈值源体积率及边界情形。[机制率证明](grid_rate_proof.md)。独立Astra审查核验了优化交换、可达类型及低阈值处理。

Mathematica精确导数余项为0，80/120位根计算稳定；独立Python有理二分和80项定向对数给
$$0.413915628690337327068033622250839363653449152613027181327487
\le\kappa_{\rm grid}\le
0.413915628690337327068033622250839363653449152613027181327488.$$
因此它严格小于0.414，而μ>1。这排除的是**该网格见证机制**，没有排除同源的完整halo或其他尺度网格。R=2则另有完整halo的粗率界log2<μ，故未投入大规模盲搜。
