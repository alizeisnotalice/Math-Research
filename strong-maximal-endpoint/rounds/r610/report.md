# 第610轮　高低密度分离迫使加权坐标端点交叉

- A 的全部等权深度轮廓中央误差有界。
- 把第609轮的同一行内密度反差转化为针对不同矩形相对位置的显式不等式。各坐标的贡献只来自另一条正权行的端点切入当前行。
- 尚缺对交叉和的中央尺度上界；一般系数差仍为 $(\mu-1)/8$。

2026-11-13。沿用第609轮的权重和密度 $s$。取一条满足该轮好行条件的 $R$，置 $a=p-\sqrt\epsilon$、$b=1-q-\sqrt{2h}$、$H=\epsilon T/m$，假设 $a,b>0,H>2$。在 $R$ 上用均匀乘积概率，令 $g=\log\max(2,\min(s,H))$。由两独立样本的平方差表示方差，两样本分别落入高低区（两种次序）的概率至少 $2ab$，所以 $\operatorname{Var}_R g\ge ab\log^2(H/2)$。

**坐标重采样的实际交叉。** 对另一行 $P$，记 $u_i=|P_i\cap R_i|/|R_i|$。仅重采样第 $j$ 个坐标，$1_P$ 翻转的概率精确为 $2u_j(1-u_j)\prod_{i\ne j}u_i$。故记 $I_R=\sum_P\lambda_P (|P\cap R|/|R|)\sum_j(1-u_j)$，它等于各轴重采样下所有翻转行权期望之和的一半。截断对数的 Lipschitz 常数为 $1/2$，振幅为 $D=\log(H/2)$，故平方变化量至多 $(D/2)\sum_P\lambda_P|1_P(x)-1_P(x^{(j)})|$。乘积方差不等式 $\operatorname{Var}g\le\frac12\sum_j\mathbb E(g(x)-g(x^{(j)}))^2$ 可由逐坐标条件期望的正交鞅差分解及 Jensen 得出。合并得到
\[
 I_R\ge2ab\log(H/2).
\]
与 $R$ 不交或包含 $R$ 的行贡献为零。该界在第609轮保证的全部好行上同时成立。

**双行量与限制。** 以 $\lambda_R|R|/T$ 平均，左边成为 $T^{-1}\sum_{R,P}\lambda_R\lambda_P |P\cap R|\sum_j(1-u_j)$，右边至少为 $(1-\sqrt\epsilon-\sqrt{2h})2ab\log(H/2)$。若中央窗给 $T/m\ge(n^c-1)/h$，取 $\epsilon=h$，则在固定中央区间该平均交叉量至少为常数倍 $\log n$。这直接约束正权行间的端点位置，但并未限定交叉数或其加权和的上限。特别是单纯增大近重合行的数目可以造成很大的未归一化双行和；需进一步结合对偶最优性及接收区域不可重复计费的条件。
