# 第538轮　固定真平均门槛下近一复合差集的面积上界

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对任意平面指标源，真正矩形平均至多 $p$、逐轴复合平均超过 $1-\epsilon$ 的区域面积至多 $O_p(\epsilon)|E|$。
- 下一步须缩小与第537轮二次面积下界的差距，或利用乘积门槛带中真正平均高于 $p$ 的部分。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。令 $0<p<1$ 固定，$0<\epsilon<(1-p)/2$，$t=2\epsilon/(1-p)$。置 $F=\{M_x1_E>1-t\}\setminus E$。对任意有限长度一维集合，所有严格成功区间在源外的并长至多 $2t/(1-t)$ 倍源长：对有限子目录取极小覆盖，区间重数至多二，每个区间的外部长度小于 $t/(1-t)$ 倍内部长度。以有理端点穷尽，再沿切片积分，得 $|F|\le 2t|E|/(1-t)$。

若 $C=M_yM_x1_E>1-\epsilon$，存在外区间 $J$ 使其中横平均超过 $1-t$ 的切片比例大于 $1-\epsilon/t$（对 $1-M_x1_E$ 用 Markov）。同时若 $S=M_{S,2}1_E\le p$，则在几乎每个这样的接收点，$J$ 中纵向原源密度至多 $p$。理由是 $M_y1_E\le S$ 几乎处处：先对可数有理外区间的纵平均用横向微分，再穷尽。于是 $F$ 在该纵区间占比严格大于 $1-\epsilon/t-p=(1-p)/2$。用纵向弱型常数二，
\[
 |\{C>1-\epsilon,\ S\le p\}|/|E|
 \le \frac{16\epsilon}{(1-p)^2(1-2\epsilon/(1-p))}.
\]
面积估计独立于源的连通性、网格与尺度。它限制的是第536轮中用 $S\le p$ 直接排除整个基底 halo 的证书。若要求 $\epsilon=O(k^{-1/2})$ 使基底门槛移动至多中央步长，则这类证书的平面面积比例至多 $O_p(k^{-1/2})$，单是该面积就至少支付半对数阶代价。第537轮已达到 $\Omega(k^{-1})$，尚不能确定最佳幂。这不是对所有乘积差集的上界；在 $S>p$ 时仍可能有非空基底门槛带。
