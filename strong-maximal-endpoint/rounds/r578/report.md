# 第578轮　切分共享源的最小门槛损失及其对偶

- A 的全部等权深度轮廓中央误差有界。
- 对任意预定的有限见证分组，精确给出把源分成互不重叠的指标子集时，各行平均最大损失的最小值。对偶只收取不同组在同一源点的加权竞争。
- 待证的是能否选择兼具局部几何上界与小竞争费用的分组，或由大的最优对偶值推出中央抵扣。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。令 $c(R)$ 是行 $R$ 的组，$a_R=|E\cap R|/|R|$。把 $E$ 分配给各组的互不重叠子源 $E_c$，允许舍去余量。定义 $\Delta$ 为对所有分配取 $\max_R(a_R-|E_{c(R)}\cap R|/|R|)$ 的最小值。对行上的概率权 $\lambda$ 写
\[
 f_c(y)=\sum_{R:c(R)=c}\lambda_R1_R(y)/|R|.
\]
则精确有
\[
 \Delta=\max_{\lambda\ge0,\,\sum\lambda_R=1}
 \int_E\big(\sum_c f_c-\max_c f_c\big).
\]
证明：按行边界把源切为有限个命中原子，在每原子上以单纯形变量分配各组体积份额。任一份额可由不交指标集精确实现，因 Lebesgue 测度无原子。最大行损失等于对行权单纯形取最大加权损失。两个有限紧凸多面体间的双线性极小极大交换后，固定行权时在各原子把全部质量给最大 $f_c$ 即达加权最优。因此上式两端都取到；原始最优可按原子分片，不要求选取某一个无分片的胜者方案。

**可核验的充分条件。** 非负数的总和减最大值至多所有不同组对的较小值之和，且 $\min(\sum_i a_i,\sum_j b_j)\le\sum_{ij}\min(a_i,b_j)$。于是令 $H_{RS}=|E\cap R\cap S|/\sqrt{|R||S|}$ 当组不同，同组取零，有
\[
 \Delta\le \tfrac12\lambda_{\max}(H).
\]
因为每对行的积分至多 $H_{RS}\sqrt{\lambda_R\lambda_S}$，且 $\sum\lambda_R=1$。该上界只用真实源上的跨组交叠。还可在原问题中把 $a_R$ 换为共同门槛 $p$，得到达成 $p$ 的最小最大短缺（允许为负），其对偶比显示公式多 $\sum_R\lambda_R(p-a_R)$，自动使用各行成功余量。

**中央预算。** 若原行均严格超过 $p$，则在最优不交分配后每行仍严格超过 $p-\Delta$。若各组对所得子源均有 $B_n(q)+r_n$ 的局部对数界（$q=p-\Delta$），对并集求和后仅付一次 $|E|$。当 $\Delta=O_I(n^{-1/2})$ 时，$B_n(q)-B_n(p)=O_I(1)$；当 $\Delta=o_I(\log n/\sqrt n)$ 时，费用为 $o_I(\log n)$。须保证组内定理对分配后的源仍适用。固定分组可以失败，例如两个不同组各有同一个矩形、源填满矩形时 $\Delta=1/2$；合组则损失为零。下一步应联合优化分组与受组内几何限制的局部上界，而非仅优化分配。
