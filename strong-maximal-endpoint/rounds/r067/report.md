# 第67轮：条件角核的双参数响应与全局径向化障碍

日期：2026-11-08。状态：条件算子定理、有限径向接口、径向化反例及独立审查完成。一般强极大常数 C_N 的锐上界仍未闭合。

## 1. 条件化和符号标签不再损失一阶 L² 界

令 Z_c=Exp(1)+cJ，J∼Bern((1+e^c)^−1)，块长为 b。记 H_b={x:Σx_i=0}、P_b 为正交投影，定义保留全部原始符号标签的条件卷积

\[
 \mathcal K_c^sG(x,\sigma)
 =E_c[G(x+P_bZ,\sigma(-1)^J)\mid\textstyle\sum Z_i=s].
\]

取任意固定正紧区间 I、J_0。对充分大的 b，c∈I、s/b∈J_0，本轮证明

\[
 \boxed{\|\partial_c\mathcal K_c^s\|_{2\to2}\le C_{I,J_0},
 \qquad\|\partial_s\mathcal K_c^s\|_{2\to2}\le C_{I,J_0}/b.}
\]

导数按每个固定 L² 输入上的强导数理解，所得导数算子范数一致有界。空间为 H_b 上 Lebesgue 测度与符号群上均匀概率的乘积。定理适用于任意 L² 输入，不要求偶性或振幅上限。在相应参数路径内，还得到动作区间的点态上确界 L² 界，以及径向变化 O(|δ|/b) 的算子差界。近 μ、临界下尾只是本定理的特例。

关键新引理为

\[
 \int_{\mathbb R}\Bigl(\sum_i\min\{t_i^2,|t_i|\}\Bigr)
 \prod_i(1+t_i^2)^{-1/2}d\tau\le C/\sqrt b,
 \quad t_i=\tau+\xi_i.
\]

它对任意移频成立。把乘积写成随机区间的交集概率后，删除一个区间能增加交集长度的项最多两个；总增量受第二小随机半径控制，其期望为 O(b^(−1/2))。这一估计配合固定倾斜下的 Fourier 分部积分，消掉条件化引入的共同漂移。除以 O(b^(−1/2)) 的密度归一化后，动作响应保持 O(1)，径向响应则为 O(1/b)。负符号字符在小频率处收缩，其余频率仍由同一随机区间引理控制。

这解决了第66轮留下的条件核响应问题。它不与第64轮 L¹ 包络的 √(b log b) 增长矛盾，也不提供一般输入的弱端点上界。单坐标块仍有障碍：固定 s>0 时，其负符号字符在 c<s 为0、c>s 为1，不能把本结论直接细化到全部独立坐标参数。

完整证明、带符号边界通量及径向面通量恒等式见 conditional_flux67.md；独立审查见 conditional_review67.md。

## 2. 有限径向位置上也有精确接口

取重心坐标 X=V(ξ−1/b)、Y=(V+s)(η−1/b)，物理传输恰为 Y=X+P_bZ。把源单纯形上的 F−B 零延拓到 H_b，其中 B 是在该径向纤维上对所有角度、标签相同的常数，得到

\[
 \|\sup_{c\in I'}|K_c^{V,s}F-K_{c_0}^{V,s}F|\|_{L^2(\sigma_\xi)}
 \le C|I'|\left(\frac{V+s}{V}\right)^{(b-1)/2}
 \|F-B\|_{L^2(\sigma_\eta)}.
\]

符号平均包括在两边。平方后乘接收 Jacobian V^(b−1)，恰匹配源 Jacobian (V+s)^(b−1)，无需深层极限近似。径向导数界还控制了同一源纤维受到条件核变化的误差；它不控制源纤维本身的平移，也不能自动完成全局预算分配。

在已经选出的 B≥1、固定振幅上限 A 的区域，右支撑斜率给

\[
 D_B(F)\ge c_A N\Phi_N(B)|F-B|^2,
 \qquad\Phi_N(t)=t(1+\log^+t)^{N-1}.
\]

因此，若缺口能按实际源预算正确分配，局部响应可降到 √(log N)/N，足以小于径向修复所需的 log N/N。下节说明不能直接用全局角平均来选取这种区域。

## 3. 直接全局角平均会丢掉接收区

在固定参考尺度的对数角坐标中，普通物理缩放 f_D(x)=f(e^D x) 精确保持强极大端点的体积/模数比。对紧支撑且避开坐标面的输入，缩放后每块角支持向重心集中，其概率为 O(D^(−(N−r)))。所以，全局角度及标签平均 B_D 可在所有径向位置都趋于0，而端点比值不变。固定 N、固定振幅类中的近端点输入可先用单调对数盒截断逼近，再作上述缩放。加上任意廉价、振幅很小的外部填充，还能保持各坐标外支撑半径为1，同时保持平均值低于阈值；这不排除按有效质量选择尺度或作局部化。

还有一个完全显式的例子。取偶对称盒

\[
 f_N(x)=(1+N^{-2})\mathbf1_{\{e^{-1}\le|x_i|\le1,\ \forall i\}},
 \qquad f_{N,D}(x)=f_N(e^Dx).
\]

对任意有实际角维数的分块 N>r，Irwin–Hall 截面公式给

\[
 \sup B_D\le(1+N^{-2})D^{-(N-r)}.
\]

D=2 时右侧至多5/8。故平均后的输入完全没有阈值1的 halo，而原输入在盒内部有严格平均余量 N^(−2)。令 \(\widetilde f_{N,D}\) 为把 B_D 拉回物理空间并在坐标图外取零所得的输入。全局 Jensen 模数比满足

\[
 \frac{\int\Phi_N(f_{N,D})}{\int\Phi_N(\widetilde f_{N,D})}
 =(1+\log(1+N^{-2}))^{N-1}\longrightarrow1.
\]

这个盒子本身不是近 Q_N 的输入，也不是 C_N 上界反例。它严格否定的是：仅凭近单位接收和很小的 Jensen 模数损失，就把全局角平均当作兼容接收轮廓。一般缩放引理与此显式例子的适用范围分别记录，未将二者混成一个更强结论。见 dilation_obstruction67.md、dilation_review67.md。

## 4. 本机验证与复现资格

正式计算使用12内核 Mathematica 和12进程本机 Python。

- 128组联合标签 Fourier 核验：116组临界参数及12组显式均值倾斜参数。块长最高2^256；补充参数含正、负倾斜，倾斜率覆盖1/4至4。计算动作与径向导数，并记录求根/均值残差。
- 62组独立 Gamma—二项/Beta 混合：分别用后验协方差、带符号边界通量及径向面通量计算导数。与 Fourier 共有34个独立参数点，三类量保留的约30位吻合。动作、径向通量残差最大约8.91e−56、6.65e−60。
- 10组 Fourier 参数加精度、步长减半、截断扩大后稳定；有限混合另有80→160位复算。大量标签下极小的积分节点按显式阈值截去，只记录离散求积的绝对遗漏上界，不宣称零值的相对精度或总误差认证。
- 74组第二小半径期望计算，块长从3至2^4096，最高5136位；大维数加倍精度后保留35位一致。10项代数、极限、坐标和 Jacobian 核验通过，普遍结论仍由解析证明给出。
- Python 检查156组盒子/分块/缩放参数。数值极值只是候选，5/8 的统一上界由解析不等式给出。

正式混合驱动实测 CPU 峰值1166.6%（12核满载约1200%），进程总 RSS 峰值约2.65GiB。输出逐例检查数值类型、设置残差和新鲜输出文件；所有正式进程均已退出。数值结果未采用定向舍入，不登记新的认证 C_N 下界。详见 validation67.json。

## 5. 一般账本与后续两项动作

仍为 Q_N≤C_N≤R_N；Q_N 是第22、28轮的固定比例反射锚定族端点，R_N 是第44轮的反馈上界。两端对数项系数仍为 (9−μ)/24 与 (3+μ)/12，间隙 (μ−1)/8 未缩小；最佳有限维认证仍是 log C64>71.79。本轮新增的是条件角核的严格响应界和径向化机制反例，没有一般 C_N 的新系数或公开优先权主张。

下一轮两项动作：第一，构造在重心对数坐标中保持缩放兼容的局部基准，证明或反驳其实际预算与接收平均可以同时保留；第二，控制接收锥复用同一源缺口的加权重数，寻找带效率条件的分配或停止规则。增长块数、全矩形几何及无界输入归约仍需分别处理，不能由局部算子界直接略去。相关局部工具及未闭合条件见 budget_bridge67.md。
