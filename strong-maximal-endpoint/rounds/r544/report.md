# 第544轮　不等宽反向条带把中央差集面积代价减半

- A 覆盖全部等权深度轮廓，中央误差有界。
- 当真实平面平均也趋近一时，平面面积可由第537轮的 $k^{-1}$ 提高到 $k^{-1/2}$，同时保持基底门槛只移动一个中央步长，并使同源尾项可忽略。
- 下一步须判定此移动门槛构造的面积是否还能提高，以及能否在一般近最优输入中产生相应缺额。
- 一般系数差仍为 $(\mu-1)/8$。

取 $0<h<1/4$，源为 $[0,1]\times[0,1]$ 与 $[-1,0]\times[1,1+h]$ 的并，接收区 $X=[h,2h]\times[1+h/2,1+h]$，忽略边界。源面积 $1+h$，接收面积 $h^2/2$。逐轴复合用纵区间 $[0,y]$；底部横平均为一，顶部向左可取得至少 $1/(1+x)$。故 $c\ge 1-2h^2=:c_0$。

真正矩形的横区间在 $x$ 处分成两侧，固定纵区间时只需检验两侧前缀。向右时顶部源平均为零，任一纵区间内底部的比例至多 $1/y\le1/(1+h/2)$。向左长度 $l\le2x$ 时，顶部横平均至多一半，底部至多一。可先把纵区间裁到 $[0,1+h]$（接收点在内且裁剪不减平均）；若命中底部，则顶部占比至少 $(h/2)/(1+h)$，否则平均至多一半。故此支平均至多 $1-h/[4(1+h)]$。向左 $l>2x$ 时，底部横平均至多 $x/l<1/2$，顶部至多 $1/(1+x)$。合并得到 $s\le1-h/5=:s_0$。以上是对所有真正矩形的统一检验。

取 $h=k^{-1/4}$ 与固定中央物理门槛 $P$。充分大时 $c_0>s_0>P$，$q=P/c_0=P+O_I(k^{-1/2})$，同时 $P/s_0-q\gtrsim_I k^{-1/4}$。若 $R_q=H_G(q)/(|G|e^{B_k(q)})\ge k^{-D}$，第541轮给 $H_G(P/s_0)/H_G(q)\le k^{A+D}e^{-c_I k^{1/4}}=o(1)$。第536轮的乘积差集公式因而给出归一化差集至少
\[
 \frac{h^2}{2(1+h)}\,(1-o(1))H_G(q)/|G|.
\]
其对数至少 $B_{k+2}(P)+\log R_q-\tfrac12\log k-O_I(1)$。相较第543轮，上述显式构造在同样的单步基底门槛位移下节省半对数；没有与第539轮固定真门槛的锐二次界冲突，因为这里真门槛趋于一。这是存在性下界，未给出普遍上界改进。
