# 第79轮：连续角点的精确定价与无损有理化

日期：2026-11-08。状态：证明固定网格源的有限角点halo表示；精确求解一个允许全部连续角点与任意源片的单列问题，证明原输入网格不能统一替代源片角点；同时闭合固定N的有理输入/有理角点技术归约。一般锐上界仍未闭合。

## 1. 固定step源的整个halo可有限表示

若实际源G紧支、在有限轴平行网格上常值，设坐标i的源网格面为B_i，则在网格超平面之外

\[
 M_{\rm S}G(x)=\max_{a\in B_1\times\cdots\times B_N}H_aG(x).
\]

这里H_a允许全部signed receiver orientations。证明先把任意包含x的矩形在x处切成以x为顶点的矩形，其中至少一个平均不小于原平均；再逐坐标移动另一端点。在不跨网格面的区间内，截面积分常值，矩形平均是端点的分式线性函数，最大值在区间端点。端点与x同格时可移到同侧网格面而不改变平均。

若坐标i有m_i个源格，distinct anchors至多∏(m_i+1)。列出所有方向的平均形式上有2^N倍，但同角点按源象限分摊模数，不能把这个方向数再当作成本因子。网格复杂度任意大，有限表示本身不提供维数一致上界。[证明及适用范围](step_halo79.md)。

关键是这里的网格属于**实际G**。仅知道F是step、G≤F，不能假设G在F网格上常值。

## 2. 连续角点的单列问题可以精确求解

统一Φ_N(t)=t(1+log⁺t)^(N−1)、J(G)=∫Φ_N(G)。取

\[
 F=2\,1_{[0,1]^N},\quad
 E_d=(1+d,1+2d)\times(0,1)^{N-1},\quad
 1<\sigma<2,\quad \sigma(1+2d)<2.
\]

定义C_one(N,σ,d)为一固定角点、一源片G≤F，以非退化矩形在E_d几乎处处达到平均≥σ的最小成本。它允许所有连续角点和任意可测源片，不只允许预设step源。

角点横向坐标可投影到[0,1]，第一坐标可写为1−u，0<u≤1。按其横向象限切分源立方体，令接收点趋向各相反端点及x1→1+2d。每块的质量约束与Jensen给

\[
 J(G)\ge u\Phi_N\!\left(\sigma\left(1+\frac{2d}{u}\right)\right).
\]

常值薄层源G=g1_[1−u,1]×[0,1]^(N−1)达到下界，其实际平均gu/(u+x1−1)>σ。故

\[
 \boxed{
 C_{\rm one}(N,\sigma,d)=
 \min_{\sigma(1+2d)\le g\le2}
 \frac{2\sigma d\,\Phi_N(g)}{g-\sigma}.
 }
\]

导数符号由D(g)=(N−1)g−σ(N+log g)决定；D'(g)>0。因此取D的唯一零点并截到可行区间即可，完整处理全宽、内部和封顶三个分支。N=2时最优为g=2。[精确证明](pricing_obstruction79.md)。

这不是整个分数列覆盖容量的精确解，更不是一般C_N的值。

## 3. 原输入网格的定价损失可达任意对数级

F的源网格顶点为{0,1}^N。第一坐标为1的角点在E_d看不到源；第一坐标为0的任一网格角点，覆盖整个E_d的最优源成本恰为

\[
 c_{\rm grid}(E_d)=\Phi_N(\sigma(1+2d)).
\]

任意源片在极端接收点必须支付完整立方体质量，均匀源恰达到。

更强地，即使允许任意多个网格角点、任意源片以及合法分数权重，逐接收点的质量下界仍给总预算

\[
 B_{\rm grid}\ge \sigma(1+2d)\,2^{-(N-1)}.
\]

连续角点则有薄层预算O_N(d)。固定N、σ时d→0，网格预算相对连续预算无任何统一乘法控制。这不是只针对一种接收格划分的现象。

对于高维单列定价，令σ_N=1+κ/N、d=N^(−β)，κ>0、β>1固定。精确内部解满足

\[
 g_*=1+\frac{\kappa+1}{N}+o(N^{-1}),\qquad
 u_*\sim2Nd,\qquad
 C_{\rm one}\sim2e^{\kappa+1}Nd,
\]

而网格全格价格趋于e^κ。因此

\[
 \boxed{
 \log\frac{c_{\rm grid}(E_d)}{C_{\rm one}}
 =(\beta-1)\log N-\log(2e)+o(1).
 }
\]

所以在这个模型中，原输入网格的对数价格会比连续最优多出任意固定倍的log N。该立方体/薄层模型不是已知高效临界族，不排除带临界效率条件的特殊离散化，也不构成一般C_N上界的反例。

## 4. 可以无损有理化，但不是统一有限网格

两个不同技术模块已经证明：

1. **cap2最优常数的输入稠密性。** 固定N，有理网格、有理高度、紧支step输入的最优比值上确界等于整个cap2类。截断、cell average及统一分母向下取整给F_k→F于L¹且J(F_k)≤J(F)；每个严格成功的固定矩形最终仍成功，Fatou传递halo测度。F_k不一定逐点≤原F，不能把这个改变输入的步骤用于固定容量源片。
2. **固定原输入的角点有理化。** 对任意有限测度接收集E和可数真实角点列覆盖，总成本B<∞，任意ε>0均可构造有限有理角点列，仍在原F之下、成本≤B，并使
\[
 \int_E\left(1-\sum_jw_j1_{\{H_{b_j}\widetilde G_j>1\}}\right)_+<\varepsilon.
\]
先截列，再把每个源按原角点象限拆开；模数可加，没有2^N费用。各保留接收紧集有严格余量及正的最小边长，故可选择靠近原角点的向外有理角点，保持真实成功。这里只是覆盖缺口的L¹近似，不是每个点的精确有限覆盖。

因此，只要目标为Lebesgue测度的上界，覆盖缺口可最后令ε→0，不产生对数级损失。对绝对连续的接收定价测度，有理角点上的全部定价不等式也可由Fatou传递到所有实角点；原子测度或角点退化面不能无条件套用。[精确量词和证明](rational79.md)。

这些结论没有给网格大小、保留列数或所需分母的维数一致控制，不能以有限搜索替代全局预算证明。
