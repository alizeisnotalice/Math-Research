# 第737轮　将对数系数结算缩为实际信息谱的正态误差

2026-11-14。一般 $C_n$ 的精确 $\log n$ 系数仍未确定。新增的是一个非渐近逆检验界及足以闭合的明确精度条件，不是已证明的一般正态逼近。

对实际负责最不利混合 $P$、并集均匀律 $Q$，写 $L=\log(dP/dQ)$，$M=E_PL$、$\Sigma^2=\operatorname{Var}_PL$、$V=-\log b_q(P)$，这里价格已用并集体积归一化。若标准化L到标准正态的Kolmogorov距离至多ε，且 $|q-1/2|+\varepsilon\le1/8$，则
$$V-M\le5\Sigma(|q-1/2|+\varepsilon)+\log\max\{8,1+\Sigma\}+5.$$
证明以任意谱分位点截取至少γ的源命中质量，兼容离散谱、阈值随机化和零方差。[证明、成长块版本与适用范围](spectral_criterion.md)。

第710轮的统一负责熵界为 $M\le\mu n-\frac12\log n+O(1)$。因此，若沿第718轮所选目录统一证明
$$\Sigma=O(\sqrt n),\qquad\varepsilon=o(\log n/\sqrt n),$$
就得到 $V\le\mu n+o(\log n)$，继而由第709轮得到一般精确系数 $c_Q=(9-\mu)/24$。这里的两项谱条件尚未由一般盒几何推出，不能据此宣称已闭合。只有方差界不足；若误差仅为 $O(\log n/\sqrt n)$，则常数也不足以匹配。

另证明：保体积群在真实目录行标签上传递时，均匀权负责且最不利，真实源价与负责源价相等。成长块Berry–Esseen界完整保留三阶矩项 $r/\sigma^2$；结合逐块熵亏损，维数趋增且误差可控的许多小块不能进入近中央区间。这解释了该数值可计算子类的限制，没有把低率积星当作近中央证据。

本机Mathematica 15实际12核，以80位计算12个二项信息谱例，最大真实维数96000；Python12进程从精确二项整数尾独立作80/120位对数计算，保存70位稳定，跨软件最大绝对误差 $4.916\times10^{-67}$。这些数值检验谱公式及实现；不承担一般正态条件的证明。Mathematica还精确核验逆高斯分位导数所需两个有理界，子核随后关闭并退出。MATLAB未由本轮脚本启动。

独立Astra审查通过主界、离散情形、对称源价与成长块估计。审查指出初稿误称“还需额外半对数容量收益”；现已修正为熵负半对数直接抵消，避免额外加入不必要条件。零密度质量和成长块维数条件也已澄清。

复现：`wolframscript -file check_formula.wl`，然后 `python3 check_spectral.py`。后者需mpmath；输出记录精度、实际尾整数位数和跨软件残差。Berry–Esseen仅用保守常数1，原始来源为[Shevtsova 2011](https://arxiv.org/abs/1111.6554)的经典iid界；不作新的优先权主张。
