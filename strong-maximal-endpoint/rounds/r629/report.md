# 第629轮　中央宽度缺额分档的接收占据数判据

- A 的全部等权深度轮廓中央误差有界。
- 固定候选源后，选取一个窄缺额档所保留的接收份额可由同点实际占据的档数控制。档数接近满占据至次多项式因子时，所得子目录既保持中央对数精度，又有一致的小缺额振荡。
- 一般目录可能属于稀疏占档分支；一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定 $H$，将 $[0,p]$ 分成 $J=\lceil p/\epsilon\rceil$ 个宽度不超过 $\epsilon$ 的不交档（末档含右端）。$X_j$ 为该档矩形并。令 $N(x)=\sum_j1_{X_j}(x)$，$\bar N=|X|^{-1}\int_X N$。恰有 $\sum_j|X_j|=|X|\bar N$，所以至少一档的子目录覆盖 $\bar N/J$ 比例，且任一接收点处留下的实际缺额极差不超过 $\epsilon$。若初始目录在原成功源 $E$ 上严格成功，选档后仍用同一 $E,p$；接收对数增益损失最多 $\log(J/\bar N)$。取 $\epsilon=n^{-1/2}$、$p$ 中央，当 $J/\bar N=n^{o(1)}$ 时损失为 $o(\log n)$。这个结论控制振荡，不保证选中的缺额档接近零；修补该档所需的绝对费用还要由第625轮公式另行结算。

**一档选择的锐障碍。** 对任意基底目录 $(G,X)$，附加一条轴，分成 $J$ 个相邻等长区间 $I_j$ 铺满 $[0,1]$。目录为 $R\times I_j$，实际源为 $G\times[0,1]$。为使各基底行在候选源上确有同一档值，可直接取候选 $H=X\times A$，在每段 $I_j$ 内选比例 $p-d_j$，其中 $d_j$ 是第 $j$ 档内部的值。于是每行平均正好为 $p-d_j$。每档仅覆盖 $|X|/J$，$\bar N=1$，但每点本来就只有一个缺额值，局部振荡恒为零。该例候选质量为 $|X||A|$，未声称它是对中央目标有威胁的小质量候选。原成功增益保持，维数代价为 $O_I(1)$。因此仅用一个全局档不能一般性保住固定份额；多档若空间分离则可同时保留。

**可合并档的精确计价。** 建图，以档为顶点，当两档接收并有正测交且某对档值可能相差超过 $2\epsilon$ 时连边。独立集对应的子目录几乎处处振荡至多 $2\epsilon$。若给独立集赋非负权，使每个顶点被覆盖的权重至少一、总权为 $C$，则这些独立集的矩形并至少有一个覆盖 $|X|/C$：每个接收点任选一档，其所在独立集总权至少一，再积分。故即便 $\bar N$ 小，只要该冲突图的分数色数为 $n^{o(1)}$，也能在小振荡子目录上保住中央精度。真正未控制的是候选质量很小且占档稀疏、冲突图分数色数又大的目录；还需考虑小体积交叠造成的假冲突。
