# 第630轮　随机档尺度保留唯一命中档的接收份额

- A 的全部等权深度轮廓中央误差有界。
- 对任意有限目录和候选源，无需任何冲突图或重数假设，即可选出一个子目录及其接收子集，保留至少 $1/O(\log n)$ 的原接收体积，且该子集上所有保留见证的实际缺额振荡至多 $n^{-1/2}$。
- 这个结论仅控制所选接收子集上的振荡。一般系数差仍为 $(\mu-1)/8$；门槛缺额的绝对大小及子集外的修补费用仍须结算。

2026-11-13。沿用第629轮 $J=\lceil p/\epsilon\rceil$ 个档和各点命中档数 $1\le N(x)\le J$。置 $L=\lceil\log_2 J\rceil$，均匀抽取整数 $s\in[0,L]$，再以概率 $t=2^{-s}$ 独立保留每个档，档内所有行同留同删。令 $Z$ 为只命中一个保留档的接收点。条件于尺度，接收点进入 $Z$ 的概率是 $Nt(1-t)^{N-1}$，$N=t=1$ 时取一。针对该点，$s=\lceil\log_2 N\rceil$ 给 $1/2<Nt\le1$（边界亦可用 $\ge1/2$），$N\ge2$ 时 $(1-t)^{N-1}\ge(1-1/N)^{N-1}\ge e^{-1}$。取尺度期望后，每点进入概率至少 $1/[2e(L+1)]$。积分即知某个确定删档结果满足
\[
 |Z|\ge |X|/[2e(1+\lceil\log_2 J\rceil)].
\]
每个 $x\in Z$ 的所有保留行来自同一个档；它们在候选源上的缺额极差至多 $\epsilon$。原成功源上这些行的严格门槛保持。档号可以随接收点改变，因此第629轮单一全局档的反例不妨碍此结果。对 $p\in I,\epsilon=n^{-1/2}$，损失的对数接收体积至多 $O(\log\log n)=o(\log n)$。同样证明适用于带任意非负有限接收权的积分。

**对证明路线的影响。** 若能对任意这种接收子集 $Z$ 及保留见证给出中央精度上界，乘上上述对数因子仍得到总体中央目标。因此在允许接收子集的估计中，稀疏占档与高冲突色数不再是独立缺口。但不可将 $Z$ 擅自替换为保留矩形的整个并；多档相交处虽未计入 $Z$，仍可属于某个见证并影响源质量。还需在同一矩形中从小振荡推出绝对缺额或控制实际修补积分。这是下一轮的具体问题。
