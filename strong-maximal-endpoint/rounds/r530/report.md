# 第530轮　切片逆序费用的精确最优排列

- A 覆盖全部等权深度轮廓，中央误差有界。
- 对有限类型的指标切片，按横切片长度递增排序，同时使每一对类型的逆序代价最小。所得公式只依赖类型分布，不依赖条带在外区间内的原始位置。
- 下一步须估计近最优外区间上的切片不可比量，或用横区间平均代替集合对称差来降低费用。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。固定外区间 $J$，归一为均匀概率。横切片取可测集合 $A_i$，各类质量 $w_i$，均位于长 $L$ 的区间。若类型 $i$ 排在 $j$ 之前，其对第529轮逆序量的贡献为 $w_iw_j|A_i\setminus A_j|$。与反向费用之差是 $w_iw_j(|A_i|-|A_j|)$。因此按长度递增即同时选中每对较小费用；拆分或交错同一类型只能产生两种方向费用的凸组合，不能更低。最优值为
\[
 H_{\min}=\sum_{i<j}w_iw_j\min(|A_i\setminus A_j|,|A_j\setminus A_i|)
 =\tfrac14\mathbb E[|A\triangle B|-||A|-|B||],
\]
其中 $A,B$ 是独立的均匀切片。等长类型任意排序均可。$H_{\min}=0$ 当且仅当所有正权类型按几乎处处包含关系构成链。有限矩形并在任一固定外区间上均属有限类型。按排序后参数做第529轮的分层抽样，再在抽得的类型内按其原始条件分布取实际纵坐标，随机置换后各边际仍是 $J$ 上均匀律。固定 $J$ 的共同区间平均和逐切片最优值积分均未变，故第529轮误差界中的 $H$ 可直接替换为 $H_{\min}$。不同外区间的最优排序允许不同；这里没有为纵向极大算子作全局重排。

**判据的适用边界。** 高不可比量仍可能与零选择损失共存。例如等权切片 $A=[0,1]\cup[2,3]$，$B=[0,1]\cup[-3,-2]$，则 $H_{\min}=1/4$。对每个 $x\in(0,1)$，共同内区间可取 $[0,1]$，两切片平均同时等于一，真实损失为零。把远处两个独占段等量加长，可任意增大 $H_{\min}$ 而保持该接收区域的零损失。所以逆序量小给出抽样逼近的充分条件；不能仅凭它大就进入有正选择缺额的分支。

本机 Python 用有理数对五种切片的全部120种排列核验公式。
