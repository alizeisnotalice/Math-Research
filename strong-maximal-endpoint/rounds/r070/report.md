# 第70轮：局部成本筛选的精确指数门槛

日期：2026-11-08。状态：局部成本算子的精确 Lᵖ 范数、单列弱准范数、筛选方法障碍和充分弱型指数准则已证明并审查；多核搜索与跨软件核验完成。尚未证明该算子的全输入弱型界，一般 C_N 锐上界仍开放。

## 1. 完整标签成本算子的精确事实

保留第69轮的共同参考动作和真实源成本 G=Φ_N(F)。在全局重心坐标、物理权测度 dν=e^(−u)du dH dλ 下，定义

\[
 \mathcal J_cG(u,X,\sigma)=\int_0^\infty e^{-s}
 K_c^sG_{u+s}(X,\sigma)ds.
\]

本轮证明，对每个 p>1、每个有限正 c，连同无标签极限，

\[
 \boxed{\|\mathcal J_c\|_{L^p(\nu)\to L^p(\nu)}=p/(p-1).}
\]

上界由条件角核收缩与径向平移得到；长径向指数轮廓乘大角球给出精确下界。并非只得到了一个可能很松的Minkowski常数。

归一化单个源原子后，其完整标签场的弱L¹准范数恰为1。Haar标签的高度2^N因子与接收壳测度2^(−N)因子必须同时保留。这个逐列事实不能相加成任意源的弱型定理。

c=∞时算子化为显式乘法核

\[
 \mathcal J_\infty F(x)=\int_{(0,1)^N}
 \frac{(N-1)!}{[-\log\prod r_i]^{N-1}}F(x_1r_1,\ldots,x_Nr_N)dr,
\]

并有参数 λ≥1 的张量Hardy正混合，混合密度为(N−1)(λ−1)^(N−2)/λ^N。条件总和核不构成加法半群：其协方差正比s²，卷积给s²+t²，与(s+t)²不同。有限c在s+t<c时也有同一反例。因此不能直接套用半群端点定理。见 [kernel70.md](kernel70.md)。

## 2. 单次 Lᵖ 筛选的损失无法靠调参消除

对0≤G≤M、H=log(M/t)≥1，Chebyshev给出

\[
 \nu\{\mathcal J_cG>t\}
 \le\frac{J(G)}t (p')^p e^{(p-1)H}.
\]

在所有p>1中优化后，最小系数精确为

\[
 \boxed{C(H)=e q,\qquad q-\log q=H+1,\ q>1;\qquad C(H)\sim eH.}
\]

取p=1+1/H也可给显式上界2e(H+1)。当F≤A固定、M=Φ_N(A)、t=J_ref N^ε时，H=Θ_A(N)，所以这种最优单次Lp筛选仍仅能认证坏集体积

\[
 O_A\bigl(Q_{\rm ref}N^{1-\varepsilon}J(G)\bigr).
\]

要使该上界为低阶需要ε>1；第69轮在K趋近κ时要求ε<2κ，而2κ<1。因此单次Lp–Chebyshev筛选不足以闭合预算桥。这只是方法障碍，不是实际弱型常数必须增长如N的反例。此截高筛选也不处理无界输入。

## 3. 所需弱型目标可放宽到一个明确指数

若未来证明实际有限参考动作、完整标签下

\[
 \nu\{\mathcal J_cG>t\}
 \le N^{\gamma+o(1)}J(G)/t,
\]

则可取γ<ε<2K，结合第69轮捕获与第68轮输运。条件预算路线的最优对数系数为

\[
 \boxed{\max\{\kappa,\gamma/2\}.}
\]

因此只需γ≤2κ即可保持参考系数。γ=2κ时，对每个固定δ>0取K=κ+δ、ε=2κ+δ，先令N趋于无穷再令δ下降；坏集指数为−δ，捕获损失为δ。

偏移参考动作的κ=α=(9−μ)/24，故所需门槛为

\[
 \boxed{\gamma\le(9-\mu)/12=0.643461288103\ldots.}
\]

一个真正成立的O(√N log N)弱型界就已足够，不必先追求维数无关。但本轮没有证明这一弱型界，也没有完成变动作到参考均值1−o(log N/N)的共同源比较或移动锚点分配。固定动作本身仍有第28轮更强的精确结果。详见 [screening70.md](screening70.md) 和 [独立审查](review70.md)。

## 4. 本机搜索与交叉核验

Python 3.12.14、SciPy 1.18.1，12进程运行24组有限对数网格MILP。维数2、3；包含c=μ的偶输入和单侧极限，允许网格内相关源质量和多角位置接收集合。每例8秒、2000节点、目标相对gap为1%。5例达到设定gap，19例限时；最大剩余gap约1.463。全部24个incumbent通过独立原始残差检查。

最大配点比值约0.996654，没有发现大于1的候选。它既不是连续模型下界证书，也不是网格或全算子的上界：接收值只在角点配点，且目标是固定预算下的接收体积。矩阵删除小于10^(−14)的正系数；在源质量和≤1时每行此项损失至多10^(−14)，另有浮点求积误差。限时解可随调度改变，未作随机采样。

正式搜索约17秒，实测CPU峰值1192.1%（12核满载约1200%），RSS峰值约3.57GiB。HiGHS内部诊断行保留在工作日志中，不当作最优性证据。

Mathematica 15、12内核独立计算96项网格积分核（50/100位）和56项筛选常数（60/120位，维数256至1048576），并逐例检查基本常数、正态分位数和优化根残差。48组核精度配对、28组筛选精度配对、48项跨软件核比较全部通过，后者最大相对差约1.56×10^(−15)。正式Wolfram日志无警告。初次符号器未化简的幂不等式检查已改成边界值与导数界的可核查分步证明。

在A=2、ε=1/2、N=1048576的规范模型阈值下，最优单次筛选系数约4.89844N；这里使用的是参考渐近阈值，不冒充精确Q_N值。所有自有批处理已退出，未保留MATLAB或Wolfram计算进程。无定向舍入总认证，未登记新认证C_N下界。见 [validation70.json](validation70.json)。

## 5. 一般账本、来源及下一轮

一般账本仍为Q_N≤C_N≤R_N，log Q_N=q0+(9−μ)L/24+o(L)，log R_N=q0+(3+μ)L/12+o(L)。系数间隙(μ−1)/8及log C64>71.79认证未变。本轮成果是精确算子事实、有适用范围的筛选方法障碍，以及降低了强度要求的条件弱型目标。

下一轮两项动作：

1. 针对实际有限c完整标签核，寻找γ≤0.64346的弱型证明或多尺度源叠加反例；单原子与坐标盒不能替代全输入检验，限时网格未构成排除证书。
2. 保留接收效率信息研究带内动作比较及停止分配；若全输入弱型太强，需证明适用于实际接收主体的替代筛选，仍须结算余集、无界振幅和移动锚点。

本轮以内部第28、67—69轮为主要依赖。外部检索候选没有提供可直接套用的同核端点定理；被排除候选与实际阅读范围列于 [sources70.md](sources70.md)，不据此宣称文献穷尽或公开优先权。
