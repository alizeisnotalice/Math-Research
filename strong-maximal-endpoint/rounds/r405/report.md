# 第405轮　部分源外冲突边的局部排除

- A 已覆盖全部等权深度轮廓。对一般有限目录，可禁止任意指定的源外冲突边，同时保持精确缩放边际；不需要把禁止关系划成互不相交的组。
- 若禁止邻居的最大总权与未禁止碰撞费除以源质量均为 $n^{o(1)}$，同门槛取整只损失 $o(\log n)$。
- 尚缺一般中央目录上满足两项预算的选边定理。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。取第402轮的最优源 $E_*$ 与非负最优权 $z_i\le1$。在行上指定简单图 $G$，令 $D=\max_i\sum_{j\sim i}z_j$，$C_0=\sum_{i<j,\,i\not\sim j}z_iz_j|(R_i\cap R_j)\setminus E_*|$。先独立提议每行，概率 $rz_i$，其中 $r=1/[8(1+D+C_0/M)]$，$M=|E_*|$。只保留被提议且无提议邻居的行。行 $i$ 的保留概率至少 $rz_i(1-rD)\ge rz_i/2$。再以独立硬币逐行稀释，使其最终边际恰为 $rz_i/2$。图边两端绝不同时入选，任意非边同时入选概率至多 $r^2 z_i z_j$，因为两端均须先独立提议。

固定源内一点，自活跃行中取权和 $s\in[1,2]$ 的子集（负载至少一，每权至多一）。二阶容斥给最终命中概率至少 $rs/2-r^2s^2/2\ge r/2-2r^2$。源外重复覆盖期望积分至多 $r^2 C_0$。由精确缩放边际及饱和行等式，源外一次覆盖项与线性行费用抵消。因此
\[
 L_*(p)\ge (r/2-2r^2)M-r^2 C_0\ge rM/4.
\]
最后一步用 $r(2+C_0/M)\le1/4$。与裸碰撞费相比，该证书允许少量总邻权承载任意大的交体积。第403轮例中禁止每条臂内部的三条配对边，得到 $D=1,C_0=0$，统一给出常数倍保证；第404轮的专用取整可得更优常数。下一步应按盒对交体积与邻权的比值选择边，并检验那些同时具有高邻权和高残差的行能占多少实际接收体积。
