# 第518轮　平移矩形筛选同时保留真实源与接收面积

- A 覆盖全部等权深度轮廓，中央误差有界。
- 任意平面矩形及任意可测指标源均可筛选，无需二进投影。在原门槛 $p$ 下同时保留 $\lambda/6$ 的接收面积和 $p-\lambda$ 的不交源分配系数。
- 下一步需控制高维截面中筛选所需的接收代价，避免每次降维累积固定损失。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。有限成功矩形按横宽递减扫描；取 $0<\lambda<p$，当且仅当与已选并的重叠面积至多 $\lambda|R|$ 时入选。记原并 $G$、入选并 $G'$。每个入选矩形新面积与真实源 $E$ 的交严格大于 $(p-\lambda)|R|$，因为原源平均严格超过 $p$。按入选顺序这些交互不重叠，因此同时可支付任意可行包围对偶权重的 $p-\lambda$ 倍。

**接收恢复。** 将每个入选盒的横投影同心放大三倍、纵投影不动，所得并为 $D$。逐水平截面，按原区间并的连通分支分组，每个同心三倍区间仍在其分支的同心三倍区间内，故 $|D|\le3|G'|$。若 $I\times J$ 被拒，收集先前与其相交的入选矩形；它们的横区间长至少为 $|I|$，故三倍横区间都包含 $I$。其纵投影在 $J$ 内的并长严格大于 $\lambda|J|$，否则二维重叠面积不可能超过 $\lambda|I||J|$。于是对几乎所有 $x\in I$，$D_x$ 在 $J$ 内的密度严格大于 $\lambda$。入选行也满足该密度条件。逐垂直切片用第467轮的一维区间覆盖界得到 $|G|\le(2/\lambda)|D|\le6|G'|/\lambda$。这一步只用于接收恢复；实际分配仍使用原矩形内部的源。取 $\lambda=p/2$ 即同时保证 $p/12$ 的接收份额与 $p/2$ 的分配系数。

对 $I\times B$ 型一般 $n$ 维见证，相同的横向放大与投影论证给 $|G|\le3 H_{n-1}(\lambda)|G'|$，因为被拒见证的基底投影并占 $B$ 的比例超过 $\lambda$。所以此证明推广时，接收费用会含低一维的一般 halo 常数，尚未达到中央次对数精度。此估计也说明仅把平面结论逐维套用不足以闭合上界。
