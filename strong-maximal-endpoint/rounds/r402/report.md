# 第402轮　无自交的源外碰撞费与逐块取整

- A 已覆盖全部等权深度轮廓。对固定最优源与对偶，给出保持门槛的子集证书，费用仅取决于不同正权见证的源外交叠，不依赖总斜率。
- 对源内的单位权覆盖另作精确结算，第401轮的大斜率星形块由此无损。
- 一般中央上界仍需对不可分目录的源外碰撞费获得统一控制。
- 一般系数差仍为 $(\mu-1)/8$。

2026-11-13。记 $M=|E_*|$，$z_i\in[0,1]$ 为最优对偶，$S=\sum z_i1_{R_i}$。定义
\[
 C=\sum_{i<j}z_i z_j|(R_i\cap R_j)\setminus E_*|.
\]
对 $0\le c\le1$ 以概率 $cz_i$ 独立选行。源外二阶容斥给覆盖概率下界 $cS-c^2\sum_{i<j}z_i z_j1_{R_i\cap R_j}$。源内保留精确乘积，利用第400轮的饱和行等式抵消线性费用，得到
\[
 L_*(p)\ge\int_{E_*}\Big[1-\prod_{i:x\in R_i}(1-cz_i)\Big]dx-c^2 C
 \ge (1-e^{-c})M-c^2 C .
\]
特别 $c=M/(M+2C)$ 给出 $L_*\ge M^2/[2(M+2C)]$。若 $C=0$ 且几乎每个源点都在某个单位权行内，取 $c=1$ 的第一式给出等号 $L_*=M$。星形构造取所有行权一满足这两个条件，不论其最优斜率多大。

按盒间正体积交的连通分量 $b$ 分解，$M=\sum M_b$ 且 $L_*=\sum L_{*,b}$，因为源容量与选行均可分开优化。各分量可独立选最优对偶、原始源与参数 $c_b$。例如若除总最优质量至多 $\eta M$ 的分量外均有 $C_b\le K M_b$，则 $L_*\ge(1-\eta)M/[2(1+2K)]$，即使异常分量有巨大碰撞费。该陈述控制证书而非直接控制接收体积。

计算 $C$ 时无需先固定最优源在单位负载层的取法。给定最优 $z$，在原子标签 $T$ 上其系数为 $h_T=\sum_{i<j\in T}z_i z_j$（和遍历 $T$ 内无序对）。在所有原始最优解上最小化 $C$ 等价于最大化 $\sum h_T x_T$，其中 $x_T$ 为源在各原子上的质量。这是具有原容量、行需求及 $\sum x_T=M$ 的有限线性规划。下一步须检验最小化后的 $C/M$ 是否仍会在高体积不可分目录上增长。
