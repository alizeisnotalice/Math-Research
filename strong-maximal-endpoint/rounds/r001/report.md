# 第 1 轮：基线复核与可复现单层对照

日期：2026-11-06（Asia/Shanghai）。状态：本轮完成基线审计与数值对照；没有宣称新的次项突破。

## 1. 已闭合结论与证明状态

记 \(\mu=\log B\)、\(\sigma=\sqrt\mu\)，B 为 \(\log B=1+B^{-1}\) 的唯一正解。

**可复核的一般结论（依赖已核验的 GMS 锐强型定理）**：
\[
\lim C_n^{1/n}=B,\qquad \limsup C_n/B^n\le\sqrt B.
\]
**本轮确认的障碍**：固定盒包含本身不足以证明附件的全空间双曲族体积比上界。因此不把全局 H_n 的三项展开登记为本项目已证定理。

### 指数率下界：只需构造矩形，不需最优矩形重排

对固定 r，\(Z_r=Y+(-\log r)J\)，其中 Y 是 Exp(1)，J 的成功率为 r/(1+r)，两者独立。
其均值 \(m(r)=1-r\log r/(1+r)\)，方差 \(v(r)=1+r(\log r)^2/(1+r)^2\)。
在 \(r=B^{-1}\) 唯一最大化均值，且 \(m=v=\mu\)。

在 x 属于单位方体且坐标非零处，取每条边连接 \(-rx_i\) 与 \(x_i\) 的矩形。
令 T 为 n 个增量之和。如果 \(P(T\ge q)=a\)，则对任何 \(\alpha<a\)，集合 E_(L-q) 中的这些矩形平均严格超过 alpha。
由精确 Gamma 体积公式，固定 n,q 后令 L→∞ 得
\[
 C_n\ge {a e^q\over(1-\log a)^{n-1}}.
\]
严格超水平事件通过 alpha 从下趋于 a 处理。对最优均值参数，存在维数无关的小参数指数矩，Chernoff 估计允许取
\(q=n\mu-K\sqrt{n\log n}\) 且 \(a\ge1-n^{-2}\)，K 为足够大的常数。
因而 \(\log C_n\ge n\mu-O(\sqrt{n\log n})\)。本段不需要控制方体外 halo，也不需要证明本轮数值优化的全局最优性。

### 一般上界与前因子

GMS 定理给 \(\|M_S\|_p=c_p^n\)，其根方程等价于
\(p(1-e^{-b_p/p})=1+e^{-b_p}\)、\(b_p=p\log c_p\)。
隐函数展开给 \(b_p=\mu+\mu/(2p)+O(p^{-2})\)：展开左边为 \(b-b^2/(2p)+O(p^{-2})\)，在 b=mu 处方程导数为 \(1+e^{-\mu}=\mu\)，所以一阶修正为 mu/2。

固定 a>0，将 f 按振幅切成 f0（≤e^a）、f1（e^a 到 e^n）及 f2（>e^n），分配阈值 \(1-2n^{-2},n^{-2},n^{-2}\)。
对 f0 取 \(p_n=1+(n-1)\log(1+a)/a\)。由 log(1+u) 的凹性，\(t^{p_n}\le\Phi_n(t)\) 于 0≤t≤e^a。
锐强型给此段系数
\[
 B^n\exp\{\mu a/(2\log(1+a))+o(1)\}.
\]
对 f1 取固定而充分大的 p，使 \(e^{b_p}/(1+a)<B\)。函数
\((p-1)u-(n-1)\log(1+u)\) 为凸函数，在 u∈[a,n] 用端点控制。
阈值产生的 \(n^{2p}\) 不影响 n 次根；左端点底数为 \(e^{b_p}/(1+a)\)，右端点 n 次根趋零。
对 f2 使用下述截断核，取 r=1/2；u≥n 时核对模数之比的底数一致有界，而阶乘使总系数 n 次根趋零。
因此两尾贡献相对于 B^n 趋零。先 n→∞ 再 a↓0，得到 sqrt(B) 前因子上界。
分段输入不相交，故各段模数积分之和等于原模数；这一步不需要对总 f 的模数另用次可加性。

### 截断核和定位

令 a_r=2/(1-r)。一维弱(1,1)常数 2 和截断给
\[
D_{M_i h}(s)\le a_r s^{-1}\int_{rs}^{\infty}D_h(t)\,dt.
\]
反复交换非负积分，最后以 \(\int_{sr^n}^g\log(t/(sr^n))^{n-1}dt\le g\log(g/(sr^n))^{n-1}\) 放宽，得到
\[
 |\{M_Sg>s\}|\le {a_r^n\over s(n-1)!}
 \int_{g>sr^n}g\,[\log(g/(sr^n))]^{n-1}.
\]
只用了 \(M_S\le M_1\cdots M_n\)，方向为有效上界。

对 \(g=f1_{f>e^{A\rho_n}}\)、\(\rho_n=\sqrt{\log n/n}\)，在 e^sqrt(n) 再切分。
中段于 s=n^-1/2 使用 \(p=\sigma\sqrt{n/\log n}\)，同样以凸性取端点。
下端对数系数为
\[
 nb_p+\tfrac p2\log n+(p-1)A\rho_n-(n-1)\log(1+A\rho_n)
 =n\mu-(A-\sigma)\sqrt{n\log n}+O_A(\log n).
\]
右端为 \(-\tfrac12n\log n+O(n/\sqrt{\log n})\)，更小。
大段取 r=1/2，系数
\[
K_n={\sqrt n4^n\over(n-1)!}
\left({\sqrt n+n\log2+\tfrac12\log n\over1+\sqrt n}\right)^{n-1}
\]
满足 \(K_n^{1/n}=O(n^{-1/2})\)。合并即得附件的定位引理。
剩余未解核心是有界振幅与阈值 1−2/sqrt(n) 的统一估计；定位本身不提供负次项。

## 2. 双曲族三项公式的缺口

附件用 halo 包含于 [-R,R]^n（R=2/alpha−1）后写出相对体积≤max(exp(qmax),R^n)。
仅由盒包含不能推出此界：\(|[-R,R]^n|/|E_L|\) 随 L 发散（n=1 已为 R exp(L)）。这指出的是论证缺口，不是最终不等式的反例。
还需全空间分层/重排论证、有限 L 的统一处理和三角阵一致中偏差误差。
特别地，普通 Berry–Esseen 的绝对误差不能直接用于 sqrt(log n) 窗口的尾相对误差；必须实际完成指数倾斜后的比较。
