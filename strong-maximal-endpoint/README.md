# 非中心强极大算子端点常数

全部资料入口见 [CONTENTS.md](CONTENTS.md)，原始附件及历史工作档案均在本项目目录内。
研究对象为 Lebesgue 测度下轴平行非中心强矩形极大算子，统一使用
\(\Phi_n(t)=t(1+\log^+t)^{n-1}\)、自然对数及阈值 1。
本项目研究最优比值 \(C_n=\sup_f |\{M_Sf>1\}|/\int\Phi_n(f)\)。
