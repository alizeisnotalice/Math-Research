# Astra upper 001：先积分时间、结构天花板与精确矩接口

范围：独立标准 α=3/2 stable、16 条未单位化体对角方向、cube [-1,1]^5。
主 clone 只读；本轮只写本目录，不提交。已读仓库 AGENTS.md 和父任务指定的
transfer、round009 短时、round005 中段预算、round004 两个模型排除报告。

先验问题：全域 g=1/10000 尚未认证。现有逐时指数倾斜下界仅约 1.543e-5；
本轮不重复该倾斜优化或任何已做 QMC 批次。

本次有限验证预登记：

1. 用 Python exact integer/rational 检查 16 个方向 tight frame、一个 det-48 五基、
   其 16 个符号反射基的方向覆盖次数。由这些事实和 Hölder 推导 p_1(0) 上界。
2. 用 256-bit Arb 对先积分时间后的 trace-Jensen 机制天花板作一次向外舍入比较，
   只比较 < 84/1000000 < 1/10000。此为方法排除，不是 G 或 C5 的上界。
3. 用 SymPy/Fraction 对负幂径向倾斜后的 normalized stable 权重生成函数，
   计算有限的 0--6 阶单相关矩，以及三个预定三、四阶联合矩；以独立的 Laplace
   导数公式交叉核验 1--4 阶同坐标及两坐标权重矩。
4. 写清保留整个矩阵相关性的多项式 minorant 接口、有限维确切矩和全域 positivity
   的验证义务；不宣称已经找到可达 g=1/10000 的 minorant。
5. 首轮 1--4 检查完成后，新增有限验证：枚举恰好 C(16,5)=4368 个五方向子集，
   用整数 Bareiss 算法求行列式；通过子集包含计数而非抽样，精确算
   E_R det(M)^2。验证全域多项式 minorant det(M)^2/35，作为新矩接口的
   实际落地证书。只运行这一固定次数，不搜索更高次数或扩充空间点。

不运行新增 Monte Carlo / QMC，不扩大既有数值搜索。数学计算实际使用本机
Python（SymPy 与 python-flint/Arb）；MATLAB 由主代理统一，当前子任务不占用。
