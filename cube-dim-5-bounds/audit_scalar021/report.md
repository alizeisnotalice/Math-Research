# scalar021：给定标量上包络族不能改善 J* 的独立有理证书

结论：双点概率测度 ν 满足所需一、二阶矩，且
`Eν d^(−3/14)<12/5<Q*`、`Eν d^(−3/20)>17/10>J*`。
因此任何在 `(0,1]` 全域有效的包络

`d^(−3/20) ≤ αd^(−3/14)+A+Bd+Cd²`，`α≥0`，

经给定矩 m,s 和上界 Q* 直接代入所得成本
`αQ*+A+Bm+Cs` 必须严格大于 `17/10`，无法改善当前 `J*<17/10`。
这是该标量包络/矩族的障碍证书；ν 不声称是真实 det(M) 分布，也不是 C5 结论。

## 1. 双点测度与正矩的精确核对

固定

```
δ = 1/4000,
m = 648/1463,
s = 126404864/474619145,
t = (s−mδ)/(m−δ) = 101081847016/168081812171,
p = (m−δ)/(t−δ) = 62203164779432261/84469295006632261.
```

取 `ν=(1−p)δ_δ+pδ_t`；p 为高点 t 的概率。精确有

```
t−δ = 404159306251829/672327248684000 > 0,
1−t = 66999965155/168081812171 > 0,
1−p = 22266130227200000/84469295006632261 > 0.
```

连同 δ>0、p>0 即得 `0<δ<t<1` 和 `0<p<1`，所以 ν 是支撑于标量
区间内部的概率测度。其矩由定义直接化简：

`Eνd=δ+p(t−δ)=m`，
`Eνd²=δ²+p(t−δ)(t+δ)=δ²+(m−δ)(t+δ)=s`。

一次独立 Fraction 计算也把两条矩残差都精确算为零。
这里审计的是 ν 与给定 m,s 的匹配；没有重新推导实际 det(M) 的矩公式。

## 3. 锁定源球与包络族的简洁证明

Q* 仅从已认证 round011 结果球读取，J* 仅从主 round006 orbit 结果球读取：


脚本把显示中点与半径都解析为精确十进制有理数，直接核对
`lower(Q*)>12/5`、`upper(J*)<17/10`。没有重跑旧 Gamma 基线。
这些比较继承源球的认证含义；本审计只复核球端点的有理比较。

现令 `f(d)=d^(−3/14)`、`g(d)=d^(−3/20)`。将任何所述全域包络对 ν 积分：

`Eνg ≤ αEνf+A+Bm+Cs`。

所以

```
αQ*+A+Bm+Cs
≥ Eνg+α(Q*−Eνf)
≥ Eνg
>17/10
>J*.
```

第二步使用 α≥0；`Q*−Eνf>0` 已由前面的严格有理间隔保证。
A、B、C 可以是任意实数，不需要非负。

## 4. 范围与限制

证明覆盖：在整个 d∈(0,1] 有效（实际上只要在 δ,t 两点有效）的此四项
包络，以及仅用 `E d=m`、`E d²=s`、`E f≤Q*` 直接代入产生的成本。
不要求主 LP 已找到或已认证任何包络；每个真正全域有效的候选都受此结论约束。

它不覆盖加入其他矩、矩阵几何、形状/空间耦合或不同函数基后的族，
也不覆盖只在更小真实支撑集上有效、而该集合未必含 δ,t 的不等式。
ν 只是标量矩问题的抽象见证，不能据其负矩给真实分布作下界。
这不是对实际 J、I、目标 C5 或其他上界路径的不可能性证明。
