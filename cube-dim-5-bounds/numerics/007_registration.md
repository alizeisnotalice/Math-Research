# 第 007 批：单一有理点的完整截时热核区间证书

固定 \(\epsilon=1/128,T=1,d=24,N=25,\rho=49/10\)，仅对 002-G 的首个
有理点 \((1,936/1009,673/1009,68/1009,917/1009)\) 操作。空间变量不扫描，
不涉及 \(g\)、\(I\) 或全域常数。

每段 \([a,2a]\), \(a=2^{-7+k}\), 使用 Fejér 第一型节点

\[
 \theta_j=\frac{(2j+1)\pi}{2N},\quad
 t_j=a\left(\frac32+\frac12\cos\theta_j\right),
\]

和题定权重

\[
w_j=\frac aN\left[1-2\sum_{k=1}^{12}
 \frac{\cos(2k\theta_j)}{4k^2-1}\right].
\]

Arb 256-bit 先证明每个权重正，并把每个时间和权重转换为包含 Arb 球的
binary64 位模式区间。C++ 从这些位模式读取 \(t_j,w_j\)，以 005b 的逐操作
outward 核计算 \(\sum w_jp_{t_j}(x)\)，而不调用 `libm cos`。

对 \(\rho=49/10\)，由复时间峰值假设，插值误差按

\[
E=\sum_{k=0}^6 a\frac{4C_{\rm peak}\sigma^{-5}\rho^{-24}}{\rho-1},\quad
\sigma=a\left(\frac32-\frac{\rho+\rho^{-1}}4\right),
\]

计算；尾只加非负区间 \([0,C_{\rm peak}/4]\)。最终比较独立 Arb 直接
Hermite 公式的 \(H_{1/128}\)。本批软限 120 秒、固定 175 节点。

## 实际运行（2026-10-25）

Arb 输入生成实际完成 175 个节点；所有权重严格为正，最小 Arb 权重为
`[2.6886679813242159397755116805636e-5 +/- 8.01e-80]`。位模式输入文件
`007_fejer_nodes.bits` 的 SHA-256 为
`8152b6ec23d0072a8cfe47ff24ed0751798775cfe3a1e1b69a2c680e0cb6521a`。

Arb 256-bit 计算的条件性插值误差为
`[2.15465358660105977098780409006e-12 +/- 7.50e-87]`，而非负尾的上端为
`[3.79491144087359296106528568172e-8 +/- 4.13e-85]`。

在 `aarch64_fpcr_0x0`、`FE_TONEAREST` 的 005b 浮点环境检查通过后，175 个
节点的 C++ 区间求和实际耗时 `3.71651 s`。四则核输出的位模式积分为

```text
[0x3f23280a2f93e82e, 0x3f23280a2f9aa51f].
```

将插值误差双侧加入、尾仅向上加入后，最终位模式包围为

```text
[0x3f23280a2ad6f1df, 0x3f2329502f53cbc2]
= [0.0001461517726236835, 0.00014618972605936863].
```

独立实际重算的直接 Hermite/Arb 值

```text
H_(1/128) = [0.000146188413048356738861943000777... +/- 8.39e-75]
```

位于该包围内。此结果是**单点**截时热核区间证书，且仍条件于文首复时间
`Cpeak` 不等式及 005b 的 binary64 环境假设；绝不蕴含空间统一性、`g`、`I`
或 `C5` 的新界。一次已修正的错误后处理另记于 `007_invalid_attempt_note.md`。
