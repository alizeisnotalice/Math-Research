## 2. 唯一二节点Gauss公式及全域Hermite下函数

记 `Delta=m0*m2-m1²=22550464/916620705>0`。准确解正交二次式

`p2(t)=t²-A*t+B`，

`A=(m0*m3-m1*m2)/Delta=8738193344/17626358775`，

`B=(m1*m3-m2²)/Delta=379983689744896/17097021594627975`。

程序准确核 `E p2(d)=E d*p2(d)=0`，残差均为0。判别式为正，
其平方根以分母 `10^80` 的整数平方根隔离；由准确p2端点符号，
得到两个互不交叠、包含唯一根且位于 `(0,1)` 的有理区间。
384-bit Arb完整球显示节点与正权重为

| 项 | 显示值 |
| --- | ---: |
| x1 | 0.04984301563450718633079171089797... |
| x2 | 0.44590278504632571586911259123149... |
| w1 | 0.80522861116598456923699399843582... |
| w2 | 0.19477138883401543076300600156418... |

准确权重定义为

`w1=(m0*x2-m1)/(x2-x1)`，`w2=(m1-m0*x1)/(x2-x1)`。

根隔离准确证明 `x1<m1<x2`，所以两权重严格为正。公式先匹配
m0、m1；利用 `xi²=A*xi-B` 及上述正交等式，再准确匹配m2、m3。
因此每个次数不超过3的多项式h都满足
`E_R h(d)=w1*h(x1)+w2*h(x2)`。

令 `f(t)=t^(-1/10)`，则

`f''''(t)=7161/10000*t^(-41/10)>0`。

在两个准确节点各匹配值与导数的三次Hermite插值h满足

`f(t)-h(t)=f''''(xi)/24*(t-x1)²*(t-x2)²>=0`，`0<t<=1`。

对任何给定正t，可在包含t及两个节点的正闭区间应用余项式；即使t
在节点外或接近0，符号仍正确。因而这是整个 `(0,1]` 的下函数。
积分并使用三次精确求积给

`J=E_R f(d) >= w1*f(x1)+w2*f(x2)=J_G`。

没有把旧加权sqrt(d)的结论转抄到此处，也没有把Gauss值作为真实J上界。

## 3. 完整数值与严格成本门比较

对节点和权重先作有理外包；再对每个 `x^(-1/10)` 用整数10次根
比较，准确验证上下端的10次幂与 `1/x` 的方向。所得 `J_G` 有理
上下界保存在results。独立从准确A、B计算的384-bit Arb完整球为

`[1.297977754543376579624205106560004201288597559940966707732126950827956440977933798686644587759192417137448114706670 +/- 6.68e-115]`。

该球严格在独立有理上下界之间。

纯Minkowski的alpha1表达式为

`I_M=c1^(5/4)*(pi²/60)*J^(5/4)`，`c1=1/(32*pi³)`，

所以 `I_M^4=J^5/(60^4*32^5*pi^7)`。成本预算为
`cost_M^4=3125*I_M^4/g0^5`。于是若要让**这个预算**成本不超过32，
必要条件是

`J <= J_gate = g0*(60^4*32^9*pi^7/3125)^(1/5)`。

这是从准确表达式推导的门，没有从展示用1.3小数造证书。pi采用主
`round010/orbit_budget.json` 完整Machin80有理区间；五次根再以整数
比较包围，独立Arb球为

`[1.34533604656775991788655218893823271516399080778197468252102753630085281250385829751133253469606539429551502501379 +/- 2.10e-114]`。

`J_G_upper<J_gate_lower` 由完整Fraction严格比较验证。将J_G下端
代入纯Minkowski成本表达式仅给约30.598177990856243的成本下界，
小于32，因此同样不能排除。该表达式的下界不是实际I或实际C5的下界。

主010的完整Jflag和currentI区间仅按源分数读取作为上下文；没有重算
