# upper_cover013：直接 Lebesgue 覆盖的局部严格余量与全局传递缺口

## 本轮结果

固定 Lebesgue 测度上的五维中心立方体极大算子 \(M\)，所有坐标使用同一半径。
本轮不使用 stable--Green、Young minorant 或负矩机制。

证明了一个对 160 个中心坐标的开放参数类成立的局部定理：32 个等半径立方体
\(Q_\epsilon=B_\infty(c_\epsilon,r)\)，\(\epsilon\in\{-1,1\}^5\)，若
\[
 \frac r2<\epsilon_j(c_{\epsilon,j}-c_{0,j})<r
 \quad(\text{每个 }\epsilon,j),\qquad
 \frac1{|Q_\epsilon|}\int_{Q_\epsilon}f>\lambda,
\]
则对 \(U=\bigcup_\epsilon Q_\epsilon\)，
\[
 \boxed{\lambda\,|\{Mf>\lambda\}\cap U|
 \le\frac{256}{9}\|f\|_1,\qquad \frac{256}{9}<32.} \tag{1}
\]
这是对**真实接收域**的统一正余量，不只是重叠函数的几何改进；对中心的小扰动稳定。
但右端仍是整份输入质量，不能把任意多个这样的包相加。尚未构造适用于所有输入和尺度的
全局选择/质量分配，因此本轮**没有证明 \(C_5<32\)**。

同时给出：

- 一个可传递到一般 \(L^1\) 的有限分包/拥挤度证书条件；尚未证明该选择条件总能实现。
- 绝对连续的紧支撑输入反例：32 个中心的非零邻域都在 \(\{Mf>1\}\)，而共同交点 0
  满足 \(Mf(0)<1\)。所以不能直接把共同交点改选成新的“好 cube”中心。
- 一个准确的退化族：见证 cubes 并集的体积/输入质量比趋于 32，但真实接收域的该比值趋于 1。
  因而必须利用接收域信息，不能只在后段重叠或并集估计中扣一个固定几何量。

## 1. 已读公开来源及适用对象

重新阅读 Aldaz [*Kissing numbers and the centered maximal operator*, arXiv:1811.10478v2](https://arxiv.org/html/1811.10478v2)
的 Definition 1.1、Theorem 1.2/2.5、Lemma 2.6 证明、Theorem 3.3 与 Corollary 3.5。
其 uniform 范围是 \(\tau\)-additive 局部有限 Borel 背景测度，在 \(\mathbb R^5\) 包括所有 Radon 测度。
\(2^5\) 尖锐性对这个背景类取上确界；Theorem 3.3 的达到构造使用离散背景测度。
固定 Lebesgue 测度包含在上界适用范围内，不能由此推得 Lebesgue 的等号。

Lemma 2.6 的关键链是
\[
 |E|\le|\bigcup Q_i|\le\sum_i|Q_i|
 <\lambda^{-1}\int f\sum_i1_{Q_i}
 \le32\lambda^{-1}\|f\|_1. \tag{2}
\]
原文同时处理背景测度的离散化；这不是把本题的固定 Lebesgue 分母 \(|Q|\) 改成
随意离散分母的许可。本轮只研究 (2) 在固定 Lebesgue 接收域中的可能损失。
原文相应 cube 结论编号是 **Corollary 3.5**；本轮不修改旧台账。

已读冻结本地 `literature/strict_upper_second_batch.md`，其旧 \(a=3/4\) 例子已否定
“32 重只在零测边界发生”。本轮不把该旧结论当作新增成果，也未重新运行其程序。
本批没有核得一个直接给出五维 cube 严格改进的新公开定理，也不声称穷尽公开文献。

## 2. 局部统一 \(256/9\) 定理的证明

不失一般性取 \(f\ge0\)，平移/缩放后令 \(c_0=0,r=1\)。记
\[
 V=|Q_\epsilon|=32,\quad S=[-1/2,1/2]^5,
 \quad N=\sum_\epsilon1_{Q_\epsilon},\quad m=\|f\|_1.
\]
中心逐坐标位于相应正交象限的外半区，故不同中心在某坐标距离大于 1，这确为
Besicovitch family；全部 cubes 都包含 0 且 \(U\subset[-2,2]^5\)，所以 \(|U|\le32V\)。

若 \(z\notin S\)，例如 \(z_j>1/2\)，所有第 \(j\) 坐标为负的 16 个中心满足
\(c_{\epsilon,j}+1<1/2\)，其 cube 都不含 \(z\)。因此
\[
 N\le32\text{ 于 }S,\qquad N\le16\text{ 于 }S^c. \tag{3}
\]
这一步不要求中心恰为 \(a\epsilon\)，所以得到的是非退化开放参数类。
令 \(f_0=f1_S,f_1=f1_{S^c}\)，\(m_i=\|f_i\|_1\)，\(t=m_1/m\)。见证条件给
\[
 32\lambda V<\int Nf\le32m_0+16m_1,
 \qquad m>\lambda V. \tag{4}
\]

**外部质量较多：\(t\ge2/9\)。** 直接用真实接收域被 \(U\) 包含及 (4)：
\[
 \lambda|\{Mf>\lambda\}\cap U|
 \le32\lambda V<(32-16t)m\le\frac{256}{9}m. \tag{5}
\]

**外部质量较少：\(t<2/9\)。** 由次线性，
\[
 \{Mf>\lambda\}\subset
 \{Mf_0>\lambda/2\}\cup\{Mf_1>\lambda/2\}. \tag{6}
\]
对第二项仅使用已经核查的全局基准 32，得到
\(\lambda|\{Mf_1>\lambda/2\}|\le64m_1<128m/9\)。这不是循环使用待证的新上界。

对第一项保留源支撑：如果一个半径 \(R\) 的 cube 对 \(f_0\) 平均大于 \(\lambda/2\)，
则 \(R<(m_0/(16\lambda))^{1/5}\)，且该 cube 必须与 \(S\) 相交。因此
\[
 \{Mf_0>\lambda/2\}\subset
 [-1/2-R_*,1/2+R_*]^5,\quad R_*=(m_0/(16\lambda))^{1/5}.
\]
利用 \(m>32\lambda\) 得
\[
 \frac{\lambda}{m}|\{Mf_0>\lambda/2\}|
 \le\left[\frac12(32\lambda/m)^{1/5}+(2m_0/m)^{1/5}\right]^5
 <\left(\frac12+2^{1/5}\right)^5
 <\left(\frac{17}{10}\right)^5<\frac{128}{9}. \tag{7}
\]
最后两个比较只需要 \((6/5)^5>2\) 与 \((17/10)^5=1419857/100000<128/9\)，
已经准确有理核验。把 (6)--(7) 相加即得 (1)。一般 \(r,\lambda,c_0\) 由尺度恢复。

这说明：高重叠输入质量若散在中央半 cube 外，(3) 产生质量重复计数损失；
若大部分集中在内部，小支撑的真实接收域又有体积损失。这两个情况共同提供局部统一余量。

## 3. 一个明确的全局传递条件

以下条件是已证明的**充分接口**，不是已经完成的选择定理。
给任意 \(f\ge0,\lambda>0\) 和紧集 \(K\subset\{Mf>\lambda\}\)，若能选有限多个包 \(P\)：

1. 包内 cubes \(Q_{P,i}\) 具有同一半径 \(r_P\)、共同点 \(c_P\)，每个对 \(f\) 的平均都大于 \(\lambda\)。
2. 输出 cube \(C_P=B_\infty(c_P,r_P)\) 覆盖接收紧集：\(K\subset\bigcup_PC_P\)。
3. 能选非负权重 \(w_{P,i}\)，每包权重和为一，使
   \[
   \sum_P\kappa_P(z)\le U_0<32\quad\text{a.e.},\qquad
   \kappa_P=\sum_iw_{P,i}1_{Q_{P,i}}.
   \]

则每包 \(\lambda|C_P|<\int\kappa_Pf\)，故
\[
 \lambda|K|\le\lambda\sum_P|C_P|
 <\int f\sum_P\kappa_P\le U_0\|f\|_1. \tag{8}
\]
对所有接收紧集可统一实现该条件，即由 Lebesgue 内正则性推出一般 \(L^1\)、全部尺度的
\(C_5\le U_0\)。这里每个固定半径卷积平均连续，严格超水平集可测；没有稳定过程迁移。

对第 2 节的完整 32-star 取均匀权重，\(\kappa=N/32\)，则 \(\kappa\le1\)，且中央半 cube
外 \(\kappa\le1/2\)。这是一条具体可优化的正 kernel 证书。输出 \(C_P\) 含包内所有
见证中心，但**不自动含原贪心覆盖已经接收的所有点**；\(C_P\) 本身也不必是好 cube。
不同包的这些 kernel 还可能重复收费。上述接收覆盖与全局拥挤度正是尚未闭合的两项。

若改用 (1) 的局部常数，则必须另证接收分块可由各自的输入质量负责，例如
\(E_P\subset\{M f_P>\lambda\}\cap U_P\)、\(\sum_P\|f_P\|_1\le\|f\|_1\)，且
每个 \(f_P\) 满足自身 star 见证条件。只有这些条件成立才可相加得到全局 \(256/9\)。
仅将 \(f_P=f1_{U_P}\) 并不能自动保持原来所有接收点的超水平性质；输入贡献可以跨包叠加。
本轮没有把这项需要证明的选择/局部化当作事实。

## 4. 共同交点不能直接改选成好 cube 的准确反例

现在取可精确枚举的对称子模型
\[
 Q_\epsilon=a\epsilon+[-1,1]^5,\quad \frac12<a<1,
 \qquad h=1-a.
\]
其公共 core 为 \([-h,h]^5\)，并集为 \([-1-a,1+a]^5\)。对每个 \(j\) 与符号 \(\sigma\)，
取外部薄盒 \(S_{j,\sigma}\)：第 \(j\) 坐标为 \((1,1+a)\) 或 \((-1-a,-1)\)，其余四坐标为
\((-h,h)\)。十盒互不相交、全部在中央单位 cube 外，体积均为 \(a(2h)^4\)。每个
\(Q_\epsilon\) 恰包含五盒，每盒恰被 16 个 cubes 包含。

在每盒上放相等质量 \(\mu=(101/100)32/5\)，取盒内常密度，其余为零，得到有界紧支撑
绝对连续输入。于是
\[
 \|f\|_1=\frac{1616}{25},\qquad
 \frac1{32}\int_{Q_\epsilon}f=\frac{101}{100}>1,
 \qquad \int_{[-1,1]^5}f=0. \tag{9}
\]
对以 0 为中心的所有半径，积分可以精确计算：半径 \(R\le1\) 时为零；
\(1<R<1+a\) 时取得各盒长度比例 \((R-1)/a\)；更大时取得全部质量。所以
\[
 A_Rf(0)=\begin{cases}
 0,&R\le1,\\
 2(101/100)(R-1)/(aR^5),&1<R<1+a,\\
 2(101/100)/R^5,&R\ge1+a.
 \end{cases}
\]
\(\frac d{dR}[(R-1)/R^5]=(5-4R)/R^6\)，故全半径最大点恰为 \(R=5/4\)，
\[
 Mf(0)=\frac{101}{100}\frac{512}{3125a}<1. \tag{10}
\]
不仅是原半径的中心 cube 不好，而是共同交点 **所有半径** 都不能成为好见证。

另一方面，每个原中心周围半径 \(\delta=1/1000\) 的邻域都在严格超水平集中：
把见证半径放到 \(1+\delta\)，即有平均下界
\((101/100)/(1+\delta)^5>1\)。这些邻域互不相交、具有正 Lebesgue 体积。
所以反例不是离散背景测度或零体积中心集造成的。

## 5. 为什么体积后段仍没有统一改进，真实接收域却能损失很大

在公共 core \([-h,h]^5\) 上均匀放质量 \(m=(1+\eta)32\)，\(\eta>0\)，记输入为 \(g\)。
所有见证平均为 \(1+\eta\)，而
\[
 \frac{|\bigcup Q_\epsilon|}{\|g\|_1}
 =\frac{(1+a)^5}{1+\eta}\longrightarrow32
 \quad(a\uparrow1,\eta\downarrow0).
\]
因此仅对“所选见证 cubes 的并集”寻求统一 \(32-\delta\) 不成立。
重叠计数的末步与并集到体积和的步骤可在这一 Lebesgue 输入族中同时接近饱和；
尚有余量的是接收域到所选并集的步骤。

实际接收域完全不同：若 \(Mg(x)>1\)，相应 cube 半径小于
\((\|g\|_1/32)^{1/5}\le1+\eta\)，且必须碰到 core。因此
\[
 \frac{|\{Mg>1\}|}{\|g\|_1}
 <\frac{(2-a+\eta)^5}{1+\eta}\longrightarrow1. \tag{11}
\]
在预登记的 \(a=999/1000,\eta=1/10000\) 处，准确核验
\[
 \frac{|\bigcup Q_\epsilon|}{\|g\|_1}
 =\frac{31920079960009999}{1000100000000000}>31.9,
\]
\[
 \frac{|\{Mg>1\}|}{\|g\|_1}
 <\frac{100551211331732211051}{100010000000000000000}<1.01.
\]
第一个数不是 \(C_5\) 下界，因为见证并集没有被断言为真实超水平集。
