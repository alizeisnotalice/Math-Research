对精确C格的第一轴period3位置位移、单位原子质量不变，登记的1024长度有限functional得到完整局部一阶公式

```
D(z)=K*(max_j z_j-min_j z_j),  sum_j z_j=0,
K≈−0.05917590190080429597576757377067677697645614226031 < 0.
```

归一range1后，整个fan的导数及最大值都等于同一个严格负的K；不是仅在两个新内部点负。K的完整Q(u,v)系数和有理隔离区间在 `fan_results.json`，小数只供阅读。

这排除该有限functional所有非零零均值period3首轴位置方向的局部一阶改进。没有Cn上界、一般输入排除、有限epsilon邻域定量值或全尺度最优性结论。没有正方向，因此未运行有限非零epsilon候选。

## 真实signed-D3基本室

输入为 `p_j=j*a1+epsilon*z_(j mod3)`，其中 `a1=1+u^3/2`、四tail间距 `s=(1+u)/2`、`u^5=2,v^5=3`。所有原子质量为1，周期3a1的总质量恒为3。

首轴平移一个格距诱导相位循环；反射x→−x、j重标为−j后，位移向量变为 `z'_j=−z_(−j)`。真实作用群是 **G={P_even,−P_odd}**，不是质量扰动中的纯S3置换。平移、反射把真实格点和同长度连续block双射到相应格点/block，保持不同原子数量、单位质量和同一个共同半径，故完整周期receiver并集体积不变。尾四轴不动，仍可反射16倍，ratio是16V/3。

6144 raw start列表j=−1,...,4并不在几何变换下逐项封闭。其资格来自025已独立核验的safe-start证明：范围归一方向有 `|z_j|≤2/3`，在足够小epsilon下原子顺序严格保持，首末原子仍是block极值，且所有候选r≤2、2a1>3，列表外的区间不与 `[0,3a1]` 相交。该完整period身份先于jet计算成立，因而同样处理并脸和零宽，不是假设179个活盒构成对称轨道。

零均值、range1方向构成六边形边界，全部可写为普通置换作用于

```
v(t)=((1-t)/2,t,−(1+t)/2), -1/3<=t<=1/3.
```

偶置换属于G，奇置换P满足 `P*v=G*(-v)`。所以v与−v两条代表边覆盖全部六边。又G中的 `−P_(02)` 把v(t)准确映为v(−t)，对−v亦然。因此完整基本室是**两条半边** `±v(t),0≤t≤1/3`。它没有把两个不等价中点误认成同一个orbit。

在t=1/3时v有两个相等分量；G中的 `−P_(01)` 将其映为−v，因此两半边的该端点确实等价。t=0则两中点不同orbit，必须分别复用025的两个证书。025方向 `(1,0,−1)` 的range为2，本轮t0值正确取其导数除2。

## 完整raw端点及准确事件资格

本轮复用025已经完整验证的2224个四维tail section，不重算static histogram或原C基线。全部 `ell∈{1,2,3,4}^5`、j=−1,...,4共6144 raw仍重新进入首末端点公式检查。共同半径

```
r=N^(1/5)/2, N=Πell, 32r^5=N
```

不随epsilon变化，五坐标同r。首轴receiver为

```
[max(0,(j+ell1−1)*a1-r+epsilon*z_last),
 min(3a1,j*a1+r+epsilon*z_first)].
```

首轴速度因此只能取z0、z1、z2、0；负半边整体翻号。尾盒不动。常数端点恰与裁切域面重合时，把0与moving速度两种候选都保留。提取先从全部6144 raw出发，包括固定空tail、负首轴宽度及可能零宽项，没有只套179个可行盒。

实际分类：4866 raw固定tail为空或零宽、1099首轴常数宽度严格负、179正常数宽度。所有6144 raw首末标签均保存于 `events.json:all_raw_inventory`，没有新增零宽出生项。旧025的strict first-span局部排除与保留零宽规则仍有效，因为本轮range1比旧range2的位移上界更小。

同一常数位置的速度相交才可能改变一侧jet次序。准确提取得366个base位置组，只有12个同位速度比较；唯一落在半边闭窗口的实际事件是 **t=1/3，z0=z1**。开内部事件为0。虽然全局速度形式z1在t0为0，但本批raw几何中moving面没有恰与固定clipping面同位，因此t0并不是实际raw速度事件；它仍作为参数域边界完整保留。

所有速度形式的任意两两相交，在 `[0,1/3]` 内也只能发生于0或1/3。这项更粗的资格单独核验，无论raw筛选和2224 section覆盖如何选择，都不能漏掉开内部事件。全section mask对应93606次raw区间成员关系，均来自该完整6144库存。

## 两次新内部union直接传播仿射系数

没有开内部事件，所以每条开半边上所有jet顺序、裁切、空集及并集端面身份固定。每section的并长度导数为准确有理仿射函数 `a_S+b_S*t`；乘以不随t变化的tail体积并求和，得 `D(t)=A+B*t`。

每条半边仅新取一个严格内部有理t=1/6，只用于选择固定端点次序，同时沿算法传播速度的常数系数、t系数。它不是由一点负号外推，也不是插值。每个section分别以区间merge和独立cut-coverage mask两种一维union核对a_S、b_S；2224个section两系数全部一致。

两半边都准确得到 **A=K、B=0**。K的非零系数为

```
K = 32/3 -192*v² -(256/3)*v³ -72*u*v +(256/3)*u*v³
    -(44/3)*u² -72*u²*v -(8/3)*u³ +72*u³*v +96*u³*v²
    -6*u⁴ +72*u⁴*v.
```

K的根隔离上端严格小于0，符号不是从展示小数得出。t0准确等于025对应方向导数/2；t1/3两半边的闭值准确相等，符合上述G作用。

## 稠密开半边延伸到闭端点

对固定有限block，端点是epsilon与方向的仿射函数；相邻输入位置有统一正间距，尾sections固定。两个方向t、t'的receiver端面位移至多 `C*epsilon*|t-t'|`。有界盒对称差由有限端面位移乘有界截面积控制，union对称差不超过各盒之和。除以epsilon取一侧极限，得到D对t的Lipschitz连续性。

因此稠密开内部的准确仿射公式唯一延伸到t0和t1/3，即使端点处有同位异速、速度相等或并脸，也不能遗漏一个额外导数值。本轮还准确核对两闭端点身份；没有为它们重跑025基线或增加一个盲endpoint数值样本。

对任意非零零均值z，令lambda=range(z)>0。真实输入按几何G作用归约到其中一条归一半边，且 `D(lambda*z)=lambda*D(z)`。两条闭半边上D恒为K，所以整个方向空间准确得到 `D(z)=K*range(z)`；零方向D(0)=0。
