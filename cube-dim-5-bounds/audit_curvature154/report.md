# 154：单调时间形状给出的 anchor 曲率上界

独立结论：153 所提不等式成立，未发现方向、常数或域反例。它依赖 029 的同一正 Gaussian 混合和 129 已证明的固定 anchor 全空间 Jensen 支撑式，不需要 Cauchy 二阶矩。当前只准备最小符号证书；未运行任何新物理 case、H/log/角点或 152 factor。153 作者实现尚未作为本证明来源。

## 1. 任意 anchor 的时间形状

仍固定五维 alpha=1、16 条未单位化 body 方向、共同时间、Lebesgue 和逆 Fourier `(2π)^-5`。029 §8 的同一密度表示为

`p_t(c)=(4π)^(-5/2)t^-5 E[(det A)^(-1/2) exp(-c^T A^-1 c/(4t²))]`，

A 的正定随机矩阵分布不依赖 t。于是 `q_c(t)=t^5 p_t(c)` 非减，且 `0<q_c(t)≤p_1(0)<∞`。不交换时间导数或取随机矩；只比较非负 Gaussian 被积函数。029/075 的正时间处处有限、连续密度保证这一表示包含全部 c 和 Green 的 S2 奇异子空间。

对 band J=[a,b]、`0<a<b≤∞`，在 J 上以 `t^-5 dt` 归一化为概率 μ。q 非减、`t^-2` 严格递减，故双重积分恒等式给

`Eμ[q t^-2] ≤ Eμ[q] Eμ[t^-2]`。

q 有界、t^-2≤a^-2、μ 总质量有限，故有限 band 和无穷尾都合法。乘回归一化常数可得

`∫J p_t(c)t^-2 dt ≤ (∫J p_t(c)dt) × (∫J t^-7 dt)/(∫J t^-5 dt)`。

这里的权重必须是 t^-5；没有将 H 的固定 epsilon 当作齐次函数，也没有用 G 替代任何 H。

## 2. 三个准确时间常数

对整个 `[ε,∞)`，权平均为

`[ε^-6/6]/[ε^-4/4] = 2/(3ε²)`。

对 `[ε,2ε]`，权平均为

`[ε^-6(1-2^-6)/6]/[ε^-4(1-2^-4)/4] = 7/(10ε²)`。

对 `[2ε,∞)`，权平均为 `1/(6ε²)`。

记 `H0=Hε(c)`、`H1=H2ε(c)`、`r=H1/H0`，则 H0、H1 正且有限，`0<r<1`。整个 band 的估计与两个子 band 的估计分别给

`Kε/H0 ≤ (2/3)ε^-2`，

`Kε/H0 ≤ ε^-2[(7/10)(1-r)+(1/6)r] = ε^-2[7/10-(8/15)r]`，

其中 `Kε=∫ε∞ p_t(c)t^-2 dt`。因此令 `Aε=1/(16ε²)`，准确有

`Qε(c):=Kε/(16H0) ≤ Aε min{2/3, 7/10-(8/15)r}`。

两个分支均是完整时间尾的上界，不是有限时间截断。

一个额外一致性约束是 **真实 r≥1/16**。令 q2=q_c(2ε)，则前段质量不超过 `q2·15/(64ε^4)`，尾质量不小于 `q2/(64ε^4)`，所以前段不超过尾质量的 15 倍。这也说明使用 exact r 时 split 分支已不大于 2/3；但证书只持有较弱 r 下界时，保留 min 仍有实际意义。c=0 的纯 t^-5 缩放给 r=1/16 和全局 2/3 等号，是解析等号点，不是本轮执行的物理 case。

## 3. 保存端点方向与正性

若持有同一 c 的 `0≤L≤H1` 和 `H0≤U<∞`，U>0，则 `r≥rL:=L/U` 且 `0≤rL≤1`。split 分支随 r 递减，故合法证书为

`Qnew = Aε min{2/3, 7/10-(8/15)(L/U)}`。

端点方向残差准确为

`(8/15)(H1/H0-L/U) = (8/15)[U(H1-L)+L(U-H0)]/(H0 U) ≥0`。

若保存 L 可能为负，可以先用 max(0,L)；若 L>U，则输入资格不一致，应拒绝，不能以截断比例代替来源核验。对合法 0≤rL≤1，这个新上包表达式处于 `[Aε/6,2Aε/3]`，因此是正的固定二次罚项。**这是上包表达式的范围，不是真实 Qε 的下界。**

可再与任何已资格的旧上包 Qold 取 min，但 Qold 必须约束同一模型、同一 ε、同一 anchor 的同一个 Qε。多个合法上包取 min 不需要独立性。

同一个 rL 下，新 split 分支相对 129 的旧阶梯式 `Aε[1-(3/4)rL]` 严格更小，其差为

`Aε(18-13rL)/60 ≥ Aε/12>0`。

min 中的 2/3 分支只能再减小新上包。这是罚项的解析改善，不代表任何实际盒已通过。

## 4. 固定 anchor 的全空间使用

129 已从固定 t 的 Hessian 界、固定 anchor 概率 `p_t(c)dt/Hε(c)` 和指数 Jensen 严格证明，对所有实 c,u 有

`log Hε(c+u) ≥ log Hε(c)+∇log Hε(c)·u-Qε(c)|u|²`。

把 Qε(c) 换成任意已证明不小于它的正 Qcert，仍是同一固定 c 的全空间下支撑式。153 的新时间估计正是给这个 Qε(c) 一个更小上包。没有把 c 的时间期望沿空间路径冻结成 Hessian 常数。

因此原同一 Hε anchor 的 Delta 和整组 directed gradient 可直接保留；H2ε 仅提供尾质量下界，不提供另一个梯度。一个证书仍用一个 anchor 和 16 个实际闭角点；二次下包的凹性不变。anchor 可以在目标盒外，位移可以穿越奇异子空间；正时间 Hε 的平滑性与 129 的全空间支撑式已覆盖这些情形。没有新的 H/log/梯度求值由此自动取得资格。

## 5. EPS64、EPS128 和未来 EPS256 的接口

- EPS64 不持有 H32（即 H_(1/32)）下界时，直接用全局分支：`A=256`，`Qcert=512/3`，适用任意实 anchor。此时的 double-cutoff 是 EPS32，不能误把 H128 当作 H2ε 的下界。
- EPS128 的 A=1024；若同一 anchor 有 H64 下界 L 和 H128 上端 U，则新上包为 `min(2048/3,3584/5-(8192/15)L/U)`。L 可以来自包含 c 的真正 H64 closed leaf，也可以来自同一 c 的完整 raw H64 interval；必须核同模型、同点或真实闭叶包含关系与来源 SHA，不能仅用 G 下界，也不混 H64 梯度。
- EPS128 新上包低于 256 当且仅当 `L/U>27/32`。旧129的 `qcert≥256` 只属于旧阶梯公式，不能对新153机制继续作输入断言。新公式本身仍为正。
- 未来 EPS256 的 A=4096；可用 `L≤H128(c)`、`H256(c)≤U`。如果已完整主审的源确实证明 **F 上 H128≥gstar**，则仅在该已证明的 anchor 域取 L=gstar。仅有 G≥gstar 或一个 H64/H128 mixed Green 覆盖标签不够；必须证明覆盖所用每个 `epsilon_leaf≥1/128`，因而 H128 逐点支配其已证 Hcutoff，或另持有直接 H128 资格。本154不假设未读的 gstar 收据已经提供这一结论。

最后一项不限制 anchor 固定后 u 的范围：L 的资格只须在 c 成立，129 的位移仍可全空间。若 c 在 F 之外，不能直接外推 F 上的 H128 下界；不得用固定 epsilon 的假齐次性作这种外推。

新 cutoff 证书最终若参与完整 G 下界，只使用 `G≥Hε`，这是正确方向。029 的一般 L1、共同正半径和完整 G 面积分接口不改变；本轮没有从曲率模块推导新 g 或 C5。
