# lower_alt014：精确 C 格上二维 parity 质量微扰的一阶响应

本轮得到两条新的、可复核的局部下降结论，而没有提高 C。对完整登记的
`l∈{1,2,3,4}^5` 周期见证联合体积泛函，在真正精确 C 格上，

- parity 作用于坐标 (1,2)：右导数严格为负，展示值 `−0.3350588441792422`；
- parity 作用于坐标 (2,3)：右导数严格为负，展示值 `−0.28052516363540264`。

这是解析端点一阶响应，由 `Q(u,v)` 中的精确系数及根隔离区间认证，
不是根据有限差商拟合。两项 `theta=1/1024` 的新候选也分别由严格内外包
union 排除。只给出此有限见证泛函的局部结论，不推出整个周期输入、
一般 L1 输入或全尺度极大算子的上界。

## 登记、分工和输入

仅写入独立 clone 的 `lower_alt014/`；没有提交、推送或修改主 clone。
登记文件先于运行。本轮只启动两个正参数候选，未追加旧 theta=1/8 网格。
另做同一两个模式在 theta=0+ 的导数计算，未触及其他代理的远间距盆地、
BCC 或全五维 D5 parity 删点。

令 `u^5=2, v^5=3`，精确格距为

    a1 = 1+u^3/2,   a2=...=a5=(1+u)/2.

格点 `p_j=(a1*j1,...,a5*j5)` 是互不相同的原子；两种模式分别取
`(p,q)=(1,2)`、`(2,3)`，赋质量

    w_j(theta)=1+theta*(-1)^(j_p+j_q).

两个 active 轴周期为 `2*a`，其他轴周期为 `a`，一个周期胞中四个
互异原子的总质量始终为四。因此质量归一化的一阶变化严格为零。
反射约化域为 active 坐标 `[0,a]`、其余坐标 `[0,a/2]`，完整周期胞
由 32 个反射副本组成，故

    R_pq(theta) = 8 * |所有登记 receiver boxes 的联合|.

不存在额外胞体积因子，也不存在质量导数补偿项。

完整枚举 `l∈{1,2,3,4}^5` 和两个 active starts `−3,...,3`。
非 active 轴使用最近的奇/偶 canonical interval；质量不依赖这些轴，
其余平移盒均被该 canonical 盒支配。登记参数附近的共同半径均不超过2，
而所有格距大于1，所以 active start 范围完整覆盖所有可能与约化域相交
的登记长度盒。本轮没有遍历长度大于4的块。

## 去重质量与共同半径导数

令 `n=∏l_k`。块质量为 `m_B(theta)=n+theta*b_B`，其中

    b_B = (-1)^(j_p+j_q) * ∏_{k不在{p,q}} l_k,

当且仅当两个 active 长度均为奇数；其他情况下 `b_B=0`。
程序另外逐一计数 active 二维块中的正/负 parity 格点，然后乘上其余
长度，核验每个可行 raw box 的 `b_B`。不同盒共用原子不会让输入总质量
重复相加；盒覆盖体积使用精确 union，也不相加重复接收区域。

每块只有一个共同立方体半径：

    r_B(theta) = (m_B(theta))^(1/5)/2,
    r_B(0)     = n^(1/5)/2,
    r'_B(0)    = b_B*r_B(0)/(5*n).

同一块的十个未截断面不是独立移动：五个 lower faces 速度均为
`−r'_B(0)`，五个 upper faces 均为 `+r'_B(0)`；位置极值项不随 theta
变动。与约化域边界的 max/min 按右侧事件次序选取活跃面。
即使质量只在两个坐标上调制，共同半径也同时推动其余三个坐标的面。

## 精确一阶 union 与退化端点

把每个端点表示为 jet `(x0,x1)`，含义为

    x(theta)=x0+x1*theta+O(theta^2), theta→0+.

所有 `x0,x1` 均在 `Q(u,v)` 中。右侧次序是先比 `x0`、相同再比 `x1`。
max/min、可行性、去重、支配和 union 使用该次序；乘法使用
`(x0,x1)*(y0,y1)=(x0*y0,x0*y1+x1*y0)`。
因此同值异速的重合端点会正确展开成一阶窄条，而不会遗漏一阶变化。

若两个端点同值同速，它们的真实分裂至多是 `O(theta^2)`。
由于块和原始端点集合有限，每个真实端点与所取一阶端点的误差一致为
`O(theta^2)`；有界盒的对称差体积被其各面位移乘以有界截面积之和控制。
所有盒的 union 对称差又不超过这些对称差之和。因此忽略同值同速端点的
高阶分裂，或只在高阶才产生的窄盒，至多改变 `O(theta^2)` 的总体积。
这说明 jet union 计算确实给出真实有限泛函的一阶系数。

从全部 raw blocks 开始进行 jet 判定，不从 C 点的42盒截断起步。
两个模式分别得到136/190个可行 raw boxes，保留96/95个 jet boxes；
递归 slicing 与独立 coordinate-mask union 的常数项、导数项和下述
分面贡献逐项一致。常数项的25个基系数逐项等于完整 C，而非其展示值。

保留盒端点中，“同一位置、存在不同速度”的值组数，按五坐标分别为：

- first-tail：`(12,10,5,5,5)`；
- tail-tail：`(6,14,14,6,6)`。

这些是保留盒的一阶事件诊断；不声称枚举了某个正区间内的全部非零
高阶端点交叉事件，也不据此把整个 `[0,1/1024]` 宣布为无事件区间。

## 导数、同步面贡献与局部含义

令 `D_pq=R'_pq(0+)`。完整精确代数式以 `u^i*v^j` 的系数存入
`*_derivative.json` 的 `right_derivative_coefficients`；有理隔离上下界均严格
小于零。按每个小胞元乘积法则，把该方向上五坐标面移动的贡献分开：

| 模式 | 坐标1 | 坐标2 | 坐标3 | 坐标4 | 坐标5 | 总导数 |
|---|---:|---:|---:|---:|---:|---:|
| first-tail | −0.00336352105685 | −0.04454621116535 | −0.09571637065235 | −0.09571637065235 | −0.09571637065235 | −0.33505884417924 |
| tail-tail | 0 | −0.04454621116535 | −0.04454621116535 | −0.09571637065235 | −0.09571637065235 | −0.28052516363540 |

表中数字仅展示。每一项都有精确系数和有理区间，且程序断言五项之和
在代数域中严格等于总导数。tail-tail 的坐标1项是净抵消为零，不能理解为
每个块在第一坐标的面均不移动。这些项是同一个共同半径方向上的乘积法则
分解，不是五个独立优化参数的偏导。

严格结论为

    R_pq(theta) = C + D_pq*theta + O(theta^2), D_pq<0.

于是每一种模式都存在一个未量化的 epsilon>0，使得
`0<theta<epsilon` 时 `R_pq(theta)<C`。平移任一 active 轴一个格距会交换
正负 parity，并保留完整周期 union，所以 `R_pq(-theta)=R_pq(theta)`。
因此也可写成 `C+D_pq*|theta|+O(theta^2)`，给出各自一维模式的严格局部
尖峰。没有推出二维独立参数组合、任意质量扰动或全局 theta 的最优性。
本轮也没有证实 epsilon 大于等于1/1024；该正参数点另行独立核验。

## theta=1/1024 的独立精确包围

对真正代数格距取包含它们的分母 `2^60` 有理区间；对所有不同块质量，
用整数五次根二分得到严格内半径和外半径，间距为 `2^-60`。
内盒在位置不确定性两端取最不利边界，外盒取最有利边界，所以

    V_inner <= V_true_exact_C_spacing <= V_outer.

这计算的是同一精确 C 格的包围，不是把格距舍入后当成新输入。
每个内盒再次验证 distinct mass、共同半径和全部端点包含关系。
内外 union 均由两个精确 Fraction 引擎独立计算并相等。

| 模式 | ratio 内/外的共同展示值 | C_lower − ratio_outer（展示） | 内外包宽度上界 |
|---|---:|---:|---:|
| first-tail | 1.993988966168487 | 0.0003274953999987160 | 3×10^-17 |
| tail-tail | 1.994042345495518 | 0.0002741160729677343 | 3×10^-17 |

比较直接读取 `lower_round003/a2_equals_a3_results.json` 的完整 C 精确隔离
区间，源 SHA256 为
`f385811e5460af63abc117804965461eed88d8ecb5b9d2cd30268387646f45d2`。
严格外包比小于 C 的精确下端点，因此这两个正参数点在登记有限家族中
不能改进 C；这比“内包未赢”强，但仍不是整个周期输入的全尺度排除。

## L1 与全尺度传递范围

任何有效内包周期见证都可传递为 L1 下界：在 n^5 接收周期胞外加一个
固定有限源原子 collar，质量至多 `4*(n+2k)^5`，接收体积至少
`n^5*32*V_inner`。令 n→∞，归一化趋向 `8*V_inner`。
将每个互异正质量原子替换为同质量、支撑在 sup-norm eta 邻域内的光滑
非负 bump。选 eta 足够小，使有限个严格内半径同时满足
`32*(r_inner+eta)^5<m_B`，则接收点用共同半径 `r_inner+eta` 完全捕获
相应 bumps，严格平均仍大于1。总 L1 质量不变。

全尺度极大算子支配这些有限见证，所以该方向的下界传递合法。
反向却不成立：有限见证泛函的局部下降不控制未登记的长块、其他尺度或
其他 L1 输入。这里没有新赢家，因此没有新的 C5 下界宣告。
