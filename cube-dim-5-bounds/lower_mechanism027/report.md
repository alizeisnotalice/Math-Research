# lower_mechanism027：双向错位与首轴质量耦合的有限模型资格

本轮完成一个三参数周期原子族、完整 16384 项连续块见证、严格 L1 传递和一阶端点接口的数学资格审查。没有计算新并集体积、任何新方向的导数值或有限参数值，因此没有新的 C5 下界。主代理保留最终证明责任。

原建议的单向奇偶层平移确实重复了旧 011；旧 011 的三个负点只排除三个参数点，不能排除整族。双向单位质量错位虽是真正不同的有限模型，但其一阶变化按两个位置坐标可加，交叉效应至多二阶。加入首轴奇偶质量参数后，共同半径在全部五轴移动，同一坐标的 tie 次序可同时依赖质量与位置。这里给出这个耦合模型的完整接口，不预断正负。

读取并锁定的来源见 `registration.json:readonly_inputs`，共 24 项，其中 17 项为本 clone 旧审计锁文件，其余为主 clone 的 003、011、014、022、024 依据。源文件完整 SHA 存在登记中；本轮不重跑它们的旧计算。

旧 011 的位置为

    (a*j1+h*(j2 mod 2), s*j2, s*j3, s*j4, s*j5).

把原建议的 `(a*j1+eps*(-1)^j2,s*j2,...)` 沿首轴平移 `−eps`，得到偶层位移 0、奇层位移 `−2eps`；必要时反射首轴后为旧模型 `h=2|eps|`。取 h 模 a 不改变该原子输入。故其机制不是新族。011 严格核验的仅是 `h/a=1/8,1/4,1/2` 三点，均低于完整 C；没有整窗或零点导数结论。本轮也不把三个有限差值当局部导数。

旧 010 的错误是把多行捕获区间合并成 union，而正确操作是对全部选中原子求交。例 `ell=(1,4,1,1,1), j1=j2=0` 的第二轴正确区间为 `[3s-r,r]`，并非行中心区间的并。以下推导一律从全部互异原子的坐标最小/最大值生成交集，包含这个反例。

旧 014 是固定位置、二维 parity 质量；024 是固定位置、首轴 period-3 质量；022 是固定旋转的有限窗。它们不覆盖下面双向错位、首轴 period-2 质量与位置的联合族。某些零参数子族故意包含旧模型；仅称非零双向错位及联合机制为新资格，不把所有子族都称新。

## 2. 模型、互异性及周期质量

令

    u = 2^(1/5),  a = 1+u^3/2,  s = (1+u)/2.

对 `j=(j1,...,j5)∈Z^5` 定义

    p_j = (a*j1+eps*(-1)^j2,
           s*j2+eta*(-1)^j1,
           s*j3, s*j4, s*j5),
    w_j = 1+mu*(-1)^j1.

本轮资格窗口为

    |eps| <= a/16,  |eta| <= s/16,  |mu| <= 1/16.                 (1)

所有权重至少 `15/16>0`。若两个点相等，首坐标给出
`a*|j1-k1|<=2|eps|<=a/8<a`，故 j1=k1。第二坐标再给出 j2=k2，最后三轴也相等。因而索引到原子位置的映射单射；以下块质量是不同真实原子的质量之和，绝不按覆盖次数重复加质量。

可用的平移周期为 `T=(2a,2s,s,s,s)`。一个周期的四个轨道由 `(j1 mod 2,j2 mod 2)∈{0,1}²` 标号，尾轴模 1。它们互不相同，质量总和为

    2*(1+mu)+2*(1-mu)=4.                                      (2)

轨道代表的几何位置可能跨出选定半开几何胞；这不影响周期轨道计数或之后按轨道构造的有限源。不是要求四个未平移代表都落在正坐标胞内。

当 eps*eta 不为零时，首轴的两组坐标与第二轴 parity 关联，第二轴的两组坐标与首轴 parity 关联。窗口内这些分裂坐标不重合，四个轨道只实现相关配对，不能成为坐标一维集合的 Cartesian 乘积。例如首轴索引不同导致第二坐标的 eta 位移改变，取两点的混合坐标一般不是一个原子。这也不是旧整体旋转矩形格：以 p_00 为原点，差向量 `p_10−p_00=(a,−2eta)` 的两倍若仍是格差，则需要一个原子位于 `(2a+eps,−3eta)`。首坐标及窗口迫使该点 j1=2、j2 为偶数；第二坐标会要求 `s*j2=−4eta`，在 `0<|eta|<=s/16` 下不可能。因此平移后的点集不是加法格，不能由矩形格整体旋转得到。

## 3. 完整登记长度族、质量及坐标极值

只取连续 Cartesian 索引块，长度

    ell=(ell1,...,ell5) ∈ {1,2,3,4}^5.                          (3)

这是完整 1024 种登记长度，不声称覆盖更长块或任意选点。首两轴起点先允许任意整数 j1,j2。尾轴使用 canonical 连续索引

    I_ell = {−floor((ell−1)/2), ..., −floor((ell−1)/2)+ell−1}.

长度 1、2、3、4 分别是 `{0}`、`{0,1}`、`{−1,0,1}`、`{−1,0,1,2}`。

令 `N=∏ell_k`，并令

    b = (-1)^j1 * ∏_(k=2)^5 ell_k,  ell1 为奇数；
    b = 0,                            ell1 为偶数。

由互异性和首轴交替和直接得到

    m_B = N+mu*b > 0,   r_B = m_B^(1/5)/2.                    (4)

每块始终只有这个共同半径 r_B，五轴和全部选中原子共享它。额外捕获别的正质量原子只增加平均，不需把这些原子计入 m_B。

定义相位位移极值

    P(j,ell,z) = (z*(-1)^j, z*(-1)^j),  ell=1；
    P(j,ell,z) = (−|z|,+|z|),           ell>=2.                (5)

设 `(e_-,e_+)=P(j2,ell2,eps)`、`(h_-,h_+)=P(j1,ell1,eta)`。Cartesian 选择保证坐标索引最小值与任何可用另一轴相位能同时选到，所以真实极值是

    x1_min = a*j1+e_-,          x1_max = a*(j1+ell1−1)+e_+;
    x2_min = s*j2+h_-,          x2_max = s*(j2+ell2−1)+h_+;
    xk_min = s*min I_ellk,      xk_max = s*max I_ellk, k=3,4,5. (6)

这既处理 ell1=1、ell2=1，也处理 ell2=3 时首末行同相位而中间行反相的情况；只看第一/最后 corner 会漏极值。

在固定域

    D=[0,2a] × [0,s] × [0,s/2]^3                             (7)

内，精确 nominal receiver 是

    B_receiver = D ∩ ∏_(k=1)^5 [xk_max−r_B, xk_min+r_B].       (8)

端点倒置为空，等宽零为零测度但在一阶分析前不可不加区分地删去。

尾轴 canonical 选择完整：固定长度和质量，原子索引区间中心在奇长时为整数、偶长时为半整数，捕获区间有相同半宽 `r_B−s*(ell−1)/2`。对任意接收坐标 `x∈[0,s/2]`，奇长的中心 0、偶长的中心 s/2 是所有允许中心中最近的一个。因此任意其他 start 能捕获 x 时 canonical start 也能。尾轴替换既不改首两轴坐标集，也不改质量与共同半径，故可逐轴支配。此论证处理边界的并列最近中心，不需排除端点。

## 4. 严格安全 starts：16×1024，而非猜测截断

以下均由有理数五次幂严格证明；本轮 Fraction 检查实际验证了对应不等式：

    9/8<u<6/5,  3/2<u^3<8/5,
    7/4<a<9/5,  17/16<s<11/10,
    (17/16)^(1/5)<65/64.

由 m_B≤(17/16)N 和 N≤4^5，全部块有

    r_B < 2*(65/64)=65/32 =: R.                              (9)

若 ell1=1，则 N≤4^4，而 `256^(1/5)/2=u^3<8/5`，所以

    r_B < (8/5)*(65/64)=13/8 =: R_single.                    (10)

窗口 (1) 给出三个严格 guard：

    a−|eps|  >=15a/16 >105/64 >13/8;
    2a−|eps| >=31a/16 >217/64 >65/32;
    2s−|eta| >=31s/16 >527/256>65/32.                         (11)

最后一步有理余量分别为 `1/64,87/64,7/256`。

首轴 j1≤−2 时，选中原子最小坐标 `x1_min<=a*j1+|eps|`，故 receiver 上端 `x1_min+r_B<0`。j1≥3 且 ell1=1 时，`x1_max−r_B>=3a−|eps|−r_B>2a`，这里必须使用 (10)，不能只使用全局 R。j1≥3 且 ell1≥2 时，`x1_max−r_B>=4a−|eps|−r_B>2a`，由第二个 guard 得到。

第二轴 j2≤−2 时同理有 `x2_min+r_B<0`。j2≥3 时即使 ell2=1，也有 `x2_max−r_B>=3s−|eta|−r_B>s`，第三个 guard 足够；这里 D 的第二轴上边界是 s，不是 2s。因此不需误用首轴的 singleton radius 来处理第二轴。

于是全部 (3) 中可能与 D 相交的首两轴起点均在

    (j1,j2)∈{−1,0,1,2}²,
    raw_count = 4^5 * 4² = 16384.                            (12)

这包含所有零宽、重叠或退化候选。是窗口 (1) 全体参数的严格完整范围；不是仅在原点有效的经验窗口。

## 5. Glide、反射与正确归一化

变换 `S(x)=(-x1,x2+s,x3,x4,x5)` 对应

    (j1,j2,j3,j4,j5) -> (−j1,j2+1,j3,j4,j5).

代入位置公式可逐项核验 `p_(S j)=S(p_j)`；首轴 parity 不变，权重相等。该变换对所有参数成立。使用加上首轴周期的

    G(x)=(2a−x1,x2+s,x3,x4,x5)

则索引映射为 `(j1,j2)->(2−j1,j2+1)`，把下半周期 `[0,2a]×[0,s]` 映到上半周期 `[0,2a]×[s,2s]`。

每个尾轴反射 `xk->s−xk` 对应 jk->1−jk，保持位置输入及权重。它给出 8 个尾反射副本，与 glide 的 2 个副本合计 16 个。他们在一个几何周期胞内部不交，交只在零测度边界。所有变换保持 sup-norm、质量、连续 Cartesian 块结构、长度和共同半径。首轴块反向后起点变为 `2−(j1+ell1−1)`，不应要求有限 start 列表逐项封闭；先对全部整数 starts 证明映射，再用第 4 节完整截断即可。

令 U(eps,eta,mu) 为 (8)、(12) 的有限并集，V=|U| 是物理坐标下的绝对五维体积。完整周期中的对应接收体积为 16V，周期质量为 4，故

    R(eps,eta,mu)=4V(eps,eta,mu).                             (13)

没有额外周期几何体积除数，也没有未计入的 Jacobian；用归一化坐标做未来计算时才需要乘回它的坐标 Jacobian。本接口保持物理坐标。

在 eps=eta=mu=0 时，输入退化为原矩形 C 格。D 的首轴 `[0,2a]` 含 4 个原半胞，第二轴 `[0,s]` 含 2 个原半胞，其余轴已经是半胞。因此由平移和反射身份，

    V(0,0,0)=8*U_C,  R(0,0,0)=32*U_C=C_cert.                 (14)

这里 U_C 是旧完整 1024 长度泛函在 `[0,a/2]×[0,s/2]^4` 的体积。第 3 节 canonical 支配和第 4 节 starts 完整性保证恒等式消费的是同一长度族。003 保存的 42 个最终保留盒不能代替新模型的全部 raw 候选。C_cert 的精确隔离区间只读取锁定 003；本轮没有重新计算原点并集或使用展示小数决定比较。

## 6. 严格水平、有限 collar 与一般 L1 全尺度传递

固定窗口内任一参数，暂只保留所有正宽 receiver。数目有限。取 δ>0，小于每个正宽盒的半最小边长和每个 r_B，将每盒十个端面向内移动 δ，记并集 U_δ，体积 V_δ。零宽盒零测度，故 `V_δ↑V` 随 δ↓0。

对 x∈U_δ 相应块的所有原子都有 `|x−p_j|_∞<=r_B−δ`。取共同立方体半径

    r'_B = r_B−δ/2>0,
    (2r'_B)^5 < (2r_B)^5 = m_B.                              (15)

将每个原子替换为同质量、非负光滑 bump，支撑在 sup-norm 半径 `ζ<δ/4` 内；则同一个 r'_B 在全部五轴捕获相应完整 bumps，平均严格大于 1。没有坐标各自选择半径，也没有把 nominal equality 当严格超水平证据。

给出可核对的有限 collar。基础 D 内全部原子首两轴索引均在 `[-1,5]`；以轨道代表 parity 0/1 分解，周期索引为 `floor(j/2)`。应用 G 后 j1 变 `2−j1`，j2 变 `j2+1`。所有 16 个副本的周期索引范围包含于

    first: [-2,2], second: [-1,3], tails: [-1,2].             (16)

尾反射 `j->1−j` 保持尾索引范围。取内部周期 `q∈{0,...,M−1}^5`，源包含周期索引 `q∈{−3,...,M+2}^5` 中全部四个轨道。统一 collar 宽 3 包含所有见证原子；轨道唯一且权重正，由 (2) 得有限源的总质量恰为

    4*(M+6)^5.                                               (17)

bumps 可跨出源轨道位置的几何包围矩形，但不作支撑截断，其 L1 质量仍准确等于 (17)。接收集合有至少 `16*M^5*V_δ` 体积，反射/平移保持严格余量。因此该光滑非负 L1 输入在水平 1 的弱型比至少为

    4*V_δ*(M/(M+6))^5.                                      (18)

先 M→∞，再 δ↓0，得到 `C5>=4V`。对任何有效向内包围 V_inner 同样有 `C5>=4V_inner`。这是 centered cube maximal operator 在一般 L1、所有正共同尺度下的合法下界：它包含这些块对应的有限组共同半径。由齐次性，水平 1 的构造足够。有限泛函低于 C 或局部导数负，均不排除未登记长块、其他尺度或其他输入。

## 7. 单位质量双向位置的一阶可加性，包括零宽出生

这部分是解析筛选，并未计算系数。先固定 mu=0，故所有 r_B 与 eps、eta 无关。对每个 raw descriptor n，其 receiver 可写成

    I_n(eps) × J_n(eta) × K_n,

其中 K_n 是三个固定尾区间的乘积，I/J 已与 D 的固定边界截断，允许空、点或退化区间。端点是线性项、绝对值、min/max 的组合，随参数 Lipschitz。

定义 `S1(eps)=∪_n (I_n(eps) Δ I_n(0))`，S2 类似。有限区间的端点 Lipschitz 给出

    |S1(eps)|<=C1*|eps|,  |S2(eta)|<=C2*|eta|.

考虑四个 union 指示函数的混合差

    F=1_U(eps,eta,0)−1_U(eps,0,0)
      −1_U(0,eta,0)+1_U(0,0,0).

若 x1 不在 S1，所有 raw 的首坐标 membership 均不变，F=0；若 x2 不在 S2 同理。由 `|F|<=2`，

    |V(eps,eta,0)−V(eps,0,0)−V(0,eta,0)+V(0,0,0)|
      <=2*C1*C2*(s/2)^3*|eps*eta|.                          (19)

该证明不需要非退化、非重叠或无 tie 假设。双零宽同时出生只占 O(|eps*eta|)；单零宽、重合面也已包含在一维 membership 变化带内。不存在因删除零宽假设而漏掉的一阶跨轴项。

沿 `(eps,eta)=t*(e,h), t↓0`，有限 endpoint 次序在充分小 t 后固定（它们是分段仿射函数），所以各方向导数存在，由 (19) 得

    D(e,h,0)=D(e,0,0)+D(0,h,0).                              (20)

反射首轴把 eps 改号而不改 eta；反射第二轴把 eta 改号而不改 eps。完整周期泛函因此分别偶，正齐次性给出

    D(e,h,0)=A*|e|+B*|h|.                                   (21)

A、B 本轮均未求值。只有以后分别证明 A<0、B<0，才能得到所有非零单位质量双向位置方向都局部下降；011 的三个非零参数负点不能提供这个前提。即使有此局部结论，也不排除有限非零参数的二阶/高阶改善。

当 mu 随 t 变化时，r_B 同时改变五轴端点，I_n 依赖 eps 和 mu，J_n 依赖 eta 和 mu，K_n 也依赖 mu。于是同一坐标的速度是位置与质量速度之和，tie 的 max/min 与重叠排序可依赖它们的联合比值。不能用 (20) 把质量方向与位置方向简单相加。这里给出的是继续资格审查的理由，并非已找到正向或证明了这种非可加性在本族必定产生增益。

## 8. 可执行端点与 jet 接口

`generator.py` 不求根、不用浮点、不做 union。调用者提供 exact ordered field scalars a,s 和 nominal r0，或提供带明确认证状态的 `radius(mass)` oracle。主要入口：

```python
from generator import descriptors, finite_receiver, raw_receiver_jet

for lengths, starts in descriptors():  # exactly 16384
    row = raw_receiver_jet(lengths, starts, a, s, r0_for(lengths),
                           (epsCoeff, etaCoeff, muCoeff))
```

对 `(eps,eta,mu)=t*(e,h,m), t↓0`，`N=∏ell`、b 如上，

    r0=N^(1/5)/2,
    r1=r0*b*m/(5N)
      =r0*(-1)^j1*m/(5ell1),  ell1 odd；否则 0.              (22)

第一轴位移速度极值为 P(j2,ell2,e)，第二轴为 P(j1,ell1,h)，尾轴位置速度 0。若原子极值的常数/速度记为 `(x_min,v_min)`、`(x_max,v_max)`，未裁切 lower receiver jet 是 `(x_max−r0,v_max−r1)`，upper 是 `(x_min+r0,v_min+r1)`。与域端点 `(d,0)` 做字典序 max/min，得到真实右侧一阶裁切。

全部数据可放入旧代数域 Q(u,v)，`u^5=2,v^5=3`：N 只含质因子 2、3，故 r0 为该域中的单项式，a,s 也在域中。字典序比较必须由 exact field equality 和认证符号决定，不可用显示小数或容差。若精确求值使用外部库，需要固定该库及输入锁；本轮未引入或运行任何旧 union engine。

返回的 `strictly_negative_constant_width` 可用于小 t 的安全局部剔除。`lex_positive_volume` 保留常数宽 0、速度宽正的出生盒。常数和速度都为 0 的宽至多 O(t²)，在一阶体积里可忽略，但不能据此声称有限 t 时绝对为空。任何已标正 jet 都不自动给出一个已经认证的非零参数窗口。

有限 receiver 函数 `finite_receiver(..., radius)` 的正宽 flag 只针对传入的标量半径。若 radius 是 nominal exact，返回 nominal box；若是严格下半径，返回内盒并需验证 `(2r)^5<m_B`；若给上半径则是外盒。实际计算用包围的 a,s,eps,eta 时，还必须方向正确地传播位置不确定性；本简单接口要求 exact scalars，不会自动完成区间 max/min。不可用普通浮点代替这些前提。

对固定 ray，真实半径由正质量的五次根给出，具有一致 O(t²) Taylor 余项。有限个 box 的每个端点与其 jet 误差均为 O(t²)；有界盒对称差体积由各面误差乘有界截面积控制，union 的对称差不超过逐盒之和。因此完整 jet union 正确给出有限泛函的一阶系数，包括同值同速面的高阶分裂。零宽盒若一个宽仅为 O(t²)，总体积也为 O(t²)；有两个 O(t) 宽的盒同样至多 O(t²)。单零宽正速度且其余常数正的盒必须进入一阶 union。
