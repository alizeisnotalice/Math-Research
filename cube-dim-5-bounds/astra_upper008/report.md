# Astra upper 008：理想分数幂的必要角点天花板

本批没有新全域g或C5界。严格排除了005三个固定二次形状仅靠改善determinant minorant达到128×10^-6的可能性；其中κ=1/256和1/128甚至无法达到10^-4。全线性η族未被此加权Jensen估计排除。

对任意固定非负f(W)，令s=5/11，A=E[d f^7]，B=E[f^7]，V=E[b f^11]。以f^7/B加权，凹Jensen给

Utrue=E[d^s f^7]≤A^sB^(1-s)。

Young角点多项式为(11/4)Utrue a^7-(7/4)Va^11。对a≥0取最大后为Utrue^(11/4)/V^(7/4)，故乘c后的必要天花板是

c A^(5/4)B^(3/2)/V^(7/4)。

**这是所选Young测试族能认证的角点数值上限，绝不是G的上界。** 它覆盖真实d^s以及所有较小的合法minorant，也覆盖全部a≥0。

对整个线性族f=1+ηW、η∈[0,1/2]，令η=u/2。两个目标的77次残差

target^4 V(u)^7-c_U^4 A(u)^5B(u)^6

均未通过最大深度10的有理Bernstein二分。首次失败区间分别为[97/512,195/1024]和[261/1024,131/512]。这本身只说明本次证书算法没成功。

为了区分算法预算与松弛本身，我们进一步准确检查已有η=1/8和族端点η=1/2（没有搜索新形状）。η=1/8的Jensen天花板约0.000125731438746839，准确低于128×10^-6；所以007唯一形状仅提高determinant下界也不能达到该目标。η=1/2的天花板约0.000143031954266095，利用c_L的四次幂准确证明大于128×10^-6。故全族残差失败不能只靠继续二分解决；该Jensen松弛在端点确实超过两个目标。仍然不能据此声称真实Young族可达到目标。
