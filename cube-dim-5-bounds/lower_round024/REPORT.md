# 第024轮：完整period3零均值质量方向的一阶fan

固定精确C格 `a1=1+u^3/2`、四tail间距 `s=(1+u)/2`、`u^5=2,v^5=3`。对第一轴3相位质量 `1+epsilon*z_(j mod3)`、`sum(z)=0`，完整登记有限functional的**所有非零质量方向的一侧导数均严格负**。

归一化 `range(z)=1` 后，整个fan的精确最大值在方向 `(1/2,0,-1/2)` 达到，为

**A ≈ −0.1350653173739652169679963179264241809841481078893768237**。

这给出 `D(z) ≤ A*range(z)<0`。它只排除这套1024长度有限functional的第一轴period3零均值局部一阶质量机制；没有Cn上界、一般weighted input排除、量化epsilon邻域或全尺度最优性结论。没有正方向，所以没有启动有限非零epsilon候选。

## S3身份和归一化资格

有限functional先定义为所有 `ell∈{1,2,3,4}^5`、首轴所有整数block starts的周期receiver并集。质量只依赖首轴相位；四tail轴仍可用canonical奇偶block并反射16倍。接收域 `[0,3a1]×[0,s/2]^4`、period mass恒为3，所以比为 `16*V/3`，没有格胞体积因子。

几何平移首轴一个格距诱导相位3-cycle；首轴反射j→−j诱导相位1、2交换。这两个作用生成S3。它们把真实格点与连续block双射到真实格点与同长度连续block；block质量不变，对应的**一个共同半径**也不变，所有五轴receiver同时映射。完整3a1周期的并集体积在平移、反射下不变，因此有限functional在质量相位的所有S3置换下不变。这里先证明真实epsilon模型的身份，再取导数，故包含tie、零宽及重叠面，不是仅对C点活盒作置换。

有限start列表j=−1,...,4并不在这些变换下逐项封闭，本轮没有使用这个错误前提。它对周期域的替代资格来自023的安全范围证明：对归一range1方向有 `|z_j|≤2/3`，足够小epsilon下原子保持正质量，最大长度块共同半径仍小于5/2，而2a1>3。j≤−2的区间上端在0左侧，j≥5的区间下端在3a1右侧。越界像不与接收域相交，完整周期积分身份照常成立。每相位两个平移像，共6144 raw候选，三个phase质量表共3072项。Cartesian索引不同即原子不同；input每period质量为3，不按不同block重复相加。

零方向D(0)=0，且一侧导数正齐次 `D(lambda*z)=lambda*D(z)`（lambda≥0），因为把lambda吸收到epsilon即可。任意非零零均值方向，令lambda=range(z)>0，除以lambda并排序成z0≥z1≥z2，则准确写成

```
z(t)=((1-t)/2,t,-(1+t)/2), -1/3<=t<=1/3.
```

S3身份和正齐次因此把整个二维零均值方向空间约化为这一个闭区间，而非只覆盖旧±(2,−1,−1)两端。旧方向的range为3，故端点导数是023相应值除3；新 `(1,0,−1)` 的range为2，故t=0导数是新值除2。

## 完整tie事件：264比较，不是采样网格

把z(t)代入每个raw block的质量斜率，可得 `delta_m(t)=mA+mB*t`。未裁切receiver端点的一阶速度为 `±r0*(mA+mB*t)/(5N)`；裁切到固定接收域端面时速度为0。在常数位置恰好与域边界重合时，两种速度候选均保留。

本轮重新检查6144 raw的常数几何：5965有严格负常数宽度，在所有归一方向的充分小epsilon下仍为空；剩179个均有正常数宽度，没有遗漏一阶零宽出生盒。所有这些179个raw的端点均进入事件构造，尚未作方向依赖的去重/去支配，因而包含可能从旧冗余关系中复活的面。

不同常数位置的端点，在epsilon→0+时其顺序不依赖速度；只有**同一常数位置**的速度仿射函数两两相交可能改变jet顺序。完整比较只有264对，158次窗口内事件出现，精确去重排序后闭窗口共有7个候选点：

```
-1/3, -alpha, -beta, 0, beta, alpha, 1/3
alpha≈0.2480507469686566, beta≈0.06920392276152704.
```

这些代数事件以Q(u,v)分子/正分母保存，交叉乘积准确排序；没有由显示小数重造端点。`events.json` 给出每个事件的原始同位面速度比较等式和有理隔离区间。PID71954用1.6008秒、峰值29966336字节完成一次提取。

## 从稠密开cells到全部闭端点的证明

相邻候选点之间，所有raw端点的jet排序、max/min裁切选择、可行性、相同端点关系和jet支配关系均固定。用一阶jet做完整union时，每个cell宽度的常数项固定、速度为t仿射；乘积的一阶项只取一个速度因子，所以该开cell上准确有

```
D(t)=A_cell+B_cell*t.
```

本轮在6个开cell各取**一个**严格内部有理t，只用来选择已经证明固定的端点次序；沿算法同时传播速度的常数系数和t系数，直接生成A_cell、B_cell。它不是由一个点外推或数值插值。6个内部点依次为 `−3/10,−1/6,−1/30,1/30,1/6,3/10`；每次都重新从完整raw检查，不套用中方向的147盒。

023的有限jet引理处理同值异速窄条、同值同速的O(epsilon²)分裂、零宽与冗余面；本轮复用它。闭端点还需连续性，而不能遗漏：在紧t窗口上，有限个正质量根函数的t导数为O(epsilon)，所以任意两个方向的各receiver端点相差至多 `K*epsilon*|t-t'|`。有界盒对称差由端面位移乘有界截面积控制，有限union的对称差不超过各盒之和。除以epsilon并取一侧极限，得到 `|D(t)-D(t')|≤K'*|t-t'|`。因此D连续，稠密的6个开cell上的公式唯一延伸到全部tie事件及闭窗口端点。

程序另外精确核验所有相邻仿射式在共同代数端点值相等，并核验正确range缩放后的两个旧端点与新中点。每段在闭区间上的最大值在端点达到；所有7个闭事件值均有严格负的有理包围。这就完成整个fan，而不只是有限点的负导诊断。

## 真正breakpoints、紧式与最大值

候选±beta两侧的A_cell、B_cell完全相同，因此它们只是raw速度交换，对最终union导数不相关。真正breakpoints是 **−alpha、0、alpha**，合并成4个准确仿射段。

令A、B、E为 `fan_results.json:compact_formula` 保存的准确Q(u,v)系数，

```
A = 新方向(1,0,-1)导数/2  ≈ -0.1350653173739652169679963179264,
B                         ≈ +0.1276218275364628408199190329884,
E = 023方向(2,-1,-1)导数/4≈ -0.1335859198264451095686021285822,
alpha=(E-A)/(-B-E)>0.

D(t) = A-B*|t|,       |t|<=alpha;
D(t) = E*(1+|t|),     alpha<=|t|<=1/3.
```

该紧式与全部6个cell输出逐项代数相等。A<0、B>0、E<0均由完整有理根隔离证实，且alpha的分子、分母都严格正。因此D随|t|严格下降，整个归一fan的最大值准确为A，在t=0达到。正负t的偶性是本轮六cell准确系数的结果，不是单凭S3或023两端值作的假设。

七个闭事件值的小数展示依次约为

-0.13506531737396520,
-0.14389724846948350, -0.16672200702388990, -0.17811455976859347.
