# 共同尾参批的结果与分段四次认证路线

`common_tail_batch.py` 在固定

```
a1=1+u^3/2,
a2=a3=a4=a5=(1+u)/2+delta
```

下准确检查了八个预登记的有理 `delta`。没有一项的完整下端点超过C的完整
上端点；因此这八点不构成新的下界候选。最近的负向点 `delta=-1/256` 的展示
值约为1.992686，仍低于C约1.994316。

这不能推出共同尾参方向全局或局部最优。和只变一个间距不同，固定端点次序
区间上的联合体积是至多四次多项式。

## 可认证的下一有限路线

对每个尾坐标和完整1024个长度向量，列出所有原始端点仿射函数
`b+m t`。所有两两交点在所选闭区间中给出有限的次序分割；不能使用某个点的
42个保留盒替代这个完整列表。

在每个开分段中，选择一个精确内部点决定各轴端点的次序和每个小胞元的覆盖
mask。每个轴段长度是一次多项式；对五轴mask交集求和，第一轴长度为常数，
故联合体积可直接以 `Q(u,v)` 系数累积为次数至多四的多项式

```
A_I(t)=c0+c1*t+c2*t^2+c3*t^3+c4*t^4.
```

极值候选仅为分段端点和 `A_I'(t)=0` 的实根。后者可按以下任何一个精确接口
认证：

1. 以有理盒将每个端点区间化，使用Bernstein形式的导数符号包围作分支隔离；
   每个隔离盒都保持到 `Q(u,v)` 的符号检查；或
2. 对系数的有理双根域表示计算三次导数的resultant/Sturm链，并用根隔离区间
   回代验证。

只有所有次序分段、所有导数根和端点都处理完毕后，才能称某个共同尾参点为
该有限窗口的最优。该路线尚未运行，因此不声称共同尾参方向已经穷尽。
