# 067 首批数学机制与冻结范围

固定 alpha=1、5维、16条未单位化 body 方向、Fourier 逆因子 (2 pi)^-5。
只取063 low中心 c，eps=1/2048，以及真实闭盒
B={1}×prod_j[c_j-h,c_j+h]，h=1/512。此盒严格位于正单位面。
目标为 H_eps 的局部 power积分，不是完整G或全局I。

## 1. 全空间正核平移比

取043的固定可逆body基N。记 a=N^-1u。单变量Cauchy核满足

  sup_z s_t(z+a)/s_t(z)
  = (sqrt(1+(a/(2t))^2)+|a|/(2t))^2
  = exp(2 asinh(|a|/(2t))).

这可从比值 (t^2+z^2)/(t^2+(z+a)^2) 的二次判别式验证；
反向比值同样受此常数控制。因此五核的乘积、对其余11方向的
正概率卷积，都保留两侧不等式。

asinh 在非负轴凹，且 ||a||1<=sqrt(5)||a||2，故

  exp(-10 asinh(||a||2/(2 sqrt(5)t)))
  <= p_t(x+u)/p_t(x)
  <= exp(10 asinh(||a||2/(2 sqrt(5)t))).

对u=(0,v)，043的准确矩阵给
||N^-1u||2^2=v^TQv，Q=I4/4-J4/36。
盒上凸二次型最大值在角点取到，16角点的最大值为h^2。
于是整个盒在所有t>0上共用

  R_h(t)=(sqrt(1+h^2/(20t^2))+h/(2 sqrt(5)t))^10,
  p_t(c)/R_h(t)<=p_t(c+u)<=R_h(t)p_t(c).

R_h(t)随t严格下降；最低端h/eps=4给准确R_h(eps)=3125。
没有将点态Hessian当成整盒界，也没有使用盒内投影间隔。

## 2. 正时间分段

固定端点：eps到1的11个dyadic octave，每个等长分为8段，
另加[1,infinity)尾段。总共89个有限端点、88有限段和一个无穷段。
令m_j=H_tj(c)-H_tj+1(c)>=0，m_tail=H_1(c)>=0。
各有限段由完整时间势之差定义，保留全3504锥的抵消。

  L=sum_j m_j/R_h(tj)+m_tail/R_h(1),
  U=sum_j m_j R_h(tj)+m_tail R_h(1)

给整盒L<=H_eps<=U。因此

  |B| L^(5/4)<=int_B H_eps^(5/4)<=|B| U^(5/4).

证明只用非负时间分解；没有遗漏时间、用采样代替积分或
将不同段的有符号锥上界相加。数值中用各m_j的向外有理下/上端
以及R的向外上端构造L/U。所有段的正性均单独验证。

## 3. 只复用已有零阶stencil

063缓存零阶为 H_eps(c)=F sum_k w_k log(A^2+B^2 k^2)，
a=144D eps=A/B，F=D^4/(144(2pi)^5)，sum w_k=0。
零阶差商权w_k只依赖中心投影，不依赖eps。由旧key准确恢复k^2，
对任意t>0使用log(B^2 k^2+(144DBt)^2)。共享常数2log B
被sum w_k=0消除。应核验每个恢复k^2确为整数平方且属于该中心。
不重跑任何旧jet、不增加阶数、不重新生成锥或几何。

## 4. 首批有限对象及停机规则

唯一中心、唯一盒、上述89个时间端点，384-bit Arb（沿用063）。
复用063 eps处球而不重算该点，仅新算其余88个标量H_t。
每完成一个端点原子写checkpoint；一个块最多120秒，并在110秒
后主动退出75以便同fingerprint续算。没有自适应增加时间端点、
新增中心、细化空间、增加精度、扩大维数或追逐更高阶jet。

有意义门预登记为U/H_eps(c)_lower<=2，理想门<=5/4；无论是否
通过均记录全部段质量、R、贡献和范围。门只衡量这一局部机制，
并不构成全域预算或成本外推。
