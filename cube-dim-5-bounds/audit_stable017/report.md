# stable017：六个连续 x 区间的认证 Hermite 插值试点

结论：已在登记的六个闭区间 `[0,0.01]`、`[1,1.01]`、`[2,2.01]`、
`[8,8.01]`、`[32,32.01]`、`[127.99,128]` 上构造连续一维密度证书。
每段都有完整四系数球、Bernstein 控制点球和统一严格余项；可以对段内任意
实点或实子区间评估。它超出六个标量点，但范围仅限这六段一维密度，
不提供全域五维 g、I、C5 或源传递证书。

## 1. 登记、端点与实际计算范围

固定 `s(x)=2/π∫₀∞u e^(−u³)cos(xu²)du`，U=4，精度 384 bits。
12 个不同端点中，0、1、2、8、32、128 的密度球直接复用 stable015 已审、
SHA-256 锁定的标量 JSON；新算另外 6 个端点密度和 11 个非零端点导数。
`s′(0)=0` 由对称性精确给出，无需数值积分。另算六个中点密度仅作检查，
不增加插值节点。实际完整生产运行一次，耗时 0.05294 s。

全部新积分使用 python-flint 0.9.0 的 `acb.integral`，将 [0,4] 分成
四段 [0,1]、[1,2]、[2,3]、[3,4]。没有执行或导入锁定核的原脚本。
密度和导数的 u 被积函数均为整函数，忽略 analytic 参数合法。
每次积分都检查返回球有限后才加入显式双侧尾球。

## 2. 导数与截尾常数的独立推导

积分核的所有实 x 导数都有可积主控，因此可以积分号下求导：

`s′(x)=−2/π∫₀∞u³e^(−u³)sin(xu²)du`。

令 `I(U)=∫_U∞u³e^(−u³)du`。分部积分给出

`I(U)=(U/3)e^(−U³)+(1/3)∫_U∞e^(−u³)du`。

因为 u³≥U³，后一积分至多 I(U)/U³。因此 U³>1/3 时，

`I(U)≤U/[3(1−1/(3U³))]e^(−U³)`，

故对所有实 x，导数截尾的绝对值至多

`D_U=2U/[3π(1−1/(3U³))]e^(−U³)`。

U=4 时分母因子 `1−1/192` 严格为正，实际算得
`D_4=1.3684844887947684135663169666693554480…×10^(−28)`。
密度截尾沿用已审的独立解析界

`T_U=2/(3πU)e^(−U³)`，
`T_4=8.5084810338476812171603691612580368026…×10^(−30)`。

这些均是 x 一致的上界，不是尾渐近或浮点拟合。

由 Fourier 形式直接求四阶导数，

`|s⁽⁴⁾(x)|≤π^(−1)∫₀∞ξ⁴e^(−ξ^(3/2))dξ
=Γ(10/3)/((3/2)π)=M4`。

实际 Arb 球为
`M4=[0.58954353980576382560161706856774633710198580068963371988326110328424755678388957 +/- 2.26e-81]`。
这个推导提供全实轴的四阶导数上界；本次只用它证明六段的余项。

## 3. 连续区间评估规则

每段 `[a,b]` 的宽度均精确为 `h=1/100`。设 `t=(x−a)/h`，
以密度端点 `fa,fb` 和导数端点 `da,db` 定义

```
c0 = fa
c1 = h*da
c2 = 3*(fb-fa) - h*(2*da+db)
c3 = 2*(fa-fb) + h*(da+db)
H(t) = c0 + c1*t + c2*t^2 + c3*t^3
```

`hermite_results.json` 的每段 `coefficient_balls_c0_to_c3` 是以上四个
系数的完整球，并已包括端点积分、截尾和序列化误差。四系数各自包含精确
Hermite 系数，故即使忽略它们的相关性，用区间 Horner 计算仍然安全。

经典带重复节点的 Hermite 余项为

`s(x)−H((x−a)/h)=s⁽⁴⁾(ζ)(x−a)²(x−b)²/4!`，

ζ 属于本段。由于 `(x−a)²(x−b)²≤h⁴/16`，对整个闭区间有

`|s(x)−H((x−a)/h)|≤E=M4*h⁴/384`，

`E=[1.5352696349108432958375444493951727528697546892959211455293257898027280124580458e-11 +/- 3.90e-91]`。

评估时必须取这个球的 **上端点** 为误差半径，不能只取显示的小数中点。
因此任意真实输入 x 或实子区间 X⊆[a,b] 的安全规则是

`s(X) ⊆ Horner(C0,C1,C2,C3,(X−a)/h) + [−upper(E),upper(E)]`。

`hermite_pilot.py` 中的 `evaluate_certificate(record,x_left,x_right=None)`
实现此规则。它用 Fraction 校验精确有理输入范围，再用 Arb 包住该输入集合。
例如无需重新积分即可读取证书并评估：

```python
import json
from fractions import Fraction
from flint import ctx
from hermite_pilot import evaluate_certificate
ctx.prec = 384
data = json.load(open("hermite_results.json"))
ball = evaluate_certificate(data["intervals"][1], "1.002", "1.007")
```

完整段还提供更紧的 Bernstein 凸包规则。四个控制点为
`fa, fa+h*da/3, fb−h*db/3, fb`；t∈[0,1] 时四个 Bernstein 基函数非负且和为1。
控制球的并凸包再加 `[−upper(E),upper(E)]`，便得到 JSON 中
`whole_domain_density_ball`。这也是覆盖整段所有 x 的严格球。

## 4. 端点与中点检查

每段实际检查了密度端点重建、导数端点重建、中点直接积分球被
`H+误差球` 包含，以及整个中点残差球位于 `[−E,E]`。全部通过。
这些有限检查用于检出代码错误；连续性的保证来自上一节的解析余项定理，
并非从通过的有限点检查外推。

没有用实际较小的中点残差代替整段的统一 E。
