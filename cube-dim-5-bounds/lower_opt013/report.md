# lower_opt013：1+3 尾距分裂与首轴耦合的八个精确事件候选

结论：八个预登记候选均准确小于完整 C；本轮没有改善下界。
这里 C 是 `lower_round003/a2_equals_a3_results.json` 的全部 25 个
`Q(u,v)` 系数，`u^5=2,v^5=3`，没有从显示小数重造 C。
仅对这八个有限候选作排除，不声称射线、邻域或全模型的最优性。

## 新机制及有限搜索范围

基点为 `a=(A,s,s,s,s)`，`A=1+u^3/2`，`s=(1+u)/2`。
测试 `a(t)=a+t*d`，方向为 `d=(k,3,-1,-1,-1)` 与其相反方向，
`k=0,1,-1,2`，共八项。尾距均作零均值的 1+3 分裂；后三组同时
耦合首轴。与 rounds 004--009 的共同尾距、2+2 分裂、首轴交替质量
或交替间距均不同。执行前已读这些轮次的归档白名单与报告。

每个方向只取 `(0,1/64]` 内最近的非零原始同轴端点事件；枚举
`ell in {1,2,3,4}^5` 的 `0,a_j/2,r-(ell_j-1)a_j/2,ell_j*a_j/2-r`，
其中 `r=(prod ell)^(1/5)/2`。完整端点表用于有限候选的选择，并未
由此声称事件间多项式已获得认证。实际正向事件参数均为

`t_plus=(-1-u+4*u^3*v-2*u^4*v^2)/6`，

反向均为 `t_minus=3*t_plus`。它们的显示值分别为
`0.00002693021328786613` 与 `0.00008079063986359839`；实际计算
直接使用以上代数系数。事件恰等关系已由保存证书的独立回读再次核对。

## 见证与体积核验

每项枚举 1024 个长度向量，得到 51 个非空盒，精确去重和支配删除后
保留 42 个。递归切片与坐标段覆盖掩码两套准确联合体积引擎相等。
归一化为 `32*union_volume`：完整格胞每胞质量为一；半胞反射因子
为 32，格胞体积在接收密度与质量密度的比中抵消。

对每个保留长度向量，实际原子是笛卡尔积的连续整数索引块，位置为
`(k_1*a_1,...,k_5*a_5)`，每原子质量一。奇数长度取索引
`-floor(ell/2),...,floor(ell/2)`；偶数长度取
`1-ell/2,...,ell/2`。程序准确验证原子数为 `N=prod ell`，同一个
半径 `r` 满足 `32*r^5=N`，盒的所有端面均包含于每个原子的
`[atom_j-r,atom_j+r]`，且盒中点在每个坐标方向都严格包含。
这验证了真实原子、共同立方体半径和见证包含关系。

`audit_saved.py` 从 JSON 重新解码所有系数，逐一遍历每项保留见证的
3676 个原子，复核包含关系和原子列表哈希；再把五轴倒序独立重算
联合体积并核对全部八个残差。回读审核通过，耗时约 14.47 秒。

## 一般 L1 传递适用性

模型仍是正间距矩形格上单位质量原子，所有见证均使用同一个立方体
半径。盒边界为零测集；把有限个盒各面向内缩小 `tau>0` 后，紧性
给出各见证到其所有原子的严格共同半径余量，故可取 `r_tau<r`，
其平均质量严格大于一。最大块长为四，保留索引
`[-N0-2,N0+2]^5` 的有限原子即可覆盖索引 `[-N0,N0]^5` 的接收胞；
质量为 `(2*N0+5)^5`，接收体积为 `(2*N0+1)^5*A_tau`。
用质量一、支撑足够小的非负光滑团替换所有原子，严格余量保持。
先令 `N0` 趋于无穷，再令 `tau` 趋零，可将每一模型比值传给固定
Lebesgue 背景的一般 L1 类与共同尺度最大算子。因此本机制没有
破坏原传递条件。但八项均败于 C，没有新的 C5 下界，也没有调用
这段传递来包装模型改善。
