# upper_cover014：不等半径 32-clique 的局部余量与可定位的全局障碍

## 结论

本轮把 013 的局部论证推进到**任意半径、任意中心的共点 32-cube Besicovitch family**。
令 \(Q_i=B_\infty(c_i,r_i)\)，不同中心互不落入对方的闭 cube，全部 \(Q_i\) 相交，
且每个对 \(f\ge0\) 的平均大于 \(\lambda\)。则
\[
 \boxed{\lambda|\{Mf>\lambda\}\cap\bigcup_{i=1}^{32}Q_i|
 \le\frac{127}{4}\|f\|_1=31.75\|f\|_1.} \tag{1}
\]
证明不要求等半径、中心恰在对称角点或逐坐标位于外半区。关键新几何事实是：
其共同 core 在**每个**坐标方向的宽度都小于最大半径。

这是单 clique 的 **whole-mass** 局部界，仍不能跨包直接相加。本轮还证明了：

1. 一个适用于真实有限 Besicovitch 见证覆盖的精确三缺陷恒等式；near32 确实迫使
   源集中到两两不交的 32-fold cores，但还必须同时控制见证平均值余量。
2. 半径降序贪心接收分配的源局部化 \(Q(x,r_x)\subset2Q_i\)，以及由此得到的明确全局收费条件。
3. 三个准确新实例：不等半径 clique、近乎饱和后段的双包、以及源仍全在 32-fold cores
   却发生重复收费的三包。后者说明 Besicovitch 性、core 不交与源集中本身不足以控制膨胀包收费。

没有证明新的全局 \(U<32\)；全局 \(C_5\le32\) 仍不变。所有数学证明交由主线审阅，
有限实例只核验明确几何和有理不等式，不代替一般选择定理。

## 1. 真实覆盖链的三个缺陷

令有限 Besicovitch 见证族 \(\mathcal Q\) 覆盖一个可测接收集 \(A\subset\{Mf>\lambda\}\)，
每个 \(Q\) 满足 \(\int_Qf>\lambda|Q|\)。记 \(m=\|f\|_1\)、\(N=\sum_{Q\in\mathcal Q}1_Q\le32\)。
定义
\[
\begin{aligned}
 D_{\rm rec}&=\lambda\left(\sum_Q|Q|-|A|\right),\\
 D_{\rm avg}&=\sum_Q\int_Qf-\lambda\sum_Q|Q|,\\
 D_{\rm mult}&=32m-\int Nf.
\end{aligned}
\]
三者非负，且有精确的全局恒等式
\[
 \boxed{32m-\lambda|A|=D_{\rm rec}+D_{\rm avg}+D_{\rm mult}.} \tag{2}
\]
因此 \(\lambda|A|>(32-\delta)m\) 迫使每个缺陷都小于 \(\delta m\)。只知道
\(\int Nf\) 接近 \(32m\)，不能忽略 \(D_{\rm avg}\)：小半径 cubes 的平均值可能远高于阈值。

令 \(H=\{N=32\}\)。因 \(N\le31\) 于 \(H^c\)，
\[
 \int_{H^c}f\le D_{\rm mult}. \tag{3}
\]
对每个有非空交的 32 元索引集 \(P\)，令 \(K_P=\bigcap_{Q\in P}Q\)。这些 core 两两不交：
若不同 \(P,P'\) 在一点相交，至少 33 个原 cubes 会在该点相交，违反 Besicovitch 上界。
因此 \(H\) 是这些 core 的有限不交并。这里**源分解确实成立**；但索引集可能共用某些 cubes，
且其接收域、包并集或膨胀源域不必不交，不能由此自动获得全局收费。

基准 \(N\le32\) 及 \(M\) 的弱型常数32，沿用已实际核查的
[Aldaz 原始 v2](https://arxiv.org/html/1811.10478v2)；其背景测度 uniform 尖锐性仍不等于
固定 Lebesgue 的尖锐性。本轮不重复文献检索或 013 的三组参数计算。

## 2. 任意不等半径 32-clique 的 core 几何

将某个共同点移到0。每个中心满足 \(|c_{i,j}|\le r_i\)。如果两个中心处于同一闭正交象限，
则逐坐标距离不大于两绝对值的较大者，所以
\(\|c_i-c_j\|_\infty\le\max(r_i,r_j)\)，违反 Besicovitch 条件。
因此每个闭正交象限至多含一个中心。

32 个中心必须恰好占据32个开正交象限，且没有坐标为零：一个零坐标中心属于至少两个闭象限，
会使所占闭象限总数超过32。对每个坐标 \(j\)，选一对仅第 \(j\) 个符号不同的相邻象限中心。
它们其余坐标同号，其距离在这些坐标上都不可能超过 \(\max(r_i,r_k)\)。因此分离只能发生在第 \(j\) 坐标：
\[
 |c_{i,j}-c_{k,j}|>\max(r_i,r_k).
\]
两个该坐标区间相交时的交长因此为
\[
 L=r_i+r_k-|c_{i,j}-c_{k,j}|<\min(r_i,r_k)\le R,
 \qquad R=\max_i r_i. \tag{4}
\]
共同 core \(K=\bigcap_{i=1}^{32}Q_i\) 在该坐标的宽度只会更小。对每个 \(j\) 都如此，
故 \(K\) 包含于一个半径 \(R/2\) 的轴平行 cube，其中心可取 core 矩形的中点。
零体积 core 同样允许；此时 \(L^1\) 源在 core 上的质量为零。

这是不等半径的统一结论，既不需要 \(r_{\min}/R\) 下界，也不需要外半象限假设。
相邻象限对的检查是不可省略的；只选最大 cube 和另一个 cube 通常只能得到一个方向薄。

## 3. 局部 \(127/4\) 接收界

记 \(U=\bigcup_{i=1}^{32}Q_i\)、\(m=\|f\|_1\)、\(f_0=f1_K\)、\(f_1=f1_{K^c}\)，
\(m_j=\|f_j\|_1\)、\(t=m_1/m\)、\(V=(2R)^5\)。最大见证 cube 给 \(m>\lambda V\)。
在 \(K^c\) 至多31重，故
\[
 \lambda|U|\le\lambda\sum_i|Q_i|<\int f\sum_i1_{Q_i}
 \le32m-m_1=(32-t)m. \tag{5}
\]
若 \(t\ge1/4\)，直接得到 (1)。

若 \(t<1/4\)，按阈值 \(\lambda/2\) 拆分
\(\{Mf>\lambda\}\subset\{Mf_0>\lambda/2\}\cup\{Mf_1>\lambda/2\}\)。
由第2节，\(f_0\) 支撑在半径 \(R/2\) 的 cube 内。保留源支撑及质量，和 013 一样得到
\[
 \frac\lambda m|\{Mf_0>\lambda/2\}|
 \le\left[\frac12(\lambda V/m)^{1/5}+(2m_0/m)^{1/5}\right]^5
 <(17/10)^5.
\]
对外部源只用已证弱型32，\(\lambda|\{Mf_1>\lambda/2\}|\le64m_1<16m\)。
准确有理比较
\[
 (6/5)^5>2,\qquad (17/10)^5+16<127/4
\]
即完成 (1)。本轮没有把 whole-mass 的 (1) 当作可逐包相加的局部质量界。

## 4. 接上贪心接收分配的明确传递条件

假设有限接收覆盖带有互不交的接收分块 \(E_i\subset Q_i\)，且每个 \(x\in E_i\)
有原始好见证 \(Q(x,r_x)\)，满足 \(r_x\le r_i\)。这是有限候选中心按半径降序贪心、
将每个中心交给首次覆盖它的已选 cube 时的半径关系；对连续接收集，必须另行建立对应分块。
由三角不等式有
\[
 Q(x,r_x)\subset B_\infty(c_i,r_i+r_x)\subset2Q_i. \tag{6}
\]

若一些已选 cubes 可按不重复的索引分成32共点 cliques \(P\)，令
\[
 U_P=\bigcup_{i\in P}Q_i,\quad D_P=\bigcup_{i\in P}2Q_i,
 \quad E_P=\bigcup_{i\in P}E_i,\quad h_P=f1_{D_P}.
\]
原 \(Q_i\) 对 \(h_P\) 仍好，且 (6) 保证
\(E_P\subset\{Mh_P>\lambda\}\cap U_P\)。因此可合法使用局部定理：
\[
 \lambda|E_P|\le\frac{127}{4}\int_{D_P}f. \tag{7}
\]
设剩余 cubes 的重叠函数为 \(N_0\)，则整体接收集 \(A\) 满足
\[
 \lambda|A|\le\int f(z)\left[\frac{127}{4}\sum_P1_{D_P}(z)+N_0(z)\right]dz. \tag{8}
\]
如果对每个输入、阈值和接收紧集，都能选出这种覆盖/分包，使右端收费不超过
\(U_*\|f\|_1\)、统一 \(U_*<32\)，才得到全局严格上界。无剩余时，一个足够的
质量加权条件是
\[
 \frac{\sum_P\int_{D_P}f}{\|f\|_1}\le\Lambda<\frac{128}{127}. \tag{9}
\]
这里比 013 更具体地接上了贪心的半径关系，但没有证明 (9) 能统一实现。
下节表明：即使原包并集不交、全部源恰在32-fold cores，\(D_P\) 的收费仍能任意多重。
近饱和若能排除此现象，必须使用 (2) 中的平均值余量及接收缺陷，而不只使用源集中。

## 5. 三个准确新实例

所有实例取 \(\lambda=1\)、\(\eta=1/65536\)，源在指定 core 内为常密度，均为有界紧支撑
Lebesgue 输入。没有重跑 013 的任何 \(a\) 实例。

### A. 单个不等半径 clique

全正象限半径1，其他31个半径 \(q=1/16\)；取中心
\(c_\epsilon=(33/34)r_\epsilon\epsilon\)。不同尺度间的最小中心距离/较大半径为 \(33/32>1\)。
core 准确为 \([-1/544,1/544]^5\)。在 core 放质量 \((1+\eta)32\)，则每个 cube 都好，
全部源都有32重，故 \(D_{\rm mult}=0\)。但小 cubes 的平均远高于阈值，
\[
 D_{\rm avg}/m=32506337/1048592,
\]
所以“源完全在32重 core”不能单独代表整条覆盖链接近饱和。
准确计算还给全空间真实接收上界
\[
 |\{Mf>1\}|/m<(1+1/544+\eta)^5/(1+\eta)<1.01.
\]
本例用一个 \(5^5=3125\) cell arrangement 准确核对原并集体积，不把并集当真实接收域。

### B. 双包：后段近32而真实接收域小

两个 packet 的半径 \(R_j=16^{-j}\)，\(j=0,1\)。取
\[
 a=4095/4096,\quad b=5/2,\quad p_j=(bR_j,0,0,0,0),
 \quad c_{j,\epsilon}=p_j+aR_j\epsilon.
\]
各包内部32个 cubes 半径为 \(R_j\)，core 半径 \((1-a)R_j\)；全族64个 cubes 也是
Besicovitch family。原包并集
\(U_j=p_j+[-(1+a)R_j,(1+a)R_j]^5\) 在第一坐标已分离。
各 core 放质量 \(m_j=(1+\eta)(2R_j)^5\)。

每个见证平均恰为 \(1+\eta\)，全部源都有32重，故
\[
 D_{\rm mult}=0,\quad D_{\rm avg}/m=32/65537,
 \quad |U_0\cup U_1|/m=\frac{36870975646169341951}{1152939096792891392}>31.97. \tag{10}
\]
这使体积和/平均/重叠的后段同时接近32，却还不是接收域结论。
对真实接收域，将最大 core 源以阈值 \(99/100\) 处理，余源以 \(1/100\) 处理：
最大 core 的可用见证半径小于 \(1003/1000\)，因为
\((1003/1000)^5>(1+\eta)/(99/100)\)。小尺度源质量比例不超过 \(1/(16^5-1)\)。故
\[
 \frac{|\{Mf>1\}|}{m}
 <\frac{(1/4096+1003/1000)^5}{1+\eta}+rac{3200}{16^5-1}
 <\frac{51}{50}=1.02. \tag{11}
\]
没有采样接收集；最后一项只使用弱型基准32。此例准确定位了 \(D_{\rm rec}\) 的大幅损失。

### C. 三包：源集中仍不保证局部源收费可加

用同样参数增加 \(R_2=1/256\)，三个原包并集仍不交，全部96个 cubes 仍为 Besicovitch。
先放上述平衡质量，再向**最小包 core** 增加100倍平衡总质量。所有见证仍好，
全部源依然都在32-fold cores，所以 \(D_{\rm mult}=0\) 仍精确成立。

膨胀包正好为
\(D_j=p_j+[-(2+a)R_j,(2+a)R_j]^5\)，按 \(j\) 嵌套，均含0；最小包 core 在所有 \(D_j\) 内。
于是准确的源收费为
\[
 \frac{\sum_j\int_{D_j}f}{m}
 =\frac{110317772210277}{37016926770551}>2.9. \tag{12}
\]
这远超 (9)。本例的见证平均余量也大：\(D_{\rm avg}/m=209718432/6619237\)。
因此它是“Besicovitch性+source32集中足以控制膨胀收费”的反例，**不是**包含所有三缺陷都小的
near-extremizer 反例。

同一构造允许任意多个 lacunary packets；把100倍平衡质量放最小 core，可使收费至少
\(100J/101\)，而原源仍全在32重区域。因此仅凭这些几何与源集中条件不存在统一收费上界。
本轮实际只算了登记的双包和三包，没有另算第四实例。

这些族可作为有限候选中心的合法贪心见证族，但没有声称它们是对**整个**真实超水平集
强制产生的唯一贪心覆盖。额外见证/更好的选择可能避免它们，这正是全局选择还需证明的内容。
