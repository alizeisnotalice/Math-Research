# 五维上界首轮：独立接口审计

日期：2026-10-25。审计对象为主项目的 `finite_source_transfer.md` 与 `tube_and_interpolation.md`，并以独立的整数枚举复核其方向几何。本审计不认证新的 \(g\)、\(I\) 或 \(C_5\) 上界。

## 已接受的基础接口

1. 16 条 body 方向的真实半群接口成立。每个方向有一个四方向补集使五维行列式绝对值为 48；因此峰值上界可取 \((48\pi^5t^5)^{-1}\)。
2. 有限源、障碍、同一接收集、全部共同尺度和一般 \(L^1\) 截断传递在五维具有正确形式。需要的维数条件是 \(n>1\)，在这里由长时可积性及小 cutoff 的 \(\epsilon^4\) 缩放满足。rank-2 奇异平面不妨碍全空间 \(G\in L^{5/4,\infty}\)、\(H=(G-c)_+\in L^1\) 或 \(LH=\mu-\delta_0\)。
3. 奇异分类的机制正确：离开 120 个 pair plane 的紧集，三参数非零尺度给 \(p_t=O(t)\)；pair plane 去掉方向线处为 \(p_t\asymp t^{-1}\)，产生对数发散；方向线处为 \(p_t\asymp t^{-3}\)。因此五维真实奇异集为 pair plane 并，不能移植四维“只在线上发散”的连续性说法。
4. 面短时预算的常数正确。面边际为 \(16t/[\pi(1+256t^2)]\)，行列式 48 的补基和事件并给 \(p_t(1,y)\le256(3\pi^5)^{-1}t^{-3}\)，故 \(\|p_t(1,\cdot)\|_{5/4}=O(t^{1/5})\)，短时势范数为 \(O(\epsilon^{6/5})\)。
5. 若以后独立认证 \(G\ge g\) a.e. 于方体及 \(I\le I_0\)，严格成本为
\[
C_5\le5^{5/4}I_0/g^{5/4}.
\]
它使用 \(J=10\cdot16I=160I\)，不是从四维常数替换维数。

## 复管与连续插值

初稿曾隐含 Chebyshev Lagrange 基非负；这不成立。修订后的 `tube_and_interpolation.md` 已作出必需修复：节点张量先经四轴 DCT 矩阵转为 Chebyshev 系数，再经精确有理矩阵转到每个物理闭块的 Bernstein 张量系数。仅在这个转换之后，才使用 Bernstein 基非负且和为一。因此连续范围认证的逻辑现在可用，前提是未来证书实际保存所有节点区间、DCT 区间、Bernstein 转换、误差与覆盖权重。

节点近似部分已明确
\[
M(\epsilon,R)=\frac1{192\pi^5(\epsilon-R/6)^4},\qquad 0<R<6\epsilon,
\]
以及四坐标逐段位移的 \(4Dh\delta\) 误差。该接口仍未生成 \(g/I\) 数据，故没有五维上界改进。

## 独立性与锁定输入

本审以 SymPy 整数计算确认：120 个 pair 均秩 2，560 个 triple 均秩 3，五元组秩分布为 1360 个秩 4 和 3008 个秩 5。它与生产器的 Bareiss 结果一致，但共享方向输入和整数线性代数，不称完全独立内核。
