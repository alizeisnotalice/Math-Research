## 定位错误与严格反例

生产源第 34 行为

```
ylo=max(0,k*s-r); yhi=min(2*s,(k+l2-1)*s+r)
```

全部选定行的 y 坐标范围为 `[k*s,(k+l2-1)*s]`，共同包含这些原子的中心必须满足

```
max(0,(k+l2-1)*s-r) <= y <= min(2*s,k*s+r).
```

生产程序使用 min−r / max+r，真正的交应为 max−r / min+r。横坐标已经使用正确方向，故问题局限于第二坐标。

独立重建生产去重和包含剔除后，保留 tag

```
(j,k,l1,l2,l3,l4,l5)=(0,0,1,4,1,1,1)
```

具有 N=4、r=u²/2，错误盒为

```
[0,r] × [0,2s] × [0,s/2]³.
```

点 `x=(u²/4,s,s/4,s/4,s/4)` 严格位于该盒内部。选定的 row 3 原子为 `(h,3s,0,0,0)`，其第二坐标到 x 的距离为 `2s>r`，因此指定共同半径不可能容纳全部 4 个选定原子。更强地，这 4 行的纵向跨度 `3s>2r`，它们在该半径没有任何共同接收中心。

还可精确核对整个无限周期输入在 `x+[-r,r]⁵` 内只有一个原子：`s>r` 排除 row 1 以外的全部行；`3s/4>r` 保证后三轴各只含零格点；`-r/2<h<3r/2` 及相邻列落在该区间外保证第一轴只含 column 0。实际平均为 **1/4**，不是所称 ≥1。这些不等式均已用有理根包围在脚本中运行断言。这里不声称该点在其他半径的最大函数一定 ≤1；反例已经直接否定当前盒/半径证书。

## 原子、奇偶、质量和反射审计

原子为 `(j*a1+h*(k mod 2),k*s,n3*s,n4*s,n5*s)`，其中 `a1=1+u³/2`、`s=(1+u)/2`、`h=a1/8`。k 不同则 y 不同，k 相同而 j 不同则 x 不同，故原子无重复。Python 负整数的 `%2` 也给出正确奇偶类。水平偏移只随行变化，块内每行选相同的连续列 j,…,j+l1−1；脚本逐点列出并检查前两坐标点数恰为 l1*l2。

取半开周期胞元 `[0,a1)×[0,2s)×[-s/2,s/2)³`。其两行分别只有 `(0,0,0,0,0)` 和 `(h,s,0,0,0)`，质量恰为 2。接收正片 `[0,a1]×[0,2s]×[0,s/2]³` 沿后三轴各独立反射，周期输入保持不变，八片内部两两不交，零测边界不计。于是一个周期的接收体积为 8V，除以质量 2 后比值为 4V。这里不再除胞元体积。此归一化本身正确，但不能修复错误见证盒。

所有五坐标使用同一 `r=N^(1/5)/2`；从各轴点集取 `[max−r,min+r]` 后，任一盒内中心均使对应 N 个不同原子同时落在共同半径 cube 内。后三轴显式选择的整数段为 l=1 时 `{0}`、l=2 时 `{0,1}`、l=3 时 `{−1,0,1}`、l=4 时 `{−1,0,1,2}`，与生产奇偶公式等价。

## 有限 collar 和一般 L1 全尺度转移：正确几何可闭合

下面只适用于**正确**的有限盒库。原 `transfer_interface.md` 所述抽象步骤可成立，但不能转移原错误盒。

对所有正体积见证盒作统一向内收缩 ε，ε 小于最小边长的一半且小于最小 r。收缩后的盒内，每个选定原子到中心的各轴距离 ≤r−ε。将共同半径改为 `r'=r−ε/2`，仍包含全部原子，而且 `N/(2r')⁵>1`。库有限，统一 ε 足够。对称反射后的库具有相同结论；收缩并集体积 Vε 随 ε↓0 趋于 V。

给出明确足够的 collar **c=9**：内层周期索引 z∈{0,…,M−1}⁵。每个见证的列索引 j,…,j+l1−1 在 [−6,9]；行索引 k,…,k+l2−1 在 [−6,9]，对应 y 周期索引 floor(k/2) 在 [−3,4]；后三轴原子索引连同反射都在 [−2,2]。平移后这些原子都位于周期索引 `{-9,…,M+8}⁵` 的有限 collection 内。按上文半开胞元约定截取这 `(M+18)⁵` 个胞元的全部原子，质量正好为 `2(M+18)⁵`。内部 M⁵ 个胞元贡献接收体积 `8M⁵Vε`。因此有限测度的弱比值 ≥`4Vε (M/(M+18))⁵`。

每个保留原子再替换为同一个非负 C∞ 紧支 bump，积分为 1，sup-norm 支持半径 δ<ε/2。对上述每个中心及其共同半径 r'，整个选定 bump 均包含在 cube 内，所以积分至少 N，严格平均仍 >1；非负性使 bump 重叠不影响总质量相加。所得函数非负、光滑、紧支且属于普通 Lebesgue L1。先令 M→∞，再 ε↓0，并相应 δ↓0，就得到 C5≥4V。所有见证半径一直是五坐标共同的 centered-cube 半径，且全正尺度最大算子当然包含这些半径。

本轮正确库的 4V 仅 1.767237955729…，故这份闭合转移没有改善既有 C。
