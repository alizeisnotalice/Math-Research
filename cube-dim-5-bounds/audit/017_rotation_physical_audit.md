## 原子质量、物理捕获和共同半径

旋转矩阵 `[[4,-3],[3,4]]/5` 正交且可逆，原 m,n 不同则平面物理点不同。物理周期 `(5s,0)`、`(0,5s)` 对应原整数位移 `(4,-3)`、`(3,4)`，其行列式为 25。因此半开平面 supercell `[0,5s)²` 恰有 25 个不同单位原子。其余三轴各一原子/周期，完整五维胞元质量仍为 25。

对任意固定 n 个平面原子，原子接收窗的交表示同一个中心在同一 r 下同时捕获它们。计数集合 `{center: number of windows≥n}` 可以分解成保留固定 n 个 ID 的矩形。它与未旋三轴固定块的 Cartesian product 捕获 K*n 个不同五维原子：三轴索引数之积为 K，平面 ID 数为 n；所有坐标统一使用

```
r=(K*n)^(1/5)/2.
```

不是分坐标改变半径。质量恰为 K*n，所以 equality-radius cube 平均至少 1；inner 使用更小的严格 r_inner，平均严格大于 1。K8/n4 的 equality r=1，实际 inner 为 `2417851639229258349412351/2417851639229258349412352`。

注册库 K≤64、n≤16，故共同 r≤2。任何平面原子可唯一归入 25 个代表加整数倍 supercell；超出邻胞索引 `{-1,0,1}²` 的点，至少一物理轴距接收区 `[0,5s]²` 大于等于 5s>2，不能被任何这些 r 捕获。225 原子有限集合对于注册半径完整；此结论不覆盖更大半径。

## 归一化和误差方向

计算次序取三未旋轴 a,s,s，再取旋转平面。接收域为 `[0,a/2]×[0,s/2]²×[0,5s]²`。仅反射三未旋轴，格点输入不变；8 个副本内部分离，组成一个完整胞元，故周期弱比值为 `8V/25`。无需再除胞元体积，也没有旋转平面的额外反射因子。

根 bracket 由精确整数第五幂认证；为 exact fifth power 特意令 lower 少一个 2^-80，保证 r_inner 严格。a=1+u³/2 和 s=(1+u)/2 对 u 单调，正系数取同向端点，负系数交换端点。给每原子窗端点：inner 使用坐标 upper−r_inner / lower+r_inner 并向内取整；outer 使用 lower−r_outer / upper+r_outer 并向外取整。截取接收域时 inner 使用域的下包围、outer 使用上包围，因此

```
inner threshold set ⊂ exact-radius threshold set ⊂ outer threshold set.
```

未旋块也是各轴 max−r/min+r 的同向包含关系。outer packet 只是有限 family 的几何外包围，其盒不必是实际可捕获原子的见证；不能把它用作下界。所有有限 family 的 union 保持该夹逼方向。

本小块的精确 planar area gap 为 `137657300752113/1208925819614629174706176`，约 1.1386745035853e−10；五维归一化 ratio gap 约 3.6345125320027e−12。这些是包含有理根/间距误差和 dyadic 坐标取整的严格 enclosure 宽度，不是随机误差或浮点误差估计。

v3 索引把所有现存 dyadic 端点精确乘以 2^40 转成整数，断言分母为 1，没有再次取整。固定 family 的多个 3D shape 先取并集，平面 packet 亦按 family 取并集；对于 plane family mask A、unrot mask B，只在 `A&B≠0` 时计五维体积。这一规则正确计算 `union_f (B_f×C_f)`，不会把不同 K/n 的平面见证与三轴见证错误拼接。本轮只读代码/manifest 论证规则，未重新认证全部 block 输出及最终无缝 rollup。

## 有限 collar 与光滑 L1、全尺度迁移

注册库中未旋轴长度≤4，选定索引分别为 `{0}`、`{0,1}`、`{−1,0,1}`、`{−1,0,1,2}`；加上允许的三轴反射后均在 [−2,2]。旋转平面的见证原子在邻胞 [-1,1]²。以半开胞元 `[-a/2,a/2)×[-s/2,s/2)²×[0,5s)²` 为周期基域，内层接收周期索引 `{0,…,M−1}⁵` 的全部见证，均包含在 padded 周期索引 `{-2,…,M+1}⁵` 的原子集合。每胞元 25 原子，无重复，质量恰为 `25(M+4)⁵`，接收体积为 `8M⁵V_inner`。

内侧见证有限，逐 family 已有严格 `(2r_inner)^5<K*n`。选统一 η>0，使所有 family 都满足 `(2(r_inner+η))^5<K*n`。把每个原子替换为同一个积分 1 的非负 C∞ bump，sup-norm 支持半径 δ<η/2。在共同 cube 半径 `r_inner+η` 下，每个被选 bump 整体仍在 cube 内，积分至少 K*n，严格平均 >1。非负 bump 即使重叠也按积分相加，总 L1 质量不变。于是普通光滑紧支 L1 输入的弱比值至少

```
(8/25)V_inner * (M/(M+4))^5.
```

令 M→∞ 得 C5≥(8/25)V_inner。所有五坐标始终共享同一个 centered cube 半径，所有正尺度最大算子包含这些有限见证半径。这证明可转移性，不证明数值超过完整 C；若全局 inner union 未超过完整 C，仍不得登记新下界。
