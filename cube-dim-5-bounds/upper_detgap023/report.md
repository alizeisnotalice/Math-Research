# detgap023：条件 logdet Jensen 损失的完整正修正

结论：主提出的三次 log 修正与 Hessian/Kronecker 正积分修正均成立。
它们不需要统一 `A≥εI` 或 `||X||<1`；后者无需三阶中心矩，且条件方差非零时
严格为正。原 least-squares 逆二次型上界和原事件概率权重保持可用。

一次预登记的最大值条件点 `v=11111,z=t=1,x=11110` 认证了局部 Green
下公式可乘至少 **1.0224**。这只是一项条件案例，不是正概率 retained-value 箱，
未重跑旧 order 网格，不能据此宣布新的全域 g、G 或 C5 界。

## 1. 全谱三次 log 上界

固定任一 order 条件：保留变量值确定，剩余独立变量同分布于 `S|S≤t`。
设剩余方向集 L，`R=Σ_(ℓ∈L)vℓvℓᵀ`，保留部分为 Aret，

`B=E_cond A=mR+Aret`，
`Yℓ=Sℓ−m`，`σ²=EYℓ²`，`μ3=EYℓ³`，
`X=B^(−1/2)(A−B)B^(−1/2)`，`cℓ=vℓᵀB⁻¹vℓ`。

每个样本 A 正定，故 X 的每个本征值 z>−1。标量恒等式

`log(1+z)−z+z²/2−z³/3 = −∫₀ᶻu³/(1+u)du ≤0`

对整个 z>−1 成立，包括任意大的正 z。因此这个三次多项式是 log 的
**上界（majorant）**，不是需要小谱半径的局部 Taylor 近似。

对谱取迹：
`logdet A≤logdet B+trX−trX²/2+trX³/3`。
独立中心化给

```
E trX = 0,
E trX² = σ² Σ cℓ²,
E trX³ = μ3 Σ cℓ³.
```

即使固定方向矩阵彼此不交换，含两个或三个不同下标的项，其随机标量因子
也因某个中心一阶矩为零而消失；只剩同一下标。rank-one 迹分别是 cℓ²、cℓ³。
所以严格有

`E logdet A ≤ logdet B−Δ3`，
`Δ3=(σ²/2)Σcℓ²−(μ3/3)Σcℓ³`。

原 logdet Jensen 还给 `E logdet A≤logdet B`，故可取 `max(Δ3,0)`。
μ3 是**中心**三阶矩，可正可负；数值求下界时不能把它换成原三阶矩或忽略符号。
固定 t 的所有剩余矩都有限。与 order022 同样，五方向子基及逆矩控制
logdet 的负部，trace 控制正部，所以期望合法。

## 2. Hessian/Kronecker 正积分修正

因为剩余 Sℓ≤t，条件下有确定矩阵

`A≤Amax=tR+Aret`，`B≤Amax`。

令 `H=A−B`、`C_u=B+uH`、`B_u=(1−u)B+uAmax`。
每个样本、每个 u∈[0,1] 都有 `0<C_u≤B_u`，故
`P=C_u⁻¹≥Q=B_u⁻¹>0`。所需的非交换情形单调性确实成立：

`P⊗P−Q⊗Q=(P−Q)⊗P+Q⊗(P−Q)≥0`。

因此对任意对称 H，

`tr(PHPH)=vec(H)ᵀ(P⊗P)vec(H)≥tr(QHQH)`。

这里不能换成一般不成立的“P²≥Q²”；Kronecker 二次型是关键。
沿线段的**精确积分余项**为

`logdet A=logdet B+tr(B⁻¹H)
−∫₀¹(1−u)tr(C_u⁻¹H C_u⁻¹H)du`。

对上面的曲率下界取条件期望，独立中心化只留下方差项，得到

`E logdet A≤logdet B−ΔH`，
`ΔH=σ² Σ_(ℓ∈L)∫₀¹(1−u)(vℓᵀB_u⁻¹vℓ)²du ≥0`。

`(1−u)` 已经是积分余项的完整权重，外面没有额外1/2。
它来自全线段精确 Hessian，而非小扰动近似；不需要统一 A 的最小本征值下界。
条件方差非零、剩余方向非空时 ΔH 严格正。

还可直接得到无需 u 求积的便宜版本：

`ΔH≥(σ²/2)Σ(vℓᵀAmax⁻¹vℓ)²`。

对 top1 条件最大值 z=t，Amax=16tI，剩余15方向均长平方5，故
`ΔH≥375σ²/(512t²)>0`。这是完整条件公式，可供后续网格使用，
但本次未重新积分任何旧网格。

## 3. 如何进入原条件 Green 下公式

令 `Q_a=xᵀB_a⁻¹x` 为原 least-squares 的条件上界。
对热核指数作普通指数 Jensen，并同时使用任一 logdet 改进，得

`E_cond[det(A)^(−1/2)e^(−Q/(4τ^(4/3)))]`
`≥det(B)^(−1/2)e^(Ψ/2)e^(−Q_a/(4τ^(4/3)))`，

其中可选 `Ψ=max(0,Δ3,ΔH)`，或它的任何可证明下界。
所有 gap 都基于 unit-time 条件变量；共同 stable 时间缩放在 gap 内抵消，
所以 `e^(Ψ/2)` 与 τ 无关。之后的 Gamma 时间积分和 κ 不变。
原最大/前二大等 disjoint-event 概率也不变，没有 tilt、KL 或新的归一化因子。

因此原条件 Green kernel 确实可乘 `exp(Ψ/2)`，逆二次型上包接口不需调整。
若 numerical gap 只有区间包围，应先取**下端点**、与0取最大，再指数化；
绝不能用 gap 中点或上端点作为安全乘子。

## 4. 唯一条件点与正 Stieltjes 矩包围

固定 v=(1,1,1,1,1)、z=t=1、x=(1,1,1,1,0)，仅一个条件 retained-value 点。
重用 order022 已核的 m(1)、a(1)、F(1)；原锁文件不修改。
本次没有推 M2/M3 的高阶截断矩级数，避免潜在积分常数问题。

令 ell=1/4，将 [ell,1] 分128等份，步长3/512。对 j=2,3，

```
Σ lo^j·[F(hi)−F(lo)] ≤ E[S^j 1_(ell<S≤1)]
E[S^j 1_(ell<S≤1)] ≤ Σ hi^j·[F(hi)−F(lo)].
```

[0,ell] 完整贡献包在 `[0,ell^jF(ell)]`，没有被丢掉。
所有 CDF 权重已实际认证严格正。CDF 使用直接 reciprocal-Gamma 系数和
Horner 求和，每残类64项及已审余项，未调用作者旧 order 引擎。
然后除以 F(1) 得条件原矩，并用

`σ²=ES²−m²`，`μ3=ES³−3mES²+2m³`。
