# 003-D：固定末四间距时第一间距的有限窗口穷尽

在

```
a2=a3=a4=a5=(1+u)/2,
a1 in [1+u^3/2-1/8, 1+u^3/2+1/8]
```

内，完整的1024个长度向量产生111条第一坐标原始端点仿射函数。两两相交并
加入窗口端点后，得到83个不同的准确参数点。当前C的第一间距
`1+u^3/2` 是其中一个点；其余82点按每批不超过八点的规则全部运行了完整
并集计算。

`a1_breakpoint_exhaustion.py` 不使用展示小数：它重新构造83点，读入每一批
的精确区间，并断言C的**下端点**严格大于全部其他82点的**上端点**。结合
`round003/lower_coordinate_breakpoints.md` 的完整原始端点次序分割引理，这证明
C是这个固定末四间距、这个第一坐标窗口、这个有限见证族的严格坐标最大值。

这不等于任意矩形格点或任意坐标的全局最优，也不自行产生C5新界；C本身仍
需要并依赖独立的几何与传递审计。
