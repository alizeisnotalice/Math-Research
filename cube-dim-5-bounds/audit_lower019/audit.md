## 独立的导数存在证明

设有限个有界轴平行盒 B_i(t) 的每个原始端点在 t=0+ 满足

    e(t) = e0 + e1*t + O(t^2).

本题的原始端点由固定格点位置与正质量的五次根半径构成，故在
`|t| < 1` 的充分小邻域中具有该展开。裁剪到固定约化域只引入有限
max/min，不改变右一阶展开的存在性。

对任意非空盒指标集 I，交盒在第 k 轴的边长是

    L_Ik(t) = (min_{i in I} upper_ik(t)
                - max_{i in I} lower_ik(t))_+.

有限 min/max 的右一阶系数按 (e0,e1) 字典序选取。理由是位置不同的
端点在充分小右邻域保持次序；位置相同则比较速度；位置与速度都相同
时，端点差至多 O(t^2)，任选其中一个不会改变一阶系数。正部操作也有
明确规则：对 x(t)=c+d*t+O(t^2)，若 c>0 保留 (c,d)，若 c<0 取零；
若 c=0 则取 (0,max(d,0))。这些规则的 O(t^2) 余项成立，因为有限
max/min 和正部对统一端点误差都是 Lipschitz 的。

于是交盒体积 `product_k L_Ik(t)` 存在右一阶展开，乘积一阶系数正是
dual-number 乘法。有限盒并集的容斥公式

    |union_i B_i(t)| = sum_{nonempty I} (-1)^(|I|+1)
                         product_k L_Ik(t)

给出整个并集的右一阶展开。容斥在这里只是独立的证明路径，没有实际
枚举作者大并集的所有子集。

因此，用仿射端点 e0+e1*t 替换真实端点，再对这些仿射盒作精确并集，
会保留常数项与右导数。作者采用的 lexicographic slicing/mask 运算
是该仿射模型的一种有限实现，乘法规则正确。

这也说明几个退化情形的处理方向：

- 零宽但一阶宽度为正的盒可能贡献一阶体积，必须保留。
- 零宽且一阶宽度也为零的盒至多贡献 O(t^2)，可在一阶运算中丢弃。
- 两个以上一阶零宽方向同时张开的盒，体积至少是 O(t^2)，不贡献右导数。
- 同值异速端点之间的一阶窄条不能合并为单一常数端点。
- 同值同速端点的二阶分裂不会改变本题的一阶答案。
- jet 去重及支配删除对仿射模型在充分小右邻域合法；高阶失去真实支配
  至多造成 O(t^2) 的差别。

代码审读确认 `first_variation.py` 从全部登记长度和 active starts
开始做 jet 可行性判定，而非只扰动旧 C 点保留的 42 个盒。其 `hi<=lo`
判定会保留零常数宽度、正一阶宽度的盒。端点的坐标贡献标记 g 在同一
坐标轴上由速度唯一决定，所以当前端点比较中 `__eq__` 的 g 分量不会
改变按 (位置,速度) 排序的结果。最终体积的 g 只用来分解乘积法则的
五个同步坐标贡献，没有将它们当成五个独立参数。

## 质量、共同半径与覆盖范围

对两个 active 轴 p,q，长度为 l、起点为 j 的块质量是

    m_B(t) = n + b_B*t,    n = product_k l_k.

一维交错和在长度为偶数时为零，在长度为奇数时为 (-1)^j。因此只有
两个 active 长度均为奇数时

    b_B = (-1)^(j_p+j_q) * product_{k not in {p,q}} l_k,

其余情形 b_B=0。这是逐格点质量求和，并不把不同 witness 共享的原子
重复计入输入总质量。对 `|t|<1`，每个格点质量 1±t 严格正。

每个块使用一个共同立方体半径

    r_B(t) = (n+b_B*t)^(1/5)/2,
    r'_B(0) = b_B*r_B(0)/(5*n).

所以五个 lower faces 同时以 -r'_B 移动，五个 upper faces 同时以
+r'_B 移动。作者实现与该公式一致，非 active 坐标的面也被共同半径
推动。

两个 active 轴的周期各为 2*a，其余为 a。半开周期胞中有四个互异
格点，两个质量 1+t、两个质量 1-t，总质量恒为 4。各坐标反射保持
parity 质量和完整登记 witness 家族。约化域 active 边长为 a、其余
为 a/2，完整周期胞包含 32 个反射副本。因此

    R_pq(t) = (32*V(t))/4 = 8*V(t),

无额外胞体积因子，也无分母导数项。平移一个 active 格距将 t 变为
-t，完整周期 witness 体积不变。因此在该有限泛函上 R(-t)=R(t)，
严格负的右导数确实意味着单参数严格局部尖峰。

登记长度为 1..4 时，n<=1024；b_B非零的块有 n<=576 且 |b_B|<=64。
对 |t|<1，所有质量不超过 1024，共同半径不超过 2，而所有 a>1。
若 active start j<=-2，则其最右接收端点 ja+r<0；若 j>=3，则最左
接收端点 `(j+l-1)a-r > a`。因此 `-3..3` 的范围包含所有可能与
约化域相交的 active starts。

对非 active 轴，块质量与平移无关。奇数长度的 canonical interval
中心在 0，偶数长度的中心在 a/2；它们分别是整个 [0,a/2] 上最近的
允许中心。因此其裁剪后接收区间支配其余平移，canonical 约化合法。
这些论证只保证 l<=4 的登记家族完整，不包含更长块或任意尺度。

## 唯一预登记退化测试

只运行了一个四矩形族，0<t<=1/4：

    A = [0,1] x [0,1],
    B = [1-t,1+t] x [0,1+t],
    C = [1+2t,2] x [0,1],
    D = [0,1] x [1+t^2,1+2t^2].

B 在 t=0 零宽，宽度以 2t 张开；x=1 上有多种不同速度。D 的两个
高度端点同值同速，但在二阶分裂。独立多项式容斥得到精确面积

    V(t) = 2-t+3t^2-t^3.

将所有端点截成一次项后，精确面积为 `2-t+2t^2`，二者右导数同为
-1。若错误丢弃 B，右导数会变成 -2。程序还在唯一登记点 t=1/16
用纯 Fraction 容斥验证了完整多项式的面积值。本测试没有调用作者的
jet 类、递归并集或 mask 引擎；它验证退化处理原则，不能替代作者大
实例的独立导数重建。

小多项式运算，没有导入作者 `field()` 或运行作者的并集程序。

5. 核验每条导数等于五个坐标贡献的逐项有理系数之和，核验相同贡献与
