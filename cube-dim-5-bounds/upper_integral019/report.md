# upper_integral019：一个正积分降维与晚中时间接口

结果：一次预登记的一维正积分试点给出严格峰值常数
`2.4372482×10⁻⁵ < C6 < 3.318237×10⁻⁵`，从而在整面 `[0,1]^4` 上认证
晚中段 `L(y)=∫₁⁴pₜ(1,y)dt` 满足 `||L||_(10/7)<1.366110×10⁻⁵`。
这提供可证明的五维中时间积分接口，但没有认证完整 `[1/65536,4]` 的 I。
核心缺口仍是 `[1/65536,1]` 的空间积分与离原点衰减。

## 1. 实际主接口与准确门槛

已读取主 clone 的 `round005/alpha15_middle_budget.md` 和对应 JSON。
采用该主文件固定的未单位化 16 个体对角方向、共同 stable 时间、
`ε=1/65536`、`T=4`、`q=10/7`、总目标 `I₀=11/1000000`。
独立 384-bit Arb 复算

`M = I₀^(7/10) − Bε^(6/5) − (3/7)(A⁵/48)4^(−7/3)`，
`D = M^(10/7)`。

完整球见结果 JSON。数值为

```
M = [0.000329705021236614293914138371365904209772403312718783530845450165587568057922379453751212036 +/- 3.13e-94]
D = [1.06143562300460297428169091520606831886653080773414323264992525041314912264260500131299402e-5 +/- 2.10e-95]
```

复算球包含于主 JSON 的同一行球内。已实际严格比较验证可用的向下有理门槛为

`D_down = 1.06143562300460297428169091520606831886653080773414323264992525041314912e-5 < D`。

因此本任务确实面对 `∫_[0,1]^4 J_(ε,4)^q ≤ D_down`；没有把其他时间区间的
旧 QMC 或有限采样当作这个条件的证据。

## 2. 正积分降维：五个基变量加一个条件变量

取 stable015 已审的 det48 基 B（列顺序为 v,w₁,…,w₄），加入方向
`w=(1,−1,−1,−1,−1)`。精确有

`B⁻¹w=(−1/3,1/3,1/3,1/3,1/3)`。

这可以直接以整数式 `B·(−1,1,1,1,1)ᵀ=3w` 核对。
令 `kₜ` 为这六个独立 stable 分量的五维和的密度。条件于第六个标量 z，

`kₜ(x) = (1/48)∫_R sₜ(z) ∏_(i=1)^5 sₜ((B⁻¹x)_i − (B⁻¹w)_i z) dz`。

这是正积分。原点处由 s 的偶性和缩放，

`kₜ(0)=C6 t^(−10/3)`，
`C6=(1/24)∫₀∞s(z)s(z/3)^5 dz`。

此外 kₜ 的 Fourier 变换是非负实函数 `exp(−tΣ₆|v·ξ|^(3/2))`。
五个基方向已保证其可积；在反演式中 `cos(x·ξ)≤1`，所以
`0≤kₜ(x)≤kₜ(0)`。原 16 方向密度是 `pₜ=kₜ*μₜ`，其中 μₜ 是其余十个
独立分量的概率律。因此 **全空间严格** 有

`pₜ(x)≤C6 t^(−10/3)`。

这一步的全空间结论来自 Fourier 反演和概率卷积，并不是把有限空间样本外推。
它把一个有用的条件期望包围问题降成了一维正积分，没有做 11 维网格。

## 3. 预登记的唯一网格、严格误差与实际成本

网格在 `registration.md` 中先固定为 R=12、N=32、h=3/8；
唯一空间单元为整个 `[0,1]^4`，唯一时间试点为 `[1,4]`。
没有试跑或追加其他网格。

设 `f(z)=s(z)s(z/3)^5`。已审 subordination 单调性保证 f 在 z≥0 非负且单调下降，
故整个连续积分满足

```
(h/24) Σ_(k=1)^N f(kh) ≤ C6
C6 ≤ (h/24) Σ_(k=0)^(N−1) f(kh) + tail_R.
```

解析截尾由 `s(x)≤Kx^(−5/2)` 给出

`f(z)≤K⁶3^(25/2)z^(−15)`，
`tail_R≤K⁶3^(25/2)/(24·14·R¹⁴)`。

计算球如下：

| 项目 | 球中点或严格含义 |
|---|---:|
|下 Darboux 和|`2.4372482371107349069696…×10⁻⁵ ±6.33×10⁻¹⁷`|
|上 Darboux 和，未加尾|`3.3169028518522838523685…×10⁻⁵ ±2.89×10⁻¹⁵`|
|解析尾上界|`1.3336999332253746220616…×10⁻⁸`|
|最终包围宽度|`8.8098831496940990476554…×10⁻⁶`|

真实单调矩形上下和之差精确是 `h(f(0)−f(R))/24`，至多 `hA⁶/24`。
所以此网格误差是可证明的离散误差，不是样本方差。尾项与核积分不确定性
远小于网格宽度，当前精度瓶颈是粗 Darboux 网格。

55 个不同核参数中，0、1、2 直接消费 stable017 的连续 Hermite 证书；
没有重算它们。其余 52 个一维密度使用已审 ξ=u² 表达式，384 bits、U=4、
四个子积分计算，共 208 次 `acb.integral` 子调用。所有返回球有限并加上统一尾球。
生产运行一次，Python 3.15.0、python-flint 0.9.0，耗时 0.06347 s。
完整有理参数表、来源和球都在 `positive_peak_results.json`。

结果后的纯球算术复核还确认：
`C6>2.4372482e−5`、`C6<3.318237e−5`、晚段范数小于 `1.366110e−5`、
下节早段门槛大于 `9.99169e−6`。该复核没有新增核积分或网格。

## 4. 可交付的中时间接口

新峰值上界是旧 `A⁵/48` 的 `0.8129648728351806…` 倍。
在唯一时间试点 `[1,4]` 上，面体积为1，故

`||L||q ≤ C6_upper·(3/7)(1−4^(−7/3))`
`≤1.3661096462393826096959602410135034592…×10⁻⁵`，

`∫_[0,1]^4 L^q ≤1.1238119716668086849589018820252870359…×10⁻⁷`。

以上上界的完整球已经输出；消费者应取相应球的上端点。
令 `E(y)=∫_ε^1pₜ(1,y)dt`。Minkowski 给
`||J_(ε,4)||q≤||E||q+||L||q`，所以足够另外取得

`||E||q ≤0.0003160439247742204678171787689557691751805…`，
即
`∫_[0,1]^4 E^q ≤9.9916959339558387568987968237251674128…×10⁻⁶`。

这里的两个右端同样是带球的门槛，应取下端点；简便可用向下门槛
`∫E^q≤9.99169×10⁻⁶`。**本任务没有认证这个早段积分。**
不能把晚段与早段的 q 次积分直接相加来代替 Minkowski。

## 5. 准确失败诊断：为何这不是完整 I 的解决方案

若把同一个峰值界机械用于全中段 `[ε,4]`，将得到

`||J||q≤C6_upper·(3/7)(ε^(−7/3)−4^(−7/3))≈2462542.4694`，

这是允许范数 M 的 `7.468926194…×10⁹` 倍。
更强的诊断是：即使用精确 C6，已证下界 `C6>2.4372482×10⁻⁵` 也让这条
“仅用峰值并积分时间”的方法比预算至少大 `5.485934060…×10⁹` 倍
（已实际用球算术核对）。所以把这一维正积分网格继续细化，无法弥补早时间
失去 x₁=1 离原点信息的误差。这不是 0.063 s 运行成本或标量认证精度的问题。

后续需要保留空间位置的条件期望包围，或其他能整合早段空间衰减的严格接口；
本次没有再登记另一方法或空间单元。
