# lower_face_reduction101：共同半径真实变分的坐标分解与有限一维面算法

主提出的分解正确。对 027 的完整有限块族，真实归一化一阶导数满足

    D(E,H,M)=F1(E,M)+F2(H,M)+3*FT(M).                         (1)

这里每个 F 已包含真实 ratio 的因子 4。F 是只让一个坐标的 receiver 端点变化的辅助几何导数，不是一个允许独立坐标半径的新极大算子。零宽出生、并脸、固定域裁切和重叠不破坏 (1)。本轮给出严格证明、四轴静态 mask 到一维速度线积分的精确算法，以及包含无界方向尾部的完整验收条件。

没有真实 C 格的 F1、F2、FT、A、B 数值或符号，没有正方向，没有新的 C5 下界。唯一计算是预登记的 10 个至多三维、每例至多三个盒的有理 toy；没有重新评估 027 的 16384 个真实端点或任何旧 baseline。主代理保留最终证明责任。

## 2. 有限轴盒 union 的一般坐标分解定理

先不使用晶格。设有限个 d 维盒的各坐标区间为 I_nk(t)，均在固定有界域 `Q=∏Q_k` 内，端点位移为 O(t)，允许空、点、重叠、完全相同的盒以及零宽出生。定义

    U(t)=∪_n ∏_k I_nk(t),             U0=U(0),
    U^(i)(t)=∪_n [I_ni(t) × ∏_(k≠i) I_nk(0)].              (4)

定义第 k 轴的 membership 变化带

    S_k(t)=∪_n (I_nk(t) Δ I_nk(0)).

有限区间的对称差长度至多由端点移动之和控制，故 `|S_k(t)|<=C_k*t`。即使一个倒置区间在 t=0 附近变成正宽，这个界仍成立；若原来严格倒置，则固定方向下足够小 t 时保持空。点集端点的 membership 差至多零测度，不影响以下积分。

考虑指示函数余项

    Z(t)=1_U(t)−Σ_i 1_U^(i)(t)+(d−1)*1_U0.                 (5)

若 x 不在任何 S_k 的相应柱带，所有 raw 盒的 membership 完全没变，Z=0。若只在第 i 个变化带内，则每个 raw 的其他坐标 membership 都保持基线；因此 `1_U=1_U^(i)`，所有其他 partial 都等于基线，仍有 Z=0。这个逐 raw 的论证没有把 union 当成体积和。

所以 Z 的支撑只可能落在至少两个坐标的变化带交叠处。又 `|Z|<=d`，得到准确上界

    ||Z(t)||_1
      <=d*Σ_(i<j) |S_i(t)|*|S_j(t)|*∏_(k≠i,j)|Q_k|
      =O(t²).                                               (6)

积分后

    |U(t)|−|U0|=Σ_i (|U^(i)(t)|−|U0|)+O(t²).               (7)

这不需要坐标参数独立：同一个 M 可以同时进入全部坐标速度，定义 (4) 只是分别冻结其他四轴的几何端点。因此它正好适用于共同半径变形。

零宽情况无需另加假设：一个盒在两轴均为零宽时，完整出生体积至多 O(t²)，所有一阶 partial 的其他静态坐标至少有一轴零测度；只有一轴零宽且其余正宽时，可能的一阶出生由该轴 partial 支付。与其他盒的重叠及遮盖已由 (5) 的 Boolean union 身份处理。不能因此提前删除所有零宽盒；单零宽出生盒必须保留到对应 partial 的算法中。

在本任务中，一阶端点 jet 有限，替换真实端点只改变 O(t²) 体积；固定方向的 jet endpoint 次序在足够小 t 后固定，故各 partial 的右导数存在。由 (7) 得真实导数等于五个 partial 导数之和。

## 3. 归一化和分解的几何对称

令 `V(t)=|U(t)∩D0|`，`V_i(t)=|U^(i)(t)∩D0|`。这里已经将区间裁切到 D0，所以交 D0 的写法仅强调物理域。真实周期质量始终为 4，完整周期接收体积为 16V，真实 ratio 为 R=4V。没有质量分母的一阶补偿，也没有几何胞体积除数。

定义

    F_i=4*lim_(t↓0) (V_i(t)−V(0))/t.                        (8)

027 的 glide 与尾反射对 partial 也成立，原因是它们的索引映射同时保持真实几何和基线几何，且它们不混合坐标轴：

    G(x)=(2a−x1,x2+s,x3,x4,x5),
    (j1,j2)->(2−j1,j2+1);
    xk->s−xk 对应 jk->1−jk, k=3,4,5.

质量、长度、N_n、b_n 和真实共同半径均按该索引映射保持。对 active 坐标使用真实端点、对 frozen 坐标使用基线端点，仍被同一个映射送到对应 partial。先对所有整数 starts 证明，再使用完整安全范围；不要求有限 start 列表在变换下逐项封闭。

这个范围也适用于 partial：每个坐标要么是 027 窗口内的真实区间，要么是零参数基线区间，两者都满足 027 的长度相关半径与位移 guard。尾轴 canonical 支配不变，因为尾 starts 不影响任何块质量，冻结或变化的半径在各尾轴仍与该轴 start 无关。于是每个 partial 在完整周期中的体积都是 16V_i。

尾轴 3、4、5 的置换保持 D0、全部登记长度、质量系数和基线其他坐标。故三个尾 partial 的导数相等，记为 FT(M)。第一 partial 只含 (E,M)，第二只含 (H,M)。代入 (7)、(8) 就得 (1)。

这里的 4 只是从真实体积一阶分解继承的固定系数。不能把某个 V_i 解释成独立坐标半径极大算子的合法 ratio，也不能把一个 F_i 的正号单独提升为新的 C5 下界。合法对象始终是最终相加后的真实方向 D。

## 4. 方向对称、M 归一化及纯位置边界

真实模型的首轴索引平移给出

    p_(j1+1,j2,...)(eps,−eta,−mu)=p_j(eps,eta,mu)+a*e1,
    w_(j1+1)(−mu)=w_j(mu).

它保持所有长度块，基线也以同样方式平移。对每个 partial 的完整周期体积分别成立，因此

    D(E,H,M)=D(E,−H,−M),
    F1(E,M)=F1(E,−M),
    F2(H,M)=F2(−H,−M),
    FT(M)=FT(−M).                                           (9)

首坐标反射通过 j1->−j1 将 eps 改号，保持 eta、mu；第二坐标反射通过 j2->−j2 将 eta 改号，保持 eps、mu。它们也保持 partial 对应关系。所以 F1 对 E 偶，F2 对 H 偶；结合 (9)，F2 对 M 也偶。此处使用完整周期和 16 个副本的身份，不是假设一个有限 start 数组在首轴平移下封闭。

所有 F 和 D 对方向正齐次，因为可把方向的正倍数吸收到 t。因此

    FT(M)=|M|*FT(1),
    D(E,H,0)=A*|E|+B*|H|,
    A=F1(1,0), B=F2(1,0).                                  (10)

这些 A、B 的符号目前未知。由 (9) 和齐次性，M<0 的方向可先将 H 改号，再把 M 变成正数；进一步利用位置反射，可将任意 M≠0 的方向化为

    |M|*D(|E|/|M|, |H|/|M|, 1).                            (11)

所以实际优化只需 M=1、E,H≥0，加上 M=0 的纯位置边界。每个有限归一方向仍由 (2) 给出非空可行 t 区间；不存在覆盖整个无界 E,H 域的共同正 t 窗口，这一点不能混淆。

## 5. 固定其余四轴的 exact mask 公式

固定 active 轴 i。对 `y∈D0_(-i)`，定义基线静态 mask

    S_i(y)={n: y∈∏_(k≠i) I_nk(0)}.                         (12)

其他四轴的全部基线端点给出有限网格，在每个开 cell 上 mask 恒定；其边界零测度。把相同 mask 的 cell 体积聚合为 W_(i,S)。所有权重为非负的绝对四维体积，包含空 mask 时

    Σ_S W_(i,S)=|D0_(-i)|.

对每个 mask 定义 active 轴一维并长度

    L_S(t)=|∪_(n∈S) I_ni(t)|.

Fubini 直接给出 partial 的精确身份和导数

    V_i(t)=Σ_S W_(i,S)*L_S(t),
    F_i=4*Σ_S W_(i,S)*L'_S(0+).                             (13)

这无需为每个新方向重建五维几何。尾轴只需生成轴 3 的一个静态权重系统，再由对称复用。

必须从全部 16384 raw 建静态 mask：一个基线正宽盒即使被其他盒覆盖，也可能在一阶速度不同后贡献；不能预先套用旧 42 盒。某 raw 在静态四轴中有零宽，则不会出现在正权重 mask 中，恰与第 2 节的出生会计吻合；若只有 active 轴零宽而其他四轴正宽，该 raw 必须留在相应 mask 中。严格负基线宽的盒可以证明在固定方向足够小 t 时为空，但删除原因和 raw 身份必须记录。

新静态权重可验证以下必要 marginal，而无需另跑旧 baseline 引擎：

    Σ_(S:n∈S) W_(i,S)=∏_(k≠i) max(0, |I_nk(0)|).

同样可有限选择 raw 对，核对 joint marginal 等于其他四轴交集长度的乘积。常数项 `4*Σ W L_S(0)` 应以完整代数系数等于锁定 C_cert；这是新权重系统的归一化一致性，不把原点重新运行当新实验。本轮没有构造这些真实权重或计算任何这样的真实和式。

## 6. 一维局部速度线的面积分公式

对某个静态 mask S，写已裁切 active 区间 jet 为

    I_n(t)=[l_n+t*alpha_n, r_n+t*beta_n]+O(t²).

严格 `l_n>r_n` 的项在固定方向小 t 时为空，可去除。令 c 遍历其余区间的全部基线端点。若某区间严格穿过 c，即 `l_n<c<r_n`，则 c 附近的整条小带被该区间覆盖，其局部 union 导数贡献为 0。

否则定义三类 endpoint 数据：

- 左侧区间：`l_n<c=r_n`，其 upper 速度组成集合 B_c；
- 右侧区间：`l_n=c<r_n`，其 lower 速度组成集合 A_c；
- 零宽区间：`l_n=r_n=c`，其速度区间为 `[alpha_n,beta_n]`，倒置时为空。

在局部放大坐标 `x=c+t*z` 中，一阶占据集为

    T_c = (∪_(beta∈B_c) (−∞,beta])
          ∪(∪_(alpha∈A_c) [alpha,∞))
          ∪(∪_(zero n) [alpha_n,beta_n]).                    (14)

基线占据集 T_c0 则是：B_c 非空时加入 `(−∞,0]`，A_c 非空时加入 `[0,∞)`。孤立零宽点不贡献基线长度。因此

    phi_c = ∫_R (1_Tc−1_Tc0) dz,
    L'_S(0+)=Σ_c phi_c.                                    (15)

积分是有限的：所有有限速度和 0 之外，两集合相同。实际算法只需把这些速度与 0 准确排序，在每个相邻区间取一个 midpoint 判断 (14) 与基线的 membership，将长度乘以指示差累加。不把多个半直线或出生区间的长度相加当 union。

推导上，固定方向下不同 c 的 O(t) 邻域可取不交，变化只发生在这些邻域；除以 t 后变成 (14)。真实端点的 O(t²) 误差在一维长度中也是 O(t²)。有限个 c、有限个 mask 允许逐项相加，得到 (15)、(13)。这也证明同值同速面的高阶分裂不影响一阶值。

域边界无需额外补偿。先做已裁切 jet：在 lower 域面取速度 `max(0,raw lower speed)`，在 upper 域面取 `min(0,raw upper speed)`；若常数不在裁切 tie 则选择其唯一分支。再使用 (14) 就自动计入边界。边界单零宽出生会给正确的一侧速度区间，不能套用未裁切速度。

该公式处理一个常被漏掉的情形：基线左右两个区间在 c 接触，基线局部全覆盖，而速度可能打开缝隙。此时 T_c0=R，(15) 是负的缝隙长度；零宽出生区间若填补部分缝隙，也由同一 union 处理。两个重复盒以不同速度分开、一个出生盒始终被正宽盒覆盖等情况同样无需单独规则。

## 7. M=1 时的有限 PWA 事件及闭端点

令

    f1(q)=F1(q,1), f2(q)=F2(q,1), q>=0,
    tau=FT(1).

在 q>=0 上，027 的位置极值速度是 `q`、`−q` 或 0；半径速度 kappa_n 是固定代数数。未裁切 endpoint 的速度为 `alpha*q+beta`，其中 alpha∈{−1,0,1}、beta∈Q(u,v)，`u^5=2,v^5=3` 取正实根。裁切 tie 的速度是该 affine 函数与 0 的 max/min。全部基线位置、静态权重也在同一个实代数域内。

生成事件时保留每个 raw 的基线位置 c 和它所有可能的 primitive 速度；裁切 tie 保留 raw affine 与 0 两个候选，不先按某个 q 去掉一支。对同一 c 的全部候选速度，连同局部基线速度 0，列出两两相等的非负解

    q=(beta_2−beta_1)/(alpha_1−alpha_2), alpha_1≠alpha_2.    (16)

恒等的两条速度不产生事件。再加入 q=0，精确去重、排序。该列表可有冗余，但不会漏掉同位 endpoint、裁切选择、零宽出生、重合面打开/闭合所需事件。不同基线位置在 t↓0 的一阶比较中不发生交换；不需要将有限 t 的全部位置交叉混入方向 fan。

在两个相邻事件之间，以及最后一个事件之后的无界 cell，所有 primitive 速度次序固定。字典序裁切、(14) 中的区间占据和 union 次序因此固定；(15) 是 affine 速度差的线性和。由 (13) 得到每段准确的

    f_i(q)=A_cell+B_cell*q.                                 (17)

应通过该已证明固定次序直接传播 affine 系数；一个有理内部 q 仅用于选择次序，不是用有限采样外推线性。所有事件均可保存在 Q(u,v) 中并用正实嵌入的有理根隔离认证大小，不能由显示小数排序或决定相等。

f_i 连续且 Lipschitz：改变 q 到 q' 使所有 active endpoint 在真实 t 模型中移动至多 C*t*|q−q'|；有限一维区间 union 的长度差不超过逐区间端点差之和。乘固定静态权重、除以 t 并令 t↓0，得到 `|f_i(q)−f_i(q')|<=C'*|q−q'|`。因此各开 cell 的公式唯一延伸到全部闭事件，包括 q=0；实现应逐项检查左右公式在共有代数端点相等。

本轮没有生成真实事件列表，不能声称实际事件数、静态 mask 数或内存开销已经很小。所得缩减是结构上的：三个四轴静态几何系统，加两个一维方向 PWA 和一个固定尾值；不需要三参数动态五维 union 网格。静态几何仍须由后续 worker 以有限对象和可恢复 checkpoint 执行。

## 8. 上确界、无穷尾部和正确验收

在 M=1 的归一方向上，独立参数分离给出扩展实数意义下的身份

    sup_(E,H>=0) D(E,H,1)
      =sup_(q>=0) f1(q)+sup_(q>=0) f2(q)+3*tau.              (18)

两函数都有有限事件，最后一个 cell 为 affine。由正齐次性和连续性，

    lim_(q→∞) f1(q)/q=F1(1,0)=A,
    lim_(q→∞) f2(q)/q=F2(1,0)=B.                           (19)

所以各自最外侧 affine 段的斜率恰为对应纯位置系数 A 或 B。这给出完整的尾部规则，而不能无证明地截断 q 窗口：

- 外侧斜率为正，则该 f 的上确界是 +∞；它同时表明对应 M=0 纯位置方向为正。
- 外侧斜率为负，则外侧段递减，全局最大值在 q=0 或有限事件中达到。
- 外侧斜率为零，则最后一段恒定；其值已在最后一个事件达到。若没有正事件，q=0 即代表这个 plateau。

两个上确界都有限时，它们都由有限 q 实现，最优 pair 可独立组合，不需要对事件笛卡尔积做二维动态 union。若 A 或 B 为正，M=1 归一化中的 +∞ 只反映未限制位置/质量方向比，并不意味着 C5 无穷或有限 t 的 ratio 无界；真实 t 仍受 (2) 约束。

若最后计算得到 A<=0、B<=0 且 (18) 的有限值<=0，才能排除这个完整三参数有限泛函的所有正一阶方向；等于零的方向仍可能有高阶改善，且从未涉及更长块或一般输入的最优性。若得到一个 D>0 的有限 pair，只证明存在某个未量化的小 t 正改进；应进一步给明确余项或认证一个严格非零 t，再消费 027 的 collar/L1 传递。027 原三点负值或旧其他机制的负导数都不能替代这里的 A、B、tau、f1、f2。
