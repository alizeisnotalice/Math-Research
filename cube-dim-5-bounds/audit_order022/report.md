## 1. 无 tilt 常数与条件 Jensen 的方向

令 `A=ΣS_v vvᵀ`、β=3/4。Gaussian 混合和 stable 缩放给

`pₜ(x)=(4π)^(−5/2)t^(−10/3)E[det(A)^(−1/2)exp(−Q/(4t^(4/3)))]`，
`Q=xᵀA⁻¹x`。

直接积分 t 得

`∫₀∞t^(−10/3)e^(−Q/(4t^(4/3)))dt
=(3/4)4^(7/4)Γ(7/4)Q^(−7/4)`，

因此源常数确为 `κ=3Γ(7/4)/(2^(7/2)π^(5/2))`。
条件事件是原始 unit-time S 的顺序事件；共同时间缩放不改变顺序，所以
条件概率可先固定，再作这个时间积分。没有 T-tilt 或遗漏的概率归一化。

固定保留变量及其值后，剩余变量独立、同分布于 `S|S≤t`。记
`m=E[S|S≤t]`、`a=1/E[S⁻¹|S≤t]`。logdet 凹性给
`E logdet A≤logdet B_m`。
另由加权 least-squares 恒等式

`xᵀA⁻¹x = min_(Σb_vv=x) Σ b_v²/S_v`，

使用 `E min≤min E` 得 `E Q≤xᵀB_a⁻¹x`，方向正确；它不是 inverse Jensen。
然后对 `exp(−logdet A/2−cQ)` 用 Jensen，得到所述正下界。

剩余方向在 top1 时 frame 最小特征值为 11；top2 时为
`16−(5+|v·w|)≥8`。因而均张成 R⁵。固定截断阈值的第一、逆矩有限；
独立五方向子基和这些矩也控制 logdet 的正负部，所以该条件 Jensen 有定义。

## 2. 概率和标签没有额外 16、2 或 1/2

正 stable 律连续，ties 概率为零。固定最大方向 v 时的概率元为
`f(z)F(z)^15 dz`，总质量 `∫₀¹u^15du=1/16`，16 个 winner 必须求和。
源把每箱 `(F_hi^16−F_lo^16)/16` 乘方向多重数，没有再除一次 16。

固定无序方向对 `{v,w}` 时，两个坐标仍由方向标签标识，完整正方形概率元为
`f(z1)f(z2)F(min(z1,z2))^14 dz1dz2`。其总质量

`2∫₀¹(1−u)u^14du=1/120`。

因此 120 对、完整正方形、无额外 1/2 是正确组合。
不同箱 i>j 的单方向权重为

`ΔF_i·(F_(j+1)^15−F_j^15)/15`，

另一标签方向概率相同、核可以不同；源明确分别加两核。
对角箱的权重已包含两三角：

`2[H(H^15−L^15)/15−(H^16−L^16)/16]`，

应只应用一次完整箱的核包围，源正是如此。

独立有限检查用三个有理 CDF 箱、结点 `1/7,2/5,3/4,9/10`，准确得到

```
16 Σ max-bin-weight = H^16−L^16,
120 Σ full-pair-box-weight = H^16−16HL^15+15L^16.
```

另给每个标签箱非对称测试代价 `10i+j+1`，逐个完整方阵与下三角“双标签”
累加也完全相等。这个检查会暴露漏标签或对角重复两次，但不是源网格重跑。

## 3. 正 stable CDF/截断矩级数

直接系数可写为

`t_k=(-1)^(k+1) z^(−βk)/[k!Γ(1−βk)]`，
`M_k=β(-1)^(k−1) z^(1−βk)/[(k−1)!Γ(2−βk)]`。

本次逐 k 用 reciprocal-Gamma 求值，没有用源的 k→k+4 递推。
F=`1−Σt_k`，`M=ΣM_k`，
`N=n0−Σ[βk/(1+βk)]t_k/z`，`n0=Γ(1/β)/β`。

M 的 Laplace 变换确是 `βλ^(β−2)e^(−λ^β)`。
先分离 `βλ^(β−2)` 后，剩余在 λ=0 的阶为 `λ^(2β−2)=λ^(−1/2)`，
Hankel 小圆弧消失；cut 上的主控在零点可积、无穷处被 e^(−zr) 控制。
反射公式给上面的直接系数。因此源 M 级数没有遗漏积分常数。
N 是全逆矩减去从 z 到无穷的逆矩尾，逐项绝对积分也合法。

β=3/4 时 k 为4倍数的项精确为零。**M 的 k=1 与 k=5 同号**，
不能在整个有限前缀上套交错级数。两份源代码都完整求和了该前缀，
只在第一个遗漏的 257/258/259 及以后用交错余项，故这点没有造成错误。
尾系数 k→k+4 的比率至多 `z⁻³/(k+4)`，M 倍率在 k≥2 后缩小，
N 倍率增加小于 `(k+4)/k`。因此共同充分界 `z⁻³/k≤64/257<1`
在全部源用域 z≥1/4 成立。

## 4. 一个不同积分路径的有限交叉

在 z=1/4，另取 Bromwich 实部 c=1：

`F(z)=e^z/π Re∫₀∞e^(iωz)e^(−(1+iω)^β)/(1+iω)dω`，
`M(z)=e^z/π Re∫₀∞e^(iωz)β(1+iω)^(β−2)e^(−(1+iω)^β)dω`。

令 `k=cos(3π/8)>0`。因 `Re(1+iω)^β≥kω^β`，截断 R=256 后的尾分别至多

`e^z/π·e^(−kR^β)/(βkR^β)`，
`e^z/π·e^(−kR^β)/(kR)`。

实际用了384-bit Arb、每积分16段。两显式尾为
F `≤5.13707e−13`、M `≤9.63201e−14`，加入双侧误差球后与直接级数球相交。
直接级数给

```
F(1/4) = [0.00019562737139330499917049254749564108864897… +/-1.16e−38],
M(1/4) = [0.00004695626218418010474107720097261777198877… +/-2.90e−39].
```

这里的不同路径交叉只认证到较宽 Bromwich 尾球的尺度；不能把两球相交
解释为独立验证了级数全部显示位数。本次 F/M/N 在 z=1 的直接级数也与源
已锁定的 F/m/a 球相容。两条路径仍共用 Arb，未宣称独立数值库认证。

## 5. 箱矩阵、退化方向及11110的所有尾

top1 的矩阵沿 v 和正交补的特征值分别为 `11c+5z` 和 `16c`，
故源 determinant 与投影二次型正确。11110 的三类 `(p,q,count)` 为
`(16/5,4/5,2)`、`(4/5,16/5,8)`、`(0,4,6)`，所有 q≥4/5。

top2 用二列 determinant lemma 得

`D_c=(11c+5z1)(11c+5z2)−r²(z1−c)(z2−c)`，
`det B_c=(16c)^3D_c`。

Woodbury 的 numerator 展开恰是源 h0,…,h3。独立枚举120对得到源的11个
不变量类与全部多重数，所有 h_i≥0，故源二次型的无相消求值可用。
`(r²,B,E,C)=(9,16,16,48)` 类的 h3=0 对应 x 位于两方向张成的平面，
但剩余 frame≥8、c=a(t)>0，有限阈值矩阵仍正定；没有错误地把 h3 当严格正。

整个箱的 determinant 因子与 inverse 因子分开用 Loewner 顺序包围是合法的：
`B_c` 对 c,z1,z2 均增加。上端 m/z 给 determinant 因子下界，
下端 a/z 给 Q 上界、从而 Q^(−7/4) 下界；上界反向。源不需要假定整个
乘积核单调，也没有用采样角点替代区间证明。

所有遗漏界逐条核对如下：

| 公式/区域 | 独立核对的关键链 |
|---|---|
|max，z<1|`B_a≤16zI`，Q≥1/(4z)，`m≥a≥F/n0`，故核≤`C n0²z^(5/4)F⁻²`；积分 fF¹³，得 `16κC n0²F(1)^14/14`|
|max，z>U|`m≥m(U)`、`a≤a0`、`11m+5z≥5U`，且 Q≥q/(16a0)，每winner概率`(1−F(U)^16)/16`；无发散矩|
|top2，min=t<ℓ|`Q≥1/(20t)`、`D_m≥16st`，核≤`C0m(t)^(−3/2)t^(5/4)s^(−1/2)`；用s≥t及m≥F/n0，积分 fF^(25/2)，得源F(ℓ)^(27/2)界|
|top2，仅一值>U且t∈[ℓ,U]|以 `s^(−1/2)≤U^(−1/2)` 分出尾概率T(U)，剩余A_U由同一源箱的正权重与m(lo)/hi给上界，两个标签因子2正确|
|top2，两值>U|丢弃F(min)^14只会增大；令W=min(S1,S2)，用`P(W>t)=T(t)²`，严格界`E[W^β1_(W>U)]≤U^βT(U)²+C_tail²U^(−β)`，其中`C_tail=(1−e⁻¹)⁻¹`|

其中 `D_m≥16(m+s)(m+t)≥16st` 逐系数成立；top2 的 Q 界来自
`B_a≤t(16I−vvᵀ)+s vvᵀ`，并保留对单体方向正交投影至少4/5。
双大变量时核可以增长，不能只断言有统一常数峰值；源使用 W 的平方尾，
正好避免了这个问题。

两个低尾数值还作了独立直接级数复核：max `1.17850808858…e−7`，
top2 `7.22523310360…e−52`，均与源球相交。高尾的解析推导和代码因子通过审阅，
但其中依赖全部箱的 A_U 未独立重算。读取源各类 finite-upper 加低/高尾的
账目与总 upper 球相容；top2 lower 高于 top1 upper、top2 upper<1e−4 的
源区间比较亦独立检查通过。
