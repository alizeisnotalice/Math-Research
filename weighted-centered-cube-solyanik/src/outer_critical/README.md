# 外层弱型常数：严格证书与本机复算

数学定义与全域证明见主稿第6、9节；本目录的有限候选不决定最优弱型范数。

- `python3 atomic_certificate.py`：仅用标准库。读取175条有理候选，独立计算连续块与全部子集两种严格光晕（按有限端点零测等价合并），用200位二进有理区间核验幂积分与输入成本；并以100次严格符号二分包围四个A1方程根。每个根的符号和幂根均以整数不等式验证。生成可再生的`certificates.json`与必要摘要`certificate_summary.json`。
- `wolframscript -file symbolic_check.wl`：Mathematica 15验证双原子公式、两个精确有理比较及τ=1/2的根/常数；其他参数的高精数值仅作交叉复算。
- MATLAB运行`matlab_check.m`：实际R2026a Update4检查20个原子链和4个比较上界。浮点合并容差1e-14，结果属于独立数值控制；严格证据来自Python有理证书和正文证明。
- `search/`：15进程两阶段DE搜索及必要种子、摘要，见其README。搜索器与验证器没有互相导入几何/幂函数。

候选输入含75个阶段1最终候选、25任务各4个阶段2初始/最终候选，共175条；重复构造保留不同来源身份以审计种子保持。τ为1/4、1/2、3/4、9/10、1；原子数上限8，重合原子会合并。

τ=1/4和1/2分别有33条严格劣于简单双原子、2条与其区间重叠，没有证书严格优于它；浮点末位优势不作改进。后三个τ的有限候选全部低于Melas值，这不构成Wτ的上界。摘要`operator_bounds`的全域上界另由正文证明Wτ≤2Aτ，再由严格根包围给数值证书；不可与有限样本上界混淆。
