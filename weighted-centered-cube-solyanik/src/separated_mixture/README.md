# 分离奇点：严格局部证书与数值控制

主定理在`paper/mixture_extension.tex`：外层始终用Lebesgue平均，权只进入光晕测量和输入成本。一般证明不依赖有限搜索。

`python3 local_certificate.py`仅需标准库，检查180个有理参数配置。权为MX.9，δ=2^(-j), j=0,5,10,20；t=2^(-k), k=4,6,…,32；ε=δt^p, p=1,2,4。置h=t/(1+2t)，在δ+ε[-1,1]内删掉孔δ+εh[-8/5,2/5]作为输入E。

对孔内中心，取半径ε−|x−δ|；(2+8/5)h<1保证见证包含整孔并留在外盒内，h/(1−8h/5)<t保证严格平均>1−t。其余外盒内部点由输入密度或同一严格见证覆盖。因此δ+ε(-1,1)是严格光晕的子集，外端点无需属于光晕，积分中为零测集。

脚本以180位二进有理数包围每个平方根，并以整数isqrt不等式逐项核验；由独立上下界计算µ(孔)/µ(E)/sqrt(t)。180例均通过，在k32,p2的四个δ测试中该量严格大于21/20。它们给特定阈值的合法下界，不是完整halo计算或最优性证明。另用保守的异点密度界严格检查其它分量的质量上界；未使用浮点容差通过证书。

`local_certificate_summary.json`是最小摘要；完整表`local_certificate_full.json`可再生而不进入Git。`wolframscript -file symbolic_check.wl`实际用Mathematica15核对碰撞系数、半轴平移差的积分和常数。数值批量与MATLAB入口见`compute/README.md`，其浮点值及积分阶次比较不作为严格区间。初次试跑误用了内禀平均，已隔离到本机rejected并完全排除出证据；最终外层程序先计算与权无关的halo，再逐权积分。
