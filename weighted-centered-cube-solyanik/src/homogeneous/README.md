# 齐次权常数的本机批量复算

先运行 `python3 factor_batch.py`，再运行 `python3 verify_factors.py`。批量程序使用15进程，各进程BLAS/OMP线程1，无墙钟终止限制。它生成3429组网格、逐任务原子检查点及进度。再次运行会检查参数、阶数、版本与有限性再复用；`computed_jobs`、`reused_jobs`及`new_integrand_samples`明确区分新算与缓存，逻辑总节点数不代表续跑又进行了同等计算。

独立验证器检查完整键集合、非空输出及80组SciPy自适应积分，另有3个闭式校验，未导入批量积分函数。`wolframscript -file symbolic_check.wl`验证面上积分与窗口恒等式；MATLAB运行`matlab_check.m`完成30组独立积分。

`run_summary.json`为首次完整运行与续跑验收的必要摘要。检查点、完整网格、CSV与临时文件可再生成，不进入Git。数值收敛差和积分器误差估计不是严格区间证书；正文结论由一般证明给出。

模型为中心方体平均、测量权||x||p^(τ−n)，β=τ/n。体积D使用lp单位球体积；面上积分为n−1维，n=1或p=∞分支使用精确值S=1。其余S直接计算，不作下限截断。分数p的面上函数无原点奇点，但不宣称在边界解析或必有几何收敛。
