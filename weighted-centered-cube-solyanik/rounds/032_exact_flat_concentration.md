# 第32轮：平坦权精确集中与光晕维数放大

## 问题与已证结果

本轮精确求解q=0、wγ=|x1|^-γ的全平移方体集中函数，并构造了随维数放大的真实光晕下界。小γ严格正例排除通用系数1，半次方历史阴性搜索的适用范围随之收紧。完整光晕锐系数仍未闭合。

固定0<γ<1、β=1−γ、n≥1。对任意平移中心方体Q及|A|≤u|Q|的子集定义Ωγ(u)。令M=aβ+(u−a)β、D=aβ+(1−a)β，则每个0<u<1有唯一a*∈(0,u/2)满足K=M'D−MD'=0，且Ω=M(a*)/D(a*)，最大值取得且与n无关。固定γ时

Ωγ(u)=2^γ uβ−2^(1−2β)u^(2β)+o(u^(2β))。

γ=1/2时a*=u/[2(1+sqrt(2u)+u)]、Ω=(u+sqrt(2u))/(1+sqrt(2u))；u1/8精确给a1/26、Ω5/12。这里根号为sqrt(2u)，不是sqrt(2)乘u。

全部0<t<1的外层上界为2^nΩ(t)/(1−Ω(t))，half例简化2^n(t+sqrt(2t))/(1−t)。这不是光晕的最优系数或二阶公式。n1已有C_out−1~tβ，正好给领先1≠2^γ的严格反例；n≥2领先系数和极限存在性仍开放。

## 完整证明

1. 对切片占比b(s)∈[0,1]作bathtub重排，精确归约长1区间；反向用B乘整个切向截面取得，所以n独立而非仅上界。
2. 不跨零I=[r,r+1]，最优子段给比值≤uβ：∫0^u(r+s)^−γds=uβ∫0^1(r/u+y)^−γdy≤uβ∫0^1(r+y)^−γdy。
3. 跨零反射为[-a,1−a]、a≤1/2。a≥u/2时对称最优子段分子固定，D递增，故退到a=u/2。a≤u/2时比值M/D。K'(a)=β(β−1)[a^(β−2)(D−M)+D(u−a)^(β−2)−M(1−a)^(β−2)]<0；K0+=∞、K(u/2)<0，所以唯一内根胜所有端点/非跨零输入。M<D保证Ω<1，因而全阈值扰动上界分母正。
4. 写a*=ub，D(ub)→1在闭区间b∈[0,1/2]一致，m(b)=bβ+(1−b)β唯一最大在1/2，故b→1/2。随后邻域驻点m'D=m∂bD给b−1/2=O(uβ)，再展开M、D，得到准确二项；不能跳过先排除b→0这一步。
5. half例驻点用r=sqrt((u−a)/a)、s=sqrt((1−a)/a)化为(r−1)(s−1)=2，再解得闭式。u1/8的有理距离为4/104、9/104、100/104，平方根比2、3、10直接给5/12。
6. n1取H5的τ=β、角向恒一即得光晕领先1。集中取等的高权子集靠近0，但其方体中心通常远离它，不能当作每个新增点的中心见证。

## 切向网格给出的严格维数下界

最终本轮还发现并独立核验了正的光晕改进。对n≥2，令Λγ=2^ββ^βγ^γ，则完整允许输入满足

max{1,Λγ^(n−1)} ≤ liminf t^-β(C_out−1) ≤ limsup t^-β(C_out−1) ≤ 2^(n+γ)。

上界由精确Ω和扰动界得到；baseline1已有远移slab。新增下界取整数k、ℓ>0、η>0，每个切向坐标用长ℓ、间距1的k个带，取其(n−1)重笛卡尔积P。令h=(1−η)(2/ℓ)^(n−1)，Dt=[−1−th,1+th]×[-1,k(1+ℓ)]^(n−1)，孔Z=(-th,th)×P。每孔点的半径1中心方体位于Dt内；每个坐标窗至多碰本带，因此缺失体积≤2thℓ^(n−1)，比例≤(1−η)t<t。µZ=(2/β)(th)^β(kℓ)^(n−1)，µDt=(2/β)(1+th)^β[k(1+ℓ)+1]^(n−1)，所以所有0<t<1的光晕下界为Jtβ/[(1+th)^β−Jtβ]，J=(1−η)^β[2^βℓ^γ/(1+ℓ+1/k)]^(n−1)。分母正。

固定几何先t→0，再η→0、k→∞，最后优化ℓ=γ/β，得Λγ^(n−1)；没有要求联合收敛一致性。γ1/5时Λ^5=4096/3125>1，因此所有n≥2已有严格大于1的系数下界。固定不等指数精确传递使上下界系数同乘a_min^-β。

仅两带也可严格改进：n2、γ1/20、k2、ℓ3/38、η1/76给h25、见证缺失75t/76<t，J=25^(19/20)/20，J^20=5^18/2^40>2。因此真实光晕的liminf至少J>2^γ>1，连把全Ω的首项当作光晕首项上界也会失败。此是解析构造与有理整数证书的结论，不是有限t的归一化假象，更不是half搜索发现；不声称liminf为真实极限或最优值。
