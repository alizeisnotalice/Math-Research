# 第16轮：共同尺度限制的精确高阶障碍

日期2026-11-05。目标是核查有限容量优化中能否把见证尺度统一；不把这一辅助模型代替真实全体输入。

## 严格结论

二维半阶、质量一输入，四中心(±a,0),(0,±a)强制共用边长ell。T(a,ell)=sup_E min_i|E∩Qi|/ell。当ell>2a时，覆盖重数至少j的区域面积为S4=(ell−2a)²、S3=ell²−4a²、S2=ell²、S1=ell²+4aell。装入质量一的最大总捕获M有五段精确式，故T=M/(4ell)。对称群平均在原子容量层面可实现等捕获，未把分数密度直接当作实际输入。

对0≤a≤1/8，全部ell>0优化恰给
H(a)=(1+2a²)/sqrt(1+4a²)−a。
当a>0唯一最佳ell=sqrt(1+4a²)，实际最优输入是覆盖重数至少三的区域，即边长ell的方体挖去四个边长a的角块，质量恰为1。

对α>9/10，所有可能的共同严格见证由pair判据自动限制到a<1/8；共同严格可行精确等价于a<a_α，其中H(a_α)=α。临界值本身不可严格达到。

a_{1−t}零点附近解析，Lagrange反演生成任意阶，前十阶为
 t+2t⁴−8t⁶+16t⁷+30t⁸−160t⁹+64t¹⁰+O(t¹¹)。
因此对t的首个偏差四阶sharp，减去2t⁴后的首个偏差六阶sharp。

矩形输入允许方向依赖尺度，其四轴半径可逼近A_α=(α⁻¹−α)/2；对全部α∈(9/10,1)，A_α>a_α，差为(1/2)t²+(1/2)t³+O(t⁴)。所以共同尺度限制在二阶半径上已排除合法输入，不能作为全体问题的无损约化。四轴半径不等于光晕面积，本轮未确定全体三阶系数。

## 实际本机计算

- Wolfram15：H导数、最佳尺度捕获恒等式残差0，InverseSeries到十阶与正文相同；保存输入和输出。
- Python Fraction：a=1/100,1/20,1/10,1/8；ell=.5,.9,.99,1,1.001,1.01,1.05,1.2,1.5,2，共40组。原子边界网格精确重验全部S_j及贪心总捕获M。SciPy原始/对偶LP与闭式η差≤1.250e−16；一般最优性由正文证明，有限检查不替代证明。
- SymPy1.14独立用Lagrange系数公式复核1..10阶，精确为1,0,0,2,0,−8,16,30,−160,64。
- mpmath1.3.0：80位、280次二分，α=.91,.95,.99,.999,.9999，第四比值(a−t)/t⁴趋2、第六比值(a−t−2t⁴)/t⁶趋−8；最小t处分别约1.999999920、−7.998399700。
- MATLAB R2026a独立边界网格+linprog完成同40组，误差≤1.111e−16；另以稳定公式H=1−a+4a⁴/[sqrt(1+4a²)(1+2a²+sqrt(1+4a²))]求5根，避免高阶相减失精度。代码分析无问题。

复现：`wolframscript -file verification/common_scale.wl`；`python3 verification/common_scale.py`；MATLAB运行`verification/common_scale_matlab.m`。Python脚本保留参数、环境、精度及结果于results/common_scale_python.json，其余输出同前缀。
