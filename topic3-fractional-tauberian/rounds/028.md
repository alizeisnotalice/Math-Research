# 第28轮：任意二阶近方体输入与 sharp 四阶余项

日期2026-11-05。继第27轮固定支撑角孔，本轮直接研究沿边逃逸的细长孔，并放宽至任意内缺、外加质量。仍为二维无权半阶、中心轴平行正方形基。

## 严格结论与范围

固定A≥0，Q0=[−1/2,1/2]²。对所有可测E（允许无界），若|EΔQ0|≤At²，则统一有

|H(1−t,E)|/|E| ≤ 2t²+2t³+C_A t⁴，0<t<t_A。

不要求E包含于Q0，不要求孔的支撑、数量、凸性、单调性或边界正则性；E可随t任意变化。对这一类取上确界C_A^near(t)，得到

C_A^near(t)=2t²+2t³+O_A(t⁴)，且 C_A^near(t)−2t²−2t³=Θ_A(t⁴)。

阶数sharp来自实际正方形下界2t²/(1−t)，其余量精确为2t⁴/(1−t)。尚未求出这个类的最优四阶系数；不把余项阶数与系数等同。

因此，若质量一输入族存在固定正三阶增益ε，即halo≥2t²+(2+ε)t³，则其到所有平移单位正方形的最小对称差除以t²必须趋于无穷。这个必要逃逸条件不声称该条件足以改善三阶项。

此外，挖去宽At²的整边条带是精确矩形模型，其比值为

2t²+2t³+2t⁴+2t⁵+(2+A²/4)t⁶+O_A(t⁷)。

相对正方形的差为(A²/4)t⁶+O_A(t⁷)，A>0时该比较的六阶是sharp。不是全体六阶系数。

全体常数的三阶区间仍为[2,10/3−2⁻⁶⁸]，极限存在性与最优值未定。第一阶偏心矩形R_(ρ,t)与正方形之差可为O(t)，不在本轮统一类中，不能借近方体定理跳过它们。

## 证明的关键变化

旧角孔的Lipschitz常数会随支撑逃逸而发散，不能把K(t)→∞直接代入第27轮余项。本轮完全更换传递方式。

1. **质量先归一化。** 若M=|E|，置F=M^(−1/2)E。经中间缩放正方形，|FΔQ0|≤(|EΔQ0|+|1−M|)/M≤4At²。不假定不规则E本身对伸缩连续。
2. **精确容量，不展开孔。** 对四个任意独立见证，覆盖数N给出∫F N≤2+∫(N−2)+。逐点恒等式(N−2)+=Σ三重交示性函数−2四重交示性函数，把整个共同质量写成Ψ=2+Σ三交面积−2四交面积。所有外加质量自动包含，无需重复记账或孔尾函数。
3. **保留全部尺度。** 严格见证边长在(1−t,(1−t)⁻¹)，与Q0比较先把中心限制为O(t)。参考正方形的精确一阶缺陷D=r+Σ(|u|−|v_j|)+，配合内含半径给出outer r=1+O_A(t)，见证距一阶平坦区为O_A(t)。没有把平坦外分支直接删掉。
4. **只投影纯几何二阶项。** 三交与四交均为矩形，故Ψ=4+tL+t²R是精确式。每个坐标的L等于两个最小右位移减两个最大左位移，从而L≤2Σu−Σr，对全部尺度成立。R是有限min/max乘积，在有界框架上一致Lipschitz；只有它被投影至flat，误差O_A(t)。
5. **连续参数的精确预算。** flat时R+2Σu≤8min(x,1−x)。24个尺度次序单形、两个x端点、每个15个二次Bernstein系数，共720个精确有理数全部非负。其直方图为0:408，2:72，4:128，5:32，6:56，8:24；正文解释单形覆盖、关于x的仿射性和非负基展开，承担严格连续域结论。该预算也可由第27轮四孔耦合解析证明独立得到。
6. **不用射线连通性。** 对每方向四个outer光晕点求和容量并令其趋于上确，得ΣR_c(x)≤4+8m(x)t+O_A(t²)。开光晕的径向上确可测，星形外包即可积分得到上界。原截面允许不连通。

正式正文为paper/sections/06p-near-square.tex，紧接上一轮一般角孔节。见证统一记P_c，参考输入记Q0；终审纠正了一处批量替换造成的算子基字母，最终仍为mathcal Q_c。
