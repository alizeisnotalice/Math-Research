# 第29轮：近偏心矩形的显式三阶包络

日期2026-11-05。以第28轮已核验提交a3780c4为基线，继续无权二维半阶、中心轴平行正方形模型。本轮没有预设近矩形类的三阶系数必为2，而是同时研究真实上界、容量松弛的边界和跨方向障碍。

## 严格结论

设面积一参考矩形R_(rho,t)的两边为e^(rho t)、e^(−rho t)，固定A≥0。存在仅依赖A的K_A、C_A、t_A，使

0<t<t_A，p=|rho|≤1−K_A t，|EΔR_(rho,t)|≤At²

蕴含

|H(1−t,E)|/|E| ≤ 2t²+[2+2p(1−p)]t³+C_A t⁴ ≤ 2t²+(5/2)t³+C_A t⁴。

E可无界，允许任意内缺、外加质量和随t变化的扰动。常数统一于明确的间隙范围，尤其统一于p≤1−ε。该类比近正方形更广，因为参考矩形与正方形之差可以是O(t)。本定理仍是输入类上的上界，未改变真实全体C的已知三阶区间[2,10/3−2⁻⁶⁸]。

2+2p(1−p)是共同区间上纯四见证容量的sharp包络，不是已证明的真实最优三阶系数。几何端点选择可以逐方向达到包络，但未证明存在一个共同输入同时实现这些选择。

当p_t→0或p_t→1并始终满足间隙条件时，近矩形类sup具有匹配展开2t²+2t³+o(t³)。若进一步p_t(1−p_t)≤M t，则sup减去2t²+2t³为Θ_(A,M)(t⁴)，余项阶数sharp，四阶最优系数未知。未把这一结论外推到1−p<K_A t的全部薄层。

## 共同区间的解析优化

偏心平坦区I_rho(x)=[L,U]为

L=max(rho/2−x,−rho/2−1+x)，U=min(rho/2+x,−rho/2+1−x)。

区间宽度至多2min(x,1−x)。令中心mu=(L+U)/2、半宽h=(U−L)/2、u_c=mu+h v_c。由于区间宽度受限，交集的min/max仍按坐标符号分组，得到精确恒等式

R(1,u;x)+2Σu =8x(1−x)+h²T(v)+4mu hΣv+8mu²。

T(v)由rho=0、x=1/2的旧预算精确定义，故T≤8；其360项独立有理Bernstein证书均非负。于是四尺度共同区间的精确最大值为

8x(1−x)+8max(L²,U²)，全部尺度同取绝对值最大的端点时达到。

这个公式的方向积分恰为2+2p(1−p)，最大为5/2。容量中的共同输入预算始终保留；“sharp”只指这个几何松弛函数，不能自动传成真实输入极值。

真实传递使用参考矩形的精确一阶缺陷

D_rho=Σ_j max(v_j,|u−c_j|)，c_1=rho/2,c_2=−rho/2，min_uD_rho=max(r,|rho|)。

间隙使内含半径1−C_A t严格低于高水平并保证outer附近的平坦区非空。所有near-outer见证距I_rho为O_A(t)，只投影纯几何二阶项，随后四方向上确半径相加、以可测星形外包积分。归一化F=|E|^(−1/2)E经中间缩放矩形给FΔR≤4At²，不要求输入正则性。

## 精确障碍与更细的固定模型结果

- **两对称方向的空矩形预算为假。** rho=1/2、四角相同孔D=[0,3/2]×[0,1/4]时，G(x)=3x+1/8于[0,1/8]，G=1/2于[1/8,7/8]，G=25/8−3x于[7/8,1]。G(.1)=G(.9)=17/40，而空孔分别为17/40、9/40；四象限配对平均从13/10升至17/10。因此只做x与1−x配对仍不够。但这个真实输入的三阶系数为4∫G=29/16<2，并非全局改善反例。
- **参考矩形统一展开：** 2t²+2t³+(2+rho²−rho⁴/2)t⁴+(2+rho²)t⁵+O(t⁶)，|rho|≤1一致。
- **一阶端点不是实际严格临界。** 实际参考矩形的临界参数为−log(1−t)/t=1+t/2+t²/3+t³/4+…；在临界处严格光晕为空。rho=1仍非空，它与矩形测试上确界R(1−t)的差为(1/2)t⁶+O(t⁷)，该比较的六阶sharp。二阶扰动的全临界层尚未闭合。
