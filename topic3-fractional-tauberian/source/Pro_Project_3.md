# Pro 研究指令｜项目 3：分数次极大算子的尺度不变光晕

请结合项目 3 原始论文与仓库最新研究记录、论文和审查材料，从最新有效进展继续。先核查现有分数次估计理论及全部关键推导，发现问题及时修正；随后持续开展实质性研究，以下方向不限定具体方法。

## 研究顺序与目标

1. **先完成无权单线性理论。** 核查模型定义、尺度不变归一化、参数范围和现有估计；在此基础上优化光晕及 Tauberian 常数，争取 sharp 指数、最优常数和精确公式。重点区分固定集合的结果与对所有集合取上确界的最优常数。
2. **继续推进高维与高阶。** 对已有一维、二维和固定方体等结果，研究能否推广到更高维、更一般输入；尝试确定真实最优常数的高阶渐近和精确系数，并建立匹配上下界。根据实际情况选择最有希望闭合的问题，不预设高阶展开必然存在。
3. **无权模型理清后，再研究带权模型。** 分别核查并推进原论文中的外层加权及其他相关带权模型，明确其定义、假设和量词；尽可能求取 sharp 阶、最优常数或精确渐近。
4. **单线性基础稳固后，适当推进多线性。** 检查对角约化及一般多输入结果，研究哪些 sharp 常数、高阶信息可以严格传递。注意分数次模型的归一化与适用范围，不混同不同输入及权模型。

## 共同要求

- 核对最新公开文献，准确比较算子、几何基、权、归一化、参数与现有最佳结果。
- 清楚区分严格定理、条件结论、数值探索与猜想；计算不能代替一般证明。
- 每轮记录已完成的推导、未解决障碍和下一步方向，并维护可读的论文及项目记录。不要只给计划。
