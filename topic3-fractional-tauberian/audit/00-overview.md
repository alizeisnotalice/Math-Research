# 核查总览

基线为source/original.pdf，SHA-256见source/provenance.json。原稿53页中的72个具编号定义、命题、引理、定理、推论、注和问题均进入原页索引；摘要与引言通过对应主结果复核，原第15–16节的实质边界归入应用末节，原18条文献及新增Aldaz记录初轮共19条已核验；第8轮按最新用户指令补核4条2026年无权相邻预印本，第9轮再核验Brunn–Minkowski实际使用版本，当前共24条，阅读范围另记。

每项数学状态见分组审计。代码的coverage检查只保证索引对应、标签和引用一致；完整推导的判断依赖正文证明及独立复核。

主要纠正历史资料的问题：旧非中心上界漏外层n次幂；旧协方差体长度缩放写成(1-alpha)^(-1/n)；旧审计把原稿已有的固定模型/全体liminf区分错误描述为原稿漏洞。原稿参考文献另有题名、DOI、页码或出版状态修订，详见references/verification.md。

第9轮通过共同核、面层压缩与凸纤维对称平均，证明中心方体全体输入首项和紧分数阶区间的一致O(t^(n+1))余项；原固定资料定理与liminf下界的历史量词保持不变，新上界单独见gl:main。

第18轮新增二维半阶全体体积上包络pb:volume，将三阶归一化剩余量的liminf/limsup夹在[2,10/3]。精确两点差体的体积方法已达其自身上限；这不等于全体C的三阶系数已确定。

第19轮的pb:four-certificate与pb:four-existence证明真正中心方体几何中六点对分别可行而四点共同不可行，允许独立尺度。pb:strict-gap进一步排除全体上确界等于两点包络，得到每固定α的严格正间隙；没有定量间隙或新的三阶区间。

第20轮pb:fourier-stability以平面支撑函数奇偶分解证明平方根稳定性，其指数在一般凸体类中sharp；pb:cap-distance及pb:quant-transfer把四球共同障碍转成亏损ε²/3。pb:sixth-gap在全部0<t≤.01得到U−C≥t6/768，未证明该间隙阶最优。mom:sixth-envelope只改进统一高矩层析包络，非真实泛函的六阶展开。

第21轮pb:parabolic-gap把全体亏损下界提高为2⁻²⁴t^(9/2)，有效域0<t≤.01；四法向归零和各向异性patch完成凸包到原光晕传递，未将局部cap或有限搜索当一般证明。pb:tangent-union的切向平方损失系数4及pb:local-caps的2/3缺深指数各有等号/渐近例证明不可改进，但不据此声称全体9/2阶sharp。mom:parabolic-envelope仍只改进高矩统一包络。

第22轮pb:quartic-gap得到真实全体亏损U−C≥κt4（绝对κ,t0存在但未数值化），由一般侧弧四邻域证书、缺口半凹性/最大函数、随参数平移及分离孔洞计数闭合。pb:quartic-relaxation证明该连续四邻域几何松弛自身的亏损阶恰t4，未构造真实halo或收窄三阶区间；mom:quartic-envelope只传递统一上包络的p⁻⁴减项。

第23轮wr:rigidity仅在四轴点位t+O(t²)的明确有限见证假设下，证明任意可测输入与单位近矩形L1差O_M(t²)，且该阶sharp；未外推为全体近极值集合刚性。wr:eight-rectangle与wr:eight-series给轴/对角八点矩形模型的完整精确分支和任意阶余项；wr:l-counterexample以L形角孔输入使另一smooth八点族严格超越全部矩形，量词为固定γ<σ<3/8后t充分小。当前真实全体C的三阶区间及四阶亏损下界均未改变。

第24轮的共同尺度 sharp 结论仍对所有面积一可测输入成立，但只约束指定八点及共同边长。方向推广须使用 `cs:rect` 的两分支矩形半径；不能将第23轮b=1/4的必要式直接外推。角孔参数全区间有退化端点分支，见 `cs:L`。

第25轮已将全体包络亏损阶从四阶下界推进并闭合为三阶：ic:pair → ic:radial/ic:boxes → ic:transfer → ic:cubic-gap。关键量词为任意面积一可测输入、任意独立八尺度和参数统一的正κ,t0；常数存在而未数值化。近端全体C的三阶上极限现在严格小于10/3，而非只对有限模型严格。见mom:cubic-envelope的真实高矩次项传递。

第26轮的ec:boxes与ec:cubic给出两组显式常数（κ,τ）=(2^-72,2^-8)、(2^-68,2^-14)。新定量支撑传递直接核对表中η，未沿用旧ic:transfer中η≤10^-6的保守选择。Python有理账本验证标量充分条件，任意输入与连续尺度的推论由正文几何证明承担。
