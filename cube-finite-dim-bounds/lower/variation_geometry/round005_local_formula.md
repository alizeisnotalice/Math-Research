## 1. 法向有限区间引理

固定一条法向坐标，接触点为0。旧的正长度区间有三类：在0结束，其右端为εβᵢ+o(ε)；在0开始，其左端为εαⱼ+o(ε)；或以正距离跨过0。新生零宽区间的两端为εaₖ+o(ε)、εbₖ+o(ε)。所有指标族有限；取ε↓0；所有余项统一为o(ε)。退化区间当左端大于右端时为空。端点开闭不影响Lebesgue长度。

若存在跨面旧区间，局部覆盖恒为满线，局部一阶变化D=0。否则速度集合为

`S = ∪ᵢ(-∞,βᵢ] ∪ ∪ⱼ[αⱼ,∞) ∪ U`, `U = ∪ₖ[aₖ,bₖ]`。

基准集合S₀按左右旧区间是否存在，分别取左半线、右半线、两者或空集。新生点在基准中长度为0。定义

`D = ∫ℝ(1_S(z)-1_S₀(z)) dz`。

该积分有限，因为远处尾部覆盖不变。设L=maxᵢβᵢ、R=minⱼαⱼ，只在相应族非空时定义。准确公式为：

|旧覆盖|D|
|---|---|
|两侧都有|若L≥R，则0；若L<R，则 `-(R-L)+|U∩(L,R)|`|
|只有左侧|`L+|U∩(L,∞)|`|
|只有右侧|`-R+|U∩(-∞,R)|`|
|两侧都无|`|U|`|

各式中U必须先取真实并集，不能相加各薄片长度或取凸包。并列结束端用max，并列起始端用min，不任取一个盒；若跨面区间存在则它遮蔽所有一阶变化。正宽旧空隙的两个边界是不同接触点，分别结算；这里的(R−L)是ε尺度中新开的缝。

证明：选择M严格大于所有有限速度的绝对值。S与S₀在[-M,M]外相同，所以D是 `|S∩[-M,M]|−M(左侧存在+右侧存在)`。若两侧存在，半线并集唯一可能的空隙是(L,R)，U填缝的长度恰为该空隙与U的交；只有左侧或右侧时，旧半线边界位移分别贡献L或−R，U只贡献半线外的部分；两侧都无时贡献|U|。这也证明所有公式和端点并列情形。

再证它是严格局部导数：取足够小的固定ρ，使(-ρ,ρ)不含其他基准端点。对精确仿射端点，令x=εz，所有变化限制于[-Mε,Mε]，换元给长度变化恰为εD。端点为仿射+o(ε)时，有限区间族并集的对称差长度不超过各端点误差绝对值之和，因此总误差o(ε)。这不是由有限差分推测导数。

## 2. n4对称薄片特例及接口

若新生区间都是[-Bₖ,Bₖ]、Bₖ≥0，则它们嵌套，U=[−B,B]，B=maxₖBₖ（无薄片取B=0，单点不贡献长度）。内部接触公式成为

`D = −max(0,R−L) + max(0,min(R,B)−max(L,−B))`。

这正是当前n4内部gap结算；L对应`plus`，R对应`-minus`。外露侧公式也保留已有半线负位移造成的损失，同时允许与半线分离的新生薄片贡献体积。对称简化要求新生中心在**实际所用坐标中**一阶静止。n4在归一化分数坐标中采用固定相位、周期O(ε)移动，作者确认该坐标中的新生中心固定；物理坐标下周期改变一般会带来中心速度，不能仅凭“相位固定”强制对称。若实际坐标中心速度为w，薄片须用[w−B,w+B]，或先转换为中心静止的归一化坐标；相位本身移动时也须用一般[aₖ,bₖ]。

直接调用：

```python
from fractions import Fraction as F
from normal_intervals import signed_length
D = signed_length(left=[F(-1)], right=[F(2)],
                  slabs=[(F(-1,2),F(0)),(F(1),F(3,2))])
assert D == -2
```

`left/right`传端点的坐标速度；右侧必须先把外向速度变号。空列表代表该侧旧覆盖不存在；`crossing=True`代表严格跨面遮蔽。接口拒绝float，接受整数、Fraction或准确十进制字符串；倒序薄片视为空，重合端点/零长度薄片不贡献长度。本接口本身不核验这些速度来自合法共同半径见证。

## 3. 提升至4D有限盒联合体积的充分条件

固定有限个轴平行盒 `Bᵢ(ε)=∏ⱼ[ℓᵢⱼ(ε),uᵢⱼ(ε)]`，允许基准零宽盒。每个端点满足 `e(ε)=e(0)+εv+o(ε)`，族有限所以余项统一；所有盒位于某固定有界区域。比较完整并集而非盒体积相加。建立包含每个基准端点的全轴安排；每个法向超平面再按其余三轴所有基准端点切成开矩形面片。包括外露面、无跨面遮蔽的内部接触面，以及只有新生盒而无旧覆盖的薄片位置。

在每个面片P内部，选取在三切向坐标严格包含该点的盒。法向上正宽盒按结束、开始、跨面分类；只有一个零宽坐标且其余三方向正宽的退化盒提供[aₖ,bₖ]。两个及以上零宽坐标的盒由统一O(ε)端点速度保证体积O(ε²)，故无一阶项。空盒不贡献。每个P的速度族和D常数。则

`|∪ᵢBᵢ(ε)| = |∪ᵢBᵢ(0)| + ε Σ_P |P|₃ D_P + o(ε)`。

证明：先把每个端点替换为其仿射近似。有限盒并集的对称差体积由各盒对称差之和控制，而每个盒对称差≤常数×端点误差总和，故替换误差o(ε)。现端点精确仿射，令K大于全部速度绝对值。联合覆盖变化只在所有基准超平面的Kε邻域内。两个不同坐标的此类邻域交集体积O(ε²)；同轴不同超平面有正最小距离，足够小ε时不相交。除去这些交集后，在每个面片离边界Kε以上部分，切向归属固定，法向恰为第1节模型，因此贡献εD_P乘该修剪面片面积。修剪面积相差O(ε)，而D_P有界，补回误差O(ε²)。有限求和并补回所有邻域交集，得公式。多零宽盒也位于至少两条此类邻域交集，故已包含于O(ε²)项。

这允许切向端点随ε移动、多坐标周期速度和多个见证重叠；它们的交叉影响进入o(ε)，每个坐标的正常数项必须在相应法向面求和。若仅枚举外露面，内部开缝被漏掉。人工基本胞元边界不应当自由外露面：可先用有限周期像覆盖较大区域并在固定胞元截取、使边界剪裁也进入安排，或直接把胞元两侧一致识别；周期像和截取的完备性须另核。

## 4. 共同半径、周期和完整质量

几何定理允许一般端点速度；代入中心方体问题时，必须由每个合法见证的同一个半径导出所有四轴速度。若该见证质量 `N₀+εN₁+o(ε)`、阈值为1，则 `r(ε)=(N₀+εN₁)^(1/4)/2`，`r′(0)=N₁/(8N₀^(3/4))`。若第j周期 `aⱼ(ε)=aⱼ(0)(1+εdⱼ)+o(ε)`，则归一化半径的速度是 `r′/aⱼ−(r/aⱼ)dⱼ`。不能对各面独立选择这个速度。

记归一化联合体积V(ε)=V₀+εV₁+o(ε)，周期行列式J₀=∏aⱼ(0)，完整输入质量M(ε)=M₀+εM₁+o(ε)。真实比值右导数为

`Q′(0+)=(J₀/M₀)[V₁+V₀(Σⱼdⱼ−M₁/M₀)]`。

n4的M₀=M₁=1时成为 `J₀V₁+Q₀Σdⱼ−Q₀`。本报告只证明所指定有限合法见证盒族的体积公式；不能自动证明它等于全部超水平集，不能自动保证n4的所有新生见证与周期像已枚举，也不能把正方向预测当成ε>0的严格数值证书。新候选仍需完整质量、准确联合体积和独立审计，再用既有一般L1传递。

## 5. 准确反例与遗漏风险

1. **漏内部接触**：`[-1,−ε]∪[ε,1]`，再乘[0,1]³。外部边界静止，但4D联合体积恰2−2ε，内部D=−2。只算外露面预测0。
2. **把薄片取凸包**：L=−2、R=2、U=[−2,−1]∪[1,2]。内部D=−4+2=−2；凸包[−2,2]错误预测0。
3. **强制对称薄片**：旧左半线截至0，新生速度区间[1,2]。准确D=1；用[−2,2]错误给2。相位移动时对称性必须证明。
4. **缺O(ε)控制而丢弃多零宽盒**：新生4D盒 `[0,√ε]²×[0,1]²`，基准有两个零宽方向，真实体积恰ε、导数1；按多零宽盒O(ε²)规则会给0。它违反有限端点速度假设。取ε=s²且有理s，体积恒等式同样准确。

前3项是有限有理局部配置，均落在准确校验覆盖的语义范围；它们是几何反例，不冒称全部都能实现为某个合法方体卫星见证族。第4项说明提升条件为何必要，不用于否定当前O(ε)周期模型。

## 7. 实际模型的N₀=0项必须单列（主代理复核后补充）

第4节半径速度公式**仅限N₀>0**。真实卫星模型还含没有主原子的纯卫星singleton：质量εm的孤立原子接收盒为以卫星为中心、共同半径 `r=(εm)^(1/4)/2` 的4D方体，四条边都是O(ε^(1/4))，体积恰εm。它在ε=0有四个零宽方向，却贡献一阶体积；所以第3节的O(ε)端点定理不能直接覆盖真实模型的全部见证。若这类盒未由另一理由遮蔽且未另结算，当前面片模型不是完整导数。

对于固定有限个纯卫星基点（不同基点有固定正间距），中心自身固定或仅移动O(ε)，旧主盒端点满足第3节假设时，可以另行准确结算。此处“重合先聚合”严格指**每个ε实际处于同一点的原子**，才能直接把质量相加后使用单个singleton接收cube。仅在ε=0合流、ε>0相对位移O(ε)的簇不属于这一直接聚合情形，见下文联合见证条件。令Kₚ为旧正宽盒并集在卫星基点p的局部切锥：只保留基准闭盒含p且四方向均正宽的旧盒，在各坐标上p严格内部时不限制方向，p等于下/上端时分别限制正/负方向。其余距离p为正的旧盒在足够小邻域内无影响。Kₚ是有限个轴平行正交锥的并。基准零宽盒不能当作覆盖任何开象限；其O(ε)厚度贡献仍由第3节另算。
