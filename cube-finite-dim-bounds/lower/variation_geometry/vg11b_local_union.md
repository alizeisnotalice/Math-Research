## 2. 原子极值与法向端点

令`P=P₁=1+√2/2`，`d(t)=Pt/50`。t≥0且h₁≤1/50时，L第一轴最小原子是−d，最大原子是P−d；H最小同为−d，最大是P+d。t=0存在多个raw并列；只取右路径赢家，不能把正h公式延伸为负t公式。相同raw候选永久并列时合为等价类，不登记无限多个事件。

法向receiver为

`H(t)=[P+d−R, −d+R]`，

`L(t)=[P−d−r(t), −d+r(t)]`。

定义唯一可能改变相对排序的函数

`F(t)=H_lower−L_lower=2d+r(t)−R = Pt/25+r(t)−R`。

全区间r(t)<R，因为30+6t/5≤156/5<36。故L_upper<H_upper始终严格。H、L宽度及交叠也严格正：实际Fraction核的粗界为

`width(H)≥2099/3125>0`，`width(L)≥79/125>0`，

`L_upper−H_lower≥7721/12500>0`。

这些界来自P∈(1707/1000,1708/1000)、R∈(1224/1000,1225/1000)、r(0)∈(1170/1000,1171/1000)、r(1)∈(1180/1000,1182/1000)。checker实际用整数二/四次幂严格核这些root caps，未用浮点重建旧P。

所以区间不可能断开，只有两种排序：

- F<0：`H_lower < L_lower < L_upper < H_upper`（完全遮蔽）。
- F>0：`L_lower < H_lower < L_upper < H_upper`。

F=0时两个lower同时相等；其余不等式保持严格。完整法向并集长度准确为

`V_normal(t)=2R−P−2d(t)+max(0,F(t))`。

这不是把两个区间长度相加，重叠只计一次。

## 4. 最小准确接口与遮蔽

`vg11b_interface.py::union_slope(intervals,side)`接收有限区间的四元组(lower,upper,lower_velocity,upper_velocity)，全部Fraction/整数，side为left/right。端点速度是沿递增路径时间的速度；left返回以负时间增量作分母的真正左导数，而非正的倒退参数系数。

实现把所有相等基准端点作为同一批：在每个c汇总旧左半线结束速度、旧右半线开始速度、零宽区间速度和严格跨面遮蔽，再调用已审signed_length；各不相交局部邻域贡献求和。向左取速度反号后，最后再反号以恢复时间导数。永久相等端点只算一个位置；正gap的空区间在足够小邻域内稳定为空，零宽区间可能在单侧出生，按完整速度区间处理。

## 5. B路径单pair的连续体积比较（严格限定范围）

本路径后3轴h=0且r<R，故L的三切向区间严格在H内。令A_H为H恒定切向面积，A_L(t)为L切向面积。实际正性可由旧根粗界2^(1/4)<6/5、3^(1/4)<4/3核出：P₂<269/250、P₃=P₄<11/10，而2r(0)>117/50超过各切向span(2P₂,P₃,2P₄)。因此0<A_L(t)<A_H。

由于法向已证连通且L_upper<H_upper，未裁剪单pair的新体积恰为

`|H(t)∪L(t)|=|H(t)|+F_+(t)A_L(t)`。

旧H第一宽损失恰2d(t)，所以

`|H(t)∪L(t)|−|H(0)|=−2d(t)A_H+F_+(t)A_L(t)<0`，`t>0`。

若F≤0，右边就是严格负的H损失；若F>0，则F=2d−(R−r)<2d，A_L<A_H。更明确的准确恒等式是

`−2d A_H+F A_L = −(R−r)A_H−F(A_H−A_L)<0`。

SymPy已实际核该代数分解。故B路径对这个未裁剪单pair确有连续局部不补偿结论；不需要有限路径浮差。**它不是完整旧union或R4的上界**：实际旧覆盖的交叠/遮蔽和其余盒运动不能用单H的体积损失替代。也不推广n4的A/C路径或其他参数族。

## 6. 单边有限差分为何不是这里的严格导数
