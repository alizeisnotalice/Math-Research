# 第5轮：自由网格核LP的准确有限模型诊断

2026-10-25。此项**不是C3上界、不是C3下界，也不是连续Laplacian核族的障碍**。

固定h=1/q、外边界半径R=3。内部格点x=h k，|k_j|<3q，外部核值为零；变量K_k≥0，在cube网格点|k_j|≤q上要求K_k≥1/8。原点以外约束

6K_k−Σ_{j=1}³(K_{k+e_j}+K_{k−e_j})≤0，

目标为min h³Σ_kK_k。这是有限差分子调和模型，仅模拟连续ΔK≥0。没有证明连续核经采样满足此约束，也没有证明网格解有合法连续插值，故与连续最优值之间无已证界方向。

符号反射及坐标置换保留有限域、障碍、约束及目标。把任何可行向量作有限群平均，得到同目标的对称可行向量。因此可准确约化到0≤k₁≤k₂≤k₃<3q。轨道权重为不同坐标排列数乘2的非零坐标数次方，目标系数c_k=该权重/q³；六邻居映射到各自轨道，重数全部保留。q=4时364变量、363约束；q=8时2600变量、2599约束。

## 实际计算及准确对偶

Python SciPy/HiGHS两档闭cube障碍的数值最优值分别约8.880214715245307、8.812289669300052。q=4矩阵送入本机MATLAB，独立linprog给8.8802147152452999。两个求解器共享相同模型矩阵，不能当成独立建模核验。数值原对偶残差记录在results/round005_free_kernel_lp.json。

写A K≤0、K≥l。取任何y≤0，令z=c−Aᵀy≥0，则对任何可行K，

cᵀK=yᵀAK+zᵀK≥zᵀl。

对q=4从数值乘子提取有理y并向零缩小999999/1000000；直接用Fraction核每个y≤0、z≥0，得到**这个有限模型**的准确下界

177604145177174498093697 / 20000000000000000000000 > 8。

完整有理乘子在results/round005_lp_dual.json。独立于SciPy的标准库checker重新生成轨道、系数和六邻居并验证对偶：

`python3 cube-finite-dim-bounds/src/check_free_kernel_dual.py`

它与发现程序共享数学模型、Python整数/Fraction，未共享稀疏矩阵实现。此证书严格排除该有限网格模型成本≤8，并不排除连续Δ核或其他生成元。

## 边界诊断及停止

另作严格内部网格障碍|k_j|<q，数值成本q=4约3.77799542、q=8约5.90823326。此时最远受约束网格坐标只有1−h；粗网格遗漏cube边界的影响巨大，不能把小于8当作连续候选。连续开闭cube边界零测，不代表有限网格障碍也可不计其影响。该对照专门展示有限点支配的风险。

按预登记共4次发现LP，另一次同q=4模型重算仅为提取新准确对偶；没有重算其他已通过证书，没有扩大网格。MATLAB矩阵文件存于仓库外scratch；源码可重新生成。这个新诊断支持继续寻找不同生成元或有效连续对偶，但不允许将有限模型失败升级为普遍障碍。
