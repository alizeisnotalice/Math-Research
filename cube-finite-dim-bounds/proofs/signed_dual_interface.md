# 连续对偶的带符号系数接口：严格解除旧模型的原点退化

2026-10-25，主代理；不产生新Cn界。基函数B与连续对偶假设复用已独审017。

旧模型中a_k≥0、ψ(0)=0，B(-k)≥0，故任何非零系数的张量至少一个轴满足|k_j|≥2。B在±2的值、一阶、二阶导均零；|k|>2时原点附近恒零。因此每个允许张量的所有原点二阶偏导均零，整和D²ψ(0)=0。这不是一般合法对偶测试函数的必要条件。

允许a_k带符号，但改为每个支撑胞元的ψ Bernstein系数≥0，仍充分保证ψ≥0。另精确施加ψ(0)=0和全部胞元Δψ Bernstein系数≤1，C²紧支撑仍由basis给出。此为真正连续的有限线性充分模型，不能将Bernstein拒绝视为实际多项式不非负。新的有理化必须先保原点等式与ψ非负；若ψ系数为负，整体正缩放不能修复。只有这些条件已准确通过时才能用整体缩放修Δ上界。

一个同一单位网格中的明确带符号例为

φ(t)=2/3[B(t−1)+B(t+1)]−B(t)/3，
Ψ_n(x)=Σ_j φ(x_j)Π_{k≠j}B(x_k)。

φ是偶C²紧支撑函数，支撑[-3,3]，φ(0)=φ′(0)=0、φ″(0)=2。对0≤t≤1，φ=t²−11t³/18≥0；对1≤t≤2，B(t−1)≥B(t)，故φ≥B(t−1)/3≥0；2≤t≤3仅剩2B(t−1)/3。支撑外为零。因此Ψ≥0，Ψ(0)=0，Hessian为2(2/3)^(n−1)I，严格正定。
