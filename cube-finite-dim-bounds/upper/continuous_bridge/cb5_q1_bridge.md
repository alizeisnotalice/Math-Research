连续核的要求是全空间分布式 `Delta K = nu − W delta_0`，其中 `nu` 为正有限测度，质量 W；并有 K≥0、偶、L1、cube 支配。连续条件允许原点真正奇性，有限值的 Q1 插值没有这种奇性。

## 2. Q1 的准确分布公式

设 n≥2，h>0，有限支撑数组 v:Z^n→R，b(t)=max(1−|t|,0)，并定义

`I_h v(x) = Σ_k v_k Π_j b(x_j/h−k_j)`。

这是连续紧支撑的张量多线性函数，每个开网格胞元内 `Delta I_hv=0`。记

`D_j²v_k = v_(k+e_j) − 2v_k + v_(k−e_j)`。

对每个方向 j 和平面 x_j=hm，法向跳密度为

`J_(j,m)(x_hat_j) = h^(-1) Σ_(k_hat_j) D_j²v_(k_hat_j,m) Π_(ell≠j) b(x_ell/h−k_ell)`，

且全空间

`Delta I_hv = Σ_(j,m) J_(j,m) H^(n−1)|{x_j=hm}`。

证明：一维帐篷的二阶分布导数是 `h^(-1)(delta_(-h)−2delta_0+delta_h)`；在有限和中按坐标求二阶导，再重编号即得。等价地，对每胞元积分两次，函数连续使测试函数法向导数项抵消，剩余项正是导数跳。边/角没有额外源，因为分布计算已经完整，互相相交的网格面在各面面积测度下为零。

因此

`Delta I_hv≥0 ⇔ 每个J_(j,m)≥0 ⇔ 每个D_j²v_k≥0`。

首个等价用不同方向网格面的互异面积测度；后一个等价用切向 Q1 函数的连续性与每胞元为顶点值凸组合。节点处切向面密度为 `D_j²v_k/h`。反之离散 Delta 仅检查 `h^(-2)Σ_j D_j²v_k≥0`，允许不同方向之间抵消；连续的不同方向面源不能这样抵消。

**强化结论。** 若 `Delta I_hv≥0` 在 `R^n\{0}` 成立，则 `I_hv=0`。因为 n≥2，面面积测度没有原点原子，Delta I_hv 是有限带符号面测度，从原点外非负推出全空间非负。（一般而言正分布是正测度，此处显式公式已直接给出带符号测度。）紧支撑测试函数取为在支撑邻域恒1可得其总质量0；正测度总质量0才推出 Delta I_hv=0，不能单凭总质量0便跳过正性。进而紧支撑分布调和的I_hv为0：例如将其用任意光滑紧支撑核卷积，得到紧支撑光滑调和函数，积分其梯度平方为0故卷积恒0，令光滑核逼近恒等便得I_hv=0。另一个更直接的有限数组证明由上述逐轴二阶差分非负：对任意固定其他坐标，有限支撑一维序列凸，只能恒0。后者给全数组v=0，不需最大值原理。

这个强化结论对所有有限网格密度都成立；提高有限原点节点值或减小 h 都不能把负源集中成原点原子。n=1是边界例外：帐篷可有负 delta_0；本项目 n=3,4 不在该例外内。

## 3. 显式三维离散可行反例

取 h=1；若 max_j|k_j|≥2 则 v_k=0；否则按非零坐标数 s=0,1,2,3 取

|s|0|1|2|3|
|---|---|---|---|---|
|v_k|11/4|5/8|1/4|1/8|

27个支撑节点外加一层邻点共125点用标准库 Fraction 检查。原点处离散 Delta 为 `−51/4`；其余内部26点恰0，外层节点非负，离散 Delta 总和0，远于此外层自动0。它甚至在 q=1、R=3 版本的主有限模型中可行（本分支没有求解该LP）。在 cube [-1,1]^3 所有节点的值≥1/8，因此 Q1 的凸组合性给整个连续 cube 的障碍支配。准确积分 `∫I_1v=Σv=21/2`。

然而在面 x=0、0<y,z<1 上，J 的四角值依 `(y,z)=(0,0),(0,1),(1,0),(1,1)` 为

`−17/4, −3/4, −3/4, −1/4`。

J为双线性凸组合，整个开面严格负，中心 J(1/2,1/2)=−3/2。取连续非负帐篷测试函数

`phi(x,y,z) = b(4x) b(4y−2) b(4z−2)`。

支撑是 `[-1/4,1/4]×[1/4,3/4]²`，离原点有正距离，只碰到网格面 x=0；中心对称消掉双线性的一次项，故

`<Delta I_1v,phi> = (−3/2)(1/4)² = −3/32`。

分布正性通常以光滑测试定义。此处 Delta I_1v 已知为有限带符号测度，所以连续紧支撑测试有意义；将 phi 用足够小的非负光滑核卷积可保持支撑避原点及其余网格面，且配对收敛到 −3/32，因此有真正非负 C_c^infinity 测试的负配对。更直接，在上述负面内取任意非零非负光滑切向测试，并乘 x方向正光滑截断即可。它严格违反原点外分布 Delta≥0。

脚本 `cb5_check.py` 和实际结果 `cb5_results.json` 独立于 SciPy、没有调用主模型矩阵，但与本文共享建模公式和 Python Fraction 算术；这不是独立审计。

## 4. 可核验的新桥接接口：奇性核加分片外部

原点必须由可识别的连续奇性承担；本节给**充分条件接口**，没有提供满足它的新核。n=3或4，`sigma_(n−1)` 为单位球面积，

`Phi_n(x) = |x|^(2−n)/((n−2)sigma_(n−1)),   Delta Phi_n=−delta_0`。

即 n3 为 `1/(4pi|x|)`，n4 为 `1/(4pi²|x|²)`。选择 rho>0、外部紧多面体Omega和有限分片。本接口采用以下偏强但可直接核验的正则假设：球外每片是有界Lipschitz域，边界由有限张C²面片组成，面片的边/角集合的H^(n−1)测度为0；各非奇性片的K有一个定义在该片闭包邻域的C²延拓。因此其梯度及二阶导在闭片有界，经典Green–Gauss公式适用，法向导数迹是可积的，且不存在未列明的边/角残项。这里不从“开片C²加梯度L1”推断这些结论。更弱的W^(2,1)版本必须另行提供其L1法向迹及对应Green–Gauss公式；本接口不默认它们。要求：

1. 在球 B_rho，`K=W Phi_n+H`，W>0准确给出，H有闭球邻域的C²延拓；外部片满足前述C²到闭包邻域的强条件（可用多项式、可验证解析式）。全片非负且偶；所有面（包含球面和Omega边界）K迹连续。Omega外取0，所以外边界迹必须0；否则Delta还含法向 delta 导数，以下测度接口失效。
2. 每片体源 `f=Delta K≥0`；球内体源是Delta H。相邻两片面，取从负侧到正侧的法向n，验证 `J=partial_n K_plus−partial_n K_minus≥0`。球界面使用n指向外，故 `J=partial_r K_out−partial_r(WPhi_n+H)`；不可漏其球面源。外边界零延拓是 `J=−partial_n K_inside≥0`。边角没有额外源的依据是本节开头的分片C²延拓与分片光滑Lipschitz域假设，以及经典Green–Gauss逐片公式；不是仅凭梯度可积推导法向迹或排除隐藏残项。
3. 验证每片支配 `K≥2^(−n)` 在 `[-1,1]^n`（几乎处处足够），不是只检节点；并准确计算或向上包围 `M=∫K`。球内奇性质量是 `W rho²/(2(n−2))`，其余为∫H及外部片积分。该公式由球坐标直接积分，不是数值近似。
4. 验证所有正体源及面源总质量有限；在紧支撑情形，上述条件自动给 `Delta K=nu−Wdelta_0` 且 `nu(R^n)=W`：取支撑邻域恒1的测试函数。独立算出nu质量=W仍可作有用的错误检查。若用非紧尾部T代替零延拓，需同时核T≥0、偶、L1、连续界面、尾部Delta正性，以及大球通量趋0；不能仅给尾部质量小。可用有界圆环截断测试将“质量=W”严格转移；不满足尾部条件就不得签署核证书。

证明：先在奇性球内挖去B_epsilon，epsilon<rho，其余各片和此圆环均满足经典Green–Gauss。逐片积分分部得到全部体/面项；本节强正则假设保证没有未列明的边/角项。令epsilon趋0，Phi_n的内边界法向导数项给−Wphi(0)，含Phi_n乘测试函数导数的边界项为O(epsilon)趋0，正则H的两个内边界项也趋0；因此奇性球内边界只给−Wdelta_0。连续迹消去各相邻界面上测试函数法向导数项。所列体和跳项全非负，故nu正。局部可积的Phi_n和紧支撑保证K∈L1。偶性和障碍另外检查，不由Delta符号自动推出。

可实现证书字段：`dimension, W, rho, pieces, formulas, shared_face_orientations, trace_equalities, bulk_lower_bounds, face_jump_lower_bounds, outer_trace_zero, outer_jump_lower_bounds, obstacle_lower_bounds, mass_interval, source_mass_interval, symmetry_certificate`。多项式条件可用有理 Bernstein 系数或有理区间证书作充分检查；含球面或Phi的条件须给真实解析/区间证明，不可冒称顶点检查自动够用。该接口适配upper_theory明确要求的核输入；后续一般L1/全尺度比较证明仍由其接口完成。

## 5. 误差不能只报一个残差

若近似拼接的分布为 `Delta K=nu_plus−mu_minus−Wdelta_0`，其中mu_minus是原点外负体/面源，则一个离散 l-infinity 残差不能替代mu_minus的测度证书；漏掉的面源可能与网格体残差完全无关。

一种代数修补接口是另造 L1、偶的校正C，使 `Delta C=mu_minus+eta_plus−A delta_0`、eta_plus≥0，并验证K+C≥0、障碍和质量。则修后正源是nu_plus+eta_plus，点源系数W+A；但校正C的存在、L1质量与支配增益需另证。本分支没有将任意负面源宣称可低成本修复。直接Newton势反号可消源，却一般带非L1远场/改变障碍；只核总负质量或点态采样不足。

用统一正余量作符号认证时，需分别登记体误差上界、每张面的导数误差上界（两侧误差相加）、外界面/球面误差、障碍误差、质量误差。只有各个连续符号条件在误差后仍过关，才是有效核证书。数值LP或数值面采样仍是诊断。

## 6. 恒定背景实际用处和范围

第2—3节纯插值恒等式与反例不使用背景密度。第4节在球坐标积分和分布Delta中使用Lebesgue体积/欧氏面积。核输入给出 `K_r(x)=r^(−n)K(x/r)`，其质量恒为M，且支配中心共同半径方体平均核 `(2r)^(−n)1_[-r,r]^n`；这里平移不变的Lebesgue背景使归一化始终是 `(2r)^n`，并允许卷积与尺度变换。非恒定密度下的方体平均分母依中心和半径变化，欧氏Delta分部还与所选背景伴随算子不同，不能沿用本接口。

仅有本桥接接口尚未重证一般 L1 的弱型比较或全尺度最大算子结论；本分支不以原点奇性核公式替代upper_theory负责的连续比较。现有有效 U3=8、U4=16均未改善。
