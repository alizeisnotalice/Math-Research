## 维度推广中的关键断点

1. 真实有限正权spanning Cauchy frame、同一时间、ψ一齐次、保守卷积及峰值Ct^(-n)是通用接口的起点。共享证明目前审定对象为n3/n4；新维度应逐条重核，而非整章改数字。
2. 尤其不能推广“Green只在线上发散”。原线外估计p_t=O(t^(4−n))仅在n≤4由时间积分直接得到有限连续；n≥5该估计不足。更高秩方向子空间、临界log发散和交叠可能出现。必须建立新的奇异分层与局部预算，或选择无需逐点分类的essential下界接口。
3. 四维1152锥、40顶点、三个N17/D20、17/(640π³)、2440单元以及角帽E4/8全部是特定维度的结果，不可代入n替换。n≥5奇数/偶数的时间积分闭式也须重新推导。
4. 三维Chebyshev的二维误差常数84、176不能原样用于(n−1)维张量。逐维算子范数、根误差、完整覆盖权重、面积归一、短时Lq预算须一起支付；保留共同尺度与联合几何。
5. 对候选G、g0、I0，质量目标形式为q=n/(n−1)，K=(G−g0/n)+/[2^n g0(1−1/n)]，成本n^q I0/g0^q。只有全空间正部源、可积性、cube支配、一般输入和全尺度比较全部成立后才能作为Cn上界；模型成本下降与有效上界改善分账。
6. 下界见证盒必须以同一半径、完整胞元质量及准确联合并集计算；保留有限块截断、边界损失与统一半径余量平滑。高维见证枚举失败不能排除整个构造族。
7. 无原子/光滑正背景仍能接近2^n。每个上界证明必须指出恒定Lebesgue密度实际用于何处，不能删除原子输入来躲避背景反例。
