# F02 · 张量 Fourier 正性与软度平方上确界

当前断言与等级以原子账本为准；本条 Skill 不因某一基础引理通过就整体标记为已验收。

## 输入与产出

局部紧阿贝尔群或欧氏因子、各因子的核/测度、Fourier 约定、张量规则和软最大参数。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 固定群、Haar/底测度及Fourier归一化，核可积或为有限测度；正定与逐点非负核是不同条件。
2. **可独立证明的简单张量规则**：有限个局部紧阿贝尔群 `G_j` 配乘积 Haar 测度、对偶群识别和约定 `k̂_j(γ_j)=∫_{G_j}k_j(x_j) overline{γ_j(x_j)}dμ_j`。若各 `k_j∈L¹(G_j)`，则 `k=⊗_j k_j` 满足 `k̂(γ_1,…,γ_m)=∏_j k̂_j(γ_j)`，由 Fubini 得出。另若各 `k_j` 分别为正定函数，则乘积核 `k(x_1,…,x_m)=∏_j k_j(x_j)` 在直积群上正定：任一有限 Gram 矩阵是各因子正半定 Gram 矩阵的逐项乘积。两项结论分别需要其所列假设；不覆盖带坐标耦合的核，也不单凭“正定且 L¹”断言 Fourier 密度处处非负。
3. 连续中心立方体指标核：明确采用F(k)(ξ)=∫e^(−ix·ξ)k(x)dx、k=2^(−n)1_([-1,1]^n)，则F(k)(ξ)=∏sin(ξ_j)/ξ_j（ξ_j=0以连续值1定义），可取负值；2π或unitary约定需相应改频率/常数，不把原始指标核当Fourier非负正核。
4. P-8205499d1bddf331刻画实连续各向同性S¹×S¹核严格正定的离散频谱支集；P-2ebc46987d4f4c81限stretched Gaussian。均不定义任意立方体核或softmax。
5. 有限整数m≥1、实q_j及β>0时定义β^{-1}logΣe^{βq_j}，直接检max q≤softmax≤max q+log(m)/β；有m增长时误差不能当统一常数。
6. 无限指标需先建立可测性、截断和尾控制；有限softmax误差式不直接提供全尺度上确界界。

## 证据与失败处理

非负空间核不等于非负Fourier，中心立方体指标核有明确负Fourier值。乘积圆严格正定定理须保底群/各向同性/连续性，softmax须β>0且控制m。
