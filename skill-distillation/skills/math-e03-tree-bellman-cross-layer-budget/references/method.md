# 树 Bellman 跨层预算势：方法与验收边界

1. 先定义根树、到达质量m(v)、子概率p(w|v)与终端约定，说明逐路径还是平均预算。

2. 平均预算逐节点检Φ(v)≥c(v)+Σ_wp(w|v)Φ(w)；逐路径预算则用sup_w，二者不互换。

3. 乘以m(v)并有限层求和，逐条用m(w)=m(v)p(w|v)抵消内部边；保留终端势项及其符号。

4. P-ee5e7f1d2f3397ce的作者Bellman构件B(F,f,A,v)=4F−f²/(v+A)有f²≤Fv、0≤A≤v及指定父子增量；常数4/32仅对应其树测度、归一化和二倍停时。

5. 若复用原文树测度，先重写λ、Λ(I)、α及所有子树Carleson条件，检查零质量分母；bi-tree仅盒条件可能不足，不把它当单树。

6. 令深度趋∞前证明终端项收敛/受控。共享输入和非嵌套中心立方体不能由普通Bellman望远镜自动编码。

## 不可省略的限制

平均预算与逐路径预算不同。节点质量、终端余项或无限深极限任一未经核验，都会破坏望远镜求和。
