# K01：Aldaz 的固定参数 CLT 与多层收益

**原文结论** S-5539d5f3421aa082，PDF第4–9页。取t固定且足够大，有限参数网格u_j∈[1/8,1/4]间距t^(−4/3)。每层质量约t^(−1)e^(−t²/2)，层数约t^(4/3)，交叠率t^(−1/3)e^(−2t^(2/3)/9)足够小，二阶Bonferroni得并集质量下界常数乘t^(1/3)e^(−t²/2)。测试平均大于e^(t²/2)/2，抵消指数后剩t^(1/3)收益。

**已检查推导**：对固定u,v，条件二项Bin(k,v/u)中的k随d变化，但k≥ud−(t+t^(−1))σ_u√d→∞。固定p=v/u∈(0,1)，Berry–Esseen误差至多标准常数×(p²+(1−p)²)/√(kp(1−p))，故在允许k区间一致趋零。对固定有限网格取最大维数门槛即可。本次没有重证Berry–Esseen标准定理，也未给最优D(t)。

适用例：先给定t=100及有限u网格，要求某个足够大的d下每层/每对满足论文概率比较；应报告存在性和未量化的门槛，再用精确二项概率或有效误差界核验具体d。

缺条件例：令t=d^(1/4)，同时沿用论文固定t的CLT和O_(t,u)(d^(−1/2))余项，不能得出同一收益。须提供随t增长的正态尾相对误差和尺度展开的统一余项。本源不能直接证明d^(1/4)弱常数下界。

GP-BRANCH、TC-A4、HS若需要随d变化的偏差参数，应转到已具明确适用区间的中偏差证据卡；本源不提供这些内部名称的定义。
