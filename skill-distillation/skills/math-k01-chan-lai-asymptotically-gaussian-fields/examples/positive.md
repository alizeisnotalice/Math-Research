# 适用案例

先核验一个有限样本精确事实：令 `U∼Unif(0,1)`，`F_1(t)=1_{U≤t}`、`F(t)=t`，并定义未标准化过程 `Z_1(t)=1·(F_1(t)−F(t))`，`0≤t≤1`。逐路径有 `sup_t Z_1(t)=1−U`，所以对明确的严格单侧事件 `{sup_t Z_1(t)>1/2}`，尾概率为 `P(U<1/2)=1/2`。这只是 `n=1` 的构件检查，不是标准化经验场的sup尾。

渐近应用另设对每个 `c`，`Y_1,…,Y_{n_c}` 为 iid `Unif(0,1)`，`F_{n_c}(t)=n_c^{-1}∑_{i=1}^{n_c}1_{Y_i≤t}`，`Z_{n_c}(t)=√{n_c}(F_{n_c}(t)−t)/√{t(1−t)}`；将端点值定义为有限样本的连续极限 `0`，并取 `n_c=⌈c^{12}⌉`。此时 `F(t)=t` 连续可微且 `F'(t)=1>0`，`c→∞` 且 `c=o(n_c^{1/6})`；Chan–Lai Theorem 4.1 / Corollary 4.2(i) 因而给出 `P{sup_t Z_{n_c}(t)>c}∼e^{−2c²}`。有限 `n=1` 的精确例不能验证该渐近式、(C)/(B1)–(B5) 或任意目标场的跨块条件。

本例是边界检查任务；总体验证记录报告了按当前 Skill 文本实际执行的两个检查。
