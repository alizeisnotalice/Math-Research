# 条件缺失案例

端点：l=(0,0) 属于变量盒，FE_OR(l)=1/4；按 sgn(0)=+1 舍入为(+1,+1)=(False,False)，违反 OR，所以 |FE_OR|≤ε 的 ε=1/4 闭阈值不够，OR 的0-rounding-friendly结论只允许 FE=0。全空间错误形式：若把未平方 FE_OR 当成本征非负违约项，F_bad=FE_OR+αΣ_i(x_i²−1)²，则在 x=(-1−t,+1) 有 FE_OR=−t/2；任意有限 α>0 取充分小 t>0 时 F_bad<0，且由其趋于+∞可知沿该射线上还存在非 Boolean 的零点。该输入在源文全空间 FE 解释中是盒外点，FE 已不再是非负违约代价；正确平方形式用 FE_OR² 且 α>0。另对单变量约束 c(x)=1[x=−1]，随机舍入期望为 (1−a)/2，导数 −1/2；若 BDD 消息递推返回 −1，说明少了 1/2，不能当成精确梯度。

本例是边界检查任务；是否通过实际调用见总体验证报告，不因文件存在自动计作行为测试通过。
