# 外放松映射、正支配与误差预算：方法与验收边界

1. 明确原可行集X、放松集Y、映射T:X→Y、原目标F与放松目标G，并分别核集合映射和目标关系；T(X)⊆Y本身不推出目标界。对非空X，最大化须逐点证明F(x)≤G(Tx)+ε(x)，最小化须逐点证明G(Tx)≤F(x)+ε(x)。精确对应F=G∘T是ε≡0的特例。若ε为有限实值且sup_X ε<∞，分别得到sup_X F≤sup_Y G+sup_X ε与inf_X F≥inf_Y G−sup_X ε；误差无有限上界时不声称该标量界。所有sup/inf按扩展实数解释；X为空时单独使用sup∅=−∞、inf∅=+∞，且避免未定义的扩展实数运算。写成max/min还须另证达到性。

2. 若F(x)≤aG(Tx)+ε(x)，列明a≥0、sup_X ε是否有限及各误差预算；仅在逆向构造已证时讨论紧性。

3. norm-induced cut 对不合格点y取 ||r(y)_+||/L≤||x−y||；由单调范数及全局Lipschitz条件证明每个真实可行x仍保留，L不得低估。

4. 区分作者定理与算法输出：紧Ω及有效cut给可行聚点；每个master均全局求解才升级为最优聚点，局部求解一般不能。

5. 有限步精确可行停止与r_j≤ε的残差停止分开；ε残差不是目标值ε误差。原文oracle复杂度依赖维数及域几何，且不是实际求解时间界。

6. 把模型、离散、截断误差分别加入统一预算，保留n、层数、极限顺序；数值解需回验真实约束。

## 不可省略的限制

外放松解未必可实现。P-b89fe2cfbd421aa7的最优性结论要求每次master全局求解；复杂度上界依赖域半径、维数和残差尺度，不能视为维数无关或目标误差证书。

# 外放松界方向：已检查基础推导

对非空X，设T(X)⊆Y，且ε:X→R有限实值、\bar ε=sup_X ε<∞。最大化若逐点有F(x)≤G(Tx)+ε(x)，则G(Tx)≤sup_YG，故sup_XF≤sup_YG+\bar ε。最小化若逐点有G(Tx)≤F(x)+ε(x)，则inf_YG≤G(Tx)≤F(x)+ε(x)，故inf_XF≥inf_YG−\bar ε。精确目标对应F=G∘T对应ε≡0；不匹配的目标必须提供上述单侧支配，不能只凭可行像包含推界。

这里的sup/inf为扩展实数；因为\bar ε有限，加入或减去\bar ε有定义。X=∅时另按sup∅=−∞、inf∅=+∞处理，不套用\bar ε公式。Y=∅而X非空与T(X)⊆Y矛盾。若要把sup/inf写成max/min，另核达到性。

目标不匹配的最小反例是X=Y={0}, T(0)=0：最大化取F(0)=1、G(0)=0，则sup_XF=1>0=sup_YG；最小化取F(0)=0、G(0)=1，则inf_XF=0<1=inf_YG。集合映射完全成立，失败只来自没有目标支配。
逆向实现性是另一命题，不能从T:X→Y推出每个y∈Y来自真实输入。
