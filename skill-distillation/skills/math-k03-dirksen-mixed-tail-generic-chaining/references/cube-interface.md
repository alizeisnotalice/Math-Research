# 中心立方体极大算子接口

中心立方体迁移接口：以 T={(x,r)} 或有限 cube-net 为索引，定义中心/半径变化的 d₂,d₁；须对每一对立方体证明 mixed-tail 增量条件、有限直径及样本可测性，并显式保留基点 cube 项。论文未替目标算子给出这些度量。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。

迁移时逐项填写：真实输入与工具变量的映射；工具假设为何成立；得到上界/下界/证书的方向；n及尺度/层数的常数；尚需证明的连接引理。
