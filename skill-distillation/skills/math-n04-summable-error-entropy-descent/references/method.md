# 可求和误差管理与熵递减：方法与验收边界

1. 逐项写出 H_(k+1)<=H_k-d_k+epsilon_k，标清符号与下标。

2. 对每个整数m≥0从k=0求和到m：Σ_(k=0)^m d_k≤H_0−H_(m+1)+Σ_(k=0)^m ε_k≤H_0−H_inf+Σ_(k=0)^m ε_k。H_inf须是与m无关的有限实下界。

3. 若ε_k≥0且Σ_(k≥0)ε_k<∞，d_k≥0使其部分和单调有界，再取m→∞。有符号误差需另给上方部分和一致界，不能把任意条件收敛偷换为逐项正误差。

4. 多尺度证明中先确定各尺度权重，再检查常数对尺度和维数是否一致。

5. 在证明总和有限前，将扰动、离散化、截断与选择误差分开管理。

## 不可省略的限制

逐步单调下降不代表总误差有限。若误差不可和或势能无下界，望远镜求和不能给出有限的累积界。

## 有限望远镜界与无限可求和的完整推导（2026-10-07）

假设对每个 `k≥0` 都有 `H_{k+1}≤H_k−d_k+ε_k`，`d_k≥0`，并存在与 `m` 无关的有限实数 `H_inf` 使所有 `H_k≥H_inf`。把逐项不等式移项并从 `k=0` 加到 `m`，得

`Σ_{k=0}^m d_k ≤ Σ_{k=0}^m(H_k−H_{k+1}) + Σ_{k=0}^m ε_k = H_0−H_{m+1}+S_m ≤ H_0−H_inf+S_m`，其中 `S_m=Σ_{k=0}^m ε_k`。

若 `ε_k≥0` 且 `Σ ε_k<∞`，则 `S_m≤Σ ε_k`。更一般地，若仅有符号误差但 `sup_m S_m<∞`，右端仍有一个与 `m` 无关的上界。因为 `d_k≥0`，其部分和单调且有界，故 `Σ d_k<∞`。绝对可和是后一条件的充分条件；误差逐项非负不是必要条件。若误差级数条件收敛，其部分和也有界，因而同样足够。

没有误差部分和上界时不能从该递推推出下降项可和：取 `d_k=1/(k+1)`、`ε_k=2/(k+1)`、`H_0=0`、`H_{k+1}=H_k+d_k`，则递推取等号且 `H_k≥0`，但 `Σd_k` 发散。这个例子用调和级数比较论证；有限截断计算只展示前若干项，不承担发散证明。

以上是对数列递推的条件推导，不是任何熵下降/极大算子原文定理的引用，也没有核实具体应用的 `H_k,d_k,ε_k` 是否满足这些前提。若 `H_inf`、误差上部分和界或 `d_k≥0` 缺失，应停止在有限步不等式。
