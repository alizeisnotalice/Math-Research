# 可求和误差管理与熵递减：方法与验收边界

1. 逐项写出 H_(k+1)<=H_k-d_k+epsilon_k，标清符号与下标。

2. 对每个整数m≥0从k=0求和到m：Σ_(k=0)^m d_k≤H_0−H_(m+1)+Σ_(k=0)^m ε_k≤H_0−H_inf+Σ_(k=0)^m ε_k。H_inf须是与m无关的有限实下界。

3. 若ε_k≥0且Σ_(k≥0)ε_k<∞，d_k≥0使其部分和单调有界，再取m→∞。有符号误差需另给上方部分和一致界，不能把任意条件收敛偷换为逐项正误差。

4. 多尺度证明中先确定各尺度权重，再检查常数对尺度和维数是否一致。

5. 在证明总和有限前，将扰动、离散化、截断与选择误差分开管理。

## 不可省略的限制

逐步单调下降不代表总误差有限。若误差不可和或势能无下界，望远镜求和不能给出有限的累积界。
