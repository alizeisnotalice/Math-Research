# 中心立方体极大算子接口

用于中心立方体极大算子研究的迁移接口：沿固定中心的嵌套立方体链，以尺度为时间、局部平均为奖励，尝试用首次越阈选尺度。缺口：须构造滤过和鞅结构，并证明单链首次命中控制所有中心立方体。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。
