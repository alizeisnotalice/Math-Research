# F03 · HS 径向层叠与平方包络

当前断言与等级以原子账本为准；本条 Skill 不因某一基础引理通过就整体标记为已验收。

## 输入与产出

测度空间、径向分层、核/算子 Kⱼ、Hilbert–Schmidt 范数约定和项目 HS 接口或平方包络公式。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 在σ有限测度空间的实际Hilbert输入/输出空间核验可测核K_j及双积分|K_j|²<∞，确认产品测度/积分算子可按通常Fubini定义；这是HS范数平方，不是径向sup的自动控制。
2. 对有限HS块族，平方和公式含 `2 Re Σ_{i<j}⟨K_i,K_j⟩HS`。范数平方恰等于各块平方和，当且仅当总实交叉项和为0。两块时只要求交叉内积实部为0（复Hilbert空间里可有非零纯虚交叉内积）；实Hilbert空间两块时这等价于正交。三块及以上时非零交叉项可相消，故两两正交是充分条件但一般不必要，例如实向量(1,0)、(−1,1)、(0,1)的三个交叉项为−1、0、1。重叠同一块给出严格差异。径向变量换元保留Jacobian与频率局部化尺度。
3. 全文来源卡P-fe527ed15cfb6ce0为arXiv:2609.30726v1的径向Schrödinger邻近结果：归一化Bessel族的合成T有||T||²=C_B，Γ=TΛT*给||Γ||Sβ≤C_B^{1−1/β}||λ||ℓβ。
4. 其Lemma2.1通过Schatten对偶将A_V的Sβ′界与系统平方函数L^p_tL^q_x界互换，限1<p,q<∞、1≤β<∞及可定义的二次型；引用的对偶/插值依赖单列。
5. Theorem4.1限d≥2、径向频率截断P_N及q*=(2d+1)/(2d−1)：||A^rad_{V,N}||S_(2d+1)≲N^{−2(d−1)/(2d+1)}||V||L^((2d+1)/2)，隐常数可依赖d和截断，不是维数一致HS界。
6. 作者证明骨架为球面平均→Hankel核局部/±振荡拆分→一维Schatten核/循环迹及加权多线性分数积分→尺度恢复；必要β范围和未解决sharpness按卡保留。
7. 项目HS平方包络仍缺具体核、层、size及逐点支配；此径向Strichartz定理不能替代中心立方体全尺度上确界。
