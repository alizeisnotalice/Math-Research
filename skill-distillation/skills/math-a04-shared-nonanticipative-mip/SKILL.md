# A04 · 共同选择的混合整数建模与非前视约束

当前能力状态：**部分可用**。可用于按信息历史构造非前视等式，并用“每个不可区分块的诱导情景图连通”判定等式传递是否充分；这一判据由 P-56 Lemma 2（PDF p.10）支持，并可直接由等式的传递性及不同连通分量赋不同变量值推出。**不得把源 Theorem 3 的普遍最小边数结论或任意逐块树选择称为全局最优**：在一般允许轨迹集合 `C` 下，独立逐 cut 选树可能产生冗余边；本地同模型反例见 [`共享边反例`](examples/shared-edge-counterexample.md)，具体复核记录见 [`2026-10-07 复核日志`](references/verification-log-20261007.md)。big-M 仍须按模型单独证明有效界。中心立方体极大算子的具体变量映射属于迁移推断，尚无已证课题结论。

## 输入与产出

共同输入变量、场景树、信息集、整数选择及连续约束。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 把对同一真实输入的所有选择写成共享变量，场景特有变量只表示观察后可调整的补救决策。
2. 按时刻和可观测历史划分场景信息集；每个尚不可区分的场景块必须满足相同决策。
3. 可将成对等式表示为情景图边；每个信息块的诱导子图连通，当且仅当等式可沿路径传递到整块。
4. 若用稀疏生成算法，逐一验证所有信息块连通。跨 cut 的共享边可能降低并集边数；P-56 Algorithm 1 同阶 blocks 按 Remark 1 并行处理且不看本轮新边，故不得仅凭其逐 cut 生成树宣称全局最小。对一般允许轨迹集 `C`，先解全局最小化或提供最优性证书；四情景反例见 [`共享边反例`](examples/shared-edge-counterexample.md)。
5. 为区分事件的逻辑变量推导有效big-M界或用指示约束；通用区分函数需按具体模型定义。
6. 记录模型是精确等价、内近似还是外放松；用小场景逐历史穷举验证非前视约束，并把求解器状态、间隙和容差回映原模型。

## 证据与失败处理

漏掉非前视约束会泄露未来信息；错误信息分块会过度约束或允许前视。P-56 Theorem 3 声称 Algorithm 1 生成最少的情景对；其证明把逐 cut 树边逐一称为必要边，但没有排除同一层其他 cut 的路径替代。`examples/shared-edge-counterexample.md` 给出一般允许轨迹集合下 5 边输出与 3 边可行图的精确例子；因此当前工具只调用连接性刻画，不把未加结构条件的全局最小性当已证结论。
