# 同一 cut 多树并行会产生非最小并集：四情景精确例

## 可行输入

设情景为 `S={0,1,2,3}`。允许观测历史为

`C={∅,{a},{b},{c},{a,a′},{b,b′},{c,c′}}`，

其中 `a,b,c` 是三个互斥的替代性部分揭示历史：历史 `{a}` 将情景3与其余 `{0,1,2}` 区分开，`{b}` 将情景2与 `{0,1,3}` 区分开，`{c}` 将情景1与 `{0,2,3}` 区分开；各自之后的 `a′,b′,c′` 才在该分支中完全揭示情景。只允许根历史及这三条分支轨迹，故 `C` 不含跨分支事件并集。P-56 PDF p.5 将 `C` 定义为可能轨迹的许可事件组合，并明确全幂集只是特殊情形；p.8 Lemma 1 只要求实际包含的事件历史诱导分区细化。每个历史的不可区分分区如下：

| 历史 | 分区 cut blocks |
|---|---|
| `∅` | `{0,1,2,3}` |
| `{a}` | `{0,1,2}`, `{3}` |
| `{b}` | `{0,1,3}`, `{2}` |
| `{c}` | `{0,2,3}`, `{1}` |
| `{a,a′}`, `{b,b′}`, `{c,c′}` | `{0}`, `{1}`, `{2}`, `{3}` |

所有状态的分区沿事件发生方向细化。

## 两种图

逐 cut 独立取排序路径时：

- `012` 取 `01,12`；
- `013` 取 `01,13`；
- `023` 取 `02,23`。

边并集为 `{01,12,13,02,23}`，共 **5** 个不同场景对。

共用中心 `0` 的星 `{01,02,03}` 只有 **3** 条边。它使根 block 连通；在 `012`、`013`、`023` 上分别诱导出包含中心的连通两边子图，单点 blocks 自动连通。任何连接四个情景的图至少有 `4−1=3` 条边，因此该星是本例全局最小。有限枚举64个无向图子集也得到边数计数 `3:1, 4:6, 5:6, 6:1`。

## 如何使用

此例不影响“对每个信息块检查诱导子图连通”这一判据。它限制的是从多个 cut 各自独立选树后，把边数相加或称每条边全局必要的步骤。若研究目标是最小 NAC pair 数，必须对所有 cuts 的边**并集**联合优化，或给出可核的最优性证书；本例不证明某个协调的树选择规则在所有模型上都失败。
