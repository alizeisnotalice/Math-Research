# 共同选择的混合整数建模与非前视约束：方法与验收边界

1. 把对同一真实输入的所有选择写成共享变量，场景特有变量只表示观察后可调整的补救决策。

2. 按时刻和可观测历史划分场景信息集；每个尚不可区分的场景块必须满足相同决策。

3. 可将成对等式表示为情景图边；每个信息块的诱导子图连通，当且仅当等式可沿路径传递到整块。

4. 若用稀疏生成算法，逐一验证所有信息块连通。不同信息块可能共享边，跨 cut 的等式路径也可能复用其他 cut 的边；因此逐 cut 取树后需按边并集检查全局目标，不能把每条逐 cut 树边都称为全局必要边。一般允许事件集合下，P-56 Algorithm 1 的任意并行树选择不保证全局最小；精确反例见 [`examples/shared-edge-counterexample.md`](../examples/shared-edge-counterexample.md)。

5. 为区分事件的逻辑变量推导有效big-M界或用指示约束；通用区分函数需按具体模型定义。

6. 记录模型是精确等价、内近似还是外放松；用小场景逐历史穷举验证非前视约束，并把求解器状态、间隙和容差回映原模型。

## 不可省略的限制

漏掉非前视约束会泄露未来信息；错误信息分块会过度约束或允许前视。一般允许事件集合下，源 Algorithm 1 的并行逐 cut 树选择有非最小反例；不可把其输出当全局最优。

已检查的基础结果是 Lemma 2 的连通性判据。P-56 Theorem 3 的一般全局最小性结论有证明缺口且在 Algorithm 1 允许的独立并行树选择下有反例；当前工具不提供该最小性保证。高级定理及常数须从真实阅读卡回查原文。
