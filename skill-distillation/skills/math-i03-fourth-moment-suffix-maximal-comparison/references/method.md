# 后缀四阶矩与最大值到末端比较：方法与验收边界

1. 验证 M_k 是同一滤过下的鞅，并定义后缀从确定索引 j 起的 M_k−M_j；若索引随机，另核对停时条件。

2. 对有限时域鞅先确认 `M_n−M_j∈L⁴`。随后对后缀鞅 `M_k−M_j` 使用 Doob L⁴：
   `E max_{j≤k≤n}|M_k−M_j|⁴≤(4/3)^4 E|M_n−M_j|⁴`。从零开始的版本相应要求 `M_n∈L⁴`。没有该可积性时不报告有限的四阶矩证书，也不把扩展值形式的 `∞≤∞` 当作实际比较。

3. 若问题需要反向比较或条件化后缀，单独证明对应不等式，不能由 Doob 方向反推。

4. 存在多个后缀时逐个列出并用并集界或最大不等式合并，保留依赖关系与常数。

5. 已本地核确定有限终端 `N` 且 `M_N∈L⁴` 的 Doob L⁴：对 `|M_k|` 次鞅用首次超过 `λ` 的停时与 layer-cake/Hölder，得 `E max_{k≤N}|M_k|⁴≤(4/3)⁴E|M_N|⁴`。确定后缀起点 `j` 的鞅差 `M_k−M_j` 也须有末端 `M_N−M_j∈L⁴`；随机起点/终端须另核停时与可积条件，数值例不授权。
