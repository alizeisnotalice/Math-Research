# 非齐次跳跃过程真实生成元：方法与验收边界

1. 从小时间转移概率定义真实生成元 L_t f(x)=lim_{h↓0}(E[f(X_{t+h})|X_t=x]−f(x))/h；先确认极限及测试函数域。

2. 按模型写漂移/扩散与 ∫[f(x+z)−f(x)−χ(z)∇f(x)·z]ν(t,x,dz)，若有跳出域或杀死，明确其边界/杀死项。

3. 检查 Lévy 可积性、局部有界性与时变强度；空间非齐次是 rate/kernel 依赖 x，时间非齐次是依赖 t，二者分别记录。若模型是非齐次纯跳 Q-process，还须登记 conservative/stable Q 与是否爆炸；Zhang (arXiv:1511.05011v2) Theorem 3.1 给出该模型的非爆炸等价判据，Theorem 3.2(a) 给出漂移充分条件，(b) 的必要性另需局部紧可分度量状态空间、紧集上局部跳率界和嵌入链 weak-Feller。不得仅由局部有界率推出非爆炸。

4. 用 f≡1 和坐标函数（在合法域内）检查质量守恒与漂移；由生成元推出演化方程时注明时间不齐次算子次序。

5. 对前向 Kolmogorov 方程，先核验 Feinberg–Shiryaev (2021) Theorem 3.5 的 Assumption 2.3（每个固定状态的总跳率在有限时间段上局部有界），并确认可测集合 `B` 在 `B×[T₀,s)` 上对 `q` 有界。对源文中的转移函数 `P`，Theorem 3.5 还规定初始边界极限和终时绝对连续；它给出的前向方程只在几乎处处 `t∈(u,s)` 成立，并称 `P` 在满足这些性质的 `\hat P` 类中极小。仅当 `P` regular 时，才援引其在值域 `[0,1]` 类中的唯一性。用 PDF pp.6–7 的 Example 3.2 检查 `B=X` 的两个积分均发散时，应报告右端未定义。来源版本为 `P-ea2d2ca36be09621`，SHA-256 `ea2d2ca36be0962160a1fa7e4498cb94fa94dcc86cefbc87d9affc124ce824f3`；该综述将 Theorem 3.5 的基础结果外引至 [9]，本卡只记录其条件化陈述，不代替被引证明。
