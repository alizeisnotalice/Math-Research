# Rademacher–Menshov 最大部分和：方法与验收边界

1. 核对两两L²正交及能量Σ_j||f_j||²；定理针对有序正交系，不要求随机Rademacher符号。

2. N≥1取m=ceil(log₂N)，补零至2^m；每个前缀分成至多m+1个互不交标准二进区间，层为0,…,m。

3. 点态Cauchy–Schwarz给每个前缀平方≤(m+1)乘其块平方和，再以所有二进块平方和支配max；积分时每层块正交且全层总能量相同。

4. 得到已检查上界||max_{k≤N}|Σ_{j≤k}f_j|||²₂≤(m+1)²Σ_j||f_j||²₂；这是明确log₂约定的充分常数，不声称最优。

5. 点态max先于积分；固定次序、前缀max与任意重排max分开。无限级数需独立可和条件及极限，不由每个有限N界自动得到。

6. 调用二维原点直角三角形P-69017c5aad080b2f或连续正交积分P-bae82db430fb1568时，先读[分模型来源与定位](frozen-source-locators.md)；前者有N^{ln(2+√3)/ln2}平方界与偏心率条件，后者需log²可积及额外归一化，均不替代上述一维有限前缀证明。

## 不可省略的限制

对数最大估计要求有限有序正交系，界依赖 N；同名 Rademacher 可微定理不是 Menshov–Rademacher 部分和结论。

# 正交部分和的二进块界：已检查基础推导

设N=2^m，f₁,…,f_N在L²中两两正交（实或复）。每个前缀[1,k]
可分为至多m+1个互不相交的标准二进区间。
对该分解逐点使用Cauchy–Schwarz：|Σ_{j≤k}f_j|²≤(m+1)Σ_{I∈分解}|Σ_{j∈I}f_j|²。
以全部二进区间的非负平方和支配右侧，取最大再积分。
每一级区间划分覆盖各索引一次；正交性消掉每个块积分中的交叉项。
因此||max_{k≤N}|Σ_{j≤k}f_j|||₂²≤(m+1)²Σ_j||f_j||₂²。
一般N补零到2^⌈log₂N⌉，得到不超过(1+⌈log₂N⌉)的范数损失。
非正交情形需要Gram矩阵或别的块界；这个证明不能只凭边际范数照搬。
