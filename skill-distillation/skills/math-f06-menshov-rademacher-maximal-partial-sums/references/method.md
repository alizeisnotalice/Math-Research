# Rademacher–Menshov 最大部分和：方法与验收边界

1. 核对两两L²正交及能量Σ_j||f_j||²；定理针对有序正交系，不要求随机Rademacher符号。

2. N≥1取m=ceil(log₂N)，补零至2^m；每个前缀分成至多m+1个互不交标准二进区间，层为0,…,m。N=1时m=0，只有单点层；N为2的幂时无需额外填充。

3. 对每个前缀的二进分解，点态 Cauchy–Schwarz 给出平方≤(m+1)乘该分解各块和的平方和。取所有标准二进区间上的非负平方和支配每个前缀；固定长度的一层是补零后索引集的分割。

4. 每个区间块和平方积分由正交性等于块内能量；逐层相加恰为总能量。因有m+1层且每个前缀至多m+1块，独立推出 `||max_{k≤N}|Σ_{j≤k}f_j|||²₂≤(m+1)²Σ_j||f_j||²₂`。这是有限维证明，不声称最优。

5. 点态max先于积分；固定次序、前缀max与任意重排max分开。无限级数需独立可和条件及极限，不由每个有限N界自动得到。

6. 调用二维原点直角三角形P-69017c5aad080b2f或连续正交积分P-bae82db430fb1568时，先读[分模型来源与定位](frozen-source-locators.md)。前者 Lemma 1.10 的 `N^δ` 平方界不要求有界偏心率；Theorem 1.9 的收敛结论另有偏心率与系数条件。后者连续正交系统需 `log²` 能量；归一化版本另有 `κ,K` 控制。二者都不替代一维有限前缀证明。

## 不可省略的限制

对数最大估计要求有限有序正交系，界依赖 N；同名 Rademacher 可微定理不是 Menshov–Rademacher 部分和结论。

# 正交部分和的二进块界：已检查基础推导

设N=2^m，f₁,…,f_N在L²中两两正交（实或复）。每个前缀[1,k]
可分为至多m+1个互不相交的标准二进区间。
对该分解逐点使用Cauchy–Schwarz：|Σ_{j≤k}f_j|²≤(m+1)Σ_{I∈分解}|Σ_{j∈I}f_j|²。
以全部二进区间的非负平方和支配右侧，取最大再积分。
每一级区间划分覆盖各索引一次；正交性消掉每个块积分中的交叉项。
因此||max_{k≤N}|Σ_{j≤k}f_j|||₂²≤(m+1)²Σ_j||f_j||₂²。
一般N补零到2^⌈log₂N⌉，得到不超过(1+⌈log₂N⌉)的范数损失。
非正交情形需要Gram矩阵或别的块界；这个证明不能只凭边际范数照搬。
