# F06 · Rademacher–Menshov 最大部分和

当前断言与等级以原子账本为准；本条 Skill 不因某一基础引理通过就整体标记为已验收。

## 输入与产出

L² 空间中的有限正交系 (fₙ)、可选系数、固定次序及前缀个数 N。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 核对两两L²正交及能量Σ_j||f_j||²；定理针对有序正交系，不要求随机Rademacher符号。
2. N≥1取m=ceil(log₂N)，补零至2^m；每个前缀分成至多m+1个互不交标准二进区间，层为0,…,m。
3. 对每个前缀的二进分解，点态 Cauchy–Schwarz 给出平方≤(m+1)乘该分解各块和的平方和。取所有标准二进区间上的非负平方和支配每个前缀；每个固定长度层分割补零后的索引集，因此由正交性，该层块积分总和恰为Σ_j||f_j||²₂。
4. 一共有 m+1 层，故独立推出 `||max_{k≤N}|Σ_{j≤k}f_j|||²₂ ≤ (m+1)²Σ_j||f_j||²₂`，其中 `m=ceil(log₂N)`；这是有限有序正交系的充分界，不声称最优。此证明不依赖随机采样，也不把数值检查当一般证明。
5. 点态max先于积分；固定次序、前缀max与任意重排max分开。无限级数需独立可和条件及极限，不由每个有限N界自动得到。
6. 调用二维原点直角三角形 P-69017c5aad080b2f 或连续正交积分 P-bae82db430fb1568 时，先读[分模型来源与定位](references/frozen-source-locators.md)。前者 Lemma 1.10 对原点直角三角形族给 `||M_N||²₂≲N^δ`，`δ=ln(2+√3)/ln2`，不要求有界偏心率；其 Theorem 1.9 的几乎处处收敛才另要求截距比有界及相应加权系数和。后者 Theorem 1.2 要求连续正交系统与 `∫|f(r)|²log²(2+r)dr<∞`，Theorem 1.3 另要求归一化系统控制。两者对象都不同于上述一维有限前缀。
