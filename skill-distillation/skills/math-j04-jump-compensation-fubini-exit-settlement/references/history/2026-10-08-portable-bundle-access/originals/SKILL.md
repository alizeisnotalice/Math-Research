# J04 · 跳跃补偿、随机 Fubini 与退出财富结算

> 审核边界：本流程整理给定对象的定义、前提、推导与证据；它本身不构成专题定理证明。数值或玩具例只核对对应实例。来源结论须在账本列出的条件内使用，未独立核验的迁移必须标注“未证迁移”。本轮逐条断言、原文定位与实际案例记录见工作包 `audit_current/jk/`。

## 输入与产出

带补偿子的整数值随机测度、可预测被积量、停时、退出收益/财富账本及绝对可积条件。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 给定整数值随机测度 N 与被积量 H 后，写出跳跃和对应的积分；逐项注明 H 的可预测性、定义域、可积性，以及退出前/退出时是否计入。此步骤是对象登记，不推出任何补偿恒等式。
2. 明确 N 的补偿子 ν 和所用补偿定理。有限速率 Poisson 过程及有界简单可预测 H 的期望恒等式按工作包局部推导使用；一般随机测度或一般可预测 H 只有在逐项核对相应定理条件后才可用。L¹绝对可积与平方可积/局部化路线分别记录，不能互相替代。
3. 交换随机积分、时间/标签积分与期望前，先指定具体随机 Fubini 定理并核验其可测性、滤过、积分域和可积性假设。绝对可积是常见充分条件；有限总强度只是特定构造的方便条件，不是通用随机 Fubini 定理。没有适用定理时不执行交换。
4. 仅在给定现金流、跳跃收益、超额跳出/杀死费用、终止时点和财富状态后写路径级账本；逐项标注跳跃是否在退出时计入，再检查可积性后取期望。没有这些合同定义时不生成通用结算公式。
5. 可选的向量 Poisson 积分矩界只用于其原文范围内的确定强度情形。Dirksen 2012 Theorem 1.1（P-c7a4dec8102c2b5b，arXiv:1208.3885v3，PDF p.3）要求 1<p,q<∞、σ与ν为σ有限测度、N为强度 dt×ν 的 Poisson 随机测度、F为简单适应的 Lq(S)-值过程；结论是最大积分 Lp 范数与六个 p/q 区间所定义 I_{p,q} 范数等价，常数依赖 p,q；q=1 只保留上界。Dirksen–Maas–van Neerven 2013 Theorems 2.11/2.13（P-8c541dc0bb435647，PDF pp.8–12）分别要求 martingale type s∈(1,2] 或 finite martingale cotype s∈[2,∞)，并给出定理所列 p 区间中的单侧界；Theorem 4.5（PDF p.16）要求 X 为 UMD、1<p<∞、F简单适应且 Poisson 强度为确定的σ有限 dt×ν，给出最大积分范数与随机 ν_p 范数的等价，常数依赖 p 与 X。两个 exact-SHA 全读卡及局限列于 J04 `references/provenance.md`；一般 X 的 ν_p 不自动有确定闭式。上述来源均不构造随机/状态依赖补偿子、一般随机 Fubini 或退出财富结算。

## 证据与失败处理

补偿只在对应可预测性和可积性条件下成立；随机 Fubini 不由形式记号保证，退出时跳跃常被漏记或重复记账。本目录 P-d1b8290539190ee5 只给补偿 Poisson 驱动 SDE 的可积跳积分/Itô 与遍历收缩；P-d69f9d48286d2a25 只给特定单跳滤过补偿。P-c7a4dec8102c2b5b 与 P-8c541dc0bb435647 的确定强度 Poisson 积分矩界另见第5步；这些来源都未提供一般随机 Fubini 或退出财富结算定理，后者仍是待来源/待契约接口。
