# J03 · 非局部 balayage 与退出测度

## 输入与产出

开集 D、非局部算子/跳核、起点或源测度、外部边界函数、退出时刻与退出位置。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 对右连续过程和开集 D，定义 τ_D=inf{t≥0:X_t∉D}；τ_D<∞ 时记录实际 X_{τ_D}∈D^c。跳跃可越过边界，退出点可能在 D^c\∂D，不能默认落在 ∂D。
2. 给定寿命 ζ，定义仅计存活到几何退出的测度 ω_D(x,A)=P_x(τ_D<ζ, X_{τ_D}∈A)，A 为 D^c 的可测子集；分别记录 τ_D=∞ 与先行杀死/同时杀死质量。对最小、时间齐次、可数状态CTMC，Kuntz–Thomas–Stan–Barahona Theorem 1.1/2.6给出 ETFSP 下界/收敛及退出、占用测度密度表征；其假设含稳定保守Q及 Σ_{x∈D}γ(x)|q(x,x)|<∞，占用测度TV收敛另需 E[τ∧T∞]<∞。这些结论不推广到一般空间的非局部算子。
3. 对调和/势函数应用 Dynkin 公式或非局部 Dirichlet 问题时核验测试域、可积性和边界数据在整个 D^c 上的定义。
4. 比较 balayage 前确认所用核、边界条件与概率退出测度一致；检查总质量仅在几乎必然退出且不被杀死时为1。
