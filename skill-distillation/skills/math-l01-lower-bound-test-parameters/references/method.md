# 下界测试参数向量：方法与验收边界

1. 先给出一个真实可行的输入函数 f，按原定义计算范数和所有平均值。

2. 把测试构型写成非负质量与高度参数；优化前加入质量、支撑、单调性和可实现性约束。

3. 精确计算目标比值，并保留严格阈值 {Mf>alpha} 的约定。

4. 把有限参数向量还原成实际函数或二进树，逐个核对父节点平均值等于子节点的加权平均。

5. 若下界见证先在离散立方体上得到，可用边长δ小胞把每个格点质量铺成常值函数：总L1质量精确保持，内胞保留超水平格点；固定d时令δ趋零，或为误差ε选δ≤ε/d。

6. 将得到的常数下界与任何上界证明分开报告；δ→0的定维转移不提供维数一致的收敛速度。

## 不可省略的限制

平均值参数看似可行，不代表它们来自同一个输入函数。某种算法的复杂度下界也不是极大算子下界构型。
