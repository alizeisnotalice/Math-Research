# L01：连续/离散弱端点见证的定量迁移

类型：**原文结论**见 S-cc47322e4d57f42a，Theorem 1、PDF第5–7页；以下有限误差选择为**已检查推导**。这里固定空间维数d，讨论非负有限支撑序列f。

设 Qδ(n) 为中心n、边长δ的立方体，0<δ<1，令 Fδ=Σ_n f(n)δ^(−d)1_Qδ(n)。其L¹质量恰等于f的ℓ¹质量。对x∈Q_(1−δ)(n)，半边长N+1/2的中心立方体包含所有k∈n+[-N,N]^d的质量小胞：坐标距离至多 N+(1−δ)/2+δ/2=N+1/2。连续平均的体积(2N+1)^d与离散格点数完全一致。

所以 |{M_cont Fδ>α}|≥(1−δ)^d #{M_disc f>α}。若要求保留离散弱型比值至少1−ε，取δ≤ε/d，Bernoulli不等式给(1−δ)^d≥1−dδ≥1−ε。此推导保留每个给定有限见证的比值；它不构造比值增长的离散见证。

正例：d=2、f=δ₀、α=1/10，离散半边长N=1的九个中心平均为1/9>α；δ=0.01时对应内胞并集面积为9×0.99²=8.8209，故连续见证的超水平面积至少此值，质量仍为1。N≥2平均≤1/25，N=0只影响原点，故该离散超水平格点数恰9。

缺条件例：固定δ=0.1并令d增长，只能保留0.9^d，不能声称固定比例；一般欧氏球没有此处体积/格点计数的精确配对，不能直接套立方体反向等价。

未补：对实际课题输入GP-BRANCH或TC-A4，须给出f、α、维数与离散见证来源。原文关于d^(1/4)下界另引Iakovlev文献，本卡未独立重证该下界。

## Aldaz 的缓冲截断：固定维数后的有限误差

**原文结论** S-5539d5f3421aa082，PDF第8–9页。好点使用的测试立方体半边长不超过√d。对核心[0,R]^d，截断格点集合放在[-√d,R+√d]^d，则核心内测试仍保留所需格点。质量上界(R+2√d+1)^d，核心体积R^d。

**已检查推导**：令a=2√d+1，缓冲比例为(1+a/R)^(−d)。Bernoulli不等式作用于(1−z)^d，z=a/(R+a)，给比例≥1−da/(R+a)。因此R≥da/ε即足够保证比例≥1−ε。这只量化固定d后的截断损失，不给Aldaz的CLT维数门槛D(t)。

有限原子测度ν向L¹函数的**已检查推导**：取非负质量1且支撑在[-h,h]^d的mollifierφ_h。若ν(Q(x,r))>α(2r)^d，则(ν*φ_h)(Q(x,r+h))≥ν(Q(x,r))；h足够小时分母(2r+2h)^d保持严格大于α的平均。因此{Mν>α}⊂liminf_(h→0){M(ν*φ_h)>α}；Fatou给超水平测度下界，且总质量不变。必须有严格阈值裕量；这里没有认证上界方向的离散化常数等价。
