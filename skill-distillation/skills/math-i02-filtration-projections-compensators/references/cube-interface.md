# 中心立方体极大算子接口

中心立方体迁移接口：先由原始样本及尺度历史定义 F_r，再明确哪些 cube-indexed 量是可选或可预测；若随机选中心/半径，须给出相对该滤过的补偿子，不能默认存在自然 Poisson 补偿。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。

迁移时逐项填写：真实输入与工具变量的映射；工具假设为何成立；得到上界/下界/证书的方向；n及尺度/层数的常数；尚需证明的连接引理。

原文结论只引用已定位阅读卡；本次检查的基础推导见method.md；任何新映射均标“迁移推断”，尚未证明的目标标“待验证猜想”。目录名称不构成原始定义。
