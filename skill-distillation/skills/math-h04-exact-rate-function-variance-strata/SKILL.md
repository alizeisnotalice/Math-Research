# H04 · 精确率函数与方差分层

> 便携证据定位见[本Skill证据索引](references/handoff-evidence-index.csv)。读取外部文献时，将 `EVIDENCE_ROOT` 设为单独提供的数据包根目录，再按索引的 `resolved_portable_path` 定位文件。文献文件属于额外数据输入，不是本Skill目录内的必需文件。

当前证据状态：**部分可用**。Rademacher 率函数、有限端点 supremum 与固定端点路径能量的确定性变分步骤已核；概率指数解释仍必须绑定匹配的 LDP / MDP 定理与其拓扑、速度和开闭集条件。不得把确定性共轭或端点能量直接报告为概率渐近。

## 输入与产出

概率模型或矩母函数、目标事件、速率函数定义、方差/参数分层与误差目标。

产出应包含适用性判断、使用的假设、数学步骤、证书或界的方向、常数依赖，以及尚未解决的缺口。

## 执行步骤

1. 从模型推出 Λ(θ)=log E e^{θX} 或归一化极限，并声明速率函数 I(x)=sup_θ{θx−Λ(θ)} 的适用拓扑与收敛速度。

把共轭或路径能量解释为概率指数之前，须绑定与当前模型匹配的 LDP / MDP 定理及其全部假设、拓扑、速度和事件开闭集方向。若无匹配定理，停止概率指数分支，只报告确定性的共轭或变分计算；方差分层还须另外核验各层的统一范围与常数。
2. 按真实方差、条件方差或协方差结构划分层；逐层检查参数范围、非退化性及层间统一常数。
3. 把概率界分成速率指数与前因子/局部方差修正；若精确率函数只描述指数阶，不把它写成精确尾等价。
4. 比较层间指数后再合并；检查最小率点、边界层和退化方差是否遗漏。
5. 固定端点路径能量使用本项已绑定的 [P318 来源合同](references/source-contract-P318.md) 与 [冻结阅读卡](references/papers/TEAM_HI-P-318df19635ebf8e5.json)：T>0、σ²>0，f 绝对连续且 f(0)=0、f(T)=a 时，∫₀ᵀ(f′)²/(2σ²) 的最小值为 a²/(2σ²T)。这是 Proposition 2.2 的确定性变分计算；仅在另行匹配该文 iid 路径 MDP 合同后解释为指数尺度。它不提供有限阈值精确概率、尾比或前因子。Cramér 共轭用 sup，支持端点可能仅无穷参数逼近，不预设 max attainment。
