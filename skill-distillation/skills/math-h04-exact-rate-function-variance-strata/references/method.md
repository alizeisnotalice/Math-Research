# 精确率函数与方差分层：方法与验收边界

1. 从模型推出 Λ(θ)=log E e^{θX} 或归一化极限，并声明速率函数 I(x)=sup_θ{θx−Λ(θ)} 的适用拓扑与收敛速度。

把共轭或路径能量解释为概率指数之前，须绑定与当前模型匹配的 LDP / MDP 定理及其全部假设、拓扑、速度和事件开闭集方向。若无匹配定理，停止概率指数分支，只报告确定性的共轭或变分计算；方差分层还须另外核验各层的统一范围与常数。

2. 按真实方差、条件方差或协方差结构划分层；逐层检查参数范围、非退化性及层间统一常数。

3. 把概率界分成速率指数与前因子/局部方差修正；若精确率函数只描述指数阶，不把它写成精确尾等价。

4. 比较层间指数后再合并；检查最小率点、边界层和退化方差是否遗漏。

5. 固定端点路径能量使用本项已绑定的 [P318 来源合同](source-contract-P318.md) 与 [冻结阅读卡](papers/TEAM_HI-P-318df19635ebf8e5.json)：T>0、σ²>0，f 绝对连续且 f(0)=0、f(T)=a 时，∫₀ᵀ(f′)²/(2σ²) 的最小值为 a²/(2σ²T)。这是 Proposition 2.2 的确定性变分计算；仅在另行匹配该文 iid 路径 MDP 合同后解释为指数尺度。它不提供有限阈值精确概率、尾比或前因子。Cramér 共轭用 sup，支持端点可能仅无穷参数逼近，不预设 max attainment。

## 不可省略的限制

速率函数的大偏差原理只控制指数尺度；方差分层不能凭标签替代统一 LDP 或局部极限定理。

Bernoulli 共轭和固定端点路径能量的确定性计算已在本目录逐步给出；P-318 的原文 MDP 合同只在其 iid、矩条件、速度和事件范围内支持指数尺度解释。一般方差分层、局部极限、有限阈值尾比与前因子仍须另有匹配定理，不能从当前计算推出。

局部证据补充见 [SOL_HN记录](audit-sol_hn.md)；其审读者与范围以记录为准。
