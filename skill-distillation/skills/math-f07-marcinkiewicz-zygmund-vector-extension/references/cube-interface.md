# 中心立方体极大算子接口

迁移推断：固定单个立方体平均算子T可做ℓ²随机化扩展；尺度族T_j需另证统一随机和控制，最大值仍需额外方法。连续中心立方体、离散Z^d立方体和dyadic尺度的测度/版本/指数范围分别核验。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。
