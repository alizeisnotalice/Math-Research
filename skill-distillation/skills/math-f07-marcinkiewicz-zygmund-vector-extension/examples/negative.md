# 条件缺失案例

先看不同算子族：在 N 点计数空间取 p=4、f_j=δ_j，令 T_j 把第 j 个坐标移到第 0 点。每个标量算子范数为 1；输入 `L⁴(ℓ²)` 范数 N^(1/4)，输出范数 N^(1/2)，比值 N^(1/4)。这不构成 p=2 反例，因为 p=2 有逐项平方求和界。

任意 Banach 值扩展也不能从 p>1 的标量界自动推出：取 p=2、B=ℓ∞² 与归一化 Hadamard 矩阵 T=2^(−1/2)[[1,1],[1,−1]]，标量 L² 范数为 1。输入 F(1)=(1,1), F(2)=(1,−1)，输入 L²(B) 范数 √2；逐坐标应用 T 后输出为 (√2,0),(0,√2)，范数为 2。Sylvester Walsh–Hadamard 矩阵给出 N=2^k 时比值 √N。 对验收案例 `F07-NEG` 的 N=8 实例，取 Ω={1,…,8} 的计数测度，按 H₁=[1]、H₂ₘ=[[Hₘ,Hₘ],[Hₘ,−Hₘ]] 定义 Sylvester 矩阵 H₈，令 T=H₈/√8，并取 F(i)=H₈ 的第 i 行作为 ℓ∞⁸ 值输入。每个 ||F(i)||∞=1，且逐坐标作用 T 得 (T_{ℓ∞⁸}F)(i)=√8 e_i；故输入 L²(ℓ∞⁸) 范数为 √8、输出为 8、比值为 √8。该段是既有有限案例的显式输入说明；保留原 2026-10-07 结果，不表示本次重跑。p=1 的单算子 Banach 值延拓需另用互不相交简单函数的三角估计。
