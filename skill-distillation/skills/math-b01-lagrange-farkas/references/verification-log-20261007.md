来源身份：`Improved Linear Embeddings via Lagrange Duality`，Kshiteej Sheth、Dinesh Garg、Anirban Dasgupta，arXiv:1711.11527v2，PDF标注日期 2017-12-14，20页，SHA-256 `f7c5f0af2f09c2dfb22612b826cea54ce5a30f617bd7b01d2b989b9d1d9555ef`。本条独立直读范围为 PDF pp.2–6，视觉回看pp.4–6；全文逐页覆盖由全库主读卡记录。该来源与 DOI `10.1007/s10994-018-5729-x` 的发表版本关系未核验。页/行侧索引为 `evidence/page-line-index/extra/X-f7c5f0af2f09c2df.json`，绑定原PDF SHA；全库读卡路径见 provenance。

### 原问题域和印刷断言

PDF p.4 的 Relaxed Primal 删除的是 `v_j^T v_m=0 (j≠m)`，而保留 `v_j^T v_j=1` 与 `v_j≠0`。p.5 式(2)将每个单位范数等式以乘子 `μ_j` dualize，故计算 dual function 时实际变量域为 `v_j≠0`，不再保留单位范数等式；互不正交也没有其他隐含约束。`ε` 无约束，要求 `Σ_i λ_i=1`，且 `λ_i≥0`。消去 `ε` 后：

`L = 1 − Σ_j μ_j + Σ_j v_j^T(μ_j I − M)v_j`, 其中 `M=Σ_i λ_i x_i x_i^T`。

PDF pp.5–6 Lemma 2 印刷称有限 dual 值要求 `{μ_j}` 为 `M` 的 top-k 特征值；p.6 的推导用梯度方程/特征向量驻点来判断极小值，但对非零开域上的全局下确界，还需逐项检验二次型的半正定性。

### 同一放松模型中的反例与正确局部条件

取合法数据维数 `d=3`、目标维数 `k=2`、两数据点 `u_1=0,u_2=e_1`，唯一归一化差向量为 `x_1=e_1`。取源允许的 `λ_1=1`，得 `M=diag(1,0,0)`。印刷 top-k 选择 `μ_1=1, μ_2=0`。`v_2=t e_1 (t>0)` 满足源的 `v_2≠0`；取另一个变量 `v_1=e_2` 也非零。式(2)/(5)的向量项为

`v_1^T(I−M)v_1 + v_2^T(0·I−M)v_2 = 1−t²`,

故令 `t→∞` 得 `g(λ,μ)=−∞`。这在源的 Relaxed Primal dual inf 域内成立，未把 `v_j=0` 纳入变量域，也未假定被删去的正交约束仍有效。

一般局部结论：对独立的每个 `v_j≠0`，二次项矩阵 `A_j=μ_jI−M` 必须半正定，且这也是有限下确界的充分条件；若存在负特征方向，缩放给 `−∞`；若 `A_j⪰0`，非零域上该项下确界为0，但当 `A_j\succ0` 时不达到。于是所给 dual function 的有限性要求 `μ_j≥λ_max(M)` 对每个 `j`，不是源文 top-j 特征值。若令 `μ_j=λ_max(M)`，每项的下确界可达到于顶特征空间；这与“必须取不同的 top-j 特征值”不同。

### 分类与能力范围

本复核**反驳**的精确命题是该 arXiv v2 第2.2节对 Relaxed Primal dual function 的 top-k 特征值有限性刻画；不是只说尚缺证明，因为源可行定义下给出 `−∞` 反例。它不直接反驳原始含 Stiefel 正交约束问题，也不自动反驳第2.2节后续关于特定算法输出的可行性/近似结论：那些推论依赖关系须逐项拆解。B01只把本例用于“先计算 `inf L`、再用一阶条件”的审计方法，不把该文的 top-k dual 当成可用定理。来源关系和全读覆盖以全库卡为准，局部核验仅 pp.2–6。
