# 中心立方体极大算子接口

通用接口：用半定lift构造可解的二次型外松弛，输出可核验界和回构候选。中心立方体极大算子仍按外层几何接口处理，提升后须保留“同一个输入函数/质量对象同时生成各中心与各立方体平均”的共同约束；不能把不同立方体各自最优的松弛变量拼成可实现证书。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。

迁移时逐项填写：真实输入与工具变量的映射；工具假设为何成立；得到上界/下界/证书的方向；n及尺度/层数的常数；尚需证明的连接引理。
