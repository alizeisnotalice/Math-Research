# 中心立方体极大算子接口

中心立方体迁移接口：若按半径/尺度排序增量，定义对应滤过 F_r 和 X_Q−X_parent(Q)；须逐项验证条件 Bernstein 矩与路径/停止线上的总预测方差上界，不能只用无条件方差。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。

迁移时逐项填写：真实输入与工具变量的映射；工具假设为何成立；得到上界/下界/证书的方向；n及尺度/层数的常数；尚需证明的连接引理。
