# 中心立方体极大算子接口

通用接口保持中心立方体最大算子M_c f(x)=sup_{Q:center(Q)=x}|Q|^{-1}∫_Q|f|，其函数类、尺度范围与边界约定由调用方显式提供。可用SOS/矩工具处理经独立建模证明可由多项式表示的子问题；不得推测项目私有变量、记号或离散到连续映射，也不得由SOS可行性自动推出算子全局界。

固定研究对象：Mₙf(x)=sup_{r>0}(2r)^{-n}∫_{x+[-r,r]^n}|f(y)|dy，使用Lebesgue测度与中心立方体。

迁移时逐项填写：真实输入与工具变量的映射；工具假设为何成立；得到上界/下界/证书的方向；n及尺度/层数的常数；尚需证明的连接引理。
