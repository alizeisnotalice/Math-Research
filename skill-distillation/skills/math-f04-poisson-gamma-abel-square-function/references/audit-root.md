# F04 · heat 原子化约化的已检查推导

这是补充原文 `S-986768affaa80a44` 中引用原子化定理的一种专门证明，只适用于下述热核。标准参考的完整原文仍未取得，不能声称一般卷积极大算子的约化已完成回查。

设固定维数 n 上的 heat 极大算子已对每个有限正原子 ν 满足

`α|{sup_{t>0}h_t*ν>α}|≤C ν(R^n)`，α>0。

要扩展到非负 f∈L¹，先令 f_R=f1_{[-R,R]^n}。将紧支撑划分为越来越细的网格，在每格选一点，并将该格 f_R 的积分作为该点原子质量，得到 ν_j；所有 ν_j 质量都等于 ∫f_R。

固定 x 及 t>0，热核 y↦h_t(x−y) 在紧支撑上一致连续，因此 `h_t*ν_j(x)→h_t*f_R(x)`。对所有正有理 t 逐点成立。热核卷积关于 t 在任意正时间附近连续（核在该时间邻域有统一L∞界，可用f_R∈L¹支配），故有理时间的上确界等于全时间上确界。

若 `sup_t h_t*f_R(x)>α`，则存在某个正有理 t 使该值严格大于α；足够大的 j 都满足 `h_t*ν_j(x)>α`。因此该层集包含于 `liminf_j {sup_t h_t*ν_j>α}`。对层集指标用 Fatou，可得其测度≤原子层集测度的 liminf≤C∫f_R/α。

最后 R→∞，由正核的单调收敛，`sup_t h_t*f_R↑sup_t h_t*f`，层集从下逼近并保持相同界。一般实/复 f 使用 `|H_tf|≤H_t|f|`。C 的维数依赖在以上步骤保持；这里没有通过有限网格引入新的维数因子。

条件缺失处理：不可直接将这个点态核一致连续论证用于球/立方体指标核；那类核须另证边界、连续尺度约化及逼近步骤。也不能把任意有符号核替换成正核而保留同一比较。
