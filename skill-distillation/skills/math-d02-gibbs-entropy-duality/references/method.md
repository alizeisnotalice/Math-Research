# Gibbs 变分与熵对偶：方法与验收边界

1. 一般概率接口固定自然对数、概率 `Q` 与实值 `Q`-几乎处处有限的可测势 `V`，并验证 `0<Z=∫e^VdQ<∞`。令 `dQ_V/dQ=e^V/Z`；该密度严格正且有限 `Q`-几乎处处，故 `Q_V` 与 `Q` 等价。若 `P≪Q`、`KL(P‖Q)<∞` 且 `E_P|V|<∞`，令 `f=dP/dQ`，则
   `dP/dQ_V=f Z e^{-V}`，从而 `log(dP/dQ_V)=log f+log Z−V` `P`-几乎处处。有限 KL 使 `log f` 的正部可积，负部由 `∫_{f<1}f|log f|dQ≤1/e` 控制；加上 `E_P|V|<∞`，逐项积分有定义且有限，得到
   `KL(P‖Q_V)=KL(P‖Q)−E_PV+log Z`。若 KL 或 `E_P|V|` 无穷/未定义，不使用该差式；若势被允许取扩展值，`Z=0` 也须单独视作未定义倾斜（对实值有限 `V` 与概率 `Q` 不会发生）。

2. 在第1步的有限域由 KL 非负得 `E_PV−KL(P‖Q)≤log Z`。等号候选 `Q_V` 只有在允许分布类包含它、且 `∫|V|e^VdQ<∞` 时才属于该有限域：这保证 `E_{Q_V}|V|<∞`，并由 `log(dQ_V/dQ)=V−log Z` 得 `KL(Q_V‖Q)<∞`。`Z<∞` 单独不保证该可积性；不满足时不声称有限域达到等号。该概率代数是本卡中的独立密度推导，不是来源对任意扩展值分布的 Donsker–Varadhan 公式证明。

3. 物理来源 P-e237bd81eec0afea 仅限经典相空间密度：PDF pp.2–6 中有限非零能壳体积给 `S_m−S=kD(ρ‖ρ_m)`，`T>0` 且配分函数有限给 `F[ρ]−F_c=kT D(ρ‖ρ_c)`、`F_c=−kTlogZ`。对数、能量与熵的积分域必须匹配；不能将这组物理恒等式转成一般标准 Borel 的变分定理。
4. Gibbs–Bogoliubov试探界另检H₀的有限Z₀及E_{ρ₀}|H−H₀|<∞，再写F_c≤F₀+E_{ρ₀}(H−H₀)；该上界方向与正指数收益自由能约定分开。

5. 作者熵增/自由能降证明用对称或详细平衡跃迁、合法换序与无边界通量；Lyapunov单调及平稳性不保证唯一平衡或长时收敛。

6. 带温度或β时从明确的势V=βF或V=−βH重新缩放，保留参考测度与单位；Z无穷、零温或无定义积分只报缺口。

## 不可省略的限制

改变参考Q会改变熵罚；Z无穷时不能建立概率倾斜。

# Gibbs弱变分式：已检查基础推导

Q是概率，V可测，0<Z=E_Q e^V<∞，dQ_V=e^V dQ/Z。
在KL(P||Q)、E_PV与涉及积分有限的情形，密度比恒等式给出
KL(P||Q_V)=KL(P||Q)−E_PV+log Z。
KL非负可由凸函数s log s的Jensen不等式得到，故
E_PV−KL(P||Q)≤log Z。
若Q_V也满足这些有限性条件，取P=Q_V达到等号。
扩展实数情形不能直接相减∞−∞，需要另行采用截断或变分定义。
