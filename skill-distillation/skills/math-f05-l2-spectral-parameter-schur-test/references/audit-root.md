# F05：Hilbert–Schmidt 均值界的符号检查

公开来源 S-19f83d2017f67f5d 第8–9页给逐谱求和工作流，但印刷组合是(1−ν)AX−νXB，证明元素却用加号；A=B=X=[1],ν=1/2时声称的正lower为1、middle为0，不能按原式操作。

以下更弱正向界为**已检查推导**：A,B正定矩阵，X任意，0≤ν≤1，r=min(ν,1−ν)，有

|| (1−ν)AX+νXB ||_F² ≥ ||A^(1−ν)XB^ν||_F²+r²||AX−XB||_F²。

酉对角化A=Udiag(λ_i)U*、B=Vdiag(μ_j)V*，令Y=U*XV。对每谱对，当ν≤1/2，

((1−ν)λ+νμ)²−ν²(λ−μ)²=(1−2ν)λ²+2νλμ≥(λ²)^(1−2ν)(λμ)^(2ν)=λ^(2(1−ν))μ^(2ν)。

这是两输入加权AMGM；ν≥1/2交换λ,μ和ν,1−ν。乘|y_ij|²后求和，由HS的酉不变性得到结论。此证明不需要Kontrovich谱比因子。

适用例：ν=1/2时上述恒等式逐谱为λμ，故整个HS式精确取等；即便A,B不交换也成立。

缺条件例：将正号改成负号、或将Frobenius范数直接改成任意算子范数，不能沿用逐谱平方求和证法。该矩阵结果没有直接给TC-A4或私有HS来源树的界；真实算子映射、非交换层交叉项仍待定义/证明。
