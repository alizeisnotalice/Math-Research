# 近极值稳定性与刚性：方法与验收边界

1. 先明确优化方向与非负亏损：最大化问题用极值减当前目标值，尖锐不等式按所选方向用有效左端减右端；列出归一化与等号集合。

2. 识别平移、伸缩、符号或相位等对称性；按模这些对称性计算距离。

3. 找到所需范数/距离、对称群及参数域匹配的定量定理；若δ≥c(d)dist^p，逐项保留p、c(d)和各极限的量词次序，再改写dist≤(δ/c(d))^(1/p)。

4. 核对所用原文版本的定义域和修订范围；连续维度提升逐项检查辅助维度条件，谱稳定性逐项检查全部允许对称性的切向核与正交条件。外依赖存在未修证明缺口时，将该来源定理保留为原文主张，不能认证全目标稳定性。

5. 对候选输入分别计算亏损和距离，区分定量稳定性与定性紧性。

6. 没有适用稳定性定理时，只报告近最优，不推断输入接近某个精确极值函数。

## 不可省略的限制

目标值接近尖锐常数，并不自动意味着函数接近极值函数；还需要模对称性的紧性和定量稳定估计。 不同版本的参数域不能混用；曾被修订的宽域、未核端点、遗漏平移切向的核论证或不匹配的范数常数都必须保留为 gap。

本项目前仅提供操作方法与待核验来源；高级定理及常数须从真实阅读卡回查原文。
