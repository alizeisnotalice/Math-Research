## 执行步骤

1. 先选标准BnB或来源quasi-BnB，固定最小化/最大化方向。标准节点真界对整个子域有效；可行incumbent在最小化给ub、最大化给lb。
2. 每个分支子域覆盖父域且边界不漏，标准最小化仅经认证lb(C)>ub才剪枝；保全局活动界、incumbent与停止间隙。
3. P-922909d5e8e47a30的qlb只须在含全局最小点的盒上≤f*，不能当任意盒的真下界；qlb(C)>ub排除含最小点，必须以保留至少一个全局最小点的归纳证明支撑剪枝。
4. qBnB(2) 的来源问题是最小化 `f` 于立方体 `C₀`，且“无约束”按来源定义：存在开集 `U₀⊃C₀`，使 `inf_{U₀} f=min_{C₀} f`；`f∈C¹` 且 `∇f` 在整个 `C₀` 上有已知 Lipschitz 常数 `L₂≥0`。因此全局极小点满足 `∇f=0`。对中心 `x_C`、半径 `r` 的节点，公式 `f(x_C)−L₂r²/2` 只在节点含全局极小点时提供 quasi-lower bound；它不是任意节点的真下界。若 `f∈C²`，可用经认证的 `C₀` 上 Hessian 最大特征值非负上界替代该梯度 Lipschitz 常数。约束边界上的节点必须改用来源 constrained-qBnB(2) 的独立取样规则与条件；若仅用局部 Lipschitz 常数，须逐节点证明其覆盖所需的线段/邻域，不能默认等同来源全局条件。来源 P-922909d5e8e47a30 PDF pp.6–8。
5. qBnB(3) 只适用于来源所定义的无约束全局最小化问题：存在开集 `U₀⊃C₀` 使 `inf_{U₀} f=min_{C₀} f`，且 `f∈C²(U₀)`。对当前节点 `C`（中心 `x₀`、半径 `r`），须有 `r>0`、`L₃>0`，闭球 `B̄₂ᵣ(x₀)⊂U₀`，并在整个闭球上有已知 Hessian-Lipschitz 常数 `L₃`。否则相应来源分支不可用；球不包含于 `U₀` 时置 `qlb(C)=−∞`。按来源设 `λ̄=max{0,5L₃r−λmin(x₀)}`、`f̂(x)=f(x)+λ̄‖x−x₀‖²/2`、`m=3L₃r`、`r₀=r`、`rₖ₊₁=3L₃rₖ²/(2m)`。必须认证 (16) `λmin(x₀)≥−L₃r`，并在每步认证 (17) `‖xₖ₊₁−xₖ‖≤rₖ+rₖ₊₁` 与 `‖xₖ−x₀‖≤rₖ+r₀`，且 Newton Hessian 可逆；认证失败才按来源 quasi-rule 置 `qlb(C)=+∞, x(C)=x₀`，这表示该节点不含全局极小点，不是任意节点上的真下界。全部通过时，理论极限 `x̂*` 给出 `x(C)=x̂*`、`qlb(C)=f̂(x̂*)−λ̄r²/2`、gap `≤3L₃r³`。有限精度必须另认证 `M r_K²/2≤ε_Newton`，其中 `M=λmax(x₀)+λ̄+2L₃r`，并将 `−ε_Newton` 纳入准下界。`L₃=0`、`r=0`、不可逆、测试未认证或浮点结果不确定时，不得把该失败当作可剪枝的 `+∞`；须另行证明或提高精度。来源 P-922909d5e8e47a30 PDF pp.9–12, Proposition 2/Theorem 1, Eqs.(14)–(17) and finite-precision rule.
6. **来源 BFS 的有限 ε-终止 gate（C04-BFS-TERM-06）**：只有来源 qBnB Algorithm 1/Theorem 2 的全部条件逐项成立，才可宣称有限步返回来源定义的 ε-最优点。目标必须是连续 `f` 在紧立方体 `C₀⊂Rᵈ` 上的最小化，给定 `ε>0`；采样规则满足 `x(C)∈C`，准下界规则满足 `qlb(C)≤f*(C)=f*` 对每个含全局极小点的子盒。并存在同一连续模量 `ψ:[0,∞)→[0,∞)`，`ψ(0)=0`，使搜索树中每个子盒 `C`（半径 `r(C)`）均有 `f(x(C))−qlb(C)≤ψ(r(C))`。搜索必须按完整代逐代 BFS 公平处理所有未剪枝盒；每个被展开盒沿最长边二分成两个覆盖父盒的子盒，故每代有限分支且子盒半径以 `q_d=√((d−3/4)/d)<1` 收缩。每代维护 `ub=f(x_best)` 及 `lb_g=min_{C∈L_g}qlb(C)`；由至少一个含全局极小点的盒持续存活，须有 `lb_g≤f*≤ub`。只在 `ub−lb_g≤ε` 时停，输出满足来源 ε-误差保证的 `x_best`。数值实现还须以可验证算术保证下界、剪枝比较和停止间隙；未认证的浮点比较不满足该 gate。此结果是给定 ε 的有限终止/近似保证，不是维数多项式复杂度界，也不自动给有限步精确极小点；qBnB(3) 的 eventual-exactness 另需其来源的非退化条件。未逐项核实模量、准下界有效性、完整代公平搜索或证书时，必须报告 gate 未满足，不得宣称收敛。来源 P-922909d5e8e47a30 Appendix A, Algorithm 1/Theorem 2 and proof, PDF pp.19–20.
7. P-deb72842d1067b4f原PDF完整，两栏续文的截断判断已撤回；Lemma3严格要求 `a≤c<d≤b`。其 SOS 下界用严格正条件 `f−λ>0`，故边界最优值一般是 `sup λ` 而非已取到的 `max λ`。该文 Theorem 1 只给定 ε 后存在有限阶数，不给阶数上界；完整 SOS 层/收敛及外引仍须保留为条件性，见[完整性更正](references/source-completeness-correction.md)。有理/区间证书与浮点 heuristic 分开，中心立方体有限构型搜索不等于解析全尺度极大界。

## 证据与失败处理

标准真下界与只对含全局极小点盒可靠的 qlb 不同；后者需专门全局极小点保留证明。qBnB 二阶/三阶的定义域、正则性、边界采样、Newton 端点和 BFS 有限 ε-终止 gate 均不可省略。SOS-BnB 完整数学审核尚未闭，qBnB 的 L₃=0 分支仍留缺口；有限 ε-终止不构成维数低复杂度或有限步精确解保证。
