# 分支定界：方法与验收边界

1. 先选标准BnB或来源quasi-BnB，固定最小化/最大化方向。标准节点真界对整个子域有效；可行incumbent在最小化给ub、最大化给lb。

2. 每个分支子域覆盖父域且边界不漏，标准最小化仅经认证lb(C)>ub才剪枝；保全局活动界、incumbent与停止间隙。

3. P-922909d5e8e47a30的qlb只须在含全局最小点的盒上≤f*，不能当任意盒的真下界；qlb(C)>ub排除含最小点，必须以保留至少一个全局最小点的归纳证明支撑剪枝。

4. qBnB(2)中心公式f(x_C)−L₂r²/2限开邻域无约束极小（梯度零）；盒边界需来源constrained取样规则，大盒可先qlb=−∞。L₂必须有效全局上界。

5. qBnB(3)限来源的无约束全局极小问题，需C²及有效Hessian-Lipschitz界。先确认闭球 B̄₂ᵣ(x₀)包含于开域；若不包含，来源置qlb(C)=−∞。Newton分支要求r>0、L₃>0；计算λ̄=max{0,5L₃r−λmin(x₀)}、f̂(x)=f(x)+λ̄‖x−x₀‖²/2，并设m=3L₃r、r₀=r、rₖ₊₁=3L₃rₖ²/(2m)。先检(16) λmin(x₀)≥−L₃r；经认证失败则置qlb(C)=+∞、x(C)=x₀。通过后，每步在2r球内以可逆Ĥ(xₖ)=H(xₖ)+λ̄I做Newton，并检(17) ‖xₖ₊₁−xₖ‖≤rₖ+rₖ₊₁及‖xₖ−x₀‖≤rₖ+r₀；任一次经认证失败同样置+∞/中心点。全部通过的理论极限为x̂*，取x(C)=x̂*、qlb(C)=f̂(x̂*)−λ̄r²/2，gap≤3L₃r³；有限精度设M=λmax(x₀)+λ̄+2L₃r，需认证M r_K²/2≤ε_Newton并取qlb(C)=f̂(x_K)−λ̄r²/2−ε_Newton。+∞只按quasi规则排除含全局极小点，不是任意盒的真下界。L₃=0、r=0、逆未认证或浮点检验不确定时禁用该字面分支，须另证/提高精度，不能把未认证失败当+∞剪枝。来源P-922909d5e8e47a30 PDF9式(14)–(17)、PDF10–11算法、PDF12有限精度规则。

6. 来源BFS有限终止需紧立方体、连续f、最长边二分及统一gap模量ψ(r)→0；维数收缩q_d=√((d−3/4)/d)，并无维数多项式复杂度。最终精确另需有限个非退化最小点。

7. P-deb72842d1067b4f原PDF完整，两栏续文的截断判断已撤回；Lemma3严格要求a≤c<d≤b。完整SOS层/收敛及外引仍待数学审核，见[完整性更正](source-completeness-correction.md)。有理/区间证书与浮点heuristic分开，中心立方体有限构型搜索不等于解析全尺度极大界。

## 不可省略的限制

标准真下界与只对含全局极小点盒可靠的qlb不同；后者需专门全局极小保留证明。qBnB二阶/三阶正则性、边界采样和Newton端点不可省略。SOS-BnB完整数学审核尚未闭（源截断误判已撤回）及qBnB的L₃=0缺口仍留，有限终止不是维数低复杂度保证。
