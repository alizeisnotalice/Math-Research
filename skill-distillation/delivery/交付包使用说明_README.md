## 一、这个包是什么

64 项数学研究 Skill（A01–N04，面向中心立方体极大算子课题）经过 **13 轮外部审核（R1–R13）** 后的工作副本 + 全部审计产物。审核对每一项做了：结构闭合检查、诚实分档核对、数值/闭式断言独立重算、案例实际执行、已发现问题修订。

```

```

## 三、快速使用

1. **按代码定位**：`audit_r12/final_index_64.json` 列出 64 项的 ID、分档、来源卡数、已验证断言 ID。
2. **读入口**：每项 `SKILL.md` 的「执行步骤」是操作序列；「证据与失败处理」是不可套用的边界。
3. **查验证状态**：
   - 全量断言登记簿：`audit_r12/assertion_register.json`（34 条子断言，唯一 ID + 双维分类）
   - 逐项复核记录：`workspace_revised/<skill>/references/verification-log-20261006.md`
   - 案例执行结果：`audit_r12/case_batch_execution_r13.json`（43/128 已执行）
4. **看依赖**：`audit_r12/dependency_graph.json`（64 skill 节点 + 274 论文节点 + 259 边）。

- 本包为纯静态文件，无全局安装动作。将 `workspace_revised/` 复制到任意工作目录即可。
- Skill 内引用论文时按 `references/` 的相对路径与 provenance 定位；PDF 原件在主交接包的 `evidence/papers/`。
- 修改历史：所有修订均为 append-only；冻结源未改动。
