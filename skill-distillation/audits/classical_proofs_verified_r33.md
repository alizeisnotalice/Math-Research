## 8. Grüss 不等式（旧18项 F4 的本体证明；此前 R7 只证了 sharpness）

**命题**：φ≤f≤Φ, γ≤g≤Γ（逐点），μ=E[f], ν=E[g]。则
|E[fg] − μν| ≤ (Φ−φ)(Γ−γ)/4。

**证明（归一化路线）**：
1. 中心化：E[(f−μ)(g−ν)] = E[fg] − μν。
2. 归一化：F := (f−μ)/(Φ−φ) ∈ [−α, β]，α := (μ−φ)/(Φ−φ)，β := (Φ−μ)/(Φ−φ)，
   **α+β = 1**；同理 G ∈ [−γ′, δ]，γ′+δ = 1。
3. 逐点乘积界：F·G ≤ max(βδ, αγ′)（混合项 ≤0）；由 β,δ,α,γ′ ∈ [0,1]：
   βδ ≤ ((β+δ)/2)² ≤ 1/4，αγ′ ≤ 1/4 ⟹ **FG ≤ 1/4 逐点**；
   对称地 FG ≥ −max(αδ, βγ′) ≥ −1/4。
4. 取期望：|E[FG]| ≤ 1/4 ⟹ |E[fg]−μν| ≤ (Φ−φ)(Γ−γ)/4 □

**复现注记**：初版尝试直接对 (μ−φ)(Γ−ν) 型乘积用独立区间界 `ab ≤ AB/4`，
发现该步**不成立**（a=A,b=B 给 AB）——打印了完整排查过程后切换到归一化路线。
教训：区间界 [0,A]×[0,B] 的乘积上确界是 AB 不是 AB/4；1/4 来自归一化后
α+β=1 的**约束**（两个偏差分量的和为 1），这是区间算术替换不了的结构。

**数值**：200,000 组随机区间与样本，max 比值 0.7917 ≤ 1 ✓（=1 需两点退化分布，
R7 穷举已证 sharpness；本批补的是不等式本体）。

## 9. Gibbs 变分原理（d02 核心公式 D02-IDEN-01 的本体证明）

**命题**：Z := ∫e^V dQ < ∞。则 log Z = sup_P {E_P V − D(P‖Q)}，唯一最优 P = Q_V := e^V/Z·Q。

**证明**：
1. 对任意 P≪Q（P⊥Q 时 D=∞，不等式平凡）：
   D(P‖Q_V) = E_P[log(dP/dQ) − V + log Z] = D(P‖Q) − E_P V + log Z ≥ 0 [KL 非负]
   ⟹ E_P V − D(P‖Q) ≤ log Z，对一切 P □
2. P = Q_V 取等：E_{Q_V}V − D(Q_V‖Q) = ∫(V − log(dQ_V/dQ))dQ_V = ∫log Z dQ_V = log Z □
   唯一性：KL(P‖Q_V)=0 ⟺ P=Q_V a.s.
3. 依赖链：KL 非负性 = Jensen（log 凹）：−E_P log(dQ/dP) ≥ −log E_P(dQ/dP) = −log Q(supp P) ≥ 0 ✓
4. **可积性条件补全**（R12 曾标"充分性未独立复核"，本批补上）：
   标准充分条件为 D(P‖Q)<∞ 且 E_P V 有限；扩展实数约定（允许 +∞）下不等式单调成立。

**数值**：2000 组随机离散实例：上界方向恒 ≥0（min 残差 0）；P=Q_V 取等残差 **4.4e−16** ✓
