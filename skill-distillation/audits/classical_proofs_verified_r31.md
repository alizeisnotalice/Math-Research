## 1. Hoeffding 引理（h05 依赖）

**命题**：X 中心化（EX=0），a≤X≤b a.s.。则 E e^{λX} ≤ exp(λ²(b−a)²/8)。

**证明**：
1. 凸性：对 x∈[a,b]，e^{λx} ≤ (b−x)/(b−a)·e^{λa} + (x−a)/(b−a)·e^{λb}。
   取期望（用 EX=0）：E e^{λX} ≤ (1−p)e^{λa} + p e^{λb}，其中 p := −a/(b−a) ∈ (0,1)。
2. 令 s := λ(b−a)。注意 **λa = −sp**（因 a/(b−a) = −p）。
   则 ln E e^{λX} ≤ −sp + ln(1−p+pe^s) =: G(s)。
3. G(0)=0；G′(s) = pe^s/(1−p+pe^s) − p ⟹ G′(0)=0；
   G″(s) = p(1−p)e^s/(1−p+pe^s)² ≤ 1/4，
   由 AM–GM：(1−p+pe^s)² ≥ 4p(1−p)e^s（等号 p=1/2 或 s=0）。
4. 二阶 Taylor 控制 ⟹ G(s) ≤ s²/8 □

**数值**：2000 组随机两点族，max LHS/RHS = **0.999984**（逼近 1，界紧）。
**复现注记**：λa=−sp 的代数曾误写为 −s(1−p)（会导致 G′(0)≠0 的假矛盾），
按 p 的定义核对后消除——这是本次复现内部发现并修正的一处推导滑步。

## 2. Bernstein 尾不等式（h05 依赖）

**命题**：|X−μ|≤M，Var=σ²。P(X−μ≥t) ≤ exp(−t²/(2(σ²+Mt/3)))。

**证明链**：
1. Bennett 型 mgf 界：ln E e^{λ(X−μ)} ≤ (σ²/M²)(e^{λM}−1−λM)。
2. 子指数不等式 e^u−1−u ≤ u²/(2(1−u/3))，0<u<3：
   逐项比较 1/k! ≤ 1/(2·3^{k−2}) ⟺ 2·3^{k−2} ≤ k!：
   k=2: 2=2 ✓；k=3: 6=6 ✓；k=4: 18≤24 ✓；此后比值 (2·3^{k−2})/k! 每步乘 3/(k+1)<1 单调下降 ✓。
3. Chernoff：P ≥-tail ≤ exp(−λt + σ²λ²/(2(1−λM/3)))；最优 λ = t/(σ²+Mt/3)。
   代入：1−λM/3 = σ²/D，D := σ²+Mt/3 ⟹ 指数 = −t²/D + t²/(2D) = **−t²/(2D)** □

**数值**：Binomial(400,0.5) 上尾 P(S≥230)=1.56e−3 ≤ 1.67e−2 ✓。

## 3. Cantelli 不等式（e01 依赖）

**命题**：P(X−μ≥t) ≤ σ²/(σ²+t²)。

**证明**：对 a>0：σ²+a² = E[(X−μ+a)²] ≥ (a+t)²P(A)，A:={X−μ≥t}
（A 上 X−μ+a ≥ a+t > 0；Aᶜ 上被积 ≥0）⟹ P(A) ≤ (σ²+a²)/(a+t)²。
对 a 求导：2(at−σ²)/(a+t)³ = 0 ⟹ a* = σ²/t，代回得 **σ²/(σ²+t²)** □

紧性（R9 已证）：两点分布 P(X=r)=1/(1+r²), P(X=−1/r)=r²/(1+r²) 取等。

## 4. Doob L^p 极大不等式（g05 常数 4C 的来源）

**命题**：非负鞅 {f_k}（有限时限 f_N）。‖max_{k≤N} f_k‖_p ≤ (p/(p−1))‖f_N‖_p。

**证明**：
1. Doob 极大引理：A_k := {f_1<λ,…,f_{k−1}<λ, f_k≥λ} 互不相交；
   λ1_{A_k} ≤ f_k 1_{A_k}；E[f_k 1_{A_k}] = E[E[f_N|F_k]1_{A_k}] = E[f_N 1_{A_k}]（A_k∈F_k）。
   求和：λ P(max_{k≤N} f_k ≥ λ) ≤ E[f_N 1_{max≥λ}]。
2. 层蛋糕：E[(max f)^p] = p∫₀^∞ λ^{p−1} P(max≥λ)dλ ≤ p∫ λ^{p−2} E[f_N 1_{max≥λ}]dλ
   = (p/(p−1)) E[f_N · (max f)^{p−1}] ≤ (p/(p−1)) ‖f_N‖_p ‖max f‖_p^{p−1}（Hölder）。
3. 若 ‖max‖_p<∞ 则消去 ⟹ ‖max f‖_p ≤ (p/(p−1))‖f_N‖_p □

**p=2**：‖max f‖₂ ≤ 2‖f‖₂ ⟹ ‖max f‖₂² ≤ 4‖f‖₂² —— **这正是 g05 的 (p′)^p 在 p=2 时 = 4C 的来源**（2²=4）。

**数值**：2000 组随机非负 f 的 4 层二进鞅，max ‖max E[f|F_k]‖₂/‖f‖₂ = **1.2288 ≤ 2** ✓。

**锐性如实标注**：常数 (p/(p−1))^p 的锐性是经典结果（二进鞅极值序列，Burchard 型构造），
本轮未重证锐性——只证明了不等式本身。g05 的「(p′)^p sharp」仍以源卡 Bellman 框架为据。
