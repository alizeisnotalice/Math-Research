## 5. Carathéodory 定理（m01 依赖；凸版 + 锥版 + 闭性推论）

**凸版**：S⊂R^d，x∈conv(S) ⟹ x 是 ≤ d+1 个 S 点的凸组合。

**证明**：取表示 x=Σc_i x_i（c_i>0, Σc_i=1）且支撑数 k 最小。
若 k≥d+2：k 个点仿射相关 ⟹ ∃α 不全零：Σα_i x_i=0 且 Σα_i=0。
对 t∈R 有 x=Σ(c_i+tα_i)x_i 且系数和仍为 1。由 Σα=0 与 α≠0 知 α 有正有负，
故可行集 {t : ∀i, c_i+tα_i ≥ 0} = [max_{α_i>0}(−c_i/α_i), min_{α_i<0}(−c_i/α_i)]
非空（含 0）且上端为正。取 t* = 上端点：恰有系数归零、其余 ≥0
⟹ 得支撑 k−1 的表示，与最小性矛盾 □

**锥版**：cone(S) 中任一点是 ≤ d 个 S 点的非负组合（k≥d+1 时线性相关，同法扰动）□

**闭性推论**：有限 S 的 cone(S) = 有限个 simplicial cone（由 ≤d 个线性无关生成元）
之并，每个 simplicial cone 闭 ⟹ cone(S) 闭 □
——这正是 Farkas 分离论证所需的闭性，**不依赖**一般有限生成锥闭性定理。

**数值**：300 例随机 LP 基本解最大支撑 = 6（d≤6），与 ≤d 一致 ✓

## 6. Farkas 引理（b01 证书逻辑闭环）

**命题**：恰一成立：(I) ∃x≥0, Ax=b；(II) ∃y, y^TA ≥ 0（逐列）且 y^Tb < 0。

**证明**：
- (I)⟹¬(II)：y^Tb = y^TAx = Σ_i x_i(y^TA)_i ≥ 0（x≥0 且逐列 ≥0），与 <0 矛盾 □
- ¬(I)⟹(II)：C := cone(A 各列) 闭（复现 5）且 b∉C。
  点对闭凸集的严格分离：∃y, ρ 使 y^Tb < ρ < y^Tz ∀z∈C。
  锥性：若 y^Tz₀ < 0 对某 z₀∈C，则 tz₀∈C（t→∞）使 y^T(tz₀)→−∞，与 <ρ 矛盾
  ⟹ y^Tz ≥ 0 ∀z∈C ⟹ y^TA ≥ 0 逐列；
  又 y^Tb < ρ ≤ y^Tz（∀z）⟹ y^Tb < 0（否则 ρ≤y^Tb 矛盾）□

**与 b01 的衔接**：b01 的 LP 对偶 gap 恒等式 c^Tx−λ^Tb = λ^T(Ax−b)≡0 是对偶侧证书；
Farkas 给原始不可行侧的证书方向——两侧合起来 b01 的"证书逻辑"完整。

## 7. 不交谱投影的 Parseval 分解（g04 p=2 常数恰 1 的机理）

**命题**：频率区间 {I} 两两不交，P_I 为对应正交投影。则 ∫Σ_I|P_I f|² = ‖f‖₂²（当 ∪I=R 全谱）。

**证明**：P_I*=P_I=P_I²；I∩J=∅ ⟹ P_IP_J = 0（谱支集不交，乘法投影代数）。
分辨率恒等：‖f‖₂² = ‖Σ_I P_I f‖₂² + ‖P_{R∖∪I} f‖₂²（正交直和分解），
‖Σ_I P_I f‖₂² = Σ_I‖P_I f‖₂² + 2Re Σ_{I<J}⟨P_I f, P_J f⟩ = Σ_I‖P_I f‖₂²
（交叉项 = ⟨f, P_I P_J f⟩ = 0）□
**常数 1 不可改进**：取 f 单频落在某 I 内 ⟹ S(f)=|f| ⟹ ‖S(f)‖₂=‖f‖₂ 取等 □

**数值**：FFT 分桶 Bessel 型验证 Σ‖P_I f‖² ≤ ‖f‖² ✓（部分谱时严格 Bessel；全谱取等）。

**与 g04 的衔接**：R21 已验 p=2 常数恰 1（解析事实），本条给出其投影代数机理；
p=2 以外 p<2 无 uniform bound 的反例机制（重复区间能量×重数）已在 R21 记录。
