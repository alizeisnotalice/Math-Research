## 1. 从 coarea 得相对高阶导数

固定真实 body32 模型、Lebesgue 测度、q=6/5。令 `R=A^T/32`。沿一个物理坐标 `e_i` 的 coarea 参数变化为 `c_v z`，其中 `|c_v|=1/32`。对每个实参数 a 与 t≥ε，

`f_t(a+c_v z)/f_t(a) = [(1+c_v z/(a+it))(1+c_v z/(a-it))]^-1`。

因此 32 个 Cauchy 密度产生 64 个线性分母。它们 Taylor 系数的绝对值由 `(1-z/(32t))^-64` 的非负系数控制。在 `|z|<32ε` 的紧子盘上存在统一可积支配，可以先在 coarea 积分和时间积分内展开；Hε 本身正且有限。故设

`a_k=binom(63+k,k)/32^k`，

则 `|[z^k](Hε(x+ze_i)/Hε(x)-1)| <= a_k ε^-k`。

Hε(x)>0 保证在原点某个小邻域内可取 q 次幂的解析支。这里只取有限阶导数，不需要声称整盘不存在复零点。有限 binomial 展开给

`D_m = m! [z^m] sum_(j=1)^m |binom(q,j)| ((1-z/32)^-64-1)^j`，

`|∂_i^m (Hε^q)(x)| <= D_m ε^-m Hε(x)^q`。

全部系数用 Fraction 精确计算：

- `D_2=1167/200`；
- `D_4=187576101/2560000`；
- `D_6=73354040202609/16384000000`。

这是一条可以接入局部积分程序的真实相对导数界；不把浮点统一误差当作导数证书。

## 2. 可积 Peano 误差和明确资源障碍

令 In、Qn 分别是一维区间长度 h 上的积分与 n节点 Gauss-Legendre 正规则。m=2n。其 Peano 核 K 在单位区间非负且反射对称：Gauss 对所有 `f^(m)>=0` 的误差非负，可由节点处二重 Hermite 插值余项中 `prod_j (x-x_j)^2` 的非负性证明。精确到 m−1 次多项式又给反射对称。直接由

`K(s) = (1-s)^m/m! - sum_j w_j (x_j-s)_+^(m-1)/(m-1)!`

及非负权，得到

`0 <= K(s) <= min(s,1-s)^m/m! <= c_n=1/(2^m m!)`。

缩放回长度 h 并应用第一节的**可积相对导数界**，

`|I_i F-Q_i F| <= θ_i I_i F`，`F=Hε^q`，

`θ_i = c_n D_(2n) (h_i/ε)^(2n)`。

如果每个 θ_i<1，正张量算子逐坐标应用给

`integral_B F <= Q_B(F) prod_i (1-θ_i)^-1`。

n=1,2,3 的精确 `c_n D_(2n)` 分别为

`1167/1600`，`62525367/327680000`，`8150448911401/83886080000000`。

代码精确核对：在 h=2ε 时，三个 θ 均严格大于1。因此对使用 n≤3 的各向同性张量 Gauss 局部规则、且要求逐格使用上式闭合的任何 box 覆盖，每个边都必须 h<2ε。本批 ε=1/1000，所以每格五维体积小于 `(1/500)^5`，覆盖单位 face 需要

`N > 500^5 = 31,250,000,000,000 cells`。

每格 n=4 已需 `4^5=1024` 节点，超过首批256节点上限。这里没有排除混合阶数、稀疏规则、更好的局部导数、距离奇异层的方法，也没有证明真实 Gauss 误差大。**结论是此明确的截时通用高阶包络不值得盲目加格。**

对实际单格 Gauss3，`θ≈9.7160922424805164e16`；分母不正，故无法从 Q 推出 I 上界。全域真实预算由下一节独立提供。

## 3. 不遗漏奇异层的真实全域预算

round005 的删一参数推导保留分母后，实际给

`||p_t(1,.)||∞ <= (243*pi^6)^-1 t^-4/(1+1024t^2)`。

全自由空间边际精确为 `32t/[pi(1+1024t^2)]`。对后五坐标逐个反射不变，所以其正正交体 L1 积分为 `t/[pi(1+1024t^2)]`。插值到 q=6/5 并缩小到 `[0,1]^5` 得

`||p_t(1,.)||q <= A t^(1/6)/(1+1024t^2)`，`A=243^(-1/6)pi^(-11/6)`。

Minkowski 应用于非负时间混合。利用 Euler beta 积分

`integral_0^infty u^(1/6)/(1+u^2) du = pi/[2 sin(7pi/12)]`

（变量 `s=u^2` 后是 `B(7/12,5/12)/2`），得到

`B_full=A*32^(-7/6)*pi/[2 sin(7pi/12)] = 0.001399991219975472...`。

为 Hε 从上预算中扣掉被删时间区间包络积分的**下界**，

`B_H <= B_full - A*(6/7)*ε^(7/6)/(1+1024ε^2)`。

Arb384 实际核对 B_H<7/5000、B_full<7/5000。另用 elementary split t=1/32，分别以分母≥1与≥1024t²控制，独立得到较弱但真实的 `A*32^(-7/6)*(6/7+6/5)=0.001770980034734138...`。因此即不采用 beta 恒等式，也有一个自含的有限全域保底预算。以上是预算上端之间的比较，绝不声称真实 H 范数至少0.0013867。
