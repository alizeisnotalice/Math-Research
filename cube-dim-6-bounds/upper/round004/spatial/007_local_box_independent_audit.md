# 第004轮：局部连续 box 的独立标量审计

审计对象是主项目的五个 Arb384 截时顶点区间，box 为
\[
 E=\{x_1=1,\ x_2,\ldots,x_5\in[749,751]/1000,\ x_6\in[0,1]/1000\},
 \qquad\epsilon=1/100.
\]
五个代表点按四个 \(749/751\) 坐标中751的个数 \(k=0,\ldots,4\) 分类。
每类有 \(\binom4k\) 个排列，而完整对称 box 的第五坐标有 \(\pm1/1000\) 两个
反射顶点。因此32顶点平均简化为 \(\sum_k\binom4kH_k^{6/5}/16\)。

第006轮 ODE 下界损失为
\(\cosh(\sqrt{129/128}/10)^5\)。五个读入顶点均严格超过
\((3/100000)\) 乘该损失，故完整对称 box 上 \(H_{1/100}>3/100000\)。
取第五坐标的正半部便得到 \(G>3/100000\) 于 \(E\)，因为 \(G\ge H_{1/100}\)。

log-半凸 face 顶点上界先作用于完整第五轴 \([-h,h]\)，再用 x6 反射把积分除以2。
独立标量重算得到
\[
 \int_EH_{1/100}^{6/5}<6.556\cdot10^{-20}<7\cdot10^{-20}.
\]
这是局部 **截时** \(H\) 积分的上界，不能写成 \(I\) 或 \(G\) 积分上界。

最后独立重算了条件命题：若未来另行严格证明
\(g\ge1/60000\) 且 \(\|H_{1/1000}(1,\cdot)\|_{6/5}\le1/16000\)，再加已审的
whole-face short-time 范数预算，则正部成本严格小于约61.68955，因而小于64。
这两个全局假设在本审中均未证明。局部 box 不会被提升为全局 \(g\) 或 \(I\) 结论。
