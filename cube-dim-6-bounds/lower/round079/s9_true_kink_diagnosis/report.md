## Fubini的准确跳变系数

对固定五维位置x：若x不在P，两个交换盒不同时涉及该位置，不能因alpha与
beta换序产生交叠分支变化；若x在背景union中，严格正常余量使整条薄条带
都已有背景覆盖。只有`x∈P\background_union`会在右侧打开
`(beta,alpha)`缺口。缺口长度的右导数为`alpha'−beta'=1`。

由Fubini积分这些真实薄条带，且半cell比值归一化为64，完整跳变为

```
g_right − g_left
 = −64·(alpha'−beta')·|P\background_union|
 = −64·|P\background_union|
 ≈ −0.782849969636032.
```

程序准确核对斜率系数差为1，唯一同时tie已完整支付。因此

```
g_left ≈  0.2998992902405504 > 0,
g_right≈ −0.48295067939548164 < 0.
```

完整right-slope 36系数与有理包围都已保存，右端严格负；不是由K正体积
单独推出这个符号。保存值checker逐系数验证`right=left−64*uncovered`。
