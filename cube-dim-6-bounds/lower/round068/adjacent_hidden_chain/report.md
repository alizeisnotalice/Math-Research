```

```

第一对是原始盒110与16，长度分别为

```
(2,4,3,3,4,4),  (1,2,1,1,1,1).
```

```

[0,(1+u)/4],
[0,(1+u)/4],
[1+u-u*v^2,(1+u)/4],
[1+u-u*v^2,(1+u)/4].
```

程序实际数域符号检查给出五个区间均严格正宽，系数及布尔结论已保存。
因此不能继续用“交换投影空交”证明s6隐藏。**这不证明s6是真实union拐点**：
背景盒遮盖及两组同时交换的联合贡献尚未分析。s6右斜率完全未认定，
