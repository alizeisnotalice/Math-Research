## s2 交换的18对局部投影全部空交

当前位置

```
s2 = 1/2 + u^2*v^3/4 ≈ 1.0455618179858608.
```

交换函数19是 `s-1`，属于 all2 长度 `(2,2,2,2,2,2)`，块质量64、
共同半径1；函数14为 `r108-s`，属于18个质量108的原始盒，
`r108=u^2*v^3/2`。完整18个长度向量与逐对证据保存在结果。

本批实际比较每对盒在除第二坐标以外的五维投影，没有把主线程建议
当作已证输入。每一个质量108盒都存在某个尾坐标长度3。在选出的分离
尾坐标中，all2盒的下端是 `a-1`，该质量108盒的上端是 `r108-a`，
所以严格分离量为

```
(a-1)-(r108-a) = u-u^2*v^3/2
             ≈ 0.031338412337651576 > 0.
```

18/18对均有正有理区间分离证据，实际选择的原坐标为3、4或5。
结果保存的是冻结实际端点之差，并非只检查长度标签或浮点值。
因此交换的两类盒固定五维投影互不相交。

按已验收的局部容斥引理：有限 union 容斥项中，只有同时含这两类交换
盒的项可能因相对端点顺序交换而改变；这些项因固定投影空交恒为零。
其余项的端点分支不变，故 s2 被 union 隐藏，其左右导数相同。
所以当前右斜率仍为已接受的完整36系数 g，严格 g>0，展示为
`0.2998992902405504`。本批没有仅从raw顺序变化推断新斜率。

## 唯一下一事件与完整排序

斜率得到 s2 完整右侧顺序。复用37个函数定义，只比较36个当前相邻对

旧清单，也没有扫描全部未来事件。

紧邻位置为

```
s3 = v^5/6 + u^4*v/3 ≈ 1.0517977841590933,
s3-s2 ≈ 0.006235966173232507.
```

```
2s-r3072 = r243-s,
r3072=u^4*v,  r243=v^5/2.
```

它们分别属于 `(3,4,4,4,4,4)` 与 `(1,3,3,3,3,3)`，各一个原始
见证。完整37函数相邻的36个gap在s2与s3均非负且至少一端严格为正，
故整个开腔室严格排序。s3左侧有效选择及顺序与064保存的s2右侧完全
相同；s3左右均127个正盒，没有出生、死亡或clipping分支切换。
因此 `[s2,s3]` 中没有未付的内部换序/分支/kink。边界连续性允许把
仿射比值延拓到s3。此前为空的块对增大s不出生，使用008已证的正宽
条件；没有重新尝试长度5/6。
