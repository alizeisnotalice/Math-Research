## 严格事件结论

当前位置为

```
s0 = u^2*v^2/3 + u^2*v^4/6
   ≈ 1.04249709664552932082.
```

准确重建 37 个不同的未截断仿射函数。原来从更早起点列出的 217 个
位置中，第一个恰是 s0；严格右侧是 **216** 个，不能继续称 217 个待跑。
本批只处理当前位置与其紧邻右位置，没有逐事件扫描余下位置。

紧邻右位置是

```
s1 = u^3*v^3/6 + u^4*v/3
   ≈ 1.04370448579515406562,
s1-s0 ≈ 0.00120738914962474480.
```

它由以下有效原始端点交换产生：

```
r216-s = 2s-r3072,
r216 = u^3*v^3/2, r3072 = u^4*v.
```

左端点类包含 `(2,3,2,2,3,3)` 的六种尾坐标排列；右端点类为
`(3,4,4,4,4,4)`。四个符号配置为 s0 左/右、s1 左/右。四侧均有 127 个
正盒，没有裁剪分支切换、出生或死亡。s0 右侧与 s1 左侧的有效端点顺序
和选择完全相同；22 个有效函数的 21 个相邻 gap 在两端非负且至少一端
严格为正，故整个开区间排序严格成立。准确序列、选择、gap 系数在结果中。
原先为空的盒不能随 s 增大出生，沿用 008 已证的 `(ell-1)s<2r` 条件。

## 为什么原始换序被 union 隐藏

s0 的交换是 r324-s 与 2s-r2304，其中
`r324=u^2*v^4/2, r2304=u^2*v^2`。涉及的 4×4 个盒对在第一坐标
的截面已经严格分离，统一分离量为

```
2*a1-r324-r2304
= 2+u^4-u^2*v^2-u^2*v^4/2
≈ 0.4599097620316115 > 0.
```

s1 的 6×1 个交换盒对也在第一坐标严格分离，统一分离量为

```
2*a1-r216-r3072
= 2+u^4-u^3*v^3/2-u^4*v
≈ 0.45628759458273727 > 0.
```

22 个逐对空交证据及向外有理根区间均已保存。因此这里甚至不需要
其他盒遮盖：交换两类盒的五维投影交集为空。

严格理由：有限盒 union 的容斥式中，只有同时含这两类交换盒的项可能
因它们的相对端点顺序改变；这些项因固定第一坐标空交而恒为零。其余
项的仿射分支不变。因此 s0 和 s1 都不是这个有限 witness union 的拐点。
这没有断言它们不是原始 arrangement 的有效事件，也没有定位下一处真正
union 拐点；后者超出本批只核当前位置及紧邻候选的授权。
