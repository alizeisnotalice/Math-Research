# F043 数学审查：固定 A3 中段短时间机制

本稿在最终源锁前完成数学准备，最终源锁后独立六配置通过；实际核验和裁决见 report/results。只处理 v=(1,1,1,1,1,1)、w=(1,1,1,−1,−1,−1)，U0=span(v,w)，rho=1/64，B 均值 u∈[1/4,3/4]。所有参数使用同一真实 Cauchy 时间 s。

## 1. 正事件、coarea 与两大参数

E={|a_v|≥1/2, |a_w|≥1/16}、E_v={|a_v|<1/2}、E_w={|a_v|≥1/2, |a_w|<1/16} 两两互斥且覆盖概率空间（阈值边界为零测）。其推前密度 P、B_v、B_w 非负，且 actual B=B_v+B_w=p−P≤p。对 E_w 单独求上包时删去 |a_v|≥1/2 限制是合法正放松；放大后密度与 B_v 可以重叠，不能把两者之和称为≤p。

v,w 正交且各长√6，故 J2=√det Gram(v,w)=6。E 上两标量密度乘积≤s²/[π²(1/4+s²)(1/256+s²)]。正测试函数推前并删除两个参数后，余商为原 body32 在 U0perp 的四维商。033 归一化 Q4/J2=R2/(2π)^4，R2=2051/47038464，故 P≤R2 s^−2/[16π^6(1/4+s²)(1/256+s²)]≤C2 s^−2，C2=64R2/π^6。此处不多乘两个删参的排列数。

剩余30列 Gram 为32I−vv^T−ww^T≥26I；其 Fourier 逆变换有界连续，有限截断概率卷积也是连续密度。正测试函数先证 a.e. 上界；右侧商密度连续，故延拓到所有 x。无需零概率 fiber 条件化。

## 2. 缺一个生成元的合法峰比较

psi 对单坐标符号和置换不变、凸且齐次。令 S=||xi||1，先取绝对值再平均所有坐标置换，得到 psi(xi)≥psi((S/6)ones)。精确 psi(ones)=60，故 psi≥10S。任何 body 向量 b 满足 |b·xi|≤S≤psi/10，因此 psi−|b·xi|≥(9/10)psi。

此式可限制到任意固定 d 维正交商 W。其 Fourier 指数积分满足

    (2π)^−d ∫_W exp[−s(psi−|b·xi|)]dH ≤ (10/9)^d Q_W s^−d。

这是齐次换元在同一维数 W 的结果，不是在概率事件中改变时间。移去 b 后商密度任一点≤其 Fourier 绝对积分，因此第三次删除后的峰损失必须且足够保守地取 (10/9)^3。若 b 的投影已经为零，上界仍合法。不能直接继承未损失的旧 Q3。

## 3. 完整中段几何及实际 face 体积

写 x_A=(1,x2,x3)，其均值 mu，零和残差 e=x_A−mu·ones；写 x_B=u·ones+z，sum z=0。e1=1−mu，delta²=dist(x,U0)²=|e|²+|z|²。相对中心 x(u)=(1,1,1,u,u,u) 有

    |x−x(u)|²=|e|²+3e1²+|z|²≤3delta²，

因为 e1²≤(2/3)|e|²。故可取 eta=√3rho。它是原 x 的真实扰动控制，不是把 orthogonal distance 本身误当欧氏扰动。

对 v 小事件，中心残差在两块上的值为 p=1−a≥1/2 与 q=u−a。无论 q 符号，p−|q|≥1/4。两等长块残差的最近 body line 距离平方恰为 (3/2)(p−|q|)²；原点距离至少√3/2。减去 eta，得 h_v0=√3/2−eta、h_v1=√(3/32)−eta。

对 w 小事件，p=1−a≥15/16，q=u+a≥3/16，p−q≥1/8，故 h_w0=15√3/16−eta、h_w1=√(3/128)−eta。所有常数均正。

任意 body pair 的 plane 可写作一个 unsigned partition 的两个支撑块，块内带固定符号。在非负中心 x(u)，改成块内同号只会增加投影范数。因此，若该 unsigned partition 不同于 A/B，至少一块混合 1 与 u：若有 r,s≥1 个两类坐标，其残差贡献为 rs/(r+s)(1−u)²≥(1−u)²/2≥1/32。若 partition 是 A/B 但 plane 不是 U0，至少一个块含相反的符号；仅取该块中的一对坐标也给残差≥2min(1,u)²≥1/8。因此所有 U≠U0 对中心距离≥1/(4√2)，对 D 中真实 x 距离≥g=1/(4√2)−eta>0。

U0 内只有两条 body line：v 与 w（两块必须各取常值±1）。所以避开 v 的任意 body pair 都不可能张成 U0；避开 w 同理。这是使用原 x 的统一正距离的理由；不是对 x−a b 的整条 fiber 取距离下确界。

真实 face 测度也可明确。A 残差空间维数2，coordinate1-maximal 的三种 wedge 由置换等测，所选 wedge 占1/3。dy_A=√3 dH²(e)，dy_B=√3 du dH²(z)，总 Jacobian 为3。rho=1/64 时，A 的最大坐标差≤√2rho<1，B 偏移≤rho<1/4，因此 cube 边界不截断该小球。u 区间长1/2，于是

    |D|=3·(1/3)·(1/2)·v4 rho^4=π²rho^4/4。

作者短范数公式借用完整 face 的 L1，并未代入这个体积；补充体积不改变其预算，也不能据此把其它 planes 当作已覆盖。

## 4. Cauchy 平均允许 fiber 孤立零距

对 z≠0、lambda>0、s>0，若 b=0，积分直接等于1/(|z|²+lambda s²)≤1/|z|²。若 L=|b|>0，设 alpha=z·b/L²，gamma²=(|z|²−L²alpha²+lambda s²)/L²>0。原分母为 L²[(a−alpha)²+gamma²]。因此

    J=∫ s/[π(a²+s²)] · 1/[L²((a−alpha)²+gamma²)] da
     =(s+gamma)/[L² gamma(alpha²+(s+gamma)²)]。

可由两个 Cauchy 密度的卷积推得；独立准确检查使用上半平面两个简单极点的留数之和。极点重合时由正参数紧集共同可积支配延拓，不产生遗漏的重根项。

把分母改写为 |z|²+(lambda+L²)s²+2L²s gamma，且 gamma≥√lambda·s/L，于是

    J≤(1+L/√lambda)/|z|²。

z 沿 b 时，原 distance 在孤立 a 处为零；gamma 仍正，公式自动支付该处。不得先用 inf_a|z−ab| 代替分母。实际反例 x(1/4)−(1/4)v=(3/8)(b1+b2)，b1=(1,1,1,1,1,−1)、b2=(1,1,1,−1,−1,1)，正好落在另一 pair plane；而原 x 对该 plane 距离平方为1/6。

## 5. 三次删除、原 ordered 权重与完整补事件

保留 b=v 或 w，删除 k=0,1,2 个非 b 方向后，剩余31−k个商列的 Gram 为32I−(P_Wb)(P_Wb)^T，介于26I和32I之间。乘积正不等式使用 operator 上界32与真实个数31、30、29，故三个率是992、960、928。每次删除只带1/|P_Wv_i|的 coarea 因子；三次相乘为1/J3。原 body32 任意三个不同方向独立，故没有零投影删参或省略项。

前两距离用 h_b0,h_b1 控制，第三距离保留为 |P_(span(i,j))perp(x−a b)|。剩余3维商峰先用上一节的 (10/9)^3 损失，再扩真实 f_s(a) 的积分到全轴并应用 Cauchy 平均，lambda=928，|P_Wb|≤√6，|P_Wx|≥g。此顺序正确支付所有 a，也保留原商归一化。

原033五类 triple counts 为480、1920、480、640、1440。方向传递性使每类中包含固定 b 的数量为3n/32，故避开 b 的计数为29n/32，即435、1740、435、580、1305。合4495 unordered=26970 ordered。乘积系数为(32/π)^3，Q3/J3=R3/(2π)^3，因此

    Crem·π^6=24576 Σ n'_j R3,j=44743079/2970。

独立后处理从五个冻结 R3 有理数重求此和，不重新枚举任何 triple 或 fan。得到

    L=(10/9)^3 Crem(1+√(6/928))/g²，
    M_b=L/(h_b0²h_b1²)，M=M_v+M_w。

actual B_v≤M_v，actual B_w≤其扩事件≤M_w，因此 actual B≤M；与此同时 actual B≤p，而不是扩事件之和≤p。Sharper 的两个时间分母可保留，但本批固定预算只用 M。

## 6. 短时间范数与未付范围

P≤p、actual B≤p，故两者各自的 D 上 L1 都≤完整 face 切片 s/[π(1+1024s²)]≤s/π。插值 q=6/5，P 的 L∞≤C2s^−2、B 的 L∞≤M，分别给时间幂 s^1/2 与 s^5/6。Minkowski 得

    ||∫_0^epsilon p_s ds||_Lq(D)
    ≤(2/3)C2^(1/6)π^−5/6 epsilon^3/2
     +(6/11)M^(1/6)π^−5/6 epsilon^11/6。

两个空间函数可重叠，使用范数之和；给 B 使用一次 L1 是因为 B 是真实互斥补事件，不是将两个扩大密度错误地合并。有限正时间截断与单调收敛处理奇异零测集。

以上仅支付固定代表 A3 中段在0<s≤1/1000的短势。其它 plane 类型、u端点、所有长时间及余 face 均未支付；全 I/g/C6 不在结论内。
