# lower003 — finite local-spacing audit registration

Date: 2026-10-25.  This independent audit studies only the 96-box active
cell of the current six-dimensional rectangular-lattice construction.  It is
not a new lower-bound certificate and makes no global-optimality claim.

The registered finite pilot consists of exactly twelve rational directions:
for each coordinate `i=1,...,6`, replace `a_i` by
`(10001/10000)a_i` and by `(9999/10000)a_i`, while all other spacings remain
fixed.  Each run re-enumerates the 4^6 common-radius witnesses, removes
contained boxes, and recomputes the union.  Acceptance objects are: (i) the
candidate/retained counts and endpoint-branch signature, to identify a
crossing of an active-cell boundary; and (ii) the signed change in the
periodic weak ratio.  A positive numerical change is only an actionable
candidate for a later exact certificate.

The companion jet calculation differentiates the *fixed* baseline branch and
ordering.  Its output is valid only if the finite perturbation reports the
same combinatorial signature; it is an analytic local derivative, not a
proof for a finite perturbation.  All union volumes use the full union, never
the sum of overlapping boxes.
