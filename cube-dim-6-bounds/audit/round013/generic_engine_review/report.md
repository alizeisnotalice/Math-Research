## 1. 合法域必须是全部节点非零的开邻域

每个 full-group cone 的六个节点是线性形式

`b_(R,j)(x)=x·r_(R,j)/q_(R,j)`。

合法域要求所有这些有限多个形式均非零。对某个合法 x₀，由有限性可以选择开球 U，使每个节点在 U 上始终保持其原正负号；即使若干非零节点互相重合，也不影响它们与0的分离。这是本轮对真实 Green 势求导的关键，不能用旧热核在某个低维商空间中的连续性替代。

既有正截时势公式为

\[
H_\epsilon(x)=(2\pi)^{-6}\sum_R\alpha_R
 D_5(\arctan(\cdot/\epsilon);b_{R,0},\ldots,b_{R,5}),
\quad\alpha_R={|\det(r_{R,0},\ldots,r_{R,5})|\over\prod_jq_{R,j}}.
\]

当节点离0正距离时，`atan(b/ε)→(π/2)sgn(b)`；在各非零节点的所有正阶 jets 趋0。有限个 cone 的真实 Hermite DD 因而有有限极限。另一方面 `H_ε=∫_ε^∞p_tdt↑G`，故此有限极限就是实际 G，而不是对一个形式符号和的定义。得到

\[
G(x)={1\over128\pi^5}\sum_R\alpha_R
 D_5(\operatorname{sgn};b_R),\qquad x\in U.             \tag{1}
\]

旧文献接口(B)只直接写了“互异且非零”的情形；本轮对非零重复的扩展需要上述局部 Hermite 极限，不能把相等节点塞入带零分母的 barycentric 式。零节点仍完全不在此扩展内。

还可用两个互不相交、避开0的固定复轮廓包住正、负节点，在相应区域令 F 分别为常数 +1、−1。留数表达

\[
D_n(F;b_0,\ldots,b_n)
 ={1\over2\pi i}\int_\Gamma {F(z)\over\prod_j(z-b_j)}\,dz
\]

在 U 内对节点解析，包括同号节点重合。因此(1)在 U 上为光滑的真实 G，有限项可直接求导；无需另行交换一个未经支配的 `ε→0` 梯度极限。

## 2. 值、节点偏导与非零重复的逐项核对

不同节点时设

\[
w_i={s_i\over\prod_{k\ne i}(b_i-b_k)},\qquad
s_i=\operatorname{sgn}(b_i).
\]

U 内所有 `s_i` 固定。直接微分给

\[
D_5=\sum_iw_i,\qquad
\partial_{b_l}D_5=-\sum_{i\ne l}{w_l+w_i\over b_l-b_i}. \tag{2}
\]

源码第37–41行逐无序 pair 缓存 `b_i−b_j`，向 partial_i 加负项、partial_j 加正项，正好是(2)。Arb 差球若包含0，即使准确有理节点不相同也报错停止；不存在近节点阈值合并或强行相除。

重复节点时，排序后的 Newton 表中若首末准确相同，则整段都相同，阶数 `k≥1` 的 Hermite jet 为0；否则作正常差商。第28行的递推由低 j 向高 j 写回，右侧 `b[j+1]` 尚未被当前阶覆盖，因此没有就地更新次序错误。

在上述固定轮廓下对某一个带标签节点微分，分母多出一项 `(z−b_j)`，准确得到

\[
\partial_{b_j}D_5(F;b_0,\ldots,b_5)
=D_6(F;b_0,\ldots,b_5,b_j).                            \tag{3}
\]

这证明了第36行 copied-node fallback，包括非零重复。导数针对一个原标签，只复制一次；物理坐标同时移动多个同值标签时，后续 chain 自然求和提供重数。Hermite 内部排序不改变对称 DD 的值；输出槽仍对应原标签 j。

所有节点同号且非零时，局部 F 是常数，五阶差商及各偏导准确为0。源码先在第34行检查全部六节点，再走第35行同号分支；full driver 第50行也先逐节点检查。故含零情况不会被此优化吞掉。

任何准确零触发 `ZeroNode`，main 捕获后返回 exit3、`unsupported_zero_node`、`full_group_completed=false`，不输出成功的 G/gradient。程序不使用 `sign(0)=0`，不删除零项，不对部分主部作未经认证的抵消。unsupported 也不意味着该点真实 G 必然发散，旧主部路径可另外处理。

## 3. Fan Jacobian、物理坐标链与负号权2

Fourier cone 变量代换 `ξ=Σu_jr_j` 给 Jacobian `|det R|`，再设 `v_j=q_ju_j` 给 `α=|det R|/∏q_j`。截时公式的前因子为 `(2π)⁻⁶`，而 `atan→(π/2)sign`，所以 Green 因子为

`(2π)⁻⁶(π/2)=1/(128π⁵)`。

无额外 factorial、coarea 因子或物理 frame Gram 因子。源码第46行建立 `alpha2=2det/∏q`；第54行对值和梯度一起除 `128π⁵`，与准确 fan 公式一致。

程序枚举 `y_j=s_jx_(perm[j])`。故

\[
\partial_{x_k}b_m={s_jr_{m,j}\over q_m},\quad perm[j]=k.
\]

第51行先按 `partial_m*r_mj/q_m` 形成 y 梯度，第52行按 sign 和 permutation 放回原坐标。这里 x 是物理坐标，不是输入分子，因此 chain **不应再次除 point denominator**。输入分母只用于求值点的节点。

对所有合法节点，

`D5(sign;−b)=D5(sign;b)`，而节点偏导在 `b→−b` 下变号；配对项的物理 Jacobian 也变号，所以最终物理梯度相同。源码 mask `0..31` 固定一个符号，另一项为 `mask xor63`；每对使用 alpha2 准确乘2。720置换×32符号代表×21cones=483840次计算，对应967680逻辑项。不是把整体负号方向删掉。

第51行对零 ray 系数略过乘加，只是某条链式系数准确为0。它发生在六个 Fourier 节点全部完成非零检查以后，与跳过零节点或整个 cone 完全不同。

## 4. 整数范围与 Arb 外包

合法 CLI 输入为正 int64 分母、排除 `LLONG_MIN` 的 int64 分子；fan 满足21cells、正 `q≤10⁶`、`|ray_i|≤10⁶`、正 `det≤10⁹`，并且应事先确认为正确的数学 fan。

六项点积在 `__int128` 中先累加，最坏绝对值不超过

`6(2⁶³−1)10⁶ = 55340232221128654842000000 < 2¹²⁷−1`。

`den*q` 也先在128bit构造，之后两者都由 checked 限制到 int64。Rat 比较的交叉乘积绝对值不超过 `(2⁶³−1)²<2¹²⁶`；比较直接用 `<`，没有再相减造成额外范围需求。`LLONG_MIN` 在取符号及 gcd 前排除，所以没有 `abs(INT64_MIN)` 的隐含溢出。hash 中的位移使用 uint64，是定义良好的模运算。输入超出范围时应拒绝，而不是约分后偷偷接受一个不同约束的接口。

节点排序、相等和正负全部在准确有理整数域中决定。Arb 只承担区间计算。值、权重、偏导、chain 和 π 的每步都使用512bit外包；`double` 只用于 chrono 计时，不进入模型量。

成功输出通过 `arb_get_interval_fmpz_2exp` 保存整个 Arb 球的完整 dyadic 外包 `[l,u]2^e`。本次复核只解析这些完整整数端点，不用30位展示或短 radius 串重造证书。对于准确参考 `Q/π⁵`，先另用1536bit Arb 外包，再要求

`native_lower < reference_lower ≤ actual ≤ reference_upper < native_upper`。

这是 **native 包含参考外包** 的正确方向，不是仅检查两个宽球相交。

## 6. 需要保留的接口限制

- **Fan 与输入必须先验证。** 程序只做数量/数值范围检查，不验证 cone 覆盖、符号常号、q是否等于ψ(ray)或 fan SHA；规范 wrapper 应使用已审文件并核对哈希。`fan()` 第46行的 `int n; in>>n` 未先检查文件可读及首字段成功，空/不存在输入有未初始化读取风险。其余解析也不应当作面向任意畸形输入的验证器。
- **CLI 整数字符串须规范。** `std::stoll` 未检查是否消耗全部文本，可能接受带尾部非数字的数值前缀。当前运行命令由准确 Python 整数转字符串构造，不受影响；后续调用者应同样强制此条件。
- **只接受成功完整输出。** 调用者必须检查 exit0、正确 status、完整 JSON、全部项数及预期输入映射。任何 exit2/3 或部分输出均不能作为证书。
- **ABI 只对已锁定环境通过。** 使用 C010 匹配的 FLINT3.6.0 最小头与当前 FLINT/GMP/MPFR runtime；编译时检查相关结构大小，运行时检查 FLINT版本，本次重核实际库/binary/archive哈希。它不是 wheel 全部 build config 的形式证明，也不认证任意升级、其他架构或其他动态库组合。
- **范围有限。** 零 Fourier 节点、超范围整数、精度不足以分离不同节点均属 unsupported/error。工具给单点外包，没有连续 box 梯度证书、统一吞吐保证或新 C6 界。

上述解析器限制已通知主和 C；遵守冻结指令，本审计没有修改 C013。对本轮冻结有效输入的数学证书结论为 PASS；后续 release 应明确采用受验证的调用 wrapper，而非把此 CLI 当作自行校验所有输入的边界。
