# 第七轮 E：词典序端点 jets 与有限盒并集的一阶系数

审计结论：在下面明确的有限性、正则性与准确比较条件下，`(F0,F1)` 的词典序切片算法给出真实并集体积的唯一常数项与右一阶系数。**真实端点的一阶 tie 无需高阶消解即可计算体积导数；但它不能被写成真实端点对所有正步长相等，也不能提供可用的有限步长。**

独立 Python/Fraction 例检共 8 个有理 1D/2D/3D 解析实例，全部通过；没有扫描 D 的候选方向，没有重算任何旧体积，没有调用 MATLAB。仅为一阶接口审计，不产生新 C6 界。

## 1. 精确成立条件

固定有限个盒、固定维度 d。对足够小的 t≥0，每个盒解释为各闭区间的笛卡尔积；若某个坐标上端小于下端，则该盒为空。全部端点位于同一个有界范围，并具有右展开

\[
e(t)=e_0+t e_1+o(t),\qquad t\downarrow0.
\]

盒数有限使所有余项可统一写为 max_e |e(t)−e₀−te₁|=o(t)。不需要先证明二阶可微。若使用 min/max 裁剪，有限个此类端点的右展开仍存在，jet 可按右侧词典序 min/max 计算。

系数 e₀,e₁ 的比较必须准确：有理数、可认证代数数的符号，或证明了分离/等式的区间算术均可。浮点容差不能将不同系数变成相等；包围区间重叠也不是等式证明。本算法只处理 **t>0 的右导数**；左侧需先代换参数。

若端点只有 sqrt(t) 一类非有限一阶展开，或盒数/坐标范围随 t 发散，上述结论不能直接套用。本件不把有限注册盒族扩张为无限块族或完整最大函数的上界。

## 2. 有限并集对端点的局部 Lipschitz 估计

先比较 N 个盒 B_k 与其端点改变量不超过 η 的盒 B̂_k。假设原端点在 [−M,M]，扰动后在 [−M−η,M+η]。若某点在对应盒中的归属不同，至少有一个坐标的一条端点不等式改变，因此该坐标落在旧端点的 η 邻域中。每坐标最多两个宽 2η 的带。

即使某个区间倒置/为空，此归属论证仍成立。因此

\[
|B_k\triangle\widehat B_k|
\le4d\eta(2M+2\eta)^{d-1}.
\]

又因

\[
\left(\bigcup_kB_k\right)\triangle
\left(\bigcup_k\widehat B_k\right)
\subseteq\bigcup_k(B_k\triangle\widehat B_k),
\]

得到体积差上界

\[
\left||\bigcup_k B_k|-|\bigcup_k\widehat B_k|\right|
\le4Nd\eta(2M+2\eta)^{d-1}.
\]

取仿射端点 ê(t)=e₀+te₁，η(t)=o(t)，则真实并集与仿射并集体积相差 o(t)。所以一阶系数由端点 jets 唯一决定，所有真实高阶分支的选择均给同一个一阶体积。

若另外有显式端点误差界 η(t)≤C t²，并有统一有界范围和适用 t 区间，上式可变成定量 O(t²) 体积误差界；本件的单纯 o(t) 假设本身不给这个定量界。

## 3. 仿射盒与双数递归切片

对仿射端点，两个不同 jets `(a₀,a₁)`、`(b₀,b₁)` 按词典序的顺序，就是充分小 t>0 时真实仿射端点的顺序：常数差非零时由常数决定；常数相等时由斜率差决定。相同 jets 对应相同的**仿射近似函数**。有限性给一个共同小邻域。

按每个坐标完整端点集切片，条带内活跃盒投影不变，逐维递归是准确的有限不交体积分解。仿射族在该最终端点顺序区间内的体积是次数至多 d 的多项式。以

\[
(a_0,a_1)+(b_0,b_1)=(a_0+b_0,a_1+b_1),
\]
\[
(a_0,a_1)(b_0,b_1)=(a_0b_0,a_0b_1+a_1b_0)
\]

执行切片公式，就准确计算其常数与一次项。结合第 2 节，结果也是真实端点族的常数与右导数。

这里的词典序仅用于端点仿射 germs 的排序；乘法是在模 t² 的截断代数中计算系数。不能把这个截断代数称为严格有序域：`(0,1)>0`，但其平方截断为零；这不表示真实 t² 不正。

同 jet 的真实端点可以在**计算一阶系数**时合并；应将真正的高阶顺序标为 unresolved，而不是将其真实 germ key 合并成一个已证明相等的函数。有限并集局部 Lipschitz 正是这种计算替代的理由。

## 4. 三类必须正确处理的退化

### 4.1 单轴新生薄层

一个基线宽度为零、宽度 jet 为 `(0,c)` 且 c>0 的区间在右侧具有一阶宽度。若其他维有非零基线宽度，则盒体积可能是一阶。不能先删除全部基线零体积盒，再微分剩余盒；这会丢失新生贡献。若薄层被旧并集覆盖，其净贡献又可能减少，因此不能简单把所有新生盒体积导数相加，必须对全部注册 raw 盒做并集切片。

若宽度 jet 为 `(0,0)`，真实宽度最多为 o(t)，在其他维有界时其体积是 o(t)，可以从一阶计算中删除。若宽度 jet 为 `(0,c)`、c<0，该坐标在小正 t 时为空。若基线宽度严格负，连续性已保证其邻近仍为空。

### 4.2 相接旧盒分离与基线包含变化

基线相同的切点可以在一阶移动成两个不同切点；词典序必须比较斜率并保留它们之间宽度为 O(t) 的新条带。冻结 t=0 的端点去重或只微分 t=0 的并集分解会漏掉 gap。

同样，t=0 被包含的盒可以向外露出一阶薄层。只依据基线坐标去重/包含裁剪不安全。按全部 jets 的包含关系裁剪仿射盒，则在一阶意义下安全；真正端点的高阶包含关系仍可能未决。

### 4.3 两个及更多同时退化维

若同一盒在两个坐标的基线宽度均为零，由有限一阶展开，这两个真实非负宽度都为 O(t)，所以该盒体积为 O(t²)，其加入对并集体积的改变也至多 O(t²)。这不要求二阶可微。三条此类薄宽度则为 O(t³)。

这个结论需要固定有限盒族、其他维有界；不能对数量增长到 1/t 的盒机械累加 O(t²) 后仍说总量 O(t²)。
