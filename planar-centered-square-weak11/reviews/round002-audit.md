## 2. 当前两面积核为什么证明合法下界

对任一最终保留的真实有限原子集合 \(S\)，精确质量为 \(M_S\)。
令
\[
 k=\operatorname{isqrt}(\lfloor D^2M_S/4\rfloor),\qquad
 \rho=(k-1)/D>0.
\]
非负数有 \(\operatorname{isqrt}(\lfloor z\rfloor)=\lfloor\sqrt z\rfloor\)，
故 \(\rho<\sqrt{M_S/4}\)。由包含 \(S\) 的 bbox 构造
\[
 [x_b-\rho,x_a+\rho]\times[y_b-\rho,y_a+\rho]
\]
时，任一接收中心同时以这个同一个半径覆盖 \(S\)，平均值严格大于一。
整数核使用盒界，独立核使用实际 tight bbox；前者即使不 tight 也只是更小的合法内矩形。
退化盒、同一原子参与多个见证及多个支持对应相同接收矩形都不破坏这个逐矩形包含。

窗口不足、reach 限制或浮点预筛误删候选，只会减少所选的合法矩形。
最终每个保留 \(S\) 都用精确质量和整数根重算，浮点筛选没有权限增加其质量、
移动最终边界或凭浮点宣称平均值严格。
因此本下界不需要先证明枚举完备。

第一个核把最终矩形端点放在统一整数网格上，以扫描线及覆盖计数线段树求并面积：
相邻事件之间的覆盖纵长度乘横宽后相加，全部用 Python 大整数。
第二个核独立枚举支持，随后用整数压缩网格的二维差分求覆盖基本小矩形。
实际 4248 个去重矩形远低于 int32 计数溢出范围，坐标宽度和面积以 Python 大整数累加。
NumPy 不用于最终几何坐标的浮点面积运算。两个程序都计算并集，不累加重叠收益。

## 3. 周期→有限的真实几何传递

记规范胞元 \(C=[0,P_x)\times[0,P_y)\)。

令其胞元并面积为 \(A\)，于是 \(A/m_2=R_2\)。

限制周期测度到
\[
 B_N=[0,NP_x)\times[0,NP_y)
\]

这是半开胞元和源规范化的直接计数；胞元角不会漏计或双计质量。

\[
 (\lfloor{\rm reach}/P_x\rfloor+2)

个规范周期胞，故 \(M_S\le30m_2\)。

## 4. 原 \(L^1\) 问题、严格性和全部尺度

对有限 \(\mu_N\) 的每个原子用半宽
\[
 \varepsilon=1/(2D)=2^{-41}
\]
的均匀小正方形替代。所得有限非负函数 \(f_N\in L^1\)，
其积分仍为 \(N^2m_2\)，即使小源块发生重叠也是按函数相加精确计质量。

每个保留中心 \(x\) 的 \(Q(x,\rho+\varepsilon)\) 覆盖全部对应小源块。
而
\[
 \rho+\varepsilon=(k-\tfrac12)/D
 <k/D\le\sqrt{M_S/4},
\]
包括理想根恰在网格点上的情形。因此平均值仍严格大于一。
这些半径就是原算子所有正尺度中的合法选择，没有改成固定最大尺度的算子。
只靠这一组见证已经得到
\[
 \frac{|\{M_\square f_N>1\}|}{\|f_N\|_1}
 \ge(1-8/N)^2R_2.
\]

\(N=10^{12}\) 时右边精确超过 \(1.7027531463\)，数值为
\(1.7027531463446508271104452884\ldots\)。
这是明确有限 \(51N^2\) 项函数和的定义，不冒称已经在机器上生成该巨大列表。
让 \(N\to\infty\) 给 \(C_2\ge R_2\)。
这里仅保证证书下界趋 \(R_2\)，不证明真实比值恰收敛于 \(R_2\)，更不证明它趋于 \(C_2\)。

主稿一般定理的显式 \(N\) 条件也正确：
若 \(R=\lambda A/m>K>0\)，取
\(N>\max\{2q,4qR/(R-K)\}\)，则
\((1-2q/N)^2R\ge(1-4q/N)R>K\)。
有限个证书的严格半径余量有正最小值，故一般定理的平滑 \(\varepsilon\) 可统一选择。
本实例因整数根多缩 \(1/D\)，更有上述具体固定 \(\varepsilon\)。
