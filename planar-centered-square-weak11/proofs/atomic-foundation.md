# 二维中心正方形 weak-(1,1) 的原子基础

2026-11-05。对象固定为 Lebesgue 接收面积、全部正半径、中心轴平行正方形。输入可以是非负 L1 密度或有限正 Borel 测度。本稿不使用其他背景测度的锐常数，不使用高阈值 Tauberian 结论。

## 0. 准确结论与标准事实

记
\[
 Q(x,r)=x+[-r,r]^2,\qquad
 M\mu(x)=\sup_{r>0}\frac{\mu(Q(x,r))}{4r^2},\qquad
 H_\lambda^>(\mu)=\{M\mu>\lambda\}.
\]
密度 f 对应 \(d\mu=|f|dx\)，并记 \(H_\lambda^\ge=\{M\mu\ge\lambda\}\)。本文证明：

1. 函数与测度都可同时归一化总质量1和阈值1；strict 与 non-strict 的**全局**弱型常数相同。
2. 全部 L1、全部有限正 Borel 测度、有限正原子的全局常数相同，且等于 \(\sup_{N\ge1}C_{2,N}\)。离散化与平滑使用原全部尺度，不截掉小半径。
3. 有限原子的严格 halo 是有限开矩形的精确并。可用坐标盒 O(N4) 枚举，也可用全部非空子集的质量公式，后者适合参数连续性。
4. 对“至多 N 个正原子”问题，存在只依 N 的紧参数域；零质量与坐标碰撞均允许。严格接收面积在此域连续且为有理系数半代数函数。因此 \(C_{2,N}\) 可达、为实代数数，且可选择实代数质量与坐标的最优配置。

这些结论不推出某个有限 N 达到全局 \(C_2\)，也不推出 L1 极值函数存在。

使用的标准测度事实是 Lebesgue 内正则性、Tonelli 与 Fatou。最后的代数性只调用以下经典代数定理：实闭域的有序域语言允许保持系数的量词消去；因此半代数集的坐标投影仍半代数，且参数取于实代数数时非空公式可在实代数实闭域中实现。其精确版本见 [Basu, Theorem 2.1](https://www.math.purdue.edu/~sbasu/raag_survey2011_final.pdf)；该文也明确允许实数域和实代数数域。下面的具体 halo、连续性、紧性和代数最优推论全部证明。

## 1. 严格 halo 可测和一个仅供基础使用的有限界

**引理1（strict halo 开）。** 对任意局部有限正 Borel 测度和 \(\lambda>0\)，\(H_\lambda^>\) 是开集。

若 x 有严格见证 r，则选 \(\epsilon>0\) 使
\[
 \mu(Q(x,r))>4\lambda(r+\epsilon)^2.
\]
对 \(\|z-x\|_\infty<\epsilon\)，有 \(Q(x,r)\subset Q(z,r+\epsilon)\)，故 z 也在严格 halo。此处允许原测度在见证边界上有原子；没有把闭盒质量的平移当成连续函数。非严格集也 Borel，因为
\[
 H_\lambda^\ge=\bigcap_{k>1/\lambda}H_{\lambda-1/k}^>.
 \tag{1}
\]

**引理2（非锐有限界）。** 对任意有限正测度，
\[
 |H_\lambda^>(\mu)|\le9\mu(\mathbb R^2)/\lambda.
 \tag{2}
\]
此处9只是使全部常数与 Fatou 论证有限的工具界，不作为本课题的新上界。

取严格 halo 内任意紧集 K。每点选一个严格见证闭正方形，其内部覆盖 K；抽出有限覆盖。按半径降序选择：保留当前闭盒后，删去所有与它相交的剩余闭盒，**边界相交也删去**。所保留闭盒真正两两不交。每个被删盒半径不大于与它相交的保留盒，因而包含在后者3倍同心盒中。于是
\[
 |K|\le9\sum_j4r_j^2
 <(9/\lambda)\sum_j\mu(Q_j)\le9\mu(\mathbb R^2)/\lambda.
\]
内正则性给(2)。若只选 interiors 不交，原子可能位于多个边界而破坏最后求和；这里特意避免该问题。由(1)和阈值逼近，非严格集也有同一个9界。

## 2. 同时归一化与 strict/non-strict 的范围

**引理3（密度归一化）。** 对 \(f\ge0\)、\(m=\|f\|_1\in(0,\infty)\)、\(\lambda>0\)，令
\[
 s=\sqrt{m/\lambda},\qquad g(x)=\lambda^{-1}f(sx).
\]
变量代换给 \(\|g\|_1=\lambda^{-1}s^{-2}m=1\)，且对每个半径 r，
\[
 \frac1{4r^2}\int_{Q(x,r)}g
 =\lambda^{-1}\frac1{4(sr)^2}\int_{Q(sx,sr)}f.
\]
全部正半径在 \(r\mapsto sr\) 下双射，故
\[
 Mg(x)=\lambda^{-1}Mf(sx),\qquad
 |H_1^>(g)|=\frac\lambda m|H_\lambda^>(f)|.
 \tag{3}
\]
非严格水平同理。题目给出的函数归一化公式因此正确。

对有限测度用
\[
 \nu(A)=m^{-1}\mu(sA),\qquad m=\mu(\mathbb R^2),\quad s=\sqrt{m/\lambda},
\]
则 \(\nu(\mathbb R^2)=1\)、\(M\nu(x)=\lambda^{-1}M\mu(sx)\)，接收面积仍满足(3)。这同时处理任意质量和阈值。

**引理4（全局阈值约定相同）。** 对固定输入类（L1、全部有限正测度、至多 N 原子或全部有限原子），定义 strict 与 non-strict 全局常数为对所有非零输入和 \(\lambda>0\) 的相应弱型比值上确界。两常数相等。

strict≤non-strict。反之，对 \(0<\theta<1\)，
\[
 \{M\mu\ge\lambda\}\subset\{M\mu>\theta\lambda\},\qquad
 \lambda|H_\lambda^\ge|\le C^>\mu(\mathbb R^2)/\theta.
\]
先固定输入与阈值，再令 \(\theta\uparrow1\)，得反向界。最后取上确界。引理2确保这些常数有限。

**固定输入／固定阈值一般不能换。** 取 \(f=\mathbf1_{[0,1]^2}\)、\(\lambda=1\)。有 \(Mf\le1\)，所以 strict 集为空。正方形内部每点的小盒平均为1；正方形外若 \(d=\operatorname{dist}_\infty(x,[0,1]^2)>0\)，在一个分离坐标上所有可相交盒的覆盖长度≤\(r-d\)，其平均≤\((r-d)/(2r)<1/2\)，故外部不在非严格集。边界零测。因此非严格集面积为1。全局常数相同绝不意味着每个固定水平集面积相同。

有限原子在固定阈值下恰有面积相同的更强性质，见§5；不能把它扩展到 L1。

## 3. 全尺度的原子离散化与平滑

分别以 \(C_{L^1}\)、\(C_{\rm meas}\)、\(C_{\rm at}\) 表示 L1、非零有限正 Borel 测度、非零有限正原子的 strict 全局常数。它们均由(2)有限，并由(3)等于总质量1／阈值1的面积上确界。

**定理5。**
\[
 C_2=C_{L^1}=C_{\rm meas}=C_{\rm at}=\sup_{N\ge1}C_{2,N}.
 \tag{4}
\]

L1 密度给有限正测度，所以 \(C_{L^1}\le C_{\rm meas}\)。剩下证明两条反向传递。

### 3.1 有限测度到有限原子

令 \(\mu_R=\mu|_{[-R,R]^2}\)。对整数 R 增大，strict halo 单调增加，且
\[
 H_1^>(\mu)=\bigcup_{R\ge1}H_1^>(\mu_R).
 \tag{5}
\]
任一原严格见证盒是有界的，最终完全位于截断窗内，所以(5)包括任意原正尺度。

对固定 R，以有限个网格半开小格划分支持，取可测量化映射 \(T_h\)，使每点位移≤h，并使 \(\nu_h=(T_h)_\#\mu_R\) 为有限原子测度。它保持质量；空格忽略。对任意原盒，
\[
 \nu_h(Q(x,r+h))\ge\mu_R(Q(x,r)).
 \tag{6}
\]
若 x 属于 \(H_1^>(\mu_R)\)，固定其一个严格见证 r。其严格余量使所有充分小 h 满足
\(\mu_R(Q(x,r))>4(r+h)^2\)。因此
\[
 \mathbf1_{H_1^>(\mu_R)}\le\liminf_{h\downarrow0}\mathbf1_{H_1^>(\nu_h)}.
\]
取任意序列 h↓0并用 Fatou、(3)，
\[
 |H_1^>(\mu_R)|\le\liminf_h|H_1^>(\nu_h)|
 \le C_{\rm at}\mu_R(\mathbb R^2).
\]
零测截断输入给空 halo。再令 R↑∞，由(5)得 \(C_{\rm meas}\le C_{\rm at}\)。没有为全部接收点选择一个统一的最小半径，也没有把未知见证半径置换为网格尺度。

### 3.2 有限原子到 L1 平滑

取非负 \(\varphi\in C_c^\infty\)、积分1、支持于 \([-1,1]^2\)，令
\(\varphi_\epsilon(x)=\epsilon^{-2}\varphi(x/\epsilon)\)、\(f_\epsilon=\mu*\varphi_\epsilon\)。对有限原子输入，\(f_\epsilon\in C_c^\infty\)，总质量等于 \(\mu(\mathbb R^2)\)。边界原子也完整移入扩大盒，因此
\[
 \int_{Q(x,r+\epsilon)}f_\epsilon\,dx\ge\mu(Q(x,r)).
 \tag{7}
\]
固定任意 strict 见证，最终扩大半径仍 strict。Fatou 与 L1 常数给
\[
 |H_1^>(\mu)|\le\liminf_{\epsilon\downarrow0}|H_1^>(f_\epsilon)|
 \le C_{L^1}\mu(\mathbb R^2).
\]
所以 \(C_{\rm at}\le C_{L^1}\)，证明(4)。同一卷积论证其实适用于任意有限正测度，只是其平滑未必紧支撑。

最后，有限原子输入总是属于某个至多 N 类；反之每个此类都是有限原子。故其上确界就是 \(\sup_NC_{2,N}\)。这一极限没有给出统一于 N 的收敛速度。non-strict 的全局版本再由引理4得到；不声称上述同阈值 Fatou 传递能逐输入处理等号平台。

## 4. 有限原子的精确矩形 halo

设
\[
 \mu=\sum_{i=1}^Nm_i\delta_{p_i},\qquad m_i\ge0,
 \quad p_i=(x_i,y_i),\quad\sum_i m_i>0.
\]
允许零质量和坐标碰撞。对非空子集 I，写
\[
 m_I=\sum_{i\in I}m_i,\quad s_I=\sqrt{m_I}/2,\quad
 a_I=\min_{i\in I}x_i,\ b_I=\max_{i\in I}x_i,\quad
 c_I=\min_{i\in I}y_i,\ d_I=\max_{i\in I}y_i,
\]
并令
\[
 R_I=(b_I-s_I,a_I+s_I)\times(d_I-s_I,c_I+s_I).
 \tag{8}
\]
任一方向下端≥上端时按空集处理。

**定理6（子集式）。**
\[
 H_1^>(\mu)=\bigcup_{\varnothing\ne I\subset[N]}R_I.
 \tag{9}
\]

若 x 有见证 r，取该闭正方形中所有正质量原子的指标为 I。非空且
\(m_I>4r^2\)，故 \(r<s_I\)。由于正方形含全部 I，x 严格位于(8)各端之间。

反之，若 \(x\in R_I\)，则到 I 的最小包容半径
\[
 d_I(x)=\max_{i\in I}\|x-p_i\|_\infty
\]
满足 \(d_I(x)<s_I\)。取正半径 \(d_I(x)\le r<s_I\)；当 d=0也能取 r>0。此盒含 I，因此
\(\mu(Q(x,r))\ge m_I>4r^2\)。即使 I 的外接盒里还含其他原子，此反向证明仍成立，绝不要求 I 是“恰好盒内原子集合”。零质量子集有 \(s_I=0\)，其 receiver 为空。

**坐标盒式。** 令 B 枚举四边坐标取自 \(\{x_i\}\)、\(\{y_i\}\) 的闭轴盒，含退化盒，\(s_B=\sqrt{\mu(B)}/2\)。则
\[
 H_1^>(\mu)=\bigcup_B(b-s_B,a+s_B)\times(d-s_B,c+s_B),
 \quad B=[a,b]\times[c,d].
 \tag{10}
\]
反向与上面相同。正向取某严格见证内全部正原子的最小外接盒 B；它在原正方形内，且 \(\mu(B)\) 等于该盒内所有原子质量，故仍 strict。候选盒至多 N4 个。盒内质量随坐标改变可以跳变，所以(10)适于精确面积核验，却不直接用作连续性的证明。

公式自动覆盖全部半径：单位质量／单位阈值下每个 strict 见证 r<1/2；它不是人为剔除其他原半径，而是由 \(4r^2<\mu(Q)\le1\) 导出。

## 5. 有限原子固定阈值的 non-strict 集

把(8)换成闭矩形 \(\overline R_I\)，仅保留 \(m_I>0\) 且两方向下端≤上端的子集。则
\[
 H_1^\ge(\mu)=\bigcup_{I:m_I>0}\overline R_I.
 \tag{11}
\]
反向：若 x 属于某闭 receiver，\(d_I(x)\le s_I\)。d>0时取 r=d；d=0时取任意 \(0<r\le s_I\)，均给平均≥1。

正向的 sup 需要说明。若 x 是正原子位置，则 M∞，已属于单原子闭 receiver。否则各正质量原子到 x 的距离是有限多个正数。\(r\) 小于最小距离时平均0；每两个相邻距离之间，分子固定、平均随 r 下降；r 超过最大距离后也下降。因此 M 在某个正原子距离上取到最大。其取等盒给 I，产生闭 receiver。

故 strict 与 non-strict 的差包含于有限条矩形边界和退化线段，Lebesgue 面积相同。忽略零质量子集是集合等式所需；若硬把其闭退化盒加入，会在原本无质量的虚拟点处制造错误接收点，虽然不改变面积。

## 6. 固定 N 的紧代表：含零质量与碰撞

现在总质量为1，阈值1。以 \(\|p_i-p_j\|_\infty\le1\) 连边，只计正质量原子。

**引理7（组件分解）。** 任一 strict 单位阈值见证 r<1/2，因而不能同时含两个不同连通分量中的原子。若 x 同时在两个分量的严格 halo，分别选见证和其中一个原子 p、q，则
\(\|p-q\|_\infty\le r_1+r_2<1\)，矛盾。因此
\[
 H_1^>(\mu)=\mathop{\dot\bigcup}_{\gamma}H_1^>(\mu_\gamma),
 \qquad |H_1^>(\mu)|=\sum_\gamma|H_1^>(\mu_\gamma)|.
 \tag{12}
\]
“分量不共享见证”仅指这个质量／阈值下的有效 strict 见证；大半径正方形当然可以同时覆盖远分量，但其平均不超过阈值。

每个含 k 个顶点的分量任意两点间有不超过 k−1条边的路径，所以其 l∞直径≤k−1≤N−1，两个坐标跨度也≤N−1。

对各分量分别平移，使其坐标最小值落在
\(((N+1)j,0)\)，j=0,…,c−1、c≤N。相邻安放框的 x 间隙至少2，所以新分量仍相互距离>1。各分量内部平移不改其 halo 面积；由(12)，总面积也不变。全部正原子于是落在
\[
 [0,D_N]^2,\qquad D_N=N(N+1).
 \tag{13}
\]
缺少的项用零质量补至 N，位置任取此盒内。碰撞的正质量可先合并；合并只是在同一点相加质量，不是移动不同位置的原子。

所以原无限参数的“至多 N”上确界，等于以下紧域上的上确界：
\[
 \mathcal K_N=\{(m_i,p_i)_{i=1}^N:m_i\ge0,\ \sum_im_i=1,
                                  \ p_i\in[0,D_N]^2\}.
 \tag{14}
\]
每个原配置有域内等面积代表；域内每个配置合并碰撞、删除零质量后又是原允许类。两方向都成立。

## 7. 面积连续：子集公式避免成员跳变

在 \(\mathcal K_N\) 上，(8)每个端点都是质量与坐标的连续函数：min、max连续，\(m_I\mapsto\sqrt{m_I}\) 在零点也连续。接收区统一位于一个只依 N 的有界盒内。

一维端点 l,u 允许倒置；用 \((l,\max(l,u))\) 表示空区间或通常区间，它与原定义完全一致。对有序端点区间，
\[
 |(l,u)\triangle(l',u')|\le|l-l'|+|u-u'|.
\]
若所有端点在 [−R,R] 内，则乘积矩形的对称差面积≤2R乘四个端点差绝对值之和。并集有
\[
 \left|\bigcup_I R_I(\theta)\triangle\bigcup_I R_I(\theta')\right|
 \le\sum_I|R_I(\theta)\triangle R_I(\theta')|.
 \tag{15}
\]
子集数固定有限，故 halo 面积函数
\(A_N(\theta)=|H_1^>(\sum_i m_i\delta_{p_i})|\) 连续。证明包含零质量消失、多个坐标相等、原子相撞、receiver 区间缩成线或空集，不需要任何一般位置假设。

概率质量下还可给全域显式模量。令
\[
 \delta_p=\max_i\|p_i-p_i'\|_\infty,\qquad
 \delta_m=\sum_i|m_i-m_i'|,\qquad
 \epsilon=\delta_p+\tfrac12\sqrt{\delta_m}.
\]
子集半径的差至多 \(\tfrac12\sqrt{\delta_m}\)，故各端点（包括空区间正规化的 max 端点）改变量≤\(\epsilon\)。每个有效 receiver 的边长≤1。产品对称差遂≤\(4\epsilon\)，从而
\[
 |A_N(\theta)-A_N(\theta')|
 \le4(2^N-1)\left(\delta_p+\tfrac12\sqrt{\delta_m}\right).
 \tag{15a}
\]
这也直接控制所有零质量、碰撞及排序改变，不依端点排列分区。

例如固定 N、步长 \(h=1/L\)，坐标向下取网格，前 N−1 个质量向下取网格、最后质量补足总和1。这样 \(\delta_p\le h\)、\(\delta_m\le2(N-1)h\)。有限网格目标最大值 \(G_{N,h}\) 因此给出
\[
 G_{N,h}\le C_{2,N}\le G_{N,h}
 +4(2^N-1)\left[h+\tfrac12\sqrt{2(N-1)h}\right].
 \tag{15b}
\]
网格只在固定紧域内取，质量仍非负；N=1按零个质量取整理解。网格面积可用(16)作精确代数计算。此为固定 N 的可认证逼近，不是统一于 N 的截断误差。

紧域 \(\mathcal K_N\) 上连续函数取最大值，因而 \(C_{2,N}=\max_{\theta\in\mathcal K_N}A_N(\theta)\) 可达。极大点只保证至多 N 个不同正原子；不保证恰好 N 个互异的正质量原子。

## 8. 半代数性与实代数最优

不能用“一般半代数集合的体积也半代数”作理由；一般参数积分可能含对数。这里依赖矩形的特殊有限公式。

记所有非空子集为有限族 \(\mathscr I\)，receiver 端点为 \(l_I,u_I,b_I,t_I\)。有限包含排除给
\[
 A_N=\sum_{\varnothing\ne J\subset\mathscr I}(-1)^{|J|+1}
 \left[\min_{I\in J}u_I-\max_{I\in J}l_I\right]_+
 \left[\min_{I\in J}t_I-\max_{I\in J}b_I\right]_+.
 \tag{16}
\]
任一 receiver 为空或退化时，其相关交集面积自动为0。这个公式虽很大，但对固定 N 是有限表达式。

添加辅助非负变量 \(s_I\) 和方程 \(4s_I^2=\sum_{i\in I}m_i\)。所有 min、max、正部的图都可用有限多项式等式／不等式表达。例如 \(z=\max(x,y)\) 等价于 \((z=x\land x\ge y)\lor(z=y\land y\ge x)\)。故(8)、(14)、(16)给 \(A_N\) 的**有理系数半代数图**，包括所有端点排列及等号情形。

由量词消去，值域 \(A_N(\mathcal K_N)\subset\mathbb R\) 是有理系数半代数集，且由紧性为紧集。其最大值 \(\beta=C_{2,N}\) 必是实代数数：若 β 为超越数，取描述值域的有限个非零有理多项式，每一个在 β 都不为0，其符号在同一个小邻域不变。描述公式遂在 β 附近恒真，与 β 是值域右端点矛盾。

还能选代数配置。argmax 由 \(\theta\in\mathcal K_N,A_N(\theta)=\beta\) 定义，系数在实代数数域中且在实数域非空。对这一存在公式作保持系数的量词消去，所得无量词陈述在两个有序域中具有相同真值。因此在实代数数域中也有一组质量、坐标、辅助根，给出同一个 β。

这是一项存在性和可判定性定理，不是低复杂度算法，也不提供统一于 N 的上界。由零质量补项，\(C_{2,N}\) 单调不减；其上确界 \(C_2\) 未因此被证明为代数数或由某个有限 N 达到。

## 9. 周期原子下界到真实有限输入的接口

此节不采用任何具体周期候选，只给后续复现用的截断规则。设周期为 L、基胞 \([0,L)^2\) 含有限原子，总质量 m>0；按半开基胞唯一复制，记无限周期测度 \(\mu_{\rm per}\)。令 h_R 是基胞内由某个 \(0<r<R\) 严格见证的点集面积，\(h=|H_\lambda^>(\mu_{\rm per})\cap[0,L)^2|\)。这些集合可测，且 \(h_R\uparrow h\)。

取 N×N 个基胞的实际原子组成有限 \(\mu_N\)，总质量 \(N^2m\)。设 \(b_R=\lceil R/L\rceil+1\)。至少 \((N-2b_R)_+^2\) 个完整基胞离截断窗边界足够远；其中每个 r<R 的原始见证完全留在截断窗内，所以
\[
 \frac{\lambda|H_\lambda^>(\mu_N)|}{N^2m}
 \ge\frac{\lambda h_R}{m}(1-2b_R/N)_+^2.
 \tag{17}
\]
先固定 R，再取 N→∞，最后 R→∞，得 \(C_2\ge\lambda h/m\)。全部大半径只在最后 R 极限恢复，没有先宣称某个统一有限 witness 上限。边界原子用半开基胞归属，内层见证严格留在截断窗内，不重计也不漏掉边界质量。

## 10. 双原子与合并的严格校验

取质量4、位置 \((0,0),(19/10,0)\) 两原子，阈值1。两个单原子 receiver 是边长2的开正方形，交面积为1/5，并面积为39/5。双原子取有理内半径 \(7/5\)，有 \(4(7/5)^2=196/25<8\)。其中心 receiver 为
\[
 (1/2,7/5)\times(-7/5,7/5).
\]
它在两个单原子并集之外另有面积18/25，因此联合 strict 接收面积至少
\[
 39/5+18/25=213/25,\qquad
 \frac{|H_1^>|}{8}\ge213/200>1.
 \tag{18}
\]
这只是一个有理内证书，不声称是双原子最优。若把两原子移动合并为任意位置的一个质量8原子，其 halo 面积恰为8，比值恒1。故不带额外几何条件的“合并不降低比值”规则已被否定。

## 11. 达到性的三种量词与交付范围

| 事项 | 结论与范围 |
|---|---|
| 已证 | 任意固定 N 的至多 N 原子问题在质量1／阈值1达到最大；可选代数配置。 |
| 已证 | 全局 L1／有限测度／有限原子上确界相同；strict 与≥的全局常数相同。 |
| 未解决 | 是否存在有限 N 满足 \(C_{2,N}=C_2\)，以及是否有任意有限 Borel 测度达到全局值。 |
| 未解决 | 是否存在非零 L1 输入达到原问题的全局常数，及其分类。 |
| 已否定 | 固定 L1 输入与阈值的strict/≥面积总相同；无条件移动合并不降比值。 |

即使各固定 N 都可达，N→∞仍可能发生微尺度或组件数失紧。原子平滑只给近极值 L1 序列，不传递极值函数存在性。本文未采用任何待核内部58原子数据，也未宣称改进目前公开的数值区间。
