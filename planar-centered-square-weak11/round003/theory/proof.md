# R003：有限周期证书的完整单侧质量第一变分

2026-11-05。本稿只写独占 scratch/round003-insertion-theory。
固定坐标、固定周期、固定有限见证族；讨论新增质量参数 \(t\downarrow0\)。
不修改 R1、R2、公开 clone 或 Terra 数据。
本稿给可审定理、必要反例及有限计算接口，不宣称一般递推或局部最优。

## 1. 模型、量词与零质量完成

固定阈值 \(\lambda>0\)、矩形周期格和有限原型支持清单。
输入为
\[
 \mu_t=\mu_0+t\nu,\qquad \nu\ge0,\quad
 m(t)=m_0+t\sigma,\quad m_0>0,
\tag{1}
\]
其中 \(\sigma=\nu(C)\)；所有支持坐标及周期均不随 t 移动。
同坐标原子先合并；每个见证内不重复列同一个物理原子。
周期副本可以进入同一见证，质量按实际副本计。
原型清单有限；在一个胞元内接收所需的平移数对充分小 t 统一有限。

记录 j 关联固定支持集 \(S_j\)、固定包含它的 bbox
\(B_j=[x_j^-,x_j^+]\times[y_j^-,y_j^+]\)，及精确质量
\[
 M_j=\mu_0(S_j)\ge0,\quad w_j=\nu(S_j)\ge0,\quad
 r_j(t)=\sqrt{(M_j+tw_j)/(4\lambda)}.
\]
允许 bbox 不 tight，也允许 \(M_j=0\) 的新点记录。
若支持清单只有 bbox 和“盒内全部原子”规则，也按这个固定坐标族理解。
理想接收矩形为
\[
 R_j(t)=[x_j^+-r_j(t),x_j^-+r_j(t)]
         \times[y_j^+-r_j(t),y_j^-+r_j(t)].
\tag{2}
\]
反向区间为空；线和点只有零测面积。
令 \(U(t)\) 为全部原型及周期平移的接收并集，\(A(t)=|U(t)\cap C|\)。
这是有限证书面积，不假设它等于真实全部尺度 halo。

必须在 t=0 就加入新输入坐标能够生成的 bbox 清单，
不能仅对旧正面积矩形取导数后声称涵盖完整插入。
对完整旧 bbox 族有一个重要的基线完成性质：
\[
 U_{\rm augmented}(0)=U_{\rm old}(0)\quad\hbox{模零测}. \tag{3}
\]
证明：新 bbox 的旧支持非空时，将它收紧到同一旧支持的 tight bbox，
指定支持质量不变；若旧族按整闭盒取质量，可用质量只会不减。
两跨度不增，所以新 bbox 的零时接收矩形包含于这个旧 tight 接收矩形。
若原族限制边长不超过 reach，tight 盒仍满足该条件。
若旧支持为空，零时只有空集或零面积点。
因此只要旧族包含这些 tight 盒，就没有插入零质量时免费领取的 O(1) 面积。
若使用有限窗口，必须在同一安全窗口内验证 tight 盒与其完整旧支持也可枚举；
不能用更小旧窗口与更大新窗口的缺项当作 (3)。
旧族若不完整，应先补完或把增大的 \(A(0)\) 明记为证书族改进，不能归功于 t。

下面定理以整个完成后的 \(U(0)\) 为基线。
不允许用另一族、另一个半径量化值或未定义的真实 halo 面积替换它。

## 2. 正旧质量记录：边、线、点的完整分类

当 \(M_j>0\)，记
\[
 r_j=r_j(0)>0,\qquad
 u_j=r_j'(0)=\frac{w_j}{8\lambda r_j}\ge0.
\tag{4}
\]
半径及四端点在零时解析，端点变化为 \(\pm u_jt+O(t^2)\)。
有限族中常数可依赖各正 M_j、坐标间距、周期和清单；
不要求关于原子数、最小质量或移动候选位置一致。

按两个初始接收边长 \(2r_j-(x_j^+-x_j^-)\)、
\(2r_j-(y_j^+-y_j^-)\) 分类：

1. 两者严格正：普通正面积矩形。
2. 一者零、另一者严格正：可一阶激活的竖线或横线。
3. 两者零：生成 O(t)×O(t) 小矩形，面积 O(t²)，无一阶单点收入。
4. 至少一者严格负：对充分小 t 仍为空。

所谓“旧时为空”必须分清第 2、3、4 类。
不能把量化半径下空矩形的统计直接当作理想第 4 类定理。

### 初始网格及侧占用

在一个胞元内取全部正面积／线记录的初始横、纵端点作有限网格。
为叙述方便，可将胞元切口平移到不穿过任何初始端线及下节新点的位置；
有限多投影坐标总能避开，面积与周期不变。
实际使用原切口时需按周期识别边界，不得重复计两份同一物理面。

竖网格段写为 \(e=\{c\}\times I\)，其中 I 是连续两横网格坐标间的开区间。
令 \(\chi_{e,-},\chi_{e,+}\in\{0,1\}\) 表示其左／右紧邻开网格片是否已被
初始正面积并集覆盖。零面积线／点不改变这个二维占用。
每个开片上的占用确为常数。

令 \(J_{e,+}\) 为所有满足以下条件的正旧质量记录：

* 初始 y 接收区间内部包含 I；
* 初始 x 接收区间长度非负；
* 其右接收端点等于 c。

令 \(J_{e,-}\) 为相应左端点等于 c 的记录。
长度零的竖线可同时出现在两侧清单；点记录因没有正 y 长度不出现。
空清单最大值按 0 解释，定义
\[
 d_e=|I|\left[
 (1-\chi_{e,-})\max_{j\in J_{e,-}}u_j+
 (1-\chi_{e,+})\max_{j\in J_{e,+}}u_j
 \right].
\tag{5}
\]
横网格段按交换两轴定义。每个物理段只计一次，令
\[
 D_{\rm edge}=\sum_{\rm 全部竖、横段}d_e\ge0.
\tag{6}
\]
这个式子已包括新坐标 bbox、退化线、正好重合边及被其他矩形遮住的面。
不是对每个矩形的周长各付一次。

### 为什么是 max／min，而非重复面积

在一条未占用侧，所有从同一物理边推出的薄条从同一法向位置起步，
厚度分别为 \(u_jt+O(t^2)\)，其并集厚度是最大值。
若该侧已被其他旧矩形内部占用，则这侧的一阶新增面积是零。
相反侧相接的两个矩形已经覆盖缝的两边，不能再把它们各自“向缝内扩张”计正收入。

更一般的 C1 端点形式也可直接检查 max/min：
将法向坐标写为 \(x=c+t\xi\)。
以右端点抵达 c 的正宽矩形给半直线 \(\xi\le b_j'(0)\)，
左端点抵达 c 的给 \(\xi\ge a_j'(0)\)，
零宽记录给区间 \([a_j'(0),b_j'(0)]\)（端序反则为空）。
这些集合先取并，再减初始左右半直线占用，所得有符号长度乘 \(|I|\)。
长度只由有限 max/min 决定。例如左右旧区都在、两面分别为速度 v_L、v_R 时，
可能新开缝的损失是 \(-(v_R-v_L)_+\)，不是两条面速度之和。
对本稿的正质量插入，\(a_j'=-u_j,b_j'=u_j\)，该通式恰化为 (5)。
它不额外声明对随 t 改变支持清单的输入已作证明。

## 3. 零旧质量新点：不能遗漏的 sqrt(t) 收入

若 \(M_j=0<w_j\)，则 \(r_j(t)=\sqrt{tw_j/(4\lambda)}\)。
只要 bbox 任一跨度严格正，对充分小 t 该记录仍为空。
因此仅 bbox 为一个点 p 的记录可能有一阶面积。
把同一点的这些记录合并，令 \(w_*(p)\) 为其最大质量系数；
其并集是中心 p、半径 \(\sqrt{tw_*(p)/(4\lambda)}\) 的一个方形。
对完整实际单点支持，w_* 就是该点的实际新增质量系数；
不能因多个清单重复领取该点质量。

在 p 附近，初始正面积矩形并集恰按四个开象限呈固定占用。
记未被占用的象限数为 \(k(p)\in\{0,1,2,3,4\}\)；线和点不算二维占用。
定义
\[
 D_{\rm point}=\sum_p\frac{k(p)}4\,\frac{w_*(p)}{\lambda}.
\tag{7}
\]
若 p 在旧并集内部则贡献 0，若在闭包外则贡献 \(w_*/\lambda\)，
在一条暴露边或角上分别按真实象限数计算。
不把边界点一律当作“孔内”或“已覆盖”。
不同 p 固定且互异，所以充分小 t 时这些小方形互不交。

## 4. 完整有限理想第一变分定理

**定理 1。** 在 §1 的固定有限周期模型、非负质量插入下，
\[
 \boxed{A(t)=A(0)+t(D_{\rm edge}+D_{\rm point})+O(t^{3/2}).}
\tag{8}
\]
若没有活跃的零旧质量点记录，可将余项改为 O(t²)。
所有重合、零长、零高及新坐标 bbox 都按 §§2–3 的清单计入。

**证明：存在性与余项。** 令 \(s=\sqrt t\)。
每个正旧质量半径 \(r_j(s^2)\) 在 s=0 实解析且只含偶次幂；
零旧质量半径是常数乘 s。
在一个胞元所需的有限平移清单中，全部端点及胞元截断线都实解析。
任意两个端点的差若不恒同，其在零右侧的符号最终固定；
恒同者保留等号。因此有限端点弱排序在足够小的正 s 区间固定。
在固定排序片上，用压缩坐标单元计算并集面积，
即被覆盖单元的横、纵端点差乘积的有限和，故 \(A(s^2)\) 有收敛的右解析展开。

每个 \(M_j>0\) 记录的集合变化面积至多 O(t)：正面积边移动 O(t)，
线激活至多 O(t)，点激活 O(t²)，严格空记录最终仍空。
每个 M=0 的非点 bbox 最终为空，点 bbox 的整个面积为 O(t)。
有限并集的变化不超过各记录对称差之和，所以 \(A(t)-A(0)=O(t)\)。
这迫使 s 展开的一次项为零，得到 \(A(t)=A(0)+Dt+O(t^{3/2})\)。
没有活跃零旧质量点时，所有非空记录直接在 t 中解析，
同样排序论证给 O(t²) 余项。下面识别 D。

**证明：一阶系数的几何识别。** 先只看 \(M_j>0\) 的记录。
至少一个初始长度负的记录在小 t 不激活；初始点记录只产生 O(t²) 面积。
其他端点相对初始网格移动 O(t)，泰勒余项 O(t²)。
去掉各初始网格顶点的 O(t) 小方形，余下的新增区域是一组有限边段的法向薄条。
在一条开边段上，切向端序和旧侧占用不变；
没有其他初始边能够越过该段的固定正间距。
所有同侧 owner 的薄条先取并，厚度为最大 u_j 的 t 倍加 O(t²)，
被旧二维区域占用的一侧不贡献。故该条贡献 (5) 加 O(t²)。
被删顶点小方形总面积 O(t²)，边段切向移动 O(t) 乘 O(t) 厚度亦 O(t²)。
有限求和得
\[
 |U_{\rm analytic}(t)|=A(0)+tD_{\rm edge}+O(t^2).
\]

再加入 \(M_j=0\) 的点方形，半径 O(sqrt(t))。
在足够小的固定邻域内，旧正面积并集的占用恰是四象限的并；
所以它相对静态旧并集的新面积恰为 \(t[k(p)/4]w_*/\lambda\)。
解析矩形的移动只在初始边的 O(t) 邻域内改变占用，
这邻域与半径 O(sqrt(t)) 方形相交的面积至多 O(t^(3/2))+O(t²)。
退化线的 O(t) 窄带也只有同阶相交误差。
各新点间固定分离，点方形之间无交；有限求和给 (7) 和 (8)。证毕。

这只是固定有限族的理想半径定理。
没有把固定族的余项常数宣称统一于原子数、最小原子质量、候选位置趋向临界线，
或随 t 漂移的新坐标 p(t)。

### 比值判据

令 \(D=D_{\rm edge}+D_{\rm point}\)、\(R_0=\lambda A(0)/m_0\)，则
\[
 \frac{\lambda A(t)}{m_0+t\sigma}
 =R_0+\frac{t}{m_0}(\lambda D-R_0\sigma)+O(t^{3/2}).
\tag{9}
\]
严格正号保证该固定方向在充分小正 t 真正提高证书比值；
严格负号保证该固定方向在充分小正 t 降低比值。
等于零不作决定，需要更高阶或直接有理步长。
这不证明当前有限族的全局最优，也不自动排除随 t 漂移的位置或有限幅度改进。

## 5. 旧外露面何时足够、何时不够

只用旧正面积 bbox 的 owner 计算一个 \(D_{\rm old}\le D\)。
若 \(\lambda D_{\rm old}>R_0\sigma\)，其本身就是充分增益证书，
新增线、新坐标 bbox、点方形都只是未使用的非负额外收入。

反过来，\(\lambda D_{\rm old}\le R_0\sigma\) 不是一般排除。
要使旧外露面判据完整，至少还须逐条检查：

* 每条未覆盖侧上，全部新增／退化 owner 的最大速度不超过旧正面积 owner 的最大速度；
* 所有新点方形的 \(k(p)w_*(p)\) 为零；
* 采用 (3) 的同一基线，未漏掉零时证书族补完。

这些条件成立时 \(D=D_{\rm old}\)，非临界符号才可只由旧面决定。
同一物理面有多个 S 时用 max，不将其逐项相加；
单纯把 3407 个去重 receiver 分配一个任选支持也未必保住完整最大速度。

### 新坐标 bbox 必要的实际反例

旧输入为质量 4 的原子位于 0，加入 \(t\delta_{(3/2,0)}\)。
可在足够大周期胞元内平移本例，或直接视作有限两原子例。
旧接收方形是 [-1,1]²。旧 bbox 不含新点，旧面移动导数为零。
新点单原子方形面积 t，对旧比值 1 单独只给中性一阶。

新增 mixed bbox [0,3/2]×{0} 在 t=0 有旧接收方形的真子矩形，
但共享其右／上／下部分外露边，速度更快。
令 \(r=\sqrt{1+t/4}\)。对 \(0<t\le1/4\)，新单原子方形与
旧、mixed 接收矩形均分离，三个方形／矩形并集的面积精确为
\[
 A(t)=9+2t-5r=4+\frac{11}{8}t+O(t^2).
\tag{10}
\]
其中 mixed bbox 额外贡献 \(3t/8+O(t^2)\)。
总质量 4+t，故
\[
 A(t)/(4+t)=1+\frac3{32}t+O(t^2)>1.
\]
严格性还可直接由 \(r\le1+t/8\) 得
\(A(t)-(4+t)\ge3t/8>0\)。
因此“旧面＋新单原子区域没有改善”不能排除完整插入；
这个例子的新坐标 bbox 在零时没有 O(1) 跳跃，却有必要的一阶收入。

### 退化线与重合边的防错例

半径 \(r(t)=\sqrt{1+t/4}\)、bbox [-1,1]×{0} 的联合接收矩形在零时是竖线，
面积为 \(4r(t)(r(t)-1)=t/2+O(t^2)\)。
它由旧两端各质量 2、中心补质量 t 的见证实现。
本句仅计算这个特定支持记录的激活面积，不声称其他见证没有更多收入。
若删除旧时零面积记录，就会漏掉这个一阶项。

同一面上的两条厚度 t、2t 薄条的并集厚度是 2t，不是 3t；
若两侧本已分别被旧矩形占用，向已覆盖侧移动都无新面积。
正旧质量的孤立点退化则只有 O(t²)，不能像零旧质量点那样给 t 级收入。
这三类不能混合收费。

## 6. 从理想一阶证书到有理严格证书

若坐标、质量、\(\lambda\)、周期和补丁系数均有理，
所有 \(r_j\) 是非负平方根代数数。
有限网格的端序、重合、占用、最大速度以及 (9) 的符号，
都可通过实代数数比较或带严格余量的有理区间完成。
同边相等必须真正作零判定，不能用浮点 epsilon 合并或拆开。

设已认证 \(\lambda D-R_0\sigma=\gamma>0\)。
定理 1 给一个充分小区间；在其中取正有理 t。
再对每个记录用分母 L 的严格内半径
\[
 \rho_{j,L}(t)=
 [\operatorname{isqrt}(\lfloor L^2(M_j+tw_j)/(4\lambda)\rfloor)-1]/L.
\tag{11}
\]
若这个表达式非正，记录按空集处理，不能代入负“半径”生成伪矩形。
每个半径相对理想值的损失小于 2/L。
有限矩形族的面积损失至多 C_F/L：逐矩形以内缩边带估计，
再用并集损失不超过各损失和。小 t 时总周长有统一有限上界，
点方形也满足这个估计。
选择 L 足够大，使面积损失小于本次严格增益的一个固定小份；
例如在 t→0 的证书编译中取 \(L^{-1}=o(t)\) 足够。
最后用精确整数并集核直接检查新比值超过旧目标。
无需预先知道余项常数：对已认证的正余量，可枚举
\(t=2^{-k},L=2^{2k}\) 并逐次作精确比较，以上估计保证最终成功停机。
有理输入时旧理想面积也是有限代数数，可直接比较；或使用其安全有理上包。

因此非临界正的一阶证书能编译为有限有理输入、严格内半径和真正 L1 下界。
不能固定粗 L 后对台阶函数取导数。
如有旧种子量化证书，只知其 \(A_L\le A(0)\)，可用
\(A(0)\le A_L+C_F/L\) 作为旧比值上包，给增益符号留安全余量；
不能未经比较就把量化旧面积当作理想 A(0)。

R2 的有限截断和平滑适用：有限见证、严格内半径及有限最大半径给 q，
然后取内胞元和小源平滑得到明确的严格 L1 比值。
没有因求导而换成不同背景测度或固定最大尺度算子。

### 可直接检查的二阶 jet 并集算法

上述导数还可不经过“任选外露面 owner”的人工解释而精确计算。
仍令 \(s=\sqrt t\)，把每个端点保留到 s²：

* M>0 时，\(r(s^2)=r_0+u s^2+O(s^4)\)；
* M=0 时，\(r(s^2)=\sqrt{w/(4\lambda)}s\)，没有余项。

以三元组 \((a_0,a_1,a_2)\) 表示端点二次多项式
\(a_0+a_1s+a_2s^2\)，包含全部原型、所需周期平移及固定胞元截断线。
按三元组的字典序作零右侧排序。
相同三元组可作任意一致 tie-break：在 jet 模型中它们就是同一条坐标线。
用这些端点多项式作矩形，按空区间规则和胞元截断，
精确计算压缩网格中被覆盖单元的多项式面积和，输出
\[
 D=[s^2]\,A_{\rm jet}(s).
\tag{12}
\]
M=0 方形的两轴 s 项乘积、退化线的 s²宽×常高，
正面积面的 s²移动及重合面的 max/min 都包含在同一个并集算法中。

证明这个有限算法足够：真实端点与二次 jet 端点差 O(s⁴)，
有限矩形并集的面积误差为 O(s⁴)。
这一扰动估计也涵盖空／线／点退化：若微扰使空矩形激活，
至少一个有效宽度只有 O(s⁴)，另一个宽度有统一上界。
因此二者 s²系数相同。
若真实两个端点同 jet 却在更高阶分开，可能变化只在 O(s⁴) 宽条中，
不需要为求 D 先判这个更高阶端序。
jet 模型本身是有限二次多项式端点族，弱排序由字典序确切决定，
面积和的 s²系数可以用有限代数运算逐格重算。
同时应输出常数项 A(0) 与 s 一次项 0 作为一致性检查。
这是主定理系数的独立计算规格；(5)–(7) 是它的几何分解。

## 7. 单个候选点的可计算参数分层

固定一个种子和 reach，令一个新增周期点 p 在胞元内变化，但每次求导时 p 固定。
可以预先选统一有限原子／bbox 窗口：
限制 \(0<t\le t_0\) 后，reach 盒的质量有统一上界，接收半径亦有界。
所有可能边界来自有限个旧坐标或 p 的有限周期副本。

先按旧原子坐标、周期及 reach 事件对输入胞元分层。
在每个开层中，各 bbox 的旧质量 M_j 和新增副本系数 w_j 不变，
故正 M_j 的 \(r_j,u_j\) 都是固定代数数。
初始接收端点是 p_x 或 p_y 的仿射函数，系数为 0 或 1。
继续加入以下事件：

* 接收宽／高为零；
* 两个同轴初始端点相等；
* 端点与胞元切口、旧 receiver 边相遇；
* p 位于旧并集的边／角。

这些事件在该层内是有限个轴向代数直线；逐层细分后，
每个二维开片上的 owner、侧占用、max 速度清单固定。
边段长度是 p_x 或 p_y 的仿射函数，因此 D 在每片上为仿射函数加常数。
输入直线和顶点另作低维层，使用闭盒成员规则与 (5)、(7) 的实际重合值；
不能只取开片的极限代替真实边界点。
二维开片可取有理内点；低维代数层未必含有理点，不能作同样假设。
可保留代数坐标证书，或先固定一个已有严格增益的正 t，
再利用有限支持 bbox 与接收并集面积对坐标的连续性作有理微扰。
微扰时保留所选有限支持标签、以实际 tight bbox 承接；
不要求一阶导数跨临界层连续。

这给出有限代数数据的全分层计算规格，不给效率或统一于 N 的复杂度保证。
可在某个片上给 D 的严格上界／正余量下界，筛选有理内点，
或对某个固定 p 完整排除其非临界小质量增益。
即使逐个固定 p 都没有正一阶方向，也不自动证明对漂移 p(t) 的统一邻域排除；
后者还要统一余项或额外的边界层分析。本稿不签这个更强量词。
