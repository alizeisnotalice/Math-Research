# 准确证书与复核程序

本稿所依13份原证书、作者和独立审核代码已在仓库归档。它们的仓库相对路径与SHA-256逐项列于 [supplement_hashes.json](../supplement_hashes.json) 的 repository_relative_source 字段；同一原件不重复复制。原运行记录的源码路径和回执保持原样。

本稿新增14组有限有理式的核验程序为 [verify_transcription.py](../verify_transcription.py)。它会在脚本所在目录写入 transcription_receipt.json；请按论文 README 的临时副本方法运行，以保留原始回执。该程序核验有限算术与引用结构，无限尾及原算子传递见正文证明。
