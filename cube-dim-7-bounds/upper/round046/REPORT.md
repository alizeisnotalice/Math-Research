# 第046轮：新逆列加权的一维行积分诊断

本轮是数值候选/反例诊断，无新Cn界。固定R>0,ρ≥4R,0<g<R/2,a=R−g，定义ell(z)=min(1,(R+ρ+a−|z|)/(2R))及J(w)=(2ρ)^−1∫1{|z−w|<ρ+a}/ell(z)dz。独立分段定义积分与稳定闭式J=1+[E(m+)+E(m−)−m+−m−]/(2ρ)比较，其中m±=max(0,±w−a)，E(m)=−2Rlog(1−(g−m)/(2R))−(g−m)当m<g，其他为0；避免J−1灾难消去。

登记15个准确有理(g/R,ρ/R)，g/R为1/128至1/8的5档，ρ/R为4/16/256，每案有限256个(h/g,r)组合、实际97个不同r复用积分。80位mpmath分段定义、均值和二阶矩共4365次，3840组合全部完成。闭式与定义积分最大观测差约1.2e−81；所检归一均值损失及二阶矩最大约1.9673/2.21145，均在检验的6/31以内。它们只是有限样本极值，不能替代全域解析证明、错误界或锐常数。

另实际SymPy验证参考r=R时均值J=1的准确恒等式。原注册/代码/运行hash及15案例摘要保留。portable stdlib checker实际在只含白名单目录核15摘要PASS，不重跑积分；摘要不能独立证明其是所有未归档raw行的max，全部raw仍在private并锁hash，可按生产code重算。

实际15PID wall2.76s、累计worker CPU36.57s，即平均约13.25核；这不是瞬时ps测得的满核。首ps过早、5秒稳定样本前结束，未声称持续满核或吃满内存。worker峰RSS约51MB。每批完成登记数量即停，无人工占用资源。

该一维诊断支持R045新机制的寻找，完整原算子一般L1/全尺度结论只由另轮解析证明与全链审计负责，不能从这3840点推出。公开和内部Cn对比本轮均无新界。未运行下界或n7专项，未动旧暂停项目。
