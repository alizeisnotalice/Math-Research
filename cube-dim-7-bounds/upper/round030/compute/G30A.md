# G30A: bounded Arb root-isolation attempt

`g30a_arb.py` computes the closed form of B and its first two derivatives using Arb power-series automatic differentiation. It encloses H = [t(t+1)B'/n]^2−AB and H' on each rational box at 512-bit precision. A box is discarded only when H has strict sign, or when H' has strict sign and exact-endpoint evaluations have equal strict sign. A box with strict sign H' and opposite strict endpoint signs isolates exactly one root. A residual box cannot support any conclusion. The covered range is [1+1/(4n2^n),4n]; claimed endpoint and tail signs require separate proofs, which this run does not verify. On t>1, B>0 and A>0, so H and F' have the same sign. For n=4,7,64 independent high-precision positive-integral numerical checks at t=7/2,6,40 agreed with H and H' to displayed binary64 precision; those checks are not interval proofs.

At 512 bits, n=4 used 159 boxes, yielding (+ to −) root in [17/16,35/32] and (− to +) root in [57/16,29/8], with zero residual boxes. n=7 used 286 boxes, yielding roots [225/224,113/112] and [51/8,13/2] with the same respective signs and zero residual boxes. These cover only the range above; a global result depends on the separate endpoint and tail arguments.

For n=64 the 4096-box limit was reached: 4041 unresolved boxes remain, even though a near-endpoint (+ to −) root was isolated. Direct interval expansion suffers dependency inflation. Increasing precision alone cannot correct that interval width, so no 1024-bit repeat or further scan was launched. In particular this is not a certificate of exactly two roots for n=64. Exact residual boxes, resource usage, process IDs and script hash are in `g30a_results.json`.

The new n=7 candidate comparison is separately recomputed by `n7_against_round028.py`: exact new F_upper < U = 12277480262982331/500000000000000 < the full original round028 Arb lower endpoint, and its finite-a bound is < U. The 60-digit raw stationary root is numerical only and is recorded with its residual in `n7_against_round028.json`. The independent original cube-cap theorem supplies the operator upper bound; neither this candidate nor H establishes an operator lower bound.
