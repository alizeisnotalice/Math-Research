# R022：有限整数参数批，续跑结果

登记范围为 n=7、整数 a=50,…,80，复用 R021 的 a=64 区间；其余30个参数仅各计算一次。由512位 Arb 外向区间进行精确有理比较，**a=63 是该31个整数中唯一严格最小者**：其上端严格小于其他30个参数各自的下端。其精确表达式为

    [1+(65/63)^7] [1+(64/63)^7(1+7 log 63)]。

结果约 77.4333403222526020323，严格小于 77.433340322253，该数是向上取 10⁻¹² 网格的结果。除63外，只有62也以其上端严格低于原 a=64 的下端。所有30个新参数的准确 dyadic 有理上下端及各自对旧64的比较在两个 terminal 文件中。此结果仅比较指定的整数有限集合，不断言对全部实数 a>1 的最优性。

首次执行的 a=50 区间已计算并 flush，随后因遗漏 import os 而在 fsync 报 NameError，以 exit 1 停止；该原始 completed 记录和持久化失败记录、原代码与 receipt 全部保留在父目录并由原 manifest 锁定。经主明确授权，独立核对该记录的上下端、源散列、公式与失败来源（reuse_check.json）后，续跑不重新计算50，只计算剩余29个值。新脚本补齐 import os，预跑锁定 SHA256；续跑 exit 0。源码来源核验与保存值可追溯，但不冒充对 a=50 的第二次 Arb 计算。

续跑程序内 CPU 0.005029 秒、wall 0.008630 秒、峰 RSS 31,834,112 字节；系统 time 包括启动 wall 0.12 秒、峰 RSS 31,866,880 字节。首次失败过程的 time 见父目录 receipt；不能声称整批一次 exit 0。check_saved.py 只读检查散列、30个唯一参数、保存端点、所有对64的比较、胜者严格区间和网格，未重跑 Arb。无额外参数、phase、MC、lower、MATLAB、提交或推送。
