# R002 frozen finite dangerous-point candidate design

Object remains the equal-weight body64 common-time Cauchy model and the Lebesgue centered axis-parallel seven-cube maximal-operator interface (general L1, common radius, all positive scales). We search only finite-sample G candidates on x=(1,y), y in [0,1]^6; no claim about true global g, a global minimum or a new operator bound is permitted. The conditional target 1/179000 is a search reference, not an established floor.

Reuse the original 8192-shape cache with SHA256 6dfa48bf8954a7d02270af5bda9c1d33d4fcaf0ba4f5e486589186b7f7c09552. No new shapes, no cache recovery, no clipping, dropping or resampling. The old eight point baselines are not reevaluated. All 8192 shape contributions enter every full point call.

The exact model reduction from R001 is G=C D E[d(P) Q(P,x)^(-3)], C=1/(2pi^(7/2)), D=2Gamma(65/2)/Gamma(32), d=det(A)^(-1/2), Q=x^T A^(-1)x. The finite-sample value is the average of all 8192 contributions, and its exact finite-sample derivative is -6CD mean[d Q^(-4)(A^(-1)x)_free]. Minimize log of this positive empirical value with that analytic gradient. This changes only the numerical objective scale, not its minimizers. No convexity or global convergence is assumed.

**Hard full-point computation budget: 32768.** A joint value/analytic-gradient evaluation is one physical full-point call; every call of this joint kernel is counted, including optimization repeats, candidate reevaluation, rationalization, near-point probes and all finite-difference calls. Gradient-only work is never hidden behind a separate uncounted oracle. At most 64 starts, each with a hard 256 joint-call cap, so optimization cannot exceed 16384. At most 8 candidate bundles are selected afterward; diagnostic work has an additional hard 8192-call guard, while the shared overall guard remains 32768. These deliberately conservative caps do not authorize spending the unused budget on automatic expansion.

Starts are the 64 deterministic unscrambled six-dimensional Sobol points (SciPy qmc.Sobol(6,scramble=False).random_base2(6)); this is deterministic initialization, not new scientific Monte Carlo. L-BFGS-B bounds are [0,1]^6, maxiter=128, maxfun=256, maxls=24, ftol=1e-13, gtol=1e-8 and maxcor=12. The callback's own cap prevents SciPy overshoot. First run starts 0..7 with up to 8 workers and provide feedback. Then run the already registered starts 8..63 with up to 15 workers. Each worker has BLAS/OpenMP thread limits 1. There is no wall limit. A start has a unique persistent handle, updated checkpoints and a complete call trace; unknown or existing handles are never silently re-dispatched.

The top terminal/best-seen points are rounded to denominator 1e6 and deduplicated, selecting at most eight bundles by empirical value. Every bundle evaluates the original point, rounded rational point, and one predeclared nearby rational perturbation y_k'=(1-7epsilon)y_k+epsilon*k, epsilon=1/1000003, k=1,...,6. Perturbations remain in the cube. Candidate diagnostics retain all eight block means, empirical SEM, largest contribution and its share, Q extrema, original shape conditioning and 80-digit same-shape diagnostics for each of the seven original cache rows with condition>1e8. Each same-point high-precision subset verification is conservatively charged an additional point call against the total budget, and its count is separately recorded. The latter are floating arithmetic diagnostics, not interval certification. Nonpositive/nonfinite Q invokes same-point 80-digit diagnostics and stops the affected start without dropping samples.

Gradient cross-checks use finite differences at h=1e-5 and h=3e-6 in all six coordinates. Central differences are used away from faces, otherwise second-order one-sided differences stay inside the box. Each stencil point is a counted full-point call. All returned numerical values are retained even if unfavorable to the target.

Exact rational S3 classification first uses the at-most-four-absolute-values property of a span of three body lines. Five or more exact distinct absolute values prove off S3. Otherwise an exact Fraction/Cramer scan of all 41664 triples either gives a body-span witness or excludes every triple. Original optimizer coordinates are also preserved as exact floathex. S3 points have infinite true G in dimension seven: a span of rank r<=3 has a nonzero-coefficient representation, and the remaining directions still span R7, yielding a small-time lower density proportional to t^(2r-7), whose integral diverges. Finite-shape pseudo-low values there cannot be called counterexamples to a genuine floor. Near-S3 bias is an explicit diagnostic concern.

Actual utilization, wall/CPU time, all call counts and solver statuses belong to receipts. On completion this finite batch stops for primary review, without g optimization extensions, extra starts, new shapes or promotion of sample values to proof.
