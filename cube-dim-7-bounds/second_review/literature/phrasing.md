# 可直接入稿的来源表述与措辞建议

以下各段供主稿按结构选用。引用键与 `references.bib` 一致；无需全部使用。内容限于三篇既有原始来源的准确归属，不构成新的几何或标量审计结论。

## 方法来源段

Stein 与 Strömberg 对一般对称凸体的中心极大算子建立了量级为 n log n 的弱型 (1,1) 估计，其证明通过有限球族的选择及加权重叠控制完成 [SteinStromberg1983, §2, pp.260–263]。本文沿用这一有限选择框架，引入独立的选择阈值和缓冲膨胀参数，并利用轴平行立方体的坐标结构估计其余增量的加权体积，由此得到可按维数直接使用的显式上界公式。

说明：原文的渐近定理限 n>1；若正文逐字写出该定理，需带上这一条件。后一句将本轮阈值、缓冲和 cap 步骤明确归属于本文，没有称它们为原文明写的结论。

## 128 比较基准段

Aldaz 对 ℓ∞ 几何下的中心极大算子给出了关于测度的统一估计，其常数为 2^n [Aldaz2020Kissing, Corollary 3.5]。取 Lebesgue 测度便得到本文模型下的基准 c_n≤2^n。本文以这一有明确出处的界作为七维应用的比较基准。

如确需解释 sharpness，可另加一句：“原文关于常数达到性的结论针对测度类上的统一问题，不表示固定 Lebesgue 测度时有 c_n=2^n。”通常引言只保留前段的正向表述即可。

## 可选维数背景段

Aldaz 证明了中心轴平行立方体极大算子的最优弱型 (1,1) 常数随维数趋于无穷 [Aldaz2011Cubes]。本文研究给定维数下可核验的显式上界。

如引言不讨论渐近维数依赖，删除本段及其引用即可；无需增加其他背景文献。

## 七维应用的归属写法

仅在主任务安排的独立算子、几何与标量二审完成后使用：

“作为应用，七维情形的显式证书给出 c_7<24.554960525965。”

该句应指向本文的应用命题及相应证书，不接在任何一个外部文献引用后使读者误以为该小数来自原文。这里不使用“最优值”“最佳已知值”或“全球纪录”。本二审未计算该小数。

## 需避免或替换的句式

| 不建议的句式 | 可用替换 |
|---|---|
| “Stein–Strömberg 定理给出了本文的自由阈值及 cap 公式。” | “本文从 Stein–Strömberg 的有限选择框架出发，分别证明自由参数估计和立方体 cap 估计。” |
| “由 O(n log n) 直接代入 n=7 即得到上述小数。” | “七维上界由本文显式公式及其标量证书得到。” |
| “Aldaz 证明 Lebesgue 情形的最优常数为 2^n。” | “Aldaz 的测度统一估计蕴含 Lebesgue 情形的上界 c_n≤2^n。” |
| “已有最佳七维公开上界为 128。” | “本文采用可由 Aldaz Corollary 3.5 得到的 128 作为比较基准。” |
| “本文在所有维数严格改进了 2^n。” | “本文公式适用于所有正整数维数，并给出七维的显式应用。” |
| “Aldaz 的发散定理说明七维上界为……” | “Aldaz 的发散定理提供维数依赖背景；七维上界另由本文证明。” |
| “首次、最新、最佳、确定最优常数。” | 使用“一个显式弱型估计”“本文所得上界”“本节给出的证书”。 |

## 成稿时的简短引用规则

- 方法框架引用 `SteinStromberg1983` 的 §2；本文新推导在文内自行证明。
- 2^n 和 128 的来源引用精确版本 `Aldaz2020Kissing` 的 Corollary 3.5。
- 维数发散只在实际使用背景时引用 `Aldaz2011Cubes`。
- 不把不同版本的编号、年份或发表信息拼成一个不存在的版本。
- 本轮没有进行新的公开最优界检索，正文不作相应最优性比较。
