## 定理与记号

令 `Q(y,r)=y+(-r,r)ⁿ`，`sQ=Q(y,sr)`；`M_n` 是全部 `r>0` 的中心立方体绝对值平均上确界，`C_n` 是其最优弱型 `(1,1)` 常数。固定

```
t>1, a>2t, τ>0,
b=a(1+1/t), α=a/(a+1), c=(b−1)/(a+1),
P=α^(−n), A_a=((b+1)/a)^n=(1+1/t+1/a)^n.
```

有限参数结论为

```
C_n ≤ (1+A_a/τ)(τ+E_a),
E_a=a^(−n)+P J_a,
J_a=1−ell_a(1)^n+n log t−(n/2)∫₁ᵗell_a(ρ)^(n−1)dρ/ρ,
ell_a(ρ)=(1+c−α/ρ)/2.
```

极限中 `A=(1+1/t)^n`，`ell(ρ)=1+1/(2t)−1/(2ρ)`，

```
B_n(t)=1−ell(1)^n+n log t−(n/2)∫₁ᵗell(ρ)^(n−1)dρ/ρ >0,
C_n ≤ F_n(t)=(sqrt(A)+sqrt(B_n(t)))².
```

## 1. 非增半径、资格前缀和拒绝覆盖

**证明。** 在有限输入族中，每步选择尚未选择且合格者中的最大半径，允许任意固定的并列规则。第 `j` 步冻结权重后，其后增加的资格和项均非负，所以一个尚未选择的立方体只能失去资格，不能重获资格。剩余合格集逐步缩小，故所选半径非增；有限性保证过程终止。

对未选 `Q=Q(y,R)`，令 `m` 是它第一次因第 `m` 次选择而失去资格的时刻。这样的时刻必存在，否则终止时它仍合格。每个 `j≤m` 选择前，Q 尚在合格集中，故最大半径规则给出 `r_j≥R`。冻结的实际权重满足

```
Σ_{j≤m} w_j 1_{bQ_j}(y)>τ.
```

若该和的第 j 项非零，则每个 `x∈Q` 满足

```
||x−y_j||∞ ≤ ||x−y||∞+||y−y_j||∞ < R+b r_j ≤ (b+1)r_j.
```

于是最终负载 `L(x)=Σ_jw_j1_{(b+1)Q_j}(x)` 在全部未选立方体上大于τ。设U为全部输入之并，V为所选小立方体之并，则 `U⊂V∪{L>τ}`。积分给

```
|U|≤|V|+τ^(−1)∫L
   = (1+A_a/τ) Σ_jv_j.
```

`b+1` 的1来自被拒绝立方体自身半径 `R≤r_j`，有限a时不得删去。不能随意使用所有最终拒绝项的半径；合法的是首次拒绝前缀，或包含它的最终 `r_j≥R` 子和。

**依赖。** 有限族、最大合格半径、冻结非负权重、第2项的 `|V|=Σv_j`、立方体同一半径及三角不等式。

**审核结果。** 通过。论文写成“首次选取较小半径之前已不合格”也是合法的等价前缀论证；明确写首次失去资格可使理由更直接。不存在要求修复的错误。

## 2. 不交增量、权重和归一化

**证明。** 每次定义

```
I_j=Q_j\⋃_{i<j}Q_i, v_j=|I_j|, w_j=v_j/(2ar_j)^n.
```

I_j是可测集合，可以不是立方体，亦可为空。如果i<j，则 `I_i⊂Q_i` 而 `I_j∩Q_i=∅`，故两两不交。每个属于所选并集的点有最早包含它的下标，因此 `⋃I_j=⋃Q_j`，`Σv_j=|V|`。`0≤v_j≤(2r_j)^n` 给 `0≤w_j≤a^(−n)`；零权重不影响资格或支付。

对所有坐标和半径作同一倍数伸缩时，v_j和分母同时乘该倍数的n次方，w_j不变。没有一步要求Q_j互不相交，也不要求aQ_j互不相交。拒绝负载积分中的每项为

```
w_j |(b+1)Q_j| = v_j ((b+1)/a)^n.
```

**依赖。** 只用有限可测集合分解和Lebesgue共同缩放。

**审核结果。** 通过。不能把I_j改成所选大方体的差集，不能假定I_j仍是方体；原稿没有这样做。

## 3. 最小半径、最后下标、自项和未捕获半径

**证明。** 固定 `W(x)=Σ_jw_j1_{aQ_j}(x)>0`。仅在正贡献项中取最小半径，再取该半径中最后下标k。由于所选半径非增，每个其他正贡献项下标均小于k；相同半径也由最后下标规则涵盖。零贡献项可舍去。

将x移到0并除以r_k后，`r_k=1`，`||y_k||∞<a`。此前正贡献项均 `r_j≥1`。其中 `y_k∈bQ_j` 的项是选择k时真实资格和的非负子和，故总和≤τ。自身项不在该和中，单独支付 `w_k≤a^(−n)`。

其他项满足

```
||y_k−y_j||∞≥br_j, ||y_j||∞<ar_j, ||y_k||∞<a.
```

若 `r_j≥t`，则

```
||y_k−y_j||∞<a+ar_j≤(a/t)r_j+ar_j=br_j,
```

矛盾。因此所有未捕获项确实 `1≤r_j<t`。端点r_j=t被严格上界排除，同半径r_j=1保留，未被误认为已捕获。

**依赖。** 第1项半径非增、第2项权重界、实际选择条件、t>1、共同伸缩。

**审核结果。** 通过。最后下标规则、自项和上下半径边界均不可省略；论文已明确保留。

## 4. 实际增量进入帽区、Jacobian和边界

**证明。** 对上述未捕获项及 `y∈I_j⊂Q_j`，置

```
z=y/(a+1), u=y_k/(a+1), m(z)=max(1,||z||∞).
```

有 `||u||∞<α`。又由 `0∈aQ_j`、`y∈Q_j` 得

```
||z||∞ < r_j < t,   m(z)≤r_j.
```

反三角不等式给

```
||y_k−y||∞≥||y_k−y_j||∞−||y−y_j||∞>(b−1)r_j,
||u−z||∞>c r_j≥c m(z).
```

故每个实际增量映入

```
D(u)={||z||∞<t, ||u−z||∞≥c m(z)}.
```

这里把严格条件放大为非严格条件只会扩大上积分；无需声称帽边界本身总为零。因 `r_j^(−n)≤m(z)^(−n)`，I_j不交，且共同映射的 `dy=(a+1)^n dz`，

```
Σ_{unpaid} w_j
 = (2a)^(−n) Σ_j ∫_{I_j}r_j^(−n)dy
 ≤ ((a+1)/a)^n 2^(−n) ∫_{D(u)}m(z)^(−n)dz
 =P H(u;c,t).
```

这是同一个全空间线性变换，不是随j变化的局部坐标，因而保留不交性。由第3项得到 `W(x)≤τ+a^(−n)+P H(u;c,t)`。

**依赖。** 第2项不交性、第3项未捕获半径区间和中心关系、反三角不等式、同一变换。

**审核结果。** 通过。Jacobian、2^(−n)、P及不等号方向全部正确。

## 5. 帽区单调性、逐面壳积分和角点

**证明。** 同时反射z、u的任一坐标保持H，故可设 `0≤u_i≤α<1`。将捕获部分定义为严格条件 `||u−z||∞<c m(z)`，它与D互补。

在内方体 `||z||∞<1` 中m=1。因 `u_i+c>1`，第i坐标交区间上端为1，下端为 `max(−1,u_i−c)`，长度

```
L_i(1)=min(2,1+c−u_i)>0.
```

未捕获的归一化体积为 `1−2^(−n)∏L_i(1)`，逐u_i非减。

外壳按唯一满足 `|z_i|=||z||∞=ρ` 的坐标及符号分开。最大值并列点位于有限个 `z_i=±z_j` 超平面中，是n维零测集；n=1时无并列集。映射 `(ρ,z_other)↦z` 的行列式绝对值为1，其余坐标在 `(-ρ,ρ)`。这不是欧氏表面面积，也不是对移动交体积求导。

正i面始终满足 `|ρ−u_i|<cρ`。负i面恰在 `u_i<(c−1)ρ` 时满足严格捕获条件；其余坐标的交长为

```
L_l(ρ)=min(2ρ,(1+c)ρ−u_l).
```

所以捕获壳密度为

```
S(ρ,u)=Σ_i[1+1_{u_i<(c−1)ρ}] ∏_{l≠i} L_l(ρ).
```

增大某u_j时，第j项的计数非增，其他每一项的L_j非增，所有其他因子非负。因此S逐坐标非增，且

```
H=1−2^(−n)∏L_i(1)
  +2^(−n)∫₁ᵗρ^(−n)[2n(2ρ)^(n−1)−S(ρ,u)]dρ
```

逐坐标非减。等号 `u_i=(c−1)ρ` 可以是完整负面，不能把它的面测度判为零；上式的严格计数已正确处理它。因c>1且u固定，每个i只有至多一个这样的ρ，其并集对dρ零测。方体内帽边界及ρ=1亦不改变体积分。n=1按空乘积1处理，上式仍成立。

于是 `H(u;c,t)≤H(α·1;c,t)`。这只是比较盒上的最大上预算，不要求角点由真实选取中心达到，不要求各步骤的最坏情形在一个实际族内同时达到。

对本参数，`c−1=(a/t−2)/(a+1)>0` 且 `α/(c−1)=at/(a−2t)>t`。因此角点每个坐标只有正面被捕获，且在[1,t]上

```
L(ρ)=(1+c)ρ−α=2ρ ell_a(ρ),
ell_a(ρ)=α[1+1/(2t)−1/(2ρ)],  0<ell_a(ρ)≤α<1.
```

全部壳项归一化后是 `n dρ/ρ`，n个捕获面给

```
2^(−n)ρ^(−n)nL(ρ)^(n−1)dρ
 = (n/2)ell_a(ρ)^(n−1)dρ/ρ.
```

故角点积分恰为J_a，得到点态 `W≤τ+E_a`，没有漏因子2。

**依赖。** H的精确定义、c>1、α<1、逐面Lebesgue参数化、非负因子乘积、a>2t。

**审核结果。** 通过。最危险的“整面等号”和“误用移动体积导数”均被原证明避开。n=1没有例外。

## 7. 一般L¹、真实坏半径和全部尺度

**证明。** 固定R>0时，绝对值平均的平移差不超过 `(2R)^(−n)|||f|(·+h)−|f|||_1`，随h趋零而趋零。因此 `E={M_nf>λ}` 是连续平均的严格超水平集之并，因而开。

任取紧 `K⊂E`。对每个x∈K，按上确界大于λ的定义选一个真实 `R_x>0`，满足其平均>λ；这不需要上确界达到。以小方体 `Q(x,R_x/a)` 覆盖K并取有限子覆盖。其a倍方体恰是原算子的真实见证。选择其中的子族，对各项

```
λv_j ≤ w_j∫_{aQ_j}|f|,
```

零增量两边均零，其他项甚至为严格不等式。有限求和并应用点态负载界得

```
λΣ_jv_j ≤∫|f|W ≤(τ+E_a)||f||_1.
```

由于K在全部输入之并内，第1项遂给 `λ|K|≤(1+A_a/τ)(τ+E_a)||f||_1`。Lebesgue内正则性取所有紧K的上确界，得相同的E估计；从而才推出E有限测度，没有预设该性质。可以取实或复f，因为全过程只使用|f|。

见证半径无上下限，有限子覆盖各半径可不同，但各立方体内部坐标共用同一半径。没有紧支集、有限原子、光滑、乘积输入或离散尺度假设。每个立方体的边界是有限个坐标超平面片，Lebesgue零测，所以开闭立方体对每个L¹平均一致。

**依赖。** L¹平移连续、有限开覆盖、实际见证平均、第1—5项、Lebesgue内正则性。

**审核结果。** 通过。结论确实是一般L¹和全部正尺度的原算子定理。

## 8. 正性、τ精确优化及n=1

**证明。** 置 `h=ell(1)=(1+1/t)/2∈(0,1)`。在[1,t]上 `0<ell≤1`，所以对所有整数n≥1，

```
B_n=1−h^n+n∫₁ᵗ[1−ell(ρ)^(n−1)/2]dρ/ρ
   ≥1−h^n+(n/2)log t>0.
```

n=1时指数0解释为1，不出现0⁰，因为ell>0；空乘积同样为1。有限J_a也正，因为 `0<ell_a<1`，同一估计可用。于是A、B均严格正，允许选实际正数 `τ=sqrt(AB)`。展开

```
(1+A/τ)(τ+B)=A+B+τ+AB/τ
              ≥A+B+2sqrt(AB),
```

等号恰在上述τ，得到F_n。这只是选择算法阈值的优化，不是对原算子输入或真实常数求极值。

**依赖。** t>1、角点积分、n为正整数、正数算术几何平均。

**审核结果。** 通过。维数1、空乘积和平方根可取性完整。

## 9. 可吸收的严格参数结论与几何改进边界

### 9.1 现有有限参数预算不能优于同t极限

这是本次重新推导的严格后果，不是数值观察。固定任意n≥1、t>1，令 `L=log t`，`I=∫₁ᵗell(ρ)^(n−1)dρ/ρ`，所以 `0<I≤L`。置 `q=α^(−1)=1+1/a>1`，由 `ell_a=α ell` 得

```
E_a=a^(−n)+q^n(1+nL)−h^n−(n/2)qI,
E_a−B_n=a^(−n)+(q^n−1)(1+nL)−(n/2)(q−1)I.
```

由二项式或 `(q^n−1)/(q−1)=Σ_{k=0}^{n−1}q^k≥n`，

```
E_a−B_n ≥ a^(−n)+n(q−1)[1+(n−1/2)L] >0.
```

且 `A_a=(1+1/t+1/a)^n>A`。固定τ时有限预算严格更大；对τ也优化后

```
min_{τ>0}(1+A_a/τ)(τ+E_a)
  =(sqrt(A_a)+sqrt(E_a))² > (sqrt(A)+sqrt(B_n))²=F_n(t).
```

a趋于无穷时收敛，因此在当前预算族、固定t下，对有限a,τ的下确界恰为F_n(t)，没有有限a达到。结论同样排除“仅重新优化现有有限a”对已有同t极限预算的改进。它不排除改变支付、利用实际增量耦合或其他覆盖算法后的真正改进。

### 9.2 维数1公式族的下确界及不取到

直接积分得 `B_1=(1−1/t+log t)/2`。令 `s=1−1/t∈(0,1)`，则 `A_1=2−s`，且 `log t=−log(1−s)>s`，所以 `B_1>s`。故对每个t>1，

```
F_1(t)>(sqrt(2−s)+sqrt(s))²
      =2+2sqrt(s(2−s))>2.
```

而t↓1时A_1→2、B_1→0，F_1→2。因此 `inf_{t>1}F_1(t)=2`，仅在被排除的端点极限趋近，无内部全局最优点。这没有断言真实C_1等于2，也没有借用一维文献。

还可排除内部局部极小点。记 `G=sqrt(A_1)+sqrt(B_1)`，直接微分得

```
G'(t)=−1/(2t²sqrt(A_1))+(t+1)/(4t²sqrt(B_1)).
```

由 `log t<t−1`，有 `4B_1<2(t−1/t)`，而
`(t+1)²A_1>(t+1)²>2(t−1/t)`（最后差为 `t²+1+2/t>0`）。故 `(t+1)sqrt(A_1)>2sqrt(B_1)`，G'>0，F_1'=2GG'>0。于是本公式族在t>1严格递增。

### 9.3 没有声称的几何改进

原帽域确实放宽实际增量来源与半径/中心耦合，单调性角点也只是放宽模型的极大点；本审计没有证明该角点可由真实选择族逼近，也没有证明其不可逼近。未得到一个仍包含全部原实例且积分严格更小的可行域，因而不提出新几何常数、不将上述有限参数障碍推广为所有覆盖法的障碍。
