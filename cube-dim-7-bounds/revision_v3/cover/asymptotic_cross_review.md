## 1. 被接受的精确命题

沿用作者的 `A_n,B_n,F_n,I_n` 定义。令

```
U_n=inf_{t>1}F_n(t), L=log n, T=nL−n log L.
```

对所有整数 `n≥ceil(exp(32))`，以下估计成立：

```
T−4n(log L+1)/L ≤ U_n ≤ T+n(6log L+5)/L.           (R1)
```

这里没有暗含t取某个预先有界范围：左界来自对全部t>1的点态下界，右界来自一个明确合法参数。于是

```
U_n=n log n−n log log n+O(n log log n/log n),
U_n−T=o(n).                                        (R2)
```

例如对上述全部n，R1给一个绝对误差常数11：因log L>1，`4(log L+1)≤8log L`、`6log L+5≤11log L`，故 `|U_n−T|≤11n log L/L`。常数不随n或t改变。此处的n下阈值仅是充分条件，不声称最小。

## 2. 一致积分估计与B单调性

对全部整数n≥2及全部t>1，`0<ell_t(ρ)≤1` 于ρ∈[1,t]。令 `d=(1/ρ−1/t)/2≥0`，则 `ell=1−d`，由 `1−d≤exp(−d)` 得

```
I_n(t)≤∫₁ᵗexp[−(n−1)(1/ρ−1/t)/2]dρ/ρ.
```

换元 `v=1/ρ−1/t`：`dρ/ρ=−dv/(v+1/t)`，上下端对应 `1−1/t` 与0。因此

```
I_n(t)≤∫₀^(1−1/t) exp[−(n−1)v/2]dv/(v+1/t)
      ≤t∫₀^∞ exp[−(n−1)v/2]dv=2t/(n−1).             (R3)
```

分母正、积分上限放大方向正确，n−1>0；不要求t≪n或t处于极值附近。该估计可以在t很大时较弱，但仍一致有效。

用于第一分区的B严格单调也独立核验如下。固定t>1，有限区间上的光滑被积函数允许Leibniz求导；设 `J=∫₁ᵗell^(n−2)dρ/ρ≥0`。因 `ell_t(t)=1`、`∂_t ell=−1/(2t²)`，

```
I_n'=1/t−(n−1)J/(2t²),
B_n'=n/(2t)+n h^(n−1)/(2t²)+n(n−1)J/(4t²)>0.      (R4)
```

n=2的J为log t，仍合法；强化命题不使用n=1。R3及R4均不依赖某个数值候选或对极小参数的假设。

由 `1−h^n≥0`、R3及 `n/(n−1)≤2`，对n≥2统一有

```
B_n(t)≥n log t−nt/(n−1).
```

置 `x=n/t`，则nt/(n−1)=`n²/((n−1)x)≤2n/x`，从而

```
B_n(n/x)≥nL−n log x−2n/x,     0<x<n.             (R5)
```

这正确保留了一个n因子，没有误写成只为O(1/x)的扣除。

## 3. L≥32下的全部阈值

以下仅需初等不等式 `1/2<log2<7/10`、`2<e<3`。这些可由对数积分/正项级数或e的级数直接证明。

1. `L−3log L≥L/2>0`：在L=32，`log32=5log2<7/2`，故 `L/2−3log L>16−21/2=11/2>0`；函数 `L/2−3log L` 的导数 `1/2−3/L` 在L≥32为正。
2. `x₀=L+4log L≤2L`：在32有 `L−4log L>32−14=18>0`，其导数 `1−4/L>0`。
3. `4L²≤2e^L`：即 `e^L/L²≥2`。该比值对L>2递增；在32，`e^32>2^32>2·32²`。
4. `2L<e^L=n`：在32可用 `2^32>64`，之后e^L/L递增。也可用e^L的正项展开直接证明。因此 `0<L/2<x₀<n`，`2n/L>1`。
5. `log2−4/L≥0`：下界严格大于 `1/2−1/8=3/8`。
6. `L³≥e`：由L≥32及e<3即得。

这些阈值都对连续的全部L≥32成立，不能只靠在一个整数维数的浮点测试。`n≥ceil(e^32)`当然推出L≥32。第1条还保证最终选择 `t=n/(L−3log L)` 为有限正数且严格大于1，因为其分母≤L<n。

## 4. 对全部t的三区间下界

任取t>1，则x=n/t恰在(0,n)，以下三段覆盖该区间；端点重叠不影响结论。

**第一段 `0<x≤L/2`。** 此时t≥2n/L。由B单调性和R5在x=L/2处的估计，

```
B_n(t)≥B_n(2n/L)
       ≥nL−n log(L/2)−4n/L
       =T+n log2−4n/L≥T.
```

由于 `F≥B`，该段下界比R1还强。这里使用单调性避免将R5直接用于x趋零时出现的无效巨额扣除，是证明一致性的关键。

**第二段 `L/2≤x≤x₀=L+4log L`。** `log x≤log L+log(1+4log L/L)≤log L+4log L/L`，且 `2n/x≤4n/L`。代R5得

```
F_n(t)≥B_n(t)≥T−4n(log L+1)/L.
```

这不假设x接近真正极小点。

**第三段 `x₀≤x<n`。** A随x增加。由全部s≥0成立的 `log(1+s)≥s−s²/2`（两边之差导数为 `s²/(1+s)≥0`），并用第3节阈值，

```
A_n(n/x)≥(1+x₀/n)^n
         ≥exp(x₀−x₀²/(2n))
         ≥exp(L+4log L−1)=nL⁴/e≥nL≥T.
```

由于 `F≥A`，第三段亦比R1强。无须对x自身做小参数展开；只在固定比较点x₀上应用全s有效的不等式，故x靠近n时同样有效。

因此对每个t>1都成立统一下界 `F_n(t)≥T−4n(log L+1)/L`。取全部t的下确界立即给R1左侧，没有把“找到一个较好参数”误当成全局下界，没有假设极小值在域内取得。

## 5. 明确可取参数的上界及常数5

取 `d=L−3log L`、`t=n/d>1`，合法性已在第3节证明。由 `log(1+s)≤s`，

```
A=(1+d/n)^n≤e^d=n/L³.
```

又因 `B≤1+n log t`，

```
log t=L−log L−log(1−3log L/L).
```

此处 `0≤3log L/L≤1/2`，所以 `−log(1−y)≤2y` 可用，得到

```
B≤T+6n log L/L+1.                                (R6)
```

还需用于交叉项的粗界B≤2nL。因为d≥L/2≥16>1，所以 `log t=L−log d≤L`，故 `B≤1+nL≤2nL`。于是

```
F=A+B+2sqrt(AB)
 ≤T+6n log L/L+1+n/L³+2sqrt(2)n/L.
```

补全作者略写的最后常数汇总：由 `n=e^L>L≥32`，有 `1≤n/L`、`n/L³≤n/L`，且 `2sqrt2<3`（平方验证为8<9）。因此

```
1+n/L³+2sqrt(2)n/L≤5n/L.
```

这给R1右侧。所有余项常数与t无关，因为上界只使用上述明确参数。不需要证明该参数全局最优、证明驻点唯一，也不声称最优t等于该表达式。

## 6. U_n与C_n的逻辑关系

覆盖定理对每个t>1给出 `C_n≤F_n(t)`，所以 `C_n≤inf_t F_n(t)=U_n`。上面证明的双侧渐近只针对U_n。因此可以推出

```
C_n≤n log n−n log log n+O(n log log n/log n),
limsup_{n→∞} C_n/(n log n)≤1.
```

第一行应理解为存在一个固定正常数控制上侧余项；不能由它写出C_n的匹配下界，不能写C_n与U_n渐近等价，更不能称已证明真实最优系数恰为1。报告和论文片段均明确作了此区分，接受其量词。

公式族误差为o(n)的结论比原O(n)加强；但它没有确定真实余项的符号、首个非零项或最优参数更精细的渐近。原文“更精细的主导余项及最优参数渐近未证明”正确。
