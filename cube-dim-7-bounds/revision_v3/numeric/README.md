# Multi-dimensional candidate bounds: independent certificates

For n=2,...,20,32,64, `table.json` contain one rational t>1 per dimension and complete rational enclosures of B_n(t) and F_n(t), with F_n=(sqrt(A_n)+sqrt(B_n))^2 and A_n=(1+1/t)^n. `U` is a strict rational upper bound for F_n. The table's decimal column is informational; the certificate uses the rational t, not a reconstructed decimal. The final paper contains the display rows. The original paper's theorem yields C_n<=F_n(t)<U. Separately t down to 1 yields C_n<=2^n. For n=2 and n=3 the computed candidates do not beat that endpoint; no assertion is made that the endpoint is the global infimum or that an interior minimum exists. For n=1 the same limit is 2. All candidate search values are heuristic: neither a bounded search nor a success flag certifies global optimality.

`generate.py` evaluates the integral using its positive integrand and minimizes over log(t) in [1e-9,20], with at most 94 optimizer evaluations and at most 96 total per dimension. The selected binary rational and every double evaluation appear in `trace.json`. The seven-dimensional point and U are the original paper's values, with one evaluation, and the original verifier also passed. The candidate for n=2 landed close to the search boundary; this is not proof about behavior elsewhere.

`verify.py` is an independent pure-Python exact arithmetic checker: expand the integral into rational terms plus beta*log(t); enclose logs using range reduction to [1,2) and the positive atanh series with a rigorous geometric tail; choose the log endpoint according to the sign of beta; round outwards; enclose square roots using integer square root. It recomputes all four complete rational endpoints and verifies F_upper<U. The expansion can have cancellation, so the log bounds are rounded outward at 210 decimal places before exact rational evaluation. No floating-point numbers are used by the verifier.

Reproduce: `python generate.py` (SciPy required); `python verify.py` (standard library only). `result.txt`, `verification_result.txt`, `trace.json`, `environment.json`, and `resources.txt` record this run. The system `time -l` reported wall/user/system time but could not query kern.clockrate under the sandbox; `verification_result.txt` reports process resource usage measured via Python. The finite-a supplement fixes a=2^256 for each previously selected t (no new search). With u=1/a, it computes exactly A_a=(1+1/t+u)^n and uses E_up=B_up+[((1+u)^n-1)(1+n log_up(t))+u^n] as an upper bound for the finite-a load. The omitted term is nonpositive because the integral I is nonnegative. The rational tau is the upward integer-square-root grid enclosure of sqrt(A_a E_up), not the infinite-a optimizer. The verifier directly checks (1+A_a/tau)(tau+E_up)<U using Fractions, and `table.json`/`table.csv` preserve the full rational values. For n=2,3 this certifies the listed candidate U, not an improvement on 2^n. Run `python add_finite.py` to recompute the supplement from the existing table without repeating the search. Python's integer-string digit limit is disabled only for displaying these exact large rational certificates.
