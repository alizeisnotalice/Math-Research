## 1. 原输入与预算条件

固定同一个一般 L1 输入 f、λ>0、有限个正体积开立方体 Q_i 及 V_i=aQ_i。严格 witness 条件 M_i=∫_(V_i)|f|>λ|V_i| 与 |V_i|≤h_i≤M_i/λ 保证 h_i 有限且严格为正。支付重分配只需 q'_i≥0 和 Σh_iq'_i=|U|：

∫|f|Σq'_i1_(V_i)=Σq'_iM_i≥λΣh_iq'_i=λ|U|。

最后除以原来的 ||f||_1 得负载证书。无需重新构造空间cover flow。h_i 的下界是继承的选择接口条件；上述积分推论自身只需要0<h_i≤M_i/λ。不能允许负系数，不能把h_i移到实际 witness 质量之外，也不能在积分时另换一组质量。h_i=M_i/λ时确为等式。

此论证保留原Lebesgue测度、中心轴平行立方体及所有正尺度、一般L1输入。没有推出新的统一C_n常数或算子下界。

## 2. 正体积 Helly 与最大团

图的边必须是两个**开盒内点相交**，即每一坐标 max(lower_i,lower_j)<min(upper_i,upper_j)。有限团中逐坐标取最大下端点和最小上端点；这两个极值由某两个盒取得，它们严格相交便给最大下端点<最小上端点。因此团的公共交集为正体积开盒。只用闭盒边界接触建边会出错。

任一点的active集合是团，所以实际负载≤最大团权。反向对每个团取其正体积公共交集，非负q确保那里负载至少是该团权。因此esssup=最大团权，且非负性允许仅枚举极大团。对极大团C，公共交集中任意点若还属于一个外部开盒，该外部顶点就与C每点相邻，违背极大性。故该公共交集本身是一个正体积、恰好实现C的incidence cell。

几何mass LP可将小incidence集合的质量移入包含它的极大团cell；每条约束质量不减，总质量不变。反方向每个团cell都可用常密度L1质量实现。故压缩是精确的，不是采样近似。有限性不可省略；无限开盒族的两两相交不自动提供正体积公共交集。

有公共开盒点时M(V)=max|V_i|：任一约束给下界，而把该总质量放入公共交集给可行解。式(6)由Q_i⊂Q(z,(a+1)r_i)及最大半径直接成立。

## 3. Module压缩和边界账单

clique module的外邻接全同，故所有含C中顶点的团可扩展为含全C的团；共同外邻团又都能与C合并。这就给L=max(L_rest,T_C+L_good)。把总支付移到h最大成员k，T'_C=Σh_iq_i/h_k≤Σq_i=T_C，且外邻接保持不变，立即给命题(8)及s_C公式。

一般只有非增。严格下降需要s_C>0与L_rest<L旧峰，且受影响branch达到旧峰；正支付落在较小h上保证s_C>0。等h或未受影响branch仍达到峰值时，不应声称严格下降。

对任意clique，anchor内的active外部顶点分为共同邻居和boundary两组，两组各自为团，因此各自支付≤L_good、Δ。anchor外只剩outside-C项，支付≤L_rest。再用T_C+L_good≤L旧峰，得到(11)的两层上界。两组是否联合成更大团不影响此上界；可能的额外高估正是其保守性。s_C≥Δ足以保证非增，s_C>Δ及L_rest<L旧峰给严格下降。

同时压缩互不相交的真正twin类成立。**LP实现范围须注意：** 若类是在当前正支撑诱导图中识别，删去的零系数在后续LP中必须保持为零；不能把某个解的support类直接用于允许这些系数重新变正的LP。使用完整固定图的twin类，或固定相应support后优化，文中的商图负载约束就是合法且不弱的。该条件来自正文“current positive coefficients”的限定，而非额外几何假设。
