# Phase A independent audit

Scope: 79 frozen completed case JSONs, each accepted case checked once; the three initial incomplete attempts stopped at the Python integer-string digit limit and were retried after raising that limit. Case hash is calculated on a single completely decoded input byte string; final read-only hash comparison found no changed input. `summary.json` records case counts and hashes, `results/` records per-case input hash, PID, elapsed wall and CPU time, peak RSS, graph nodes and stop type.

Independent stdlib Fraction code reconstructs witness budgets from rational geometry and strict open-box intersections, enumerates all maximal cliques with a 2^20 node and 65536 output cap, and compares the complete output to each case. Censored enumeration is explicitly distinct from pass. Every case verifies initial and final payment against recorded U, nonnegative q, true full-graph maximum load, every accepted pair's nonadjacency, exact old/new pair budget, recorded energy and load, and strict lexicographic decrease in (L,Σh_iq_i²). Each final vector and stop tag is verified. For `iteration_cap` the step count is exactly 128. For `stop_pair_coordinate`, every nonedge is independently checked via the exact minimum of a maximum of three affine functions, followed by the energy minimum on the entire minimum-load interval; no lexicographic improvement remains. These checks do not assert pair-choice optimality at each intermediate step.

Result: 79 passed; 50 coordinate stops with 129033 nonedges checked in total, 29 iteration caps, 3827 accepted steps. There are no censored graphs or failed cases. The first invocation inadvertently included registration JSON, and the last accidentally included three summary/registration files; these are noncases, not counted and their failed scratch outputs were removed. Final code filters exact case names. Source geometry and historical U/q are audited as given; the scope does not reconstruct old atoms, original histories, or old LP certificates. No independent judgment on the three newly emitted LP certificates is made here. This is not a C_n result.
