# R070 computation review

The target-coordinate diagnostic is H2(w)=(2ρ)^−1∫1_{|z−w|<ρ+a0} [−log ℓ(z)]²/ℓ(z) dz. The implementation evaluates its closed expression and checks select integrals/one-sided derivatives. A separately implemented 100-decimal split quadrature at one rational state agrees with the closed expression to approximately 7.0e−104; this is one numerical diagnostic, not a rigorous uniform identity or an operator theorem.

Receipt and source hashes, unique index coverage, statuses and recorded counts were checked independently. Pilot: 14 tasks, 157,500 states and 70 source cross-check records; production: 242 tasks, 2,722,500 states and 1,210 cross-check records. Both report all completed. Each width stage has 256 completed tasks and 4,096 model states. The original width stage sets n=2^L, which is a surrogate rather than n=exp(L) for L=log n. The later width_e stage explicitly uses n=exp(L), carries rho(J−1) and centered variance, but at 90 decimal digits very small J−1 contributions can still round away. Both use numerical 32/64-point quadrature, not interval error proofs.

The width-stage Cantelli diagnostics are for the relative fluctuation of ΣH2(w_i), where w_i are modeled target coordinates. They do **not** by themselves establish a Cantelli lower-retention bound for the theory's V=Σφ_i or certify the exceptional-set/full-cover interface. A separate fixed-source-face variance theorem plus its hypotheses and finite guards is needed; results on ΣH2 do not substitute for it. The separate R071 geometry draft was reported to derive such a fixed-face bridge for a specified parameter set, but this review does not independently accept that draft or extend it to the full frontier4 grid.

Frontier4 records all 1,280 receipt hashes, 7,556,400 domain rejections, 1,251,011 payment rejections and 1,678,349 eligible points, totaling 10,485,760. Its screening is double precision, and its post-run selected-candidate recheck is 120-digit numerical arithmetic using an S64 positive exponential prefix; neither is a strict interval certificate. The current highest recheck candidate has L=40448/5<8192, qmax=11569/12800, σ=25/256, χ=63/1280, D=768; it is not the fixed parameter set reported for R071 (L≥8192, qhi=.91, σ=.09, χ=.045, D=256). Binding a candidate to an applicable frozen theorem and checking all finite gates remains necessary. Display decimals must not be used as exact inputs to a proof.

The existing archive manifest's 16 member hashes and all compressed original UTF-8 receipts independently match the current four archived stages (14 pilot, 242 production, 256 width and 256 width_e). The separately produced frontier4_archive was subsequently verified: its eight manifest entries, 1,280 compressed original receipts, total counts, float top64 merge, and recheck source and summary hashes all match; `frontier_archive_check.json` records that independent archive check. Both `check.json` and `archive_check.json` record actual independent runtimes, source/summary hashes and resource metadata. Worker CPU totals and per-process RSS maxima are taken from receipts; CPU samples are samples, not average guaranteed utilization. No integrations were replayed except the single stated diagnostic.
