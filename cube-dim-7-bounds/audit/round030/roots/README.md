## 1. 精确公式与符号等价

记 D=B_n'(t)>0，A=(1+1/t)^n，B 为主稿原积分公式。对积分核按有限二项式展开，j=0项给 q^(n−1)log t，其余项为

S=sum_{j=1}^{n−1} binom(n−1,j) q^(n−1−j)(−1/2)^j(1−t^(−j))/j，q=1+1/(2t)。

因此被审脚本中的 B=1−h^n+n log t−n(S+q^(n−1)log t)/2 与原定义完全相同，h=(1+1/t)/2。

由 A'=−nA/[t(t+1)]，

F'=(sqrt A+sqrt B)[D/sqrt B−n sqrt A/(t(t+1))]。

所有参与比较的量都严格为正，所以

sign F'=sign H，H=[t(t+1)D/n]^2−AB。

平方没有引入伪根。若 K=t(t+1)D/n，则

H'=2K[(2t+1)D+t(t+1)B'']/n−A'B−AD。

脚本令 t(X)=T+X，使用截断长度3的 Arb 形式幂级数获得 B[1]=D、2B[2]=B''，再用长度2的 A、B、D 计算 H，故返回的 H[1] 正是 H' 的包络。这里不是用一条在整个盒上收敛的数值 Taylor 近似：每个形式系数通过区间运算同时包住所有中心 t∈T 的对应导数。因盒均处于 t>1，逆元及实 log 的定义域合法。512位精度影响包络宽度，不影响向外包络的严格性。

## 2. 分支与覆盖审查

初始有理分割覆盖 [1+1/(4n2^n),4n]。每次二分将一个闭盒替换为两个在精确有理中点相接的闭盒。分支仅有：

* H 在整个闭盒严格同号：该盒无根。
* H' 在整个闭盒严格同号，且两个精确端点的 H 同号：由单调性无根。
* H' 严格同号且两端 H 异号：连续性与严格单调性给恰好一个根。
* 否则二分；达到资源限制仍保留队列，异常也保存至残余清单。

不存在静默丢弃异常盒的路径。严格端点符号同时排除了共享边界上的遗漏根。只有队列及异常清单都为空才允许根完整性结论。

## 3. 端点和尾部对全部整数 n≥2 充分

本轮 `parameter_theory/proof.md` 第5节所用导数表示给 D>0。

尾部 t≥4n：D≥n/(2t)、B<1+n log t，故 t²>4(1+n log t)(1+1/t)^(n−2) 足以推出 F'>0。指数因子≤e^(1/4)<4/3；后一严格不等式可由 e^x<1/(1−x) 在0<x<1直接得到。t²/(1+n log t)在 t≥4n 递增。所需边界比较化为 3n>1/n+log(4n)，n=2时可用 log8<3 作严格验证，而差的实变量导数为3+1/n²−1/n>0。因此整条尾部成立，不只在一个样本点成立。

端点令 δ=t−1≤2^(−n)/(4n)。核在积分域内属于(0,1]，故 J≤log t≤δ，进而

D≤n+n(n−1)δ/4，B≤nδ[1+(n−1)δ/8]，D≥n/[2(1+δ)]。

n≥2时 δ≤1/32、nδ≤2^(−n)/4、(n−1)δ/8≤1/128。于是

B(1+δ)²≤2^(−n)(1+1/128)(33/32)²/4<2^(−n)。

负导数项 n t^(−2)(1+1/t)^(n/2−1)≤n2^(n/2−1)，而上述式子使 D/sqrt B 严格大于该数。这就给出整个近端区间 F'>0。最后一个常数比较在独立脚本中以有理数实际核验。

## 4. 唯一全局极小参数的闭合

两条解析半无限区间与有限根隔离区间无缝覆盖 t>1。因此 n=4,7 的 F' 全域仅有上述两个零点，符号为 +、−、+，驻点类型分别为严格极大和严格极小。

原 `revision_v3/endpoint/proof.md` 的 F_n(2)<2^n 证明已单独审核：n=4 的 B_4(2)=(1841+72log2)/768 由独立 SymPy 有限积分展开核对，且 log2<1 给 sqrt A+sqrt B<9/4+7/4=4。n≥5 的 δ_n=2^(n/2)−(3/2)^(n/2) 归纳中，δ_5²=1267/32−18sqrt3>259/32>6>1+5log2，δ_(n+1)>sqrt2 δ_n，均正确。因此特别适用于 n=7。

再由 F(1+)=2^n、F(t)→∞ 与连续性，全局极小值在内点取得；该点必须是驻点，严格极大点不能取得全局极小值，只能为第二根。故全局极小参数唯一。这里的唯一性是该固定一参数上界公式族的结论，与真实 C_n 是否等于 U_n 无关。
