# 第67轮：外域反演控制完整集中来源；有界密度阻止全局覆盖

日期：2026-10-10。**一般维度无关 weak-(1,1) 上界仍未证明。** 本轮从任意有限正Radon来源测度直接出发，处理第66轮未覆盖的“集中块内部只捕获部分来源”问题，证明一个阈值相关的完整极大水平集界。另给出光滑输入的解析障碍：不能要求所有实际任务都由这类集中子块见证。这里的定理是本项目新增的已证明工具，不宣称文献首创。

## 1. 准确结论与适用条件

设Q是Rⁿ上的有限正Radon测度，q=Q(Rⁿ)>0，α>0，

r=(q/(αω_n))^{1/n}，　supp Q⊂B[c,ρ]。

所有半径均使用中心开球定义M_nQ。证明

α|{M_nQ>α}| ≤ 2q(1+ρ²/r²)^{n/2}。　　　　　　　　　(1)

特别，若ρ≤r/√n，则

α|{M_nQ>α}| ≤ 2√e q。　　　　　　　　　　　　　　　(2)

更一般，nρ²/r²≤κ时右端≤2e^{κ/2}q，κ可为任意正数。常数不依赖来源的原子数、内部对称性、坐标独立性、局部doubling或支撑内的质量形状。

(1)对任意有界支撑成立，但其右端可能随n迅速增长；(2)才是一个维度无关的**集中分支**。集中条件依赖α：固定q、ρ时，相当于α≤q/[ω_n(√nρ)^n]。不满足该条件的任意输入仍属于主问题，未被排除。

本结论控制全部{M_nQ>α}，而非只控制所有来源同时入球的整块见证区A_α(Q)。证明不把Q先原子化，因此不存在从特殊有限模型推广到一般密度的步骤。

## 2. 反演给出的准确外域积分

**引理。** R>|y−c|时，

∫_{|x−c|>R}|x−y|^{−2n}dx
 =ω_n R^n/(R²−|y−c|²)^n。　　　　　　　　　　　　　(3)

证明：令b=y−c、u=x−y、z=u/|u|²。反演导数是

D_z/D_u=|u|^{−2}(I−2uuᵀ/|u|²)，

括号内是沿u反射的正交矩阵，因此Jacobian绝对值为|u|^{−2n}。记A=R²−|b|²>0，外域条件变为

|u+b|²>R² ⇔ 1+2b·z−A|z|²>0
 ⇔ |z−b/A|²<R²/A²。

这是球心+b/A、半径R/A的球，删去z=0不改变体积。反演在非零点光滑且互逆，变量代换直接给(3)。该论证对n=1也成立；不使用有维度损失的球面逐点估计。

## 3. 对完整极大算子的正核支配与外域二阶矩

令ν=Q/q。对于任意t>0和x，逐点有

1_{|x−y|<t}/t^n ≤ |x−y|^{−n}。

所以在|x−c|>R>ρ上，

M_nQ(x)/α ≤ H(x):=∫(r/|x−y|)^n ν(dy)。

这是对全部半径取上确界后的支配，不依赖达到上确界的球，也不要求球捕获整个Q。由于外域与来源支撑有正距离，H在那里有限。Jensen给

1_{M_nQ>α} ≤ H² ≤ ∫r^{2n}|x−y|^{−2n}ν(dy)。

非负Tonelli与(3)给出准确的分布敏感上界：

α|{M_nQ>α}|
 ≤q(R/r)^n [1+∫(r²/(R²−|y−c|²))^n ν(dy)]，　R>ρ。　(4)

其中第一项支付观察球B(c,R)内的全部体积；第二项支付球外水平集。边界球面为零Lebesgue体积。没有把按ν抽样的概率当作观察球心的体积。

取R²=r²+ρ²，则R>ρ，且R²−|y−c|²≥r²。于是(4)中的括号≤2，得到(1)。再由log(1+s)≤s得(2)。ρ=0时同样合法；所得常数2不是单点质量的最佳常数1，本轮不声称常数最优。

本证明允许奇异来源和任意非对称连续来源。零质量测度的结论平凡。来源若无界，则不能直接选择这样的R；空间或质量截断的剩余部分必须另证预算，不能视为本定理已覆盖。

## 4. 球面矩的独立交叉公式

反演证明不依赖本节。为独立检查(3)的指数和常数，记U为S^{n−1}的均匀方向，0≤a<1，则

E|U−ae₁|^{−2n}=(1+a²)/(1−a²)^{n+1}。　　　　　　　　(5)

可由偶矩E U₁^{2k}=(1/2)_k/(n/2)_k推导。n≥2时该偶矩由球面纬度积分及分部积分递推得到；n=1时U₁=±1，公式仍成立。展开

(1+a²)^{−n}(1−[2a/(1+a²)]U₁)^{−n}，

因为2a/(1+a²)<1，级数绝对一致收敛，可以逐项平均。奇次项为0，使用(n)_{2k}=2^{2k}(n/2)_k((n+1)/2)_k及(2k)!=2^{2k}k!(1/2)_k，得到

(1+a²)^{−n}Σ_{k≥0} [((n+1)/2)_k/k!][4a²/(1+a²)²]^k，

求和即(5)。其中(a)_k表示升阶乘，k=0取1。再利用

(d/dt)[t^n/(1−a²t²)^n]
 =n t^{n−1}(1+a²t²)/(1−a²t²)^{n+1}

完成径向积分，可重得(3)。程序另用奇数维的有理纬度积分计算(5)，没有只把左右同一表达式互相比对。

## 5. 不能把支撑半径直接换成方差

第66轮的方差证书适用于整块交球几何。本轮(3)要求来源点全部处于积分域的内侧，因此不自动容纳方差替换。

例如r=1，Q=(1−ε)δ₀+εδ_{Le₁}，L=2，0<ε<1/16。若以均值c=εLe₁为心、σ²=ε(1−ε)L²为方差，取所谓R²=1+σ²，则远原子距离c为(1−ε)L，其平方大于R²。外域包含远原子的邻域，因而

∫_{|x−c|>R}|x−Le₁|^{−2n}dx=∞。

σ可以趋零，但该外域二阶矩仍发散。这否定的是“把ρ替成σ后照搬本证明”的步骤，**不是**对某个尚未证明的方差弱型估计的反例，更不是C_n发散的反例。若连续输入在外域某个开集上密度为正，H的|x−y|^{−n}核还会在这些x处局部不可积；不能未经来源截断就全空间使用这个正核。

## 6. 集中子块不能覆盖任意输入：严格密度障碍

**命题。** 设P=f dx，0≤f≤Lα，且n^{n/2}>L。不存在非零Q≤P以及c、ρ，使

supp Q⊂B[c,ρ]，　ρ≤(q/(αω_n))^{1/n}/√n。　　　　　　(6)

证明：ρ=0时因P无原子而q=0；ρ>0时

q≤P(B[c,ρ])≤Lαω_nρ^n，

而(6)要求q≥αω_n n^{n/2}ρ^n，与n^{n/2}>L矛盾。此结论允许Q为任意子测度，包括任意部分来源及任意分数密度；并非只否定预先指定的团块划分。

如果把阈值改成θα，0<θ≤1，必要条件变成L≥θ n^{n/2}。例如L=3/2时，想靠降低阈值产生集中子块，至少要令θ≤(3/2)n^{−n/2}。在直接水平集覆盖中支付1/θ会留下巨大维度损失；没有证明其他机制能补回这笔费用。

### 障碍输入确实有正体积的真实首次任务

取n≥3，L=3/2，沿用真实网格V_j=8/(α2^j)，R₁^n=4/(αω_n)。在0附近放密度3α/2、质量1/4的均匀球；在10R₁e₁附近放相同密度、质量3/4的另一均匀球。两球的半径相对于R₁分别为

a=24^{−1/n}，　b=8^{−1/n}。

将整个概率密度与支撑半径ηR₁的非负光滑概率核卷积，其中

0<η≤min(a,1−a)/8。

两来源仍分离，总质量1、密度≤3α/2。在近中心半径ηR₁的观察球内：

- R₁球完整捕获近质量1/4、排除远来源，故g₁=α/16≤α/8，J≥2。
- 取D=n+6，有(R_D/R₁)^n=2^{1−D}<(a/2)^n，因此R_D<aR₁/2。
- 因观察偏移与平滑半径之和≤aR₁/4，整个R_D球落在保留的常密度平台内，故g_D=3α/2、K_{α/2}≤D。
- 任意半径平均≤3α/2；平台内足够小的球平均恰为3α/2，所以M_nP=3α/2。

因此该正体积观察球确实属于E={α<M_nP≤2α,J≥2,K_{α/2}≤D}。与此同时n^{n/2}>3/2，任何非零Q≤P都不满足(6)。这直接排除“每个实际任务总能交给某个阈值α下的集中子块”这一全局覆盖接口。

## 7. 对主线的作用与下一步接口

新增工具把集中来源的完整极大集，包括所有部分捕获，直接转为源点平均的可积外域二阶矩。在这一分支中不再需要逐个枚举来源子集、球族交集或首次捕获标签。

它没有给一般P的全尺度绝对常数。首先，集中条件不对任意限制切集保留：即使P整体很集中，取支持内两个相隔正距离的小区域并让其质量趋零，Q=P|U的包围半径仍有正下界，而r_Q趋零。其次，第6节给出根本没有集中子块的光滑输入。最后，即便有很多集中块，分别估计M Q_i也不能无条件相加弱L¹准范数。

因此下一步需对非集中、尤其是密度接近阈值的来源建立直接体积预算，并与来源截断/反演外域预算拼接，完整支付截断余量及跨块相互作用。第66轮的整块几何衰减尚不能代替这一“部分来源”预算。当前没有新的全一般弱型上界，也没有随维数发散的真正弱型下界。

## 8. 实际执行的三批核验

使用本机Python标准库Fraction整数有理算术，按math-l03-rational-and-interval-certificates的证书工作流核对残差方向；不把skill中的文献索引当作本轮定理依据。程序独立，无第三方依赖；Python版本及自身SHA-256见verification.json。

1. **反演与Jacobian：** 三批维数(1,2,3,4)、(8,16,32)、(64,128,256)，每维8个有理点，种子670000+n。共80次准确核验外域/球内的带符号等式、反演互逆、导数对向量长度的缩放。n≤4另作32次高斯消元行列式核验；高维未声称枚举矩阵行列式。
2. **独立角向积分：** 三批奇数维(1,3,5)、(9,17,33)、(65,97,129)，a=0、1/5、1/2、9/10。共36次有理球面矩核验。n≥3用纬度密度(1−t²)^{(n−3)/2}及代换v=1+a²−2at，把积分化为有限有理幂次积分；n=1直接平均两点。覆盖近边界和中心基准。
3. **真实全半径正核支配：** 三批中的偶数维，随机不等权8来源，坐标为[-4,4]整数除以4n，确保每个来源距离≤1/√n。观察点半径3/4、1、5/4、2。32次精确按距离平方排序、合并同距、累计质量并取右极限最大值，核验M/α≤H及H²≤E核平方。这里归一化αω_n=q=1；未用粗半径网格冒充极大值，亦未声称这些观察点代表完整高维体积。
4. **一维完整水平集：** 三批来源数4、16、64，各5组，种子671000+100b+t，正随机有理权；每组α=1/8、1/2、2，共45个完整体积检查。枚举排序来源的全部连续子段S，其见证区为(max S−q_S/(2α), min S+q_S/(2α))，合并区间计算整个{M_1Q>α}。任何区间捕获的来源必为连续子段，因此是全空间精确值。逐项核验(1)的平方形式，无根式近似。
5. **光滑密度障碍的几何证书：** 三批n=(3,4)、(16,32)、(128,256)，用80位二进制向外有理根区间选择η，核验R₁完整捕获、R_D平台余量、D=n+6及n^n>9/4。六例通过。连续密度平台上的全半径值由第6节的密度上下界证明；未用离散采样代替连续积分。

三批全部断言通过。一般n及一般来源的结论依据第2、3、6节的解析证明，有限检验仅验证计算接口。未重跑所有历史轮次，不保存可再生的全量点表或中间搜索输出。
