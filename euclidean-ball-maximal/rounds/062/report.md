# 第62轮：容量余量下的可求和重分配引理

2026-10-08。目标仍是任意非负L¹输入的中心欧氏球极大算子维数无关 weak-(1,1) 上界，**本轮没有证明主定理**。

第61轮证明，精确最优分配的旧任务搬移量不能按新增需求线性控制。本轮找到一个成立的替代工具：给定容量C的旧分配与完整目标分配，允许(1+ε)C后，可以在一般来源测度上控制搬移量≤(1−ε)δ/ε。固定最终目标时，多批新增也能在同一个容量下累计结算。真实链的精确公式说明1/ε阶必要。

## 1. 精确假设与可用范围

来源空间Y、旧任务空间T和新增任务空间均为标准Borel空间，P为有限正来源测度，d为有限旧需求测度，新增需求总质量为δ。每个任务t有指定的合法来源集合S_t。分配是任务×来源的正测度，任务边缘必须等于需求，并集中在合法关系{(t,y):y∈S_t}上。

已经给定：

- 旧分配B，其来源边缘b≤CP；
- 同一旧需求的目标分配T_old，以及新增需求的目标分配T_new；
- 它们的来源边缘满足T_old^col+T_new^col≤CP。

C是给定可行容量，不在此假设它已对全部欧氏球输入一致有界。若旧、新任务有相同几何标签，可使用带“旧/新”标记的不交任务空间。

实际欧氏球任务仍采用第60—61轮的E_P、共享β、首次K_β和原来源球。对有限截止D，其需求有限，且任务和来源都可放在标准Borel空间中。下面的引理直接适用于任意P及满足上述容量条件的分配，不依赖原子数、几何维数、对称性或局部doubling比。它不声称独立构造出了所需的统一容量目标分配。

## 2. 一般测度重分配定理

**定理。** 对0<ε≤1，存在保持每个任务合法来源及全部需求的分配，使来源边缘≤(1+ε)CP，旧分配的半总变差距离不超过

(1−ε)δ/ε。

ε≥1时保留旧分配、加入目标新增分配即可，容量≤2CP，无需搬移旧任务。

### 2.1 构造合法的转移核

对旧任务边缘d作条件分解：

B(dt,dy)=d(dt)B_t(dy)，T_old(dt,dy)=d(dt)T_t(dy)。

B_t、T_t均为d几乎处处定义的概率核，并支撑于同一S_t。定义来源转移测度

F(dy,dz)=∫B_t(dy)T_t(dz)d(dt)。

其第一边缘为b，第二边缘为T_old^col。沿第一边缘分解F=b(dy)K(y,dz)，于是K是b几乎处处的Markov核，

bK=T_old^col。

记a=T_new^col，所以a(Y)=δ且a+bK≤CP。在b零质量处如何延拓K不影响下文。

### 2.2 有容量截断的收缩固定点

设θ=1−ε。对0≤r≤b，定义

Γ(r)=min{b,θ(a+rK)}。

这里所有来源测度均相对于P绝对连续，min表示对其P密度逐点取小者。确实，r≤b给rK≤bK≤CP，因此每一步合法。

区间{0≤r≤b}是L¹(P)中的闭集。Markov核在总变差范数下非扩张，固定障碍b的逐点截断也非扩张，故

‖Γ(r)−Γ(s)‖_TV≤θ‖r−s‖_TV。

ε>0时θ<1，因此存在唯一固定点r。也可从r_0=0开始单调迭代，得到r_m↑r，并且

‖r−r_m‖_TV≤θ^m‖r‖_TV。

这给出了收敛与截断误差，而非仅形式上的无限求和。

### 2.3 实施撤出及重新分配

令f=dr/db，0≤f≤1。每个旧任务撤出比例

q_t=∫f(y)B_t(dy)，

将撤出量按同一任务的目标核T_t重新分配：

B'_t(dy)=(1−f(y))B_t(dy)+q_tT_t(dy)。

它仍为概率核，仍支撑于S_t。撤出来源边缘为r；重新注入来源边缘为rK。这一步只改变合法旧任务内部的来源分配。新增任务直接采用T_new。

令g=a+rK。最终来源边缘为b−r+g。由r≤b，g≤a+bK≤CP。固定点在每个来源有两种分支：

- r=b时，最终边缘密度为g≤CP；
- r=θg时，最终边缘密度为b+εg≤(1+ε)CP。

故容量满足结论。

每行撤出与注入的总量相同，三角不等式给

½‖B'−B‖_TV≤r(Y)。

这里‖·‖_TV采用有符号测度总变差质量的约定，因此对等质量正分配的“搬移量”为其一半。又由固定点

r(Y)≤θ(δ+r(Y))，

所以r(Y)≤(1−ε)δ/ε。证毕。

此证明不依赖无限维强对偶，也不需要先证明存在最优分配；只使用已经给定的B及T。完全相同的证明可将CP换成任意给定有限容量测度ν，得到(1+ε)ν。

## 3. 固定目标时，多批费用可真正累计结算

预先固定最终目标T_old、T_new及原旧分配B。让新增任务依次到达，其目标来源边缘a_t按测度单调增加，最后等于a。始终使用同一个b、K、C和ε，而不是把上一步输出当作新基准后重新放大容量。

令r_t是min{b,θ(a_t+r_tK)}的固定点。由从零迭代的单调性，s≤t时r_s≤r_t。相应的旧分配B_t'用第2.3节同一公式及相同条件核构造。两时刻的撤出比例之差非负，因而

½‖B_t'−B_s'‖_TV≤(r_t−r_s)(Y)。

沿任意有限时间分割求和，右侧望远镜相消。因此旧任务全路径总搬移量≤r_final(Y)≤(1−ε)δ/ε，每个时刻的容量都≤(1+ε)CP。新增任务从加入起始终使用其固定目标核，本身无需重复搬移。

这是允许预先固定最终目标的结论，不是未知未来任务下的在线算法。若每一步更换目标T、转移核K或原基准B，则上述望远镜论证不再自动成立。也不能将本定理逐步以(1+ε)C作为新的C，从而隐藏容量的连乘。

## 4. 第61轮真实链的精确容量—搬移权衡

沿用N个等质量w来源、N−1条相邻旧任务（每条需求a），以及新增来源0的单点任务需求a。旧容量最优分配中，边j（连接j−1和j，1≤j≤N−1）向左质量为

b_j^old=a(1−j/N)。

新精确最优容量是C=a/w。现在允许每个来源容量质量(1+ε)a。令新边向左质量为b_j。

来源0约束给b_1≤aε；后续来源给b_j≤b_{j−1}+aε，所以b_j≤jaε。每条旧边的搬移至少为[b_j^old−jaε]_+。取

b_j=min{a(1−j/N),jaε}

可以达到这些下界：首点容量满足约束，后续相邻差b_j−b_{j−1}≤aε，末点容量≤a。因此最小搬移量恰为

R_ε=aΣ_{j=1}^{N−1}[1−j(ε+1/N)]_+。

设τ=ε+1/N、m=max(0,ceil(1/τ)−1)，则

R_ε/a=m−τm(m+1)/2≤1/(2τ)≤1/(2ε)。

最后的不等式也可由递减函数(1−τx)_+的积分上界得到。当ε→0且Nε→∞时，εR_ε/a→1/2。因此普适搬移界中的1/ε阶不能改成o(1/ε)。这并不声称第2节的系数最优。

若端点任务逐步增加到ta（0≤t≤1），始终保留同一最终容量(1+ε)C，则最优边左流为

b_j(t)=min{a(1−j/N),a(1−t+jε)}，

总搬移为aΣ_j[t−j(ε+1/N)]_+。各边左流随t单调下降，因此全路径费用仍恰为R_ε，没有分批次数因子。

第61轮已将整条链及新增任务实现为同一光滑一维概率输入的真实首次越阈子任务，质量a=24/(30625N)、w=8/(35N)，只涉及相邻两个捕获尺度。故上述必要的1/ε阶并非仅抽象超图障碍。这里仍是子任务的分配权衡，不是完整E_P的弱型下界。

## 5. 精确算法及三批验证

复现环境Python 3.14.6，仅标准库Fraction；未依赖浮点优化器。运行：

```sh
cd euclidean-ball-maximal
python3 rounds/062/verify.py > /tmp/euclidean-round62-full.json
```

有限矩阵中，K由旧行与固定目标行组成。为避免把有限次迭代当成精确固定点，代码采用障碍活跃集法：先将所有r_i固定在b_i，释放满足θg_i<b_i的坐标，对释放集精确求解(I−θK^T)的子矩阵系统。该逆为非负Neumann级数；每次释放使r逐坐标下降，已释放坐标不重新达到上障碍，至多N次释放阶段终止。最终逐坐标验证r_i=min(b_i,θg_i)，并独立验证每行质量、来源支持、列边缘和搬移上界。返回数值只是证书；一般结论来自第2节证明。

## 6. 到主目标还差什么

本轮消除了“精确最优长交换链使任何搬移预算都失败”这一过强障碍：保留固定容量余量和固定最终目标后，可以无来源数损失地结算搬移。但一般真实球任务是否有绝对容量C的目标分配，仍未证明。将未知目标分配作为本引理的前提不能当作完成主定理。

下一步需要从完整球任务的几何、真实记录接受和来源质量构造目标分配，或证明其容量上界；本引理可以支付该构造中的扰动重分配，但不能取代容量证明。第61轮删源产生的ρlog(1/ρ)资格边界损失也没有被本引理处理，因为这里任务需求及合法支持在旧任务上保持不变。
